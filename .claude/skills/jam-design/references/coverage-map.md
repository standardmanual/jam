> 신설 문서 (티켓 20260918_0423). 채원(`jam-designer`)의 ④ 디자인 크래프트 모드가 화면 ×
> 품질 기준으로 점검한 결과를 누적하는 표다. **요청할 때만** 실행하는 모드이며, 칸별
> 점검일·결과를 쌓아 같은 칸을 다시 보지 않는다.

## 점검 대상 (화면 축)

첫 경험(로그인·온보딩·연동) · 홈 · 보상(배지 목록/상세/획득 연출/미획득) ·
수집(인벤토리·컬렉션·아이템북) · 경제(믹스·미션·포인트·랭킹) · 지도(드랍·픽업·만료) ·
소통(알림·리캡·공유) · 내 정보 · 공통 상태 · 앱 겉모습

## 점검 기준 (품질 축)

시각 · 심미 · UI 디테일(모든 상태) · 모션·피드백 · UX 흐름 · 기기·환경 · 접근성 · 일관성 ·
게임 설계 윤리

## 진행 방식

1. 사용자가 범위(화면 축 중 1개 이상) 지정
2. 코드 먼저 읽고, 필요한 화면만 캡처
3. 결과표 + 개선 제안 Top 5(텍스트 배치도) + 불일치 목록 산출
4. 사용자 채택 → 티켓 생성
