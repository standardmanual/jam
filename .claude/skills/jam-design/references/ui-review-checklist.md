## 0. 먼저 볼 것 — 사전 판정과의 대조

채원① 사전 판정이 있으면 그것이 기준이다. 없으면 이 절은 건너뛴다.

- [ ] `components` — 판정한 컴포넌트를 그대로 썼는가 (새로 만들었다면 **중대**)
- [ ] `tokens` — 판정한 토큰을 그대로 썼는가
- [ ] `states` — 사전 판정에 적은 상태가 전부 구현됐는가 (누락은 **중대**)
- [ ] `layout` — 배치도와 눈에 띄게 다르지 않은가 (다르면 **중대**)

---

## 1. 접근성 — 위반은 전부 **중대**

- [ ] **대비**: 본문 텍스트 4.5:1, 18px 이상·굵은 글씨 3:1, UI 경계·아이콘 3:1 이상
- [ ] **터치 영역**: 누를 수 있는 모든 요소가 44×44px 이상 (시각 크기가 작으면 패딩·`::before`로 확보)
- [ ] **라벨**: 아이콘만 있는 버튼에 `aria-label`, 입력에 연결된 `<label>`, 이미지에 의미 있는 `alt`
      (장식 이미지는 `alt=""`)
- [ ] **키보드·포커스**: 포커스 링을 지우지 않았는가. 지웠다면 대체 표시가 있는가
- [ ] **색만으로 정보를 전달하지 않는가** (희귀도·상태는 색 + 텍스트/아이콘)
- [ ] **모션**: `prefers-reduced-motion`에서 큰 움직임이 꺼지는가

## 2. 토큰 준수 — 위반은 **중대**

- [ ] 색상: `design-system/tokens/colors`에 대응 토큰이 있는데 `#hex`·`rgb()`를 직접 썼는가
- [ ] 간격: 토큰 스케일 밖의 임의값(`13px`, `p-[7px]`)을 썼는가
- [ ] 타이포: 정의된 타입 스케일 밖의 `font-size`·`line-height`를 썼는가
- [ ] 라운드·그림자·모션: 대응 토큰 대신 직접 값을 썼는가

> 토큰이 **없어서** 직접 값을 쓴 경우는 중대 문제가 아니라 **신규 토큰 제안**이다. 사용자에게 올린다.

## 3. 레이아웃 — 제안

- [ ] 작은 화면(360px)에서 잘리거나 겹치지 않는가
- [ ] 안전영역(노치·홈 인디케이터)과 하단 탭바를 침범하지 않는가 —
      오버레이는 `src/lib/uiOverlay.ts`의 하단 점유 높이 신고를 쓴다
- [ ] 정렬 축이 일관된가. 습관적 가운데 정렬로 읽기 흐름이 끊기지 않는가
- [ ] 여백이 관계를 표현하는가 (묶인 것은 가깝게, 다른 것은 멀게)
- [ ] 긴 텍스트·긴 배지 이름에서 레이아웃이 무너지지 않는가

## 4. 상태 — 제안 (사전 판정에 적힌 상태 누락은 **중대**)

- [ ] 로딩 — 스켈레톤/스피너가 있고 레이아웃이 튀지 않는가
- [ ] 빈 상태 — 무엇을 하면 채워지는지 알려주는가
- [ ] 오류 — [현상] → [원인] → [해결책] 3단계 구조인가
- [ ] 비활성·선택·눌림 — 시각적으로 구분되는가
- [ ] 경계값 — 0개, 1개, 아주 많음, 아주 긴 이름

## 5. 모션·피드백 — 제안

- [ ] 누른 즉시 반응이 있는가 (100ms 이내)
- [ ] 전환 길이가 토큰 범위 안인가. 과하게 길지 않은가
- [ ] 애니메이션이 의미를 갖는가 (어디서 와서 어디로 가는지)

## 6. 시각 슬롭 — 제안

걷어낼 것: 의미 없는 그라디언트·유리질 효과 · 뜻 없는 아이콘 · 습관적 가운데 정렬 ·
재고 이미지 느낌 · 근거 없는 강조

## 7. 일관성 — 제안

- [ ] 같은 역할의 요소가 다른 화면과 같은 모양인가
- [ ] 이 서비스 전용 UI가 이미 두 곳 이상에서 쓰이는가 → **MODULAR 승격 후보**
- [ ] `design-system/components/**`를 고쳤다면 대응 `*.stories.*`도 고쳤는가

## 8. 게임 설계 윤리 — 제안

- [ ] 가짜 긴급감(진짜가 아닌 카운트다운)을 만들지 않았는가
- [ ] 확률·조건을 유저가 알 수 있게 표시하는가
- [ ] 실패를 조롱하지 않는가

| 분류 | 처리 |
|---|---|
| **중대 문제** | 접근성 위반 · 토큰 있는데 직접 입력 · 사전 판정과 눈에 띄게 다름 · 사전 판정 상태 미구현 → 재작업 |

| **승격 후보** | 반복 사용되는 서비스 전용 UI |
