# 자동화 목록

> 자동화 목록과 담당 배분이다. 스크립트 자체는 각 파일이 원천이다.

**원칙:** 판단은 에이전트가, 정해진 절차는 스크립트가. 쓰기는 DB 직접이 아니라 **어드민 API**를
통한다 (권한 검사·검증 로직을 그대로 탄다).

## 1차 (도입 시 함께 만든다)

| # | 자동화 | 담당 | 내용 |
| --- | --- | --- | --- |
| A1 | `verify` | 아현·민지 | lint·타입·테스트 전체·`token-refs`·**슬롭/금칙어 검사**. 통과/실패와 실패 항목만 출력 |
| A2 | diff 정리 스크립트 | 민지·아현 | 잠금·생성·대용량 파일을 뺀 diff와 변경 요약 전달 |
| A3 | 현황판 생성 | 카리나 | 티켓 상태값(OPEN·IN_PROGRESS·WAITING)에서 진행 중·승인 대기 목록 자동 생성 (세션 시작 hook). 저장 위치·형식은 `dashboard-format.md` |
| A4 | 승인 후 처리 | 카리나 | 오염 검사 → 머지 → 티켓 종료 → (사용자가 push를 요청하면) push 1회 → 배포 확인 |
| A5 | **어드민 API 읽기** | 카즈하 | 지표·미션·드랍·배지·유저 현황 조회. **DB 전체 권한 불필요** |
| A6 | 작업 공간 정리·준비 | 아현 | 오래된 worktree 정리, 패키지 재설치 방지 |
| A7 | push hook | 전원 | 리뷰 브랜치 push 시 `verify` 실행 |

## Slack 채널

| 채널 | 용도 | 휴대폰 푸시 |
|---|---|---|
| `#jam-alert` | 즉시 알림급 위험(장애·비용 급증·개인정보·경제 붕괴), 예약 작업 전체 실패 | 켬 |
| `#jam-report` | 주간·월간 리포트 요약 3~5줄 + 리포트 링크 | 끔 |

채널 ID는 `scheduled-jobs.md` 「Slack 알림」 절에만 적는다(단일 원천).

두 채널 모두 공개 채널이다(사용자 결정). 글 내용은 요약 3~5줄 + 리포트 링크이며 개인 식별 정보는 쓰지 않는다.
예약 작업의 외부 발행 금지에서 **이 Slack 알림만 예외**다. 게시 규칙은 `scheduled-jobs.md` "Slack 알림".

## 제외한 자동화

- 유저 제재·데이터 변경·경제 수치 변경의 자동 실행

## 안전장치

- 쓰기 자동화는 **승인된 항목만** 실행한다. 스크립트가 새 항목을 만들지 않는다.
- 유저 제재·데이터 변경·경제 수치 변경은 자동화 대상에서 제외한다.
- 모든 자동 실행은 결과를 기록하고, 실패하면 카즈하가 다음 점검에서 잡는다.
