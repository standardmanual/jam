- 유저 제재·데이터 변경·경제 수치 변경의 자동 실행

## CLAUDE.md 자동 포함 — 선택 제외 불가 (정정, 2026-09-18)

설계 원본은 "아현·민지 외 6개 에이전트는 `CLAUDE.md`를 제외해 호출당 8.4KB를 절감한다"를
전제했으나, 티켓 20260918_0422에서 **기술적으로 불가능함을 확인해 포기했다.**

- `.claude/agents/*.md`의 공식 frontmatter 키는 `name`·`description`·`tools`·
  `disallowedTools`·`model`·`permissionMode`·`skills`·`memory`·`maxTurns`·`isolation`뿐이며,
  프로젝트 `CLAUDE.md` 자동 주입을 제어하는 키는 없다 (Claude Code 공식 문서 확인).
- 실제로는 **8개 에이전트 전부가 매 호출마다 `CLAUDE.md`를 받는다.**
- 대체 방법(Read 도구 제한으로 간접 차단, 서브에이전트 구조를 인라인 호출로 전환)은 이번
  시리즈 범위에서는 적용하지 않았다 — 효과가 불확실하거나 더 큰 구조 변경이 필요하다.
- 따라서 **호출당 8.4KB 절감 목표는 이번 도입에서는 달성하지 못한다.** 각 에이전트 정의의
  "CLAUDE.md 제외" 문구는 실질 효과가 없는 참고 표시로만 남는다.

## 안전장치

- 쓰기 자동화는 **승인된 항목만** 실행한다. 스크립트가 새 항목을 만들지 않는다.
- 유저 제재·데이터 변경·경제 수치 변경은 자동화 대상에서 제외한다.
- 모든 자동 실행은 결과를 기록하고, 실패하면 카즈하가 다음 점검에서 잡는다.
