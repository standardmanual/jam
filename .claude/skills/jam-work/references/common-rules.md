## 슬롭 제거 기준

| 종류 | 걷어낼 것 | 담당 |
| --- | --- | --- |
| 글 슬롭 | 상투구("~을 통해", "혁신적인", "여정"), 번역투, 과장, 의미 없는 수식, 반복, 이모지 남발, 내용 없는 서론·맺음말 | 글 쓰는 전원 + 게이트 리뷰(민지, 체크리스트 12번) |
| 시각 슬롭 | 의미 없는 그라디언트·유리질 효과, 뜻 없는 아이콘, 습관적 가운데 정렬, 재고 이미지 느낌 | 채원 (배지 이미지는 윈터와 함께) |
| 설계 슬롭 | 의미 없는 기능·배지 남발, 근거 없는 효과 주장, 채우기용 화면, 가짜 긴급감 | 혜린·민지·카즈하 |

**작동 방식:** JAM 문장 사전(`docs/service/writing/SLOP_DICTIONARY.md`)의 패턴 매칭 가능한 부분은
`scripts/check-slop.mjs`가 `verify` 단계에서 거르고, 문맥 판단이 필요한 나머지(사전 §4)는 게이트 리뷰(민지)가 판정한다.

티켓 생성 권한은 `docs/agents/team-operations.md` §3 「티켓 권한」이 단일 원천이다.
