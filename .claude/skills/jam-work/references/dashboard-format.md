## 형식

자동 생성 구간과 수기 구간을 마커로 분리한다. 스크립트는 **마커 안쪽만** 덮어쓰고, 마커 밖의
수기 구간(최근 결정·다음 할 일)은 건드리지 않는다.

```markdown
# 현황판

<!-- AUTO:START (스크립트가 매 세션 시작 시 이 구간만 재생성한다) -->
생성 시각: 2026-09-18 09:00 KST

## 진행 중 (OPEN · IN_PROGRESS)
- [P1] 20260918_0421 에이전트 팀 도입 ② 설정과 스크립트 (OPEN, 2026-09-18)
- [P1] 20260918_0422 에이전트 팀 도입 ③ 에이전트 정의와 워크플로 (IN_PROGRESS, 2026-09-18)

## 승인 대기 (WAITING)
- [P2] 20260919_0900 시즌 미션 「...」 제안 (2026-09-19)
<!-- AUTO:END -->

## 최근 결정 (카리나 직접 기록, 최대 5개)
-

## 다음 할 일 (카리나 직접 기록)
-
```

- **진행 중**: `status: OPEN` 또는 `IN_PROGRESS`인 티켓. `[우선순위] id 제목 (상태, 생성일)` 형식.
- **승인 대기**: `status: WAITING`인 티켓. 제목 앞 `[분류 대기]` 표시가 있으면 우선순위 칸을
  비운다 (카즈하 초안).
- **최근 결정 / 다음 할 일**: 스크립트가 만들지 않는다. 카리나가 세션 종료 시 직접 갱신한다.
- 상위 티켓이 있으면 하위 티켓을 들여쓰기로 그 아래 표시한다 (`loop-improvements.md` 5번).
