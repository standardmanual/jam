# 기획서 양식 (혜린, `/jam-plan`)

> 티켓 20260918_0423에서 파일화. 혜린이 2단계(기획서)에서 쓰는 형식.

한 줄 정의 · 문제 · 대상 · 성공 기준 · 동작 정의 · 범위 · **하지 않을 것** · 리스크 ·
검토한 대안 · 작업 분해(**티켓별 완료 조건 포함**) · PRD 반영안 · 판단(만들자/미루자/만들지 말자)

## 리스크 점검 목록 (JAM 전용)

경제 균형(드랍 확률·포인트 인플레·희귀도 가치) · 세계관 충돌(윈터) · 유저가 학습한 규칙 변경 ·
운영 부담(카즈하) · 개인정보·외부 의존(Strava·지도) · 비용

## 작업 분해 표기

여러 에이전트가 얽힌 기획은 **상위 티켓 + 하위 티켓** 구조로 제안한다.

## 흐름

```
기획서 승인 → 카리나: 기획 티켓 저장 → PRD 갱신 → 분해안대로 티켓 생성 → 순서대로 /jam-work
```
