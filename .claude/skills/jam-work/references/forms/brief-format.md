## 작업 분해 표기

여러 에이전트가 얽힌 기획은 **상위 티켓 + 하위 티켓** 구조로 제안한다. 하위 티켓 행마다
다음을 적는다.

- (a) **완료 조건**
- (b) **선행 티켓** — 없으면 "없음"
- (c) **세로 조각** — 티켓 하나가 끝나면 사용자에게 보이는 동작 하나가 완성되는 단위로 자른다.
  층별(DB만·API만·화면만)로 자르지 않는다
- (d) **체크포인트** — 묶음 실행 중 사용자 확인이 필요한 지점. 정지 조건의 원천은
  `.claude/skills/jam-work/references/stop-conditions.md`다 — 옮겨 적지 않는다
- (e) **크기 상한** — 티켓 하나가 `plan_only` 기준을 넘지 않게 나눈다. 수치는
  `.claude/skills/jam-work/references/stop-conditions.md` 참조

선행 순서는 상위 티켓의 하위 티켓 표 「선행」 열에 적는다(규칙: `docs/agents/issue-tracker.md`).
