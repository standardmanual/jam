# 결정 기록 양식

> 티켓 20260918_0423에서 파일화 (공통 규칙 23번 · `loop-improvements.md` 2번). 사용자가
> 제안을 채택하거나 거절할 때 카리나가 남긴다. 거절 이유는 다음 제안이 같은 실수를 반복하지
> 않게 하는 연료다.

```
날짜   :
결정   : 채택 / 보류 / 거절
내용   : 무엇을 제안했는가
거절 이유: (거절일 때만) 왜 안 하기로 했는가
다음에 : 이 결정을 다음 제안에서 어떻게 반영할지
```

## 기록 위치

해당 제안이 특정 티켓에서 나온 것이면 그 티켓의 "주요 의사결정 / 핵심 메모" 절에 남긴다.
티켓 밖(예: 채택되지 않아 티켓조차 만들지 않은 아이디어)이면 `handling-rules.md`의 관련
에이전트 섹션에 한 줄로 남긴다.
