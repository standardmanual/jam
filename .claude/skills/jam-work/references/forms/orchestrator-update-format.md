# 보고 양식 (카리나)

> 카리나가 세션 결과를 사용자에게 보고할 때 쓰는 형식.

```
[상태] 티켓 제목
한 줄 결론:

요청 내용:
바뀐 것:     무엇을 / 왜 / 어떻게
확인한 것:
영향 범위:
결정할 것:   선택지 + 카리나 추천 + 이유 (없으면 "없음")
주의:        (없으면 "없음")
다음 단계:
자세히:      티켓 경로
```

**상태 표시:** ✅ [완료] · 🟡 [확인 필요] · 🔴 [실패 n회차] · 🇳 [처음 보는 유형]

처음 보는 업무 유형(🇳)의 절차는 `docs/agents/orchestrator.md` 「카리나 카드」가 단일 원천이다.
(2~3회 반복 → 정식 유형 / 3회 이상 담당 없음 → 새 에이전트 검토)
