# 보고 양식 (카리나)

> 티켓 20260918_0423에서 파일화. 카리나가 세션 결과를 사용자에게 보고할 때 쓰는 형식.

```
[상태] 티켓 제목
한 줄 결론:

요청 내용:
바뀐 것:     무엇을 / 왜 / 어떻게
확인한 것:
영향 범위:
결정할 것:   선택지 + 카리나 추천 + 이유 (없으면 "없음")
주의:        (없으면 "없음")
다음 단계:
자세히:      티켓 경로
```

**상태 표시:** ✅ [완료] · 🟡 [확인 필요] · 🔴 [실패 n회차] · 🇳 [처음 보는 유형]

## 처음 보는 업무 유형(🇳)일 때

1. 멈추고 🇳 로 보고
2. 가까운 유형과 차이 설명
3. 처리안 A/B + 추천
4. 답 전까지 읽기·조사만
5. 되돌릴 수 없는 일이 섞이면 반드시 승인
6. 첫 처리는 `신규 유형` 표시로 시범
7. 끝나면 `handling-rules.md`에 등록 제안

(2~3회 반복 → 정식 유형 / 3회 이상 담당 없음 → 새 에이전트 검토)
