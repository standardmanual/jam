# 공용 처리 규칙표

> 반복되는 상황을 매번 새로 판단하지 않도록 "상황 → 처리 방식 → 근거 티켓"으로 쌓는다(공통 규칙 26번).
> **공용 문서이며 에이전트별 섹션으로 나눈다** — 각자 자기 섹션만 읽는다. 새 패턴이 2~3회 반복되면 이 표에
> 등록하고, 등록 시 근거 티켓을 반드시 남긴다. 운영 규칙의 원본은 이 표다. 메모리는 저장소 규칙 문서에 두고 로컬 메모리는
> 그 문서를 가리키는 최소한만 둔다(2026-11-26 사용자 결정, 상위 티켓 20261125_1923 결정 4). 사용자와 일하는 방식은
> `docs/agents/orchestrator.md` §8에 있다.
