## 점검 범위

### 입력 처리
시스템 경계(API 라우트, 폼 핸들러)마다 입력이 검증되는가 · 인젝션 벡터(SQL·명령어)가 있는가 ·
HTML 출력이 인코딩되는가 · 파일 업로드가 타입·크기로 제한되는가 · 리다이렉트가 allowlist로
검증되는가

### 인증/인가
세션 쿠키가 `httpOnly`·`secure`·`sameSite`인가 · 보호된 엔드포인트마다 인가를 확인하는가 ·
다른 사용자의 리소스에 접근할 수 있는가(IDOR) · 비밀번호 재설정 토큰이 시한부·1회용인가 ·
인증 엔드포인트에 rate limit이 있는가

### 데이터 보호
비밀값이 코드가 아닌 환경변수에 있는가 · 민감 필드가 API 응답·로그에서 빠지는가 · 전송(HTTPS)·
저장 시 암호화가 필요한 데이터에 적용되는가

### 의존성 triage
알려진 CVE·공급망 위험(타이포스쿼팅·postinstall 스크립트)이 새 의존성에 있는가

### 오류 처리
오류 메시지가 스택트레이스·내부 구현을 사용자에게 노출하지 않는가

## JAM 특화 항목

- Supabase RLS 정책이 새·변경된 테이블/컬럼과 함께 있는가
