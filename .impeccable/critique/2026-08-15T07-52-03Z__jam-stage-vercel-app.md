## 1. 동일하게 유지된 부분

- 배지도감: 3탭(액티비티/장소/아이템북) + 2필터 드롭다운 + 3열 그리드 구조
- 미션 목록: 3탭(진행중/참가중/종료) + 3필터 드롭다운 구조
- 하단 내비게이션: 6항목 구조 (투데이/배지/JAM/미션/인벤/프로필)
- 인벤토리: 3열 그리드 + 슬롯 프로그레스 바
- 아이템북/컬렉션: 2열 그리드 + 팩션명 + 프로그레스 바
- 조합/믹스 페이지: "내 아이템" 섹션이 하단에 위치하는 구조
- 드랍 페이지: 지도 풀스크린 + 바텀시트 구조 의도

## 2. 변경된 부분 (Figma가 제안하는 변경)

**홈:**
- 콘텐츠 카드 축소: 스테이징 3개 카드(진행 알림/배지 소개 등) → Figma는 투데이 1개만
- 검색 버튼: 스테이징 독립 오렌지 버튼 → Figma 인라인 통합

**미션 목록:**
- 미션 카드에 정사각 썸네일 이미지 추가 (DB에 컬럼 없음 → 데드 스펙 위험)
- 미션 상태 배지 표현 방식 변경

**인벤토리:**
- 타이틀: "인벤" → "인벤토리" (Figma 기준)
- CTA 버튼: "믹스" → "조합하기" (용어 퇴행)
- 프로그레스: 잔여량 포커스 → 분수형

**조합:**
- 타이틀: "믹스" → "조합" (용어 퇴행)
- 버튼: "믹스하기" → "조합하기"
- 슬롯: 10개 2×5 그리드 → 4개 가로 1행 (기능 축소!)

**컬렉션/아이템북:**
- 타이틀: "아이템북" → "컬렉션"
- "완성" chip 추가

**프로필 (가장 큰 변화):**
- Instagram형 소셜 프로파일로 전환 (Posts/Followers/Following)
- Follow/Message/Email 소셜 액션 버튼 추가

## 5. 현재 스테이징 서비스에서 문제가 발견된 부분

**중요:**
- 미션 타입 영문 코드 직접 노출 (STREAK_DAYS 등, 번역 딕셔너리 있는데 미사용)
- 드랍 탭 라벨 "JAM" — 기능 설명 불가
- 믹스 기능이 탭바에 없어 인벤 → 믹스 경로만 존재 (디스커버빌리티 약함)
- activity_type 번역 미적용 (미션 상세 조건)
- 미션 필터 3개 네이티브 select — 모바일 OS 피커 기동으로 이질적

**보통:**
- 위치 정보 마운트 시 1회만 획득, 이동 중 갱신 없음
- Image 컴포넌트 미사용으로 배지 이미지 최적화 없음
- 인벤토리에서 슬롯 배치 아이템 숨겨지는 것 설명 없음

**낮음:**
- 미션 보상 배지 이미지 alt="" 빈값
- CombineClient 실행 버튼이 Button 컴포넌트 미사용
