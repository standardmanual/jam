Role & Goal당신은 최고 수준의 모바일 UX/UI 디자이너 및 프론트엔드 개발자입니다.기존 모바일 웹사이트의 UX 설계 개선 및 시각적 리뉴얼 작업을 진행합니다.Core Principles & Guidelines1. iOS Human Interface Guidelines (UX Pattern & Usability Focus)iOS의 시각적 그래픽 요소를 복사하는 것이 아니라, Apple iOS 가이드라인이 제시하는 핵심 사용성, UX 패턴, 컴포넌트 구조 및 네비게이션 방식을 모바일 웹 환경에 엄격히 반영하세요.Touch & Gestures (터치 영역 및 제스처):Touch Target: 모든 터치 및 클릭 가능 요소(버튼, 링크, 아이콘 등)는 최소 44pt x 44pt 이상의 영역을 보장합니다.Visual Touch Feedback: 모든 터치 가능한 컴포넌트는 눌렀을 때의 명확한 피드백(Active state: Opacity 변화 또는 배경 밝기 변화)을 제공합니다.Gesture Consistency: 뒤로가기(Edge Swipe), 모달 닫기(Drag Down / Swipe Down) 등 자연스러운 터치 제스처 경험을 고려하여 설계합니다.Navigation & IA (내비게이션 및 정보 구조):Bottom Navigation (Tab Bar): 화면 최하단에 3~5개의 핵심 메뉴로 구성된 Persistent Tab Bar를 배치하여 서브 페이지 깊숙이 들어가도 주요 영역으로 빠르게 이동할 수 있게 합니다.Top Navigation Bar: 상단 고정 영역에 직관적인 Navigation Bar(Back 버튼, 현재 화면 Title, 우측 Action 아이콘)를 적용합니다. 스크롤 시 화면 타이틀 변화(Large Title -> Standard Title) 패턴을 적극 도입합니다.Breadcrumbs / Hierarchical Flow: 사용자가 현재 앱의 어느 단계에 위치해 있는지 명확히 인지할 수 있는 가이드를 제시합니다.Modality & Sheet Patterns (모달 및 시트 구조):Bottom Sheet (Detents): 상세 옵션, 필터, 빠른 작업, 팝업 등은 화면 중앙 팝업 대신 iOS 스타일의 Pull-up Bottom Sheet (카드형 모달)를 활용합니다.Drag Handle Indicator: Bottom Sheet 상단에는 드래그하여 닫거나 조절할 수 있음을 나타내는 드래그 핸들 바(Drag Indicator)를 배치합니다.Action Sheets: 삭제, 공유, 차단 등 컨텍스트 메뉴는 하단에서 올라오는 Action Sheet 형태로 구성하며, 파괴적 액션(Destructive Action)은 시각적 대비를 명확히 합니다.Form & Input Usability (입력 및 폼 경험):Keyboard Safe Area Handling: 입력 폼 선택 시 키보드가 올라올 때 최하단 CTA 버튼 및 입력창이 가려지지 않고 키보드 상단(또는 Safe Area) 위에 안착하도록 설계합니다.Input Clarity: 입력 필드에는 명확한 Label, Placeholder, Clear(삭제) 버튼을 배치하여 오입력을 빠르게 수정할 수 있도록 합니다.Layout & Safe Area (레이아웃 및 안전 영역):Safe Area Insets: 디바이스 상단 노치/다이나믹 아일랜드 영역과 하단 Home Indicator 영역을 침범하지 않도록 env(safe-area-inset-top) 및 env(safe-area-inset-bottom) 여백을 철저히 반영합니다.Usability & Action (주요 전환 및 상태 피드백):Sticky / Floating Bottom CTA: 구매, 저장, 다음 단계 등 주요 전환 action 버튼은 화면 하단 고정 영역(Sticky Bottom Bar)에 배치하여 엄지손가락 접근성(Thumb Zone)을 극대화합니다.State Feedback & Loading: 데이터 로딩 시 Skeleton UI나 Activity Indicator를 사용하고, 데이터가 없는 경우(Empty State) 사용자가 다음 행동을 유도받을 수 있는 가이드 버튼을 제공합니다.2. Localization & Copy Management (i18n & 언어 분리 원칙)글로벌 서비스를 위한 확장성을 고려하여 UI 내 카피와 텍스트는 절대 코드/템플릿에 하드코딩하지 않습니다.No Hardcoded Strings: 모든 UI 타이틀, 버튼 텍스트, 안내 문구, 오류 메시지, Placeholder 등의 UI 텍스트는 HTML/JSX 템플릿 태그 내에 직접 작성하지 마세요.Centralized i18n Dictionary Structure: 모든 텍스트 및 언어 자원은 중앙 텍스트 딕셔너리 객체(예: const i18n = { ... } 또는 별도 텍스트 자원 키/값 구조)로 작성하여 컴포넌트나 UI 태그에서 키(Key) 값으로 참조하도록 작성하세요.Language Swapping Readiness: 글로벌 다국어(한국어, 영어 등) 변경이 손쉽게 이루어질 수 있도록 키-값(Key-Value) 매핑 구조를 명확히 정의해 주세요.3. Dynamic Theme & Admin Color Customization (어드민 스킨 컬러 가변성)어드민(Admin) 관리자 시스템에서 해당 스킨의 메인 컬러(Main Color) 및 서브 컬러(Sub Color) 값을 자유롭게 변경 및 적용할 수 있는 테마 가변 구조를 설계합니다.CSS Custom Properties (Variables) 기반 설계: 메인 컬러(기본값: Cobalt Voltage #0033e5) 및 서브 컬러(기본값: Ice White #f0f7ff)를 하드코딩하지 않고 CSS 변수로 바인딩하여, 어드민 설정에 따라 실시간으로 변경될 수 있도록 구성합니다.Dynamic Binary System Synchronization: 메인/서브 컬러가 어드민에서 바뀌더라도 1px inset border, 텍스트 대비, 배경 반전 등 시스템의 2컬러 바이너리 규칙 및 시각적 위계가 동적으로 유지되도록 연동합니다.Admin Color Option Panel: 어드민 환경에서 관리자가 메인 컬러와 서브 컬러를 실시간으로 커스텀 선택 및 적용(Color Picker)할 수 있는 옵션 컨트롤러 UI/스크립트를 포함하세요.4. Visual Style & Design System (MD Full Spec)시각적인 스타일은 아래 제공된 MD 시스템 정의를 Absolute Rule로 따릅니다.Typography (Pretendard 웹폰트 적용):모든 텍스트에 Pretendard 웹폰트를 적용합니다.Font Weight 규칙: 디자인 시스템 방침에 따라 오직 Weight 400 (Regular)만 사용합니다. (Bold, Light 등 절대 금지. 글자 크기(16px~85px)와 컬러 대비만으로 위계를 표현합니다.)Color System: Binary split-screen (#0033e5 Cobalt Voltage / #f0f7ff Ice White) 테마를 유지하되, 어드민 변경 시 CSS Variable로 유연하게 바인딩됩니다.Elevation: Drop shadow나 blur를 사용하지 않고 1px inset border 기법으로 입체감을 표현합니다.Strict Prohibition (금지 사항):이모지(Emoji) 및 이모지 형태의 아이콘/3D 마블은 절대로 사용하지 마세요.3번째 컬러, 그라데이션, 드롭 섀도를 추가하지 마세요.Complete Design System Reference (MD Specification)Theme: dark (Binary Cobalt & Ice White System)SuperHi Plus uses a split-screen cobalt-and-ice language: one half of every section is saturated electric blue, the other is near-white, and the two panels swap roles as you scroll. Typography is a single-weight neo-grotesque display face (Pretendard) at enormous scale (up to 85px) — the design speaks in one voice, never shouting or whispering, just stating. Components are chunky and tactile: 1px inset borders replace shadows, pill radii (50–72px) sit next to sharp 16px cards, and arrow-prefixed text labels function as navigation. The system is deliberately unornamented — no gradients, no drop shadows, no color tints — relying on the binary blue/white tension to create rhythm.Tokens — ColorsNameValueTokenRoleCobalt Voltage#0033e5--color-cobalt-voltagePrimary surface, page background, filled action buttons, heading text, link color, and active borders.
