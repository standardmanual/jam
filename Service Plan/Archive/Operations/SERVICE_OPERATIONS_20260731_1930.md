## [데이터 정정] POI 배지 반경 오설정으로 인한 오탐 발급 — 44개 POI 수정 + 오발급 회수

**배경**: sihyunrr@gmail.com 계정이 실제로 지나간 적 없는 "서울숲역(에스엠타운) 4/5번출구" 배지를 획득한 것으로 나타나 원인 조사.

**원인**: 이 두 POI를 포함해 **총 44개의 지하철(`transit`) 카테고리 POI**가 `radius_meters: 500`으로 설정돼 있었음(정상값은 50m — 같은 카테고리 973개 중 929개는 50m). 이 44개는 전부 `poi_tier=2`, 합성 `naver_id`(`syn:...`) 패턴으로 2026-07-23~07-26 사이 생성된 행으로, **드랍/픽업 자동수집 파이프라인(T2, `/api/drops`)이 만든 POI를 배지에 그대로 연결하면서 드랍용 기본 반경(500m)을 배지 매칭용 반경(50m)으로 좁히지 않은 것**이 원인. 결과적으로 "그 출구를 지나감"이 아니라 "그 좌표 반경 500m 안 어디서든 활동하면" 배지가 발급되는 상태였음.

**조치**:
1. 해당 44개 POI의 `radius_meters`를 500 → 50으로 일괄 수정(직접 DB 쿼리, 코드 변경 없음).
2. sihyunrr@gmail.com 계정의 잘못 발급된 이력 4건(서울숲역 4/5번출구, 각 2회) `user_poi_badge_earns`에서 삭제(회수). 유저 확인 후 진행.

**남은 영향 범위**: 이 44개 POI에 연결된 배지를 획득한 **다른 유저**들도 같은 방식으로 잘못 발급받았을 가능성이 있음 — 이번엔 신고가 들어온 이 계정만 소급 처리했고, 전체 유저 대상 일괄 재검증/회수는 진행하지 않음(필요 시 별도 작업 — `poi_tier=2` + `naver_id` `syn:` 패턴 + `radius_meters` 500이었던 이력을 `user_poi_badge_earns.earned_at`이 수정 이전인 건으로 조회하면 대상 특정 가능).

**별건 — 남산 배지**: 같은 계정이 "남산" 배지도 실제로 지나간 적 없다고 신고했으나, 남산 POI는 `radius_meters: 50`(정상), `poi_tier: 1`로 위 오탐 패턴에 해당하지 않음. 코드 조사만으로는 원인을 확정하지 못해 조치하지 않음 — 실제 GPS 경로 확인이 필요하면 별도 조사 필요(과거 문서화된 "산 POI 매칭 구조적 한계"와 관련 가능성).

**관련 테이블**: `poi`(44행 UPDATE), `user_poi_badge_earns`(4행 DELETE). 코드 변경 없음.
