## 3. 툴 확정: Gemini 수동 입력 (Recraft 폐지)

Recraft API 자동 생성 방식은 폐지했다. 배경이 불투명하게 나오는 문제, 로고 합성 자동화의
번거로움, API 전용 필드(style_id·negative_prompt 등)에 맞춰 문서를 관리해야 하는 부담이
이유. 대신 다음 절차로 전환:

1. Claude가 스타일그룹 정의서 + 컨텐츠 브리프를 조합해 아이템별 **컨텐츠 브리프 프롬프트**
   (섹션마다 negative prompt + 생성 prompt)를 텍스트 문서로 작성
2. 사용자가 이 프롬프트를 Gemini에 직접 붙여넣어 이미지를 생성
3. 배경 투명화까지 사용자가 직접 후처리해 최종 파일을 준비

→ 이미지 생성·후처리 전체가 사용자 손을 거치므로, API 크레딧·자동 배치 관리 이슈가 사라진다.
로고 합성은 당분간 하지 않는다 (재도입 여부는 별도 논의).

## 4. 스타일 통제 방식

세계관마다 다음을 세트로 관리하되, 전부 **텍스트(정의서 서술)로 관리**한다 (API 필드가 아님):

1. **팔레트 지정** — 색상 5개 내외를 직접 지정 (프롬프트로 "보라색 계열"이라고 쓰는 것보다 정확)
2. **절대 금지 요소 목록** — 드롭섀도우·그라데이션·텍스트 등을 단어로만 나열해 정의서에 기록하고,
   컨텐츠 브리프 프롬프트 작성 시 각 아이템 섹션의 negative prompt에 그대로 반영한다
3. **텍스트 사용 여부** — `텍스트_사용여부: no`인 세계관은 negative prompt에도 텍스트 관련
   금지를 이중으로 넣어 방어한다
4. **문법(구도) 고정** — 정의서의 "톤/다이나믹함"에 정한 구도 문법(예: 중앙 오브젝트 + 상태
   과장 묘사)을 모든 아이템의 생성 prompt에 동일하게 반영해, 매 생성마다 스타일이 흔들리지
   않게 한다

## 5. 작업 순서

1. 세계관별 스타일그룹 정의서 + 레퍼런스 이미지 확정 (디자이너가 채움, 필요 시 Claude가
   `정의서_작성_요청_프롬프트.md`로 초안 작성)
2. 세계관별 컬렉션·아이템 브리프 확정 (디자이너가 채움 → 시각 컨셉으로 정제)
3. 컬렉션별 컨텐츠 브리프 프롬프트 생성 (Claude, 아이템별 negative/생성 prompt)
4. 양산: 사용자가 Gemini에 프롬프트를 입력해 아이템당 여러 장 생성 후 선별
5. 후처리: 배경 투명화, 규격 정리 (사용자 직접 작업)
6. **수동 QC** — 디자이너가 직접 선별 (자동 QC 없음)

## 6. 폴더 구조

`02_스타일그룹/` 아래에 세계관 하나당 폴더 하나(`{세계관번호} {세계관이름}`, FACTIONS.md 기준 10개).
폴더 안에:
- 스타일그룹 정의서 (스타일 규칙)
- 레퍼런스 이미지 (무드 이미지에서 잘라낸 개별 요소)
- 컨텐츠 브리프 — `컨텐츠_브리프/{컬렉션ID} {컬렉션이름}.md`
- 컨텐츠 브리프 프롬프트 — `컨텐츠_브리프/{컬렉션ID} {컬렉션이름}_프롬프트.md` (Claude가 생성,
  Gemini에 그대로 입력할 아이템별 negative/생성 prompt)

세계관 10개 × 컬렉션 10개 = 컨텐츠 브리프 100개는 FACTIONS.md(세계관 설명)·ITEMBOOKS.xlsx
(컬렉션·아이템 텍스트)·서비스 DB `badges` 테이블(아이템 UUID) 기준으로 에이전트가 이미
전량 생성 완료. 디자이너가 채울 부분은 세계관별 `스타일그룹_정의서.md`(팔레트·렌더링 규칙 등)와
`레퍼런스_이미지/` 뿐이다.

## 7. ID 체계

이미지 파일 추적을 위해 사람이 아닌 에이전트가 직접 부여한다 (영문/숫자만 사용).

- **스타일 그룹 ID**: 세계관 번호 2자리 (`01`~`10`) — 스타일그룹_정의서.md에 표기
- **컬렉션 ID**: `{세계관번호}-{컬렉션번호}` (예: `01-01`) — 컨텐츠_브리프.md와 폴더명에 표기
- **아이템 ID**: 서비스 DB `badges.id`(UUID). 아이템 1개당 rarity(common/rare/legend/mythic)
  4종이 각각 별도 UUID를 가지므로, 컨텐츠_브리프.md의 "#" 열에 4개 전부 표기
