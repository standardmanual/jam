# 컨텐츠 브리프 항목 생성 요청 프롬프트 ([숲속의 갱단] 전용)

새 컬렉션의 아이템 항목(이름·설명·생성해야 하는 표현)을 만들 때마다, 아래 [ ] 부분만 채워서
요청해주시면 됩니다. 이 프롬프트는 `스타일그룹_정의서.md`에 이미 정의된 이 세계관의 스타일·톤·
금지 요소를 전제로 하므로, [숲속의 갱단] 세계관 안에서만 재사용하세요.

---

```
[숲속의 갱단] 컬렉션 [컬렉션 ID 및 이름]의 컨텐츠 브리프 아이템 항목을 만들어줘.

이 세계관과 스타일 정의서를 전제로 아이템을 구상해:

세계관 설명:
"네 핫도그 소시지, 우리가 털어간다. 꼬우면 산으로 오든가."
도심 공원과 외곽 산자락을 지배하는 실세들 (다람쥐·길고양이 컨셉). 방심한 등산객의 가방을 털고,
길가에 흘린 간식에서 가장 맛있는 부분만 빼먹는 범인들. 훔친 물건은 깊은 숲속 동물들의 비밀
환전소 '그루터기 살롱'에서 도토리와 거래된다. 구역을 존중하며 걷는 자들에게는 보물을 슬쩍
흘려두기도 한다.

스타일 정의서에서 아이템 구상 시 반드시 지켜야 하는 제약:
- 텍스트·문구·숫자가 이미지에 들어가지 않아도 되는 소재로 구상한다 (텍스트_사용여부: no)
- 사람은 등장하지 않는다 — 등산객·인물은 가방·간식 같은 흔적으로만 암시한다
- 사물이든 동물이든 눈·표정을 붙여 의인화할 수 있다 (강제는 아니며, 소재에 따라 선택한다)
- 완성 이미지가 원형·방패형 등 공통 프레임에 갇히지 않고, 소재 자체의 실루엣이 배지 외곽이
  되는 자유형태로 그려질 것을 전제로 구상한다 (프레임에 맞춰 소재를 억지로 자르지 않아도 됨)
- 하나의 아이템 = 하나의 구체적인 장면·사물. 여러 요소를 나열하지 말고 한 가지 핵심 소재나
  순간에 집중한다

컬렉션 컨셉:
[이 컬렉션이 다루는 소재·상황을 한두 문장으로 설명. 예: "인간들의 방심을 틈타 가방을 털고
간 무법자들의 전리품이 깊은 숲속 그루터기 살롱에서 도토리와 밀거래되는 모습"]

아이템 개수: [숫자, 보통 9개]

각 아이템은 아래 3가지를 채워줘 (이름 / 설명 / 생성해야 하는 표현):
- 이름: 소재를 한눈에 알 수 있는 짧은 명사구
- 설명: 세계관 톤(능청스럽고 장난기 있는 도둑 서사)에 맞는 1~2문장. "~입니다" 존댓말체로,
  아이템이 왜·어떻게 이 세계관 안에서 생겨났는지 위트있게 서술한다
- 생성해야 하는 표현: 실제 이미지에 그려질 단 하나의 구체적인 시각 요소를 짧은 구로 명시한다
  (예: "케첩이 지그재그로 발라져있는 구운 소시지"). 이 문구가 나중에 이미지 생성 프롬프트의
  핵심 장면이 되므로, 모호한 표현 대신 눈에 보이는 형태·배치를 구체적으로 적어줘

`컨텐츠_브리프_양식.md` 형식(세계관 / 컬렉션 / 아이템 표)에 맞춰 표로 정리해서 컨텐츠 브리프
파일 하나만 만들어줘. 다른 파일은 만들지 마. 등급별 UUID는 비워두고, 내가 별도로 채울게.
```

---

## 이 프롬프트가 하는 일

- 스타일 정의서의 금지 요소·구도 규칙(자유형태, 텍스트 없음, 사람 등장 금지 등)을 아이템
  구상 단계에서부터 전제하게 해서, 나중에 이미지 생성 단계에서 규칙 위반이 발견되는 걸
  막습니다.
- "하나의 아이템 = 하나의 구체적 장면"이라는 원칙을 명시해서, 여러 소재가 뒤섞인 산만한
  아이템이 나오지 않게 합니다.
- "생성해야 하는 표현"이 구체적인 시각 정보를 담도록 강제해서, 다음 단계인 이미지 생성
  프롬프트(`컨텐츠_브리프_프롬프트_양식.md`)로 바로 옮길 수 있는 수준의 문서가 나오게
  합니다.
- 등급별 UUID 필드는 비워두게 해서, 자동 발급 단계와 충돌하지 않게 합니다.
