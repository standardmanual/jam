# [Feature] 드랍 플로우 UI

## 배경 / 문제 정의
지도 화면에서 POI를 선택했을 때 드랍할 아이템을 선택하는 모달/바텀시트 UI.

## 상세 요구사항
- 바텀시트에서 아이템 목록 표시 (인벤토리에서 슬롯 미장착 아이템만)
- 각 아이템: 배지 이미지 + 이름 + 일련번호 + 등급
- "드랍" 버튼 클릭 시 POST /api/drops 호출
- 로딩 상태 표시
- 성공/실패 토스트 메시지

## 구현 계획
1. `src/components/drops/DropModal.tsx`
2. `src/hooks/useDropItem.ts` (POST 요청 로직)
3. 바텀시트 애니메이션
