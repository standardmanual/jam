# [Service] 드랍 아이템 순환 모니터링

## 배경 / 문제 정의
유저가 드랍한 아이템이 제대로 순환하는지, 30일 만료 정책이 잘 작동하는지 모니터링. 좀비 드랍(회수되지 않는 아이템) 탐지.

## 모니터링 항목
1. **만료율**: 30일 이내 픽업된 아이템 비율 (목표 > 80%)
2. **좀비 드랍**: 30일 이상 미픽업 아이템 → 자동 삭제
3. **회전율**: POI당 평균 드랍-픽업 사이클 (목표 < 2일)

## 구현 계획
1. `src/app/api/cron/drop-circulation/route.ts` Cron
2. 일 1회 실행, 통계 생성
