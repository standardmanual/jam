# [Infra] 900개 배지 CSV 시드 데이터

## 배경
아이템배지 900개를 세계관 10종, 아이템북 100권에 분배해야 함. 어드민이 수동으로 입력하기 어려워 CSV로 일괄 임포트.

## 상세 요구사항
- CSV 파일 형식:
  - `name`, `rarity` (common/rare/legendary/mythic), `faction_id`, `item_book_id`, `image_url`, `point_reward`, `drop_weight`
- 각 아이템북당 9개 배지 (3 common, 3 rare, 2 legendary, 1 mythic)
- 총 900개 = 100책 × 9개

## 구현 계획
1. CSV 파일 생성 (900행)
2. Supabase 관리 패널에서 임포트 또는 API 대량 삽입
3. 데이터 검증
