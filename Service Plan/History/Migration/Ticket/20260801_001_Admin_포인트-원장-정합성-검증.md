# [Admin] 포인트 원장 정합성 검증 대시보드

## 배경
포인트 유통량의 무결성을 모니터링. 유통량 ≠ 월렛합 또는 원장합 시 경고.

## 상세 요구사항
- 어드민 포인트 대시보드
- 3가지 수치:
  1. treasury.total_minted (전체 발행)
  2. SUM(point_wallets.balance) (월렛 잔액 합)
  3. SUM(point_transactions) (원장 합)
- 불일치 시 경고 및 원인 분석 도구
