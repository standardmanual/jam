# [UI] 지도 — POI/배지 서클 줌 레벨 연동 크기 조절

## 배경 / 문제 정의
드랍메뉴 지도에서 POI 서클과 POI 배지 서클이 최초 진입 줌레벨에서 너무 작게
표시되어 배지 디자인을 알아보기 어렵다는 피드백. 기존에는 `BADGE_MARKER_SIZE`,
`DROP_MARKER_SCALE` 모두 줌 레벨과 무관한 고정값이었음 — 줌인/줌아웃해도 마커
크기가 전혀 바뀌지 않았다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 최초 진입 줌(17)을 포함한 기본 구간에서 서클 크기 130%로 확대
- 줌아웃 시 일정 레벨(≤15)에서 서클 축소
- 줌인 시 일정 레벨(≥19)에서 서클을 130%보다 더 확대(160%)
- 계단식(3단계) 스케일 채택 — naver 지도 마커는 HTML을 매 렌더마다 새로 그리는
  구조라 연속(선형) 스케일을 적용하면 줌 조작 중 프레임마다 재계산되어
  깜빡임/버벅임 위험이 있음. 3단계로 끊고 `zoom_changed`에 디바운스(120ms)를
  걸어 전환 빈도를 최소화

### UI/UX 관점
- 서클 크기 변화 외 색상/아이콘/라벨 로직은 기존과 동일하게 유지

## 구현 계획
- `MapView.tsx`에 `zoom` state 추가 + `zoom_changed` 리스너(디바운스 120ms)
- `getZoomScaleMultiplier(zoom)` 함수 신설 (≥19→1.6, ≥16→1.3, 그 외→1.0)
- 드랍/픽업 POI 서클 크기, 방문 배지 마커 서클 크기·상단 오프셋에 배율 적용
- 클러스터 마커(줌 13 이하 집계 마커)는 요청 범위 밖 — 변경하지 않음
- 실제 화면에서 검증할 수 있도록 임시 테스트 페이지(`/dev/marker-zoom-test`)를
  목업 데이터로 신설. `proxy.ts` 공개 경로에 `/dev` 추가(로그인 없이 접근 가능)
