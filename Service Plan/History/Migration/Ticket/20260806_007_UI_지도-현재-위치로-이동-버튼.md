# [UI] 지도 — 현재 위치로 이동 버튼

## 배경 / 문제 정의
드랍메뉴 지도 화면에서 사용자가 지도를 이동/줌한 뒤 다시 자신의 현재 위치로
돌아올 방법이 없었음. 구글맵 등에서 통상적으로 제공하는 우측 하단 "내 위치로
이동" 버튼을 추가 요청받음. 지도 회전(bearing/tilt) 기능은 요구사항에서 제외.

## 상세 요구사항

### 서비스/코드베이스 관점
- 지도 화면 우측 하단에 원형 버튼 배치, 탭하면 현재 위치를 재조회해 지도
  중심을 그 위치로 이동
- 기존에 표시 중인 파란 점(현재 위치 마커)과 정확도 서클도 새 위치로 갱신
- 지도 회전/베어링 기능은 구현하지 않음 (naver 지도 기본 상태 그대로, panning만)

### UI/UX 관점
- 버튼 위치: 화면 우측, 하단 플로팅 탭바(bottom: safe-area+16px, h-16px) 위로
  겹치지 않도록 `bottom: safe-area+96px`
- 아이콘: 구글맵 스타일 크로스헤어(십자선 + 원형 타겟) 아이콘, 흰 배경 원형 버튼

## 구현 계획
- `MapView.tsx`에 버튼 자체 내장(부모 컴포넌트에 props 추가 불필요) — 지도
  인스턴스와 현재 위치 마커/서클을 이미 이 컴포넌트가 들고 있으므로 자연스러움
- 클릭 시 `navigator.geolocation.getCurrentPosition` 재호출 → `map.morph(latlng, 현재줌)`으로
  중심 이동(줌 레벨 변경 없음, 회전 없음) + 마커/서클 위치 갱신
- 이를 위해 사용자 위치 마커(`Marker`)·서클(`Circle`) 인스턴스를 ref에 저장
- `naver-maps.d.ts`에 없던 `Marker.setPosition` / `Circle.setCenter` 타입 선언 추가
  (런타임 API에는 이미 존재하나 프로젝트 자체 최소 타입 선언에 누락돼 있었음)
