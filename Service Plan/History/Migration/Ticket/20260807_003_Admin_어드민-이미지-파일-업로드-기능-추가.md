# [Admin] 어드민 이미지 파일 업로드 기능 추가

## 배경
어드민에서 배지·아이템북 등 컨텐츠를 생성·수정할 때 대표 이미지를 URL 직접 입력으로만 등록할 수 있어,
별도로 이미지를 업로드해 URL을 복사하는 번거로운 과정이 필요했다.
PC에서는 파일 선택 버튼으로, 모바일에서는 파일 탐색기 또는 사진 앨범에서 바로 선택할 수 있도록 개선 요청.

## 상세 요구사항
- 배지 등록/수정 폼 (BadgeForm): 이미지 URL 필드에 파일 선택 버튼 추가
- 아이템북 등록/수정 폼 (ItemBookForm): 동일하게 적용
- PC: 파일 탐색기에서 파일 선택
- 모바일: OS 파일 피커(파일 또는 사진 앨범에서 선택)
- 지원 형식: JPEG, PNG, WebP, GIF, SVG (최대 5MB)
- 업로드 후 URL 자동 채움 + 미리보기 즉시 반영
- URL 직접 입력도 계속 지원 (기존 기능 유지)

## 완료 기록

### 구현 내용 요약
1. **Supabase Storage `images` 버킷 신설** — public, 5MB 제한, 이미지 MIME 타입만 허용. RLS 정책: 공개 읽기 + 인증 업로드/삭제.
2. **업로드 API 신설** (`/api/admin/upload-image`) — 어드민 인증 후 service_role로 Storage에 업로드, 폴더 파라미터(`badges` / `itembooks`) 지원.
3. **공통 컴포넌트 신설** (`ImageUploadField`) — URL 입력 + 파일 선택 버튼 조합. 파일 선택 시 업로드 후 URL 자동 반영. 에러 메시지 인라인 표시. `accept` 속성으로 모바일 파일 피커 지원.
4. **BadgeForm** 이미지 URL 필드를 `ImageUploadField`로 교체 (folder=`badges`)
5. **ItemBookForm** 이미지 URL 필드를 `ImageUploadField`로 교체 (folder=`itembooks`)

### Supabase Storage
- 버킷: `images` (public)
- 파일 경로: `badges/{timestamp}_{random}.{ext}`, `itembooks/{timestamp}_{random}.{ext}`
- RLS: SELECT는 전체 공개, INSERT/DELETE는 인증 유저
