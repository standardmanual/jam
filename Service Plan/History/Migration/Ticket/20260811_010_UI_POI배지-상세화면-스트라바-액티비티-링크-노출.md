# [UI] POI 배지 상세화면에도 액티비티 배지처럼 획득 당시 스트라바 액티비티 링크 노출

## 배경 / 문제 정의

액티비티 배지는 배지 상세화면(`/badges/[id]`)의 "획득 정보" 카드에 `triggered_by_strava_id`가
있으면 "Strava에서 보기 ↗" 링크 버튼이 노출된다. POI 배지는 같은 화면에서 이 링크가
전혀 노출되지 않는다 — 사용자가 정확히 지적한 현상.

## 기존 티켓 검토 (레인저 사전 검토)

정확히 일치하는 기존 티켓은 없음. 관련 티켓:
- [20260806_002](./20260806_002_UI_배지-상세-오버레이.md) — 지도 탭 오버레이(별개 컴포넌트, 이번 대상 아님)
- Phase 16 마이그레이션(`053_user_poi_badge_earns.sql`) — POI 배지 반복 획득 이력 테이블 신설 시점부터
  `triggered_by_strava_id` 컬럼이 이미 존재함. **UI 미노출 문제이지 데이터 부재 문제가 아님.**

## 원인 (레인저가 코드 레벨로 미리 확인)

`jam-web/src/app/(main)/badges/[id]/page.tsx`:
- 액티비티 배지: `earned`(= `user_activity_badges` 쿼리 결과)에 `triggered_by_strava_id`가 있으면
  641~650행에서 "Strava에서 보기 ↗" 버튼 렌더링.
- POI 배지: 획득 이력이 `poiEarns`(= `user_poi_badge_earns` 쿼리 결과, 584~609행)로 별도 렌더링되는데,
  이 목록 아이템에는 장소명·획득일시·`triggered_by_activity_name`만 표시하고 **Strava 링크 버튼이 없음**.
  `user_poi_badge_earns` 테이블에는 `triggered_by_strava_id` 컬럼이 이미 존재하고(마이그레이션 053),
  `UserPoiBadgeEarnRow` 타입에도 이미 필드가 있으므로 **DB/타입 변경 없이 프론트 렌더링만 추가하면 됨**.

## 상세 요구사항

### 서비스/코드베이스 관점
- `poiEarns.map(...)` 각 항목(584~609행)에 `e.triggered_by_strava_id`가 있으면 액티비티 배지와
  동일한 스타일의 "Strava에서 보기 ↗" 링크를 추가한다.
- POI 배지는 반복 획득이라 이력이 여러 건일 수 있음 — 각 이력 항목마다 그 항목을 트리거한
  스트라바 액티비티로 링크되어야 한다 (전체 카드에 링크 하나가 아니라 항목별 링크).
- 기존 "획득 정보" 카드(611행~)는 `earned`(user_activity_badges) 기준이라 POI 배지에서는 애초에
  렌더링되지 않는 구조 그대로 두고, POI는 `poiEarns` 이력 리스트 쪽에 링크를 붙이는 방식으로 처리한다
  (두 갈래 렌더링 구조 자체는 유지 — Phase 16에서 의도적으로 분리한 구조이므로 통합 리팩터링은
  이번 범위 아님).

### UI/UX 관점
- 링크 버튼 UI는 기존 "Strava에서 보기 ↗" 버튼과 동일한 문구(`d.badges.viewOnStrava`)·스타일을
  재사용한다 (새 문구 추가 시 UX_WRITING_GUIDELINE.md 검증 필요하나, 기존 문구 재사용이면 해당 없음).
- 이력 리스트 항목이 촘촘한 카드형이라 버튼을 항목마다 풀사이즈로 넣으면 과할 수 있음 — 텍스트
  링크나 작은 아이콘 버튼 등 리스트 아이템에 맞는 크기로 조정 여부는 구현 시 판단.

### 구현 내용 요약
레인저 사전 조사(원인 분석) 검증 결과 그대로 확인됨 — `user_poi_badge_earns` 쿼리가 이미 `select('*')`로
`triggered_by_strava_id`를 포함해 조회하고 있었고, `UserPoiBadgeEarnRow` 타입에도 필드가 존재해 DB/API/타입
변경 없이 프론트 렌더링만 추가하면 되는 것이 맞았음.

`poiEarns.map(...)` 이력 리스트의 각 항목에 `e.triggered_by_strava_id`가 있을 때 "Strava에서 보기 ↗"
텍스트 링크(`d.badges.viewOnStrava` 문구 재사용)를 추가했다. 이력이 여러 건일 수 있는 POI 배지 특성상
카드 전체가 아니라 항목별로 링크를 붙였다. 리스트 아이템이 촘촘한 구조라 액티비티 배지의 풀사이즈
버튼 대신 작은 밑줄 텍스트 링크로 처리(요구사항의 "리스트 아이템에 맞는 크기로 조정" 지침 반영).
