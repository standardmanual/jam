# [UI] 푸터 위 슬로건 문구 추가

## 배경 / 문제 정의
푸터("© 2026 Standard Manual All Rights Reserved.") 바로 위에 동일한 텍스트 크기로
'JAM은 삐끗할 때도 있습니다. 하지만 곧 바로 잡습니다.' 문구를 가로 중앙정렬로 추가한다.
또한 푸터가 페이지마다 하드코딩되어 있는지 검토하고, 하드코딩이면 공통 모듈로 전환한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/components/ui/Footer.tsx`가 이미 단일 공통 컴포넌트이며
  `jam-web/src/app/(main)/layout.tsx`에서만 렌더링되어 하드코딩 중복은 없음 (사전 조사 완료).
  → 공통 모듈 전환 작업은 불필요, 신규 텍스트만 이 컴포넌트에 추가.
- 신규 문구는 `jam-web/src/lib/i18n/ko.ts`의 `common` 딕셔너리에 새 키로 추가
  (기존 `footerCopyright`과 동일한 패턴).

### UI/UX 관점
- 신규 텍스트는 기존 저작권 텍스트와 동일한 크기(`text-[11px]`, `leading-none`)로 스타일링.
- 가로 중앙정렬 (`flex justify-center` 또는 `text-center`).
- 위치: 기존 footer 콘텐츠(로고+저작권) 바로 위 줄.
- 홈(`/`) 경로는 기존과 동일하게 Footer 전체가 렌더링되지 않음 — 이 문구도 홈에서는 노출 안 함
  (기존 조건부 렌더링 로직 유지).

### 컨텐츠 관점
- UX Writing 가이드라인 검토 대상 문구: '신뢰 회복' 톤 — 해요체는 아니지만 사용자가 지정한
  고정 문구이므로 임의 수정 금지. 가이드 문서와 대조해 문제 없는지 확인만 진행.

## 구현 계획
1. `ko.ts`에 `footerSlogan: 'JAM은 삐끗할 때도 있습니다. 하지만 곧 바로 잡습니다.'` 키 추가.
2. `Footer.tsx`에서 기존 로고+저작권 줄 위에 새로운 줄로 슬로건 텍스트 렌더링, 동일 폰트 크기·중앙정렬 적용.
3. 로컬에서 페이지 렌더링 확인 (다크/라이트 무관, 텍스트 줄바꿈 여부 확인).

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
사전 조사대로 `Footer.tsx`가 이미 단일 공통 컴포넌트임을 재확인. 공통 모듈 전환은 불필요하며
슬로건 문구만 `ko.ts`에 신규 키(`footerSlogan`)로 추가하고, `Footer.tsx`에서 기존
로고+저작권 줄 위에 동일 폰트 크기(`text-[11px]`, `leading-none`)로 가로 중앙정렬 렌더링.
기존 `pathname === '/'` 조건부 렌더링 로직은 그대로 유지되어 홈에서는 신규 문구도 노출되지 않음.

### 변경된 파일
```
jam-web/src/lib/i18n/ko.ts
jam-web/src/components/ui/Footer.tsx
```

      jest 타입 에러만 존재, 이번 변경과 무관)

      줄과 동일한 flex/text 유틸리티 패턴을 재사용해 렌더링 리스크 낮음.
