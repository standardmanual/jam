# [BadgeEngine] 종목별 대표 배지 레벨업 미션 게이팅 도입

## 배경 / 문제 정의

현재 액티비티 배지는 Rare 이상 등급에서 `prerequisite_badge_names`(같은 종목 내 다른 속성 배지 중 아무거나 OR 보유)로 크로스게이트가 걸려 있다(`ACTIVITY_BADGES.md` 설계 원칙 #2). 종목별로 가장 "운동으로서 실제 목표 달성"처럼 느껴지는 배지 트리 1개씩(총 5개)을 골라, 이 크로스게이트 대신 **미션 메뉴에서 미션을 완료해야만 상위 등급 배지를 받을 수 있는 구조**로 전환한다.

미션 시스템 자체는 이미 존재하고(`jam-web/src/app/(main)/missions/`, `jam-web/src/app/admin/missions/`), 미션 완료 시 배지를 보상으로 지급하는 기능도 이미 있다(`grantMissionRewards`, `jam-web/src/lib/missions/rewards.ts`). 다만 설계 과정에서 점검한 결과, 기존 미션 엔진은 이번 정책이 요구하는 조건(연속일수·단일세션 지속시간·등반고도)을 계산하지 못해 **엔진 확장이 선행되어야** 한다 (아래 "시스템 결정사항" 참조).

## 최종 컨텐츠 스펙

5개 트리 모두 **Common은 미션 없이 기존 조건 그대로**, **Rare/Legendary/Mythic은 각각 미션을 완료해야** 다음 등급 배지 획득 조건이 열린다. 미션명과 미션보상배지명은 동일하게 확정한다 ("Hard"/"Ultra" 영문 표기는 프로젝트 한국어 전용 규칙에 대한 명시적 예외로 유지 확정됨). 미션보상배지의 대표 이미지는 **동일한 대상 배지의 해당 등급 이미지를 그대로 재사용**한다(예: "동네 산책러 레벨업"은 실제 "동네 산책러" Rare 배지 이미지 재사용).

## 주요 의사결정 / 핵심 메모

- 기존 크로스게이트(다른 속성 배지 OR)와 신규 미션 게이팅(단일 미션배지 AND)은 병행 — 5개 트리만 전환, 나머지 142개는 기존 유지.
- 사이클 미션은 최초 "평균속도" 안으로 제안했으나, 도로 위 과속 유도 위험으로 "롱라이드 지속시간"으로 변경.
- 러닝(첫 숨결) Legendary/Mythic 조건값을 기존 문서값(60km/150km)에서 40km/100km로 변경 확정.
- 등산(첫 고도) Mythic 조건값은 4,000m 하향 검토했으나, 등산 트리가 "누적" 조건임을 재확인하고 6,000m 유지로 최종 결정.
- 트레일 미션은 최초 "누적 등반"으로 설계했다가 "미션은 단일 활동 기준"이라는 정정에 따라 재설계. Mythic 단일 활동 4,000m는 현실적으로 달성 불가능한 난이도라는 우려로 3,000m로 하향.
- 미션명의 "Hard"/"Ultra" 영문 표기는 프로젝트 한국어 전용 절대 규칙과 충돌한다고 안내했으나, 사용자가 의도적으로 유지 확정.
- "미션상황 개인형" 요구사항은 기존 `achievement` 모드로 해석했으나 실제 코드 확인 결과 미충족 — 신규 모드 추가로 결정.
- 기존 발급 건 회수는 사용자가 명시적으로 지시했으나, Claude Code의 플랫폼 안전 규칙상(영구 데이터 삭제 직접 실행 금지) SQL만 준비하고 실행은 사용자가 직접 하기로 함.
