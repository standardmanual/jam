# [BadgeEngine] 종목별 대표 배지 레벨업 미션 게이팅 설계

## 배경 / 문제 정의

현재 액티비티 배지는 Rare 이상 등급에서 `prerequisite_badge_names`(같은 종목 내 다른 속성 배지 중 아무거나 OR 보유)로 크로스게이트가 걸려 있다(`ACTIVITY_BADGES.md` 설계 원칙 #2). 이 방식은 전체 147개 배지에 균일하게 적용되지만, "미션을 수행해야만 상위 등급 배지를 받을 수 있다"는 명확한 목표 달성 서사는 없다.

종목별로 가장 "운동으로서 실제 목표 달성"처럼 느껴지는 배지 트리 1개씩(총 5개)을 골라, 기존 크로스게이트 대신 **미션 메뉴에서 미션을 완료해야만 상위 등급 배지를 받을 수 있는 구조**로 전환한다. 미션 시스템은 이미 존재하며(`jam-web/src/app/(main)/missions/`, `jam-web/src/app/admin/missions/`), 미션 보상으로 "배지 지급"을 설정할 수 있는 기능도 이미 있다(`Service Plan/Specs/PRD/PointSystem/OBJECT_MODEL.md:76`). 즉 새 기능이 아니라 기존 미션 보상 기능 + 기존 crossgate 필드 조합으로 구현 가능하다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 선정된 5개 배지 트리는 Rare/Legendary/Mythic에서 기존 `prerequisite_badge_names`(다른 속성 배지 OR)를 제거하고, 아래 표의 "미션보상배지명" 1개만 배열에 넣는 방식(사실상 AND, 엔진 스펙상 배열 1개도 지원됨 — `CONDITION_JSON_SPEC.md:80`)으로 교체한다.
- Common 등급은 기존 설계 원칙("Common은 prerequisite 없음")을 그대로 유지하며 미션이 없다.
- 나머지 142개 배지는 기존 크로스게이트 로직을 그대로 유지한다 (이번 변경 범위 아님).
- 미션 조건 속성은 대상 배지 자체의 속성과 겹치지 않게 선정했고(예: 걷기는 거리 배지 + 연속일수 미션), 종목별 강도 곡선은 같은 종목의 이미 튜닝된 다른 배지 등급값을 재사용해 상대 난이도를 맞췄다.

### 컨텐츠 관점

**공통 규칙**: 선정된 트리는 5개(종목당 1개). Common은 미션 없음. Rare/Legendary/Mythic은 각각 별도의 미션에 참가해서 완료해야 다음 등급 배지 획득 조건이 열린다. 미션명·미션보상배지명의 등급 접미사는 "Hard"(Legendary용)/"Ultra"(Mythic용) 영문 표기를 의도적으로 유지한다(프로젝트 한국어 전용 규칙에 대한 명시적 예외로 확인됨).

## 구현 계획

1. 미션 메뉴에 위 15개 미션(5종목 × 3등급) 실제 생성 (어드민 미션 관리 화면 또는 SQL)
2. 미션보상배지 15종 실제 배지로 생성 (미션보상배지명은 가배정 상태 — 실제 이름 확정 필요)
3. 5개 대상 배지 트리(동네 산책러/첫 숨결/언덕의 도전자/첫 고도/야생의 주자)의 Rare/Legendary/Mythic `condition_json`에서 기존 `prerequisite_badge_names`를 제거하고 해당 미션보상배지명 1개로 교체
4. `ACTIVITY_BADGES.md`·`BADGE_ENGINE_UNIFIED.md`에 최종 반영
5. SQL 마이그레이션 파일 작성 (`supabase/migrations/0XX_...sql`)

## 주요 의사결정 / 핵심 메모

- 기존 크로스게이트(다른 속성 배지 OR)와 신규 미션 게이팅(단일 미션배지 AND)은 병행 — 5개 트리만 미션 게이팅으로 전환, 나머지 142개는 기존 유지.
- "가치 높은 배지"의 기준은 실제 운동 목표 달성감이 큰 속성(거리·고도·지속시간)으로 정의 — 빈도·연속·계절 등 리텐션형 속성은 제외 (사이클만 예외적으로 연속이 아닌 등반 속성 선택).
- 사이클 미션은 최초 "평균속도" 안으로 제안했으나, 도로 위 과속을 유도할 위험이 있어 "롱라이드 지속시간"으로 변경.
- 러닝(첫 숨결) 배지 조건값은 이번 설계 과정에서 기존 문서값(Legendary 60km/Mythic 150km)에서 40km/100km로 변경됨 — 사용자 확인 완료.
- 등산(첫 고도) Mythic 조건값은 4,000m로 낮추는 안이 논의됐으나, 등산 트리가 원래 "누적" 조건임을 재확인하고 6,000m 유지로 최종 결정.
- 트레일 미션 조건은 최초 "누적 등반"으로 설계했다가, "미션은 단일 활동 기준"이라는 사용자 정정에 따라 재설계. Mythic 단일 활동 4,000m는 현실적으로 달성 불가능한 난이도라는 우려로 3,000m로 하향.
- 미션명·미션보상배지명의 "Hard"/"Ultra" 영문 표기는 프로젝트 한국어 전용 절대 규칙과 충돌한다고 안내했으나, 사용자가 의도적으로 유지하기로 확정함(명시적 예외).
- 미션보상배지명은 최종 확정 아님(가배정) — 실제 생성 시점에 별도로 이름 확정 예정.
