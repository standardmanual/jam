# [UI] 하드코딩 속성값 → DS v2 토큰 전면 교체

## 배경 / 문제 정의

DS v2 적용(티켓 20260814_001) 이후에도 서비스 UI 소스코드에 하드코딩된 raw 속성값이 다수 잔존한다.
- Tailwind 임의값(raw 픽셀·raw 색상): 약 98건 (텍스트/간격/반경)
- 인라인 style 색상·rgba(): 약 29건
- Strava 브랜드 컬러 `#FC4C02`는 의도적 예외

목표: 모든 하드코딩 raw값을 DS v2 토큰(`--spacing-*`, `--text-*`, `--radius-*`, `--color-*`)으로 교체.
일치하는 토큰이 없으면 가장 근접한 값으로 매핑한다.

## DS v2 토큰 매핑 기준

### spacing
| raw | 토큰 |
|---|---|
| 4px | `--spacing-4` |
| 8px | `--spacing-8` |
| 10px | `--spacing-12` (근접) |
| 12px | `--spacing-12` |
| 16px | `--spacing-16` |
| 20px | `--spacing-24` (근접) |
| 24px | `--spacing-24` |
| 32px | `--spacing-32` |
| 40px | `--spacing-48` (근접) |
| 44px | `--touch-target-min` |
| 48px | `--spacing-48` |
| 64px | `--spacing-64` |

### typography (text-size)
| raw | 토큰 |
|---|---|
| 10–11px | `--text-caption` (12px, 근접) |
| 12px | `--text-caption` |
| 14px | `--text-small` |
| 16px | `--text-body` |
| 20px | `--text-body-l` |
| 24px | `--text-h4` |
| 28px | `--text-h3` |

### border-radius
| raw | 토큰 |
|---|---|
| 4px | `--radius-xs` |
| 8px | `--radius-sm` |
| 16px | `--radius-card` |
| 50%/9999px | `--radius-pill` |

## 상세 요구사항

### 서비스/코드베이스 관점
- 대상 경로: `jam-web/src/app/(main)/` (어드민 제외), `jam-web/src/components/`
- 제외 대상: admin 경로, `__tests__`, `StravaStatusCard.tsx`의 `#FC4C02`
- Tailwind arbitrary 값 → `var(--token)` 형식으로 교체
  - `text-[14px]` → `text-[length:var(--text-small)]`
  - `px-[16px]` → `px-[var(--spacing-16)]`
  - `rounded-[8px]` → `rounded-[var(--radius-sm)]`
- 인라인 style 색상값 → DS v2 색상 토큰 참조
- `rgba(0,0,0,0.X)` 패턴 → `color-mix()` 또는 `oklch()` 보다는 기존 `/opacity` Tailwind 패턴 유지하되, 색상 base는 토큰으로

### UI/UX 관점
- 시각적 변화 최소화: 토큰 값이 raw값과 ±2px 이내 차이인 경우 토큰으로 통일 허용
- 기능·레이아웃 변경 없음

## 구현 계획
1. `app/(main)/` 하위 페이지 컴포넌트 순회하며 raw 속성값 → 토큰 교체
2. `components/ui/`, `components/map/`, `components/inventory/` 컴포넌트 교체
3. CSS in JS (style={{}}) 패턴 교체

### 주요 의사결정 / 핵심 메모

- MapView.tsx의 Leaflet 마커 HTML 문자열 내 `#ffffff`, `rgba()` 값은 JavaScript 템플릿 문자열이므로 CSS var()를 주입해도 DOM 렌더 시 변수 해석이 안 됨 → 변경 제외

### 잔여 이슈
