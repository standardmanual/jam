## 상세 요구사항

### 수정 항목 1 — 미션 목록 타입 코드 노출

**위치:** `jam-web/src/app/(main)/missions/MissionsListClient.tsx` 약 212행 부근

**현재 상태:** raw 문자열(`RUNNING`, `HIKING` 등 영문 코드)이 그대로 화면에 표시됨  
**기대 상태:** 한국어 레이블로 표시됨  
**구현:** `MISSION_TYPE_LABELS` 딕셔너리가 동일 파일에 이미 정의되어 있으나 실제 렌더링에 연결되지 않음.
표시 지점에서 `MISSION_TYPE_LABELS[type] ?? type` 형태로 연결할 것.

**UX Writing 검증:**
- 미션 타입 레이블은 기존 `MISSION_TYPE_LABELS` 값 그대로 사용 (신규 용어 도입 금지)

### 수정 항목 2 — 미션 상세 activity_type 미번역

**위치:** `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx` 136~138행 부근

**현재 상태:** `activity.type`(영문 코드)이 번역 없이 그대로 표시됨  
**기대 상태:** 한국어로 번역되어 표시됨  
**구현:** 
1. `ACTIVITY_TYPE_LABELS` 딕셔너리를 파일 상단에 추가:
   ```ts
   const ACTIVITY_TYPE_LABELS: Record<string, string> = {
     Run: '달리기',
     Ride: '자전거',
     Hike: '하이킹',
     Walk: '걷기',
     Swim: '수영',
     Workout: '운동',
     // 기존 코드에서 사용되는 타입을 확인 후 추가
   }
   ```
2. 렌더링 지점에서 `ACTIVITY_TYPE_LABELS[activity.type] ?? activity.type` 적용

**주의:** 실제 Supabase에 저장된 `activity_type` 값을 grep/코드 확인 후 딕셔너리를 완성할 것.

### 수정 항목 3 — 미션 보상 배지 alt 빈값

**위치:** `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx` 191행 부근

**현재 상태:** `<img alt="">` 또는 `<Image alt="">` — 빈 alt  
**기대 상태:** `alt="{배지명} 배지"` (예: `alt="산악왕 배지"`)  
**구현:** 배지 객체의 이름 필드(예: `badge.name`, `badge.title`, `badge.display_name` 중 실제 필드명 확인)를 사용해 `alt={${badge.name} 배지}` 형태로 수정

**UX Writing 검증:**
- alt 텍스트: `{배지명} 배지` 형식 고정 (DESIGN_RENEWAL_SPEC §7 Accessibility)

### 수정 항목 4 — 인벤토리 우상단 버튼 레이블 확인 및 수정

**현재 상태 확인 필요:** 버튼 레이블이 "믹스" / "믹스하기" / "조합" / "조합하기" 중 무엇인지 확인

**구현:** 레이블이 "믹스하기"가 아닌 경우 수정. `/combine` 경로 연결 유지.

### 구현 내용 요약
4가지 즉시 수정 항목 모두 구현 완료.

1. `MissionsListClient.tsx`: 미션 카드 하단 타입 표시(`m.mission_type` 영문 코드) →
   `MISSION_TYPE_LABELS[m.mission_type] ?? m.mission_type` 연결. `uppercase` CSS 클래스도 함께 제거.
2. `MissionDetailClient.tsx`: `ACTIVITY_TYPE_LABELS`를 `@/lib/utils`에서 import 후
   `condition.activity_type` 렌더링에 적용. 기존 `capitalize` CSS 클래스도 함께 제거.
3. `MissionDetailClient.tsx`: 보상 배지 이미지 `alt=""` → `alt={`${b.name} 배지`}`
