## 상세 요구사항

### 항목 1 — 미션 카드 상태 뱃지 (To-Do 010)

**위치:** `jam-web/src/app/(main)/missions/MissionsListClient.tsx`

**현재:** 탭(진행중/참가중/종료)으로만 상태 구분. 카드 자체에 상태 표시 없음.  
**기대:** 카드마다 상태 chip 표시.

**뱃지 로직 (DB 컬럼 추가 없이 기존 필드 기반):**
- `status === 'active'` + 생성일 7일 이내(`created_at > now() - 7days`) → **"NEW"** (`--color-primary` 오렌지, `--radius-tags`)
- `status === 'active'` + 사용자가 참가한 미션(`userMissionStatus` 또는 참가 여부 필드 확인) → **"참가중"** (흰 outline, `--radius-tags`)
- `status === 'active'` + `end_date is null` → **"상시"** (흰 outline, `--radius-tags`)
- `status === 'ended'` → 뱃지 없음

뱃지 복수 표시 가능 (예: "NEW" + "참가중" 동시). 위치: 카드 좌상단 또는 썸네일 위 오버레이.

> 코드 확인 사항: 미션 카드에 참가 여부를 알 수 있는 필드가 있는지 확인. 없으면 "참가중" 뱃지는 보류하고 NEW + 상시만 구현.

**UX Writing:** "NEW", "참가중", "상시" — 고정 용어.

### 항목 2 — 인벤토리 슬롯 카운트 개선 (To-Do 012)

**위치:** `jam-web/src/app/(main)/inventory/` 하위 컴포넌트 (슬롯 카운트 표시 부분)

**현재:** 단순 "N개 남음" 표시.  
**기대:** `{used} / {max} 슬롯 사용중 · {remaining}개 남음` 형식

- `used` = 현재 사용 슬롯 수
- `max` = 최대 슬롯 수
- `remaining = max - used`
- 위치: 기존 표시 위치 유지 (프로그레스바 아래)
- 색상: `--color-text-secondary` (`--text-small`)

**UX Writing:** "N / M 슬롯 사용중 · K개 남음" 형식 고정.

### 항목 3 — 아이템북 발견 배지 수 표시 (To-Do 009)

**위치:** `jam-web/src/app/(main)/itembooks/` 하위 컴포넌트

**현재:** `discoveredBadgeCount`가 계산되지만 UI에 미노출.  
**기대:** 각 아이템북 카드에 발견 진행률 표시.

- 표기: `{discovered} / {total}` 또는 `{discovered}개 발견` (코드 데이터 구조 확인 후 결정)
- 전체 배지 수(`totalBadgeCount`)가 있으면 `N / M` 형식, 없으면 `N개 발견`
- 색상: `--color-text-secondary`, `--text-caption`

**UX Writing:** 수량 표기는 "N / M" 또는 "N개 발견" — 직관적 형식 우선.
