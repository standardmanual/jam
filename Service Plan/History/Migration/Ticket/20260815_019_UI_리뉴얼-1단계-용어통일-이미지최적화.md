### 항목 2 — 네이티브 `<img>` → Next.js `<Image>` 최적화 (To-Do 006)

**목적:** 자동 WebP 변환, lazy-loading, 사이즈 최적화 적용.

**구현 방법:**
1. `jam-web/src/` 전체 `<img ` 태그 grep → 목록 확보
2. SVG·아이콘·base64 data URI는 교체 제외
3. 외부 URL 이미지: `next.config.js`의 `images.remotePatterns` 등록 (이미 등록된 도메인 확인 후 누락분 추가)
4. 각 이미지에 `width`/`height` 명시 또는 `fill` prop + 부모 `position: relative` 처리
5. CLS 방지: 이미지 크기를 미리 알 수 없는 동적 이미지는 `fill` + `aspect-ratio` 컨테이너 사용

**주의:**
- 배지 이미지(`badge_image_url`)는 Supabase Storage 외부 URL — 이미 remotePatterns에 있는지 확인
- 아바타·썸네일 등 크기가 정해진 이미지는 `width`, `height` 명시 방식 선호
