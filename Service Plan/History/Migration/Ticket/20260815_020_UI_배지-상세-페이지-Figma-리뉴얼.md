# [UI] 배지 상세 페이지 Figma 리뉴얼 — 3종 베리에이션

## 배경 / 문제 정의

Figma에서 배지 상세 페이지 디자인이 확정됐으나, 현재 구현은 이전 화이트 카드 기반으로
다크 테마 기조와 맞지 않는다. 09_배지 상세 / 13_인벤토리 상세 두 스펙을 통합해
단일 구조 위에 배지 유형별(액티비티·아이템·POI) 3종 베리에이션으로 재구현한다.

**현재 상태:**
- `/badges/[id]/page.tsx` — 흰 `<Card>` 컴포넌트 + 128px(item)/176px(activity) 사각형 아바타
- `/inventory/[itemId]/page.tsx` — 동일하게 흰 카드 기반

**기대 상태 (Figma 스펙):**
- 200px 원형 흰 아바타 (`rounded-full bg-white`)
- 섹션 구분: 전체 너비 divider (`--color-border`)
- 카드: 다크 서피스 (`--color-surface` + `--color-border` 1px 테두리)
- 섹션 레이블: 11px Bold uppercase `--color-text-secondary`

### UI/UX 관점

- **아바타 원형**: `rounded-full` — 기존 `rounded-[var(--radius-cards)]` 대체
- **divider**: `<hr className="border-0 border-t border-[var(--color-border)] mx-0" />` (full-width, padding 없이)
- **다크 카드**: `bg-surface` 토큰 사용 (`--color-surface` = `#1A1A1A`), 흰 `Card` 컴포넌트 제거
- **아이템 "배지 상세" 링크**: 인벤토리에서 badges 상세로 교차 진입 경로 신설
