# [UI] 배지 상세 페이지 상단 이미지 영역 카드 레이아웃 변경

## 배경 / 문제 정의
현재 배지 상세 페이지(액티비티·아이템·POI 3종) 상단에는 원형(rounded-full) 이미지 컨테이너와 배지명, 배지등급이 flex column으로 나열되어 있다. 이를 가로 기준 1:1 비율의 카드 영역으로 통합해 구조적으로 정리한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 대상 파일: `jam-web/src/app/(main)/badges/[id]/page.tsx`
- 3개 변형(item, poi, activity) 모두 동일하게 변경

### UI/UX 관점
- 상단 배지 이미지 영역을 카드 타입으로 변경
  - 카드 보더: **없음**
  - 카드 배경색: **투명**
- 카드 내부에 포함할 요소: 배지 이미지, 배지명(`<h1>`), 배지 등급(`<RarityBadge>`)
- `description`은 카드 밖(하단)에 유지
- 카드 비율: **가로값 기준 1:1** (`aspect-square w-full`)
- 카드 내부 배치: 배지 이미지, 배지명, 배지 등급을 영역 안에 밸런스 있게 세로 배치

### DS 재사용 판정
- `Card` 컴포넌트: 배경·보더 있음 → 조건 불일치, 미사용
- `BadgeFrame` 컴포넌트: 고정 px 크기, 이미지 클리핑 전용 → 조건 불일치, 미사용
- **서비스 전용 div + Tailwind** 로 구현

## 구현 계획

### hero-section 변경 (3개 변형 공통)

현재:
```
div.flex.flex-col.items-center.gap-6.pt-[40px].px-6.pb-[32px]
  div (원형 200×200 이미지 컨테이너)
  h1 (배지명)
  RarityBadge
  p.description (있는 경우)
```

변경 후:
```
div.px-6.pt-[40px].pb-[32px]
  div.w-full.aspect-square (투명 배경, 보더 없음, flex col)
    div (이미지 영역 - 유연한 크기)
    h1 (배지명)
    RarityBadge
  p.description (카드 밖 하단, 있는 경우)
```

- 이미지 크기: `w-[55%] aspect-square` 비율로 카드 내부에서 유동적으로
- 배치: 카드 내부 `flex flex-col items-center justify-center gap-4 p-6`
- 이미지 원형 컨테이너는 유지 (bg-white, rounded-full)
