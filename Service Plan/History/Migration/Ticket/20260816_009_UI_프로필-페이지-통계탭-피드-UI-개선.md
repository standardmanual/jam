# [UI] 프로필 페이지 통계탭·피드 UI 개선

## 배경 / 문제 정의
프로필 페이지의 여러 UI 요소가 타 페이지 디자인과 불일치하고, 희귀도 태그 스타일이
비일관적으로 적용되어 있다.

## 상세 요구사항

### UI/UX 관점
- 배지/컬렉션/팔로워/팔로잉 통계탭 영역의 숫자 텍스트에 primary 컬러 강조 적용
- 최근 활동(FeedSection) 아래 필터 탭 디자인을 배지/미션 페이지와 동일하게 통일 (`outlined={false}`)
- 최근 활동 피드에 표시되는 배지 등급 태그를 보더 타입 → 배경색 타입으로 변경
  (토큰: `--color-rarity-*` 배경, `--color-rarity-*-text` 텍스트)
- 최근 활동 각 탭 목록에 ListRowCard UI 컴포넌트 활용 확인 및 정비

### 서비스/코드베이스 관점
- `ProfileClient.tsx` — statTabs 숫자 span에 `text-[color:var(--color-primary)]` 추가
- `FeedSection.tsx` — SlidingTabs에 `outlined={false}` 추가
- `FeedSection.tsx` — `RARITY_COLOR` 맵을 배경색 기반으로 변경 (shadow → bg + text 토큰)
- FeedCard 내 rarity 태그 및 DetailSheet 내 rarity 태그 모두 반영

## 구현 계획

### 재사용 판정 (오케스트레이터)
- SlidingTabs: 기존 컴포넌트 재사용, `outlined={false}` prop만 추가
- ListRowCard: FeedSection.FeedCard에서 이미 사용 중 — 구조 유지
- RarityBadge: DS에 존재하나 서비스 래퍼 없음 → 토큰 직접 사용하여 인라인 스타일 적용

### 변경 파일
- `jam-web/src/app/(main)/FeedSection.tsx`
- `jam-web/src/app/(main)/profile/ProfileClient.tsx`
