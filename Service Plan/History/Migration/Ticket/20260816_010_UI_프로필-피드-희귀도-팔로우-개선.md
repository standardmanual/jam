# [UI] 프로필·피드 희귀도 태그 타이포 통일·팔로우 롤백·RARITY 공통화

## 배경 / 문제 정의
티켓 009 개선 리뷰(스카우트)에서 세 가지 미비점이 제기됨:
1. 희귀도 태그 타이포: 서비스 측 희귀도 태그에 DS RarityBadge 기준 fontWeight 700, textTransform uppercase, letterSpacing 누락
2. 팔로우 낙관적 업데이트 롤백 누락: API 실패 시 UI 상태가 서버값과 틀어지는 버그
3. RARITY_LABEL 중복 정의: FeedSection·BadgesClient 두 곳에 동일 맵 존재 → 공통 유틸 추출

## 상세 요구사항

### 서비스/코드베이스 관점
1. **희귀도 태그 타이포 통일** (`FeedSection.tsx`)
   - FeedCard 내 rarity span, DetailSheet 내 rarity span 모두에
     `font-bold uppercase tracking-[var(--tracking-label)]` 추가
   - DS RarityBadge.jsx 기준: fontWeight 700, textTransform uppercase, letterSpacing var(--tracking-label)
   - tracking 토큰: `--tracking-label`이 DS CSS에 없을 경우 `tracking-widest`(Tailwind 기본) 사용

2. **팔로우 낙관적 업데이트 롤백** (`ProfileClient.tsx`)
   - `handleFollow`: API 실패 시 setFollowing·setFollowerCnt 원래 값으로 되돌리기
   - `handleListFollow`: API 실패 시 setListFollowStates 원래 값으로 되돌리기
   - try/catch 패턴 사용

3. **RARITY_LABEL/RARITY_COLOR 공통 유틸 추출** (`jam-web/src/lib/rarity.ts` 신규)
   - `RARITY_LABEL` (d.feed.rarity* 기반), `RARITY_COLOR` (bg+text 토큰 클래스 맵) 상수 추출
   - `FeedSection.tsx`·`BadgesClient.tsx` 양쪽에서 import하여 중복 제거
   - BadgeRarity 타입 import 포함

### UI/UX 관점
- 희귀도 태그가 DS RarityBadge와 시각적으로 통일됨 (대문자+볼드+자간)
