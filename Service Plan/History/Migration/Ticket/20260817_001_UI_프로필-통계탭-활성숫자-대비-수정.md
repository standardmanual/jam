# [UI] 프로필 통계탭 활성 숫자 대비 수정 + 라벨 볼드 처리

## 배경 / 문제 정의
프로필 페이지 통계바(배지/컬렉션/팔로워/팔로잉, `SlidingTabs` 기반)에서 탭을 활성화하면
슬라이딩 pill 배경이 `var(--color-primary)`(레드-오렌지)로 바뀌는데, 숫자 텍스트가
`text-[color:var(--color-primary)]`로 하드코딩돼 있어 활성 탭에서는 배경과 글자색이 같아져
숫자가 보이지 않는 문제가 있었다. 라벨(배지/컬렉션/팔로워/팔로잉) 텍스트도 볼드 처리 요청.

## 원인
`SlidingTabs`는 `.t-tab[aria-selected="true"] { color: var(--tabs-text-active); }`로 활성 탭의
글자색을 바꾸는데, 이는 상속을 통해 적용된다. 라벨 span은 색을 따로 지정하지 않아 정상적으로
흰색으로 바뀌지만, 숫자 span은 자체 `color`를 인라인으로 고정해 상속을 끊어버려 활성 상태에서도
계속 레드-오렌지로 남아있었다.

## 수정 내용
- `jam-web/src/app/(main)/profile/ProfileClient.tsx`의 `statTabs` 생성부: 각 탭이 현재
  활성 탭인지(`isTabView && activeTab === tab.key`) 판단해, 활성일 때는 숫자 색을
  `var(--tabs-text-active)`(현재 variant의 활성 텍스트색, onCard에서는 흰색)로, 비활성일 때는
  기존 `var(--color-primary)`로 표시.
- 같은 곳의 라벨 span에 `font-bold` 추가.
