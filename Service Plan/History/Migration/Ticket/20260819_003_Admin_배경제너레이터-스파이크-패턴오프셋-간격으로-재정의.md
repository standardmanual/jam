# [Admin] 배경 제너레이터 스파이크 — 패턴 "오프셋"을 행/열 간격으로 재정의

## 배경 / 문제 정의
티켓 [20260819_001](20260819_001_Admin_배경테마-제너레이터-스파이크.md) 스파이크에서 패턴 모드의
"오프셋"은 CSS `background-position`으로 타일 전체를 밀어내는(pan) 방식으로 구현됐다.

사용자 정정: "오프셋"은 **행 사이 간격(row gap)·열 사이 간격(column gap)을 각각 조정하는 옵션**이어야
한다 — 타일을 미는 게 아니라 타일과 타일 사이의 여백을 늘리고 줄이는 것.

이 정의는 기존에 별도로 제안했던 "Gap(간격)" 옵션과 사실상 동일한 역할이다. 별도 옵션 두 개로
중복시키지 않고 **"오프셋" 하나로 통합**한다 — 즉 최종 패턴 옵션은 7종이 아니라 6종이 된다:
XY 그리드 수 / 오프셋(행 간격·열 간격) / 대칭반복(mirror) / 이미지 크기 조절 / Row·Column
stagger(벽돌쌓기 배치) / 이미지 회전.

## 상세 요구사항

### 서비스/코드베이스 관점
- `PatternPanel.tsx`에서 기존 "오프셋"(가로/세로 슬라이더, CSS `background-position` 라이브 적용)을
  제거하고, **"행 사이 간격" / "열 사이 간격"** 두 개의 슬라이더로 교체한다.
- `patternTile.ts`에서 이 간격을 반영: 티켓 20260819_001 완료 기록에 따르면 대칭반복·Gap·stagger·
  회전·크기는 이미 "반복 최소 단위를 캔버스에 구워서 `background-repeat`로 반복"하는 방식으로
  통일돼 있었다. 오프셋도 이 그룹으로 편입시켜, 캔버스에 타일을 구울 때 이미지 주위에
  행간격(세로 방향 여백)·열간격(가로 방향 여백)을 반영해서 그린 뒤 반복시킨다. (기존에 오프셋만
  예외적으로 라이브 CSS 포지션으로 처리하던 특수 케이스를 없애는 것 — 코드 단순화 효과도 있음)
- 이미 구현돼 있던 "Gap" 관련 코드가 있다면 오프셋 구현으로 흡수·통합하고 중복 옵션을 남기지 않는다.
- 그 외 제약(스테이징 전용, 로그인 없이 접근, main 머지 금지)은 티켓 001과 동일.

### UI/UX 관점 (해당 시)
- "행 사이 간격" / "열 사이 간격"을 별도 슬라이더로 분리 노출해 각각 독립 조정 가능해야 한다.

### 컨텐츠 관점 (해당 시)

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `PatternPanel.tsx`의 "오프셋 X / Y"(배경 밀기) 슬라이더와 별도 "Gap" 슬라이더를 모두 제거하고,
  "오프셋 (행 간격 / 열 간격)" 슬라이더 1쌍으로 통합했다. 기존 "Gap" 코드(단일 값으로 셀 크기를
  줄이던 로직)를 오프셋 구현이 그대로 흡수했다 — 별도 옵션으로 중복시키지 않았다.
- `patternTile.ts`의 `buildTileCanvas`에서 `gap` 단일 파라미터를 `rowGap`(셀 세로폭 축소, 행 사이
  여백)·`colGap`(셀 가로폭 축소, 열 사이 여백)로 분리해 각각 독립 반영한다. 캔버스에 타일을 구울 때
  간격을 이미 반영해서 굽고 `background-repeat`로 반복하는 기존 통일 방식에 오프셋을 편입시켰다.
- 기존에 오프셋만 예외적으로 처리하던 라이브 CSS `background-position` 로직(`PatternPanel.tsx`의
  `style.backgroundPosition`, `flattenPattern`의 `offsetX`/`offsetY` 인자)을 모두 제거했다.
  `flattenPattern`은 이제 `(tileCanvas, outWidth, outHeight)` 3개 인자만 받아 오프셋 없이 타일을
  그대로 반복해서 평면화한다.
- `types.ts`의 `PatternParams`에서 `offsetX`/`offsetY`/`gap` 3개 필드를 제거하고 `rowGap`/`colGap`
  2개 필드로 정리했다 (기본값 각 0, 슬라이더 범위 0~60px, 기존 Gap과 동일).
- **최종 패턴 옵션은 6종**: XY 그리드 수 / 오프셋(행 간격·열 간격) / 대칭반복(mirror) / 이미지 크기
  조절 / Row·Column stagger(벽돌쌓기 배치) / 이미지 회전.

### 주요 의사결정 / 핵심 메모
- "오프셋"과 "Gap"은 사용자 정정에 따라 동일 개념(타일 사이 여백)으로 판단해 하나로 통합했다.
  UI 상 라벨은 "오프셋 (행 간격 / 열 간격)"으로 노출해 사용자가 원래 기대한 용어("오프셋")를
  유지하면서 실제 동작(간격 조정)을 괄호로 명시했다.
- 행 간격(rowGap)은 셀 세로폭(cellH)을, 열 간격(colGap)은 셀 가로폭(cellW)을 줄이는 방식으로
  구현했다 — `tilePitchY - rowGap`, `tilePitchX - colGap`. 이미지가 셀 안에서 축소되며 타일 사이
  여백이 생기는 방식으로, 티켓 001의 "캔버스에 구워서 반복" 통일 원칙을 그대로 따른다.
