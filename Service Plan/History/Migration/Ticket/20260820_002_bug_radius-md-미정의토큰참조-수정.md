# [bug] `--radius-md` 미정의 토큰 참조 수정

## 배경 / 문제 정의

모듈러-서비스 토큰 전수 비교 조사 중 발견: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx:282`가
`rounded-[var(--radius-md)]`로 `--radius-md`를 참조하는데, 이 토큰은 `design-system/tokens/radius.css`
주석에 "v2 changes: --radius-md removed (caused card < md confusion)"이라고 명시된 대로 DS v2에서
의도적으로 제거됐고, `globals.css`에도 정의된 적이 없다. 즉 미정의 CSS 변수라 해당 요소가 현재
`border-radius` 없이(각진 모서리로) 렌더링되고 있을 가능성이 높다.

## 상세 요구사항

1. `MissionDetailClient.tsx:282`의 실제 화면(스크린샷/Playwright 등으로) 확인 — 정말 각진
   모서리로 보이는지, 우연히 다른 규칙으로 radius가 적용돼 눈에 안 띄는지 먼저 확인.
2. 깨져 있다면 올바른 토큰으로 교체. 후보: `--radius-sm`(8px) / `--radius-card`(16px) — 해당
   요소가 무엇인지(카드/버튼/뱃지 등) 보고 문맥에 맞는 쪽 선택.
3. `grep -rn "var(--radius-md)"` 등으로 같은 패턴의 다른 잔존 참조가 없는지 전체 재확인.

## 구현 계획

1. 실제 렌더링 확인
2. 올바른 토큰으로 교체
3. 전체 코드베이스 재검색으로 유사 사례 없는지 확인

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
`MissionDetailClient.tsx:282`의 보상 배지 썸네일 컨테이너(`w-16 h-16`, 64px)가 DS v2에서 제거된
`--radius-md`를 참조해 미정의 CSS 변수 상태였다. 미정의 var()는 브라우저에서 기본값 없이 무시되므로
해당 요소는 각진 모서리로 렌더링되고 있었을 것으로 판단(런타임 인증 게이트로 실제 스크린샷 확인은
불가, 아래 alerts 참조). 같은 파일 내 동일 64px 썸네일 컨테이너 패턴을 다른 화면(`TodayCardStack.tsx`,
`ProfileClient.tsx`)에서 조사한 결과 모두 `--radius-cards`(16px)를 사용하는 것을 확인해 동일 토큰으로
교체했다. `--radius-sm`(8px)은 인풋/칩용으로 이 문맥(카드형 이미지 썸네일)에 맞지 않아 배제.

전체 재검색(`grep -rn "radius-md" jam-web/src`) 결과 앱 소스 코드 내 잔존 참조는 이 1건뿐이었다.
`design-system/` 폴더 내 `_ds_bundle.js`, `dashboard.html`, `_ds_manifest.json`, `guidelines/radius-scale.html`,
`_adherence.oxlintrc.json`에도 `--radius-md`(v1 시절 12px 값) 참조가 남아 있으나, 이들은 MODULAR
자체의 빌드 산출물/문서 아티팩트이며 서비스 코드(`jam-web/src`)가 아니라 이번 티켓 범위(`MissionDetailClient.tsx`
및 서비스 코드 전수조사) 밖으로 판단해 손대지 않았다. 별도 확인 필요(alerts 참조).
