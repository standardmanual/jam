# [UI] 프로필 통계탭 이중 박싱 제거

## 배경 / 문제 정의

프로필 페이지 통계탭(배지/컬렉션/팔로워/팔로잉)이 바깥 흰 박스 안에 여백을 두고 안쪽에
회색 배경 박스가 또 들어있는 이중 박싱으로 보인다. `ProfileClient.tsx`가
`<Card tone="inverse" className="p-0 overflow-hidden">`로 패딩을 0으로 만들려 했으나,
티켓 20260820_009에서 전환된 MODULAR `Card.jsx`는 padding을 항상 인라인
`style={{ padding: 'var(--layout-card-padding)' }}`로 부여한다. 인라인 style은 CSS
클래스보다 항상 우선순위가 높아 `className="p-0"`가 무시되고 24px 패딩이 그대로
적용되면서, 그 안의 회색 `SlidingTabs`(`.t-tabs`, `--tabs-bar-bg: rgba(0,0,0,0.06)`)와
이중 박스처럼 보이는 것이 원인이다.

같은 패턴(`Card tone="inverse" className="p-0 ..."`)이
`TodayCardStack.tsx:51`에도 있어 동일 버그가 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `Card.jsx`는 20260820_009에서 "padding prop 제거 — 토큰으로 전역 통일"을 의도적으로
  선택한 것이므로, prop을 되살리거나 컴포넌트 동작을 바꾸지 않는다(다른 11개 호출처 영향 방지).
- 대신 `className="p-0"` → `style={{ padding: 0 }}`로 변경한다. `Card.jsx`는
  `style={{ ...토큰값, ...style }}` 순서로 병합하므로 `style` prop이 토큰값을 정상적으로
  덮어쓴다.
- `ProfileClient.tsx`(통계탭)와 `TodayCardStack.tsx`(동일 패턴) 양쪽 모두 수정.

### UI/UX 관점
- 흰 바깥 박스가 사라지고 회색 통계탭 박스가 Card의 크기(모서리 radius 포함)를 그대로
  채워야 한다. `overflow-hidden`은 유지해 radius 클리핑을 보존한다.

## 구현 계획
1. `ProfileClient.tsx` 통계 바 Card의 `className="p-0 overflow-hidden"` →
   `className="overflow-hidden" style={{ padding: 0 }}`로 변경
2. `TodayCardStack.tsx`도 동일 패턴 확인 후 동일하게 수정
3. staging에서 dev-login 후 프로필 페이지 통계탭, 홈 TodayCardStack 카드 육안 확인
