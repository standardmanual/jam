# [UI] 배지 상세 화면 TopNav-컨텐츠 간 여백 제거

## 배경 / 문제 정의

배지 상세 화면(`badges/[id]/page.tsx`)에서 TopNav(뒤로가기 바) 하단과 페이지 컨텐츠
(배지 아이콘이 든 회색 카드) 시작 부분 사이에 눈에 띄는 세로 공백이 있다. 사용자가
스크린샷에 빨간 펜으로 표시하며 이 간격 제거를 요청했다.

원인: `BadgeHeroSection.tsx:36`의 `pt-[40px]`(TopNav 다음 첫 컴포넌트의 상단 패딩)이
세로 간격 전체를 만들고 있다. TopNav 자체(`design-system/components/navigation/TopNav.jsx`)는
세로 방향 padding/margin이 없어 원인이 아니다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/(main)/badges/[id]/BadgeHeroSection.tsx:36`의 `pt-[40px]`를 제거(0)한다.
- `BadgeHeroSection`은 item/poi/activity 3개 배지 변형이 공유하는 컴포넌트이므로, 세
  변형 화면 모두에서 여백이 사라지는지 확인한다.
- pt 제거로 인해 회색 카드가 페이지 좌우 패딩(`px-6`)과 별도로 위쪽에서 잘리거나 다른
  요소와 겹치지 않는지 확인한다.

### UI/UX 관점
- TopNav 바로 아래에 컨텐츠가 붙어야 하며, 과도한 여백 없이 자연스러운 최소 간격만
  남기거나 완전히 붙인다(사용자 지시대로 "간격 삭제" 우선 — 완전 제거 후 시각적으로
  너무 붙어 보이면 그때 최소값 조정).

## 구현 계획
1. `BadgeHeroSection.tsx`의 `pt-[40px]` → 제거(클래스에서 삭제, 필요시 `pt-0`)
2. staging에서 dev-login 후 배지 상세 화면(item/poi/activity 각 1건씩) 육안 확인
