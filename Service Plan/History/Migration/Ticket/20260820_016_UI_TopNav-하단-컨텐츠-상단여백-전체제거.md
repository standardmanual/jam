# [UI] TopNav 하단 컨텐츠 상단 여백 전체 제거

## 배경 / 문제 정의

티켓 20260820_014에서 배지 상세 화면의 TopNav-컨텐츠 간 40px 여백을 제거했다. 사용자가
이를 전체 서비스로 확장 요청: **TopNav를 쓰는 모든 화면에서, TopNav 바로 다음 컨텐츠의
상단 padding-top을 전부 0으로 통일**한다. 조사 결과 대부분 화면이 `--spacing-24`(24px)
토큰으로 일관 적용돼 있었으나, 이 토큰 표준값을 포함해 **전부 제거**하기로 사용자가
명시 확인했다(범위 확정 완료 — 배지상세류의 비정상적으로 큰 값만 고치는 게 아니라
TopNav 있는 화면 전체를 대상으로 함).

TopNav 자체(`design-system/components/navigation/TopNav.jsx`)는 세로 padding/margin이
없다(가로 padding, height 56px, safe-area-inset-top만 있음) — 세로 여백은 전부 TopNav
다음에 오는 개별 화면의 wrapper가 만들고 있다.

## 상세 요구사항

### 서비스/코드베이스 관점

TopNav를 사용하는 화면 전수 조사 결과(어드민 제외 — MODULAR 적용 대상 아님), 아래 파일의
TopNav 직후 컨텐츠 wrapper에서 **padding-top(pt-*)만** 0으로 변경한다.
좌우 padding(px-*), 하단 padding(pb-*), 요소 간 gap은 건드리지 않는다.

1. `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx:136` — `pt-8` → 제거
2. `jam-web/src/app/(main)/missions/[id]/status/MissionStatusClient.tsx` — 로딩(501)·에러(506)
   `pt-6`, 랭킹형(531) 인라인 `padding` 중 top, 달성형(599) `pt-[var(--spacing-16)]`,
   개인형(625) `pt-[var(--spacing-24)]` — 모두 top 값만 0으로
3. `jam-web/src/app/(main)/search/page.tsx:91` — `pt-[var(--spacing-24)]` → 제거
4. `jam-web/src/app/(main)/points/page.tsx:81` — `pt-[var(--spacing-24)]` → 제거
5. `jam-web/src/app/(main)/profile/edit/page.tsx:210` — `pt-[var(--spacing-24)]` → 제거
6. `jam-web/src/app/(main)/profile/ProfileClient.tsx:432` — 타인 프로필(TopNav 있는) 분기의
   `pt-[var(--spacing-24)]` → 제거. **본인 프로필 분기(티켓 015에서 만든
   `pt-[calc(env(safe-area-inset-top)+var(--spacing-24))]`)는 TopNav가 없는 케이스이므로
   이번 티켓 대상이 아님 — 건드리지 않는다.**
7. `jam-web/src/app/(main)/[username]/followers/page.tsx:74` — `pt-[var(--spacing-24)]` → 제거
8. `jam-web/src/app/(main)/[username]/following/page.tsx:74` — `pt-[var(--spacing-24)]` → 제거
9. `jam-web/src/app/(main)/[username]/itembooks/page.tsx:142` — `pt-[var(--spacing-24)]` → 제거
10. `jam-web/src/app/(main)/itembooks/[id]/page.tsx:216` — `pt-4` → 제거

(`badges/[id]/BadgeHeroSection.tsx`는 티켓 014에서 이미 0으로 완료 — 이번 대상 아님.)

각 파일 수정 전, 라인 번호가 최신 상태와 일치하는지 먼저 확인할 것(다른 병합으로 라인이
밀렸을 수 있음) — grep으로 `TopNav`와 그 직후 wrapper를 재확인 후 수정.

### UI/UX 관점
- TopNav 바로 아래에 컨텐츠가 여백 없이 붙어야 한다.
- 좌우 여백·컨텐츠 내부 요소 간 간격(gap)은 유지해 레이아웃이 깨지지 않게 한다.

## 구현 계획
1. 위 10개 파일을 순회하며 padding-top 값만 0으로 변경
2. `npx tsc --noEmit`으로 타입 에러 없음 확인
3. staging에서 dev-login 후 각 화면(미션 상세, 미션 현황 3가지 분기, 검색, 포인트,
   프로필 수정, 타인 프로필, 팔로워/팔로잉, 유저 컬렉션 목록, 아이템북 상세) 육안 확인

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
티켓에 명시된 10개 파일에서 TopNav 직후 컨텐츠 wrapper의 padding-top(pt-*)만 0으로 변경.
좌우/하단 padding, gap은 그대로 유지. `MissionStatusClient.tsx`의 랭킹형 인라인
`padding: '12px 16px 8px'`는 top 값만 `0px`로 변경. `ProfileClient.tsx`는 티켓 015에서
분기된 타인 프로필(`!isOwnProfile`) 케이스의 `pt-[var(--spacing-24)]`만 `pt-0`으로 변경,
본인 프로필의 safe-area 보정 padding은 그대로 유지.
