# [bug] 프로필 컬렉션 목록 등급 태그 미노출

## 배경 / 문제 정의

배지 > 컬렉션 탭 > 컬렉션 목록에서는 각 컬렉션 그리드 카드 대표 이미지에 등급(rarity)
태그와 완성 태그가 함께 노출된다. 반면 프로필 > 컬렉션 탭 > 컬렉션 목록에서는 완성
태그만 보이고 등급 태그가 노출되지 않는다.

원인 조사 결과, 두 화면은 동일한 컴포넌트(`jam-web/src/components/ui/CollectionGridCard.tsx`)를
쓰고 있고 태그 렌더링 로직도 하나뿐이라 스타일 분기는 없다. 문제는 데이터 소스 단계에
있다.

- 배지 페이지(`jam-web/src/app/(main)/badges/page.tsx:104-133`)는 서버 컴포넌트에서
  아이템북별 최초 등록 아이템배지의 `rarity`(`created_at ASC` 기준)를 계산해
  `itemBookProgress.rarity`로 `BadgesClient`에 넘기고, `BadgesClient.tsx:281-291`이
  `<CollectionGridCard rarity={progress.rarity} .../>`로 전달한다.
- 프로필 컬렉션 목록의 데이터 소스인 `jam-web/src/app/api/users/[username]/itembooks/route.ts`는
  이 rarity 계산 로직 자체가 없어 응답 객체(`BookRaw`/최종 매핑, 78-88행)에 `rarity` 필드가
  아예 없다. `ProfileClient.tsx`의 `ItemBookItem` 타입(56-63행)에도 `rarity` 필드가 없고,
  `ProfileClient.tsx:329-338`의 `<CollectionGridCard>` 호출부도 `rarity` prop을 넘기지 않는다.

즉 프론트엔드 prop 누락이 아니라 백엔드 API가 애초에 rarity를 계산·반환하지 않는 것이
근본 원인이다. 컴포넌트가 동일하므로 rarity만 전달되면 태그 크기·스타일은 두 화면에서
자동으로 동일해진다(사용자가 요청한 "태그 크기 동일" 조건은 별도 조치 없이 충족됨).

## 상세 요구사항

### 서비스/코드베이스 관점
1. `jam-web/src/app/api/users/[username]/itembooks/route.ts`에 `badges/page.tsx:104-133`와
   동일한 방식(아이템북에 속한 `type='item'` 배지를 `created_at ASC`로 조회해 처음 만나는
   배지의 rarity를 그 아이템북의 대표 rarity로 채택)으로 rarity 계산 로직을 추가하고,
   응답 객체에 `rarity` 필드를 포함한다.
2. `ProfileClient.tsx`의 `ItemBookItem` 타입에 `rarity: BadgeRarity` 필드를 추가한다.
3. `ProfileClient.tsx:329-338`의 `<CollectionGridCard>` 호출부에 `rarity={book.rarity}`를
   전달한다.

### UI/UX 관점
- 프로필 > 컬렉션 목록의 각 카드에 등급 태그가 배지 페이지와 동일한 위치(좌상단)·동일한
  크기로 노출돼야 한다. 완성 태그와의 배치(가로 나열)도 동일해야 한다.

## 구현 계획
1. `route.ts`에 rarity 계산 쿼리·매핑 추가 (badges/page.tsx의 기존 로직 참고, 중복 로직이지만
   서버 컴포넌트와 API 라우트라 공유 유틸 추출은 이번 범위 밖 — 필요시 후속 검토)
2. `ItemBookItem` 타입에 `rarity` 필드 추가
3. `ProfileClient.tsx` 호출부에 `rarity` prop 전달
4. staging에서 dev-login 후 프로필 > 컬렉션 목록에서 등급 태그가 배지 > 컬렉션 탭과
   동일하게 보이는지 확인 (여러 등급의 컬렉션으로 교차 확인)

### 참고 — 범위 밖 발견물
`jam-web/src/components/ui/CollectionGridCard 2.tsx`는 rarity prop이 없는 구버전 중복
파일로 어디서도 import되지 않는 죽은 코드다. 이번 티켓과 무관하니 별도 정리 티켓으로
분리한다.
