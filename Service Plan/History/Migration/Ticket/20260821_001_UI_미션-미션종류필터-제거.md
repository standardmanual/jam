# [UI] 미션 페이지 — 세 번째(미션 종류) 필터 드롭다운 제거

## 배경 / 문제 정의
사용자 요청: 미션 페이지의 세 번째 필터 드롭다운(거리·횟수·POI 방문 등 미션 종류로 필터링하는
"전체" 드롭다운)을 제거한다.

## 상세 요구사항
[MissionsListClient.tsx](../../../../jam-web/src/app/(main)/missions/MissionsListClient.tsx)의
정렬(오래된순/최신순/마감임박) + 활동종류(자전거 등) + **미션 종류(전체)** 3개 드롭다운 중
마지막 미션 종류 드롭다운을 제거한다. 정렬·활동종류 드롭다운 2개만 남긴다.

## 구현 계획
1. `typeFilter` state, 관련 필터링 로직, `<select>` 엘리먼트 제거
2. 더 이상 쓰이지 않게 되는 `MISSION_TYPES`/`MISSION_TYPE_LABELS` 상수와 `MissionType` import 제거
3. tsc/eslint/build 검증 후 소스코드 → 스테이징 → 프로덕션까지 반영
