# [UI] 배지 상세 공유 버튼 + 미리보기 바텀시트 (UI 셸)

## 배경 / 문제 정의

배지 공유 기능(획득한 액티비티/POI/아이템 배지를 투명 PNG로 만들어 OS 공유시트로 내보내는 기능)
기획이 확정됐다. 과거 드랍 공유 카드 기능(`ShareCardModal`, `/api/drops/{id}/share`)은
2026-08-17 메뉴 개편으로 삭제됐으나(티켓 `20260731_004`), 이는 이후 제대로 재개발하기 위한
임시 삭제였고 이번이 그 정식 구현이다.

이번 티켓은 그 기능의 **UI 진입점(아이콘 버튼 + 미리보기 바텀시트 뼈대)만** 범위로 한다.
투명 PNG 실제 생성 로직·스트라바 데이터 연동·OS 공유시트 연결은 후속 티켓에서 별도 처리한다
(정적/더미 미리보기로 대체).

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `IconButton`(MODULAR)의 `ICON_PATHS`에 `share` 키를 추가했다. Material Symbols `ios_share`
  원본은 `viewBox="0 -960 960 960"` 채워진(fill) path인데, 다른 아이콘은 전부 24×24 stroke
  기반이라 좌표계가 다르다 — 24×24 좌표계에 맞게 옮기고, 이 path에만
  `fill="currentColor" stroke="none"`을 지정해 부모 svg의 `fill="none" stroke="currentColor"`
  기본값을 덮어썼다.
  - **1차 구현 버그(게이트 리뷰 FAIL) → 수정**: 최초 `transform="translate(0, 960) scale(0.025)"`
    로 커밋했으나, SVG transform 리스트는 오른쪽 항목이 점에 먼저 적용되는 규칙 때문에 실제로는
    scale이 먼저 적용돼 좌표가 y[936,960] 범위로 튀어 24×24 viewBox를 완전히 벗어나 아이콘이
    렌더링되지 않았다. `transform="scale(0.025) translate(0, 960)"`로 순서를 바꿔 재수정했고,
    path 전체 정점을 파싱한 좌표 검증으로 x[4,20], y[1,22] 범위(0~24 안)에 들어옴을 확인했다.
- 배지 상세 페이지(activity/poi/item 3개 분기) 각각의 `<TopNav>` `rightSlot`에
  `<BadgeShareButton imageUrl={badgeRow.image_url} badgeName={badgeRow.name} />`를 전달했다.
- `BadgeShareButton`(서비스 신규, `badges/[id]/BadgeShareButton.tsx`)을 작성했다.
  `IconButton icon="share"` 클릭 시 `useState`로 `BottomSheet(detent="full")`를 열고, 내부에
  다크 톤으로 재조정한 체크보드 프레임(`repeating-conic-gradient`, 흰색 저투명도
  `rgba(255,255,255,0.06)`/`rgba(255,255,255,0.02)` 2톤) 안에 배지 원본 이미지를
  `object-fit: contain`으로 더미 미리보기로 표시한다. 실제 투명 PNG 생성 로직은 이번 범위 밖.
- i18n(`ko.ts`)에 `badges.shareButtonLabel`('공유'), `badges.sharePreviewTitle`
  ('공유 이미지 미리보기') 2개 키 추가.

### 주요 의사결정 / 핵심 메모
> 개발 과정에서 검토·결정된 사항, 선택하지 않은 대안과 그 이유.
- 더미 미리보기 이미지로 별도 placeholder 자산을 새로 만들지 않고, 이미 `page.tsx`에서 조회된
  `badgeRow.image_url`을 그대로 재사용했다. 실제 공유용 투명 PNG 생성 로직은 후속 티켓에서
  이 자리를 교체할 예정이라 이번엔 "배지 이미지가 미리보기 자리에 보인다" 수준의 더미로 충분하다고
  판단.
- 체크보드 톤은 `spike/background-generator/FilterPreview.tsx`(라이트 `#f3f4f6`/`#ffffff`)를
  그대로 가져오지 않고, 다크 서피스 위에서 은은하게 보이도록 흰색 저투명도 2톤
  (`rgba(255,255,255,0.06)`/`rgba(255,255,255,0.02)`)으로 새로 조정했다(티켓 지시대로 재사용 금지).
- (개선 리뷰 제안, 이번엔 미채택) fill 기반 아이콘 대비 `IconButton`을 stroke/fill 두 계열
  공식 지원하도록 리팩터링하는 안은 이번 범위 밖으로 남겨둠 — fill 기반 아이콘이 하나 더
  필요해지는 시점에 재검토.
