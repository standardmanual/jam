# [Admin] 컬렉션 관리 필터 — 네이티브 select 다크 팝업 버그 수정

## 배경 / 문제 정의
티켓 20260822_001에서 추가한 세계관 필터·이름 정렬 드롭다운이 네이티브 HTML `<select>`로
구현되어, 드롭다운 팝업이 브라우저/OS의 시스템 다크모드 설정을 그대로 따라가면서 어드민
라이트 테마와 어긋나는 다크 테마로 렌더링됨(사용자 스크린샷으로 확인, 2026-08-22).
어드민 UI는 shadcn/ui를 표준으로 쓰기로 과거에 정의돼 있었다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 대상 파일: [ItemBookList.tsx](jam-web/src/components/admin/itembooks/ItemBookList.tsx)
- 네이티브 `<select>` 2개(세계관 필터, 이름 정렬)를 `@/components/ui/select`
  (`Select`/`SelectTrigger`/`SelectContent`/`SelectItem`)로 교체
- 필터링/정렬 로직(`selectedFactionId`, `sortOrder` 상태 및 파생 배열 계산)은 변경하지 않음 —
  값 변경 핸들러만 네이티브 `onChange` → shadcn `onValueChange`로 전환

### UI/UX 관점 (해당 시)
- 라이트 테마로 일관되게 렌더링되어야 함 (시스템 다크모드 설정과 무관하게)

## 구현 계획
`select.tsx`가 이미 프로젝트에 세팅돼 있으므로 신규 컴포넌트 제작 없이 그대로 가져다 쓴다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
네이티브 `<select>` 2개(세계관 필터, 이름 정렬)를 `@/components/ui/select`의 `Select`/
`SelectTrigger`/`SelectValue`/`SelectContent`/`SelectItem`(Radix 기반 shadcn 컴포넌트)로 교체했다.
값 변경 핸들러를 `onChange={(e) => ...e.target.value}`에서 `onValueChange={setXxx}`로 전환했고,
필터링/정렬 로직과 상태(`selectedFactionId`, `sortOrder`, `filteredItemBooks` 파생 배열)는
그대로 유지했다. shadcn `SelectContent`는 라이트 컬러(`bg-white text-neutral-900`)가
하드코딩돼 있어 브라우저/OS의 시스템 다크모드 설정과 무관하게 항상 라이트 테마로 렌더링된다.
