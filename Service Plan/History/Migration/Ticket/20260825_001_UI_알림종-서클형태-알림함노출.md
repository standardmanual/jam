# [UI] 알림 종 서클 형태 통일 + 전 화면 노출 + 간격 균일화

## 배경 / 문제 정의

[20260824_021](20260824_021_UI_알림함-화면-TopNav-진입점.md)로 알림함을 배포한 뒤
staging에서 확인하며 나온 UI 피드백 2건이다.

1. **종 아이콘이 우측 프로필 아이콘과 형태가 다르다.** 아바타는 36px 서클 안에 담겨 있는데
   종은 서클 없이 24px 아이콘만 떠 있어 우측 슬롯의 시각적 리듬이 깨진다.
2. **알림함(`/notifications`) 자신에는 종이 없다.** 021이 세운 "back chevron이 없는 루트
   화면에만" 규칙 때문인데, 화면마다 우측 아이콘 구성이 달라지는 게 어색하다.

## 상세 요구사항

### 1. 종을 프로필 아바타와 같은 형태로

아바타(`TopNav.tsx`의 `avatarSlot`)가 이미 쓰는 패턴을 그대로 따른다.

| 층 | 크기 |
|---|---|
| 터치영역 (`<Link>`) | 44×44 (`w-11 h-11`) |
| 서클 | 36×36 (`w-9 h-9`), `--radius-pill`, `bg-surface-elevated` |
| 아이콘 | 16×16 (`w-4 h-4`) |

### 2. 버블 앵커 재조정

`.t-badge`의 기준 박스가 24px 아이콘 → 36px 서클로 바뀐다. 원형이라 바운딩 박스의 우상단
모서리는 이미 원 바깥이므로 `-6/-8` 같은 큰 오프셋이 불필요하다. `-2/-2`로 당겨 아바타 배지처럼
테두리에 걸치게 한다. 서클에 배경색이 있어 종 글리프와 겹칠 일도 없다.

**`transitions.css`의 원본 스니펫 영역은 건드리지 않는다** — 확장 섹션의 `.jam-bell-dot`만 수정.

### 3. 노출 규칙 — 조건 제거 (2026-08-25 최종)

```
1차: 루트 화면(logo || !showBack)에만
2차: 루트 화면 + 알림함(/notifications)
최종: TopNav가 렌더되는 모든 화면
```

**서비스 래퍼가 `centerSlot`(동기화)·`avatarSlot`(프로필)을 조건 없이 항상 렌더**한다는 점이
결정적이었다(미연동 유저도 연결 버튼을 본다). 종만 화면마다 나타났다 사라지면 우측 구성이
들쭉날쭉해지므로 셋을 한 세트로 묶는다.

결과적으로 판정 로직이 **사라졌다** — `isRootScreen`·`isNotificationsScreen`과 `usePathname`
의존이 모두 제거됐다. 호출부가 `rightSlot`을 쓰는 화면(배지 상세 공유 버튼)은
`[공유버튼][종][아바타]`가 되고, TopNav 자체를 렌더링하지 않는 `/drops`는 자연히 제외된다.

### 3. 우측 슬롯 간격 균일화 (2026-08-25 추가)

staging 확인 결과 종 좌우 간격이 어긋나 보였다. DS TopNav 구조를 실측하니 원인이 명확했다.

```
헤더 바깥      : gap 8   ([좌측][centerSlot][우측영역])
우측 영역 안쪽 : gap 8   ([rightSlot][avatarSlot])
44px 터치박스 안의 36px 서클 → 양옆 4px 여백
```

| 구간 | 계산 | 실측 |
|---|---|---|
| 동기화 → 종 | 8(바깥 gap) + 4(종 좌 여백) | **12px** |
| 종 → 프로필 | 4(종 우 여백) + 8(안쪽 gap) + 4(아바타 좌 여백) | **16px** |

종에 `-mr-1`(-4px)을 주어 안쪽 gap을 상쇄, 양쪽 모두 12px로 맞췄다.
**DS를 고치지 않았다** — `gap: 8`은 배지 상세의 공유 버튼 등 다른 호출부에도 적용되므로
서비스 쪽에서 해결하는 편이 영향 범위가 작다.

### 4. 한글 줄바꿈 수정 (2026-08-25 추가)

staging 실데이터 확인에서 **"'각성 상태의 동 / 공'을"** 처럼 단어 중간이 끊겼다.

021의 A-4(오버플로 방지)로 넣은 `[overflow-wrap:anywhere]`가 원인이다. 공백 없는 긴 닉네임이
카드 밖으로 나가는 걸 막으려던 건데, 일반 한글 문장까지 아무 데서나 끊었다.

근본 원인은 CSS 기본값이다 — **한글은 `word-break: normal`에서도 음절 단위로 자유롭게 끊긴다.**
어절 단위로 끊으려면 `keep-all`을 명시해야 한다.

```
변경 전: break-words [overflow-wrap:anywhere]
변경 후: [word-break:keep-all] break-words
```

두 속성이 각각 다른 일을 한다.

| 속성 | 역할 |
|---|---|
| `word-break: keep-all` | 한글을 어절 단위로만 끊는다 (`BadgeRevealCarousel`의 기존 선례) |
| `break-words` (`overflow-wrap: break-word`) | 한 덩어리가 카드보다 길 때만 끊는다 — 긴 닉네임 대비 최후 수단 |

`anywhere`는 A-4의 목적에 과했다. `break-word`로 충분하고, 오버플로 방지 효과는 그대로다.
