# [Service] 미션 마일스톤 알림에 부동소수점 진행 수치가 그대로 노출

## 배경 / 문제 정의
미션 50%/80% 마일스톤 알림 문구가 `'전체 활동 누적 300km, 절반을 넘었어요 (202.24999999999997/300km)'`처럼
소수점 오차가 그대로 노출된 진행 수치를 괄호로 붙이고 있었다. UX Writing 가이드상 불필요한 정보이며
부동소수점 연산 오차까지 그대로 사용자에게 보였다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `msgMissionMilestone50`/`msgMissionMilestone80` 템플릿에서 `({progress})` 부분 제거

## 구현 계획
`jam-web/src/lib/i18n/ko.ts`의 두 템플릿 문자열에서 `({progress})`를 삭제하고,
`jam-web/src/lib/notifications/message.ts`의 `mission_milestone` 분기에서 더 이상 쓰이지 않는
`progress` 변수 생성 코드와 `slotProgress` 템플릿을 함께 제거. 경미한 문구 수정이라 파이프라인
없이 오케스트레이터가 직접 처리.
