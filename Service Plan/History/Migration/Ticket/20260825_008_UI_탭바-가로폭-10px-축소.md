# [UI] 하단 탭바 가로 폭 10px 축소

## 배경 / 문제 정의
하단 플로팅 탭바(캡슐)의 최대 폭을 10px 줄여달라는 요청.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/components/ui/TabBar.tsx`의 `max-w-[398px]` → `max-w-[388px]`
- `TabBar`는 MODULAR-서비스 병존 구현 컴포넌트(`/jam-work` 문서 기준)라
  `jam-web/design-system/components/navigation/TabBar.jsx`의 `maxWidth: 398` → `388`도 함께 수정

## 구현 계획
경미 수정(2파일, 값 하나씩 교체, 로직 변경 없음) — 파이프라인 없이 오케스트레이터가 직접 처리.
Storybook에서 DS TabBar 스토리를 렌더링해 실제 폭이 388px로 반영되는지 실측 확인.
