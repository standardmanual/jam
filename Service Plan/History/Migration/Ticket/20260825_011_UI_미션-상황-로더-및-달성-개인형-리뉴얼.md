# [UI] 미션 진행 상황 — 로딩 텍스트를 눈모양 로더로, 달성형·개인형도 랭킹형과 동일하게 리뉴얼

## 배경 / 문제 정의
[20260825_010](./20260825_010_UI_미션-진행상황-랭킹-화면-디자인-리뉴얼.md)에서 랭킹형(그래프가 있는
타입)만 리뉴얼했다. 후속 요청 두 가지:
1. 로딩 상태가 "불러오는 중..." 텍스트였는데, 다른 화면(배지 획득 연출·배지 공유 카드 등)이 쓰는
   `WanderingEyesLoader`(눈모양 로더)로 통일
2. 그래프(포디엄·프로그레스바)가 없는 나머지 타입(달성형·개인형)도 랭킹형과 같은 방식으로 리뉴얼

## 상세 요구사항

### 서비스/코드베이스 관점
- 로딩: `<p>{d.missions.statusLoading}</p>` 텍스트 → `WanderingEyesLoader`(`@ds/components/feedback/WanderingEyesLoader`, `NavigationLoader`/`BadgeRevealOverlay`/`BadgeShareButton`과 동일 컴포넌트)로 교체
- 달성형: 전체를 `bg-surface-elevated rounded-[var(--radius-cards)] p-6` InfoCard로 감싸고, 섹션
  라벨("달성 현황") 옆에 참가자 수를 병기(랭킹형 "전체 순위" 섹션과 동일 구조). 개별 참가자 행
  (`AchievementRow`, `Card tone="inverse"`)은 기존 그대로 — 이미 앱 전역에서 널리 쓰이는 카드
  어휘(투데이·홈·컴바인·프로필 등)라 변경 불필요
- 개인형: 동일하게 InfoCard로 감싸고 섹션 라벨("나의 현황")을 15px bold로 통일. 달성 칩은
  `MissionDetailClient`의 달성형 진행상황 칩과 동일한 클래스(`bg-white/10` / `bg-border`)로 교체
- 미사용 정리: `d.missions.statusLoading` i18n 키 제거 (교체로 인해 미사용)

## 구현 계획
경미 수정 범위를 넘는 실질적 UI 변경이지만 20260825_010과 같은 연장선상 작업이라 별도 파이프라인
없이 직접 구현. 로컬 dev 서버 + `dev-login`으로 실제 달성형·개인형 미션 데이터 브라우저 확인.
