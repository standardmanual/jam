# [UI] 미션 상황 화면 진입 시 로더가 두 번(다른 위치에) 보이는 문제

## 배경 / 문제 정의
[20260825_011](./20260825_011_UI_미션-상황-로더-및-달성-개인형-리뉴얼.md)에서 "불러오는 중" 텍스트를
`WanderingEyesLoader`로 바꿨는데, 사용자가 실기기에서 확인한 결과 미션 상황 화면 진입 시 로더가
두 곳에서 순차적으로 보였다:
1. 라우트 전환 중 `NavigationLoader`(전역, 화면 정중앙, 전체화면 오버레이) — 정상 동작
2. 화면 도착 후 `/api/missions/[id]/status` 응답을 기다리는 동안 뜨는 로더 — TopNav 바로 아래
   (`py-[var(--spacing-32)]`만 준 상태)라 화면 중앙이 아니라 위쪽에 걸쳐 보임

두 로더의 위치가 달라 마치 로더가 "이중으로, 다른 자리에" 뜨는 것처럼 어색해 보였다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/(main)/missions/[id]/status/MissionStatusClient.tsx`의 로딩 컨테이너를
  `min-h-[calc(100dvh-56px)] flex items-center justify-center`로 변경 — TopNav(56px)를 제외한
  나머지 영역 정중앙에 오도록 해서 라우트 전환 로더와 위치가 자연스럽게 이어지도록 함

## 구현 계획
경미 수정(1파일, className 값 교체) — `window.fetch`를 임시로 패치해 API 응답을 인위적으로
지연시킨 뒤 로딩 상태를 스크린샷으로 실측 확인.
