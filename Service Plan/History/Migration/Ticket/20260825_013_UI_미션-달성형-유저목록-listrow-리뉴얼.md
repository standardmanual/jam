# [UI] 미션 상황 — 달성형 유저 목록을 랭킹형과 동일한 ListRow 스타일로 리뉴얼

## 배경 / 문제 정의
[20260825_011](./20260825_011_UI_미션-상황-로더-및-달성-개인형-리뉴얼.md)에서 달성형 섹션을
InfoCard로 감쌌지만, 참가자 개별 행은 여전히 흰 `Card tone="inverse"` 카드였다. 사용자가 랭킹형의
새 유저 목록(다크 톤, 내 행만 레드 강조)과 나란히 비교한 뒤, 달성형 목록도 같은 방식으로 —
`ListRowCard`를 쓰되 색상만 바꿔서 — 통일해달라고 요청.

## 상세 요구사항

### 서비스/코드베이스 관점
- `AchievementRow`: `Card tone="inverse"`(흰 카드) → `ListRowCard`(`bg-surface-elevated`, 다크)로 교체
  - icon: `SimpleAvatar`를 랭킹형 `RankingListRow` 아바타와 동일한 톤(`var(--color-border)` bg,
    `#666` 아이콘, 36px)으로 재색상화
  - title: 내 행(`highlight`)만 `var(--color-primary)` bold, 그 외는 `var(--color-text)` 기본
  - trailing: 달성 칩 `bg-white/10 text-text`, 미달성 칩 `bg-border text-text-secondary`로
    다크 배경에 맞게 재색상화 (기존 `bg-black/[0.06]` 등 흰 카드 전제 색상 제거)

## 구현 계획
경미~중간 수정(1파일, 컴포넌트 교체 + 색상 토큰화). 실제 달성형 미션(참가자 5명) 데이터로
브라우저 확인.
