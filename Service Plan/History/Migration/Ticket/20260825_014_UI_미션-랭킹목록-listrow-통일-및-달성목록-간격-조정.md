# [UI] 랭킹형 유저 목록도 ListRowCard로 통일 + 달성형 목록 행간 좁힘

## 배경 / 문제 정의
[20260825_013](./20260825_013_UI_미션-달성형-유저목록-listrow-리뉴얼.md)에서 달성형(`AchievementRow`)
목록만 `ListRowCard`로 전환했는데, 정작 원래 참고 대상이던 랭킹형(`RankingListRow`, 그래프가 있는
목록)은 여전히 커스텀 인라인 마크업이라 같은 상세 화면 안에서 구현 방식이 갈라져 있었다. 사용자가
"그래프가 있는 페이지의 유저 리스트도 다시 점검해서 반영해줘"라고 요청 — 랭킹형도 동일하게
`ListRowCard` 기반으로 통일.

추가로, 프로그래스바가 없는 목록(달성형)은 한 줄짜리 행인데 `ListRowCard` 기본 패딩(위아래 16px,
행간 32px)이 헐렁해 보인다는 피드백을 받아 행간을 좁혔다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `RankingListRow`: 커스텀 `<div>` 마크업 → `ListRowCard`로 전환
  - `icon`: 순위 번호 + 아바타를 함께 묶어 전달
  - `children`: 유저명 + `ProgressBar`를 세로로 배치(그래프가 있는 목록이라 2줄 콘텐츠에
    기본 패딩이 자연스러움 — 별도 패딩 조정 없음)
  - `trailing`: 진행값
- `AchievementRow`: `ListRowCard`에 `className="!py-[var(--spacing-8)]"`를 추가해 위아래 패딩을
  16px → 8px로 좁힘(행간 32px → 16px). `!important`가 필요한 이유: `ListRowCard`의 기본
  패딩과 동일한 유틸리티 클래스라 소스 순서만으로는 덮어써지지 않음

## 구현 계획
경미 수정(1파일). 랭킹형(참가자 6명)·달성형(참가자 5명) 실제 미션 데이터로 브라우저 재확인.
