# [Admin] 미션 보상 배지 선택 목록에 소프트 삭제 필터 누락

## 배경 / 문제 정의
> 티켓 20260825_016(미션 보상 지급 시 소프트 삭제 배지 스킵) 개선 리뷰에서 "범위 밖 발견물"로
> 확인된 이슈. 지급 시점(`jam-web/src/lib/missions/rewards.ts`)은 이미 `deleted_at IS NULL`
> 필터로 걸러지므로 실제 오지급은 없지만, 어드민이 미션을 만들거나 수정할 때 보는 보상 배지
> 선택 목록에는 이미 소프트 삭제된 배지도 여전히 후보로 표시된다. 어드민이 삭제된 배지를 보상으로
> 선택해도 실제 지급은 되지 않으므로, "선택했는데 지급이 안 된다"는 혼란을 겪을 수 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/admin/missions/page.tsx:30-34` — 보상 배지 후보 목록을 조회하는
  `badges` 쿼리에 `.is('deleted_at', null)` 필터 추가
- `jam-web/src/app/admin/missions/MissionList.tsx` — 위 목록을 그대로 props로 받아 쓰므로
  별도 필터링 로직이 없는지 확인만 하고, 있다면 정합성 유지

## 구현 계획
1. `admin/missions/page.tsx`의 배지 조회 쿼리에 `.is('deleted_at', null)` 필터 추가
2. `MissionList.tsx`가 이 목록을 그대로 사용하는지 확인 (별도 조치 불필요 시 기록만)
3. 타입체크로 회귀 여부 확인
