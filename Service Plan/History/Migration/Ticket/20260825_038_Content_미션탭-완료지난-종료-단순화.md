# [Content] 미션 탭 이름 "완료/지난" → "종료" 단순화

## 배경 / 문제 정의
미션 탭 3개 중 세 번째 탭 라벨이 `완료/지난`으로 두 단어가 슬래시로 병기되어 있다.
사용자 요청에 따라 `종료`로 단순화한다. (탭이 가리키는 대상 — 참여 후 종료된 미션 +
완료한 미션 — 자체는 변경 없음, 라벨 문구만 수정)

## 상세 요구사항

### 컨텐츠 관점
- `jam-web/src/lib/i18n/ko.ts`의 `missions.tabEnded` 값을 `'완료/지난'` → `'종료'`로 변경
- 같은 파일의 `joinErrorCompleted` 에러 메시지가 탭 이름을 텍스트로 인용하고 있어
  (`"완료/지난 탭에서 다시 볼 수 있어요"`) 탭 이름과 불일치하지 않도록 함께 수정

## 구현 계획
`ko.ts` 두 줄만 수정하는 경미 수정. 로직 변경 없음 (탭 필터링 로직은 그대로 유지).
