# [UI] 바텀시트 'X' 닫기 버튼 전체 제거

## 배경 / 문제 정의
> 왜 이 작업이 필요한가. 현재 상태와 기대 상태의 차이.

바텀시트(BottomSheet) 헤더의 'X' 닫기 버튼을 서비스 전체에서 제거한다. 사용자 지시에 따라
사용성(닫을 수단이 줄어드는 문제)은 이번 작업 범위에서 고려하지 않는다 — 드래그-투-클로즈,
백드롭 탭 닫기 등 다른 닫기 수단이 이미 있다는 전제.

X 버튼만 있던 헤더 행은 제거 후 빈 행으로 남기지 않고 행 자체를 제거한다. 단, 같은 행에
제목 텍스트 등 다른 콘텐츠가 함께 있었다면 그 콘텐츠는 유지하고 X 버튼만 제거한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `src/components/ui/BottomSheet.tsx` 및 이를 사용하는 모든 화면에서 X 닫기 버튼(lucide-react
  `X` 아이콘 등)을 렌더링하는 코드를 찾아 제거한다
- X 버튼 제거로 헤더 행이 완전히 비면 그 행(wrapper div 등)도 함께 제거한다
- 드래그-투-클로즈, 백드롭 클릭 닫기 등 기존 닫기 로직·핸들러(`onClose` 등)는 X 버튼과 무관하게
  유지한다 (다른 트리거에서 계속 사용될 수 있음)
- design-system(`design-system/components/navigation/BottomSheet.jsx`) 쪽 병존 구현도 대상인지
  확인 — 서비스에 실제 반영되는지 여부에 따라 처리 범위 결정

### UI/UX 관점 (해당 시)
- 사용성 저하는 사용자가 명시적으로 고려 대상에서 제외함

## 구현 계획
> 어떻게 구현할지. 접근 방법, 영향 범위, 주요 변경 포인트.

### 조사 결과 (오케스트레이터, Explore 서브에이전트)

실제 서비스 바텀시트의 X 버튼은 `src/components/ui/BottomSheet.tsx:296` 한 곳에만 정의되어
있고, `showCloseButton`/`closeLabel` prop을 통해 5개 사용처가 공유한다.
`hasHeader = Boolean(title) || showCloseButton` (line 230)이라 title 없이 X만 켠 사용처는
X 제거 시 헤더 행이 완전히 빈다.

design-system 쪽 `design-system/components/navigation/BottomSheet.jsx`는 애초에 X 버튼이
없고(Storybook 전용, 서비스 미사용) 이번 범위에서 제외한다. `sheet.tsx`(어드민 사이드 드로어
전용, 바텀시트 아님)·`dialog.tsx`(완전 미사용)의 X도 무관.

### 재사용 판정 (오케스트레이터)
신규 UI 도입이 아닌 기존 컴포넌트 기능 축소 — MODULAR 재사용/확장 판정 대상 아님.
`BottomSheet.tsx`의 `showCloseButton`/`closeLabel` prop과 그 렌더링 로직 자체를 제거한다.

### 사용처별 처리 방침

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `BottomSheet.tsx`에서 `showCloseButton`/`closeLabel` prop과 X 버튼(`IconButton icon="close"`)
  렌더링 블록을 제거. 더 이상 쓰지 않는 `IconButton` import도 정리.
- 헤더 표시 조건 `hasHeader`를 `Boolean(title) || showCloseButton`에서 `Boolean(title)`로 변경 —
  title 없이 X만 있던 헤더 행(`ItemEarnHistory.tsx`, `PoiEarnHistory.tsx`)은 자동으로 사라짐.
  title이 항상 존재하는 조건이 되어, 헤더 안 `title ? <h2>...</h2> : <span/>` 삼항식의
  `<span/>` 분기가 죽은 코드가 되므로 `<h2>{title}</h2>` 단일 렌더로 정리(요청 범위 내 자연스러운
  정리 — 별도 기능 변경 아님).
- `InventoryItemHistorySheet.tsx`: `closeLabel={d.common.close}` 호출부 제거, `title`은 유지.
- `BadgeShareButton.tsx`, `BadgeDetailSheet.tsx`: `showCloseButton={false}` 호출부 제거(prop
  자체가 삭제되어 무의미해진 전달).
- `onClose`(드래그-투-클로즈, 백드롭 클릭)는 그대로 유지 — 변경 없음.
- `BadgeRevealOverlay.tsx`/`src/app/spike/badge-reveal/BadgeRevealSpikeClient.tsx`의
  `closeLabel` prop은 `BottomSheet`가 아니라 별도 컴포넌트 `BadgeRevealCarousel`(MODULAR
  patterns)의 prop이라 티켓 범위 밖 — 손대지 않음(오케스트레이터 조사 결과와 일치, 재확인 완료).

### 주요 의사결정 / 핵심 메모
- 티켓 방침대로 `showCloseButton`/`closeLabel` prop을 완전히 삭제하는 방식을 택함(예: prop만
  무시하고 항상 false로 두는 방식은 죽은 코드/타입만 남기므로 채택하지 않음).
- 헤더 안 `title ? <h2> : <span/>` 삼항식은 `hasHeader = Boolean(title)`로 바뀌며 `<span/>`
  분기가 도달 불가능해져 `<h2>{title}</h2>` 단일 렌더로 정리 — 이 자체는 티켓이 명시한 변경은
  아니지만, 우리 변경이 만든 죽은 코드를 같은 파일 내에서 정리한 것이라 범위 확장으로 보지 않음.
- `BadgeRevealOverlay.tsx`/spike 페이지의 `closeLabel`은 `BadgeRevealCarousel`(다른 컴포넌트)
  prop이라 오케스트레이터 조사 결과대로 범위 밖 처리, 재확인 완료.
