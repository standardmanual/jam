# [Admin] shadcn 디자인시스템 전환 — 1단계: 기반

## 배경 / 문제 정의

전체 배경·원칙·프리셋 값은 `Service Plan/Specs/PRD/AdminUI/REDESIGN.md`(2026-08-26 전면
개정판) 참조 — **이 티켓을 시작하기 전에 반드시 먼저 읽을 것.** 실행 순서·완료 기준은
`Service Plan/Specs/PRD/AdminUI/PHASES.md`의 "Phase 1 — 기반" 절과 동일하다(이 티켓은
그 절의 실행 단위).

**핵심 배경 요약**: 2026-08-05에 어드민을 shadcn/ui로 리디자인하기로 했었으나, `components.json`
설정만 하고 실제 테마 변수(`globals.css`의 `--primary` 등)를 채우지 않아 이후 개발자들이
하드코딩 hex 색상으로 새어나갔다. 이번엔 shadcn 공식 프리셋 CLI로 테마를 실제로 채우고,
shadcn 전용 폴더를 처음부터 MODULAR와 분리해 같은 실패를 구조적으로 막는다.

**두 디자인시스템 완전 분리**: JAM! 서비스 본체=MODULAR(그대로 유지, 이 티켓과 무관) /
JAM! 어드민=shadcn(이 티켓 대상) / 어드민 내 서비스 미리보기 프레임=MODULAR 예외 유지
(이미 올바름, 손대지 않음). 자세한 내용은 REDESIGN.md 1절.

## 상세 요구사항

### 1. shadcn 전용 폴더 분리

`src/components/ui/`는 지금 MODULAR 래퍼(`Button.tsx`, `TopNav.tsx`, `Footer.tsx`,
`TabBar.tsx`, `Toast.tsx`, `SlidingTabs.tsx`, `BadgeGridCard.tsx`, `CollectionGridCard.tsx`,
`ListRowCard.tsx`, `LoadingSpinner.tsx`, `NotificationBell.tsx`, `PopInNumber.tsx`,
`SwapText.tsx`, `icons.tsx`, `dotm-hex-8.tsx`, `dotm-square-3.tsx`, `wandering-eyes.css`)와
shadcn 프리미티브(`accordion.tsx`, `alert-dialog.tsx`, `alert.tsx`, `checkbox.tsx`,
`dialog.tsx`, `input.tsx`, `select.tsx`, `sheet.tsx`, `switch.tsx`, `table.tsx`, `tabs.tsx`,
`textarea.tsx`, `shadcn-badge.tsx`, `shadcn-button.tsx`, `shadcn-card.tsx`)가 한 폴더에
섞여 있다. `shadcn-*` 접두어는 이름 충돌(진짜 `Button.tsx`/`Card.tsx`가 MODULAR 걸로 이미
있어서) 회피 흔적이다.

- shadcn 프리미티브 전용 폴더 신설(예: `src/components/admin/ui/` — 정확한 경로는 재량,
  MODULAR와 절대 겹치지 않는 이름으로).
- `components.json`의 `aliases.ui`를 새 경로로 변경.
- 기존 shadcn 프리미티브 12개 파일 이전 + 어드민 전역 import 경로 갱신.
- `shadcn-button.tsx`/`shadcn-badge.tsx`/`shadcn-card.tsx`는 새 폴더로 옮기며 접두어 없는
  정식 이름(`button.tsx`/`badge.tsx`/`card.tsx`)으로 복원 가능(새 폴더에선 충돌 없음).
- MODULAR 래퍼 파일들은 `src/components/ui/`에 그대로 둔다 — 이번 티켓 대상 아님.

### 2. 프리셋 테마 적용 (공식 shadcn CLI 사용, 하드코딩 절대 금지)

```bash
npx shadcn@latest apply b5Jgcv00m --only theme,font
```

- 프리셋: `style: maia`, `baseColor: stone`, `theme: stone`, `chartColor: sky`,
  `radius: medium` (`npx shadcn@latest preset decode b5Jgcv00m`로 재확인 가능)
- 위 1번에서 `tailwind.css` 경로를 이전했다면, CLI가 그 새 경로에 쓰도록
  `components.json` 갱신이 먼저 돼 있어야 한다.
- **실측 확인(2026-08-26)**: `globals.css`에 shadcn 표준 변수가 지금 전혀 없어서, 서비스
  본체(MODULAR, 완전히 다른 변수 이름 체계)와 충돌 위험이 없다. 별도 CSS 파일 분리는
  불필요 — 단일 `tailwindCssFile`에 직접 적용하는 공식 방식을 따른다.
- 적용 후 어드민 화면에서 `bg-primary`/`text-foreground` 등 시맨틱 클래스가 실제로
  이 프리셋 색상으로 렌더링되는지 반드시 눈으로 확인할 것(2026-08-05 실패의 재발 방지 —
  "설정은 됐지만 실제로 안 먹힘" 상태를 남기지 않는다).

### 3. 폰트 — Pretendard로 교체

- `src/app/admin/layout.tsx`가 지금 `next/font/google`로 Inter를 로드 중
  (`--font-admin-inter` 변수, 주석: "Cal Sans는 공개 웹폰트가 아니라...Inter 600 대체").
  이 로드를 제거한다.
- Pretendard는 `globals.css` 최상단에 이미 CDN import(`@import url('https://cdn.jsdelivr.net/
  gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.css')`)로 전역 로드돼 있다
  (서비스 본체·어드민 공용). 추가 설치 없이 `font-family: 'Pretendard', ...` 참조만 어드민
  레이아웃에 반영하면 된다.
- shadcn `apply --only font`가 프리셋 기본값(`inter`)을 CSS 변수로 써넣을 수 있는데, 그
  변수 값을 Pretendard로 덮어쓸 것(프리셋 폰트 값보다 이 요구사항이 우선).

### 4. 아이콘 — lucide → tabler

- `@tabler/icons-react` 설치.
- `components.json`의 `iconLibrary: "tabler"`로 갱신.
- lucide-react 사용처는 어드민 전용 3개 파일뿐(실측 확인, 프로젝트 전체에서 `src` 내
  lucide-react import 3건 = 전부 admin):
  - `src/components/admin/AdminSidebar.tsx` — `ChevronLeft`, `ChevronRight` →
    `IconChevronLeft`, `IconChevronRight`
  - `src/components/admin/AdminHeader.tsx` — `Menu` → `IconMenu2`
  - `src/components/admin/poi/MapPreview.tsx` — `ExternalLink` → `IconExternalLink`
- lucide-react 자체를 `package.json`에서 제거할지는 재량(다른 곳에서 안 쓰는 게 확인되면
  제거해도 무방, 남겨둬도 무해).

- `BadgeDetailPreviewFrame.tsx`, `ItemBookDetailPreviewFrame.tsx`와 그 내부에서 쓰는
  `components/ui/TopNav.tsx`, `Footer.tsx` 등 MODULAR 래퍼 — 이번 티켓과 무관, 손대지 않음
