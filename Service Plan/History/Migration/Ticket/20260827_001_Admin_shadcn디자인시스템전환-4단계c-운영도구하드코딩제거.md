# [Admin] shadcn 디자인시스템 전환 — 4단계c: 운영 도구 하드코딩 제거

## 배경 / 문제 정의

4단계a(`20260826_017`, CLOSED)·4단계b(`20260826_018`, CLOSED)에서 선행 인프라(스코프
오버라이드, Portal container)와 배지·POI·아이템북·세계관 도메인 전환을 마쳤다. 이
티켓(4단계c)은 그 기반 위에서 운영 도구 화면들의 하드코딩을 제거한다.

시작 전 `Service Plan/Specs/PRD/AdminUI/PHASES.md`의 "Phase 4" 절과 `20260826_017` 티켓의
"구현 기록"(색상 매핑 규칙)을 반드시 먼저 읽고, `20260826_018`이 4b에서 확장한 매핑
패턴(`hover:bg-primary/90`, `bg-muted hover:bg-accent`, `hover:border-foreground/30` 등)도
참고해 동일한 규칙을 따를 것.

## 상세 요구사항

`text-[#...]`/`border-[#...]`/`bg-[#...]` 형태의 하드코딩 hex 클래스를 4단계a/b와 동일한
규칙으로 shadcn 시맨틱 토큰에 매핑한다. 각 다이얼로그/셀렉트가 있다면 4단계a가 추가한
`container` prop을 실제로 연결할 것.

**주의**: `AbusingClient.tsx`는 어뷰징(GPS 조작 감지 등) 상태를 색으로 구분하는 UI가
있을 수 있다(예: 위험도별 빨강/노랑 배지) — 이런 **의미 있는 상태 색상**(경고·위험 등)은
`text-foreground`/`bg-muted` 같은 중립 토큰으로 뭉개지 말고, shadcn의 `destructive` 계열
토큰이나 기존 Tailwind 팔레트(`red-*`, `amber-*` 등, 이미 3단계 Data Table 작업에서
BanTable 등이 쓴 관례가 있으면 그걸 참고)를 유지할 것 — 정보 손실 없이 시맨틱하게만
정리한다.

## 구현 기록 (2026-08-27, 리뷰 대기)

대상 8개 파일(`simulator/page.tsx`·`AbusingClient.tsx`·`AmbientDropForm.tsx`·
`DropPolicyForm.tsx`·`CombinePolicyForm.tsx`·소형 페이지 3개, 실측 128건) 전량 전환 완료.

**매핑**: 4a(`20260826_017`)·4b(`20260826_018`)와 동일한 규칙을 순서 있는 리터럴
문자열 치환(파이썬 스크립트)으로 일괄 적용 — `border-[#e5e7eb]`→`border-border`,
`text-[#6b7280]`/`text-[#898989]`/`text-[#9ca3af]`→`text-muted-foreground`,
`text-[#374151]`/`text-[#111111]`→`text-foreground`, `bg-[#111111]`→`bg-primary`,
`border-[#111111]`→`border-primary`, `bg-[#242424]`(hover)→`bg-primary/90`,
`bg-[#f3f4f6]`/`bg-[#f8f9fa]`/`bg-[#f5f5f5]`→`bg-muted`,
`hover:bg-[#e5e7eb]`→`hover:bg-accent`, `hover:border-[#d1d5db]`→`hover:border-foreground/30`,
`placeholder-[#9ca3af]`→`placeholder:text-muted-foreground`,
`accent-[#111111]`→`accent-primary`. 부분 문자열 치환이라 `text-[#111111]/60` 같은
opacity 변형도 `text-foreground/60`으로 자동 처리됨.

**"선택됨" 상태 UI 판별**: 이번 범위의 모든 선택 상태 UI(유저 검색 결과 선택 항목, 선택된
유저 요약 카드, 시뮬레이션 결과 "적용됨" 배지, 어뷰징 탭 활성 상태·카운트 배지)는 비선택
상태와 짝을 이루는 토글형이라 4b `AdjacencyEditor` 판별 기준(텍스트가 opacity 없는 순수
hex → `text-foreground`)을 일관 적용했다. 4a `BadgeMultiSearchSelect` 특례(`text-primary`
통일)에 해당하는 "독립된 단일 색조 배지/칩" 패턴은 이번 5개 파일에 없었다.
