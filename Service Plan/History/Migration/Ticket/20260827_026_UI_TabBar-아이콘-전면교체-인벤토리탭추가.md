# [UI] TabBar 아이콘 전면 교체 + 인벤토리 탭 추가

## 배경 / 문제 정의
사용자가 `Asset/badge.svg`, `Asset/drop.svg`, `Asset/inventory.svg`, `Asset/mission.svg` 4개
아이콘 파일을 첨부하고 TabBar 아이콘 교체를 요청했다. 확인 결과:

- 현재 서비스 TabBar(`src/components/ui/TabBar.tsx`)는 today/badges/drops/missions 4탭만 있고
  인벤토리 탭이 없다. 반면 디자인시스템(`design-system/components/navigation/TabBar.jsx`)에는
  today/badges/drops/missions/inventory 5탭이 이미 정의돼 있다 — 병존 구현 간 탭 구성이 어긋나
  있던 상태.
- 사용자 확인 결과: **인벤토리 탭을 5번째(마지막) 탭으로 추가**하고, **활성 시 별도 제작한
  두꺼운(filled) 아이콘, 비활성 시 첨부된 outline 아이콘**을 사용하기로 함.
- today(투데이) 탭 아이콘은 이번 교체 대상이 아님(첨부 파일 없음, 기존 집 모양 아이콘 유지).

### 서비스/코드베이스 관점
- `src/components/ui/TabBar.tsx`의 `baseTabs` 배열:
  - `badges`/`drops`/`missions` 탭의 `iconFill`/`iconLine`을 위 스펙으로 교체.
    각 아이콘의 `<svg>`는 `viewBox="0 -960 960 960"`로 변경(기존 `viewBox="0 0 24 24"`에서
    변경 — Material Symbols 좌표계 사용). `className="w-6 h-6"`·`fill="currentColor"`는 유지.
  - 배열 마지막에 `inventory` 탭 신규 추가: `href: '/inventory'`, `label: d.nav.inventory`
    (이미 `src/lib/i18n/ko.ts`에 `nav.inventory: '인벤토리'` 존재, 라우트 `/inventory`도 이미 존재
    — 추가 작업 불필요, TabBar 배열에만 반영).
  - `today` 탭은 변경하지 않는다.
- **병존 구현 동기화**: `design-system/components/navigation/TabBar.jsx`도 동일한 아이콘으로
  갱신해 서비스와 스토리북 간 드리프트를 없앤다. 이 컴포넌트는 이미 5탭(today/badges/drops/
  missions/inventory) 구조라 탭 추가는 불필요, 아이콘 교체만 진행.
  - `icons.badges.fill/line`, `icons.drops.fill/line`, `icons.missions.fill/line`,
    `icons.inventory.fill/line`을 위 스펙으로 교체. DS는 `<svg viewBox="0 0 24 24" ...>`로
    감싼 뒤 내부에 `<path>`만 넣는 구조이므로, viewBox도 `0 -960 960 960`으로 바꿔야 한다
    (`TabBar.jsx` 91번째 줄 `<svg viewBox="0 0 24 24" ...>`).
  - `today` 아이콘은 DS에서도 변경하지 않는다.
  - Storybook Story(`TabBar.stories.tsx`)는 아이콘 자체를 렌더링 확인하는 용도이므로 별도
    수정 없이 기존 Story로 시각 확인 가능.

### UI/UX 관점 (해당 시)
- 인벤토리 탭 추가로 탭이 4개→5개가 되면서 각 탭의 `flex-1` 폭이 줄어든다. 터치 타겟
  최소 크기(44pt) 확보 여부를 육안으로 확인할 것.
- 활성/비활성 아이콘 실루엣이 형태 자체가 달라지므로(선 vs 채움), 탭 전환 시 아이콘이
  "다른 아이콘으로 바뀐 것처럼" 튀어 보이지 않는지 실제 화면에서 확인 필요.
