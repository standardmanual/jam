# [UI] 미션 목록 필터 — OS 네이티브 피커 → 인앱 드롭다운 교체

## 배경 / 문제 정의

현재 미션 목록 페이지(`/missions`)의 필터(카테고리, 상태, 정렬)가 HTML 네이티브 `<select>`를 사용하고 있다. 모바일에서 iOS/Android OS 기본 피커(드럼롤 picker, 하단 시트)가 뜨는 구조로, JAM!의 앱 일관성과 디자인 시스템에서 벗어난다.

**발견 경위:** 2026-08-15 Figma 와이어프레임 vs 스테이징 비교 분석 중 Casey 항목으로 식별.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/(main)/missions/MissionsListClient.tsx` 의 3개 `<select>` (카테고리·상태·정렬) 를 인앱 드롭다운/필터칩 컴포넌트로 교체
- 필터 상태는 URL searchParams 또는 로컬 state 유지 (현재 방식 계승)
- 선택 옵션 목록은 기존 값(`CATEGORY_OPTIONS`, `STATUS_OPTIONS`, `SORT_OPTIONS`)과 동일

### UI/UX 관점
- 인앱 드롭다운은 상단 필터바 형태 또는 모달/바텀시트로 구현 가능
- 디자인 리뉴얼 후 모듈러 DS v2 컴포넌트와 정합성이 필요하므로 리뉴얼 완료 후 구현
- Figma 와이어프레임에서 미션 목록 필터 UI 형태 확인 후 구현 방식 결정

## 구현 계획
> 디자인 리뉴얼 이후 진행. Figma 와이어프레임의 필터 UI 패턴이 결정되면 해당 컴포넌트를 DS에 등록 후 적용.
