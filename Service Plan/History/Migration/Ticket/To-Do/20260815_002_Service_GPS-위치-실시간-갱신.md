# [Service] 드랍 화면 GPS 위치 — 마운트 1회 → 실시간 갱신

## 배경 / 문제 정의

현재 `/drops` 페이지(`DropsClient.tsx`)는 컴포넌트 마운트 시 `navigator.geolocation.getCurrentPosition()`을 1회만 호출한다. 사용자가 이동하더라도 위치가 갱신되지 않아, 드랍 가능 배지 판정이 마운트 시점의 좌표를 기준으로 고정된다.

**발견 경위:** 2026-08-15 Figma vs 스테이징 분석 중 Casey 항목으로 식별.

## 상세 요구사항

### 서비스/코드베이스 관점
- `navigator.geolocation.watchPosition()` 으로 전환하여 이동 중 위치 갱신
- 컴포넌트 언마운트 시 `clearWatch()` 호출로 리소스 정리 필수
- 갱신 주기·오차 허용 범위(accuracy threshold)는 배터리·UX 트레이드오프 검토 필요
- 과도한 갱신으로 드랍 API가 반복 호출되지 않도록 debounce 또는 위치 변화 임계값(예: 20m) 적용

### UI/UX 관점
- 위치 갱신 중 상태 표시 여부 결정 필요 (현재는 "위치 파악 중" 초기 상태만 존재)
- 위치 갱신 실패(accuracy 불량, 타임아웃) 시 기존 좌표 유지 or 재시도 정책 결정
