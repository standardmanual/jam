# [UI] 미션 카드 썸네일 이미지 + DB 마이그레이션

## 배경 / 문제 정의

현재 미션 목록·상세 화면에 썸네일 이미지가 없다. Figma 와이어프레임에서는 미션마다 대표 이미지가 카드 상단에 표시된다. 현재 DB `missions` 테이블에 `image_url` 컬럼이 없어 구조적으로 불가능한 상태.

**발견 경위:** 2026-08-15 Figma vs 스테이징 분석 중 Jordan 항목으로 식별.

## 상세 요구사항

### 서비스/코드베이스 관점
- `missions` 테이블에 `image_url TEXT` 컬럼 추가 (DB 마이그레이션)
- 미션 썸네일 에셋 업로드 파이프라인 구축 (Supabase Storage 또는 외부 CDN)
- `MissionsListClient.tsx` 의 `MissionRow` 타입에 `image_url?: string` 추가
- 미션 목록·상세 컴포넌트에 썸네일 이미지 렌더링 추가
- 어드민 패널에서 미션별 이미지 업로드 기능 추가 필요

### UI/UX 관점
- 이미지 없는 미션의 fallback 처리 (플레이스홀더 또는 이모지/아이콘)
- 미션 목록 카드: 이미지 비율, 그리드 or 리스트 레이아웃 확정 (리뉴얼 시 결정)
- Next.js `<Image>` 컴포넌트 사용

### 컨텐츠 관점
- 기존 미션 데이터에 이미지 에셋 소급 필요 (미션별 대표 이미지 제작 또는 선정)

## 구현 계획
> 디자인 리뉴얼 시 DB 스키마에 반영하기로 확정 (2026-08-15 의사결정). 리뉴얼 단계에서 일괄 처리.
