# [UI] 믹스 화면 빈 슬롯 온보딩 안내 추가

## 배경 / 문제 정의

현재 `/combine` (믹스) 화면은 인벤토리 아이템을 10개 슬롯에 배치하는 UI이지만, 빈 슬롯에 아무런 안내가 없어 초초 사용자가 어떻게 사용하는지 파악하기 어렵다. 인벤토리에서 믹스로 진입하는 경로도 명시적이지 않다.

**발견 경위:** 2026-08-15 Figma vs 스테이징 분석 중 Jordan 항목으로 식별.

## 상세 요구사항

### UI/UX 관점
- 믹스 슬롯이 모두 비어있을 때(최초 진입) 온보딩 안내 표시
  - 예: "인벤토리에서 아이템을 선택하면 여기에 배치돼요" 또는 시각적 힌트
- 인벤토리 → 믹스 진입 플로우 명확화 (현재는 인벤토리 내 "믹스" 버튼으로만 진입)
- 빈 슬롯("+" 플레이스홀더)의 역할을 직관적으로 안내

### 컨텐츠 관점
- UX Writing 가이드라인 준수: 빈 상태 문구는 해요체, 간결하게
- 예시 문구 후보: "아이템을 골라 믹스해 보세요", "인벤토리에서 아이템을 추가해요"

## 구현 계획
> 디자인 리뉴얼 후 믹스 화면 UI 개선과 함께 진행.

### 구현 내용 요약

- `selected.length === 0` 조건으로 빈 슬롯 온보딩 안내 표시 (슬롯 그리드 아래, 믹스하기 버튼 위)

- 별도 CTA 버튼 없음 — 기존 "믹스하기" 버튼 경로 유지
