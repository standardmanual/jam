# [UI] "아이템북" eyebrow + "컬렉션" 제목 혼재 → "컬렉션"으로 통일

## 배경 / 문제 정의

현재 `/itembooks` 페이지에서 상단 eyebrow 텍스트는 "컬렉션"이지만 페이지 제목(H1)은 "아이템북"으로, 두 용어가 혼재한다. 2026-08-15 의사결정에서 "컬렉션"으로 통일하기로 확정했으나 디자인 리뉴얼 후 적용 예정.

**발견 경위:** 2026-08-15 Figma vs 스테이징 분석 중 Minor 항목으로 식별. 의사결정: "컬렉션으로 변경".
