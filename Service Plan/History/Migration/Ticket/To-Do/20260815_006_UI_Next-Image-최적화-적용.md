# [UI] 네이티브 `<img>` → Next.js `<Image>` 최적화 전환

## 배경 / 문제 정의

일부 화면에서 Next.js `<Image>` 대신 네이티브 `<img>` 태그를 사용 중이다. `<Image>` 컴포넌트는 자동 WebP 변환, lazy-loading, 사이즈 최적화를 제공하므로 전환 시 성능 개선 기대.

**발견 경위:** 2026-08-15 Figma vs 스테이징 분석 중 Minor 항목으로 식별.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/` 전체에서 `<img` 태그 사용처 grep 후 목록 확보
- 외부 도메인 이미지: `next.config.js`의 `images.domains`/`remotePatterns` 등록 필요
- 동적 크기 이미지: `fill` prop 또는 `width`/`height` 명시
- SVG·아이콘류는 교체 대상에서 제외 가능

### UI/UX 관점
- 전환 후 레이아웃 시프트(CLS) 없도록 `width`, `height` 또는 `fill` + 부모 컨테이너 `position: relative` 처리

## 구현 계획
> 디자인 리뉴얼 후 컴포넌트 개편 시 함께 적용. 리뉴얼 전 단독 적용은 이중 작업이 될 수 있어 보류.
