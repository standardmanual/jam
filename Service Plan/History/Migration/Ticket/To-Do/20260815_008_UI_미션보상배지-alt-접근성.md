# [UI] 미션 보상 배지 이미지 `alt=""` → 의미 있는 alt 텍스트 추가

## 배경 / 문제 정의

`/missions/[id]/MissionDetailClient.tsx` 191행의 보상 배지 이미지에 `alt=""`(빈 값)이 설정되어 있다. 스크린리더 사용자에게 이미지 내용이 전달되지 않는 접근성 문제.

**발견 경위:** 2026-08-15 Figma vs 스테이징 분석 중 Minor 항목으로 식별.

## 상세 요구사항

### 서비스/코드베이스 관점
- `MissionDetailClient.tsx` 191행: `alt=""` → `alt={`${배지명} 배지`}` 또는 `alt={badge.name}` 형태로 변경
- 배지 이미지가 순수 장식(decorative)이 아닌 콘텐츠 이미지이므로 의미 있는 alt 텍스트 필수
- 배지 데이터에 `name` 필드가 있으면 해당 값 사용

### UI/UX 관점
- 접근성 기준: WCAG 2.1 Level AA 준수 (모든 비장식 이미지에 alt 텍스트 필수)

## 구현 계획
> 즉시 적용 가능한 1줄 수정. 리뉴얼 전 단독 적용 고려 가능.
