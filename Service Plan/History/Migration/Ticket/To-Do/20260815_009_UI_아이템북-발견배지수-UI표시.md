# [UI] 아이템북 발견 배지 수(discoveredBadgeCount) UI 표시

## 배경 / 문제 정의

`/itembooks/page.tsx`에서 `discoveredBadgeCount`가 계산되지만 UI에 표시되지 않는다. 사용자가 전체 배지 중 몇 개를 발견했는지 진행률을 확인할 수 없다.

**발견 경위:** 2026-08-15 Figma vs 스테이징 분석 중 Minor 항목으로 식별.

## 상세 요구사항

### 서비스/코드베이스 관점
- `discoveredBadgeCount` 값을 컬렉션 페이지 상단 또는 각 아이템북 카드에 표시
- 표시 형태 예: `"12/30"`, `"12개 발견"`, 프로그레스바 등 (리뉴얼 시 Figma 기준으로 확정)
- 전체 배지 수(`totalBadgeCount`)도 함께 노출 필요한지 검토

### UI/UX 관점
- 진행률 정보는 수집 동기 부여에 효과적 — Figma 와이어프레임에서 표시 위치 확인 후 적용
- 숫자 표기: UX Writing 가이드라인의 수량 표기 규칙 준수

## 구현 계획
> 디자인 리뉴얼 후 컬렉션 페이지 UI 개편 시 함께 적용.
