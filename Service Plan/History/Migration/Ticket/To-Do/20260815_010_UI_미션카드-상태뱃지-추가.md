# [UI] 미션 카드 상태 뱃지 추가 (NEW / 참가중 / 상시 등)

## 배경 / 문제 정의

현재 미션 목록은 탭(진행중/참가중/종료)으로만 상태를 구분. Figma 와이어프레임에서는 카드마다 "NEW", "참가중", "상시" 뱃지가 직접 표시돼 탭 없이도 상태를 즉각 파악할 수 있다.

**발견 경위:** 2026-08-15 Design Review B-03 항목. 결정: Figma 방향 적용.  
**관련 티켓:** 20260815_003 (미션 썸네일 DB 마이그레이션) — 썸네일과 별도 독립 작업.

## 상세 요구사항

### 서비스/코드베이스 관점
- `MissionsListClient.tsx` 미션 카드 컴포넌트에 상태 뱃지 추가
- 뱃지 레이블 매핑 (현재 `status` 필드 값 기준):
  - `active` + 신규 미션(N일 이내 생성) → "NEW" (오렌지)
  - `active` + 참가한 미션 → "참가중" (회색/흰색)
  - `active` + 기한 없음(`end_date is null`) → "상시" (회색)
  - `ended` → 뱃지 없음 또는 "종료"
- "신규"의 기준일(예: 생성 후 7일) 정책 결정 필요

### UI/UX 관점
- 카드 좌상단 또는 썸네일 위 오버레이 위치 (리뉴얼 Figma 기준)
- 뱃지는 복수 조합 가능: "NEW" + "참가중" 동시 표시
- DS v2 토큰 기반 chip 컴포넌트 사용
