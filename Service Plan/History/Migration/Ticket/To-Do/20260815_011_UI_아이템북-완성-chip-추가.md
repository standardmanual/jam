# [UI] 아이템북 "완성" Chip 추가

## 배경 / 문제 정의

현재 아이템북 카드는 완성 여부를 시각적으로 구분하지 않는다. Figma 와이어프레임에서는 해당 아이템북의 모든 배지를 획득한 경우 오렌지 "완성" chip을 카드에 표시해 수집 성취감을 시각화한다.

**발견 경위:** 2026-08-15 Design Review B-04 항목. 결정: Figma 방향 적용.

## 상세 요구사항

### 서비스/코드베이스 관점
- `/itembooks/page.tsx` 및 아이템북 카드 컴포넌트에 완성 판정 로직 추가
- 완성 기준: 해당 아이템북의 전체 배지 수 = 사용자 획득 배지 수
- 기존 `discoveredBadgeCount` 데이터를 활용하면 추가 API 호출 불필요
- chip 표시: 오렌지 "완성" (DS v2 토큰 기반, `--color-rarity-legend` 또는 브랜드 오렌지)

### UI/UX 관점
- 카드 우상단 또는 하단 chip 위치 (리뉴얼 Figma 기준)
- 완성된 북은 리스트 상단 정렬 또는 시각적 강조 고려

## 구현 계획
> 디자인 리뉴얼 후 컬렉션(아이템북) 페이지 UI 개편 시 함께 적용.
