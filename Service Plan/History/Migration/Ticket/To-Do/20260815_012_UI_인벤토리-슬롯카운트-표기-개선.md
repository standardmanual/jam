# [UI] 인벤토리 슬롯 카운트 "현재/최대" 형식으로 표기 개선

## 배경 / 문제 정의

현재 인벤토리는 슬롯 프로그레스바 + "N개 남음" 단순 표시. Figma에서는 "22 / 40 슬롯 사용중 · 18개 남음"으로 현재 사용량·최대 용량·잔여량을 동시에 표시한다.

**발견 경위:** 2026-08-15 Design Review B-05 항목. 결정: Figma 방향 적용.

## 상세 요구사항

### 서비스/코드베이스 관점
- `/inventory/page.tsx` 또는 인벤토리 컴포넌트의 슬롯 카운트 표기 변경
- 표기 형식: `{used} / {max} 슬롯 사용중 · {remaining}개 남음`
- 현재 사용 슬롯 수(`used`), 최대 슬롯 수(`max`), 잔여 수(`remaining = max - used`) 계산

### UI/UX 관점
- 프로그레스바 아래에 텍스트 레이블로 표시
- UX Writing 가이드라인 수량 표기 규칙 준수

## 구현 계획
> 디자인 리뉴얼 후 인벤토리 화면 UI 개편 시 함께 적용. 단순 텍스트 변경이므로 리뉴얼 전 단독 적용도 가능.
