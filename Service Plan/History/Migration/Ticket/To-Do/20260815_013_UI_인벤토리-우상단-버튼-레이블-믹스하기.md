# [UI] 인벤토리 우상단 버튼 레이블 → "믹스하기"

## 배경 / 문제 정의

Figma에서 인벤토리 우상단 버튼 레이블이 "조합하기"로 표기. 2026-08-15 의사결정에서 "믹스" 용어가 확정됐으므로, 현재 서비스 구성(우상단 버튼 위치)을 유지하되 레이블을 "믹스하기"로 명시한다. 현재 코드의 실제 레이블 확인 후 불일치 시 수정.

**발견 경위:** 2026-08-15 Design Review D-06 항목. 결정: 버튼 위치 유지, 레이블 "믹스하기" 확정.

## 상세 요구사항

### 서비스/코드베이스 관점
- `/inventory/page.tsx` 또는 인벤토리 레이아웃 컴포넌트의 우상단 버튼 레이블 확인
- 현재 레이블이 "믹스" 또는 "믹스하기"가 아닌 경우 수정
- `/combine` 경로로 연결하는 현재 구조 유지

### UI/UX 관점
- 버튼은 `Button` 컴포넌트 사용 (DS v2 일관성)
- 레이블: "믹스하기" (해요체 아님 — 짧은 액션 레이블 기준)

## 구현 계획
> 단순 레이블 수정이므로 리뉴얼 전 즉시 적용 가능. 리뉴얼 시 전체 인벤 UI와 함께 재검토.
