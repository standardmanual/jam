# [UI] 로딩 스켈레톤 리뉴얼 후 재설계

## 배경 / 문제 정의

Figma 와이어프레임에 로딩 상태(스켈레톤/스피너)가 정의되지 않음. 2026-08-15 결정: 현재 스켈레톤을 제거하고 리뉴얼 후 새 UI 기준에 맞게 재설계한다.

**발견 경위:** 2026-08-15 Design Review E-01 항목. 결정: 스켈레톤 제거 + 리뉴얼 후 재설계.

## 상세 요구사항

### 서비스/코드베이스 관점
- 현재 서비스에서 스켈레톤 UI가 사용되는 위치 전체 파악 (grep 필요)
- 리뉴얼 전 단계: 기존 스켈레톤 제거 또는 단순 스피너로 임시 교체
- 리뉴얼 단계: 각 화면(홈·미션·배지도감·인벤토리·드랍)별 스켈레톤 레이아웃 재설계
  - 스켈레톤은 실제 콘텐츠 레이아웃과 동일한 구조여야 함 (CLS 방지)
  - DS v2 토큰 기반 `--color-surface-*` 색상 사용

### UI/UX 관점
- 3G 환경 기준 로딩 시간(2~4초) 동안 레이아웃 안정성 유지
- `prefers-reduced-motion` 대응: 스켈레톤 shimmer 애니메이션 비활성화 지원

## 구현 계획
> 1단계: 리뉴얼 전 — 기존 스켈레톤 임시 제거 또는 스피너 교체.  
> 2단계: 리뉴얼 후 — 각 화면 레이아웃 기준으로 스켈레톤 재설계 및 Figma 정의.
