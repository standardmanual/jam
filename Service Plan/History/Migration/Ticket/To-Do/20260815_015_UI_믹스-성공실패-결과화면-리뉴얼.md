# [UI] 믹스 성공/실패 결과 화면 리뉴얼

## 배경 / 문제 정의

Figma 와이어프레임에 믹스(조합) 성공/실패 결과 화면이 정의되지 않음. 현재 서비스에는 성공 배너(체크 애니메이션)와 실패 토스트가 구현되어 있으나, 리뉴얼 시 이 화면들도 새 UI 기준에 맞게 재설계가 필요하다.

**발견 경위:** 2026-08-15 Design Review E-04 항목. 결정: 리뉴얼 후 관련 화면 제작.

## 상세 요구사항

### 서비스/코드베이스 관점
- 현재 구현:
  - 성공: `checkRef` 체크 애니메이션 배너 (CombineClient.tsx)
  - 실패: 토스트 메시지
- 리뉴얼 방향:
  - 성공: 신규 배지 획득 모달 또는 풀스크린 결과 화면 (배지 이미지 + 이름 + 희귀도)
  - 실패: 원인별 에러 메시지 (레시피 없음 / 재료 부족 등 3단계 에러 구조)

### UI/UX 관점
- 믹스 성공은 서비스의 핵심 감정 포인트 — 배지 획득 순간을 충분히 축하하는 UI 필요
- 희귀도에 따른 시각 차별화 (COMMON vs MYTHIC 결과 화면 연출 차이)
- 실패 메시지: UX Writing 가이드라인 [현상] → [원인] → [해결책] 3단계 구조

### 컨텐츠 관점
- 실패 케이스별 메시지 초안 필요:
  - "이 조합에 맞는 레시피가 없어요. 다른 아이템 조합을 시도해 보세요."
  - "아이템이 부족해요. 인벤토리에서 더 수집해 보세요."

## 구현 계획
