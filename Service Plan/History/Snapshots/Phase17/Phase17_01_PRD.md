# JAM! Phase 17 PRD — 드랍 메뉴 개편: 'JAM' 지도 + POI 배지 노출

> 작성일: 2026-07-31
> 로직 원천: `jam-web/src/app/(main)/drops/`, `jam-web/src/components/map/MapView.tsx`, `jam-web/src/app/api/drops/`, `jam-web/src/lib/poi/`, `jam-web/src/app/(main)/badges/[id]/`

---

## 1. 배경 및 목표

### 현행 분석 (2026-07-31 코드 확인)

- 하단 메뉴/화면명이 "드랍"이며, `/drops` 라우트(`DropsClient.tsx` + `MapView.tsx`)에서 드랍/픽업 전용 지도를 제공한다.
- 지도는 **사용자 현재 위치 기준 반경(500m, `NAVER_RADIUS_M`)** 으로 카페 등 드랍/픽업용 POI를 불러온다(`GET /api/drops?lat=&lng=`) — **뷰포트(화면 범위) 기반이 아니다.** 지도를 이동해도 재조회되지 않는다.
- 드랍/픽업 POI는 색상 원 마커로만 표시된다(초록=픽업 가능, 회색=범위 내, 진회색=범위 밖). 배지 이미지는 쓰이지 않는다.
- 산/지하철 등 "장소 방문으로 획득하는" POI 배지는 Phase 16에서 이미 만들어졌다 — `badges.type='poi'`, `poi.linked_badge_id`(POI→배지 FK), `user_poi_badge_earns`(획득 이력). 이 배지들은 현재 지도에 전혀 노출되지 않고, `/badges` 목록에서만 확인 가능하다.
- 배지 상세 화면(`/badges/[id]/page.tsx`)은 활동(activity)·아이템(item)·POI(poi) 세 타입 배지가 **이미 같은 화면을 공유**한다. 다만 획득 시 공유카드 만들기(`ShareCardModal`) 버튼이 세 타입 모두에서 노출되고 있다.
- `poi` 테이블에는 이미 `radius_meters`, `linked_badge_id`, `poi_tier` 등 필요한 컬럼이 있다 — 지도 노출을 위한 스키마 변경은 필요 없고, **뷰포트 기반 조회 API**가 새로 필요하다.

### Phase 17 목표

1. 메뉴명 "드랍" → **"JAM"** 으로 변경(기존 드랍/픽업 기능은 그대로 유지).
2. 지도 위에 등록된 산·지하철 **POI 배지**를 30px 원형 마커(배지 이미지)로 노출 — 미획득은 그레이, 획득은 원본 이미지 + 탭하면 배지 상세 이동.
3. POI 배지 마커는 **현재 지도 화면(뷰포트)** 에 걸리는 것만 표시 — 이동/줌마다 다시 계산.
4. 특정 줌 레벨 이하로 축소하면 개별 마커 대신 **숫자 클러스터**로 표시(API 호출량 최적화).
5. 기존 드랍/픽업 마커도 이번 기회에 배지 마커와 시각적으로 구분되도록 리디자인.
6. 배지 상세 화면의 **공유카드 만들기 기능을 전 타입(활동/아이템/POI)에서 제거**.

## 3. 기능 요구사항

### 3-1. 메뉴명 변경

- 하단 탭/네비게이션의 "드랍" 라벨을 **"JAM"** 으로 변경.
- 라우트 경로(`/drops`)와 내부 컴포넌트/파일명은 변경하지 않는다(URL 하위 호환, 리팩터링 범위 아님) — 사용자에게 보이는 문구만 변경.

### 3-2. 드랍/픽업 마커 리디자인

- `MapView.tsx`의 `markerIconHtml` 및 POI 마커 렌더링 로직을 20px 서클로 변경.
- 색상: 픽업 가능 배지 있음 = 메인 포인트 컬러(디자인 토큰 `--color-*` 참조), 없음 = 그레이.
- 서클 내부에 드랍/픽업을 상징하는 아이콘(예: 하강 화살표류)을 배경과 대비되는 네거티브 컬러로 표시.
- 기존 "범위 밖(진회색, 반투명)" 상태 표현은 유지.

### 3-3. POI 배지 마커 노출

- 배지 마커: 지름 30px 원형, 배지 이미지(`badges.image_url`)를 원 안에 표시.
- 미획득 상태: 이미지를 그레이스케일(그레이) 필터로 표시. **탭 비활성** — 클릭 이벤트 자체를 걸지 않아 눌러도 아무 반응이 없어야 한다.
- 획득 상태(`user_poi_badge_earns`에 해당 배지 이력 1건 이상): 원본 컬러 이미지 표시. 탭하면 `/badges/[id]`로 이동.
- 대상: `poi.linked_badge_id`가 있고, 연결된 배지의 `type='poi'`인 POI 전체(현재 드랍/픽업 파이프라인의 카페 등 POI와는 별도 집합).

### 3-4. 뷰포트 기반 POI 배지 조회 API (신규)

- 신규 엔드포인트 제안: `GET /api/poi-badges?swLat=&swLng=&neLat=&neLng=&zoom=`
  - 지도 뷰포트의 남서/북동 좌표(bounding box)를 받아 그 안에 있는 POI 배지만 반환.
  - `zoom > 13`: 개별 POI 배지 목록 반환 — `{ poi_id, badge_id, name, latitude, longitude, image_url, earned }`.
  - `zoom <= 13`: 개별 좌표 대신 **그리드 단위로 묶은 클러스터**(`{ lat, lng, count }`)를 반환해 payload와 마커 렌더링 비용을 줄인다(그리드 셀 크기는 줌 레벨에 비례).
  - 인증된 유저 기준으로 `user_poi_badge_earns`를 조인해 `earned` 여부를 함께 계산.
- 기존 `/api/drops`(드랍/픽업용, 사용자 위치 반경 기반)는 로직 변경 없이 그대로 유지 — 완전히 별도 API.

### 3-5. 뷰포트 이동/줌 처리 (클라이언트)

- `MapView.tsx`에 네이버 지도 `idle` 이벤트(이동/줌 완료 시점) 리스너 추가.
- 디바운스 후, 새 뷰포트가 마지막으로 조회한 범위를 벗어났을 때만 `/api/poi-badges` 재호출.
- 줌 레벨이 13을 기준으로 클러스터⇄개별 전환될 때도 동일 트리거로 재조회.

### 3-6. 배지 상세 화면 — 공유카드 제거

- `badges/[id]/page.tsx`에서 `ShareCardModal` import 및 렌더링 블록 삭제(활동/아이템/POI 공통, 조건 없이 전체 제거).
- `ShareCardModal.tsx` 컴포넌트 파일 및 `/api/share-card` 라우트 삭제(다른 화면에서 참조하지 않음을 코드 조사로 확인 완료).

### 3-7. 기존 드랍/픽업 기능 회귀 방지

- `/api/drops`, `/api/drops/poi/[poiId]`, `/api/drops/[dropId]/pickup` 등 기존 드랍/픽업 API·플로우는 변경하지 않는다.
- 드랍/픽업 바텀시트(POI 탭 시 뜨는 UI)는 기존 카페 등 드랍용 POI 마커에서만 트리거되고, 배지 마커 탭은 배지 상세 페이지 이동으로 완전히 분리된 동작이어야 한다.

## 4. 사용자 여정

### 4-1. 유저 — 지도에서 POI 배지 탐색

```
1. 하단 탭 "JAM" 진입 → 기존 드랍 지도와 동일한 화면, 라벨만 변경
2. 지도 위에 카페 등 드랍/픽업 마커(20px, 그레이/포인트컬러)와
   산/지하철 배지 마커(30px, 배지 이미지)가 함께 표시됨
3. 아직 못 가본 산 정상 배지는 그레이로 흐릿하게 보임 → 실물 획득 동기 부여
4. 이미 획득한 지하철역 배지는 원본 컬러로 선명하게 보임 → 탭 → 배지 상세 화면 이동
   (획득 정보, 조건, 획득 이력 확인 — 공유카드 버튼은 더 이상 없음)
```

### 4-2. 유저 — 지도 이동/줌 시 동적 로딩

```
1. 지도를 드래그해서 다른 동네로 이동 → 이동이 멈추면 짧은 디바운스 후
   새 화면 범위의 POI 배지만 재조회되어 표시됨
2. 손가락으로 줌아웃해서 도시 단위로 넓게 보면(줌 13 이하) 개별 배지 대신
   지역별 숫자 클러스터(예: "12")로 뭉쳐서 표시됨
3. 다시 줌인하면 클러스터가 풀리고 개별 배지 마커로 전환됨
```

## 5. 비범위 (Out of Scope — 이번 Phase 아님)

- 드랍/픽업 자체 로직(발급 조건, 픽업 제한 등) 변경 — 100% 현행 유지.
- 카페 등 드랍/픽업용 POI 자동 수집 파이프라인(`lib/poi/naver.ts`, `categories.ts`) 변경.
- 공유카드 기능의 대체재(예: 다른 형태의 배지 공유) 기획 — 이번엔 제거만, 재도입 계획 없음.
- POI 배지 지도 마커에 클러스터 이외의 고급 시각화(히트맵 등).
- 오프라인 캐싱, 지도 타일 프리페치 등 성능 고도화.
