## ⚠️ 중요: Phase 로드맵과 실제 개발의 불일치

2026-07-09~10에 작성된 이 Phase 계획은 **실제 개발 순서와 매우 다르게 진행됐습니다.**

예시:
- **계획**: Phase 11 = 커뮤니티 피드 + 소셜 공유 + 랭킹
- **실제**: Phase 11 = 드랍엔진 v2 (세계관 모멘텀 도입)

- **계획**: Phase 13 = P2P 플리마켓 실제 오픈
- **실제**: Phase 13 = 미션 참가/상황 개편

- **계획**: Phase 15 = 아이템 조합/비밀 조합법
- **실제**: Phase 15 = (미사용, 조합 v2는 따로 구현됨)

따라서 **이 폴더의 문서로 현재 서비스 상태를 파악하면 안 됩니다.**

## 이 폴더를 활용하는 방법

### 정당한 용도
- "Phase X 당시에는 뭐가 계획돼 있었나?" 하는 **역사적 호기심**
- "왜 계획 번호와 실제 구현이 다르지?" 할 때 **불일치 사유 추적**
- 과거 회의록/이메일 링크로 "그때 왜 그렇게 계획했지?" 되짚어 보기

### 피해야 할 용도
- **절대 "현재 스펙이 뭔지" 확인하려고 이 폴더 쓰지 말 것** — 2개월 전 계획이므로 이미 낡음
- 새 기능 개발 시 "08월에는 뭐가 계획됐더라" 참고하기 — 그냥 우선순위를 새로 정하세요
