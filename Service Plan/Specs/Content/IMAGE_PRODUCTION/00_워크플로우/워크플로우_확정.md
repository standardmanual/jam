# 워크플로우 확정 문서

마지막 업데이트: 2026-08-18

## 3. 툴 확정: Recraft 단독 사용

다른 플랫폼(fal.ai 등 어그리게이터, Flux, Seedream, Nano Banana 등)은 검토 후 배제.
이유: Recraft 직접 사용과 어그리게이터 경유의 단가가 사실상 동일했고,
이 프로젝트에 필요한 커스텀 스타일 기능·편집 도구가 Recraft 자체 API에 통합되어 있어
파이프라인이 단순해짐.

## 4. 모델 확정: Recraft V3 / V3 Vector

Recraft 최신 모델(V4.1)은 프롬프트 이해력이 더 좋지만, 이 프로젝트의 핵심 기능인
**커스텀 스타일 고정(style_id)**, **금지 요소 지정(negative_prompt)**,
**텍스트 억제(no_text)** 를 API 문서상 지원하지 않음 (V2/V3 모델 전용 기능).

→ 스타일 일관성이 최우선이므로 **V3 / V3 Vector를 기본 모델로 확정.**
(참고: V4.1에서 다른 경로로 커스텀 스타일이 가능한지는 추후 실사용 중 재검토 가능)

## 5. 스타일 통제 방식

세계관마다 다음 4가지를 세트로 관리:

1. **커스텀 스타일** — 레퍼런스 이미지 3~5장으로 스타일을 등록하고, 발급된 스타일 ID를
   해당 세계관의 모든 생성 요청에 사용
2. **팔레트 지정** — 색상 5개 내외를 직접 지정 (프롬프트로 "보라색 계열"이라고 쓰는 것보다 정확)
3. **금지 요소 목록** — 드롭섀도우·그라데이션·텍스트 등을 별도 필드에 단어로만 나열
   (문장으로 안 써도 됨, "~없이"라고 안 써도 됨)
4. **텍스트 억제 스위치** — 텍스트를 아예 안 넣는 옵션을 켜서 금지 목록과 이중으로 방어

## 6. 작업 순서

1. 세계관별 스타일그룹 정의서 + 레퍼런스 이미지 확정 (디자이너가 채움)
2. 세계관별 커스텀 스타일 등록 → 검증 배치로 확인 (컬렉션 1개, 9장) → 만족할 때까지 반복
3. 세계관별 컬렉션·아이템 900개 브리프 확정 (디자이너가 채움 → 시각 컨셉으로 정제)
4. 양산: 아이템당 여러 장씩 과잉 생성
5. 후처리: 배경 제거, 팔레트 정리, 규격 정리
6. **수동 QC** — 디자이너가 직접 선별 (자동 QC 없음, 900장은 사람이 충분히 볼 수 있는 규모)

## 7. 비용 예상

900장 기준, 아이템당 6~8장 과잉 생성 + 후처리 포함 **약 $200~300**.
스타일 등록 시행착오 비용은 $5 미만.
→ 비용은 이 프로젝트의 제약 조건이 아님. 품질 기준으로만 판단할 것.

## 8. 폴더 구조

`02_스타일그룹/` 아래에 세계관 하나당 폴더 하나. 폴더 안에:
- 스타일그룹 정의서 (스타일 규칙)
- 레퍼런스 이미지 (무드 이미지에서 잘라낸 개별 요소)
- 컨텐츠 브리프 (컬렉션·아이템 내용, 컬렉션마다 파일 1개)
