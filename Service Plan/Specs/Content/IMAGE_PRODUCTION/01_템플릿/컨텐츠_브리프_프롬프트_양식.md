# 컨텐츠 브리프 프롬프트 양식

컬렉션 하나당 파일 하나로 만듭니다. Claude가 해당 컬렉션의 `스타일그룹_정의서.md` +
`컨텐츠_브리프.md`를 조합해 작성하는 **완성된 산출물**입니다 — 빈 칸을 채우는 재사용
템플릿이 아니라, 매 컬렉션마다 실제 내용이 다 채워진 문서를 새로 만듭니다.

파일명: `{컬렉션ID} {컬렉션이름}_프롬프트.md` (컨텐츠_브리프.md와 같은 폴더)

사용자가 이 문서를 그대로 Gemini에 붙여넣어 이미지를 생성하므로, 아이템별 섹션 안에
군더더기 설명 없이 Gemini가 바로 읽을 수 있는 프롬프트 텍스트만 담습니다.
