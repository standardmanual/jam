# 스타일그룹 정의서 작성 요청 프롬프트 (재사용 템플릿)

세계관을 새로 추가할 때마다, 아래 [ ] 부분을 채워서 그대로 요청해주시면 됩니다.

---

```
[숲속의 갱단]의 스타일그룹 정의서를 작성해줘.

첨부한 이미지는 스타일 분석을 위한 무드 참고용이야.
그림체, 선 스타일, 표현 기법, 컬러톤, 형태·컬러의 조형적 밸런스만 참고하고
이미지 속 구체적인 사물·캐릭터·문구는 참고하지 마.
실제 이미지 생성 시 참고할 레퍼런스 이미지는 내가 별도로 준비할 거니까,
이 이미지들을 크롭해서 쓰라고 제안하지 마.

아래 요구사항이 참고 이미지의 내용과 상충되는 경우, 요구사항을 우선해:

1. 지브리 스튜디오의 애니메이션 스타일
2. 이미지가 영역 밖으로 넘치지 않도록 함
3. dittering 표현 금지.
   4. AI로 생성한 무드를 최대한 느꺼지지 않도록함
      5.채도를 높게 표현함

세계관 설명:
  "네 핫도그 소시지, 우리가 털어간다. 꼬우면 산으로 오든가."
  도심 공원과 외곽 산자락을 지배하는 실세들 (다람쥐·길고양이 컨셉). 방심한 등산객의 가방을 털고, 길가에 흘린 간식에서 가장 맛있는 부분만 빼먹는 범인들. 훔친 물건은 깊은 숲속 동물들의 비밀 환전소 **'그루터기 살롱'**에서 도토리와 거래된다. 구역을 존중하며 걷는 자들에게는 보물을 슬쩍 흘려두기도 한다.

개별 아이템 설명 예시 (있다면):
| 이름 | 설명 |
|---|---|
| 반짝이는 도토리 | 수정처럼 투명하게 만든 도토리 |

정의서 파일만 만들어서 채팅에 제공해줘. 다른 파일은 만들지 마.
내가 준 요구사항들을 별도 섹션으로 새로 만들지 말고,
정의서 템플릿에 이미 있는 섹션 안에 채워 넣어줘.
정의서 본문에 "(요구사항 1)"처럼 내가 몇 번으로 제시했는지 표기하지 말고,
규칙 내용만 자연스럽게 서술해줘.
이 세계관의 전체 컬렉션·아이템 수를 전제하는 표현은 쓰지 마.
실제 생성은 이 세계관 전체가 아니라 컬렉션 1개 또는 일부만 대상으로 요청할 수도 있어.
다른 세계관의 내용(설명, 아이템 예시 등)도 이 정의서에 언급하지 마 — 이 세계관만
읽고도 완결되는 문서여야 해.
세계관 설명 문장 안에 다른 세계관 소속 요소(캐릭터·세력 등)가 언급되더라도,
그걸 이 세계관에서 어떻게 표현할지 해석하거나 언급하지 마.
```

## 이 프롬프트가 하는 일

- **레퍼런스 이미지 = 스타일 분석용**이라는 것을 먼저 못 박아서, 제가 임의로 "이 부분을
  크롭해서 쓰세요" 같은 제안을 하지 않도록 막습니다.
- **요구사항 우선순위**를 명시해서, 레퍼런스 이미지에서 읽히는 느낌(예: 캐릭터, 텍스트
  스타일)과 명시적 요구사항이 부딪힐 때 항상 요구사항이 이기도록 합니다.
- **출력물을 정의서 파일 하나로 제한**해서, 매번 전체 zip이나 다른 파일이 딸려 나오지
  않게 합니다. (전체 폴더 구조 갱신이 필요할 때는 별도로 요청해주세요.)
- **새 섹션을 만들지 않고, 요구사항 번호도 본문에 남기지 않게** 해서, 정의서가 대화
  맥락 없이도 다음 단계(컨텐츠 브리프 프롬프트 생성)에서 그대로 읽을 수 있는 완결된
  문서가 되도록 합니다.
- **고정 수량·다른 세계관 언급을 배제**해서, 세계관 전체가 아니라 컬렉션 1개 또는
  일부만 생성 요청하는 경우에도 정의서 내용이 그대로 유효하게 합니다.
