# 대량 이미지 생성 프로젝트 — 폴더 안내

## 폴더 구조

```
recraft-bulk-image-project/
├── README.md                          ← 지금 보고 계신 파일
├── 00_워크플로우/
│   └── 워크플로우_확정.md              ← 지금까지 결정된 내용 총정리
├── 01_템플릿/
│   ├── 스타일그룹_정의서_양식.md       ← 세계관(스타일 그룹)마다 채우는 빈 양식
│   └── 컨텐츠_브리프_양식.md           ← 컬렉션·아이템 내용을 채우는 빈 양식
└── 02_스타일그룹/
    └── {세계관번호} {세계관이름}/      ← 세계관 1개 = 폴더 1개, FACTIONS.md 기준 10개 존재
        ├── 스타일그룹_정의서.md        ← 이 세계관의 스타일 규칙 (기본 정보는 채워짐, 나머지는 디자이너 작성)
        ├── 레퍼런스_이미지/            ← 무드 이미지에서 잘라낸 개별 요소 3~5장을 여기에
        └── 컨텐츠_브리프/
            └── {컬렉션ID} {컬렉션이름}/
                └── 컨텐츠_브리프.md    ← 컬렉션 1개 = 폴더 1개 (세계관당 10개, 내용은 이미 채워짐)
```

## ID 체계

Recraft 등록·이미지 파일 추적용으로 영문/숫자 체계를 사용합니다. 사람이 채우지 않고
에이전트가 FACTIONS.md·ITEMBOOKS.xlsx·서비스 DB(badges 테이블) 기준으로 직접 부여합니다.

- **스타일 그룹 ID**: 세계관 번호 2자리 (`01`~`10`, FACTIONS.md의 세계관 번호 그대로)
- **컬렉션 ID**: `{세계관번호}-{컬렉션번호}` (예: `01-01`, 세계관당 01~10)
- **아이템 ID**: 컨텐츠_브리프.md의 "#" 열 — 아이템 1개당 실제 서비스 DB의 배지 UUID를
  rarity(common/rare/legend/mythic) 4종 모두 표기

## 사용법

1. **컨텐츠 브리프**: 세계관 10개 × 컬렉션 10개 = 100개 전부 이미 생성·완료된 상태입니다
   (FACTIONS.md 세계관 설명 + ITEMBOOKS.xlsx 컬렉션·아이템 텍스트 + DB 배지 UUID 기준).
   내용 수정이 필요하면 말씀해주세요.
2. **디자이너가 채울 것은 `스타일그룹_정의서.md`뿐입니다**: 세계관마다 기본 정보(ID·이름·설명)는
   이미 채워져 있고, 팔레트·렌더링 규칙·절대 금지 요소·텍스트 사용 여부·캐릭터화 규칙·톤을 채우면 됩니다.
3. `레퍼런스_이미지/` 폴더에 무드 이미지에서 잘라낸 개별 요소(스티커 낱장 등) 3~5장을 넣으세요.
   **스티커 시트 전체를 통으로 넣지 마세요.**
4. 세계관 하나(스타일 정의서 + 레퍼런스)가 다 채워지면 저에게 알려주세요. 그다음부터는 제가 처리합니다.

## 지금 당장 채우실 것

10개 세계관 전부 `스타일그룹_정의서.md`가 기본 정보만 채워진 빈 양식 상태입니다. 세계관별로:

- [ ] 팔레트(주조색/보조색/배경색)
- [ ] 렌더링 규칙(아웃라인/채색/조명/질감)
- [ ] 절대 금지 요소
- [ ] 텍스트/레터링 사용 여부
- [ ] 캐릭터화 규칙, 톤/다이나믹함
- [ ] `레퍼런스_이미지/`에 개별 요소 3~5장 추가
