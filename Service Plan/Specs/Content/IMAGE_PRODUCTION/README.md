# 대량 이미지 생성 프로젝트 — 폴더 안내

## 폴더 구조

```
recraft-bulk-image-project/
├── README.md                          ← 지금 보고 계신 파일
├── 00_워크플로우/
│   └── 워크플로우_확정.md              ← 지금까지 결정된 내용 총정리
├── 01_템플릿/
│   ├── 스타일그룹_정의서_양식.md       ← 세계관(스타일 그룹)마다 채우는 빈 양식
│   └── 컨텐츠_브리프_양식.md           ← 세계관·컬렉션·아이템 내용을 채우는 빈 양식
└── 02_스타일그룹/
    └── _예시_아스팔트레인저/           ← 세계관 1개 = 폴더 1개, 이 구조를 10개 복제
        ├── 스타일그룹_정의서.md        ← 이 세계관의 스타일 규칙 (양식 복사본)
        ├── 레퍼런스_이미지/            ← 무드 이미지에서 잘라낸 개별 요소 3~5장을 여기에
        └── 컨텐츠_브리프/
            └── 진흙탕의_영광.md        ← 컬렉션 1개 = 파일 1개 (예시로 이미 채워둠)
```

## 사용법

1. **새 세계관을 시작할 때**: `02_스타일그룹/_예시_아스팔트레인저` 폴더를 통째로 복사해서
   `02_스타일그룹/{세계관이름}` 으로 이름을 바꾸세요.
2. `스타일그룹_정의서.md`를 채우고, `레퍼런스_이미지/` 폴더에 무드 이미지에서 잘라낸
   개별 요소(스티커 낱장 등) 3~5장을 넣으세요. **스티커 시트 전체를 통으로 넣지 마세요.**
3. 컬렉션마다 `컨텐츠_브리프/` 안에 파일 하나씩 (`컬렉션이름.md`) 만들어서
   `컨텐츠_브리프_양식.md`를 채우세요. 한 세계관에 컬렉션이 10개면 파일도 10개입니다.
4. 세계관 하나(스타일 정의서 + 레퍼런스 + 컬렉션 10개 브리프)가 다 채워지면
   저에게 알려주세요. 그다음부터는 제가 처리합니다.

파일럿으로 진행 중인 **아스팔트 레인저** 세계관 기준:

- [ ] `레퍼런스_이미지/` 폴더에 스티커 시트에서 잘라낸 개별 이미지 3~5장 추가
- [ ] `진흙탕의_영광.md`는 대화에서 주신 내용으로 이미 채워뒀습니다 — 확인만 해주세요
- [ ] 나머지 컬렉션 9개의 이름·설명·아이템 9개씩 → `컨텐츠_브리프_양식.md` 복사해서 채우기
