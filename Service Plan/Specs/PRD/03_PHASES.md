## 현재 상태 요약

핵심 기능(배지·인벤토리·드랍/픽업·컬렉션·세계관·조합·미션·포인트·어드민)은 모두
구현되어 있다. 미구현으로 확인된 것은 **P2P 플리마켓 실거래, D2C 실물 패치 구매,
푸시 알림** 3가지뿐 — 상세는 [01_PRD.md](./01_PRD.md) §6-2 참고.

## 개발 이력 (시간순, 티켓 기준)

### 2026-07-09~10 — 초기 구축 (Phase 1~7 원안)
온보딩(구글 로그인·프로필)·Strava 연동·배지 자동발급·공유카드·POI 사후인증·인벤토리·
확률 드랍·어드민 패널·유저 드랍/픽업(당시 Google Maps)·OSM 기반 T2 POI·아이템 일련번호.
계획대로 완료된 것으로 확인됨. 상세는 [History/PHASES_ROADMAP_ARCHIVE.md](../../History/PHASES_ROADMAP_ARCHIVE.md).

### 2026-07-15~20 — 배지 엔진 안정화
POI 매칭 바운딩박스 사전필터, 배지 이름당 최상위 레어리티 1개만 노출하는 "성장 티어"
정책, 빈 `condition_json` 발급 버그 수정, 미구현 조건 3종(`temperature_min/max` 등) 구현.

### 2026-07-21 — 유저 검색 + 드랍엔진 v2 전면 교체
유저 검색 기능(`api/users/search`) 추가. **아이템배지 드랍엔진을 v2로 전면 교체**
— 활동당 최소 1개 확정 드랍 + 세계관 서사 모멘텀(마르코프 가중 추첨) 도입, 상세는
[BadgeEngine 문서](../BadgeEngine/BADGE_ENGINE_UNIFIED.md) §3 참고. 동시에 Strava 싱크
파이프라인 안정화(동시 싱크 잠금, 첫 싱크 드랍 1회 제한, 무한대기 타임아웃 수정),
홈/프로필 피드 중복 표시 버그 수정.

### 2026-07-22~23 — 지도·POI 소스 전환 + 앰비언트 드랍 + 포인트 1a
**드랍/픽업 지도를 Google Maps → 네이버 지도(NCP Maps.js)로, T2 POI 소스를
OpenStreetMap → 네이버 지역검색 오픈API로 전환** (인프라 전면 교체). 배지 이미지 없는
아이템배지 전량에 샘플 이미지 랜덤 배정, 피드가 배지 정보 변경을 반영 못하던 구조적
문제 수정. **POI 앰비언트(시스템) 아이템배지 드랍** 신규 도입 — 유저 행동과 무관하게
시스템이 주기적으로 POI에 아이템을 배치. (→ **2026-08-25 전면 제거**, 티켓
[20260825_004](../../History/Migration/Ticket/20260825_004_Feature_앰비언트-드랍-기능-제거.md).
미완성이 아니라 쓰지 않기로 한 제품 결정이다 — [01_PRD.md](./01_PRD.md) §6 참고) **잼 포인트 시스템 1a단계**(유저별 잔액/
`point_wallets`) 신규 구축. Vercel Hobby 플랜의 Cron 빈도 제한으로 배포 실패했던
근본 원인 해결.

### 2026-07-24~26 — 미션 개편 + 홈 CMS 도입
미션 시스템(당시 명명 "Phase13") 개편 — 참가 필수화, 참가자만 완료 보상, 네이티브
confirm 대신 인앱 확인 UI. 미션 목록에 진행중/참여중/종료 탭 추가. 홈/프로필 Feed
섹션 통합·공용 컴포넌트화. 드랍 메뉴 개선(당시 명명 "Phase14") — 모드탭 제거, POI
중심 재구성. **홈을 "투데이" CMS 체계로 개편** — `today_cards` 테이블, 템플릿 기반
콘텐츠 카드 신규 도입, 이후 Feed 섹션을 투데이 화면에서 제거. GPS 오탐(false
positive)으로 실내 픽업/드랍이 막히던 문제 수정.

### 2026-07-27 — POI 대량 등록 + 조합 시스템 v2
전국 산 POI 847개(산림청 공공데이터), 지하철·기차역 POI 929개 일괄 등록. POI
카테고리와 드랍/픽업 파이프라인 연동을 코드 하드코딩에서 DB(`poi_categories`)로 이전.
**POI 배지 타입(`type='poi'`) 신규 추가** — 반복 획득 가능, 어드민에서 다중 POI 연결.
미션 목록 정렬/필터 UI 조정. **아이템 조합 시스템을 v2로 재설계** — "정석 레시피,
재료 정확 매칭" 방식으로 전면 교체, 재료 수 2~10개로 확장, 세계관 다양성 티어 정책
도입.

### 2026-07-30~08-01 — 슬롯 정책 확정 + 자동 동기화 + 신뢰성 개선
아이템북 슬롯 정책 확정 — 슬롯 장착 아이템은 인벤토리 칸을 차지하지 않음. **Strava
전체 유저 자동 동기화 Cron** 신규 추가. 러닝(`road_running`→`running` 개명) 카테고리
속도 조건 배지 2종 추가. 산 POI 좌표 오매핑(경상도 좌표가 서울 관악 인접으로 잘못
등록됨) 수정, POI 매칭 엔진에 선분(segment) 기반 최근접 거리 계산 추가로 근본
해결. **드랍 메뉴를 "JAM" 지도 화면으로 개편**(당시 명명 "Phase17") — 지도 위에
산·지하철역 등 POI 오버레이. POI 배지를 배지함 "장소" 탭 및 프로필 배지 갤러리에
노출(수 차례 버그 수정 거침 — max_rows 제한, 오탐 발급 등). **배지·드랍 엔진
신뢰성 개선** — 성과 배지 홍수 방지 캡 제거, 첫 Strava 싱크 처리 개선.

### 2026-08-06 — 문서 체계 재정리 + 도메인 전환
`Service Plan` 폴더를 PRD·티켓·컨텐츠·배지엔진 4카테고리로 재정리(이 문서 포함).
**서비스 도메인을 `jam-rose.app` → `j-a-m.app`으로 전환**, `NEXT_PUBLIC_BASE_URL`
환경변수 통일, 불필요해진 `STRAVA_REDIRECT_URI` 삭제. Google 로그인 화면의
`supabase.co` 도메인 노출 문제는 검토 후 기존 방식 유지로 결정(Supabase Pro 플랜
Custom Domain 전환 시 재검토 예정).

## 과거 Phase 번호와 실제 구현의 대응 관계 (참고용)

계획 문서(`History/PHASES_ROADMAP_ARCHIVE.md`)의 Phase 번호가 티켓 제목에 종종
그대로 쓰였지만, 원래 계획된 내용과는 다른 경우가 많다.

| 계획상 Phase 번호 | 원래 계획 | 실제 그 번호로 불린 작업 |
|---|---|---|
| Phase 10 | (신규 번호, 원안에 없음) | 유저 검색 기능 |
| Phase 11 | 커뮤니티 피드 + 소셜 공유 | 드랍엔진 v2 (세계관 모멘텀) |
| Phase 13 | P2P 플리마켓 | 미션 시스템 개편 |
| Phase 14 | 지도 고도화 + POI 확장 | 드랍 메뉴 개선 |
| Phase 15 | 아이템 조합/비밀 조합법 | (번호는 안 쓰였으나) 실제로 조합 시스템 v2가 07-27에 구현됨 |
| Phase 16 | 다이나믹 미션 시스템 | POI 배지 타입 추가 |
| Phase 17 | (제거된 기능 — 티켓 20260824_017로 전면 제거) | 드랍 메뉴 → "JAM" 지도 개편 |

번호를 현재 상태 파악에 참고하지 말 것 — 위 표는 왜 혼란스러운지 설명하기 위한
기록일 뿐이다.
