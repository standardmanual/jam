# 슬롭 사전

> 신설 문서 (티켓 20260918_0423, 팀 공통 규칙 9번). "슬롭 제거" 중 **글 슬롭**의 금칙 표현과
> 대체 표현을 모은다. 초기 목록은 AI 씬(생성형 AI로 작성된 글에서 자주 보이는 상투구)의
> 보편 기준으로 시작하고, **사용자가 거슬린 표현을 발견하면 이 문서에 직접 추가**하는 구조다.
>
> 이 문서는 `Specs/UX_WRITING_GUIDELINE.md`(제품 UI 문구의 용어·톤·구조 규칙)와 역할이
> 다르다 — 그쪽은 "무엇을 어떻게 쓸지", 이 문서는 "무엇을 쓰지 말지"다. 둘 다 참조한다.

## 담당

글 쓰는 전원(카리나·아현·혜린·윈터·윤진·하니) + 한국어 리뷰(건당 1회). 검사는
`verify` 스크립트(자동화 A1)가 기계적으로 먼저 거른다.

## 금칙 표현 → 대체 표현

| 금칙 | 왜 슬롭인가 | 대체 |
| --- | --- | --- |
| "~을 통해" | 번역투, 없어도 뜻이 통함 | 문장을 능동형으로 재구성 |
| "혁신적인", "게임체인저" | 근거 없는 과장 | 구체적 효과를 직접 서술 |
| "여정" (journey) | 번역투 상투구 | "과정", "동안" 또는 생략 |
| "다양한", "여러 가지" | 의미 없는 수식, 개수·종류를 감춤 | 실제 개수·목록으로 대체 |
| "궁극의", "완벽한" | 근거 없는 과장 | 구체적 조건·수치로 대체 |
| 이모지 남발 | 내용을 대체하지 못하는 장식 | 필요한 곳 1개 이내, 없어도 무방하면 삭제 |
| 내용 없는 서론("오늘은 ~에 대해 알아보겠습니다") | 정보 없이 분량만 채움 | 바로 본론 시작 |
| 내용 없는 맺음말("이상으로 마치겠습니다") | 정보 없이 분량만 채움 | 다음 행동(CTA)이 없으면 생략 |
| 반복 강조("정말", "진짜", "너무너무") | 의미 없는 강도어 반복 | 필요하면 구체적 근거로 대체, 없으면 삭제 |
| "만나보세요", "확인해보세요" (남발) | 마케팅 상투구 | 구체적 행동·혜택으로 대체 |

## 확장 방식

1. 사용자가 거슬린 표현을 발견 → 이 표에 행 추가 (금칙·이유·대체)
2. `verify`의 금칙어 검사 목록에도 반영 (자동화 A1, 스크립트 쪽은 티켓 20260918_0421 담당)
3. 같은 표현이 검사에서 3회 이상 걸리면 대체 표현을 더 구체화

## 예외

트라이브별 목소리(세계관 캐릭터의 말투)는 윈터 검수를 거쳐 이 사전보다 우선한다 — 목소리
설정 자체가 금칙 표현을 의도적으로 쓰는 경우(패러디·풍자 톤)는 윈터가 판단한다.
