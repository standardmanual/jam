# [Feature] 인앱 구글맵 렌더링 및 마커

## 배경 / 문제 정의
드랍/픽업 화면에서 네이티브 구글 지도 표시. POI와 드랍 아이템을 마커로 표시.

## 상세 요구사항
- 구글맵 JS API 로드
- 유저 현재 위치 중심 표시 (파란 원형 마커)
- POI 마커 (회색, 클릭 시 상세 표시)
- 드랍 아이템 마커 (배지 이미지, 클릭 시 픽업 가능)
- 줌 레벨 17 기본값
- 터치/마우스 드래그 패닝, 핀치 줌

## 구현 계획
1. `src/components/drops/MapView.tsx` 컴포넌트
2. @googlemaps/js-api-loader 라이브러리
3. 마커 CSS 커스터마이징
4. 클릭 이벤트 핸들링
