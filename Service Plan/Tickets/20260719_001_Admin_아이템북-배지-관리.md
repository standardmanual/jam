# [Admin] 아이템북 + 배지 관리

## 배경

## 상세 요구사항
- 아이템북 목록 (세계관별 필터)
- 아이템북 생성/수정 (name, faction_id, story_text, is_active)
- 배지 할당 UI (900개 배지 중 선택)
- 완성 배지 설정 (아이템북 완성 시 발급할 배지 지정)
