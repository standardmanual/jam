# [BadgeEngine] 산 카테고리 POI 반경 50m → 150m 일괄 상향

## 배경 / 문제 정의

`sihyunrr@gmail.com` 계정이 activity 19681086473(용마산·아차산 트레일)에서
루트가 두 산 정상 인근을 통과했음에도 POI 배지가 발급되지 않았다.

**원인**: 산 POI의 데이터 모델이 "정상 좌표 1개 + radius_meters" 구조인데,
- GPS drift 누적으로 실제 루트가 단일 정상 좌표에서 50m+ 떨어짐
- 선분 매칭(pointToSegmentDistanceMeters)을 사용해도 정상 인근을 지나는 루트가
  50m 반경 안에 들어오지 않는 경우가 발생

과거 이슈 이력:
- 2026-07-31: `SERVICE_OPERATIONS_20260731_1100.md` — 선분 매칭 추가.
  "반경 넓히는 방안은 어뷰징 위험으로 기각"이었으나, 실제 데이터로 재검토한 결과
  150m도 어뷰징 위험이 낮다고 판단(산 구간은 도시보다 POI 밀집도 낮음).
- 2026-07-31: "산 = 단일 좌표 + 50m 반경의 구조적 한계는 별도 과제 보류"로 남겨둠.

## 해결 방식

`poi` 테이블에서 `mountain` 카테고리 + `radius_meters=50`인 POI 847개를 150m로
일괄 업데이트.

```sql
UPDATE poi
SET radius_meters = 150
WHERE category = 'mountain' AND radius_meters = 50;
-- 영향: 847행 (이미 500m인 6개는 그대로 유지)
```
