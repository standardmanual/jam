# [Infra] /jam-work 크루 페르소나(콜사인) 적용 — 롤백 대비 문서화

## 배경 / 문제 정의
[티켓 007](./20260811_007_Infra_개발자-리뷰어-분리-워크플로우-jam-work-도입.md)에서 만든 `/jam-work` 파이프라인(jam-developer / conservative-reviewer / progressive-reviewer)에 정체성을 부여하기 위해, JAM! 서비스의 트레일/체크포인트 세계관을 반영한 콜사인 페르소나를 설계 → 사용자 검토(아티팩트) → 적용.

**요청 조건**: 이 워크플로우를 나중에 쉽게 삭제할 수 있도록, 적용 시점과 변경 범위를 명확히 기록해 둘 것.

## 상세 요구사항

### 서비스/코드베이스 관점
- 콜사인 매핑: 베이스캠프(오케스트레이터·나 자신) · 레인저(PM/SOT·나 자신이 겸함) · 트레일메이커(jam-developer) · 체크포인트(conservative-reviewer) · 스카우트(progressive-reviewer)
- **기능/권한 로직은 전혀 변경하지 않음** — 순수하게 각 서브에이전트 정의 파일 상단에 콜사인·톤 문단만 추가. 티켓 007에서 확정한 권한 경계(main push는 베이스캠프만, SQL 직접 실행도 베이스캠프만, 트레일메이커는 review 브랜치까지 등)는 그대로 유지.
- `jam-work/SKILL.md`에는 콜사인 매핑표와, 0단계/3단계(둘 다 오케스트레이터가 직접 수행하는 단계)에 "레인저 모자를 쓴다" / "베이스캠프 모자를 쓴다"라는 표현만 추가 — 실행 순서·책임 주체는 변경 없음.

### 롤백 방법 (요청에 따라 명시)
아래 파일들을 이 티켓의 커밋 이전 상태로 되돌리면 콜사인 이전 상태로 완전히 복원된다:

```
.claude/agents/jam-developer.md       (콜사인 문단만 제거하면 티켓 007 상태로 복원)
.claude/agents/conservative-reviewer.md (동일)
.claude/agents/progressive-reviewer.md  (동일)
.claude/skills/jam-work/SKILL.md        (콜사인 매핑 블록 + "모자를 쓴다" 문구 2곳 제거)
```

- 가장 간단한 방법: 아래 "배포 정보"의 커밋 해시를 `git revert <해시>`
- `/jam-work` 워크플로우 전체(페르소나 포함)를 완전히 걷어내고 싶은 경우: 티켓 007의 "변경된 파일" 목록 + 이 티켓의 파일 목록을 합쳐서 전부 삭제 + `.claude/agents/`, `.claude/skills/jam-work/` 디렉터리 제거
- 세션 메모리에도 이 적용 시점이 기록되어 있음 (`ranger`가 아닌 실제 메모리 파일명은 완료 기록 참고) — 별도 세션에서 롤백을 요청해도 컨텍스트를 빠르게 복구 가능

## 구현 계획
아티팩트로 제시한 5개 페르소나 카드(베이스캠프/레인저/트레일메이커/체크포인트/스카우트) 내용 중 톤·태그라인만 발췌해 각 정의 파일 상단에 반영. 기능 변경 없음이 핵심이므로 diff를 최소화.
