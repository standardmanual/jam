# [UI] 모듈러 디자인시스템 v2 스테이징 적용 (디자인 리뉴얼)

## 배경 / 문제 정의

`design-system-staging/v2/`에 새로운 모듈러 디자인시스템(DS v2)이 완성되었다.
현재 `jam-web`은 SuperHi Plus(코발트/아이스) 색채 체계와 Pretendard 폰트를 사용 중이며,
DS v2는 블랙 캔버스/화이트/레드-오렌지(#e8461f) 팔레트 + Noto Sans KR로 전환된다.

**작업 성격:** 디자인 리뉴얼. 기능 변경 없음.
**금지 사항:** 새 기능 추가, 화면 구성 변경.
**필수 사항:** 기존 기능·컨텐츠 100% 유지 + UX Writing 가이드라인 준수.

## 상세 요구사항

### 서비스/코드베이스 관점
- `globals.css` 색상 토큰 → DS v2 `tokens/colors.css` 로 교체
- `globals.css` 타이포그래피 → DS v2 `tokens/typography.css` 로 교체
- 반경/간격 토큰 → DS v2 `tokens/radius.css`, `spacing.css` 로 교체
- 폰트 교체: Pretendard CDN 제거 → Next.js `next/font/google`로 Noto Sans KR 로드
- `components/ui/` 내 공통 컴포넌트 색상·스타일 → DS v2 시맨틱 토큰으로 교체
- Tailwind 유틸리티 클래스(`bg-jam-*`, `text-jam-*`, `bg-[#0033e5]` 등) → CSS 변수 직접 참조로 전환
- 배지 희귀도 색상 매핑 업데이트 (의사결정 항목 참조)

### UI/UX 관점
- 전체 페이지 (21개 라우트) 시각 스타일 전환
- TabBar 활성 색: cobalt → --color-primary(red #e8461f)
- 버튼, 카드, 인풋, 내비게이션 등 DS v2 컴포넌트 스타일 적용
- DS v2에 없는 컴포넌트(SlidingTabs, Footer, WanderingEyesLoader 등)는 DS v2 토큰 기반으로 직접 스타일 맞춤

### UX Writing 관점
- i18n/ko.ts 기준 현재 용어 준수 상태 양호 (겟/믹스/픽업/드랍 등 올바름)
- 전체 화면 텍스트 재검토: UX_WRITING_GUIDELINE.md 고정 용어 검증
