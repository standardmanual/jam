# [UI] 미션 상황보기 페이지 Figma 리뉴얼

## 배경 / 문제 정의
기존 미션 상황보기(`/missions/[id]/status`) 페이지는 단순 Card 컴포넌트 기반의 텍스트 목록 형태다.
Figma 스펙(06_미션 상황)을 기반으로 시각적으로 풍부한 랭킹 UI로 전면 리뉴얼한다.

미션 상세 페이지 리뉴얼(현재 커밋 9aeb6d7, 브랜치 claude/mission-detail-layout-2394fe)과 동일 워크트리에서 작업한다.

## 상세 요구사항

### UI/UX 관점

**Figma 스펙(06_미션 상황) 주요 레이아웃:**

1. **헤더 정보 바** (페이지 상단)
   - 좌: "랭킹 · 참가자 N명" (13px, #B2B2B2)
   - 우: "미션: [목표값]" — mission.condition에서 목표 값 표시 (13px, #B2B2B2)

2. **TOP 3 포디엄** (랭킹 타입에만 적용)
   - 배열: 2위(좌) - 1위(중앙, 최장바) - 3위(우)
   - 각 유저: 원형 아바타 + 유저명 + 진행값 텍스트 (상단)
   - 바 높이: 1위=130px, 2위=90px, 3위=60px
   - 바 컬러: 1위=#0D3320/border #56C985, 2위=#1A3A2A/border #4CAF7D, 3위=#1E2E1E/border #5A7A5A
   - 아바타 원 크기: 1위=60px(border 2px #56C985), 2위=48px(border 2px #4CAF7D), 3위=48px(border 2px #5A7A5A)
   - 랭킹 숫자 컬러: 1위=#56C985, 2위=#4CAF7D, 3위=#8AAA8A
   - 진행값 컬러: 1위=#56C985, 2위=#4CAF7D, 3위=#8AAA8A

3. **전체 순위 목록** (4위 이후, 구분선 + 레이블)
   - 헤더 행: "전체 순위" (13px, #B2B2B2) + separator
   - 각 행: 순위번호(14px bold, #B2B2B2) + 아바타(36px circle) + 유저명(14px, #FFF) + 진행값(14px bold, #FFF)
   - 행 하단: 진행 프로그레스 바 (6px 높이, 좌 인덴트 32px, 배경 #1E1E1E)
   - 바 그라디언트: 상위일수록 밝은 그린, 하위일수록 어두운 그린
   - 행 간 구분선: #1E1E1E 1px

4. **나의 순위 카드** (하단 고정)
   - 항상 목록 최하단에 고정 노출 (화면 밖에 있더라도)
   - 배경: #0D2A1A, border: 1px solid #2E7D52, border-radius: 12px
   - 순위 숫자 컬러: #56C985
   - 유저명(bold, #FFF) + 서브텍스트 "[달성값] 달성" (#B2B2B2, 11px)
   - 진행값: 초록색 (#56C985)
   - 진행 바: 배경 #1A3A2A, fill: linear-gradient(#00CC66 → #33E580)
   - "나"임을 표시하는 "(나)" 텍스트 없음 — 별도 카드 디자인으로 구분

### 서비스/코드베이스 관점

- **파일 경로 (워크트리):**
  - `jam-web/src/app/(main)/missions/[id]/status/MissionStatusClient.tsx` — 전면 개편
  - `jam-web/src/app/(main)/missions/[id]/status/page.tsx` — mission 조건값 추가 조회 필요할 수 있음

- **미션 타입별 렌더링:**
  - `status_display_type === 'ranking'` → 포디엄 + 전체 순위 목록 (Figma 스펙 그대로)
  - `status_display_type === 'achievement'` → 기존 AchievementRow 유지하되 시각적 개선
  - `status_display_type === 'individual'` → 기존 개인형 카드 유지

- **API:** `/api/missions/[id]/status` 기존 그대로 사용 (변경 없음)
  - ranking 타입 응답: `{ type, entries: RankingEntry[], me: RankingEntry | null, totalParticipants }`
  - RankingEntry 구조: `{ userId, username, avatarUrl, progressValue, isCompleted, completedAt, rank }`

- **목표값 표시:** `missionTitle` 외에 goal 정보가 필요한 경우 page.tsx에서 조건값 조회 추가

- **기존 Card 컴포넌트:** 나의 순위 카드는 인라인 스타일로 직접 구현 (DS v2 토큰 사용)
- **DS 토큰:** `--color-bg`, `--color-surface`, `--color-border`, `--color-primary`, `--color-text-secondary`
- **워크트리 경로:** `.claude/worktrees/mission-detail-layout-2394fe/jam-web/src/...`

## 구현 계획

1. `MissionStatusClient.tsx` 전면 개편:
   - 랭킹 타입: `Podium` 컴포넌트(상위 3명) + `RankingList` 컴포넌트(4위~) + `MyRankCard` 컴포넌트
   - 프로그레스 바 너비: 1위의 progressValue를 100%로 삼아 상대적 비율 계산
   - 나의 순위 카드: 목록 끝에 고정 노출 (entries에 이미 포함된 경우 중복 방지)
2. `page.tsx`: 목표값 표시를 위해 mission 조건값 추가 조회 검토
