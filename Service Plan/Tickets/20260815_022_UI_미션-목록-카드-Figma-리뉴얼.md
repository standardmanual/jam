# [UI] 미션 목록 카드 Figma 리뉴얼

## 배경 / 문제 정의
기존 미션 목록(`/missions`) 페이지의 미션 카드는 `Card` 컴포넌트 기반의 가로형 이미지 + 텍스트 레이아웃이다.
Figma 스펙(`mission-item-1`)을 기반으로 썸네일 + 텍스트 영역(메타배지·제목·설명·보상)의 수평 카드로 전면 리뉴얼한다.

## 상세 요구사항

### Figma `mission-item-1` 스펙

카드 전체: `flex-row`, `padding: 8px 0`, `gap: 16px`

**thumbnail** (90×90px)
- 배경: `#1A1A1A`, `border-radius: 12px`
- 이미지 없을 때: 흰색 플레이스홀더

**text-area** (flex 1, flex-col, gap 8px)
- **meta-row** (flex-row wrap, gap: 6px 8px)
  - `badge/new`: pill, 배경 `#E8461F`, "NEW" 10px bold 흰색 — 7일 이내 신규 미션에만
  - `badge/status`: pill, 배경 `#1A1A1A`, 테두리 `#2A2A2A`, 참가 상태 텍스트 10px `#B2B2B2`
    - 상태 텍스트: "참가중" (joined & !done) | "완료" (done) | "시작전" (!started) — 미표시 상태도 있음
  - 기간 텍스트: 11px `#B2B2B2` ("상시" or "N일 N시간 남음" or "종료됨")
- **title**: 16px bold, `#FFFFFF`
- **desc**: 12px / line-height 17px, `#B2B2B2`, 2줄 클램프
- **reward**: 11px, `#E8461F` (보상 요약 텍스트)

### 구현 범위

- **파일:** `jam-web/src/app/(main)/missions/MissionsListClient.tsx`
- 기존 `Card` + 가로 이미지 블록 제거 → 인라인 스타일로 Figma 카드 레이아웃 구현
- 기존 기능 유지: 탭(진행중/참가중/종료), 정렬, 필터(활동종류·미션타입), `isNewMission`, `rewardSummary`
- 기존 상태 뱃지 문자열은 기존 i18n 키(`tagJoined`, `tagDone`, `tagUpcoming`, `tagPermanent`, `tagEnded`) 재사용
- `badge/status` 위치: 뱃지(참가중/완료/시작전)가 있는 미션에만 노출
- 카드 전체를 `Link`로 래핑 유지
- 색상 상수는 함수 외부에서 `const`로 선언

### 미채택 대안
- 기존 Card 컴포넌트 수정 방안 — 컴포넌트가 범용으로 쓰여 직접 수정이 사이드이펙트 유발, 인라인 레이아웃으로 대체
- next/Image 사용 — `<img>` 직접 사용 (외부 도메인 설정 불필요)
