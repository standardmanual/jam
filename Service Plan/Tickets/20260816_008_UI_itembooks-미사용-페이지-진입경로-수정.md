# [UI] /itembooks 미사용 페이지 진입 차단 및 뒤로가기 경로 수정

## 배경 / 문제 정의

- `/itembooks` 페이지(컬렉션 목록)는 메인 내비게이션 어디에도 연결되지 않은 미사용 페이지
- `/itembooks/[id]`의 `backHref` 기본값이 `'/itembooks'`로 설정되어 있어, `from` 파라미터 없이 진입 시 뒤로가기가 미사용 페이지로 이동함
- 아이템배지 상세(`/badges/[id]`) → 뒤로 → `/itembooks/[id]` → 뒤로 → `/itembooks` (미사용) 로 끝남

## 구현 내용

1. `/itembooks/[id]/page.tsx`: `backHref` 기본값 `'/itembooks'` → `'/badges#itembook'`
2. `/itembooks/page.tsx`: 전체를 `redirect('/badges#itembook')`으로 교체
