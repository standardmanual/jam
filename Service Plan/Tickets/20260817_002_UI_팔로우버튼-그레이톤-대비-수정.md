# [UI] 팔로우 버튼(팔로잉 상태) 카드 배경과 겹쳐 안 보이는 문제 수정

## 배경 / 문제 정의
프로필 통계탭(배지/컬렉션/팔로워/팔로잉) 목록에서 이미 팔로우 중인 유저의 "팔로잉" 버튼이
`ListRowCard`(다크 배경, `--color-surface-elevated`) 위에서 전혀 보이지 않았다.
`/[username]/followers`, `/[username]/following` 페이지의 공용 `FollowButton` 컴포넌트도
동일 패턴(같은 `ListRowCard` + 같은 버튼 스타일)이라 동일하게 문제가 있었다.

## 원인
`Button`의 `surface="sub"` + `variant="outline"`은 `bg-black/[0.04]`(라이트 카드 전용 4% 블랙 틴트)로
채워지도록 설계돼 있는데, 두 호출부(`ProfileClient.tsx`의 리스트 팔로우 버튼, `FollowButton.tsx`)
모두 실제로는 **다크** `ListRowCard` 위에 놓이면서 `surface="sub"`를 그대로 썼다. 4% 블랙 틴트가
이미 어두운 카드 배경 위에서는 사실상 투명해 보이고, 텍스트 색(`text-text-inverse`=검정)도 어두운
배경과 거의 같은 톤이 되어 버튼 자체가 안 보였다.

`surface` prop을 "main"으로 바꾸는 방식은 채택하지 않았다 — `primary`(팔로우 미완료) 상태의 배경색까지
함께 바뀌어(레드 → 화이트) 의도하지 않은 색상 변경이 생기기 때문. 대신 아웃라인 상태에만 배경을
오버라이드했다.

## 수정 내용
- `jam-web/src/app/globals.css`: 신규 토큰 `--color-chip-gray: rgba(255, 255, 255, 0.12)` 추가.
  절대 hex가 아닌 흰색 오버레이라 부모 카드 톤이 무엇이든(surface/surface-elevated/bg-tint 등)
  항상 밝게 도드라진다.
- `jam-web/src/app/(main)/profile/ProfileClient.tsx`: 리스트 팔로우 버튼의 outline(팔로잉) 상태에
  `style={{ backgroundColor: 'var(--color-chip-gray)', color: 'var(--color-text)' }}` 오버라이드 적용.
- `jam-web/src/app/(main)/[username]/FollowButton.tsx`: 동일 패턴으로 outline(팔로잉) 상태 오버라이드.
