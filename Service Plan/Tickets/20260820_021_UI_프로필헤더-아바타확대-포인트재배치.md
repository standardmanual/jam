# [UI] 프로필 헤더 — 아바타 확대·편집버튼 축소·아이디 전체노출·포인트 재배치

## 배경 / 문제 정의
사용자가 프로필 화면 스크린샷을 첨부해 헤더 영역(아바타 + 편집 아이콘 + 아이디 + 잼포인트)
레이아웃 조정을 요청했다. 티켓 20260820_019로 개편된 현재 레이아웃
([ProfileClient.tsx](../../../../jam-web/src/app/(main)/profile/ProfileClient.tsx) L439~503)
기준 아래 4가지를 조정한다.

## 상세 요구사항

### UI/UX 관점
1. 프로필 아바타 크기를 키운다 (기존 64px `w-16 h-16` → 확대)
2. 편집 펜 아이콘 버튼 크기를 절반으로 줄인다 (기존 44px `w-11 h-11` → 절반)
3. 유저 아이디를 더 이상 `truncate`(말줄임표) 처리하지 않는다 — 전체 노출
4. 잼포인트 표시를 아이디 아래로 이동하고, 크기를 기존의 약 절반으로 줄인다

## UI 탐색·재사용 판정
기존 컴포넌트(`Image`, `PencilIcon`, `ChevronRightIcon`)와 서비스 자체 토큰(`--text-heading`,
`--text-subheading` 등, `globals.css`)만으로 해결 가능 — 신규 MODULAR 컴포넌트 불필요.
`--text-subheading`(24px)이 기존 `--text-heading`(44px)의 약 절반에 해당하는 기존 정의 토큰이라
포인트 텍스트 축소에 그대로 사용.

## 구현 계획
1. 아바타: `w-16 h-16`(64px) → `w-24 h-24`(96px), `Image` width/height prop도 동일하게 조정,
   플레이스홀더 아이콘도 비례 확대(`w-7 h-7` → `w-10 h-10`)
2. 편집 버튼: `w-11 h-11`(44px) → `w-[22px] h-[22px]`(22px, 정확히 절반), 내부 아이콘도 비례 축소
3. 아이디: `truncate` 클래스 제거, `break-words`로 교체(줄바꿈 허용)
4. 포인트: 아바타 우측 가로 배치(기존)에서 아이디 하단 세로 배치로 이동, 텍스트 크기
   `--text-heading`(44px) → `--text-subheading`(24px, 약 절반), 체브런 아이콘도 비례 축소
5. 팔로우 버튼(타인 프로필)은 레이아웃 영향 없이 그대로 유지
