# [UI] "아이템북" 표기 전수 제거 → "컬렉션" 통일 + 공개 URL /collections 전환

## 배경 / 문제 정의

2026-08-15 의사결정([20260815_005](20260815_005_UI_아이템북-컬렉션-용어-통일.md))으로 사용자 노출
용어를 "컬렉션"으로 통일하기로 확정했으나 "디자인 리뉴얼 후 적용" 조건부로 미착수 상태였다.
그 사이 일부 화면은 "컬렉션"으로 바뀌었지만, 서비스 도메인·소스코드 주석·Service Plan 문서 전반에
"아이템북"/"itembook" 표기 또는 "컬렉션(아이템북)" 병기가 다수 잔존했다.

**사용자 확인 사항 (2026-08-21, 오케스트레이터가 세 차례 질문으로 범위 확정):**
1. 내부 코드 식별자(DB 테이블/컬럼명, API 라우트 내부 경로, 컴포넌트/파일명, 스토리지 폴더명)는
   2026-08-15 결정대로 **그대로 유지**한다 (breaking change 방지).
2. 단, **공개 URL만 예외적으로 전환**한다: `/itembooks/[id]` → `/collections/[id]`,
   `/[username]/itembooks` → `/[username]/collections`. 이미 공유된 링크 보호를 위해
   기존 경로에서 새 경로로 **301(308) 리다이렉트**를 추가한다.
3. 관리자 전용 화면(`/admin/itembooks`)은 공개 URL이 아니므로 대상에서 제외한다.

## 상세 요구사항

### 서비스/코드베이스 관점 — 변경 대상
- 사용자에게 노출되는 모든 UI 텍스트에서 "아이템북"을 "컬렉션"으로 교체, "컬렉션(아이템북)" 병기 제거
- 공개 라우트 디렉토리 변경: `(main)/itembooks/**` → `(main)/collections/**`,
  `(main)/[username]/itembooks/**` → `(main)/[username]/collections/**`
- 위 라우트를 참조하는 모든 내부 링크 갱신
- `next.config`에 구 경로 → 신 경로 301 리다이렉트 추가 (`/admin`, `/api`와 충돌 방지)

### 서비스/코드베이스 관점 — 변경 제외 대상 (그대로 유지)
- DB 테이블/컬럼명, API 라우트 내부 경로, `ItemBook*` 컴포넌트/파일명, 스토리지 폴더 경로
- 관리자 화면(`/admin/itembooks/**`)과 그 안의 기술적 식별자 노출
- 순수 코드 주석(비노출)은 일괄 변경 강제하지 않음

### 컨텐츠 관점
- PRD/Content/BadgeEngine/UX 가이드라인 등 **현재 유효한 문서**에서 "아이템북" 표기를 "컬렉션"으로 갱신
- **과거 CLOSED 티켓의 완료 기록, 날짜가 명시된 변경이력(changelog) 문단은 원문 그대로 보존**
