# [UI] 홈 화면 — 스트라바 연동 후 상태 카드 제거 (미연동 안내 카드는 유지)

## 배경 / 문제 정의

티켓 20260824_010에서 홈 카드의 동기화 버튼/연결하기 링크는 제거했지만, 카드 자체는
"연동 상태를 보여주는 정보 표시"로 두 상태(연동/미연동) 모두 남겨뒀다. 이제 Topnavi
중앙 슬롯에 동기화 버튼이 상시 노출되므로, 연동 후 상태를 보여주던 카드(마지막 동기화
시각 표시)는 중복이라 제거하고, 최초 가입 시 노출되는 미연동 안내 카드(연동 유도 목적)만
남긴다 — 사용자 확인 완료.

## 상세 요구사항

### 서비스/코드베이스 관점
- `src/app/(main)/page.tsx`의 Strava 상태 카드 조건부 렌더링에서 `stravaConnection`
  참일 때의 카드(마지막 동기화 시각 표시) 블록을 제거.
- `!stravaConnection`일 때의 미연동 안내 카드(`d.today.stravaNotConnectedTitle`/
  `stravaNotConnectedBody`)는 그대로 유지.
- 더 이상 쓰이지 않는 `ActivityIcon` import 제거.

## 구현 계획
1. `page.tsx`에서 `stravaConnection ? (...) : (...)` 삼항 분기를 `!stravaConnection && (...)`로 단순화
2. 미사용 import 정리
3. 로컬 dev 서버에서 미연동 계정으로 카드 유지 확인(연동 계정 카드 미노출은 코드 리뷰로 확인 — 연동 테스트 계정 부재)
