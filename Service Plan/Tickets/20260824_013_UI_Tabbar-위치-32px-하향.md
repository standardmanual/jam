# [UI] Tabbar 위치 32px 하향 조정

## 배경 / 문제 정의

플로팅 캡슐 Tabbar가 화면 하단에서 너무 떠 있다는 사용자 피드백 — 32px 더 아래로
내려달라는 요청.

## 상세 요구사항

### 서비스/코드베이스 관점
- 기존 `bottom: calc(safe-area-inset-bottom + 16px)` 공식에서 32px을 뺀다.
- safe-area가 0인 기기(대부분 Android, 노치 없는 구형 iPhone)에서 결과가 음수(-16px)가
  되면 화면 밖으로 일부 잘려 보이므로 **0px로 clamp**한다: `max(0px, calc(safe-area +
  16px - 32px))`.
- DS `design-system/components/navigation/TabBar.jsx`와 서비스
  `src/components/ui/TabBar.tsx` 양쪽 모두 동일 공식으로 수정(병존 구현, 함께 고쳐야
  스토리북과 서비스 화면이 어긋나지 않음).

## 구현 계획
1. DS `TabBar.jsx`의 `bottom` 계산식 수정
2. 서비스 `TabBar.tsx`의 `bottom` 계산식을 동일 공식으로 수정
3. 로컬 dev 서버에서 화면 밖으로 잘리지 않고 하단에 안착하는지 확인

---
## 완료 기록

### 구현 내용 요약
두 파일의 `bottom` 값을 `max(0px, calc(<safe-area> + 16px - 32px))`로 수정. safe-area가
0인 로컬 브라우저 환경에서 정확히 0px(화면 최하단에 붙음, 클리핑 없음)으로 렌더링되는
것을 확인했다.
