# [UI] Tabbar 최소 여백 10px로 복구 (0px clamp 과교정 수정)

## 배경 / 문제 정의

티켓 20260824_013에서 Tabbar를 32px 내리면서 safe-area 0 기기의 화면 밖 클리핑을
막기 위해 `max(0px, ...)`로 clamp했는데, 그 결과 safe-area가 0인 기기(로컬 브라우저
포함 대부분 Android·구형 iPhone)에서 Tabbar가 페이지 하단에 완전히 붙어버려 기존에
있던 여백이 사라졌다. 사용자 요청: 최소 10px은 떨어지도록 복구.

## 상세 요구사항

### 서비스/코드베이스 관점
- DS `TabBar.jsx`와 서비스 `TabBar.tsx` 양쪽의 clamp 하한을 `0px` → `10px`로 변경:
  `max(10px, calc(safe-area + 16px - 32px))`.
- safe-area가 큰 기기(iPhone 노치 등, 34px 등)에서는 여전히 `34+16-32=18px`로
  clamp에 걸리지 않아 영향 없음 — 이번 변경은 safe-area가 작은 기기에서만 체감됨.

## 구현 계획
1. DS `TabBar.jsx`의 clamp 하한 10px로 변경
2. 서비스 `TabBar.tsx`의 clamp 하한 10px로 변경(동일 공식 유지)
3. 로컬 dev 서버(safe-area=0)에서 하단에 완전히 붙지 않고 여백이 보이는지 확인

### 구현 내용 요약
두 파일의 clamp 하한을 `0px`에서 `10px`로 변경. 로컬 브라우저(safe-area=0)에서
Tabbar가 화면 최하단에서 10px 띄워져 렌더링되는 것을 확인했다.
