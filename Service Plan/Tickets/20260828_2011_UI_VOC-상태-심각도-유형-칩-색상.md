# [UI] VOC 카드 상태·심각도·유형 칩 색상 지정

## 배경 / 문제 정의

티켓 20260828_1921에서 만든 VOC 카드의 상태/심각도/카테고리 칩이 전부 동일한 회색
톤(`bg-surface`)이라 구분이 안 됐다. 사용자가 상태값별 의미 색상과 심각도 강조를
요청함. 1파일·수 줄 스타일 변경으로 파이프라인 없이 직접 처리(경미 수정).

## 상세 요구사항

- 상태 칩(문의중/확인중/답변완료) — 값별로 다른 배경색:
  - 문의중: 밝은 레드
  - 확인중: 밝은 블루
  - 답변완료: 밝은 그린
- 심각도 값: 숫자 부분만 볼드 + 포인트(강조) 컬러
- 유형(카테고리) 칩: 밝은 그레이

## 구현 계획

`jam-web/src/app/(main)/voc/page.tsx`의 `VocCard` 칩 렌더링부만 수정.

## 완료 기록

### 구현 내용 요약
- `STATUS_CHIP_CLASS` 맵 추가 — 문의중=`#ff6b6b`+어두운 텍스트, 확인중=`#4dabf7`+어두운
  텍스트, 답변완료=기존 `--color-rarity-rare`(#00cc7a)/`--color-rarity-rare-text` 토큰
  재사용(신규 색상 도입 최소화).
- 심각도는 `d.voc.severityLabel`("심각도 {severity}/5") 템플릿을 숫자 기준으로 분리해
  숫자만 `<strong>` + `text-[color:var(--color-primary)]`로 강조(FeedSection.tsx의
  `eventCheckinRepeat` 분할 패턴과 동일 기법 재사용).
- 유형(카테고리) 칩은 `--color-base-grey-200`(밝은 그레이, 기존 토큰) 배경 + 어두운
  텍스트로 분리(`CATEGORY_CHIP_CLASS`).
- 사용되지 않게 된 `t` i18n 헬퍼 import 제거.

### 주요 의사결정 / 핵심 메모
> 답변완료 색상은 새 색을 만들지 않고 기존 `--color-rarity-rare` 토큰(뱃지 희귀도 green)을
> 재사용했다. 빨강/파랑은 디자인 시스템에 대응 토큰이 없어(레드는 `--color-primary`와
> 겹치는 톤이라 심각도 강조색과 분리하기 위해) VOC 페이지 로컬 값으로 최소 도입했다 —
> 전역 토큰 승격은 다른 화면에서 같은 색이 필요해질 때 판단.
