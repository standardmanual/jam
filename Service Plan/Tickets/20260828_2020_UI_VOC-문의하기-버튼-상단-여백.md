# [UI] VOC 문의하기 버튼 상단 여백 50px 추가

## 배경 / 문제 정의

`/voc` 페이지 콘텐츠 영역이 TopNav 바로 아래 여백 없이 시작해 답답해 보인다는 피드백.
1줄 스타일 변경으로 파이프라인 없이 직접 처리(경미 수정).

## 구현 계획

`jam-web/src/app/(main)/voc/page.tsx` 콘텐츠 wrapper의 `pt-0`을 `pt-[50px]`로 변경.
