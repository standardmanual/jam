# [UI] VOC 카드 번호 위치·유형 줄바꿈, 정렬 탭 라벨 조정

## 배경 / 문제 정의

사용자 육안 확인 후 나온 소규모 UI 조정 3건. 파이프라인 없이 직접 처리(경미 수정).

## 상세 요구사항

- `#N` 번호를 카드 우측(trailing)이 아닌 좌측 첫 컬럼(icon 슬롯)으로 이동
- 유형(카테고리) 칩을 상태/심각도/날짜 행과 분리해 별도 줄로 줄바꿈
- 정렬 탭 라벨: "최신글 순"→"최신글", "최신 답변 순"→"최신 답변"

## 구현 계획

`jam-web/src/app/(main)/voc/page.tsx`(`VocCard`), `jam-web/src/lib/i18n/ko.ts`(`voc.sortLatest`/`sortAnswered`) 수정.
