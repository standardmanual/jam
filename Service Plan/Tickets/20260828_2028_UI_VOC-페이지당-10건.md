# [UI] VOC 페이지네이션 단위를 10건으로 변경

## 배경 / 문제 정의

`/api/voc`의 `PAGE_SIZE`가 20이라 현재 시트 데이터(18건)로는 항상 1페이지에 다 들어가
페이지네이션 UI가 실제로 노출/동작하는 걸 볼 수 없었다. 10건 단위로 낮춰달라는 요청.
1줄 상수 변경으로 파이프라인 없이 직접 처리(경미 수정).

## 구현 계획

`jam-web/src/app/api/voc/route.ts`의 `PAGE_SIZE = 20` → `10`.
