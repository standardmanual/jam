# [UI] 드랍 지도 POI 배지 마커 — 서클 제거, 배지 이미지 그대로 노출

## 요청 원문
드랍 페이지에서 지도 위에 노출되는 POI 배지 이미지를 서클 안에 넣지 않고 배지 이미지
그대로 보여줌. 크기는 현재 서클의 크기에 맞춤.

## 처리 방식
1파일·수 줄·로직 무변경(줌 배율·클릭 이벤트·데이터 흐름 불변, 마크업 스타일만 조정)에
해당해 파이프라인 없이 오케스트레이터가 직접 처리.

## 변경 내용
`jam-web/src/components/map/MapView.tsx`의 `badgeMarkerIconHtml()` — 흰 배경·테두리·
그림자·`overflow:hidden`으로 구성된 원형 래퍼(`circle`)를 제거하고, 배지 이미지를
기존 서클과 동일한 `size`(줌 배율에 따라 가변) 크기의 투명 박스에 `object-fit:contain`으로
직접 렌더링. 미획득 배지의 grayscale 필터·투명도, POI 이름 라벨, 클러스터 마커는 변경 없음.
