# [UI] 프로필 화면 TopNav 하단 여백 추가

## 배경 / 문제 정의
사용자가 타인의 프로필 방문 화면과 내 프로필 편집 화면 스크린샷을 첨부하며 "Topnavi 아래에
여백이 필요해"라고 지적. 두 화면 모두 컨텐츠 wrapper에 `pt-0`이 걸려 있어 TopNav 바로 아래에
프로필 헤더/사진이 붙어 있었다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/(main)/profile/ProfileClient.tsx` — 타인 프로필(`isOwnProfile=false`) 경로의
  컨텐츠 wrapper가 `pt-0`이던 것을, 본인 프로필 경로가 이미 쓰던 `pt-[var(--spacing-24)]`로 통일
- `jam-web/src/app/(main)/profile/edit/page.tsx` — 컨텐츠 wrapper `pt-0` → `pt-[var(--spacing-24)]`

## 구현 계획
경미 수정(2파일·각 1~2줄, 로직 무변경)으로 판단해 `/jam-work` 파이프라인 없이 오케스트레이터가
직접 처리. 신규 스타일값 하드코딩 없이 코드베이스에 이미 있는 `--spacing-24` 토큰과, 본인
프로필 경로가 쓰던 기존 패턴을 그대로 재사용.

---
## 완료 기록

  분기를 제거하고 `pt-[var(--spacing-24)]`로 통일 (본인/타인 프로필 모두 동일 여백).
