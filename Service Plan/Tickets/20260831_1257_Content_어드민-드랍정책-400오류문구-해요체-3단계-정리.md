# [Content] 어드민 드랍 정책 API의 400 오류 문구 3종을 해요체 3단계로 정리

## 배경 / 문제 정의

`jam-web/src/app/api/admin/drop-policy/route.ts`의 400(입력 검증 실패) 응답 문구 3종이
옛 문체(합니다체·1단계 통보)로 남아 있다. 같은 파일의 500 문구만 티켓 20260831_1118에서
해요체 3단계로 갱신돼, **한 파일 안에서 톤이 갈린다.**

현재 상태 (커밋 `6214ebeb` 기준):

| 위치 | 현재 문구 |
|---|---|
| `route.ts:26` | `` `${key}: 0 이상의 숫자여야 합니다.` `` |
| `route.ts:38` | `` `rarity 분포 합이 1이어야 합니다. (현재 ${raritySum.toFixed(3)})` `` |
| `route.ts:47` | `` `모멘텀+인접+탐험 합이 1 이하여야 합니다. (현재 ${bucketSum.toFixed(3)})` `` |

이미 갱신된 같은 파일 500 문구 (`route.ts:59`):
> 드랍 정책이 저장되지 않았어요. 데이터베이스가 요청을 거부했어요. 다시 시도해도 같으면
> 괄호 안 오류 내용을 개발자에게 전달해 주세요. (…)

이 건은 티켓 20260831_1149의 "범위 밖 발견물" 3번에서 분리됐다.

## 상세 요구사항

### 컨텐츠 관점

- `Service Plan/Specs/UX_WRITING_GUIDELINE.md` §4 에러 대응 가이드라인의
  **[현상] → [원인] → [해결책]** 3단계 구조와 §2-1 해요체를 적용한다.
- **기준 형식은 `jam-web/src/app/api/admin/abusing/policy/route.ts`다.** 티켓 20260831_1149에서
  같은 계열 문구를 아래 형태로 정리했고 개선 리뷰에서 가이드 준수 판정을 받았다:
  > 어뷰징 정책이 저장되지 않았어요. {key} 값이 0 이상의 숫자가 아니에요. 값을 확인하고 다시 저장해 주세요.
- 현상 문구는 같은 파일 500과 맞춰 **"드랍 정책이 저장되지 않았어요."** 로 고정한다.

### 서비스/코드베이스 관점

- **코드 로직 변경 없음.** 문자열만 교체한다. 검증 조건·상태 코드·응답 형태를 건드리지 않는다.
- 어드민 전용 화면이므로 `{key}` 같은 코드 식별자를 문장에 노출하는 것은 허용 범위다
  (원인 특정 우선). **한글 라벨 매핑을 새로 만들지 않는다** — 필드가 늘 때마다 수동 등록해야
  하는 지점만 늘어난다.
- 합계 문구의 `(현재 0.000)` 실측값 표기는 원인 특정에 필요하므로 유지한다.

### UI/UX 관점

- 폼(`jam-web/src/app/admin/drop-policy/DropPolicyForm.tsx:104`)이 `json.error`를 읽어
  화면에 표시하는 구조는 이미 되어 있다. 폼 변경은 불필요하다.
- **위치 지시어를 쓸 경우 실제 렌더 구조와 맞는지 확인한다.** 티켓 20260831_1118에서
  "아래" → "괄호 안"으로 교정한 이력이 있다. 오류 문구는 저장 버튼 아래 단일 `<p>`로만
  렌더되므로(`DropPolicyForm.tsx:155-159`) 화면 위치를 가리키는 표현은 쓰지 않는다.

## 구현 계획

`route.ts`의 400 응답 3곳의 템플릿 문자열만 교체한다.

| 라인 | 변경 후 |
|---|---|
| 26 | 드랍 정책이 저장되지 않았어요. {key} 값이 0 이상의 숫자가 아니에요. 값을 확인하고 다시 저장해 주세요. |
| 38 | 드랍 정책이 저장되지 않았어요. rarity 분포 합이 1이 아니에요. (현재 …) 네 등급 값을 합이 1이 되게 맞추고 다시 저장해 주세요. |
| 47 | 드랍 정책이 저장되지 않았어요. 모멘텀·인접·탐험 가중치 합이 1을 넘었어요. (현재 …) 세 값을 합이 1 이하가 되게 맞추고 다시 저장해 주세요. |

문면은 구현 단계에서 가이드라인에 맞춰 최종 확정한다 — 위 표는 3단계 구조의 뼈대다.

영향 범위: `route.ts` 1개 파일. 호출부·테스트·DB 변경 없음.
