# [UI] 하단 탭바 — 활성 탭 배경 필 추가

## 배경 / 문제 정의

사용자가 참고 스크린샷과 함께 하단 탭바(`TabBar`) UI 수정을 요청했다:
1. 가로 길이를 줄이고 메뉴 간 간격을 줄일 것
2. 선택된 탭의 아이콘 배경에 참고 스크린샷과 같은 활성 상태 표시(배경 필)를 추가할 것

1차 구현에서 필 전체 폭을 `w-fit`(아이콘 5개 크기만큼만 감쌈)으로 좁혔으나, 사용자가 실제
화면을 보고 "너무 줄였다"며 **폭은 원래대로 복원하고 활성 배경 필만 유지**해달라고 요청해
최종적으로는 요구사항 2번만 반영됐다.

## 상세 요구사항 (최종)

- 탭바 전체 폭·탭 간 간격은 기존 그대로 유지(`w-[calc(100%-42px)] max-w-[388px]`,
  `justify-between`, 탭별 `flex-1`).
- 활성(선택된) 탭의 아이콘 뒤에 44×44px 크기의 반투명 흰색(`rgba(255,255,255,0.9)`) 둥근
  사각형 배경을 추가한다. 기존 필 배경(`--color-chrome-bg-inverse`,
  `rgba(255,255,255,0.72)`)보다 더 불투명해 겹쳐도 구분된다.
- 모서리 반경은 기존 버튼 반경 토큰(`--radius-nav-buttons`) 재사용 — 새 값 도입 없음.
- 아이콘 색(`--color-primary`/`--color-icon-inactive`)·활성 점(`TabActiveDot`) 로직은
  변경 없음 — 배경 필만 추가.

## 구현 계획

1. `jam-web/src/components/ui/TabBar.tsx`(서비스 실사용): 각 탭 `Link` 안에 활성일 때만
   렌더링되는 배경 `<span>` 추가, 아이콘 크기(44px)에 맞춰 중앙 정렬.
2. `jam-web/design-system/components/navigation/TabBar.jsx`(MODULAR, 병존 구현) — 서비스와
   동일하게 배경 필 추가해 두 구현을 동기화.
3. 로컬에서 여러 탭(투데이/배지)을 오가며 배경 필이 정상적으로 활성 탭에만 나타나는지,
   전체 폭·간격이 기존과 동일한지 스크린샷으로 확인.

### 주요 의사결정 / 핵심 메모
- 활성 배경 필은 `inset-0`이 아니라 44×44 고정 크기 + 절대중앙정렬로 구현했다 — 탭이
  `flex-1`(가변 폭)이라 `inset-0`을 쓰면 필이 탭 폭만큼 넓어져 아이콘 대비 지나치게 커지고,
  탭 높이도 바 전체 높이(`h-full`, 64px)라 `inset-0`이면 필이 세로로도 과하게 길어진다.
  고정 44px 정사각을 중앙 정렬해 참고 스크린샷의 "아이콘 크기만큼만 감싸는" 느낌을 재현했다.
- MODULAR(`design-system/`)과 서비스(`src/components/ui/`) 두 구현을 함께 고쳤다 —
  `TabBar`는 jam-work 문서 기준 "병존 구현"(서비스·DS 별도 유지) 부류라 한쪽만 고치면
  Storybook과 실제 서비스가 갈린다.

### 추가 수정 (2026-09-01, 같은 날 후속 요청)
사용자가 실화면을 보고 "활성 배경이 서클(원)이 아니라 스크린샷 같은 형태여야 한다"고
지적했다. 원인: `--radius-nav-buttons`가 실제로는 `--radius-pill`(9999px)의 별칭이라,
44×44 정사각 배경에 적용하면 완전한 원이 됐다. 참고 스크린샷은 모서리만 둥근 사각형이라
`--radius-card`(16px, 카드 표면용 토큰)로 교체 — 새 값을 만들지 않고 기존 토큰 재사용.
서비스·MODULAR 양쪽 파일 모두 동일하게 수정. 로컬 스크린샷으로 사각형 형태 확인.

### 추가 수정 2 (2026-09-01, 같은 날 재차 요청)
사용자가 스크린샷을 다시 짚으며 "정사각형이 아니라 양옆은 완전히 둥글고 위아래는 직선인
캡슐(스타디움) 모양"이라고 정정했다. 44×44(또는 16px 라운드) 정사각형이 아니라, **높이보다
폭을 넓게 잡고 `rounded-full`/`--radius-pill`을 적용**하는 방식으로 교체 —
정사각형에 pill 반경을 주면 완전한 원이 되지만, 가로가 더 긴 사각형에 pill 반경을 주면
반경이 짧은 변(높이)에 의해 자연히 클램프되어 "양옆 반원 + 위아래 직선" 캡슐 모양이
정확히 나온다. 최종 크기: 64×48px(서비스는 Tailwind `w-16 h-12 rounded-full`, MODULAR는
`width:64,height:48,borderRadius:'var(--radius-pill)'`). 로컬 스크린샷으로 캡슐 형태 확인.

### 추가 수정 3 (2026-09-01, 같은 날 재차 요청)
사용자가 "활성 배경 색을 화이트가 아니라 투명한 그레이로"라고 요청. 기존
`rgba(255,255,255,0.9)`(거의 불투명한 흰색)를 `rgba(0,0,0,0.08)`(반투명 검정 8%)로
교체 — 이미 흰색 반투명 크롬(`--color-chrome-bg-inverse`) 위에 얹는 형태라, 검정을 살짝
얹으면 참고 스크린샷처럼 "회색 톤"으로 보인다(새 그레이 색상 토큰을 만들지 않고 기존
반투명 오버레이 관용구를 재사용). 서비스·MODULAR 양쪽 동기화, 로컬 스크린샷으로 확인.
