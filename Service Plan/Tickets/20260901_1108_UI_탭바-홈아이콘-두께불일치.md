# [UI] 하단 탭바 — 홈 아이콘 선 두께 불일치

## 배경 / 문제 정의

사용자가 하단 탭바에서 "투데이"(홈) 아이콘만 다른 4개 아이콘·비활성 상태 대비 선이 얇아
보인다고 지적했다.

**원인**: 티켓 `20260827_026`에서 배지/드랍/미션/인벤토리 4개 아이콘은 Material Symbols
아이콘 세트(`viewBox="0 -960 960 960"`)로 교체됐으나, 투데이(홈) 아이콘만 "이번 교체
대상이 아니다"라는 이유로 예전 커스텀 24×24 좌표계 path를 그대로 유지했다
(`TabBar.tsx`/`TabBar.jsx` 주석에 명시). Material Symbols는 일관된 선 굵기로 설계된
아이콘 세트라, 손으로 그린 예전 path보다 시각적으로 더 두꺼워 두 세트가 섞이면서 홈만
얇아 보이는 불일치가 생겼다.

## 상세 요구사항

- 홈 아이콘(fill/line 두 상태 모두)을 나머지 4개와 동일한 Material Symbols "home"
  아이콘으로 교체해 선 두께를 통일한다.
- 정확한 path 데이터는 Google Fonts Material Symbols 공식 SVG(`fonts.gstatic.com`)에서
  직접 가져와 임의로 그리지 않는다 — outlined(`home/default/24px.svg`)와
  filled(`home/fill1/24px.svg`) 두 변형 모두 확인 후 사용.
- `viewBox`도 나머지와 동일하게 `0 -960 960 960`으로 통일 — 기존에 있던 `t.key === 'today'`
  분기(DS `TabBar.jsx`)를 제거해 5개 탭이 같은 좌표계를 쓰도록 정리.
- 서비스(`src/components/ui/TabBar.tsx`)·MODULAR(`design-system/.../TabBar.jsx`) 병존
  구현 양쪽 모두 동일하게 수정.

## 구현 계획

1. Google Fonts Material Symbols API에서 "home" 아이콘의 outlined/filled 정확한 SVG
   path 데이터 확보.
2. `TabBar.tsx`·`TabBar.jsx`의 `today`(홈) 아이콘 fill/line path와 viewBox를 교체.
3. DS `TabBar.jsx`의 viewBox 탭별 분기 로직 제거(5탭 전부 동일 viewBox).
4. 로컬에서 홈 활성/비활성 상태를 스크린샷으로 확인해 다른 아이콘과 두께가 맞는지 검증.

## 완료 기록

### 구현 내용 요약
계획대로 구현. Material Symbols 공식 SVG 엔드포인트에서 정확한 path를 가져와 사용:
- outlined: `M240-200h120v-240h240v240h120v-360L480-740 240-560v360Zm-80 80v-480l320-240 320 240v480H520v-240h-80v240H160Zm320-350Z`
- filled: `M160-120v-480l320-240 320 240v480H560v-280H400v280H160Z`

두 파일 모두 `viewBox="0 -960 960 960"`으로 통일했고, DS `TabBar.jsx`의
`t.key === 'today' ? '0 0 24 24' : '0 -960 960 960'` 조건 분기를 제거해 5탭이 단일
viewBox를 쓰도록 정리했다.
