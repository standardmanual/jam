  (일일 누적 이동거리 GPS 조작 감지 상한 — 티켓

  참고)
- 어드민 폼(`AbusingPolicyForm` 등)에 해당 필드 입력 UI 추가

### UI/UX 관점 (해당 시)
- shadcn 어드민 디자인시스템(다른 어뷰징 정책 필드와 동일한 입력 컴포넌트) 사용

## 구현 계획
- 기존 `/admin/abusing` 폼의 다른 숫자 입력 필드(예: `soft_epic_rate` 등) 패턴을 그대로 따라
