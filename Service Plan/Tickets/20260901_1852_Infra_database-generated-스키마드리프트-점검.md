# [Infra] database.generated.ts 스키마 드리프트 점검·재생성

## 배경 / 문제 정의
티켓 [20260824_017](20260824_017_Infra_떠돌이신화-기능-전면제거.md)에서 발견:
`database.generated.ts`(Supabase 자동 생성 타입)가 실제 DB 스키마보다 뒤처져 있다.
이후 티켓 [20260831_1213](20260831_1213_Service_Supabase제네릭-생성타입전환-쓰기타입검사-복구.md)·
[20260831_1158](20260831_1158_Infra_수기타입-생성타입-불일치-전수점검.md)에서 관련 타입
불일치를 상당 부분 다뤘을 가능성이 있으므로, 이 티켓은 **먼저 현재 드리프트가 남아있는지
재확인**하고 남아있는 만큼만 처리한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- Supabase MCP `generate_typescript_types`(또는 CLI `supabase gen types`)로 최신 타입을
  생성해 현재 `database.generated.ts`와 diff
- 차이가 없으면(이미 1213/1158에서 해소됐다면) 티켓에 "재확인 결과 드리프트 없음"으로
  기록하고 종료
- 차이가 있으면 재생성 반영 + 그로 인해 컴파일 에러가 나는 호출부 수정

## 구현 계획
- diff 우선 확인 → 필요시에만 재생성 및 후속 타입 수정
