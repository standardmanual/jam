# [UI] 홈 진행도 카드 미션 링크가 상세 대신 목록으로 이동하던 오류 수정

## 배경 / 문제 정의
사용자가 "내 진행도" 카드의 노출 유형별 이동 정책을 명시함:
- 진행 중인 아이템북(컬렉션): 해당 컬렉션 상세 페이지로 이동
- 완성도 최고 미션 1건: 해당 미션 상세 페이지로 이동
- "드랍 아이템 찾아보기": 드랍 메뉴로 이동
- "미션 참가해보기": 미션 메뉴로 이동

코드 대조 결과 3개는 정책과 일치했으나(`/collections/{id}`, `/drops`, `/missions`),
**미션 진행도 카드만 `/missions`(목록)로 이동해 정책과 어긋남**을 발견 — 미션 상세 라우트는
`/missions/[id]`인데 `src/lib/today/status.ts:162`의 `missionCandidates()`가 항상 정적
문자열 `/missions`를 href로 반환하고 있었음.

## 상세 요구사항

### 서비스/코드베이스 관점
- `src/lib/today/status.ts`의 `missionCandidates()` — `href: '/missions'`를
  `href: \`/missions/${p.mission_id}\``로 수정해 미션 상세 페이지로 이동하게 함

## 구현 계획
1자리 문자열 리터럴 수정 — 로직 변경 없음, 경미 수정으로 파이프라인 없이 직접 처리.
