# [UI] 팔로잉 소식 카드에서 노출되는 팔로잉 프로필 이미지 제거

## 배경 / 문제 정의
사용자 요청: 홈 상단 "팔로잉 소식" 카드(`TodayStatusStrip` 우측 셀)에 노출되는 팔로잉 프로필
이미지(아바타 스택)를 제거.

## 상세 요구사항

### 서비스/코드베이스 관점
- `TodayStatusStrip.tsx`의 `RightCell` — `friend_activity` 분기에서 아바타 스택 마크업 제거,
  메시지 텍스트만 남김
- `src/lib/today/status.ts` — 더 이상 쓰이지 않는 `avatarUrls` 필드·조회 로직 정리
  (안 쓰는 코드 방치 금지 원칙)

## 구현 계획
1. `TodayStatusStrip.tsx`: 아바타 `<span>` 스택 마크업 제거, 미사용 `Image`/`UserIcon` import 정리
2. `status.ts`: `TodayRightStatus`의 `avatarUrls` 필드 제거, `FRIEND_AVATAR_MAX`(상위 3명 조회)
   로직 제거 — 아바타 미노출로 다인원 유저 정보 조회 자체가 불필요해짐. 단일 팔로잉(count===1)
   케이스의 `singleFriendName`/href 계산용 유저 조회만 남김(username·display_name만 select).

---
## 완료 기록

### 구현 내용 요약
- `TodayStatusStrip.tsx`: 아바타 스택(`-space-x-2` 원형 이미지/이니셜 아이콘) 마크업 제거,
  메시지 텍스트만 표시. 미사용된 `Image`(next/image)·`UserIcon` import 제거.
- `src/lib/today/status.ts`: `TodayRightStatus.friend_activity`에서 `avatarUrls` 필드 제거.
  기존에는 `FRIEND_AVATAR_MAX`(3명)만큼 유저를 조회해 `avatar_url`을 포함한 정보를 가져왔으나,
  이제 그 조회의 유일한 실사용처였던 `singleUser`(count===1일 때만 필요)만 남기고 다인원 조회
  로직·`avatar_url` select 컬럼·`FRIEND_AVATAR_MAX` 상수를 모두 제거해 불필요한 DB 조회도
  함께 줄임.
