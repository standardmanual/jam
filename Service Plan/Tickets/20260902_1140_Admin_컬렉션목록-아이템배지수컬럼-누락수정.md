# [Admin] 컬렉션 목록 "아이템 배지 수" 컬럼도 비활성화 시 0으로 사라지는 문제 추가 수정

## 배경 / 문제 정의
[20260902_1043](./20260902_1043_Admin_컬렉션비활성화-아이템배지목록노출버그수정.md)에서
컬렉션 수정 화면(`/admin/itembooks/[id]`)의 "배지 슬롯 관리" 목록만 고쳤는데, 사용자가 실제로
확인한 화면은 **컬렉션 목록 페이지(`/admin/itembooks`)의 "아이템 배지 수" 컬럼**이었다.
배포 후에도 "복구되지 않았다"는 피드백을 받고 확인한 결과, 이 컬럼도 동일한 원인
(`badges` 조회에 `.is('deleted_at', null)` 필터)으로 컬렉션이 비활성화되면 0으로 표시되고
있었다. 20260902_1043 티켓에서 "목록 페이지의 집계 숫자는 범위 밖(기존 동작이 잘못된 게
아님)"이라고 판단한 것이 실제 사용자 의도와 어긋난 스코핑 오류였다.

## 상세 요구사항
- `src/app/admin/itembooks/page.tsx`의 `itemBadgeCountMap` 조회에서
  `.is('deleted_at', null)` 필터를 제거한다 — 20260902_1043에서 `[id]/page.tsx`에 적용한
  것과 동일한 원칙(배정 관계가 남아있으면 활성/비활성 무관하게 노출).
- 컬렉션 상세 화면(`ItemBookDetail`)의 "소속 아이템배지" 숫자는 기존처럼 활성 배지 수만
  의미하도록 이미 별도 계산 중이므로 이번 수정과 무관(20260902_1043에서 이미 분리해둠).

## 구현 계획
- 1줄 필터 제거, 1개 파일만 영향. DB 마이그레이션 없음.
- 경미 수정으로 판단해 파이프라인 없이 오케스트레이터가 직접 처리(같은 로직 패턴이
  20260902_1043 게이트 리뷰에서 이미 PASS 판정을 받은 바 있음).
