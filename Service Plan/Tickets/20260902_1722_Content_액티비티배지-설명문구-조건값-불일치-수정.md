# [Content] 액티비티 배지 설명(description) 문구의 수치 ↔ 실제 조건값(condition_json) 불일치 14건 수정

## 배경 / 문제 정의
현재 생성된 액티비티 배지 전체 목록을 Supabase(`jam-prod`) `badges` 테이블에서 직접 조회해
마크다운으로 정리하던 중, `description`(화면 노출 문구)에 적힌 숫자와 `condition_json`(실제
발급 조건값)이 서로 다른 배지 14건을 발견했다.

`condition_json`은 배지엔진이 실제 판정에 쓰는 값이라 정상 동작하지만, 사용자에게 노출되는
설명 문구가 다른 숫자를 말하고 있어 오정보다. 예: 걷기 `루틴의 수호자` Rare는 조건값이
"주 5회"인데 설명 문구는 "주 4회 달성"으로 되어 있음.

이 중 러닝 `첫 숨결` Epic/Mystic 2건은 `Specs/Content/ACTIVITY_BADGES.md`에 이미 기록된 과거
경위가 있다 — 티켓 `20260813_001`에서 조건값을 60km/150km → 40km/100km로 낮췄고, 티켓
`20260825_028`(마이그레이션 `101_mission_gated_badge.sql`)에서 DB `condition_json`을 40/100으로
맞췄으나 **`description` 문구는 갱신하지 않아** "60km"/"150km" 문구가 잔류했다.
나머지 12건은 이번에 새로 발견됐다 — 과거 등급 난이도 조정 시 조건값만 올리고 설명 문구는
그대로 둔 것으로 추정된다(원인 불명, 재발 방지책은 잔여 이슈 참고).

## 상세 요구사항

- 배지 상세/도감 화면에서 해당 14개 배지의 노출 문구가 바뀌므로 실제 반영 확인 필요
