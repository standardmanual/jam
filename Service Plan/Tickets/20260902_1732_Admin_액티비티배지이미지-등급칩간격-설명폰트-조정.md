# [Admin] 액티비티 배지 이미지 — 등급칩 간격·설명 폰트 크기 조정

## 배경 / 문제 정의

티켓 [[20260902_1613]]로 배포한 `/admin/activity-badge-image`의 합성 결과를 사용자가 실제로
확인한 뒤 나온 시각 조정 요청 2건이다. 피그마 실측값을 그대로 구현했으나 실제 이미지에서
비율이 의도와 달랐다.

1. **등급 칩과 배지 이름이 붙어 보인다.** 피그마 node 8:28의 flex gap은 10이고 구현도 10이었으나,
   구운 이미지에서는 간격이 없어 보였다.
2. **설명 텍스트가 작다.** 피그마는 20px이었다.

## 상세 요구사항

| 항목 | 변경 전 | 변경 후 | 근거 |
|---|---|---|---|
| 등급칩 ↔ 이름 간격 (`NAME_GAP`) | 10 | **20** | 사용자 요청 "10px의 간격을 추가해" |
| 설명 폰트 (`CONDITION_FONT_SIZE`) | 20 | **30** | 사용자 요청 "설명 텍스트를 30px로 변경" |
| 설명 행간 (`CONDITION_LINE_HEIGHT`) | 30 | **36** | 사용자 요청 "행간을 1.2배로" (30 × 1.2) |

모든 값은 540 좌표계 기준이며 출력 배율 `S = size/540`이 그대로 적용된다(1080 출력에서 각각
40 / 60 / 72px). 자간(-0.8)은 피그마 값을 유지했다.

### 행간 결정 경위

폰트를 30으로 올리면 행간 30은 배수 1.0이 되어 여러 줄에서 한글이 겹친다. 처음에는 피그마의
1.5배 비율을 유지해 45로 잡았으나, 실렌더를 본 사용자가 **1.2배**로 지정해 36으로 확정했다.
피그마(1.5배)보다 촘촘하며, 이 값으로 장문 설명이 배지 이름을 침범하던 것도 함께 완화됐다.

### 피그마와 어긋나는 유일한 수치

이 세 값은 이제 **피그마 node 8:33 실측값과 다르다.** 나머지 치수(라운드 60/48, 노치 39.4737,
패딩 58, 이름 64px, 자간, 글래스 그라디언트 등)는 전부 실측값 그대로다. 코드 상수 주석에
이 티켓 번호와 함께 근거를 남겨, 나중에 "피그마와 왜 다르지"라는 질문이 다시 나오지 않게 했다.

### 주요 의사결정 / 핵심 메모

- **행간은 실렌더를 보고 두 번 조정했다.** 폰트만 30으로 올리면 행간 배수가 1.0이 되어 한글이
  겹치므로 우선 피그마 비율(1.5배 = 45)로 잡았고, 사용자가 결과를 본 뒤 1.2배(36)로 확정했다.
- **설명이 커지면서 줄 수가 늘어난다.** 같은 문구가 20px에서 2줄이던 것이 30px에서 3줄이 되고,
  설명 블록은 콘텐츠 프레임 하단에 붙는 양끝 정렬이라 **위로 자라 이름 쪽을 침범**할 수 있다.
  자동 축소를 하지 않는 것은 [[20260902_1613]]에서 사용자가 확정한 사항이므로, 넘치면 운영자가
  문구·줄바꿈을 수동으로 조절한다. 행간 45일 때는 장문 설명이 이름과 맞닿았고, 36으로 낮추면서
  같은 케이스에서 여백이 생겼다.

### 잔여 이슈
- 설명이 20px에서 30px로 커지면서 같은 문구의 줄 수가 늘어난다. 설명 블록은 콘텐츠 프레임
  하단에 붙는 양끝 정렬이라 줄이 늘면 위로 자라 이름 쪽으로 접근한다. 행간 36에서는 3줄까지
  여유가 있으나, 더 긴 설명에서는 여전히 겹칠 수 있다 — 자주 발생하면 콘텐츠 프레임 세로 배분
  규칙을 다시 볼 필요가 있다.
