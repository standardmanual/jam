# [Admin] 배지 상세 화면에 배경 테마·계열 키 표시 없음

> 어드민 배지 생성/수정/상세 화면 구성 점검(2026-09-06) 중 발견. 관련: `20260906_1420`·`20260906_1421`·`20260906_1422`·`20260906_1424`

## 배경 / 문제 정의

배지 생성/수정 화면(`jam-web/src/app/admin/badges/BadgeForm.tsx` +
`BadgeDetailPreviewFrame.tsx`)은 배경색·블롭 애니메이션을 정교하게 설정할 수 있고, 실제
상세화면과 동일한 컴포넌트 구조(TopNav→Hero→본문→Footer)로 라이브 미리보기까지 제공한다.

그런데 정작 저장 후 확인하는 **상세 화면(`jam-web/src/components/admin/badges/BadgeDetail.tsx`,
314줄 전체)에는 배경 테마 정보(`background_color`/`background_animation`)가 어디에도
표시되지 않는다.** 지금 이 배지에 배경색이 설정돼 있는지, 애니메이션이 켜져 있는지,
켜져 있다면 어떤 파라미터인지 확인하려면 **수정 화면을 열어야만** 알 수 있다.

`family_key`도 같은 문제다 — 수정 화면(`BadgeForm.tsx` 661-675행)엔 읽기전용으로 노출되고
"2단 교차 게이트가 이 키로 계열을 가리킨다"는 중요한 설명까지 붙어 있는데, 상세 화면엔
아예 항목이 없다. 다른 배지의 교차 게이트 조건이 이 배지의 계열을 참조하고 있는지 확인하려는
운영자가 상세 화면만 봐서는 이 배지의 `family_key`가 뭔지조차 알 수 없다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `BadgeDetail.tsx`에 아래 두 항목을 추가:
  1. **배경 테마** — `background_color`(hex 값 그대로, 또는 색상 스와치 + hex 텍스트)와
     `background_animation`(설정 여부 최소 표시, 있다면 어떤 파라미터인지는 구현자 판단 —
     상세 화면은 편집 화면이 아니므로 전체 파라미터를 다 늘어놓기보다 "애니메이션 적용됨"
     정도의 요약이면 충분할 수 있음). 미설정 시 "없음"으로 표시(다른 항목들과 동일한 규칙)
  2. **계열 키(family_key)** — 값이 있으면 그대로, 없으면 "— 없음 —"
- 완전한 라이브 미리보기(`BadgeDetailPreviewFrame`)까지 상세 화면에 넣을 필요는 없다 —
  이건 저작 도구 전용 기능이고, 상세 화면은 "지금 뭐가 저장돼 있는지 텍스트로 확인"이
  목적이므로 과하게 만들지 않는다(범위 밖 참고)

### UI/UX 관점 (해당 시)
- 기존 "기타 정보" 카드(포인트 보상·드랍 가중치·유효 기간이 있는 카드, `BadgeDetail.tsx`
  240-265행)에 이어서 넣는 것이 자연스러워 보이나, 배치는 구현자 판단
- UX Writing 가이드의 "없음" 표기 관례(다른 필드들이 이미 쓰고 있는 패턴)를 그대로 따를 것

### 컨텐츠 관점 (해당 시)
해당 없음.

## 구현 계획

1. `BadgeDetail.tsx`에 배경 테마·계열 키 표시 블록 추가
2. 배경색만 설정된 배지, 애니메이션이 설정된 배지, 둘 다 없는 배지 세 케이스로 상세 화면
   렌더링 확인
3. `family_key`가 있는 배지/없는 배지 각각 확인

### 범위 밖
- 상세 화면에 `BadgeDetailPreviewFrame` 수준의 실제 렌더링 미리보기를 넣는 것 — 텍스트/값
  표시로 충분하다고 판단. 필요성이 제기되면 별도 티켓으로
