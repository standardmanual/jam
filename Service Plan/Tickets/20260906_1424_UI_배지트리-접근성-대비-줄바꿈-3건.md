# [UI] 배지 트리 — 화면 정리 9건이 남긴 접근성·대비·줄바꿈 3건

> 선행: `20260906_1323`(배지 트리 화면 정리 9건). **세 건 모두 그 티켓이 새로 만든 결함**이고,
> 인터랙션 리뷰가 실측으로 잡아냈다. 사용자 확정(2026-09-06): 9건을 먼저 staging에 올리고
> 이 세 건은 별도 티켓으로 분리한다.
>
> 대상 화면: `/badges/tree` 하나.

## 배경 / 문제 정의

`20260906_1323`은 표시 층을 크게 손봤고 게이트 리뷰 PASS로 staging(`d1ca879e`)에 반영됐다.
다만 세 지점에서 **바꾸기 전보다 나빠졌다.** 셋 다 원인이 명확하고 수정 범위가 좁다.

### ① 레일 헤더 `aria-label`이 누적 횟수를 삼킨다 — 보조기술 정보 손실

`20260906_1323` §3이 「자세히」로 라벨을 바꾸면서, 계열 이름이 사라질까 봐 헤더 버튼에
`aria-label={`${familyName} 자세히`}`를 명시하도록 지시했다. **그 판단이 틀렸다.**

계열명(`BadgeStageRail.jsx` 344행 부근)도 `×N` 반복 칩(348~359행 부근)도 **버튼 안에** 있어서
내용 기반 이름 계산이 이미 둘 다 읽고 있었다. `aria-label`은 그 계산을 통째로 대체하므로:

| | 전 | 후 |
|---|---|---|
| 낭독 | 「동네 산책러 누적 3회 다음 Common」 | 「동네 산책러 자세히」 |

반복형 계열의 **누적 횟수가 보조기술에서 사라졌다.**

### ② 조건값 캡션의 대비가 AA 기준 미달

`BadgeStageRail.jsx` 524행 부근의 `opacity: 0.7`은 원래 정보가 없는 `'—'` 글리프에만 걸던
감쇠다. §7이 그 자리에 **실제 정보(획득 조건)** 를 넣으면서 조건값이 0.7로 그려진다.

인터랙션 리뷰 실측(합성 후 계산):

| 테마 | 계산 | 대비 | WCAG AA(11px = large text 아님, 4.5:1) |
|---|---|---|---|
| 다크 | `#b2b2b2 × 0.7` on `#1f1f1f` | 약 4.4:1 | 아슬아슬하게 미달 |
| 라이트 | `#666 × 0.7` on `#f5f4f0` | 약 2.9:1 | 크게 미달 |

### ③ 말줄임을 뺀 자리에 `overflow-wrap`이 없다 — 넘침 가능

§5가 `BadgeStampRow`·`BadgeLevelGauge`의 이름 줄에서 말줄임 3속성을 걷어내고
`wordBreak: 'keep-all'`만 남겼다. `keep-all`은 한글 어절 중간 끊김을 막는 대신
**공백 없는 긴 토큰의 비상 줄바꿈까지 막는다** — 그런 이름이 하나 들어오면
`minWidth: 0` 컬럼을 뚫고 넘친다. §5가 `title`도 함께 지워서 전체를 볼 방법도 없다.

같은 컴포넌트군에 이미 올바른 선례가 있다 — `BadgeStageRail.jsx` 341행 부근의 계열명은
`overflowWrap: 'anywhere'`를 쓴다.

## 상세 요구사항

### ① aria-label 제거 (또는 잃는 조각 없이 재조립)

- `BadgeStageRail`의 **헤더 버튼 `aria-label`을 지운다.** 지우면 내용 기반 이름 계산이
  복구돼 계열명 + `×N` + 「자세히」가 모두 읽힌다.
- 상태를 명시적으로 고정하고 싶다면 지우는 대신 조각을 빠짐없이 조립한다:
  `` `${familyName}, 누적 ${earnCount}회, 자세히` `` (`earnCount`가 null이면 그 조각 제외).
  **둘 중 어느 쪽을 택했는지와 근거를 완료 기록에 남길 것.**
- ⚠️ 눈금 그룹의 `summarySentence`(「{계열명}, N단계 중 M단계 획득. 다음 단계 {등급}」)는
  **건드리지 않는다.** 그건 헤더 버튼이 아니라 `role="group"`의 이름이고 정상 동작 중이다.
- 검증: 스토리에 `earnCount`가 있는 케이스를 두고, 접근성 이름에 「누적」이 포함되는지
  단언한다(스토리 play 단언이 이 환경에서 안 돌면 최소한 스토리는 남길 것).

### ② 조건값 캡션의 감쇠 해제

- `BadgeStageRail` 캡션의 `opacity: 0.7`을 **`showConditionText`일 때는 걸지 않는다.**
  색은 이미 `--color-text-secondary`라 충분히 물러나 있다.
- `0.7` 감쇠는 **정보가 없는 `'—'` 케이스에만** 남긴다(그 자리는 원래 「값 없음」 표기다).
- 지금 조건은 `!showProgress && stop.status === 'not-reached'`(캡션이 조건값)이므로,
  `opacity`를 `!showProgress && stop.status === 'not-reached' && !showConditionText ? 0.7 : 1`
  형태로 좁히면 된다. 실제 변수명은 구현 코드를 읽고 맞출 것.
- **다크·라이트 양쪽에서 4.5:1을 넘는지 확인하고 계산 값을 완료 기록에 적는다.**
  넘지 못하면 `--color-text-secondary` 대신 한 단계 진한 토큰을 쓴다 — 단,
  **토큰 값 자체를 바꾸지 않는다**(다른 화면이 물고 있다).

### ③ `overflow-wrap: anywhere` 추가

- `BadgeStampRow.jsx`·`BadgeLevelGauge.jsx`의 이름 `<span>`에
  `overflowWrap: 'anywhere'`를 `wordBreak: 'keep-all'`과 **함께** 지정한다.
  두 속성은 상충하지 않는다 — 평소엔 어절 단위로 끊고, 어절 하나가 컬럼보다 길 때만
  강제로 분리한다.
- 스토리에 **공백 없는 긴 이름** 케이스를 추가해 넘침 회귀를 잠근다.
- `title` 복원은 하지 않는다 — 이제 전체가 보이므로 정보 가치가 없다.

### 하지 않는 것

- 「자세히」 문구 자체 변경 (사용자가 확정한 문구다)
- 펼친 상태에서 「접기」로 바꾸기, 조건값 조각 수 축소, 요약 헤더 재배치, 획득 링 + 앰버 캡션
  충돌 등 **판단이 갈리는 개선안** — 인터랙션 리뷰가 함께 제안했지만 이 티켓 범위 밖이다
  (아래 「검토만 하고 넘긴 제안」 참고)
- `--color-text-secondary` 등 토큰 값 변경
- 발급 엔진·진행 계산 로직

### UI 재사용 판정 (오케스트레이터 결정)

**기존 컴포넌트 수정만. 신규 컴포넌트 없음.** 대상 3파일
(`BadgeStageRail.jsx`·`BadgeStampRow.jsx`·`BadgeLevelGauge.jsx`)은 `src/components/ui/`에
병존 구현이 없는 「연결된 컴포넌트」이고, 서비스 호출부는 `BadgeFamilyRow.tsx` 하나다.
`design-system/components/**`를 고치므로 대응 `*.stories.tsx`를 함께 갱신한다.

## 구현 계획

1. `BadgeStageRail.jsx` — ①(aria-label) + ②(opacity 조건 분기) + 주석 갱신
2. `BadgeStampRow.jsx` · `BadgeLevelGauge.jsx` — ③(`overflowWrap`)
3. 스토리 3종 갱신 — `earnCount` 접근성 이름 케이스 / 공백 없는 긴 이름 케이스
4. 검증: `npx tsc --noEmit` · `npm run lint` · `npx vitest run` · `npm run ds:check`
5. 대비 실측값(다크·라이트)을 완료 기록에 숫자로 남긴다

## 검토만 하고 넘긴 제안 (인터랙션 리뷰, 이번 범위 아님)

기록으로만 남긴다 — 채택 여부는 별도 판단이다.

- 펼친 상태에서 라벨을 「접기」로 바꾸거나, 글자를 빼고 셰브런만 남긴다
- 아코디언 본문 mount에 전이가 없어 셰브런만 움직인다(200ms `opacity` + `translateY` 제안)
- 진행 채움을 `width %` → `transform: scaleX()`로 바꿔 GPU 속성으로 전이 가능하게 한다
- `.ds-rail-header:active { opacity: 0.7 }`이 카드 전체를 흐려 「비활성」처럼 읽힌다
- 조건값이 모든 `not-reached` 눈금에 붙어 연결선이 14px까지 눌리고 「다음 할 일」 강조가 희석된다
  (조각 수를 1~2개로 줄이거나 앵커 아닌 눈금의 `maxWidth`를 낮추는 안)
- 요약 헤더의 「전체」를 그리드 밖 전폭 헤더로 올린다
- 전부 획득한 반복형 계열에서 획득 링 + 앰버 진행 캡션이 한 눈금에 동시에 그려진다
- `maxWidth: 92` 등 고정 px이 200% 텍스트 확대에 취약하다(`em` 단위 제안)
- 「미도달」이 UX Writing 용어표에 없는 신규 상태 용어다(aria 전용) — 등재 검토
- 한글 폰트에 진짜 이탤릭이 없어 11px 합성 기울임이 뭉갠다(「진행 표시 준비 중」)
