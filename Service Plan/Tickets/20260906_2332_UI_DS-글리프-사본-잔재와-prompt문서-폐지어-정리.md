# [UI] DS 글리프 사본 잔재와 prompt 문서의 폐지어를 정리한다

## 배경 / 문제 정의

티켓 20260906_2140이 `LockGlyph`·`CheckGlyph`·`StarGlyph`·`ChevronDownGlyph`를
`design-system/components/icons/BadgeStatusGlyphs.jsx` 단일 소스로 통합했다.
**한 벌이 남았다** — `BadgeStatusSection.jsx:33`이 아직 로컬 `ChevronDownGlyph`를 선언한다.
`BadgeStatusGlyphs`가 이미 같은 이름을 export하고 `BadgeFamilyCardHeader`는 거기서
import하므로, 이 파일만 갈라져 있다. 「한쪽만 고치면 갈라진다」는 통합의 이유가 그대로 남는다.

**별개로 `*.prompt.md`에 폐지어가 남아 있다.** 이 파일들은 claude.ai/design 재생성 입력이라
**여기 남은 폐지어가 다음 생성물로 되돌아온다.**

| 파일 | 잔존 |
|---|---|
| `BadgeStageRail.prompt.md` (24-26·37행) | 「충족」 5회 |
| `BadgeProgressRingCard.prompt.md:13` | ariaLabel 예시가 **「미도달」** — 현재 코드(「아직」)와 이미 어긋남 |
| `UnlockConditionSheetContent.prompt.md:19` · `.d.ts:13,51` | 「충족」·「잠금 해제 조건」 |

폐지어 기준은 `UX_WRITING_GUIDELINE.md` §1.3 (2026-09-06 갱신, 커밋 `00ead78f`).

## 상세 요구사항

### 서비스/코드베이스 관점
- `BadgeStatusSection.jsx:33`의 로컬 `ChevronDownGlyph`를 지우고 `BadgeStatusGlyphs`에서
  import한다. **호출부의 `size`가 명시돼 있는지 확인** — 기본값이 다르면 픽셀이 바뀐다
- 위 표의 `*.prompt.md`·`*.d.ts` 폐지어를 현행 문구로 교체한다
  (「충족」→「다 채웠어요」 계열, 「미도달」→「아직」, 「잠금 해제 조건」→「받는 방법」)
- 다른 `*.prompt.md`에도 같은 폐지어가 있는지 전수 grep

### UI/UX 관점
- 렌더 결과가 한 픽셀도 바뀌지 않아야 한다 (글리프 통합은 형태 동일)

## 구현 계획

글리프 통합 1건 + 문서 문구 교체. Story 동반 필요(`BadgeStatusSection`).
