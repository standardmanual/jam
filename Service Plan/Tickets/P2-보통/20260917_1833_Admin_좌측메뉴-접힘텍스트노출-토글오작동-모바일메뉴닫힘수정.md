# [Admin] 좌측 메뉴 접힘 텍스트 노출 · 토글 오작동 · 모바일 메뉴 닫힘 수정

## 배경 / 문제 정의
어드민 좌측 메뉴(`AdminSidebar`, shadcn `Sidebar` 컴포넌트 기반)에서 아래 세 가지 문제가
보고됐다.

1. 좌측 메뉴를 접었을 때 텍스트가 일부 노출된다.
2. 좌측 메뉴 접기/펴기 토글(`SidebarTrigger`, `AdminHeader.tsx`)이 간헐적으로 동작하지 않는다.
3. 모바일에서 메뉴 항목을 눌러 페이지를 이동해도 메뉴(Sheet 드로어)가 자동으로 닫히지 않고
   그대로 열려 있어, 이동한 페이지 내용이 가려진다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 접힘(아이콘) 모드에서 메뉴 라벨 텍스트가 어떤 상태에서도 보이지 않아야 한다. 특히
  `AdminSidebar.tsx`의 `isIconMode` 조건부 렌더링(Accordion 트리 ↔ 아이콘 트리 전환)과
  `Sidebar`의 CSS 폭 트랜지션(200ms) 타이밍이 어긋나 전환 애니메이션 도중 텍스트가 잠깐
  보이는 것이 원인일 가능성이 있다 — 재현 후 근본 원인을 확인하고 수정한다.
- 토글 버튼(`SidebarTrigger` → `useSidebar().toggleSidebar`)이 클릭해도 반응하지 않는
  경우의 재현 조건을 확인하고 수정한다.
- `AdminSidebar.tsx`의 메뉴 항목(`SidebarMenuButton` 내부 `Link`) 클릭 시, 모바일
  드로어(`openMobile`)를 닫도록 처리한다. `useSidebar()`의 `isMobile`·`setOpenMobile`을
  활용해 항목 클릭 핸들러에서 `isMobile`일 때만 닫는다(데스크탑 동작에는 영향 없어야 함).

### UI/UX 관점 (해당 시)
- 접힘 모드 전환·모바일 드로어 닫힘 모두 시각적 깜빡임 없이 자연스러워야 한다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- **문제 1(접힘 텍스트 노출)**: `AdminSidebar.tsx`의 메뉴 라벨 `<span>`에
  `group-data-[collapsible=icon]:hidden`이 누락돼 있었다. 접힘 트리거 클릭 시 컨테이너 폭이
  200ms에 걸쳐 줄어드는데, 텍스트가 `overflow-hidden`에만 의존해 잘려 보이는 상태로 남아
  전환 애니메이션 도중 순간적으로 노출됐다. 모든 메뉴 라벨 span(대시보드 1개 + 그룹 항목
  아이콘모드/아코디언모드 각각)에 해당 클래스를 추가해 접힘 상태 진입과 동시에 즉시 사라지도록
  수정.
- **문제 2(토글 간헐 오작동) + 문제 3(모바일 메뉴 미닫힘)**: Playwright로 실제 브라우저
  재현한 결과 두 문제는 동일 원인이었다. 모바일 드로어(Sheet, Radix Dialog 기반)에서 메뉴
  항목을 눌러 페이지를 이동해도 드로어를 닫는 로직이 없어 `Sheet`가 열린 채로 남았고, Radix
  Dialog의 스크롤 잠금(`document.body.style.pointerEvents = 'none'`)도 해제되지 않아 이후
  사이드바 토글 버튼(`SidebarTrigger`)을 포함한 페이지 전체 클릭이 먹통이 됐다(모바일
  뷰포트에서 실측: 드로어 열고 → 메뉴 링크 클릭 → 토글 버튼 클릭 시도 → 타임아웃 확인).
  `useSidebar()`의 `isMobile`·`setOpenMobile`을 사용해 모든 메뉴 `Link` 클릭 시
  `isMobile`이면 `setOpenMobile(false)`로 드로어를 닫도록 `handleNavClick` 핸들러를
  추가·연결. 데스크탑 접기/펼치기 토글 자체는 재현 스크립트로 40회 연속 클릭 + 무대기
  연타 30회 모두 실패 없이 정상 동작함을 확인했다 — 데스크탑 단독 토글 버그는 재현되지
  않았고, 보고된 "간헐적 오작동"은 모바일 드로어 미닫힘으로 인한 pointer-events 잠금이
  실질 원인으로 판단된다.
