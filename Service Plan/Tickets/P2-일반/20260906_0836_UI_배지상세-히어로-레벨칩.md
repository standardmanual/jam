# [UI] 배지 상세 히어로가 레벨형에 칩을 그리지 못한다

> 출처: `20260905_0038` B묶음 게이트 리뷰 발견물. 선행: `20260905_0036`(`BadgeLevelChip`).

## 문제

`src/app/(main)/badges/[id]/BadgeHeroSection.tsx:100`이
`<RarityBadge rarity={badge.rarity ?? undefined} />`였다.

**v5 레벨형 193종은 `rarity`가 NULL**이고 `RarityBadge`는 미지 값을 그리지 않으므로
(티켓 `20260905_0036`에서 조용한 Common 폴백을 없앴다) **상세 화면에 칩이 하나도 뜨지
않았다** — 등급도 레벨도 알 수 없는 상태다.

같은 줄의 주석이 「Lv.N 칩은 티켓 `20260905_0036`/`0037`」로 위임을 명시했으나
**두 티켓 모두 이 파일을 손대지 않았다.** 0036은 DS 컴포넌트만 만들었고(서비스 미연결),
0037은 배지 트리 화면만 연결했다.

## 수정

`BadgeTrophyGridCard.tsx:119`(티켓 `0037`)와 **같은 분기**를 쓴다:

```tsx
{badge.level != null ? <BadgeLevelChip level={badge.level} /> : <RarityBadge rarity={badge.rarity ?? undefined} />}
```

- `badge` props 타입에 `level?: number | null`을 **선택**으로 추가.
  필수로 만들면 실제 배지 레코드가 아닌 호출부(어드민 배경 미리보기
  `BadgeDetailPreviewFrame.tsx`, dev 샘플 `dev-sample/item-badge-serial`)가 막힌다.
- 주 경로(`badges/[id]/page.tsx`)는 `select('*')`라 `level`이 이미 들어온다 —
  호출부 3곳(`:331`·`:441`·`:514`) 전부 `badgeRow`를 그대로 넘기므로 추가 변경이 없다.
- 위임 주석을 「왜 이 분기가 필요한가」로 바꿨다. 다음 사람이 `RarityBadge`만 남기지
  않도록 실패 모드(칩이 조용히 사라진다)를 명시했다.

  `level`을 빼고 조회한다. 다만 **현재 v5 630종 중 `prerequisite_badge_names`를 쓰는
  배지가 0건**이라 도달 불가 경로다 — 2단 교차 게이트가 시딩되는 시점
  (`20260906_0110`)에 함께 봐야 한다.
