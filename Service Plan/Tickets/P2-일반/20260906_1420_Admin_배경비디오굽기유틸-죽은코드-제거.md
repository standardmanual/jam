# [Admin] 배경 애니메이션 "굽기(bake)" 유틸 318줄 죽은 코드 제거

> 어드민 배지 생성/수정/상세 화면 구성 점검(2026-09-06) 중 발견. 관련: `20260906_1421`·`20260906_1422`·`20260906_1423`·`20260906_1424` (같은 점검에서 나온 별개 항목들)

## 배경 / 문제 정의

`jam-web/src/app/admin/badges/bakeBackgroundVideo.ts`(318줄)는 배지 배경 "제너레이터"의
애니메이션 모드를 짧은 반복 재생 MP4(H.264, WebCodecs + mp4-muxer)로 구워 저장하던 유틸이다.

그런데 이 제너레이터 기능 자체가 티켓 `20260901_1929`에서 완전히 제거됐다 —
`BackgroundGeneratorPreview.tsx` 44-51행 주석에 그 경위가 남아 있다. 지금 배경 테마는
배경색 또는 라이브 블롭 애니메이션(`BlobAnimationFields.tsx`, `20260901_1944`) 둘 중
하나이고, 어느 쪽도 "구워서 저장"하지 않는다 — 애니메이션은 화면에서 실시간으로 돈다.

`grep -rn bakeBackgroundVideo`로 확인한 결과 이 파일을 참조하는 곳은 **파일 자기 자신뿐**이다.
`BadgeForm.tsx`·`BackgroundGeneratorPreview.tsx` 어디에서도 import하지 않는다.

딸린 npm 의존성 `mp4-muxer`(`package.json` 42행)도 이 파일 하나만 쓰고 있어 함께 정리
대상이다 (`bakePreviewToBlob.ts`의 `canvasToBlob`은 별개 — `buildBadgeShareBlob.ts`·
`activity-badge-image/page.tsx`가 지금도 쓰고 있어 살아있는 코드다. 착각해서 같이 지우지 말 것).
