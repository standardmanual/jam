# [Content] 배지 문서 생성기가 등급별 설명을 싣지 않는다

> 선행: `20260906_1305`(등급별 설명 분화 — 이 문제를 만든 티켓)
> 개선 리뷰 제안에서 분리 (2026-09-06 사용자 승인)

## 배경 / 문제 정의

티켓 `20260906_1305`이 계열당 한 문장이던 배지 설명을 **131계열 436행에서 등급별로 분화**했다.
정본은 `Service Plan/Specs/Content/v5_catalog_writing.json`의 `등급별설명` 필드다.

정본 JSON을 읽는 소비자는 둘인데 **하나만 갱신됐다.**

| 소비자 | `등급별설명` 반영 | 결과 |
|---|---|---|
| `v5_seed_build.py` → 시드 SQL·rows.json | ✅ 반영됨 | DB 436행 갱신 완료 |
| `v5_doc_build.mjs` → `ACTIVITY_BADGES.md` | ❌ 14행이 `r['설명']`만 집는다 | 계열마다 최저 등급 문장 하나만 실린다 |

`ACTIVITY_BADGES.md`는 스스로 "정본은 DB이고 이 문서는 산출물에서 생성한다"고 선언하는데,
지금 상태로는 **산출물의 절반(436행)이 문서에서 보이지 않는다.** 문서가 틀린 것은 아니지만
불완전하고, 이 문서만 보고 판단하면 「계열 내 등급이 같은 설명을 쓴다」는 이미 깨진 전제를
그대로 믿게 된다.

`20260906_1305`에서는 급한 대로 문서 상단에 한계를 명시하는 주석만 넣어두고
(「아래 계열 표의 「설명문」은 최저 등급 문장 하나만 싣는다」) 이 티켓으로 넘겼다.

## 상세 요구사항

### 컨텐츠 관점

- `Service Plan/Specs/Content/v5_doc_build.mjs`가 `등급별설명`을 함께 읽도록 고친다
- 계열 블록의 `<details><summary>설명문</summary>`에 **등급/레벨별 문장을 모두** 싣는다.
  등급형은 Common→Mystic 순, 레벨형은 Lv 오름차순
- 최저 등급 행은 `설명` 필드에서, 나머지는 `등급별설명`에서 온다는 것이 표에서 읽히게 한다
- `등급별설명`이 없는 계열(1행짜리 63계열)은 지금과 동일하게 한 줄만 싣는다
- 고친 뒤 **생성기를 돌려 `ACTIVITY_BADGES.md`를 재생성한다.**
  ⚠️ 문서를 손으로 고치지 않는다 — 이 문서의 규칙이다(문서 상단 주석)
- `20260906_1305`이 넣어둔 상단 한계 주석은 이 작업이 끝나면 **지운다**
  (Specs는 「지금 사실」만 담는다 — 해소된 한계를 남기지 않는다)

## 구현 계획

1. `v5_doc_build.mjs` 14행 부근의 `r['설명']` 소비 지점을 등급별로 확장
2. `node "Service Plan/Specs/Content/v5_doc_build.mjs"` 재생성
3. diff 확인 — 계열 표 구조는 그대로이고 설명문 블록만 늘어나야 한다
4. `ACTIVITY_BADGES.md` 상단의 한계 주석 제거

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
`v5_doc_build.mjs`의 `desc` 맵이 라이팅 정본 행 전체(`r['설명']`뿐 아니라 `등급별설명`까지)를
들고 오도록 고쳤다. 계열 블록의 `<details><summary>설명문</summary>`에서:
- `등급별설명`이 없는 63계열(1행)은 기존과 동일하게 `- **이름** — 설명` 한 줄
- `등급별설명`이 있는 131계열은 계열의 `사다리`를 등급형은 Common→Rare→Epic→Mystic,
  레벨형은 Lv 오름차순으로 정렬한 뒤, 첫 행은 `Rare `설명` — ...`처럼 `설명` 필드에서,
  나머지는 `Epic `등급별설명` — ...`처럼 `등급별설명`에서 가져와 중첩 목록으로 표시
  (필드 태그를 백틱으로 표기해 출처를 구분)
- 재생성 전 131계열 436행 전수를 사다리 rarity/level 키와 대조해 누락·잉여 키 0건 확인
- `node v5_doc_build.mjs`로 `ACTIVITY_BADGES.md` 재생성. diff 확인 결과 계열 표(`| ... |`)는
  0건 변경, 설명문 블록만 변경됨. 상단의 「설명문은 최저 등급 문장 하나만 싣는다」 한계
  주석(티켓 `20260906_1305`가 넣어둔 것)도 재생성으로 자동 제거됨(생성기 코드에 없던 수기
  삽입 문단이었음)
