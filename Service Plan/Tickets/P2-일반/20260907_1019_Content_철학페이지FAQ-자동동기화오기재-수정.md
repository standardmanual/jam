# [Content] 철학 페이지 FAQ — "자동 동기화" 오기재 수정

## 배경 / 문제 정의

티켓 20260907_0934로 추가한 `/philosophy` FAQ 중 "운동을 마쳤는데 왜 배지가 바로 안
나오나요?" 답변이 "자동 동기화까지 시간이 조금 걸릴 수 있으니"라고 서술해, 마치 주기적
자동 동기화가 존재하는 것처럼 읽혔다. 사용자 지적으로 확인한 사실(`Service Plan/Specs/
PRD/04_PROJECT_SPEC.md` 「Vercel Cron 작업」):

> **2026-07-31 제거**: `/api/cron/sync`(전체 유저 순차 동기화 크론)는 삭제됐다. 이후
> Strava 동기화는 **수동 버튼(`POST /api/strava/sync`)과 OAuth 콜백 직후 1회**만 발생한다.

즉 JAM에는 자동(주기적) 동기화 기능이 없다 — 사실과 다른 문구였다.

## 상세 요구사항

### 컨텐츠 관점
- "운동을 마쳤는데 왜 배지가 바로 안 나오나요?" 답변에서 "자동 동기화" 표현 제거,
  동기화는 유저가 홈 화면 버튼을 직접 눌러야 발생한다는 사실로 정정
- "배지는 어떻게 얻나요?" · "아이템은 어떻게 드랍되나요?" 답변의 "Strava 동기화가
  되면"(피동, 자동처럼 읽힘) → "Strava 동기화를 하면"(능동, 유저 행위 명시)으로 통일해
  같은 페이지 안에서 동기화가 유저 행위라는 사실을 일관되게 전달
