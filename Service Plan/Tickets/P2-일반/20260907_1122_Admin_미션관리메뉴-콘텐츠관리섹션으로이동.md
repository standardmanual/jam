# [Admin] 미션 관리 메뉴를 콘텐츠 관리 섹션으로 이동

## 배경 / 문제 정의
> 왜 이 작업이 필요한가. 현재 상태와 기대 상태의 차이.

어드민 사이드바에서 "미션 관리"(`/admin/missions`)가 "정책 및 밸런스" 섹션에 있었다.
사용자 요청에 따라 "콘텐츠 관리" 섹션으로 옮긴다. "게이트 미션 관리"(`/admin/gate-missions`)는
별도 항목이며 이번 요청 대상이 아니므로 정책 및 밸런스에 그대로 둔다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `src/components/admin/adminNavItems.ts`의 `NAV_GROUPS`에서 `policy` 그룹의
  `{ href: '/admin/missions', label: '미션 관리', ... }` 항목을 제거하고 `content` 그룹으로 이동
- 라우트(`/admin/missions`)·라벨·아이콘은 변경하지 않는다 (메뉴 그룹 소속만 변경)

## 구현 계획
> 어떻게 구현할지. 접근 방법, 영향 범위, 주요 변경 포인트.

`NAV_GROUPS` 배열 리터럴만 수정하는 단순 이동. 로직 변경 없음 (경미 수정 — 풀 파이프라인 생략).
