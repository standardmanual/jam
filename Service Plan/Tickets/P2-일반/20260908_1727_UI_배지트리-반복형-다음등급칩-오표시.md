# [UI] 배지 트리 반복형 계열의 "다음 등급" 칩이 최고 등급 획득 후에도 계속 표시됨

## 배경 / 문제 정의
> 왜 이 작업이 필요한가. 현재 상태와 기대 상태의 차이.

배지 트리 페이지(`/badges/tree`)에서 배지 카드 이름 아래에 "다음 + 등급칩"(예: "다음 Common")
영역이 뜨는데, 반복형(`repeatable`) 계열은 이미 최고 등급(예: Epic)까지 다 받은 뒤에도 이 칩이
계속 표시된다. 사용자가 첨부한 스크린샷("겨울잠" 배지, 0%·"다음 Common"·"×0"·"0/1회·1회 남음")이
이 상태다 — 실제로는 더 이상 다음 등급이 없는데도 마치 다음 단계가 남은 것처럼 보인다.

## 원인 (조사 완료)

`jam-web/src/components/badges/BadgeFamilyRow.tsx` 122~146행, 반복형 분기.

```ts
const frontierStage = frontierStageOf(family, earnedBadgeIds)
...
metaText={formatFamilyMetaLine(
  frontierStage?.rarity ? (RARITY_LABEL[frontierStage.rarity] ?? null) : null,
  null
)}
earned={frontierStage ? earnedBadgeIds.has(frontierStage.id) : false}
```

`frontierStageOf`(`jam-web/src/lib/badgeTree.ts` 211~223행)는 반복형에 한해 모든 눈금을 다
획득한 뒤에도 마지막(최고) 눈금을 계속 반환하도록 의도적으로 설계돼 있다(티켓 20260905_0031 —
"반복형은 다 받아도 다음 회차가 계속 진행 중"이라는 원칙). 문제는 `metaText`를 만드는 부분이
`frontierStage?.rarity`만 보고 무조건 "다음 {rarity}"를 붙인다는 점이다 — 바로 아래에서 계산하는
`earned`(이 눈금이 실제로 획득됐는지) 값을 재사용하지 않는다. 그 결과 최고 등급을 이미 획득한
계열에도 "다음 {최고등급}" 칩이 계속 뜬다.

등급형(`graded`)은 `stops.find(s => s.status !== 'earned')`로 미획득만 걸러 next로 삼아 이
문제가 없고, 무한레벨형(`leveled`)도 `nextLevel != null`일 때만 표시해 정상이다. **세 분기 중
반복형만 "이미 획득했는지" 체크가 빠져 있다.**

같은 유형("Mystic 없이 Epic이 최고 등급인 반복형 계열")이 다수 존재해(cycling:X1/X2,
hiking:X1/X2 등, 티켓 20260908_1033 참고) 이 배지 하나만의 문제가 아니다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `BadgeFamilyRow.tsx`의 반복형 분기에서, `frontierStage`가 이미 획득된 상태(`earned === true`)면
  `metaText`를 `null`(또는 빈 값)로 넘겨 "다음 등급" 칩 자체가 렌더링되지 않게 한다. 미획득
  상태에서는 기존과 동일하게 "다음 {rarity}" 칩을 그대로 표시한다.
- `frontierStageOf`의 설계(다 받아도 마지막 눈금을 계속 반환)는 그대로 유지한다 — 진행률·회차
  카운트 등 다른 용도로 쓰이므로 건드리지 않는다. 이번 수정은 **표시 문구 조립부**로 한정한다.

### UI/UX 관점 (해당 시)
- "다음 Common" 등 등급칩 영역이 최고 등급 획득 후에는 자연스럽게 사라져야 한다. 그 아래 회차
  진행률(`0/1회` 등) 표시는 이번 범위에서 건드리지 않는다(별도 확인 필요하면 후속 이슈로 분리).

### 컨텐츠 관점 (해당 시)
- 해당 없음.

## 구현 계획
> 어떻게 구현할지. 접근 방법, 영향 범위, 주요 변경 포인트.

1. `BadgeFamilyRow.tsx` 반복형 분기의 `metaText` 계산에 `earned` 조건을 추가한다(순서상 `earned`
   값을 먼저 계산해 재사용하거나, 같은 조건식을 `metaText` 계산에도 적용).
2. 최고 등급을 이미 획득한 반복형 계열(겨울잠 등)과, 아직 미획득인 반복형 계열 양쪽으로 회귀
   재현 경로를 확인한다.
3. `BadgeFamilyRow`가 배지 트리 페이지 한 곳에서만 쓰이므로 파급 범위는 그 페이지로 한정된다 —
   다른 화면 확인은 불필요.
