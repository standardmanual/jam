# [UI] 배지그리드카드 이름 말줄임 제거, 2줄 표시로 변경

## 배경 / 문제 정의
컬렉션 상세 페이지(`/collections/[id]`)에서 각 배지 컬럼의 배지 이름이 1줄로 말줄임(`truncate`,
`text-overflow: ellipsis`) 처리되어 있어, 이름이 조금만 길어도 뒷부분이 잘려 보인다. 이름
전체를 읽을 수 있도록 2줄까지 표시하도록 바꾼다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `src/components/ui/BadgeGridCard.tsx:140` — 배지 이름 `<p>`의 `truncate` 클래스를
  `line-clamp-2`로 교체(1줄 말줄임 → 2줄까지 표시, 2줄 넘으면 그때 말줄임)
- MODULAR 병존 구현 `design-system/components/patterns/BadgeGridCard.jsx:132-139`의 인라인
  스타일(`overflow: hidden; textOverflow: ellipsis; whiteSpace: nowrap`)도 동일한 의미로
  2줄 클램프(`WebkitLineClamp: 2; WebkitBoxOrient: 'vertical'; display: '-webkit-box'` 등)로
  맞춘다 — 서비스 코드와 MODULAR가 어긋나지 않게 함께 수정
- 두 컴포넌트를 사용하는 다른 화면(배지 상세, 프로필, 알림함 등)에서 카드 높이가 늘어나며
  생기는 레이아웃 깨짐이 없는지 확인

### UI/UX 관점 (해당 시)
- 이름이 1줄인 배지는 기존과 동일하게 보여야 한다 (2줄 강제 아님, 최대 2줄까지 허용)
- 2줄로도 다 안 들어가는 경우에만 말줄임 처리

## 구현 계획
`BadgeGridCard.tsx`와 MODULAR `BadgeGridCard.jsx` 두 파일의 이름 텍스트 스타일을
`line-clamp-2`(Tailwind) / 동등한 인라인 스타일로 교체한다. 컬렉션 상세 페이지
(`src/app/(main)/collections/[id]/SlotGrid.tsx`가 이 컴포넌트를 사용)에서 실렌더로 확인한다.
