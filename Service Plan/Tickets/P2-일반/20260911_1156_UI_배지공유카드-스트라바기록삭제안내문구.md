# [UI] 배지 공유 카드 생성 실패 시 "스트라바 기록 삭제" 안내 문구 추가

## 배경 / 문제 정의
배지 공유 시트의 "카드"(통계 포함 공유 카드) 항목은 `/api/badges/[id]/share-data`가
Strava 활동을 재조회해 페이스·시간을 계산한다. 이 활동이 Strava 쪽에서 **삭제되거나
비공개로 전환**되면 Strava API가 404를 반환하는데, 현재 `route.ts`는 401(토큰 만료)만
따로 구분하고 나머지(404 포함)는 전부 `strava_fetch_failed`(502, "지금은 이미지를 만들
수 없어요 / 잠시 후 다시 시도해주세요")로 뭉뚱그린다.

이 문구는 "일시적인 서버 문제니 다시 시도하면 된다"는 뉘앙스인데, 실제로는 Strava
활동이 사라진 것이라 재시도해도 똑같이 실패한다. 사용자 입장에서 "왜 안 되지, 내가 뭘
잘못했나"로 읽히기 쉽다. 원인이 우리 서비스가 아니라 Strava 쪽 데이터에 있다는 것을
분명히 하고, 확인해볼 곳(Strava 앱)을 안내하는 문구로 바꾼다.

또한 이 실패 상태가 캐러셀 프레임(이미지 영역) 안에서는 `MedalIcon`만 보이고, 실제
안내 문구는 프레임 바깥 별도 영역에 작게 표시된다 — 아이콘이 무엇을 의미하는지
직관적이지 않다. 아이콘 대신 이미지 영역 안에 안내 문구를 직접 보여준다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `route.ts`: `getActivityById` 결과가 404면 `strava_activity_not_found`라는 새 에러
  사유로 구분해 반환한다(기존 401→`strava_disconnected`, 그 외→`strava_fetch_failed`
  유지, 404만 신규 분리).
- `BadgeShareButton.tsx`:
  - `ShareErrorReason`·`KNOWN_ERROR_REASONS`에 `strava_activity_not_found` 추가.
  - `errorCopy`에 새 사유 케이스 추가 — "우리가 삭제해서 못 만든다"가 아니라 "Strava
    에서 이 기록을 확인할 수 없다, Strava에서 확인해봐라"는 톤.
  - 캐러셀 `renderItem`의 에러 분기에서 `MedalIcon` 대신 title·body 텍스트를 이미지
    영역 안에 직접 표시한다. 프레임 바깥의 기존 안내 블록(`activeItemState.kind ===
    'error'` 아래)과 중복되지 않도록 정리한다(접근성 aria-live 알림 역할은 유지).
- `ko.ts`: `shareErrorActivityNotFoundTitle`/`Body` 신규 키 추가.

## 구현 계획
1. `route.ts`에 404 분기 추가.
2. `BadgeShareButton.tsx` 타입·`errorCopy`·렌더링 수정.
3. `ko.ts`에 새 문구 추가 (UX Writing 가이드 톤 — 에러는 [현상]→[원인]→[해결책] 3단계,
   해요체).
