# [UI] 배지 공유 캐러셀 에러 안내 문구 색상·줄바꿈 수정

## 배경 / 문제 정의
티켓 `20260911_1156`에서 캐러셀 프레임(체크보드 배경) 안에 직접 표시하도록 바꾼 에러
안내 문구가, 프레임 배경이 어두운데 `--color-text-secondary` 톤을 써서 실기기에서 잘
안 보였다. 또한 `strava_activity_not_found` 문구의 줄바꿈 위치를 사용자가 직접 지정했다.

## 상세 요구사항
### 서비스/코드베이스 관점
- `BadgeShareButton.tsx`: 캐러셀 프레임 안 에러 텍스트 색상을 `--color-text-secondary` →
  `--color-text-inverse`(기존 비활성 팝오버에서 쓰던 흰색 토큰)로 변경. `whitespace-pre-line`
  추가해 문구의 줄바꿈(`\n`)이 반영되게 한다.
- `ko.ts`: `shareErrorActivityNotFoundTitle`/`Body`에 줄바꿈 반영.
  - title: `Strava에서\n기록을 확인할 수 없어요.`
  - body: `활동이 삭제되지 않았는지\n확인해보세요.`

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `BadgeShareButton.tsx`의 캐러셀 프레임 안 에러 title/body `<p>`의 텍스트 색상을
  `--color-text-secondary`(및 `/60`)에서 `--color-text-inverse`(및 `/70`)로 변경 —
  어두운 체크보드 배경 위에서 흐리게 보이던 문제를 해결했다. 이 색상은 이미 이 컴포넌트의
  비활성 버튼 팝오버에서 어두운 배경 위 흰 텍스트로 쓰이던 토큰을 재사용했다.
  `whitespace-pre-line`을 추가해 `\n`으로 지정한 줄바꿈이 그대로 렌더링되게 했다.
- `ko.ts`의 `shareErrorActivityNotFoundTitle`/`Body`에 사용자가 지정한 줄바꿈 위치를
  반영했다. 마침표가 추가된 것은 사용자 지시를 그대로 따른 것으로, 기존 UX Writing
  가이드의 "제목에 마침표 없음" 원칙과 다르다 — 이번 문구는 2줄 문단 형태라 문장 종결을
  명확히 하는 편이 낫다는 판단으로 예외를 뒀다.
- 색상 변경은 `strava_activity_not_found` 뿐 아니라 캐러셀 프레임 안에서 렌더링되는
  모든 에러 사유(strava_disconnected/no_strava_trigger/strava_fetch_failed/unknown)에
  공통 적용된다 — 사용자가 "텍스트가 흐려서 안 보인다"고 지적한 것은 색상 자체의 문제였기
  때문에 사유별로 구분하지 않았다.

  일관성을 유지했다.
