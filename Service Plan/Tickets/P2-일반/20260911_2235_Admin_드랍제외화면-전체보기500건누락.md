# [Admin] 드랍 제외 관리 화면 — 필터 없이 전체 보기 시 500건 이후 배지 누락

## 배경 / 문제 정의
티켓 20260911_2220(드랍 정책 — 아이템배지 드랍 제외 기능)의 게이트 리뷰 중 발견된
범위 밖 이슈다. `/admin/drop-policy/exclusions` 화면의 `DropExclusionBadgesTable`에
넘기는 배지 조회(`page.tsx`)에 `.limit(500)`이 걸려 있다. 활성 아이템북 소속
아이템배지가 이미 900개에 근접하므로, 트라이브·컬렉션 필터를 걸지 않고 "전체 보기"
상태로 조회하면 이름순 500개를 넘는 배지는 **안내 문구 없이 조용히 목록에서 빠진다.**
운영자가 특정 배지를 전체 목록에서 찾다가 못 찾는 상황이 재현될 수 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/admin/drop-policy/exclusions/page.tsx`의 배지 조회 쿼리 검토
- 다음 중 하나로 해결:
  1. 페이지네이션 추가 (다른 어드민 목록 화면과 동일한 패턴이 있으면 재사용)
  2. 500건 초과 시 "일부만 표시 중, 필터를 사용하세요" 안내 문구 표시
  3. limit을 늘리고 검색/정렬 UI로 보완

## 구현 계획
- 담당자가 기존 어드민 테이블(예: `/admin/badges`)의 페이지네이션 패턴을 확인 후
  동일 패턴 적용을 우선 검토
