# [Content] 미슐랭 POI 체크인 배지 생성 — JAM MICHELIN 디자인 42개 일괄 생성

## 배경 / 문제 정의

[[20260912_0115]]에서 `poi_categories`에 `michelin` 카테고리를 신설하고 서울 미쉐린 가이드
레스토랑 42곳을 `poi` 테이블에 등록했다(전부 `is_active=false`·`pending_review=true`,
`linked_badge_id`는 아직 없음).

이번 티켓에서는 이 42곳을 **체크인 배지 타입(`type='checkin'`)으로 실제 배지화**한다.
기존 `mountain`(847개)·`train_subway`(929개)와 동일하게 **POI 1개 = 배지 1개** 1:1 생성
패턴을 따른다(`BADGE_ENGINE_UNIFIED.md` §3.14).

배지 이미지는 신규 피그마 템플릿("미쉐린 가이드" 문장을 두른 골드/레드 라벨 디자인, 하단에
Jam 로고)을 사용하며, 템플릿의 `POI`라는 이름의 텍스트 레이어에 각 레스토랑 이름을 주입해
생성한다.

- 디자인 출처: Figma `UXcBEgFagmO5ARwH5F0mMW` node-id `15-127`
  (텍스트 레이어 id `15:113`, 레이어명 `POI`, 예시 문구 `강민철 레스토랑`)
- 사용자가 텍스트 길이 확인을 완료함(42곳 상호명이 템플릿 폭 안에 들어감을 확인) — 다만
  실제 구현 시 최장 상호명 기준으로 렌더 결과를 한 번 더 육안 확인한다.

## 상세 요구사항

### 서비스/코드베이스 관점

1. **배지 레코드 생성**: `poi.category='michelin'` 42곳 각각에 대해 `badges` 테이블에
   `type='checkin'`, `rarity='common'` 배지를 1:1 생성하고 `poi.linked_badge_id`를 연결한다.
   - 배지 이름 = POI 이름 그대로
   - 설명은 기존 자동 생성 규칙(mountain/transit)과 톤을 맞춘 문구를 새로 정의한다
     (예: `"{POI명}에서 체크인했습니다"` 계열 — 정확한 문구는 `UX_WRITING_GUIDELINE.md`
     기존 체크인 문구 규칙을 따라 구현 단계에서 확정)
   - 아이콘은 신규 생성하는 배지 이미지 자체를 사용 (기존 `anyway_star.png` 공용 아이콘과
     달리, 이번 디자인은 레스토랑 이름이 라벨 안에 들어가는 형태라 배지별로 이미지가 다르다 —
     지하철역/산 배지와 동일한 방식)
2. **체크인 매칭 반경 등록**: `src/lib/poi/radius-policy.ts`의
   `EXACT_MATCH_RADIUS_BY_CATEGORY`에 `michelin` 항목이 없으면 기본값 500m가 적용된다.
   레스토랑은 도심 밀집 지역에 인접해 있는 경우가 많아 500m는 인근 다른 매장과 오탐 위험이
   있으므로, `mountain`(150m)·`train_subway`(50m) 사례를 참고해 적정 반경(권장: 50m,
   식당 단위 정밀도 기준)을 등록한다. §3.14 문서의 "카테고리를 표에 등록하지 않으면 기본값이
   적용되어 오탐이 재발한다"는 경고를 그대로 따른다.
3. **배지 이미지 생성**: `jam-web/scripts/badge-image-gen/configs/michelin-poi-badge.config.js`
   신규 작성.
   - Figma MCP(`get_design_context`, `get_metadata`)로 node `15:127` 배경 요소 좌표·텍스트
     노드(`15:113`) 사양(x/y/width/height/fontSize/color/align)을 정확히 추출해 배경 SVG를
     조립한다 (`backgrounds/michelin-poi-badge.svg`, 기존 `metro-poi-badge.svg` 방식 재사용)
   - dataSource는 `poi(category='michelin')` ↔ `badges(linked_badge_id)` 조인, 소프트삭제
     배지 제외 (기존 `metro-poi-badge.config.js` 패턴 참고)
   - 텍스트 렌더링은 기존 `text.measure: 'font'`(폰트 실측 모드) 재사용 — 상호명 길이 편차가
     역명보다 클 수 있으므로 `autoShrink: true` 필수
   - 대표 케이스(최장/최단 상호명) 샘플 생성 후 육안 확인
4. **DB 반영**: 생성된 이미지를 `badges.image_url`에 일괄 UPDATE (SQL 파일로 남기고
   service_role 키로 직접 실행 — `jam-web/supabase/migrations/seed_*.sql` 또는
   `seed_update_michelin-poi-badge_images.sql`)
5. **POI 활성화**: 어드민 `/admin/poi/review`에서 미슐랭 POI 42곳을 전부 승인
   (`is_active=true`, `pending_review` 처리). 배지 이미지가 먼저 프로덕션에 반영된 뒤 활성화
   해야 한다 — [[20260824_020]]에서 발견된 "이미지 파일 미배포 상태에서 DB부터 바꾸면 깨져
   보인다"는 배포 순서 문제를 반복하지 않는다.

### 컨텐츠 관점

- 배지 설명 문구는 `UX_WRITING_GUIDELINE.md`의 체크인 배지 톤(신남)을 따른다.
- `Service Plan/Specs/Content/` 하위 체크인 배지 관련 문서(있다면)에 미슐랭 배지 42종 추가
  사실을 반영한다.
