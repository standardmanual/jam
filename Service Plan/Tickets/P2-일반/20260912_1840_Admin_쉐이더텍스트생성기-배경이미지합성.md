# [Admin] 쉐이더 텍스트 생성기 — 배경 이미지 합성 기능 추가

## 배경 / 문제 정의

`20260912_1532`로 만든 쉐이더 텍스트 생성기의 배경(`Background`)은 현재 "단색" ·
"투명" 두 가지 모드만 지원한다(`BACKGROUND_MODES = ['color', 'transparent']`,
`shaderTextDissolve.ts:77`). 사용자가 세 번째 모드로 **배경 이미지 업로드 → 텍스트
이펙트와 합성**하는 기능을 요청했다.

## 상세 요구사항

### 1. 데이터 모델

`BACKGROUND_MODES`에 `'image'`를 추가한다. `ShaderTextBackgroundParams`
(`shaderTextDissolve.ts:190`)에 이미지 자체는 저장하지 않는다 — **실루엣 이미지와
동일한 제약**을 따른다: 업로드한 이미지는 `image_gen_params`/프리셋 jsonb에 바이너리로
넣지 않고, 재편집 시 다시 업로드해야 한다(`loadShaderTextSilhouette` 주석,
`composeShaderTextDissolve.ts:63~69` 참고). `mode: 'image'`만 저장되고, 실제 이미지
객체는 이전과 마찬가지로 컴포넌트 상태(`page.tsx`의 `silhouetteImage`와 대칭되는
`backgroundImage` state)로만 다룬다.

### 2. 이미지 로딩 — 기존 실루엣 로더 재사용

`loadShaderTextSilhouette()`(`composeShaderTextDissolve.ts:71`)는 이름과 달리 내부
로직이 "File → HTMLImageElement" 그 자체라 실루엣에 특화된 부분이 없다. 이 함수를
배경 이미지 로딩에도 그대로 재사용하거나(호출부만 늘리기), 이름을 더 범용적으로
바꿔(`loadShaderTextImage` 등) 두 군데에서 같이 쓴다 — 구현자 재량. **로직을 복사해
새로 만들지 않는다.**

### 3. 렌더링 파이프라인 — 배경 합성 위치

`drawShaderTextDissolve()`(`composeShaderTextDissolve.ts:493`)에 `backgroundImage:
HTMLImageElement | null` 파라미터를 추가한다(`silhouetteImage`와 같은 방식으로 4번째
인자). 7~8단계(가장자리 블러 + 배경 합성, 현재 `composeShaderTextDissolve.ts:547~554`)의
`if (params.background.mode === 'color')` 분기 옆에 `'image'` 분기를 추가한다:

```ts
resetCtx(ctx, size)
if (params.background.mode === 'color') {
  ctx.fillStyle = params.background.color
  ctx.fillRect(0, 0, size, size)
} else if (params.background.mode === 'image' && backgroundImage && backgroundImage.naturalWidth > 0) {
  // cover 방식으로 1280×1280을 꽉 채운다(레터박스 없음). 종횡비가 다르면 짧은 변에 맞춰
  // 확대하고 넘치는 부분은 중앙 기준으로 잘라낸다.
  const scale = Math.max(size / backgroundImage.naturalWidth, size / backgroundImage.naturalHeight)
  const w = backgroundImage.naturalWidth * scale
  const h = backgroundImage.naturalHeight * scale
  ctx.drawImage(backgroundImage, (size - w) / 2, (size - h) / 2, w, h)
}
// mode === 'transparent'면 아무것도 채우지 않는다(기존 동작 유지)
ctx.filter = params.edgeBlur > 0 ? `blur(${params.edgeBlur}px)` : 'none'
ctx.drawImage(finalMask, 0, 0)
```

- **cover 방식(짧은 변 기준 확대 후 중앙 크롭)을 기본으로 한다** — 배지 이미지는 항상
  1:1 정사각형이므로 레터박스(여백)가 남으면 어색하다. contain 방식이 필요하다는
  피드백이 나오면 후속 티켓에서 옵션으로 추가한다.
- `edgeBlur`는 최종 `finalMask`(텍스트 이펙트)에만 걸리고 배경 이미지 자체는 블러
  대상이 아니다 — 기존 단색 배경도 그랬으므로 동일하게 유지한다.
- 텍스트 이펙트(`finalMask`)는 배경 위에 **일반 알파 합성**(`source-over`, 기존과 동일)으로
  올라간다 — 텍스트의 투명 영역(글자 사이·바깥)으로 배경 이미지가 그대로 비친다.

### 4. UI

`ShaderTextControls.tsx`의 Background 섹션(`Select`가 있는 466행 부근, `mode ===
'color'`일 때 색상 피커를 보여주는 476행 분기)에:

- `Select` 옵션에 "이미지" 추가 (라벨은 UX 라이팅 가이드에 맞는 자연스러운 한국어로 —
  "배경 이미지" 등, 최종 문구는 구현자가 확정)
- `mode === 'image'`일 때 파일 업로드 UI 노출. 기존 실루엣 업로드 UI(`page.tsx`에서
  실루엣 토글 시 나타나는 부분)와 **동일한 컴포넌트/패턴**을 재사용한다(shadcn/ui,
  새 업로드 컴포넌트를 따로 만들지 않는다).
- 업로드한 배경 이미지의 파일명 또는 작은 썸네일을 보여줘서 "지금 어떤 이미지가
  적용돼 있는지" 알 수 있게 한다(실루엣 UI가 이미 이런 처리를 하고 있다면 그대로
  따른다).
- 이미지를 지우고 다시 단색/투명으로 되돌리는 동작도 확인한다(Select에서 모드만
  바꾸면 `backgroundImage` state는 유지해도 무방 — 다시 "이미지"로 돌아오면 이전에
  올린 이미지가 복원되는 편이 자연스럽다. 페이지를 벗어나거나 새로고침하면 당연히
  사라진다).

### 5. 배지 적용·내보내기와의 관계

- **PNG 다운로드·배지 적용(`generate` API) 흐름은 변경 없음** — 이미 굽힌 최종 캔버스를
  그대로 쓰므로, 배경이 단색이든 이미지든 결과 PNG에는 이미 합성되어 있다.
- **주의**: 배경 이미지를 쓰면서 동시에 "배경 투명 PNG 내보내기"를 기대할 수 없다 —
  이미지 모드는 그 자체로 불투명한 배경을 의미한다. 이는 당연한 제약이라 별도 경고
  UI까지는 만들지 않는다.

## 구현 계획

1. `shaderTextDissolve.ts`: `BACKGROUND_MODES`에 `'image'` 추가, 타입·정규화 함수
   (`backgroundMode()`) 갱신
2. `composeShaderTextDissolve.ts`: `drawShaderTextDissolve()`에 `backgroundImage`
   파라미터 추가, 배경 합성 분기 추가(3절 코드 참고)
3. `loadShaderTextSilhouette()` 재사용 또는 범용화(2절)
4. `page.tsx`: `backgroundImage` state 추가, 업로드 핸들러 연결, `ShaderTextCanvas`에
   prop 전달
5. `ShaderTextCanvas.tsx`: `backgroundImage` prop 받아 `drawShaderTextDissolve` 호출에 전달
6. `ShaderTextControls.tsx`: Background 섹션에 "이미지" 옵션·업로드 UI 추가
7. esbuild+Playwright 헤드리스로 배경 이미지 합성이 실제로 되는지(cover 크롭 포함)
   렌더링해 확인 — 이번 대화에서 써 온 검증 방식 그대로

## 유예된 판단 (이 티켓에서 다루지 않음)

- contain(레터박스) 방식은 이번 범위에서 만들지 않는다 — cover만 지원
- 배경 이미지에도 블러·색보정 같은 추가 편집 옵션은 넣지 않는다(있는 그대로 합성)
- 배경 이미지를 프리셋/재편집용으로 영구 저장(Storage 업로드 후 URL 저장)할지는
  향후 필요성이 확인되면 별도 티켓 — 이번 범위는 실루엣과 동일하게 "세션 동안만
  유지, 재편집 시 재업로드"로 제한한다

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
`BACKGROUND_MODES`에 `'image'`를 추가하고, `drawShaderTextDissolve()`에 4번째 인자
`backgroundImage: HTMLImageElement | null`를 받아 티켓 3절 코드 그대로 cover 방식 배경 합성
분기를 추가했다. 실루엣 로더 `loadShaderTextSilhouette`는 이름을 범용화해
`loadShaderTextImage`로 바꾸고 배경 이미지 로딩에도 재사용했다(로직 복제 없음). `page.tsx`에
`backgroundImage`/`backgroundFile` state를 `silhouetteImage`와 대칭으로 추가하고
`ShaderTextCanvas`에 prop으로 전달했다. `ShaderTextControls.tsx`의 Background Select에
"배경 이미지" 옵션을 추가하고, `mode === 'image'`일 때 실루엣 업로드 UI와 동일한 패턴(파일
input + 선택된 파일명 표시)을 그대로 재사용했다. Select에서 모드를 바꿔도 `backgroundImage`
state는 유지하므로 "이미지"로 되돌아오면 이전에 올린 이미지가 복원된다(티켓 명시 동작).
