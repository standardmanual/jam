# [Admin] 쉐이더 텍스트 생성기 메뉴와 기능 제거

## 배경 / 문제 정의

2026-09-12에 신설한 어드민 "쉐이더 텍스트 생성" 도구(디졸브 에코 이펙트, 티켓
`20260912_1532` 및 후속 개선 티켓 `20260912_1729`·`20260912_1742`·`20260912_1840`)를
사용자 요청으로 완전히 제거한다. 같은 날 밤 별도로 신설된 "쉐이더 랩"(`/admin/shader-lab`,
티켓 `20260912_1951`·`20260912_2157`)은 이 기능과 **별개의 어드민 메뉴**이며 제거 대상이
아니다 — 쉐이더 랩이 쉐이더 텍스트를 대체·흡수한 관계가 아니므로, 쉐이더 랩은 그대로 두고
쉐이더 텍스트 생성기만 걷어낸다.

두 기능의 유일한 접점은 쉐이더 랩의 텍스트 레이어가 쉐이더 텍스트 모듈의 상수
`PRETENDARD_VARIABLE_CSS_URL`(가변 폰트 CDN URL)을 값 복사 없이 그대로 import해 쓰고
있다는 점이다. 이 상수를 옮기지 않고 소스 파일을 삭제하면 쉐이더 랩 빌드가 깨진다.

## 상세 요구사항

### 서비스/코드베이스 관점

1. **어드민 페이지 삭제** — `jam-web/src/app/admin/shader-text/` 디렉토리 전체
   (`layout.tsx`, `page.tsx`, `ShaderTextBadgeApply.tsx`, `ShaderTextCanvas.tsx`,
   `ShaderTextControls.tsx`, `ShaderTextExportPanel.tsx`, `ShaderTextPresetPanel.tsx`)
2. **API 라우트 삭제** — `jam-web/src/app/api/admin/shader-text/` 디렉토리 전체
   (`generate/route.ts`, `search/route.ts`, `presets/route.ts`, `presets/[id]/route.ts`)
3. **라이브러리 삭제**:
   - `jam-web/src/lib/admin/composeShaderTextDissolve.ts`
   - `jam-web/src/lib/admin/shaderTextBadgeSearch.ts`
   - `jam-web/src/lib/admin/shaderTextRingField.ts`
   - `jam-web/src/lib/admin/shaderTextDissolve.ts` — **단, `PRETENDARD_VARIABLE_CSS_URL`
     상수를 먼저 다른 위치(예: `jam-web/src/lib/admin/shaderLab/textFontOptions.ts` 또는
     신규 공용 상수 파일)로 옮기고, `jam-web/src/app/admin/shader-lab/layout.tsx` 2행의
     import 경로를 갱신한 뒤에 삭제한다.**
4. **어드민 내비게이션 메뉴 제거** — `jam-web/src/components/admin/adminNavItems.ts` 89행
   `{ href: '/admin/shader-text', label: '쉐이더 텍스트 생성', icon: IconTypography }` 삭제
   (90행 쉐이더 랩 항목은 유지)
5. **테스트 갱신** — `jam-web/src/components/admin/__tests__/adminNavItems.test.ts`에서
   `/admin/shader-text` 경로 검증 항목 제거
6. **잔여 주석 정리** (선택, 빌드에는 영향 없음) — `shader-lab/ShaderLabParamField.tsx`,
   `shader-lab/ShaderLabWebGpuGate.tsx`, `shader-lab/ShaderLabSavePanel.tsx`,
   `shaderLab/textFontOptions.ts`, `shaderLab/composition.ts`에 남은 쉐이더 텍스트 언급 주석
   중 오해 소지가 있는 것만 정리
7. **DB 마이그레이션** — `public.shader_text_presets` 테이블은 이미 프로덕션에 적용되어
   있다(마이그레이션 167). 기존 마이그레이션 파일은 수정하지 않고, `DROP TABLE`을 수행하는
   **신규** 마이그레이션 파일을 작성한다 (관련 RLS 정책 포함 정리). **jam-developer는 SQL
   파일 작성까지만 하고 실행하지 않는다** — 실행은 사용자 승인 후 오케스트레이터가 처리
   (`/jam-work` 4단계).
8. **범위 밖**: 이 도구로 이미 생성해 배지에 적용한 이미지(`badges.image_url`,
   `badges.image_gen_params`에 `generator: "shader-text-dissolve"`로 저장된 값)는 건드리지
   않는다 — 도구만 제거하고 이미 만들어진 결과물은 유지한다.

## 구현 계획

1. `shaderTextDissolve.ts`의 `PRETENDARD_VARIABLE_CSS_URL` 상수를 이동하고 쉐이더 랩의
   import를 갱신한다 (먼저 처리 — 순서를 지키지 않으면 빌드가 깨진 상태로 남는다).
2. 위 파일·디렉토리들을 삭제한다.
3. `adminNavItems.ts`·해당 테스트 파일을 갱신한다.
4. `DROP TABLE public.shader_text_presets` 마이그레이션 SQL 파일을 신규 작성한다
   (`jam-web/supabase/migrations/` 다음 번호).
5. 삭제 후 `npm run typecheck`·`npm run lint`로 끊어진 import·미사용 참조가 없는지 확인한다.
6. 로컬 실렌더로 어드민 내비게이션에서 "쉐이더 텍스트 생성" 메뉴가 사라졌는지, 쉐이더 랩
   화면(특히 텍스트 레이어의 폰트 로딩)이 정상 동작하는지 확인한다
   (`DEV_PROCESS_GUARDRAILS.md` 패턴 13).

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약

1. `PRETENDARD_VARIABLE_CSS_URL` 상수를 `shaderTextDissolve.ts`에서
   `shaderLab/textFontOptions.ts`로 이관하고, `shader-lab/layout.tsx`의 import를
   `@/lib/admin/shaderLab/textFontOptions`로 갱신했다(먼저 처리해 빌드 단절 구간이 없게 함).
2. `/admin/shader-text` 어드민 페이지 7개 파일, `/api/admin/shader-text` API 라우트 4개
   파일, `lib/admin`의 쉐이더 텍스트 전용 라이브러리 4개 파일을 삭제했다.
3. `adminNavItems.ts`에서 쉐이더 텍스트 생성 메뉴 항목과 미사용이 된 `IconTypography` import를
   제거했다(쉐이더 랩 항목은 유지). `adminNavItems.test.ts`의 디자인 그룹 검증 목록에서도
   해당 경로를 제거하고 회귀 사유를 주석으로 남겼다.
4. 선택 항목이던 잔여 주석 정리도 함께 수행했다 — `ShaderLabParamField.tsx`·
   `ShaderLabWebGpuGate.tsx`·`ShaderLabSavePanel.tsx`·`shaderLab/composition.ts`·
   `shaderLab/textFontOptions.ts`에 남아 있던, 삭제될(된) 파일·라우트를 가리키던 주석을
   해당 파일이 없어져도 뜻이 통하도록 다시 썼다.
5. `public.shader_text_presets`를 `DROP TABLE IF EXISTS`로 정리하는 신규 마이그레이션
   `169_drop_shader_text_presets.sql`을 작성했다(원본 167 파일은 수정하지 않음). 167에는
   명시적 `POLICY`가 없고 `ENABLE ROW LEVEL SECURITY`만 있어 `DROP TABLE`이 그 설정까지
   함께 정리한다 — 별도 `DROP POLICY` 구문은 불필요.
6. 이미 배지에 적용된 `badges.image_url`/`image_gen_params`(`generator:
   "shader-text-dissolve"`)는 손대지 않았다(범위 밖 명시 사항).

### 주요 의사결정 / 핵심 메모

- `PRETENDARD_VARIABLE_CSS_URL` 이관 위치는 티켓이 예시로 든
  `shaderLab/textFontOptions.ts`를 그대로 선택했다 — 이 파일이 이미 쉐이더 랩 텍스트
  레이어의 폰트 관련 상수(`SHADER_LAB_TEXT_FONT_CSS_VARIABLE`)를 담고 있어 응집도가 높다.
  신규 공용 상수 파일을 따로 만들지 않았다(사용처가 `shader-lab` 하나뿐이라 과잉 추상화로
  판단).
- 마이그레이션 167이 `POLICY` 없이 `ENABLE ROW LEVEL SECURITY`만 적용한 방식이었음을
  확인하고, 169는 `DROP TABLE`만으로 충분하다고 판단했다(정책이 없으니 별도로 드롭할 정책도
  없음).
- 잔여 주석 정리(선택 항목)는 티켓이 명시한 5개 파일 전부에 적용했다 — 삭제된 파일
  (`ShaderTextPresetPanel.tsx`, `/admin/shader-text` 라우트)을 가리키는 주석을 그대로 두면
  이후 독자가 존재하지 않는 파일을 찾아보게 되는 오해 소지가 있다고 판단했다.

### 잔여 이슈
