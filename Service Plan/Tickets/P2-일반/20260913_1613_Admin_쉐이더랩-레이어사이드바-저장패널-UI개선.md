# [Admin] 쉐이더 랩 — 레이어 사이드바·저장 패널 UI 개선

## 배경 / 문제 정의

사용자가 `/better-interface`로 `/admin/shader-lab`을 검토해달라고 요청했고, 실제 사용 중
다음 4가지 문제를 직접 보고했다.

1. 레이어 추가 드롭다운(29개 옵션)이 PC·모바일 모두에서 화면에 잘려 선택할 수 없다.
2. 저장/불러오기 패널이 항상 펼쳐진 카드 하나를 통째로 차지해 레이어 목록이 아래로 밀린다.
3. 레이어 행의 아이콘(표시·위로·아래로·삭제)이 자리를 너무 차지해 레이어 이름이 잘린다.
4. 레이어/미리보기/속성 카드의 설명 문구가 불필요하다.

better-interface 검토 결과, 1·3번은 코드 레벨 원인이 확인된 HIGH 등급 결함이었다.

## 검토에서 확인된 원인과 결정된 방향

### 1. 레이어 추가 드롭다운 (HIGH)

`jam-web/src/components/admin/ui/select.tsx`의 `SelectContent` 내부 `SelectPrimitive.Viewport`가
`position === 'popper'`일 때 높이를 `h-[var(--radix-select-trigger-height)]`(트리거 버튼
자신의 높이, 약 40px)로 고정해뒀다. 바깥 `SelectContent`는 이미 충돌 인식 가용 높이
(`--radix-select-content-available-height`)로 `max-h`를 걸어뒀는데, 안쪽 뷰포트가 그 공간을
못 쓰고 트리거 높이에 갇혀 29개 항목이 사실상 한 줄씩만 보이는 좁은 창에 갇힌다.

**수정 방향**: `select.tsx`는 어드민 전체가 공유하는 원시 컴포넌트다. popper 모드의
`Viewport` 높이 고정(`h-[var(--radix-select-trigger-height)]`)을 제거하고
`w-full min-w-[var(--radix-select-trigger-width)]`만 남긴다. 다른 화면의 Select에 미치는
영향(짧은 목록이 트리거보다 커 보이지 않는지)을 실렌더로 확인할 것.

### 2. 레이어 추가 드롭다운 그룹화 (MEDIUM)

`jam-web/src/lib/admin/shaderLab/effectRegistry.ts`에 이미 `kind: 'source' | 'effect'`
필드가 있다(1281번째 줄부터 각 레이어 정의). `select.tsx`가 이미 export하지만 안 쓰이는
`SelectGroup`/`SelectLabel`을 `ShaderLabLayerSidebar.tsx:46-58`의 드롭다운에 적용해
"소스"(6종)·"이펙트"(23종) 2그룹으로 나눈다.

**이번 범위에는 포함하지 않음**: `command.tsx`(검색형 콤보박스)로 완전히 바꾸는 것은
범위가 더 크다 — 1·2번 수정 후에도 여전히 찾기 불편하면 별도 티켓으로 판단한다.

### 3. 레이어 행 아이콘 과밀 (HIGH)

`ShaderLabLayerSidebar.tsx:67-126`. 260px 사이드바 컬럼(`page.tsx:95`
`lg:grid-cols-[260px_1fr_320px]`) 안에서 카드 패딩(48px)·아이콘 4개(표시·위로·아래로·삭제,
각 28px=112px)·gap(24px)을 빼면 레이어 이름에 남는 폭이 약 60px뿐이다. 한글 레이어 이름
대부분이 2~3자만 보이고 잘린다. `title` 속성은 있지만 마우스 호버에서만 동작해 터치·키보드
사용자는 전체 이름을 볼 방법이 없다.

**수정 방향**: 표시(눈) 토글만 인라인에 남기고, 위로·아래로·삭제는
`jam-web/src/components/admin/ui/dropdown-menu.tsx`로 묶어 "⋮ 더보기" 버튼 하나로
압축한다. 보이는 버튼이 4개 → 2개로 줄어 이름에 폭이 돌아온다. 위로/아래로가 비활성화되는
경계(첫 번째/마지막 항목)는 메뉴 안에서도 `disabled`로 유지한다.

### 4. 저장/불러오기 위치 (MEDIUM)

현재 `page.tsx:115-123`에서 레이어 카드 바로 아래 항상 펼쳐진 별도 카드로 저장/불러오기
전체(이름 입력+저장 버튼+목록+안내문, `ShaderLabSavePanel.tsx`)를 보여준다. 저장/불러오기는
가끔 쓰는 보조 동작인데 상시 카드 하나를 통째로 차지해 자주 쓰는 레이어 목록이 화면
아래로 밀린다.

**수정 방향**: 사용자 제안대로 페이지 제목("쉐이더 랩", `page.tsx:86`) 우측에 이름 입력
+ 저장 버튼 + "목록" 버튼만 컴팩트하게 배치하고, "목록" 버튼을 누르면
`jam-web/src/components/admin/ui/popover.tsx`로 여는 팝업 안에 기존 목록 UI(불러오기/삭제,
`ShaderLabSavePanel.tsx`의 목록 렌더링 부분)를 넣는다. `ShaderLabSavePanel.tsx`의 상태
관리(로직)는 그대로 재사용하고 UI 배치만 "헤더 인라인 폼 + 팝오버 목록"으로 재구성한다
(컴포넌트를 분리할지 하나로 유지한 채 조건부 렌더링할지는 구현 시 판단).

### 5. 설명 텍스트 정리 (LOW)

다음 3곳의 `CardDescription`은 삭제한다 — 카드 제목과 실제 동작만으로 이미 자명하고
어떤 행동도 안내하지 않는 문장이다.

- `page.tsx:118` "작업 유실 방지용 최소 저장이에요." (저장/불러오기 카드 — 4번 수정으로
  이 카드 구조 자체가 바뀌므로 함께 처리)
- `page.tsx:129` "이 캔버스가 그대로 결과물로 내보내져요(WYSIWYG)."
- `page.tsx:140` "선택한 레이어의 값을 조정해요."

### 6. 레이어 순서 설명은 삭제 대신 압축 (MEDIUM — 정보 손실 주의)

`page.tsx:100` "목록 위쪽일수록 나중에(위에) 그려져요."는 **그대로 삭제하지 않는다.** 이
순서(위=나중에 그려짐)는 런타임이 배열을 뒤집어 합성하기 때문(`page.tsx:40-46` 주석 참고)에
직관과 반대다 — 이 문장이 유일한 안내 수단이다.

**수정 방향**: 문장을 상시 노출하는 대신, 레이어 카드 제목("레이어") 옆에 작은 정보
아이콘(`IconInfoCircle` 등 기존 아이콘 세트인 `@tabler/icons-react`에서 선택)을 두고,
마우스 호버(또는 `title` 속성)로 같은 문장을 보여준다. 화면은 깔끔해지고 정보는 완전히
사라지지 않는다.

## 상세 요구사항

### 서비스/코드베이스 관점

1. `select.tsx`의 popper 모드 Viewport 높이 고정 제거.
2. `ShaderLabLayerSidebar.tsx` 추가 드롭다운에 `SelectGroup`/`SelectLabel`로 소스/이펙트
   2그룹 적용.
3. `ShaderLabLayerSidebar.tsx` 레이어 행: 표시 토글만 인라인, 위로/아래로/삭제는
   `DropdownMenu`(⋮ 트리거)로 통합.
4. 저장/불러오기를 페이지 헤더 우측 컴팩트 폼 + `Popover` 목록으로 재구성
   (`page.tsx`/`ShaderLabSavePanel.tsx`).
5. `page.tsx`의 CardDescription 3곳 삭제.
6. `page.tsx`의 레이어 순서 설명을 정보 아이콘 + 호버 텍스트로 대체.

### UI/UX 관점

- 어드민 화면이므로 MODULAR 탐색 절차는 생략한다(기존 정책).
- 신규 의존성 추가 없음 — `dropdown-menu.tsx`/`popover.tsx`/`SelectGroup`/`SelectLabel`
  모두 프로젝트에 이미 있는 컴포넌트다.

### 컨텐츠 관점

- 해당 없음.

## 구현 계획

1. `select.tsx` Viewport 높이 고정 제거 → 어드민 전체 다른 Select 화면(배지 폼 등)에
   회귀가 없는지 로컬 실렌더로 확인.
2. `ShaderLabLayerSidebar.tsx` 드롭다운 그룹화 + 레이어 행 아이콘 `DropdownMenu` 통합.
3. `page.tsx`/`ShaderLabSavePanel.tsx` 저장/불러오기 헤더 이동 + Popover 목록.
4. `page.tsx` CardDescription 3곳 삭제, 레이어 순서 설명을 정보 아이콘으로 대체.
5. 로컬 `ADMIN_EMAILS` 실렌더 확인(드롭다운 29개 항목 스크롤·그룹 라벨, 더보기 메뉴
   위/아래/삭제 동작, 저장/불러오기 팝오버, 정보 아이콘 호버) — 워크트리 제약으로
   `next dev`/`build` 불가 시 esbuild+playwright 병행 검증.
