# [Admin] 쉐이더 랩 — 리퀴드 메탈 이미지 마스크 지원 + 텍스트/리퀴드 메탈 색상 투명도

## 배경 / 문제 정의

티켓 20260913_1948에서 만든 리퀴드 메탈 레이어를 사용자 피드백에 따라 다음과 같이
수정한다:

1. **배경 전체 적용은 유지** — 이미지를 올리지 않으면 지금처럼 전체 화면에 적용된다.
2. **이미지(벡터 포함)를 올리면 그 이미지 위에 적용** — 원본 라이브러리의 핵심 기능
   (`toProcessedLiquidMetal()`)을 이번엔 실제로 통합한다. 이전 티켓(20260913_1948)에서는
   구현 복잡도 때문에 범위에서 제외했었다.
3. **`shape`(모양) 파라미터를 완전히 제거** — 원/데이지/다이아몬드/메타볼 프리셋은 더 이상
   필요 없다(이미지 유무로만 분기).
4. ~~텍스트 레이어 위에서는 텍스트에 적용~~ — 사용자가 취소함(범위 밖).
5. **배경색(`colorBack`)에 투명도 조절 추가.**

또한 별도로, "모든 색상 설정에 투명도를 지원해달라"는 요청을 조사한 결과, 원본
`@basementstudio/shader-lab`의 TSL 기반 레이어(그라디언트·하프톤·ASCII·디더링 등,
색상 필드 약 30개)는 `hexToRgb`류 유틸이 hex를 항상 6자리로 잘라 알파를 구조적으로
버린다는 것을 확인했다 — 전체 지원은 각 pass 파일을 개별 patch해야 하는 매우 큰 작업이라
사용자와 협의해 **텍스트 레이어(`textColor`)와 리퀴드 메탈(`colorBack`) 두 곳으로만
범위를 좁혔다.**

## 원본 조사 결과 (근거)

- **Canvas 2D의 8자리 hex(`#RRGGBBAA`) 지원**: 실측 확인 — `ctx.fillStyle = '#ff000080'`로
  그린 픽셀의 alpha가 정확히 128(50%)로 나옴. 텍스트 레이어(`text-pass.js`)는 Canvas 2D
  `fillStyle`을 그대로 쓰므로 **패치 없이 UI에서 8자리 hex를 넘기기만 하면 `textColor`
  알파가 그대로 반영된다.**
- **`@paper-design/shaders`의 `getShaderColorFromString`**: 이미 8자리 hex를 완전히
  지원함(코드 확인 완료, 티켓 20260913_1948에서 이미 검증됨) — 리퀴드 메탈의 `colorBack`도
  패치 없이 UI 변경만으로 알파가 반영된다.
- **`toProcessedLiquidMetal(file)`**: 순수 브라우저 API(Canvas 2D, `Image`)로 동작하며
  SVG를 명시적으로 지원한다(`isSVG` 분기, `svgMaxSize=4096`). 포아송 방정식을 512px
  작업 크기·40회 반복(SOR)으로 풀어 이미지 형태의 부드러운 엣지 마스크를 만들고,
  `canvas.toBlob()`으로 PNG blob을 반환한다 — Web Worker 없이 메인 스레드에서 동작한다.
- **원본 `LiquidMetal` React 컴포넌트의 이미지 처리**: `toProcessedLiquidMetal(url).then(
  (result) => URL.createObjectURL(result.pngBlob))`로 처리된 PNG를 Object URL로 만들어
  `u_image`에 넘긴다. 코어 `ShaderMount` 클래스는 문자열 URL을 받으면 무시하고 경고만
  내므로(20260913_1948에서 이미 확인), Object URL을 `new Image()`로 로드해
  `HTMLImageElement`로 변환한 뒤 넘겨야 한다(투명 픽셀 처리와 동일한 패턴).
- **기존 image 레이어의 asset 업로드 흐름**: `ShaderLabPropertiesPanel.tsx`가
  `layer.type === 'image'`일 때 파일 입력을 보여주고 `patch({ asset: { kind: 'image', src,
  fileName } })`로 저장한다. `pipeline-manager.js`의 `applyLayerState()`는
  `pass instanceof MediaPass`일 때만 `asset`을 `setMedia()`로 전달하는 특별 분기가 있다 —
  `LiquidMetalPass`에도 동일한 성격의 분기(`pass instanceof LiquidMetalPass`)를 patch로
  추가해야 한다.

## 상세 요구사항

### 리퀴드 메탈 — 이미지 마스크 지원

1. `effectRegistry.ts`의 `liquidMetalFields`에서 `shape` select 필드 제거.
2. `ShaderLabPropertiesPanel.tsx`에서 `layer.type === 'liquid-metal'`일 때도 이미지 업로드
   UI를 노출(문구는 image 레이어와 다르게 — "이미지를 올리면 그 형태에 리퀴드 메탈을
   입혀요. 올리지 않으면 배경 전체에 적용돼요").
3. `liquid-metal-pass.js` patch:
   - `setImageAsset(src)` 메서드 신규 추가 — `toProcessedLiquidMetal(src)` 호출 →
     `pngBlob`을 Object URL로 변환 → `new Image()`로 로드해 `HTMLImageElement`로 확보,
     원본 종횡비(`imageData.width / imageData.height`)도 함께 저장.
   - 이미지가 있으면 `u_image=업로드이미지`, `u_isImage=true`,
     `u_imageAspectRatio=저장한종횡비`. 없으면 기존처럼 투명 픽셀 + `u_isImage=false`
     (배경 전체 모드).
   - `u_shape`는 항상 `LiquidMetalShapes.none`(0)으로 고정.
4. `pipeline-manager.js` patch: `applyLayerState()`에 `pass instanceof LiquidMetalPass`일
   때 `asset`을 `pass.setImageAsset(asset?.src ?? null)`로 전달하는 분기 추가(MediaPass
   분기와 병렬).

### 색상 투명도 (텍스트 레이어 `textColor` + 리퀴드 메탈 `colorBack`)

5. `paramFields.ts`의 `ColorFieldDefinition`에 `alpha?: boolean` 옵션 추가(기본
   false — 나머지 36개 색상 필드는 영향 없음).
6. `ShaderLabParamField.tsx`의 `type === 'color'` 렌더러에서 `field.alpha`가 true면
   hex6 컬러피커 + 알파 슬라이더(0~1) 조합 UI로 렌더링(내부 값은 8자리 hex
   `#RRGGBBAA`로 합쳐서 저장). false/undefined면 기존 그대로.
7. `effectRegistry.ts`: `textFields`의 `textColor`에 `alpha: true`(기본값 `#ffffffff`),
   `liquidMetalFields`의 `colorBack`에 `alpha: true`(기본값 `#AAAAACFF`).
8. `text-pass.js`/`liquid-metal-pass.js`는 패치 불필요(위 조사 결과대로 8자리 hex를
   그대로 통과시키면 런타임이 알파를 이미 반영함) — 실측으로 재확인만 한다.

## 구현 계획

1. `paramFields.ts`/`ShaderLabParamField.tsx`에 알파 지원 UI 인프라 추가.
2. `effectRegistry.ts`: `textColor`/`colorBack`에 `alpha: true` 지정, `liquidMetalFields`
   에서 `shape` 제거.
3. `liquid-metal-pass.js` patch: `setImageAsset()` 추가, shape 로직 제거.
4. `pipeline-manager.js` patch: `LiquidMetalPass`용 asset 전달 분기 추가.
5. `ShaderLabPropertiesPanel.tsx`: 리퀴드 메탈에도 이미지 업로드 UI 노출.
6. esbuild+playwright 실측:
   - PNG 이미지 업로드 시 그 형태에 리퀴드 메탈이 입혀지는지(이미지 없을 때와 렌더링
     결과가 다른지)
   - SVG 이미지 업로드도 정상 처리되는지(라이브러리의 SVG 특별 처리 분기 확인)
   - `colorBack` 알파를 0.3 정도로 낮췄을 때 실제로 배경이 투명하게(아래 레이어가
     비쳐 보이거나, 최종 알파 채널 값이 낮게) 나오는지
   - 텍스트 레이어 `textColor` 알파를 낮췄을 때 실제로 텍스트가 반투명하게 나오는지
   - 이미지 asset을 제거(다시 없앰)했을 때 배경 전체 모드로 정상 복귀하는지
7. `npx tsc --noEmit`, `npm run lint`, `npx vitest run` 재확인.

## 유예된 판단

- 나머지 약 30개 색상 필드(그라디언트·하프톤·ASCII·디더링 등)의 투명도 지원은 이번
  범위 밖(원본 런타임이 알파를 구조적으로 버리는 큰 제약, 사용자와 협의해 제외 확정).
- 리퀴드 메탈의 `colorTint`는 투명도 요청 대상이 아니었으므로 그대로 둔다.
