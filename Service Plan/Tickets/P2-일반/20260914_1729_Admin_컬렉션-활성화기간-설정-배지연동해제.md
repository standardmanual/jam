# [Admin] 컬렉션 활성화 기간(시작-종료) 설정 및 배지 연동 해제

## 배경 / 문제 정의
현재 `item_books`(컬렉션) 테이블은 `is_active` boolean만 갖고 있고, 어드민 화면
(`ItemBookTable.tsx`의 `ItemBookActiveToggleButton`)에서도 단순 on/off 토글만 지원한다.
컬렉션을 비활성화하면 `jam-web/src/lib/admin/itembook-deactivation.ts`의
`cascadeDeactivateItemBookBadges`가 소속 배지 전체를 연쇄 비활성화(`deleted_at` 세팅 +
`deactivated_by_item_book_id` 기록)하고, 재활성화 시 `cascadeActivateItemBookBadges`가
그 배지들만 되살린다.

사용자 요청은 다음 두 가지다.
1. 컬렉션에 시작-종료 기간을 지정해 예약 노출(및 자동 만료)이 가능하게 한다. 배지 상세화면에
   이미 있는 기간 설정 UI/로직을 참고한다.
2. 컬렉션의 활성 상태와 소속 배지의 활성 상태를 더 이상 연동하지 않는다. 컬렉션이 비활성(또는
   기간 밖)이어도 소속 배지의 `item_book_id` 지정 목록은 그대로 유지하고, 배지 자체의 활성
   여부는 컬렉션과 무관하게 독립적으로 관리된다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `item_books` 테이블에 활성화 시작/종료 시각 컬럼을 추가한다(마이그레이션 파일 작성, 배지
  상세화면의 기존 기간 컬럼·판정 로직을 참고해 동일한 패턴으로 맞춘다).
- 컬렉션의 "활성 상태" 판정은 기간(시작 ≤ 현재 < 종료, 종료 미설정 시 시작 이후 계속 활성 등
  배지 쪽 기존 규칙과 동일하게) 기준으로 계산한다.
- `cascadeDeactivateItemBookBadges` / `cascadeActivateItemBookBadges` 및 이를 호출하는
  지점을 제거한다. 컬렉션 활성화/비활성화(또는 기간 설정) 작업이 배지의 `deleted_at`,
  `deactivated_by_item_book_id`를 더 이상 건드리지 않게 한다.
- 배지 노출 판정 로직(서비스 측 컬렉션/배지 조회 API·쿼리)에서: 배지가 소속된 컬렉션이 비활성
  (기간 밖 포함)이면 **컬렉션**은 노출하지 않는다. 배지 자체는 컬렉션 상태와 무관하게 자신의
  활성 여부로만 노출 판단한다. 즉 컬렉션 비활성 시에도 배지-컬렉션 연결(`item_book_id`)은
  삭제·해제하지 않고 유지한다.
- `deactivated_by_item_book_id` 컬럼(마이그레이션 146)이 이번 변경으로 더 이상 쓰이지 않게
  되면 사용처 전체를 확인하고 정리 방향을 구현 단계에서 판단한다(즉시 컬럼 삭제까지는 이번
  티켓 범위인지 여부를 구현 시 재검토 — 최소 범위로는 코드 참조 제거만 하고 컬럼 자체는
  후속 티켓으로 미뤄도 됨).

### UI/UX 관점 (해당 시)
- 컬렉션 상세화면(어드민)에 시작일시-종료일시 입력 UI를 추가한다. 배지 상세화면의 동일 UI
  컴포넌트/패턴을 그대로 재사용한다(신규 컴포넌트 제작 금지, 기존 것을 확인하고 재사용).
- 기존 `ItemBookActiveToggleButton`(단순 on/off)은 기간 기반 설정과의 관계를 정리한다
  (완전 대체할지, 병기할지는 배지 상세화면의 기존 패턴을 그대로 따른다).

### 컨텐츠 관점 (해당 시)
- 해당 없음.

## 구현 계획
> 배지 상세화면의 기간 설정 구현(컬럼명, UI 컴포넌트, 활성 판정 함수)을 먼저 찾아 그대로
> 답습하는 것이 핵심이다. 새로운 패턴을 고안하지 않는다.
1. 배지 쪽 기간 설정 컬럼·UI·판정 로직 위치 확인
2. `item_books`에 동일 패턴의 기간 컬럼 추가 마이그레이션 작성
3. 컬렉션 상세화면에 기간 입력 UI 추가
4. `itembook-deactivation.ts`의 캐스케이드 로직 제거 및 호출부 정리
5. 컬렉션/배지 노출 쿼리에서 "컬렉션 비활성 시 컬렉션만 미노출, 배지-컬렉션 연결 유지" 규칙 반영
6. `deactivated_by_item_book_id` 잔존 참조 확인 및 정리 방향 기록
