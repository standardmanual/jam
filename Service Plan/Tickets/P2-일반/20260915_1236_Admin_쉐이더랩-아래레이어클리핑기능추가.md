# [Admin] 쉐이더 랩 — 레이어별 "아래 레이어에 클리핑" 옵션 추가

## 배경 / 문제 정의

이미지 레이어(투명 영역이 있는 PNG) 위에 그라디언트·디더링·패턴 같은 이펙트 레이어를 쌓으면,
그 이펙트가 이미지의 투명 영역까지 뒤덮어버린다. 사용자는 이미지의 투명한 부분에는 위에 쌓은
이펙트도 적용되지 않기를 원한다(Photoshop의 "아래 레이어에 클리핑"과 동일한 개념).

기존 합성 방식(`buildBlendNode()`의 `filter` 모드, 표준 소스-오버 알파 합성)은 레이어를 쌓을
때마다 알파가 항상 커지는 쪽으로만 동작한다 — 위에 올린 레이어가 자기 알파를 갖고 있으면
그 영역만큼 최종 알파도 늘어난다. 이건 "빈 캔버스에 새 이펙트로 모양을 만드는" 워크플로우에는
맞지만, "이미 만들어진 이미지 모양 안에서만 이펙트를 장식으로 쓰고 싶다"는 워크플로우에는
맞지 않는다.

## 상세 요구사항

### 서비스/코드베이스 관점

- 항상 켜진 기본 동작이 아니라 **레이어별로 켜고 끌 수 있는 옵션**으로 만든다(사용자 결정) —
  기존에 이펙트로 캔버스 전체를 새로 채우던 작업물이 이번 변경으로 깨지면 안 된다.
- 옵션이 꺼져 있으면(기본값) 기존 동작 그대로 — 알파가 커질 수 있다.
- 옵션이 켜져 있으면 그 레이어는 자신보다 아래(먼저 그려진) 레이어들의 누적 알파가 이미
  차지한 영역 안에서만 섞이고, 최종 알파도 그 누적 알파를 절대 넘지 않는다.

## 구현 계획

1. `types.d.ts`: `ShaderLabLayerConfig`에 `clipToBelow?: boolean` 추가.
2. `blend-modes.js`: `buildBlendNode()`에 `clipToBelow` 매개변수를 추가하고, `filter` 분기에서
   켜져 있으면 `blendFactor`에 `baseAlpha`를 한 번 더 곱하고 `outAlpha`를 `baseAlpha` 그대로
   유지하도록 분기(빌드 시점 JS 분기, TSL 런타임 `select()` 아님 — 레이어 설정이 바뀔 때만
   colorNode 자체를 다시 빌드하는 기존 `compositeMode` 패턴과 동일).
3. `pass-node.js`: `clipToBelow` 필드 + `updateClipToBelow()`(변경 시 `colorNodeDirty=true`,
   기존 `updateCompositeMode()`와 동일 패턴) 추가, `composeColorNode()`가 `buildBlendNode()`에
   전달.
4. `pipeline-manager.js`: 레이어 시그니처(`createLayerSignature`)에 `clipToBelow` 포함(값이
   바뀌면 재적용 트리거), `applyLayerState()`가 `pass.updateClipToBelow()` 호출.
5. `layerFactory.ts`: 신규 레이어 기본값 `clipToBelow: false`.
6. `ShaderLabPropertiesPanel.tsx`: "화면에 표시" 스위치 옆에 "아래 레이어에 클리핑" 스위치
   추가(레이어 공통 속성이라 특정 레이어 타입의 `params`가 아니라 레이어 최상위 필드로 둠).
7. 로컬 esbuild+실제 WebGPU 브라우저 실렌더로: 절반 투명 이미지 레이어 위에 그라디언트
   레이어를 올려 클리핑 켜짐/꺼짐 각각 투명 영역이 실제로 제외/포함되는지 확인.
8. `npx patch-package @basementstudio/shader-lab`, `npm install` 재적용성, `npx tsc --noEmit`,
   `npm run lint`.

## 완료 기록

### 구현 내용 요약

구현 계획 1~8 그대로 진행했다. `clipToBelow`가 켜졌을 때의 수식은:

```js
const blendFactor = clipToBelow ? rawBlendFactor.mul(baseAlpha) : rawBlendFactor;
const outAlpha = clipToBelow ? baseAlpha : baseAlpha.add(blendFactor.mul(float(1).sub(baseAlpha)));
```

`rawBlendFactor = opacity × 이 레이어 자신의 알파`다. 클리핑이 꺼져 있으면(기본값) 기존
20260914_1045/20260915_1042의 표준 소스-오버 공식과 100% 동일해 회귀가 없다.

### 주요 의사결정 / 핵심 메모

- **항상 켜진 기본 동작이 아니라 레이어별 옵션으로 결정**했다(사용자 확인) — 지금까지 만든
  배지 중 이펙트로 캔버스 전체를 새로 채우는 방식(예: 20260915_1125에서 투명 배경 지원을
  추가한 ink·pattern 등)이 있을 수 있어, 기본 동작을 강제로 바꾸면 그 결과물들이 예고 없이
  달라질 위험이 있었다.
- **TSL 런타임 `select()`가 아니라 JS 빌드 시점 분기를 썼다**: `clipToBelow`는 레이어
  설정값(사용자가 스위치를 토글할 때만 바뀌고, 매 프레임 바뀌는 값이 아니다)이라
  `compositeMode`와 똑같이 값이 바뀔 때만 `colorNodeDirty=true`로 셰이더 그래프 자체를
  다시 빌드하는 게 더 단순하고, 매 프레임 불필요한 런타임 분기 비용도 없다.
