# [UI] 컬렉션 상세화면 대표 이미지+이름 영역을 배지 상세화면 구조와 통일

## 배경 / 문제 정의
컬렉션 상세화면(`/collections/[id]`)의 대표 이미지~설명 영역이 배지 상세화면
(`/badges/[id]`)의 동일 영역과 마크업 구조가 달랐다. 배지 상세는 이미지+이름이
`bg-surface-elevated` 카드 하나에 속하고 설명은 카드 밖에 분리돼 있는 반면, 컬렉션 상세는
대표 이미지가 카드 전체를 꽉 채우고 이름·설명이 별도 블록으로 나뉘어 있어 두 상세화면의
시각 구조가 어긋나 있었다.

## 상세 요구사항

### UI/UX 관점
- 수정 대상: 컬렉션 상세화면의 대표 이미지 ~ 설명 영역 (`ItemBookHeroSection.tsx`)
- 수정 방향: 배지 상세화면(`BadgeHeroSection.tsx`)의 동일 영역 구조에 맞춰 변경
  - 이미지 + 이름을 하나의 카드(`bg-surface-elevated`, `rounded-[var(--radius-cards)]`, `p-6`)로 묶음
  - 설명은 카드 밖(`mt-6`)으로 분리
- 추가사항: 배지 이미지 크기(200×200px 고정)에 맞춰 컬렉션 대표 이미지도 동일 크기로 수정

### UI 재사용 판정 (오케스트레이터 결정)
서비스 전용 구현 유지 — MODULAR `_ds_manifest.json`에 히어로 카드 패턴 없음,
`BadgeHeroSection.tsx` 주석에도 'MODULAR 신규 컴포넌트 아님' 명시. `ItemBookHeroSection.tsx`를
`BadgeHeroSection.tsx` 패턴에 맞춰 개별 수정한다.

## 구현 계획
`ItemBookHeroSection.tsx`의 마크업을 `BadgeHeroSection.tsx`와 동일한 구조로 재작성한다.
진행도 바(`ProgressBar`)는 이번 티켓 범위 밖이라 기존 위치·마크업을 유지한다.

  그대로 재사용하므로 별도 수정 없이 함께 반영됨

### 주요 의사결정 / 핵심 메모
- 진행도 바(`ProgressBar`) 영역은 티켓 범위(대표 이미지~설명)에 포함되지 않아 손대지 않았다.
  카드/설명 사이 간격은 `BadgeHeroSection`과 동일하게 `mt-6`을 명시했지만, 설명~진행도 바
  간격은 부모 컨테이너의 `gap-3`만 유지해 기존 리듬을 보존했다.
- 이미지 태그는 기존 `<img>`(원격 이미지, eslint-disable 유지)를 그대로 두고 크기만
  200×200px 고정으로 바꿨다. 배지 상세는 `next/image`를 쓰지만, 이는 이번 티켓 범위 밖의
  구현 방식 차이라 임의로 통일하지 않았다.
