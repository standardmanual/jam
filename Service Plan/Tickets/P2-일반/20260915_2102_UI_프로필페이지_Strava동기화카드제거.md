# [UI] 프로필 페이지 Strava 동기화 카드 제거

## 배경 / 문제 정의

영역을 화면에서 제거한다. (사용자 요청)

## 상세 요구사항

### UI/UX 관점
- 대상: `jam-web/src/app/(main)/profile/ProfileClient.tsx`의 "Strava 연동" 카드
  (본인 프로필 + 기본뷰일 때 노출되던 `<Card tone="inverse">` 블록, 연결/미연결 상태 모두 포함)
- 카드 JSX 블록 전체 삭제
- 카드 삭제로 이 파일에서 미사용이 되는 import(`ActivityIcon`, `formatRelativeTime`) 정리
- 카드에서만 쓰이던 i18n 문구 4개(`d.profile.stravaTitle`, `stravaConnected`,
  `stravaDisconnected`, `stravaConnectButton`, `src/lib/i18n/ko.ts`)가 다른 곳에서
  쓰이지 않는지 재확인 후 정리
- `strava` prop 자체(타입 `StravaConnectionRow | null`)와 페이지 서버 컴포넌트의 데이터
  조회 로직은 이번 범위 밖 — prop이 남아 있어도 기능상 문제 없으면 건드리지 않는다
  (범위 확장 방지)

### 주요 의사결정 / 핵심 메모
- 1차 시도에서 jam-developer가 티켓 파일을 찾지 못해 HALT했다 — 원인은 review 브랜치가
  `origin/staging`을 기점으로 새 워크트리를 만드는데, 오케스트레이터가 만든 티켓 파일이
  로컬 untracked 상태로만 있어 origin에 반영되지 않았기 때문. 티켓 파일을 커밋+push한
  뒤 재시도해 해결
- 2차 시도의 개선 리뷰(`progressive`, 경량 모델) 단계에서 "카드가 삭제되지 않았다"는
  오판이 있었으나, 실제 diff와 브라우저 실렌더 확인 결과 정확히 삭제되어 있었다 —
  제안형 단계의 착오로 판단해 판정에 반영하지 않음
