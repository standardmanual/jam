# [UI] 검색 페이지 TopNav-검색폼 간격 추가 + 검색폼 크기 축소

## 배경 / 문제 정의
`/search` 페이지(`https://j-a-m.app/search`)에서 두 가지 문제가 있다 (사용자 실사용 피드백):
1. TopNav와 검색창 사이에 간격이 전혀 없다 (`pt-0`)
2. 검색폼(입력폼 + 버튼) 자체가 너무 크다 — 체감상 30% 정도 줄여도 될 정도

## 상세 요구사항

### UI/UX 관점
- 대상 파일: `jam-web/src/app/(main)/search/page.tsx`,
  `jam-web/src/app/(main)/UserSearchBar.tsx`
- **간격**: `search/page.tsx`의 컨테이너 `pt-0`을 다른 페이지(홈 `page.tsx`, `inventory/page.tsx`
  등)와 동일한 `pt-[var(--spacing-24)]`로 변경해 TopNav와 검색폼 사이 간격을 준다
- **검색폼 크기**: 세로 크기(패딩·버튼 높이)를 약 30% 축소. **가로폭은 유지한다**
  (`flex-1 min-w-0` 등 가로 관련 클래스는 그대로 둔다)
- **주의**: `UserSearchBar` 컴포넌트는 홈 화면(`(main)/page.tsx`)에서도 재사용된다.
  컴포넌트 자체를 직접 줄이면 홈 화면 검색바도 함께 작아지므로, `/search` 페이지에서만
  작게 렌더링되도록 컴포넌트에 옵션(예: `size` prop)을 추가하고 홈 화면 호출부는 기존
  동작 그대로 유지되게 한다

### UI 재사용 판정 (오케스트레이터 결정)
기존 서비스 컴포넌트(`UserSearchBar`, `Button`)를 그대로 확장 — MODULAR `Button.tsx`에
이미 `xs` 사이즈(조밀한 컨텍스트 전용, 44px 규칙의 명시적 예외)가 정의되어 있어 신규
컴포넌트나 MODULAR 확장 없이 기존 `size` prop 체계로 해결 가능. 신규 UI 추가가 아니므로
디자인 시스템 탐색 절차는 이 판단으로 대체한다.

## 구현 계획
- `UserSearchBar`에 `size?: 'default' | 'compact'`(기본값 `'default'`) prop 추가
  - `compact`일 때: 폼 컨테이너 패딩 축소(`p-[var(--spacing-8)]` → 더 작은 값),
    입력 세로 패딩 축소(`py-2` → 더 작은 값), 버튼을 `size="xs"`로 전환
  - `default`(생략 시)는 기존 마크업과 동일 — 홈 화면 영향 없음
- `search/page.tsx`에서 `<UserSearchBar defaultValue={q ?? ''} size="compact" />`로 호출,
  컨테이너 `pt-0` → `pt-[var(--spacing-24)]`로 수정
- 가로폭에 영향 주는 클래스(`flex-1`, `min-w-0`, 컨테이너 `px-[var(--spacing-16)]`)는
  건드리지 않는다
