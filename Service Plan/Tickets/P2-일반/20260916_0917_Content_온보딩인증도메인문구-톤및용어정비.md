## 배경 / 문제 정의

티켓 20260915_2246의 딕셔너리 이관 구조는 게이트 PASS했지만, 한국어 리뷰가 `d.auth.*` 신규
문구 7종 전체에서 번역투·수동태·§4.1 3단계 미충족·§1.3 미등재 용어("활동 기반 배지")를
지적했다.

## 상세 요구사항 — `jam-web/src/lib/i18n/ko.ts`의 `d.auth` 값 수정

### (a) 에러 3단계 구조(§4.1) 미충족 — 최우선
`stravaSyncError`("Strava 동기화 중 오류가 발생했어요. 잠시 후 다시 시도해 주세요.")는
현상뿐이고 정형구 CTA다. 가이드 §4.1 표에 이미 이 시나리오의 모범답안이 있다:
→ "Strava 동기화가 끊겼어요. 동기화 권한이 해제됐거나 Strava 연결이 잠시 불안정했을 수
있어요." + CTA 버튼 `[Strava 다시 동기화하기]`

### (b) 수동태·시스템 시점 교정
- `stravaNotConnectedTitle`("Strava 동기화 안 됨") → 빈 상태(§4.3)인데 "안 됨"이 실패처럼
  읽힌다 → "아직 Strava를 동기화하지 않았어요"
- `stravaConnectedTitle`("Strava 동기화됨") → "Strava와 동기화하고 있어요"
- `stravaNoSyncYet`("아직 동기화된 데이터가 없어요") → "데이터"는 공급자 언어 → "아직
  불러온 활동이 없어요"

### (c) 미등재 용어(§1.3) — "활동 기반 배지"
`stravaConnectPrompt`의 "활동 기반 배지"는 용어표에 없는 조어다. 컨텐츠 체계의 고정 명칭은
**액티비티배지**다 → "Strava를 동기화하면 달린 기록으로 액티비티배지를 획득할 수 있어요"

### (d) 표기 규칙(§3)
`stravaLastSyncedLabel`("마지막 동기화:")의 콜론은 UI 라벨이 아니라 로그 필드 표기다 →
"마지막 동기화" (콜론 제거). 값 포맷도 §3 날짜/시간 규칙("7월 31일 오후 3시 30분" 형태)을
따르는지 별도 확인.

### (e) 카드 헤더 길이 제약 확인
`stravaNotConnectedTitle`/`stravaConnectedTitle`이 카드 헤더처럼 자리가 좁으면 위 (b) 대안이
길 수 있다 — 필요하면 "Strava 동기화 전" / "Strava 동기화 중"으로 축약하되, 후자가 "지금
진행 중"으로 오독되지 않는지, §5.3 처리 중 라벨과 화면에서 겹치지 않는지 확인한다.

## 구현 계획
- `ko.ts`의 해당 키 값만 수정한다.
- (a)는 CTA 버튼 배치가 필요하므로 `StravaStatusCard.tsx`(또는 실제 렌더 위치)에서 버튼
  추가 여부를 함께 확인한다.
- 완료 후 `/im-not-ai`로 재검사한다.
