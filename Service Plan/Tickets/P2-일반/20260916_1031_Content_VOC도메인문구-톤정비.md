## 배경 / 문제 정의

티켓 20260915_2251의 딕셔너리 이관 구조는 게이트 PASS했지만, 한국어 리뷰가 `loadError`
(구 `loadFailed`)의 §4.1 3단계 미충족·정형구, `emptyBody`의 UI 조작 지시형 문장, 기존
`emptyTitle`의 수동태를 지적했다.

## 상세 요구사항 — `jam-web/src/lib/i18n/ko.ts`의 `d.voc` 값 수정

### (a) `loadError` — §4.1 3단계 구조 미충족 (최우선)
현재("문의 내역을 불러오지 못했어요. 잠시 후 다시 시도해 주세요.")는 현상만 있고 원인이
없으며, 해결책도 CTA가 아니라 서술문이다.
→ "문의 내역을 불러오지 못했어요. 네트워크 연결이 불안정할 수 있어요." + 가능하면 CTA
버튼 `[다시 불러오기]`로 해결책 분리(§5.1 동사형)

### (b) `emptyBody` — UI 조작 지시형 문장
"문의하기 버튼을 눌러 첫 문의를 남겨 보세요"는 화면에 이미 보이는 버튼을 문장으로 다시
지시하는 매뉴얼식 표현이다(§2.2 Bad 예시와 동일 구조).
→ "궁금한 점이 생기면 언제든 문의해 주세요" (버튼 조작 지시 제거, 첫 문의임을 살리고
싶다면 "첫 문의를 남겨 보세요"로 조작 절차만 뗀 형태도 검토)

### (c) `emptyTitle` — 수동태(시스템 시점), 이번 티켓 대상 아니었으나 (b)와 세트로 처리 권장
"아직 등록된 문의가 없어요"의 "등록된"은 시스템이 처리하는 관점이다.
→ "아직 남긴 문의가 없어요" (사용자 시점 능동)

## 구현 계획
- `ko.ts`의 해당 키 값만 수정한다.
- (a)의 CTA 버튼 추가가 필요하면 `voc/page.tsx`의 에러 뷰 구조도 함께 확인한다.
- 완료 후 `/im-not-ai`로 재검사한다.
