# [Content] 배지관리에 등록되지 않은 배지 이미지 파일 삭제

## 배경 / 문제 정의
> 왜 이 작업이 필요한가. 현재 상태와 기대 상태의 차이.

티켓 20260916_1525(배지 이미지 픽셀 크기 전수 조사)의 후속. 사용자가 배지관리(=`badges`
테이블)에 등록되지 않은 배지 이미지 파일을 삭제해달라고 요청.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/public/badges/` 아래 로컬 이미지 파일 3,412개 중, 현재 어떤 배지·아이템북·투데이
  카드에서도 참조하지 않는 파일을 찾아 삭제한다.
- 삭제 전 반드시 아래 4곳 전부를 대조해 "미등록"을 확정한다(하나라도 참조하면 삭제 대상에서
  제외):
  1. `badges.image_url`
  2. `item_books.image_url` / `item_books.background_image_url`
  3. `today_cards.cover_image_url`
  4. `jam-web/src/` 안의 하드코딩 참조(`dev-sample` 페이지 등) — 마이그레이션/시드 SQL은
     이미 적용된 1회성 이력이라 제외 대상에서 다시 뺀다.

## 구현 계획
> 어떻게 구현할지. 접근 방법, 영향 범위, 주요 변경 포인트.

1. `public/badges/` 전체 파일 목록과 `badges.image_url`을 PostgREST로 배치 대조(300개씩
   12회) → 1차 미등록 후보 1,276개.
2. `information_schema.columns`을 스캔해 `/badges/` 패턴을 담을 수 있는 모든 text 컬럼을
   전수 확인 → `item_books.image_url`(55건), `today_cards.cover_image_url`(2건)에서 추가
   참조 발견 → 3개 파일(`s019`, `s065`, `s309`) 제외.
3. 코드베이스 grep으로 마이그레이션/시드 SQL(이미 적용된 이력)과 실제 실행 코드를 구분 —
   `dev-sample/item-badge-serial/page.tsx`의 `s019.png` 하드코딩만 실제 라이브 참조였고
   위 2번에서 이미 제외됨을 재확인.
4. `poi/transit/` 폴더(951개)는 전량 `poi/metro/`와 동일 파일명(배지 id) 중복 — 티켓
   20260824_020(METRO 디자인 929개 일괄 재생성)에서 이미 "미사용으로 남는다"고 예고된
   구 디자인 잔존물임을 과거 티켓으로 교차 확인.
5. 최종 확정 1,273개를 `git rm`으로 삭제.
