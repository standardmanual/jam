# [Admin] 쉐이더 랩 텍스트 레이어에 구글 폰트 선택지 추가

## 배경 / 문제 정의
쉐이더 랩(`/admin/shader-lab`)의 텍스트 레이어는 현재 Pretendard Variable 단일 폰트만
지원한다(`jam-web/src/lib/admin/shaderLab/textFontOptions.ts`). 사용자가 텍스트 레이어에
구글 폰트를 불러와 선택할 수 있도록 기능을 확장해달라고 요청했다.

`@basementstudio/shader-lab` 패키지의 텍스트 렌더링 패스는 임의의 `font-family` 문자열을
받지 않고, 패키지 내부에 고정된 슬롯 이름(`sans`/`mono`/`bsmnt-grotesque`/`adhesion`/
`blob`/`bunker`/`caniche`/`carpenter`/`curia`/`ffflauta`/`numero`/`xer0`/`trovador`/
`b-mecha`/`impact`) 중 하나여야만 실제로 폰트가 반영된다. 그중 `cssVariable`이 지정된
슬롯만 CSS 커스텀 프로퍼티 값을 읽어 실제 웹폰트를 적용할 수 있다. 연속 굵기(range)를
지원하는 슬롯은 `sans`(`--geist-sans`)·`mono`(`--geist-mono`)·`bsmnt-grotesque`
(`--bsmnt-grotesque`) 3개뿐이며, 이미 ASCII 레이어(고딕/고정폭)와 텍스트 레이어
(Pretendard)가 모두 점유하고 있다. 나머지 미사용 슬롯(`adhesion`/`blob`/`bunker`/
`caniche`/`carpenter`/`curia`/`ffflauta`/`numero`/`xer0`/`trovador`/`b-mecha`/`impact`)은
고정 굵기 1개만 지원한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 구글 폰트를 최소 1종 이상, 미사용 고정폭 슬롯을 활용해 텍스트 레이어 폰트 선택지로 추가한다.
- `SHADER_LAB_TEXT_FONT_OPTIONS` 배열 구조(라벨·슬롯 값·굵기 범위)를 그대로 따른다 — 항목만
  추가하면 선택지가 늘어나는 기존 설계를 유지한다.
- 추가하는 구글 폰트는 Google Fonts CSS API(`fonts.googleapis.com`)에서 불러온다.
  `/admin/shader-lab` 라우트(`layout.tsx`)에서만 로드하고, 사이트 전역 타이포그래피에는
  영향을 주지 않는다.
- 선택한 슬롯이 고정 굵기 1개짜리라면, `fontWeightRange`를 `min === max === default`로
  두어 UI 굵기 슬라이더가 실제로 반영되지 않는 값을 보여주지 않도록 한다(기존 Pretendard
  케이스가 range 슬롯을 쓴 것과 달리, 고정폭 슬롯은 굵기 조절 자체가 무의미하다는 점을
  UI에서 드러내거나 숨긴다).
- 가변 굵기가 필요하다면 range 슬롯 3개가 이미 모두 소진된 패키지 한계를 문서에 남기고,
  1차로는 고정 굵기 구글 폰트로 범위를 좁힌다.

### UI/UX 관점 (해당 시)
- 텍스트 레이어 폰트 드롭다운에 새 옵션이 표시되고, 선택 시 쉐이더 랩 미리보기에 실제로
  반영되는지 로컬 실렌더로 확인한다.

### 컨텐츠 관점 (해당 시)
- 해당 없음.

## 구현 계획
1. 추가할 구글 폰트 종류를 정한다(범용성 고려, 예: Noto Sans KR 등 — 한글 지원 여부 확인).
2. `textFontOptions.ts`에 미사용 고정폭 슬롯 하나를 골라 새 옵션을 추가하고, 그 슬롯의
   `cssVariable`을 구글 폰트 값으로 덮어쓰는 상수를 정의한다(기존 `PRETENDARD_VARIABLE_CSS_URL`·
   `SHADER_LAB_TEXT_FONT_CSS_VARIABLE` 패턴을 그대로 따른다).
3. `layout.tsx`에 Google Fonts CSS `<link>`를 추가하고, `:root`에 새 슬롯의 CSS 변수를
   `!important`로 덮어쓰는 `<style>`을 추가한다.
4. 로컬 `npm run dev`로 `/admin/shader-lab`에 접속해 텍스트 레이어에서 새 폰트를 선택하고
   실제 렌더링에 반영되는지 확인한다(로컬 `ADMIN_EMAILS` 셸 환경변수로 인증).
5. 버전 고정 CDN URL을 쓰는 기존 관례(Pretendard `v1.3.9` 고정)에 맞춰, Google Fonts는
   `display=swap` 등 안정적인 쿼리 파라미터로 고정하고 추적 태그를 피한다.
