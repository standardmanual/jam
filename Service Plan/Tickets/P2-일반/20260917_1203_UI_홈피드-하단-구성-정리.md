# [UI] 홈 피드 하단 구성 정리 — 바로가기·최근배지 섹션 제거, Footer 추가

## 배경 / 문제 정의
> 왜 이 작업이 필요한가. 현재 상태와 기대 상태의 차이.

홈 피드(`/`) 하단의 '바로가기' 섹션과 '최근 배지' 섹션을 제거하고, 그 대신 다른 페이지와
동일하게 공통 Footer를 노출한다. 사용자 요청에 따른 홈 화면 구성 단순화.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/(main)/page.tsx`에서 '바로가기' 섹션(약 113번째 줄 이전, 미션·인벤토리·
  드랍·믹스 4개 링크 카드) 마크업 제거
- 같은 파일에서 '최근 배지' 섹션(113~157번째 줄, 데이터 페칭 42~47·59·64·66~73번째 줄 포함)
  마크업 및 관련 쿼리 제거. `Promise.all` 배열 원소 수·구조분해 순서 조정 필요
- `jam-web/src/lib/i18n/ko.ts`에서 두 섹션 전용 키 삭제
  - 바로가기: `shortcutsTitle`, `shortcutMissionTitle/Body`, `shortcutInventoryTitle/Body`,
    `shortcutDropsTitle/Body`, `shortcutCombineTitle/Body` (약 221~230번째 줄)
  - 최근배지: `recentBadgesTitle`, `recentBadgesViewAll`, `recentBadgesEmptyTitle`,
    `recentBadgesEmptyBody` (약 215~219번째 줄)
- `jam-web/src/components/ui/Footer.tsx`의 `FOOTER_EXCLUDED_PATHS` 배열에서 `'/'` 제거
  (기존에는 "상단 로고 중복" 우려로 홈 화면만 제외되어 있었음 — 바로가기·최근배지 섹션 제거로
  홈 화면이 짧아지므로 중복 우려가 완화된다고 판단해 제거 결정. 사용자 확인 완료)
- 두 섹션에서만 쓰이던 import(`MedalIcon`, `RarityBadge`, `BadgeLevelChip`, `EmptyState` 등)는
  다른 섹션에서 재사용 여부를 개별 확인한 뒤 미사용 시에만 제거

### UI/UX 관점 (해당 시)
- 바로가기·최근배지 섹션 제거 후 홈 피드 레이아웃(카드 간 여백 등)이 어색하지 않은지 확인
- Footer 추가 후 상단 로고와 시각적으로 중복되거나 어색해 보이지 않는지 확인

### 컨텐츠 관점 (해당 시)
- 해당 없음 (텍스트 삭제만 발생, 신규 문안 없음)

## 구현 계획
> 어떻게 구현할지. 접근 방법, 영향 범위, 주요 변경 포인트.

1. `page.tsx`에서 바로가기 섹션 마크업 삭제
2. `page.tsx`에서 최근배지 섹션 마크업·쿼리·타입 삭제, `Promise.all` 조정
3. `ko.ts`에서 두 섹션 관련 키 일괄 삭제
4. 미사용 import 정리
5. `Footer.tsx`의 `FOOTER_EXCLUDED_PATHS`에서 `'/'` 제거
6. 로컬 실렌더로 홈 피드 레이아웃·Footer 노출 확인

별도 컴포넌트 신설이나 MODULAR 확장 없음 — 기존 코드 삭제 + 기존 Footer 컴포넌트 재사용.
