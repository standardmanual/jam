# [UI] 컬렉션 상세화면 상단 히어로를 배지 상세화면과 동일 구조로 매칭

## 배경 / 문제 정의
배지 상세화면(`BadgeHeroSection.tsx`, 티켓 20260917_1211/1245)에서 대표 이미지+이름+설명을
1:1 카드 하나로 통합하고, 등급칩+이름과 설명을 하나의 그룹으로 묶어 카드 하단에 붙이는
구조로 개편했다. 컬렉션 상세화면(`ItemBookHeroSection.tsx`)도 같은 구조로 맞춰 두 상세화면의
일관성을 확보한다.

현재 `ItemBookHeroSection.tsx`는 카드(1:1, 이미지+이름)까지는 배지와 구조가 비슷하지만:
- 설명이 카드 **밖**(`mt-6`)에 별도 `<p>`로 있음 (배지는 카드 안)
- 이름이 이미지 바로 아래 고정(`pt-4`)이라, 배지처럼 "이름+설명 그룹이 카드 하단에 붙는"
  모양이 아님
- 문장 마침표 기준 자동 줄바꿈 미적용 (원본 `whitespace-pre-line` 통짜 렌더)

## 상세 요구사항

### 서비스/코드베이스 관점
- 대상 파일: `jam-web/src/app/(main)/collections/[id]/ItemBookHeroSection.tsx`
- 카드 크기(1:1 `aspect-square`)는 이미 배지와 동일 — 유지
- 대표 이미지(200×200, `object-contain`)도 이미 배지와 동일 — 유지
- 설명(`book.description`)을 카드 안으로 이동하고, `BadgeHeroSection`과 동일하게 이름
  블록과 설명 블록을 하나의 `flex-1 justify-end` 그룹으로 묶어 카드 하단에 붙인다.
  컬렉션에는 등급칩(RarityBadge)이 없으므로 이름만 있는 점은 그대로 둔다.
- 마침표 기준 문장 분리 자동 줄바꿈(`splitDescriptionSentences`)을 컬렉션 설명에도 동일하게
  적용한다. 배지 컴포넌트에 있는 로직을 복붙하지 말고 공용 유틸(예:
  `jam-web/src/lib/descriptionSentences.ts`)로 추출해 `BadgeHeroSection.tsx`와
  `ItemBookHeroSection.tsx` 양쪽에서 import해 쓴다.
- **카드 배경 테두리(`border border-[var(--color-border)]`)는 배지와 다르게 의도적으로 남긴
  값이다(20260915_2006 — 컬렉션 대표 이미지가 카드를 꽉 채우지 않아 경계 보정 목적).
  배지와 "구조를 매칭"하되 이 테두리는 제거하지 않는다.**
- 진행도 바(`ProgressBar`)는 **카드 안으로 넣지 않고 현재처럼 카드 밖에 유지**한다. 사용자
  명시 지시.
- 카드(outer wrapper)와 진행도 바 사이 세로 간격을 **20px**로 맞춘다. 현재는 부모
  (`collections/[id]/page.tsx`의 `flex flex-col gap-3`, 12px)가 형제 간격을 결정하는데,
  부모 `gap-3`를 직접 바꾸면 진행도 바 다음에 오는 다른 섹션과의 간격도 함께 바뀌므로 건드리지
  않는다. 대신 진행도 바 래퍼에 보정 마진(`mt-[var(--spacing-8)]`, 8px)을 추가해
  12px(부모 gap) + 8px = 20px를 만든다.

### UI/UX 관점 (해당 시)
- 어드민 배경 프리뷰 프레임(`ItemBookDetailPreviewFrame.tsx`)이 이 컴포넌트를 그대로 재사용하므로
  (20260819_011 원칙), 별도 분기 없이 구조 변경만으로 프리뷰도 함께 갱신되는지 확인한다.

### 컨텐츠 관점 (해당 시)
- 해당 없음. 기존 컬렉션 설명 문구 자체는 변경하지 않는다 — 렌더링 방식(줄바꿈)만 변경.

## 구현 계획
1. `splitDescriptionSentences` 함수를 `BadgeHeroSection.tsx`에서 공용 유틸 파일로 추출
2. `BadgeHeroSection.tsx`가 공용 유틸을 import하도록 수정 (동작 변화 없음, 회귀 확인 필요)
3. `ItemBookHeroSection.tsx`의 카드 내부 구조를 배지와 동일한 이미지(flex-shrink-0) +
   이름·설명 그룹(flex-1 justify-end) 형태로 재구성, 설명을 카드 안으로 이동
4. 진행도 바 래퍼에 보정 마진 추가로 카드-진행바 간격 20px 확보
5. 어드민 프리뷰 프레임에서 회귀 없는지 코드 상 확인 (동일 컴포넌트 재사용이므로 별도 수정 불필요할 것으로 예상)
6. lint·typecheck 확인

재사용 판정: 신규 MODULAR 컴포넌트 없음 — 기존 서비스 전용 컴포넌트(ItemBookHeroSection)
구조를 배지 쪽과 맞추는 리팩터링, 공용 유틸 함수 추출 정도.
