# [Admin] 쉐이더랩 슬라이스 이펙트 — 교차선 제거·이동량 균일화

## 배경 / 문제 정의
직전 티켓([20260917_1256](./20260917_1256_Admin_쉐이더랩-슬라이스이펙트-균일패턴-교차라인-회전각도추가.md))에서
슬라이스 이펙트에 균일 패턴·교차선·360도 회전각을 추가했다. staging 실제 렌더링을 확인한
사용자가 아래 두 가지 후속 수정을 요청했다.

1. 교차선 기능이 의도한 만큼 만족스럽지 않아 완전히 제거한다 — `블록 너비`·`교차선 간격`
   필드와 화면에 그려지는 교차선 자체를 모두 없앤다.
2. 이동량(`amount`)을 조절할 때 슬라이스된 각 조각이 밀리는 강도가 조각마다 서로 다른데
   (첨부 스크린샷 참고 — 밴드별로 이동 거리가 제각각이라 얼룩진 느낌), 이걸 모든 조각이
   동일한 강도로 밀리도록 고친다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 대상 파일 (직전 티켓과 동일):
  - `jam-web/patches/@basementstudio+shader-lab+3.0.2.patch` 안의 `slice-pass.js`
  - `jam-web/src/lib/admin/shaderLab/effectRegistry.ts`의 `sliceFields`
- **교차선 제거**: `effectRegistry.ts`에서 `blockWidth`·`crossLineSpacing` 필드를 삭제한다.
  `slice-pass.js`에서 `blockWidthUniform`·`crossLineSpacingUniform`과 교차선 렌더링 블록
  (`crossCoord`/`crossMod`/`distFromLine`/`crossLineMask`/`withCrossLines`)을 모두 제거하고
  최종 색상은 `blended`를 그대로 반환한다. `blockIndex`는 현재 다른 계산에 쓰이지 않는 죽은
  코드이므로 함께 제거한다.
- **이동량 균일화**: 현재 `sliceStrength = pow(bandNoise, 1.35) * amount * gate * breathe`
  구조라, `gate`로 선택된 밴드라도 `bandNoise` 크기에 비례해 서로 다른 강도로 밀린다. 또한
  `breathe`가 밴드마다 다른 위상(`bandPhase`)을 쓰고 있어 같은 순간에도 밴드마다 움직임의
  세기가 다르다. `bandNoise`에 의한 크기 스케일링과 밴드별 위상차를 제거해, 게이트로 선택된
  모든 밴드가 동일한 `amount` 강도로(그리고 애니메이션이 있다면 같은 위상으로) 밀리도록 한다.
  `bandNoise`는 "어느 밴드를 선택할지"(gate) 결정에는 계속 쓴다 — 이 부분은 목표 1(균일
  패턴)과 무관하며 유지 대상이다.
  - `smearMix`(트레일 블렌드 강도)도 같은 이유로 `bandNoise` 기반 크기 변화가 있다
    (`gate * (bandNoise * 0.42 + 0.18)`) — 이동량과 같은 원칙으로 밴드 간 균일하게
    (`gate * 고정값`) 바꿀지, 트레일은 별개 시각 요소라 그대로 둘지 구현 시 판단하고 근거를
    완료 기록에 남긴다.

### UI/UX 관점 (해당 시)
- 필드 2개(`블록 너비`, `교차선 간격`)가 어드민 UI에서 사라진다 — 레이아웃 확인.

### 컨텐츠 관점 (해당 시)
- 해당 없음.

## 구현 계획
1. `effectRegistry.ts`의 `sliceFields`에서 `blockWidth`·`crossLineSpacing` 제거.
2. `slice-pass.js`에서 관련 유니폼·필드 매핑·교차선 렌더링 로직 제거, `sliceStrength`/
   `breathe` 계산을 밴드 간 균일하게 재작성.
3. patch 파일 재생성(`patch-package`).
4. 로컬 실렌더로 이동량을 여러 값(0, 120, 300 등)으로 바꿔가며 모든 선택된 밴드가 동일한
   거리로 밀리는지, 교차선이 화면에서 완전히 사라졌는지 확인 후 스크린샷 보고.
