# [Content] `UX_WRITING_GUIDELINE.md` — 사용량 배지 관련 용어·문체 예외 반영

## 배경 / 문제 정의

티켓 [20260910_1959](../P2-일반/20260910_1959_Content_JAM카테고리-사용량배지3종-신규생성.md) 실행
중 한국어 리뷰(humanize-korean)가 배지 이름·설명 3건을 검수하며 가이드라인 문서 자체의
공백 3건을 지적했다. 판정에는 영향 없는 제안형이었지만, 문서가 현재 실제 관행을 따라가지
못하고 있다는 신호라 별도 티켓으로 분리해뒀다.

## 상세 요구사항

### 컨텐츠 관점

`Service Plan/Specs/UX_WRITING_GUIDELINE.md`에 아래 3건을 반영한다.

1. **§1.3 용어 표(53행 근처)에 신규 개념 3종 추가** — "팔로워"·"팔로잉"·"Strava 동기화
   횟수/일일 동기화 횟수"가 이번 티켓들로 처음 사용자 노출 배지 조건에 올랐는데 표에 없다
   (§7 "신규 용어 필요 시 표 갱신 후 사용" 절차가 지켜지지 못한 상태). 각 행에 고정 용어와
   사용 기준을 채운다.
2. **같은 표에 "발걸음"·"궤적" 사용 기준 신설** — grep 확인 결과 이 두 단어는 현재 문서에
   전혀 없다. 기존 배지들에서 이미 본인의 운동(활동)을 가리키는 표현으로 쓰이고 있는데,
   "팔로워 10,000명" 같은 소셜 지표 배지가 늘어나면 "타인의 발걸음"처럼 오용될 소지가 있다.
   "본인 활동에만 쓴다"는 사용 기준을 명시한다.
3. **§2.1(167행) 문장 규칙에 배지 이름·설명문의 `-습니다`체 예외 명문화** — 현재 문서는
   "해요체"를 원칙으로 규정하는데(167-170행), 실제 배지 플레이버 텍스트는 관행적으로
   `-습니다`체를 써왔다(한국어 리뷰가 "위반 아님"으로 확인한 기존 관행). 문서와 관행이
   어긋난 상태이므로, 배지 이름·설명문은 예외임을 명시한다.

## 구현 계획

문서 직접 수정. 코드 변경 없음. `Specs/`는 "현재 상태 덮어쓰기" 원칙 문서이므로 변경 이력을
본문에 누적하지 않고, 표에 항목만 추가한다.

### Acceptance Criteria

1. §1.3 용어 표에 "팔로워"·"팔로잉"·"일일 동기화 횟수"(또는 확정된 명칭) 행이 존재한다.
2. 같은 표에 "발걸음"·"궤적"이 "본인 활동에만 사용" 기준과 함께 존재한다.
3. §2.1에 배지 이름·설명문의 `-습니다`체 예외가 명시되어 있다.
4. 기존 표 항목·문구는 변경되지 않는다(신규 추가만, 기존 내용 훼손 없음).
