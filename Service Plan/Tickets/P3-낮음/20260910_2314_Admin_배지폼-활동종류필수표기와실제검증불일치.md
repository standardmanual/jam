# [Admin] 배지 폼 — "활동 종류 *" 필수 표기와 실제 검증 불일치

## 배경 / 문제 정의

티켓 [20260910_2258(Admin)](20260910_2258_Admin_JAM카테고리-어드민배지분류표시통합.md)
게이트 리뷰에서 발견된 범위 밖 이슈. `BadgeForm.tsx`의 "활동 종류" 필드가 필수 표기(`*`)를
달고 있지만, 클라이언트·서버 어디에도 `activity_types` 최소 1개 선택을 강제하는 검증
로직이 없다.

JAM! 배지처럼 `activity_types=[]`(빈 배열)로 저장되는 것 자체는 배지엔진이
`admin_category='jam'` 배지를 별도 로직으로 처리하므로(`badge-engine/index.ts:1020`
부근) 기능상 문제를 일으키지 않는다 — 즉 급한 버그는 아니다. 다만 "*" 표기가 실제 동작과
다르다는 점에서 어드민 사용자에게 혼동을 줄 수 있다.

## 상세 요구사항

### 서비스/코드베이스 관점

- `BadgeForm.tsx`의 "활동 종류" 라벨 옆 `*` 표기를 제거하거나(필수가 아님을 인정), 실제로
  최소 1개 선택을 강제하는 클라이언트·서버 검증을 추가한다 — 어느 쪽이 맞는 정책인지는
  구현 전에 판단이 필요하다. JAM! 배지처럼 의도적으로 빈 배열을 저장하는 케이스가 있으므로,
  검증을 추가한다면 `admin_category='jam'`일 때는 예외 처리해야 한다.

## 구현 계획

우선순위가 낮아 다음 어드민 배지 폼 관련 작업 시 함께 처리해도 무방하다.
