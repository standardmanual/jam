# [Admin] JAM! 배지의 타입을 바꾸면 "활동 종류" 체크박스가 사라져 되돌릴 UI가 없음

## 배경 / 문제 정의

티켓 [20260911_0202](20260911_0202_Admin_배지생성수정화면-타입별개편.md) 게이트 리뷰에서
발견된 범위 밖 이슈.

이번 개편으로 "활동 종류(+JAM!)" 체크박스 그룹이 `type === 'activity'`일 때만 렌더링되도록
바뀌었다. `admin_category`는 이전부터(티켓 20260910_2055) `type`과 무관하게 항상 그대로
저장되는 설계다. 이 둘이 만나면: 관리자가 기존 JAM! 배지(`type='activity'`,
`admin_category='jam'`)를 열어 타입을 아이템/체크인으로 바꾸면, "활동 종류" 체크박스
그룹 자체가 화면에서 사라져 `admin_category='jam'` 값을 그 세션에서 되돌릴 UI 수단이
없어진 채로 저장될 수 있다(`handleSubmit`이 type과 무관하게 `admin_category`를 그대로
전송하므로).

실제로 이런 타입 전환을 할 이유가 거의 없는 드문 시나리오라 우선순위는 낮다.

## 상세 요구사항

### 서비스/코드베이스 관점

- 타입을 `activity`에서 다른 타입으로 바꿀 때, `admin_category`가 `'jam'`이면 자동으로
  비우는 처리를 추가하거나(다른 종목 선택 시 이미 있는 상호배타 처리와 동일한 패턴),
  타입이 `activity`가 아닐 때도 "활동 종류" 섹션 대신 현재 `admin_category` 값을 보여주고
  해제할 수 있는 최소한의 UI를 남긴다.

## 구현 계획

`toggleActivityType`/`toggleAdminCategoryJam` 근처에, 타입 변경 핸들러에서
`admin_category==='jam'`이고 새 타입이 `'activity'`가 아니면 `adminCategory`를 비우는
분기를 추가하는 정도로 해결 가능해 보인다.
