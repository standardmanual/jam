# [Admin] 조건이 비어 있는 배지 폼에도 "진행률이 표시되지 않아요" 경고가 뜸

## 배경 / 문제 정의

티켓 [20260911_0901](../P2-일반/20260911_0901_Admin_배지생성조회수정-아티팩트기준리뉴얼.md) 게이트
리뷰에서 발견된 범위 밖 이슈.

새 액티비티 배지를 등록하려고 폼을 열면, 조건을 하나도 넣지 않았는데도 "이 조건은 배지 트리
화면에 진행률이 표시되지 않아요" 경고가 뜬다. `BadgeForm.tsx`의 `progressIssue`가
`explainUnsupportedProgress(condPreview ?? {})`를 호출하는데, 이 함수가 빈 조건에도 사유를
돌려주기 때문이다(`src/lib/badge-engine/badgeProgress.ts`). 리뉴얼 전에도 같은 식이었으므로
기존 동작이다. 빈 조건에 경고를 띄우는 것은 오탐이라 어드민이 경고를 무시하게 만든다.

## 상세 요구사항

### 서비스/코드베이스 관점

- 조건이 비어 있으면(`condPreview`가 null이거나 키가 없으면) 진행률 경고를 계산하지 않는다.
- `explainUnsupportedProgress` 자체를 고칠지, 폼 쪽에서만 막을지는 이 함수의 다른 호출부를
  확인한 뒤 정한다.

## 구현 계획

폼의 `progressIssue` 계산에 빈 조건 가드를 추가하는 정도로 해결될 가능성이 높다.
