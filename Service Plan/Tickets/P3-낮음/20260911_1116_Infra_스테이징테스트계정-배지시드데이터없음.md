# [Infra] 스테이징 테스트 계정에 획득 배지 시드 데이터가 없음

## 배경 / 문제 정의
티켓 `20260911_1102`(배지 공유 시트 이미지 선택 캐러셀 추가) 게이트 리뷰 과정에서 발견된
범위 밖 사항이다.

스테이징 테스트 계정(`dev-tester@jam.local`, `user_id 00000000-0000-0000-0000-000000000001`)이
획득한 배지가 activity·item 유형 모두 0건이다. 이 때문에 배지 상세·공유 관련 UI 작업을
로컬/스테이징에서 실렌더로 검증하려면 매번 실제 배지 보유 계정을 별도로 찾아야 하고,
`admin` 관점의 실렌더 검증(`DEV_PROCESS_GUARDRAILS.md` 패턴 13)조차 이 제약 때문에 온전히
수행하지 못하는 경우가 생긴다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 스테이징 테스트 계정에 activity형·item형 배지를 각 1~2종 이상 시드하는 SQL 작성
  (`Service Plan/Specs/DEV_PROCESS_GUARDRAILS.md` 원칙에 맞춰 `seed_*.sql`로 저장).
- 레벨형·반복 획득형(COUNT ≥ 2) 배지도 최소 1종씩 포함해, 공유 카드의 LEVEL/COUNT 행
  렌더링까지 실렌더로 확인 가능하게 한다.

## 구현 계획
> DB 변경이므로 CLAUDE.md 5번 규칙에 따라 SQL 파일 작성 후 사용자 승인 하에
> 오케스트레이터가 직접 Supabase에 실행한다.
