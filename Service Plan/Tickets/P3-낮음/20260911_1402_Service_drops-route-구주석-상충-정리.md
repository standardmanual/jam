# [Service] drops/route.ts 구주석과 신규 동작 상충 정리

## 배경 / 문제 정의
티켓 `20260911_1343`(게이트 리뷰 sideFindings)에서 발견됨. `jam-web/src/app/api/drops/route.ts`
61~65행의 `gatePois` 함수 위 주석(09-07 오전 티켓 `20260907_1242` 작성)이 다음과 같이
서술한다:

> "자동승인/검토대기는 둘 다 저장되되 pending_review 값만 다르다(노출은 동일, 게이트와
> 노출 로직은 분리 — 티켓 완료기록 참고)"

이는 `20260911_1343`에서 수정된 새 동작(검토대기면 `is_active`도 강제로 `false`)과
상충한다. 새 주석은 127~131행 부근(`is_active` 계산부)에 추가됐지만, 61~65행의 구주석은
갱신되지 않아 같은 파일 안에 서로 다른 설명이 남아 있다. 동작에는 영향 없는 순수 문서성
이슈다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/api/drops/route.ts` 61~65행의 주석을 실제 동작(검토대기면 `is_active`도
  함께 비노출)에 맞게 정정한다.

## 구현 계획
1. 61~65행 주석을 새 동작 설명으로 교체 (또는 127~131행 주석을 참조하도록 축약).
2. 코드 동작 변경 없음 — 순수 주석 수정이므로 리뷰 없이 처리 가능한 경미 수정 범위.
