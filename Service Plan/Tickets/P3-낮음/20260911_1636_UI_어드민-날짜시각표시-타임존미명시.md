# [UI] 어드민 투데이·배지 화면의 날짜·시각 표시가 타임존을 명시하지 않음

## 배경 / 문제 정의

티켓 [20260911_1454](../P2-일반/20260911_1454_Admin_투데이컨텐츠-화면리뉴얼.md) 게이트
리뷰 중 발견됨(범위 밖). `TodayCardDetail.tsx`의 날짜·시각 포맷 함수, `TodayCardForm.tsx`의
`toLocalInputValue`(예전 `TodayCardList.tsx`에서 그대로 옮겨온 로직), `TodayCardTable.tsx`의
`toLocaleDateString('ko-KR')` 호출이 모두 `timeZone`을 명시하지 않고 실행 환경의 로컬
타임존에 의존한다.

이 프로젝트는 이미 `LocalDate.tsx`·`today-calendar.ts` 등에서 `timeZone: 'Asia/Seoul'`을
명시하는 패턴을 쓰고 있는데, 어드민 투데이·배지 쪽 화면은 이 티켓 이전부터 그 패턴을
따르지 않고 있었다 — 이번 리뉴얼이 새로 만든 문제가 아니라 기존 코드를 그대로 옮기거나
동일한 관례를 반복한 것이다.

이 컴포넌트들은 모두 `'use client'`라, 서버(보통 UTC로 도는 Vercel 서버리스)에서 먼저
렌더된 값과 브라우저(KST 로컬)에서 hydration될 때의 값이 달라질 수 있다 — 시각이 9시간
어긋나 보이거나, React hydration 경고가 날 수 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 어드민 투데이·배지 화면에서 날짜·시각을 표시하는 지점을 모두 찾아, `Intl.DateTimeFormat`
  또는 기존 유틸에 `timeZone: 'Asia/Seoul'`을 명시하도록 통일한다.
- 이미 있는 `LocalDate.tsx`·`today-calendar.ts`의 타임존 처리 패턴을 그대로 따를지, 아니면
  어드민 전용 공통 포맷 유틸을 새로 만들지는 구현 시점에 판단한다.
