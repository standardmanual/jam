# [Admin] 미션 조건 null 저장 시 오류 문구가 어색함

## 배경 / 문제 정의

`checkMissionCondition`(`jam-web/src/lib/missions/condition-keys.ts`, 기존 코드)은
`condition_json`이 `null`일 때 "조건은 중괄호로 감싼 객체여야 하는데 지금은 빈 값(null)
형태예요"라는 오류 문구를 낸다. 티켓 20260911_2118(미션 달성 조건 필드 UI 전환) 게이트
리뷰 중 발견된 범위 밖 이슈로, 새 필드 빌더에서 모든 필드를 비운 채 저장을 시도하는 극단적
케이스에서 이 문구가 노출될 수 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `checkMissionCondition`의 null 케이스 오류 문구를 다듬는다.

### UI/UX 관점 (해당 시)
- `Service Plan/Specs/UX_WRITING_GUIDELINE.md`의 에러 메시지 3단계 구조([현상] → [원인] →
  [해결책])에 맞춰 재작성한다.

## 구현 계획
- `condition-keys.ts`의 해당 분기 문구를 가이드라인에 맞게 수정하고, 관련 테스트가 있다면
  함께 갱신한다.
