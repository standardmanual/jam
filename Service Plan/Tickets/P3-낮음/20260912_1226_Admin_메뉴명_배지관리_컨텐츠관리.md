# [Admin] 어드민 메뉴명 변경 — "배지 관리" → "컨텐츠 관리"

## 배경 / 문제 정의
어드민 좌측 내비게이션 최상위 그룹(`id: 'content'`)의 라벨이 "배지 관리"였는데, 이 그룹
안에는 배지 계열 관리·배지 일괄 변경·아이템배지·컬렉션 등 배지 외 컨텐츠도 포함돼 있어
그룹명을 "컨텐츠 관리"로 바꾼다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `src/components/admin/adminNavItems.ts`의 `NAV_GROUPS` 중 `id: 'content'` 그룹의
  `label`을 "배지 관리" → "컨텐츠 관리"로 변경
- 그룹 안의 개별 항목 `{ href: '/admin/badges', label: '배지 관리', ... }`은 그대로 유지
  (해당 항목은 `/admin/badges` 페이지 자체를 가리키는 라벨이라 그룹명과 별개)

### UI/UX 관점 (해당 시)
- 어드민 좌측 메뉴에서만 노출되는 텍스트, 일반 사용자 화면에는 영향 없음

## 구현 계획
`adminNavItems.ts` 1줄 수정 + 이를 검증하는 `__tests__/adminNavItems.test.ts`의 그룹
라벨 assertion 동반 수정.
