# [UI] 프로필 페이지 — 프로필 이미지를 라운드 카드에서 서클로 변경

## 배경 / 문제 정의

프로필 페이지(`/profile`, `/[username]`) 상단의 프로필 이미지가 라운드 카드 모양
(`rounded-[var(--radius-cards)]`)이었다. 서클(원형)로 바꾸고, 크기(96×96px)는 그대로
유지한다.

## 상세 요구사항

### 서비스/코드베이스 관점

- `ProfileClient.tsx`의 프로필 이미지 `<Image>`와, 이미지가 없을 때의 대체 아이콘
  `<div>` 두 곳 모두 원형으로 바꾼다(둘 다 같은 모양을 유지해야 하므로 함께 변경).
- 크기(`w-24 h-24`, 96px)는 그대로 둔다.
- 다른 화면(헤더의 작은 아바타 등)은 이미 `rounded-full`이라 영향 없음 — 이번 변경
  대상이 아니다.

## 경미 수정 판정

파일 1개, 클래스명 2곳(`rounded-[var(--radius-cards)]` → `rounded-full`)만 바꾸는
원인-결과가 1:1로 명확한 변경이라 `/jam-work` 0.1절 기준 경미 수정으로 처리했다
(Workflow 파이프라인 생략, 오케스트레이터 직접 구현).
