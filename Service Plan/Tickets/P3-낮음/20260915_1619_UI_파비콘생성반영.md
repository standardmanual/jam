# [UI] JAM 로고 기반 파비콘 생성·반영

## 배경 / 문제 정의

서비스에 파비콘이 없었다(`src/app/favicon.ico`는 Next.js 기본 placeholder). JAM 로고
이미지를 기반으로 파비콘을 만들어 반영한다.

## 상세 요구사항

### 서비스/코드베이스 관점

- 기존 로고 자산(`design-system/assets/logo/jam-logo-white.png`, "Jam™" 와이드
  워드마크, 2238×925)을 원본으로 쓴다.
- 와이드 워드마크를 그대로 축소하면 16~32px에서 거의 안 보이므로, 가장 알아보기 쉬운
  단일 글리프("J")만 잘라 정사각형 아이콘으로 재구성한다.
- 브랜드 정체성이 살도록 배경은 투명이 아니라 브랜드 프라이머리 색상
  (`--color-base-red`, `#e8461f`)으로 채우고 흰색 "J"를 중앙에 배치한다 — 애플 터치
  아이콘은 투명 배경을 지원하지 않아(iOS가 임의로 채움) 애초에 불투명 배경이 필요하기도
  하다.
- Next.js App Router 파일 컨벤션(`app/favicon.ico`·`app/icon.png`·`app/apple-icon.png`)을
  그대로 써서 코드 변경 없이 자동으로 `<head>` 태그가 생성되게 한다.

## 경미 수정 판정

코드 로직 변경 없이 이미지 자산 3개(`favicon.ico`·`icon.png`·`apple-icon.png`)만
교체·추가하는 원인-결과가 명확한 작업이라 `/jam-work` 0.1절 기준 경미 수정으로 처리했다
(Workflow 파이프라인 생략, 오케스트레이터 직접 구현).

## 완료 기록

### 구현 내용 요약

`design-system/assets/logo/jam-logo-white.png`에서 "J" 글리프 영역(왼쪽 0~411px, 원본
2238×925 기준)을 타이트 크롭한 뒤, 브랜드 레드(`#e8461f`) 배경 정사각형 캔버스 중앙에
16% 여백을 두고 배치했다(Python PIL). 16/32/48/180/192/512px 크기로 만들어:

- `src/app/favicon.ico` — 16/32/48 멀티사이즈 ICO(브라우저 탭용)
- `src/app/icon.png` — 512×512(모던 브라우저·PWA용, Next.js가 자동으로 `sizes` 태그 생성)
- `src/app/apple-icon.png` — 180×180(iOS 홈 화면 추가용)

세 파일 모두 Next.js가 파일 컨벤션으로 자동 인식해 별도 코드 변경 없이 `<head>`에
`<link rel="icon">`·`<link rel="apple-touch-icon">` 태그가 생성된다.

### 변경된 파일
```
jam-web/src/app/favicon.ico  (교체 — 기본 placeholder → JAM 브랜드 파비콘, 멀티사이즈 ICO)
jam-web/src/app/icon.png     (신규 — 512x512)
jam-web/src/app/apple-icon.png  (신규 — 180x180)
```

### 테스트 결과
- [x] 로컬 dev 서버(`npm run dev`) 실렌더 — 페이지 `<head>`에 세 `<link>` 태그가 올바른
      `rel`·`sizes`·`type`으로 생성되는 것을 확인(favicon.ico=48x48/x-icon,
      icon.png=512x512/png, apple-icon.png=180x180/png — Next.js가 자동 부여)
- [x] `curl`로 실제 서빙되는 `/favicon.ico`·`/icon.png` 바이트를 받아 `file` 명령으로
      디코딩 검증 — favicon.ico가 16/32/48 세 크기를 모두 담고 있음을 확인(첫 시도에서
      PIL ICO 저장 시 소스 이미지를 16px본으로 잘못 넘겨 1개 크기만 담기는 문제를 발견해
      512px 원본에서 다시 생성해 바로잡음)
- [x] `npx tsc --noEmit` — 오류 없음(코드 변경 없음, 확인 차원)

### 주요 의사결정 / 핵심 메모

- **와이드 워드마크 대신 "J" 단일 글리프를 골랐다**: 2238:925(약 2.4:1) 비율의 "Jam™"
  전체를 정사각형에 욱여넣으면 16~32px에서 글자가 뭉개져 브랜드 인식이 오히려 떨어진다.
  세로로 긴 "J" 획은 축소해도 형태가 뚜렷하게 남는다.
- **불투명 브랜드 레드 배경을 택했다**: 투명 배경 흰 글리프만 쓰면 밝은 브라우저 탭
  배경에서 거의 안 보이고, iOS 애플 터치 아이콘은 애초에 투명을 지원하지 않아 임의로
  채워버린다 — 브랜드 색으로 직접 채우는 쪽이 모든 컨텍스트에서 일관된다.
