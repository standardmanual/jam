# [UI] 알림 벨 버튼 배경을 더 밝게

## 배경 / 문제 정의

TopNav 알림 벨 버튼(`NotificationBell.tsx`)의 원형 배경이 공용 토큰
`--color-surface-elevated`(#1f1f1f)를 써서 헤더 배경과 거의 구분되지 않는다는 요청 — 좀
더 밝게 해달라는 요청.

## 상세 요구사항

### 서비스/코드베이스 관점

- 알림 벨 버튼의 배경만 밝게 한다 — 다른 곳에서도 널리 쓰는
  `--color-surface-elevated` 토큰 자체는 건드리지 않는다(변경 범위 확대·회귀 위험 방지).
- 새 색상값을 임의로 만들지 않고, 이미 존재하는 토큰 중 한 단계 밝은 값
  (`--color-base-grey-700`, #2a2a2a — `--color-border`와 동일 값)을 재사용한다.

## 경미 수정 판정

파일 1개, 클래스 1곳(`bg-surface-elevated` → `bg-[var(--color-base-grey-700)]`)만 바꾸는
원인-결과가 1:1로 명확한 변경이라 `/jam-work` 0.1절 기준 경미 수정으로 처리했다(Workflow
파이프라인 생략, 오케스트레이터 직접 구현). 새 토큰을 만들지 않고 기존 값을 재사용해
MODULAR 확장 판단도 해당 없음.
