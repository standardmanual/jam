# [UI] 파비콘 색상을 블랙, 모양을 서클로 변경

## 배경 / 문제 정의

티켓 [20260915_1619](20260915_1619_UI_파비콘생성반영.md)에서 만든 파비콘(브랜드 레드
정사각형 배경 + 흰색 "J")을 블랙 배경 + 서클(원형) 모양으로 바꿔달라는 요청.

## 상세 요구사항

### 서비스/코드베이스 관점

- 배경 색상을 브랜드 레드(`#e8461f`)에서 블랙(`#000000`)으로.
- 배경 모양을 정사각형에서 서클(원형)로 — 정사각 캔버스 안에 원을 그리고 그 바깥은
  투명 처리.
- 흰색 "J" 글리프·크롭·배치 로직은 그대로 유지.
- 애플 터치 아이콘(`apple-icon.png`)은 iOS가 투명을 지원하지 않아(임의로 채움) 원형
  바깥 모서리도 검정으로 채운 불투명 정사각 버전을 별도로 만든다(시각적으로는 동일 —
  모서리가 어차피 검정이라 원/사각 구분이 안 보이고, iOS가 자체적으로 모서리를 둥글림).

## 경미 수정 판정

코드 로직 변경 없이 이미지 자산 3개(`favicon.ico`·`icon.png`·`apple-icon.png`)만
재생성·교체하는 원인-결과가 명확한 작업이라 `/jam-work` 0.1절 기준 경미 수정으로
처리했다.

## 완료 기록

### 구현 내용 요약

20260915_1619의 생성 스크립트를 재사용해 배경만 바꿨다 — 정사각 채움 대신
`ImageDraw.ellipse()`로 캔버스에 내접하는 검정 원을 그리고 그 바깥은 투명으로 뒀다(브라우저
탭용 `favicon.ico`·`icon.png`). `apple-icon.png`만 예외적으로 원 바깥까지 검정으로 채운
불투명 정사각 버전을 별도로 만들었다(iOS 투명 미지원 대응, 20260915_1619 완료 기록에서
이미 밝힌 제약과 동일).
