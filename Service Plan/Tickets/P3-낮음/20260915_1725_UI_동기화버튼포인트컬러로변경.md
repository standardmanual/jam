# [UI] 동기화 버튼 색상을 메인 포인트 컬러로 변경

## 배경 / 문제 정의

TopNav 중앙의 "동기화" 버튼이 `--color-secondary`(브라운, #8a5a2e)로 채워져 있었다.
메인 포인트 컬러(`--color-primary`, 브랜드 레드오렌지 #e8461f — "0 포인트" 숫자·배지
강조 등에 쓰는 색)로 바꿔달라는 요청.

## 사전 조사 결과

"동기화" 버튼은 스트라바 연동 상태에 따라 **두 곳에서** 렌더된다 — 둘 다 같은 인라인
`style={{ backgroundColor: 'var(--color-secondary)', ... }}`를 썼다.

1. `src/components/SyncButton.tsx` — 스트라바 연동된 유저(수동 동기화 트리거)
2. `src/components/ui/TopNav.tsx`의 `centerSlot` — 미연동 유저(누르면 연동 플로우로 이동)

둘 다 같은 자리(TopNav 중앙)에 같은 라벨로 뜨는 동일한 버튼이라 연동 상태와 무관하게
색이 일치해야 한다 — 한쪽만 고치면 로그인 유저에 따라 색이 달라 보이는 회귀가 생긴다.

## 경미 수정 판정

파일 2개, `--color-secondary` → `--color-primary` 교체 각 1곳씩(총 2줄)만 바꾸는
원인-결과가 1:1로 명확한 변경이라 `/jam-work` 0.1절 기준 경미 수정으로 처리했다.
