# [UI] 배지 상세화면 등급칩(RarityBadge)도 md 크기로 통일

## 배경 / 문제 정의
> 왜 이 작업이 필요한가. 현재 상태와 기대 상태의 차이.

티켓 20260916_1443에서 `BadgeHeroSection.tsx`의 `BadgeLevelChip`을 `size="md"`로 맞췄으나,
같은 자리에서 등급형 배지일 때 그려지는 `RarityBadge`는 여전히 기본값 `sm`(8px)이라 배지
종류에 따라 상세화면 칩 크기가 갈리는 상태였다. 사용자 확인 후 `RarityBadge`도 `md`로
맞추기로 했다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `BadgeHeroSection.tsx:110`의 `<RarityBadge rarity={badge.rarity ?? undefined} />` 호출에
  `size="md"`를 추가한다.

## 구현 계획
> 어떻게 구현할지. 접근 방법, 영향 범위, 주요 변경 포인트.

`BadgeHeroSection.tsx` 1개 파일, 1줄 변경. 기존 컴포넌트의 기존 size variant만 지정.

### 구현 내용 요약

배지("자정의 경계인" MYSTIC) 상세화면을 직접 렌더링해 칩이 커진 것을 확인했다.
