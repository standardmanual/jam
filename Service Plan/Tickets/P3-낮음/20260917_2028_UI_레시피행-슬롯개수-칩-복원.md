# [UI] 레시피 행 타이틀 옆 슬롯 개수 칩 복원

## 배경 / 문제 정의

티켓 `20260917_2014`에서 레시피 보상 행을 공통 컴포넌트(`RecipeRewardRow`)로 통일하며
"슬롯 N개" 텍스트가 사라졌다. 사용자가 타이틀 우측에 회색 칩 "(n)" 형태로 다시 노출해
달라고 요청. 경미한 수정이라 파이프라인 없이 직접 처리한다.

## 상세 요구사항

`RecipeRewardRow`의 `title` 우측에 슬롯 개수를 회색 칩 `(n)`으로 표시한다.
`ListRowCard`의 `title`이 string만 받아 칩을 인라인으로 붙일 수 없어, `children`(전체
커스텀 렌더링)으로 우회해 타이틀 행을 직접 그린다.

---
## 완료 기록

### 구현 내용 요약
`RecipeRewardRow`에 `slotCount: number` prop 추가. `ListRowCard`의 `title`/`subtitle`
prop 대신 `children`으로 전환해, 타이틀 텍스트 옆에 회색 배경 pill 칩 `(n)`을 렌더하고
그 아래 기존 subtitle(등급 칩+배지명)을 그대로 유지. `CombineClient.tsx`의 두 호출부
(레시피 탐색 목록 행, 믹서 요약바) 모두 `slotCount={recipe.slots.length}` 전달.
