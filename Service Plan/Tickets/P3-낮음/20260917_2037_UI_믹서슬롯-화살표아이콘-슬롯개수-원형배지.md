# [UI] 믹서 슬롯 화살표 아이콘 · 레시피 슬롯 개수 원형 배지 수정

## 배경 / 문제 정의

사용자 실화면 확인 후 나온 세부 수정 2건. 경미한 스타일 조정이라 파이프라인 없이 직접
처리한다.

1. 채울 수 있는(fillable) 믹서 슬롯의 '+' 텍스트를 사용자가 첨부한 다운로드 화살표
   아이콘(Material Symbols `arrow_downward_alt`)으로 교체, 색상은 흰색.
2. 레시피 행 타이틀 옆 슬롯 개수 표시를 "(n)" 텍스트에서 **회색 원형 배지 안에 숫자만**
   표시하는 형태로 변경.

## 상세 요구사항

- `MixerSlot.jsx`의 `fillable` 상태 렌더링에서 '+' 텍스트를 인라인 SVG(`viewBox="0 -960
  960 960"`, path `M480-240 240-480l56-56 144 144v-368h80v368l144-144 56 56-240 240Z`)로
  교체, `fill="var(--color-base-white)"`. 잠긴(locked) 슬롯은 기존 '+' 텍스트 유지.
- `RecipeRewardRow.tsx`의 슬롯 개수 표시를 `w-5 h-5` 원형(`rounded-pill`) 배경 안에
  숫자만(괄호 없이) 넣는 형태로 변경.

### 구현 내용 요약
위 두 항목 그대로 반영. `MixerSlot.jsx`는 `fillable` 분기를 추가해 SVG를 렌더링하고

개수 칩의 마크업만 pill 텍스트 → 고정 크기 원형으로 바꿨다(props/로직 변경 없음).
