# [Admin] 어드민 API 403 에러 메시지 형식 통일

## 핵심 요약
- 요구사항: 어드민 API 라우트의 권한 거부 응답 형식을 하나로 맞춘다.
- 구현 계획: `getAdminUser()` 인라인 패턴(영문 `Forbidden`)을 쓰는 쓰기 핸들러를 `requireAdmin()`으로 옮긴다.
- 관련 파일: `jam-web/src/app/api/admin/badges/route.ts`, `drop-policy/route.ts`, `badge-metric-labels/route.ts` 외 같은 패턴을 쓰는 어드민 라우트
- 출처: 티켓 20260918_1149 게이트 리뷰(민지) 범위 밖 발견물

## 배경 / 문제 정의
1149에서 GET 핸들러만 `requireAdminRead(req)`로 바꾸면서, 같은 파일 안에서 GET은 한국어 403 메시지를,
POST·PUT은 영문 `Forbidden`을 반환하게 되었다. 기능 결함은 아니지만 어드민 API의 에러 응답이 일관되지 않다.

## 완료 조건
- 어드민 라우트의 권한 거부 응답이 한 가지 형식으로 통일되어 있다
- 권한 검사 동작(누가 통과하는지)은 바뀌지 않는다
