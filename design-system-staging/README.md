# 코딩 에이전트: 필독 사항

이것은 Claude Design (claude.ai/design)에서 제공하는 핸드오프 번들(handoff bundle)입니다.

사용자가 AI 디자인 도구를 사용하여 HTML/CSS/JS로 디자인 목업을 만든 후, 코딩 에이전트가 이 디자인을 실제로 구현할 수 있도록 이 번들을 내보냈습니다.

## 수행해야 할 작업 — 중요

**`jam-design-system/project/` 아래에 있는 기본 디자인 파일을 찾아 처음부터 끝까지 읽으세요.** 그런 다음 **해당 파일의 import 항목을 따라가세요**: 구현을 시작하기 전에 각 조각들이 어떻게 연결되는지 이해할 수 있도록 불러오는 모든 파일(공유 컴포넌트, CSS, 스크립트)을 열어보세요.

**모호한 부분이 있다면 구현을 시작하기 전에 사용자에게 확인을 요청하세요.** 잘못된 것을 구축하는 것보다 사전에 범위를 명확히 하는 것이 훨씬 비용이 적게 듭니다.

## 디자인 파일 안내

디자인 매체는 **HTML/CSS/JS**입니다 — 이것들은 프로토타입이며 프로덕션 코드가 아닙니다. 여러분이 할 일은 대상 코드베이스(React, Vue, 네이티브 등 적합한 무엇이든)에 맞춰 이 디자인을 **픽셀 단위까지 완벽하게(pixel-perfect) 재현**하는 것입니다. 시각적 결과물을 동일하게 맞추되, 프로토타입의 내부 구조가 타겟 환경에 딱 들어맞는 경우가 아니라면 그대로 복사하지 마세요.

**사용자가 요청하지 않는 한 이 파일들을 브라우저에 렌더링하거나 스크린샷을 찍지 마세요.** 치수, 색상, 레이아웃 규칙 등 필요한 모든 내용은 소스에 상세히 설명되어 있습니다. HTML과 CSS를 직접 읽으세요; 스크린샷이 소스 코드보다 더 많은 정보를 제공하지는 않습니다.
