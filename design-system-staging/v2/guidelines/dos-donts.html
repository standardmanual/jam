해야 할 것

  • 블랙 캔버스(--color-bg)를 유지할 것 — 깊이감은 섀도가 아닌 테두리와 회색 카드 서피스로 표현한다.
  • 레드-오렌지 Primary(--color-primary)를 단 하나의 지배적 액센트로 사용할 것. 브라운은 Secondary 보조 역할만 한다.
  • 완전 필(pill) 반경은 버튼과 태그에만 사용할 것 — 카드와 인풋은 8–10px 중간 단계를 유지한다.
  • 웨이트 600 + 촘촘한 자간은 H1/H2에만 적용할 것 — 본문은 웨이트 400, 일반 자간을 유지한다.
  • 간격은 4px 기본 배수 스케일(4/8/12/16/24/32/48/64)로 구성할 것.

하지 말아야 할 것

  • tokens/colors.css 팔레트 외부의 색상을 이유 문서화 없이 추가하지 말 것 (amber/mythic-pink 도입 선례는 readme.md 참고).
  • 어떤 서피스도 밝은/흰색 배경으로 전환하지 말 것 — 이 시스템은 다크 전용이다.
  • Bold Display의 웨이트·자간 규칙을 일반 본문에 적용하지 말 것 — 히어로 숫자 전용이다.
  • 카드나 인풋에 필(pill) 반경을 섞지 말 것 — 버튼으로 읽혀 버튼의 시각적 시그니처를 훼손한다.
  • 박스 섀도를 추가하지 말 것 — 블랙 배경 시스템으로 전환할 때 의도적으로 엘리베이션을 제거했다.
