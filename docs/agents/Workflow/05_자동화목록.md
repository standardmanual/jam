# 자동화 목록

**원칙:** 판단은 에이전트가, 정해진 절차는 스크립트가. 쓰기는 DB 직접이 아니라 **어드민 API**를 통한다 (권한 검사·검증 로직을 그대로 탄다).

## 1차 (도입 시 함께 만든다)

| # | 자동화 | 담당 | 내용 |
| --- | --- | --- | --- |
| A1 | `verify` | 아현·민지 | lint·타입·테스트 전체·`ds:check`·**슬롭/금칙어 검사**. 통과/실패와 실패 항목만 출력 |
| A2 | diff 정리 스크립트 | 민지·아현 | 잠금·생성·대용량 파일을 뺀 diff와 변경 요약 전달 |
| A3 | 현황판 생성 | 카리나 | 티켓 상태값에서 진행 중·승인 대기 목록 자동 생성 (세션 시작 hook) |
| A4 | 승인 후 처리 | 카리나 | 오염 검사 → 머지 → 티켓 종료 → push 1회 → 배포 확인 |
| A5 | **어드민 API 읽기** | 카즈하 | 지표·미션·드랍·배지·유저 현황 조회. **DB 전체 권한 불필요** |
| A6 | 작업 공간 정리·준비 | 아현 | 오래된 worktree 정리, 패키지 재설치 방지 |
| A7 | push hook | 전원 | 리뷰 브랜치 push 시 `verify` 실행 (전체 테스트 3.1초) |

## 2차 (1차 안정화 후)

| # | 자동화 | 담당 | 내용 |
| --- | --- | --- | --- |
| B1 | **어드민 API 쓰기** | 윤진·카즈하 | 승인된 미션·오늘 카드·앰비언트 드랍을 자동 등록 (사람이 폼 입력 안 함) |

| B7 | 티켓 지표 집계 | 카즈하 → 혜린 | 재시도·실패 사유·소요 시간·비용 → 월간 회고 입력 |
| B9 | 완료 기록 자동 작성 | 카리나 | 아현의 구현 요약으로 티켓 완료 기록 채움 |
| B10 | 멈춘 티켓 알림 | 카즈하 | 2주 이상 움직임 없는 OPEN 티켓 |

## 제외한 자동화
- **즉시 알림(휴대폰·메신저)** — 사용자 결정으로 제외. 긴급 상황은 다음 세션이나 주간 브리핑에서 확인한다.
- 유저 제재·데이터 변경·경제 수치 변경의 자동 실행

## CLAUDE.md 포함 여부 (에이전트별)
서브에이전트는 호출될 때마다 프로젝트 `CLAUDE.md`(8.4KB)를 읽는다. 정의 파일에서 제외할 수 있다.

| 포함 | 제외 |
| --- | --- |
| 아현, 민지 (코드 규칙 필요) | 채원, 혜린, 윈터, 윤진, 카즈하, 하니 |

## 검사 우회 차단
`settings.json`의 거부 목록에 `Bash(git commit --no-verify)`·`Bash(git push --no-verify)` 추가.

## 안전장치
- 쓰기 자동화는 **승인된 항목만** 실행한다. 스크립트가 새 항목을 만들지 않는다.
- 유저 제재·데이터 변경·경제 수치 변경은 자동화 대상에서 제외한다.
- 모든 자동 실행은 결과를 기록하고, 실패하면 카즈하가 다음 점검에서 잡는다.
