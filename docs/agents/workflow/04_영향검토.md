## 새로 만들 것
에이전트 정의 8개 · 스크립트(`verify`·diff 정리·현황판·승인 후 처리·어드민 API 읽기·작업 공간 준비) · 문서(공통 규칙·슬롭 사전·처리 규칙표·현황판·커버리지 맵·브랜드 보이스·플레이북·트렌드 노트) · 양식 7종 · 폴더 4개 · 예약 작업 2개(꺼 둠) · push hook
**만들지 않는 것:** 요약본 3종 · 문서 영향 지도 · 영향 범위 지도 · 구현 패턴 카드

## 고칠 것
`CLAUDE.md` · `jam-web/CLAUDE.md` · `/jam-work`+`jam-work.js` · `/jam-docs` · `/jam-design` · `.githooks/pre-commit` · `settings.json` · 티켓 템플릿

## 없앨 것
개선 리뷰 단계 + `progressive-reviewer` · 인터페이스 리뷰 단계 · 디자인 커맨드 4개 · 외부 스킬 링크 5종 · "15줄 미만 개선 리뷰 생략" 조건

## 그대로 두는 것

## 루프 보완으로 추가되는 변경
티켓 템플릿(완료 조건) · 결정 기록 양식(거절 이유) · 결과 기록 양식 · 상위/하위 티켓 표기 · 공용 규칙표 구조 · 세계관 변경 시 시뮬레이터 검증 절차

## 위험과 대응
범위가 큼 → 작업 브랜치 + 검증 티켓 3건 / 스킬·hook 불일치 → 규칙은 한 곳에 적고 참조 / 자동 발행 → 꺼진 상태로 시작 / 디자인 병목 → 생략 조건

## 도입 순서 (한 브랜치)
① 선행(테스트 13건·작업 공간 정리) → ② 기반 문서 → ③ 스크립트 3개 → ④ 정의 8개 → ⑤ 워크플로·스킬 → ⑥ hook·설정·CLAUDE.md → ⑦ 스킬 정리 → ⑧ 예약 작업(꺼 둠) → ⑨ 검증 티켓 3건 → 머지 → 태그
