## 왜 옮겼나

`v{n}.{m}` 접미사를 붙여 새 파일로 저장하는 규칙 때문에 사본 15개가 누적됐습니다.
인접 버전 간 실제 차이는 4~110줄인데 500줄 문서를 통째로 복제하는 방식이라
중복률이 약 93%였고, 무엇보다 **어느 파일이 최신본인지 파일만 봐서는 알 수 없었습니다.**
(버전 접미사가 없는 `02 JAM! 서비스 플랜.md`가 실은 6월에 쓴 v2.2 원본이었습니다.)

## 새 규칙

- 서비스 플랜은 **단일 파일을 직접 수정**합니다. 새 버전 파일을 만들지 않습니다.
- 버전 이력은 git이 보관합니다 — `git log --follow`로 조회하세요.
- 자세한 절차는 `.claude/skills/jam-docs/SKILL.md` ⑤ 항목 참조.
