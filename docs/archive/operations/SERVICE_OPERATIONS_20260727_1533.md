## 미션 목록 정렬·필터 UI 추가

**관련 파일:** `src/app/(main)/missions/MissionsListClient.tsx`

- **정렬**: 기존 탭(진행중/참여중/종료) 위에 정렬 세그먼트 추가 — 기본순(정렬 없음) / 종료임박순(`ends_at` 오름차순) / 신규순(`created_at` 내림차순).
- **필터**: "필터" 버튼 클릭 시 패널 노출 — 활동 종류(러닝/자전거/트레일러닝/등산/걷기, `condition_json.activity_type` 기준) + 미션 유형(거리/횟수/장소방문/아이템수집, `mission_type` 기준) 복수 그룹, 각각 단일 선택. 활성 필터 개수를 버튼에 뱃지로 표시, 초기화 버튼 제공.
- **활동종류 필터 주의사항**: `poi_visit`/`item_collect` 타입처럼 애초에 `activity_type` 조건이 없는(종목 무관) 미션은 활동종류 필터를 걸면 결과에서 제외됨 — "종목 무관 미션도 다 보여달라"는 요구가 아니라 "이 종목에 해당하는 미션만" 좁혀보는 필터로 설계.
- **신규 뱃지**: 정렬과 별개로, 생성된 지 7일 이내인 미션 카드에 항상 "NEW" 뱃지 노출(정렬 미적용 상태에서도 신규 미션을 시각적으로 식별 가능).
- 정렬/필터는 현재 탭(`ongoing`/`joined`/`ended`) 내에서만 적용되며 탭 전환 시 유지됨(초기화 안 됨) — 탭을 오가며 같은 조건으로 비교하기 편하도록 의도적으로 유지.
