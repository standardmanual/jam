# 컨텐츠 브리프 프롬프트 양식

컬렉션 하나당 폴더 하나, 아이템 하나당 파일 하나로 만듭니다. Claude가 해당 컬렉션의
`스타일그룹_정의서.md` + `컨텐츠_브리프.md`를 조합해 작성하는 **완성된 산출물**입니다 —
빈 칸을 채우는 재사용 템플릿이 아니라, 매 컬렉션마다 실제 내용이 다 채워진 문서를 새로
만듭니다.

폴더/파일 위치: 컨텐츠_브리프 폴더 안에 이미지 생성 결과 폴더(`{컬렉션ID} {컬렉션이름}`)와
분리된 `{컬렉션ID} {컬렉션이름}_프롬프트` 폴더를 만들고, 그 안에 아이템 수만큼
`{컬렉션ID}_{#}_{아이템이름}_프롬프트.md` 파일을 각각 만듭니다 (아이템 이름은 공백을 뺀
붙임표기로, 이미지 파일명 규칙과 동일하게 맞춥니다).

사용자가 이 문서를 그대로 Gemini에 붙여넣어 이미지를 생성하므로, 파일 안에는 군더더기
설명 없이 Gemini가 바로 읽을 수 있는 프롬프트 텍스트만 담습니다. 각 파일은 독립적으로
완결되어야 합니다 — 다른 아이템 파일 없이 이 파일 하나만 붙여넣어도 작동해야 함.

---

## `{컬렉션ID}_{#}_{아이템이름}_프롬프트.md`

# {컬렉션ID} {컬렉션이름} — {#}. {아이템 이름}

(컨텐츠_브리프 표의 설명을 한 줄 참고용으로 남겨도 됩니다.)

**negative prompt**
(정의서의 "절대 금지 요소" 전체 + 텍스트_사용여부가 no면 텍스트 관련 금지도 포함. 단어/짧은 구를 쉼표로 나열)

**생성 prompt**
(정의서의 팔레트·렌더링 규칙·캐릭터화 규칙·톤/다이나믹함을 문장으로 녹이고, 컨텐츠_브리프
표의 "생성해야 하는 표현"을 핵심 장면으로 반영. 정의서에 구도 문법이 정해져 있으면 모든
아이템 파일에 동일하게 적용)

(컨텐츠_브리프.md의 아이템 수만큼 파일 반복)
