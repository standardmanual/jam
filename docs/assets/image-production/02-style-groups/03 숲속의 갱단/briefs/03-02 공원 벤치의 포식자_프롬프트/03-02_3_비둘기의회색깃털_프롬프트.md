# 03-02 공원 벤치의 포식자 — 3. 비둘기의 회색 깃털

도심의 진정한 지배자, '닭둘기' 보스가 날갯짓 한 번으로 남기고 간 묵직한 위엄입니다.

**생성 prompt** (recraftv4_1은 negative_prompt 미지원 — 금지 요소는 본문에 서술)

원형 배지 아이콘. 배지 바깥 사각 캔버스는 완전 투명. 비비드 그린 컬러 링 테두리가 배지 외곽을 두르고, 안쪽은 노을빛 오렌지·앰버 톤의 원형 배경판으로 채워져 있으며, 배경판 가장자리에는 짙은 그린 수풀과 브라운 흙길 실루엣이 작게 배치되어 있다. 배경판 중앙에는 크고 두툼한 회색 깃털 한 개가 놓여 있으며, 깃가지 하나하나가 또렷하게 갈라진 결을 살려 표현한다. 채색은 플랫 컬러 위주이며 그림자는 소수의 병렬 해칭 선으로만 암시하고, 드롭섀도우나 사실적 그라데이션·사진 같은 질감·3D 렌더링 없이 채도 높고 선명한 톤을 유지한다. 텍스트나 문구는 전혀 넣지 않으며, 등장하는 동물·사물에는 눈·코·입 등 어떠한 표정이나 의인화된 자세도 그리지 않는다. 원형 배지 프레임을 벗어나 사각 캔버스 구석까지 침범하는 구도, 워터마크·서명·로고도 넣지 않는다.
