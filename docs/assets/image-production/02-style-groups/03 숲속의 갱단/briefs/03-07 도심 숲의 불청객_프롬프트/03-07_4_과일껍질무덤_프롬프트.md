# 03-07 도심 숲의 불청객 — 4. 과일 껍질 무덤

주말 등산객들이 버리고 간 사과와 배 껍질만 알뜰하게 골라 먹은 야생동물들의 짬처리 흔적입니다.

**생성 prompt** (recraftv4_1은 negative_prompt 미지원 — 금지 요소는 본문에 서술)

원형 배지 아이콘. 배지 바깥 사각 캔버스는 완전 투명. 클리어 블루 컬러 링 테두리가 배지 외곽을 두르고, 안쪽은 하늘색 원형 배경판으로 채워져 있으며, 배경판 위에는 흰 구름 몇 조각이 떠 있다. 배경판 중앙에는 돌돌 말린 사과 껍질과 배 껍질 조각들이 소복하게 쌓여 있다. 채색은 플랫 컬러 위주이며 그림자는 소수의 병렬 해칭 선으로만 암시하고, 드롭섀도우나 사실적 그라데이션·사진 같은 질감·3D 렌더링 없이 채도 높고 선명한 톤을 유지한다. 텍스트나 문구는 전혀 넣지 않으며, 등장하는 동물·사물에는 눈·코·입 등 어떠한 표정이나 의인화된 자세도 그리지 않는다. 원형 배지 프레임을 벗어나 사각 캔버스 구석까지 침범하는 구도, 워터마크·서명·로고도 넣지 않는다.
