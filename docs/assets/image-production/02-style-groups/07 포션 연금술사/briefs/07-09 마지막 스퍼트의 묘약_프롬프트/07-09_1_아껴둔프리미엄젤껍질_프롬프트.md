# 07-09 마지막 스퍼트의 묘약 — 1. 아껴둔 프리미엄 젤 껍질

1개에 만 원이 넘는 초고가 젤. 정말 죽을 것 같은 마의 구간을 위해 아끼고 아끼다 뜯어낸 황금빛 포장지입니다.

**negative prompt**
완전히 납작한 플랫 일러스트, 입체감 없는 채색, 디더링, 도트·노이즈 패턴, 사진 같은 사실적 질감, 배경 무늬·색상·그림자, 캔버스 밖으로 넘치거나 잘리는 구도, 워터마크, 서명, 타사 로고, 사람, 인체, 동물, 동물 캐릭터, 의인화된 얼굴이나 표정

**생성 prompt**
모바일 게임 아이템 아이콘 스타일의 툰 기반 3D 배지 아이콘. 1:1 정사각 캔버스, 살짝 위에서 내려다보는 3/4 시점. 황금빛 포장지 하나가 뜯겨 있다. 오브젝트에 자연스럽게 딸린 나무 태그나 종이 라벨 같은 작은 표면 위에 두껍고 확신에 찬 글씨로 'GOLD' 한 단어를 새겨 넣는다.

모든 배지는 1:1 정비율의 정사각형 캔버스에 담기며, 오브젝트는 살짝 위에서 내려다보는 3/4 시점의 게임 아이템 아이콘 구도로 캔버스 중앙을 가득 채우되 캔버스 밖으로 넘치거나 잘리지 않는다. 아웃라인은 두껍고 균일한 잉크선이 아니라, 형태 경계를 따라 살짝 어두운 톤으로 마감하는 얇고 부드러운 반사실적 윤곽선으로 처리한다. 채색은 툰 셰이딩 기반의 세미-페인터리 렌더링으로, 색면을 명·중간·암 2~3단으로 나누되 경계를 딱딱하게 끊지 않고 부드럽게 블렌딩한 하이라이트를 얹어 입체감을 살린다. 왼쪽 위에서 오는 광원을 가정해 밝은 하이라이트와 오른쪽 아래의 부드러운 그림자로 볼륨감을 표현하며, 완전한 평면 일러스트로 그리지 않는다. 소재별로 질감을 구분한다 — 유리·액체는 매끈하고 반투명한 광택, 코르크· 나무·가죽은 갈라지거나 거친 표면, 종이·라벨은 살짝 구겨지고 접힌 표면. 다만 사진 같은 사실적 질감이나 디더링(도트·노이즈 패턴)은 쓰지 않는다. 색감은 판타지 포션 특유의 화려하고 비현실적인 채도로 매우 높게 유지하며, 주조색은 독성 라임그린, 보조색은 일렉트릭 블루·핫 마젠타·앰버 골드·딥 브라운을 활용한다. 배경은 그림자나 무늬 없는 순백 단색이다. AI 생성 특유의 인위적으로 매끈하거나 기계적으로 대칭적인 인상이 드러나지 않도록, 붓질하듯 자연스러운 하이라이트 경계와 살짝의 비대칭을 살려 마감한다.
