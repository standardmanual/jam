# 브랜드 보이스 가이드 (초안)

> 신설 문서 (티켓 20260918_0423). 윤진(`jam-marketer`)이 관리하는 문서 자리이며, 초안은
> 도입 시범 산출물이다. 실제 캠페인·홈피드 문구를 쌓으며 채워 나간다. `docs/service/writing/UX_WRITING_GUIDELINE.md`
> (제품 UI 문구 규칙)와 겹치지 않도록 이 문서는 **마케팅 채널(뉴스레터·홈피드·캠페인)의 목소리**만
> 다룬다.

## 원칙 (윤진 정의 기준)

1. 세계관을 벗어나지 않는다
2. 사례는 겉모습이 아니라 **작동 원리**를 가져온다
3. 과장하지 않는다
4. 외부로 나가는 것은 전부 승인을 거친다

## 톤 (초안 — 실 데이터로 보정 필요)

| 상황 | 톤 | 예시 방향 |
| --- | --- | --- |
| 배지 획득 알림 | 신남, 짧게 | "○○ 배지 획득! 다음은 △△가 보인다" |
| 시즌 안내 | 세계관 목소리(트라이브별 분화) | 트라이브 화자 톤 유지, 운영성 공지는 '공통' 표시 |
| 복귀 유도 | 담백, 압박감 없이 | 마감 임박 강조는 가짜 긴급감(설계 슬롭)이므로 피한다 |
| 오류·실패 안내 | `UX_WRITING_GUIDELINE.md` [현상]→[원인]→[해결책] 구조 그대로 | 마케팅 채널에서도 제품 오류 안내는 그 기준을 따른다 |

## 어미

- 마케팅 채널(홈피드 카드 제목·부제·설명, 에디토리얼 기사 본문, 캠페인 문구)도 서비스 공통 보이스인
  **해요체**로 쓴다. 기준은 `docs/service/writing/UX_WRITING_GUIDELINE.md` §2.1이다 (2026-09-29 사용자 결정, 티켓 20260929_1250).
- 예외: 세계관 원문(TRIBES.md·컬렉션 설명·배지 설명문)을 인용할 때는 큰따옴표로 감싸고 화자를 밝혀 원문 어미
  (`-다`체·`-습니다`체)를 그대로 둔다. 인용 밖의 문장을 원문 말투에 맞추지 않는다.
  - X: 도시의 가을이 깊어지면, 그루터기 살롱의 문이 먼저 열린다. (윤진이 쓴 문장인데 `-다`체)
  - O: 도시의 가을이 깊어지면 그루터기 살롱의 문이 먼저 열려요.
- 기사 본문의 구성(설명 → 킥 → CTA)은 `docs/service/prd/content-automation/PRD.md` §8 「기사 본문 구성」이 정본이다.

## 갱신 방식

캠페인·홈피드 문구를 쓸 때마다 이 문서를 참고하고, 새로운 패턴이 자리 잡으면 이 문서에
추가한다. 실 사용자 반응(결과 기록, `forms/outcome-record-format.md`)을 근거로 갱신한다 —
추측으로 톤을 바꾸지 않는다.
