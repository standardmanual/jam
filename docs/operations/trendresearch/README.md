# JAM 트렌드 지식 문서 — 에이전트 읽기 규칙

## 기본 규칙: latest.md만 읽는다

- 에이전트는 기본적으로 이 폴더에서 `latest.md` 하나만 읽는다.
- `archive/`는 과거 회차 보관용이다. 기본적으로 읽지 않는다.
- 누적 파일은 없다. 매 회차마다 새 파일이 생기고, `latest.md`는 그 회차 내용으로 교체된다.
- 따라서 같은 파일을 매번 다시 읽을 필요가 없다. 새로 학습할 것은 `latest.md`에 들어 있는 이번 회차 내용뿐이다.

## 과거가 필요할 때만

- 특정 날짜나 주제의 과거 내용이 필요할 때만 `archive/YYYY-MM-DD.md`를 날짜를 지정해서 읽는다.
- 그 경우에도 폴더 전체를 스캔하지 않고, 필요한 날짜 파일 하나만 읽는다.

## 파일 구조

- `latest.md` — 가장 최근 회차의 신규 내용만 담는다. 매 회차 교체된다.
- `archive/YYYY-MM-DD.md` — 회차별 불변 기록. 생성된 뒤에는 수정하지 않는다.
- `README.md` — 이 규칙 문서. 회차 내용이 아니다.

## 회차 파일 형식

각 회차 파일은 3개 주제로 나뉜다.

1. 마케팅 비즈니스 — 마케팅 이론, 마케팅 비즈니스 트렌드, 마케팅 기술
2. 트렌드·이슈·밈 — 마케팅업계 또는 인터넷·커뮤니티에서 유행하는 트렌드, 이슈, 밈
3. 전국 주요 행사·스팟 — 전국의 주요 행사, 주요 스팟 정보

각 항목은 날짜, 핵심 요약, 왜 중요한지, 출처(발신자·메일 제목·메일 발송일)만 적는다. 메일 본문을 통째로 복사하지 않는다.

## 새 메일이 없는 회차

- 새 메일이 없는 회차는 새 파일을 만들지 않고 `latest.md`를 그대로 둔다.
- 이때 `latest.md`는 여전히 '마지막 업데이트된 파일'이다. 빈 파일로 덮어쓰지 않는다.
