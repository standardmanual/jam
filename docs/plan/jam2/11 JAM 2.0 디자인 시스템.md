# JAM 2.0 디자인 시스템

> **JAM 2.0 기획 문서다.** 디자인 단계의 산출물이고, 사용자가 2026-10-15에 토큰 정리 5건과 적용 결정 4건을 정했다. 서비스 적용은 상위 티켓 20261015_2130에서 진행하며 아직 코드에 반영하지 않았고,
> 에이전트는 이 문서를 현재 서비스 사실의 근거로 쓰지 않는다. 지금 서비스의 디자인 시스템은 [`jam-web/DESIGN.md`](../../../jam-web/DESIGN.md)와 `jam-web/design-system/tokens/`에 있다.

## 0. 이 문서에 대해

- 서비스 적용 티켓(상위 `20261015_2130`, 하위 5개)이 이 문서를 기준으로 쓴다. 코드에 옮긴 뒤에는 코드의 토큰 파일이 값의 원천이 된다.
- 서비스 적용은 staging에 바로 쌓고, 토큰 이름은 새 시스템 이름으로 일괄 교체한다. 새 시스템에 없는 값도 새 시스템의 이름 규칙을 따른다(2026-10-15 사용자 결정, 상위 티켓 결정 1·2).
- 1절의 피그마 파일 외에 이전 피그마 파일(서비스 화면 파일, 리뉴얼 파일)은 참고하지 않는다(2026-10-15 사용자 결정).
- 토큰 값의 원천은 1절의 피그마 파일이다. 이 문서는 피그마 값을 모두 옮겨 적지 않고, 사용자 결정으로 바뀐 값과 지금 서비스와의 대응만 적는다.
- JAM 2.0을 배포할 때 `jam-web/DESIGN.md`를 이 문서의 결과로 덮어쓴다.

### 0.1 그대로 두는 것 (2026-10-15 사용자 결정)

- 해상도 기준. 유저 화면은 모바일 컨테이너 최대 폭 430px(`jam-web/src/app/(main)/layout.tsx`)이다. 새 시스템의 `dimensions/screens/*`(640px부터)는 유저 화면 분기에 쓰지 않는다.
- UX 라이팅 가이드라인([`UX_WRITING_GUIDELINE.md`](../../service/writing/UX_WRITING_GUIDELINE.md), JAM 2.0 재정비안은 [UX 라이팅 재정비](<service-redesign/UX 라이팅 재정비.md>)).
- UI 기능과 정책. 바뀌는 것은 토큰과 시각 표현이다.
- 단위 화면은 사용자가 피그마에서 고칠 수 있다.
- 어드민(운영툴 포함)은 범위 밖이다(진행 노트 2절 진행 규칙 16).

## 5. 화면 규칙

### 5.1 카드와 표면

- 페이지 바탕은 `background/background`, 카드는 `surface/surface` + 1px `border`이고 그림자를 쓰지 않는다(2.2절 7번).
  흰 카드와 크림 바탕의 대비가 1.05:1이라 테두리가 없으면 카드가 보이지 않는다.
- 새 시스템에는 TopNav와 카드류 컴포넌트가 없다. 지금 서비스의 TopNav, ListRowCard, Card, BottomSheet, BadgeGridCard, CollectionGridCard는 새 토큰과 새 기본 부품으로 다시 조립한 서비스 패턴 컴포넌트로 둔다.

### 5.2 진행 상태 색 (2.2절 8번)

| 상태 | 가는 선·점·링 | 면 채우기 |
|---|---|---|
| 모자람(채우는 중) | `warning/warning` #f5a300 | `accent-content/accent-yellow` + `foreground/foreground` 글자 |
| 다 채움·획득 | `success/success` #17c964 | `accent-content/accent-green` + `foreground/foreground` 글자 |
| 방금 들어옴 | `accent-content/accent-blue`(6절 열린 항목) | `accent-content/accent-lightblue` + `foreground/foreground` 글자 |
| 손대지 않음(트랙) | `default/default` #f2f2f2 | |

`accent-content`의 초록·노랑·하늘색은 크림 바탕 대비가 1.1~1.3:1이라 선과 점으로 쓰지 않는다.

### 5.3 강조색

- `accent/accent` #19b551은 크림 바탕 위 글자 대비가 2.57:1이다. 버튼 같은 채우기에만 쓰고, 강조 글자는 `foreground/link` #0e7a38(5.18:1)을 쓴다.
- 초록 위 글자는 `accent/accent-foreground`(#171717, 6.63:1)다. 흰 글자는 2.7:1이라 쓰지 않는다.
- 안 읽은 소식 점은 `danger/danger`다. 지금은 주 강조색과 같은 빨강이었지만 주 강조색이 초록이 되므로 위험 계열로 옮긴다.

## 6. 열린 항목

> 2026-10-15 사용자 결정: 아래 항목은 우선 새 디자인 시스템 값 그대로 적용하고 나중에 바꾼다. 적용하는 값은 상위 티켓 20261015_2130 결정 6에 있다.

- **진행 상태 색과 희귀도 색이 겹친다.** `warning/warning` #f5a300은 epic 칩과 같은 값이고, `success/success` #17c964는 rare #00cc7a와 색상이 가깝다.
  지금 서비스는 진행 상태 색을 등급 색과 색상각 22° 이상 떨어뜨려 같은 색으로 읽히지 않게 했다(`jam-web/design-system/tokens/colors.css` 주석, 티켓 20260903_2329). 5.2절을 그대로 쓸지 사용자 확인이 필요하다.
- 「방금 들어옴」의 선·점 색. 새 시스템의 파랑 계열(`accent-content/accent-blue` #48a4fc)은 크림 바탕 대비가 2.5:1이다.
- 태그 칩(ShapeTag)의 8색. `accent-content`는 6색이라 두 색이 모자란다.
- 탭바 활성 아이콘. 흰 필 위 #19b551은 대비 2.7:1로, 아이콘 대비 기준 3:1에 못 미친다.
- 모달 배경 blur(`--blur-scrim`)를 남길지.
- 희귀도 mystic 칩의 흰 글자 대비가 3.51:1이다. 지금 서비스와 같은 값이다.

## 7. 5단계 티켓에서 확인할 것

- 토큰을 거치지 않고 코드에 직접 적은 색이 49개 파일에 286군데 있다(2026-10-15). 다크를 전제한 값은 흰색 반투명 40군데(17개 파일),
  `text-white`·`bg-black` 같은 직접 지정 59군데(29개 파일), 그림자 29군데(10개 파일), blur 13군데(3개 파일)다. 토큰을 바꿔도 따라 바뀌지 않는다.
- 공통 컴포넌트를 쓰는 서비스 파일 수(2026-10-15): TopNav 24, ListRowCard 16, Card 14, BottomSheet 9, BadgeGridCard 5, CollectionGridCard 2.
- Noto Sans KR로 바꾼 뒤 폭이 고정된 칩과 버튼의 글자 넘침을 렌더링으로 확인한다. micro(11px → 12px)를 쓰는 작은 카드 안 버튼이 먼저 확인할 곳이다.
- 서비스에 Pretendard를 불러오는 줄(`jam-web/src/app/globals.css` 1행)을 Noto Sans KR 로딩으로 바꾼다.
