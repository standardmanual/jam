# 홈피드·배지·미션·드랍 운영 자동화 파이프라인 — PRD (JAM 2.0)

> **상태: draft (JAM 2.0 개정, 2026-10-26).**  
> 2026-09-24 1단계 프로덕션 배포 스펙에서, JAM 2.0의 신규 도메인(5개 트라이브, 4등급 컬렉션, 잼·캡슐·잠긴 배지·챕터)과 완성된 어드민 운영툴([`ops-tool/PRD.md`](../ops-tool/PRD.md))을 통합하여 전면 개정했다.
> 상위 기획은 사용자 승인(2026-10-26)을 거쳤으며, 에이전트 주간 루틴 재설정은 상위 티켓 [20260930_1504](../../../tickets/p2-normal/20260930_1504_Infra_에이전트와-루틴-재설정-첫-주간-루틴.md)에서 진행한다.

---

## 1. 한 줄 정의

트렌드·시즌·세그먼트·컨텐츠 코퍼스 2.0을 입력받아 홈피드 주간 편성안·미션 초안·앰비언트 드랍 일정을 주간 운영 묶음(`ops_bundle` JSON)으로 자동 생성하고, 어드민 운영툴(`ops-inbox`)을 통한 사람의 승인을 거쳐 자동 예약 공개하며, 반응 계측과 패턴 사전 학습으로 순환하는 운영 자동화 체계.

---

## 2. 원칙

1. **완전 자동 게시는 없다 (Human-in-the-Loop).**  
   외부로 노출되는 모든 컨텐츠(홈피드 카드, 미션, 시스템 드랍)는 사람이 어드민 운영툴에서 확인하고 승인해야만 예약 공개된다.
2. **개인화는 유저군 세그먼트와 트라이브·챕터 단위다.**  
   유저 1인 단위 개인화 추천 엔진은 배제하고, [소속 트라이브 × 챕터 단계 × 활동 패턴 × 환경(날씨·특일)] 세그먼트로 편성한다.
3. **경제 수치와 안전 규칙은 불가침이다.**  
   배지 드랍 확률, 잼 정산/소비 공식, 캡슐 충전량 등 경제 밸런스 수치는 자동화가 변경하지 않는다. 날씨/기온은 야외 활동 강요 조건으로 쓰지 않으며, 밤 조건과 캡슐 열기 횟수는 순위형 미션의 기준값으로 쓸 수 없다.
4. **정치·재난·사건사고·혐오 소재는 항상 자동 제외한다 (§10).**  
   민감 소재는 기계적으로 1차 차단하고, 통과된 소재만 윈터 검수를 거쳐 톤을 조율한다.
5. **어드민 운영툴(`ops-inbox`)이 단일 승인·예약 관문이다.**  
   과거의 Markdown 리포트와 시드 SQL 수동 작성 방식은 폐기하며, 에이전트는 운영 묶음 API(`POST /api/admin/ops-inbox/bundles`)로 제출하고 운영툴의 6종 자원 연결 핸들러가 자동 예약 공개한다.
6. **세계관 텍스트(신규 5개 트라이브 정본) 원문은 왜곡하거나 임의 창작하지 않는다.**  
   원문 그대로 또는 승인된 정본 서사(`docs/plan/jam2/tribe-rethink/`) 발췌만 인용한다.
7. **묶음이 제출되면 슬랙으로 안내한다.**  
   에이전트 루틴이 묶음을 제출하면 즉시 `#jam-report`에 요약과 운영툴 바로가기 링크를 게시한다.

## 4. 컨텐츠 코퍼스 2.0과 활성·비활성 규칙

생성 층이 참조하는 코퍼스는 JAM 2.0의 신규 5개 트라이브 세계관 설정, 4등급 컬렉션 50종의 서사, 아이템 배지 1,800종의 설명 전부다.

| 코퍼스 | 출처 | 활성 판정 |
|---|---|---|
| **트라이브 세계관** (5종) | `tribes.description`·`tribes.tagline`<br>(정본: `docs/plan/jam2/tribe-rethink/`) | `tribes.is_active` (현재 활성 3종: 한입만 연구회, 물건 덕후들의 방, 소셜 에너지 100% / 비활성 2종) |
| **컬렉션 서사** (50종) | `item_books.story_text` | `item_books.is_active` 이고, 소속 트라이브(`tribe_id`)도 `tribes.is_active`여야 한다. |
| **아이템 배지** (1,800종) | `badges.description` | `deleted_at IS NULL` 이고 소속 컬렉션 및 소속 트라이브가 모두 활성 상태여야 한다. |

### 생성 규칙
1. **비활성 컨텐츠 추천 제외**: 대상 선택(카드의 이동 목적지, 미션 보상, 시스템 드랍 대상)은 반드시 활성 컨텐츠에서만 고른다.
2. **세계관 배경 인용 분리**: 비활성 트라이브나 비활성 컬렉션의 글·서사는 에디토리얼 본문에 배경으로 인용할 수 있으나, 획득·방문 유도 대상으로는 지정하지 않는다.
3. **API 자동 선택 (`/api/admin/content-corpus`)**: 후보 ID 없이 호출하면 KST ISO 주차 순환으로 활성 후보만 균형 있게 발췌한다.

| **T17** | 계절 전환 예고 | 시즌 전환 임박 | 시즌 캘린더 | 세계관 목소리 / 다음 시즌 트라이브 | 미션 목록 (`/missions`) |

### 편성 불변 규칙
1. **요일별 전원 카드 보장**: 요일마다 조건 없는(`all`) 카드가 최소 1장 이상 편성되어야 하며, 해당 카드는 반드시 `large_thumbnail`(커버 이미지 포함) 레이아웃이어야 한다.
2. **트라이브 노출 격리**: 특정 트라이브 제한 카드는 해당 트라이브 소속 유저에게만 노출되며, 다른 트라이브 유저의 피드가 비지 않도록 `all` 카드가 항상 받쳐준다.
3. **미션 카드 규칙**: 미션 소개 카드(`mission_spotlight`)는 `large_thumbnail` 레이아웃과 미션 대표 이미지를 그대로 사용한다.

## 7. 미션 기획 자동화 (`kind: "mission"`)

에이전트는 주간 묶음 제출 시 주간 트라이브 미션과 공통 미션을 함께 기획하여 제안한다.

### 7.1 미션 구분
- **트라이브 미션 (주간 1~2건)**: 신규 5개 트라이브의 세계관 이벤트. 특정 트라이브만 참여할 수 있도록 `mission_allowed_tribes`를 지정한다.
- **공통 미션 (주간 1건 또는 상시)**: 트라이브 제한 없이 모든 유저가 함께 달성하는 활동 미션.

### 7.2 JAM 2.0 미션 조건 가드레일 (엄수)
1. **밤 조건의 순위형 금지**: 밤 시간대 조건이 포함된 미션은 달성형/개인형만 허용하며, "어두울 때는 무리하지 마세요" 안전 안내문을 필수로 붙인다.
2. **캡슐 열기 횟수의 순위형 금지**: 유료 상품 결제 유저의 순위 독점을 방지하기 위해 캡슐 횟수는 순위형 조건으로 쓰지 않는다.
3. **모은 잼(`jam_period_earned`)의 랭킹보드 미노출**: 기간 동안 모은 잼 조건 미션은 홈 투데이 랭킹 보드에 연결하지 않는다 (미션 상세에서만 진행값 확인).
4. **날씨/기온 조건 배제**: 궂은 날씨에 억지 외출을 유도하지 않기 위해 날씨는 미션 조건으로 쓰지 않는다.

## 8. 시스템 앰비언트 드랍 기획 자동화 (`kind: "drop_schedule"`)

특정 시즌 행사, 주말 게릴라, 미개척 장소 활성화를 위해 에이전트가 주간 드랍 일정을 기획한다.

1. **지점 선택**: POI 카테고리(`poi_category`) 기반 무작위 분배 또는 특정 POI 목록(`poi_ids`) 직접 지정.
2. **아이템 선택**: 특정 아이템 배지 목록(`badge_ids`) 또는 특정 컬렉션(`collection_ids`) 지정.
3. **수량 상한**: 예약 1건이 필드에 살포하는 드랍 총합은 **최대 100개**로 제한한다 (`total_count <= 100`).
4. **종료 시각 없음**: 드랍은 유저가 주울 때까지 필드에 잔류하므로 `ends_at`을 두지 않는다.

## 9. JAM 2.0 특화 자동화 5대 패턴 (사용자 확정)

주간 운영 묶음 제출 시 에이전트가 우선적으로 조합하여 편성하는 5대 특화 패턴이다.

1. **「피드+스팟+드랍+미션」 4중 결합 게릴라 이벤트 패키지**  
   TourAPI 축제나 로컬 핫스팟 발견 시, [홈피드 카드 + 앰비언트 드랍 + 연계 미션] 3종을 상호 `links`로 연결하여 묶음으로 제안. 유저에게 일관된 현장 탐방 경험을 제공한다.
2. **컬렉션 「라스트 원(Last One)」 결손 추적 매핑**  
   4등급 컬렉션 중 슬롯 7~8개를 채운 유저층을 감지하여, 결손 배지가 출몰하는 POI 구역에 시스템 드랍을 집중 살포하고 타깃팅 피드 카드를 노출한다.
3. **「잠긴 배지 구출 & 인벤토리 정체 해소」 잼 순환 미션**  
   인벤토리 내 잠긴 배지 누적 및 잼 부족 감지 시, `jam_period_earned` 조건의 잼 획득 미션과 해금 넛지 피드를 연계하여 잼 경제 선순환을 유도한다.
4. **크로스 트라이브 「원정 탐험 & 단서 교환」 미션**  
   소속 트라이브 외 타 트라이브 컬렉션 결손이 심화된 경우, 트라이브 전용 미션(`mission_allowed_tribes`)을 통해 타 트라이브 영역 방문 시 타 트라이브 배지를 보상으로 지급한다.
5. **「미개척 스팟 보물찾기 (포가튼 스팟)」 자동화**  
   최근 30일간 체크인/픽업 로그가 0건인 소외된 외딴 POI를 발굴하여 희귀(Rare/Epic) 시스템 드랍을 1~2개 배치하고 탐험 피드 카드로 모험을 유도한다.

## 10. 이슈 소재 입력과 자동 제외 필터

### 10.1 소재 소스
- 기상청 단기예보, 공공 특일정보 API, 한국관광공사 TourAPI (자동 수집).
- 유튜브 Data API, 빅카인즈 Open API (뉴스 트렌드 키워드).
- 지정 수동 열람 채널 (윤진·윈터의 트렌드 검수).

### 10.2 자동 제외 범주
| 범주 | 기록 사유 문구 | 예외 |
|---|---|---|
| **정치** | 정치적 논쟁 소재로 자동 제외 | 없음 |
| **재난·사고** | 재난·사고 소재로 자동 제외 | 순수 기상특보 안전 안내만 허용 |
| **범죄·사건** | 범죄·사건 소재로 자동 제외 | 없음 |
| **혐오·비하** | 혐오·비하 표현 소재로 자동 제외 | 없음 |
| **실존 인물** | 실존 인물 언급으로 자동 제외 | 없음 |
| **저작권 소재** | 저작권 직접 인용으로 자동 제외 | 작동 원리 차용만 허용 |
| **비교·순위형 밈, 의료 조언** | 세계관 미배정 소재로 제외 | 없음 |

## 11. 주간 주기와 운영툴 워크플로

운영 일정은 기존 스케줄(화요일 기획안 → 수요일 확정 → 목요일 정기 배포)을 그대로 유지한다.

```
[화요일 09:00 KST] 에이전트 주간 루틴 자동 실행
   ↓
[09:05 KST] 주간 운영 묶음 JSON POST /api/admin/ops-inbox/bundles 전송
   ↓
[09:06 KST] 슬랙 #jam-report 채널로 기획안 도착 알림 발송 (운영툴 직접 링크 포함)
   ↓
[화~수요일] 운영자가 어드민 운영툴(ops-inbox) 접속
   - 기획안 상세 검토, 카드 미리보기 확인, 문안 수정, 불필요 항목 제거
   - 이미지 지시(image_spec) 확인 및 필요 시 이미지 서랍에서 생성
   ↓
[수요일 18:00 KST] 운영자 "승인" 버튼 클릭
   ↓
[즉시] 운영툴 자원 연결 핸들러가 차주 월~일 편성 데이터 예약 등록
   - today_cards 예약 등록
   - missions 생성 및 공개 시각 설정
   - drop_schedules 등록
   ↓
[목요일 정기 배포 시] 시스템이 정식 예약 일정에 따라 무인 자동 공개
```

## 12. 계측 및 패턴 사전 연계

- **이벤트 수집**: `today_card_events`에 노출(`impression`), 클릭(`click`)을 기록하며 개인 식별자는 남기지 않는다.
- **조회 API**: `GET /api/admin/today/metrics`가 유형별·모양별·패턴 번호별(`P01`~`P18`) 반응률을 집계한다.
- **패턴 사전 환류**: 수집된 지표는 어드민 운영 패턴 사전(`ops_patterns`)의 성과 데이터로 연결되어 다음 주 에이전트 브리핑 및 편성 비율 조정에 반영된다.
