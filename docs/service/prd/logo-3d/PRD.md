# 3D 로고 제너레이터 PRD

> 요구사항 정본·결정 기록은 상위 티켓 [20261103_1349](../../../tickets/p2-normal/20261103_1349_Feature_3D-로고-제너레이터-별도-어드민-페이지-상위.md)에 있다. 이 문서는 구현된 동작과 규칙만 담는다.

## 1. 한 줄 정의
어드민이 Google Fonts 글자(또는 SVG 로고)를 3D로 압출하고, 원본보다 앞뒤로 튀어나오는 스틸 틀을 자동으로 만든 뒤, 두께·색·회전·줌·시점·배경을 조절해 PNG로 저장하는 별도 어드민 페이지(`/admin/logo-3d`)다.

## 2. 구성
| 층 | 위치 | 역할 |
|---|---|---|
| 형상 엔진 | `jam-web/src/lib/logo-3d/buildGeometry.ts` | 윤곽 → 틀·타일·바닥판 (티켓 20261103_1350) |
| 입력 변환 | `jam-web/src/lib/logo-3d/fontOutline.ts`, `svgOutline.ts` | 폰트·SVG → 윤곽 (티켓 20261103_1351) |
| 폰트 중계 | `GET /api/admin/logo-3d/font?family&weight` | 구글 폰트 TTF를 서버가 받아 흘려보냄 (어드민 로그인 필수) |
| 화면 | `jam-web/src/app/admin/logo-3d/` | 페이지·설정 패널·뷰포트·설정 파일 (티켓 20261103_1352) |

메뉴는 어드민 사이드바 「디자인」 그룹의 「에셋」 바로 아래 「3D 로고」다. 로그인·권한은 기존 어드민 레이아웃이 확인한다.

## 3. 화면
좌측 미리보기, 우측 설정 패널의 2단이다(어드민 에셋과 같은 구성). 패널 컴포넌트는 `@/components/admin/ui/*`(shadcn/ui)만 쓰고 네이티브 `<select>`는 쓰지 않는다.

### 3.1 입력
- 폰트 글자: 폰트 검색 드롭다운(정적 카탈로그 `googleFontsCatalog.json`), 굵기 100~900, 글자열(최대 24자). 글자열은 300ms 멈춘 뒤 반영한다.
- SVG 파일: 업로드한 SVG 문자열을 브라우저 `DOMParser`로 읽는다(5MB 이하). 스크립트·외부 이미지 요소는 읽기 전에 지운다.
- 둘 중 하나만 활성이다. 폰트·글자열을 건드리면 폰트로, SVG를 올리면 SVG로 전환된다.
- 불러오는 동안 미리보기에 「불러오는 중이에요...」를 보이고, 실패하면 패널 위쪽 오류 영역에 `[현상] → [원인] → [해결책]` 문장을 보이며 **이전에 만든 3D 로고를 그대로 유지**한다.

### 3.2 조절 항목
| 구역 | 항목 | 비고 |
|---|---|---|
| 두께 | 로고 깊이, 외곽선 폭, 틀 앞쪽 돌출, 틀 모서리 둥글림, 타일 모서리 둥글림 | 범위는 `LOGO3D_PARAM_RANGES`. 윤곽 최소 두께를 넘는 값은 형상 엔진이 상한으로 줄이고, 사유를 패널에 「값을 자동으로 조정했어요」로 보인다 |
| 색 | 프리셋 팔레트 6종(틀·타일 색 쌍), 틀 색·타일 색 직접 선택 | 직접 고르면 팔레트 선택이 풀린다 |
| 시점 | 원근 / 등각, 회전 X·Y·Z(−180~180°), 줌(30~300%) | 등각은 방위각 45°·고도 약 35.264°의 직교 투영 |
| 배경 | 배경 방식, 배경 A·B, 배경 각도 | 아래 3.3 |
| 저장 | 비율 1:1·4:5·9:16·16:9, PNG 저장 | 아래 3.4 |

슬라이더를 끄는 동안은 형상을 즉시 다시 만들지 않고 한가해질 때 만든다. 회전·줌·시점·색·배경을 바꿀 때는 형상을 다시 만들지 않고 다시 그리기만 한다.

### 3.3 스테이지(배경) 3모드
어드민 에셋(`assets/shapeStudioConfig.ts`)의 `BackgroundMode`·`bgA`·`bgB`·`bgAngle`과 같은 형태이고, 배경 섹션의 문구·배치도 같다.

| 모드 | 쓰는 입력 | 비고 |
|---|---|---|
| Gradient | 배경 A, 배경 B, 배경 각도 | 각도 0°면 왼쪽(A) → 오른쪽(B), 양수는 위쪽으로 돈다. 색은 smoothstep으로 섞는다 |
| Solid | 배경 A | 나머지 입력은 비활성 |
| Transparent | 없음 | 미리보기는 체크무늬, 저장한 PNG의 배경 픽셀 알파는 0 |

### 3.4 회전·줌 입력
슬라이더와 마우스가 같은 상태를 바꾼다. 미리보기를 드래그하면 가로 이동은 Y, 세로 이동은 X 회전(1px당 0.5°)이고, 휠은 줌이다. 카메라를 도는 방식(OrbitControls)이 아니라 로고를 돌리는 방식이라 슬라이더 값과 항상 일치한다.

### 3.5 PNG 저장
- 크기는 에셋 제너레이터와 같은 긴 변 1280px 규칙이다: 1:1 1280×1280, 4:5 1024×1280, 9:16 720×1280, 16:9 1280×720.
- Gradient·Solid는 2D 캔버스에 배경을 먼저 칠하고 3D 이미지를 위에 얹는다. Transparent는 배경을 칠하지 않는다.
- 파일명은 `logo-3d-{글자열 앞부분 12자}-{비율}.png`이고 비율의 `:`는 `x`로 바꾼다(예: `logo-3d-JAM-16x9.png`). SVG는 파일 이름을 쓴다.
- 서버 저장(프리셋·콘텐츠 적용)은 범위 밖이다. PNG를 내려받아 에셋으로 올리는 흐름이다.

## 4. 렌더 품질과 Blender 렌더의 차이
- 실시간 WebGL이라 크롬·유약 반사는 Blender 경로 추적 렌더보다 품질이 낮다. 반사용 환경 맵(밝은·어두운 띠가 있는 스튜디오 환경)으로 맞추되 차이는 남는다.
- 재질: 틀은 금속성 0.95·거칠기 0.36의 매트 스틸, 타일은 거칠기 0.3·광택층 거칠기 0.07의 도자기(`MeshPhysicalMaterial`)다. 환경은 배경과 별개라 배경이 투명이어도 반사는 그대로다.
- 장식이 많거나 획이 매우 가는 폰트는 외곽선·둥글림이 깨질 수 있어 형상 엔진이 값을 줄이고 사유를 알린다.

## 5. 알려진 한계
- 한글 폰트는 파일 전체를 받는다(Noto Sans KR 700이 약 6.0MB). 용량을 줄이는 처리는 다음 단계다.
- M처럼 좁은 틈이 있는 글자는 외곽선 폭 최솟값(0.010)과 틀 모서리 둥글림 최댓값(0.040)을 함께 쓰면 틀 윗면에 넓이가 거의 0인 삼각형이 생겨 가는 이음선이 보일 수 있다. 형상 엔진의 결함으로 별도 처리 대상이다.
- 굵기는 100~900을 모두 고를 수 있지만 폰트마다 있는 굵기가 다르다. 없는 굵기를 고르면 오류 영역에 안내가 나온다.
