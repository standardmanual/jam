# [BadgeEngine] JAM! 행동 지표 ① 믹스 4종과 공용 틀

> 상위: 20260930_1456 · 하위 순서 ① · 선행 없음

## 핵심 요약

- 요구사항: 믹스 시도·성공·실패·레시피 최초 성공 지표를 만들고, 13개 지표가 함께 쓸 공용 틀(조건 등록·가드·어드민 폼·발급기 공유)을 만든다. 믹스 성공은 지금 기록되지 않으므로 기록 테이블부터 만든다.
- 구현 계획: 아래 「구현 계획」(파일 단위, 혜린 초안·카리나 확정)을 따른다. 실패 로그 CHECK 버그(티켓 20261001_0636)도 마이그레이션 200에서 함께 고친다.
- 관련 파일: 「구현 계획」에 파일·함수·줄 위치가 있다.

## 시작 절차

상위 티켓 20260930_1456의 「주요 의사결정」(혜린 시작 검토, 사용자 결정 Q1~Q3, 가정 A1~A20, 포인트 추천표)이 이 티켓의 전제다. 혜린 검토는 1456에서 끝났으므로 다시 하지 않는다.
그 결정과 다르게 가야 하면 멈추고 사용자에게 확인한다. 마이그레이션은 사용자 승인 뒤 메인 세션이 실행한다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 마이그레이션 파일 2개에 각각 `-- 되돌림 SQL` 블록이 있다(`deploy-gate check` 통과). 199는 `badges_condition_json_known_keys`를 62키로 넓히고 기존 행을 바꾸지 않는다. 200은 `user_combine_success_logs`
  (RLS 켬·정책 0, `recipe_id` FK 없음, `(recipe_id) where is_recipe_first` 부분 유니크), RPC `record_combine_success`(service_role만 실행), 실패 로그 CHECK 4값 보정을 만든다.
- 믹스 시도·성공·실패 각각을 조건으로 한 배지가 조건을 채우면 발급된다(테스트). 시도는 「성공 기록 수 + `no_recipe_match` 수」이고, 소각 전에 끝난 실패(`invalid_count`·`items_not_found`·`recipe_not_found`)는 세지 않는다(테스트).
- 레시피가 일치하면 보상이 비어도(빈손 성공) 성공 1건으로 기록된다(테스트).
- 같은 레시피를 두 유저가 동시에 성공해도 최초 표시는 정확히 1건이고, 그 유저만 `recipe_first_success` 배지를 받는다(테스트).
- 성공 기록 실패·판정 예외·알림 실패가 있어도 `/api/combine` 응답(상태 코드·JSON 키·메시지)은 변경 전과 같다(테스트). 재료 소각·보상 지급 순서는 바뀌지 않는다.
- 레지스트리가 62키를 선언하고, 레지스트리와 최신 CHECK 마이그레이션의 키 집합이 같다(자동 탐지 테스트). 새 4키는 `repeat_count`·다른 measurable 조건과 함께 저장할 수 없고,
  `USAGE_METRIC_CONDITION_KEYS`의 모든 키에는 판정기가 있다(계약 테스트).
- 어드민 조건 폼이 4키를 입력·저장·복원하고(왕복 테스트), `recipe_first_success`는 존재하지 않는 레시피 ID로 저장할 수 없다(테스트).
- 유저 초기화가 `user_combine_success_logs`도 지운다(테스트).
- 기존 JAM! 6지표 경로, `usage-badges.test.ts`, 메인 엔진의 JAM! 제외 동작은 바뀌지 않고 기존 테스트가 전부 통과한다.
- 문서: `BADGE_ENGINE_UNIFIED.md`, `CONDITION_JSON_SPEC.md`, `02_DATA_MODEL.md` §7을 사실로 갱신한다.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤)
- 사용자 승인을 받아 199·200을 실행한다(코드 배포보다 먼저가 안전). 실행 뒤 RLS·정책·인덱스 술어·함수 권한·실패 로그 CHECK를 확인하고, 200의 DO 블록 롤백 스모크로 동시 최초 성공 1건을 실측한다.
  `database.generated.ts`를 `information_schema.columns`·`pg_proc`과 대조한다.
- 사용자에게 「시도·성공은 배포일부터, 실패는 2026-09-10부터 센다」를 알린다(Q1의 한계).
