# [HomeFeed/Admin] 홈피드 카드 동영상 미디어 지원 및 에셋(Shape Studio) 연동

## 핵심 요약
- 요구사항: 에셋(Shape Studio / `/admin/assets`)에서 생성한 동영상을 홈피드 카드의 이미지(커버 미디어) 영역에서 사용할 수 있도록 지원한다.
- 범위:
  1. **홈피드 카드 렌더링 (`CardImageSlot.tsx`)**:
     - `imageUrl`이 동영상(mp4, webm 등)일 경우 `<video>` 태그로 자동 재생(`autoPlay`, `loop`, `muted`, `playsInline`) 지원.
     - `HeroCard`, `PosterCard`, `SquareCard`, `DomeCard`, `TicketCard` 등 `CardImageSlot`을 사용하는 모든 카드 모양에서 자연스러운 클리핑 및 비율 적용.
  2. **어드민 투데이 콘텐츠 폼 (`TodayCardForm.tsx`)**:
     - 커버 미디어 필드에 동영상(MP4, WebM) 및 이미지 직접 파일 업로드 기능 제공.
     - 우측 레일 실시간 미리보기에서 동영상 재생 확인.
  3. **에셋 화면 (`/admin/assets`의 `ApplyTab.tsx`)**:
     - 홈피드 카드로 반영 시 '이미지(정지화면)'와 '동영상(15초 모션)' 중 선택 가능하도록 확장.
     - 동영상 모드 선택 시 캔버스 모션을 녹화하여 `/api/admin/asset-generator/apply`를 통해 업로드하고 `cover_image_url`에 자동 반영.
  4. **API 확장 (`/api/admin/asset-generator/apply/route.ts`, `/api/admin/upload-image/route.ts`)**:
     - 비디오 파일(`video/mp4`, `video/webm`) 업로드 및 `today_cards.cover_image_url` 연동 지원.

## 완료 조건
- 홈피드 카드의 커버 미디어에 MP4/WebM 동영상 주소가 설정된 경우, 화면에서 무음 루프로 자동 재생된다.
- 돔형(`DomeCard`)과 티켓형(`TicketCard`)을 포함한 모든 카드 모양에서 동영상이 지정된 모양의 테두리/마스크에 맞게 클리핑된다.
- 어드민 투데이 카드 등록/수정 화면에서 동영상 파일을 직접 업로드할 수 있다.
- 에셋(/admin/assets) 화면의 콘텐츠 적용 탭에서 홈피드 카드를 선택하고 동영상으로 바로 적용할 수 있다.
- 타입체크, ESLint, 단위 테스트 전수 통과.
