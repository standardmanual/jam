# [Infra] gate_key_backup_20261031 표에 행 단위 보안(RLS)이 꺼져 있다

## 핵심 요약

- 요구사항: `public.gate_key_backup_20261031`(72행)에 행 단위 보안이 꺼져 있어 공개 키만 있으면 누구나 읽고 쓸 수 있다. 켠다.
- 구현 계획: `ALTER TABLE "public"."gate_key_backup_20261031" ENABLE ROW LEVEL SECURITY;` 한 줄. 같은 날짜대의 다른 백업 표(`gate_mission_backup_20261028` 등)는 RLS를 켜고 정책을 두지 않아 service_role만 접근한다. 같은 모양으로 맞춘다.
- 관련 파일: 새 마이그레이션 `jam-web/supabase/migrations/`(번호는 원격 staging 기준으로 push 직전 확인). 되돌림은 `DISABLE ROW LEVEL SECURITY`.

## 배경 / 문제 정의

2026-11-03 다른 조사 중 DB 조회 도구의 보안 경고(`rls_disabled`, critical)로 발견했다. 표에 무엇이 들어 있는지는 읽지 않았다. 이름이 «게이트 키 백업»이라 내용을 확인한 뒤 노출됐던 기간과 내용에 따라 후속 조치가 필요한지 판단한다. 이 DB는 staging·프로덕션 공용이라 즉시 프로덕션에 반영된다(CLAUDE.md 절대 규칙 6).

## 완료 조건

- `gate_key_backup_20261031`의 RLS가 켜져 있고, 공개 키로 조회하면 0행이다. (읽기 전용 확인: `pg_class.relrowsecurity`와 공개 키 조회)
- 켜기 전 표 내용에 외부에 알려지면 곤란한 값이 있었는지 확인해 이 티켓에 남긴다.
