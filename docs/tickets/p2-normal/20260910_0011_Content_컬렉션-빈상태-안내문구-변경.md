# [Content] 컬렉션 탭 빈 상태 안내 문구 변경

## 배경 / 문제 정의
배지 > 컬렉션 탭에서 컬렉션이 없을 때 보이는 안내 문구("관리자가 컬렉션을 등록하면 이 곳에
표시돼요")가 실제 획득 조건(아이템배지 획득)을 설명하지 않고 운영 관점 문구였다. 사용자
요청으로 사용자 행동 기준 문구로 교체한다.

## 상세 요구사항

### 컨텐츠 관점
- `src/lib/i18n/ko.ts`의 `emptyItembookBody` 값을 "관리자가 컬렉션을 등록하면 이 곳에
  표시돼요" → "아이템배지를 획득하면 컬렉션이 나타납니다"로 변경(사용자 지정 문구 그대로 반영)
- 사용 위치: `src/app/(main)/badges/BadgesClient.tsx`의 컬렉션 탭 빈 상태(`EmptyState`)

## 구현 계획
경미 수정(1파일, 문구 한 줄) — 파이프라인 없이 직접 처리.

## 완료 기록

### 구현 내용 요약
`ko.ts`의 `emptyItembookBody` 문구를 사용자 지정대로 교체. `UX_WRITING_GUIDELINE.md`
대조 결과 "컬렉션"·"아이템배지"는 문서에 이미 쓰이는 표현과 일치. 다만 가이드의 해요체
원칙과 달리 사용자가 준 문구는 "나타납니다"(합쇼체)라 문서 규칙과는 다르지만, 사용자가
정확한 문구를 지정했으므로 그대로 반영했다.
