# [UI] 컬렉션 상세 슬롯 해제 버튼 색상을 그레이로 변경

## 배경 / 문제 정의
컬렉션 상세(`/collections/[id]`) 슬롯 장착 모드에서 "해제" 버튼이 "장착" 버튼과 동일한
`--color-primary`(브랜드 컬러) 배경을 쓰고 있었다. 장착(양성 액션)과 해제(취소성 액션)를
시각적으로 구분해 달라는 사용자 요청.

## 상세 요구사항

### 서비스/코드베이스 관점
- `src/app/(main)/collections/[id]/SlotGrid.tsx`의 해제 버튼(`unslotButton`)만
  `bg-[color:var(--color-primary)]` → `bg-[color:var(--color-base-grey-600)]`(#666666)로 변경
- 장착 버튼(`slotButton`)은 그대로 유지(브랜드 컬러)
- 텍스트 컬러(`--color-text-on-primary`, 흰색)는 그대로 유지 — 회색 배경에서도 대비 충분

## 구현 계획
경미 수정(1파일, className 값 1곳) — 파이프라인 없이 직접 처리.
