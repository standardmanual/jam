# [Admin] 드랍 정책 — 아이템배지 드랍 제외 기능 추가

## 배경 / 문제 정의
어드민에서 특정 아이템배지(또는 컬렉션 전체)를 드랍 후보에서 제외할 수 있는 기능이 없다.
현재 드랍엔진의 제외 메커니즘은 `badges.deleted_at`(소프트삭제)와 `item_books.is_active`
(컬렉션 전체 활성/비활성)뿐이며, "드랍에서만 제외하고 나머지는 그대로 둔다"는 의미의
플래그는 존재하지 않는다.

## 상세 요구사항

### 서비스/코드베이스 관점
- DB: `public.badges`에 `drop_excluded BOOLEAN NOT NULL DEFAULT false` 컬럼 추가,
  `public.item_books`에도 동일하게 `drop_excluded BOOLEAN NOT NULL DEFAULT false` 추가
  (사용자 확정 — `item_books.is_active`와는 별도 플래그. `is_active`는 화면 노출 자체를
  끄는 더 강력한 개념으로 남겨두고, `drop_excluded`는 "드랍만 제외"라는 좁은 의미)
- 드랍엔진(`jam-web/src/lib/drop-engine/index.ts:172-201` 근방, 아이템배지 후보 조회
  쿼리): 후보 조회 시 `item_books.drop_excluded = false` AND `badges.drop_excluded = false`
  조건을 추가한다. 컬렉션이 `drop_excluded=true`면 그 소속 배지 전체가, 배지 개별
  `drop_excluded=true`면 그 배지 하나만 드랍 후보에서 빠진다.
- 마이그레이션 파일은 `jam-web/supabase/migrations/0XX_설명.sql`로 작성만 하고 실행은
  사용자 승인 후 오케스트레이터가 처리한다 (CLAUDE.md 규칙).

### UI/UX 관점
- 어드민 화면(신규 또는 기존 `/admin/drop-policy` 하위 확장)에 다음 UX를 구현:
  1. **트라이브 선택 필터** — 조회 좁히기 전용(사용자 확정). 트라이브 자체를 드랍
     제외하는 기능은 이번 범위 밖.
  2. **컬렉션 선택 필터** — 선택한 트라이브 소속 컬렉션만 목록에 표시(드릴다운).
  3. **아이템 배지 다중 선택** — 선택한 컬렉션(또는 전체) 소속 아이템배지 목록에서
     체크박스로 다중 선택 후 일괄 "드랍 제외"/"제외 해제" 액션.
     기존 `src/app/admin/badges/`의 `RowSelectionState` + `DataTableBulkActionBar`
     패턴(일괄 비활성화 기능, 티켓 20260908_2129)을 그대로 재사용한다.
  4. **컬렉션 전체 선택** — 컬렉션 단위로 "이 컬렉션 전체 드랍 제외" 토글 하나로
     `item_books.drop_excluded`를 켜고 끌 수 있다. 배지 다중선택과는 별개의 액션이다.
  5. 현재 `drop_excluded=true` 상태인 배지·컬렉션은 목록에서 시각적으로 구분 표시한다.
- `src/app/admin/`은 MODULAR 적용 제외 대상이다 — 디자인 시스템 탐색 없이
  service-specific으로 구현한다.
- 노출 문구는 `UX_WRITING_GUIDELINE.md` 기준을 따른다.

## 구현 계획
1. 마이그레이션 SQL 작성(badges·item_books에 `drop_excluded` 컬럼 추가)
2. 드랍엔진 후보 조회 쿼리에 제외 조건 추가
3. 어드민 화면 구현 (트라이브 필터 → 컬렉션 필터 → 배지 다중선택/컬렉션 전체 토글)
4. `npm run db:types`로 생성 타입 갱신 필요 (마이그레이션 실행 후, 오케스트레이터가 처리)

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
`public.badges`·`public.item_books`에 `drop_excluded BOOLEAN NOT NULL DEFAULT false` 컬럼을
추가하고, 드랍엔진(`drop-engine/index.ts`)의 컬렉션 조회에 `.eq('drop_excluded', false)`,
개별 배지 후보 필터에 `if (b.drop_excluded) return false`를 추가했다. 어드민에
`/admin/drop-policy/exclusions` 화면을 신설해 트라이브 필터(조회 좁히기 전용)→컬렉션 필터
드릴다운, 컬렉션 전체 드랍 제외 스위치 목록, 아이템배지 체크박스 다중선택+일괄 제외/해제
(기존 `RowSelectionState`+`DataTableBulkActionBar` 패턴 재사용)를 구현했다. API는
`PATCH /api/admin/badges/[id]/drop-exclude`, `PATCH /api/admin/itembooks/[id]/drop-exclude`
2건을 신설했다.

### 주요 의사결정 / 핵심 메모
- "컬렉션 전체 드랍 제외"는 기존 `item_books.is_active`를 재사용하지 않고 별도
  `drop_excluded` 플래그를 신설하기로 확정 — `is_active`는 화면 노출 자체를 끄는
  더 강력한 개념으로 유지하고, 드랍 전용 제외는 별도 의미로 분리(사용자 확정).
- 트라이브 선택은 드랍 제외 대상이 아니라 조회 좁히기 필터로만 동작(사용자 확정).
  트라이브 단위 드랍 제외가 필요해지면 별도 티켓으로 진행.
