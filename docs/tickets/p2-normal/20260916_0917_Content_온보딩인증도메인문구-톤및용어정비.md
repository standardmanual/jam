# [Content] 온보딩/인증(Strava) 도메인 문구 톤 및 용어 정비

## 배경 / 문제 정의

티켓 20260915_2246의 딕셔너리 이관 구조는 게이트 PASS했지만, 한국어 리뷰가 `d.auth.*` 신규
문구 7종 전체에서 번역투·수동태·§4.1 3단계 미충족·§1.3 미등재 용어("활동 기반 배지")를
지적했다.

## 상세 요구사항 — `jam-web/src/lib/i18n/ko.ts`의 `d.auth` 값 수정

### (a) 에러 3단계 구조(§4.1) 미충족 — 최우선
`stravaSyncError`("Strava 동기화 중 오류가 발생했어요. 잠시 후 다시 시도해 주세요.")는
현상뿐이고 정형구 CTA다. 가이드 §4.1 표에 이미 이 시나리오의 모범답안이 있다:
→ "Strava 동기화가 끊겼어요. 동기화 권한이 해제됐거나 Strava 연결이 잠시 불안정했을 수
있어요." + CTA 버튼 `[Strava 다시 동기화하기]`

### (b) 수동태·시스템 시점 교정
- `stravaNotConnectedTitle`("Strava 동기화 안 됨") → 빈 상태(§4.3)인데 "안 됨"이 실패처럼
  읽힌다 → "아직 Strava를 동기화하지 않았어요"
- `stravaConnectedTitle`("Strava 동기화됨") → "Strava와 동기화하고 있어요"
- `stravaNoSyncYet`("아직 동기화된 데이터가 없어요") → "데이터"는 공급자 언어 → "아직
  불러온 활동이 없어요"

### (c) 미등재 용어(§1.3) — "활동 기반 배지"
`stravaConnectPrompt`의 "활동 기반 배지"는 용어표에 없는 조어다. 컨텐츠 체계의 고정 명칭은
**액티비티배지**다 → "Strava를 동기화하면 달린 기록으로 액티비티배지를 획득할 수 있어요"

### (d) 표기 규칙(§3)
`stravaLastSyncedLabel`("마지막 동기화:")의 콜론은 UI 라벨이 아니라 로그 필드 표기다 →
"마지막 동기화" (콜론 제거). 값 포맷도 §3 날짜/시간 규칙("7월 31일 오후 3시 30분" 형태)을
따르는지 별도 확인.

### (e) 카드 헤더 길이 제약 확인
`stravaNotConnectedTitle`/`stravaConnectedTitle`이 카드 헤더처럼 자리가 좁으면 위 (b) 대안이
길 수 있다 — 필요하면 "Strava 동기화 전" / "Strava 동기화 중"으로 축약하되, 후자가 "지금
진행 중"으로 오독되지 않는지, §5.3 처리 중 라벨과 화면에서 겹치지 않는지 확인한다.

## 구현 계획
- `ko.ts`의 해당 키 값만 수정한다.
- (a)는 CTA 버튼 배치가 필요하므로 `StravaStatusCard.tsx`(또는 실제 렌더 위치)에서 버튼
  추가 여부를 함께 확인한다.
- 완료 후 `/im-not-ai`로 재검사한다.

### 주요 의사결정 / 핵심 메모
- (a) CTA 버튼 `[Strava 다시 동기화하기]`는 붙이지 않았다. `stravaSyncError`를 반환하는
  `/api/strava/sync`(500 오류 JSON body)를 실제로 호출하는 `SyncButton.tsx`는 이 값을
  읽지 않고 별도 고정 토스트 `d.today.syncFailed`("동기화 실패. 잠시 후 다시
  시도해주세요")를 띄운다 — 즉 `stravaSyncError` 문구 자체가 현재 어떤 화면에도 노출되지
  않는다. CTA를 붙일 렌더 지점이 없어 문구만 완성하고 버튼은 잔여 이슈로 남긴다.
- (e) 카드 헤더 길이 제약은 검토 대상이 아니었다 — 유일한 렌더 후보였던
  `StravaStatusCard.tsx`가 아래 잔여 이슈처럼 고아 컴포넌트라 실제 화면 폭 제약이 없다.
  축약안("Strava 동기화 전"/"Strava 동기화 중")은 적용하지 않고 원안을 그대로 썼다.

### 잔여 이슈
- `StravaStatusCard.tsx`(`jam-web/src/components/strava/StravaStatusCard.tsx`)는
  코드베이스 어디서도 import되지 않는 고아 컴포넌트다. 이 티켓이 교정한
  `stravaNotConnectedTitle`/`stravaConnectPrompt`/`stravaConnectedTitle`/
  `stravaLastSyncedLabel`/`stravaNoSyncYet`은 전부 이 컴포넌트에서만 쓰여, 교정 문구가
  실제로 화면에 노출되지 않는다. 컴포넌트를 어딘가에 연결하거나(온보딩/설정 화면 등) 죽은
  코드로 정리하는 결정이 필요하다.
- `stravaSyncError`도 위와 같은 이유로 미노출 상태다 — `/api/strava/sync`의 500 오류를
  클라이언트가 실제로 사용자에게 보여주려면 `SyncButton.tsx`가 이 값을 읽어 토스트로
  띄우도록 바꿔야 한다(현재는 고정 문구 `d.today.syncFailed`를 씀). CTA 버튼
  `[Strava 다시 동기화하기]`도 이 개편이 선행돼야 붙일 자리가 생긴다.
- `stravaLastSyncedLabel`의 실제 렌더에 쓰이는 `LocalDate` 포맷
  (`{year:'numeric', month:'long', day:'numeric', hour:'2-digit', minute:'2-digit'}`)은
  `toLocaleString('ko-KR')` 결과가 "2026년 9월 16일 오후 03:30"처럼 시:분을 콜론으로
  이어 붙인다 — §3 가이드 예시("오후 3시 30분")와 다르다. 이 티켓은 `d.auth` 값 교정만
  범위라 `LocalDate` 옵션 자체는 건드리지 않았다. 이 포맷 패턴은 배지 상세
  페이지(`badges/[id]/page.tsx`)에도 동일하게 쓰이고 있어, 손대려면 이 티켓 범위를 넘는
  더 넓은 후속 티켓이 필요하다 — 이미 티켓 20260916_0833(날짜/시간 표기 가이드 불일치,
  저장소 전역)로 추적 중이다.

**한국어 리뷰 반영 — 추가 커밋**: 게이트 PASS 후 한국어 리뷰가 `stravaConnectPrompt`의
"달린 기록"이 러닝만 가리켜 라이딩·트레일러닝 사용자를 배제하는 사실 오류임을 지적해
"활동 기록"으로 수정했다(스타일이 아니라 정확성 문제라 즉시 반영). 그 외 지적(§4.1
CTA·§1.3 용어표 등재 등)은 정책상 기록만 남긴다.
