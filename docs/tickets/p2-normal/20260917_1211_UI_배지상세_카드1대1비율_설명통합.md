# [UI] 배지 상세 페이지 카드 1:1 비율 확장 및 설명 통합

## 배경 / 문제 정의
현재 배지 상세 페이지(`BadgeHeroSection.tsx`)는 배지 이미지·이름이 노출되는 영역만
`aspect-square`로 1:1 비율을 유지하고, 배지 설명(description)은 그 카드 밖에 별도
문단(`<p>`)으로 렌더링된다. 설명 줄바꿈도 원본 문자열에 포함된 `\n`에만 반응하는
`whitespace-pre-line` 방식이라, 실제 배지 설명 문구(마침표로 문장이 끝나는 형태)에서는
줄바꿈이 거의 일어나지 않는다.

사용자(디자이너) 요청: 이미지+이름 카드와 설명을 하나의 카드로 통합하고, 그 통합 카드
전체가 1:1 비율을 유지하도록 레이아웃을 재구성한다. 문장 가독성을 위해 마침표 기준
자동 줄바꿈도 추가한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `aspect-square`(1:1 비율)를 현재의 이미지 서브블록이 아니라, 이미지+등급칩+이름+설명을
  전부 포함하는 바깥 카드 컨테이너로 이동한다.
- 이미지 크기(200×200)는 우선적으로 유지한다. 통합 카드 안에서 공간이 부족하면 이미지
  크기를 줄이지 말고, 이미지/이름/등급칩/설명 사이의 간격(margin, gap)부터 줄여서 1:1
  비율 안에 내용이 들어가도록 한다.
- 설명(`badge.description`)은 마침표(`.`) 위치에서 자동 줄바꿈되도록 처리한다. 소수점
  표기(예: "3.5") 등 문장 종결이 아닌 마침표가 실제 배지 설명 컨텐츠에 존재하는지
  `Service Plan/Specs/Content/`의 배지 설명 문구를 확인해 오탐 여부를 판단하고, 있다면
  단순 `split('.')` 대신 안전한 처리 방식을 택한다.
- 대상 파일: `jam-web/src/app/(main)/badges/[id]/BadgeHeroSection.tsx`

### UI/UX 관점 (해당 시)
- 통합 카드는 배경·radius·padding을 공유하는 하나의 시각적 블록으로 보여야 한다.
- 설명 텍스트가 짧은 배지와 긴 배지 모두 1:1 카드 안에서 자연스럽게 보여야 한다 (넘치거나
  과도한 여백이 남지 않도록).

## 구현 계획
1. `BadgeHeroSection.tsx`의 카드 래퍼 구조를 재구성: 이미지 서브블록의 `aspect-square`를
   제거하고, 이미지+등급칩+이름+설명을 감싸는 최상위 카드 div에 `aspect-square`(또는
   동등한 1:1 비율 제약)를 적용한다.
2. 카드 내부 요소 간 간격(margin-top 등)을 검토해, 필요 시 축소해도 되는 값으로 조정한다
   (이미지 크기 축소는 최후 수단으로도 사용하지 않는다).
3. 설명 렌더링 로직을 마침표 기준 문장 분리 방식으로 변경한다 (예: 문장 배열로 나눠
   블록 요소 또는 `<br/>`로 표시).
4. 실제 배지 설명 컨텐츠 샘플을 확인해 소수점 등 예외 케이스 유무를 점검한다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `aspect-square`를 이미지 서브블록이 아니라 이미지+등급칩/레벨칩+이름+설명을 모두 포함하는
  바깥 카드로 이동해, 카드 전체가 1:1 비율을 유지하도록 재구성
- 이미지 200×200 크기는 유지(`flex-shrink-0`)하고, 요소 간 간격(`gap-2→gap-1`,
  `pt-4→pt-2`)을 줄여 1:1 비율 안에 설명까지 들어가도록 조정
- 카드 밖에 있던 배지 설명을 카드 안(`flex-1 min-h-0 overflow-hidden`)으로 이동
- 마침표 자동 줄바꿈 로직(`splitDescriptionSentences`) 추가 — 정규식
  `(?<!\d)\.(?!\d)`로 숫자 사이 소수점(예: "42.195")을 제외하고 문장 종결 마침표만 분리
- 실제 배지 설명 컨텐츠(`seed_v5_activity_badges.rows.json`)에서 소수점 포함 사례를
  확인해 오탐 방지 로직에 반영
