# [Feature] 드랍 POI 카드 — 보유 아이템 많을 때 화면 넘침 수정

## 배경 / 문제 정의

`/drops`에서 POI를 탭하고 "드랍하기"를 누르면 열리는 카드(`PoiCarouselModal.tsx`의
`PoiCard`)가 보유 아이템 개수만큼 세로로 계속 자라도록 설계돼 있었다(의도된 동작으로
주석에 명시돼 있었음). 아이템이 많은 유저(스크린샷 기준 8개 이상)는 카드가 화면 위
(로고·TopNav 영역)까지 밀고 올라가 상단 콘텐츠가 가려지는 문제가 발생했다.

## 상세 요구사항

### 서비스/코드베이스 관점

`PoiCarouselModal.tsx`의 두 목록(드랍용 아이템 선택 목록, 픽업 가능 목록)에 각각
`max-h-[50vh] overflow-y-auto`를 추가해 카드 자체의 무한 성장을 막고 목록 내부만
스크롤되게 한다.
