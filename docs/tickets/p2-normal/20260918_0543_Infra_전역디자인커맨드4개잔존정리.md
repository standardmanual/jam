# [Infra] 전역 `~/.claude/commands/`에 남은 디자인 커맨드 4개 정리

## 배경 / 문제 정의
티켓 `20260918_0422`(에이전트 팀 도입 ③) 게이트 리뷰가 발견한 범위 밖 항목이다.

프로젝트 `.claude/commands/`의 디자인 커맨드 4개(`ui-audit`·`design-system-review`·
`accessibility-check`·`refactor-ui`)는 티켓 `20260918_0422`에서 삭제했다(채원 모드로 흡수).
그런데 `~/.claude/commands/{ui-audit,design-system-review,accessibility-check,refactor-ui}.md`가
전역(모든 프로젝트 공용, git 미추적)에 그대로 남아 있다. 저장소 밖이라 워크트리 격리 에이전트가
손대지 못했다.

"삭제한 커맨드를 참조하는 곳이 없다"는 완료 조건은 저장소 범위에서는 충족됐지만, 전역 사본이
남아 있으면 다른 프로젝트나 세션에서 여전히 호출될 수 있다.

## 상세 요구사항
- `~/.claude/commands/ui-audit.md`, `design-system-review.md`, `accessibility-check.md`,
  `refactor-ui.md` 4개 파일의 삭제 여부를 판단한다
- **주의**: 이 파일들은 다른 프로젝트에서도 쓰일 수 있다. 삭제 전에 다른 프로젝트가 이 커맨드에
  의존하는지 확인하고, 애매하면 사용자에게 확인한다

## 완료 조건
- 4개 파일의 삭제 또는 존치 여부가 결정되고, 결정과 근거가 완료 기록에 남는다

## 완료 기록

### 구현 내용 요약
4개 파일 내용을 확인한 결과 JAM 전용 내용이 전혀 없는 범용 UI 감사 도구(WCAG 체크리스트,
React 컴포넌트 일반 감사 절차 등)임을 확인했다. 홈 디렉토리에 다른 프로젝트(피치스 필라테스
디자인 등) 흔적이 있어 다른 프로젝트가 계속 쓸 가능성을 사용자에게 확인했고, **삭제**하기로
결정했다.

### 변경된 파일
```
~/.claude/commands/ui-audit.md (삭제, 저장소 밖)
~/.claude/commands/design-system-review.md (삭제, 저장소 밖)
~/.claude/commands/accessibility-check.md (삭제, 저장소 밖)
~/.claude/commands/refactor-ui.md (삭제, 저장소 밖)
```

### 주요 의사결정 / 핵심 메모
사용자 결정(2026-09-18): 삭제. JAM! 저장소 안에서는 이미 채원(jam-designer) 모드가 이
역할을 대체하므로 충돌 없음. 다른 프로젝트에서 필요해지면 다시 만들 수 있다.
