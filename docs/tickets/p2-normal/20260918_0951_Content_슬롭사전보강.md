# [Content] 슬롭 사전 보강 — 금칙 단어·금지 문장·안티 슬롭 구조 원칙

## 배경 / 문제 정의
티켓 20260918_0423이 만든 `Service Plan/Specs/SLOP_DICTIONARY.md`는 초기 목록(10개 항목,
단어 차원 위주)만 갖춘 상태였다. 사용자가 AI 슬롭의 대표 금칙어·금지 문장·구조 원칙을
정리한 자료를 제공해 이를 기존 사전에 통합·보강한다.

## 상세 요구사항
- 기존 "금칙 표현 → 대체 표현" 단일 표를 성격별로 분리: 관습적 비유 / 과장된 수식어 /
  번역투 표현 / 의미 없는 수식·반복
- 새 섹션 "금지 문장" 추가 — 서론·범용성 강조·주의 환기·마무리 4개 유형, 문장 전체
  패턴을 금지 대상으로 함
- 새 섹션 "안티 슬롭 구조 원칙" 추가 — 서론 없는 본론 진입, 묘사 대신 팩트, 행동 중계 금지.
  단어·문장 필터링으로 잡히지 않는 글 구조 차원 지침이라 기계 검사 대상이 아님을 명시

## 완료 기록

### 구현 내용 요약
`Service Plan/Specs/SLOP_DICTIONARY.md`를 3개 섹션(금칙 단어·금지 문장·안티 슬롭 구조
원칙)으로 재구성하고 사용자 제공 자료를 기존 항목과 병합했다(중복 제거, 표 형식 유지).

### 변경된 파일
```
Service Plan/Specs/SLOP_DICTIONARY.md
```

### 잔여 이슈
- `scripts/verify.sh`의 슬롭 검사는 여전히 플레이스홀더(`true`, 항상 통과)다. 사전 내용이
  갖춰졌으니 실제 검사로 전환 가능한 상태이나, 검사 대상 범위(어떤 파일·어떤 텍스트)와
  트라이브 목소리 예외(사람 판단 필요)를 사람이 어떻게 분리할지 별도 설계가 필요해
  이번 티켓 범위에서는 다루지 않았다.
