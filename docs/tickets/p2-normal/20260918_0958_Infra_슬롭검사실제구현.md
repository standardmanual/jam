# [Infra] `verify.sh` 슬롭 검사를 플레이스홀더에서 실제 검사로 전환

## 배경 / 문제 정의
티켓 20260918_0421이 만든 `scripts/verify.sh`의 슬롭 검사는 "사전이 아직 없다"는 이유로
`true`(항상 통과)인 플레이스홀더였다. 티켓 20260918_0951에서 `SLOP_DICTIONARY.md`를
보강했으니 이제 실제 검사로 전환할 수 있다.

## 상세 요구사항
- 검사 대상: `jam-web/**`, `Service Plan/**`(단 `docs/tickets/**`는 제외 — 사용자
  결정, 2026-09-18)
- 검사 방식: 전체 파일이 아니라 `origin/staging` 대비 diff의 **추가된 라인만** 검사한다
  (이미 승인된 기존 텍스트까지 매번 걸리면 게이트가 무의미해진다)
- `SLOP_DICTIONARY.md`의 "금칙 단어" 표(1절)와 "금지 문장" 표(2절)를 파싱해 패턴을
  자동 추출한다 — 사전에 새 행을 추가하면 스크립트 수정 없이 검사 대상이 늘어난다
- "안티 슬롭 구조 원칙"(3절)과 "이모지 남발"은 문자열 매칭으로 판단할 수 없어 이 스크립트의
  대상이 아니다(한국어 리뷰·사람 검토가 담당)

## 완료 기록

### 구현 내용 요약
- `scripts/check-slop.mjs` 신규 작성 — `SLOP_DICTIONARY.md`의 표에서 따옴표로 감싼 패턴을
  추출하고, `git diff origin/staging...HEAD`의 추가 라인(jam-web·Service Plan, Tickets 제외)에서
  매칭 여부를 검사
- `scripts/verify.sh`의 슬롭 검사 단계를 `true` 플레이스홀더에서 이 스크립트 호출로 교체

### 변경된 파일
```
scripts/check-slop.mjs (신규)
scripts/verify.sh (수정)
```

### 테스트 결과
- [x] `node --check scripts/check-slop.mjs` 문법 통과
- [x] 슬롭 표현("혁신적인 여정을 통해 다양한") 포함한 임시 커밋 → 3건 검출, exit 1 확인
  (테스트 후 커밋 되돌림)
- [x] 같은 슬롭 표현을 `docs/tickets/` 안에 넣은 임시 커밋 → 제외 확인, exit 0
  (테스트 후 커밋 되돌림)
- [x] `bash scripts/verify.sh` 전체 재실행 → `lint · typecheck · test · ds:check · slop` 통과

### 잔여 이슈
- "이모지 남발"(개수 임계값 판단)과 안티 슬롭 구조 원칙(서론 없는 본론 진입 등)은 여전히
  사람 검토 영역이다.
- diff에 공백이 있는 경로가 있으면 git diff가 파일명 끝에 탭을 붙이는데, 이를 정확히
  처리하도록(trimEnd) 구현했다 — Service Plan처럼 공백 포함 경로에서 실제로 확인함.
