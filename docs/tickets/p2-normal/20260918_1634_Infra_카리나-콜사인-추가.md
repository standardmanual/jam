# [Infra] 카리나(오케스트레이터)에 콜사인 추가

> 관련 티켓: `20260918_1617_Infra_콜사인-이름-통일-카즈하-워크플로개선점발견-역할추가.md`

## 핵심 요약
- 요구사항: 서브에이전트 8인은 전부 `**Call sign: <이름>**` 표기가 있는데, 정식 에이전트 파일이
  없는 카리나(오케스트레이터)만 콜사인이 없었다. 같은 표기를 추가한다.
- 구현 계획: `docs/agents/orchestrator.md`의 "0. 카리나 카드"(세션 시작 hook이 그대로 출력하는
  절) 제목 바로 아래에 `**Call sign: 카리나** — "즉흥 대신 틀로 일한다."` 한 줄 추가.
- 관련 파일: `docs/agents/orchestrator.md:13` 근처

## 배경 / 문제 정의
사용자가 "콜사인이 없는 에이전트도 콜사인을 이름으로 생성해"라고 요청. 8개 서브에이전트 정의
파일은 이미 콜사인=이름으로 통일돼 있었으나(티켓 20260918_1617), 카리나는 별도 에이전트 정의
파일이 없어(오케스트레이터=메인 세션 자체) 콜사인 표기가 빠져 있었다.

## 완료 조건
- `node scripts/ticket-dashboard.mjs` 출력의 "카리나 — 오케스트레이터 카드" 절 바로 아래에
  `Call sign: 카리나` 줄이 나타난다.
