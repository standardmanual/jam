# [Infra] 실행 지표 원장 — 티켓 완료 기록의 고정 표를 집계해 주간 브리핑 「워크플로 수치」와 루프 장부를 채운다

## 핵심 요약

- 요구사항: 워크플로 실행의 토큰·소요·에이전트 수·재작업 여부가 사람 손으로 티켓 문장에만 남고 집계되지 않는다(W39 리포트가 "분석하지 않았다"고 명시). 티켓 완료 기록에 **고정 표**를 두고, 스크립트가 CLOSED 티켓을 훑어 주간 집계를 내며, 카즈하 주간 브리핑의 「워크플로 수치」 절이 그 출력을 쓰게 한다. 루프 장부(올린 건수·머지·반려·사유·토큰)의 칸도 같은 표에 둔다.
- 구현 계획: `docs/tickets/_TEMPLATE.md` 완료 기록에 표 양식 추가, `scripts/ticket-metrics.mjs`(집계기, 기간 인자, 표 없는 티켓은 "미기록"으로 셈) + 테스트, `forms/weekly-briefing-format.md`·`scheduled-jobs.md` 주간 프롬프트에 집계 명령 반영, `jam-ops.md`에 "표를 읽는다" 절, `/jam-work` SKILL.md 4단계 3번(완료 기록에 표 작성)을 표 기준으로 갱신.
- 관련 파일: `docs/tickets/_TEMPLATE.md`, `scripts/ticket-metrics.mjs`(신규)·`scripts/ticket-metrics.test.mjs`(신규), `.claude/skills/jam-work/references/forms/weekly-briefing-format.md`, `.claude/skills/jam-work/references/scheduled-jobs.md`(주간 절), `.claude/agents/jam-ops.md`, `.claude/skills/jam-work/SKILL.md`(4단계), `docs/specs/DOCUMENT_SCHEMA.md`(티켓 완료 기록 절이 있으면)
- 상위 티켓: 20260921_2207(#3). 루프 장부는 20260921_2234 §5의 2단계. 경로: ③ 표준(infra)

## 배경 / 문제 정의

운영 점검(20260921_2207 §2.5)에서 토큰 수치는 티켓 자유 문장에만 있고, 워크플로 journal에는 토큰 필드가 없으며, 다른 PC의 실행 기록은 이 PC에서 볼 수 없다. 티켓은 git에 있어 PC를 가로지르는 유일한 원천이다. 오늘 티켓 20260921_0841 완료 기록에 쓴 표(실행 / 에이전트 / 전체 토큰 / 출력 토큰 / 소요 / 도구 호출)를 표준으로 삼는다.

## 상세 요구사항

### 서비스/코드베이스 관점

- 표 양식(고정 헤더): `| 실행 | 에이전트 수 | 전체 토큰 | 출력 토큰(아현 / 게이트) | 소요 | 도구 호출 |`, 마지막 행 `| 합계 | ... |`. 값의 출처는 Workflow 완료 알림 `<usage>`(전체 토큰·소요·에이전트 수·도구 호출)와 결과의 `tokenUsage`(출력 토큰).
- 재작업 행: 재작업이 있으면 실행 행이 둘 이상이 되고, 「주요 의사결정」에 사유가 있어야 한다. 집계기는 실행 행이 2개 이상인 티켓을 "재작업"으로 센다.
- 집계기 출력(기간 인자 `--since 2026-09-15`): 티켓 수 · 표 있는 티켓 수 · 전체 토큰 합계·중앙값 · 소요 합계·중앙값 · 재작업 티켓 수 · 우회 플래그(`JAM_SKIP_`) 언급 티켓 수 · 루프 장부(작성자가 루틴인 브랜치의 머지·반려 수는 2단계 도입 전까지 0). 마크다운 표로 출력해 브리핑에 붙일 수 있게 한다.
- 표 없는 옛 티켓은 파싱하지 않고 "미기록"으로만 센다(정규식으로 문장을 긁지 않는다).
- 고정 헤더는 이미 쓰이고 있는 20260921_0841 표(`| 실행 | 에이전트 | 전체 토큰 | 출력 토큰(아현 / 게이트) | 소요 | 도구 호출 |`, 열 이름 「에이전트」)와 글자 단위로 일치시킨다 — 완료 조건이 0841 집계를 요구하기 때문이다. 위 요구사항의 「에이전트 수」 표기는 이 줄로 대체한다(2026-09-22 카리나 사전 확인).
- `docs/specs/DOCUMENT_SCHEMA.md`에는 티켓 완료 기록 절이 없다(2026-09-22 확인) — 이 파일은 고치지 않는다.
