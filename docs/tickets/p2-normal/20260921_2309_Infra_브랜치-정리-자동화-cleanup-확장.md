# [Infra] 브랜치 정리 자동화 — `workspace-setup.sh cleanup`이 워크트리와 함께 브랜치도 지운다

## 핵심 요약

- 요구사항: 세션 시작마다 도는 `workspace-setup.sh cleanup`이 병합된 워크트리만 지우고 브랜치는 남긴다. 연결 워크트리가 없는 `worktree-wf_*` 로컬 브랜치와 `origin/staging`에 병합된 로컬 `claude/jamwork-*` 브랜치를 함께 지우고, 원격 리뷰 브랜치는 `cleanup --remote`로 목록을 보여 준 뒤 `--yes`일 때만 지운다(카리나가 사용자 승인 후 실행).
- 구현 계획: `scripts/workspace-setup.sh`의 `cleanup_worktrees`에 브랜치 정리 단계 추가, `--remote [--yes]` 하위 옵션, 테스트 `scripts/workspace-setup.test.mjs`(임시 저장소·링크드 워크트리로 4상황), `gen-team-doc.mjs` 설명 표 문구 갱신, `team-operations.md` §9 ② 「남은 위험」 갱신.
- 관련 파일: `scripts/workspace-setup.sh`, `scripts/gen-team-doc.mjs`(`explain` 표), `docs/agents/team-operations.md` §4·§9, `docs/agents/contract.json`(`paths_exist`에 테스트 추가 시)
- 상위 티켓: 20260921_2207(#5). 루프 검토(20260921_2234) 도입 순서 0단계. 경로: ③ 표준(infra)

## 배경 / 문제 정의

운영 점검(20260921_2207 §2.2)에서 연결 워크트리가 없는 `worktree-wf_*` 로컬 브랜치 4개, 병합된 로컬 `claude/jamwork-*` 2개, 병합된 원격 리뷰 브랜치 14개가 남아 있었고, 2026-09-21에 손으로 지웠다. 하네스는 격리 워크트리를 만들 때 `worktree-wf_*` 브랜치를 만들고 아현이 그 위에서 `claude/jamwork-*`로 갈아타므로, 워크플로가 돌 때마다 두 종류의 브랜치가 남는다. 루프가 매일 브랜치를 만들면 쌓이는 속도가 빨라진다. `team-operations.md` §9 ②가 이 위험을 "가끔 확인한다"로 남겨 두었다.

## 상세 요구사항

### 서비스/코드베이스 관점

- 로컬 정리(세션 시작 자동): ① `git worktree list --porcelain`에 연결되지 않은 `worktree-wf_*` 브랜치 삭제(`-D`, 하네스가 main에서 만든 빈 브랜치) ② `origin/staging`에 병합된(`git merge-base --is-ancestor`) 로컬 `claude/jamwork-*` 삭제(`-d`) ③ 미병합·연결된 브랜치는 보존하고 이유를 출력. 세션 훅 출력은 지금처럼 "제거" 줄만 남긴다.
- 원격 정리(수동): `cleanup --remote`는 병합된 원격 `claude/jamwork-*`·`claude/docs-*` 목록만 출력하고 종료 코드 0. `cleanup --remote --yes`는 삭제를 실행한다. 세션 훅에서는 부르지 않는다. `git fetch --prune`을 먼저 한다.
- 테스트: 임시 저장소에 링크드 워크트리와 브랜치 4종(연결된 worktree-wf / 연결 안 된 worktree-wf / 병합된 jamwork / 미병합 jamwork)을 만들어 보존·삭제가 맞는지 확인한다. 가드레일 패턴 15(`GIT_*` 제거)를 지킨다.

## 구현 계획

1. 스크립트에 함수를 추가하고 기존 출력 형식을 유지한다.
2. 테스트 작성, `verify.sh` `scripts-test`에 포함.
3. 생성기 설명 표와 `team-operations.md` §9 ② 갱신(생성 구간은 생성기로).

## 완료 조건

- 임시 저장소 테스트에서 연결 안 된 `worktree-wf_*`와 병합된 `claude/jamwork-*`만 지워지고 나머지 둘은 보존된다.
- `cleanup --remote`가 목록만 출력하고 아무것도 지우지 않으며, `--yes`가 있을 때만 지운다(임시 원격 저장소로 확인).
- 세션 시작 훅 출력 형식이 기존과 같다(`grep -E "^제거"`).
- `team-operations.md` §9 ②의 「남은 위험」이 갱신되어 있고 `gen-team-doc --check` 통과.
