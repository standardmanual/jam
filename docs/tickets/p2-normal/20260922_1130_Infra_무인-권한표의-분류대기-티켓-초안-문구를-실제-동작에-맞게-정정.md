# [Infra] 무인 권한표의 "분류 대기 티켓 초안" 문구를 실제 동작(리포트 안에만 적는다)에 맞게 정정한다 — 새 경로 제한 훅과의 충돌 예방

## 핵심 요약

- 요구사항: 무인 카리나 권한표(§4-3)의 "명확한 문제는 분류 대기 티켓 초안" 문구가 `scheduled-jobs.md`·`jam-ops.md`·`team-operations.md` §6·`orchestrator.md`·`docs/agents/workflow/01_공통규칙.md` 다섯 곳에 같은 문장으로 복제돼 있다. 실제 동작은 티켓 20260918_1156에서 "파일을 만들지 않고 리포트 안에 `[분류 대기 초안]`으로만 적는다"로 좁혀졌는데, 문구는 그 사실을 담지 않는다. 티켓 20260921_2306이 도입한 pre-commit 경로 제한(루틴 작성자는 `jam-doc/operations/reports/` 밖 변경 불가, 우회 변수 없음) 아래에서 문구를 문자 그대로 구현하면 예약 루틴 커밋이 조용히 차단된다. 문구를 실제 동작으로 고치고, 다섯 사본을 단일 원천 + 참조로 줄인다.
- 구현 계획: (1) 단일 원천을 `scheduled-jobs.md` §4-3로 정하고 문구를 "명확한 문제는 리포트 본문에 `[분류 대기 초안]`으로 적는다(티켓 파일은 만들지 않는다 — 경로 제한 훅)"로 바꾼다. (2) 나머지 네 곳은 참조 문장으로 바꾸거나, 생성 구간이면 `gen-team-doc.mjs` 근거 설정을 고친 뒤 재생성한다. (3) `contract.json`에 "이 문구가 한 곳에만 있다" 검사 줄을 추가할 수 있으면 추가한다.
- 관련 파일: 위 다섯 문서, `scripts/gen-team-doc.mjs`, `docs/agents/contract.json`
- 상위 티켓: 20260921_2306(민지 게이트의 범위 밖 발견물). 경로: ③ 표준(infra) 또는 `docs` 유형(코드 무변경이면 카리나 직접)

## 배경 / 문제 정의

CLAUDE.md 규칙 5의 전형("중복은 드리프트의 필요조건"). 좁혀진 동작이 티켓 1156에만 있고 권한표 사본 다섯 곳은 옛 문구라, 다음에 루틴 프롬프트를 쓰는 사람이 옛 문구를 근거로 티켓 파일 생성을 구현할 수 있다. 민지 발견물 [3]도 함께 참고: 2026-09-19~20 부트스트래핑 시기에는 `noreply@anthropic.com` 신원으로 광범위한 파일을 커밋한 이력이 있어(예: 890aeac9), 클라우드 세션이 git config 설정을 건너뛰는 경로가 생기면 같은 훅에 막힌다 — 이건 티켓 20260921_0901의 확인 항목으로 넘긴다.
