# [Feature] 홈피드·배지·미션 운영 자동화 파이프라인 1단계 (상위 티켓)

> `/jam-plan` 2단계 기획서를 사용자가 2026-09-23에 승인해 만든 상위 티켓이다. 동작 정의·유형 카탈로그·양식의
> 정본은 [PRD](../../specs/prd/content-automation/PRD.md)(draft)에 있고, 이 티켓은 기획 경위·결정 기록·리스크·
> 하위 티켓 표를 담는다. 기획 담당 혜린, 마케팅 윤진, 세계관 검수 윈터, 사실 확인 카즈하.

## 핵심 요약

- 요구사항: 정식 오픈 후 홈피드 컨텐츠·배지 추천·미션 생성·추천을 자동화한다. 한국 트렌드·이슈 기반, 유저군
  세그먼트 개인화, 반응 학습(전략 변경안을 사람에게 제안), 브랜드 언어 학습. 트라이브 10·컬렉션 100·아이템배지 900의
  설명 컨텐츠를 전부 활용하되 비활성 컨텐츠는 추천·소개하지 않는다(글·세계관 노출은 허용). 리포트가 생성되면
  슬랙으로 안내한다.
- 구현 계획: 6층(입력·세그먼트·생성·제안승인·전략변경안·유형리뷰)을 하위 티켓 10개로 나눠 입력·세그먼트 층부터
  세로 조각 단위로 만든다. 제안 결과물은 리포트 문서에서 시작한다.
- 관련 파일: `docs/specs/prd/content-automation/PRD.md`, `jam-web/src/lib/today/exposure.ts`,
  `.claude/skills/jam-work/references/scheduled-jobs.md`, `.claude/agents/jam-marketer.md`

## 배경 / 문제 정의

정식 오픈 후 홈피드·배지·미션 운영을 매번 수작업으로 기획해야 하고, 트라이브·날씨·시즌·사회 이슈를 조합한
컨텐츠 제안 체계가 없으며, 어떤 컨텐츠 유형이 실제로 반응이 있는지 구조적으로 알 방법이 없다. 사용자는 현재 유저
수치를 판단 근거에서 제외하고 "그런 기능이 있는 서비스"를 만들기를 원한다.

## 기획서 (혜린, 2026-09-23 승인)

- **대상**: 운영자(혜린·윤진·카즈하의 편성 부담) + 최종 유저(세그먼트별 관련성 높은 카드·미션·배지 제안)
- **성공 기준(측정 가능)**
  1. 매주 월요일, 요일별로 다른 7일 편성 후보안이 주간 리포트에 자동으로 올라온다
  2. 신규 세그먼트 태그 3종 이상이 실제 조건 충족 유저에게 다른 카드를 노출한다
  3. 전략 변경안이 근거 신호(최소 3주 연속 패턴)와 함께 사람 승인 대기로 올라온 사례가 1건 이상 생긴다
  4. 17종 유형별 노출·열람·후속 행동 지표가 2주·1개월 주기로 집계되어 유지·수정·보완·제거 판단 초안이 나온다
- **범위**: PRD §3~§12 전부
- **하지 않을 것**: PRD §13
- **가정(확인됨)**: 정식 오픈 후 운영 전제 · 세그먼트 단위 개인화 · 전략 학습은 시스템 제안 + 사람 승인 · 리포트
  문서로 시작 · 정치·재난·사건사고·혐오 자동 제외 · 입력·세그먼트 층부터 착수 · `strava_connections.last_synced_at`
  존재 · 컬렉션 잔여 계산 함수와 유저 최근 위치 컬럼 존재 · `badges.description` 존재, 배지 활성 판정은 배지
  엔진 발급 후보 필터와 동일 · 예약 작업 토큰 여유 약 30%(주간 2회 평균 105,170 / 상한 15만)
- **가정(미확인)**: 투데이 카드 단위 노출·클릭 계측 존재 여부(GA4는 켜져 있으나 카드 단위 이벤트는 코드에서 확인
  못 함. 티켓 20260923_2259에서 현황 점검 후 도입) · 세그먼트 임계값 수치(시범 운영으로 조정)
- **열린 질문(나중에 정해도 됨)**: 어드민 승인 화면 전환 시점(리포트 방식 4주 안정 운영 후) · 세그먼트 임계값
- **검토한 대안**: 완전 자동 게시(기각, 승인 경로 없이 브랜드 리스크) · 어드민 화면부터 구축(기각, 검증 전 UI 투자)
  · 유저 1인 단위 추천(보류) · 유형 리뷰 2주 단일 주기(비채택, 이원안 채택)
- **판단**: 만들자.

## 리스크 (JAM 전용 점검)

- 경제 균형: 미검증. 배지·미션 보상 수치는 자동화 대상에서 제외해 차단.
- 세계관 충돌: 윈터 검수 완료(2026-09-23). 중단 사안 없음. 주의(높음) 1건: 미스터리 헌터를 일상 화자로 쓰지 말 것.
  주의(보통) 1건: "지역 트라이브" 개념은 설정에 없으므로 T13·T16은 POI 유형 기반. T17은 매핑표 등재 전 사람 전용.
  원문 훼손 금지.
- 유저가 학습한 규칙 변경: 미션 `gate_axis` 스키마·`exposure_tags` 매칭 규칙은 자동 생성도 동일 스키마 준수.
- 운영 부담: 입력층·계측층이 예약 작업 데이터 출처 표·토큰 상한에 추가됨. 실측 전 상한 재산정 금지. 오픈 초기
  표본 미달 시 학습 기반 제안을 내지 않고 규칙 기반으로만 제안.
- 개인정보·외부 의존: 기상청·특일정보·TourAPI·유튜브·빅카인즈·LLM API 신규 의존. 위치 기반 독려는 좌표
  미노출·매칭 외 미보관. 계측 이벤트는 집계만(결정 4-6).
- 비용: 코퍼스 전량을 프롬프트에 넣으면 토큰이 유형×카드 수만큼 곱해진다. 유형별 선별 발췌 상한을 지시문에 명시.
- 사고 방지: 비활성 컨텐츠가 추천 대상에 오르는 것을 승인 전 기계 검사(활성 재조회)로 자동 반려.
