# [Service] 컨텐츠 코퍼스 접근 계층 — 유형별 선별 발췌와 활성 판정

## 핵심 요약

- 요구사항: 생성 층이 트라이브 10·컬렉션 100·아이템배지 900의 설명 코퍼스를 통째로 받지 않고, 유형 ID별로 필요한
  발췌(각 1~3건)만 받는다. 비활성 컨텐츠는 추천 대상에서 자동 제외되고, 승인 전 기계 검사가 대상의 활성 여부를
  재조회해 어긋나면 반려한다. PRD §4.
- 구현 계획: `jam-web/src/lib/content-corpus/`에 `selectCorpusForType(typeId, ctx)`와 `verifyActiveTargets(draft)`를
  만들고, 예약 세션이 읽을 수 있도록 어드민 읽기 API로 노출한다(어드민 자동화 읽기 토큰, 티켓 20260918_1149 경로).
- 관련 파일: `jam-web/src/lib/content-corpus/`(신규), `jam-web/src/app/api/admin/`(읽기 라우트 신규),
  `jam-web/src/lib/badge-engine/index.ts`(활성 필터 조건 참조: `deleted_at IS NULL`, `valid_from`·`valid_until`),
  DB `tribes.description/tagline/is_active`, `item_books.story_text/is_active`, `badges.description`. 스펙: PRD §4.

## 배경 / 문제 정의

사용자 결정: 설명 컨텐츠를 전부 활용하되 비활성 컨텐츠는 추천·소개하지 않고 글·세계관 노출만 허용한다. 900건을
매 호출에 넣으면 토큰이 유형×카드 수만큼 곱해지고, 비활성 컨텐츠가 추천 대상에 오르는 사고를 사람 검토만으로 막기
어렵다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 활성 판정: 트라이브 `is_active`, 컬렉션 `is_active`, 배지는 `deleted_at IS NULL` 이고 유효 기간 안(배지 엔진 발급
  후보 필터와 같은 조건).
- 유형 → 코퍼스 매핑: T01·T04 → 트라이브 설명 + 해당 컬렉션 서사 / T02·T07·T10 → 배지 설명 1건 / T06 → 믹스 대상
  배지 설명 각 1건 / T09·T11·T17 서사 부분 → 트라이브 설명. 발췌 건수 상한을 인자로 둔다.
- 대상 선택(활성만)과 본문 인용(비활성 가능)을 결과 구조에서 분리해 돌려준다.
- 원문은 그대로 돌려준다. 요약·재작성하지 않는다.
- `verifyActiveTargets`: 후보안의 대상 ID 목록을 재조회해 비활성이 섞이면 반려 사유를 돌려준다.

## 구현 계획 (파일 단위, 계획 반환 면제 근거)

| 파일 | 할 일 |
|---|---|

읽기 토큰 인증 경로를 대조함).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 유형 ID를 주면 그 유형에 필요한 코퍼스만 상한 건수 안에서 반환하고, 전체 코퍼스를 읽는 경로가 없다(테스트로 확인).
- 비활성 트라이브·컬렉션·배지(유효 기간 밖 포함)는 추천 대상 목록에서 빠지고, 본문 인용 목록에는 규칙대로 포함될 수
  있다.
- 비활성 대상이 섞인 후보안을 `verifyActiveTargets`에 넣으면 반려와 사유가 반환된다.
- 어드민 읽기 API가 어드민 자동화 읽기 토큰으로만 접근된다.

크기 상한: 5파일/100줄.

## 완료 기록 (2026-09-23)

### 구현 내용 요약
유형 ID(T01~T17)별 선별 발췌 계층 신설. `selectCorpusForType(typeId, ctx, limit)`은 매핑표에 따라 추천·소개형(T02·T06·T07·T10)은 활성
배지만 대상·인용에 담고, 글·세계관 노출형(T01·T04·T09·T11·T17)은 대상을 비운 채 인용만 채우며 비활성 트라이브·컬렉션 원문도 인용 가능.
매핑에 없는 유형은 DB 미조회. `verifyActiveTargets(draft)`는 대상 재조회로 비활성이 섞이면 반려. 어드민 읽기 API
`GET /api/admin/content-corpus`는 `requireAdminRead`로만 인증. 원문은 요약 없이 그대로 반환.
