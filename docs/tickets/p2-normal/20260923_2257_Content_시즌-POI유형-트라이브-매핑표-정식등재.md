# [Content] 시즌·소재·POI 유형 × 트라이브 매핑표 정식 등재 (윈터 모드 ①)

## 핵심 요약

- 요구사항: 자동 생성이 시즌·날씨·기념일·지역 행사·POI 유형 소재를 트라이브에 연결할 때 쓸 매핑표를 세계관 정본에
  정식 등재한다. 등재 전까지 T04·T17은 즉석 배정을 하지 않고, T17은 사람 전용이다. PRD §12.
- 구현 계획: 윈터 모드 ①(설정 관리, Opus)이 2026-09-23 검수 초안을 정식 표로 확장해 제안 → 사용자 승인 → 카리나가
  `TRIBES.md`(또는 컨텐츠 문서)에 반영. 인접 그래프는 건드리지 않는다.
- 관련 파일: `jam-doc/planning/content/TRIBES.md`, `jam-doc/planning/content/POI.md`(POI 유형 목록), 상위 티켓
  20260923_2252 「윈터 검수 요지와 매핑 규칙 초안」. 스펙: PRD §12.

## 배경 / 문제 정의

윈터 검수에서 "지역 트라이브" 개념이 설정에 없고, 시즌·소재를 트라이브에 연결하는 표가 없어 자동화가 즉석 배정을
하면 임의 배정이 된다고 지적했다(주의·보통). 미스터리 헌터를 일상 화자로 쓰는 것은 정체성과 충돌한다(주의·높음).

## 상세 요구사항

### 컨텐츠 관점
- 표 1: 소재 범주(계절·날씨 구분·전통 기념일·지역 축제·공공 캠페인·활동 씬 유행·수집 문화 등) → 어울리는 트라이브
  1~3개 → 안 어울리는 트라이브 → 이유.
- 표 2: POI 유형(`naver_category` 대분류) → 어울리는 트라이브.
- 어떤 트라이브에도 붙이지 않는 소재 목록(PRD §7.3 마지막 행)과 미스터리 헌터 노출 상한 원칙을 함께 적는다.
- 시즌 캘린더(연간 시즌 구분과 전환 시점)의 초안도 같은 절에 둔다. DB 저장은 후속 판단.
- 인접 그래프·드랍 확률은 변경하지 않는다. 변경이 필요해 보이면 별도 엔진 티켓으로 넘긴다.

### 소재·시간대·POI 유형 × 트라이브 매핑

홈피드·미션 컨텐츠가 계절·날씨·기념일·지역 행사·장소를 어느 트라이브의 목소리로 말할지 정하는 표다. 자동 생성은 이 표에 적힌 배정만 쓰고, 표에 없는 조합을 즉석에서 만들지 않는다.

- 표에서 트라이브를 함께 적었다고 해서 두 트라이브가 인접한다는 뜻은 아니다.
- "공통"은 특정 트라이브 없이 JAM! 목소리로 말한다는 뜻이다. "지역 트라이브"라는 개념은 없다.
- 미스터리 헌터는 어느 행에도 배정하지 않는다(아래 노출 원칙 참고).
- 우선순위는 **기상특보 규칙 → 날씨 행 → 계절 행** 순서다.

- 포션 연금술사는 수분·전해질·카페인을 얼마나 먹으라는 문장으로 쓰지 않는다. 그렇게 쓰면 의료 조언이 된다.
- 표에 없는 밈·신조어는 가장 가까운 범주로 분류해 이 표를 따른다. 맞는 범주가 없으면 공통으로 둔다. 유행어는 영구 컨텐츠에 넣지 않는다.

#### 표 2. POI 유형 × 트라이브

기준은 `poi.category` 슬러그다. 분류 체계의 정본은 `docs/specs/prd/02_DATA_MODEL.md`에 있다.

| POI 유형 | 어울리는 트라이브 | 이유 |
|---|---|---|
| 산 (`mountain`) | 숲속의 갱단 · 아스팔트 레인저 | 갱단은 "외곽 산자락을 지배"하며 "방심한 등산객의 가방을 털고", 레인저는 험한 지형에서 버틴다 |
| 공원 (`park`) | 숲속의 갱단 · 낭만 미식가 | 갱단은 "도심 공원"의 실세이고, 미식가는 "자정의 한강 공원"에 있다 |
| 자연 (`nature`) | 숲속의 갱단 · 셔터 마피아 | 깊은 숲에 '그루터기 살롱'이 있고, 셔터는 "숨겨진 일몰 명소"를 찾는다 |
| 자전거길/트레일 (`route`) | 셔터 마피아 · 장비병 환자들 | 셔터는 "50km 험난한 라이딩도 '그곳의 노을이 예쁘기 때문'"에 감행하고, 장비병은 "카본·티타늄"을 믿는다 |
| 관광명소 (`tourist_attraction`) | 셔터 마피아 · 아날로그 수집가 | 셔터의 파편은 "'인생샷 포인트'임을 알리는 이정표"가 되고, 유적과 박물관에는 수집가가 말하는 "누군가의 기억"이 있다 |
| 음식점/카페 (`food`) | 낭만 미식가 · 셔터 마피아(카페) | 미식가는 '무명' 푸드트럭을 쫓고, 셔터는 "비밀 카페를 찾아내는 헌터들"이다 |
| 미슐랭 (`michelin`) | 낭만 미식가 | 미식가는 "맛을 종교처럼 숭배"한다. 다만 미식가가 쫓는 것은 이름 없는 '무명'이므로 등급이나 순위로 말하지 않는다 |
| 편의점/마트 (`convenience`) | 포션 연금술사 · 낭만 미식가 | 연금술사는 "에너지 젤·전해질 캔디·고카페인 알약"을 갖고 다니고 '오아시스 자판기'를 찾는다. 미식가는 "편의점 불빛 아래" 있다 |
| 기차/지하철 (`train_subway`) | 아날로그 수집가 · 비트 마에스트로 | 분실물이 모이는 곳이라 '분실물 센터 999'와 닿는다. 비트는 "모든 소음이 차단되고" 난 뒤의 주파수를 찾는다 |
| 경기장 (`stadium`) | 비트 마에스트로 | 트랙 위에서 "180 BPM" 페이스로 달린다 |
| 학교 (`school`) | 공통 | 세계관 근거가 없다. 미성년자 공간이므로 담백한 정보형으로만 쓴다 |
| 관공서 (`government`) | 공통 | 세계관 근거가 없다 |
| 병원 (`hospital`) | 공통 | 의료 시설에는 세계관 목소리를 얹지 않는다 |
| 약국 (`pharmacy`) | 공통 | 포션 연금술사를 붙이면 약물·도핑으로 오해받는다 |
| 미분류 (`unassigned`) | 배정 없음 | 거부된 POI를 보관하는 분류이며 노출 대상이 아니다 |

- 작심삼일 클럽("이불 속")과 미스터리 헌터는 장소에 묶인 정체성이 아니므로 POI 유형에 배정하지 않는다.
- 이 표는 컨텐츠 화자를 정하는 데만 쓴다. POI 유형별 트라이브 드랍 가중치나 앰비언트 드랍 설정으로 쓰지 않는다. 그렇게 쓰려면 별도 엔진 티켓과 시뮬레이터 검증이 필요하다.

#### 어떤 트라이브에도 붙이지 않는 소재

1. **순위·비교형 밈.** 기록으로 줄을 세우거나 남을 깎아내리는 유행이다. 작심삼일 클럽의 자조("나는 항상 나에게 져준다")는 허용되며, 이것은 남과 비교하는 말이 아니다.
2. **다이어트·체중·시술 같은 의료성 조언.** 포션 연금술사의 카페인이나 "도핑"은 세계관 속 허구이므로 실제 섭취량이나 효능 문장으로 옮기지 않는다.
3. **종교 의례·상징.** 성탄절과 부처님오신날은 "쉬는 날"로만 쓴다.
4. **실존 대회명.** 마라톤·트레일 대회 이름과 브랜드 러닝 허브·팝업 이름도 포함한다.
5. **국가 추념일·참사 추모일.** 세계관의 장난기는 추모와 어울리지 않는다. 공통 화자로도 소재로 삼지 않는다.
6. **상표명이 들어간 기념일·챌린지.** 과자 이름이 붙은 날이나 브랜드명이 들어간 챌린지가 여기에 해당한다.
7. **러닝 크루 매너 갈등·민폐 밈.** 특정 집단을 조롱하는 쪽으로 흐른다.
8. **실시간 위치나 경로 공유를 부추기는 인증 유행.**
9. **기상특보가 내린 날의 외출·활동 권유.**
10. **음주 권유.** 낭만 미식가의 "맥주 한 캔"은 원문을 인용하는 데서만 쓴다. 술을 마시라거나 마신 뒤 운동하라고 권하지 않는다.

#### 미스터리 헌터 노출 원칙

미스터리 헌터의 배지는 "도시 괴담이자 모든 유저가 열망하는 환상 등급 전리품"이다. 인접 그래프에서도 "epic·mystic 드랍 시에만 낮은 확률로 등장"하는 전역 스파이스다. 자주 들리는 괴담은 더 이상 괴담이 아니므로, 미스터리 헌터를 일상 화자로 쓰지 않는다.

- 표 1, 표 2, 시간대 화자 원칙 어디에도 배정하지 않는다. 반복되거나 정보성이거나 흔한 밈인 소재에도 붙이지 않는다.
- 등장할 수 있는 경우는 세 가지뿐이다.
  - epic·mystic 등급 아이템이 실제로 드랍되거나 픽업됐다는 소식
  - 미스터리 헌터 아이템이 들어간 등록 조합 레시피(`COMBINE_RECIPES.md`) 소개
  - 사람 등급 세계관 컨텐츠에서 사람이 직접 고른 경우
- 등장할 때는 목격담이나 소문 형식으로 쓴다. 미스터리 헌터가 유저에게 직접 말을 걸지 않고, 여럿이 함께하자는 어휘도 쓰지 않는다.
- "고통의 임계점(러너스 하이)"을 도달 목표나 미션 조건으로 내걸지 않는다.
- 일간 편성에는 미스터리 헌터의 노출 상한을 둔다. 희소성이 곧 정체성이므로 자주 보여서 그 희소성을 써 버리지 않게 하려는 장치다. 상한은 운영에서 정한다.
- **이 상한은 컨텐츠 노출 빈도 조정이며 드랍 확률과 무관하다.** 미스터리 헌터가 언제 드랍되는지는 인접 그래프와 드랍 엔진이 정하며, 이 원칙은 그것을 바꾸지 않는다.

#### 시간대 화자 원칙

| 시간대 | 화자 | 근거 원문 |
|---|---|---|
| 자정·심야 | 낭만 미식가 · 숲속의 갱단 | 미식가: "자정의 한강 공원, 편의점 불빛 아래 가쁜 숨을 몰아쉬는 이들". 갱단: 인접 서사의 "심야 숲의 기묘함" |
| 새벽·황혼(매직아워) | 셔터 마피아 | "하루 중 가장 완벽한 빛이 머무는 환상의 뷰포인트 '매직 아워 25시'", "붉게 물드는 단 15분의 마법" |
| 보조(새벽·심야) | 비트 마에스트로 | 인접 서사의 "새벽 감성(물안개 ↔ Lo-Fi)", 정의의 "모든 소음이 차단되고 자신과 심장 박동만 존재하는" |

- 비트 마에스트로는 보조 화자다. 주 화자를 먼저 배정하고, 같은 시간대 소재가 겹칠 때 두 번째 화자로 쓴다.
- 낮 시간대에는 전용 화자를 두지 않고 표 1과 표 2를 따른다. 미스터리 헌터는 어느 시간대의 화자도 아니다.
- 심야·새벽 컨텐츠는 그 시간대에 활동한 기록이 있는 유저에게만 보여 준다. 모든 유저에게 심야 활동을 권하지 않는다.

#### 시즌 캘린더 초안

시즌 경계는 24절기로 정한다. 절기는 특일정보에서 받을 수 있어 자동으로 판정할 수 있다. 날짜는 해마다 하루 정도 달라진다.

| 시즌 | 기간 | 주도 트라이브 후보 |
|---|---|---|
| 겨울→봄 전환 | 입춘 ~ 경칩 전날 (2월 초 ~ 3월 초) | 봄 주도 트라이브 예고 · 아날로그 수집가 |
| 봄 | 경칩 ~ 입하 전날 (3월 초 ~ 5월 초) | 숲속의 갱단 · 셔터 마피아 · 작심삼일 클럽 |
| 봄→여름 전환 | 입하 ~ 망종 전날 (5월 초 ~ 6월 초) | 여름 주도 트라이브 예고 · 셔터 마피아 |
| 여름 | 망종 ~ 입추 전날 (6월 초 ~ 8월 초) | 낭만 미식가 · 포션 연금술사 · 비트 마에스트로 |
| 장마철(여름 안) | 날짜로 고정하지 않는다. 비·폭우가 이어지는 기간이다 | 아스팔트 레인저 · 작심삼일 클럽 |
| 여름→가을 전환 | 입추 ~ 백로 전날 (8월 초 ~ 9월 초) | 가을 주도 트라이브 예고 · 셔터 마피아 |
| 가을 | 백로 ~ 입동 전날 (9월 초 ~ 11월 초) | 숲속의 갱단 · 셔터 마피아 · 아날로그 수집가 |
| 가을→겨울 전환 | 입동 ~ 대설 전날 (11월 초 ~ 12월 초) | 겨울 주도 트라이브 예고 · 아날로그 수집가 |
| 겨울 | 대설 ~ 입춘 전날 (12월 초 ~ 2월 초) | 아스팔트 레인저 · 장비병 환자들 · 작심삼일 클럽(연말연시) |

- 전환기에 나가는 계절 전환 예고(T17)는 다음 시즌의 주도 트라이브가 말한다. 마감이나 날짜는 강조하지 않는다.
- 비트 마에스트로, 포션 연금술사, 장비병 환자들은 계절보다 시간대나 유행 소재로 더 자주 등장한다. 미스터리 헌터는 시즌을 주도하지 않는다.
- 주도 트라이브는 세계관에 맞춰 고른 후보다. 반응 기록이 쌓이면 월간 리포트를 근거로 보정한다. DB에 저장할지는 나중에 정한다.


### 윈터의 경고와 확인 사항 (원고 밖)

- **엔진 영향 없음.** 인접 그래프·드랍 확률·가중치를 바꾸지 않는다. 반영 후 「트라이브 인접 그래프」 절 diff는 0줄이어야 한다. 표 2를 드랍 가중치로 쓰기 시작하면 그때부터 엔진 변경이다.
- 주의(높음): 레인저 캐치프레이즈("태풍 경보? 훌륭한 인터벌 트레이닝 날씨군")를 실제 특보일에 그대로 쓰면 태풍 속 외출 권유가 된다. 폭우·태풍 날 레인저는 대기·회고형으로만 쓴다.
- 주의(높음): PRD T13·T16의 POI 유형 기준은 `naver_category`(네이버 원본 문자열, 수동 등록분은 비어 있음)가 아니라 `poi.category` 15종이어야 한다. DB는 직접 확인하지 않았다(확신도 보통).
- 참고(높음): 티켓 2254의 날씨 구분(맑음·비·극한)은 표 1의 8단계보다 거칠다. 입력이 세분되기 전에는 "극한"을 폭우·태풍 행 규칙으로 처리한다.
- 참고(높음): 월간 리포트 2026-09 축 A 카드 7·8은 삭제된 "JAM! 레벨 0" 트라이브에 매핑돼 있다. 카드 7은 아날로그 수집가, 카드 8은 공통으로 본다. 리포트는 시점 기록이라 고치지 않는다.
- 참고(보통): 셔터 마피아가 표 1에 7행, 표 2에 4행 나와 쏠림이 있다. 주간 편성표 분포로 감시한다.
- **사용자 결정 필요(참고·보통)**: 장비병 환자들 정의에 "매일 자정 … 심야의 비밀 암시장 '카본 앨리'"가 있다. 시간대 원칙에 "카본 앨리 소식에 한해 자정 보조 화자"를 더할지. PRD T09의 기존 결정과 달라 원고에는 넣지 않았다.
- 참고(보통): "미슐랭"은 실존 상표. 카테고리 라벨로만 쓰고 컨텐츠 문구에는 별 등급 표현을 쓰지 않는다.
- 참고(낮음): 기차/지하철 소재와 '분실물 센터 999'를 한 문장에 붙이면 실존 작품 제목이 연상될 수 있다.
- 참고(높음): `tribes-history/` 스냅샷은 드랍 설정 변경 때만 두므로 이번에는 만들지 않는다.
