# [Infra] 주간 편성 지시문 확장 — 17종 카탈로그·요일별 후보 A/B/C·윈터 수정 반영

## 핵심 요약

- 요구사항: 매주 월요일 주간 리포트 「홈피드 초안」 절에 요일별로 다른 7일 편성이 후보 A/B/C(유형 ID·세그먼트·
  트라이브·문안 방향·등급)와 윤진 1픽, 트라이브·유형 분포와 함께 올라온다. PRD §6·§8·§12.
- 구현 계획: 윤진 정의 모드 ⑥과 주간 예약 작업 지시문, 주간 리포트 양식을 PRD §8 형식으로 바꾼다. 코퍼스는
  20260923_2256의 발췌 API로만 읽고, 이슈 소재는 20260923_2255의 통과분만 쓴다. 윈터 수정 5건과 미스터리 헌터 노출
  상한을 지시문에 고정한다.
- 관련 파일: `.claude/agents/jam-marketer.md`(모드 ⑥), `.claude/skills/jam-work/references/scheduled-jobs.md`
  (주간 작업), `jam-doc/operations/reports/README.md`(리포트 양식), `.claude/skills/jam-story/SKILL.md` §4. 스펙: PRD §6·§8·§12.

## 배경 / 문제 정의

지금 주간 홈피드 초안은 7일치를 한 안으로 내고 사람이 통째로 승인한다. 사용자는 매일 다른 7일 계획과 주제별 후보안을
원하며, 사람이 요일마다 후보를 고르는 구조로 바꾸기로 했다.

## 상세 요구사항

### 컨텐츠 관점
- 요일마다 주제가 다르고 후보 2~3개. 같은 주에 같은 유형이 두 번 대표가 되지 않는다. 트라이브 이야기 계열은 주 2회
  이하, 연속 배치 금지. 트라이브 분포는 매주 순환하고 0회·2회 이상 트라이브를 표시한다.
- 윈터 수정 5건: T09 미스터리 헌터 제외와 시간대별 화자 한정 / T13·T16은 POI 유형 매칭 / T15 트라이브별 어휘 분리 /
  T17은 매핑표 등재 전 사람 전용 / 미스터리 헌터 일간 노출 상한.
- 생성 전 프롬프트 필수 항목(PRD §12)을 지시문에 넣는다. 원문 요약·재작성 금지.
- 각 후보에 유형 ID와 등급을 표시한다. 사람이 「최종 선택」·「승인」을 채우면 카즈하가 어드민에 등록하는 절차를 적는다.
- 편성 후보안이 생성되면 `scripts/slack-post.mjs`로 `#jam-report`에 안내 글(대상 주·요일별 주제·1픽 요약·트라이브 분포·승인 필요 표시 + 리포트
  링크)을 올린다. 형식은 PRD §8-1과 `scheduled-jobs.md` 「Slack 알림」 절을 따른다. 스레드 답글 반영 절차(5-4)를 지시문에 적는다.

## 구현 계획

1. PRD §8 형식을 리포트 양식에 반영
2. 윤진 모드 ⑥ 지시문 개정(카탈로그 참조·후보 3개·1픽·분포·윈터 규칙)
3. 주간 예약 작업 프롬프트 개정(코퍼스 API·소재 통과분 참조)
4. 세션에서 1회 수동 실행해 7일 편성을 생성하고 윤진·윈터가 검토

- 생성된 후보에 미스터리 헌터 일상 화자, "지역 트라이브" 표현, T17 자동 생성이 없다(윈터 검토 기록).
