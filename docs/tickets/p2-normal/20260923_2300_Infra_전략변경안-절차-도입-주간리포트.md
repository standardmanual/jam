# [Infra] 전략 변경안 절차 도입 — 주간 리포트 「전략 변경안」 절과 양식

## 핵심 요약

- 요구사항: 카드 반응 계측이 최소 3주 연속 패턴을 보이면, 시스템이 PRD §10 양식의 전략 변경안(무엇을 바꾸자·근거
  신호·기대 변화·되돌리는 조건·과장 검사)을 주간 리포트에 승인 대기로 올린다. 사람 승인 없이는 반영하지 않는다.
- 구현 계획: 주간 예약 작업에 「전략 변경안」 절 생성 단계를 추가(윤진 모드 ④ 성과 회고 + 카즈하 수치). 최소 표본·
  3주 연속 조건을 지시문에 고정. 시뮬레이션 데이터로 1회 시연.
- 관련 파일: `.claude/skills/jam-work/references/scheduled-jobs.md`(주간 작업), `.claude/agents/jam-marketer.md`(모드 ④),
  `.claude/agents/jam-ops.md`, `jam-doc/operations/reports/README.md`. 스펙: PRD §10.

## 배경 / 문제 정의

사용자 결정: 반응 학습은 시스템이 전략을 스스로 바꾸되 바꿀 안을 사람에게 제안하는 방식이다. 지금은 반응 기록도 변경안
양식도 없다.

## 상세 요구사항

### 컨텐츠 관점
- 양식은 PRD §10 그대로. 과장 검사가 "예"이면 자동 반려.
- 최소 3주 연속 신호가 없으면 절을 비우고 "관찰 중"만 남긴다. 오픈 초기 표본 미달 기간에는 규칙 기반 제안만 한다.
- 변경안 승인은 주간 편성 승인과 별개 칸이다. 승인된 변경은 다음 주 편성 지시문에 반영되고, 되돌리는 조건도 함께 기록한다.

## 구현 계획

1. 리포트 양식에 「전략 변경안」 절 추가
2. 주간 작업 지시문에 생성 조건·양식·반려 규칙 추가
3. 시뮬레이션 데이터(가상의 3주 반응 표)로 1회 시연 → 사용자에게 먼저 보고(체크포인트)

## 완료 조건

- 시뮬레이션 데이터로 주간 작업을 세션에서 수동 실행하면 PRD §10 양식의 변경안이 승인 대기 상태로 생성된다(시연 1건을
  완료 기록에 첨부).
- 3주 미만 신호에서는 변경안이 생성되지 않고 "관찰 중"만 남는 것을 같은 방식으로 확인한다.
- 과장 검사 "예"인 변경안이 자동 반려되는 경로가 지시문에 있다.
