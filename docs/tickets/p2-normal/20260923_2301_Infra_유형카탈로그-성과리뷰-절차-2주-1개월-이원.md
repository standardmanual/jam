# [Infra] 유형 카탈로그 성과 리뷰 절차 — 2주(자동 등급)·1개월(초안·사람 등급) 이원

## 핵심 요약

- 요구사항: 17종 유형별 지표(노출·열람·성공 행동·채택률)를 기록해, 자동 등급 6종은 2주마다, 나머지 11종은 1개월마다
  유지·수정·보완·제거 판단 초안이 리포트에 올라오고 세션에서 사람이 확정한다. PRD §11.
- 구현 계획: 새 루틴을 만들지 않는다. 주간 예약 작업에 격주 조건(주차 홀짝 등)으로 「유형 리뷰」 절을 추가하고,
  월간 작업에 「유형 카탈로그 리뷰」 절을 추가한다. 양식은 PRD §11. 첫 실행은 세션에서 수동으로 한다.
- 관련 파일: `.claude/skills/jam-work/references/scheduled-jobs.md`(주간·월간 작업), `.claude/agents/jam-ops.md`,
  `.claude/agents/jam-marketer.md`, `docs/operations/reports/README.md`. 스펙: PRD §11.

## 배경 / 문제 정의

사용자 요구: 반응이 없는 유형을 2주 또는 1개월에 한 번 제거·수정·보완할 수 있어야 한다. 카즈하 확인: 2주 주기 루틴은
없고, 주간(월 09:00)·월간(1일 09:00) 루틴만 있다.

## 상세 요구사항

### 컨텐츠 관점
- 유형당 1행 양식: 유형 ID · 지표 요약 · 판정 · 근거 · 다음 리뷰까지 관찰 조건 · 승인.
- "반응 없음" 기준(연속 N회 하위권 → 관찰 대상 → 판정 후보)의 N과 기준선은 오픈 후 실측으로 정한다. 지시문에는
  "미정, 실측 후 확정"으로 둔다.
- 제거된 유형은 자동 복귀하지 않는다. 판정 확정은 세션에서 사용자 승인으로 하고 PRD §6 표를 고친다.
- 유형 리뷰(카탈로그 구성)와 전략 변경안(편성 비중·톤)의 역할 분리를 지시문에 적는다.
- 리뷰 절이 생성되면 `#jam-report`에 안내 글(판정 후보 유형 ID와 판정 목록·관찰 대상 수 + 승인 필요 표시 + 리포트 링크)을 올린다(PRD §8-1).
