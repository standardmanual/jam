# [Feature] 자동 생성 컨텐츠 유형 17종의 템플릿·이동 목적지 매핑 정의

> `docs` 유형, 카리나 직접. 사용자 질문(2026-09-24 "카드를 누르면 어디로 가는지 정해지지 않았다")에서 발견한 스펙 공백.

## 핵심 요약

- 요구사항: 카드의 이동 목적지는 유형 ID가 아니라 템플릿+대상 필드로 정해지므로(`targetHref.ts`), 유형 17종마다 등록 템플릿과 목적지를
  PRD §6에 정의한다. 트라이브를 보여 주는 화면은 없다는 사용자 확인에 따라 트라이브 소재 카드(T01·T11)의 목적지는 그 무드가 담긴 컬렉션으로 잡고
  성공 행동도 "컬렉션 상세 진입"으로 정정한다.
- 관련 파일: `docs/service/prd/content-automation/PRD.md` §6·§8, `.claude/agents/jam-marketer.md` ⑥, `.claude/skills/jam-work/references/forms/weekly-briefing-format.md`.

## 완료 조건

- PRD §6 표에 「템플릿 · 이동 목적지」 열이 17행 모두 채워져 있고, T01·T11 성공 행동이 정정됐다.
- 편성 후보안 형식(윤진 정의·브리핑 양식)에 목적지 칸이 있고, 등록 절차가 §6 열을 참조한다.
