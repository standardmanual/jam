# [UI] 에디토리얼 기사 본문 끝에 대상 CTA 버튼(컬렉션·미션·직접 링크) 추가

> 티켓 20260924_0106(유형별 이동 목적지 매핑)에서 발견. 자동 생성 유형 T01·T11·T17은 "기사 본문 → 컬렉션·미션"으로 이어져야 하는데,
> 기사 화면(`/today/[cardId]`)은 본문을 문단으로만 렌더하고 홈으로 가는 링크만 있어 CTA가 없다. `ui` 유형(채원 사전 판정 필요).

## 핵심 요약

- 요구사항: 에디토리얼 기사 카드에 `item_book_id`·`mission_id`·`target_href` 중 하나가 있으면 본문 끝에 CTA 버튼 1개를 보여 준다. 라벨은
  대상에 따라 "컬렉션 보기"·"미션 보기"·"바로가기"(직접 링크는 어드민이 `target_href`와 함께 라벨을 적을 수 있으면 그 라벨). 대상이 없으면
  버튼을 그리지 않는다(기존 화면 그대로).
- 구현 계획: 채원 ① 판정 후 확정. 후보: `jam-web/src/app/(main)/today/[cardId]/page.tsx`(본문 문단 렌더 뒤 CTA 블록), CTA 링크 계산은
  `jam-web/src/lib/today/targetHref.ts`의 규칙 재사용(에디토리얼은 자기 자신 `/today/[id]`로 가므로 "대상 필드 기준" 보조 함수 필요),
  어드민 폼은 에디토리얼 템플릿에서 `item_book_id`·`mission_id`·`target_href` 입력을 허용(`today-sections.ts` 필드 매트릭스 확인).
- 관련 파일: `jam-web/src/app/(main)/today/[cardId]/page.tsx` 8~45행, `jam-web/src/lib/today/targetHref.ts` 39행(에디토리얼 분기),
  `jam-web/src/lib/admin/today-sections.ts` `TODAY_FIELDS_FOR`(108행 근방), 디자인 시스템 버튼(채원 판정).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 대상 필드가 있는 에디토리얼 카드의 기사 화면 본문 끝에 CTA 버튼이 보이고, 누르면 컬렉션 상세·미션 상세·직접 링크로 이동한다.
- 대상 필드가 없는 기사는 기존과 동일하게 보인다(회귀 테스트).
- 어드민 에디토리얼 폼에서 컬렉션·미션·직접 링크 중 하나를 지정해 저장할 수 있다.
- 채원 ① 판정(컴포넌트 재사용·토큰)을 따랐고 채원 ② 리뷰 통과.

크기 상한: 5파일/100줄. 선행: 없음. 이 티켓이 닫히기 전까지 T01·T11·T17 자동 생성 카드의 목적지는 기사 본문까지다.
