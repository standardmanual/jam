# [API] 카드 이벤트 기록 API에 유저별 빈도 제한과 카드 노출 상태 검증을 추가한다

> 티켓 20260924_0004 게이트 리뷰(민지)의 범위 밖 발견물에서 자동 생성.

## 핵심 요약

- 요구사항: `POST /api/today/events`는 로그인만 확인하고 카드 ID의 노출 여부·요청 빈도를 검증하지 않아, 로그인 유저가 임의 카드 ID로 노출·클릭을 반복 전송해 전략 변경안·유형 리뷰 집계를 조작할 수 있다. 카드가 현재 활성·노출 기간 안인지 검증하고, 유저별 분당 요청 상한(예: 60건)을 둔다. 상한 판정에 쓰는 유저 키는 요청 처리 중에만 쓰고 저장·로그하지 않는다(집계 전용 원칙 유지).
- 관련 파일: `jam-web/src/app/api/today/events/route.ts`, `jam-web/src/lib/today/events.ts`(`recordTodayCardEvent` 앞 검증), 테스트 `jam-web/src/lib/today/__tests__/events.test.ts`

## 완료 조건

- 비활성·기간 밖 카드 ID는 400으로 거부되고, 분당 상한 초과는 429로 거부되며, 저장 페이로드와 로그에 유저 식별자가 없다(테스트로 확인).

크기 상한: 파일 3개, 60줄 이내.
