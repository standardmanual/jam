# [Content] 가을 시즌 미션을 기획·등록한다 (금요일 T04 카드 공백 해소)

> 금요일 편성 공백의 원인은 편성이 아니라 미션 부재다.

## 핵심 요약

- 요구사항: 가을 시즌 미션을 만들어 어드민에 등록한다. 미션이 있어야 T04(시즌 이슈×트라이브)·T15(함께하기)처럼 미션을 소개하는 유형을 편성할 수 있다.
- 구현 계획: 윈터가 가을 행 소재(숲속의 갱단·아날로그 수집가·포션 연금술사 중 활성 트라이브만, TRIBES.md 매핑)로 미션 안을 쓰고, 혜린이 조건·보상 수치를 정하고(경제 수치는 `/jam-plan`), 사용자 승인 뒤 어드민에 등록한다. 등록되면 10/2(금) 같은 빈 요일에 T04 카드를 편성한다.
- 관련 파일: `jam-doc/planning/content/TRIBES.md` 매핑 절(가을 행), `jam-doc/planning/content/`의 미션 문서, `docs/specs/prd/content-automation/PRD.md` §6 T04·T15

## 배경 / 문제 정의

2026-09-24 실측: 미션은 전체 53건이고 10/2에 진행 중이거나 시작 예정인 미션이 0건이다. 가을·숲속의 갱단 관련 미션도 없다. 그래서 9/28~10/4 편성의 금요일(T04)을 등록하지 못했다. 사용자 요청: "티켓 생성해".

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 가을 시즌 미션 1건 이상이 기획·승인·등록돼 10월 중 노출 기간을 갖는다.
- 그 미션을 소개하는 T04 카드 후보가 다음 편성표에 오른다.

### 사용자 결정 필요
- 미션 콘셉트·보상(경제 수치는 `/jam-plan`으로).

크기 상한: 컨텐츠 등록 위주.
