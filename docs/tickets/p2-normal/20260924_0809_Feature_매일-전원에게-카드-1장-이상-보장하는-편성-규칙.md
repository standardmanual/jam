# [Feature] 모든 유저에게 매일 카드가 1장 이상 보이도록 편성 규칙과 검증을 만든다

> 혜린 점검 발견 16·23과 사용자 요청에서 나온 규칙이다.

## 핵심 요약

- 요구사항: 개인화 카드(조건 태그)만 편성하면 조건에 맞는 유저가 없는 날 그 유저의 홈이 비어 보인다. **요일마다 조건 없는(`all`) 카드를 최소 1장** 두는 규칙을 편성표 형식과 검증에 넣는다.
- 구현 계획: PRD §8에 "요일마다 `all` 카드 1장 이상" 규칙을 추가하고, 주간 편성표에 요일별 「전원 노출 카드」 칸을 둔다. 검증은 편성 확정 전 요일별로 `all` 카드 유무를 확인하는 절차(리포트 점검 또는 등록 전 SQL)로 한다.
- 관련 파일: `docs/service/prd/content-automation/PRD.md` §8, `.claude/skills/jam-work/references/scheduled-jobs.md` 주간 절, `jam-web/src/lib/today/cards.ts`(조회 조건 70~85행)

## 배경 / 문제 정의

2026-09-24 점검 결과(9/28~10/4 편성): 전원 노출이 보장되는 날은 수(`all`)·일(`all`)뿐이다. 월(`itembook_remaining_le3`)·화(`strava_stale_14d`)는 조건에 맞는 유저만, 금은 카드가 없고, 목은 날씨 3종이 맑음·구름·비만 덮어 폭염·한파(`weather_extreme`)인 날과 날씨값이 없는 날은 아무에게도 안 나간다. 홈은 카드가 0장이면 최상단 영역이 통째로 사라진다. 사용자 요청: "개인화 카드 적용으로 모두에게 어떤 카드든 보여지는지 확인해야함".

## 진행 (2026-09-24)

- PRD §8 형식에 「전원 카드」 칸과 「후보 본문」 절, 요일마다 `all` 카드 1장 이상 규칙을 넣었다. §8-2에 등록 전 점검 SQL을 넣었다. 윤진 정의(`jam-marketer.md`)와 주간 지시문(`scheduled-jobs.md`)에도 반영했다.
- 점검 SQL을 9/28~10/4 편성에 돌린 결과: 10/1(날씨 카드 3종)과 10/3(공휴일 카드)은 `all` 카드가 0장이다. 두 날은 조건 태그가 사실상 전원에게 켜지지만, 날씨·특일 값이 저장되지 않으면 그날 홈이 빈다. 매일 아침 저장값을 확인한다.
- 남은 것: 2026-09-29(화) 주간 실행이 낸 10/5 주 후보안에서 빈 요일이 없는지 확인한다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- PRD §8에 「요일마다 `all` 카드 1장 이상」 규칙이 있다.
- 주간 편성 후보안 형식과 윤진 지시문에 그 칸과 점검이 들어간다.
- 다음 주 편성분에서 빈 요일이 없음을 확인한다.

크기 상한: 문서 위주.
