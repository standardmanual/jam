# [Service] 투데이 카드 클릭을 GA 이벤트(`today_card_click`)로도 보낸다

> 사용자 결정(2026-09-24): 카드 클릭 여부를 GA 지표로 확인한다. 확인해 보니 GA에는 투데이 카드 이벤트가 없었다(보내는 이벤트는 `home_view`·`mission_join`·`combine_success` 등 11종).

## 핵심 요약

- 요구사항: 카드를 누르면 GA 이벤트 `today_card_click`을 보낸다. 파라미터는 `card_id`·`content_type_id`·`template_type`이다(개인 식별자 없음). 자체 계측(`today_card_events`)의 클릭 기록은 그대로 둔다.
- 구현 계획: `TodayCardTracker`에 `contentTypeId`·`templateType` props를 더하고 클릭 핸들러에서 `trackEvent`를 함께 부른다. 랭킹보드 카드처럼 `trackClick={false}`인 카드는 보내지 않는다.
- 관련 파일: `jam-web/src/app/(main)/TodayCardTracker.tsx`, `jam-web/src/app/(main)/TodayCardStack.tsx`(트래커 호출부 315행 근방), `jam-web/src/lib/analytics/gtag.ts`(`trackEvent`)

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 카드 클릭 시 GA 이벤트가 파라미터와 함께 전송된다.
- 클릭을 세지 않는 카드(`trackClick={false}`)는 보내지 않는다.

### 후속 범위 (담당: 사용자, 시점: 배포 뒤)
- GA 보고서에서 파라미터로 나눠 보려면 GA 관리 → 맞춤 정의에 `content_type_id`·`template_type`·`card_id`를 이벤트 범위 맞춤 측정기준으로 등록한다.

크기 상한: 2파일/20줄.
