# [Service] 미션 53건이 모두 노출 조건에 걸려 공개 미션이 없다 — 공개 미션 운영 원칙을 정한다

> 2026-09-24 가을 미션 기획(티켓 0808) 중 발견했다. 사용자가 티켓 생성을 승인했다.

## 핵심 요약

- 요구사항: 2026-09-24 DB 조회 결과 미션 53건 전부 `engine_condition` 게이트형이고 전부 `visibility_rule_json`(특정 배지 보유)이 걸려 있다. 누구나 볼 수 있는 공개 미션은 0건이고, 누적 참가는 2명, 완료는 1건이다. 주간 리포트의 "미션 달성자 0명"은 난이도보다 노출 구조 때문일 가능성이 있다(유저별 배지 보유는 실측하지 않았다, 추정).
- 구현 계획: ① 카즈하가 활성 유저 중 미션을 하나라도 볼 수 있는 인원을 집계로 확인한다(개인 식별 없이). ② 혜린이 "상시 공개 미션 최소 N건" 같은 운영 원칙을 제안하고 사용자가 정한다. ③ 가을 미션(0808)이 첫 공개 미션이다.
- 관련 파일: `jam-web/src/lib/missions/visibility.ts`(187행 근방, 규칙이 null이면 공개), `jam-web/supabase/migrations/seed_v5_gate_missions.sql`, `missions` 테이블

## 진행 (2026-09-24)

- 가을 미션(0808)을 노출 조건 없이 등록해 공개 미션이 1건이 됐다(`b1009708-3258-477d-9278-107ad2c67d12`).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 활성 유저 대비 미션 노출 가능 인원이 집계로 확인된다.
- 공개 미션 운영 원칙이 정해져 문서(미션 PRD 또는 운영 문서)에 기록된다.
