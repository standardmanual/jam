# [Content] 믹스 레시피가 0건이라 믹스 기능을 쓸 수 없다 — 레시피를 기획·등록한다

> 2026-09-24 믹스 소각 안내(0813)를 스테이징에서 확인하다가 발견했다. 사용자가 티켓 생성을 승인했다.

## 핵심 요약

- 요구사항: 2026-09-24 DB 조회 결과 `combination_recipes`·`combination_recipe_slots`가 모두 0건이다. 믹스 화면은 "아직 등록된 레시피가 없어요"만 보여 믹스 기능을 쓸 수 없다. `docs/service/content/COMBINE_RECIPES.md`의 등재 레시피도 0건이다. 레시피를 기획·등록한다.
- 구현 계획: ① 윈터가 활성 트라이브 3종의 아이템배지로 만들 레시피 안(슬롯 구성·결과물·서사)을 쓴다. ② 혜린이 경제 영향(재료 소각·보상 배지 희귀도·실패 포인트)을 점검하고 사용자가 정한다(`/jam-plan`). ③ 어드민 `/admin/recipes`로 등록하고 `COMBINE_RECIPES.md`에 등재한다. ④ 등록되면 PRD §15 「믹스 레시피」 칸을 고쳐 T06·T10 편성을 다시 연다.
- 관련 파일: `docs/service/content/COMBINE_RECIPES.md`, `jam-web/src/app/admin/recipes/`, `jam-web/src/lib/combine/`, `docs/service/prd/content-automation/PRD.md` §8·§15

## 배경 / 문제 정의

- 믹스 유도 카드(T10) 2장이 빈 믹스 화면으로 안내하고 있어 끄고 교체했다(W39 리포트 「믹스 유도 카드 교체」). 9/29 카드는 「믹스 레시피가 있어요」라는 사실과 다른 문구였다. 후보안 작성(윤진)과 검수(윈터), 등록(카리나) 어디에서도 DB의 레시피 수를 확인하지 않았다.
- 믹스 소각 안내(0813)는 구현됐지만 레시피가 없어 화면에서 확인할 수 없다.
- 어드민 레시피 조회 API(`GET /api/admin/recipes`)는 로그인 세션만 받아 주간 루틴이 레시피 수를 직접 확인할 수 없다. 그래서 PRD §15에 레시피 현황 칸을 두고 편성 규칙이 그 칸을 따르게 했다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 레시피가 1건 이상 기획·승인·등록되고 `COMBINE_RECIPES.md`에 등재된다.
- PRD §15 「믹스 레시피」 칸이 실제 건수로 고쳐진다.

### 후속 범위 (담당: 카리나, 시점: 등록 뒤)
- 스테이징에서 믹스 소각 안내(0813) 화면 확인.

크기 상한: 컨텐츠 등록 위주.

## 완료 기록

### 구현 내용 요약
윈터가 활성 트라이브 3종의 아이템배지로 레시피 5건을 기획했고 혜린이 경제 점검(실패 파밍 통로, 성공·실패 포인트 상대 관계)을 했다. 사용자가 R1·R2·R3 등록, R4 보류, R5 제외, 실패 포인트 10P 유지, 성공 포인트 재료 수 × 10P를 승인했다(2026-09-24). 시드 SQL로 레시피 3행과 슬롯 8행을 등록했고, 슬롯 후보 22개 배지가 모두 존재함(type=item, common, 삭제 안 됨, 이름당 1건)과 `bad_refs` 0건을 확인했다. `COMBINE_RECIPES.md` §4·§6을 등재 내용과 2026-09-24 카탈로그 기준으로 다시 썼고 PRD §15 「믹스 레시피」 칸을 3건으로 고쳤다.
