# [Admin] 어드민 메인에 주간 캘린더 뼈대를 만들고 Vercel 크론 4개의 실행 예정을 표시한다

## 핵심 요약

- 요구사항: 어드민 메인에 이번 주(월~일) 캘린더를 두고, 크론 4개의 실행 예정 시각을 KST로 요일 칸에 표시한다. 기존 개수 카드와 빠른 실행은 캘린더 아래로 옮겨 유지한다.
- 구현 계획: `vercel.json`의 `crons`를 import해 cron 식을 파싱하는 순수 함수(UTC→KST 변환, 주간 발생 시각 목록)를 만들고, 캘린더 컴포넌트에 넘긴다. 매시간 크론(ambient-drop)은 칸마다 반복 표시하지 않고 '매시간' 한 줄로 묶는다. 이전·다음 주 이동을 지원한다.
- 관련 파일:
  - `jam-web/src/app/admin/page.tsx` `AdminDashboardPage` (전체 교체, 개수 카드·빠른 실행 유지)
  - `jam-web/vercel.json` `crons` (읽기만)
  - 신규: `jam-web/src/lib/admin/cronSchedule.ts` (cron 식 파싱·KST 변환), `jam-web/src/app/admin/WeeklyCalendar.tsx`

## 배경 / 문제 정의

크론 목록의 원천은 `vercel.json` 하나다. 화면은 이 파일을 읽기만 하고 크론 이름·주기를 따로 적지 않는다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 크론 표시 이름은 경로(`/api/cron/poi-cleanup` 등)에서 가져오고, 한국어 설명 매핑이 필요하면 경로를 키로 하는 표시용 라벨만 둔다.
- 어드민 유형이므로 MODULAR를 적용하지 않는다. 조회만 하며 DB 변경은 없다.
- 표시하는 시각은 모두 KST다. 데이터 하나를 불러오지 못해도 해당 영역만 오류 문구를 보이고 페이지 전체는 렌더된다(기존 `serviceError` 패턴).
- 실렌더 검증은 `docs/specs/DEV_PROCESS_GUARDRAILS.md` 패턴 13(로컬 `ADMIN_EMAILS` 셸 환경변수)으로 한다.

## 구현 계획

`vercel.json`의 `crons`를 import해 cron 식을 파싱하는 순수 함수(UTC→KST 변환, 주간 발생 시각 목록)를 만들고, 캘린더 컴포넌트에 넘긴다. 매시간 크론(ambient-drop)은 칸마다 반복 표시하지 않고 '매시간' 한 줄로 묶는다. 이전·다음 주 이동을 지원한다.

## 완료 조건

- 어드민 메인에 이번 주 캘린더가 표시되고, 크론 4개가 KST 기준 요일·시각에 표시된다(예: poi-cleanup `0 0 * * *` → 매일 09:00, external-inputs `0 21 * * *` → 매일 06:00).
- ambient-drop은 '매시간'으로 한 번만 표시된다.
- 이전·다음 주 이동이 동작한다.
- `cronSchedule.ts`의 UTC→KST 변환(날짜 경계 넘김 포함)에 단위 테스트가 있다.
- 기존 개수 카드 4개와 빠른 실행 버튼이 그대로 동작한다.
