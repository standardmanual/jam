# [Admin] 주간 캘린더의 요일 칸에 홈피드 카드 편성을 표시한다

## 핵심 요약

- 요구사항: 캘린더 7일 칸마다 그날 등록된 홈피드 카드(유형 ID·제목)를 표시하고, 카드가 없는 날은 '미편성'으로 표시한다.
- 구현 계획: 서버 컴포넌트에서 `today_cards`를 주간 범위로 조회(`/api/admin/today`의 조회 로직 재사용)해 캘린더에 넘긴다. 카드를 누르면 `/admin/today/[id]`로 이동한다.
- 관련 파일:
  - `jam-web/src/app/api/admin/today/route.ts` `GET` (조회 로직 참고·재사용)
  - `jam-web/src/app/admin/today/TodayCardTable.tsx` (표시 형식 참고)
  - `jam-web/src/app/admin/WeeklyCalendar.tsx`, `jam-web/src/app/admin/page.tsx`
  - 스펙: `docs/specs/prd/` 홈피드 절(§8)

## 배경 / 문제 정의

주간 편성 승인 뒤 카드가 요일마다 등록됐는지 확인하려면 지금은 `/admin/today`에서 날짜를 하나씩 넘겨야 한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 어드민 유형이므로 MODULAR를 적용하지 않는다. 조회만 하며 DB 변경은 없다.
- 표시하는 시각은 모두 KST다. 데이터 하나를 불러오지 못해도 해당 영역만 오류 문구를 보이고 페이지 전체는 렌더된다(기존 `serviceError` 패턴).
- 실렌더 검증은 `docs/specs/DEV_PROCESS_GUARDRAILS.md` 패턴 13(로컬 `ADMIN_EMAILS` 셸 환경변수)으로 한다.

## 구현 계획

서버 컴포넌트에서 `today_cards`를 주간 범위로 조회(`/api/admin/today`의 조회 로직 재사용)해 캘린더에 넘긴다. 카드를 누르면 `/admin/today/[id]`로 이동한다.

## 완료 조건

- 캘린더의 각 요일 칸에 그날 카드의 유형 ID와 제목이 표시된다.
- 카드가 없는 날은 '미편성'으로 표시된다.
- 카드를 누르면 해당 카드 편집 화면으로 이동한다.
- 주를 이동하면 그 주의 카드로 바뀐다.
