# [Admin] 주간 캘린더에 미션과 게이트 미션의 기간을 막대로 표시한다

## 핵심 요약

- 요구사항: 이번 주와 겹치는 미션의 `starts_at`~`ends_at`을 캘린더 위에 가로 막대로 표시하고, 게이트 미션은 구분 표식을 붙인다.
- 구현 계획: `missions`에서 주간 범위와 겹치는 행을 조회하고 `isGateMission()`으로 게이트 미션을 구분한다. 이번 주에 시작하거나 끝나는 미션은 시작·종료 표식을 붙인다.
- 관련 파일:
  - `jam-web/src/app/api/admin/missions/route.ts` (조회 로직 참고)
  - `jam-web/src/lib/missions/gateMissions.ts` `isGateMission` (217줄 부근)
  - `jam-web/src/app/admin/WeeklyCalendar.tsx`, `jam-web/src/app/admin/page.tsx`

## 배경 / 문제 정의

진행 중이거나 곧 끝나는 미션을 한눈에 볼 방법이 없다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 기간이 정해지지 않은 상시 미션은 막대 대신 '상시' 목록으로 따로 모은다.
- 어드민 유형이므로 MODULAR를 적용하지 않는다. 조회만 하며 DB 변경은 없다.
- 표시하는 시각은 모두 KST다. 데이터 하나를 불러오지 못해도 해당 영역만 오류 문구를 보이고 페이지 전체는 렌더된다(기존 `serviceError` 패턴).
- 실렌더 검증은 `docs/specs/DEV_PROCESS_GUARDRAILS.md` 패턴 13(로컬 `ADMIN_EMAILS` 셸 환경변수)으로 한다.

## 구현 계획

`missions`에서 주간 범위와 겹치는 행을 조회하고 `isGateMission()`으로 게이트 미션을 구분한다. 이번 주에 시작하거나 끝나는 미션은 시작·종료 표식을 붙인다.

## 완료 조건

- 이번 주와 겹치는 미션이 기간만큼의 막대로 표시되고, 누르면 미션 편집 화면으로 이동한다.
- 게이트 미션에는 구분 표식이 있다.
- 이번 주에 종료되는 미션에는 종료 표식이 있다.
- 기간 겹침 판정 함수에 단위 테스트가 있다(주 경계 걸침 포함).
