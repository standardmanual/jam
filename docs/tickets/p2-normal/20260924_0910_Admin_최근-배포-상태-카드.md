# [Admin] 어드민 메인에 staging·프로덕션의 최근 배포 상태를 표시한다

## 핵심 요약

- 요구사항: staging과 프로덕션의 마지막 배포 시각(KST), 상태(Ready/Error 등), 커밋 메시지를 카드로 표시한다.
- 구현 계획: 서버에서 Vercel REST API(배포 목록)를 `VERCEL_API_TOKEN`으로 호출한다. 토큰은 서버 환경변수로만 두고 화면에 노출하지 않는다. 짧은 캐시(예: 60초)를 둔다.
- 관련 파일:
  - `jam-web/src/app/admin/page.tsx`
  - 신규: `jam-web/src/lib/admin/vercelDeployments.ts`

## 배경 / 문제 정의

배포가 성공했는지 확인하려면 지금은 Vercel 대시보드를 따로 열어야 한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- **선행 조건(WAITING 사유)**: 사용자가 읽기 권한 Vercel 토큰을 발급해 `VERCEL_API_TOKEN`으로 등록해야 한다(2026-09-24 사용자 결정: 나중에 등록).
- 토큰이 없으면 카드에 '토큰 미등록' 안내만 표시하고 오류로 처리하지 않는다.
- 어드민 유형이므로 MODULAR를 적용하지 않는다. 조회만 하며 DB 변경은 없다.
- 표시하는 시각은 모두 KST다. 데이터 하나를 불러오지 못해도 해당 영역만 오류 문구를 보이고 페이지 전체는 렌더된다(기존 `serviceError` 패턴).
- 실렌더 검증은 `docs/specs/DEV_PROCESS_GUARDRAILS.md` 패턴 13(로컬 `ADMIN_EMAILS` 셸 환경변수)으로 한다.

## 구현 계획

서버에서 Vercel REST API(배포 목록)를 `VERCEL_API_TOKEN`으로 호출한다. 토큰은 서버 환경변수로만 두고 화면에 노출하지 않는다. 짧은 캐시(예: 60초)를 둔다.

## 완료 조건

- 토큰이 있으면 staging·프로덕션 각각의 마지막 배포 시각, 상태, 커밋 메시지가 표시된다.
- 토큰이 없으면 '토큰 미등록' 안내가 표시되고 페이지는 정상 렌더된다.
- 응답 파싱 함수에 단위 테스트가 있다.
