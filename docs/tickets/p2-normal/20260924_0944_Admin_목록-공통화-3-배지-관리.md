# [Admin] 목록 공통화 ③ 배지 관리 목록 전환

## 핵심 요약

- 요구사항: 배지 관리(4,091건) 목록을 상위 티켓 20260924_0916 §1 표준과 §4.1 배지 행대로 바꾼다. 표 안 대표 기능은 활성 스위치,
  일괄 처리는 활성화(등급 1)·비활성화(등급 2)·트라이브 지정(등급 1)·삭제(등급 3)·내보내기다. 컬렉션 지정은 넣지 않는다(티켓
  20260924_0937 선행).
- 구현 계획: ①(20260924_0940)의 부품과 ②(20260924_0941)의 서버 틀·공용 도구를 쓴다. 파일 단위 계획은 아래 표.
- 관련 파일: `jam-web/src/app/admin/badges/page.tsx`, `jam-web/src/components/admin/badges/BadgesTable.tsx`,
  `jam-web/src/app/admin/badges/BadgesFilterBar.tsx`, `jam-web/src/components/admin/badges/BadgeList.tsx`,
  `jam-web/src/app/api/admin/badges/[id]/route.ts:242-291`, `jam-web/src/app/api/admin/badges/bulk-delete/route.ts`

## 배경 / 문제 정의

- 일괄 활성화·비활성화가 단건 PATCH를 반복한다(`BadgesTable.tsx:313-358`).
- 상태 "전체" 필터가 동작하지 않는다. `BadgesFilterBar.tsx:80`이 'all'을 URL에서 지우면 `badges/page.tsx:70`이 기본값 'active'로
  되돌린다.
- 검색어가 정제 없이 `.or()`에 들어간다(`badges/page.tsx:206`).
- `POST /api/admin/badges/bulk`는 이미 배지 일괄 변경 도구가 쓴다. 그래서 목록용 일괄 API는 `list-bulk`로 이름을 정한다.

`list-bulk` 동작:
- `activate`(등급 1): `deleted_at = null`. `updateByIdsAllOrNothing`.
- `deactivate`(등급 2): 미리보기 `impact.droppableCount` = `poi_drops`에서 대상 배지, `is_available = true`, `picked_up_at is null`
  건수(`jam-web/src/lib/admin/poi-drops.ts:22-27`의 무효화 조건과 같게). 실행은 모든 묶음 반영이 성공한 뒤에 부수효과를 실행한다.
- `assign_tribe`(등급 1, payload `tribe_id`): 체크인 배지는 저장 API가 트라이브를 null로 강제하므로(`[id]/route.ts:91-92`) "체크인
  배지"로 건너뛴다. 소속 컬렉션이 있고 그 컬렉션의 트라이브가 다르면 "소속 컬렉션의 트라이브와 다름"으로 건너뛴다(드랍 엔진은
  배지가 아니라 컬렉션의 트라이브를 본다, `jam-web/src/lib/drop-engine/index.ts:185-201`). 분류 로직은 순수 함수로 둔다.
- `delete`(등급 3, `maxIds` 100): `collectBadgeReferences`로 막힌 항목을 건너뛴다(배지 한 건마다 참조를 세므로 상한 100).

일괄 처리 바: 대표 [활성화] [비활성화], 더보기 [트라이브 지정] [내보내기] [삭제]. 정렬은 기존 목록(최신, 오래된, 이름 오름·내림,
계열, 레벨)을 유지한다.

## 구현 계획

계획 반환 면제 사유: 신규 7개·수정 5개·삭제 1개 + 테스트 2개, 약 +1,200/−700줄. 한 화면의 전환이라 더 나누면 일괄 처리 바와 API가
갈라진다. 파일 단위 계획은 위 표와 같다.

## 완료 조건

- `rg -n "for \(const id of" jam-web/src/components/admin/badges` 결과가 0건이다.
- `bulk-delete` 라우트가 없고, `rg "badges/bulk-delete" jam-web/src` 결과가 0건이다. 배지 일괄 변경 도구의 `/api/admin/badges/bulk`는
  바뀌지 않았다.
- 단위 테스트: `parseBadgeListParams`(상태 'all'이 'active'로 되돌아가지 않음 포함), 트라이브 지정 분류 함수(체크인 배지·컬렉션
  트라이브 불일치 건너뜀).
- `scripts/verify.sh` 통과.
- 로컬 실렌더(패턴 13, **저장하지 않고 읽기만**): 상태 "전체"를 고르면 비활성 배지도 보인다. 필터 결과 전체 선택 → 비활성화 확인창에
  무효화될 드랍 수가 표시된다(실행하지 않음). 행 빈 곳 클릭은 상세로 이동하고 스위치 클릭은 이동하지 않는다. 모바일 폭에서 카드
  뷰가 그대로다.
- 단건 PATCH 비활성화의 부수효과가 추출 전과 같다(기존 테스트 통과 + 추출 함수 단위 테스트).
