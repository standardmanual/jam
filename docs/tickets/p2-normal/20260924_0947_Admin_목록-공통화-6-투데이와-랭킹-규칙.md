- 투데이 활성 토글이 응답 성공 여부를 보지 않고, 삭제도 오류를 무시한다(`TodayCardList.tsx:24-37`).
- 날짜를 바꿔도 선택이 풀리지 않는다(`TodayCardTable.tsx:66-82`에 목록 변경 시 선택 초기화가 없음).

- 날짜 이동이 다른 쿼리 파라미터를 버린다(`TodayDateNav.tsx:23`).
- 랭킹 규칙 삭제는 바로 지운다(`ranking-modes/[id]/route.ts:33-44`). 카드의 규칙 참조는 삭제 시 비워지도록 되어 있어
