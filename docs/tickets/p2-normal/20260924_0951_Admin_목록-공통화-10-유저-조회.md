## 배경 / 문제 정의

- 목록이 최근 100명만 보여 주고 검색·필터가 없다(`users/page.tsx:7-11`). 배지·아이템 수를 행째로 세어 1,000행 상한에 걸린다(`:18-47`).
- 행마다 초기화·삭제 버튼이 있고 선택 기능이 없다(`UsersTable.tsx:85-103`).
- 단건 초기화는 본인·어드민 계정을 막지 않는다(삭제는 `[id]/route.ts:21`에서 본인만 막음).
- `app/api/admin/users/route.ts:19`는 검색어를 정제 없이 필터에 넣는다.
- 이메일은 `public.users.email`(NOT NULL)에 있다. 가입할 때 `handle_new_user()` 트리거가 auth에서 복사하고 이후에는 동기화하지 않는다
  (가입 시점 값). auth 스키마를 조회하지 않고 이 칸으로 검색한다.
- 유저 상세의 배지 이력은 개수 제한이 없어 실제로는 1,000행에서 잘리고, 총 개수도 배열 길이다(`users/[id]/page.tsx:29-33, 89`).

미리보기 `impact`(200개씩 나눠 건수 합산):
