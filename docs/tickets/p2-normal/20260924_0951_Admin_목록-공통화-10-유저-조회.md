# [Admin] 목록 공통화 ⑩ 유저 조회 목록 전환 — 검색·서버 페이지 이동·등급 3 일괄 처리(포인트 지급·회수, 초기화, 삭제)

## 핵심 요약

- 요구사항: 유저 조회 목록을 상위 티켓 20260924_0916 §1 표준과 §4.4 유저 행대로 바꾼다.
  - 이름·이메일 검색, 서버 페이지 이동(한 쪽 50건), 트라이브·온보딩·제재 상태 필터. 제재 상태·어드민 여부를 칸으로 표시.
  - 일괄: 대표 [내보내기], 더보기 [포인트 지급·회수] [초기화] [삭제] — 셋 다 등급 3(확인 문구 입력, 상위 티켓 결정 3).
  - **어드민 계정과 실행자 본인은 일괄 대상에서 자동으로 뺀다.** 유저별 결과를 돌려준다.
  - 유저 상세의 배지 이력 표에 번호 페이지 이동을 넣는다(현재 개수 제한 없음).
- 구현 계획: ①(20260924_0940) 부품, ②(20260924_0941)의 `readBulkRequest`(실행 어드민 신원 포함)·`isAdminAccount`·
  `countRowsByKey`·`sanitizeSearchTerm`을 쓴다. 단건 라우트의 로직을 lib로 추출해 단건과 일괄이 같은 함수를 쓴다.
- 관련 파일: `jam-web/src/app/admin/users/page.tsx:7-47`, `jam-web/src/app/admin/users/UsersTable.tsx:49,85-103`,
  `jam-web/src/app/api/admin/users/[id]/reset/route.ts:20-139`, `jam-web/src/app/api/admin/users/[id]/route.ts:21-67`,

## 배경 / 문제 정의

- 목록이 최근 100명만 보여 주고 검색·필터가 없다(`users/page.tsx:7-11`). 배지·아이템 수를 행째로 세어 1,000행 상한에 걸린다(`:18-47`).
- 행마다 초기화·삭제 버튼이 있고 선택 기능이 없다(`UsersTable.tsx:85-103`).
- 단건 초기화는 본인·어드민 계정을 막지 않는다(삭제는 `[id]/route.ts:21`에서 본인만 막음).
- `app/api/admin/users/route.ts:19`는 검색어를 정제 없이 필터에 넣는다.
- 이메일은 `public.users.email`(NOT NULL)에 있다. 가입할 때 `handle_new_user()` 트리거가 auth에서 복사하고 이후에는 동기화하지 않는다
  (가입 시점 값). auth 스키마를 조회하지 않고 이 칸으로 검색한다.
- 유저 상세의 배지 이력은 개수 제한이 없어 실제로는 1,000행에서 잘리고, 총 개수도 배열 길이다(`users/[id]/page.tsx:29-33, 89`).

### 일괄 API `POST jam-web/src/app/api/admin/users/bulk/route.ts` (`maxDuration` 60)
- `partitionUserTargets`(순수 함수): `isAdminAccount`에 해당하면 "어드민 계정", 실행 어드민 본인이면 "본인 계정"으로 건너뛴다.
- `grant_points`: 입력을 `validateAdminGrantInput`으로 한 번 검증(0이 아닌 정수, 허용된 사유, 기타 사유면 메모 필수, 1,000P 이상이면
  확인 필요)한 뒤 유저마다 `executeAdminGrant`(동시 5건). 회수는 음수 금액이다.
- `reset`·`delete`: `maxIds` 50, 유저마다 차례로(동시 2건 이하), `results[{ id, ok, error }]`.
- 신규 `.../users/ids/route.ts`, `.../users/export/route.ts`.

미리보기 `impact`(200개씩 나눠 건수 합산):
- 공통: 대상 수, 자동 제외된 어드민·본인 수.
- 포인트: 합계(금액 × 대상 수), 회수라면 잔액이 음수가 될 유저 수(`point_wallets.balance < |금액|`), 발송될 알림 수.
- 초기화: 배지 이력 수, 영구 삭제될 아이템 수, 미션 완료 기록 수.
- 삭제: 배지 이력 수, 소유자 없음으로 바뀔 아이템 수, 사라질 포인트 잔액 합계, Strava 연동 수.

## 완료 조건

- 단위 테스트:
  - `partitionUserTargets`: 어드민(`is_admin` 또는 `ADMIN_EMAILS`)과 본인이 "건너뜀"으로 분류된다.
  - `validateAdminGrantInput`: 단건 라우트와 같은 규칙.
  - `user-list`의 검색어 정제·필터 조건.
- 단건 초기화 라우트가 본인·어드민 계정에 403을 돌려준다(로컬에서 본인 ID로 호출해 확인, 실제 초기화 없음).
- 일괄 API 미리보기가 영향 수치와 확인 문구를 돌려주고 DB는 바뀌지 않는다. 확인 문구 없이 실행하면 409다.
- `scripts/verify.sh` 통과.
- 로컬 실렌더(패턴 13, **저장하지 않고 읽기만**): 이메일 일부로 검색된다. 필터 결과 전체 선택 → 삭제 확인창에 자동 제외 수와 영향
  수치가 보이고, 확인 문구가 일치할 때만 버튼이 켜진다(실행하지 않음). 유저 상세의 배지 이력이 50건씩 나뉜다.
