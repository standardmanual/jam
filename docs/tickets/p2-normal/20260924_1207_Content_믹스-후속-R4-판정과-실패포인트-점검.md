(4) 문서 드리프트를 고친다: `SERVICE_OPERATIONS.md` §8이 옛 방식(재료 2~3개, `success_rate`)을 설명하고 있다.

- **(1) R4 판정 자료**: 「황금빛 도토리」는 랜덤 드랍 풀에 있다(아이템배지 270종 모두 제외 없음, 가중치 1.0, 조건 없음). 그러나 전체 아이템 개체 1,269개(인벤토리 4개) 중 이 배지를 획득한 사례가 0건이다. R4는 도토리 1종 고정 슬롯이라 지금 등록하면 아무도 채울 수 없다. **보류를 유지한다.** 재판정 조건은 도토리 획득 사례가 생기거나 R4 슬롯 후보를 넓히는 것이다(같은 갱단 컬렉션의 「반짝이는 도토리」·「다람쥐의 숨겨둔 호두」를 슬롯 후보로 넣는 안은 윈터·혜린 판단이 필요하다).
- **(4) 문서 드리프트**: `SERVICE_OPERATIONS.md` §8을 현재 코드(레시피 선택형, 슬롯 기반 OR 매칭, 소각 순서, 실패 포인트)로 다시 썼다. `COMBINE_RECIPES.md` §4·§6은 티켓 0902에서 이미 고쳤다.
- **(2)(3) 점검 항목**: 실패 포인트 합계와 결과물 배지 유효 여부는 어드민 읽기 토큰으로 읽을 수 있는 데이터가 없다(`kpi/weekly`는 미션 달성자·배지 발급량·동기화 실패만 반환하고, 레시피 조회 API는 로그인 세션만 받는다). 데이터 출처를 만드는 API 티켓 20260924_1455로 분리했다.
