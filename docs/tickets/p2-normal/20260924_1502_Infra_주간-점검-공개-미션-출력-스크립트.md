# [Infra] 주간 점검이 쓰는 어드민 읽기 스크립트에 「공개 미션 점검」 출력을 추가한다

> 티켓 20260924_1408이 지시문에만 넣은 공개 미션 점검을 실제로 돌게 하는 후속이다. 9/29 첫 주간 실행 전에 필요하다.

## 핵심 요약

- 요구사항: 주간 루틴이 수집 명령으로 쓰는 `scripts/admin-api-read.mjs`는 「미션: N건」처럼 건수만 출력해서, 카즈하가 「오늘 참가 가능한 공개 미션 수」와 「상시 공개 미션 보상 배지 유효 여부」를 판단할 수 없다(지시문대로면 항상 「확인 불가」). 스크립트가 이미 받아 오는 미션·배지 응답으로 두 점검 결과를 직접 출력하게 한다. 루틴 저장 프롬프트는 바꾸지 않는다(프롬프트가 이 스크립트를 이미 실행한다).
- 구현 계획(파일 단위):
  1. 신규 `scripts/public-mission-check.mjs`: 순수 함수 `computePublicMissionCheck(missions, badges, now)`. 공개 미션은 `gate_axis`·`gated_badge_id`·`visibility_rule_json`이 모두 null인 미션이다. 참가 가능은 공개이고, 노출됐고(`exposure_mode`가 `hidden`이면 아니오, `scheduled`이면 `exposure_at` 이후, 그 외는 `starts_at` 이후 — `jam-web/src/lib/missions/visibility.ts` `isMissionExposed`와 같은 규칙), `ends_at`이 null이거나 지금보다 뒤인 것이다. 상시 공개 미션(`ends_at`이 null인 공개 미션)마다 `reward_badge_ids`의 배지가 배지 응답에 있고 `deleted_at`이 null인지 센다. 반환은 건수만이며 미션 제목·유저 정보는 넣지 않는다.
  2. 수정 `scripts/admin-api-read.mjs`(60~90행 `main`): 기존 출력 끝에 「공개 미션 점검」 줄을 붙인다. 형식은 `- 공개 미션 점검: 참가 가능 N건` (0이면 뒤에 ` [주의]`), `- 상시 공개 미션 보상 배지: 유효 N건, 삭제·미조회 M건` (M이 0보다 크면 ` [주의]`). 미션 또는 배지 조회가 실패했으면 `- 공개 미션 점검: 확인 불가 (사유)`를 출력하고 종료 코드는 바꾸지 않는다.
  3. 신규 `scripts/public-mission-check.test.mjs`: 게이트 미션·노출 조건 미션 제외, 시작 전·종료됨·`hidden`·`scheduled` 미도래 제외, 상시 미션 배지 삭제·미조회 집계, 빈 배열 처리.
- 관련 파일: `scripts/admin-api-read.mjs`, `scripts/public-mission-check.mjs`(신규), `scripts/public-mission-check.test.mjs`(신규), `docs/service/SERVICE_OPERATIONS.md` §9-5, `.claude/skills/jam-work/references/scheduled-jobs.md`(주간 절 안내 문장 정정), `.claude/agents/jam-ops.md`

## 완료 기록

### 구현 내용 요약
어드민 읽기 스크립트(`scripts/admin-api-read.mjs`)가 공개 미션 점검 두 줄을 직접 출력하게 했다. 순수 함수 `computePublicMissionCheck(missions, badges, now)`(`scripts/public-mission-check.mjs`, 신규)가 건수만 계산한다. 공개 미션은 `gate_axis`·`gated_badge_id`·`visibility_rule_json`이 모두 null인 미션이고, 참가 가능은 공개이며 노출됐고(`isMissionExposed`와 같은 규칙) `ends_at`이 null이거나 미래인 미션이다. 상시 공개 미션(`ends_at` null)의 보상 배지가 배지 응답에 있고 `deleted_at`이 null인지 센다. 출력은 `- 공개 미션 점검: 참가 가능 N건`(0이면 [주의])과 `- 상시 공개 미션 보상 배지: 유효 N건, 삭제·미조회 M건`(M이 0보다 크면 [주의])이며, 조회 실패 시 `확인 불가 (사유)`를 출력하고 종료 코드는 바꾸지 않는다. 카즈하 지시문·주간 지시문·§9-5는 「스크립트가 직접 출력하고 카즈하는 옮긴다」로 고쳤다. 루틴 저장 프롬프트는 바꾸지 않았다(프롬프트가 이 스크립트를 이미 실행한다).
