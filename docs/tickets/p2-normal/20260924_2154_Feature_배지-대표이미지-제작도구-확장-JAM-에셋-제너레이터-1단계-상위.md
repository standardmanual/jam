# [Feature] 배지 대표 이미지 제작 도구 확장 — JAM! 에셋 제너레이터 1단계 (상위 티켓)

> `/jam-plan` 2단계 기획서를 사용자가 2026-09-24에 승인해 만든 상위 티켓이다. 동작 정의·화면 구성·레이어·프리셋·컬러
> 규칙·경로 표시의 정본은 [PRD](../../specs/prd/asset-generator/PRD.md)(draft)에 있고, 이 티켓은 기획 경위·결정 기록·리스크·
> 하위 티켓 표를 담는다. 기획 담당 혜린, 구현 아현, 사전·사후 판정 채원, 마케팅 윤진, 세계관 검수 윈터.

## 핵심 요약

- 요구사항: 프로토타입 `jam-doc/assets/prototypes/20260924_jam-asset-generator.html`(브랜드 글자·업로드 그림을 랜덤 곡선을
  따라 반복 복사하는 리본 그래픽 도구)을 어드민 "디자인" 메뉴의 정식 화면으로 옮기고, 이미지·텍스트 레이어와 프리셋을 더해
  배지 대표 이미지를 **수동 경로**(어드민에서 조절·랜덤·검색·미리보기·적용)와 **자동 경로**(윤진이 프리셋+색+텍스트로 생성 →
  사용자 컨펌 → 메인 세션 등록)로 만든다. 1차는 배지 프리셋 1종.
- 구현 계획: 하위 티켓 10개를 공용 모듈 → 어드민 화면 → 레이어 → 프리셋 → 적용·경로 표시 → CLI → 등록 스크립트 → 에이전트
  정의 순으로 진행한다. DB 변경은 파일 작성까지 하위 티켓에서, 실행은 승인 후 메인 세션.
- 관련 파일: `docs/specs/prd/asset-generator/PRD.md`, `jam-doc/assets/prototypes/20260924_jam-asset-generator.html`,
  `jam-web/src/components/admin/adminNavItems.ts`, `jam-web/src/lib/admin/applyGeneratedImage.ts`,

## 배경 / 문제 정의

윤진이 홈피드 카드·배지·미션·컬렉션 컨텐츠에 쓸 이미지를 만들 경로가 없다. `shader-lab`은 배경 생성 전용이고 `/jam-img`는
배지 아이콘 생성 전용이라, 컨텐츠를 발행할 때마다 디자이너 리소스에 기대거나 이미지 없이 나간다. 2026-09-24에 만든 에셋
제너레이터 프로토타입(리본 그래픽·그라데이션·블러·회전·곡선·PNG/MP4 저장·전체 랜덤)이 브랜드 그래픽의 뼈대가 될 수 있음이
확인되어, 이를 운영 도구로 확장한다.

## 기획서 (혜린, 2026-09-24 승인)

- **대상**: 윤진(기획안+이미지 생성, 컨펌 자료 준비) · 사용자 본인(컨펌) · 메인 세션(컨펌 후 등록 실행) · 어드민 사용자(수동
  경로) · 채원·윈터(컨텐츠 단위 컬러 방향 제시·검수)
- **성공 기준(측정 가능)**
  1. 어드민에서 이미지 레이어(아이콘 자리)와 텍스트 레이어(배지 이름 자리, 구글 폰트 선택)를 갖춘 배지 프리셋 1종을 저장할 수 있다
  2. 수동 경로: 프로토타입과 같이 모든 속성을 직접 조절하거나 전체 랜덤 버튼을 쓸 수 있고, 프리셋 불러오기·이미지 레이어·텍스트
     레이어가 추가된 화면에서 배지를 검색·필터·미리보기한 뒤 적용 버튼으로 그 배지의 대표 이미지에 반영할 수 있다
  3. 자동 경로: 윤진이 프리셋+지정 컬러+배지 텍스트로 만든 이미지와 배지 기획안(이름·설명·획득 조건)을 묶어 파일로 준비하면,
     사용자가 컨펌 한 번으로 메인 세션이 등록 스크립트를 실행해 배지 데이터와 이미지가 함께 등록된다
  4. 적용된 이미지는 원본이 보관되고 서비스 실제 표시 크기에 맞는 WebP 축소본이 자동 생성되어 배지 화면에 반영된다
  5. 배지 목록·상세에서 제작 경로(수동 제작 / 아이콘 파이프라인 / 윤진 자동)가 라벨로 구분된다
  6. 같은 시드를 다시 넣으면 같은 이미지가 재현된다
- **범위**: 배지 프리셋 1종. 수동 경로 전체 + 자동 경로 전체. 공용 모듈 패키지화, 이미지·텍스트 레이어, 프리셋 저장, 적용, 제작
  경로 표시, 출력 규격 최적화, 에이전트 CLI, 등록 스크립트, 에이전트 정의 갱신(승인 항목).
- **하지 않을 것**: PRD §13 (미션·컬렉션·홈피드 프리셋, 배지 배경 적용, 영상 서버 생성, `shader-lab` 수정, 프리셋 없는 완전 랜덤 CLI)
- **가정(확인됨)**: 어드민 컴포넌트로 재구현(HTML 임베드 아님) · 원본 보관 + WebP 축소본 · 컬러는 UI 디자인 토큰과 별개 · 1차는
  PNG만 서버 생성 · `/jam-img`와 병행하고 제작 경로 값으로 구분 · 배지 배경 제외 · 등록 실행은 항상 메인 세션 · 컬러 방향은 윤진의
  컨텐츠 기획 문서(주간·월간 리포트)에 컨텐츠별로 기록 · 텍스트 글자 내용은 컨텐츠에서 채우고 스타일만 프리셋 · 그라데이션
  시작색은 배경색과 항상 같음 · 그 외 속성은 랜덤이며 시드 기록
- **가정(미확인)**: 홈피드 `today_cards`의 공용 저장 함수 지원 시점(후속 차수 착수 조건) · `shader-lab`의 이미지·텍스트 레이어
  코드가 재사용 가능한 형태인지(착수 시 아현이 확인)
- **열린 질문(나중에 정해도 됨)**: 프리셋 없이 색만 지정하는 완전 랜덤 CLI 모드를 넣을지(혜린 추천: 이번엔 프리셋 기반만) ·
  기존 `/jam-img` 배지의 제작 경로 소급 채우기 · 미션·컬렉션 프리셋 착수 시점(배지 1종 운영 결과 뒤)
- **검토한 대안**: 프로토타입 HTML을 어드민에 그대로 끼워 넣기(기각, 어드민 컴포넌트 일관성) · 윤진에게 등록 도구 부여(기각,
  CLAUDE.md 6항 충돌·승인 관문이 도구에 의존) · 배지·미션·컬렉션·홈피드 동시 착수(기각, 범위 과다) · 컬러 방향성 고정 표 문서
  (기각, 사용자가 컨텐츠 기획 문서 기록 방식 선택) · `shader-lab`에 레이어로 통합(기각, 사용자가 별도 도구 확장을 지시)
- **판단**: 만들자. 배지 1종·수동+자동 두 경로를 좁게 끝까지 검증한 뒤 미션·컬렉션·홈피드로 넓힌다.

## 리스크 (JAM 전용 점검)

- 세계관 충돌: 컬러 방향이 컨텐츠별 기획 문서에만 기록되어 트라이브 색 일관성 기준이 시간이 지나며 흔들릴 수 있다 → 윈터가 매
  컨펌 건을 검수하고, 반복되는 판단 기준이 보이면 표로 승격할지 재검토.
- 유저가 학습한 규칙 변경: 배지 대표 이미지가 세 경로로 섞여 스타일이 달라 보일 수 있다 → 제작 경로 라벨(성공 기준 5)로 운영자가
  원인을 바로 추적.
- 운영 부담: 컨펌 때 이미지까지 판단해 검토 시간이 늘 수 있다(별도 승인 단계는 없어져 접점 수는 줄어듦) → 1차 운영 뒤 카즈하에게
  컨펌 소요 시간 실측 요청. 미검증.
- 비용: 등록 실행은 메인 세션으로 제한. 이미지 생성 재시도가 서버 연산 비용에 미치는 영향은 미검증 → 1차 운영 후 실측.
- 외부 의존: 서버 렌더링용 캔버스 라이브러리와 WebP 변환 라이브러리 추가 여부는 하위 티켓 2155·2200의 승인 항목.
