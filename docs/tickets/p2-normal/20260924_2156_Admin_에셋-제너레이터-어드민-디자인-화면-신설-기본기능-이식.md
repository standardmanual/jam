# [Admin] 에셋 제너레이터 어드민 "디자인" 화면 신설 + 프로토타입 기본 기능 이식

## 핵심 요약

- 요구사항: 어드민 "디자인" 메뉴 묶음에 `에셋 제너레이터` 화면을 추가하고, 프로토타입의 기능(스테이지 비율·배경색·원천 그래픽
  선택/업로드·크기·블러·회전·진행 방향 회전·그라데이션·곡선 불규칙성·다시 뽑기·속도·복사 간격·복사 수·전체 랜덤·재생/정지·머리
  위치·PNG 저장·영상 저장)을 어드민 컴포넌트로 동등하게 옮긴다. PRD §3·§4.1.
- 구현 계획: 2155의 공용 모듈을 쓰는 클라이언트 화면. 설정 패널은 프로토타입의 접기·펼치기 섹션 구조와 한 줄 행(레이블·슬라이더·값)
  정렬을 어드민 디자인시스템(shadcn 기반) 컴포넌트로 옮긴다. `shader-lab`은 참고만 하고 수정하지 않는다.
- 관련 파일: `jam-web/src/components/admin/adminNavItems.ts`("디자인" 묶음에 항목 추가, 테스트 `__tests__/adminNavItems.test.ts`
  갱신), 신규 `jam-web/src/app/admin/asset-generator/`(page·layout·Viewport·PropertiesPanel·ExportPanel), `jam-web/src/lib/asset-generator/`
  (2155), 참고 `jam-web/src/app/admin/shader-lab/`(레이아웃·WebGPU 게이트·내보내기 패널 구조)

## 배경 / 문제 정의

프로토타입은 `jam-doc/assets/prototypes/`의 단일 HTML이라 로그인·권한·배지 검색·적용과 연결되지 않는다. 어드민 화면이 있어야
프리셋(2159)·적용(2200)을 붙일 수 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 라우트 `/admin/asset-generator`. 어드민 권한 게이트는 기존 어드민 화면과 같은 방식.
- 설정 패널의 속성 목록·기본값·범위는 프로토타입과 같다(속도 1000~2000px/s, 복사 수 200~800, 불규칙성 0~100 등).
- 영상 저장은 프로토타입과 같이 브라우저에서만(WebCodecs 정밀 인코딩, 미지원 시 실시간 녹화 대체). MP4 묶음 라이브러리는 프로토타입과
  같은 버전·무결성 해시로 불러온다.
- 화면 높이: 설정 패널이 스테이지보다 세로로 커지지 않는다(프로토타입의 높이 묶기 규칙 유지).

### UI/UX 관점
- 채원 사전 판정(①) 대상: 신규 화면. 프로토타입의 섹션 구성과 한 줄 행 정렬을 유지하되 어드민 디자인시스템 토큰·컴포넌트를 쓴다.
  프로토타입 전용 CSS를 그대로 복사하지 않는다.
- 사용자 노출 문구는 `docs/specs/UX_WRITING_GUIDELINE.md`를 따른다(해요체, 고정 용어).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 어드민 "디자인" 묶음에 `에셋 제너레이터`가 보이고 `/admin/asset-generator`가 어드민 권한으로 열린다.
- 프로토타입의 속성 전부가 같은 범위·기본값으로 동작하고, 전체 랜덤·재생/정지·머리 위치·PNG 저장·영상 저장(2초 입력 시 60fps
  120프레임 MP4)이 동작한다.
- 같은 시드·같은 설정에서 프로토타입과 같은 곡선·같은 스탬프 위치가 나온다(비교 스크립트 또는 테스트).
- 설정 패널 높이가 스테이지 높이를 넘지 않는다(1280×800 창 기준). **카리나 실렌더, 머지 뒤**(격리 워크트리에서는 확인 불가, 게이트 판정 대상에서 제외).
- `shader-lab` 파일 변경 없음. `npm run lint`·`npm test` 통과.
