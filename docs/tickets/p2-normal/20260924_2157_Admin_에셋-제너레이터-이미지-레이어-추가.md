# [Admin] 에셋 제너레이터 이미지 레이어 추가

## 핵심 요약

- 요구사항: 리본 레이어 위(또는 아래)에 업로드한 PNG/SVG를 고정 레이어로 얹는 이미지 레이어를 추가한다. 위치·크기는 스테이지
  비율(%)로, 회전·불투명도·순서를 조절한다. PRD §4.2.
- 구현 계획: 2155의 레이어 합성 훅에 이미지 레이어 렌더러를 구현하고, 2156 화면에 레이어 목록(추가·순서·삭제)과 이미지 레이어
  속성 패널을 붙인다. `shader-lab`의 이미지 레이어 사용감(업로드·위치·크기)을 참고하되 코드는 수정하지 않는다.
- 관련 파일: `jam-web/src/lib/asset-generator/render.ts`(레이어 합성 훅), `types.ts`(이미지 레이어 타입), `jam-web/src/app/admin/asset-generator/`
  (레이어 사이드바·속성 패널 신규 컴포넌트), 참고 `jam-web/src/app/admin/shader-lab/ShaderLabLayerSidebar.tsx`·`ShaderLabPropertiesPanel.tsx`

## 배경 / 문제 정의

배지 대표 이미지는 리본 그래픽 위에 아이콘(`/jam-img` 산출물 등)을 얹어 완성한다. 프리셋의 "아이콘 이미지 자리"가 이 레이어다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 레이어 목록: 리본 레이어(고정 1개, 삭제 불가) + 이미지 레이어 0~N. 위/아래 순서 변경.
- 이미지 레이어 속성: 원본(업로드, 화면에서는 메모리 보관 — 저장소 업로드는 2159), 위치 x·y(%), 크기(짧은 변 대비 %), 회전(°),
  불투명도(%), 순서.
- 렌더링은 리본 장면 위에 합성한다. 재생 중에도 고정 위치에 그대로 있다(곡선을 따라 움직이지 않는다).
- PNG·영상 저장 결과에 이미지 레이어가 포함된다.

### UI/UX 관점
- 레이어 사이드바와 속성 패널은 기존 설정 패널의 섹션 규칙(접기·펼치기, 한 줄 행)을 따른다.

## 구현 계획 (파일 단위)

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 이미지 레이어를 추가해 PNG/SVG를 올리면 리본 위에 고정으로 표시되고, 위치·크기·회전·불투명도·순서 변경이 즉시 반영된다.
- 스테이지 비율을 바꿔도 이미지의 상대 위치·크기가 유지된다.
- PNG 저장 결과에 이미지 레이어가 포함된다(저장 파일 픽셀 확인).
- `shader-lab` 파일 변경 없음. `npm run lint`·`npm test` 통과.
