# [Admin] 에셋 제너레이터 배지 적용 흐름 + 제작 경로 표시 + 출력 규격 최적화(WebP)

## 핵심 요약

- 요구사항: 어드민 화면의 적용 탭에서 배지를 검색·필터·미리보기한 뒤 적용하면, 원본 PNG를 보관하고 서비스 표시 크기에 맞는 WebP
  축소본을 만들어 `badges.image_url`에 반영하고 제작 경로 값(`admin-generator`)을 기록한다. 배지 목록·상세에 제작 경로 라벨을 보여 준다.
  PRD §7·§9·§10·§12.
- 구현 계획: `badges.image_source` 컬럼 마이그레이션 **파일 작성**(실행은 승인 후 메인 세션). 적용 API는 공용 `applyGeneratedImage`
  관례(도구별 폴더, 5MB 제한)를 따르되 WebP 변환·원본 보관·경로 기록을 더한 새 라우트로 만든다(공용 함수의 시그니처를 바꾸지 않는다).
  배지 검색·필터·목록은 `/api/admin/badges/search`와 어드민 목록 테이블 공통 컴포넌트(20260924_0916)를 재사용한다.
- 관련 파일: `jam-web/supabase/migrations/<다음번호>_badges_image_source.sql`(신규), `jam-web/src/app/api/admin/asset-generator/apply/route.ts`
  (신규), `jam-web/src/lib/admin/applyGeneratedImage.ts`(참고·재사용), `jam-web/src/app/admin/asset-generator/ApplyTab.tsx`(신규),
  배지 목록·상세 화면(`jam-web/src/app/admin/badges/`)에 라벨 추가, 서비스 배지 표시 컴포넌트(실제 표시 크기 실측 대상)

## 배경 / 문제 정의

기존 공용 저장 함수는 PNG를 크기 변환 없이 그대로 올린다(`shader-lab` 1920×1920). 서비스 화면에는 표시 크기에 맞는 축소본이 필요하고,
세 제작 경로가 섞이면 스타일 차이의 원인을 화면에서 추적할 수 있어야 한다(사용자 결정 2·7).

## 상세 요구사항

### 서비스/코드베이스 관점
- 컬럼 `badges.image_source text NULL CHECK (image_source IN ('admin-generator','agent-generator','jam-img'))`. 기존 행은 NULL(미상).
  되돌림 SQL 포함.
- 적용 API: 입력은 배지 id + PNG(원본 1280×1280). 처리: 원본을 `badges/asset-generator/{id}.png`에 보관 → 표시 규격으로 축소한 WebP를
  `badges/asset-generator/{id}.webp`에 저장 → `image_url`은 WebP, `image_source = 'admin-generator'`. 5MB 상한.
- 표시 규격: 서비스에서 배지 대표 이미지가 그려지는 컴포넌트의 실제 표시 크기를 실측해 "표시 크기 × 2" 이하로 정하고, 수치를 PRD §9와
  이 티켓 완료 기록에 남긴다.
- WebP 변환 라이브러리: 저장소에 `sharp`가 이미 있으면 재사용, 없으면 추가는 **승인 항목**.
- 배지 목록·상세: 제작 경로 라벨(수동 제작 / 윤진 자동 / 아이콘 파이프라인 / 미상) 표시. 검색 필터에 제작 경로 조건을 추가한다.

### UI/UX 관점
- 채원 사전 판정(①) 대상: 적용 탭(검색·필터·미리보기·적용)과 배지 목록 라벨. 목록 테이블 공통 컴포넌트를 재사용하고 새 표를 만들지 않는다.
- 적용은 되돌리기 어려우므로 확인 단계와 결과 안내(어느 배지에 반영됐는지)를 둔다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 마이그레이션 파일이 작성되어 있다(되돌림 포함). **실행은 완료 조건에 넣지 않는다.**
- 적용 탭에서 배지를 검색·선택·미리보기한 뒤 적용하면 저장소에 원본 PNG와 WebP가 모두 생기고, `image_url`이 WebP를 가리키며
  `image_source`가 `admin-generator`로 기록된다(테스트 배지 1건으로 확인).
- WebP의 긴 변이 실측한 표시 규격 이하이고, 실측 수치가 완료 기록에 적혀 있다.
- 배지 목록·상세에 제작 경로 라벨이 보이고 필터가 동작한다.
- `npm run lint`·`npm test` 통과.

### 후속 범위 (담당: 카리나, 시점: 게이트 통과 뒤)
- 사용자 승인 후 메인 세션이 마이그레이션을 실행하고 `02_DATA_MODEL.md`·PRD §9 규격 수치를 갱신한다.
- `/jam-img`의 `register-badge-images.js`에 `image_source = 'jam-img'` 기록을 추가하는 후속 티켓을 만든다.
