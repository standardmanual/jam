# [Infra] 에셋 제너레이터 에이전트 CLI — 프리셋 + 컬러 + 텍스트 → PNG, 시드 기록

## 핵심 요약

- 요구사항: 에이전트(윤진)가 브라우저 없이 호출하는 명령을 만든다. 입력은 프리셋 ID·배경색·그라데이션 끝색·텍스트 내용·(선택) 시드.
  그라데이션 시작색은 배경색과 같고, 나머지 리본 속성은 전체 랜덤 규칙으로 채운다. 출력은 PNG 파일과 시드. 같은 시드면 같은 이미지.
  PRD §8·§11.
- 구현 계획: 2155의 공용 모듈에 서버 캔버스(승인된 라이브러리)와 글꼴 로더를 주입해 렌더링한다. 프리셋은 DB에서 읽고 이미지 원본은
  저장소에서 내려받는다. 기존 CLI 관례(`jam-web/scripts/recraft/*.js`: Node, 절대 경로 인자, 환경변수)를 따른다.
- 관련 파일: 신규 `jam-web/scripts/asset-generator/render.mjs`, `jam-web/src/lib/asset-generator/`(2155), 참고 `jam-web/scripts/recraft/generate-batch.js`
  (인자·환경변수 관례), `jam-web/src/lib/admin/shaderLab/googleFonts.ts`(글꼴 식별자 → 서버 폰트 파일 매핑 근거)

## 배경 / 문제 정의

자동 경로의 첫 단계다. 윤진이 컨펌 자료에 넣을 이미지를 어드민 화면 없이 만들 수 있어야 한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 명령 예: `node jam-web/scripts/asset-generator/render.mjs --preset <id> --bg "#ff1a00" --end "#ff4dff" --text "배지 이름" --out <절대경로.png> [--seed 123]`.
  결과로 저장 경로와 시드를 표준 출력(JSON)으로 낸다.
- 시드가 없으면 새로 뽑고, 있으면 그대로 써서 어드민 화면과 같은 결과가 나온다(곡선·스탬프 위치 동일).
- 글꼴: 프리셋의 글꼴 식별자에 해당하는 구글 폰트 파일을 내려받아 캐시하고 서버 캔버스에 등록한다. 내려받기 실패 시 오류로 중단하고
  기본 글꼴로 대체하지 않는다(컨펌 자료가 어드민과 달라지는 것을 막기 위함).
- 출력 규격은 프리셋의 스테이지 비율, 긴 변 1280(원본). 축소본은 등록 스크립트(2202)가 만든다.
- 환경변수: Supabase 서비스 키 등은 기존 스크립트와 같은 이름을 쓴다. 키가 없으면 안내 문구와 함께 종료.

## 구현 계획 (파일 단위)

| 파일 | 할 일 |
|---|---|
| `jam-web/scripts/asset-generator/render.mjs` (신규) | 인자 파싱·프리셋 조회·이미지 내려받기·렌더링·PNG 저장·시드 출력 |
| `jam-web/scripts/asset-generator/fonts.mjs` (신규) | 구글 폰트 파일 내려받기·캐시·등록 |
| `jam-web/src/lib/asset-generator/render.ts` | 서버 캔버스 주입 경로 보강(필요 시) |

체크포인트: 서버 캔버스 라이브러리는 2155의 승인 결과를 따른다. 승인 전에는 이 티켓을 시작하지 않는다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 어드민에서 저장한 배지 프리셋으로 명령을 실행하면 PNG와 시드가 나온다.
- 같은 프리셋·색·텍스트·시드로 어드민 화면에서 만든 PNG와 곡선·스탬프 위치·텍스트 위치가 같다(비교 스크립트로 확인, 블러·리샘플링
  미세 차이만 허용).
- 시드를 바꾸면 다른 리본이 나오고 시드를 같게 하면 같은 리본이 나온다.
- 글꼴 내려받기 실패 시 기본 글꼴로 대체하지 않고 오류로 종료한다.
- `npm run lint`·`npm test` 통과.
