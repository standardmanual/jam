# [Infra] 윤진(jam-marketer) 에이전트 정의 갱신 — 배지 이미지 자동 제작과 등록 묶음 준비 역할

## 핵심 요약

- 요구사항: 윤진의 정의에 "배지 프리셋을 골라 채원·윈터가 제시한 색과 배지 텍스트로 CLI(2201)를 실행해 이미지를 만들고, 등록 묶음
  (2202 형식)을 준비해 사용자 컨펌 자료로 올린다"는 절차를 추가한다. 컨텐츠 기획 문서(주간·월간 리포트)에 컨텐츠별 배경색·끝색과 선택
  근거를 적는 규칙도 넣는다. PRD §6·§8.
- 구현 계획: `.claude/agents/jam-marketer.md`(영어 정의, 출력은 한국어)의 Modes 표와 절차에 항목 추가. "초안만 만들고 발행하지
  않는다" 원칙은 그대로 두고, CLI 실행(파일 생성)은 발행이 아님을 명시한다. 등록은 여전히 하지 않는다.
- 관련 파일: `.claude/agents/jam-marketer.md`, `docs/agents/team-operations.md`(권한·접근 범위 표에 CLI 실행 추가 — 생성 구간이면
  `node scripts/gen-team-doc.mjs`로 갱신), `.claude/skills/jam-work/references/scheduled-jobs.md`(주간 루틴에 이미지 제작 단계가
  들어가면 여기도 갱신)

## 배경 / 문제 정의

윤진은 현재 읽기·검색 도구만 있고 이미지·컬러 역할이 없다(2026-09-24 조사). 자동 경로가 돌아가려면 정의에 절차와 도구 사용 범위가
있어야 한다. 에이전트 정의 변경은 사용자 명시 승인 사항이다(`/jam-plan` 규칙).

## 상세 요구사항

### 서비스/코드베이스 관점
- 추가할 절차: (1) 컨텐츠 기획 시 배경색·끝색을 채원·윈터의 제시를 받아 정하고 기획 문서에 근거와 함께 적는다 (2) 프리셋 선택 (3) CLI
  실행으로 PNG·시드 생성 (4) 등록 묶음 작성 (5) 컨펌 요청에 기획안과 이미지를 함께 첨부. 등록은 하지 않는다.
- 도구: Bash 실행 권한이 필요하다(CLI). 허용 범위를 `jam-web/scripts/asset-generator/render.mjs`로 한정하는 방법을 정의에 적는다.
- 슬랙 안내 형식이 있으면(2252 PRD §8-1) 이미지 첨부 방식을 함께 정한다.
