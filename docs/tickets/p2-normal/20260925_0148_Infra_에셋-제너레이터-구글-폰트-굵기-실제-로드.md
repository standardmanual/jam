# [Infra] 에셋 제너레이터 텍스트 레이어의 구글 폰트 굵기를 실제 파일로 불러온다 (합성 볼드 제거)

> 티켓 20260924_2158 게이트 리뷰에서 민지가 낸 범위 밖 발견물(`[참고]`, 아현 alerts와 동일)을 3.2절대로 자동 티켓화했다.
> 참고 신호의 기본값은 P3이지만, 브라우저(합성 볼드)와 서버 렌더링 2201(실제 700 파일)의 결과가 달라져 "컨펌한 이미지 =
> 등록되는 이미지"(PRD §11 재현성)를 깨뜨릴 수 있어 P2로 올렸다.

## 핵심 요약

- 요구사항: 텍스트 레이어 글꼴 식별자는 `{ family, weight }`인데, 브라우저 로더가 재사용하는
  `jam-web/src/lib/admin/shaderLab/googleFonts.ts`의 `ensureGoogleFontLoaded`는 항상 굵기 400 스타일시트만 요청한다. 굵기를
  700 등으로 바꾸면 실제 파일이 없어 브라우저가 합성 볼드로 대체한다. 지정한 굵기의 실제 파일을 로드해 미리보기·저장 결과가
  서버 렌더링과 같은 글꼴 파일을 쓰게 한다.
- 구현 계획: 두 안 중 하나. (a) `googleFonts.ts`에 굵기 인자를 받는 함수를 **추가**한다(기존 함수 시그니처·shader-lab 동작은
  그대로 둠). (b) 에셋 제너레이터 쪽 브라우저 로더(`AssetGeneratorViewport.tsx`의 `loadFontInBrowser`)가 `buildGoogleFontCssUrl`
  대신 굵기를 포함한 CSS URL을 직접 만든다. 2158 완료 조건이 `googleFonts.ts` 무수정이었던 이유는 shader-lab 회귀 방지였으므로,
  (a)로 가더라도 기존 함수는 건드리지 않는다.
- 관련 파일: `jam-web/src/lib/admin/shaderLab/googleFonts.ts`(`buildGoogleFontCssUrl` 44줄, `ensureGoogleFontLoaded` 56줄,
  `waitForGoogleFontLoaded` 88줄 — 굵기 400 고정 지점), `jam-web/src/app/admin/asset-generator/AssetGeneratorViewport.tsx`
  (`loadFontInBrowser`, 폰트 로드 대기 `waitForFonts`), `jam-web/src/app/admin/asset-generator/TextLayerFields.tsx`(굵기 선택),
  `docs/specs/prd/asset-generator/PRD.md` §4.3

## 배경 / 문제 정의

2158은 shader-lab의 구글 폰트 모듈을 수정 없이 재사용하는 조건으로 텍스트 레이어를 구현했다. 그 모듈은 shader-lab 용도(굵기
400~900을 가변 폰트 CSS 변수로 처리)에 맞춰 400 스타일시트만 요청한다. 텍스트 레이어는 `ctx.font`에 굵기를 직접 넣으므로 실제
파일이 없으면 브라우저가 합성 볼드를 그린다. 서버 렌더링(2201)은 식별자대로 실제 굵기 파일을 등록할 예정이라 두 결과가 달라진다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 텍스트 레이어가 고른 굵기의 실제 폰트 파일(Google Fonts CSS2 `wght@<weight>` 또는 가변 축 범위)을 로드한다.
- 로드 대기(`waitForFonts`)와 실패 감지(`document.fonts.check`)가 굵기까지 포함해 판정한다.
- shader-lab 화면의 폰트 동작은 바뀌지 않는다(회귀 테스트 또는 diff로 확인).

## 구현 계획
1. 굵기 인자를 받는 로더를 추가하거나 에셋 제너레이터 쪽 로더가 굵기 포함 URL을 만든다.
2. `waitForFonts`·실패 감지가 굵기를 반영하도록 고친다.
3. 카리나 실렌더(머지 뒤)에서 굵기 700 텍스트를 넣고 `document.fonts`에 해당 굵기 FontFace가 로드됐는지 확인한다.

## 완료 조건
- 텍스트 레이어에서 굵기 700을 고르면 `document.fonts`에 그 패밀리의 700 FontFace가 `loaded` 상태로 존재한다(카리나 실렌더, 머지 뒤).
- shader-lab의 텍스트 레이어 폰트 동작이 바뀌지 않는다. `npm run lint`·`npm test` 통과.
