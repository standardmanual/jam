# [Feature] 에셋 제너레이터 2차 — 미션·컬렉션·홈피드 확장 + 윤진 신규 기획 자동 경로 (상위 티켓)

> `/jam-plan` 2단계 기획서를 사용자가 2026-09-25에 승인해 만든 상위 티켓이다. 1차(배지 프리셋
> 1종, [20260924_2154](20260924_2154_Feature_배지-대표이미지-제작도구-확장-JAM-에셋-제너레이터-1단계-상위.md))가
> 검증한 제작·적용·경로표시 틀을 미션·컬렉션·홈피드로 넓히고, 윤진이 정기(주간·월간) 산출물에서
> 신규 배지·미션·홈피드 콘텐츠를 기획안+이미지까지 함께 제안하는 자동 경로를 새로 연다. 기획
> 담당 혜린, 구현 아현, 사전·사후 판정 채원, 마케팅 윤진, 세계관 검수 윈터.

## 핵심 요약

- 요구사항: 적용 탭에 콘텐츠 유형(배지/미션/컬렉션/홈피드) 선택을 넣어 3종에도 검색·필터·미리보기·적용을
  지원하고, 3종 각각 프리셋을 저장할 수 있게 한다. 배지·미션·주간 홈피드는 윤진이 정기 산출물에서
  신규 콘텐츠(이름+설명+이미지+시드)를 기획해 등록 묶음으로 준비 → 사용자 컨펌 → 메인 세션 등록까지
  자동 경로를 연다. 컬렉션은 100개 고정 카탈로그라 신규 기획 없이 기존 레코드에 이미지만 적용한다.
- 구현 계획: 하위 티켓 11개를 프리셋 대상 확장 → 3종 프리셋·적용 탭(병행 가능) → 등록 묶음·스크립트
  (미션·홈피드) → 에이전트 정의 갱신(윤진, 채원·윈터) 순으로 진행한다. `render.mjs`는 코드 확인 결과
  `target_type`을 가리지 않고 프리셋 id로만 동작해 신규 CLI가 필요 없다. DB 변경은 파일 작성까지
  하위 티켓에서, 실행은 승인 후 메인 세션.
- 관련 파일: `docs/specs/prd/asset-generator/PRD.md`, `jam-web/src/app/admin/asset-generator/ApplyTab.tsx`,
  `jam-web/src/lib/admin/badgeImageSource.ts`, `jam-web/scripts/asset-generator/register-badge.mjs`,
  `.claude/agents/jam-marketer.md`, `.claude/agents/jam-designer.md`, `.claude/agents/jam-tribe.md`

## 배경 / 문제 정의

1차 완료(2026-09-25) 뒤 어드민 "적용" 도구는 배지 하나에만 쓸 수 있어, 미션·컬렉션·홈피드는
여전히 이미지 없이 나가거나 디자이너 리소스에 기댄다. 또한 윤진 정의(`jam-marketer.md` 결정
4-9)는 "제안은 세션에서만, 예약 실행에서는 절대 하지 않는다"는 원칙이라, 정기 리포트(주간·월간)는
소재만 모을 뿐 신규 콘텐츠 기획은 사람이 매번 세션을 열어야 나온다 — 정기 발행 리듬이 끊긴다.

## 기획서 (혜린, 2026-09-25 승인)

- **대상**: 어드민 사용자(적용 도구 확장 수혜) · 윤진(신규 기획+이미지 자동 제안, 주간·월간 정기
  산출물) · 사용자 본인(기획안+이미지 컨펌) · 메인 세션(컨펌 후 등록 실행) · 채원·윈터(컨텐츠 단위
  컬러 방향 제시·세계관 검수)
- **성공 기준(측정 가능)**
  1. 어드민 적용 탭 콘텐츠 유형 드롭다운으로 배지/미션/컬렉션/홈피드를 전환해 각각 검색·필터·
     미리보기·적용할 수 있다
  2. 미션·컬렉션·홈피드 각각 이미지+텍스트 레이어를 갖춘 프리셋을 최소 1종씩 저장·불러올 수 있다
  3. 미션·컬렉션·홈피드 이미지 적용 시 원본 PNG 보관 + 400px(임시 규격, 디자인 리뉴얼 전까지) WebP
     축소본이 자동 생성되어 반영된다
  4. 미션·홈피드 목록·상세에 제작 경로 라벨(수동 제작/윤진 자동/미상)이 배지와 같은 패턴으로
     보인다(공용 모듈로 일반화). 컬렉션은 자동 기획 경로가 없어 라벨 값은 `admin-generator`/미상만
  5. 윤진이 신규 배지·미션·홈피드 기획안(이름·설명+이미지+시드, 트렌드·지표 근거)을 등록 묶음
     파일로 준비하면, 사용자가 기획안+이미지를 한 번에 컨펌한 뒤 메인 세션이 콘텐츠별 등록
     스크립트를 실행해 콘텐츠와 이미지가 함께 등록된다(배지는 기존 스크립트 재사용, 미션·홈피드는
     신규 스크립트)
  6. 세계관과 닿는 신규 기획안은 윈터 검수를 거친 기록이 등록 묶음에 남고, 순수 운영성 콘텐츠는
     검수 없이 진행된 기록이 남는다
  7. 윤진 에이전트 정의가 "정기 산출물에서 신규 배지·미션·홈피드 기획+이미지 제안"을 허용하도록
     갱신되고, 등록 실행은 여전히 하지 않는다(Forbidden 유지)
- **범위**: `asset_presets.target_type` 확장(badge/mission/collection/home_feed) · 3종 프리셋
  저장·불러오기 · 적용 탭 콘텐츠 유형 확장 · 3종 `image_source` 신설 및 라벨·필터 · 미션·홈피드
  등록 묶음·등록 스크립트 신설 · 윤진·채원·윈터 에이전트 정의 갱신(승인 완료 항목)
- **하지 않을 것**: 컬렉션 신규 기획(100개 고정 카탈로그) · 경제 수치(드랍 확률·포인트) 조정(별도
  기획 예정) · 3종 이미지 규격 정식 실측(디자인 리뉴얼 때, 지금은 400px 임시 확정) · 기존 컨텐츠
  자동화 파이프라인(20260923_2252)과의 통합(별도 신설) · 뉴스레터(윤진 모드 ⑦, 계속 꺼둠) ·
  `shader-lab` 배경 저작 기능 흡수(별도 하위 티켓 20260925_1416에서 제거만 함, 대체는 후속 차수)
- **가정(확인됨)**: 3종 400px WebP 임시 규격(디자인 리뉴얼 전까지) · `render.mjs`는 프리셋 id로만
  조회해 `target_type` 필터 없이 그대로 재사용 가능(코드 확인, `render.mjs` 99행) · 미션 어드민
  API가 검증 함수를 갖추고 있어 등록 스크립트가 재사용 가능(코드 확인, 실제 재사용 여부는 착수 시
  아현이 재확인) · 등록 실행은 항상 메인 세션(CLAUDE.md 6항) · 컬러 방향은 계속 윤진의 컨텐츠
  기획 문서에 기록 · 트렌드 근거 검증은 별도 관문 없이 사용자의 컨펌 단계가 겸함
- **가정(미확인)**: `today_cards` 신규 기획 등록 스크립트와 기존 주간 편성 seed SQL 파이프라인이
  실제 운영에서 혼동 없이 구분되는지(1차 운영 후 실측) · 정기 산출물 컨펌 빈도 증가가 실제 검토
  시간에 미치는 영향(카즈하 실측 필요)
- **열린 질문(나중에 정해도 됨)**: 미션·홈피드 등록 묶음 형식을 `REGISTRATION_BUNDLE.md`에 절
  추가로 확장할지 별도 파일로 분리할지(혜린 추천: 분리 — 필드가 크게 달라 한 문서면 추적이
  어려움) · 컬렉션 자동화 착수 시점(미션·홈피드 운영 결과 뒤) · 기존 `/jam-img` 배지 제작 경로
  소급 채우기(1차부터 이어진 질문)
- **검토한 대안**: 3종을 각각 별도 상위 티켓으로 쪼개기(기각, 1차와 같은 틀 재사용이라 경계가
  얕음) · 기존 컨텐츠 자동화 파이프라인에 신규 기획 기능을 얹기(기각, 그 파이프라인은 "기존 활성
  컨텐츠 추천·편성" 전용) · 홈피드 신규 기획도 기존 seed SQL만 재사용(기각, 기획안 검증·되돌림
  기록·컨펌 자료가 없음) · 미션·홈피드용 CLI 별도 신설(기각, 코드 확인 결과 불필요) · 자동 경로를
  열지 않고 세션 전용 유지(기각, 사용자가 에이전트 정의 변경을 명시 승인했고 정기 리듬 유지가
  핵심 목적)
- **판단**: 만들자. 1차가 좁게 끝까지 검증됐고 재사용 가능한 공용 모듈이 이미 있다. 정책 충돌
  (윤진 에이전트 정의)도 사용자가 이미 풀었다.

## 리스크 (JAM 전용 점검)

- 세계관 충돌: 윤진이 매번 "세계관과 닿는지" 판단해야 해 경계가 흔들릴 수 있다 → 등록 묶음에
  "윈터 검수 여부/사유" 필드를 남겨 사후 추적.
- 유저가 학습한 규칙 변경: 홈피드 카드 등록 경로가 두 갈래(기존 주간 편성 seed SQL / 신규 기획
  등록 스크립트)로 병존해 운영자가 카드 출처를 혼동할 위험 → `today_cards.image_source`(구분값)로
  라벨 구분, 어드민 목록 노출.
- 운영 부담: 컨펌 대상이 배지 하나에서 배지+미션+홈피드 세 갈래로 늘어 검토 시간이 늘 수 있다 →
  미검증. 1차 운영 뒤 카즈하에게 컨펌 소요 시간 실측 요청.
- 경제: 범위 밖(결정, 별도 기획 예정). 신규 배지·미션 정기 발행이 드랍 확률·보상 총량에 미치는
  영향은 측정하지 않는다.
- 출력 규격: 미션 상세(`w-full aspect-square`)·홈피드 카드(`aspect-[16/9]`·`aspect-[4/5]`)는
  화면 폭에 비례해 늘어나는 레이아웃이라 400px 원본이 실측 없이 확대돼 흐려 보일 위험이 있다 —
  **미검증**, 디자인 리뉴얼 때 정식 실측 예정. 컬렉션(200×200 고정)은 배지와 동일해 리스크 낮음.
- 외부 의존·비용: 추가 외부 의존 없음(기존 CLI·`@napi-rs/canvas`·구글 폰트 재사용). 정기 산출물
  이미지 생성·등록 스크립트 실행 빈도 증가의 서버 연산 비용 영향은 미검증 — 1차 운영 후 실측.
