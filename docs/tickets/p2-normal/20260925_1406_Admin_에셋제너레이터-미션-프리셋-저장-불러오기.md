# [Admin] 에셋 제너레이터 미션 프리셋 저장·불러오기

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 2번. 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: 대상 유형이 `mission`인 프리셋을 이미지 레이어·텍스트 레이어와 함께 저장·불러오기·
  삭제할 수 있다. 저장·불러오기·삭제 메커니즘 자체는 배지 프리셋(하위 티켓 20260924_2159)과 동일—
  대상 유형만 `mission`으로 다르다.
- 구현 계획: 20260925_1405가 만든 유형 선택 UI에서 `mission`을 고르면 배지 프리셋과 같은 저장·
  불러오기·삭제 흐름을 쓴다. 배지 프리셋 코드와 분기 없이 공유되도록 한다(유형별 별도 컴포넌트를
  새로 만들지 않는다).
- 관련 파일: `jam-web/src/app/admin/asset-generator/PresetPanel.tsx`,
  `jam-web/src/app/api/admin/asset-generator/presets/route.ts`·`[id]/route.ts`

## 배경 / 문제 정의

상위 티켓 결정 1·2: 미션·컬렉션·홈피드 확장을 한 번에 진행하고, 유형별 별도 프리셋으로 나눈다.
이 티켓은 미션 쪽 저장·불러오기를 배지 프리셋 메커니즘 그대로 검증한다.

## 완료 조건
- 미션 대상 프리셋을 이미지 레이어 1개 이상 + 텍스트 레이어 1개 이상으로 저장할 수 있다.
- 저장한 프리셋을 불러오면 레이어 구성이 그대로 복원된다.
- 프리셋 목록·삭제가 `target_type='mission'`으로 필터링된 상태에서 정상 동작한다(다른 유형
  프리셋과 섞이지 않는다).
- `scripts/verify.sh` 통과.
