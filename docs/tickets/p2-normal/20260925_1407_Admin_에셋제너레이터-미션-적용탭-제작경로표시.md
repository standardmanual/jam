# [Admin] 에셋 제너레이터 미션 적용 탭·제작 경로 표시

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 3번. 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: 어드민 "적용" 탭에 콘텐츠 유형 선택 드롭다운을 추가하고(상위 티켓 결정 5), 미션을
  고르면 미션 검색·필터·미리보기 후 적용 버튼으로 그 미션의 `image_url`에 반영할 수 있다. 적용 시
  원본 PNG 보관 + 400px(임시 규격) WebP 축소본 자동 생성. `missions.image_source` 컬럼을 신설해
  목록·상세에 제작 경로 라벨·필터를 넣는다.
- 구현 계획: `missions.image_source text NULL` + CHECK(`admin-generator`·`agent-generator`) 마이그레이션
  파일 작성(실행은 승인 후 메인 세션). `badgeImageSource.ts`를 공용 모듈(예: `contentImageSource.ts`)로
  일반화해 배지·미션이 함께 쓰게 한다. 적용 API는 `/api/admin/asset-generator/apply`를 콘텐츠 유형
  파라미터로 확장하거나 유형별 분기를 추가한다(배지 적용 API의 원본+WebP 업로드 로직 재사용).
  미션 검색 컴포넌트는 미션 목록 화면의 기존 검색·필터를 재사용하거나 새로 만든다.
- 관련 파일: `jam-web/src/app/admin/asset-generator/ApplyTab.tsx`,
  `jam-web/src/app/api/admin/asset-generator/apply/route.ts`, `jam-web/src/lib/admin/badgeImageSource.ts`,
  `jam-web/src/lib/admin/badgeImageWebp.ts`, `jam-web/src/app/admin/missions/`(미션 목록·검색 참고)

## 배경 / 문제 정의

상위 티켓 결정 4·5: 3종에도 제작 경로 라벨(수동 제작/윤진 자동/미상)을 넣고, 적용 탭은 유형
드롭다운 하나로 통합한다. 미션은 이 확장의 첫 실제 적용 대상이다.

## 완료 조건
- 적용 탭에서 유형을 "미션"으로 고르면 미션 검색·필터·미리보기가 보이고 적용 버튼이 동작한다.
- 적용 후 `missions.image_url`이 WebP 공개 URL로, `image_source`가 `admin-generator`로 갱신된다.
- 원본 PNG가 저장소에 보관되고 WebP는 배지와 같은 규격(긴 변 400px)이다.
- 미션 목록·상세에 제작 경로 라벨이 보이고, 목록에서 제작 경로로 필터링할 수 있다.
- `scripts/verify.sh` 통과.
