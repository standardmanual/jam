# [Admin] 에셋 제너레이터 미션 적용 탭·제작 경로 표시

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 3번. 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: 어드민 "적용" 탭에 콘텐츠 유형 선택 드롭다운을 추가하고(상위 티켓 결정 5), 미션을
  고르면 미션 검색·필터·미리보기 후 적용 버튼으로 그 미션의 `image_url`에 반영할 수 있다. 적용 시
  원본 PNG 보관 + 400px(임시 규격) WebP 축소본 자동 생성. `missions.image_source` 컬럼을 신설해
  목록·상세에 제작 경로 라벨·필터를 넣는다.
- 구현 계획 (사전 조사 완료, 파일·함수 단위):
  1. `jam-web/supabase/migrations/188_missions_image_source.sql` 신규 작성(실행은 4단계 승인 후
     메인 세션). 순수 확장: `ALTER TABLE missions ADD COLUMN image_source text NULL, ADD
     CONSTRAINT missions_image_source_check CHECK (image_source IN ('admin-generator',
     'agent-generator'))`. `badges.image_source` CHECK(마이그레이션 `186_badges_image_source.sql`)와
     같은 값 어휘를 쓴다.
  2. `src/lib/admin/badgeImageSource.ts`(44줄)를 `src/lib/admin/contentImageSource.ts`로 일반화:
     `BadgeImageSource`→`ContentImageSource`, `BADGE_IMAGE_SOURCES`→`CONTENT_IMAGE_SOURCES`,
     `badgeImageSourceLabel()`→`contentImageSourceLabel()`, `IMAGE_SOURCE_FILTER_OPTIONS`는 이름
     유지. 호출부 3곳(`BadgesFilterBar.tsx:178-185`, `BadgeForm.tsx:46,1243-1248`,
     배지 목록 쿼리 파일의 `imageSource` 파라미터)을 새 이름으로 갱신.
  3. `src/app/api/admin/asset-generator/apply/route.ts`(110줄): `badgeId` 고정 필드(31행)를
     `targetType`(`badge`|`mission`)·`targetId`로 일반화. 테이블명(50·92행 `badges`)·이미지 URL
     컬럼·스토리지 폴더 접두사(66-67행 `badges/`)를 `TARGET_TYPE_CONFIG` 맵으로 분기(이번 티켓은
     `badge`·`mission` 2개 항목만 채움, 92-95행 update에 `image_source: 'admin-generator'` 유지).
     `convertBadgeImageToWebp`(`badgeImageWebp.ts`, 61행 호출)는 수정 없이 그대로 재사용(배지와
     동일 400px 규격, 상위 티켓 결정 4).
  4. `src/app/admin/asset-generator/ApplyTab.tsx`(178줄): 콘텐츠 유형 드롭다운(배지/미션) 추가.
     `handleSelectBadge`(88행)·`handleApply`(93-126행)를 유형별로 분기하거나 제네릭화. 미션
     검색은 새 `MissionSearchSelect`를 만들거나(`BadgeSearchSelect` 패턴 미러링), 기존
     `src/app/admin/missions/MissionFilterBar.tsx`의 검색 부품(`DataTableSearch`)을 재사용.
  5. `src/app/admin/missions/MissionFilterBar.tsx`(93줄): "제작 경로" 필터를
     `BadgesFilterBar.tsx:178-185` 패턴 그대로 추가(`DataTableFacetedFilter` +
     `IMAGE_SOURCE_FILTER_OPTIONS`).
  6. `src/app/admin/missions/MissionForm.tsx`: 상세 화면에 "제작 경로 · {라벨}" 표시를
     `BadgeForm.tsx:1243-1248` 패턴으로 추가.
  7. 미션 목록 서버 쿼리(배지의 `badge-list-query.ts`에 대응하는 파일, 미확인 시 아현이 같은
     디렉터리에서 탐색)에 `imageSource` 파라미터 → `.eq('image_source', ...)` 필터 추가.
- 관련 파일: 위 1~7 목록 참고. 계획 반환 면제(`planOnlyWaiver`) 부여: 카리나가 Explore로 사전
  조사를 마치고 파일 단위 계획을 작성함(2026-09-25).

## 배경 / 문제 정의

상위 티켓 결정 4·5: 3종에도 제작 경로 라벨(수동 제작/윤진 자동/미상)을 넣고, 적용 탭은 유형
드롭다운 하나로 통합한다. 미션은 이 확장의 첫 실제 적용 대상이다.

## 완료 조건
- 적용 탭에서 유형을 "미션"으로 고르면 미션 검색·필터·미리보기가 보이고 적용 버튼이 동작한다.
- 적용 후 `missions.image_url`이 WebP 공개 URL로, `image_source`가 `admin-generator`로 갱신된다.
- 원본 PNG가 저장소에 보관되고 WebP는 배지와 같은 규격(긴 변 400px)이다.
- 미션 목록·상세에 제작 경로 라벨이 보이고, 목록에서 제작 경로로 필터링할 수 있다.
- `scripts/verify.sh` 통과.
