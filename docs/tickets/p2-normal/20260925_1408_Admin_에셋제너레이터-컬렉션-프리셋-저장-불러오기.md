# [Admin] 에셋 제너레이터 컬렉션 프리셋 저장·불러오기

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 4번(1과 선행, 2와 병행 가능). 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: 대상 유형이 `collection`인 프리셋을 이미지·텍스트 레이어와 함께 저장·불러오기·삭제할
  수 있다. 메커니즘은 배지·미션 프리셋과 동일, 대상 유형만 다르다.
- 구현 계획: 20260925_1405의 유형 선택 UI에서 `collection`을 고르면 같은 저장·불러오기·삭제
  흐름을 쓴다.
- 관련 파일: `jam-web/src/app/admin/asset-generator/PresetPanel.tsx`,
  `jam-web/src/app/api/admin/asset-generator/presets/route.ts`·`[id]/route.ts`

## 배경 / 문제 정의

상위 티켓 결정 1·2·6: 컬렉션은 신규 기획 없이 기존 레코드에 이미지만 적용하지만, 프리셋 저장·
불러오기 자체는 배지·미션과 같은 방식으로 지원한다.

## 완료 조건
- 컬렉션 대상 프리셋을 이미지+텍스트 레이어로 저장·불러올 수 있다.
- 프리셋 목록·삭제가 `target_type='collection'`으로 다른 유형과 섞이지 않는다.
- `scripts/verify.sh` 통과.
