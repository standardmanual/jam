# [Admin] 에셋 제너레이터 컬렉션 적용 탭·제작 경로 표시

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 5번. 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: 적용 탭에서 유형을 "컬렉션"으로 고르면 컬렉션(`item_books`) 검색·필터·미리보기 후
  적용 버튼으로 `item_books.image_url`에 반영할 수 있다. `item_books.image_source` 컬럼을 신설해
  목록·상세에 제작 경로 라벨을 넣는다. 컬렉션은 자동 기획 경로가 없어(상위 티켓 결정 6) 라벨 값은
  `admin-generator`/미상만 쓰인다.
- 구현 계획: `item_books.image_source text NULL` + CHECK(`admin-generator`만, `agent-generator` 값은
  이번엔 쓰이지 않지만 미션·홈피드와 CHECK 어휘를 통일해 둔다) 마이그레이션 파일 작성(실행은 승인
  후 메인 세션). 컬렉션 검색은 어드민 컬렉션 목록의 기존 검색·필터(20260924_0945 표준 목록)를
  재사용한다.
- 관련 파일: `jam-web/src/app/admin/asset-generator/ApplyTab.tsx`,
  `jam-web/src/app/api/admin/asset-generator/apply/route.ts`, `jam-web/src/app/admin/itembooks/`

## 배경 / 문제 정의

상위 티켓 결정 4·6: 컬렉션은 신규 기획 없이 기존 레코드에 이미지만 적용하는 수동 경로만 지원한다.

## 완료 조건
- 적용 탭에서 유형을 "컬렉션"으로 고르면 컬렉션 검색·필터·미리보기가 보이고 적용 버튼이 동작한다.
- 적용 후 `item_books.image_url`이 WebP 공개 URL로, `image_source`가 `admin-generator`로 갱신된다.
- 원본 PNG 보관 + WebP(긴 변 400px) 반영.
- 컬렉션 목록·상세에 제작 경로 라벨이 보인다.
- `scripts/verify.sh` 통과.
