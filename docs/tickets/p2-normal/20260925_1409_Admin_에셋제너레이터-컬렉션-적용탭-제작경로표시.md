# [Admin] 에셋 제너레이터 컬렉션 적용 탭·제작 경로 표시

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 5번. 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: 적용 탭에서 유형을 "컬렉션"으로 고르면 컬렉션(`item_books`) 검색·필터·미리보기 후
  적용 버튼으로 `item_books.image_url`에 반영할 수 있다. `item_books.image_source` 컬럼을 신설해
  목록·상세에 제작 경로 라벨을 넣는다. 컬렉션은 자동 기획 경로가 없어(상위 티켓 결정 6) 라벨 값은
  `admin-generator`/미상만 쓰인다.
- 구현 계획 (1407이 실제로 만든 구조를 그대로 확장, 파일·함수 단위):
  1. `jam-web/supabase/migrations/189_item_books_image_source.sql` 신규 작성(실행은 4단계
     승인 후 메인 세션). 순수 확장: `ALTER TABLE item_books ADD COLUMN IF NOT EXISTS
     image_source text NULL, ADD CONSTRAINT item_books_image_source_check CHECK (image_source
     IN ('admin-generator', 'agent-generator'))` — `188_missions_image_source.sql`과 같은 값
     어휘(컬렉션은 자동 기획 경로가 없어 `agent-generator`는 이번엔 값이 채워지지 않지만,
     어휘는 통일해 둔다). idempotent + 되돌림 SQL 포함(188번 패턴 그대로).
  2. `src/app/api/admin/asset-generator/apply/route.ts`: `TargetType` 유니온에 `'collection'`
     추가, `TARGET_TYPE_CONFIG`에 항목 추가 — `table: 'item_books'`, `nameColumn: 'name'`,
     `storagePrefix: 'item_books'`, `hasDeletedAt: false`(item_books는 `deleted_at`이 아니라
     `is_active`로 비활성화한다 — `itembook-list-query.ts` 확인), 안내 문구 2개. `isTargetType`
     함수의 허용값에도 추가.
  3. `src/app/admin/asset-generator/ApplyTab.tsx`: `ContentType`에 `'collection'` 추가,
     `CONTENT_TYPE_OPTIONS`에 `{ value: 'collection', label: '컬렉션' }` 추가. `collectionId`/
     `collection` state와 `handleSelectCollection` 추가, `targetId`/`targetName`/
     `targetImageUrl` 삼항 분기를 3분기로 확장, `handleContentTypeChange`에 컬렉션 state 초기화
     추가, `handleApply`의 FormData 분기(`contentType === 'badge' ? ... : ...`)도 3분기로.
  4. 신규 `src/components/admin/ItemBookSearchSelect.tsx` — `MissionSearchSelect.tsx`(전체
     129줄) 패턴을 그대로 미러링하되, 기존 `/api/admin/itembooks/search`(이미 있음, 응답
     `{itemBooks: [{id,name,imageUrl}]}`)를 호출한다. 새 검색 API를 만들지 않는다.
  5. `src/app/admin/itembooks/ItemBookFilters.tsx`(61줄): "제작 경로"
     `DataTableFacetedFilter`를 `MissionFilterBar.tsx:87-91` 패턴으로 추가
     (`IMAGE_SOURCE_FILTER_OPTIONS` from `contentImageSource.ts`).
  6. `src/components/admin/itembooks/ItemBookTable.tsx`(데스크톱)·`ItemBookCard.tsx`(모바일):
     "제작 경로" 라벨을 `MissionTable.tsx:249-254` 패턴으로 추가(`contentImageSourceLabel`).
  7. `src/app/admin/itembooks/ItemBookForm.tsx`(690줄, `imageUrl` state는 67행): "제작 경로 ·
     {라벨}" 표시를 `MissionForm.tsx:217-221` 패턴으로 추가(수정 화면에서만).
  8. `src/lib/admin/itembook-list-query.ts`: `ItemBookListParams`에 `imageSource: string |
     undefined` 추가, `parseItemBookListParams`에서 파싱, `applyItemBookListFilters`에
     `mission-list-query.ts:180-181` 패턴(`UNKNOWN_IMAGE_SOURCE_FILTER` sentinel 처리 포함)
     그대로 추가.
- 관련 파일: 위 1~8 목록 참고. 계획 반환 면제(`planOnlyWaiver`) 부여: 카리나가 1407 병합 결과를
  직접 조회해 파일 단위 계획을 작성함(2026-09-25). 9개 파일 예상, 임계값(5개/100줄) 초과 확실.

## 배경 / 문제 정의

상위 티켓 결정 4·6: 컬렉션은 신규 기획 없이 기존 레코드에 이미지만 적용하는 수동 경로만 지원한다.

## 완료 조건
- 적용 탭에서 유형을 "컬렉션"으로 고르면 컬렉션 검색·필터·미리보기가 보이고 적용 버튼이 동작한다.
- 적용 후 `item_books.image_url`이 WebP 공개 URL로, `image_source`가 `admin-generator`로 갱신된다.
- 원본 PNG 보관 + WebP(긴 변 400px) 반영.
- 컬렉션 목록·상세에 제작 경로 라벨이 보인다.
- `scripts/verify.sh` 통과.
