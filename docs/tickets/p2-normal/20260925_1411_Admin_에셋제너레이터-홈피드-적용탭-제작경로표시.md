# [Admin] 에셋 제너레이터 홈피드 적용 탭·제작 경로 표시

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 7번. 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: 적용 탭에서 유형을 "홈피드"로 고르면 `today_cards` 검색·필터·미리보기 후 적용 버튼으로
  `today_cards.cover_image_url`에 반영할 수 있다. `today_cards.image_source` 컬럼을 신설하되,
  기존 주간 편성 승인→seed SQL 등록 경로와 이번 적용 경로가 구분되는 값을 쓴다(상위 티켓 리스크:
  홈피드 등록 경로 이중화).
- 구현 계획: `today_cards.image_source text NULL` + CHECK(`admin-generator`·`agent-generator`) 마이그레이션
  파일 작성(실행은 승인 후 메인 세션). `content-automation/PRD.md` §8-2(기존 seed SQL 등록 경로)에
  각주로 이 이중 경로를 명시하고 라벨로 구분되는 링크를 남긴다. 홈피드 검색은 `today_cards` 어드민
  목록의 기존 검색·필터를 재사용한다.
- 관련 파일: `jam-web/src/app/admin/asset-generator/ApplyTab.tsx`,
  `jam-web/src/app/api/admin/asset-generator/apply/route.ts`, `jam-web/src/app/admin/today/`,
  `docs/specs/prd/content-automation/PRD.md`

## 배경 / 문제 정의

상위 티켓 결정 4·리스크: 홈피드는 기존 주간 편성 파이프라인(20260923_2252)의 seed SQL 등록 경로와
이번 신규 적용 경로가 병존한다. 운영자가 카드 출처를 혼동하지 않도록 라벨로 명확히 구분해야 한다.

## 완료 조건
- 적용 탭에서 유형을 "홈피드"로 고르면 카드 검색·필터·미리보기가 보이고 적용 버튼이 동작한다.
- 적용 후 `today_cards.cover_image_url`이 WebP 공개 URL로, `image_source`가 `admin-generator`로
  갱신된다.
- 원본 PNG 보관 + WebP(긴 변 400px) 반영.
- 홈피드 목록·상세에 제작 경로 라벨이 보이고, 기존 seed SQL 등록 카드(image_source NULL)와 이번
  경로로 만든 카드가 라벨로 구분된다.
- `content-automation/PRD.md` §8-2에 이중 등록 경로 각주가 반영된다.
- `scripts/verify.sh` 통과.
