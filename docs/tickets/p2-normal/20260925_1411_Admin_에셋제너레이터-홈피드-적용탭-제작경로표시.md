> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 7번. 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: 적용 탭에서 유형을 "홈피드"로 고르면 `today_cards` 검색·필터·미리보기 후 적용 버튼으로
  `today_cards.cover_image_url`에 반영할 수 있다. `today_cards.image_source` 컬럼을 신설하되,
  기존 주간 편성 승인→seed SQL 등록 경로와 이번 적용 경로가 구분되는 값을 쓴다(상위 티켓 리스크:
  홈피드 등록 경로 이중화).
- 구현 계획 (1407·1409가 만든 구조를 그대로 확장, 파일·함수 단위):
  1. `jam-web/supabase/migrations/190_today_cards_image_source.sql` 신규 작성(실행은 4단계
     승인 후 메인 세션). 순수 확장, `188_missions_image_source.sql`과 같은 값 어휘
     (`admin-generator`·`agent-generator`), idempotent + 되돌림 SQL.
  2. `src/app/api/admin/asset-generator/apply/route.ts`: `TargetType`에 `'home_feed'` 추가.
     **주의**: today_cards의 이미지 컬럼은 `image_url`이 아니라 `cover_image_url`이다 —
     `TARGET_TYPE_CONFIG`에 `imageUrlColumn: 'image_url' | 'cover_image_url'` 필드를 신설해
     badge·mission·collection엔 `'image_url'`을, home_feed엔 `'cover_image_url'`을 채운다.
     현재 하드코딩된 `table.update({ image_url: webpUrl, image_source: ... })` 호출을
     `table.update({ [config.imageUrlColumn]: webpUrl, image_source: 'admin-generator' })`로
     일반화하고, `TargetTable.update()` 인터페이스 시그니처도 동적 키를 받도록 조정
     (`Record<string, string>` 형태). `nameColumn: 'title'`, `storagePrefix: 'today_cards'`,
     `hasDeletedAt: false`.
  3. `src/app/admin/asset-generator/ApplyTab.tsx`: `ContentType`에 `'home_feed'` 추가,
     `CONTENT_TYPE_OPTIONS`에 `{ value: 'home_feed', label: '홈피드' }` 추가. state·
     `handleSelectCard` 추가, `targetId`/`targetName`/`targetImageUrl` 분기를 4분기로 확장
     (홈피드는 `cover_image_url` 필드에서 읽는다), `handleContentTypeChange`·`handleApply`도
     4분기로.
  4. 신규 `src/app/api/admin/today/search/route.ts` — `itembooks/search/route.ts` 패턴 그대로
     (`today_cards`에는 검색 전용 API가 아직 없다), `ilike('title', ...)`로 검색해
     `{cards: [{id, title, imageUrl: cover_image_url}]}` 반환.
  5. 신규 `src/components/admin/TodayCardSearchSelect.tsx` — `MissionSearchSelect.tsx` 패턴
     그대로, 4번에서 만든 `/api/admin/today/search`를 호출.
  6. `src/lib/admin/today-list-query.ts`: `TODAY_LIST_COLUMNS`(현재
     `'id, title, template_type, layout_type, exposure_tags, starts_at, ends_at, sort_order,
     is_active, created_at'`)에 `image_source` 추가, `TodayListRow` Pick에 추가,
     `TodayListParams`에 `imageSource: string | undefined` 추가, `parseTodayListParams`에서
     파싱, `applyTodayListQuery`에 `mission-list-query.ts:180-181` 패턴(eq/is null,
     `UNKNOWN_IMAGE_SOURCE_FILTER`)을 추가.
  7. `src/app/admin/today/TodayFilterBar.tsx`(50줄): "제작 경로" `DataTableFacetedFilter`를
     `MissionFilterBar.tsx:87-91` 패턴으로 추가.
  8. `src/app/admin/today/TodayCardTable.tsx`(326줄, `columns` 정의 94-190행): "제작 경로"
     컬럼을 `MissionTable.tsx:249-254` 패턴으로 추가.
  9. `src/app/admin/today/TodayCardForm.tsx`(`coverImageUrl` state 125행): "제작 경로 ·
     {라벨}" 표시를 `MissionForm.tsx:217-221` 패턴으로 추가(수정 화면에서만).
  10. `docs/specs/prd/content-automation/PRD.md` §8-2 "**등록 방식**" 단락(191행 부근)에 각주
      추가: 어드민 적용 탭 경로(`image_source='admin-generator'`)와 기존 seed SQL 등록 경로
      (`image_source` NULL, 하위 티켓 20260925_1413 등록 스크립트 완성 후엔
      `'agent-generator'`)를 구분한다.
- 관련 파일: 위 1~10 목록 참고. 계획 반환 면제(`planOnlyWaiver`) 부여: 카리나가 1407·1409 병합
  결과와 홈피드 어드민 화면(today-list-query·TodayFilterBar·TodayCardTable·TodayCardForm)·
  content-automation PRD §8-2를 직접 조회해 파일 단위 계획을 작성함(2026-09-25). 10개 파일
  예상, 임계값(5개/100줄) 초과 확실.

## 배경 / 문제 정의

상위 티켓 결정 4·리스크: 홈피드는 기존 주간 편성 파이프라인(20260923_2252)의 seed SQL 등록 경로와
이번 신규 적용 경로가 병존한다. 운영자가 카드 출처를 혼동하지 않도록 라벨로 명확히 구분해야 한다.

## 완료 조건
- 적용 탭에서 유형을 "홈피드"로 고르면 카드 검색·필터·미리보기가 보이고 적용 버튼이 동작한다.
- 적용 후 `today_cards.cover_image_url`이 WebP 공개 URL로, `image_source`가 `admin-generator`로
  갱신된다.
- 원본 PNG 보관 + WebP(긴 변 400px) 반영.
- 홈피드 목록·상세에 제작 경로 라벨이 보이고, 기존 seed SQL 등록 카드(image_source NULL)와 이번
  경로로 만든 카드가 라벨로 구분된다.
- `content-automation/PRD.md` §8-2에 이중 등록 경로 각주가 반영된다.
- `scripts/verify.sh` 통과.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- 1407·1409가 만든 구조를 그대로 확장해 적용 탭에 "홈피드" 유형을 추가했다. `today_cards`에는
  검색 API가 없어 `/api/admin/today/search`를 신설하고 `TodayCardSearchSelect.tsx`를 만들었다
  (`MissionSearchSelect` 패턴).
- `apply/route.ts`의 `TARGET_TYPE_CONFIG`에 `home_feed`를 추가했다. today_cards의 이미지
  컬럼이 `cover_image_url`이라 `imageUrlColumn` 필드를 신설해 update를 동적 키로 일반화했다.
- `today_cards.image_source` 컬럼(마이그레이션 190, 순수 확장)을 추가하고, 홈피드 목록(컬럼·
  필터)과 수정 화면에 제작 경로 라벨을 표시했다. NULL(기존 seed SQL 등록 카드)은 "미상"이다.
- `content-automation/PRD.md` §8-2에 어드민 적용 탭 경로와 기존 seed SQL 등록 경로를 구분하는
  각주를 추가했다.
- **실렌더 발견 결함 패치(142bf1da)**: 이미지가 있는 카드를 선택하면 어드민 화면 전체가 오류
  화면으로 바뀌었다. 현재 DB의 이미지가 있는 카드 13장이 전부 외부 호스트(`storage.heypop.kr`
  등)라 `next.config.ts`의 `images.remotePatterns`에 없었고, 「현재 이미지」 썸네일의
  `next/image`가 예외를 던졌다. 해당 `<Image>`에 `unoptimized`를 붙여 호스트 검사를 건너뛴다.
