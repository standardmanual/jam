# [Infra] 윤진 에이전트 정의 갱신 — 정기 기획 신규 제안 허용

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 10번. 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: `.claude/agents/jam-marketer.md`의 "제안은 세션(`/jam-story`)에서만, 예약 실행에서는
  절대 하지 않는다"는 원칙(결정 4-9)에, 정기 산출물(주간 홈피드/월간 배지·미션)에서 신규 콘텐츠
  기획+이미지 준비는 예외로 허용하는 조건을 추가한다. 등록 실행 권한은 여전히 없다(Forbidden 유지).
  담당은 카리나·하니(에이전트 정의·문서체계), 사용자 명시 승인은 이 기획 승인 대화에서 이미
  받았다.
- 구현 계획: 정의 파일에 새 절(또는 기존 ⑧ 절 확장)을 추가해 — 정기 산출물에서 신규 배지·미션·
  홈피드 기획안(이름+설명+이미지+시드, 트렌드·지표 근거)을 준비하고 등록 묶음 파일로 저장할 수
  있음, 세계관과 닿는 기획안은 윈터 검수를 거치며 그 여부·사유를 등록 묶음에 남김, 등록 실행은
  절대 하지 않고 항상 메인 세션이 사용자 컨펌 후 처리함(변경 없음)을 명시한다.
- 관련 파일: `.claude/agents/jam-marketer.md`

## 배경 / 문제 정의

상위 티켓 결정 8: 사용자가 이 정의 변경을 명시 승인했다 — "윤진이 신규배지 제안, 신규 미션 제안,
주간 홈피드 컨텐츠 기획안을 트렌드와 지표를 반영해서 주간·월간으로 나에게 제시하고, 승인하면
어드민에 등록해서 유저에게 노출한다."

## 완료 조건
- `jam-marketer.md`가 갱신되어 정기 산출물에서 신규 배지·미션·홈피드 기획+이미지 준비를 허용하는
  절이 있다.
- 등록 실행은 여전히 하지 않는다는 Forbidden 조항이 그대로 유지·명시된다.
- 하위 티켓 20260925_1412·1413(등록 스크립트) 완료 뒤 착수한다(스크립트 존재를 전제로 절차를
  적는다).
