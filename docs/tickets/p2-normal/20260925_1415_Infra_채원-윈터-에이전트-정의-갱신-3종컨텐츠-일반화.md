# [Infra] 채원·윈터 에이전트 정의 갱신 — 3종 컨텐츠 일반화

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 11번(선행 없음, 쓰임은 10번 이후). 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: `.claude/agents/jam-designer.md`(채원)·`.claude/agents/jam-tribe.md`(윈터)의 "배지 대표
  이미지" 한정 문구를 "배지·미션·홈피드 콘텐츠"로 일반화한다. 윈터는 조건부 검수 관문(신규 기획안
  중 세계관과 닿는 것만 검수, 순수 운영성 콘텐츠는 생략 가능)을 명시한다. 컬렉션은 신규 기획이
  없으므로 이 확장 대상에서 제외됨을 함께 적는다.
- 구현 계획: 1차(배지, 20260924_2204)에서 이미 정의한 "컬러 방향 제시·검수" 절차를 그대로 두고,
  적용 범위 문구만 3종으로 넓힌다. 새 역할·새 관문을 만들지 않는다.
- 관련 파일: `.claude/agents/jam-designer.md` §5, `.claude/agents/jam-tribe.md` §④

## 배경 / 문제 정의

상위 티켓 결정 10·11: 컬러 방향 제시(채원)·세계관 검수(윈터) 자체는 1차 배지 때 이미 만들어져
있다(20260924_2204). 이번엔 그 절차가 미션·홈피드에도 적용된다는 것만 명시하면 된다. 사용자가
이 정의 변경도 명시 승인했다.

## 완료 조건
- `jam-designer.md`·`jam-tribe.md`가 갱신되어 "배지" 한정 문구가 "배지·미션·홈피드"로 일반화된다.
- 윈터의 검수 관문이 "세계관과 닿는 신규 기획안만"으로 조건부임이 명시된다.
- 컬렉션이 이 확장 대상에서 제외됨(신규 기획 없음)이 명시된다.
