# [Infra] 채원·윈터 에이전트 정의 갱신 — 3종 컨텐츠 일반화

> 상위 티켓 [20260925_1404](20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 11번(선행 없음, 쓰임은 10번 이후). 기획 경위·결정 기록·리스크는 상위 티켓 참고.

## 핵심 요약

- 요구사항: `.claude/agents/jam-designer.md`(채원)·`.claude/agents/jam-tribe.md`(윈터)의 "배지 대표
  이미지" 한정 문구를 "배지·미션·홈피드 콘텐츠"로 일반화한다. 윈터는 조건부 검수 관문(신규 기획안
  중 세계관과 닿는 것만 검수, 순수 운영성 콘텐츠는 생략 가능)을 명시한다. 컬렉션은 신규 기획이
  없으므로 이 확장 대상에서 제외됨을 함께 적는다.
- 구현 계획: 1차(배지, 20260924_2204)에서 이미 정의한 "컬러 방향 제시·검수" 절차를 그대로 두고,
  적용 범위 문구만 3종으로 넓힌다. 새 역할·새 관문을 만들지 않는다.
- 관련 파일: `.claude/agents/jam-designer.md` §5, `.claude/agents/jam-tribe.md` §④

## 배경 / 문제 정의

상위 티켓 결정 10·11: 컬러 방향 제시(채원)·세계관 검수(윈터) 자체는 1차 배지 때 이미 만들어져
있다(20260924_2204). 이번엔 그 절차가 미션·홈피드에도 적용된다는 것만 명시하면 된다. 사용자가
이 정의 변경도 명시 승인했다.

## 제안안 (카리나, 2026-09-25 — 사용자 승인 대기)

에이전트 정의 변경이라 실제 수정 전에 아래 안을 사용자에게 보이고 승인을 받는다. **승인 전에는 정의 파일을
고치지 않는다.**

### 확인한 사실 (2026-09-25 두 정의 파일을 읽고 확인한 결과)

- **채원(`jam-designer.md`)**: 「⑤ 컨텐츠 컬러 방향」의 모드 표 행은 「윤진이 **배지·컨텐츠** 기획 때 요청」이고, 절 첫 문장은
  「**배지 대표 이미지**(에셋 제너레이터)의 컨텐츠별 배경색과 그라데이션 끝색을 다룬다」다. 「배지」 한정은 이 두 곳뿐이고
  나머지(입력·출력·브랜드 색 기준)는 이미 컨텐츠 단위로 쓰여 있다. 도구는 읽기 전용이고 바뀌지 않는다.
- **윈터(`jam-tribe.md`)**: 「④ 컬러 검수」의 모드 표 행은 「**배지·컨텐츠** 컬러의 세계관 적합성 검수」이고 절 도입은
  「윤진이 **배지·컨텐츠**의 배경색·그라데이션 끝색 후보를 가져오면」이다. 「② 검수」는 이미 「배지·아이템·POI·**미션**·카피」를
  포함한다. 즉 티켓이 말한 「배지 한정 문구」는 두 정의 모두 실제로는 **「배지·컨텐츠」로 이미 절반쯤 일반화**되어 있다.
  없는 것은 세 가지다: 홈피드·미션이라는 명시, **조건부 관문**(세계관과 닿는 기획안만 검수)의 명시, **컬렉션 제외**의 명시.
- 윈터의 검수 결과를 담을 자리는 이미 구현되어 있다. 미션·홈피드 등록 묶음(1412·1413)의 `world_review`(세계관과 닿는지 ·
  윈터 검수 여부 · 사유)와, 「닿는데 윈터 검수를 안 거친」 묶음을 거절하는 스크립트 검증이다.
- 에이전트 계약 검사와 자동 생성 문서는 도구·모델만 보므로 문구 변경은 검사에 걸리지 않는다(1414와 같다).

### 결정이 필요한 것

1. **제안대로 적용할지**: 아래 변경안은 티켓 본문의 「적용 범위 문구만 넓히고 새 역할·새 관문을 만들지 않는다」를 지킨다.
   카리나 추천: 승인.
2. **채원 절의 선택 한 줄**: 「출력 규격(400px)과 실제 화면 크기에서의 확대 선명도는 판단하지 않는다」를 넣을지. 상위 티켓
   결정 3이 「미션·홈피드는 실측 없이 400px로 임시 확정, 디자인 리뉴얼 때 정식 실측」이라, 채원이 컬러 방향을 낼 때 이 문제까지
   떠맡지 않게 하는 문구다. 카리나 추천: 포함.
3. **누가 「세계관과 닿는가」를 판단하나**: 이 안은 **윤진이 판단하고 사유를 `world_review`에 적으며**, 닿는 것만 윈터에게
   검수를 요청한다(1404 리스크 절과 같다). 무관 판정을 윈터가 다시 확인하지 않는다(확인하면 「순수 운영성은 생략」이라는
   조건부 관문의 취지와 어긋나고 호출 비용이 는다). 경계가 흔들릴 위험은 1404가 「사유를 묶음에 남겨 사후 추적」으로 받아들였다.
