# [Infra] 홈피드-카드-원샷-스크립트와-대비-계산

## 핵심 요약

- 요구사항: 홈피드 카드 한 장을 만드는 「렌더 → bundle.json 작성 → `--dry-run` 검증」을 명령 하나로 하게 하고, 배경·끝색과 흰 글자의 대비 계산 명령도 만든다. 윤진(2차)과 채원이 같은 작업을 도구 호출 여러 번으로 반복하며 쓰던 토큰(66,010·67,313 중 큰 몫)을 줄인다.
- 구현 계획: `make-home-feed-card.mjs`가 카드 필드 JSON(`--card`), 색(`--bg`·`--end`), 제목·요약(`--text`·`--subtext`), 묶음 폴더(`--out-dir`), 시드(`--seed`, 기본은 묶음 ID에서 결정)를 받아 `render.mjs`와 같은 렌더 함수를 부르고, `bundle.json`을 만들고, 등록 흐름의 `--dry-run`을 실행해 한 줄 JSON 요약(이미지 경로·파일 크기·검증 결과·건너뜀 항목)을 출력한다. 서비스 롤 키 없이 관리자 읽기 API 경로로 동작해야 한다(`presetSource.mjs`). `contrast.mjs`는 `--bg`·`--end`를 받아 흰 글자 대비 비율과 큰 글자(3:1)·일반 글자(4.5:1) 통과 여부를 출력한다.
- 관련 파일: 신규 `jam-web/scripts/asset-generator/make-home-feed-card.mjs`·`contrast.mjs`와 `__tests__/`의 테스트. 참고: `render.mjs`(인자·출력), `renderArgs.mjs`, `fillTextLayers.mjs`, `registerHomeFeedBundle.mjs`(bundle.json 검증), `registerHomeFeedFlow.mjs`(dry-run 흐름), 명세 정본 `docs/specs/prd/asset-generator/HOME_FEED_REGISTRATION_BUNDLE.md` §2·§3.

## 완료 조건

- 명령 한 번으로 `image.png`와 `bundle.json`이 지정한 폴더에 생기고, `--dry-run` 검증 결과가 한 줄 JSON으로 출력된다. 검증 실패면 종료 코드가 0이 아니다.
- `--dry-run`은 형식만 검증하고 DB 읽기 검사는 「건너뜀」임을 출력에 밝힌다(서비스 롤 키가 없는 환경).
- `contrast.mjs`가 지난 시험 실행의 값(예: `#8a5a2e` 흰 글자 5.86, `#3d2812` 13.90)을 소수 둘째 자리까지 재현한다.
- 테스트가 정상 경로·검증 실패·필수 인자 누락을 포함한다. `scripts/verify.sh`가 통과한다.
