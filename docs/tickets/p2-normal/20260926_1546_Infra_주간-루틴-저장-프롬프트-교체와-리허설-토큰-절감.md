# [Infra] 주간-루틴-저장-프롬프트-교체와-리허설-토큰-절감

## 핵심 요약

- 요구사항: 1542~1545가 머지되면 주간 루틴 저장 프롬프트와 윤진·카즈하·채원·윈터 호출 지시를 새 규칙과 스크립트에 맞게 교체하고, 리허설로 토큰을 실측한다.
- 구현 계획: (1) 「규칙의 원본을 먼저 읽는다」를 `doc-section.mjs` 절 발췌 호출로 바꾼다. (2) 카즈하 지시를 `weekly-collect.mjs` 한 번 실행으로 바꾼다. (3) 이미지 단계를 `make-home-feed-card.mjs`와 `contrast.mjs` 사용으로 바꾸고, 채원에게는 색 토큰 파일(`jam-web/design-system/tokens/colors.css`)만 읽고 통째로 읽지 말 파일(`_ds_manifest.json`)을 명시한다. (4) 코퍼스가 빈 값이면 재시도하지 않고 트라이브 문서의 필요한 절만 발췌한다. (5) 요일당 전원 카드 large_thumbnail·미션 대표 이미지 규칙을 프롬프트에 넣는다. (6) `RemoteTrigger update`는 `job_config.ccr`를 통째로 바꾸므로 `events`(프롬프트)와 `session_context`(차단 도구)를 함께 보낸다.
- 담당: 카리나. 사용자 승인 뒤 교체하고 시험용 루틴에서 리허설한다(비용 발생).

## 완료 조건

- 교체 뒤 `RemoteTrigger get`으로 프롬프트 전문·차단 도구·허용 도구·환경·cron이 의도한 값인지 대조한다.
- 리허설의 하위 에이전트 토큰 합계를 기록하고 399,572와 비교한다.
