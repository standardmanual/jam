# [UI] 홈피드-프리셋-1대1과-큰-카드-16대9-불일치-확인

> 2026-09-26 규칙 반영 중 발견. 요일마다 큰 카드 이미지를 만들게 되므로 확인이 필요하다.

## 핵심 요약

- 요구사항: 에셋 제너레이터의 `홈피드` 프리셋은 1:1(1280×1280)인데, 홈 화면의 `large_thumbnail`은 `aspect-[16/9]`(`TodayCardStack.tsx` 81행)이다. 1:1 이미지를 16:9 영역에 넣으면 위아래가 잘리는지, 제목·요약(세로 31%·41%)이 잘리지 않는지 실렌더로 확인하고, 필요하면 16:9 프리셋을 추가한다.
- 구현 계획: 채원이 판정한다. 결과에 따라 (a) 1:1 유지(잘림 없음 확인) (b) 16:9 프리셋 신설(어드민 디자인 화면에서 사용자 승인) 중 고른다.
- 관련 파일: `jam-web/src/app/(main)/TodayCardStack.tsx`(`LargeThumbnailCard` 68~90행), 에셋 제너레이터 홈피드 프리셋(id `51aa4673-f723-4929-ac20-a302202b7aa7`), `docs/specs/prd/asset-generator/PRD.md`.
