# [Infra] 월간 루틴 저장 프롬프트가 옛 버전인 문제를 바로잡고 토큰을 줄인다

> 2026-09-26 사용자 지시(주간과 같은 문제가 월간에도 있는지 점검, 토큰 절감 반영, 이미지 생성 역할 반영 확인).

## 핵심 요약

- 요구사항: 월간 루틴(`trig_01A4aC3MVkh72FtGCk97oLHK`)의 저장 프롬프트를 현재 문서(월간 절·PRD §7·§11)에 맞게 교체하고, 토큰이 큰 구간(하니 문서 점검)을 스크립트 출력 기반으로 바꾼다.
- 구현 계획: 저장 프롬프트 교체는 티켓 20260926_1543(`doc-section.mjs`) 머지 뒤 카리나가 한다. 문서는 지금 고친다(`scheduled-jobs.md` 월간 절).
- 관련 파일: `.claude/skills/jam-work/references/scheduled-jobs.md` 379~410행(월간 절), `jam-doc/operations/reports/monthly/2026-09.md`(1회차 결과), `scripts/doc-check.mjs`, `scripts/issue-filter-check.mjs`, `docs/specs/prd/content-automation/PRD.md` §7.3·§11.

## 점검 결과

### 1. 주간과 같은 문제가 있다: 저장 프롬프트가 2026-09-18 버전이다

저장 프롬프트에 없는 항목(백업 원문 대조, 각 검색어 0건):
- 표준 형식(`jam-doc/marketing/트렌드_노트.md`)과 `issue-filter-check.mjs` 판정, 「제외된 소재」 절(PRD §7.3, 윤진 정의 108행이 이 절을 전제로 한다)
- 윤진 모드 ④의 「유형 카탈로그 리뷰」 절(초안·사람 등급 11종, PRD §11)과 「매핑표 갱신 후보」 항목(어드민 `today/metrics` 사용)
- 하니에게 「`jam-doc/`에 실제로 어떤 문서가 바뀌는지 관찰」 요청

1회차 리포트(`2026-09.md`)의 절이 트렌드 노트·배지·미션 제안 재료·문서 점검·소재 카드·비용뿐인 것과 일치한다. 이대로 두면 2026-10-01 09:00 KST 첫 정기 실행도 위 절들을 빠뜨린다.

문서 안의 불일치도 하나 있다: 월간 절 절차는 「출처 7곳」, 표는 6곳(`blog.naver.com`은 9-18에 뺐다).

### 2. 이미지 생성 역할

- 세션 경로는 반영돼 있다: 윤진 ⑧(신규 배지·미션·홈피드), 채원 ⑤(컬러 방향), 윈터 ④(컬러 검수).
- 예약 경로는 주간 홈피드만 대상이다. 월간 「배지·미션 제안 재료」와 배지·미션은 문서(월간 절·4-12·윤진 정의 132행)가 의도적으로 제외했다. 사용자가 이전에 「배지·미션 이미지도 포함」이라고 하신 것과 차이가 있어 결정이 필요하다(아래 「결정 대기」).
- 채원·윈터 정의는 「호출 세션이 부른다」만 있고 예약 실행의 호출 주체(루틴 본체)를 적지 않았다. 동작에는 문제가 없고 윤진 정의가 이를 밝힌다. 채원 정의의 「대비 계산에 Bash를 쓸 수 있다」는 매번 파이썬을 새로 짜게 만든다(티켓 20260926_1544의 `contrast.mjs`로 대체).

## 결정 대기

- 월간에서 배지·미션 이미지를 만들지: **추천은 만들지 않는 것**이다. 월간은 「모아 두기만」이라 이미지를 붙일 구체적 기획안이 없고, 기획안을 쓰는 세션(`/jam-story`, 윤진 ⑧)에서 이미지를 만들어 컨펌받는 흐름이 이미 있다. 월간에 넣으면 상한 30만을 넘기기 쉽다. 사용자가 「월간에도」를 원하시면 별도 티켓으로 범위를 정한다.
