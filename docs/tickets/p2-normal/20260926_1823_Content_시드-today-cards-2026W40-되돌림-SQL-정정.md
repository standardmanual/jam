# [Content] 시드 SQL 되돌림 블록의 주석 누락과 재활성화 id 누락을 정정한다(배포 전 처리 완료)

## 핵심 요약

- 요구사항: 시드 SQL 되돌림 블록의 주석 누락과 재활성화 id 누락을 정정한다(배포 전 처리 완료)
- 구현 계획: 미정(착수 전 실측부터)
- 관련 파일: `jam-web/supabase/migrations/seed_today_cards_2026W40.sql`(58~91줄)

## 배경 / 문제 정의

프로덕션 배포 전 점검(민지 모드 ②·③, 티켓 1741·1756 배포)의 범위 밖 발견물이다. 여러 줄 UUID 목록에서 첫 줄만 주석이라 나머지 32줄이 실행 가능한 텍스트로 남았고, 기존 카드 13건 비활성화에 대해 재활성화 목록이 11건이었다(`06d6b6a2…`·`45340202…` 누락).

## 완료 조건

- 되돌림 구간이 전부 주석이고 재활성화 id가 13건이며 비활성화 UPDATE의 id와 일치한다.

### 구현 내용 요약

- 되돌림 블록의 비주석 줄을 모두 주석 처리하고 누락 id 2건을 추가했다. 주석과 목록만 바뀌고 실행되는 SQL은 그대로다.
- 검증: 되돌림 구간의 비주석 줄 0건, 재활성화 id 13건(비활성화 UPDATE의 id 13건과 동일).
