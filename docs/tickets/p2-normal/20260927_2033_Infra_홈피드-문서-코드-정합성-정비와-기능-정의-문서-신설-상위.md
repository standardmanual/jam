# [Infra] 홈피드 문서·코드 정합성 정비와 기능 정의 문서 신설 (상위)

## 핵심 요약

- 요구사항: 2026-09-27 세션에서 홈피드 기능 정의를 소스 코드와 대조하다 발견한 어긋남을 모두 해결하고, 홈피드 서비스 기능 정의를 별도 문서(`docs/specs/prd/home-feed/PRD.md`)로 만들어 코드가 바뀌면 문서도 함께 바뀌도록 기계적으로 강제한다.
- 구현 계획: 하위 티켓 5개(아래 표). 코드 3건은 아현→민지 표준 경로, 문서 갱신과 루틴 저장 프롬프트 교체 2건은 카리나가 직접 한다.
- 관련 파일: 하위 티켓별 「관련 파일」 참고.

## 배경 / 문제 정의

사용자 요청(2026-09-27): "가장 최신의 홈피드 기능 정의 전체를 알려줘" → "소스코드도 확인해" → "지금 발견한 문제점을 모두 해결하고 문서를 최신화 해. 홈피드 기능 정의 문서를 별도로 항상 최신화 하고 별도 문서로 저장해".

소스 코드(staging `906a039`)와 대조해 확인한 문제:

사용자 결정(2026-09-27, 이 세션):
- 코퍼스 API: ID 없이 호출하면 API가 활성 후보에서 자동 선택(ISO 주차 순환). ID를 주면 기존 동작.
- 최신화 장치: 생성 구간 + 커밋 차단(홈피드 코드가 바뀌었는데 문서가 안 바뀌면 차단, `JAM_SKIP_DOCLINT=1`로 우회하고 사유를 남김).
- 레이아웃 규칙: 어드민 폼 추천값 변경 + 등록 스크립트 검사.
- 주간 루틴 저장 프롬프트 교체 승인.
