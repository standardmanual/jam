# [Feature] 홈피드 기능 정의 문서 작성과 관련 문서 최신화 (docs)

## 핵심 요약

- 요구사항: 형제 티켓 2036이 만든 뼈대 `docs/specs/prd/home-feed/PRD.md`에 홈피드 서비스 기능 정의 본문을 코드 기준으로 쓰고 `status: active`로 바꾼다. 흩어진 문서의 낡은 서술을 고치고, 같은 사실을 여러 곳에 적지 않도록 새 문서를 참조하게 바꾼다.
- 구현 계획: 카리나가 직접(docs 유형). 2034·2035·2036 머지 뒤에 코드와 다시 대조해 쓴다.
- 관련 파일:
  - `docs/specs/prd/home-feed/PRD.md`(본문)
  - `docs/specs/prd/01_PRD.md` — §3 기능 표 「홈 / 투데이」 행(약 81행), §4 화면 구성(약 105~114행), 약 206행 「7종 템플릿」
  - `docs/specs/prd/02_DATA_MODEL.md` — `today_cards` 행(약 519행) 「템플릿 7종」
  - `docs/specs/prd/content-automation/PRD.md` — §4(코퍼스 자동 선택), §5(10/1 예정 안내 삭제), §8(기사 본문 형식), §8-2(요일별 점검 조회에 큰 카드 수), §9(기사 상세 계측 없음), §15(구현 상태 갱신)
  - `docs/specs/prd/README.md` — 새 폴더 행
  - `.claude/skills/jam-story/SKILL.md` §4 표(약 63행) 「발행은 카즈하」
  - `.claude/agents/jam-marketer.md` ⑥ 코퍼스 문단·후보 본문 형식
  - `.claude/skills/jam-work/references/scheduled-jobs.md` — `ADMIN_API_BASE_URL` 현재 상태, 주간 윤진 지시문의 코퍼스 문장
