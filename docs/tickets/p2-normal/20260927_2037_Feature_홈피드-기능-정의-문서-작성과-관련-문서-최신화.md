## 핵심 요약

- 요구사항: 형제 티켓 2036이 만든 뼈대 `docs/service/prd/home-feed/PRD.md`에 홈피드 서비스 기능 정의 본문을 코드 기준으로 쓰고 `status: active`로 바꾼다. 흩어진 문서의 낡은 서술을 고치고, 같은 사실을 여러 곳에 적지 않도록 새 문서를 참조하게 바꾼다.
- 구현 계획: 카리나가 직접(docs 유형). 2034·2035·2036 머지 뒤에 코드와 다시 대조해 쓴다.

  - `.claude/skills/jam-story/SKILL.md` §4 표(약 63행) 「발행은 카즈하」
  - `.claude/agents/jam-marketer.md` ⑥ 코퍼스 문단·후보 본문 형식
