# [Infra] 주간 루틴 저장 프롬프트 교체 — 편성 안내 글의 「등록」 문장과 코퍼스 자동 선택

## 핵심 요약

- 요구사항: 주간 루틴(`trig_01DrqvaJccpp17ZBKyTgQgeX`) 저장 프롬프트에 ① PRD §8-1의 편성 안내 글 문장 「승인하려면 리포트의 최종 선택·승인 칸을 채우고 이 글에 '등록'이라고 답해 주세요」를 넣고, ② 코퍼스 호출이 ID 없이도 활성 후보를 받는다는 사실(2034, 프로덕션 반영 뒤)과 빈 값일 때의 기존 폴백을 함께 적는다. ③ 9/26 레이아웃 규칙이 등록 검사로 강제된다는 사실(2035)을 이미지 단계 지시에 반영한다.
- 구현 계획: 카리나가 `update_trigger`로 프롬프트만 교체하고 `get_trigger`로 다시 받아 대조한다. 교체 전 원본 전문은 이 티켓 완료 기록에 백업한다. `scheduled-jobs.md` 주간 절의 교체 기록을 갱신한다.
- 관련 파일: 루틴 저장 프롬프트(claude.ai/code/routines), `.claude/skills/jam-work/references/scheduled-jobs.md` 「주간 — 화요일 09:00 KST」 절

상위 티켓 [20260927_2033](20260927_2033_Infra_홈피드-문서-코드-정합성-정비와-기능-정의-문서-신설-상위.md) 문제 2·5·6. 사용자가 2026-09-27 이 세션에서 교체를 승인했다. 다음 실행은 2026-09-29 09:01 KST다.

## 완료 조건

- `get_trigger`로 받은 프롬프트에 ①②③이 들어 있고, 그 밖의 내용은 교체 전 원본과 같다(차이를 완료 기록에 적는다). cron·활성 상태·모델이 바뀌지 않았다.
- `scheduled-jobs.md` 주간 절에 교체 시각(KST)과 내용이 적혀 있고 `node scripts/gen-scheduled-jobs.mjs --check`가 통과한다.
