# [Content] W40 금요일(10/2) 미션 소개 카드를 큰 썸네일과 미션 대표 이미지로 바꾼다

## 핵심 요약

- 요구사항: 10/2 활성 카드 `b3ff9bf0-f81c-4184-ac8b-5ca314ccd7fd`(「그루터기 살롱의 겨울 채비」, `mission_spotlight`, 전원)를 미션 카드 규칙(PRD §8)대로 `large_thumbnail` + 커버 = `missions.image_url`로 바꾼다.
- 구현 계획: `jam-web/supabase/migrations/seed_today_cards_2026W40_mission_card_large.sql`을 사용자 승인 뒤 메인 세션이 실행한다.
- 관련 파일: 위 SQL 파일(되돌림 SQL 포함)

## 배경 / 문제 정의

상위 티켓 [20260927_2033](20260927_2033_Infra_홈피드-문서-코드-정합성-정비와-기능-정의-문서-신설-상위.md) 작업 중 DB 읽기로 확인했다(2026-09-27): 이 카드는 `layout_type = 'shortcut'`, `cover_image_url = NULL`이고, 연결된 미션에는 대표 이미지가 있다. W40 시드(`seed_today_cards_2026W40.sql` 8행)는 「새 규칙 적용 전 리포트라 shortcut으로 등록한다」고 결정했으므로, 새 이미지가 필요한 다른 요일 카드는 이 티켓에서 바꾸지 않는다. 미션 카드만 새 이미지 없이 규칙에 맞출 수 있어 제안한다.

## 완료 조건

- 사용자 승인 뒤 SQL을 실행했고, 확인 조회에서 `layout_type = 'large_thumbnail'`, `same_cover = true`다.
- 승인되지 않으면 이 티켓은 CLOSED(미실행)로 닫고 사유를 남긴다.
