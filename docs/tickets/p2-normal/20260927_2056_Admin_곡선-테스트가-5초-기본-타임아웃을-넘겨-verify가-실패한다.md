# [Admin] 곡선 테스트 1건이 vitest 기본 타임아웃(5초)을 넘겨 verify가 실패한다

## 핵심 요약

- 요구사항: `jam-web/src/lib/asset-generator/__tests__/curve.test.ts`의 「고리가 있든 없든 모든 시드의 완성 경로가 회전 반경 5%·중앙 통과 10% 이상이다」(약 103행)가 클라우드 세션 컨테이너에서 5,284ms로 기본 타임아웃 5,000ms를 넘겨 실패한다. 판정 로직은 통과 쪽이며 느린 것이 원인이다. 테스트를 건너뛰거나 지우지 않고, 원인(시드×불규칙도 전수 반복의 계산량)을 줄이거나 근거를 적어 이 테스트의 타임아웃을 명시한다.
- 구현 계획: 반복 범위·계산 비용을 먼저 재고, 커버리지를 유지하는 선에서 계산을 줄인다. 줄일 수 없으면 `it(..., timeout)`으로 근거와 함께 상한을 준다.
- 관련 파일: `jam-web/src/lib/asset-generator/__tests__/curve.test.ts` 약 103행 테스트, 대상 함수 `jam-web/src/lib/asset-generator/curve.ts`

## 배경 / 문제 정의

티켓 20260927_2034 구현 중 아현이 `scripts/verify.sh`의 `test` 단계 실패로 보고했다(해당 티켓과 무관, 파일 미수정). 카리나가 2026-09-27 20:56 KST 메인 트리에서 단독 실행으로 두 번 재현했다(`npx vitest run src/lib/asset-generator/__tests__/curve.test.ts`: 1 failed | 9 passed, `Test timed out in 5000ms`, 5,284ms). CI(GitHub Actions)에서는 러너가 빨라 통과할 수 있으나, 로컬·클라우드 세션의 `verify.sh`가 막혀 다른 티켓의 검증을 방해한다. 관련 이전 티켓: 20260926_1756(큰 고리 구간 추가), 20260926_1826·1827(곡선 테스트 보강).

## 완료 조건

- 같은 명령을 클라우드 세션에서 3회 실행해 모두 통과한다.
- 테스트가 검사하는 시드·불규칙도 조합(커버리지)이 줄었다면 그 이유를 완료 기록에 적는다. 테스트를 skip·삭제하지 않는다.
- `scripts/verify.sh`의 `test` 단계가 통과한다.
