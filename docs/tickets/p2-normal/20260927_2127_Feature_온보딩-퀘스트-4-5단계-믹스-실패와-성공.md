# [Feature] 온보딩 퀘스트 4~5단계: 믹스에 한 번 실패해 아이템을 잃어 보고, 레시피를 확인해 성공한다 (T4)

## 핵심 요약
- 요구사항: 4단계는 아무 재료로 믹스해 실패하고 투입한 아이템배지가 소각되는 장면을 보여 준다. 5단계는 레시피 「살롱의 장물 시세」를 확인하고 정확한 재료로 성공한다.
- 구현 계획: 퀘스트 전용 화면(`/onboarding-quest`)에서 실제 믹서 부품을 연출용 재료·결과로 재사용한다(2026-09-27 결정 A, 실제 믹스 페이지에는 분기를 넣지 않는다). 실제 믹스 API는 호출하지 않는다.
- 관련 파일: 믹서 화면(`/combine` 계열), `jam-doc/planning/content/COMBINE_RECIPES.md` L28·L84·L91

## 배경 / 문제 정의
실제 믹스는 성공·실패와 무관하게 투입한 아이템배지를 소각한다(`COMBINE_RECIPES.md` L84). 사용자는 실패하면 아이템배지를 잃을 수 있다는 점을 튜토리얼에서 강조하기를 원했다. 연출용이라 잃어도 손해가 없으므로 실패를 직접 겪게 한다. 기획 전문과 결정 이력은 상위 티켓 `20260927_2123`에 있다.

## 상세 요구사항
- 공통 원칙: 1~7단계는 연출용 데이터다. `inventory_items`·`poi_drops`·`badges`·`user_activity_badges`·`point_transactions`에 행을 만들지 않는다. 서버에는 T1의 진행 테이블에 단계 완료만 기록한다.
- 연출용 아이템·레시피는 실제 카탈로그의 기존 아이템·레시피(이름·이미지)를 빌려 쓴다. 안내 문구는 중립 톤이며 코치마크·설명 팝업은 쓰지 않는다.
- 4단계: 레시피와 맞지 않는 재료로 믹스하면 실패하고, 투입한 연출용 아이템이 사라지는 장면과 함께 "실패하면 넣은 아이템배지를 잃는다"는 사실을 강조한다(문구는 채원 확정). 실패 포인트는 연출로만 보여 주고 실제로 지급하지 않는다.
- 5단계: 레시피 탐색에서 「살롱의 장물 시세」를 확인한 뒤, 정확한 재료로 믹스하면 성공하고 결과물 아이템을 받는다.
- 4단계에서 재료를 잃어도 5단계를 할 수 있도록, 픽업(T3)에서 충분한 재료를 준다.

## 구현 계획
채원 사전 판정(실패·성공 연출, 기존 믹서 재사용 범위) → 연출 재료·결과 정의 → 믹서 주입 → 진행 기록.

## 완료 조건
- 4단계에서 투입한 연출용 아이템이 가방에서 사라지고, 실패로 아이템을 잃는다는 안내가 화면에 보인다.
- 5단계에서 「살롱의 장물 시세」 결과물을 받고 진행도가 5로 바뀐다.
- 4·5단계 동안 `combine` 관련 테이블(`user_combine_fail_logs` 포함)과 `point_transactions`에 해당 유저의 행이 생기지 않는다.
