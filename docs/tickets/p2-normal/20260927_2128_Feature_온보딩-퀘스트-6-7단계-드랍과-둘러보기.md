# [Feature] 온보딩 퀘스트 6~7단계: 믹스 결과물을 드랍하고 미션·트라이브 화면을 둘러본다 (T5)

## 핵심 요약
- 요구사항: 6단계는 믹스 결과물을 POI에 드랍하는 장면, 7단계는 미션 목록이나 트라이브 화면을 한 번 열면 완료.
- 구현 계획: 드랍은 퀘스트 전용 화면(`/onboarding-quest`)에서 실제 드랍 부품을 연출용 데이터로 재사용한다(2026-09-27 결정 A). 7단계는 실제 미션 목록·트라이브 화면을 연 것을 기록한다(실제 컨텐츠라 연출이 필요 없다).
- 관련 파일: 드랍 화면, 미션 목록(`/missions`), 트라이브 화면, T1 진행 테이블

## 배경 / 문제 정의
내가 만든 아이템을 세상에 내려놓는 드랍과, 앞으로 할 거리(미션·트라이브)를 보여 주는 것으로 연출 구간을 마무리한다. 기획 전문과 결정 이력은 상위 티켓 `20260927_2123`에 있다.

## 상세 요구사항
- 공통 원칙: 1~7단계는 연출용 데이터다. `inventory_items`·`poi_drops`·`badges`·`user_activity_badges`·`point_transactions`에 행을 만들지 않는다. 서버에는 T1의 진행 테이블에 단계 완료만 기록한다.
- 연출용 아이템·레시피는 실제 카탈로그의 기존 아이템·레시피(이름·이미지)를 빌려 쓴다. 안내 문구는 중립 톤이며 코치마크·설명 팝업은 쓰지 않는다.
- 6단계: 믹스 결과물을 가까운 POI에 드랍하면 연출용 아이템이 가방에서 빠지고 지도에 놓인 장면을 보여 준다. 실제 `poi_drops`는 만들지 않는다.
- 7단계: 미션 목록 또는 트라이브 화면 중 하나를 열면 완료된다.
- 7단계를 마치면 연출용 데이터는 가방·지도에서 더 이상 보이지 않고, 퀘스트 카드는 실제 연동 단계(T6)를 가리킨다.

## 구현 계획
드랍 연출 주입 → 화면 진입 판정 → 연출 데이터 정리 → 진행 기록.

## 완료 조건
- 6·7단계를 마치면 진행도가 7로 바뀌고, 가방·지도에 연출용 데이터가 남지 않는다.
- 6단계 동안 `poi_drops`·`inventory_items`에 해당 유저의 행이 생기지 않는다.
