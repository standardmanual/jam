# [UI] 온보딩 퀘스트 건너뛰기: 지금 넘기면 받을 수 없는 것이 있다는 뉘앙스로 선택하게 한다 (T8)

## 핵심 요약
- 요구사항: 홈 퀘스트 카드의 건너뛰기를 누르면 [계속하기]/[건너뛰기] 선택을 보여 준다. 건너뛰면 곧바로 실제 연동 카드로 넘어가고 완료 배지는 영구히 받을 수 없다.
- 구현 계획: 별도 화면(`/onboarding-quest`, N2에서 삭제) 대신 홈 카드(N3)에서 여는 모달 또는 바텀시트로 선택 UI를 만든다 → 건너뛰기 시각 기록 → 카드가 T6 단계를 가리키도록 전환.
- 관련 파일: `jam-web/src/app/(main)/OnboardingQuestCard.tsx`(N3에서 수정된 버전, 건너뛰기 진입점 추가 대상), `jam-web/src/app/api/onboarding-quest/step/route.ts`(건너뛰기 기록용 API 필요 여부 확인 — 현재는 `skipped_at`을 쓰는 라우트가 없다), `docs/specs/UX_WRITING_GUIDELINE.md`

## 배경 / 문제 정의
실제 서비스를 빨리 쓰고 싶은 유저를 붙잡아 두지 않되, 끝까지 해 본 유저만 보상을 받게 해 보상의 의미를 지킨다. 설명 팝업이 아니라 유저가 직접 고르는 선택 UI다. 결정 번복(2026-09-28)으로 퀘스트 전용 화면이 없어지므로(결정 16), 건너뛰기 선택도 전용 화면이 아니라 홈 카드에서 여는 모달·바텀시트로 바꾼다. 기획 전문과 결정 이력은 상위 티켓 `20260927_2123`에 있다.

## 사용자 결정 (2026-09-28, 카리나 코드 확인 후)
1. **보상 문구 통일**: 홈 카드의 보상 문구를 실제 배지 이름 「퀘스트 클리어」에 맞춘다. 대상은 `jam-web/src/lib/i18n/ko.ts` `onboardingQuest.rewardHint`(「끝까지 가면 첫 퀘스트 배지와 100포인트」), `onboardingQuest.awaitingActivity.description`(「…퀘스트 완료 배지를 획득해요.」), 그리고 새 건너뛰기 문구다. 최종 문구는 채원이 확정한다.
2. **노출 단계**: 건너뛰기는 카드가 진행 중(`kind: 'in_progress'`)인 모든 단계(1단계 `sync` 포함)에서 보인다. 7단계를 다 마쳐 `awaiting_sync`가 된 카드에는 없다.

### 카리나가 확인한 코드 사실 (2026-09-28)
- `OnboardingQuestCard.tsx`는 서버 컴포넌트이고, `in_progress` 카드는 `sync` 차례를 빼면 카드 전체가 `<Link>`다(L77~87). 링크 안에 버튼을 넣으면 누를 수 있는 요소가 겹치므로 카드 구조를 바꿔야 한다(배치는 채원 판정).
- 건너뛴 뒤의 카드는 이미 준비돼 있다: `resolveOnboardingQuestCard`(`status.ts` L33~41)가 `skipped_at`이 있으면 `awaiting_sync`로 보내고, 미연동이면 Strava 연동 카드(`lastStep`, 보상 언급 없음), 연동 후 활동 대기면 `awaitingActivitySkipped`(보상 언급 없음)를 그린다. 문지기(`screen-gate.ts` L46)도 건너뛴 유저에게는 연출을 끈다. 그래서 건너뛴 뒤 연출 단계로 다시 들어갈 경로는 코드상 이미 없다.
- `skipped_at`을 쓰는 라우트는 없다. `POST /api/onboarding-quest/step`은 `skipped_at`이 있으면 409 `SKIPPED`를 돌려준다(L55~57).

## 상세 요구사항

### 서비스/코드베이스 관점
- 공통 원칙: 연출용 데이터다. `inventory_items`·`poi_drops`·`badges`·`user_activity_badges`·`point_transactions`에 행을 만들지 않는다. 서버에는 `user_onboarding_quests.skipped_at`에 건너뛰기 시각만 기록한다.
- 문구는 "이 순간을 넘기면 받을 수 없는 것이 있다"는 뉘앙스를 담는다(예: "지금 건너뛰면 퀘스트 클리어 배지는 다시 받을 수 없어요" — 유저 노출 문구에 「온보딩」은 쓰지 않는다, `docs/specs/UX_WRITING_GUIDELINE.md` L116). 최종 문구는 채원이 UX 라이팅 가이드에 맞춰 확정한다.
- 건너뛰면 `skipped_at`을 기록하고, 이후 어떤 경로로도 완료 배지를 받을 수 없다(재도전 경로 없음).
- 건너뛰면 남은 연출 단계는 사라지고 카드는 실제 연동 단계(T6)를 가리킨다.
- 건너뛰기 시각 기록용 서버 엔드포인트가 필요하다 — 기존 `POST /api/onboarding-quest/step`은 `step_progress`만 갱신하므로(`route.ts` L69-72), 새 라우트를 추가하거나 이 라우트를 확장한다.
- `skipped_at` 기록 직후 `recordOnboardingQuestCompletion`(`jam-web/src/lib/onboarding-quest/completion.ts`, T6/20260927_2129)을 호출한다 — 건너뛴 시점에 이미 처리된 실제 활동이 있으면 그 자리에서 완료 시각도 함께 기록한다(사용자 결정 2, 20260927_2129).

### UI/UX 관점 (해당 시)
- 별도 화면 대신 홈 카드에서 여는 모달이나 바텀시트로 구현한다. 정확한 형태(모달 vs 바텀시트)와 배치는 채원 사전 판정.

## 구현 계획
채원 사전 판정(모달 vs 바텀시트, 카드 안 건너뛰기 진입점 배치, 문구 3곳 확정) → 아래 파일 단위 계획.

### 파일 단위 계획 (예상 7개 파일·약 250줄 — 테스트 포함)
1. `jam-web/src/lib/onboarding-quest/progress.ts`: 순수 판정 `validateSkip(row)` 추가 — 행 없음 → `NOT_FOUND`, 이미 건너뜀 → 멱등 성공(`alreadySkipped`), 7단계를 모두 마침(`nextStepOf(step_progress) === null`) → `ALL_STEPS_DONE` 거부(실수로 보상을 잃지 않게), 그 외 → 기록.
2. `jam-web/src/app/api/onboarding-quest/skip/route.ts`(신규): `step/route.ts` L17~53과 같은 인증·스위치·행 조회 → `validateSkip` → `update({ skipped_at: now }).eq('user_id').is('skipped_at', null)` → 직후 `recordOnboardingQuestCompletion(serviceClient, user.id)` 호출(상위 결정 25, 반환값은 쓰지 않는다 — 건너뛴 유저는 보상 없음).
3. `jam-web/src/app/(main)/OnboardingQuestCard.tsx`: `in_progress` 카드에 건너뛰기 진입점 추가(링크와 겹치지 않게 구조 조정, 채원 판정대로).
4. `jam-web/src/app/(main)/OnboardingQuestSkipSheet.tsx`(신규, `'use client'`): 채원이 고른 기존 모달/바텀시트 컴포넌트로 [계속하기]/[건너뛰기] 선택. [건너뛰기] → `POST /api/onboarding-quest/skip` → 성공 시 `router.refresh()`로 카드가 연동 단계로 바뀐다. 실패는 토스트(`d.common.networkError` 또는 새 저장 실패 문구), 시트는 닫지 않는다.
5. `jam-web/src/lib/i18n/ko.ts` `onboardingQuest`: 건너뛰기 문구 블록 추가, `rewardHint`·`awaitingActivity.description`을 「퀘스트 클리어」로 통일.
6. 테스트: `jam-web/src/lib/onboarding-quest/__tests__/progress.test.ts`(`validateSkip` 4케이스), `jam-web/src/app/(main)/OnboardingQuestCard.test.tsx`(진행 중 카드에 건너뛰기 진입점이 있고 `awaiting_sync` 카드에는 없음).

## 완료 조건
- 홈 카드의 건너뛰기를 누르면 선택 UI가 보이고, [계속하기]를 고르면 닫히고 진행 중인 단계로 돌아간다.
- [건너뛰기]를 고르면 `skipped_at`이 기록되고, 카드가 실제 연동 단계를 가리킨다.
- 건너뛴 뒤에는 연출 단계로 다시 들어갈 수 있는 경로가 없다.
- 7단계를 모두 마친 유저는 서버가 건너뛰기를 거부한다.
- 홈 카드의 보상 문구와 건너뛰기 문구가 모두 「퀘스트 클리어」 배지를 가리킨다.
