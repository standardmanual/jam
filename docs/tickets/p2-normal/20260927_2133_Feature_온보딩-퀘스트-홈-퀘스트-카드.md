# [Feature] 온보딩 퀘스트 대상 유저의 홈 맨 위에 진행도를 보여 주는 퀘스트 카드를 띄운다 (T1b)

## 핵심 요약
- 요구사항: `user_onboarding_quests` 행이 있고 퀘스트가 끝나지 않은 유저에게 홈 맨 위(인사말 아래, 오늘의 현황 스트립 위)에 퀘스트 카드를 보여 준다. 진행도(n/7)와 다음 행동을 보여 주고, 7단계 완료 또는 건너뛰기 뒤에는 실제 Strava 연동을 가리킨다.
- 구현 계획: 진행 상태 조회·카드 상태 계산 함수 → 카드 컴포넌트 → 홈 페이지 삽입 → 문구 사전 → 상태 계산 단위 테스트.
- 관련 파일: `jam-web/src/lib/onboarding-quest/status.ts`(신규, `getOnboardingQuestCard(userId)`), `jam-web/src/app/(main)/OnboardingQuestCard.tsx`(신규), `jam-web/src/app/(main)/page.tsx`(L29-38 병렬 조회에 추가, 인사말 블록과 `TodayStatusStrip` 사이에 렌더), `jam-web/src/lib/i18n` 사전(`d.today` 옆에 `d.onboardingQuest`), `jam-web/src/lib/onboarding-quest/__tests__/status.test.ts`(신규), `jam-web/src/lib/onboarding-quest/config.ts`(T1a, 읽기만)

## 배경 / 문제 정의
온보딩 퀘스트는 완료할 때까지 홈에 계속 노출돼야 한다. 투데이 CMS(`today_cards`)는 모든 유저에게 같은 카드를 보여 주는 구조라 유저별 진행도를 담을 수 없으므로 앱에서 따로 그리는 카드가 필요하다. 기획 전문과 결정 이력은 상위 티켓 `20260927_2123`에 있다.

## 상세 요구사항
- 노출 조건: `ONBOARDING_QUEST_ENABLED`가 true이고, 행이 있고, `completed_at`이 비어 있을 때만 보인다. 행이 없는 유저(기존 유저)에게는 보이지 않는다.
- 카드 상태 세 가지
  1. **진행 중**: `skipped_at`이 비어 있고 `step_progress`에 7단계가 다 차지 않음 → 진행도(n/7)와 다음 단계 이름, 퀘스트 이어 하기 버튼. 버튼이 가리키는 퀘스트 화면은 T2에서 만든다(이 티켓에서는 경로 상수만 둔다).
  2. **실제 연동 대기**: 7단계를 모두 마쳤거나 `skipped_at`이 있고, `completed_at`이 비어 있음 → 실제 Strava 연동으로 이어지는 안내. 링크는 기존 미연동 타일과 같은 `/api/strava/auth`다. 이미 Strava를 연결했지만 활동이 0건이면 "첫 활동이 들어오면 완료된다"는 상태를 보여 준다.
  3. **숨김**: `completed_at`이 있음.
- 건너뛰기 버튼·선택 화면은 T8 범위다. 이 티켓에서는 만들지 않는다.
- 문구는 중립 톤, 해요체, `docs/specs/UX_WRITING_GUIDELINE.md`의 고정 용어를 따른다. 코치마크·설명 팝업은 쓰지 않는다.
- 조회 실패 시 카드를 숨기고 오류만 기록한다(홈 렌더를 막지 않는다).

## 구현 계획
1. `jam-web/src/lib/onboarding-quest/status.ts`(신규): 행 조회 + 순수 함수 `resolveOnboardingQuestCard(row, { stravaConnected })` → `{ kind: 'in_progress', done, total, nextStep } | { kind: 'awaiting_sync', stravaConnected } | null`
2. `jam-web/src/lib/onboarding-quest/__tests__/status.test.ts`(신규): 행 없음·진행 중·7단계 완료·건너뜀·완료·스위치 꺼짐 경우
3. `jam-web/src/app/(main)/OnboardingQuestCard.tsx`(신규): 채원 판정대로 기존 컴포넌트·토큰 사용
4. `jam-web/src/app/(main)/page.tsx`: 병렬 조회에 추가하고 인사말 블록 다음에 렌더
5. i18n 사전에 `onboardingQuest` 문구 추가

## 완료 조건
- 행이 있고 1단계만 마친 테스트 계정의 홈 맨 위에 "1/7" 진행도와 다음 단계 안내가 보인다.
- 행이 없는 계정, 스위치가 꺼진 상태, `completed_at`이 있는 계정에서는 카드가 보이지 않는다.
- 7단계를 마쳤거나 건너뛴 행이면 카드가 `/api/strava/auth`로 이어지는 연동 안내로 바뀐다.
- 상태 계산 단위 테스트가 위 경우를 모두 다루고 통과한다.
- 진행 상태 조회가 실패해도 홈이 정상 렌더된다.
