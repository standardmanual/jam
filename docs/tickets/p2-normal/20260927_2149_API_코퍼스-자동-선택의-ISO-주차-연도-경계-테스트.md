# [API] 코퍼스 자동 선택의 ISO 주차 계산에 연도 경계 테스트를 더한다

## 핵심 요약

- 요구사항: `isoWeekOrdinal`(자동 선택 순환의 키)에 연도 경계(12월 말이 다음 해 1주차, 1월 초가 전년도 52·53주차) 테스트가 없다. 같은 해 안 월·일요일과 다음 주 이동만 검사한다.
- 구현 계획: 테스트만 추가한다. 테스트가 결함을 드러내면 같은 티켓에서 고친다.
- 관련 파일: `jam-web/src/lib/content-corpus/select.ts` 약 20~30행 `isoWeekOrdinal`, 테스트 `jam-web/src/lib/content-corpus/__tests__/content-corpus.test.ts` 약 326~341행

## 배경 / 문제 정의

2026-09-27 `/jam-ship` 5단계 병렬 점검(민지 모드 ③, 범위 `origin/main..origin/staging` = 2c7e909..b491fbe)의 테스트 공백 발견물이다. 승격을 막지 않는 항목이라 범위 밖 발견물 규칙(`jam-work` SKILL 3.2절)으로 티켓화했다. 원 티켓: 20260927_2034·2035·2036.

## 완료 조건

- 2026-12-28~2027-01-03, 2027-12-27~2028-01-02 같은 경계 주의 KST 날짜마다 ISO 8601 주차와 같은 주에 속한 날의 값이 같고, 다음 주로 넘어갈 때 정확히 1 증가한다(연도가 바뀌어도). 버그가 나오면 함께 고친다.
- `scripts/verify.sh`가 통과한다.
