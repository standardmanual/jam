# [Admin] 에셋 제너레이터에 퀘스트 카드 인트로 영상 렌더 CLI를 추가하고 7장 영상을 만든다

## 핵심 요약
- 요구사항: 에셋 제너레이터 리본 모션(곡선·스탬프·그라데이션)과 로고 글자 J·A·M, 카드 컨텐츠로 만드는 7초 반복 인트로 영상을 CLI로 렌더한다. 7장 모두 같은 모션 문법을 쓰고 카드마다 무드 컬러만 다르다.
- 구현 계획: 카리나가 샘플 제작에 쓴 스크립트(`render-v5.mjs`, 세션 임시 폴더)를 `jam-web/scripts/asset-generator/render-quest-video.mjs`로 옮기고, 코어는 번들(core.js) 대신 `jam-web/src/lib/asset-generator/*.ts`를 직접 import한다. 서비스용 압축본(H.264 MP4·VP9 WebM·WebP 포스터)까지 한 번에 만든다.
- 관련 파일: `jam-web/scripts/asset-generator/`(renderCard.mjs·fonts.mjs·brandLetters.mjs 재사용), `jam-web/src/lib/asset-generator/curve.ts`(`buildPath`·`posAt`), `render.ts`(`buildStamp`·`drawRibbonLayer`), 출력 `jam-web/public/onboarding-quest/`, 원본 보관 `jam-doc/assets/onboarding-quest/`

## 배경 / 문제 정의
사용자가 온보딩 퀘스트 카드마다 재생 버튼 없이 자동 재생되는 브랜드 영상을 요청했다(2026-09-27). 1번 카드 샘플을 네 차례 다듬으며 아래 모션 문법을 확정했다. 서비스 스크린샷과 에셋 제너레이터 밖의 그래픽(아이콘 등)은 쓰지 않는다.

## JAM 모션 문법 (확정)
1. **트레일**: 에셋 제너레이터 리본(원천 그래픽은 브랜드 글자 J·A·M)이 모든 장면의 주인공이다. 그라데이션 시작색은 항상 그 장면의 배경색이다.
2. **A 포털**: 로고 A의 타원 구멍(`jam_logo.svg` 중심 226.7·78.4, 반지름 35.1×20.6)이 커지며 다음 장면을 열고, 마지막에는 작은 로고의 A로 빨려 들어가며 닫힌다.
3. **컬러 플립**: 박자에 맞춰 배경색과 글자색이 통째로 뒤집힌다.
4. **비트 컷**: 120BPM(0.5초) 박자에 맞춰 타이포가 끊어 들어오고 끊어 나간다. 슬라이드·페이드를 쓰지 않고, 박자 동안 자간만 조금 좁힌다.
5. **자리**: 모든 텍스트는 좌하단 같은 자리(x 56, 기준선 H-72). 칩은 타이틀 바로 위. 작은 로고는 우하단.

## 타임라인 (14박, 7초)
| 박 | 장면 |
|---|---|
| 0~2 | 기본 팔레트, J 트레일 등장, 설명 첫 박자 |
| 2~4 | 컬러 플립, A·M 트레일 합류, 설명 둘째 박자 |
| 4~4.9 | A 포털로 기본 팔레트 복귀, 트레일이 로고 자리로 모임 |
| 5.4~7 | JAM 로고 굳음, 설명 셋째 박자 |
| 7~12.5 | 끝 장면: 칩 + 타이틀 + 작은 로고, 느린 M 트레일 |
| 12.5~13.4 | 작은 로고의 A 포털로 닫힘 |
| 13.4~14 | 빈 바탕(첫 프레임과 같아 이음매 없이 반복) |

## 출력 규격
- 원본: 1280×720, 30fps, H.264 CRF 16(보관용, `jam-doc/assets/onboarding-quest/`)
- 서비스: 960×540, H.264 High CRF 26 `+faststart`, VP9 WebM CRF 38, 음성 없음, 포스터 WebP(끝 장면 한 장, 품질 80) — 1번 샘플 실측 MP4 174KB·WebM 150KB·포스터 18KB
- 파일 이름: `step-01.mp4`·`step-01.webm`·`step-01-poster.webp` … `step-07.*`

## 완료 조건
- `node jam-web/scripts/asset-generator/render-quest-video.mjs <카드번호>`가 원본·서비스용 세 파일을 만든다. 같은 입력이면 같은 결과가 나온다(시드 고정).
- 7장 모두 만들어 `jam-web/public/onboarding-quest/`(서비스용)와 `jam-doc/assets/onboarding-quest/`(원본)에 있다.
- 서비스용 MP4는 장당 300KB 이하다.
- 첫 프레임과 마지막 프레임이 같은 빈 바탕이라 반복 재생 시 이음매가 보이지 않는다.
- 에셋 제너레이터 PRD(`docs/specs/prd/asset-generator/PRD.md`) §9 출력 규격에 퀘스트 카드 영상 행이 추가돼 있다.
