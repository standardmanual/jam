# [UI] 홈 퀘스트 카드에 단계별 인트로 영상을 재생 버튼 없이 자동 재생한다

## 핵심 요약
- 요구사항: 홈 퀘스트 카드(T1b `OnboardingQuestCard.tsx`) 맨 위에 16:9 영상 칸을 두고, 진행 중 상태에서는 다음 단계 영상(`step-0N`)을 음소거·반복·인라인으로 자동 재생한다.
- 구현 계획: `<video autoPlay muted loop playsInline preload="metadata" poster>` + WebM·MP4 두 소스. 동작 줄이기 설정·데이터 절약 모드에서는 포스터만 보여 준다.
- 관련 파일: `jam-web/src/app/(main)/OnboardingQuestCard.tsx`, `jam-web/src/lib/onboarding-quest/status.ts`(`nextStep` → 영상 번호), `jam-web/public/onboarding-quest/`(티켓 `20260927_2319` 산출물)

## 배경 / 문제 정의
사용자가 퀘스트 카드에 재생 버튼 없이 바로 재생되는 영상을 붙이기를 요청했다(2026-09-27). 영상 제작은 `20260927_2319`, 카드 적용은 이 티켓이다.

## 상세 요구사항
- 영상 칸은 카드 안 칩 위, 카드 폭 전체, 16:9, 카드 모서리와 같은 반경으로 잘린다. 채원 사전 판정을 받는다.
- 진행 중: 다음 단계 번호의 영상. Strava 미동기화: 7번 영상의 끝 장면 포스터 또는 영상 없음 중 채원이 정한다. 활동 0건 대기: 영상 없음.
- `muted`·`playsInline`을 반드시 둔다(iOS 자동 재생 조건). 재생 버튼·컨트롤을 보이지 않는다.
- `prefers-reduced-motion: reduce`이거나 `navigator.connection.saveData`가 참이면 영상 대신 포스터 이미지만 보여 준다.
- 화면 밖에 있으면 재생을 멈춘다(IntersectionObserver). 홈에 영상은 하나뿐이다.
- 영상이 로드되지 않으면 포스터가 남고 카드 나머지는 정상 동작한다.
- 영상은 장식이므로 `aria-hidden`을 두고, 카드의 텍스트가 정보를 전달한다.

## 완료 조건
- 진행 중 테스트 계정의 홈 카드에서 다음 단계 영상이 재생 버튼 없이 자동으로 반복 재생된다(데스크톱 크롬·iOS 사파리).
- 동작 줄이기를 켜면 포스터만 보인다.
- 카드가 화면 밖으로 나가면 영상이 멈추고, 다시 들어오면 이어서 재생된다.
- 영상 파일이 없거나 실패해도 카드 레이아웃이 깨지지 않는다.
- `scripts/verify.sh`가 통과한다.
