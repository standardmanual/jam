# [Feature] 온보딩 퀘스트 전용 화면과 관리자 미리보기를 삭제한다 (N2)

## 핵심 요약
- 요구사항: 결정 16에 따라 퀘스트 전용 화면 `/onboarding-quest`와 관리자 미리보기 `/onboarding-quest/preview`를 삭제한다. 실제 화면으로 옮길 연출 로직(1단계 배지 획득 연출, 2단계 연출 도토리)은 T2c·N4가 가져간다.
- 구현 계획: 아래 「관련 파일」의 삭제 대상을 모두 지우고, `TopNav`의 `decorative` prop이 더 이상 쓰이지 않으면 함께 정리한다. `api/onboarding-quest/step/route.ts`·`progress.ts`·`demo-data.ts`·`step-error.ts`·`config.ts`·`status.ts`는 삭제하지 않는다(N1·N3·N4·T3~T5b가 계속 재사용).
- 관련 파일: 삭제 대상은 상세 요구사항의 목록. 옮길 로직 출처는 `steps/SyncStep.tsx`(L26-76, `BadgeRevealOverlay` + `DEMO_SYNC_REVEAL_BADGE` 연출 → T2c로), `steps/InventoryStep.tsx`(L21-54, `InventoryGrid mode="select"` + `DEMO_INVENTORY_ITEM` 연출 → N4로).

## 배경 / 문제 정의
결정 번복(2026-09-28, 결정 14·16): 퀘스트 전용 화면은 서비스에 없는 페이지라서, 그 화면을 눌러 봐도 실제 서비스를 익히는 온보딩이 되지 않는다는 사유로 폐기됐다. `/onboarding-quest`(T2a·T2b, 티켓 `20260927_2330`·`20260927_2125`)와 관리자 미리보기 `/onboarding-quest/preview`(P, 티켓 `20260928_0058`, staging 머지 완료)를 제거하고, 그 화면들이 실제 화면 부품을 연출용 데이터로 재사용하던 접근(2026-09-27 결정 A/12, 이미 폐기)의 산출물을 정리한다. 기획 전문과 결정 이력은 상위 티켓 `20260927_2123`에 있다.

- `TopNav`(`jam-web/src/components/ui/TopNav.tsx`)의 `decorative` prop(L83 정의, L86 파라미터, L94-96·L125-126·L136·L149 `inert` 분기 5곳)은 삭제 대상 두 화면(`onboarding-quest/page.tsx` L61, `preview/QuestPreviewClient.tsx` L36)에서만 쓰인다. grep 확인 결과(2026-09-28) 다른 호출부가 없으므로, 두 화면을 지우면서 `decorative` 관련 코드를 함께 제거한다. 제거하면 `logoNode`·`avatarSlot`·`composedRightSlot`·`centerSlot`의 `<div style={{ display: 'contents' }} inert={decorative}>` 래퍼도 함께 걷어낼 수 있다 — 위험을 줄이려면 이 정리는 범위 밖으로 미루고 prop만 남겨도 된다(아현 판단, 완료 기록에 선택을 남긴다).
- 이 경로를 가리키는 다른 코드 확인(2026-09-28 grep 완료): `jam-web/src/proxy.ts`에는 `onboarding` 경로 판정이 없고, 미들웨어 파일도 없다. `OnboardingQuestCard.tsx`(N3에서 수정)를 제외하면 `/onboarding-quest` 경로를 참조하는 다른 코드가 없다.
