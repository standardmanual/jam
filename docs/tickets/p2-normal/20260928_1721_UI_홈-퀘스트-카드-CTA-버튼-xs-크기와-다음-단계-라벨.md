# [UI] 홈 퀘스트 카드 CTA 버튼 네 개를 xs 크기로 줄이고, 「이어 하기」 라벨을 「다음 단계 >」로 바꾼다

## 핵심 요약
- 요구사항: 티켓 20260928_1537에서 만든 홈 퀘스트 카드 CTA 버튼 네 개(① 동기화 ② 이어 하기 ③ Strava 동기화하기 ④ 동기화)를 `size="sm"`에서 `size="xs"`로 줄이고, ② 버튼 라벨을 「다음 단계」 + 오른쪽 화살표 아이콘(`ChevronRightIcon`)으로 바꾼다.
- 구현 계획: 아래 「구현 계획」 5항목. 로직 변경 없음.
- 관련 파일:
  - `jam-web/src/app/(main)/OnboardingQuestCard.tsx` — ② `Button` L122-129(`size="sm"` L125, 라벨 `{ctaLabel}`), ③ `Button` L157-166(`size="sm"` L160), 파일 머리 주석 L31 「[이어 하기]」
  - `jam-web/src/app/(main)/OnboardingSyncButton.tsx` — L76 `size={appearance === 'card' ? 'sm' : 'xs'}`
  - `jam-web/src/components/SyncButton.tsx` — L112 `size={appearance === 'card' ? 'sm' : 'xs'}`
  - `jam-web/src/lib/i18n/ko.ts` — L223 `onboardingQuest.continueButton: '이어 하기'`
  - 문서: `docs/specs/prd/home-feed/PRD.md` L53(`size="sm"`), L58(「[시작하기/이어 하기]」), `docs/specs/prd/01_PRD.md` L55(「[이어 하기]」)
  - 테스트: `jam-web/src/app/(main)/OnboardingQuestCard.test.tsx` L93·L113 테스트 이름의 「이어 하기」(단언은 `d.onboardingQuest.continueButton` 참조라 값 변경을 따라간다)

## 배경 / 문제 정의
티켓 20260928_1537을 staging에서 확인한 사용자가 카드 버튼이 너무 크다고 요청했다(2026-09-28).

## 확정한 결정 (2026-09-28 사용자 문답)
1. 네 버튼 모두 작은 버튼으로 바꾼다(카드 간 크기 통일).
2. 크기는 **그냥 `xs`**(높이 약 31px)를 쓴다. `Button.tsx`의 "xs는 44px 터치 타겟 규칙의 예외, 본문 액션에 쓰지 않는다" 주석과 어긋나지만 사용자가 명시적으로 택했다 — 터치 영역을 따로 넓히지 않는다.
3. ② 라벨은 「다음 단계 >」: 문구 `다음 단계` + `ChevronRightIcon`(기존 `icons.tsx`, `w-4 h-4` 등 기존 사용례 크기). 텍스트에 `>` 문자를 넣지 않는다.
4. `startButton`(「시작하기」)은 `done===0`이면 항상 sync 차례라 ② 카드에서 도달하지 않는 경로다. 건드리지 않는다.

## 구현 계획
1. `ko.ts`: `continueButton: '다음 단계'`.
2. `OnboardingQuestCard.tsx`: ②③ `size="xs"`. ② 버튼 자식을 `<span>{ctaLabel}</span><ChevronRightIcon … />`로(아이콘 import 추가). 머리 주석 L31 「[이어 하기]」 → 「[다음 단계]」.
3. `OnboardingSyncButton.tsx`·`SyncButton.tsx`: card 분기 크기 `'sm'` → `'xs'`(nav 분기는 이미 xs, 결과적으로 삼항이 사라져도 된다). `variant`·`style` 분기는 그대로.
4. 테스트 이름의 「이어 하기」를 「다음 단계」로. 필요하면 ② CTA에 아이콘(svg)이 있다는 단언 추가.
5. 문서: `home-feed/PRD.md` L53 `size="xs"`로, L58 「[시작하기/다음 단계]」로. `01_PRD.md` L55 「[다음 단계]」로.

## 완료 조건
- 네 카드의 CTA 버튼이 모두 `size="xs"`로 렌더된다(상단 바 동기화 버튼과 같은 높이).
- ② 카드 버튼이 「다음 단계」 문구 오른쪽에 화살표 아이콘을 보여 주고, 누르면 기존처럼 그 단계 화면으로 이동한다.
- `ko.ts`의 `continueButton` 값이 「다음 단계」다. 코드·PRD 어디에도 「이어 하기」 라벨 서술이 남지 않는다(`status.ts` L30 주석의 일반 서술 「이어 하기」는 라벨이 아니므로 제외).
- TopNav의 두 동기화 버튼 모양·동작은 바뀌지 않는다.
- `scripts/verify.sh` 통과.
