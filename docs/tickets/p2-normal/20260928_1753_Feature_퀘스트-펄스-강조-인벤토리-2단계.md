# [Feature] 퀘스트 2단계(인벤토리)에서 눌러야 할 연출 배지 칸에 펄스 강조를 준다 (Q2)

## 핵심 요약
- 요구사항: `bag` 차례에 `/inventory`로 들어오면, 누르면 단계가 기록되는 연출 배지 칸(`leadingItem`)에 공용 펄스(`.jam-quest-pulse`, 티켓 20260928_1752)를 준다.
- 구현 계획: `QuestBagGrid`가 `InventoryGrid`에 넘기는 `leadingItem` 셀에 펄스 클래스를 조건부로 붙인다. 셀 모양(둥근 사각)에 맞게 래퍼 radius를 맞춘다.
- 관련 파일:
  - `jam-web/src/app/(main)/inventory/QuestBagGrid.tsx` — L55-67(`leadingItem` L61)
  - `jam-web/src/components/inventory/InventoryGrid.tsx` — 셀 렌더 L70-77(선두 셀에 클래스를 붙일 수 있는 선택 prop이 필요하면 추가)
  - 테스트: 해당 컴포넌트의 기존 테스트 파일(없으면 `QuestBagGrid` 정적 렌더 단언 추가)
  - 문서: `docs/service/prd/01_PRD.md` 온보딩 퀘스트 서술(L55 부근)에 2단계 강조 대상 한 줄

## 배경 / 문제 정의
상위 20260927_2123의 펄스 강조 분해안 Q2. 결정·규격은 티켓 20260928_1752 「확정한 결정」을 따른다(펄스만, 1.6초, reduced-motion 정지, 말풍선 없음).

## 완료 조건
- `bag` 차례의 `/inventory`에서 연출 배지 칸 둘레에 펄스가 보이고, 셀 모서리 모양과 펄스 모양이 어긋나지 않는다.
- 칸을 누르면(단계 기록 후 홈으로 이동) 기존 동작이 그대로다.
- `bag` 차례가 아니거나 퀘스트 대상이 아닌 유저의 평소 인벤토리에는 펄스가 없다(결정 22).
- `scripts/verify.sh` 통과, `01_PRD.md` 서술이 코드와 일치한다.
