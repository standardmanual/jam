# [Feature] 퀘스트 3·6단계(가상 지도 픽업·드랍)에서 지금 눌러야 할 요소로 펄스 강조를 옮겨 간다 (Q3)

## 핵심 요약
- 요구사항: `pickup`·`drop` 차례의 `/drops` 가상 지도에서, 지금 눌러야 할 요소 하나에만 공용 펄스(`.jam-quest-pulse`, 티켓 20260928_1752)를 주고 누르면 다음 요소로 옮긴다.
  - `pickup`: ① 정지 마커 → ② 모달의 픽업 그룹 행(1건)
  - `drop`: ① 정지 마커 → ② 「여기에 드랍」 버튼 → ③ 드랍할 아이템 칸 → ④ 확인 버튼
- 구현 계획: 새 순서 상태를 만들지 않고, 화면이 이미 가진 상태(모달 열림 여부, 드랍 모드 단계, 선택된 아이템 유무)로 지금 대상 하나를 판단해 클래스를 붙인다. `PoiCarouselModal`에는 퀘스트 전용 선택 prop(예: `questPulseTarget`)을 얹어 평소 호출부에는 영향이 없게 한다.
- 관련 파일:
  - `jam-web/src/app/(main)/drops/QuestPickupScene.tsx` — 마커 L128-151, 픽업 대체 처리 `onPickupOverride` L56-73
  - `jam-web/src/components/PoiCarouselModal.tsx` — 픽업 그룹 행 `ItemRow onClick` L888-898, 「여기에 드랍」 `dropHereButton` L909-912, 드랍용 인벤토리 그리드 L821 부근, 확인 버튼 L841 부근
  - 테스트: 두 컴포넌트의 기존 테스트(정적 렌더 단언)
  - 문서: `docs/specs/prd/01_PRD.md` 온보딩 퀘스트 서술에 3·6단계 강조 대상 한 줄

## 배경 / 문제 정의
상위 20260927_2123의 펄스 강조 분해안 Q3. 결정·규격은 티켓 20260928_1752 「확정한 결정」을 따른다. 결정 7(여러 대상이면 지금 하나만, 누르면 다음으로)이 이 티켓의 핵심이다.

## 완료 조건
- `pickup` 차례: 모달을 열기 전에는 마커에만, 연 뒤에는 픽업 행에만 펄스가 있다.
- `drop` 차례: 마커 → 「여기에 드랍」 → 아이템 칸 → 확인 버튼 순으로 한 번에 하나에만 펄스가 있다.
- 퀘스트 차례가 아닌 평소 `/drops`와 평소 `PoiCarouselModal` 호출부에는 펄스가 없다(선택 prop 기본값 미지정).
- 기존 픽업·드랍 연출과 단계 기록 동작이 그대로다.
- `scripts/verify.sh` 통과, `01_PRD.md` 서술이 코드와 일치한다.
