# [UI] 홈 퀘스트 카드의 펄스 링이 버튼이 아니라 카드 폭 전체로 그려진다

## 핵심 요약
- 요구사항: 홈 퀘스트 카드 ①·② CTA의 펄스 링이 버튼(약 102px) 둘레에만 그려지게 한다.
- 구현 계획: 경미 수정(0.1절). `CTA_ROW_PULSE_CLASS`에 `self-start` 한 단어 추가.
- 관련 파일: `jam-web/src/app/(main)/OnboardingQuestCard.tsx` L50 `CTA_ROW_PULSE_CLASS`, 테스트 `OnboardingQuestCard.test.tsx` L148-153

## 배경 / 문제 정의
티켓 20260928_1752(Q1) 머지 뒤 카리나가 staging 관리자 미리보기(6단계 드랍 차례 홈)에서 확인했다. 펄스 래퍼 `div`(`flex rounded-pill jam-quest-pulse`)가 flex-col 카드의 기본 stretch로 카드 폭(350px)까지 늘어나, 102px 버튼 옆으로 알약 모양 링이 카드 끝까지 그려졌다. 20260928_1537에서 버튼 자체가 늘어났던 것과 같은 원인이다. 정적 렌더 테스트로는 레이아웃을 잴 수 없어 게이트를 통과했다(범위 밖 티켓 20260928_1647이 다루는 공백).

## 완료 조건
- staging 홈 카드에서 펄스 래퍼 폭이 버튼 폭과 같다(`getBoundingClientRect` 실측).
- ③·④ 카드와 다른 화면의 펄스는 영향이 없다.
