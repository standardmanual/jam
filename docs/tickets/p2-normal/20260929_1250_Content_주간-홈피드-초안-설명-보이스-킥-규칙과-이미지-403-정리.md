# [Content] 주간 홈피드 초안의 설명·말투·킥 규칙 보완과 이미지 렌더 403 정리

## 핵심 요약

- 요구사항: 2026-W40 주간 리포트(첫 화요일 정기 실행)에서 드러난 네 가지를 고친다.
  ① 이미지 6장이 모두 HTTP 403으로 렌더 실패 ② 카드 설명이 월요일(기사)만 있음 ③ 본문이 반말(`-다`체)
  ④ 기사 본문이 컨텐츠 설명뿐이라 유저의 재미·동기를 끄는 킥이 없음
- 구현 계획: ①은 루틴 환경 허용 목록에 Supabase 스토리지 호스트를 추가(사용자)하고 문서·오류 메시지를
  보완한다. ②~④는 PRD §8(정본)·브랜드 보이스 가이드·윤진 정의·루틴 프롬프트 초안을 고친다.
- 관련 파일: `docs/specs/prd/content-automation/PRD.md` §8 표 형식·규칙 목록,
  `jam-doc/marketing/브랜드_보이스_가이드.md` 「톤」 절, `.claude/agents/jam-marketer.md` 117~119줄(후보안 규칙),
  `.claude/skills/jam-work/references/scheduled-jobs.md` 주간 루틴 「프롬프트 초안 (윤진)」 행,
  `jam-web/scripts/asset-generator/renderCard.mjs` 113~121줄(이미지 레이어 원본 로드)

## 배경 / 문제 정의

- 2026-W40 리포트(`jam-doc/operations/reports/weekly/2026-W40.md`, 커밋 `94fcf8cc`)에서 사용자가 조정을 요청했다.
- ① 원인 조사: `홈피드` 프리셋(`51aa4673-…`)의 `updated_at`이 2026-09-26 09:32 UTC(18:32 KST)이고, 이때 Supabase
  스토리지(`ceehnkzdbecxwzxrhhns.supabase.co/storage/v1/object/public/images/asset-generator/presets/…svg`)의
  이미지 레이어가 들어갔다. 렌더가 성공한 W39 실행(커밋 `6ded4eeb`, 2026-09-26 06:25 UTC)은 그보다 앞선다.
  렌더는 이 원본을 `@napi-rs/canvas`의 `loadImage(url)`로 직접 내려받는다. 로컬에서 같은 URL은 200을 받는다.
  따라서 루틴 클라우드 환경(`jam-ops`)의 네트워크 허용 목록에 이 호스트가 없어 이그레스 프록시가 403을
  돌려준 것으로 판단한다(확신도: 보통 — 클라우드에서 직접 재현하지는 않았다).
- ② 본문(`body_markdown`)이 있는 템플릿은 `editorial_article`뿐이다. 나머지 템플릿에는 설명을 쓰는 규칙이 없었다.
- ③ `UX_WRITING_GUIDELINE.md` §2.1(해요체)은 제품 UI 문구 규칙이고, 윤진이 따르는 브랜드 보이스 가이드에는 어미
  규칙이 없었다. 월요일 본문은 TRIBES.md 원문(`-다`체)을 인용 표시 없이 이어 붙였다.
- ④ 윤진 정의·PRD §8에 "원문을 요약·재작성하지 않고 인용"하라는 규칙만 있고 기사 구성 규칙이 없었다.

## 상세 요구사항

### 컨텐츠 관점
- 사용자 결정(2026-09-29): 설명은 **카드 템플릿에 따라** 쓴다 — 기사는 본문 전문, 그 밖의 템플릿은 짧은 설명.
  설명은 후보마다 표에 함께 보인다.
- 윤진이 쓰는 문장은 해요체다. 인용한 세계관 원문은 따옴표로 구분하고 원문 어미를 그대로 둔다.
- 기사 본문은 「설명(원문 인용 포함) → 킥(유저의 재미·동기를 끄는 한 방) → CTA」 순서로 쓴다.

### 서비스/코드베이스 관점
- 이미지 레이어 원본을 못 받으면 오류 메시지에 URL과 「네트워크 허용 목록 확인」 안내가 나온다.

## 완료 조건

- PRD §8 표 형식에 「설명」 칸이 있고, 템플릿별 설명 규칙·해요체 규칙·기사 구성(설명→킥→CTA) 규칙이 적혀 있다.
- 브랜드 보이스 가이드에 어미 규칙(해요체, 인용 예외)이 있다.
- 윤진 정의와 루틴 프롬프트 초안이 PRD §8을 가리키고 새 규칙과 충돌하지 않는다.
- `scheduled-jobs.md`에 이미지 단계가 필요로 하는 호스트(`ceehnkzdbecxwzxrhhns.supabase.co`)가 적혀 있다.
- 렌더 스크립트가 이미지 레이어 원본을 못 받으면 URL과 허용 목록 안내가 담긴 오류를 낸다.

### 후속 범위 (담당: 사용자·카리나, 시점: 이 티켓 커밋 뒤)
- 사용자가 claude.ai 환경 설정에서 `jam-ops` 허용 목록에 `ceehnkzdbecxwzxrhhns.supabase.co`를 추가한다.
