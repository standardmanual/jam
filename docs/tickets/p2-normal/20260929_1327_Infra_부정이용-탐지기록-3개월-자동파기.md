# [Infra] 부정 이용 탐지 기록(abusing_logs)을 3개월이 지나면 자동으로 파기한다

## 핵심 요약
- 요구사항: 개인정보 처리방침 v1.1(적용일 2026-10-01) 3항과 위치기반서비스 이용약관 제5조는 부정 이용 탐지 기록의 보유기간을 "탐지일로부터 3개월"로 적었다. 현재 `abusing_logs`는 기간 제한 없이 쌓이므로, 3개월이 지난 행을 지우는 정리 작업을 만든다.
- 구현 계획: 기존 일일 크론(`jam-web/vercel.json`의 `/api/cron/poi-cleanup`, 매일 00:00 UTC)에 삭제 단계를 붙이거나 새 크론 경로를 만든다. `created_at < now() - interval '3 months'` 기준 삭제. 크론 추가는 Vercel 요금·빌드와 무관하나 기존 크론 재사용을 우선 검토한다.
- 관련 파일: `jam-web/vercel.json`(crons), `jam-web/src/app/api/cron/poi-cleanup/route.ts`, `jam-web/supabase/migrations/010_abusing_policy.sql`(58행 `abusing_logs` 정의), `jam-web/src/lib/abusing/`(`logAbusingEvent`)

## 배경 / 문제 정의
티켓 20260929_1326에서 처리방침 보유기간을 약관 초안(2026-09-29 사용자 확정값 3개월)과 맞췄다. 문서는 3개월을 약속하지만 파기 장치가 없어, 적용일(2026-10-01) 이후 3개월이 지나는 2027-01-01 전에는 구현돼야 서술이 사실이 된다. `LOCATION_TERMS.md` 하단 B-3, `PRIVACY_POLICY.md` 하단 7번과 같은 과제다.

## 완료 조건
- 탐지일로부터 3개월이 지난 `abusing_logs` 행이 매일 한 번 자동 삭제된다. 확인 방법: 테스트에서 `created_at`이 3개월 1일 전인 행과 2개월 전인 행을 두고 정리 함수를 실행하면 앞의 행만 사라진다.
- 삭제 건수가 크론 응답 또는 서버 로그에 남는다.
- `PRIVACY_POLICY.md` 하단 7번과 `LOCATION_TERMS.md` B-3을 해결로 표시한다.
