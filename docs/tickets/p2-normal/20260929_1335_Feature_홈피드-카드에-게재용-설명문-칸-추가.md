# [Feature] 홈피드 카드에 게재용 설명문 칸 추가

## 핵심 요약

- 요구사항: 에디토리얼 기사가 아닌 홈피드 카드에도 유저에게 보이는 짧은 설명문(40자 이하)을 넣을 수 있게 한다.
  지금은 제목·부제만 보여서, 주간 편성안의 「설명(게재 문안)」을 담을 곳이 없다(2026-09-29 사용자 결정).
- 구현 계획: `today_cards.description`(text, nullable) 추가 → 홈 카드 화면이 부제 아래에 표시 → 어드민 폼·상세에서
  입력·표시 → 홈피드 등록 묶음(`register-home-feed-card.mjs`)이 받는다. 기사(`editorial_article`)는 본문이 있으므로 쓰지 않는다.
- 관련 파일:
  - `jam-web/supabase/migrations/197_today_cards_description.sql` (신규: 컬럼 추가 + 되돌림 SQL 주석, 번호는 push 직전 `origin/staging` 기준 재확인)
  - `jam-web/src/types/database.ts`·`database.generated.ts` — `today_cards` Row/Insert/Update에 `description`
  - `jam-web/src/app/(main)/TodayCardStack.tsx` — 레이아웃별 렌더 함수에서 `card.subtitle` 출력 바로 아래(94·116·154·193·205·243줄 부근). 어느 레이아웃에 보일지는 채원① 판정을 따른다
  - `jam-web/src/lib/admin/today-sections.ts` — 폼 값 타입(51줄 부근 `body_markdown` 옆)·`TODAY_FIELDS_FOR`/저장 페이로드 변환(305줄 부근)
  - `jam-web/src/app/admin/today/TodayCardForm.tsx` — 상태(134줄 부근)·입력 칸·저장 페이로드(334줄 부근)
  - `jam-web/src/components/admin/today/TodayCardDetail.tsx` — 상세 표시
  - `jam-web/src/app/api/admin/today/route.ts`·`[id]/route.ts` — 허용 필드 목록이 있으면 추가
  - `jam-web/scripts/asset-generator/registerHomeFeedBundle.mjs`(검증: 문자열·길이·제어 문자, 기사 템플릿이면 거절)·`registerHomeFeedRecord.mjs`(insert 페이로드)
  - 테스트: `src/lib/admin/__tests__/today-sections.test.ts`, `src/lib/today/__tests__/today-logic.test.ts`(카드 픽스처), `scripts/asset-generator/__tests__/registerHomeFeedBundle.test.ts`
  - 문서: home-feed PRD(카드 필드·레이아웃 표시 절, 생성 구간은 `node scripts/gen-team-doc.mjs` 등 근거 설정으로 재생성), `02_DATA_MODEL.md` today_cards 절, `HOME_FEED_REGISTRATION_BUNDLE.md` 필드 표

## 배경 / 문제 정의

- 티켓 20260929_1250에서 주간 편성안의 「후보 설명」을 게재 문안과 운영 메모로 나눴다. 기사 카드는 게재 문안이
  `body_markdown`으로 들어가지만, 그 밖의 카드는 담을 칸이 없어 승인해도 등록할 수 없다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `description`은 nullable text. 값이 없으면 화면은 지금과 똑같다(회귀 없음).
- `editorial_article`은 description을 쓰지 않는다: 어드민 폼은 이 템플릿에서 칸을 숨기고 저장 시 비운다(다른 템플릿 전용 필드와 같은 방식). 등록 묶음은 기사에 description이 있으면 거절한다.
- 길이 상한: 40자(공백 포함). 어드민 폼과 등록 묶음이 같은 상수를 쓴다. 줄바꿈 불가.
- 표시: 부제 아래 한 덩어리 문단, 14px(`--text-small`), 넘치면 2줄에서 말줄임(`line-clamp-2`). `shortcut` 레이아웃은 그리지 않고 어드민 폼에 「바로가기형은 화면에 보이지 않아요」 안내를 둔다.
- 사용자 결정(2026-09-29, 채원① 승인 항목): 2줄 + 40자 상한, 바로가기형 미표시, 14px, 기사 템플릿 전환 시 값 삭제 안내 한 줄.

### UI/UX 관점
- 채원①이 판정할 것: 어느 레이아웃(`large_thumbnail`·`banner`·`shortcut`·`badge_gallery`·`ranking_list`·`other`)에 보일지, 토큰, 줄 수 제한.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 마이그레이션 파일이 컬럼 추가와 되돌림 SQL(주석)을 담는다. 실행은 하지 않는다.
- description이 있는 비기사 카드는 채원①이 정한 레이아웃에서 부제 아래에 보이고, 없는 카드는 이전과 같은 모양이다(테스트 또는 스토리로 확인).
- 어드민 폼에서 비기사 템플릿은 설명문을 입력·수정·저장할 수 있고, 기사 템플릿에서는 칸이 보이지 않고 저장 값이 null이다.
- `register-home-feed-card.mjs --dry-run`이 description을 받아 insert 페이로드에 넣고, 40자 초과·줄바꿈·기사 템플릿에 description이 있으면 거절한다(테스트).
- `scripts/verify.sh` 통과.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤)
- 사용자 승인 뒤 마이그레이션 실행(Supabase MCP), `database.generated.ts` 재생성 필요 여부 확인.
- 콘텐츠 자동화 PRD §8·윤진 정의·루틴 프롬프트의 「게재 문안」이 description 칸으로 들어간다는 연결(티켓 20260929_1250 후속과 함께).
