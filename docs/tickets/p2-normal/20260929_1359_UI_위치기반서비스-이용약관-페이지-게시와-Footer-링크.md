# [UI] 위치기반서비스 이용약관 페이지를 게시하고 Footer의 개인정보처리방침 아래에 링크를 둔다

## 핵심 요약
- 요구사항: `docs/specs/LOCATION_TERMS.md` 원고(제1조~부칙)를 `/location-terms` 페이지로 게시하고, 전역 Footer의 「개인정보처리방침」 링크 바로 아래에 「위치기반서비스 이용약관」 링크를 추가한다. 원고 하단 「게시 전 확인 필요 사항」(내부 메모)은 페이지에 옮기지 않는다.
- 구현 계획: `/privacy` 페이지(`jam-web/src/app/(main)/privacy/page.tsx`)와 같은 레이아웃·타이포 패턴으로 새 페이지를 만든다. 표(제5조 서비스 표, 제6조 위탁 표)는 `/privacy`처럼 세로형 정의 카드로 바꿔 가로 스크롤을 만들지 않는다.
- 관련 파일:
  - `jam-web/src/app/(main)/location-terms/page.tsx` — 신규. 참고 원본은 `jam-web/src/app/(main)/privacy/page.tsx` 전체(상단 주석 3~24행, 로컬 헬퍼 `Section`·`P`·`Note`·`H3`·`OrderedList`·`DefCard` 31~92행, 본문 94행~)
  - `jam-web/src/components/ui/Footer.tsx` — `FOOTER_EXCLUDED_PATHS`(24행)에 `'/location-terms'` 추가, 상단 주석(15~19행)에 제외 사유 한 줄, 링크 묶음 `div`(53~66행)의 `/privacy` 링크 바로 아래에 같은 `className`으로 링크 추가
  - `jam-web/src/lib/i18n/ko.ts` — `common.footerPrivacy`(37행) 아래에 `footerLocationTerms: '위치기반서비스 이용약관'`
  - `docs/specs/LOCATION_TERMS.md` — frontmatter `status: draft` → `active`, `description`과 머리말(10~15행)의 "아직 게시하지 않은 초안" 서술을 게시 사실로 교체, 하단 메모 제목을 「남은 확인 필요 사항」으로 변경

## 배경 / 문제 정의
위치기반서비스 이용약관 원고는 2026-09-29 사업자 정보·보유기간·위탁·시행일(2026-10-01)이 확정됐다(티켓 20260929_1303). 사용자가 같은 날 Footer의 개인정보처리방침 아래에 약관 링크를 두고 지금 게시하기로 결정했다. 동의 화면·위치정보 이용 기록 등 게시 전제 구현 과제는 원고 하단 메모에 남긴 채 진행한다(사용자 결정).

## 상세 요구사항

### UI/UX 관점
- 페이지 제목(TopNav·h1): `위치기반서비스 이용약관`
- 본문은 원고 문구를 그대로 옮긴다(조·항·호 번호와 표 내용 포함). 문구를 새로 다듬지 않는다 — 원고와 페이지가 한 글자라도 다르면 어느 쪽이 맞는지 알 수 없게 된다.
- 제5조 표는 서비스 5개를 카드 하나씩(서비스 / 이용하는 위치정보 / 목적 및 내용 / 보유기간), 제6조 표는 수탁자 3개를 카드 하나씩(수탁자 / 위탁 업무 / 전달하는 정보)으로 바꾼다.
- 제14조·제15조의 사업자 정보도 카드형으로 둔다.
- 부칙의 시행일(2026년 10월 1일)은 상수 하나로 둔다.
- Footer 새 링크는 기존 두 링크와 같은 스타일·간격이며, `/location-terms` 화면에서는 Footer를 숨긴다(`/privacy`와 같은 이유).

## 구현 계획
1. `jam-web/src/app/(main)/location-terms/page.tsx` 신규(서버 컴포넌트, 예상 350~400줄). 헬퍼를 `/privacy`에서 복사할지 공용으로 뽑을지는 채원① 판정을 따른다.
2. `jam-web/src/components/ui/Footer.tsx` 링크·제외 경로·주석(약 10줄).
3. `jam-web/src/lib/i18n/ko.ts` 문자열 1줄.
4. `docs/specs/LOCATION_TERMS.md` frontmatter·머리말·메모 제목(약 10줄).

## 완료 조건
- 로그인한 상태로 `/location-terms`를 열면 제1조부터 부칙까지 원고와 같은 문구가 보이고, 「게시 전 확인 필요 사항」·「남은 확인 필요 사항」 메모 내용은 보이지 않는다.
- 375px 폭에서 `/location-terms`에 가로 스크롤이 없다(`document.documentElement.scrollWidth <= clientWidth`).
- 홈 등 Footer가 보이는 화면에서 링크가 Philosophy → 개인정보처리방침 → 위치기반서비스 이용약관 순서로 세로로 보이고, 새 링크를 누르면 `/location-terms`로 이동한다.
- `/location-terms` 화면에는 Footer가 보이지 않는다.
- `LOCATION_TERMS.md`의 `status`가 `active`이고 머리말에 "아직 게시하지 않은 초안" 서술이 없다.
- `scripts/verify.sh`가 통과한다.

## 주요 의사결정
- 새 페이지 하나가 350줄을 넘어 `plan_only` 임계값(100줄)을 넘는다. 파일 단위 계획을 위에 적었고, 원고를 옮기는 단순 반복 작업이라 쪼갤 실익이 없으며, 사용자가 게시 시점(지금)을 확정했으므로 첫 호출부터 계획 반환을 면제한다.
