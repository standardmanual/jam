# [Service] 개인정보 처리방침·위치기반서비스 이용약관 페이지를 로그인 없이 볼 수 있게 한다

## 핵심 요약
- 요구사항: `/privacy`와 `/location-terms`(티켓 20260929_1359에서 신설)를 로그인하지 않은 방문자도 열 수 있게 한다. 로그인 화면의 동의 안내 문구에서 두 문서로 갈 수 있게 링크를 거는 것도 검토한다.
- 구현 계획: `jam-web/src/proxy.ts`의 `publicPaths`(56행)에 두 경로를 추가한다. 두 페이지가 로그인 사용자 정보를 쓰지 않는지(`(main)/layout.tsx`가 세션을 요구하는지 포함) 먼저 확인한다.
- 관련 파일: `jam-web/src/proxy.ts`(56~57행 `publicPaths`·`isPublicPath`), `jam-web/src/app/(main)/layout.tsx`, `jam-web/src/lib/i18n/ko.ts`(854행 `terms` 문구), 로그인 화면 컴포넌트

## 배경 / 문제 정의
2026-09-29 조사에서 `publicPaths`에 `/privacy`가 없는 것을 확인했다. 로그인하지 않은 방문자는 방침을 열면 `/login`으로 보내진다. 로그인 화면은 "계속하면 JAM!의 이용약관 및 개인정보처리방침에 동의하는 것으로 간주돼요"라고 안내하는데, 동의하기 전에는 그 방침을 읽을 수 없다. 「개인정보 보호법」 제30조제2항은 처리방침을 정보주체가 쉽게 확인할 수 있게 공개하도록 정한다.

## 완료 조건
- 로그아웃 상태에서 `/privacy`와 `/location-terms`를 열면 리다이렉트 없이 본문이 보인다.
- 다른 보호 경로(예: `/`, `/profile`)는 로그아웃 상태에서 종전대로 `/login`으로 간다.
