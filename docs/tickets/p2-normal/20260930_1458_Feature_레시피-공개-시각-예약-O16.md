# [Feature] 레시피 공개 시각 예약 (O16)

> 상위: 20260930_1450 · 순서 2 병행 · 07 인벤토리 G(O16)

## 핵심 요약

- 요구사항: 레시피를 만들어 두고 정한 시각에 공개한다. 지금은 만들면 바로 모든 유저에게 공개된다(07 5.1, 06 7절). 운영툴에서 레시피를
  예약 공개하려면 먼저 필요하다.
- 구현 계획: 혜린 검토에서 확정한다. 비공개 기능이 마이그레이션 174에서 삭제된 이력이 있으니 그 사유를 먼저 확인한다.
- 관련 파일: `jam-web/src/lib/combine/`, `jam-web/src/app/api/admin/recipes/`, `jam-web/src/app/admin/recipes/`,
  `jam-doc/planning/content/COMBINE_RECIPES.md`.

## 시작 절차

상위 티켓 20260930_1450의 「진행 규칙」을 따른다. 새 세션에서 시작하고, **혜린의 검토와 사용자 질문을 거쳐 답을 이 티켓에 적은 뒤에만**
작업을 시작한다. 진행 중에 이미 개발된 것에 영향이 생기면 별도 티켓으로 떼어 바로 실행한다.

## 완료 조건

- 공개 시각을 미래로 둔 레시피는 그 시각 전까지 유저의 믹스 화면과 API에 나오지 않고, 시각이 되면 나온다(테스트).
- 공개 시각 전에 공개를 취소할 수 있다.
- `COMBINE_RECIPES.md`와 관련 PRD가 갱신됐다.
