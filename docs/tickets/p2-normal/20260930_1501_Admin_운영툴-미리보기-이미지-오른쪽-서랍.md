# [Admin] 운영툴 미리보기·이미지·오른쪽 서랍

> 상위: 20260930_1450 · 순서 3 · 07 인벤토리 D

## 핵심 요약

- 요구사항: 자원별 미리보기(저장하지 않는 렌더), 오른쪽 서랍의 에셋 제너레이터와 컨텐츠 연결, 승인 때 에셋 제너레이터로 실제 이미지 생성
  (07 4.1·4.3·4.5, 06 12.4의 3).
- 구현 계획: 기획안에 담긴 색·문안·프리셋으로 렌더한다. 프리셋 렌더는 AI를 쓰지 않는다. 「색 대기」 카드는 사용자가 서랍에서 색을 채운다(07 9절 2).
- 관련 파일: `jam-web/src/app/admin/asset-generator/`, `jam-web/scripts/asset-generator/render.mjs`, `jam-web/src/app/admin/today/TodayPreviewModal.tsx`.
- 관련 티켓: 에셋 제너레이터 후속 20260926_0105·1341·1758·1759·1811·1815·1824·1825·1826·1827·1830·2331, 20260927_0008·0124·0129·0130
  (착수 때 함께 판단한다, 2026-09-30 티켓 20260930_1451 사용자 결정).

## 시작 절차

상위 티켓 20260930_1450의 「진행 규칙」을 따른다. 새 세션에서 시작하고, **혜린의 검토와 사용자 질문을 거쳐 답을 이 티켓에 적은 뒤에만**
작업을 시작한다. 진행 중에 이미 개발된 것에 영향이 생기면 별도 티켓으로 떼어 바로 실행한다.

## 선행 조건

1455(골격). 홈피드 카드 미리보기는 1453의 구현을 따른다.

## 완료 조건

- 샘플 묶음의 모든 항목이 기획 상세에서 미리보기로 보인다.
- 서랍에서 색이나 문안을 바꾸면 미리보기가 바로 바뀌고, 서랍이 열려도 원래 화면이 그대로 보인다.
- 승인하면 이미지가 만들어져 해당 자원에 붙는다.
