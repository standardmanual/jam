# [Admin] 운영툴 패턴 사전과 학습 기능

> 상위: 20260930_1450 · 순서 4 · 07 인벤토리 E

## 핵심 요약

- 요구사항: 패턴 사전(S5, DB), 조합 뽑기 읽기 API, 결정 기록·결과 읽기 API, 결과와 기록 화면(S6), 컬렉션별 아이템 획득 경로를 만든다
  (07 3.4·4.3·4.8, 06 6.3).
- 구현 계획: 에이전트는 기존 자동화 토큰(읽기)으로 읽는다. 조합 뽑기는 최근에 덜 쓴 패턴·트라이브·지점 카테고리를 돌려준다.
- 관련 파일: `jam-web/src/lib/admin/auth.ts`, `jam-web/src/app/api/admin/`, 1454(패턴 사전 원고).

## 시작 절차

상위 티켓 20260930_1450의 「진행 규칙」을 따른다. 새 세션에서 시작하고, **혜린의 검토와 사용자 질문을 거쳐 답을 이 티켓에 적은 뒤에만**
작업을 시작한다. 진행 중에 이미 개발된 것에 영향이 생기면 별도 티켓으로 떼어 바로 실행한다.

## 완료 조건

- 툴에서 패턴을 만들고 고칠 수 있고, 새 패턴 후보를 승인하면 사전에 들어간다.
- 자동화 토큰으로 조합 뽑기, 결정 기록(수정 전후 차이 포함), 결과를 읽을 수 있다(테스트).

- 카드 노출·열람 이벤트의 「패턴」 열이 패턴 사전의 패턴을 기록하고, 패턴별 결과에서 카드 노출·열람을 볼 수 있다. 잇는 방식은 티켓 20260930_1453의
  사용자 결정 4(이벤트마다 모양·패턴 복사 저장, 패턴 열은 이 티켓 뒤에 채운다)를 따른다(2026-09-30 티켓 20260930_1451 사용자 결정으로 추가,
  같은 날 1453에서 결정).
- 시험 묶음(`is_sample: true`)은 결정 기록·결과 읽기 API와 패턴별 결과에서 뺀다(2026-09-30 티켓 20260930_1455 가정 8로 추가).
- 「획득 경로가 막힌 컬렉션」 신호(07 4.2)가 조건을 만들었을 때 운영 홈에 뜬다. 자리는 1502 ①·②가 만든다(2026-10-01 1502 시작 검토로 추가).
