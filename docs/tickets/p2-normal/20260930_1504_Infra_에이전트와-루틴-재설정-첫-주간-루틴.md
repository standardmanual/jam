# [Infra] 에이전트와 루틴 재설정, 첫 주간 루틴 실행

> 상위: 20260930_1450 · 순서 5 · 07 인벤토리 I

## 핵심 요약

- 요구사항: 07 3절대로 에이전트와 루틴을 바꾸고, 첫 주간 루틴을 새 체계로 실행한다.
- 구현 계획: 윤진·윈터·채원·혜린·카즈하·하니의 정의, `/jam-story`, 주간·월간 루틴 스펙, 혜린의 「주간 밸런스 점검」 모드, 기획안 제출
  스크립트, 기획안의 「유저가 겪는 것」 쉬운 문장을 반영한다. 주간 리포트는 브리핑·분석만 담는다(06 11.7의 8).
- 관련 파일: `.claude/agents/jam-marketer.md`·`jam-tribe.md`·`jam-designer.md`·`jam-pm.md`·`jam-ops.md`·`jam-guide.md`, `.claude/skills/jam-story/SKILL.md`,
  `.claude/skills/jam-work/references/scheduled-jobs.md`, `docs/agents/team-operations.md`(자동 생성 구간은 `node scripts/gen-team-doc.mjs`),
  티켓 20260926_1541·1546·1549(지금 루틴 프롬프트), 06 플랜 12절.

## 시작 절차

상위 티켓 20260930_1450의 「진행 규칙」을 따른다. 새 세션에서 시작하고, **혜린의 검토와 사용자 질문을 거쳐 답을 이 티켓에 적은 뒤에만**
작업을 시작한다. 진행 중에 이미 개발된 것에 영향이 생기면 별도 티켓으로 떼어 바로 실행한다.

## 선행 조건

1455(제출 API), 1503(읽기 API). 1454의 패턴이 툴에 입력되어 있어야 첫 루틴이 조합 뽑기를 쓸 수 있다.

## 주의

- 에이전트 정의와 예약 루틴 저장 프롬프트의 교체는 사용자 승인을 받는다.
- 전환하는 날까지 지금 루틴과 등록 절차를 유지한다(진행 규칙 7). 전환하면 옛 경로(리포트의 홈피드 초안, 예약 실행의 이미지 생성, 시드 SQL 등록)를 닫는다.

## 완료 조건

- 화요일 루틴이 새 순서(07 3.2)로 돌아 받은 기획함에 운영 묶음을 제출했다.
- 사용자가 툴에서 그 묶음을 승인해 예약 공개까지 1회 끝났고, 결정 기록과 슬랙 이력 알림이 남았다.
- 에이전트 정의와 팀 운영 지도가 갱신됐고 pre-commit 정합성 검사가 통과한다.
