### 1회차: 보내는 도구 (화면 없음, 클라우드·DB 영향 없음)

기준: 루틴은 쉘 명령으로 서버를 부르고, 윤진은 `curl`과 직접 명령이 금지라(`.claude/agents/jam-marketer.md` 53~59행) **스크립트 한 개로만** 보낸다. 서비스 롤 키는 쓰지 않고 읽기 토큰(`ADMIN_API_READ_TOKEN`)만 쓴다. 토큰의 쓰기가 열린 경로는 정확히 두 개(`POST /api/admin/ops-inbox`, `POST /api/admin/ops-inbox/routine-start`, 경로 상수는 `jam-web/src/lib/admin/opsInbox/constants.ts`)다.

1. `scripts/ops-submit.mjs` (새, `scripts/admin-api-read.mjs`의 환경변수·오류 처리 방식을 따른다): `node scripts/ops-submit.mjs bundle <묶음.json>`은 파일을 읽어 1MB를 넘으면 보내기 전에 막고 `POST ${ADMIN_API_BASE_URL}/api/admin/ops-inbox`로 보낸다. `node scripts/ops-submit.mjs start <시작.json>`은 16KB를 넘으면 막고 `.../routine-start`로 보낸다. 허용하는 경로는 이 두 개뿐이고 다른 경로 이름이 오면 실패한다. 응답은 요약만 출력한다(상태 코드, `id`, `bundle_id`, `item_count`, `format_errors`, `warnings`. 토큰·본문 전체는 출력하지 않는다). 상태별 문장: 201 받음, 200 이미 같은 묶음을 받음(재시도 안전), 409 같은 `bundle_id`에 다른 내용이라 **새 `bundle_id`로 다시 보내라**, 400 형식 오류(서버가 준 `details`를 그대로), 401·403 토큰 문제, 그 밖은 일반 실패. 종료 코드는 성공 0, 이미 받음 0, 그 밖 1. `ADMIN_API_BASE_URL`은 `https://`이거나 `http://localhost`일 때만 받는다(토큰을 평문으로 보내지 않는다). `ADMIN_API_READ_TOKEN`이 없으면 실행하지 않는다.
2. `scripts/ops-read.mjs` (새): `node scripts/ops-read.mjs <이름>`이 허용 목록의 GET 경로 하나를 읽고 JSON을 그대로 출력한다. 이름→경로: `trend-sources`(`/api/admin/ops-trend-sources`, 켜진 출처만), `patterns-draw`(`/api/admin/ops-patterns/draw`, 조합 뽑기), `rules`(`/api/admin/ops-rules`), `decisions`(`/api/admin/ops-decisions`), `patterns`(`/api/admin/ops-patterns`), `item-paths`(`/api/admin/item-paths`), `kpi-weekly`(`/api/admin/kpi/weekly`), `today-metrics`(`/api/admin/today/metrics`). 각 이름의 정확한 경로·메서드·쿼리는 `jam-web/src/app/api/admin/` 아래 라우트 파일에서 확인해 맞추고(조합 뽑기가 POST면 그에 맞게), 쿼리가 필요한 것은 `--query key=value`로 받는다. 응답이 너무 길면 줄이지 않고(재료 판단은 에이전트 몫) 그대로 낸다. 인증·URL 규칙은 `ops-submit.mjs`와 같다. 새 경로를 더할 때 쓰는 목록은 한 상수 객체 하나다.
3. 시험: `scripts/ops-submit.test.mjs`·`scripts/ops-read.test.mjs`(다른 `scripts/*.test.mjs`와 같은 방식, 로컬 `http.createServer` 가짜 서버로 201·200·409·400·401·네트워크 오류·1MB 초과를 확인하고, 토큰이 출력과 오류 문장에 없고, 허용 밖 경로·`http://` 원격 주소·토큰 없음이 거절됨을 확인한다). **두 경로 상수가 `jam-web/src/lib/admin/opsInbox/constants.ts`와 같은지** 파일 텍스트로 대조하는 시험을 둔다. 임시 저장소를 쓰는 시험은 `GIT_*` 환경변수를 지우고 쓴다.
4. 문서: `.claude/skills/jam-work/references/scheduled-jobs.md`의 「무인 경로에 적용하는 점검」과 「데이터 출처」에 두 스크립트를 허용 명령으로 적고(「예약 실행은 DB 쓰기·DB 변경을 하지 않는다」 문장 70·92줄 부근에는 받은 기획함 제출과 시작 기록 예외를 이미 적었는지 확인하고 빠진 것만 더한다), `docs/agents/contract.json`의 `paths_exist`에 새 스크립트·시험 경로를 더한다(`node scripts/check-contract.mjs`로 확인).

**1회차에서 하지 않는 것**: 에이전트 정의·루틴 스펙 수정(회차 2·3), 클라우드 루틴 등록·실행, 실제 묶음 제출(시험 제출도 이 회차에서는 로컬 가짜 서버로만), `routineCheckStartsAt` 쓰기.
