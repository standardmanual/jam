# [Feature] 서비스 옵션 11개 (O1~O4, O7, O9~O14)

> 상위: 20260930_1450 · 순서 상시 · 07 인벤토리 G(나머지)

## 핵심 요약

- 요구사항: 운영툴을 막지 않으면서 운영 패턴의 폭을 넓히는 서비스 옵션 11개를 만든다(07 5.2, 06 6.2).
- 구현 계획: 이 티켓은 목록 관리용이다. 착수할 때 옵션 하나씩 별도 티켓(`parent: "20260930_1450"`)으로 나눠 새 세션에서 진행한다. 여는
  아이디어가 많은 O1·O2·O3부터 한다.
- 관련 파일: 06 플랜 6.1(지금 되는 것과 안 되는 것)·6.2(옵션과 여는 아이디어).

## 시작 절차

상위 티켓 20260930_1450의 「진행 규칙」을 따른다. 새 세션에서 시작하고, **혜린의 검토와 사용자 질문을 거쳐 답을 이 티켓에 적은 뒤에만**
작업을 시작한다. 진행 중에 이미 개발된 것에 영향이 생기면 별도 티켓으로 떼어 바로 실행한다.
