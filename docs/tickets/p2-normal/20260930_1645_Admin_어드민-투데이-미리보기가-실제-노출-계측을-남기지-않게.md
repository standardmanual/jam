# [Admin] 어드민 투데이 미리보기가 실제 노출 계측을 남기지 않게 한다

> 상위: 20260930_1450 · 티켓 20260930_1453 설계 중 채원 사전 판정에서 발견(2026-09-30)

## 핵심 요약

- 요구사항: 어드민 투데이 미리보기에서 카드를 그릴 때 노출·클릭 이벤트(`/api/today/events`, GA `today_card_click`)를 보내지 않는다.
  카드를 눌러도 어드민이 서비스 화면으로 이동하지 않게 한다.
- 구현 계획: 미리보기 경로에서는 `TodayCardTracker`와 카드 링크를 그리지 않는다(예: `TodayCardStack`에 미리보기 여부를 알리는 prop을 더한다).
  1453 구현에서 새 카드 그리기가 「계측 정보가 없으면 트래커·링크를 그리지 않는다」 규칙을 갖게 되므로, 그 전에 끝낼지 1453 구현에 흡수할지는
  착수할 때 정한다.
- 관련 파일:
  - `jam-web/src/app/admin/today/TodayPreviewModal.tsx` 12줄(`TodayCardStack` import), 81줄(렌더)
  - `jam-web/src/app/(main)/TodayCardStack.tsx` 346줄 부근(`TodayCardTracker`로 카드를 항상 감싼다)
  - `jam-web/src/app/(main)/TodayCardTracker.tsx`(노출 `IntersectionObserver`, 클릭 GA 이벤트 68줄)
  - `jam-web/src/lib/today/events.ts` 64줄 `assertCardExposable`(기간·활성만 확인한다)

## 배경 / 문제 정의

- 어드민 미리보기는 홈과 같은 `TodayCardStack`을 재사용하고, `TodayCardStack`은 모든 카드를 `TodayCardTracker`로 감싼다(코드 확인, 2026-09-30).
- 그래서 어드민이 오늘 날짜를 미리 보면 게재 중인 카드의 노출 이벤트가 실제로 기록된다. 서버의 `assertCardExposable`은 카드의 기간과 활성 여부만
  확인하므로 이 기록을 거르지 못한다. 카드를 누르면 클릭 이벤트가 남고 어드민이 서비스 화면으로 이동한다.
- 이 계측은 카즈하 주간 브리핑과 윤진의 유형 리뷰에 쓰인다. 노출 수가 작아서(주간 노출 한 자릿수 유형이 있다) 어드민 미리보기 몇 번으로도 수치가 흔들린다.
- 어드민 미리보기의 배지가 모두 흑백으로 보이는 문제(미리보기 데이터에 `earned` 값이 없어 미보유로 그린다)도 함께 발견됐다. 이 티켓에서 함께
  고칠지는 착수할 때 정한다.

## 완료 조건

- 어드민 미리보기에서 카드를 보여도 `/api/today/events` 요청과 GA `today_card_click`이 발생하지 않는다(테스트 또는 네트워크 확인).
- 미리보기에서 카드를 눌러도 서비스 화면으로 이동하지 않는다.
- 홈 화면의 노출·클릭 계측은 그대로 동작한다(기존 테스트 통과).

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약

- `TodayCardStack`에 `preview?: boolean`(기본 false)을 더했다. 켜면 `TodayCardTracker`와 카드 `<Link>`를 그리지 않는다. 랭킹 카드는 제목 링크·트래커 2곳·순위 행 링크(`username: null`)를 모두 끈다.
  의미는 「계측과 이동을 끄고 모양만 그린다」 하나라서 1453 구현이 그대로 이어받는다. 홈과 미리보기가 같은 본문을 그리도록 레이아웃 선택을 `CardBody`로 뺐다(홈 DOM 동일).
- 날짜 미리보기 모달(`TodayPreviewModal.tsx`)과 카드 폼의 「홈 화면 미리보기」(`TodayCardForm.tsx`)가 `preview`를 켠다. 카드 폼 미리보기는 저장된 카드를 고칠 때 실제 카드 id로
  노출을 기록할 수 있던 같은 결함이라 함께 막았다(아현 발견, 민지 범위 안 판정).
- PRD home-feed §9에 «어드민 미리보기는 계측 대상이 아니다» 불릿을 더했다.
- 게이트: 민지 1차 PASS(CI 36807291939). 머지 `01bcd689`(리뷰 브랜치 `claude/jamwork-20260930_1645-today-preview-no-tracking`, 범위 `ce03c617..019805d9`).
  머지 전 오염 검사는 staging만 앞서 가서 실패했고, 브랜치에 이 티켓 커밋만 있고 겹치는 파일·충돌이 없음을 확인해 오염이 아니라고 판정했다.
