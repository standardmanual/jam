# [Service] 홈피드 시간대 태그 경계를 운영 패턴 사전에 맞춘다

> 상위: 20260930_1450 · 영향 티켓(진행 규칙 4) · 티켓 20260930_1453 결정 19에서 생성

## 핵심 요약

- 요구사항: 홈피드 노출 시간대 태그 5개의 경계를 운영 패턴 사전의 시각 정의(심야 22:00~05:00, 새벽·이른 아침 05:00~08:00, KST)에 맞춘다.
  새 경계는 `time_dawn` 05~08, `time_morning` 08~11, `time_afternoon` 11~17, `time_evening` 17~22, `time_night` 22~05다(2026-10-01 사용자 결정).
- 구현 계획: 판정 함수와 어드민 라벨을 고치고, 홈피드 PRD 생성 구간을 다시 만든다. 태그 이름은 바꾸지 않는다.
- 관련 파일:
  - `jam-web/src/lib/today/exposure.ts` 33~40줄 `timeOfDayTag()` (경계 분기와 줄 끝 주석)
  - `jam-web/src/lib/today/__tests__/today-logic.test.ts` (`timeOfDayTag` 경계 테스트)
  - `jam-web/src/lib/admin/today-sections.ts` 140~144줄 `TODAY_EXPOSURE_TAG_OPTIONS`의 시간대 라벨
  - `docs/specs/prd/home-feed/PRD.md` 생성 구간 `exposure-tags`(손으로 고치지 않고 `node scripts/gen-home-feed-doc.mjs`로 다시 만든다)
  - `jam-doc/planning/content/OPS_PATTERNS.md` 63줄(「`time_dawn`(00~06시)은 새벽 조건의 근거로 쓰지 않는다」 문장)

## 배경 / 문제 정의

- 지금 `time_dawn`은 00~06시라 심야(22~05시)를 포함한다. 운영 패턴 사전은 심야 활동 권유를 닫고 새벽·이른 아침(05~08시)은 연다.
  그래서 사전은 `time_dawn`을 새벽 조건의 근거로 쓰지 않는다고 적어 두었다(티켓 20260930_1454 윈터 검수).
- 티켓 20260930_1453 완료 조건에 「태그 범위나 이름을 이 정의에 맞출지 정한다」가 남아 있었고, 사용자가 2026-10-01에 「범위를 05~08시로
  변경, 나머지 경계도 패턴 사전과 완전히 일치」로 정했다(1453 결정 19).
- 카리나가 읽은 값(2026-10-01, 읽기 전용): 시간대 태그가 붙은 카드는 4장(`time_dawn` 2, `time_morning` 1, `time_afternoon` 1)이고,
  노출 중이거나 게재 예정인 카드는 0장이다. 경계를 바꿔도 지금 운영되는 노출에는 영향이 없다.

## 구현 계획

1. `timeOfDayTag()`의 분기를 새 경계로 바꾼다. `time_night`는 22~24시와 00~05시 두 구간이다.
2. 라벨을 `time_dawn (05~08)`, `time_morning (08~11)`, `time_afternoon (11~17)`, `time_evening (17~22)`, `time_night (22~05)`로 바꾼다.
3. 경계 테스트를 시각마다(04:59·05:00·07:59·08:00·10:59·11:00·16:59·17:00·21:59·22:00·23:59·00:00, KST) 고정한다.
4. `node scripts/gen-home-feed-doc.mjs`로 홈피드 PRD를 다시 만든다.
5. OPS_PATTERNS.md 63줄의 「`time_dawn`(00~06시)은 새벽 조건의 근거로 쓰지 않는다」를 「`time_dawn`은 이 새벽 정의(05~08시)와 같다」로 고친다.

## 완료 조건

- KST 04:59는 `time_night`, 05:00은 `time_dawn`, 08:00은 `time_morning`, 17:00은 `time_evening`, 22:00은 `time_night`로 판정된다(단위 테스트).
- 어드민 카드 폼의 시간대 태그 라벨이 새 경계를 보인다.
- 홈피드 PRD 생성 구간이 새 라벨로 갱신됐고 `node scripts/gen-home-feed-doc.mjs --check`(또는 verify의 동기화 검사)가 통과한다.
- OPS_PATTERNS.md의 시각 정의 문장이 새 태그와 일치한다.
- `scripts/verify.sh`가 통과한다.
