# [Admin] 배지 저장 API의 최초 성공 레시피 존재 검사 배선을 라우트 테스트로 지킨다

> `/jam-ship` 2026-10-01 병렬 점검(민지 모드 ③) 범위 밖 발견물. 점검 범위 `efd7be8d..946ebad7`(origin/main → origin/staging).

## 핵심 요약

- 요구사항: 어드민 배지 저장 API가 `findRecipeFirstSuccessNotFoundError`를 불러 400을 돌려주는 배선이 테스트로 지켜지지 않는다. 함수 단위 테스트만 있어 호출 줄이 지워져도 CI가 통과하고, 없는 레시피를 가리키는 배지가 저장돼 영원히 발급되지 않는다. [정확성/주의]
- 구현 계획: 생성(POST)·수정(PATCH) 라우트 테스트에 없는 레시피 ID로 저장하면 400을 받는 사례를 더한다.
