# [BadgeEngine] 앰비언트 예약 대상 읽기가 매일 배포의 지점·배지 조회를 복제했다

> 출처: 20261001_2051(1457-①) 게이트(민지) 범위 밖 발견물

## 핵심 요약

- 요구사항: 두 경로가 같은 조회·판정 함수를 쓰도록 공용화한다(동작 불변, 기존 ambient-drop 테스트 무수정 통과).
- 구현 계획: 착수할 때 관련 파일을 읽고 파일 단위로 적는다.
- 관련 파일: `jam-web/src/lib/ambient-drop/scheduleTargets.ts` 102·144~151행, `jam-web/src/lib/ambient-drop/index.ts`의 같은 조회(139~176·221~222행 부근)

## 배경 / 문제 정의

예약 대상 읽기(`scheduleTargets.ts`)가 매일 배포(`index.ts`)의 지점·활성 시스템 드랍 수 조회와 배지 유효기간 판정을 따로 적었다. 한쪽 조건만 고치면 매일 배포와 예약의 판정이 어긋난다.

## 완료 조건

- 지점·활성 드랍 수 조회와 배지 유효기간 판정이 한 곳에만 있다.
- 기존 ambient-drop 테스트와 예약 테스트가 수정 없이 통과한다.
