# [BadgeEngine] 재평가 미리보기에 「열릴 예정 배지 포함」 옵션

> 1500 영향 티켓 E1(2026-10-01 1500 시작 검토 Q3 사용자 결정 「승인 때 미리 센다」). 1500 ⑨(JAM! 배지 핸들러)보다 먼저 한다.

## 핵심 요약

- 요구사항: 예약 공개되는 JAM! 배지는 공개 시각에 옛 기록으로 소급 지급되고 회수할 수 없다. 지금 재평가 미리보기(`reevaluate-all` dry-run)는 `valid_from`이 미래인 배지를
  후보에서 빼므로(BADGE_ENGINE 2.17 알려진 한계 2) 승인 때 「공개되면 약 N명에게 P포인트」를 셀 수 없다. 미리보기에 「열릴 예정 배지 포함」(읽기 전용) 옵션을 더해,
  1500 ⑨가 예약 등록 요약창에 그 수를 보이게 한다.
- 구현 계획: 착수할 때 관련 파일을 읽고 파일 단위로 적는다. DB 변경 없음, 쓰기 없음.
- 관련 파일: `jam-web/src/app/api/admin/badges/reevaluate-all/route.ts`, `jam-web/src/lib/badge-engine/reevaluateCatalog.ts`, `jam-web/src/lib/badge-engine/jamActionBadges.ts` 168행
  (`valid_from` 필터), `jam-web/src/lib/badge-engine/index.ts` 1013행, `docs/specs/badge-engine/BADGE_ENGINE_UNIFIED.md` 1411~1412행(2.17)

## 완료 조건

- [ ] 옵션을 켠 미리보기가 공개 예정 JAM! 배지를 후보에 넣어 받을 유저 수와 포인트 합을 돌려준다. 옵션을 끈 기본 동작과 실제 재평가(쓰기)는 바뀌지 않는다(테스트).
- [ ] 미리보기는 DB에 쓰지 않는다(테스트). BADGE_ENGINE 2.17이 갱신됐다.
