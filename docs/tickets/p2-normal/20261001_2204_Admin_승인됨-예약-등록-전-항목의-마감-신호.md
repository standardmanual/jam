# [Admin] 「승인됨(예약 등록 전)」 항목의 마감 신호

> 1500 영향 티켓 E2(2026-10-01 1500 시작 검토 Q1 사용자 결정 「승인 후 한 번 더」). 1500 ① 뒤 아무 때나 한다.

## 핵심 요약

- 요구사항: 승인은 「승인됨」에서 멈추고 [N개 예약 등록하기]를 한 번 더 눌러야 예약된다(1500 Q1). 지금 「승인 마감 임박」 신호는 결정 전(도착·검토중) 항목만 보므로,
  승인만 하고 예약 등록을 안 한 항목의 공개 시각이 다가오거나 지나도 운영 홈에 아무 신호가 없다. 같은 마감 규칙을 「승인됨」 항목에도 걸거나 별도 신호를 둔다.
- 구현 계획: 아래 「구현 계획」 절(2026-10-04 파일 단위).
- 관련 파일: `jam-web/src/lib/admin/opsSignals/statusRules.ts` 100~124행(`evaluateApprovalDeadline`), PRD §5 신호 표(146·175행 부근)와 기준값 표

## 구현 계획
