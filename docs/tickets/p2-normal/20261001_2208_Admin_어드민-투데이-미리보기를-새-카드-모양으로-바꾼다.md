# [Admin] 어드민 투데이 미리보기를 새 카드 모양으로 바꾼다 (1453-b6)

## 배경 / 문제 정의

- 지금 두 미리보기는 홈과 같은 `TodayCardStack`에 `preview`를 켜서 그린다(1645). 홈은 전환 상수가 꺼져 있어 `shape`가 없는 옛 카드 71장을 옛 렌더러로 그리므로, 미리보기도 옛 모양이다.
  b1 설계상 미리보기는 늘 `resolveShape`로 새 모양을 정한다(`toCardView`) — 그 경로를 아직 아무 화면도 쓰지 않는다.
- 1645 잔여 이슈 (가): 미리보기에서 배지가 흑백으로 보인다. 확정 설계 3절은 「유저 정보가 없는 미리보기는 컬러」다. 지금 `toCardView`는 `earned`가 없으면(undefined) `brief` 썸네일과 이미지 모양의
  승격 배지 그림을 흑백으로 만든다(329·339줄). 타일(`list`)은 이미 「값이 없으면 컬러」다. 날짜 미리보기 조회(`todayPreview.ts`)는 `earned`를 싣지 않는다.
- 1645 잔여 이슈 (나): 새 어드민 화면이 `preview`를 빠뜨려도 타입 오류가 나지 않는다. 표시 데이터는 `tracking` 옵션을 주지 않으면 계측 정보가 없으므로(`toCardView` 기본값), 새 경로는 기본이 안전하다.
- 날짜 미리보기 조회는 `resolved_mission`·`resolved_collection`을 싣지 않아, 새 모양의 필수 정보(미션 기간·보상, 컬렉션 이름·아이템 수)가 빈다.
- 날짜 미리보기 모달의 카드 폭은 약 432px로 실제 기기(360 기기 328px, 430 기기 398px)보다 넓다. 확정 설계 8절과 1501은 미리보기 폭을 360과 430으로 전환한다.

## 상세 요구사항

### 1. 공용 미리보기 목록 (신규)

- 표시 데이터 배열을 받아 새 틀로 세로로 쌓아 그리는 어드민 컴포넌트를 둔다(가칭 `jam-web/src/app/admin/today/TodayCardPreview.tsx`). 홈 캔버스와 같은 `bg-surface` 판 위에, 카드 사이 간격은 홈과 같다.
- 폭 전환: 「360」·「430」 두 값(shadcn `Tabs`)이고 기본은 360이다. 판 폭은 기기 폭에서 홈의 좌우 여백을 뺀 카드 폭(328px·398px)이 되게 한다(값은 홈 레이아웃에서 확인).
  폭 값은 한 곳에 상수로 둔다. 1501이 같은 컴포넌트를 쓸 수 있게 표시 데이터만 받는다(카드 행·DB를 모른다).
- 계측 정보가 없는 표시 데이터만 그린다. 출력에 트래커(`data-tracker` 등)·링크(`<a`)·`jam-press`가 없어야 한다. 내 순위 강조(`currentUserId`)는 넘기지 않는다.

### 2. 날짜 미리보기 모달

- 조회 결과(`TodayCardWithHref[]`)를 `toCardView(card, { now })`로 바꿔 위 1로 그린다. 옛 카드(`shape` NULL)도 대응표대로 새 모양이 된다.
- 기준 시각(`now`): 선택한 날짜가 오늘(KST)이면 지금, 아니면 선택한 날짜의 00:00(KST)이다. 「N일 남음」 계산과 컬렉션 공개 판정에 같은 값을 쓴다.
- 빈 상태·로딩·오류 문구는 지금 그대로다.

### 3. 날짜 미리보기 조회 (`todayPreview.ts`)

- 홈 조회(`getTodayCards`)처럼 `resolved_mission`(미션을 쓰는 카드만)과 `resolved_collection`(컬렉션 소식 카드만, 공개 판정 기준 시각은 위 2의 기준 시각)을 싣는다.
  `cards.ts`의 판정·변환 함수를 export해 재사용하고 같은 규칙을 다시 쓰지 않는다. 노출 개인화와 미션 참가 필터를 하지 않는 기존 단순화는 그대로다.
- 배지는 지금처럼 `earned` 없이 싣는다(유저 정보가 없는 미리보기).

### 4. 보유 여부를 모를 때 컬러 (`cardView.ts`)

- `brief` 썸네일과 이미지 모양의 승격 배지 그림은 `earned === false`일 때만 흑백이다. `earned`가 없으면 컬러다(타일과 같은 규칙). 홈은 늘 `true`/`false`를 실으므로 홈 출력은 바뀌지 않는다.
- `cardView.test.ts`를 고치므로 492줄 테스트 이름 「드랍 카드: 지역 줄과 지역 핀」을 「드랍 카드: 필수 정보 지역 줄과 칩 줄 지역 핀」으로 다듬는다(1716 민지 발견).

### 5. 카드 폼의 「홈 화면 미리보기」

- 폼 값으로 만든 카드(`previewCard`)를 `toCardView`로 바꿔 위 1로 그린다(폭 전환 포함, 레일 폭이 좁으면 판이 가로로 넘쳐도 된다 — 처리는 구현이 정하되 카드 폭은 줄이지 않는다).
- 폼은 미션·컬렉션 값을 따로 읽지 않는다(새 API 없음). 필수 정보 중 폼이 가진 값만 보이고, 미션 기간·보상처럼 폼에 없는 값은 그 줄이 생략된다. 이 한계를 PRD에 적는다.

### 6. 테스트와 문서

- 테스트: 공용 미리보기 목록(다섯 모양 표시 데이터를 그려 트래커·링크·`jam-press` 0개, 폭 전환 값), 날짜 미리보기의 표시 데이터 변환(옛 `layout_type` 카드가 새 모양이 됨, 기준 시각 규칙),
  조회 함수(미션·컬렉션을 싣는 카드 판정 — 순수 함수 단위), `toCardView`의 `earned` 없음 → 컬러·`false` → 흑백(두 경로), 1645의 회귀 의도(「미리보기는 계측과 이동을 모두 끈다」)를 새 경로 기준으로 옮긴 테스트.
  `TodayCardStack.preview.test.tsx`는 b7에서 `preview` prop과 함께 지우므로 이번에는 남긴다.
- 문서: 홈피드 PRD §6(표시 데이터 항목의 「유저 정보가 없으면 컬러」, 어드민 미리보기가 새 틀을 쓴다는 사실), 어드민 투데이 미리보기를 서술하는 PRD(새 모양·폭 전환·기준 시각·폼 미리보기의 한계).
  생성 구간은 고치지 않는다(b7).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 날짜 미리보기와 카드 폼 미리보기가 `TodayCardStack`을 쓰지 않고 표시 데이터 + `TodayCard`로 그린다. `shape`가 NULL인 옛 카드도 새 모양으로 그려진다(테스트).
- 미리보기 출력에 트래커·링크·`jam-press`가 없다(다섯 모양 모두, 테스트).
- 유저 정보가 없는 미리보기에서 배지 그림(썸네일·승격 이미지·타일)이 컬러이고, 홈은 미보유 배지를 지금처럼 흑백으로 그린다(테스트).
- 날짜 미리보기 조회가 미션을 쓰는 카드에 `resolved_mission`, 컬렉션 소식 카드에 `resolved_collection`을 싣고, 기준 시각 규칙을 지킨다(테스트).
- 폭 전환(360·430)이 카드 폭 328px·398px를 만든다(테스트 또는 실측 기록).
- 홈(`TodayCardStack`)의 출력과 동작이 바뀌지 않는다(기존 테스트 통과).
- `scripts/verify.sh`가 통과하고, 홈피드 PRD와 어드민 PRD가 갱신됐다(PRD 동기화 검사·`gen-home-feed-doc.mjs --check` 통과).
- 새 사용자 노출 문구(폭 전환 라벨 등)가 한국어 자연스러움 판정을 통과한다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
어드민 투데이의 두 미리보기(날짜 미리보기 모달, 카드 폼 「홈 화면 미리보기」)가 `TodayCardStack` + `preview` 대신 표시 데이터(`toCardView`, 계측 없음) + 새 틀(`TodayCard`)로 그린다.
미리보기는 전환 상수와 무관하게 `resolveShape`로 모양을 정하므로 `shape`가 NULL인 옛 카드도 새 모양으로 보인다. 공용 목록 `TodayCardPreview`는 표시 데이터만 받고, 「기기 폭(px)」 탭(360·430, 기본 360)으로
카드 폭 328·398px를 만든다(폭 상수 한 곳, 1501이 재사용). 날짜 미리보기 조회는 홈과 같은 판정 함수(`cards.ts`에서 export)로 `resolved_mission`·`resolved_collection`을 싣고,
기준 시각(`previewBaseTime`, 오늘이면 지금·아니면 그날 00:00 KST)을 「N일 남음」과 컬렉션 공개 판정에 쓴다. `toCardView`는 `earned === false`일 때만 흑백이라 보유 여부를 모르는 미리보기는 컬러다
(1645 잔여 이슈 가). 카드 폼은 새 조회 없이 폼이 가진 값만 보인다. 홈(`TodayCardStack`) 출력은 바뀌지 않았다.

계획 표와 다른 3곳(민지 타당 판정): `previewBaseTime`을 `todayPreview.ts`가 아닌 `lib/admin/today-calendar.ts`에 뒀다(서버 모듈을 클라이언트 모달이 import하면 빌드가 깨진다).
`ResolvedBadge.earned`를 선택값으로 바꿨다(「값이 없으면 컬러」를 타입이 표현, 홈은 늘 boolean). 날짜 미리보기 모달 폭을 480에서 520px로 넓혔다(398px 카드 + 판 여백 + 스크롤바).
