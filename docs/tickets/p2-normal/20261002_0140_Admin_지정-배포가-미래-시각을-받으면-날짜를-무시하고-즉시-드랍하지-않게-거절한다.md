# [Admin] 지정 배포가 미래 시각을 받으면 날짜를 무시하고 즉시 드랍하지 않게 거절한다

## 핵심 요약

- 요구사항: `POST /api/admin/ambient-drop/deploy`의 지정 배포(본문이 있는 요청)에서 `scheduled_at`이 있는데 `'now'`가 아니면 400 해요체 문장으로 거절한다. 지금은 미래 ISO 시각도 정상 입력으로 통과해 날짜를 무시하고 **즉시** 드랍한다(되돌릴 수 없다).
- 관련 파일: `jam-web/src/app/api/admin/ambient-drop/deploy/route.ts`(57행 부근, `parseAmbientDropScheduleInput(allowNow: true)` 호출 앞에 검사), 같은 폴더 `__tests__/route.test.ts`(미래 시각 케이스 추가), `docs/service/badge-engine/BADGE_ENGINE_UNIFIED.md` §3.12(「없거나 now」라는 문장과 코드를 맞춘다).
- 출처: 티켓 20261001_2053 게이트(민지) WARN. 화면은 항상 `'now'`를 보내 실사고 가능성은 낮고 어드민 전용이다. 사용자가 그대로 머지하고 후속으로 남기기로 했다(2026-10-02).
