## 착수 전에 정한 것 (2026-10-02 카리나)

1. 경로는 `/api/cron/ops-reconcile`, 일정은 `*/10 * * * *`다. `/api/cron/reconcile`은 예전 Strava 크론 이름이라 쓰지 않는다(04 112행).
2. 라우트는 GET, `CRON_SECRET`이 비었거나 다르면 401, `maxDuration = 60`. 결과에 오류가 있으면 500 `{ ...result, ok: false }`(Vercel이 실패로 센다), 없으면 200. 슬랙은 `after()`로 응답 뒤에 보낸다.
3. 어드민 달력: `*/10`을 「10분마다」로 보이고 `CRON_LABELS`에 「운영 상태 맞추기」를 더한다.
4. 결정 기록 화면: `end` 「종료했어요」, `external_change` 「밖에서 바뀐 것을 찾았어요」와 전후 시각·비활성 diff, 행위자가 `system:`이면 「시스템이」, `fail`은 기록의 사유를 보인다(문구는 착수 때 확정).
