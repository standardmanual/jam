# [API] 운영툴 패턴 사전 ⑦b 아이템 얻을 길 읽기 API(`GET /api/admin/item-paths`)

> 상위: 20260930_1503 · 하위 순서 ⑦b · 선행: ⑦a 20261004_1640(계산 함수). ⑬ S6 화면과 에이전트가 쓴다.

## 핵심 요약

- 요구사항: `requireAdminRead`(관리자 세션 또는 토큰 GET, 쓰기 메서드 없음)로 인증하는 `GET /api/admin/item-paths`를 만든다. 요청 때 ⑦a `computeItemPaths`로
  계산하고 저장하지 않으며, 결과를 컬렉션 단위로 쪽을 나눠 돌려준다(`limit`/`offset`, `onlyBlocked`). 원천 하나라도 읽기에 실패하면 500(조용히 「막힘」으로 바뀌지 않게).
- 구현 계획: 아래 「구현 계획」 절. DB 변경 없음.
- 관련 파일: `jam-web/src/app/api/admin/ops-patterns/route.ts`(구조), `jam-web/src/lib/db/fetchAllRows.ts`(1,000행 넘는 쪽 읽기 — 활동 아이템 3,600개 이상),
  `docs/specs/prd/ops-tool/PRD.md` §11, `docs/specs/badge-engine/BADGE_ENGINE_UNIFIED.md` §3.12.
