# [Admin] 어드민 컬렉션·배지 폼의 기간 입력이 날짜만 받아 저장하면 공개 시각이 바뀐다

> 발견: 1500 ⑩ 시작 검토(2026-10-04 카리나, Explore 코드 지도). 1500의 영향 티켓 E5다(상위 1450 진행 규칙 4).
> 사용자 결정(2026-10-04 「둘 다 영향 티켓」): 첫 실제 컬렉션 예약(1500 ⑩ 사용자 확인 지점) 전에 고친다. 운영툴이 만든 컬렉션은 아이템을 채우러 기존 어드민 컬렉션 편집 화면을 반드시 연다(1500 Q4).

## 핵심 요약

- 현상(확인한 사실, 2026-10-04 코드):
  - 컬렉션 폼 `jam-web/src/app/admin/itembooks/ItemBookForm.tsx`: `toDateInput = iso.slice(0, 10)`(81행)으로 저장된 ISO(UTC)의 앞 10자를 `type="date"` 입력(360·365행)에 넣고,
    저장할 때 `new Date(validFrom).toISOString()`(131–132행)으로 보낸다. 날짜만 있는 문자열은 UTC 자정으로 읽힌다.
  - 배지 폼 `jam-web/src/app/admin/badges/BadgeForm.tsx`도 같은 방식이다(197행 `toDateInput`, 485–486행 저장, 1098·1103행 `type="date"`).
  - 저장할 때마다 두 칸을 다시 보낸다(값을 고치지 않아도 보낸다).
- 영향(위 사실에서 따라 나오는 결과): 운영툴이 만든 항목은 공개 시각이 KST 시각까지 정해져 있다. 예를 들어 `valid_from`이 KST 10/20 00:00(= UTC 10/19 15:00)이면 폼은 시작일을 10/19로 보이고,
  다른 칸만 고쳐 저장해도 `valid_from`이 UTC 10/19 00:00(= KST 10/19 09:00)으로 바뀌어 15시간 일찍 공개된다. 종료 시각도 같은 방식으로 바뀐다.
  - 컬렉션: 1500 ⑩-a(티켓 20261004_2039)가 만든 공개 전 컬렉션에 아이템을 채우러 이 화면을 연다.
  - 배지: 1500 ⑨-a가 만든 JAM! 배지, 특히 레시피와 공개 시각이 밀리초까지 같아야 하는 「가장 먼저 성공」 배지가 어긋난다.
  - 상태 맞추기는 이런 변경을 「밖에서 바뀜」으로 기록만 한다(1500 G8).
- 구현 계획(안): 두 폼의 기간 입력을 레시피 폼과 같은 KST `datetime-local`로 바꾼다. 표시는 `jam-web/src/lib/admin/kst-format.ts`의 `toKstLocalInputValue`(52행), 저장은 `+09:00`을 명시한 변환
  (`jam-web/src/app/admin/recipes/RecipeForm.tsx` 37–43행 `kstLocalToIso`. 두 폼이 함께 쓰도록 공용 위치로 옮길지 착수 때 정한다)을 쓴다.
  입력값을 바꾸지 않았으면 원래 ISO를 그대로 보낸다(분 단위로 왕복하면 초·밀리초가 잘려 「가장 먼저 성공」 배지와 레시피의 시각 일치가 깨진다).
- 관련 파일: 위 두 폼, `kst-format.ts`, 레시피 폼(선례), 어드민 PRD의 컬렉션·배지 폼 서술(착수 때 위치 확인), 두 폼의 기존 테스트(있으면).

## 착수 때 정할 것

- 기존 값의 표시: 지금 어드민에서 날짜만 넣어 저장한 값은 UTC 자정(= KST 09:00)이다. 새 입력에서는 「09:00」으로 보인다. 그대로 보일지, 안내 문장을 둘지 정한다(데이터는 고치지 않는다).
- 공용 변환 함수의 위치(`kst-format.ts`에 `kstLocalInputToIso`를 더하는 안).

## 완료 조건

- 두 폼이 기간을 KST 날짜·시각으로 보이고 저장한다. 공개 시각이 KST 10/20 00:00인 컬렉션·배지를 열어 다른 칸만 고쳐 저장해도 `valid_from`·`valid_until`이 바뀌지 않는다(바꾸지 않은 칸은 원래 ISO 그대로, 테스트).
- 새로 고른 KST 시각이 `+09:00` 기준으로 저장된다(테스트). 레시피 폼 동작은 바뀌지 않는다.
- `scripts/verify.sh` 전 항목 통과. 어드민 실렌더는 카리나가 머지 뒤 push 전에 `DEV_PROCESS_GUARDRAILS.md` 패턴 13대로 한다(`admin` 유형).
