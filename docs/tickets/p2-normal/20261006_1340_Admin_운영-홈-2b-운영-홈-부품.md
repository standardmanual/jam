## 카리나 가정 (2026-10-06, 사용자 이의 없음)

1. 합친 칸의 값: 키·상태·시험·묶음 연결은 운영 항목, 날짜 겹침·모양·노출 대상·커버는 실제 카드 값.
2. 미션도 같은 방식으로 합친다(`mission_id`, 신호에는 영향 없음).
3. 「예약 등록 대기」 칸은 approved + preparing(「승인됨 N · 준비중 M」), `stageOfItemStatus`의 `prepare` 결과다.
4. 「패턴 제안」과 다섯 칸 밖 상태는 각주로 따로 센다.
5. 신호 머리 숫자는 「종」 단위로 센다.
6. 다음 주 줄의 기준은 S7 `nextWeekCheckFromWeekday`(`loadSignalOverrides`).
7. 에이전트 이름이 빈 결정 기록은 「에이전트()가 …」 대신 「에이전트가 …」.
8. 경제 추이 링크(`EconomyTrend.tsx` `trendHref`)는 `sample`을 유지한다.
9. 주간 캘린더의 주 이동이 `?sample=1`을 잃는 기존 동작(`WeeklyCalendar.tsx:71`)은 ②에서 고치지 않고 ③이 해결한다.

- 시험 묶음 1개 fixture로 켬·끔 렌더 두 벌: 켜면 숫자·신호·이력에 시험이 더해지고 「시험 N개 포함」과 줄마다 「시험」 칩, 끄면 모두 빠진다.
