# [Admin] 운영툴 취소와 상태 맞추기 크론이 겹치면 이중 기록과 오알림이 난다

## 핵심 요약

- 요구사항: `cancelItem`은 자원을 먼저 지우고(224행) 그 뒤 항목을 「취소」로 바꾼다(249행). 그 사이 10분 상태 맞추기(`ops-reconcile`, 2026-10-06 프로덕션 첫 가동)가 자원을 `missing`으로 읽으면 시스템이 먼저 취소하고 `cancel` 기록과 #jam-alert 「운영툴 밖에서 지워졌어요」를 남기며, 사용자는 409를 받는다. 이 경합을 막거나 같은 취소로 인정한다.
- 구현 계획: 착수 때 정한다. 후보: 취소 시작 때 항목을 「취소 중」으로 먼저 선점, 또는 상태 맞추기가 방금 운영툴이 지운 자원을 외부 변경으로 보지 않게 한다. 경합 테스트를 먼저 쓴다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/execute/cancel.ts` 224–281, `jam-web/src/lib/admin/opsInbox/execute/reconcile.ts`(조건부 update 453행), `cancel.test.ts` 307행

## 배경 / 문제 정의

2026-10-06 `/jam-ship`(origin/main daf6db727 → 565c3067b) 5단계 병렬 점검(민지 모드 ③ 1번 [정확성/주의]). 그룹 취소는 핸들러를 차례로 불러 창이 더 길다.

## 완료 조건

- 취소 도중 상태 맞추기가 돌아도 사용자 취소가 성공하고 외부 변경 기록·알림이 나지 않는다(경합 테스트).
