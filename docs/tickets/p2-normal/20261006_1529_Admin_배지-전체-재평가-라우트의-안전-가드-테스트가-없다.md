# [Admin] 배지 전체 재평가 라우트의 안전 가드 테스트가 없다

## 핵심 요약

- 요구사항: 실제 발급이 가능한 관리자 POST `reevaluate-all`에 라우트 테스트가 0건이다. `includeUpcoming`과 `dryRun:false` 동시 금지(59행), `badgeIds`는 `includeUpcoming` 없이 금지(67행, 전체 카탈로그 발급 사고 방지), 대상 0명(90행), 미리보기 500(117–128행)을 테스트로 고정한다. 같은 묶음: `previewUpcomingJamBadges` 오류 경로(배지 메타 조회 실패 332행, 유저별 실패 `errors[]` 364–367행)와 미리보기 500 응답이 `err.message`를 그대로 내는 점(126행, 관리자 전용).
- 구현 계획: 아래 「구현 계획」. 유형 `api`. 오류 응답은 고정 문장으로 바꾼다(2026-10-06 카리나 결정, 다른 어드민 라우트와 같은 방식 — 상세는 서버 로그).
- 관련 파일: `jam-web/src/app/api/admin/badges/reevaluate-all/route.ts` 54–128, `jam-web/src/lib/badge-engine/reevaluateCatalog.ts` 332·364–367
