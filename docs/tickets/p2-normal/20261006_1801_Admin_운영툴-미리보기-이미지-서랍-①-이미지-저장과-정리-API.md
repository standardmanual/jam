# [Admin] 운영툴 미리보기·이미지·서랍 ① 이미지 저장·정리 API

> 상위: 20260930_1501 ① · 20260930_1450 순서 3 · 07 인벤토리 D

## 핵심 요약

- 요구사항: 운영자 브라우저가 만든 이미지를 받아 WebP로 저장하고 항목의 `resource`에 쓴다. 예약된 뒤에는 `created_resource`가 가리키는 자원에도 함께 쓴다(Q1 B). 파일은 새 자원 전용 경로에 올리고 예약 실패·공개 전 취소·되돌림 때 그 파일만 지운다(Q3 A). 렌더는 브라우저에서 하므로(Q8 A, 서버 렌더는 웹 서버에서 도는 선례가 없다) 이 조각에는 렌더 코드가 없다.
- 구현 계획: 1501 「주요 의사결정」의 시작 검토 결정(2026-10-06)을 따른다. 변경 후 운영툴 PRD와 1501 문서를 갱신한다.
- 관련 파일: `jam-web/src/app/api/admin/asset-generator/apply/route.ts`(기존 행에만 붙임, 그대로 둠), `jam-web/src/lib/admin/opsSignals/composition.ts`(`hasItemImage`, 수정 없음)
