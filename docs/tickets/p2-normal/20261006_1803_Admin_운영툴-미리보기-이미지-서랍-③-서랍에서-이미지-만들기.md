# [Admin] 운영툴 미리보기·이미지·서랍 ③ 서랍에서 이미지 만들기

> 상위: 20260930_1501 ③ · 20260930_1450 순서 3 · 07 인벤토리 D

## 핵심 요약

- 요구사항: 승인 직후 운영자 브라우저가 에셋 제너레이터와 같은 코드(`src/lib/asset-generator/render.ts`)로 이미지를 만들어 ①의 저장 API에 올린다(Q2 A, Q8 A). 실패해도 승인은 유지하고 「이미지 제작 필요」로 남긴다. 서랍에서 [이미지 만들기]와 다시 만들기를 누를 수 있고, 예약된 뒤에도 항목과 자원 두 곳에 함께 붙인다(Q1 B). 시험 묶음은 자원을 만들지 않으므로 미리보기만 하고 이미지를 저장하지 않는다.
- 한계: 이미지를 만드는 동안 탭이 열려 있어야 한다. 닫히면 「이미지 제작 필요」로 남고 서랍에서 다시 만든다.
- 구현 계획: 1501 「주요 의사결정」의 시작 검토 결정(2026-10-06)을 따른다. 변경 후 운영툴 PRD와 1501 문서를 갱신한다.
- 관련 파일: ①의 이미지 서버, 1502 서랍, `jam-web/src/app/admin/asset-generator/`, 운영툴 PRD §8.8
