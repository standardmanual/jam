## 핵심 요약

- 요구사항: 서랍에 트라이브별 승인 색 쌍 목록을 보여 주고 하나를 고르면 미리보기가 바로 바뀐다. 직접 입력도 허용한다(Q4 A). 색을 채우면 항목의 `color_pending`을 해제하고 결정 기록에 남긴다. 승인 색 쌍 팔레트 데이터가 코드에 이미 있는지 착수 때 먼저 확인한다(미확인).
- 구현 계획: 1501 「주요 의사결정」의 시작 검토 결정(2026-10-06)을 따른다. 변경 후 운영툴 PRD와 1501 문서를 갱신한다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/fields.ts`(`color_pending`), 1502 서랍, 신호 「비어 있는 컨텐츠」
