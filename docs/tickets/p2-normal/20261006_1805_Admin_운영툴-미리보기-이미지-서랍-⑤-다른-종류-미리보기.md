## 핵심 요약

- 요구사항: 미션·JAM! 배지·컬렉션·레시피·드랍 항목의 미리보기를 만든다. 레시피 미리보기는 재료와 카드 모양만 보여 주는 정적 화면이고, 시험 믹스는 1159에 맡기며 서랍에는 「믹스 화면에서 시험해 보기」 링크와 공개 전에도 믹스 화면에서 볼 수 있다는 안내 문구만 둔다(Q5 A).
- 구현 계획: 1501 「주요 의사결정」의 시작 검토 결정(2026-10-06)을 따른다. 변경 후 운영툴 PRD와 1501 문서를 갱신한다.
- 관련 파일: 1502 서랍, 운영툴 PRD §8, 티켓 20260930_1458 하위 1159(시험 믹스)
