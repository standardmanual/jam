# [Admin] 기획 상세 왼쪽 미리보기 칸이 좁아 카드가 잘린다

> 상위: 20260930_1501 ② 실렌더 확인(2026-10-07)에서 발견. ③ 20261006_1803 앞에 처리하면 좋다.

## 핵심 요약

- 요구사항: 기획 상세(S3) 왼쪽 미리보기 칸에서 카드가 잘리지 않고 보이게 한다.
- 문제: 1440 폭에서 왼쪽 칸은 280px이고 안쪽 판은 246px인데, 기기 폭 360을 고르면 카드 판이 360px라 가로로 스크롤해야 한다. 430은 더 넘친다. 운영자는 카드를 한눈에 못 본다.
- 구현 계획: (a) 왼쪽 열을 360·430 판이 들어가는 폭으로 넓히거나, (b) 미리보기 판을 칸 폭에 맞춰 축소(`transform: scale`)하거나, (c) 좁은 칸에서는 기기 폭 전환을 숨기고 축소만 한다. 폭이 한정된 3열 배치(`@[68rem]`)와 서랍 열(320px) 배분을 함께 본다. 방식은 채원 사전 판정과 사용자 선택이 필요하다.
- 관련 파일: `jam-web/src/components/admin/ops/OpsBundleWorkspace.tsx`(왼쪽 `aside aria-label="미리보기"`와 `@[68rem]` 그리드), `jam-web/src/components/admin/ops/OpsCardPreview.tsx`, `jam-web/src/app/admin/today/TodayCardPreview.tsx`(`previewCardWidth`, 판 `overflow-x-auto`)

## 완료 조건

- [ ] 기획 상세 왼쪽 칸에서 카드 전체가 가로 스크롤 없이 보인다(또는 축소되어 보인다).
- [ ] 폭 360·430 전환이 동작한다.
- [ ] 서랍 안 미리보기도 같은 기준으로 확인한다.
