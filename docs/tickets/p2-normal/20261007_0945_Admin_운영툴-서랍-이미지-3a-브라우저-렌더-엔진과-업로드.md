# [Admin] 운영툴 서랍에서 이미지 만들기 ③-a 브라우저 렌더 엔진과 업로드 클라이언트

## 핵심 요약

- 요구사항: 프리셋·색·문안을 받아 PNG Blob 한 장을 만드는 **브라우저용 조립 함수**와, ①의 저장 API(`POST /api/admin/ops-inbox/[bundleId]/items/[itemId]/image`)에 올리는 클라이언트를 만든다. **화면 변화는 없다.** 서랍 연결과 승인 직후 자동 제작은 ③-b(20261007_0946)다.
- 검증 기준: 같은 입력을 서버 CLI(`scripts/asset-generator/renderCard.mjs`)와 이 조립 함수가 같은 순서·같은 값으로 그린다(가짜 캔버스 호출 기록 대조, `render.test.ts` 방식).
- 구현 계획: 아래 표. `render.ts`는 그리기 부품 모음이라 「카드 한 장을 만드는 함수」가 없다. 조립은 서버(`renderCard.mjs` 33~168줄)와 어드민 화면(`AssetGeneratorViewport.tsx`)에 따로 있어 브라우저 공용 조립을 새로 둔다. 작업 유형 `admin`.
- 관련 파일: 아래 표.

## 결정 (2026-10-07 사용자, 1803 시작 검토)

1. 기획안에 이미지 지시 칸을 정한다(칸 이름은 ③-b에서 확정. 이 티켓의 조립 함수 입력은 `{ preset, bg, end, values, seed }`로 CLI와 1:1이다).
2. 1803을 ③-a(엔진)와 ③-b(서랍·승인 흐름)로 나눈다.

## 카리나 가정

1. `AssetGeneratorViewport.tsx`(662줄)는 고치지 않는다(회귀 위험). 브라우저 어댑터(캔버스 팩토리·이미지·글꼴 로더·브랜드 글자·알파 자르기)는 새 파일에 두고, 같은 조립이 네 벌째가 되는 중복은 범위 밖 발견물로 티켓화한다.
2. 서버 전용 코드(`opsInbox/image.ts`, `scripts/asset-generator/*.mjs`, `serverCanvas.ts`)를 클라이언트 모듈이 import하지 않는다. 가져와도 되는 것은 `render.ts`·`curve.ts`·`random.ts`·`layerKeys.ts`·`presetSerialize.ts`·`assetGeneratorHelpers.ts`다.
3. 레이어 값 적용(`applyLayerValues.mjs`의 규칙)은 TS로 옮겨 쓰고, 같은 입력에 같은 결과가 나오는지 대조 테스트를 둔다(.mjs는 고치지 않는다).
4. 글꼴 로드는 시간 제한(타임아웃)을 둔다. 제한을 넘기거나 실패하면 던져 호출부가 「이미지 제작 필요」로 남기게 한다.
5. 업로드 클라이언트는 던지지 않고 `{ ok: true, url } | { ok: false, status, message }`로 돌려준다. JSON 전용 `postOpsJson`은 쓰지 않고 FormData(`image` 필드, PNG)로 보낸다.
6. 시드는 호출부가 정해 넘긴다(이 티켓은 값을 받기만 한다).

## 완료 기록

### 구현 내용 요약

- `renderPreset.ts`: `renderPresetToCanvas({ preset, bg, end, values, seed }, deps)`. `renderCard.mjs`와 같은 순서(값 적용 → 리본 원천 그래픽 → 스탬프 → 곡선 → 배경 → 리본 → 글꼴 등록 → 이미지 로드 → 역순 오버레이)로 그린다. 캔버스·이미지·글꼴·원천 그래픽은 의존 주입이다. `applyLayerValues` 규칙을 TS로 옮겼다(`.mjs`는 그대로).
- `imageRender.client.ts`: `renderPresetToPngBlob`. 프리셋을 `GET /api/admin/asset-generator/presets/[id]`로 읽고 캔버스 팩토리·이미지·글꼴 로더(각 15초 제한)·브랜드 글자 J·알파 자르기·`canvasToBlob`을 붙인다. 실패와 시간 초과는 한국어 메시지로 던진다.
- `imageClient.ts`: `postItemImage`. FormData `image`(PNG)로 §11.12에 올리고 던지지 않는다. 400·403·404·500은 고정 문장, 409는 서버 이유 문장(시험 묶음 포함), 네트워크 오류는 status 0.
