# [Admin] 운영툴 서랍 이미지 ③-b2 서랍의 이미지 만들기 버튼과 「이미지 제작 필요」 표시

## 핵심 요약

- 요구사항: 승인 이후(승인됨·준비중·예약됨·게재중) 이미지가 비어 있는 항목에 「이미지 제작 필요」를 보이고, 서랍·기획 상세에서 [이미지 만들기]·[다시 만들기]를 누를 수 있게 한다(②~④와 같은 흐름 `makeItemImage`). 시험 묶음·이미지 칸 없는 종류는 버튼과 표시를 감춘다.
- 선행: ③-b1 20261007_0947. 이 티켓에서 서랍에 연결한 뒤 **실제 브라우저로 ③-a 엔진 결과(글꼴·이미지·`toBlob`)를 확인한다**(③-a 게이트 WARN 이월).
- 착수 때 할 일: 파일 단위 계획을 쓰고(규모 판정 포함) `/jam-work`로 진행한다. 코드 지도는 0946 「코드 지도」를 따른다.
