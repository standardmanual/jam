# [Admin] 운영툴 이미지 저장 라우트의 오류 경로와 경계에 테스트가 없다

## 핵심 요약

- 요구사항: `POST /api/admin/ops-inbox/[bundleId]/items/[itemId]/image`에서 묶음·항목 DB 조회 오류 500(71·77행), WebP 업로드 실패(104행), `applyItemImage`의 `not_allowed`·`conflict`·`not_found`·`error` → 409·404·500 변환(113행), 빈 파일(`size===0`)과 정확히 5MB 경계(63·65행)에 테스트가 없다(지금은 첫 업로드 실패와 5MB+1바이트만 있음).
- 구현 계획: 위 경로마다 라우트 테스트를 추가한다(동작 변경 없음).
- 관련 파일: `jam-web/src/app/api/admin/ops-inbox/[bundleId]/items/[itemId]/image/route.ts`(63–113행), 같은 폴더 `__tests__/route.test.ts`

## 배경 / 문제 정의

2026-10-07 `/jam-ship` 5단계 병렬 점검(민지 모드 ③ 테스트 공백, 범위 565c3067b..9142afab7)의 범위 밖 발견물 [테스트/주의] 2번이다. 승격을 막지 않는 항목이라 배포와 별도로 처리한다.

## 완료 조건

- 위 경로가 테스트로 고정되고 기존 테스트가 통과한다.
