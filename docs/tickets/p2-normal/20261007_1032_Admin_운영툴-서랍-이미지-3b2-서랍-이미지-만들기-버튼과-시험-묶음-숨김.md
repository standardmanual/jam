# [Admin] 운영툴 서랍 이미지 ③-b2 서랍·기획 상세 [이미지 만들기] 버튼과 시험 묶음 숨김

> 상위: 20261007_0946(③-b) → 20261006_1803(③). 서브에이전트 코드 지도(2026-10-07)와 사용자 결정으로 ③-b를 세 조각(b1-a → b1-b → b2)으로 나눴다. 순서대로 처리한다.

## 핵심 요약

- 요구사항: 서랍과 기획 상세에서 승인됨 항목의 [이미지 만들기]·다시 만들기(새 시드)를 누를 수 있다. 시험 묶음에서는 버튼과 표시를 감춘다.
- 선행: ③-b1-b 20261007_1031.
- 구현 계획(파일 단위):
  1. 신규 `jam-web/src/components/admin/ops/OpsImageProduction.tsx`: 「이미지 제작 필요」·「만드는 중」 표시와 [이미지 만들기]/다시 만들기 버튼. ③-b1-b의 훅을 쓴다.
  2. `OpsScheduleDrawer.tsx` `ReadyItemBody`(190~239줄): `statusNotice`(207~211줄)가 승인됨 항목에서 푸터를 대체하므로 버튼은 푸터 밖, `OpsCardPreview` 바로 아래에 둔다.
  3. `OpsDecisionWorkspace.tsx` 183~203줄: 상세 영역에 같은 부품을 넣는다(`detailFooter` 안은 취소·종료 분기에 가려지므로 밖에 둔다).
  4. 시험 묶음 숨김: `isSample`이면 부품이 아무것도 그리지 않는다(필요하면 `OpsItemActions`에 `isSample` prop).
  5. `PRD.md` §8.8 버튼·다시 만들기 문장.
  6. 테스트: 신규 `OpsImageProduction` 테스트, 수정 `scheduleDrawer.test.tsx`.
- 조각 2(1031) 실렌더에서 확인: `image_spec`에 `bg`·`end`가 없으면 렌더가 실패한다(`preset_id`만 있는 항목은 승인은 유지되지만 「이미지 제작 필요」로 남는다). 이 조각에서 버튼으로 다시 만들 때 같은 실패가 나지 않도록 `bg`·`end` 누락을 제출 경고(`imageSpecWarnings`)에 더하거나 호출부에서 기본값을 정한다. 조각 2의 승인 직후 「이미지 제작 필요」 깜빡임에는 「만드는 중」 표시를 미리보기에 연결한다.
- 확정(카리나, 2026-10-07): `bg`·`end` 누락은 호출부에서 기본값을 임의로 정하지 않고, 제출 경고(`imageSpecWarnings`, `jam-web/src/lib/admin/opsInbox/imageSpec.ts`)에 「`bg`·`end`가 없으면 이미지가 만들어지지 않아요」 계열 경고를 더한다(오류 아님, 문장은 해요체·현상→원인→해결 순서). `imageSpec.test.ts`·`validate.test.ts`에 경우를 더한다. 「만드는 중」은 `OpsCardPreview`의 이미지 자리에 연결한다(훅의 making 집합을 `OpsImageProduction`이 내려주는 쪽이 간단하면 그쪽).
- 규모: 소스 3~5개·약 110줄 + 테스트 2개·약 120줄 + 문서. 임계값을 넘길 수 있어 첫 호출부터 `planOnlyWaiver`를 넣는다.
- 관련 파일: 위 계획의 경로.

## 결정 (2026-10-07 사용자 승인) 과 가정

- 승인: `image_spec`은 선택 칸이고 비어 있으면 제출 검사에서 경고만 한다. 일괄 승인(`OpsBulkApprove`)은 자동 제작에서 제외한다. 「다시 만들기」는 새 시드를 쓴다. ③-b를 나눈다.
- 가정(카리나, 사용자가 코드 지도 조사 뒤 따로 답하지 않은 항목): (1) 경고는 제출 응답에만 싣고 DB에는 저장하지 않는다(`ops_bundles.format_errors`는 오류 전용). (2) `image_spec`이 비어 있으면 `colors`로 대신 그리지 않고 제작을 건너뛴 채 「이미지 제작 필요」로 둔다. (3) 「이미지 제작 필요」 판정 대상은 PRD §5 현행대로 카드 모양(hero·poster·square)만이다. (4) 게재중·예약됨 항목에는 표시하지 않는다.
- 시험 묶음 미리보기 렌더(저장 없이 그리기)는 ⑤로 미룬다.
