## 결정 (2026-10-07 사용자 승인) 과 가정

- 승인: `image_spec`은 선택 칸이고 비어 있으면 제출 검사에서 경고만 한다. 일괄 승인(`OpsBulkApprove`)은 자동 제작에서 제외한다. 「다시 만들기」는 새 시드를 쓴다. ③-b를 나눈다.
- 가정(카리나, 사용자가 코드 지도 조사 뒤 따로 답하지 않은 항목): (1) 경고는 제출 응답에만 싣고 DB에는 저장하지 않는다(`ops_bundles.format_errors`는 오류 전용). (2) `image_spec`이 비어 있으면 `colors`로 대신 그리지 않고 제작을 건너뛴 채 「이미지 제작 필요」로 둔다. (3) 「이미지 제작 필요」 판정 대상은 PRD §5 현행대로 카드 모양(hero·poster·square)만이다. (4) 게재중·예약됨 항목에는 표시하지 않는다.
- 시험 묶음 미리보기 렌더(저장 없이 그리기)는 ⑤로 미룬다.
