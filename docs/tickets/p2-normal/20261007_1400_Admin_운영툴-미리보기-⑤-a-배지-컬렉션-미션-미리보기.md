## 결정 (2026-10-07 사용자 승인, 코드 지도 조사 뒤)

- ⑤를 ⑤-a(배지·컬렉션·미션, 항목 안의 값만 사용·DB 추가 조회 없음) → ⑤-b(레시피·드랍, 이름 조회·시험 믹스 안내)로 나눈다.
