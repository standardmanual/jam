## 완료 기록

### 구현 내용 요약
- `loadLayerImage.mjs`의 주소 내려받기를 `downloadImage`로 분리해 보호를 넣었다: (1) https가 아니면 요청 전에 거절(기존에 받던 http 주소는 이제 거절됨), (2) `AbortController`로 15초 제한(`FETCH_TIMEOUT_MS`, 시험용 `deps.timeoutMs`), (3) `Content-Length`가 5MB를 넘으면 본문을 읽기 전에 거절, (4) 본문은 스트리밍으로 읽다가 5MB를 넘으면 `reader.cancel()` 후 중단(`body`가 없는 응답은 `arrayBuffer()` 후 크기 검사), (5) 오류 문구는 주소의 쿼리·해시를 뺀 `safeSource`를 쓴다. 로컬 파일 경로 분기는 바꾸지 않았다.
- 15초 근거: 브라우저 쪽 `imageRender.client.ts`의 `RENDER_LOAD_TIMEOUT_MS`(15,000ms)와 같은 값이다(카리나가 직접 확인). `loadLayerImage`의 호출처는 별도 시간을 기대하지 않는다.
- PRD(`docs/service/prd/asset-generator/PRD.md` §8): `--img01`의 「http(s) URL」을 「https URL」로 고치고 URL 보호 규칙 한 줄을 추가했다.
