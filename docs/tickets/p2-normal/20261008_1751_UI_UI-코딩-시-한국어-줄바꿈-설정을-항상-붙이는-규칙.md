# [UI] UI 코딩 시 한국어 줄바꿈 설정(keep-all 등)을 항상 붙이는 규칙

> 출처: 2026-10-08 사용자 지시 「UI 코딩시 한국어 표기에 keep-all을 항상 적용하도록 해. 첨부한 파일의 파란색 chip 옵션을 사용해」, 이어서 「지금 수정하지 말고 앞으로 그렇게 하도록 규칙을 정해」.

## 핵심 요약

- 요구사항: 한국어 줄바꿈 비교 이미지에서 파란 칩으로 표시된 다섯 옵션(`word-break: keep-all`, `overflow-wrap: break-word`, `white-space: nowrap`, `text-wrap: balance`, `text-wrap: pretty`)을
  앞으로 UI 코딩 때 항상 쓰도록 규칙으로 정한다. 기존 코드는 고치지 않는다.
- 구현 계획: 유형 `docs`(카리나 직접). 규칙 원본은 `docs/specs/UX_WRITING_GUIDELINE.md` §3.2 한 곳에 두고, 구현자(아현 `jam-developer.md` 규칙 6)와
  사후 리뷰(채원 `ui-review-checklist.md` §4)에는 그 절을 가리키는 줄만 둔다.
- 관련 파일: `docs/specs/UX_WRITING_GUIDELINE.md` §3.2, `.claude/agents/jam-developer.md` 규칙 6, `.claude/skills/jam-design/references/ui-review-checklist.md` §4.

## 완료 조건

- §3.2에 대상별 CSS·Tailwind 유틸리티·하는 일이 표로 있고, 아현 규칙과 채원 점검표가 그 절을 가리킨다. 기존 화면 코드는 바뀌지 않는다.

### 주요 의사결정 / 핵심 메모
- 이미지는 `text-wrap`에서 balance와 pretty를 둘 다 파란 칩으로 표시했다. 카리나가 역할로 나눴다: 제목·카드 제목·두세 줄 안내는 balance, 여러 줄 본문은 pretty.
- `white-space: nowrap`은 이미지 예시(버튼)대로 짧은 라벨에만 쓰고, 길이를 모르는 문구에는 쓰지 않는다는 조건을 붙였다(좁은 화면에서 넘침 방지).
- 규칙 원본을 디자인 시스템 폴더(`jam-web/design-system/guidelines/`)가 아니라 UX 라이팅 가이드에 둔 이유: 그 폴더는 claude.ai/design 업로드용 시각 자료(HTML)이고, 아현은 화면 문구를 쓸 때 UX 라이팅 가이드를 찾아보도록 이미 정해져 있다.
- 전역 기본값(`globals.css`의 body에 `keep-all`)으로 한 번에 거는 방법은 기존 화면 전체가 바뀌므로 사용자 지시(지금 수정하지 않음)에 따라 택하지 않았다.
