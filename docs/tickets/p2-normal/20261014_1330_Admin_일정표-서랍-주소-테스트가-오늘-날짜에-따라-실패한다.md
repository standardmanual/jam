# [Admin] 일정표 서랍 주소 테스트가 오늘 날짜에 따라 실패한다

## 핵심 요약

- 요구사항: `drawerParams.test.ts`의 「쿼리가 비어 있어도 연다」가 실행하는 날짜와 무관하게 통과하도록 고친다.
- 구현 계획: 테스트가 시스템 시계를 고정하거나, 현재 보이는 기간을 쿼리로 명시해 `openDrawerQuery`가 오늘 날짜에 기대지 않게 한다.
- 관련 파일: `jam-web/src/lib/admin/opsSchedule/__tests__/drawerParams.test.ts`(56~58줄), `jam-web/src/lib/admin/opsSchedule/drawerParams.ts`(`openDrawerQuery` 51~70줄)

## 배경 / 문제 정의

2026-10-14 13:30(KST)에 이 테스트 파일만 실행해 직접 재현했다. 23건 중 1건이 실패한다.

- 기대: `drawer=day&date=2026-10-07`
- 실제: `drawer=day&day=2026-10-07`

원인은 `openDrawerQuery('', …)`가 빈 쿼리에서 오늘 날짜로 보이는 기간을 구해 대상 날짜(2026-10-07)의 기간과 비교하기 때문이다. 오늘이 2026-10-07과 같은 기간일 때만 `date`를 쓰고, 다르면 `day`를 쓴다. 함수 동작은 의도된 것이고(주석 참고), 테스트가 날짜에 기대는 것이 결함이다.

티켓 20261014_1319 처리 중 아현이 `scripts/verify.sh`의 `test` 단계가 이 한 건 때문에 실패한다고 보고했다(재현은 위 테스트 단독으로만 했다).

## 완료 조건

- 오늘 날짜가 2026-10-07과 다른 주·달이어도 이 테스트가 통과한다.
- `openDrawerQuery`의 동작(보이는 기간 안이면 `date`, 밖이면 `day`)은 바뀌지 않는다.
