# [Infra] 카즈하·채원 정의 문서의 모드별 상세를 참조 파일로 옮겨 호출마다 드는 고정 비용을 줄인다

## 핵심 요약

- 요구사항: 티켓 20261015_1103(윤진)과 같은 방식을 카즈하(`jam-ops`, 10,487B)와 채원(`jam-designer`, 9,400B)에 적용한다. 모드 전용 절을 참조 파일로 옮기고, 모든 호출에 필요한 규칙(원칙·데이터 접근·개인정보·Slack 게시 범위·작업 폴더·금지)은 정의 문서에 남긴다. `docs` 유형, 카리나 직접. 사용자 승인 2026-10-15(「2단계 진행해」).
- 구현 계획: 카즈하의 ③ 선별·⑦ Workflow 개선점·주간 브리핑과 예약 실행 절차를 `.claude/skills/jam-work/references/ops-*.md`로, 채원의 ① 사전 판정·④ 크래프트·⑤ 컨텐츠 컬러를 `.claude/skills/jam-design/references/designer-*.md`로 옮긴다. 채원 ② 사후 리뷰는 그 모드에서 이미 읽는 `ui-review-checklist.md` 머리로 옮겨 읽기 횟수를 늘리지 않는다(선례: 티켓 20260922_1800의 민지 모드 ②·③). 규칙 문장은 고치지 않는다.
- 관련 파일: `.claude/agents/jam-ops.md`(37~67·79~108·129~140행 이동), `.claude/agents/jam-designer.md`(47~93·101~130행 이동), `.claude/skills/jam-design/references/ui-review-checklist.md`(머리), `.claude/skills/jam-work/references/scheduled-jobs.md` 193·211·224행, `.claude/skills/jam-work/references/handling-rules.md` 88행, `docs/operations/reports/README.md` 35행
