# [Infra] CLAUDE.md에서 docs/README.md와 겹치는 폴더 규칙을 걷어내 호출마다 드는 고정 비용을 줄인다

## 핵심 요약

- 요구사항: 티켓 20261015_1103의 후속 3단계다. `CLAUDE.md`는 서브에이전트 여덟 명이 호출마다 받고 선택 제외가 안 된다. 전원이 알아야 하는 규칙만 남기고, 다른 문서에 같은 내용이 있는 부분은 걷어낸다. `docs` 유형, 카리나 직접. 사용자 승인 2026-10-15(「3단계 진행해」).
- 구현 계획: 처음에는 「폴더 = 수명주기」 절을 새 참조 파일로 옮기려 했다. 조사해 보니 `docs/README.md`가 같은 폴더 표·버전 규칙·훅 설명·경로 표기 규칙을 이미 갖고 있었다. 새 파일을 만들지 않고 `CLAUDE.md`의 중복만 걷어내고, 그 절을 가리키던 문서의 경로를 `docs/README.md`로 고친다. 규칙 문장은 고치지 않는다.
- 관련 파일: `CLAUDE.md`(문서 체계 개요 70~74행, 폴더 = 수명주기 90~103행), `.claude/agents/jam-developer.md` 72행, `.claude/skills/jam-docs/SKILL.md` 12~15행, `docs/DOCUMENT_SCHEMA.md` 135행, `.githooks/pre-commit` 286행, `docs/agents/team-operations.md` 407행

### 주요 의사결정 / 핵심 메모

- 예상 효과(추정, 1바이트당 0.39~0.46토큰): 호출 한 번에 약 240~280토큰, 데일리 미팅 여섯 명에 약 1,400~1,700토큰이다. 3단계 단독 효과는 작다.
- `CLAUDE.md`는 이미 두 차례 줄었다(13,467B → 9,457B → 7,562B). 남은 내용은 거의 전원 규칙이다. 더 줄이려면 메인 세션만 쓰는 규칙(절대 규칙 3·4, 절대 규칙 6의 세부 불릿, 팀의 `/jam-work` 줄)이 남는다. 합이 약 1.9KB(호출당 약 750~850토큰)인데 main 배포 금지와 DB 실행 관문이 들어 있어서 사용자 결정 없이 옮기지 않았다. 옮긴다면 `docs/agents/orchestrator.md` 카드(세션 시작 때 훅이 출력)에 관문 한 줄씩을 남기는 방식이 안전하다.
