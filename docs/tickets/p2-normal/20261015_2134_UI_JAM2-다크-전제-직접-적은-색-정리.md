# [UI] JAM 2.0 다크를 전제로 코드에 직접 적은 색을 정리한다

> 개발 세션의 카리나는 이 티켓을 시작하기 전에 아래 「시작 전에 사용자에게 물을 결정」을 질문창(AskUserQuestion)으로 묻고, 답을 「주요 의사결정」에 적은 뒤 아현을 부른다(상위 티켓 결정 4).

## 핵심 요약

- 요구사항: 토큰을 거치지 않고 코드에 직접 적은 색 가운데 다크 바탕을 전제로 한 값을 새 토큰으로 바꾼다.
- 구현 계획: 하위 티켓 1·3이 끝난 뒤 다시 센다 → 영역별로 묶어 교체 → 화면 실렌더 확인.
- 관련 파일: 2026-10-15 측정 기준 49개 파일 286군데. 흰색 반투명 `rgba(255,255,255,…)` 40군데(17개 파일), `text-white`·`bg-black` 등 59군데(29개 파일), 그림자 29군데(10개 파일), blur 13군데(3개 파일). 시작할 때 다시 센 목록을 「구현 계획」에 파일 단위로 적는다

## 배경 / 문제 정의

토큰을 바꿔도 직접 적은 색은 따라 바뀌지 않아 라이트 바탕 위에 다크 흔적(흰 글자, 흰 반투명 면, 어두운 그림자)으로 남는다.
하위 티켓 1·3에서 일부가 정리되므로 이 티켓은 그 뒤에 남은 것만 다룬다(상위 티켓 결정 3의 순서).

## 시작 전에 사용자에게 물을 결정

1. **이미지·영상 위 글자**: 배지 이미지나 배경 영상 위의 흰 글자는 바탕이 바뀌어도 이미지 위에 있으므로 의도된 흰색일 수 있다. (추천) 이미지 위 글자는 흰색을 유지하고 `colors/snow`로만 이름을 바꾼다 / 모두 새 글자색으로 바꾼다
2. **그림자**: (추천) 새 시스템 규칙대로 모두 지운다. 입력창 그림자(`field/shadow`)만 남긴다 / 배지 공개 연출처럼 연출용 그림자는 남긴다
3. **blur**: (추천) 탭바(전용 토큰)를 뺀 나머지 blur는 새 시스템 `blur` 0을 따라 지운다 / 연출용 blur는 남긴다
4. **티켓 크기**: 다시 센 결과가 크면 (추천) 홈·배지·인벤토리·지도·프로필 영역별로 하위 티켓을 쪼갠다 / 한 티켓으로 진행한다

## 완료 조건

- 리터럴 흰색·검정(`text-white`·`bg-black`·인라인 `#fff`·SVG `fill`)과 그 위·아래에 놓이는 면 사이의 대비를 전수 점검해 글자 4.5:1·아이콘 3:1 미만을 0건으로 만든다. 2131이 남긴 짝 어긋남(인계 절)이 대상이다.

- 시작할 때 다시 센 목록의 항목마다 「바꿈」 또는 「의도된 값이라 유지(사유)」가 완료 기록에 있다.
- 유지하지 않기로 한 다크 전제 값이 0건이다.
- 바뀐 화면의 393px 폭 스크린샷을 완료 기록에 남긴다.

## 2131에서 넘어온 인계 (민지·채원② 범위 밖 발견물, 2026-10-15)

- **옛 빨강 리터럴 약 16곳**(`232,70,31`·`#e8461f`): `MissionStatusClient.tsx` 10곳, `MissionsListClient.tsx` 2곳, `forbidden/page.tsx` 1곳, `MissionDetailClient.tsx` 1곳, `design-system/components`의 `BadgeGridCard.jsx`·`MissionCard.jsx` 각 1곳. 알려진 임시 결함 목록(`text-white`·`bg-black`·`rgba(255,255,255,…)`)에 없는 부류다.
- **이미지 위 막 60%**: 흰 글자가 놓이는 막의 설계 하한은 검정 60%인데 `--backdrop`은 50%다. `PosterCard.tsx:30`은 `--base-black` 60%를 직접 섞었고, `BadgeRevealOverlay.tsx:140·163·168`은 흰 글자를 `--backdrop` 위에 그대로 둔다(크림 바탕 합성 시 4.14:1, 60%면 5.94:1). 「이미지 위 막」 역할 토큰을 새로 둘지 정한다. Base를 직접 쓰는 곳: `PosterCard.tsx:30`, `MixerSlot.jsx:122·123·142`, `SlotGrid.tsx:408`, `ItemCandidateSheet.tsx:104`, `voc/page.tsx:44`, `ItemSerialCode.jsx:241`.

**3차 사후 리뷰 중대 (사용자 결정 2026-10-16: 2133·2134로 인계)**

- **진행 상태 색을 글자색으로 쓴 곳**: `--progress-short`(호박 #f5a300)·`--progress-done`(초록 #17c964)·`--warning`은 문서 5.2절대로 가는 선·점·링에만 쓰는 색인데, 옛 `--status-*` 글자색을 1:1로 옮기며 글자까지 따라가 흰 카드 위 2.07~2.19:1이다. `jam-web/design-system/components/patterns/BadgeFamilyCardHeader.jsx:63-70`의 `progressRampColor` 한 곳을 고치면 `BadgeStageRail.jsx:449·508·547`, `BadgeProgressRingCard.jsx:147`, `BadgeLevelGauge.jsx:71`, `BadgeStampRow.jsx:135`, `DualAxisGauge.jsx:52·170`이 함께 풀린다. 그 밖에 `UnlockConditionSheetContent.jsx:102·206·232`, `jam-web/src/app/(main)/combine/RecipeRewardRow.tsx:113`이 있다. 다 채움 글자는 `--link`(5.44:1), 거의 다는 `--foreground`로 두고 선·링·점 색은 유지한다. `NotificationsClient.tsx:96` 경고 아이콘(`--warning`, 크림 위 1.98:1)도 같은 계열이다.
- **`--muted` 글자가 `--border` 면 위(3.46:1)**: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx:287,313-315`(상태 칩·연속 일수 원 숫자), `MissionStatusClient.tsx:319`(「미달성」 칩). 칩 면을 `--background-secondary`나 `--default-soft`로 옮기거나 글자를 `--foreground`로 둔다.
- **accent 면 위에 남은 리터럴 흰 글자·글리프**(2.3~2.7:1, `--accent-foreground`로): `jam-web/src/components/map/MapView.tsx:162-170,239`(클러스터 개수·드랍 마커), `jam-web/src/app/(main)/drops/QuestPickupScene.tsx:139-148`(`fill="#ffffff"`), `MissionStatusClient.tsx:71,163,169,190-199`(포디엄 1위 막대 순위·값, 사용자명 `#FFF`). 리터럴 흰색은 `text-white` 말고도 인라인 `#fff`·`#FFF`·`#FFFFFF`와 SVG `fill="#ffffff"`가 있으니 이 형태도 목록에 넣는다. `jam-web/src/app/(main)/collections/[id]/page.tsx:258·288`의 `color: '#FFFFFF'`도 같다.
- **콘텐츠 배경 위 글자가 흰색 전제에서 어두운 색으로 뒤집힘**: 블롭 애니메이션 기본 배경 `#555555`는 흰 글자 7.46:1을 전제로 정한 값인데 글자가 `--foreground`(#171717, 2.40:1)·`--muted`(1.30:1)가 됐다. `jam-web/src/app/(main)/badges/[id]/BadgeHeroSection.tsx:88,129,139`, `jam-web/src/app/(main)/collections/[id]/ItemBookHeroSection.tsx:73,100-117`, `jam-web/src/lib/badgeBackgroundTheme.ts`(`getBadgeThemedTextStyle`), `jam-web/src/lib/blobAnimation.ts:64-72`. 배경이 있는 카드는 `--snow` 계열, 배경이 없는 흰 카드일 때만 `--foreground`·`--muted`로 가른다(`background_video_url` 보유 배지 351건). 데이터가 정하는 면이라 사용자 결정이 필요하다.
- 불투명도 글자 단계 `text-foreground/40·/50`은 크림 위 2.53:1·3.39:1이다(`/60`은 4.60:1). `points/page.tsx` 내역 머리글·날짜, `PoiCarouselModal.tsx` 거리 줄, `ProfileClient.tsx` 화살표를 `--muted`로 올린다. 같은 화면 포디엄 2·3위 막대는 옛 빨강(`rgba(232,70,31,…)`)이고 1위만 초록이라 한 화면에 빨강·초록이 섞이므로 `color-mix(var(--accent) N%, transparent)`로 맞춘다.
- `QuestPreviewBanner.tsx:74-75` 라벨은 이번 2131에서 `--foreground`로 고쳤다(다른 것은 남지 않음).
