# [UI] JAM 2.0 다크를 전제로 코드에 직접 적은 색을 정리한다

> 개발 세션의 카리나는 이 티켓을 시작하기 전에 아래 「시작 전에 사용자에게 물을 결정」을 질문창(AskUserQuestion)으로 묻고, 답을 「주요 의사결정」에 적은 뒤 아현을 부른다(상위 티켓 결정 4).

## 핵심 요약

- 요구사항: 토큰을 거치지 않고 코드에 직접 적은 색 가운데 다크 바탕을 전제로 한 값을 새 토큰으로 바꾼다.
- 구현 계획: 하위 티켓 1·3이 끝난 뒤 다시 센다 → 영역별로 묶어 교체 → 화면 실렌더 확인.
- 관련 파일: 2026-10-15 측정 기준 49개 파일 286군데. 흰색 반투명 `rgba(255,255,255,…)` 40군데(17개 파일), `text-white`·`bg-black` 등 59군데(29개 파일), 그림자 29군데(10개 파일), blur 13군데(3개 파일). 시작할 때 다시 센 목록을 「구현 계획」에 파일 단위로 적는다

## 배경 / 문제 정의

토큰을 바꿔도 직접 적은 색은 따라 바뀌지 않아 라이트 바탕 위에 다크 흔적(흰 글자, 흰 반투명 면, 어두운 그림자)으로 남는다.
하위 티켓 1·3에서 일부가 정리되므로 이 티켓은 그 뒤에 남은 것만 다룬다(상위 티켓 결정 3의 순서).

## 시작 전에 사용자에게 물을 결정

1. **이미지·영상 위 글자**: 배지 이미지나 배경 영상 위의 흰 글자는 바탕이 바뀌어도 이미지 위에 있으므로 의도된 흰색일 수 있다. (추천) 이미지 위 글자는 흰색을 유지하고 `colors/snow`로만 이름을 바꾼다 / 모두 새 글자색으로 바꾼다
2. **그림자**: (추천) 새 시스템 규칙대로 모두 지운다. 입력창 그림자(`field/shadow`)만 남긴다 / 배지 공개 연출처럼 연출용 그림자는 남긴다
3. **blur**: (추천) 탭바(전용 토큰)를 뺀 나머지 blur는 새 시스템 `blur` 0을 따라 지운다 / 연출용 blur는 남긴다
4. **티켓 크기**: 다시 센 결과가 크면 (추천) 홈·배지·인벤토리·지도·프로필 영역별로 하위 티켓을 쪼갠다 / 한 티켓으로 진행한다

## 완료 조건

- 리터럴 흰색·검정(`text-white`·`bg-black`·인라인 `#fff`·SVG `fill`)과 그 위·아래에 놓이는 면 사이의 대비를 전수 점검해 글자 4.5:1·아이콘 3:1 미만을 0건으로 만든다. 2131이 남긴 짝 어긋남(인계 절)이 대상이다.

- 시작할 때 다시 센 목록의 항목마다 「바꿈」 또는 「의도된 값이라 유지(사유)」가 완료 기록에 있다.
- 유지하지 않기로 한 다크 전제 값이 0건이다.
- 바뀐 화면의 393px 폭 스크린샷을 완료 기록에 남긴다.

### 주요 의사결정 / 핵심 메모
> 개발 과정에서 검토·결정된 사항, 선택하지 않은 대안과 그 이유.

**시작 전 사용자 결정 (2026-10-16, 질문창)**

1. **이미지 위 글자**: 추천안(흰색 유지, `--snow`로 이름만)이 아니라 「모두 새 글자색」을 골랐으나, 그대로 적용하면 어두운 이미지·영상·블롭 배경 위 글자 대비가 무너져 후속 질문으로 정했다. **결론: 어두운 이미지·영상·블롭·막 위 글자만 `--snow`를 유지하고, 그 밖의 모든 글자는 새 글자색(`--foreground`·`--muted` 등)으로 바꾼다.** 글자 4.5:1·아이콘 3:1 완료 조건이 우선한다.
2. **그림자**: 모두 지우고 입력창 그림자(`field/shadow`)만 남긴다. `box-shadow: inset 0 0 0 1px …` 형태의 테두리·선택 링은 그림자가 아니라 테두리 대용이라 유지한다.
3. **blur**: 탭바(`--tabbar-blur`)를 뺀 나머지 blur를 모두 지운다(새 시스템 `blur` 0).
4. **티켓 크기**: 하위 티켓을 늘리지 않고 한 티켓에서 영역별로 3회로 나눠 돌린다(2133에서 회마다 게이트를 돌려 재작업이 0회였다).

- 배지 상세: 획득/미획득, 배경 없음/블롭/정적 배경색(테마). 미획득은 `grayscale opacity-50`을 유지한다. 컬렉션 링크 행의 이미지 폴백.

- 홈 피드 시트: 열림/닫힘, 행 묶음(아코디언 펼침/접힘), 아바타 이미지/폴백 아이콘.
- 배지 공유: 툴팁 열림(그림자 없음), 시트 미리보기 체크보드 면.

- VOC: 상태 칩 3종(문의중/확인중/답변완료)+심각도 칩+카테고리 칩, 답변 있음/없음, 빈 상태.

- 퀘스트 픽업 장면: 마커 펄스 중 / 모달 열림.

#### 알려진 임시 결함

시각 슬롭 경고
- 흰 반투명을 검정 반투명으로 1:1 뒤집지 않는다(`bg-white/8` → `bg-black/8` 금지). 면 레시피는 `--background-secondary`(카드 안) 또는 `--surface` + `--border`(크림 위)다.
- 카드 속 카드에 이중 테두리를 만들지 않는다. 카드 안 행이나 칩은 테두리 없는 `--background-secondary`다.
- 약하게 보이려고 `opacity-60`이나 `text-foreground/60`을 쓰는 습관을 되살리지 않는다. 약한 글자는 `--muted`다. 약하게 만드는 `opacity`는 이미지(썸네일)에만 쓴다.
- 칩 색 남발 금지. NEW와 참가중이 같은 줄에 나란히 같은 초록으로 놓이면 위계가 흐려진다(옛 빨강도 둘이 같았다). 달성 초록(`accent-content-green`, 네온)은 칩 크기에서만 쓰고 면적을 넓히지 않는다. 색만으로 상태를 구분하지 않도록 칩 글자는 그대로 유지한다.
- 포디엄 막대의 그라디언트는 순위(높이·알파)를 표현하는 기존 구조만 유지하고 새 그라디언트·유리질은 추가하지 않는다.
- 그림자로 위계를 만들지 않는다. 툴팁은 어두운 반전 면이라 그림자 없이도 분리된다.
- `--snow`는 반전 면·블롭·이미지 위 막에서만 쓴다. 흰 글자 습관(`text-white` → `text-snow`로 이름만 바꾸기)을 크림·흰 카드 위에 적용하지 않는다.
- 면을 바꾸면 그 위 글자·아이콘·글리프도 짝으로 바꾼다(잠금 글리프, 포디엄 글자, 체크인 칩 글자 사례).
- 정적 투명 체크보드는 기능 패턴이다. 장식 패턴으로 키우지 않는다.

티켓과 실제의 어긋남 (카리나가 완료 기록에 반영하도록 알린다)
- 티켓이 인용한 "`background_video_url` 보유 배지 351건"은 낡은 수치다. 티켓 20260914_1930이 2026-09-14에 배경 이미지·영상을 전량 삭제했다(배지 82, 컬렉션 10, 트라이브 1). 남은 것은 `background_color`와 `background_animation` 소수(당시 배지 각 1건)다. 나는 DB 도구가 없어 현재 건수를 확인하지 못했다. 카리나가 읽기 전용 SELECT로 `badges`, `item_books`, `tribes`의 `background_color`, `background_animation` 보유 건수를 확인해 주기 바란다. 건수가 소수면 "배경이 있으면 snow" 단순 규칙으로 충분하다.
- 취소 버튼(MissionDetailClient 439~443행)은 이미 Button secondary라 변경할 것이 없다. 참가하기 버튼은 461행에 있다.

#### 알려진 임시 결함

- 흰 반투명을 검정 반투명으로 1:1 뒤집지 않는다(`bg-white/10` → `bg-black/10` 금지). 면 레시피는 흰 Card 안 `bg-background-secondary`, 크림 위 단독은 `bg-surface border border-border`다.
- PoiCarouselModal ItemRow 안 아이콘 칸에 같은 secondary를 또 쓰면 면이 이중으로 겹쳐 칸이 사라진다. 그래서 칸은 `bg-surface`(흰색)로 둔다. 카드 속 카드에 이중 테두리도 만들지 않는다.
- `text-white` → `text-snow` 이름만 바꾸는 습관을 크림·흰 면에 적용하지 않는다. snow는 PosterCard 막·CardChipRow scrim·지도 라벨 막·`--backdrop` 로더 눈에서만 쓴다.
- 약하게 보이려고 `opacity`나 `text-foreground/N`을 쓰는 습관을 되살리지 않는다. 약한 글자는 `--muted`다. opacity는 이미지·비활성 표현에만 남긴다(미획득 썸네일, 빈 슬롯, 범위 밖 마커).
- 지도 클러스터의 radial-gradient와 PosterCard의 막 그라디언트는 기능 구조(개수 표현, 글자 가독성 램프)다. 새 그라디언트나 유리질은 추가하지 않는다.
- 현재 위치 버튼은 그림자를 지우면 지도 위에서 윤곽이 사라지므로 1px `--border`로 분리한다. 그림자로 위계를 만들지 않는다.
- accent 마커의 글리프가 흰색에서 근검정으로 뒤집히는 것은 이 회에서 눈에 띄는 변화다. 393px로 지도를 열어 흰 글리프에 익숙한 눈에 어색하지 않은지 본다.
- 판정이 어려워 유지한 것(blur 2종, 미사용 dotmatrix, 브랜드 색)은 사유를 완료 기록에 적는다. 임의로 지우지 않는다.
- 지금 코드의 일부 주석(PosterCard 17~19, CardChipRow 10~11, ArticleView 16, blobAnimation 67~70)이 `text-white`·`--foreground = #ffffff`를 설명한다. 주석이 거짓이 되지 않게 함께 고친다.
