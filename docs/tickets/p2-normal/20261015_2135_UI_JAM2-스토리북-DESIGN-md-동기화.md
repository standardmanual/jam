## 핵심 요약

- 요구사항: 스토리북의 파운데이션 페이지와 컴포넌트 스토리, `jam-web/DESIGN.md`, MODULAR 안내 문서를 새 디자인 시스템 기준으로 맞춘다.

`jam-web/DESIGN.md`는 다크 캔버스와 레드오렌지 기준이고, 희귀도 이름도 옛 이름(legend·mythic)이다. 상위 티켓 결정 1로 staging이 라이트가 되므로 문서와 스토리북도 지금 서비스에 맞춰야 한다.
[JAM 2.0 디자인 시스템](<../../plan/jam2/11 JAM 2.0 디자인 시스템.md>) 0절은 "JAM 2.0을 배포할 때 DESIGN.md를 덮어쓴다"고 적었는데, staging에 바로 적용하기로 해서 시점이 앞당겨진다.
