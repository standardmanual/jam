# [Admin] 어드민 범위 밖에 그려지는 포털이 서비스 토큰 색을 받는다

## 핵심 요약

- 요구사항: `container` 없이 `body` 바로 아래에 그려지는 어드민 포털(AlertDialog·Dialog·Select·Popover 등)이 `[data-admin-theme]` 밖이라 서비스 `--border`·`--foreground`·`--muted` 값을 받는다. 어드민 색이 바뀌기 전과 같게 만든다.
- 구현 계획: 포털 컨테이너를 어드민 루트로 지정하거나, 포털 콘텐츠에 `data-admin-theme`를 걸어 어드민 값을 되찾게 한다. 둘 중 하나로 정하고 `container`를 받지 않는 어드민 포털 파일 19개를 개별 확인한다.
- 관련 파일: `jam-web/src/components/admin/ui/alert-dialog.tsx`(54행 `border-border`, 91행 `text-foreground`, 132행 `bg-white text-foreground hover:bg-muted`), `jam-web/src/app/admin/strava-backfill/StravaBackfillClient.tsx`(261행 AlertDialog)

## 배경 / 문제 정의

티켓 20261015_2131에서 서비스가 새 이름(`--border`·`--foreground`·`--muted` 등)을 `:root`에 정의하고 어드민은 `[data-admin-theme]` 안에서 같은 이름을 다시 정의해 덮도록 했다. 이 방식은 포털이 어드민 범위 밖에 그려지면 어드민 값이 아니라 서비스 값을 받는다.
`StravaBackfillClient.tsx`의 취소 버튼은 hover 때 서비스 `--muted`(#666666) 배경 위에 어두운 글자가 올라간다. 같은 문제를 가진 `container` 미지정 포털 파일이 19개 더 있고, 토큰 이름 클래스를 쓰는지 개별 확인이 필요하다.
어드민 코드를 건드리지 않는다는 2131의 범위 때문에 남은 발견물이다(민지 sideFindings, 2026-10-15).

## 완료 조건

- 로컬 `next dev`(메인 트리)에서 어드민 다이얼로그(`strava-backfill`의 AlertDialog 포함)의 테두리·글자·hover 색이 2131 이전과 같다(`getComputedStyle`로 확인).
- `container`를 받지 않는 어드민 포털 파일 19개를 확인해 목록과 결과를 완료 기록에 남긴다.
- `scripts/verify.sh`가 통과한다.
