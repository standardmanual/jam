# [Admin] 어드민 범위 밖에 그려지는 포털이 서비스 토큰 색을 받는다

## 핵심 요약

- 요구사항: `container` 없이 `body` 바로 아래에 그려지는 어드민 포털(AlertDialog·Dialog·Select·Popover 등)이 `[data-admin-theme]` 밖이라 서비스 `--border`·`--foreground`·`--muted` 값을 받는다. 어드민 색이 바뀌기 전과 같게 만든다.
- 구현 계획: 포털 컨테이너를 어드민 루트로 지정하거나, 포털 콘텐츠에 `data-admin-theme`를 걸어 어드민 값을 되찾게 한다. 둘 중 하나로 정하고 `container`를 받지 않는 어드민 포털 파일 19개를 개별 확인한다.
- 관련 파일: `jam-web/src/components/admin/ui/alert-dialog.tsx`(54행 `border-border`, 91행 `text-foreground`, 132행 `bg-white text-foreground hover:bg-muted`), `jam-web/src/app/admin/strava-backfill/StravaBackfillClient.tsx`(261행 AlertDialog)

## 배경 / 문제 정의

티켓 20261015_2131에서 서비스가 새 이름(`--border`·`--foreground`·`--muted` 등)을 `:root`에 정의하고 어드민은 `[data-admin-theme]` 안에서 같은 이름을 다시 정의해 덮도록 했다. 이 방식은 포털이 어드민 범위 밖에 그려지면 어드민 값이 아니라 서비스 값을 받는다.
`StravaBackfillClient.tsx`의 취소 버튼은 hover 때 서비스 `--muted`(#666666) 배경 위에 어두운 글자가 올라간다. 같은 문제를 가진 `container` 미지정 포털 파일이 19개 더 있고, 토큰 이름 클래스를 쓰는지 개별 확인이 필요하다.
어드민 코드를 건드리지 않는다는 2131의 범위 때문에 남은 발견물이다(민지 sideFindings, 2026-10-15).

## 완료 조건

- 로컬 `next dev`(메인 트리)에서 어드민 다이얼로그(`strava-backfill`의 AlertDialog 포함)의 테두리·글자·hover 색이 2131 이전과 같다(`getComputedStyle`로 확인).
- `container`를 받지 않는 어드민 포털 파일 19개를 확인해 목록과 결과를 완료 기록에 남긴다.
- `scripts/verify.sh`가 통과한다.

### 주요 의사결정 / 핵심 메모

- **방식 선택: 포털 콘텐츠에 data-admin-theme를 건다(B안)**. 근거:
  1. 바꾸는 곳이 6개 프리미티브뿐이다. A안(컨테이너를 어드민 루트로)은 컨테이너를 못 받는 호출 파일 25곳을 고치거나, 프리미티브 기본값을 `document.querySelector`로 바꿔야 한다.
  2. B안은 CSS 변수 범위만 바꾼다. 포털 DOM 위치·쌓임 순서·포커스 순서가 그대로다. A안은 포털이 어드민 래퍼 안으로 옮겨져 stacking context와 `fixed` 기준이 달라질 수 있다.
  3. SSR/hydration에서 `document` 접근이 없다.
  4. 이미 `container`를 넘기는 호출은 같은 값을 한 번 더 받을 뿐 달라지는 것이 없다.
- `components/admin/ui`는 어드민 밖에서 import하는 곳이 없음을 확인했다(grep, `app/admin`·`components/admin` 밖 일치 0건) — 서비스 화면의 색은 영향받지 않는다.
- Tooltip은 Portal을 쓰지 않고 인라인으로 그려져 대상이 아니다.
- **`container` 없는 포털 호출 파일 확인(티켓의 19개는 현재 25개)**: `<…Content>` 태그에 container가 없는 파일을 정규식으로 센 결과다. 전부 위 프리미티브를 거치므로 한 번에 덮인다.
  - app/admin: activity-badge-image/page, asset-generator/ApplyTab·PresetPanel·TextLayerFields, assets/ShapeStudioPanel, assets/logo3d/Logo3DSections, badge-image/page, gate-missions/GateMissionForm, missions/MissionConditionSection·MissionForm, points/UserGrantForm, strava-backfill/StravaBackfillClient(AlertDialog), users/[id]/UserTribeChangeForm
  - components/admin: MultiBadgeSearchSelect, data-table/{bulk-action-bar,column-header,faceted-filter,sort-select,view-options}, ecosystem/DevRequestButton, ops/{OpsBalanceRuleFields,OpsScheduleFilters,OpsSignalFields,OpsStatusLegend,trends/OpsTrendSources}
  - 호출 파일별로 토큰 이름 클래스 사용 여부는 개별 확인하지 않았다: 프리미티브 한 곳에서 일괄 덮으므로 파일별 확인이 결과를 바꾸지 않는다.

### 잔여 이슈
- 로컬 `next dev`에서 strava-backfill AlertDialog 취소 버튼 hover의 `getComputedStyle`(배경이 서비스 `--muted` #666666이 아닌 어드민 값) 확인이 남는다(메인 트리에서, 쓰기 버튼은 누르지 않는다).
