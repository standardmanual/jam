# [Admin] 어드민 배지 삭제 가드에 개체 이력(inventory_item_events)의 배지 참조를 더한다

## 핵심 요약

- 요구사항: 티켓 20261018_0053 게이트(민지)가 짚었다. 마이그레이션 235가 만든 `inventory_item_events.badge_id`(ON DELETE SET NULL)가 어드민 배지 삭제 가드 `jam-web/src/lib/admin/badge-references.ts`의 참조 목록에 없다. 지금은 배지를 지워도 막히지 않고 이력의 배지 칸만 NULL이 된다. 227의 `item_issue_log` 선례처럼 «삭제를 막지 않는 참조»로 목록에 더하고, 삭제 확인 화면에 이력 건수가 보이게 할지 정한다.
- 구현 계획: `badge-references.ts`에 새 항목을 더하고 관련 시험을 맞춘다(227 선례와 `BADGE_UNDO_REFERENCE_TABLES` 방식은 0053에서 이미 반영됨).
- 관련 파일: `jam-web/src/lib/admin/badge-references.ts`, `jam-web/src/lib/admin/registerChecks/references.ts`.

## 완료 조건

- 배지 삭제 가드가 개체 이력의 참조를 알고, 삭제는 막지 않되 영향 건수를 센다(시험 포함).

## 완료 기록

티켓 20261018_0055의 어드민 회차가 처리했다(2026-10-18, 커밋 `d44c14188`). `lib/admin/badge-references.ts`에 `inventory_item_events.badge_id`(ON DELETE SET NULL, 삭제를 막지 않음)와 `combine_pending_results.badge_id`(삭제를 막음)를 더했고 시험(`badge-references-combine.test.ts`)이 분류를 고정한다. 알려진 영향: 개체 이력이 남은 배지는 단건 삭제 가드의 합계에 걸려 하드 삭제가 계속 막힐 수 있다(`item_issue_log` 선례와 같은 동작).
