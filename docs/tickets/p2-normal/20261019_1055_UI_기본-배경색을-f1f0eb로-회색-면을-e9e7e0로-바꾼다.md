# [UI] 기본 배경색을 #f1f0eb로, 회색 면을 #e9e7e0로 바꾼다

## 핵심 요약

- 요구사항: 사용자 요청(2026-10-19)으로 기본 배경색 `--background`를 #fafaf0에서 **#f1f0eb**로 바꾼다. 새 바탕과 거의 같아지는 회색 면(`--background-secondary`·`--default`·`--default-soft`, 지금 #f2f2f2)은 사용자가 고른 **#e9e7e0**로 함께 바꾼다.
- 구현 계획: 토큰 값과 값이 박힌 곳을 바꾸고, 디자인 시스템 문서 11과 DESIGN.md의 낡은 값·대비 숫자를 고친다. 컴포넌트 설명 주석의 대비 숫자는 후속 티켓으로 남긴다(사용자 결정).
- 관련 파일: `jam-web/design-system/tokens/colors.css`(38~42행, 74~75행과 대비를 적은 주석), `jam-web/design-system/_ds_manifest.json`(생성 파일), `jam-web/src/app/layout.tsx`(28행 `themeColor`), `jam-web/.storybook/preview.tsx`(24·28행), `jam-web/src/lib/pageBackground.ts`(4행 주석), 위 두 값이 적힌 주석과 문서(아래 계획)

## 배경 / 문제 정의

JAM 2.0 디자인 시스템 적용(상위 티켓 20261015_2130)에서 기본 배경은 크림 #fafaf0이었다. 사용자가 새 값 #f1f0eb로 바꾸라고 했다. 값만 바꾸면 회색 면(#f2f2f2)이 바탕과 1.02:1이 되어 바탕 위에 직접 놓이는 보조 버튼, 탭 트랙, 진행 바 트랙이 사라진 것처럼 보인다. 그래서 회색 면도 함께 바꾼다.

## 사용자 결정 (2026-10-19, 질문창)

1. **범위**: 값이 박힌 곳과 핵심 문서(디자인 시스템 문서 11, DESIGN.md, 토큰 주석)까지 고친다. 컴포넌트 설명 주석의 대비 숫자(약 20개 파일)는 후속 티켓으로 남긴다(추천안).
2. **회색 면은 함께 바꾼다.** 후보 가운데 **#e9e7e0**를 골랐다(추천안). 새 바탕과 1.08:1(지금 #f2f2f2가 기존 바탕에서 갖던 1.07:1과 같은 수준), 흰 면과 1.24:1, 보조 글자 `muted` 4.64:1이다.

### 계산해 둔 대비 (WCAG 상대 휘도 공식, 새 바탕 #f1f0eb)

| 쌍 | 기존(#fafaf0) | 새 값 |
|---|---|---|
| `foreground` #171717 | 17.07 | 15.71 |
| `muted` #666666 | 5.47 | 5.03 |
| `link` #0e7a38 | 5.18 | 4.77 |
| `accent` #19b551(글자로 쓸 때) | 2.57 | 2.37 |
| 흰 카드 #ffffff | 1.05 | 1.14 |
| `border` #cfc9b4 | 1.58 | 1.45 |
| `warning` #f5a300 / `success` #17c964 / `danger` #ff383c | 1.98 / 2.09 / 3.40 | 1.82 / 1.92 / 3.13 |
| 회색 면 #e9e7e0(바탕 / 흰 면 / `muted` 글자 / `foreground` 글자 / `border`) | 해당 없음 | 1.08 / 1.24 / 4.64 / 14.49 / 1.34 |

문서와 주석에 새 숫자를 쓸 때는 위 표를 그대로 옮기거나, 표에 없는 쌍(예: `accent-content` 6색, 진행 트랙의 채움 대비)은 같은 공식으로 스크립트를 돌려 계산한 값을 쓴다. 손으로 추정한 값을 쓰지 않는다.

## 구현 계획 (파일 단위)

규모 사전 판정: 바뀌는 파일이 토큰, 생성 파일, 앱 설정, 스토리북, 주석, 문서까지 열 개를 넘는다. 사용자가 범위를 정했고 아래가 파일 단위 계획이라 첫 호출부터 `planOnlyWaiver`를 넘긴다. 변경 줄 수는 값과 주석이라 적다.

1. `jam-web/design-system/tokens/colors.css`
   - `--background: #f1f0eb`(38행). `--surface-transparent: rgba(241, 240, 235, 0)`(42행, 같은 색의 완전 투명).
   - `--background-secondary`(39행), `--default`(74행), `--default-soft`(75행)를 `#e9e7e0`. 같은 값 #f2f2f2를 쓰는 다른 토큰이 있으면 같은 이유인지 확인해 함께 바꾸고, 이유가 다르면 바꾸지 않고 요약에 적는다.
   - 대비 숫자를 적은 주석을 새 값으로 고친다: `--link` 「크림 바탕 5.18:1」 → 4.77:1, `--accent` 「2.57:1」 → 2.37:1, `accent-content` 「1.1~1.3:1」 → 같은 공식으로 계산한 범위.
2. `jam-web/design-system/_ds_manifest.json`: 생성 파일이라 손으로 고치지 않는다. `jam-web/scripts/ds-manifest-sync.mjs`로 다시 만든다(실행 방법은 스크립트 머리말과 `package.json`을 따른다). `--background`(495행), `--surface-transparent`(519행), `--background-secondary`·`--default`·`--default-soft`(501·651·657행) 값이 바뀌어야 한다.
3. `jam-web/src/app/layout.tsx` 28행 `themeColor: "#f1f0eb"`.
4. `jam-web/.storybook/preview.tsx` 24·28행: 기본 배경 `#f1f0eb`와 주석.
5. 값(#fafaf0 또는 #f2f2f2)이 적힌 주석: `jam-web/src/lib/pageBackground.ts`(4행), `jam-web/src/components/today/{BriefCard,HeroCard,ListCard,PosterCard,SquareCard}.stories.tsx`(캔버스 설명 줄), `jam-web/src/components/ui/SlidingTabs.tsx`(53·61행), `jam-web/design-system/components/navigation/SlidingTabs.stories.tsx`(76행), `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`(440행). 값만 새 값으로 바꾸고, 같은 줄의 대비 숫자도 새 값으로 계산해 고친다. `PosterCard.stories.tsx` 52행의 `fill="#f2f2f2"`는 그림 속 색이라 **바꾸지 않는다**.
6. `docs/plan/jam2/11 JAM 2.0 디자인 시스템.md`: 3.1절 대응표의 새 값 열(78·79·81·96행), 2.1절 3번 값(55행), 5절의 대비 숫자(5.1절 174행 흰 카드 1.05 → 1.14, 5.1절 `background-secondary` 값과 1.07 문구, 5.2절 트랙 값, 5.3절 2.57·5.18, 5.4절 `ghost`의 5.18과 `secondary` 212·213행의 값과 1.07, 5.5절 `field/border` 1.58, 6절 열린 항목 249·251행의 1.58·1.07). 문서의 `#f2f2f2`는 회색 면이면 `#e9e7e0`로 바꾼다. 문서의 결정 이력(1~2절의 「2026-10-15 사용자 결정」 표)은 이력이라 값을 바꾸지 않고, 새 결정을 5절 서두나 0절에 2026-10-19 한 줄로 적는다(기본 배경 #f1f0eb, 회색 면 #e9e7e0, 사용자 결정, 이 티켓).
7. `jam-web/DESIGN.md`: 값이나 대비 숫자가 적힌 곳(`크림 바탕` 문장 가운데 숫자가 있는 줄)만 고친다. 값을 옮겨 적지 않는 문서라 대부분은 바꿀 것이 없을 수 있다.
8. 이 티켓에서 하지 않는 것: 컴포넌트 설명 주석 중 5번에 없는 곳의 「크림 바탕 N:1」 숫자(약 20개 파일, 후속 티켓), 피그마 파일 수정, claude.ai/design 업로드본, 어드민 화면(리뉴얼 범위 밖).

## 완료 조건

### 구현 범위 (게이트 판정 대상)

- `colors.css`에서 `--background`가 `#f1f0eb`이고 `--surface-transparent`가 같은 색의 투명값이며, `--background-secondary`·`--default`·`--default-soft`가 `#e9e7e0`다.
- `_ds_manifest.json`이 `ds-manifest-sync.mjs`로 다시 만든 결과이고 새 값을 담는다(`scripts/verify.sh`의 `ds:check`가 통과한다).
- `layout.tsx`의 `themeColor`와 스토리북 기본 배경이 `#f1f0eb`다.
- `jam-web/src`, `jam-web/design-system`, `jam-web/.storybook`에서 `#fafaf0`이 **남아 있지 않다**(`jam2-token-migrate.report.json` 같은 이관 이력 파일 제외). 확인 방법은 `git grep -nIi fafaf0 -- jam-web ':!jam-web/scripts/jam2-token-migrate.report.json'`가 0건인 결과다.
- 회색 면 #f2f2f2가 토큰·주석·문서에서 위 계획 범위에 한해 새 값으로 바뀌어 있고, 바뀌지 않은 `#f2f2f2`는 `PosterCard.stories.tsx`의 그림 색뿐이다.
- 문서 11과 DESIGN.md(계획 6·7번)에 남은 크림 바탕 대비 숫자가 위 표의 값과 같다. 표에 없는 쌍을 쓴 곳은 같은 공식의 계산 결과이고, 어떻게 계산했는지 요약에 적는다.
- `scripts/verify.sh`가 통과한다.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤)

- 로컬 `next dev`와 스토리북으로 홈, 배지 목록, 프로필, 보조 버튼이 있는 화면, 탭, 진행 바에서 새 바탕과 회색 면이 구분되어 보이는지 실렌더로 확인하고 스크린샷으로 사용자에게 보여 준다.
- 후속 티켓을 만든다: 컴포넌트 설명 주석의 낡은 대비 숫자 정리(계획 8번의 약 20개 파일).
