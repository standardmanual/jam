# [UI] 기본 배경색을 #f1f0eb로, 회색 면을 #e9e7e0로 바꾼다

## 핵심 요약

- 요구사항: 사용자 요청(2026-10-19)으로 기본 배경색 `--background`를 #fafaf0에서 **#f1f0eb**로 바꾼다. 새 바탕과 거의 같아지는 회색 면(`--background-secondary`·`--default`·`--default-soft`, 지금 #f2f2f2)은 사용자가 고른 **#e9e7e0**로 함께 바꾼다.
- 구현 계획: 토큰 값과 값이 박힌 곳을 바꾸고, 디자인 시스템 문서 11과 DESIGN.md의 낡은 값·대비 숫자를 고친다. 컴포넌트 설명 주석의 대비 숫자는 후속 티켓으로 남긴다(사용자 결정).
- 관련 파일: `jam-web/design-system/tokens/colors.css`(38~42행, 74~75행과 대비를 적은 주석), `jam-web/design-system/_ds_manifest.json`(생성 파일), `jam-web/src/app/layout.tsx`(28행 `themeColor`), `jam-web/.storybook/preview.tsx`(24·28행), `jam-web/src/lib/pageBackground.ts`(4행 주석), 위 두 값이 적힌 주석과 문서(아래 계획)

## 배경 / 문제 정의

JAM 2.0 디자인 시스템 적용(상위 티켓 20261015_2130)에서 기본 배경은 크림 #fafaf0이었다. 사용자가 새 값 #f1f0eb로 바꾸라고 했다. 값만 바꾸면 회색 면(#f2f2f2)이 바탕과 1.02:1이 되어 바탕 위에 직접 놓이는 보조 버튼, 탭 트랙, 진행 바 트랙이 사라진 것처럼 보인다. 그래서 회색 면도 함께 바꾼다.

## 사용자 결정 (2026-10-19, 질문창)

1. **범위**: 값이 박힌 곳과 핵심 문서(디자인 시스템 문서 11, DESIGN.md, 토큰 주석)까지 고친다. 컴포넌트 설명 주석의 대비 숫자(약 20개 파일)는 후속 티켓으로 남긴다(추천안).
2. **회색 면은 함께 바꾼다.** 후보 가운데 **#e9e7e0**를 골랐다(추천안). 새 바탕과 1.08:1(지금 #f2f2f2가 기존 바탕에서 갖던 1.07:1과 같은 수준), 흰 면과 1.24:1, 보조 글자 `muted` 4.64:1이다.
