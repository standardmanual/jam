# [Admin] JAM2 밸런스 설정 새 표 구역: 잠긴 아이템 배지, 챕터, 컬렉션 완성·믹스 실패 포인트 (묶음 7, 7-2)

## 핵심 요약

- 요구사항: 7-1이 만든 설정 화면 틀에 새 표 구역을 더한다. (1) 잠긴 아이템 배지의 등급별 최소값, (2) 챕터(챕터별 누적 점수, 활동별 점수, 주간 상한, 챕터 더하기: `chapter_definitions`, `chapter_score_rules`), (3) 컬렉션 등급별 완성 포인트와 믹스 실패 포인트(`item_book_tier_default_rewards`와 믹스 정책의 포인트 칸).
- 구현 계획: 1회. 구역별 읽기·저장 API와 입력 검증, 변경 이력 연결, 시험.
- 관련 파일(시작 때 아현이 확인한다): 위 새 표들(마이그레이션 220·221·222 등), 운영 로직 12장(챕터), 8장, 7장(혜린 조사(2026-10-22), 카리나가 직접 확인하지는 않았다). 규모 약 18파일 1,500줄.

## 배경 / 문제 정의

새 설정 표는 편집 화면이 없다. 챕터는 «챕터 3»처럼 숫자로만 표기하고 이름은 두지 않는다(2026-10-21 결정).

## 상세 요구사항

### 서비스/코드베이스 관점

- DB 변경은 없다. 값 검증(음수, 순서가 거꾸로인 누적 점수 등)은 서버에서 한다.
- 챕터 더하기는 새 챕터 행을 추가하는 동작이므로 지금 챕터 점수 계산과 연출이 읽는 곳(`lib/chapter/`)과 맞는지 확인한다.

## 선행과 시작 전 확인

- 선행: 7-1.
- 시작 때 사용자에게 물을 것: 챕터 더하기에서 챕터를 줄이거나 점수를 바꿀 때 이미 챕터에 오른 유저를 어떻게 다룰지. 추천안은 시작 때 붙인다.

## 완료 조건

- 새 표 세 구역에서 값을 바꾸면 저장되고 변경 이력에 남는다(시험으로 고정).
- 잘못된 값(음수, 거꾸로 된 누적 점수)은 저장되지 않고 이유가 보인다.
