# [Infra] 정책 변경 시 서비스 정책 대시보드 동기화 에이전트 규칙 추가

## 핵심 요약

- 요구사항: 서비스 운영 정책, 밸런스 수치, 속도/어뷰징 기준, 도메인 규칙 변경 시 어드민 서비스 운영 정책 대시보드(`policiesData.ts`)도 함께 동기화하도록 에이전트 팀 규칙(CLAUDE.md, jam-work, jam-docs, jam-developer, jam-reviewer, DoD, contract.json)에 명시한다.
- 구현 계획: `CLAUDE.md`, `.claude/skills/jam-work/SKILL.md`, `.claude/skills/jam-docs/SKILL.md`, `.claude/agents/jam-developer.md`, `.claude/agents/jam-reviewer.md`, `.claude/skills/jam-work/references/definition-of-done.md`, `docs/agents/contract.json`에 정책 대시보드 동기화 규칙을 명시하고 계약 검사를 통과시킨다.
- 관련 파일: `CLAUDE.md`, `.claude/skills/jam-work/SKILL.md`, `.claude/skills/jam-docs/SKILL.md`, `.claude/agents/jam-developer.md`, `.claude/agents/jam-reviewer.md`, `.claude/skills/jam-work/references/definition-of-done.md`, `docs/agents/contract.json`.

## 배경 / 문제 정의

신규 구현된 서비스 운영 정책 대시보드(`/admin/policy-dashboard`)는 JAM 2.0 운영 로직 19개 장 전체 96개 세부 정책을 체계화한 단일 관제 화면이다. 향후 서비스 정책, 밸런스 수치, 판정 기준, 챕터/미션/포인트 규칙이 변경될 때 코드와 문서만 수정하고 대시보드 카탈로그(`jam-web/src/lib/admin/policyDashboard/policiesData.ts`)를 갱신하지 않으면 대시보드 정보가 현실과 어긋나는 정보 불일치가 발생한다. 따라서 모든 에이전트가 정책 변경 작업 시 이 대시보드 카탈로그를 필수 동기화 대상으로 취급하도록 운영 규칙에 명시해야 한다.

## 상세 요구사항

1. `CLAUDE.md`: 절대 규칙 §2(서비스 변경 시 문서 체계 갱신)에 정책·밸런스 수치·판정 규칙 변경 시 `jam-web/src/lib/admin/policyDashboard/policiesData.ts` 동기화 의무 명시.
2. `.claude/skills/jam-work/SKILL.md`: 파이프라인 분기표(engine, service, content, admin, api) 및 4단계 승인 후 처리에 정책 대시보드 동기화 확인 명시.
3. `.claude/skills/jam-docs/SKILL.md`: 정책 대시보드 카탈로그(`policiesData.ts`) 동기화 가이드 절 추가.
4. `.claude/agents/jam-developer.md` (아현): 구현 원칙/하드 룰에 정책·수치 변경 시 `policiesData.ts` 동기화 명시.
5. `.claude/agents/jam-reviewer.md` (민지): 게이트 리뷰 체크리스트 11번(문서 및 정책 대시보드 반영)에 동기화 점검 항목 명시.
6. `.claude/skills/jam-work/references/definition-of-done.md`: 품질 점검 항목에 서비스 정책 대시보드 동기화 체크리스트 추가.
7. `docs/agents/contract.json`: `paths_exist`에 `jam-web/src/lib/admin/policyDashboard/policiesData.ts` 등록하여 파일 이동/삭제 시 계약 검사에서 감지.
