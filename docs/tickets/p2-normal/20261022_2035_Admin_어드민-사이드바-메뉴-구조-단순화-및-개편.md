# [Admin] 어드민 사이드바 메뉴 구조 단순화 및 개편

## 핵심 요약
- 요구사항: 관리자 서비스 좌측 메뉴를 업무 도메인별 6개 그룹(라이브, 유저, 콘텐츠, 밸런스, 디자인, 시스템)으로 재배치하고, 그룹명 및 메뉴명을 단순화(기획함→운영플랜, 유저 목록→유저, 배지 일괄수정→배지 수정, 미션 마스터 콘텐츠 그룹 이동 등)한다.
- 구현 계획: `jam-web/src/components/admin/adminNavItems.ts`의 `NAV_GROUPS`를 6개 그룹 구조로 개편하고 관련 라벨을 축약·수정하며, `adminNavItems.test.ts` 회귀 테스트를 함께 갱신한다.
- 관련 파일:
  - `jam-web/src/components/admin/adminNavItems.ts` (L45-L108 `NAV_GROUPS`)
  - `jam-web/src/components/admin/__tests__/adminNavItems.test.ts` (회귀 테스트)

## 배경 / 문제 정의
기존 어드민 좌측 메뉴는 5개 그룹 중 `컨텐츠 관리`에 12개 메뉴가 몰려있고, 유저 관리/CS 업무(유저 조회, 포인트 관리, 어뷰징 제재, 발급 현황)가 여러 그룹에 분산되어 있어 관리자의 탐색 피로도가 높았다. 또한 그룹명과 메뉴명이 다소 길어 직관적인 인지가 어려웠다.

## 상세 요구사항
1. **그룹 단순화 (6개 그룹)**:
   - `live` (라이브): 운영플랜, 일정표, 투데이, 패턴 사전
   - `users` (유저): 유저, 포인트, 어뷰징, 아이템배지, 미소유 배지
   - `content` (콘텐츠): 배지, 배지 계열, 배지 수정, 지표 라벨, 컬렉션, 미션, 게이트 미션, 퀘스트 프리뷰, 트라이브, 체크인, 레시피
   - `balance` (밸런스): 정책 대시보드, 밸런스, 시뮬레이터, 앰비언트 드랍, 드랍 제외, 인벤토리, 랭킹
   - `design` (디자인): 체크인 배지, 액티비티 배지, 에셋
   - `system` (시스템): 운영 설정, Strava 백필
2. **명칭 단순화 반영**:
   - `기획함` → `운영플랜`
   - `유저 목록` → `유저`
   - `배지 일괄수정` → `배지 수정`
   - `미션 관리` → `미션` (콘텐츠 그룹으로 배치)
   - 기타 그룹명 및 메뉴명 간결화

## 구현 계획
1. `jam-web/src/components/admin/adminNavItems.ts`의 `NAV_GROUPS` 배열을 6개 그룹 및 신규 라벨로 수정.
2. `jam-web/src/components/admin/__tests__/adminNavItems.test.ts`를 신규 메뉴 구조에 맞게 갱신.
3. 단위 테스트 및 린트 검증.

## 완료 조건

- 어드민 사이드바에서 6개 그룹이 간결한 이름으로 노출되며, 각 메뉴 클릭 시 정상 라우팅됨
- 기존 32개 메뉴 항목의 URL 누락이 없어야 함
