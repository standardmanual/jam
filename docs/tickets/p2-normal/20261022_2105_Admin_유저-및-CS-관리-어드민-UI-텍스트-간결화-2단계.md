# [Admin] 유저 및 CS 관리 어드민 UI 텍스트 간결화 (UX Writing 가이드 2단계)

## 핵심 요약
- 요구사항: JAM! UX 라이팅 가이드라인에 따라, 유저 및 CS 관련 화면(`users`, `points`, `item-badges`)의 장황한 설명문, 합쇼체(`~합니다`), 마침표 오용, 잔여 시스템 용어를 정비하고 간결한 해요체/명사형 UI 텍스트로 전환한다.
- 구현 계획: 
  - `users`: 페이지 헤더 간결화(`유저`), 필터 옵션 명확화(`제재 중`→`이용 정지`), 삭제/초기화 경고 문구 단호·명확 톤 적용, 세부 테이블의 빈 상태 문구 해요체 전환(`~없어요`).
  - `points`: 페이지 헤더 간결화(`포인트`), 설명문 내 '잼' 접두사 제거, 정합성 오류 경고문 및 고액 원장 설명문 해요체 전환.
  - `item-badges`: 페이지 헤더 간결화(`아이템배지`, `미소유 배지`), 빈 상태 문구 및 액션 안내문 해요체 전환.

## 배경 / 문제 정의
유저 조회, 포인트 관리, 아이템배지 현황 등 CS/운영 관련 화면들에서 합쇼체(`~합니다.`)와 해요체가 뒤섞여 있고, 빈 상태(Empty state)에 불필요한 마침표가 들어가 있거나, 탈퇴/삭제 등 위험 작업 경고 문구가 딱딱하고 장황했다. 이를 가이드라인에 맞추어 직관적이고 일관된 UX 라이팅으로 정돈한다.

## 완료 조건
- 유저, 포인트, 아이템배지 화면들의 제목과 메뉴명이 일치
- 빈 상태 메시지가 마침표 없는 해요체(`~없어요`)로 통일
- ESLint, Typecheck 및 단위 테스트 통과
