# [Admin] 라이브 운영 어드민 UI 텍스트 간결화 (UX Writing 가이드 3단계)

## 핵심 요약
- 요구사항: JAM! UX 라이팅 가이드라인에 따라, 라이브 운영 관련 화면(`ops-inbox` [운영플랜], `ops-schedule` [일정표], `today` [투데이], `ops-patterns` [패턴 사전])의 메뉴명 불일치, 합쇼체(`~합니다`), 단문 마침표 오용, 잔여 시스템 용어를 정비하고 간결한 해요체/명사형 UI 텍스트로 전환한다.
- 구현 계획: 
  - `ops-inbox`: 사이드바 개편에 맞춰 '받은 기획함'을 '운영플랜'으로 화면 제목 및 백링크 라벨 통일, 빈 상태 및 안내 단문 마침표 제거.
  - `today`: 헤더 '투데이 콘텐츠 관리'를 '투데이'로 통일, CMS/엔지니어링 설명문 정돈, 카드 추가 버튼 라벨 표준화, 미리보기 모달 및 카드 상세/폼의 합쇼체 탈피 및 위험 삭제 액션 단호·명확 톤 전환, 빈 상태 메시지(`~없어요`) 통일.
  - `ops-schedule` / `ops-patterns`: 이미 정돈된 해요체/명사형 유지 및 잔여 단문 마침표 확인.
- 관련 파일:
  - `jam-web/src/app/admin/ops-inbox/page.tsx`
  - `jam-web/src/app/admin/ops-inbox/OpsInboxTable.tsx`
  - `jam-web/src/app/admin/ops-inbox/[bundleId]/page.tsx`
  - `jam-web/src/app/admin/ops-inbox/[bundleId]/not-found.tsx`
  - `jam-web/src/app/admin/today/page.tsx`
  - `jam-web/src/app/admin/today/TodayCardTable.tsx`
  - `jam-web/src/app/admin/today/TodayPreviewModal.tsx`
  - `jam-web/src/app/admin/today/TodayCardForm.tsx`
  - `jam-web/src/app/admin/today/new/page.tsx`
  - `jam-web/src/app/admin/today/[id]/edit/page.tsx`
  - `jam-web/src/components/admin/today/TodayCardDetail.tsx`

## 배경 / 문제 정의
사이드바 메뉴가 '운영플랜', '투데이'로 개편되었으나 화면 헤더와 백링크에는 여전히 '받은 기획함', '투데이 콘텐츠 관리' 등의 구 명칭이 남아있다. 또한 투데이 관련 모달과 폼 컴포넌트에 합쇼체(`~합니다`)와 불필요한 마침표가 남아있어 서비스 가이드라인과 톤앤매너가 불일치했다. 이를 가이드라인에 맞추어 직관적이고 일관된 UX 라이팅으로 정돈한다.

## 완료 조건
- 사이드바 메뉴명과 화면 헤더/백링크 일치 ('운영플랜', '투데이')
- 합쇼체 제거 및 해요체 전환
- 빈 상태 메시지가 마침표 없는 해요체(`~없어요`)로 통일
- 단위 테스트, ESLint, Typecheck 전수 통과
