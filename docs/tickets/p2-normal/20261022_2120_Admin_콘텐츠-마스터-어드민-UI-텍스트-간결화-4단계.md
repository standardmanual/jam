# [Admin] 콘텐츠 마스터 어드민 UI 텍스트 간결화 (UX Writing 가이드 4단계)

## 핵심 요약
- 요구사항: JAM! UX 라이팅 가이드라인에 따라, 콘텐츠 마스터 화면(`missions` [미션], `itembooks` [컬렉션], `recipes` [레시피], `poi` [체크인/장소])의 헤더 및 메뉴명 통일, 합쇼체(`~합니다`), 단문 마침표 오용, 잔여 시스템 용어를 정비하고 간결한 해요체/명사형 UI 텍스트로 전환한다.
- 구현 계획: 
  - `missions`: 헤더 '미션' 통일, 폼 필드 라벨/도움말 단문 마침표 제거, 빈 상태 메시지(`~없어요`), 삭제 안내 단호·명확 톤 전환.
  - `itembooks`: 헤더 '컬렉션' 통일, 도안/아이템 연결 관련 문구 간결화, 빈 상태 메시지 정돈.
  - `recipes`: 헤더 '레시피' 통일, 조합식 영향도 및 삭제 다이얼로그 단호·명확 톤 전환, 빈 상태 메시지 통일.
  - `poi`: 헤더 '체크인' 통일, 장소 승인/검수 텍스트 해요체 전환 및 빈 상태 정돈.

## 배경 / 문제 정의
미션, 컬렉션, 레시피, 체크인 등 핵심 마스터 콘텐츠 관리 화면들에 여전히 긴 설명형 문장, 합쇼체(`~합니다`), 단문 마침표, 딱딱한 삭제 경고문이 남아있었다. 이를 UX Writing 가이드라인에 맞추어 간결하고 명확한 해요체/명사형으로 정비했다.

## 완료 조건
- 각 화면의 제목과 사이드바 메뉴명 일치 ('미션', '컬렉션', '레시피', '체크인')
- 불필요한 단문 마침표 제거 및 해요체 전환
- 빈 상태 메시지가 마침표 없는 해요체(`~없어요`)로 통일
- 단위 테스트, ESLint, Typecheck 전수 통과

## 완료 기록

### 구현 내용 요약
- `missions`: 헤더 `미션`으로 통일, 액션 버튼 `+ 미션 등록` 표준화, 폼 및 표의 에러/안내 메시지 단문 마침표 제거, 빈 상태 메시지 마침표 없는 해요체 통일(`조건에 맞는 미션이 없어요`)
- `itembooks`: 헤더 `컬렉션`으로 통일, 빈 상태 메시지 해요체 전환(`조건에 맞는 컬렉션이 없어요`, `등록된 컬렉션이 없어요`), 등록/수정 폼의 삭제 확인 톤 단호·명확 전환(`삭제할까요? 삭제한 컬렉션은 되돌릴 수 없어요`, 버튼 `삭제`)
- `recipes`: 헤더 `레시피`로 통일, 부제 간결화, 목록 빈 상태 문구 정돈(`등록된 레시피가 없어요`), 폼 내 유효성 에러 문구 및 안내문 단문 마침표 제거
- `poi`: 헤더 `체크인`으로 통일, 검토 큐 및 신규 등록 화면의 장황한 안내문/엔지니어링 티켓 번호 완전 제거 후 직관적인 해요체 전환, 폼 및 삭제 모달 단호·명확 톤 통일
- 48개 단위 테스트, ESLint, `typecheck` 전수 통과 확인
