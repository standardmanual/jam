# [Admin] 콘텐츠 마스터 2 & 디자인·도구 어드민 UI 텍스트 간결화 (UX Writing 가이드 5단계)

## 핵심 요약
- 요구사항: JAM! UX 라이팅 가이드라인에 따라, 배지(`badges`, `badge-families`, `badge-metric-labels`), 트라이브(`tribes`), 에셋 스튜디오(`assets`), 정책 대시보드(`policy-dashboard`)의 헤더 및 메뉴명 통일, 합쇼체(`~합니다`), 단문 마침표 오용, 잔여 시스템 용어를 정비하고 간결한 해요체/명사형 UI 텍스트로 전환한다.
- 구현 계획: 
  - `badges`: 헤더 '배지' 통일, 폼 필드 라벨/도움말 단문 마침표 제거, 빈 상태 메시지(`~없어요`), 삭제 안내 단호·명확 톤 전환.
  - `badges/bulk`: 헤더 '배지 수정' 통일.
  - `badge-families`: 헤더 '배지 계열' 통일, 빈 상태 메시지 통일.
  - `badge-metric-labels`: 헤더 '지표 라벨' 통일.
  - `tribes`: 헤더 '트라이브' 통일, 인접 설정 및 폼 도움말 해요체 전환, 빈 상태 메시지 통일.
  - `assets`: 헤더 '에셋' 통일, Shape Studio 설명문 정돈.
  - `policy-dashboard`: 헤더 '정책 대시보드' 통일, 설명문 간결화.

## 배경 / 문제 정의
배지, 트라이브, 에셋, 정책 대시보드 화면들에서 사이드바 메뉴명과 화면 헤더 간의 미세한 불일치('배지 관리', '트라이브 관리' 등)가 존재하고, 일부 폼과 테이블의 빈 상태 문구 및 위험 액션 확인 문구가 합쇼체나 장황한 설명문으로 남아있었다. 이를 가이드라인에 맞추어 직관적인 해요체/명사형으로 정돈한다.

## 완료 조건
- 각 화면의 제목과 사이드바 메뉴명 일치 ('배지', '배지 수정', '배지 계열', '지표 라벨', '트라이브', '에셋', '정책 대시보드')
- 불필요한 단문 마침표 제거 및 해요체 전환
- 빈 상태 메시지가 마침표 없는 해요체(`~없어요`)로 통일
- 단위 테스트, ESLint, Typecheck 전수 통과
