# [Admin] 공통 셸·에러·디자인·시스템 및 잔여 어드민 UI 텍스트 전수 정돈 (UX Writing 가이드 6단계)

## 핵심 요약
- 요구사항: JAM! UX 라이팅 가이드라인에 따라, 공통 에러 화면(`admin/error.tsx`), 공통 셀렉트 컴포넌트(`*SearchSelect.tsx`), 공통 데이터테이블(`data-table.tsx`), 디자인 도구(`badge-image`, `activity-badge-image`), 밸런스 잔여(`ranking-modes`, `drop-policy/exclusions`), 시스템(`strava-backfill`)에 남아있는 합쇼체(`~합니다`), 단문 마침표 오용, 긴 설명형 안내 문구를 정비하고 간결한 해요체/명사형 UI 텍스트로 전환하여 전수 개편을 완결한다.
- 구현 대상:
  - `admin/error.tsx`: 오류 타이틀 및 안내문 해요체 전환 (`문제가 생겼어요`, `페이지를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`)
  - 공통 `SearchSelect` 8종: 빈 상태 메시지 `검색 결과가 없어요`, `선택한 배지가 없어요`로 통일 (마침표 제거)
  - `data-table.tsx`, `data-table-faceted-filter.tsx`: 기본 빈 상태 메시지 `표시할 항목이 없어요`, `결과가 없어요`로 정돈
  - `badge-image`, `activity-badge-image`: 상단 안내문 및 검색 빈 상태 메시지 간결한 해요체 전환
  - `ranking-modes`: 상단 안내문 및 삭제 다이얼로그 단호·명확 톤 전환
  - `drop-policy/exclusions`: 제외 정책 설명문 간결화
  - `strava-backfill`: 백필 안전 안내문 및 알림 타이틀 해요체 정돈

## 배경 / 문제 정의
1~5단계를 통해 주요 관리 메뉴들이 정비되었으나, 공통 셀렉트 컴포넌트, 공통 에러 바운더리, 디자인 생성 도구 및 일부 정책 페이지에 합쇼체 및 단문 마침표가 잔존해 있었다. 이번 6단계 작업을 통해 어드민 서비스 전체의 어조와 용어를 일관되게 완성한다.

## 완료 조건
- 모든 대상 컴포넌트의 합쇼체(`~합니다`, `~있습니다` 등)를 친절하고 명확한 해요체 또는 명사형 종결로 정돈
- 빈 상태 메시지는 마침표 없는 해요체(`~없어요`)로 전수 통일
- 단위 테스트, Typecheck, ESLint 전수 통과
