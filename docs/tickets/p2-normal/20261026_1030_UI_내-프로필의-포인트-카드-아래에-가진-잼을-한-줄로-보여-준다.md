# [UI] 내 프로필의 포인트 카드 아래에 «가진 잼 {n}» 한 줄을 보여 준다

## 핵심 요약

- 요구사항: 묶음 3(`20261018_0050`)에서 사용자 결정이 남았던 «가진 잼을 늘 보이는 자리»를 정한 결과를 구현한다. 사용자가 채원 추천을 승인했다(2026-10-26): **내 프로필의 포인트 카드 바로 아래에 «가진 잼 {n}» 한 줄**을 둔다. 투데이에는 이미 캡슐 위젯이 있어 두지 않는다.
- 구현 계획: 기존 `jam-web/src/components/jam/JamBalance.tsx`를 재사용한다. 내 프로필의 포인트 카드 위치는 시작 때 아현이 확인한다(`jam-web/src/app/(main)/profile/ProfileClient.tsx` 근처). 잔액 데이터는 지갑/원장 읽기를 이미 하는 곳이 있으면 그것을 쓴다. 다른 유저의 프로필에는 보이지 않는다. 화면 작업이라 채원 사전 판정을 받는다.
- 관련 파일: `jam-web/src/components/jam/JamBalance.tsx`, `jam-web/src/app/(main)/profile/ProfileClient.tsx`, 문구 `jam-web/src/lib/i18n/ko.ts`, 잼 원장 읽기 `jam-web/src/lib/jam/`.

## 배경 / 문제 정의

잼 잔액을 늘 보이는 자리가 없어 유저가 지금 가진 잼을 캡슐 시트를 열어야 알 수 있다. 동기화 결과 화면의 «이번에 받은 잼»(`20261025_2050`)은 잔액이 아니라 받은 합계라 `JamBalance`와 섞이지 않게 한다.

## 완료 조건

- 내 프로필에서 포인트 카드 바로 아래에 «가진 잼 {n}»이 보이고 다른 유저의 프로필에는 보이지 않는다.
- 잔액이 0이어도 깨지지 않고, 320~430px에서 겹침과 가로 넘침이 없다.
- 기존 프로필 시험이 통과한다.
