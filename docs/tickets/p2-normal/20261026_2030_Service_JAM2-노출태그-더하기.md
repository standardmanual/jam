# [Service] JAM 2.0 노출 태그 더하기: 트라이브·챕터·캡슐·잼·인벤토리

> 상위: 20261026_2020

## 핵심 요약

- 요구사항: 홈피드 노출 태그에 소속 트라이브, 챕터 구간, 캡슐 게이지, 잼 보유량, 인벤토리 여유를 기준으로 한 태그를 더한다(자동화 PRD §5).
- 구현 계획: 태그 이름과 경계값을 정하고 `computeUserExposureTags`에 판정을 더한다. 어드민 태그 선택지와 홈피드 PRD 생성 표를 갱신한다.
- 관련 파일: `jam-web/src/lib/today/exposure.ts`(266~300줄 `computeUserExposureTags`), `TODAY_EXPOSURE_TAG_OPTIONS`, `scripts/gen-home-feed-doc.mjs`, 스펙 `docs/service/prd/home-feed/PRD.md` §4, `docs/service/prd/content-automation/PRD.md` §5

## 상세 요구사항

- 2026-10-26 오전 개정본 PRD에 적혔던 태그 이름(`tribe_gourmet` 등)은 실제 트라이브와 맞지 않았다. 트라이브 태그는 실제 트라이브 식별자에서 만든다.
- 경계값(잼 많음·적음, 인벤토리 남은 칸, 챕터 구간)은 정책 대시보드의 값과 겹치지 않게 한 곳에 상수로 둔다.
- 요청 때 추가 조회가 늘어나므로 홈 응답 시간 변화를 잰다.

## 완료 조건

- 각 새 태그가 조건을 만족하는 시험 유저에게만 붙는다(단위 테스트).
- `node scripts/gen-home-feed-doc.mjs` 뒤 홈피드 PRD §4 생성 표에 새 태그가 있다.
- 자동화 PRD §5의 「예정」 문장이 실제 태그 이름으로 바뀌어 있다.
