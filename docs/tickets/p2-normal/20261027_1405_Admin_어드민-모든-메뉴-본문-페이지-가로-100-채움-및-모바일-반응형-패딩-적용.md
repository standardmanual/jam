# [Admin] 어드민 모든 메뉴 본문 페이지 가로 100% 채움 및 모바일 반응형 패딩 적용

## 핵심 요약
- 요구사항: 메뉴마다 상이하던 어드민 본문 페이지 너비 제한을 모두 제거하고 브라우저를 100% 채우도록 통일하며, 모바일 반응형 패딩 및 브레이크포인트 적용
- 구현 계획: `SidebarInset`에 `min-w-0 w-full` 적용하여 flexbox overflow 방지, 어드민 전 메뉴 80개 화면의 root container 및 폼에서 임의의 `max-w-*` 제약 제거 및 `w-full` 통일, 고정 `p-8`을 모바일 `p-4`, 데스크톱 `md:p-8` 반응형 패딩으로 일괄 전환, 모바일 찌그러짐 방지 반응형 그리드 브레이크포인트 적용
- 관련 파일: `jam-web/src/components/admin/ui/sidebar.tsx`, `jam-web/src/app/admin/**/page.tsx`, `jam-web/src/components/admin/**`

## 배경 / 문제 정의
어드민 내 페이지별로 root container의 가로폭이 임의의 `max-w-6xl`, `max-w-7xl`, `max-w-5xl`, `max-w-4xl`, `max-w-3xl`, `max-w-xl` 등으로 각각 고정되어 있거나 100%로 다르게 처리되어 화면 일관성이 부족했다. 또한 모바일이나 좁은 브라우저 환경에서 고정 `p-8` 패딩(좌우 64px) 및 고정 2열 그리드로 인해 컨텐츠가 심하게 눌리는 현상이 발생하여, 전 메뉴를 100% 브라우저 채움 및 반응형 패딩/브레이크포인트로 표준화해야 했다.

## 상세 요구사항
1. `SidebarInset` 레이아웃 컨테이너에 `min-w-0 w-full`을 적용하여 넓은 테이블이나 차트 렌더링 시 가로 스크롤 및 레이아웃 깨짐 방지
2. 어드민 하위 모든 메뉴의 `page.tsx` 및 폼/상세 컴포넌트 루트에서 `max-w-*` 제약을 제거하고 `w-full`로 일괄 변경
3. 고정 `p-8`을 `p-4 md:p-8` 반응형 패딩(`w-full p-4 md:p-8 space-y-6`)으로 통일
4. 모바일 화면에서 찌그러지던 2열 그리드(시뮬레이터, 운영 홈 바로가기 등)에 반응형 브레이크포인트(`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`, `grid-cols-1 lg:grid-cols-2`) 적용

## 구현 계획
1. `jam-web/src/components/admin/ui/sidebar.tsx`: `SidebarInset` 기본 className에 `min-w-0 w-full` 반영
2. 어드민 80개 파일 전수 검사 및 `className="w-full p-4 md:p-8 space-y-6"` (또는 `w-full p-4 md:p-8`) 전환
3. `BadgeForm`, `TodayCardForm`, `ItemBookForm`, `PoiForm`, `TribeForm`, `RankingModeForm` 등 폼 컨테이너 `w-full` 전환
4. `jam-web/src/app/admin/simulator/page.tsx`: `grid-cols-1 lg:grid-cols-2` 반응형 그리드 적용
5. TypeScript, ESLint, 단위/통합 테스트, Next.js 프로덕션 빌드 전수 검증

## 완료 조건

- [x] 모바일 해상도에서 패딩이 16px(`p-4`)로 줄어들고 찌그러짐 없는 반응형 뷰 제공
