# [Admin] 어드민 펼쳐진 사이드바 가로 너비 PC 기준 170px로 조정

## 핵심 요약
- 요구사항: 데스크톱(PC) 환경에서 펼쳐진 어드민 좌측 사이드바 너비를 기존 `16rem`(256px)에서 `170px`로 축소 조정하여, 본문 작업 영역을 더 넓게 확보하면서도 네비게이션 메뉴 아이템이 단정하게 표시되도록 개선
- 구현 계획: `jam-web/src/components/admin/ui/sidebar.tsx`의 `SIDEBAR_WIDTH` 상수를 `170px`로 변경하고, `AdminSidebar.tsx` 내 메뉴 항목(라벨 텍스트, 아이콘, 아코디언 트리거 등)의 렌더링 및 말줄임/여백 상태를 검증
- 관련 파일: `jam-web/src/components/admin/ui/sidebar.tsx`, `jam-web/src/components/admin/AdminSidebar.tsx`

## 배경 / 문제 정의
현재 어드민 사이드바 기본 너비는 shadcn 기본값인 `16rem`(256px)으로 설정되어 있다. 최근 어드민 본문 가로 100% 채움 및 사이드바 오프캔버스 전환이 반영되었으나, 사이드바를 펼친 상태에서도 좌측 네비게이션 영역이 256px를 차지하여 본문 작업 영역이 다소 좁아지는 느낌이 있었다. 데스크톱 환경에서 가로 폭을 약 170px로 슬림화하면 본문 공간을 추가로 약 86px 확보할 수 있으며, 메뉴 라벨들도 말줄임 없이 충분히 안정적으로 노출될 수 있다.

## 상세 요구사항
1. 데스크톱(PC, md 이상) 환경에서 펼쳐진 어드민 사이드바 너비(`--sidebar-width`)를 `170px`로 설정
2. 오프캔버스 접기 시 좌측 이동 오프셋(`left-[calc(var(--sidebar-width)*-1)]`)도 `-170px`로 정상 연동되어 화면 밖으로 깔끔하게 숨겨짐
3. 모바일 환경(768px 미만)에서는 기존 `SIDEBAR_WIDTH_MOBILE`(`18rem`, 288px) 드로어 너비를 유지하여 터치 친화적 경험 보존
4. 사이드바 내부 텍스트(예: '트렌드 레이더', '생태계 상황판', '에셋 제너레이터' 등 긴 한글 라벨)가 170px 안에서 잘림 없이 자연스럽게 표시되는지 확인 및 여백 최적화
5. 기존 단축키(`Cmd+B`), 헤더 토글 버튼(`SidebarTrigger`), 최좌측 레일(`SidebarRail`) 동작과의 정합성 유지

## 구현 계획
1. `jam-web/src/components/admin/ui/sidebar.tsx`:
   - `const SIDEBAR_WIDTH = "170px"`로 수정
2. `jam-web/src/components/admin/AdminSidebar.tsx`:
   - 170px 너비에 맞추어 패딩 및 여백이 적절한지 점검 (AccordionItem 패딩 등 확인)
3. 시각적 검증:
   - Playwright 스크린샷으로 170px 너비에서의 어드민 사이드바 메뉴 렌더링 확인
4. 테스트 및 빌드 검증:
   - `npm run typecheck`, `npm run lint:ci`, `vitest` 관리자 테스트 및 Next.js 빌드 검증
