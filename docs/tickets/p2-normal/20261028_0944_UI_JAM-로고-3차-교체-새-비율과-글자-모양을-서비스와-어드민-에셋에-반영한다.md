# [UI] JAM 로고 3차 교체: J 홈·A 모양·가로세로비가 바뀐 새 로고를 서비스 이미지·마스크 CSS·공유 이미지·어드민 에셋 글자 경로에 반영한다

## 핵심 요약

- 요구사항: 사용자가 2026-10-28 09:37~09:38에 `jam-web/design-system/assets/logo/`의 파일 3개(`jam-logo.svg`·`jam-logo-black.png`·`jam-logo-white.png`)를 최신 로고로 바꿨다.
  직전 로고(10-27, 커밋 `7a401ee1b`)와 **J의 홈 크기, A의 모양, 전체 가로세로비**가 다르다. 서비스에서 쓰는 로고(이미지·마스크 CSS·배지 공유 이미지·파비콘·앱 아이콘)와
  어드민 > 디자인 > 에셋(Shape Studio)의 글자 경로를 모두 새 로고로 맞춘다.
- 구현 계획: ① 브랜드 원본(`docs/assets/brand/`)을 새 로고로 바꾼다 ② `gen-brand-assets.mjs`의 캔버스 높이를 925에서 865로 고쳐 이미지 7개를 다시 만든다
  ③ `.jam-logo-mark`의 `aspect-ratio`와 배지 공유 이미지의 로고 폭을 새 비율로 맞춘다 ④ 코드에 복사돼 있는 글자 경로 5곳(부록 데이터)을 교체한다.
  고칠 내용과 값이 모두 이 티켓에 확정돼 있어 `/jam-work` 경로 ②(가벼운 UI)로 처리한다.
- 관련 파일:
  - 입력(사용자가 바꾼 파일, 이 티켓과 같은 커밋에 올림): `jam-web/design-system/assets/logo/jam-logo.svg`(흰색, 2610×865), `jam-logo-black.png`, `jam-logo-white.png`(둘 다 2610×865)

## 배경 / 문제 정의

카리나가 새 로고 파일과 현재 코드를 직접 대조해 확인한 사실(2026-10-28)이다.

| 항목 | 직전 로고(10-27) | 새 로고 |
|---|---|---|
| 캔버스 | 로고 PNG 2610×925, 로고 폭 2609px가 가운데 | **2610×865**, 로고가 캔버스를 가득 채움 |
| 가로세로비 | 2.82:1 | **3.017:1** |
| J | 홈(안쪽 흰 칸) 높이가 865 기준 약 242 | 홈이 길어져 약 312(위 막대 y=231.9, 아래 막대 y=543.6) |
| A | 구멍이 삼각형 | 구멍이 물방울 모양이고 글자가 더 넓다(205 기준 폭 177 → 195.4) |
| M | 폭 255.4(205 기준) | 같은 모양(255.6) |

- 사용자가 넣은 PNG 2개는 새 SVG와 일치한다(글자 경로를 합쳐 2610px로 렌더해 사용자의 검정 PNG와 비교한 알파 마스크 차이 0.04%).
- 코드의 비율 의존 지점:
  - `globals.css`의 `.jam-logo-mark { aspect-ratio: 2610 / 925 }`가 상단 바(높이 26px)·로그인(48px)·문의(16px)의 로고 폭을 정한다. 값을 안 고치면 로고 마스크가 새 PNG를 옛 비율 칸에 맞춰 위아래로 남는다.
  - `buildBadgeShareBlob.ts`는 로고를 고정 칸 174.2336×72(2.42:1, **옛 옛 로고의 Figma 값**)에 그린다. 새 로고(3.017:1)를 이 칸에 그리면 가로로 약 20% 눌린다. 직전 로고(2.82:1)도 이미 약 14% 눌려 있었다.
  - `login/page.tsx`·`voc/page.tsx`·`TopNav.tsx`는 이미 `.jam-logo-mark`를 쓰고 이미지 크기를 직접 적지 않는다. 고칠 것이 없다.
- 아이콘 3개(`icon.png`·`apple-icon.png`·`favicon.ico`)는 `j.svg`의 J를 쓴다. J의 홈이 길어졌으므로 같은 스크립트로 다시 만든다.
- 어드민 > 디자인 > 에셋 화면(`/admin/assets`, Shape Studio)은 글자 경로를 코드 안에 복사해 둔다. 직전 라운드는 이 중 `ShapeStudioViewport.tsx`의 A만 바꿨고
  `shapeStudioConfig.ts`·에셋 제너레이터·CLI·`imageRender.client.ts`는 옛 글자 그대로다. 이번에 5곳을 모두 맞춘다.

## 상세 요구사항

### 서비스/코드베이스 관점

1. **브랜드 원본 교체** (`docs/assets/brand/`)
   - `jam_logo.svg`: 사용자의 `design-system/assets/logo/jam-logo.svg` 전체를 가져오되 `fill="white"`만 `fill="black"`으로 바꾼다(2610×865 viewBox 그대로, 경로 수정 금지).
   - `j.svg`·`a.svg`·`m.svg`: 부록 A의 경로로 바꾼다. 색은 기존처럼 `fill="white"`(A는 `fill-rule="evenodd" clip-rule="evenodd"` 유지). 크기는 J 575×865, A 826×865, M 1081×865
     (`width`·`height`·`viewBox` 모두 같은 값).
2. **이미지 7개 재생성**
   - `gen-brand-assets.mjs`: `LOGO_H`를 865로 고치고 파일 머리 주석·`TopNav` 언급 주석을 새 규격(2610×865)에 맞게 고친다. `renderLogo`는 이제 원본 비율이 캔버스와 같으므로
     `resize({ width: LOGO_W, height: LOGO_H })`로 캔버스를 정확히 채운다(옛 코드의 가운데 맞춤으로 오른쪽 1px이 비던 문제도 함께 사라진다).
   - `J_HEIGHT_RATIO`(0.685)는 그대로 둔다. 새 J의 크기감은 머지 뒤 카리나가 눈으로 확인한다(후속 범위).
   - `node jam-web/scripts/gen-brand-assets.mjs`로 7개 파일을 만든다.
   - `gen-brand-assets.test.mjs`의 로고 규격 검사를 2610×865로 고친다.
3. **마스크 CSS**: `globals.css`의 `aspect-ratio`를 `2610 / 865`로, 두 주석(`가로세로비 2610:925`와 파일 설명)을 새 값으로 고친다.
4. **배지 공유 이미지**: `LOGO_HEIGHT = 72`는 그대로 두고 `LOGO_WIDTH`를 `217.2486`(= 72×2610/865)로 바꾼다. `LOGO_WIDTH` 위의 주석에 옛 값(174.2336)이 옛 로고의
   Figma 칸 크기였고 새 로고 비율에 맞춰 폭만 고쳤다는 사실을 한 줄로 남긴다. 가운데 맞춤(`logoX`)은 폭 상수를 그대로 따르므로 바꾸지 않는다.
5. **글자 경로 5곳 교체**: 부록 B(로컬 좌표)와 부록 C(합친 좌표)의 문자열을 **복사해서** 넣는다. 손으로 다시 적거나 옮겨 그리지 않는다.
   - `shapeStudioConfig.ts`: `J_D`·`A_D`·`M_D`를 부록 C로, `BUILTIN_GLYPHS`의 `box`를 부록 C의 값으로 바꾼다(`JAM`의 box는 `[0, 0, 617.432, 204.628]`).
   - `ShapeStudioViewport.tsx`·`AssetGeneratorViewport.tsx`·`brandLetters.mjs`의 `BRAND_LETTERS`: `w`·`h`·`d`를 부록 B로 바꾼다.
   - `imageRender.client.ts`의 `BRAND_J`: `w`·`h`·`d`를 부록 B의 J로 바꾼다.
   - 새 A는 구멍을 `evenodd`로 파야 보인다. `AssetGeneratorViewport.tsx`와 `brandLetters.mjs`의 `brandLetterSvgMarkup`은 `fill-rule="evenodd"`가 없으므로 `<path ... fill="#000" fill-rule="evenodd"/>`로 고친다
     (`ShapeStudioViewport.tsx`는 이미 있다. `imageRender.client.ts`는 J만 쓰므로 그대로 둔다).

### UI/UX 관점

- 상단 바·로그인·문의 화면의 로고가 새 모양과 새 비율로 보이고 위아래 빈 칸이 없다.
- 탭 아이콘·iOS 홈 화면 아이콘 안 J가 새 J(홈이 긴 모양)다.
- 배지 공유 이미지의 로고가 눌리지 않고 새 비율 그대로 그려진다.
- 어드민 > 디자인 > 에셋의 J·A·M·JAM 글자 프리셋이 새 글자 모양이다.

### 범위 밖 (같이 처리하지 않는다)

- 이미 게시된 배지 이미지에 합성돼 있는 옛 로고(`recraft/compose-logo*`로 만든 이미지)는 그대로 둔다. 다시 합성할지는 별도 결정이다(티켓 20260925_1125와 같은 판단).
- `docs/assets/prototypes/*.html`(에셋 제너레이터·Shape Studio 원형 시안)에 박힌 옛 글자 경로는 시점 기록이라 고치지 않는다.
- claude.ai/design 업로드본 갱신은 머지 뒤 `/jam-ds`로 한다(후속 범위).
- 글자 경로 복사본을 SVG 원본과 자동 대조하는 검사는 이번에 넣지 않는다(후속 티켓 후보).
