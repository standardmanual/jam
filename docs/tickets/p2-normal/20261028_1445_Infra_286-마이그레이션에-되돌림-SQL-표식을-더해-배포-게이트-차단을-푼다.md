# [Infra] 286 마이그레이션에 되돌림 SQL 표식을 더해 배포 게이트 차단을 푼다

> 범위 밖 발견물(2026-10-28, 티켓 20261028_1425 파이프라인의 민지 `sideFindings`). 카리나가 `node scripts/deploy-gate.mjs check`를 직접 돌려 같은 결과를 확인했다. 민지 판정의 기본 우선순위는 P1이지만, main 배포가 JAM 2.0 출시 전까지 멈춰 있어 P2로 조정했다.

## 핵심 요약

- 요구사항: `jam-web/supabase/migrations/286_today_cards_add_dome_ticket_shapes.sql`에 `-- 되돌림 SQL` 블록을 더해 배포 게이트의 차단을 푼다.
- 구현 계획: 파일 끝에 되돌림 블록 주석을 더한다. 이미 DB에 적용된 마이그레이션이므로 **파일 내용만 보태고 실행하지 않는다**(`db-migration-rules.md` 4절의 짝 파일 방식도 쓸 수 있다).
- 관련 파일: 위 286 파일(끝 6줄이 `COMMIT;`), `scripts/deploy-gate.mjs`(`ROLLBACK_MARKER` 정규식), `docs/agents/contract.json`의 `deploy_gate.rollback_sql_required_from`.

## 배경 / 문제 정의

- `node scripts/deploy-gate.mjs check`(2026-10-28 실행)가 `origin/main → origin/staging` 범위에서 「차단(되돌림 SQL 없는 마이그레이션 1건)」을 낸다. 신규 마이그레이션 77건 중 286만 해당한다. 비밀값·API 라우트·인증 래퍼 점검은 통과한다.
- 286은 `today_cards`의 `layout_type`·`shape` CHECK 제약에 `dome`과 `ticket`을 더하는 확장이다(티켓 20261022_2225).
- 이 상태로는 `/jam-ship`이 main에 승격하지 못한다.

## 상세 요구사항

### 서비스/코드베이스 관점

- 되돌림 SQL은 제약을 이전 값 집합으로 되돌리는 문장이어야 한다. 이전 값 집합은 286 앞의 마이그레이션에서 확인한다(`dome`·`ticket`이 없던 시절의 `layout_type`·`shape` 정의). `dome`·`ticket` 값을 가진 행이 있으면 되돌릴 수 없다는 경고를 함께 적는다.
- 마이그레이션을 다시 실행하지 않는다(이미 적용됨). 파일의 주석만 늘린다.

## 구현 계획

1. 286 파일 끝(`COMMIT;` 뒤)에 `-- 되돌림 SQL` 블록 주석을 더한다.
2. `node scripts/deploy-gate.mjs check`가 이 차단을 더 이상 내지 않는지 확인한다.

## 완료 조건

- 286 파일에 `-- 되돌림 SQL`로 시작하는 줄이 있고, 되돌림 문장이 이전 제약 정의와 일치한다.
- `node scripts/deploy-gate.mjs check`의 마이그레이션 점검이 통과한다.
