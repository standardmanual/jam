# [Admin] 트렌드 레이더 등록 출처 수정 및 삭제 기능 추가

## 핵심 요약
- 요구사항: 어드민 > 라이브 > 트렌드 레이더(`/admin/ops-trends`) 화면에서 이미 등록한 출처의 이름 및 위치를 수정하고, 불필요한 출처를 삭제할 수 있는 기능 제공
- 구현 계획:
  1. 백엔드 API: `DELETE /api/admin/ops-trend-sources/[id]` 엔드포인트 및 `deleteTrendSource` 함수 구현 (`sourceStore.ts`, `[id]/route.ts`)
  2. 클라이언트 요청 유틸: `sourceClient.ts`에 `updateTrendSourceRequest` 및 `deleteTrendSourceRequest` 추가
  3. 프론트엔드 UI: `OpsTrendSources.tsx` 테이블에 '관리' 열을 추가하여 '수정' 및 '삭제' 액션 버튼 제공
     - 수정: 선택한 행의 이름/위치를 변경할 수 있는 `SourceEditForm` 제공 (종류는 읽기 전용으로 표시)
     - 삭제: `AlertDialog`를 통해 삭제 재확인 팝업 노출 후 삭제 처리 및 목록 갱신
  4. 문서 갱신: `docs/service/prd/admin-boards/PRD.md`에 출처 수정 및 삭제 기능 반영
- 관련 파일:
  - `jam-web/src/app/api/admin/ops-trend-sources/[id]/route.ts`
  - `jam-web/src/lib/admin/opsTrends/sourceStore.ts`
  - `jam-web/src/components/admin/ops/trends/sourceClient.ts`
  - `jam-web/src/components/admin/ops/trends/OpsTrendSources.tsx`
  - `docs/service/prd/admin-boards/PRD.md`

## 배경 / 문제 정의
현재 어드민의 트렌드 레이더 화면에서는 출처 추가(POST)와 켜기/끄기(PATCH enabled)만 지원되었고, 오타 수정이나 변경된 위치/주소 업데이트, 불필요한 출처의 삭제 경로가 UI에 제공되지 않았다. 특히 이전 결정에서 "삭제 경로 없이 enabled=false로 대신한다"로 설계되었으나, 운영자가 잘못 등록한 출처나 더 이상 관리하지 않는 출처를 정리하고자 할 때 테이블에 계속 남아 시각적 혼란을 주는 문제가 있어 실제 수정 및 삭제 기능이 필요하다.

## 상세 요구사항
1. **출처 수정**:
   - 테이블 각 행에 '수정' 버튼 배치
   - 클릭 시 해당 출처의 정보를 편집할 수 있는 양식(`SourceEditForm`) 노출
   - 이름(1~60자) 및 위치(최대 300자, 저장소 폴더는 허용 목록에서 선택, 직접 올린 자료는 선택적) 수정 지원
   - 종류(`kind`)는 수정 불가(안내 라벨로 표시)
   - 수정 요청 시 `PATCH /api/admin/ops-trend-sources/[id]` 호출 및 오류(중복 이름 409, 유효성 실패 400 등) 인라인 표시
   - 수정 완료 후 화면 갱신(`router.refresh()`)
2. **출처 삭제**:
   - 테이블 각 행에 '삭제' 버튼 배치
   - 클릭 시 실수 방지를 위한 확인 대화상자(`AlertDialog`) 노출 (출처 이름 명시)
   - 확인 시 `DELETE /api/admin/ops-trend-sources/[id]` 호출
   - 관리자 세션 체크, 미존재 시 404, 정상 삭제 시 200 반환 및 목록 갱신
3. **영향도 및 안전성**:
   - `OpsTrendRadar.tsx`는 이미 출처 번호가 삭제되었더라도 `출처 N`으로 대체 표기하도록 구현되어 있어 이전 주간 묶음의 출처 번호 참조가 깨지지 않음
   - 삭제 시 고유 색인(`uq_ops_trend_sources_name`)이 해제되어 향후 동일 이름으로 재등록 가능
4. **테스트 및 검증**:
   - `DELETE` API 라우트 테스트 추가 (`route.test.ts`)
   - `deleteTrendSource` 저장소 테스트 추가 (`sourceStore.test.ts`)
   - `sourceClient` 수정/삭제 요청 함수 및 `OpsTrendSources` UI 렌더링/액션 테스트 추가 (`OpsTrendSources.test.tsx`)
