# [UI] 상단 내비의 문의 버튼을 없애고 푸터 확률 안내 다음 줄에 문의 링크를 둔다

## 핵심 요약

- 요구사항(사용자 지시): 상단 내비(TopNav)의 «문의» 버튼을 제거하고, 푸터에서 «확률 안내» 링크 바로 다음 줄에 «문의» 링크를 둔다. 링크는 지금 버튼이 가는 `/voc`로 연결한다.
- 구현 계획: `TopNav.tsx`의 `logoNode`에서 `Button`(`router.push('/voc')`)을 뺀다. `Footer.tsx`의 링크 묶음 맨 끝(확률 안내 뒤)에 같은 스타일의 `Link`를 하나 더하고, 문구는 `jam-web/src/lib/i18n/ko.ts`의 `common`에 `footerInquiry: '문의'`로 둔다. 상단 버튼 전용이던 `voc.inquiryButton` 키는 다른 곳에서 쓰지 않으면 지운다.
- 관련 파일(지도): `jam-web/src/components/ui/TopNav.tsx` 126~139행(`logoNode`, `Button`·`router`가 다른 곳에서 쓰이는지 확인하고 안 쓰이면 import도 정리), `jam-web/src/components/ui/Footer.tsx` 70~76행 부근(`/probability` 링크 뒤), `jam-web/src/lib/i18n/ko.ts` 38~40행(`common.footer*`)·2133행(`voc.inquiryButton`), 시험 `jam-web/src/components/ui/__tests__/TopNav.test.tsx`·`jam-web/src/components/ui/__tests__/Footer.test.tsx`.

## 배경 / 문제 정의

- 베타 테스트 VOC 임시 채널(티켓 20260828_1548)로 로고 옆에 «문의» 버튼을 두었다. 이 입구를 푸터의 텍스트 링크로 옮긴다.
- `/voc` 화면은 `(main)` 레이아웃 안이라 푸터가 보인다. 푸터의 «문의» 링크가 자기 화면을 가리키게 되지만 `/philosophy`처럼 푸터를 빼지는 않는다(지시에 없다).

## 상세 요구사항

### UI/UX 관점
- 푸터 «문의» 링크는 앞의 링크들과 같은 클래스(15px, 밑줄, `active:opacity-60`)를 쓰고 같은 `flex-col gap-0` 묶음 안, 확률 안내 바로 다음 줄에 둔다.
- 상단 내비의 로고 옆에는 버튼이 남지 않고 로고만 남는다.
- 새 문구는 만들지 않는다. «문의»는 기존 버튼 문구와 같다.

## 완료 조건

- 로고가 보이는 화면의 상단 내비에 «문의» 버튼이 없다.
- 푸터에서 «확률 안내» 다음 줄에 «문의» 링크가 있고 누르면 `/voc`로 이동한다.
- `TopNav`·`Footer` 시험이 이 변경을 고정하고, 쓰이지 않게 된 `voc.inquiryButton` 키가 남지 않는다.
- 어드민이 아닌 서비스 화면이라 로컬 실렌더로 상단과 푸터를 확인했다.

## 진행 조건

- 사용자 지시(2026-10-31). 가벼운 UI 경로(채원 판정 생략): 기존 링크 스타일과 기존 문구를 그대로 쓴다.
