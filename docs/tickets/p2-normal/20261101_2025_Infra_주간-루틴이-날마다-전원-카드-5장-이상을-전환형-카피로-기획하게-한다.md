# [Infra] 주간 루틴이 날마다 전원 카드 5장 이상을 전환형 카피로 기획하게 한다

## 핵심 요약

- 요구사항: 2026-11-03 정기 주간 루틴부터 날마다 모든 유저가 보는 카드 5장 이상을 서로 다른 컨텐츠로 기획하고, 제목은 간결하게, 설명은 상세하게 쓴다. 기획은 윤진이 판단한다.
- 구현 계획: 윤진·혜린 정의와 주간 스펙, 07 블루프린트, content-automation PRD를 고친다. 원격 루틴 프롬프트는 실행 때 이 파일들을 읽으므로 바꾸지 않는다.
- 관련 파일: `.claude/agents/jam-marketer.md`, `.claude/agents/jam-pm.md`, `.claude/skills/jam-work/references/scheduled-jobs.md`, `.claude/skills/jam-story/references/marketer-home-feed.md`, `docs/plan/vision/07 JAM! 라이브 운영 블루프린트.md`, `docs/service/prd/content-automation/PRD.md`, `docs/service/prd/ops-tool/PRD.md`

## 배경 / 문제 정의

사용자는 홈피드 카드를 에이전트가 트렌드와 지표로 직접 기획하고, 날마다 모두에게 노출되는 최소 5개 카드를 원한다(2026-10-31). 시험 묶음 `weekly-sim-2026-W45-c`에서 이 기준을 확인했고, 사용자가 2026-11-01에 정기 루틴 적용을 승인했다. 윤진 정의의 「조합 뽑기를 먼저 쓰고 창의력에 맡기지 않는다」와 블루프린트의 같은 문장이 이 방향과 부딪혔다.

## 완료 조건

### 구현 범위
- 윤진 정의 모드 ⑨에 전원 카드 5장 이상, 전환형 카피, 실재하는 재료만 사용, 서비스 사실 대조, 항목 상한 확인이 있고 「창의력에 맡기지 않는다」가 없다.
- 혜린 정의에 카드 문구와 서비스 운영 로직 대조가 있다.
- 주간 스펙 「새 체계 주간」 절에 기준이 있어 원격 프롬프트가 읽는다.

### 후속 범위 (담당: 사용자 허용 뒤 카리나, 완료 2026-11-01)
- [x] 운영 설정에 `minLiveCards` 5, `maxLiveCards` 12, `maxNewUserCards` 8을 저장하고, 그 뒤 07 4.2와 ops-tool PRD의 신호 설명 수치를 맞춘다.

### 후속 범위 (담당: 카리나, 시점: 2026-11-03 실행 뒤)
- 정기 묶음에서 날마다 전원 카드 5장 이상, 기사 없음, 가상 재료 없음을 확인한다.

## 완료 기록

### 구현 내용 요약

구현 범위의 문서와 정의를 고쳤다. 코드는 바꾸지 않았다.

### 테스트 결과
- [x] 코드 변경 없음. 원격 루틴 프롬프트가 `### 새 체계 주간` 절과 에이전트 정의 파일을 실행 때 읽는 것을 `RemoteTrigger get`으로 확인했다.
- [ ] 규칙 효과는 아직 실행으로 확인하지 못했다(2026-11-03 첫 실행).

### 주요 의사결정 / 핵심 메모
- 신호 기준값을 코드 기본값으로 바꾸면 기본값을 전제한 시험 49건이 깨져서, 설계대로 운영 설정에 바꾼 값만 저장하기로 했다(`saveThresholds.ts`, 사용자 결정 2026-10-01).
- 12장과 8장은 전원 5~6장에 개인화·이틀 걸침을 더한 시험 묶음을 근거로 카리나가 잡은 초기값이다.
- 운영 설정 저장은 처음에 자동 모드 권한 판정에 막혔고, 사용자가 2026-11-01에 명시적으로 허용한 뒤 실행했다. `PATCH /api/admin/ops-rules/signals/empty_content`와 `/overlap`이 모두 200이었고, DB의 `ops_rules` 신호 행 3개(값 5·12·8, 직전 값 3·5·3)와 운영 설정 화면의 결과 문장을 확인했다. 저장 주체는 로컬 테스트 관리자 세션(`dev-tester@jam.local`)이다. 되돌리려면 운영 설정에서 칸을 기본값으로 되돌리거나 같은 값으로 저장한다.
- 묶음 항목 상한 60은 올리지 않고 윤진이 제출 전에 세게 했다. 시험 묶음은 59개였다.
- jam-* 서브에이전트를 쓸 수 없어 게이트 리뷰 없이 카리나가 직접 고쳤다.

### 잔여 이슈
- 신호의 게재 카드 수는 전원 카드만이 아니라 그날 걸치는 카드 전부를 센다. 전원 5장 미만을 따로 알리는 신호는 없다.
