# [Admin] 시험 등록 묶음을 45주차로 옮기고 W45-c를 지운다

## 핵심 요약

- 요구사항: 52주차가 아니라 이번 주 45주차로 등록하고, 기존 45주차 내용은 지운다(사용자 지시 2026-11-02).
- 구현 계획: 백업 표를 만든 뒤 2027-W52 묶음 4개의 주차와 항목·카드 기간을 W45-c의 같은 제목 항목 기간으로 옮기고, `weekly-sim-2026-W45-c`를 지운다.
- 관련 파일: `jam-web/supabase/seed_20261102_ops_move_w52_to_w45.sql`

## 완료 조건

- 운영플랜에 45주차 묶음 4개만 있고, 2027년 게재 카드가 0장이며, 일정표의 11월 2일~8일에 카드 19장이 보인다.

## 완료 기록

### 구현 내용 요약

드라이런(DO 블록 RAISE 롤백)에서 항목 24·카드 19·묶음 4를 확인한 뒤 백업하고 실행했다. W45-c 묶음과 항목 59건, 결정 기록 1건이 지워졌다. 시험 카드는 실제 노출 대상(`exposure_tags: all`, `is_active: true`)이라 기간이 되면 staging과 프로덕션 유저 홈에 함께 보인다.

### 테스트 결과
- [x] DB 읽기 확인: 묶음 4개 모두 `2026-W45`, 결정 기록 52건, 2027년 게재 카드 0장.
- [x] 로컬 어드민 운영플랜: 전체 4, 모두 «45주차 (11/2~11/8)».
- [x] 로컬 어드민 일정표: 11월 2일~8일에 카드가 보인다.
- [x] staging 유저 홈: 오늘 카드 «한 번이면 끝나는 미션»이 보인다.
- [ ] 프로덕션 유저 홈: 로그인이 필요해 직접 보지 못했다.

### 주요 의사결정

- 실패 항목 5건은 지우지 않고 실패 기록으로 남겼다(지우라는 지시 범위 밖).
- 같은 제목 카드는 지우지 않고 모두 옮겼다. 시험을 여러 번 해서 같은 날 같은 제목이 겹친다(«쉬어 가는 일요일» 3장, «정류장 의자의 방석» 3장, «합주실 앞 계단»·«메모 속 동네 한 바퀴»·«비 오는 날엔 집에서» 각 2장).

### 잔여 이슈

- 시험 카드 문구는 W45-c 시뮬레이션에서 왔다. 오늘 카드는 «10포인트»를 말하지만 연결된 미션이 없다.
- `today_cards` 기간이 끝나면 시험 카드는 자동으로 내려간다. 되돌림 SQL은 SQL 파일 끝에 있다.
- 실행 때 실패 항목의 `updated_at`까지 바꿔 일정표 오늘 칸에 «실행 실패» 신호 5건이 떴고, 원래 시각으로 되돌렸다.
