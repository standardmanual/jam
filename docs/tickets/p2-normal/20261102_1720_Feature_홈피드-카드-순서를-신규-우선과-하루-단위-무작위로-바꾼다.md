# [Feature] 홈피드 카드 순서를 신규 우선과 하루 단위 무작위로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-02): 같은 카드가 매일 맨 위에 있어서 새롭지 않다. **새로 생긴 카드를 맨 위로 올리거나 순서를 무작위로** 바꾼다.
- 결정(카리나, 두 요구를 함께 만족): 카드를 두 묶음으로 나눈다. ① **새 카드** = 노출이 시작된 지 24시간이 안 된 카드(`now - starts_at < 24h`), `starts_at` 내림차순. ② **나머지** = 유저와 날짜(KST)를 씨앗으로 한 **하루 단위 결정적 섞기**. 같은 유저는 하루 안에서 새로고침해도 순서가 같고, 다음 날과 다른 유저에게는 순서가 바뀐다. `sort_order`는 순서에 쓰지 않는다(맨 위 고정 효과를 없애는 것이 목적). 같은 점수일 때만 `sort_order` 오름차순, 그다음 `id`로 안정 정렬한다.
- 구현 계획(파일 단위):
  1. `jam-web/src/lib/today/cardSelection.ts`의 `sortHomeCards`를 `sortHomeCards(cards, { seed, now })`로 바꾼다. `SortableHomeCard`에 `id`를 더한다. 섞기는 `seed + card.id`를 문자열 해시(예: FNV-1a 32bit)해 정렬 키로 쓴다. 서버 전용 모듈을 가져오지 않는다(순수 함수 유지). 새 카드 판정 시간(24시간)은 상수로 둔다.
  2. `jam-web/src/lib/today/cards.ts`의 `getTodayCards`(약 150~160행): SQL `.order('sort_order')`·`.order('starts_at')`는 두고(안정 입력), 거름이 끝난 `cards`를 돌려주기 전에 `sortHomeCards(cards, { seed: `${userId}:${kstDate(now)}`, now })`를 호출한다. 이 파일 머리 주석의 ORDER BY 서술도 고친다.
  3. 어드민 미리보기 `jam-web/src/lib/admin/homePreview/load.ts`(약 282행)의 `sortHomeCards(...)` 호출이 같은 규칙을 쓰게 한다. 씨앗은 미리보기 뷰어의 가상 유저 ID(없으면 고정 문자열 `preview`)와 그날의 KST 날짜(`date`)이고, `now`는 `baseTime`이다. 미리보기 화면에 «순서는 유저·날짜마다 달라요» 한 줄을 더해도 된다(어드민 문구 해요체).
  4. 승인 전 대기 항목(`pendingToday`, 같은 파일 약 290행)의 `sortOrder` 정렬은 그대로 두고, 미리보기 목록에서 등록된 카드 뒤에 붙는 기존 방식을 유지한다.
  5. `docs/service/prd/home-feed/PRD.md` 169행 «정렬은 `sort_order` 오름차순, 같으면 `starts_at` 내림차순이다»와 177행의 정렬 설명, 어드민 노출 순서 서술을 새 규칙으로 고친다. `jam-web/src/lib/admin/policyDashboard/policiesData.ts`에 홈피드 정렬 정책 항목이 있으면 함께 고친다(없으면 해당 없음으로 기록).
  6. 시험: `lib/today/__tests__/`의 기존 정렬 시험을 고치고 더한다. 새 카드(24시간 이내)가 sort_order와 무관하게 앞에 온다 · 같은 씨앗은 같은 순서 · 다른 날짜/유저 씨앗은 (충분히 많은 카드에서) 순서가 달라진다 · 입력 배열을 바꾸지 않는다 · 같은 카드 집합이면 입력 순서와 무관하게 결과가 같다.
- 관련 파일: `jam-web/src/lib/today/cardSelection.ts`(46행 `sortHomeCards`), `lib/today/cards.ts`(`getTodayCards`), `lib/admin/homePreview/load.ts`(282행), 관련 시험 `lib/today/__tests__/`, `docs/service/prd/home-feed/PRD.md`(169·177행)

## 완료 조건

- 같은 유저가 같은 날 홈을 여러 번 열어도 카드 순서가 같고, 날짜가 바뀌거나 다른 유저가 보면 새 카드 묶음을 뺀 나머지 순서가 달라진다(시험으로 확인).
- 노출이 시작된 지 24시간 안인 카드는 `sort_order`와 상관없이 맨 앞에 온다. 24시간이 지나면 섞이는 묶음으로 들어간다.
- `sort_order`가 낮다는 이유로 같은 카드가 매일 맨 위에 오는 일이 없다.
- 어드민 미리보기가 홈과 같은 함수로 순서를 정하고, 변경한 PRD에 같은 규칙이 적혀 있다.
- `scripts/verify.sh`가 통과하고, 로컬 `ADMIN_EMAILS` 어드민에서 홈피드 미리보기를 열어 순서가 날짜마다 달라지는 것을 확인한다.
