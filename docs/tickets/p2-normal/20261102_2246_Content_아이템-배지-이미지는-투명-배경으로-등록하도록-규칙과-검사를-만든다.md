# [Content] 아이템 배지 이미지는 투명 배경으로 등록하도록 규칙과 검사를 만든다

## 핵심 요약

- 요구사항: 아이템 배지 정식 이미지를 등록할 때 배경이 투명한 PNG만 받도록 규칙을 적고, 등록 경로에서 알파 채널을 검사하게 한다.
- 구현 계획: ① 이미지 제작·등록 규칙 문서에 «투명 배경 필수»와 이유를 적는다. ② 어드민 이미지 등록 또는 `/jam-img` 파이프라인에서 알파가 전부 불투명이면 경고하는 검사를 둘지 정한다.
- 관련 파일: `docs/service/content/` 중 아이템 배지 이미지 규칙 문서(없으면 새로 두지 않고 기존 컨텐츠 문서에 한 절), `.claude/skills/jam-img/`(배경 제거 단계).

## 배경 / 문제 정의

- 티켓 20261102_1834로 아직 얻지 못한 아이템 배지가 «이미지의 가장 바깥 윤곽을 딴 회색 실루엣»으로 나온다. 실루엣은 CSS 필터(`brightness(0)`)로 만들기 때문에 알파 채널이 있어야 윤곽이 생긴다.
- 2026-11-02 실측: 등록된 아이템 배지 이미지 171개 중 배경이 투명한 것은 `factions/03-xx` 계열 72개뿐이고, `factions/02-xx`·`tribes/01-xx` 계열은 알파가 0%(불투명)다. 이런 이미지는 실루엣이 회색 정사각형으로 나온다.
- 활성 컬렉션 15개(배지 540개)는 이미지가 아직 없으므로, 정식 이미지를 넣기 전에 규칙을 정해 두면 같은 문제가 반복되지 않는다.

## 상세 요구사항

### 컨텐츠 관점
- 아이템 배지 이미지는 배경이 투명한 PNG로 등록한다.
- 불투명 배경 이미지가 이미 등록돼 있다면 목록을 뽑아 교체 대상으로 알린다(교체 자체는 이 티켓 범위가 아니다).

## 구현 계획

1. 알파 채널을 검사하는 방법을 정한다(제작 단계 경고 / 등록 단계 거절 중 하나).
2. 규칙 문서에 한 절을 적고 `/jam-img`의 안내를 맞춘다.

## 완료 조건

- 규칙 문서에 «아이템 배지 이미지는 투명 배경 PNG»와 그 이유(미발견 실루엣)가 적혀 있다.
- 불투명 배경 이미지를 등록하려 하면 경고나 거절이 나오는 경로가 정해져 있다(구현은 후속 티켓으로 나눠도 된다).
