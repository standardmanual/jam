# [Content] 카피 화자를 친구로 유지하고 권유 어미와 느낌표 규칙을 정한다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-03): 당근 보이스 가이드를 롤모델로 삼아 지금 JAM! 보이스톤과 비교하고, 화자는 «운동을 마친 사람의 성과를 같이 반가워하는 친구»로 유지한다. 당근에서는 문장 습관만 가져온다.
- 결정(사용자, 2026-11-03):
  1. 화자는 친구를 유지한다. 이웃 화자(동네 공동체)는 쓰지 않는다.
  2. 가져오는 것 네 가지: 권유는 「~해 봐요」(시키는 「~하세요」 대신), 보상은 명사형 「획득!」으로 끊지 않고 문장으로 맺기, 권유·안내 문장에서 느낌표 쓰지 않기, 카드 한 장에 일상 장면 하나 담기.
  3. 가져오지 않는 것: 이웃 호칭, 고정 용어 치환, 의인화·은유, 보상 숨기기, 열린 질문 마무리.
- 관련 파일: `docs/service/writing/UX_WRITING_GUIDELINE.md`(§2.6 신설), `docs/marketing/브랜드_보이스_가이드.md`(화자 절, 금칙 표, 톤 표 예시), `.claude/skills/jam-story/references/marketer-home-feed.md`(§2.6 참조 한 줄).

## 배경 / 문제 정의

홈피드·미션 문구 샘플 19건을 세어 보니 11건이 「포인트 획득!」 명사형으로, 6건이 「~하세요」 명령형으로 끝났고 해요체 평서문은 2건뿐이었다. 느낌표는 11건에 있었다. 따뜻함이 단어가 아니라 부호에서 나오고, 같은 제목과 설명이 여러 번 반복됐다. 문서에는 화자와 권유 어미를 정한 규칙이 없었다.

## 완료 조건

- UX 라이팅 가이드라인에 화자와 네 가지 문장 습관, 가져오지 않는 것이 한 절(§2.6)로 있다.
- 브랜드 보이스 가이드가 같은 규칙을 다시 적지 않고 §2.6을 가리키며, 마케팅 전용 금칙 3행이 채워져 있다.
- `scripts/verify.sh`가 통과한다.

## 완료 기록

### 구현 내용 요약
UX 라이팅 가이드라인 §2.6 「권유·안내 문장의 화자와 온도」를 신설했다. 규칙 네 가지를 Good/Bad 표로 적고, 같은 주 편성에서 같은 문장 모양이 세 번 넘게 이어지지 않게 하는 규칙과 가져오지 않는 것을 더했다. 오류·요청 문장의 「~해 주세요」는 그대로 둔다. 브랜드 보이스 가이드에는 화자 절을 더하고, 금칙 표를 3행으로 채웠고, 톤 표의 「다음은 △△가 보인다」 예시를 UX 라이팅 재정비 문서(§7)가 정한 대로 뺐다.

### 실행 기록(메인 세션, 사용자 지시 2026-11-03 «네, 고쳐 쓰기»)
- 노출 기간이 아직 끝나지 않은 홈피드 카드 15장(설명 14건, 제목 1건)과 미션 4개(설명 4건, 제목 1건)의 문구를 새 규칙으로 고쳐 썼다. 파일: `jam-web/supabase/migrations/seed_copy_friend_voice_20261103.sql`과 되돌림 `_down.sql`.
- 실행 전 시험: 같은 SQL 끝에 예외를 던져 되돌리는 방식으로 21건이 모두 예상한 이전 값과 일치하고 트리거 오류가 없음을 확인했다. 이어서 실제로 적용했다.
- 실행 후 읽기 확인: 노출 기간이 남은 카드와 미션에서 「~세요」, 느낌표, 「나누기」가 0건, 60자 초과 0건, 「장소 배지」·「발견」·「찾아서」 0건이다.
- 함께 고친 것: 「놓고, 줍고, 나누기」를 윈터 제안대로 「놓고, 줍고, 이어가기」로 바꿨다(카드와 미션). 「역에서 체크인하면 장소 배지」는 고정 용어 위반이라 「체크인 배지」로 바로잡았다. 「발견」과 「찾아서」는 「떨어져 있어요」와 「획득해 봐요」로 바꿨다.
- 노출 기간이 지난 카드, 이미 새 규칙에 맞는 카드(「겨울잠」 배지 카드, 11월 9일 이후 주간 카드 중 규칙에 맞는 것)는 건드리지 않았다.

### 가정과 후속
- 「쌀쌀해지기 전에」, 「활동 길에」 같은 장면 문구는 제가 정했고 윈터 톤 확인은 거치지 않았다.
- 「오늘은 입동이에요」 카드의 노출일(11월 7일)이 입동과 맞는지는 아직 확인하지 않았다.
- 규칙을 기계로 거르는 검사(`scripts/check-slop.mjs`에 권유 자리의 「~하세요」와 「획득!」 끝맺음 추가)는 만들지 않았다. 코드 변경이라 `/jam-work` 티켓으로 따로 간다. 한 문장 규칙이 아니라 문맥 판단이 섞이므로 경고 수준으로 시작하는 것을 권한다.
- 입동 카드 노출일 확인, 윈터가 제안한 제목 「놓고, 줍고, 이어가기」 반영, 「발견」과 「찾아서」 용어 정리는 이 티켓 밖이다.
