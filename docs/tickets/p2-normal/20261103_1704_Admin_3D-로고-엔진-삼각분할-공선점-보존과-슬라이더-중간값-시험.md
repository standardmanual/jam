# [Admin] 3D 로고 형상 엔진 — 삼각분할 전에 일직선 점을 보존해 경계 밖 조합의 납작한 삼각형을 없애고, 슬라이더 중간값을 훑는 시험을 더한다

> 티켓 20261103_1352(3D 로고 화면) 게이트 리뷰·로컬 실렌더 확인의 범위 밖 발견물로 자동 생성한 티켓이다.

## 핵심 요약

- 요구사항: 윗면 삼각분할이 일직선 위 중간 점을 지워 긴 직선 띠가 양 끝점만 남는 문제를 근본적으로 없앤다. 슬라이더 경계 12개 조합 밖에서도 윗면 삼각형 품질(넓이/최장변² ≥ 2×10⁻⁴)이 지켜지게 한다.
- 구현 계획: `withDelaunayLids`에서 `triangulateD` 전에 공선점을 보존하는 방법을 찾는다(점을 미세하게 비껴 두고 되돌리는 시도는 복원 뒤 넓이 0 삼각형을 만들어 폐기됐다). 슬라이더 중간값 격자(틀 폭 × 틀 베벨)를 훑는 시험을 더한다.
- 관련 파일: `jam-web/src/lib/logo-3d/buildGeometry.ts`(`withDelaunayLids`, `MIN_LID_BAND` 하한), `jam-web/src/app/admin/logo-3d/__tests__/logo3dParamRange.test.ts`

## 배경 / 문제 정의

3번 티켓에서 윗면 띠 폭 하한 0.0003으로 경계 12개 조합은 통과시켰지만, 하한 값이 단조롭지 않아(0.0004·0.0007은 경계 1건 실패, 0.0008은 기본 시험을 깸) 엔진이 조금 바뀌면 판정이 뒤집힐 수 있다. 경계 밖 조합(예: A 틀 폭 0.013 × 베벨 0.006 q=1.1×10⁻⁴, J 틀 폭 0.03 × 베벨 0.003, J 틀 폭 0.05 이상 일부)에는 납작한 삼각형이 남는다. PRD 5절에 한계로 적혀 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 기본값(틀 폭 0.03, 베벨 0.0145)의 겉모습은 그대로여야 하고, 1번 티켓의 기존 시험이 통과해야 한다.

## 구현 계획

`withDelaunayLids`에서 `triangulateD` 전에 공선점을 보존하는 방법을 찾는다(점을 미세하게 비껴 두고 되돌리는 시도는 복원 뒤 넓이 0 삼각형을 만들어 폐기됐다). 슬라이더 중간값 격자(틀 폭 × 틀 베벨)를 훑는 시험을 더한다.

## 완료 조건

- 틀 폭 × 틀 베벨 슬라이더 범위를 촘촘히 훑은 격자(예: 각 6값)의 모든 조합에서 M·A·J 윗면 삼각형이 넓이/최장변² ≥ 2×10⁻⁴이다.
- 하한 `MIN_LID_BAND`에 의존하지 않거나, 의존하더라도 값을 바꿔도 시험이 뒤집히지 않는다.
- PRD 5절의 알려진 한계 문장이 결과에 맞게 갱신된다.
- `npm run lint`·`typecheck`·`test`가 통과한다(`scripts/verify.sh`).
