# [Feature] 3D 로고 제너레이터를 에셋 화면의 「3D」 모드로 통합하고, 프리셋이 3D 설정값까지 저장하게 한다 (상위 티켓)

> 2026-11-03 사용자 지시: 「이 페이지를 에셋 메뉴의 Mode 중에 3D 모드로 추가해. 동일한 선택옵션들(캔버스, 프리셋 등)은 에셋을 기준으로 만들어」, 이어서 「프리셋 범위를 확장해. 폰트, 두께, 색, 각도 등의 설정값을 저장해」.
> 앞서 「별도 페이지」로 정한 구조(상위 티켓 20261103_1349)를 바꾸는 결정이다.

## 핵심 요약

- 요구사항: 에셋 화면(`/admin/assets`)의 Mode(Shape·Ribbon)에 「3D」를 더한다. 3D 전용 섹션(입력·두께·색·시점)은 지금 3D 화면에서 옮기고, 공통 옵션(Canvas 비율·Preset·Background·Overlay Layers·Export·콘텐츠 적용)은 에셋 것을 그대로 쓴다. 프리셋은 3D 설정값(폰트·굵기·글자열, 두께, 색, 회전·줌·시점)까지 저장·불러온다.
- 구현 계획: 하위 티켓 5개를 순서대로 진행하고, 마지막에 색감·질감 티켓(20261103_1718)을 통합 구조에 맞춰 고쳐 실행한다.
- 관련 파일:
- 에셋 화면(`jam-web/src/app/admin/assets/`): `page.tsx`(모드 상태 `engineMode` 106줄, 상단 「랜덤 생성」 버튼 670~698줄, 뷰포트 715줄·패널 739줄 이후 props, PNG 저장 704·782줄), `ShapeStudioPanel.tsx`(제작/적용 전환 315줄, Mode 섹션 350~379줄, Preset 381~394줄, Canvas 396~428줄, Shape 전용 섹션 431~927줄 중 Background 846~927줄, Ribbon 전용 929~1217줄, 공통 Overlay Layers 1219줄·Export 1268줄), `ShapeStudioViewport.tsx`(내보내기 핸들 `exportPng`·`recordVideo` 54~55줄 타입, 962~1100줄 구현), `shapeStudioConfig.ts`(`StudioEngineMode` 60줄, `ShapeStudioState`의 `bgMode`·`bgA`·`bgB`·`bgAngle`·`grain` 82~86줄)
- 옮겨 올 3D 화면(`jam-web/src/app/admin/logo-3d/`): `page.tsx`(폰트·SVG → 윤곽 효과, 형상 생성 `buildLogoGeometry`), `Logo3DPanel.tsx`(Input·Thickness·Color·View 섹션), `Logo3DViewport.tsx`(three 렌더러·환경 조명·PNG 저장), `logo3dConfig.ts`(상태 타입·기본값·`isometricCameraPose`·`PALETTES`), `logo3dDefaultSvg.ts`(티켓 20261103_1712에서 추가되는 기본 로고 SVG)
- 형상 엔진·입력 변환(수정하지 않고 재사용): `jam-web/src/lib/logo-3d/`, 폰트 중계 `jam-web/src/app/api/admin/logo-3d/font/route.ts`

## 결정 기록 (사용자, 2026-11-03)

- 3D는 별도 페이지가 아니라 에셋의 세 번째 Mode다. 별도 페이지 `/admin/logo-3d`와 디자인 그룹의 「3D 로고」 메뉴는 없애고 옛 주소는 에셋 3D 모드로 보낸다.
- 공통 옵션은 에셋 기준이다. 배경은 3D 자체 배경 대신 에셋 Background 섹션(Gradient·Solid·Transparent, 각도, 그레인)을 쓰고 Shape 모드와 같은 값을 공유한다.
- **프리셋 범위 확장(사용자 결정)**: 3D 설정값을 저장한다. `asset_presets`에 비어 있어도 되는 JSON 칸(`engine_state`)을 추가한다. 형식은 `{ mode, version, state }`로 모드 공통이라 나중에 Shape·Ribbon 설정도 DB 변경 없이 담을 수 있다(이번 범위는 3D만).
- 3D의 동영상 저장은 로고가 한 바퀴 도는 턴테이블 영상으로 지원한다(골격 단계에서는 비활성).
- 상단 「랜덤 생성」 버튼은 3D 모드에서 숨긴다.
