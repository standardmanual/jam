# [Admin] 에셋 3D 모드 1 — 골격: Mode에 「3D」 추가, 3D 섹션·상태·입력 이식, 3D 미리보기(에셋 Background 공유)

> 상위 티켓 [20261103_1733](20261103_1733_Feature_3D-모드를-에셋-화면으로-통합-프리셋-확장-상위.md)의 1번. 착수 조건: 티켓 20261103_1712(SVG 기본 로고)가 머지된 뒤.

## 핵심 요약

- 요구사항: 에셋 화면 Mode에 「3D」 버튼을 더하고, 3D를 고르면 미리보기에 3D 로고가 나오며 패널에 3D 전용 섹션(Input·Thickness·Color·View)과 에셋 공통 섹션(Preset·Canvas·Background·Overlay Layers·Export)이 보인다. Background는 Shape 모드의 Background 섹션(`bgMode`·`bgA`·`bgB`·`bgAngle`·`grain`)을 그대로 쓰고 값을 공유한다.
- 구현 계획: `StudioEngineMode`에 `'3d'`를 더하고, 3D 상태(입력·두께·색·시점)를 에셋 페이지 상태의 한 부분으로 옮긴다. 폰트·SVG → 윤곽 효과는 훅으로 빼서 옮기고, 3D 렌더러(`Logo3DViewport`의 three 부분)는 에셋 미리보기 영역 안에서 3D 모드일 때 그려지게 한다.
- 관련 파일:
- 에셋 화면(`jam-web/src/app/admin/assets/`): `page.tsx`(모드 상태 `engineMode` 106줄, 상단 「랜덤 생성」 버튼 670~698줄, 뷰포트 715줄·패널 739줄 이후 props, PNG 저장 704·782줄), `ShapeStudioPanel.tsx`(제작/적용 전환 315줄, Mode 섹션 350~379줄, Preset 381~394줄, Canvas 396~428줄, Shape 전용 섹션 431~927줄 중 Background 846~927줄, Ribbon 전용 929~1217줄, 공통 Overlay Layers 1219줄·Export 1268줄), `ShapeStudioViewport.tsx`(내보내기 핸들 `exportPng`·`recordVideo` 54~55줄 타입, 962~1100줄 구현), `shapeStudioConfig.ts`(`StudioEngineMode` 60줄, `ShapeStudioState`의 `bgMode`·`bgA`·`bgB`·`bgAngle`·`grain` 82~86줄)
- 옮겨 올 3D 화면(`jam-web/src/app/admin/logo-3d/`): `page.tsx`(폰트·SVG → 윤곽 효과, 형상 생성 `buildLogoGeometry`), `Logo3DPanel.tsx`(Input·Thickness·Color·View 섹션), `Logo3DViewport.tsx`(three 렌더러·환경 조명·PNG 저장), `logo3dConfig.ts`(상태 타입·기본값·`isometricCameraPose`·`PALETTES`), `logo3dDefaultSvg.ts`(티켓 20261103_1712에서 추가되는 기본 로고 SVG)
- 형상 엔진·입력 변환(수정하지 않고 재사용): `jam-web/src/lib/logo-3d/`, 폰트 중계 `jam-web/src/app/api/admin/logo-3d/font/route.ts`

## 상세 요구사항

### 서비스/코드베이스 관점
- `shapeStudioConfig.ts`의 `StudioEngineMode`를 `'shape' | 'ribbon' | '3d'`로 넓힌다.
- 3D 상태(`source`·폰트·굵기·글자열·SVG, `params`, 팔레트·틀 색·타일 색, `rotX`·`rotY`·`rotZ`·`zoom`·`view`)는 에셋 페이지가 들고 있는다. 3D 화면의 `bgMode`·`bgA`·`bgB`·`bgAngle`·`ratio`는 쓰지 않고 에셋의 값(`ShapeStudioState`의 배경 필드, 에셋 `ratio`)을 쓴다.
- 폰트·SVG → 윤곽 효과(폰트 캐시·디바운스·오류 유지·SVG 기본 로고 포함)는 `useLogo3DOutline` 같은 훅으로 옮긴다. 동작은 지금 3D 화면과 같아야 한다.
- 미리보기: 3D 모드에서는 에셋 미리보기 영역에 three 렌더러가 그려진다. 배경은 에셋 Background 값으로 칠한다(Gradient·Solid·Transparent, 각도). 그레인을 3D에도 반영할 수 있으면 반영하고, 못 하면 이유를 완료 기록에 남긴다.
- 모드를 바꿀 때 3D 렌더러·형상은 정리(`dispose`)하거나 숨겨서 메모리가 새지 않게 한다.
- 3D 모드에서 상단 「랜덤 생성」 버튼은 숨기고, Export의 동영상 저장 버튼은 비활성으로 둔다(동영상은 티켓 1737).
- 이 티켓에서는 Overlay Layers 합성·PNG 저장·콘텐츠 적용을 3D에 연결하지 않아도 된다(티켓 1735). 다만 3D 모드에서 그 버튼을 눌렀을 때 오류가 나지 않게(비활성 또는 안내) 한다.
- 어드민 UI 규칙: shadcn/ui 컴포넌트만 쓴다(네이티브 select 금지). 섹션 머리 형식(영문 제목 + 한글 설명)은 에셋 패널과 같게 한다.

### UI/UX 관점
- Mode 버튼은 「Shape (WebGL)」「Ribbon (2D 곡선)」 옆에 「3D」(예: 「3D (입체 로고)」)로 둔다.
- 패널 섹션 순서(3D 모드): 제작/적용 전환 → Mode → Preset → Canvas → Input → Thickness → Color → View → Background → Overlay Layers → Export.

## 구현 계획

1. `shapeStudioConfig.ts` 모드 타입 확장 → 3D 상태 타입·기본값을 에셋 쪽 설정(예: `assets/logo3d/` 아래 파일)으로 옮긴다(`logo3dConfig.ts`의 순수 함수·`PALETTES`·`isometricCameraPose` 재사용).
2. `useLogo3DOutline` 훅 → 3D 패널 섹션 컴포넌트(`Logo3DPanel.tsx`의 섹션들을 옮김) → 미리보기 연결 → `page.tsx`·`ShapeStudioPanel.tsx` 모드 분기.
3. 별도 페이지(`/admin/logo-3d`)는 이 티켓에서는 그대로 둔다(정리는 티켓 1738). 옮긴 코드는 두 곳에서 같이 쓰도록 공용 위치로 옮기거나, 별도 페이지가 새 위치를 가져다 쓰게 한다(코드 중복 금지).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 에셋 Mode에 「3D」가 있고, 누르면 `engineMode === '3d'`가 되어 3D 패널 섹션과 3D 미리보기가 나온다(시험: 모드 전환에 따른 섹션 표시 또는 상태).
- 3D 모드의 배경이 에셋 Background 섹션 값(`bgMode`·`bgA`·`bgB`·`bgAngle`)을 따르고, Shape 모드로 돌아가도 같은 값이 유지된다(시험).
- 폰트·SVG 입력 동작이 기존 3D 화면과 같다: 폰트 변경·글자열 디바운스·오류 시 이전 형상 유지·SVG 모드 기본 로고(시험은 기존 시험을 옮겨 유지).
- 3D 모드에서 「랜덤 생성」이 숨겨지고 동영상 저장이 비활성이다. PNG 저장·콘텐츠 적용을 눌러도 오류가 나지 않는다.
- 모드 전환 시 3D 렌더러·형상의 `dispose`가 호출된다(코드 확인 또는 시험).
- 옮긴 코드가 별도 페이지와 중복되지 않는다(한 곳에서 가져다 씀).
- `npm run lint`·`typecheck`·`test`가 통과한다(`scripts/verify.sh`).

### 후속 범위 (담당: 카리나, 시점: 머지 뒤, push 전)
- 로컬 `ADMIN_EMAILS` 개발 서버로 `/admin/assets`에서 Shape·Ribbon·3D를 오가며 실렌더를 확인한다(여러 글자 옆면 포함, 배경 공유, 콘솔 오류 없음).
