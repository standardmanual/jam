## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
3D 뷰포트가 보이는 화면을 2D 캔버스 한 장으로 합성한다(`composeStage`). 순서는 Shape 저장과 같이 배경 → 3D → 그레인 → 오버레이 레이어이고, 미리보기와 PNG 저장이 같은 합성 함수를 쓴다. 그레인은 배경과 3D 모두에 입히되 알파 0 픽셀은 건드리지 않아 Transparent는 알파 0을 유지한다. PNG 저장(`exportPngFile`)은 에셋 Export 크기를 긴 변, Canvas 비율로 짧은 변을 정해 three를 다시 그린다. 3D 뷰포트가 `AssetGeneratorViewportHandle`을 구현해 콘텐츠 적용 탭이 3D 모드에서 정지 이미지로 반영한다(`ApplyTab`의 `imageOnly`). Shape 뷰포트의 오버레이 그리기·로드 효과는 `overlayStage.ts`로 옮겨 두 뷰포트가 함께 쓴다(동작 변화 없음). 동영상 저장은 계속 비활성.
