# [Admin] 3D 로고 별도 페이지 정리 — `/admin/logo-3d`를 에셋 3D 모드로 보내고, 「3D 로고」 메뉴를 없애고, PRD를 에셋 쪽으로 합친다

> 상위 티켓 [20261103_1733](20261103_1733_Feature_3D-모드를-에셋-화면으로-통합-프리셋-확장-상위.md)의 5번. 착수 조건: 4번(20261103_1737) 머지 뒤.

## 핵심 요약

- 요구사항: 별도 페이지와 메뉴를 없애 3D 로고를 만드는 경로를 에셋 3D 모드 하나로 둔다. 옛 주소로 들어오면 에셋 화면이 3D 모드로 열린다.
- 구현 계획: `/admin/logo-3d`를 `/admin/assets?mode=3d`로 리디렉트하고(에셋 페이지가 `mode` 쿼리로 초기 모드를 정하게), `adminNavItems.ts`의 「3D 로고」 항목(디자인 그룹, 에셋 다음)을 지운다. 별도 페이지 전용 파일 중 더는 쓰이지 않는 것을 지운다(공용으로 옮긴 코드는 유지). `docs/service/prd/logo-3d/PRD.md`의 내용을 에셋 PRD(`docs/service/prd/asset-generator/PRD.md` 또는 에셋 화면 PRD)로 합치고 색인을 고친다.
- 관련 파일: `jam-web/src/app/admin/logo-3d/`(page·Panel·Viewport·config·시험), `jam-web/src/components/admin/adminNavItems.ts`(110줄 근처 `/admin/logo-3d`)와 `__tests__/adminNavItems.test.ts`, `jam-web/src/app/admin/assets/page.tsx`(초기 모드), `docs/service/prd/logo-3d/PRD.md`, `docs/service/prd/README.md`, `docs/INDEX.md`

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- `/admin/logo-3d` 요청이 `/admin/assets?mode=3d`로 리디렉트되고, 에셋 화면이 3D 모드로 열린다(시험).
- 어드민 메뉴에 「3D 로고」가 없다(메뉴 시험 갱신).
- 지운 파일을 가져다 쓰는 곳이 없다(타입 검사·빌드 기준), 남은 시험이 모두 통과한다.
- PRD가 에셋 쪽으로 합쳐지고 색인이 맞다(`docs/INDEX.md` 재생성).
- `npm run lint`·`typecheck`·`test`가 통과한다(`scripts/verify.sh`).

### 후속 범위 (담당: 카리나, 시점: 머지 뒤, push 전)
- 로컬에서 옛 주소 리디렉트와 메뉴를 눈으로 확인한다.
