# [Admin] 에셋 화면 — 녹화 중에 「녹화 취소」 버튼이 눌리지 않는다 (Shape·3D 공통)

> 티켓 20261103_1737(3D 동영상 턴테이블) 게이트 리뷰와 로컬 실녹화의 범위 밖 발견물로 자동 생성한 티켓이다.

## 핵심 요약

- 요구사항: 동영상 녹화 중에 「녹화 취소」 버튼을 누르면 녹화가 멈추고 원래 상태로 돌아온다.
- 구현 계획: `ShapeStudioPanel.tsx`에서 「녹화 취소」 버튼을 `fieldset disabled={exportBusy}` 밖으로 빼거나, 그 버튼만 비활성 상속을 받지 않게 구조를 바꾼다. 3D·Shape 모두 취소 경로(`onCancelVideo`)가 실제로 녹화를 멈추는지 확인한다.
- 관련 파일: `jam-web/src/app/admin/assets/ShapeStudioPanel.tsx`(464줄 근처 `<fieldset disabled={exportBusy}>`, 1377~1386줄 「녹화 취소」 버튼), `page.tsx`(`onCancelVideo` 연결), `ShapeStudioViewport.tsx`·`logo3d/Logo3DViewport.tsx`(취소 처리)

## 배경 / 문제 정의

2026-11-03 로컬 실녹화에서 녹화 중 「녹화 취소」 버튼이 `:disabled` 상태임을 확인했다. 버튼 자체에는 비활성 속성이 없지만, 녹화 중 패널 입력을 막으려고 감싼 `fieldset`이 비활성이라 그 안의 버튼도 함께 막힌다. Shape 모드도 같은 구조라 원래부터 있던 결함이다.

## 완료 조건

- 녹화 중 「녹화 취소」 버튼이 활성이고(시험: 녹화 중 상태에서 버튼이 `:disabled`가 아님), 누르면 녹화가 멈추고 파일이 저장되지 않으며 미리보기·회전값이 원래대로 돌아온다(3D·Shape 각각).
- 녹화 중 다른 패널 입력은 지금처럼 막혀 있다.
- `npm run lint`·`typecheck`·`test`가 통과한다(`scripts/verify.sh`).
