# [UI] 캡슐 게이지에 채운 양 숫자를 두 자리로 표시한다

## 핵심 요약

- 요구사항: 홈피드와 프로필의 캡슐 게이지(프로그래스바)에 채운 양의 숫자를 보인다. 채운 비율이 50% 이상이면 채움 안쪽 왼쪽, 50% 미만이면 트랙 바깥쪽 오른쪽에 둔다(사용자 첨부 시안 기준).
- 구현 계획: 두 화면이 같은 `CapsuleGauge`를 쓰므로 이 컴포넌트에 숫자를 더한다. 자리 판정과 글자 변환은 순수 함수(`capsuleNumberPlacement`·`capsuleNumberText`)로 `capsule-gauge.ts`에 둔다.
- 관련 파일: `jam-web/src/components/capsule/CapsuleGauge.tsx`, `jam-web/src/lib/capsule/capsule-gauge.ts`, 시험 3개, `docs/service/prd/home-feed/PRD.md`, `jam-web/src/lib/admin/policyDashboard/policiesData.ts`

## 배경 / 문제 정의

게이지는 티켓 20261028_1739에서 «퍼센트·진행 숫자를 화면에 쓰지 않는다»는 규칙으로 만들어졌다. 사용자가 시안(두 가지 모양)을 첨부하며 채운 양을 숫자로 보이도록 바꾸라고 요청했다. 이 요청은 이전 규칙을 바꾸는 결정이다.

## 상세 요구사항

### UI/UX 관점
- 숫자는 지금 채운 양(`filled`) 하나다. 퍼센트 기호와 필요량은 쓰지 않는다.
- 50% 이상(경계 50%는 안쪽): 채움 안쪽 왼쪽, 트랙 색(`--capsule-track`) 글자. 번개는 채움 오른쪽 끝에 그대로 둔다.
- 50% 미만: 트랙 안쪽 오른쪽 끝, 오렌지(`--capsule-fill`) 글자.
- 글자는 20px 굵은 숫자(`tabular-nums`), 가장자리 간격 14px.
- 새 토큰은 만들지 않았다. 기존 두 토큰을 글자색으로 쓴다.
- 합친 연출이 게이지를 붙드는 동안에는 연출 전에 값이 드러나지 않도록 두 자리 모두 숨긴다. 안쪽 숫자는 번개 자리를 뺀 너비 안에서만 보여 채움이 차오를 때 같이 드러난다.
- 접근성: `role="img"`와 숫자 없는 `aria-label`은 그대로다.

## 완료 조건
- 홈과 내 프로필의 게이지에서 채운 비율 50% 미만은 오른쪽 끝 오렌지 숫자, 50% 이상은 채움 안쪽 왼쪽 어두운 숫자로 보인다.
- 시험(게이지·위젯·메인 화면)이 통과하고 타입 검사·린트에 오류가 없다.

### 주요 의사결정 / 핵심 메모
- 경계 판정은 모션 중간값이 아니라 실제 값(채운 양 ÷ 필요량)으로 한다. 채움이 차오르는 동안 숫자 자리가 바뀌지 않는다.
- 숫자는 쉼표 없이 시안처럼 자릿수 그대로 쓴다. 필요하면 천 단위 쉼표는 `capsuleNumberText` 한 곳에서 바꾼다.
- 폭이 좁은 기기(320px)에서 아주 큰 숫자가 절반 근처에서 안쪽에 들어가면 번개 앞에서 잘릴 수 있다. 실제 필요량 범위에서는 해당하지 않아 처리하지 않았다.

### 잔여 이슈
- 로컬에서 로그인 상태의 홈·프로필 실화면은 열지 못했다. 같은 컴포넌트를 서버 렌더한 마크업에 실제 토큰 CSS를 입혀 확인했다. staging 배포 뒤 화면 확인이 필요하다.
