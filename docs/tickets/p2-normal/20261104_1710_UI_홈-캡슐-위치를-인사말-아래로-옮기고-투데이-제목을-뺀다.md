# [UI] 홈 캡슐 위치를 인사말 아래로 옮기고 투데이 제목을 뺀다

## 핵심 요약

- 요구사항: ① 홈의 캡슐 위젯을 «{이름}님, 오늘도 좋은 하루예요» 인사말 바로 다음, 퀘스트(«JAM! 시작하기» 카드)보다 위로 옮긴다. ② 홈 투데이 영역의 제목 «투데이»와 부제 «오늘의 소식»을 뺀다. ③ 캡슐 게이지 숫자(티켓 20261104_1640)에 transitions.dev Number pop-in을 적용한다.
- 구현 계획: ① `page.tsx`에서 `CapsuleWidget`을 인사말 줄 아래, `OnboardingQuestCard` 위로 옮긴다. ② `TodayCardStack`의 머리글 div를 지우고 쓰지 않게 된 i18n 키 `today.cardStackSubtitle`을 지운다(`cardStackTitle`은 기사 상세 상단 바가 써서 유지). ③ 이미 설치된 `t-digit-pop-in`과 공유 `PopInNumber`를 재사용하고, `PopInNumber`에 `playOnMount` 옵션을 더한다.
- 관련 파일: `jam-web/src/app/(main)/page.tsx`, `jam-web/src/app/(main)/TodayCardStack.tsx`, `jam-web/src/lib/i18n/ko.ts`, `jam-web/src/components/capsule/CapsuleGauge.tsx`, `jam-web/src/components/ui/PopInNumber.tsx`, 시험 3개, `docs/service/prd/home-feed/PRD.md`, `jam-web/src/lib/admin/policyDashboard/policiesData.ts`

## 배경 / 문제 정의

사용자가 홈의 캡슐 위치를 바꾸고, 투데이 머리글을 없애고, 숫자에 팝인 전환을 적용하라고 요청했다. 위젯 순서와 화면 문구가 바뀌는 변경이라 PRD의 홈 구성 표를 함께 고쳤다.

## 상세 요구사항

### UI/UX 관점
- 홈 순서: 상단 바, (이용 정지 배너), 인사말 + 검색, **캡슐**, «JAM! 시작하기» 카드, (Strava 끊김 카드), 오늘의 현황 스트립, 투데이 카드 스택.
- 투데이 카드 스택은 제목·부제 없이 카드만 쌓는다. 노출할 카드가 0장이면 영역 전체를 그리지 않는 규칙은 그대로다.
- 게이지 숫자 팝인: 채움이 값에 닿기 전에는 투명하고, 닿은 뒤 각 자리가 블러와 함께 8px 아래에서 500ms 동안 들어오며 끝 두 자리가 70ms씩 뒤따른다. 값이 바뀌면 새 값에 닿은 뒤 다시 재생한다. 모션 줄이기에서는 전환 없이 바로 보인다.

## 완료 조건
- 홈에서 캡슐이 인사말 바로 아래, 퀘스트 카드 위에 보인다.
- 홈에 «투데이»·«오늘의 소식» 글자가 없다.
- 게이지 숫자가 채움이 닿은 뒤 팝인한다.
- 시험(`src/components`, `src/app/(main)`)이 통과하고 타입 검사·린트에 오류가 없다.

### 주요 의사결정 / 핵심 메모
- 팝인은 transitions.dev에서 원문을 확인했고, 프로젝트에 같은 코드가 이미 `transitions.css`(`t-digit-*`)와 `PopInNumber`로 설치돼 있어 새로 만들지 않고 재사용했다.
- `PopInNumber`는 첫 렌더에서 재생하지 않는 규칙이라 `playOnMount`를 선택 옵션으로 더했다. 기존 사용처(프로필 팔로워 수, 포인트 잔액)는 동작이 같다.
- 게이지는 닿기 전 투명한 글자를 두었다가, 닿은 뒤 `PopInNumber`로 바꿔 끼워 재생한다.

### 잔여 이슈
- 팝인의 실제 움직임은 staging 배포 뒤 화면에서 확인한다.
