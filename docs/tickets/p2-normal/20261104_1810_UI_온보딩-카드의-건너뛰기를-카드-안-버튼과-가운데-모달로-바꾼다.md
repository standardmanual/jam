# [UI] 온보딩 카드의 건너뛰기를 카드 안 버튼과 가운데 모달로 바꾼다

## 핵심 요약

- 요구사항: 신규 가입자에게 보이는 «미리 해보기 건너뛰기»를 카드 안 우측 아래의 버튼으로 두고, 누르면 하단 시트가 아니라 가운데 모달로 확인받는다.
- 구현 계획: 진입 컴포넌트(`OnboardingQuestSkipSheet` → `OnboardingQuestSkipModal`)가 `Button` outline sm을 우측 정렬 행에 두고 새 서비스 전용 `ConfirmModal`을 연다. 건너뛰기 API·GA4 이벤트·`router.refresh()`는 그대로다.
- 관련 파일: `jam-web/src/app/(main)/OnboardingQuestSkipModal.tsx`, `jam-web/src/app/(main)/OnboardingQuestCard.tsx`, `jam-web/src/components/ui/ConfirmModal.tsx`, `jam-web/src/components/transitions.css`, 시험 2개 이상, `docs/service/prd/home-feed/PRD.md`

## 배경 / 문제 정의

기존에는 카드 밖 좌측의 작은 텍스트 링크를 눌러 하단 시트에서 확인했다. 사용자가 진입을 카드 안 버튼으로, 확인 화면을 모달로 바꾸라고 요청했다.

## 상세 요구사항

### UI/UX 관점 (채원 사전 판정, 2026-11-04)
- 버튼: `Button` outline sm(높이 44px). 한 카드의 primary는 연출 CTA 하나라서 primary를 쓰지 않는다. 연출 CTA 행 바로 아래 `flex justify-end` 행에 두고, 실제 체크리스트가 함께 있으면 구분선 앞에 둔다.
- 모달: 서비스에 가운데 확인 다이얼로그가 없어(`ModalToast`는 단일 알림, Radix `alert-dialog`는 어드민 전용) 서비스 전용 `ConfirmModal`을 새로 만들었다. MODULAR 승격은 두 번째 사용처가 생길 때 후보로 올린다.
- 층과 구조: z-50(시트·다이얼로그 층, 토스트 z-60 아래), `document.body` 포털, `role="dialog"` `aria-modal` `aria-labelledby`, 열리면 포커스는 «계속하기», Tab 순환·Escape·닫힘 때 포커스 복귀, 스크롤 락은 `pushMainScrollLock`.
- 모션: 기존 `--modal-*` 토큰(열림 250ms·닫힘 150ms·배율 0.96)으로 `.t-modal`·`.t-modal-backdrop`을 `transitions.css` «프로젝트 확장»에 더했다. 이동·블러 없음, 모션 줄이기에서는 전환 없음, 백드롭에 blur 없음.
- 문구는 기존 `d.onboardingQuest.skip`을 그대로 쓴다(새 문구 없음).
- 요청 중에는 Escape·스크림 탭·«계속하기»로 닫히지 않는다. 실패하면 저장 실패 토스트가 모달 위에 뜨고 모달은 유지된다.

## 완료 조건
- 연출 중 카드 안 우측 아래에 outline 버튼이 보이고 카드의 primary는 연출 CTA 하나다.
- 버튼을 누르면 화면 가운데에 모달이 뜨고 하단 시트는 뜨지 않는다.
- «계속하기»는 닫기, «건너뛰기»는 기존 API 호출 후 `router.refresh()`다.
- 시험·타입 검사·린트 통과, staging 실화면에서 모달이 열린다.
