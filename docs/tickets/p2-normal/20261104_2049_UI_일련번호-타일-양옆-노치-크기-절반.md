# [UI] 아이템 배지 일련번호(ItemSerialCode) 타일 양옆의 반원 노치 크기를 절반으로 줄인다

## 핵심 요약

- 요구사항: 일련번호 타일(알파벳 카드·숫자 박스)의 세로 변 가운데에 파인 원형 노치의 크기를 절반으로 줄인다.
- 구현 계획: `NOTCH_RATIO`(노치 반지름 ÷ height)를 0.09125에서 0.045625로 바꾼다. 한 줄 수정이다(경미 수정, 카리나 직접 처리).
- 관련 파일: `jam-web/design-system/components/patterns/ItemSerialCode.jsx` — 상수 `NOTCH_RATIO`(35행), 사용처 `tilePath`(210행 `nr = h * NOTCH_RATIO`)

## 배경 / 문제 정의

사용자가 노치가 크다고 보고 절반 크기를 요청했다. 노치는 `tilePath`의 `clipPath`로 타일 좌우 변 가운데를 도려내는 반원이며, 반지름이 `height × NOTCH_RATIO`다.

## 상세 요구사항

### UI/UX 관점
- 노치 반지름만 절반으로 줄인다. 모서리 둥글기(`CORNER_RATIO`)·타일 폭·간격·글자 크기·릴 모션은 그대로다.
- `ItemSerialCode`를 쓰는 모든 화면(배지 상세, 드랍 시트, 잠긴 상세, 후보 행, 획득 이력)에 함께 적용된다.

## 구현 계획

`NOTCH_RATIO`를 0.045625로 바꾸고 주석에 사유를 남긴다.

## 완료 조건

- `tilePath`가 만드는 좌우 노치 반지름이 이전의 절반이다(height 50 기준 4.56px → 2.28px).
- 그 밖의 치수와 릴 모션은 바뀌지 않는다. 변경 파일은 `ItemSerialCode.jsx` 한 개, 변경 줄은 한 줄이다.
- `scripts/verify.sh`가 통과한다.
