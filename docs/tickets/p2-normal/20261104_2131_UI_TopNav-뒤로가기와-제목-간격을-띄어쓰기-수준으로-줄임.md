# [UI] TopNav 뒤로가기(<)와 제목 사이 간격을 띄어쓰기 수준으로 줄인다

## 핵심 요약

- 요구사항: 「< 미션」처럼 뒤로가기 chevron과 제목 사이가 너무 넓다(약 22px). 띄어쓰기 한 칸 정도(약 5px)로 줄인다. (사용자 지시, 스크린샷 첨부)
- 구현 계획: DS `TopNav.jsx`의 뒤로가기 버튼(앵커·버튼 두 갈래)에 `marginRight: -17`을 주어 제목을 당기고, `position: relative; zIndex: 1`로 버튼을 제목 위 층에 올려 44×44 터치 영역을 그대로 지킨다.
- 관련 파일: `jam-web/design-system/components/navigation/TopNav.jsx`(뒤로가기 `<a>`·`<button>` style), `jam-web/src/components/ui/__tests__/TopNav.test.tsx`(끝에 시험 1건 추가)

## 배경 / 문제 정의

버튼은 44px 폭이고 24px chevron이 가운데에 놓여, chevron 오른쪽 끝에서 버튼 끝까지 약 18px의 빈 면이 있다. 여기에 flex gap 4px가 더해져 chevron과 제목 사이가 약 22px였다.

## 완료 조건

- 뒤로가기 chevron 오른쪽 끝과 제목 왼쪽 끝 사이가 약 5~6px이다. (실측 6px)
- 뒤로가기 버튼의 터치 영역은 44×44 그대로이고, 겹친 구간을 눌러도 버튼이 눌린다. (실측: 버튼 오른쪽 끝 3px 안쪽에서 `elementFromPoint`가 버튼)
- 관련 시험·lint 통과.
