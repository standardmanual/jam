# [UI] 미션 상세페이지 맨 아래의 비활성 «참가중» 버튼을 지운다

## 핵심 요약

- 요구사항: 미션 상세페이지 맨 아래의 «참가중» 텍스트(비활성 버튼)를 지운다. 위쪽에 «참가중» 칩이 이미 있어 중복이다.
- 구현 계획: `participating` 분기가 그리던 비활성 `button`을 `null`로 바꾼다. 분기 자체를 지우면 아래 `isActive` 분기의 «참가하기» 버튼이 참가 중에도 떠서 안 된다.
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx` — CTA 영역 `participating ? ...`(637행 부근). 칩(164행 `d.missions.tagJoined`)은 그대로 둔다.

## 배경 / 문제 정의

참가 중인 미션은 히어로의 «참가중» 칩과 맨 아래 비활성 버튼에 같은 말이 두 번 나온다(사용자 지적).

## 상세 요구사항

### UI/UX 관점
- 참가 중일 때 맨 아래 CTA 자리는 비운다. 완료(`isCompleted`)의 «종료» 버튼, 잠금, 참가 전 «참가하기»는 그대로다.
- 참가자만 보이는 «미션 상황 보기» 링크는 그대로다.

## 완료 조건

- 참가 중인 미션의 상세에서 맨 아래에 «참가중» 텍스트가 없고, 위쪽 «참가중» 칩은 남아 있다.
- 참가 중에 «참가하기» 버튼이 뜨지 않는다.
- 이 문구를 단정하는 시험·문서는 없다(grep 확인).
