# [UI] 미션 상세의 보상 박스를 달성 조건 위로 옮기고 «보상» 레이블과 «완료하면 바로 받아요» 문구를 뺀다

## 핵심 요약

- 요구사항: ① 보상 영역의 «완료하면 바로 받아요» 텍스트 제거 ② 보상이 표시된 미색(테두리 없는) 박스를 달성 조건 섹션 위로 이동 ③ «보상» 레이블 제거.
- 구현 계획: 바깥 흰 `InfoCard`(레이블 포함)를 없애고, 보상 행을 미색(`--background-secondary`) 테두리 없는 박스로 달성 조건 카드 바로 위에 둔다. 포인트 행은 `ListRowCard tone="tint"`에서 캡션(`subtitle`)만 뺀다. 배지 행·잠긴 배지 행은 `Card tone="tint"`로 감싸 같은 모양으로 맞춘다.
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`(보상 블록을 «달성 조건 카드» 앞으로 이동), `jam-web/src/lib/i18n/ko.ts`(`rewardSectionTitle`·`rewardPointsCaption` 삭제), `MissionDetailClient.notice.test.tsx`(레이블 단정 교체와 위치 시험 추가)

## 배경 / 문제 정의

사용자가 보상 영역의 레이블·캡션이 불필요하고, 보상 박스를 달성 조건보다 먼저 보이게 하길 요청했다. 지금 보상 영역은 «보상» 레이블이 붙은 흰 테두리 카드 안에 미색 포인트 박스가 들어 있는 모양이다.

## 상세 요구사항

### UI/UX 관점
- 보상 영역에는 레이블과 바깥 카드가 없다. 미색 박스(테두리 없음)가 그대로 보인다.
- 포인트 박스는 «N 포인트»만 보인다. 배지 보상 행의 캡션(«완료하면 획득해요»)은 사용자 요청 범위 밖이라 그대로 둔다.
- 선착순 안내(`limitedSlots`)는 보상 박스 아래 작은 글씨로 둔다.
- 위치: «달성 조건» 카드 바로 위. 잠금 안내·받을 보상 안내가 있으면 그 아래(히어로 직후 순서는 그대로)다.
- 디자인 시스템 메모: `Card`의 `tint` 톤은 «크림 바탕 위 단독 카드로는 쓰지 않는다»고 적혀 있다. 이번 모양은 사용자가 직접 지정했다.

## 완료 조건

- 보상이 있는 미션 상세에서 «보상» 레이블과 «완료하면 바로 받아요»가 없고, 보상 박스가 «달성 조건» 카드보다 위에 있다.
- 보상이 없는 미션에는 보상 박스가 없다.
- `MissionDetailClient*.test.tsx`와 i18n 시험이 통과하고 타입·린트에 문제가 없다.
