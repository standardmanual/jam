# [UI] 믹스 레시피 행의 획득 포인트를 굵게 하고 아래에 작은 «포인트» 단위를 붙인다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-04): 믹스 획득 포인트를 볼드로 표시하고, 줄을 바꿔 작은 글씨로 «포인트»를 적는다.
- 구현 계획: `RecipeRewardRow.tsx`의 `trailing`(포인트 값)을 세로 두 줄로 바꾼다. 숫자는 `text-base font-bold`, 아래 줄은 `text-xs text-muted`의 «포인트». 단위 문구는 `d.combine.pointsUnit`(`ko.ts`)으로 둔다.
- 관련 파일: `jam-web/src/app/(main)/combine/RecipeRewardRow.tsx`(`trailing` 약 105~110줄), `jam-web/src/lib/i18n/ko.ts`(`combine.noRewardLabel` 아래 `pointsUnit`), `jam-web/src/app/(main)/combine/CombineClient.test.tsx`

## 완료 조건

- 레시피 탐색 목록과 믹서 상단 요약바의 포인트가 굵은 숫자 + 아래 줄 작은 «포인트»로 보인다. 포인트가 0이면 그리지 않는다. (로컬 실렌더 확인)
- 관련 시험·lint 통과.
