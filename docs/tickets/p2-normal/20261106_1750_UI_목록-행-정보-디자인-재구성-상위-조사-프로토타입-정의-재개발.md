# [UI] 목록 행 정보 디자인 재구성 (상위): 조사, 프로토타입, 디자인 시스템 정의, 재개발

## 핵심 요약

- 요구사항: 프로필 피드·알림·미션·믹스 레시피 등 목록 행이 화면마다 글자 크기·강조·간격이 달라 보기 어렵다(사용자 요청 2026-11-06). 목록 행 컴포넌트를 정보 역할 기준으로 재구성해 디자인 시스템에 새로 정의하고, 적용할 화면을 다시 개발한다.
- 진행 순서(사용자 결정 2026-11-06): ① 목록 행이 쓰이는 곳 전수 조사 → ② 조사 결과로 컴포넌트를 재구성하고 프로토타입 제작 → ③ 프로토타입 검토 후 디자인 시스템 정의 → ④ 새 컴포넌트로 적용처 재개발.
- 현재: 1단계(조사)·2단계(프로토타입, 20261106_1759)·3단계(디자인 시스템 정의, 20261106_2003) 완료. 4단계(서비스 재개발)는 1배치(프로필 피드, 20261106_2252)가 끝났고 2배치(알림 20261107_0010, 레시피·등급 올리기 20261107_0011)를 진행 중이다.
- 관련 파일: `jam-web/src/components/ui/ListRowCard.tsx`(서비스 사본), `jam-web/design-system/components/patterns/ListRowCard.jsx`(원본), `jam-web/design-system/tokens/typography.css`

## 배경 / 문제 정의

프로필 피드 한 행의 «행위 라벨 / 대상 / 장소» 세 줄이 모두 16px이고 색만 다르며, 시간도 16px로 제목과 경쟁한다. 알림·미션·믹스 레시피의 행은 각자 다른 크기와 강조를 쓴다. 공용 `ListRowCard`가 아이콘·제목·부제·오른쪽 칸만 정하고, 실제 화면 대부분은 `children`으로 안쪽을 직접 그리기 때문이다.

## 1단계 조사 결과

조사 방법: 영역 4개로 나눠 코드를 읽었다(프로필·소셜·알림, 미션·랭킹·배지, 믹스·인벤토리·드랍·기타, 디자인 시스템과 공용 부품). 코드에서 확인한 값만 적었고 실렌더 측정은 하지 않았다. 어드민 화면과 테스트는 제외했다. 글자 크기는 Tailwind 클래스를 px로 환산했다(text-xs 12, sm 14, base 16, lg 18, xl 20, 2xl 24).

- **B2**: `ListRow variant="media" tone="flat"`. 썸네일은 lead(48 tile), NEW·상태 칩 줄은 `eyebrow`, 제목은 `title`(strong), 설명은 `meta`(`metaLines=2`), 조건 줄과 보상 줄은 `footer`(media 전용). 열린 미션은 `href`, 잠긴 미션은 `disabled`를 쓰지 않고 `onClick`으로 토스트를 띄운다. `disabled`는 행 전체 불투명도 0.4와 키보드 차단을 함께 걸어 현재 «썸네일만 흐리게, 글자 대비 유지» 규칙과 토스트 동작을 깨기 때문이다. 잠김 표현(흑백 + 딤 + 자물쇠)은 lead 안 내용으로 옮긴다.
- **칩**: NEW는 `warning`, 참가중은 `accent`, 완료·기간·시작 전은 `neutral`, 잠김은 `neutral` + 자물쇠 글리프로 `ListRowChip`에 맞춘다. 색은 컬러 개편(20261107_2201) 중이라 그 쪽 정의를 따른다. 지금 파일 안 세 칩은 10px이고 `ListRowChip`은 12px라 칩이 커진다.
- **보상 줄**: 현재 `--link` 색 굵은 글자다. `ListRow`에 이 색을 입히는 슬롯이 없어(`value`는 오른쪽 가운데 정렬) `footer` 안에서 호출부가 색을 정해야 한다. 컬러 개편에서 `--link` 글자색이 남는지 확인이 필요하다. 보상 줄 안의 `RarityBadge`·`BadgeLevelChip`은 MODULAR 칩이라 열린 티켓 20261106_2322(행 안 등급 칩 12px 통일)와 겹친다.
- **B3·B4·B8**: tint 행으로 lead 64를 48로, 캡션 13px를 meta 14px로 옮긴다. 같은 보상 박스 안의 포인트 보상 행은 3-3에서 이미 `ListRow tone="tint"`(lead 48)로 바뀌어, 코드상으로는 배지 보상 행(lead 64)과 포인트 행의 높이가 다르다. 이 불일치는 4배치가 풀어 준다.
- `LockedTile`은 `size` 값을 받으므로 48로 맞출 수 있다(원본 변경 여부는 채원이 확인).

### 5-1 판정 결과 (채원 사전 판정, 구현 반영)

| 판정 | 결과 |
|---|---|
| 1 `#번호` 자리 | 칩 줄 맨 앞 첫 항목으로 옮겼다(`text-xs leading-none text-muted whitespace-nowrap`, 칩 면 없음). 크기는 `text-base`에서 `text-xs`로 내렸다. |
| 2 안쪽 여백 | `Card`의 `--layout-card-padding`(24px)을 그대로 쓴다(기존 16px). 320px 본문 폭은 약 200px에서 약 238px로 넓어진다. 목록 `gap-2`는 유지한다. |
