# [UI] 행 안 등급 칩 글자를 12px로 맞춘다 (RarityBadge·BadgeLevelChip sm 승격)

## 핵심 요약

- 요구사항: 프로필 피드 행에서 한 줄에 놓이는 등급 칩(글자 8px, 높이 16px)과 «마지막 파편!» 칩(글자 12px, 높이 20px)의 크기를 맞춘다. 서비스 약 18곳이 쓰는 sm 크기가 바뀌므로 파급 범위를 채원이 판정한다.
- 구현 계획: 미정(착수 전 규모 판정).
- 관련 파일: `jam-web/src/components/ui/BadgeGridCard.tsx` 근처의 `RarityBadge`·`BadgeLevelChip`(정의 위치는 착수 때 확인), `jam-web/design-system/components/cards/RarityBadge.*`, `BadgeLevelChip.*`

## 배경 / 문제 정의

티켓 20261106_2252 실측: 등급 칩 Epic·Lv.7은 높이 16px·글자 8px, 마지막 파편 칩은 높이 20px·글자 12px로 4px 차이가 났다(3단계 때 티켓에 적은 11px가 아니라 실제로는 8px). 상위 티켓 3단계 잔여 이슈 «칩 12px 한 크기»의 후속이다. 사용자 결정이 필요한 변경이라 별도 티켓으로 둔다.

## 완료 조건

- 행 안에서 모든 칩의 글자가 12px이고 높이가 같다.
- 서비스에서 sm 칩이 쓰이는 곳의 줄바꿈·넘침이 깨지지 않는다(채원 파급 판정과 사용자 승인 후).
