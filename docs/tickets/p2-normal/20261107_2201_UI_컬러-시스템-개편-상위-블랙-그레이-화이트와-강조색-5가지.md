# [UI] 컬러 시스템 개편 (상위): 블랙·그레이·화이트와 강조색 5가지

## 핵심 요약
- 요구사항: 디자인 시스템의 강조색·보조색을 걷어내고 블랙·그레이·화이트 체계로 바꾼다. 강조색 5가지(`--jam-red`·`--jam-yellow`·`--jam-green`·`--jam-purple`·`--jam-blue`)는 토큰만 만들고 아직 어디에도 쓰지 않는다(카드 포함, 사용처는 사용자가 따로 지정).
- 구현 계획: 하위 티켓을 순서대로 진행한다. ① `20261107_2202` 토큰·공용 컴포넌트(ds, CLOSED) ② `20261107_2203` 서비스 화면 카드 외곽선·하드코딩 색 ③ `20261107_2246` 약해진 상태 신호 정리 ④ `20261107_2247` 어드민. ③·④는 1회차 머지 뒤 측정(2026-11-07)으로 ②에서 분리했다.
- 관련 파일: 하위 티켓 참고. 확정 시안: https://claude.ai/artifact/FCSEicJiJfcPm2rapFKqxy (3판)

## 배경 / 문제 정의
지금 디자인 시스템은 크림 바탕(#f1f0eb)과 초록 강조색(#19b551·#0e7a38), 보조색 6가지(`--accent-content-*`)를 쓴다. 사용자가 2026-11-07 대화에서 강조색을 컨텐츠별로 직접 정하기로 하고, UI의 강조는 모두 블랙으로 바꾸기로 결정했다.

## 확정 스펙 (2026-11-07 사용자 결정)
1. 새 토큰: `--jam-red #FF1D1D`, `--jam-yellow #FEC100`, `--jam-green #5BEA07`, `--jam-purple #BA8AF7`, `--jam-blue #0695EC`. 이름은 문서·코드 모두 하이픈 형식. 정의만 하고 소비처는 만들지 않는다.
2. 강조 UI는 블랙: CTA(기존 강조색 버튼) #171717 바탕 + #fcfcfc 글자. `--accent`·`--accent-soft`·`--accent-soft-hover`·`--link`는 블랙/그레이로. `--accent-content-*` 6색은 없앤다.
3. 상태색·진행 막대는 블랙/그레이: success·danger #171717, warning #525252, progress-done #171717, progress-short #737373, progress-latest #525252.
4. 그대로 둔다: `--point-text` #ff4400, `--rarity-*` 4색, `--capsule-*`.
5. 바탕: 전체 페이지(서비스 열 바깥) #E6E6E6, 서비스 영역 #FFFFFF. 크림·베이지(#f1f0eb·#e9e7e0·#cfc9b4)는 없애고 테두리·구분선은 #e5e5e5.
6. 카드: 외곽선을 모두 없애고 면 #F7F7F7(`--card-bg`).
7. 보조 버튼(윤곽선형·연한 면형): 외곽선 없이 면 #E5E5E5(`--btn-secondary`), 글자 블랙.

8. 모양 태그(ShapeTag)는 디자인 시스템에서 제거한다.
9. 어드민 화면도 개편 범위에 넣는다(2회차).
