## 배경 / 문제 정의
상위 티켓 참고. 화면 대부분은 역할 토큰(`--accent`·`--link`·`--border`·`--background` 등)을 거쳐 색을 받으므로, 토큰 값과 공용 컴포넌트를 먼저 바꾸면 화면 대부분이 한 번에 바뀐다.

## 구현 계획
1. `colors.css` 값 교체
   - 바탕: `--background` #ffffff(서비스 영역), 새 `--page-bg` #e6e6e6(서비스 열 바깥), `--background-secondary` #f5f5f5, `--surface` #ffffff, `--surface-transparent` rgba(255,255,255,0), 새 `--card-bg` #f7f7f7, 새 `--btn-secondary` #e5e5e5
   - 선: `--border`·`--field-border`·`--separator` #e5e5e5, `--default`·`--default-soft` #f5f5f5
   - 강조: `--accent` var(--base-neutral-900), `--accent-foreground` var(--snow), `--accent-soft` #f5f5f5, `--accent-soft-hover` #e5e5e5, `--link` var(--base-neutral-900)
   - 상태: `--success`·`--danger` var(--base-neutral-900), `--warning` #525252, 진행 막대 `--progress-done` #171717·`--progress-short` #737373·`--progress-latest` #525252·`--progress-latest-soft` rgba(82,82,82,.18)·`--progress-track` #e5e5e5. `--progress-sweep`가 지운 색을 참조하면 그레이 계열로 바꾼다
   - 새 강조색 5개 `--jam-red` 등을 추가하고 "정의만, 소비처 없음(사용처는 사용자가 지정)" 주석을 단다
   - `--accent-content-*` 6줄 삭제, `--point-text: #ff4400`(리터럴), `--rarity-*`·`--capsule-*`는 손대지 않는다
   - 크림·베이지 값을 전제로 한 주석(대비 수치 등)은 새 값 기준으로 고친다
2. `globals.css`: `html`·`body` 바탕을 `var(--page-bg)`로. `@theme`에 새 토큰 매핑을 추가하고 지운 토큰 매핑을 없앤다
3. `layout.tsx` 서비스 열 래퍼에 `bg-background`(흰색)를 명시해, 430px 바깥만 #E6E6E6이 보이게 한다. 어드민도 개편 대상이지만(사용자 결정) 어드민 화면별 정리는 2회차 몫이다. 1회차에서는 어드민이 토큰 교체를 그대로 따르게 두고 별도 보존 처리를 하지 않는다
4. `Card.jsx` default: `background: var(--card-bg)`, 외곽선 제거(박스 크기를 지키려면 `1px solid transparent`). tint·inverse는 그대로. 주석의 "크림 바탕" 설명을 새 규칙으로 바꾼다
5. `Button.jsx` light: primary는 토큰 교체로 자동 블랙, secondary `background: var(--btn-secondary)`, outline은 외곽선 없이 secondary와 같은 면, danger는 `var(--danger)` 바탕 + `var(--snow)` 글자(블랙 위 블랙 글자 방지). ghost는 `--link`가 블랙이 되므로 그대로
6. ShapeTag를 디자인 시스템에서 제거한다(사용자 결정 2026-11-07). 컴포넌트 파일 4개를 지우고 「관련 파일」의 참조를 모두 정리한다
7. `--accent-content-*` 소비 화면 4곳을 블랙/그레이 토큰으로 바꾼다(초록 체크·완료 표시는 `--foreground`, 파랑은 `--muted` 등 의미에 맞게)
8. 스토리·프롬프트 문서·매니페스트를 새 토큰에 맞춘다. `Colors.stories.tsx`에 강조색 5개와 `--card-bg`·`--btn-secondary`·`--page-bg`를 보이고 지운 토큰을 뺀다
