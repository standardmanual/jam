## 1회차 리뷰에서 넘어온 점검 (민지·채원②, 2026-11-07)
- 완료 칩 통일: `collections/[id]` 획득 칩(블랙 면+흰 글자), 미션 두 화면의 달성 칩(`bg-btn-secondary`, 미달성 `bg-border`와 같은 #e5e5e5), voc 상태 칩(답변완료 `bg-default`는 카드 위에서 안 보임, 확인중과 구분 안 됨)을 「완료 칩」 하나로 정한다. 파일: `voc/page.tsx` 50행 근처, `MissionDetailClient.tsx` 615행, `MissionStatusClient.tsx` 322·534행
- 오류 표시: success·danger가 둘 다 #171717이므로 Input·Select·Textarea 오류 상태에 문구가 `aria-describedby`로 연결돼 있는지 확인한다
- 링크: `--link`가 블랙이 됐으므로 색만으로 링크를 구분하던 곳에 밑줄·굵기 단서를 준다
- 카드 위 연한 면: `--accent-soft`·`--default`(#f5f5f5)를 카드(#f7f7f7) 안에서 쓰는 곳은 `--btn-secondary`로 한 단계 어둡게 바꾼다
- 진행 막대 토큰: `--progress-*` 리터럴을 `var(--base-neutral-*)` 참조로 바꾼다
- 알려진 한계(사용자 확인 필요): `--field-border` #e5e5e5는 흰 바탕 대비 약 1.26:1, 카드와 흰 바탕은 약 1.07:1이다(계산값). 실화면을 본 뒤 사용자에게 조정 여부를 묻는다
