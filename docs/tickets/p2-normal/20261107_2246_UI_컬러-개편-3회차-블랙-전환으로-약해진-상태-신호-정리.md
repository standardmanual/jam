## 점검 항목 (1회차 리뷰, 2026-11-07) (민지·채원②, 2026-11-07)

- 링크: `--link`가 블랙이 됐으므로 색만으로 링크를 구분하던 곳에 밑줄·굵기 단서를 준다
- 카드 위 연한 면: `--accent-soft`·`--default`(#f5f5f5)를 카드(#f7f7f7) 안에서 쓰는 곳은 `--btn-secondary`로 한 단계 어둡게 바꾼다
- 진행 막대 토큰: `--progress-*` 리터럴을 `var(--base-neutral-*)` 참조로 바꾼다
- 알려진 한계(사용자 확인 필요): `--field-border` #e5e5e5는 흰 바탕 대비 약 1.26:1, 카드와 흰 바탕은 약 1.07:1이다(계산값). 실화면을 본 뒤 사용자에게 조정 여부를 묻는다

## 목록 행 3-5배치에서 넘어온 점검 (카리나, 2026-11-08)

티켓 20261107_1947(순위·달성 행을 `ListRow`로 옮김)의 실렌더에서 나온 사실이다. 사용자가 이 건을 컬러 개편 쪽에서 정하기로 했다(2026-11-08).

- 컬러 개편 2회차까지 반영된 상태에서 미션 현황 달성 행(`AchievementRow`, 폭 320px)의 «나» 칩(`ListRowChip` accent)과 «미달성» 칩(`ListRowChip` neutral)의 면 색이 둘 다 `rgb(245, 245, 245)`로 같았다. «달성» 칩(accent)도 같은 색일 가능성이 높아, 달성과 미달성이 문구로만 구분된다. 달성 상태의 행은 테스트 데이터에 없어 화면으로 확인하지 못했다.
- 3-5배치는 달성 칩을 `--accent-content-green`에서 `ListRowChip` accent로 바꾸는 것을 사용자 승인(2026-11-07)으로 받아들였다. 컬러 개편 전에는 accent가 옅은 색이었지만 지금은 neutral과 같은 회색이라 승인 당시 의도보다 변화가 크다.
- 확인할 것: 컬러 개편 뒤 `ListRowChip`의 accent·neutral 톤이 달성 상태 신호로 구분되는지(색 또는 다른 단서). 구분이 안 되면 칩 톤 값은 컬러 개편이, 칩 사용 방식(달성은 accent 유지 등)은 `AchievementRow`(`jam-web/src/app/(main)/missions/[id]/status/MissionStatusClient.tsx`)에서 정한다. «나» 칩도 같은 회색이라 이름 옆에서 눈에 띄는지 함께 본다.
- 이 건은 3-5배치 쪽에서 토큰·공용 컴포넌트를 고치지 않는 범위라 컬러 개편 3회차로 넘긴다.
