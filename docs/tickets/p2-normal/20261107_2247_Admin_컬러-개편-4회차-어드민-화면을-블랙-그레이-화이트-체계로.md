# [Admin] 컬러 개편 4회차: 어드민 화면을 블랙·그레이·화이트 체계로

## 핵심 요약
- 요구사항: 사용자 결정(2026-11-07)으로 어드민도 컬러 개편에 넣는다. 어드민은 shadcn/ui 표준을 유지하면서 shadcn 토큰(`globals.css` 120~151·524~553줄의 `--primary`·`--accent`·`--ring`·`--chart-*`·`--sidebar-*` 등)과 어드민 화면의 크림·초록 잔여 색을 블랙·그레이·화이트로 맞춘다. 카드 외곽선 제거를 어드민에도 적용할지는 시작 전에 사용자에게 확인한다(어드민 카드·표는 shadcn 표준 외곽선을 쓴다).
- 구현 계획: 시작 전에 카리나가 측정한다. 2026-11-07 측정 시 어드민에서 `border border-border` 계열을 쓰는 파일은 91개(`src/app/admin` 44, `src/components/admin` 47)였다.
- 관련 파일: 측정 후 채운다.

## 사용자 결정 (2026-11-08)
- 어드민의 오류·경고·완료 상태색(빨강·노랑·초록, Tailwind `red-*`·`amber-*`·`emerald-*`와 `--destructive`)은 **유지**한다. 운영 도구에서 상태를 한눈에 구분하는 것이 중요하다
- 어드민의 카드·표·입력 외곽선(shadcn 표준)은 **유지**한다

## 측정 (2026-11-08)
- 어드민은 `globals.css` 128줄 `[data-admin-theme]` 스코프에서 shadcn 프리셋 값을 따로 정의한다. 바탕 `oklch(1 0 0)`(흰색), 기본 버튼 `--primary` `oklch(0.216 0.006 56)`(거의 블랙), 테두리 `oklch(0.923 0.003 48.7)`(옅은 회색)이라 이미 블랙·그레이·화이트 계열이다(채도 0.003~0.013)
- 어드민 화면 파일에 크림·초록 옛 hex는 없다(`logo3dConfig.ts`의 3D 로고 설정값만 있고 이는 UI 색이 아니다)
- 따라서 결정대로라면 코드 변경이 거의 필요 없다. 할 일은 1~3회차 토큰 변경(서비스 공용 토큰 `--card-bg`·`--background-secondary`·`--field-border` 등)이 어드민에 번진 곳이 없는지 로컬 `ADMIN_EMAILS` 실렌더로 확인하는 것이다

## 완료 조건
- 상태색·외곽선은 유지되고, 어드민 화면에 1~3회차 토큰 변경으로 깨진 곳이 없다(어드민 대시보드·배지·컬렉션·운영 화면 실렌더)
- 어드민 실렌더를 로컬 `ADMIN_EMAILS` 셸 변수로 확인했다
- `scripts/verify.sh` 통과
