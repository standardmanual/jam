# [UI] 프로필 화면의 탭을 걷고 «팔로워 · 팔로잉 · 포인트» 숫자 줄로 바꾼다

## 핵심 요약
- 사용자 요청(2026-11-08, https://stage.j-a-m.app/god 기준): 프로필의 통계 탭 카드(배지·컬렉션·팔로워·팔로잉)를 없애고, 이름 아래에 숫자 줄 «팔로워 nnn,nnn  팔로잉 nnn,nnn  포인트 nnn,nnn»을 둔다. 숫자를 누르면 캡슐 바 아래에 해당 리스트를 기존 화면을 활용해 보여 준다.
- 참고 모양: 인스타그램식 한 줄 «게시물 **641**   팔로워 **586**   팔로우 **3344**» (라벨은 보통 굵기, 숫자는 굵게, 항목 사이 넓은 간격).

## 사용자 결정 (2026-11-08)
1. 제거 범위는 **프로필 안만**: 프로필의 배지 탭·컬렉션 탭 내용과 `/[username]/collections` 화면을 없앤다. 하단 내비의 `/badges`, 컬렉션 상세 `/collections/[id]`는 그대로 둔다. 없어진 곳으로 가던 링크는 프로필 기본 화면(`/{username}`)으로 보낸다.
2. 숫자 표기: 999,999까지는 쉼표(`586`, `12,345`), 1,000,000부터 `1.0M`·`1.2M`(소수 한 자리).
3. 위치: 이름 아래, 지금 포인트 줄 자리. 편집 버튼은 그 줄 오른쪽 끝에 유지한다. **포인트는 본인 프로필에서만** 보인다(지갑은 본인 전용). 다른 사람 프로필에는 팔로워·팔로잉만 보인다.
4. 리스트 동작: 기본은 지금처럼 활동 피드다. 숫자를 누르면 그 리스트로 바뀌고, 열린 숫자는 선택 표시를 한다. 같은 숫자를 다시 눌러도 닫히지 않는다(다른 숫자를 누르면 그 리스트로 바뀜). 피드로 돌아가는 길은 지금처럼 아바타·이름 링크(`clearProfileHash`)다. 주소 해시는 `#followers`·`#following`·`#points`.
5. (2026-11-08 추가) **다른 사람 프로필의 기본 화면은 배지 리스트**다. 해시 없이 타인 프로필에 들어오면 활동 피드 대신 그 사람의 배지 그리드(지금 배지 탭 내용: `badgeItems` + `BadgeGridCard` 3열, 빈 상태 `emptyBadgesOther`)를 보여 준다. 팔로워·팔로잉을 누르면 그 목록으로 바뀌고, 아바타·이름을 누르면 배지 리스트로 돌아간다. 본인 프로필의 기본 화면은 지금처럼 활동 피드다. 배지 숫자는 숫자 줄에 넣지 않는다.

## 완료 조건
- 타인 프로필에 해시 없이 들어오면 배지 그리드가 보이고, 본인 프로필 기본은 활동 피드다.
- 프로필에 배지·컬렉션·팔로워·팔로잉 탭 카드가 없다. 이름 아래 숫자 줄이 있고, 본인은 «팔로워 · 팔로잉 · 포인트», 타인은 «팔로워 · 팔로잉»이다.
- 숫자는 쉼표 표기, 백만 이상 `n.nM`. 라벨은 보통 굵기, 숫자는 굵게(참고 이미지).
- 숫자를 누르면 캡슐 바 아래(타인은 헤더 아래)에 팔로워/팔로잉 목록(기존 목록 행), 포인트 내역(기존 /points 목록)이 보인다. 열린 숫자는 선택 표시가 있다.
- `/[username]/collections`가 없고, 그리로 가던 알림·뒤로가기 링크는 프로필 기본 화면으로 간다.
- 새 색 값·`--jam-*` 토큰 없음. `scripts/verify.sh` 통과.

## 배경 / 문제 정의
- 통계 탭 카드가 배지·컬렉션까지 넷이라 프로필이 무겁고, 배지·컬렉션은 하단 내비 화면과 겹친다.
