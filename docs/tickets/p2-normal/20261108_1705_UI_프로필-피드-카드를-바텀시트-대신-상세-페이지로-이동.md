# [UI] 프로필 피드 카드를 누르면 바텀시트 대신 상세 페이지로 이동한다

## 핵심 요약
- 요구사항(사용자, 2026-11-08): 프로필 페이지의 각 피드를 누르면 바텀시트로 열지 말고 해당 콘텐츠의 상세 페이지로 이동시킨다. 애매한 곳은 먼저 물어 확인받는다.
- 확정한 이동 대상(사용자 답변)
  - 배지 획득: 배지 상세(`/badges/{badge_id}`, 타인 프로필이면 `?u=`).
  - 아이템 픽업: 그 아이템 배지의 상세.
  - 아이템 드랍: 사용자는 «해당 체크인 지점을 누른 드랍 화면»을 원했다. 그런데 드랍 피드에는 지점 정보가 없다. 피드를 기록하는 `recordItemDroppedFeed`(`lib/drop-engine/issueFollowUp.ts`)가 `poi_name: ''`로 싣고 지점 id는 저장하지 않으며, 이 드랍은 Strava 동기화·캡슐 지급이라 어느 지점과도 연결돼 있지 않다. 사용자가 «엔진도 고쳐 지점을 기록한다»를 골랐지만 기록할 지점이 없어 불가능하다. 그래서 이번에는 아이템 픽업과 같은 배지 상세로 보낸다(되돌리기 쉬운 기본값).
  - 챕터 오름: 상세 페이지가 없어 내 프로필 맨 위로 올린다(움직임 줄이기 설정이면 바로 올림).
  - 미션 참여·완료·취소: 미션 상세(이미 그랬다).
  - 컬렉션 완성: 컬렉션 상세(`/collections/{collection_id}`).
  - 친구 소식(`/feed`): 종류와 상관없이 그 친구의 프로필(`/{username}`).
  - 타인 프로필의 배지 그리드 카드: 그 배지의 상세(`?u=`).
- 관련 파일: `jam-web/src/app/(main)/FeedSection.tsx`(`feedTarget`·`goToFeedTarget` 추가, `handleCardClick`, 시트 상태·렌더 제거, `friendProfileHrefs` prop), `jam-web/src/app/(main)/profile/ProfileClient.tsx`(`handleCardClick`, 시트 제거), `jam-web/src/app/(main)/feed/page.tsx`(친구 user_id→/username 맵), `jam-web/src/app/(main)/FeedSection.test.tsx`, `docs/service/prd/chapter/PRD.md` 189줄

## 완료 조건
- 프로필(내·타인)의 피드 카드와 타인 배지 그리드 카드를 눌러도 바텀시트가 열리지 않고 위 표대로 이동한다. 친구 소식 카드는 그 친구의 프로필로 간다.
