# [Content] 컬렉션과 아이템 배지에 시선과 동작 칸을 더하고 원고 문구를 채운다

## 핵심 요약

- 요구사항: JAM 2.0 원고에 아이템 배지마다 적어 둔 «시선과 동작»을 아이템 배지와 컬렉션의 DB 정보에 넣는다(사용자 요청 2026-11-08).
- 컬렉션 단위 문구는 원고에 없었다. 사용자 지시(2026-11-08)에 따라 아이템 배지의 시선과 동작을 쓴 방식에 맞춰 컬렉션 50개의 문구를 새로 썼다(윈터 초안, 트라이브별 5회).
- 현재: 완료. 컬렉션 문구 50개를 사용자가 그대로 확정했다(2026-11-08).

## 한 일

1. 원고 `docs/plan/jam2/tribe-rethink/manuscript/`의 01~05 원고 6.x절 머리에 «시선과 동작(컬렉션)» 한 줄씩 50개를 넣었다.
   - 쓰는 방법: 컬렉션의 아이템 9개를 원고 순서대로 훑는 하나의 시선과 동작으로 잇는다. 아이템 문장과 같은 «~하고, ~를 거쳐, ~에서 멈춘다» 모양이고, 아이템 3~4개의 구체적인 사물로 경로를 만든다. 사물은 그 컬렉션 아이템의 시선과 동작에 나오는 것만 쓴다.
2. 마이그레이션 330: `item_books.gaze_motion`, `badges.gaze_motion`(text, NULL 허용)을 더했다. 되돌림은 `330_gaze_motion_columns_down.sql`.
3. 데이터: 아이템 450개 × 등급 4 = 배지 1800행, 컬렉션 50행을 채웠다. 칸 추가는 MCP로, 데이터는 같은 원고에서 뽑은 값을 supabase-js로 넣었다(마이그레이션 파일에도 같은 값을 남겼다).
4. `jam-web/src/types/database.generated.ts`에 두 칸을 더했다. 타입 검사 통과.
5. `docs/service/prd/02_DATA_MODEL.md` 4절에 칸 설명을 더했다.

## 실행 확인 (2026-11-08)

- `gaze_motion`이 채워진 컬렉션 50, 배지 1800행, 서로 다른 (컬렉션, 아이템) 450.
- 원고의 (컬렉션 이름, 아이템 이름) 450쌍이 모두 DB의 삭제되지 않은 배지 4행씩과 짝지어졌다(빠진 쌍 0).
- 두 칸은 새 칸이라 기존 데이터는 바뀌지 않았다. 칸을 읽는 코드는 없다.

## 완료 기록

- 사용자가 컬렉션 문구 50개를 이대로 확정했다(2026-11-08). 나중에 고치면 원고와 DB(`item_books.gaze_motion`)를 함께 고친다.
