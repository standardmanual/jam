# [UI] 활동 묶음 카드는 누르면 아래에 카드를 나열하지 않고, 누른 그 카드가 펼쳐진다

## 핵심 요약

- 요구사항: 내 프로필 «전체» 탭의 활동 묶음 카드(예: «Evening Trail Run / 배지 3개와 50 포인트를 획득했어요»)를 누르면, 지금은 묶음 카드 아래에 들여쓴 별도 카드(FeedCard) 여러 장이 나열된다. 이를 **누른 묶음 카드 자체가 늘어나며 그 안에 하위 항목이 들어가는** 방식으로 바꾼다. 펼친 뒤에도 화면에는 카드 한 장으로 보여야 한다.
- 구현 계획: `ActivityGroupCard`의 구조를 바꾼다. 지금은 헤더 `ListRow`와 그 아래 패널(`t-acc-panel`)이 형제이고, 패널 안에 테두리를 가진 `FeedCard`가 각각 그려진다. 바깥 카드 면(테두리·배경·모서리)이 헤더와 패널을 함께 감싸고, 하위 항목은 그 면 안에서 별도 카드 테두리 없이 그려지도록 한다. 어떤 컴포넌트·토큰을 쓸지는 채원① 판정을 따른다.
- 관련 파일:
  - `jam-web/src/app/(main)/FeedSection.tsx` — `ActivityGroupCard`(약 758~831행), 패널 안 `FeedCard` 나열(약 821~826행), `FeedCard`(약 551행~)
  - `jam-web/src/components/transitions.css` — `.t-acc`·`.t-acc-panel`·`.t-acc-panel-inner`(약 191~235행) 높이 전환
  - `ListRow` 컴포넌트(MODULAR) — 카드 면을 그리는 쪽. 하위 항목을 테두리 없이 그릴 변형이 있는지 채원이 판정한다

## 배경 / 문제 정의

사용자 지적(2026-11-08, 스크린샷 첨부): 묶음 카드를 누르면 새 카드 UI가 아래에 나열되어, 묶음 카드와 하위 카드가 서로 다른 덩어리로 보인다. 사용자가 기대하는 동작은 누른 카드가 그 자리에서 확장되는 것이다.

## 상세 요구사항

### UI/UX 관점
1. 펼친 상태에서 묶음 헤더와 하위 항목이 **한 카드 면 안에** 있다. 하위 항목마다 별도의 카드 테두리가 보이지 않는다(항목 사이 구분은 채원 판정).
2. 하위 항목이 지금 보여 주는 정보(배지 이미지, «×N», 이벤트 라벨, 제목, 부제, 칩, 시각)는 그대로 보인다.
3. 하위 항목을 누르면 지금처럼 해당 상세 페이지로 간다(`onItemClick`).
4. 묶음 헤더를 다시 누르면 접힌다. 높이 전환 애니메이션과 접힌 동안 `inert` 처리(포커스·보조기술 차단)는 유지한다.
5. `aria-expanded`·`aria-controls` 연결은 유지한다.
6. 단건 카드(묶음이 아닌 카드)의 모양은 바뀌지 않는다.
7. 다른 사람 프로필의 피드·친구 소식에서도 같은 `ActivityGroupCard`를 쓰므로 함께 바뀐다(의도한 범위).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 펼친 묶음 카드의 DOM에서, 하위 항목이 묶음 카드의 바깥 카드 면 요소 안에 들어 있다(헤더와 같은 테두리 상자의 자손).
- 하위 항목에는 단독 카드 테두리가 그려지지 않는다.
- 헤더 클릭으로 `aria-expanded`가 true/false로 바뀌고, 접힌 상태에서 패널 내부가 `inert`다.
- 하위 항목 클릭 시 `onItemClick`이 그 항목으로 호출된다.
- `scripts/verify.sh` 통과.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤 push 전)
- 메인 트리 next dev에서 내 프로필 «전체» 탭의 묶음 카드를 펼쳐, 카드 한 장이 늘어나는 모양인지 스크린샷으로 확인한다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
`ActivityGroupCard`를 MODULAR `Card` 한 장으로 감쌌다. 헤더와 펼침 패널이 같은 카드 면 안에 있고, 하위 항목은 `FeedCard`에 새로 둔 선택 prop으로 `ListRow tone="flat"` + `separator`를 써서 면·테두리·들여쓰기 없이 구분선으로만 나뉜다. 패널 위쪽에 1px `--separator`를 두고 마지막 항목에는 구분선이 없다. 단건 카드는 prop 기본값이 없어 모양이 그대로다. 높이 전환(`transitions.css`)·`inert`·`aria-expanded`/`aria-controls`는 그대로다.

채원① 판정: 재사용(신규 컴포넌트·variant·토큰 없음, MODULAR 수정 없음). 바깥 면은 Card, 헤더·하위 항목은 ListRow flat. 헤더 쉐브론은 눈에 보이는 신규 요소라 제외하고 후속 티켓으로 분리했다. 연결 범위: `ui` 유형이라 해당 없음.
