# [UI] 간격 역할 토큰을 만들고 클래스 대응표를 문서에 남긴다 (1회차, 화면 변경 없음)

## 핵심 요약

- 요구사항: 상위 티켓 20261108_1926의 확정 값을 이름 붙은 토큰으로 `spacing.css`에 추가하고, 각 값에 대응하는 Tailwind 기본 클래스를 문서에 표로 남긴다. 화면·컴포넌트의 실제 간격은 이 회차에서 바꾸지 않는다(눈에 보이는 변화 없음).
- 구현 계획: `jam-web/design-system/tokens/spacing.css`에 `--spacing-20: 20px`과 역할 토큰 14개를 더한다. 클래스는 기존 규칙(`globals.css` 108~111줄: 클래스는 Tailwind 기본 유틸리티, 변수는 클래스 밖에서만)을 지킨다. 그래서 Tailwind 별칭(`@theme`)은 만들지 않는다.
- 관련 파일: `jam-web/design-system/tokens/spacing.css`(22~25줄 layout 토큰 부근), `jam-web/design-system/foundations/Spacing.stories.tsx`(역할 이름과 클래스 대응 구획 추가), `jam-web/design-system/readme.md`(간격 절의 대응표), `jam-web/src/app/globals.css` 108~111줄 주석(대응표 위치 한 줄 안내). `npm run ds:check`와 `scripts/verify.sh` 통과가 필요하다.

## 배경 / 문제 정의

상위 티켓 20261108_1926에서 사용자가 간격 눈금을 확정했다. 화면을 고치기 전에 값에 이름을 붙이고 클래스 대응을 한 곳에 적어, 2~5회차가 같은 표를 보고 작업하게 한다.

## 상세 요구사항

추가할 역할 토큰(값은 확정, 이름은 아래를 쓴다. 괄호는 대응하는 Tailwind 기본 클래스):

| 이름 | 값 | 클래스 대응 |
|---|---|---|
| `--page-x` | 16 | `px-4` |
| `--page-top` | 16 | `pt-4` |
| `--page-bottom` | 24 | `pb-6` |
| `--gap-section` | 20 | `gap-5` · `space-y-5` |
| `--gap-section-lg` | 24 | `gap-6` |
| `--gap-group` | 12 | `gap-3` |
| `--gap-text` | 8 | `gap-2` |
| `--gap-label` | 4 | `gap-1` |
| `--gap-card` | 8 | `gap-2` |
| `--gap-card-detail` | 12 | `gap-3` |
| `--card-padding` | 16 | `p-4` |
| `--card-padding-row` | 12 16 | `py-3 px-4` |
| `--gap-field` | 16 | `gap-4` |
| `--gap-actions` | 8 | `gap-2` |

- `--layout-card-padding`(24)와 `--layout-section-gap`(48)은 이 회차에서 바꾸지 않는다. 3회차에서 `--layout-card-padding`을 `var(--card-padding)`로 바꾼다. `--spacing-32`·40·48·64·96은 지우지 않고 주석으로 「화면은 직접 쓰지 않는다(5회차에서 검사)」를 단다.
- 기존 사용처(FeedSection 469줄, today 카드의 `var(--spacing-32)`, EmptyState의 `--layout-section-gap`)는 이 회차에서 건드리지 않는다.

## 완료 조건

- `spacing.css`에 위 14개 토큰과 `--spacing-20`이 있고, 값이 표와 같다.
- Storybook 간격 구획과 DS readme에 같은 대응표가 있고, 세 곳(CSS·스토리·readme)의 값이 일치한다.
- 화면과 컴포넌트의 계산된 간격은 바뀌지 않는다(기존 토큰 값 무변경, 신규 토큰은 참조하는 곳이 없음).
- `npm run ds:check`와 `scripts/verify.sh`가 통과한다.
