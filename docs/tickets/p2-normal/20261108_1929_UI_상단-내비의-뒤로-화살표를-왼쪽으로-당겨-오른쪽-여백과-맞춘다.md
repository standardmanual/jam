# [UI] 상단 내비의 뒤로 화살표를 왼쪽으로 당겨 오른쪽 여백과 맞춘다

## 핵심 요약

- 요구사항: 상단 내비(TopNav)의 «< 뒤로»가 오른쪽 프로필 사진보다 안쪽에서 시작해 좌우 여백이 맞지 않는다(사용자 지적, 2026-11-08). 화살표와 제목을 왼쪽으로 당겨 오른쪽 여백과 맞춘다.
- 구현 계획: DS `TopNav.jsx`의 뒤로 버튼(`<a>`·`<button>` 두 곳)에 `marginLeft: -18`을 준다. 터치 영역 44×44는 그대로 두고 위치만 옮긴다.
- 관련 파일: `jam-web/design-system/components/navigation/TopNav.jsx` — 뒤로 버튼 style(약 75~81행, 92~98행)

## 배경 / 문제 정의

헤더 안쪽 여백은 좌우 16px이다. 오른쪽 슬롯(프로필 사진)은 끝에서 16px에 붙는데, 뒤로 버튼은 44px 터치 영역 가운데에 24px 아이콘을 두고 아이콘 안에서도 선이 x=9에서 시작해, 눈에 보이는 화살표 왼쪽 끝이 약 34px에 있었다.

## 완료 조건
- 375px 폭에서 눈에 보이는 화살표 왼쪽 끝이 헤더 왼쪽에서 16px 안팎이고, 오른쪽 슬롯의 오른쪽 여백(16px)과 같다.
- 뒤로 버튼의 크기는 44×44 그대로다. 제목은 화살표와의 간격을 유지한 채 함께 당겨진다.
- 로고를 쓰는 탭 최상위 화면의 헤더는 바뀌지 않는다.
