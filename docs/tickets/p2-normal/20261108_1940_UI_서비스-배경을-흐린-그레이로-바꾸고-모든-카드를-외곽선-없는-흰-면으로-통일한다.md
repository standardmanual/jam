# [UI] 서비스 배경을 흐린 그레이(#f5f5f5)로 바꾸고, 모든 카드를 외곽선 없는 흰 면(#ffffff)으로 통일한다

## 핵심 요약

- 요구사항(사용자, 2026-11-08): ① 서비스 영역(430px 서비스 열)의 배경색을 #f5f5f5로 바꾼다. ② 모든 카드의 면을 #ffffff로 한다. ③ 모든 카드의 외곽선을 **컴포넌트 근원에서** 없앤다. 호출부마다 덮어쓰는 방식이 아니라 토큰·MODULAR 컴포넌트 정의에서 고쳐, 이후 어떤 화면에서 카드를 써도 외곽선이 없게 한다.
- 구현 계획:
  1. 토큰(`jam-web/design-system/tokens/colors.css`): `--background` #ffffff → #f5f5f5(= `--base-neutral-100`), `--card-bg` #f7f7f7 → #ffffff. 새 토큰은 만들지 않는다.
  2. MODULAR 카드 계열 컴포넌트에서 카드 외곽 테두리(`1px solid var(--border)` 또는 투명 테두리)를 제거한다: `cards/Card.jsx`, `cards/MissionCard.jsx`, `cards/LockedTile.jsx`, `patterns/ListRow.jsx`(default tone 면), `patterns/BadgeGridCard.jsx`, `patterns/CollectionGridCard.jsx`, 그 밖에 채원①이 카드로 판정하는 컴포넌트. 각 Story가 새 모양을 보여 주는지 확인한다.
  3. 서비스 래퍼·서비스 전용 카드: `src/components/ui/ListRow.tsx`, `src/components/ui/BadgeGridCard.tsx`, `src/components/ranking/RankingListRow.tsx`, `src/components/today/DomeCard.tsx`, `src/components/inventory/InventoryGrid.tsx` 등에서 카드 외곽선을 걷어낸다.
  4. 호출부 덮어쓰기 제거: `src/app/(main)/FeedSection.tsx` `ActivityGroupCard`의 Card style(흰 면·테두리 덮어쓰기, 약 796~802행)을 지우고 Card 기본값을 쓴다.
  5. 지금 `--background`(흰색) 위에서 흰 면이라 구분이 필요 없던 곳, 반대로 `--background`를 "흰 면"의 뜻으로 쓰던 곳(헤더·시트·입력칸 등)이 배경 변경으로 회색이 되는지 채원①이 목록으로 판정한다.
- 관련 파일: 위 목록. 테두리 사용처는 `grep -rln "var(--border)\|var(--card-bg)" jam-web/design-system/components jam-web/src`로 찾은 28개 파일이 후보다(입력칸·체크박스·진행 막대·구분선처럼 카드가 아닌 테두리는 제외).

## 배경 / 문제 정의

지금 서비스 바탕은 흰색이고 카드 면은 #f7f7f7(Card default) 또는 흰 면 + 1px `--border`(ListRow default 등)로 섞여 있다. 사용자는 바탕을 흐린 그레이로, 카드를 외곽선 없는 흰 면으로 통일하길 원한다.

## 상세 요구사항

### UI/UX 관점
1. 서비스 열 바탕은 #f5f5f5다. 서비스 열 바깥(`--page-bg`)과 어드민(`[data-admin-theme]`)은 바꾸지 않는다.
2. 카드(Card, ListRow default 면, 배지·컬렉션 그리드 카드, 미션 카드, 잠긴 타일, 오늘 화면 카드, 랭킹 행, 인벤토리 칸 등)는 #ffffff 면이고 외곽선이 없다.
3. 입력칸(`--field-border`), 체크박스, 구분선(`--separator`), 진행 막대처럼 카드가 아닌 요소의 선은 그대로다.
4. 카드 안의 회색 면(`--background-secondary` 등)은 그대로다.
5. 대비: #f5f5f5 바탕 위 `--muted`(#666666) 글자의 대비가 4.5:1 이상인지 확인한다.
