# [UI] 서비스 화면의 가로·위·아래 여백을 화면 틀 값으로 통일한다 (2회차)

## 핵심 요약

- 요구사항: 서비스 화면 루트의 여백을 가로 16(`px-4`) · 맨 위 16(`pt-4`) · 맨 아래 24(`pb-6`)로 통일한다. 미션 상세·배지 상세의 가로 24(`px-6`)도 16으로 맞춘다. 구획 사이(gap)와 카드 안·카드 사이 간격은 4회차 범위라 이 회차에서 건드리지 않는다.
- 구현 계획: 아래 「파일별 계획」의 클래스를 그대로 바꾼다. 클래스는 Tailwind 기본 유틸리티만 쓴다(`--page-*` 변수는 클래스 밖용). 로직·문구는 바꾸지 않는다.
- 관련 파일: `jam-web/src/app/(main)/` 아래 아래 표의 15개 파일. 깨질 수 있는 시험은 해당 화면의 `*.test.tsx`(클래스 문자열을 검사하는 곳). `collections/[id]/__tests__/UnslotAllSheet.test.tsx`의 `px-6`은 시트라 대상이 아니다.
