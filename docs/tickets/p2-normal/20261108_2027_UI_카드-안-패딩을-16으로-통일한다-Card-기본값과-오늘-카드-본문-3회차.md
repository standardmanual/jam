# [UI] 카드 안 패딩을 16으로 통일한다: Card 기본값과 오늘 카드 본문 (3회차)

## 핵심 요약

- 요구사항: 카드 안 패딩을 24에서 16으로 낮춘다. MODULAR `Card` 기본값(인라인 `padding`)과, 카드 면 패딩을 0으로 두고 본문 칸이 24를 가진 오늘 카드(`today/`)의 본문을 함께 맞춘다. 시트·모달·빈 상태의 안쪽 여백(`--layout-card-padding` 24 사용처)은 카드가 아니므로 바꾸지 않는다.
- 구현 계획: `Card.jsx`가 `--layout-card-padding` 대신 `--card-padding`(1회차에서 만든 16)을 쓰게 한다. `--layout-card-padding` 값(24)은 그대로 둔다. 오늘 카드 본문 칸의 `p-6`을 `p-4`로 바꾸고 관련 설명 주석·DS 문서·스토리·시험을 같은 값으로 맞춘다. 클래스는 Tailwind 기본 유틸리티만 쓴다.
- 관련 파일: 아래 「파일별 계획」. 근거: 상위 티켓 20261108_1926, 아티팩트 https://claude.ai/artifact/Po4G2tVK4P82b1G3MkH5uf

## 완료 조건

- `Card`의 기본 padding이 16이다(`--card-padding` 참조). `--layout-card-padding`은 24 그대로이고 시트·모달·빈 상태의 여백은 바뀌지 않는다.
- 오늘 카드 본문 칸·이미지 위 글 상자·가로 스크롤 줄이 16이고, `ListCard`의 `-mx`와 `px`가 같은 값이다.
- 문서·스토리·시험이 새 값과 일치하고 효력 없던 `py-8`이 사라진다.
- `npm run ds:check`와 `scripts/verify.sh`가 통과한다. 로직·문구는 바뀌지 않는다.
- 실렌더(홈 히어로·진행도, 포인트 잔액, 소개 강조 박스)는 staging 배포 뒤 카리나가 확인한다.
