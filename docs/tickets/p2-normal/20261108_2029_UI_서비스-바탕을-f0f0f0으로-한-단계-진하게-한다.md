# [UI] 서비스 바탕을 #f0f0f0으로 한 단계 진하게 한다

## 핵심 요약

- 요구사항: 티켓 20261108_1940에서 서비스 바탕을 #f5f5f5로 바꿨는데, 흰 카드와의 구분이 약하다(사용자, 2026-11-08). 다섯 단계 샘플(#f5f5f5·#f2f2f2·#f0f0f0·#eeeeee·#ebebeb)을 비교한 뒤 사용자가 #f0f0f0을 골랐다.
- 구현 계획: `jam-web/design-system/tokens/colors.css`의 `--background` 값을 #f0f0f0으로 바꾸고, #f5f5f5를 적어 둔 주석·문서를 맞춘 뒤 `npm run ds:manifest`로 매니페스트를 다시 만든다. 기본 회색 단계에 없는 값이라 리터럴 hex로 둔다(새 토큰 없음).
- 관련 파일: `jam-web/design-system/tokens/colors.css`(38행), `_ds_manifest.json`, 주석: `src/lib/pageBackground.ts`, `src/components/ui/TopNav.tsx`, `src/components/ui/__tests__/bottomSheetFaces.test.tsx`, `design-system/components/cards/Card.prompt.md`·`Card.stories.tsx`

## 완료 조건
- `--background`가 #f0f0f0이고 새 토큰이 없다.
- 375px 로컬 실렌더에서 서비스 열 바탕이 rgb(240, 240, 240), 카드가 흰 면이다.
- #f0f0f0 위 `--muted`(#666666) 대비가 4.5:1 이상이다.
