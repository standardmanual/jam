# [UI] 구획·카드 사이·폼 간격을 확정 값으로 맞춘다: 홈·피드·프로필·포인트·알림 (4회차 a)

## 핵심 요약

- 요구사항: 홈 루트, 오늘 카드 목록, 프로필, 포인트, 알림의 구획 사이·카드 사이·묶음 안 간격을 확정 눈금(구획 20, 같은 목록의 카드 8, 상세 화면의 이어진 카드 12, 묶음 안 12·8·4)에 맞춘다. 클래스 문자열만 바꾸고 로직·문구는 바꾸지 않는다. 4회차는 a·b·c 세 묶음이고 파일이 겹치지 않아 병렬로 진행한다.
- 구현 계획: 아래 「파일별 계획」과 「간격 판정 규칙」대로 바꾼다. 역할이 애매한 컨테이너는 바꾸지 않고 보고한다.
- 근거: 상위 티켓 20261108_1926, 아티팩트 https://claude.ai/artifact/Po4G2tVK4P82b1G3MkH5uf

## 간격 판정 규칙 (클래스는 Tailwind 기본 유틸리티만 쓴다)

| 관계 | 값 | 클래스 |
|---|---|---|
| 성격이 다른 블록·카드 블록 사이(구획) | 20 | `gap-5`·`mt-5`·`mb-5` |
| 큰 구획 전환(읽는 글 화면) | 24 | `gap-6` |
| 같은 목록의 카드·행·타일 사이 | 8 | `gap-2` |
| 상세 화면에서 카드끼리 이어질 때 | 12 | `gap-3` |
| 묶음 안(카드 안 블록 12 · 제목+본문 8 · 라벨+값 4) | 12·8·4 | `gap-3`·`gap-2`·`gap-1` |

- 컨테이너의 역할이 분명할 때만 바꾼다. 역할이 애매하면 바꾸지 말고 summary의 assumptions에 줄 위치와 이유를 적는다(추측으로 바꾸지 않는다).
- 32 이상 값과 임의 px 값을 새로 쓰지 않는다. 로직·문구·카드 안 패딩(3회차 완료)·화면 틀(2회차 완료)은 건드리지 않는다.
- 줄 위치는 2026-11-08 staging 기준이다. 시험이 클래스 문자열을 검사하면 새 값으로 갱신한다.

## 완료 조건

- 위 표의 줄이 규칙에 맞게 바뀌고, 바꾸지 않은 줄은 보고에 이유가 있다.
- `gap-*`·`mt-*`·`mb-*` 중 구획·카드 사이·묶음 안 외의 줄, 로직, 문구, 카드 안 패딩, 화면 틀이 바뀌지 않는다.
- 시험이 새 값과 일치하고 `scripts/verify.sh`가 통과한다.
- 실렌더(stage 375px)는 배포 뒤 카리나가 확인한다.
