# [UI] 구획·카드 사이·폼 간격을 확정 값으로 맞춘다: 미션·배지·컬렉션 상세와 인벤토리 (4회차 b)

## 핵심 요약

- 요구사항: 미션 상세·현황, 배지 상세, 컬렉션 상세, 인벤토리, 조합의 구획 사이·카드 사이·묶음 안 간격을 확정 눈금(구획 20, 같은 목록의 카드 8, 상세 화면의 이어진 카드 12, 묶음 안 12·8·4)에 맞춘다. 클래스 문자열만 바꾸고 로직·문구는 바꾸지 않는다. 4회차는 a·b·c 세 묶음이고 파일이 겹치지 않아 병렬로 진행한다.
- 구현 계획: 아래 「파일별 계획」과 「간격 판정 규칙」대로 바꾼다. 역할이 애매한 컨테이너는 바꾸지 않고 보고한다.
- 근거: 상위 티켓 20261108_1926, 아티팩트 https://claude.ai/artifact/Po4G2tVK4P82b1G3MkH5uf

- 줄 위치는 2026-11-08 staging 기준이다. 시험이 클래스 문자열을 검사하면 새 값으로 갱신한다.
