# [Feature] 믹스 등급 올리기 정책 변경: 6개, 컬렉션 선택 없음 (상위, 3회차)

## 핵심 요약

- 요구사항: 등급 올리기를 같은 등급 아이템 배지 6개(지금 5개)로 바꾸고, 유저가 컬렉션을 고르지 않게 한다. 소속 트라이브의 활성 컬렉션에서 아이템 배지마다 같은 확률로 무작위 발급한다. 같은 등급만 넣는 규칙(첫 재료를 담으면 같은 등급만 활성)은 이미 있고 유지한다.
- 구현 계획: 1회차 서버·API(굴림, 트라이브 단위 후보, 어드민 아이템 길) → 2회차 화면(6칸, 컬렉션 행·시트 삭제, 문구) ∥ 3회차 확률 안내 페이지·정책 대시보드·문서. 2·3회차는 1회차가 반영된 뒤 병렬로 진행한다.
- 하위 티켓: 1회차 20261108_2321(완료), 2회차 20261108_2322, 3회차 20261108_2323(완료).
- DB 변경 없음(`combine_policy.tier_up_probability` 값은 그대로 쓴다).

## 결정

| 항목 | 결정(2026-11-08, 사용자) |
|---|---|
| 재료 | 같은 등급의 아이템 배지 6개(지금 5개). 중복 없음 |
| 결과 등급 | 지금 확률 유지: 윗등급 `combine_policy.tier_up_probability`(기본 0.7), 재료 등급 그대로 나머지(어드민에서 조정). Mystic 재료는 윗등급이 없어 Mystic 100% |
| 컬렉션 | 유저가 고르지 않는다. 소속 트라이브의 활성 컬렉션(공개 기간 안) 전체에서 아이템 배지마다 같은 확률로 뽑는다 |
| Mystic | Mystic 6개도 재료로 허용한다(Mystic이 나온다) |
| 같은 등급만 | 이미 구현되어 있다(첫 재료를 담으면 그 등급만 활성, 나머지 비활성). 6칸에서도 유지한다 |
| 후보 부족 | 굴린 등급의 후보가 트라이브에 없으면 소각 전에 거절한다. 지금처럼 재료 등급과 윗등급 후보가 모두 있어야 시작할 수 있다(윗등급 100%를 노린 재시도 방지) |
