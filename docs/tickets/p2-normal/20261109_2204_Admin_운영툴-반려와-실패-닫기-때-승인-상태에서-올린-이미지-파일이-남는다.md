# [Admin] 운영툴 반려와 실패 닫기 때 승인 상태에서 올린 이미지 파일이 남는다

## 핵심 요약

- 요구사항: 항목을 반려(`decide.ts`의 `rejectItem`)하거나 실행 단계에서 실패로 닫을 때(`failClose` 경로) 승인 상태에서 올린 `ops-inbox/{접두사}/{항목 ID}.png`·`.webp`가 지워지지 않고 공개 버킷에 남는다. 지워야 하는지 정하고, 지우면 `removeOpsImageFiles`를 부르며 테스트로 고정한다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/decide.ts`(`rejectItem`), 실패로 닫는 경로(`failClose`, `execute/run.ts`), `jam-web/src/lib/admin/opsInbox/image.ts`(`removeOpsImageFiles`)

## 배경 / 문제 정의

티켓 20261007_0952(이미지 경합·`failGroup` 정리)를 구현하며 사용자가 2026-11-09에 반려와 `failClose` 정리를 이번 범위에서 뺐다. 이 티켓이 그 범위 밖 발견물이다. 반려된 항목은 이미지를 다시 받지 않으므로 지워도 되는지(복구 가능성, 반려 취소 여부)를 먼저 확인해야 한다.

## 완료 조건

- 반려와 실패 닫기 경로의 파일 처리 방침이 정해지고 테스트로 고정된다.
- `docs/service/prd/ops-tool/PRD.md` §8.8의 방침 문장이 갱신된다.
