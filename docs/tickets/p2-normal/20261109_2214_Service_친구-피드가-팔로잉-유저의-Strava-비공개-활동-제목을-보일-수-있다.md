# [Service] 친구 피드가 팔로잉 유저의 Strava 비공개 활동 제목을 보일 수 있다

## 핵심 요약

- 요구사항: 홈의 친구 피드가 팔로잉하는 유저들의 `strava_activities` 제목을 `FeedSection`에 넘긴다. 티켓 20261008_1506에서 다른 유저 프로필의 활동 제목은 막았지만, 같은 방식의 노출이 친구 피드에 남아 있다. 이 피드에서도 제목을 숨길지 사용자가 정해야 한다. [보안/주의]
- 구현 계획: (미정 — 착수 전 사용자 결정) 20261008_1506과 같은 방침이면 친구 피드는 본인 글이 아니므로 제목 조회를 건너뛰고 `activityName`이 없을 때의 기존 동작(제목 줄만 비움)을 쓴다.
- 관련 파일: `jam-web/src/app/(main)/feed/page.tsx` L77-88(`strava_activities` 제목 모으기), `jam-web/src/app/(main)/[username]/page.tsx`(20261008_1506에서 고친 기준 구현)

## 배경 / 문제 정의

20261008_1506의 게이트 리뷰(민지)가 범위 밖 발견물 `[보안/주의]`로 지적했다. 연동 스코프가 `activity:read_all`이라 Strava에서 비공개로 둔 활동의 제목이 저장되어 있을 수 있고, 공개 범위는 저장하지 않아 가려낼 수 없다.

## 완료 조건

- 사용자가 친구 피드의 방침을 정한다(제목 숨김 또는 유지).
- 숨기기로 정하면 친구 피드에서 다른 유저의 활동 제목이 내려가지 않는다는 것을 시험으로 고정한다.
