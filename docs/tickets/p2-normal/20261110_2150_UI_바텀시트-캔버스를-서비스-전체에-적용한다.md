# [UI] 바텀시트 캔버스(«JAM! 바텀시트»)를 서비스 전체에 적용한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): Claude 디자인 캔버스 «JAM! 바텀시트»(`claude.ai/artifact/7tni32qascnkWdaUHujB7e`)에서 직접 고친 최종 상태를 서비스 바텀시트에 적용한다. 앞선 티켓 20261110_2048(Strava 끊기 시트)과 20261110_2108(Strava 중복 안내·한번에 빼기)의 연장이다.
- 공통(`BottomSheet`, MODULAR `BottomSheet.jsx`): 여백을 토스뱅크 레퍼런스 기준으로 바꿨다. 헤더 `px-6 pt-5`, 본문 `px-6 py-6`, 푸터 `px-5 pt-2`·아래 `safe-area+20px`(예전 탭바 높이 92px/16px 구분은 없앴고 `footerBottomInset`은 값과 무관한 deprecated), 시트 안 버튼 높이 56px(`py-[15px]!`), 본문 행간 1.4배·문단 간격 4px. 공용 클래스는 `components/ui/sheetClasses.ts`에 모았다. 제목은 20px 굵게(20261110_2048에서 정함).
- 시트별: ① Strava 두 시트와 한번에 빼기: 여백·행간·버튼 높이. ② 탈퇴: «지워지는 것» 제목, «남는 것» 묶음(법에 따른 보관 안내), Strava 동기화 줄을 걷고, 값 행은 8px 여백·구분선·굵은 라벨로, «탈퇴합니다» 낱말만 붉은 글자(`--danger-text` #d61f1f 새 토큰). ③ 받지 않은 믹스 결과: 제목 «아직 인벤토리에 담지 않았어요!», 소개 문장 삭제, 푸터 «필요한 인벤토리 슬롯 N개»(숫자 굵게), 카드는 `BadgeGridCard`. ④ 믹스·등급 올리기 «내 배지»: `BagItemCell`을 `BadgeGridCard` 기반으로 바꾸고(사용 중은 라벨, 미보유·비활성은 흐리게), 등급 올리기 묶음 제목은 등급 칩 하나(개수·«6개부터 넣을 수 있어요» 줄 삭제, Common 칩도 그림). ⑤ 아이템 개체 선택: 제목은 배지 이름 20px 굵게(기본값), 안내 문장 삭제, 개체는 `BadgeGridCard` 3열로 일련번호 칩+등급 칩(`ItemCandidateRow`가 카드가 됨, `ItemSerialCode`는 폭이 넓어 글자 칩으로). ⑥ 방문·획득 기록: 값 행 8px·구분선. ⑦ 배지 공유 미리보기: 좌우 24px, 버튼 56px. ⑧ 드랍 배지 상세: «← 뒤로»와 «연결 위치» 제목을 걷고 등급 칩 md 크기, 아래 여백 20px. ⑨ 피드 상세(`DetailSheet`): 쓰지 않아 코드·시험·층 서열 표에서 걷었다.
- 알아 둘 점(사용자 결정이 시안에 담겨 코드에 반영된 것): 탈퇴 시트에서 보관 기간 안내(체크인·드랍·픽업 기록 6개월, 부정 이용 탐지 기록 3개월)가 화면에서 빠졌다. 문구 키(`keptLabel` 등)는 `ko.ts`에 남겨 두었다. 법적 고지 성격이면 되살려야 한다. 등급 올리기에서 «6개부터 넣을 수 있어요» 안내가 빠졌고, 받기 시트에서 잠긴 결과의 설명 문구가 사라졌다(카드가 잠금 타일과 고정 이름만 그린다). `RarityBadge`의 Common 미표시 규칙(DESIGN_RENEWAL_SPEC)에 등급 올리기 묶음 제목이 예외로 들어갔다. 일련번호 칩은 캔버스를 따라 글자 칩이다.
- 관련 파일: `jam-web/src/components/ui/BottomSheet.tsx`·`sheetClasses.ts`·`BadgeGridCard.tsx`(`pressed`·`disabled` 추가), `jam-web/design-system/components/navigation/BottomSheet.jsx`·`.d.ts`, `components/account/WithdrawSheet.tsx`, `components/strava/*Sheet.tsx`, `components/inventory/ItemCandidate*.tsx`, `app/(main)/combine/{PendingResultsSheet,BagItemCell,TierUpPanel,CombineClient}.tsx`, `app/(main)/collections/[id]/{UnslotAllSheet,SlotGrid}.tsx`, `app/(main)/badges/[id]/{PoiEarnHistory,ItemEarnHistory,BadgeShareButton}.tsx`, `app/(main)/drops/BadgeDetailSheet.tsx`, `app/(main)/FeedSection.tsx`, `jam-web/design-system/tokens/colors.css`·`src/app/globals.css`(`--danger-text`), `jam-web/src/lib/i18n/ko.ts`, 문서 `docs/plan/jam2/11 JAM 2.0 디자인 시스템.md` 5.6절.
- 담당 에이전트: 오케스트레이터(파이프라인은 리뷰 브랜치 push가 필요해 «요청 전에는 push하지 않는다» 지시와 부딪혀 돌리지 않았다).

## 완료 조건

- 위 시트들이 캔버스와 같은 여백·행간·카드·칩으로 보인다.
- 피드 상세 시트 코드가 남아 있지 않다.
- 관련 시험·타입·린트가 통과한다.

## 완료 기록

- **검증**: 시험은 어드민을 뺀 전체가 통과한다(전체 실행에서 실패는 어드민 시험 47개 파일뿐이고 이 변경 전에도 같게 실패했다). `tsc --noEmit` 통과, `eslint` 오류 없음, `npm run ds:check` 오류 0.
- **확인하지 못한 것**: 실제 화면 렌더링(시트가 로그인·특정 상태에서만 열려 눈으로 보지 못했다). 카드 안 일련번호 칩의 폭·줄바꿈, 믹스 가방에서 사용 중 카드가 눌리지 않음, 56px 버튼이 작은 화면에서 푸터를 얼마나 차지하는지. 시트마다 상태 변형(빈칸 부족·로딩·오류)을 캔버스는 대표 상태 하나만 그렸다.
