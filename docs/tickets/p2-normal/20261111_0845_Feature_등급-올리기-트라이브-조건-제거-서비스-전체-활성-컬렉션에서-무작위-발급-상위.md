# [Feature] 등급 올리기에서 트라이브 조건을 빼고 서비스 전체 활성 컬렉션에서 무작위로 발급한다 (상위, 2회차)

## 핵심 요약

- 요구사항: 등급 올리기의 결과 아이템 후보를 «유저 소속 트라이브의 활성 컬렉션»에서 «서비스에서 활성화된 모든 컬렉션(트라이브 무관)»으로 바꾼다. 사용자 지시 2026-11-11.
- 구현 계획: 1회차 서버 굴림·시작 검사·어드민 아이템 길 → 2회차 확률 안내 페이지·정책 대시보드·운영 문서·문구. 2회차는 1회차가 반영된 뒤 진행한다.
- 하위 티켓: 1회차 20261111_0846(완료, 로컬 staging 머지 `5004b12ba`), 2회차 20261111_0847.
- DB 변경 없음(`combine_policy.tier_up_probability` 값 그대로, 발급 RPC `combine_grant_results`는 트라이브를 보지 않는다).

## 배경 / 문제 정의

staging 자동 로그인 테스트 계정(232, 트라이브 «낭만 미식가»)으로 common 6개 등급 올리기를 실행하자 「지금은 받을 수 있는 아이템 배지가 없어요」 토스트가 나왔다(2026-11-11). 원인은 소속 트라이브에 활성 컬렉션이 없어 서버가 `no_candidate`로 소각 전에 거절한 것이다(`lib/combine/tierUp.ts` ⑥-2 `tribeSupportsTierUp`). 2026-11-11 DB 실측: 활성 컬렉션 15개는 모두 유저가 없는 트라이브 5곳(3개씩)에 있고, 실제 유저 2명의 트라이브(낭만 미식가·숲속의 갱단)는 컬렉션이 모두 꺼져 있다. 오픈 전 정리로 컬렉션을 줄인 상태에서는 트라이브 단위 판정이 등급 올리기를 막는다.

## 결정 (사용자 지시 2026-11-11 + 카리나 가정, 가정은 바로잡을 수 있다)

| 항목 | 결정 |
|---|---|
| 후보 풀 | 서비스에서 지금 발급할 수 있는 모든 아이템 배지: 컬렉션 활성·공개 기간 안·드랍 제외 아님, 배지 삭제 아님·공개 기간 안·드랍 제외 아님. **트라이브 조건만 뺀다**(기존 판정 그대로, 소속 트라이브가 없는 컬렉션도 포함) *(가정)* |
| 아이템 고르기 | 정한 등급의 후보 전체에서 배지마다 같은 확률(컬렉션을 먼저 뽑지 않는다) *(가정)* |
| 결과 등급 | 변경 없음: 윗등급 `tier_up_probability`(기본 0.7), 재료 등급 그대로 나머지, Mystic 재료는 Mystic 100% |
| 시작 검사 | 단위만 트라이브에서 서비스 전체로 바꿔 유지한다: 풀에 재료 등급과 바로 윗등급이 모두 있어야 시작(윗등급만 있는 풀에서 재시도로 윗등급 100%를 얻는 길 방지) *(가정)* |
| 재료 | 변경 없음: 같은 등급 6개, 트라이브·컬렉션 무관 |
