## 배경 / 문제 정의

디자이너가 캔버스에서 미션 상황 화면을 새로 그렸다(2026-11-11, 사용자 직접 지시와 수정 포함). 지금 화면은 1~3위 포디엄과 별도 «내 순위 카드»가 있고 달성형은 상세에서 열리지 않는다. 캔버스는 위쪽에 내 상태를 크게 보이고 아래에 전체 목록을 두는 한 골격으로 두 틀을 통일했다.

### UI/UX 관점 — 공통 골격
- 화면 전체 배경(상단 바 뒤까지): 위에서 아래로 `#fbfbfb → #fdf3f3(280px) → #fbe3e3(580px) → #f9d6d6`의 세로 그라데이션(강조색 `--jam-red` 색상 0°, 아주 옅게). 프로필 뒤에 흰 빛(`radial-gradient(70% 60% at 50% 32%, #fff → 투명)`, 높이 420px). 상단 바는 투명하게 두고 그라데이션이 바 뒤까지 이어진다.
- 위쪽 «나» 영역(가운데 정렬, 패딩 12 24 40): 내 프로필 원 **114px**(사진 없으면 사람 아이콘 47px; 흰 링 3px + 그림자 `0 10px 28px rgba(0,0,0,.14)`) → 내 이름(18/26 굵게, 한 줄 말줄임, 최대 280px, 위 12) → 아래 틀별 영역(위 20).
- 아래 카드: 흰색 94% 불투명, 모서리 `--radius-2xl`, 좌우 바깥 여백 16, 위쪽 «나» 영역과 겹치지 않게 이어 붙는다. 카드 제목 **21px** 굵게(전에는 15px), 오른쪽에 «참가자 N명» 12px 회색.
- 목록 행: 지금의 `ListRow tone="tint"`(행 사이 8px). 목록 아래 바탕 그라데이션이 카드 아래로도 이어진다.

### 랭킹형
- 포디엄(1·2·3위 영역)과 «내 순위 카드»(`MyRankCard`)를 지운다. 전체 랭킹은 **1위부터** 한 목록(`RankingListRow`)이다. 내 행에는 지금처럼 «나» 칩(`accent`).
- 위쪽: «나의 진행 상황»(14/20 회색) → 내 진행값 **52/60 굵게**(숫자는 `formatMissionProgress`, 단위는 16/24 회색: 거리 `km`·횟수 `회` 등 — 미션 상세의 `goal.unit` 도우미를 찾아 같은 단위를 쓴다) → «내 순위»(14/20 회색) → «{N}위» **32/40 굵게, 색 `--jam-red`(#FF1D1D)**. 내 순위가 공개 목록(`visible_rank_count`) 밖이어도 위쪽에 보이므로 별도 카드는 없다.
- 참가자 1~3명이어도 목록 행만 1~3개 나온다(빈 포디엄 칸 없음). 참가자 없음이면 지금의 `EmptyState`.

### 달성형
- 위쪽: 내 프로필·이름 아래 «나의 진행 상황» → 내 상태 **칩**: 알약(`border-radius: 9999px`), 안쪽 여백 4·16, 글자 **30/36 굵게**(`--text-3xl`). 달성 = 면 `--jam-red`·글자 `--snow`, 미달성 = 면 `--base-neutral-600`(#525252)·글자 `--snow`.
- 아래 «달성 현황» 카드: **다른 참가자만** 나온다(내 행·«나» 칩·«— 나 —» 구분 없음). 먼저 달성한 사람이 위, 미달성이 뒤. 행 오른쪽 칩은 지금과 같다(달성 `done`, 미달성 `surface-muted`). 공개 수(`visible_rank_count`)가 있으면 그 수까지만.
- 참가자 없음이면 `EmptyState`.

### 문구 (사용자 확정은 «랭킹» 하나뿐이다. 나머지는 아래 가정이고 카리나가 사용자 보고에 가정으로 알린다)
- 상세의 버튼: 랭킹형 «랭킹»(확정), 달성형 «달성 현황»(가정 — 카드 제목과 같은 말).
- 라벨 «나의 진행 상황»·«내 순위»는 서비스에 있는 말이다(`myProgressTitle`, `statusRankLabel`의 «N위»). «내 순위» 라벨은 새 문구라 UX Writing 가이드를 점검한다.

### 지우지 않는 것 / 범위 밖
- 개인형은 되살리지 않는다(DB 제약도 두 값이다).
- 로딩·오류 화면(눈 모양 로더, «불러오지 못했어요»)은 지금 그대로다.
- API의 랭킹형 응답 모양(`entries`·`me`·`totalParticipants`)은 바꾸지 않는다.

## 최종 반영 값 (2026-11-11 캔버스 수정 반영)

초기 시안(그라데이션 배경, 흰 카드, 레드 «N위»)에서 캔버스 «JAM! 미션 상황»을 사용자가 고쳐 간 최종 상태다. 위 상세 요구사항과 다르면 이 절이 맞다.

- **배경:** 그라데이션과 프로필 뒤 흰 빛 없음. `--jam-red`(#FF1D1D) 단색, 상단 바 투명.
- **위쪽 «나» 영역:** 프로필 114px(흰 링 3px, **그림자 없음**), 이름 `--text-lg`. 라벨·진행값·단위 `--foreground`, «N위» `--snow`(32/40 굵게, 화면 전용 토큰 `--status-rank-size`). 진행값 `--text-5xl`.
- **달성형 내 상태 칩:** 달성 `--foreground` 면, 미달성 `--muted` 면, 글자 `--snow`(30/36 굵게, 패딩 4·16).
- **카드:** 검정 토큰 94%(`--status-card-bg`), 제목 21px(`--status-card-title-size`)·«참가자 N명»은 `--snow`. 목록 행은 밝은 tint 면에 검정 글자.
- **랭킹 행:** 진행 막대 채움 `--jam-red`, 내 행 표식은 «나» 칩이 아니라 `--jam-red` 면 22px 원(안에 «나» 11px). `RankingListRow`의 선택 prop(`barColor`, `meMarker`)으로만 켜서 홈 피드 랭킹 카드는 그대로다.
- **달성형 목록:** 다른 참가자만, «다른 참가자 N명»(나 제외), 서버가 내 행을 먼저 빼고 공개 수만큼 자른다. «미달성» 칩 `--muted` 면·`--snow` 글자.
- **빈 상태:** «참가자 없음»은 도달할 수 없어 화면·문구 키·시험을 삭제. 달성형에서 나만 참가한 경우 «아직 다른 참가자가 없어요»만 남음.
- **상세 버튼:** 랭킹형 «랭킹 보기», 달성형 «달성 현황 보기»(후자는 «~ 보기» 형태로 맞춘 가정). 검정 면·흰 글자, 참가 중이거나 완료한 사람에게만.
