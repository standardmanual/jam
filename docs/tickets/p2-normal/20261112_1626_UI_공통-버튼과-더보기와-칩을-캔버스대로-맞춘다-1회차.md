# [UI] 공통 버튼·더보기·칩을 캔버스대로 맞춘다 (1회차)

## 핵심 요약

- 요구사항: 캔버스에서 확정된 버튼·칩 변경을 **공통 컴포넌트에서** 반영한다. 상위 티켓 20261112_1625의 공통 원칙을 따른다.
- 구현 계획: ① `LoadMoreButton`을 신설해 더보기 3곳을 한 컴포넌트로 모으고 레이블을 «더보기»로 통일한다. ② 팔로우 버튼을 `xs`로. ③ 프로필 편집 저장·취소를 한 줄 반반으로. ④ 컬렉션 «한번에 빼기»를 회색 알약으로, 교체 시트 «빼기»를 시트 큰 버튼 규격으로. ⑤ 미션 «랭킹 보기»를 회색 알약 버튼으로. ⑥ 캐러셀 카드의 등급·레벨 칩을 `size="md"`로.
- 관련 파일(지도, 경로 기준 `jam-web/`):
  - **더보기**: `src/components/ui/LoadMoreButton.tsx`(신규, 안에서 `Button variant="outline" fullWidth`) + 스토리/시험. 호출부 3곳: `src/app/(main)/notifications/NotificationsClient.tsx` 342~356행(직접 쓴 흰 알약 `<button>` 교체, 오류일 때 «다시 시도»는 children으로), `src/components/points/PointHistoryList.tsx` 134~142행(같은 직접 마크업), `src/app/(main)/FeedSection.tsx` 697~707행(`Button outline fullWidth`를 `LoadMoreButton`으로). 문구: `src/lib/i18n/ko.ts` `common.loadMore`(27행)와 `points.loadMore`(1390행)를 모두 «더보기»로. 시험: `points/page.test.tsx`, `notifications/NotificationsClient.test.tsx`, `FeedSection.test.tsx`의 문구 참조.
  - **팔로우 버튼**: `src/app/(main)/[username]/FollowButton.tsx` ~80~90행 `size="sm"` → `"xs"`(`--scale-compact` 파생: 12px, 패딩 7.4px 16.8px, 폭은 글자에 맞춤). 목록 행 `FollowUserList.tsx`(~73)는 `ListRow`의 `trail` 슬롯이라 오른쪽 끝 정렬은 이미 된다. 시험: `__tests__/FollowUserList.test.tsx`. 실측 높이가 캔버스(약 35px)와 어긋나면(계산 32.8px) 사용자에게 알린다.
  - **저장·취소**: `src/app/(main)/profile/edit/page.tsx` ~359~388행. 직접 쓴 검정 `<button>`과 글자뿐인 취소를 `flex gap-2`로 감싸 `Button primary fullWidth`(저장) + `Button variant="secondary" fullWidth`(취소)로 교체. 폭 361px에서 각 176.5px, 높이 52px이 자동으로 나온다. 탈퇴 링크는 그 아래 그대로.
  - **한번에 빼기**: `src/app/(main)/collections/[id]/SlotGrid.tsx` ~557~567행 `variant="primary"` → 더보기와 같은 회색 알약(`variant="outline"` 또는 `secondary`). `UnslotAllSheet.tsx` ~124~132행의 확인 시트 실행 버튼은 검정·56px이라 그대로 둔다.
  - **교체 시트 «빼기»**: `src/components/inventory/ItemCandidateSheet.tsx` ~93~103행 `secondaryAction`의 직접 쓴 `<button>`(12px·약 40px)을 `Button` + `SHEET_BUTTON_CLASS`(`src/components/ui/sheetClasses.ts`, 16px·56px)로 교체. 색은 검정 유지. 이 컴포넌트는 `PoiCarouselModal.tsx`와 `SlotGrid.tsx`(~600~627)가 공유하므로 두 곳 모두 확인.

## 배경 / 문제 정의

캔버스 댓글로 확정됐다. 더보기는 화면마다 레이블('더 불러오기'·'더 보기')과 모양(흰/회색)이 달랐고, 팔로우 버튼은 `sm`이 실제로는 큰 크기로 남아 있었다. 저장·취소는 세로로 쌓여 있었고, 한번에 빼기·랭킹 보기는 큰 검정 버튼이었다.

## 상세 요구사항

### UI/UX 관점
- **더보기**: 알림·포인트·프로필·친구 피드의 «더 불러오기»·«더 보기»를 모두 «더보기»(붙여쓰기)로. 모양은 프로필의 것과 같게: 폭 전체, 높이 52px, 회색(`--btn-secondary`) 알약, 글자 가운데, 위 간격 16px.
- **팔로우·팔로잉 버튼**(팔로워·팔로잉 목록): 작은 크기. 오른쪽 끝에 붙는다.
- **프로필 편집 저장·취소**: 한 줄, 각 폭 반(176.5px), 간격 8px, 높이 52px. 저장은 검정(비활성일 때 기존 0.4 투명도), 취소는 회색 알약(`secondary`).
- **한번에 빼기**(컬렉션 상세 트리거): 배경 `--btn-secondary`, 글자 `--foreground`. 확인 시트 안의 «한번에 빼기» 실행 버튼은 검정 유지.
- **교체 시트 «빼기»**: 글자 16px, 높이 56px, 폭 시트 안쪽 전체, 색 검정 유지.
- **미션 상세 «랭킹 보기»/«달성 현황»**: 더보기와 같은 회색 알약(높이 52px, 폭 361px).
- **캐러셀 카드 칩**: 등급·레벨 칩이 `ListRowChip` 규격(12px 굵게, 높이 20px, 안쪽 여백 2px 8px).

## 구현 계획

위 지도의 순서대로. `LoadMoreButton`은 새 컴포넌트라 채원① 판정에서 `needsApproval`이 걸릴 수 있다(사용자가 이미 «근원적 수정»을 지시했으므로 승인된 것으로 본다).

## 완료 조건

- 알림·포인트·프로필·친구 피드에서 더보기 레이블이 «더보기»이고, 네 곳이 같은 `LoadMoreButton`을 쓴다(소스에 직접 쓴 더보기 `<button>`이 남지 않는다).
- `rg "더 불러오기|더 보기" jam-web/src`로 사용자 노출 문구가 남지 않는다(주석 제외).
- 팔로우 버튼이 `size="xs"`이고 시험이 통과한다.
- 프로필 편집 화면에서 저장·취소가 한 줄에 반씩 놓인다.
- 컬렉션 «한번에 빼기» 트리거가 회색, 확인 시트 실행 버튼은 검정이다. 교체 시트 «빼기»가 `SHEET_BUTTON_CLASS` 규격이다.
- 미션 상세 «랭킹 보기»가 회색 알약 버튼이다.
- 캐러셀 카드 칩이 `size="md"`로 그려진다(스토리 확인).
- `scripts/verify.sh`가 통과하고 DS 쌍 대조가 어긋나지 않는다.
