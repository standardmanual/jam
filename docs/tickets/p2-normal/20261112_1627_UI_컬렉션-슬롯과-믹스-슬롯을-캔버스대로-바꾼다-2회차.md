# [UI] 컬렉션 슬롯·믹스 슬롯을 캔버스대로 바꾼다 (2회차)

## 핵심 요약

- 요구사항: 컬렉션 상세와 믹스 레시피의 **아이템 배지 슬롯 표현**을 캔버스대로 바꾼다. 상위 티켓 20261112_1625의 공통 원칙(근원적 수정, DS 쌍 동기)을 따른다.
- 구현 계획: ① `BadgeGridCard`(서비스 사본+DS 사본)에 슬롯 상태 표현을 넣는다. 비어 있는 슬롯은 «이미지 비표시 + 외곽선 점선», 넣을 수 있는 슬롯은 «회색 이미지 + 외곽선 점선». ② `SlotCircleButton`의 + 원을 이미지 가운데로. ③ 컬렉션 상세 맨 위 카드를 `BadgeHeroSection`과 같은 방식(비율 고정 해제)으로. ④ 등급 올리기 빈 슬롯 «+»를 검은 원 안의 +로. ⑤ 레시피 상세 «믹스하기» 버튼에서 아이콘 제거.

## 배경 / 문제 정의

비어 있는 슬롯은 알파 외곽선 그대로 회색(#a3a3a3 상당)으로 채운 실루엣이었다. 캔버스에서 사용자가 «회색으로 채우던 것을 제거하고 이미지 외곽선을 따라 점선으로» 바꾸라고 확정했고, 넣을 수 있는 슬롯은 «이미지는 지금처럼 회색, 거기에 외곽선 점선 추가»로 확정했다.

## 상세 요구사항

### UI/UX 관점
- **비어 있는 슬롯**(후보 없음 `isUndiscovered`, 믹스 `unowned`): 이미지를 그리지 않는다. 실루엣 이미지의 **알파 외곽선을 따라가는 점선**만 보인다. 점선: 굵기 2px, 선 3px·간격 4px, `stroke-linejoin: round`, 색은 배지 이름 글자색(`--muted`, #666). 이름 글자와 같은 회색이어야 한다.
- **넣을 수 있는 슬롯**(`isSlottable`, 믹스 `addable`): 이미지는 지금처럼 `grayscale opacity-40`, 그 위에 **같은 점선**(불투명 100%, 이미지 투명도의 영향을 받지 않는다).
- **+ 원**: 지름 24px 검은 원(`--background-inverse`), 흰 플러스 14px. 위치는 오른쪽 위 모서리가 아니라 **이미지의 정중앙**.
- 장착된 슬롯(`isSlotted`)은 지금과 같다(− 버튼 포함).
- **점선 구현 방식은 채원①이 판정한다.** 캔버스 시안은 이미지 알파를 마칭 스퀘어로 추적해 SVG `<path>`에 `stroke-dasharray="3 4"`를 준 것이다. 후보: (a) 클라이언트에서 같은 출처 이미지(`/_next/image`, 폭 90 이미지의 2x 후보 w=256)를 canvas로 읽어 윤곽을 추적하고 이미지 URL별로 캐시. (b) 윤곽 path를 이미지 생성 단계에서 미리 만들어 저장(DB 변경이라 이 티켓 범위 밖이면 후속 티켓으로 분리). 추적 실패·로딩 중에는 점선을 그리지 않고(이미지도 안 그린 채) 빈 칸으로 둔다. 새 공용 부품(가칭 `OutlinedSlotImage`)을 만들면 `BadgeGridCard` 서비스·DS 사본이 함께 쓴다. 성능(슬롯 최대 30칸)과 CORS를 판정에 포함한다.
- **컬렉션 상세 맨 위 카드**: 이미지·이름·설명이 모두 보인다. 카드 높이는 내용에 맞춰 자동(`aspect-square` 해제). 이미지 200px 고정이 길이 긴 설명에서 이름을 가리면 이미지 크기를 줄인다(캔버스는 설명 길이에 맞춰 153~200px).
- **등급 올리기 빈 슬롯 +**: 검은 원 24px 안 흰 + 14px(굵은 선).
- **믹스하기 버튼**(레시피 상세): 아이콘 없이 글자만.

## 구현 계획

위 지도의 순서. 점선 방식이 `needsApproval`로 올라오면 사용자 승인을 받는다.

## 완료 조건

- 컬렉션 상세에서 비어 있는 슬롯이 점선 외곽선만 보이고, 넣을 수 있는 슬롯은 회색 이미지에 점선이 겹쳐 보인다. 믹스 레시피 상세도 같다(같은 컴포넌트 경로).
- + 원이 넣을 수 있는 슬롯 이미지의 정중앙에 있다.
- 설명이 긴 컬렉션에서도 맨 위 카드의 이름이 가려지지 않는다.
- 등급 올리기 빈 슬롯 6칸이 검은 원 안 + 이고 `MixerSlot` 스토리에 반영돼 있다.
- 레시피 상세 «믹스하기» 버튼에 아이콘이 없다. 인벤토리의 믹스하기 링크는 그대로다.
- DS 사본·서비스 사본이 어긋나지 않고 `scripts/verify.sh`가 통과한다.

## 완료 기록

### 구현 내용 요약
- 채원① 판정: MODULAR 확장 + DS 신규 부품 1개 `SlotOutline`(점선 외곽선). 방식은 (a) 클라이언트 윤곽 추적: `/_next/image`(같은 출처, 폭 90 이미지의 2x 변환본 w=256·q=75, 기존 srcset 변환본 재사용)를 canvas로 읽어 알파를 마칭 스퀘어로 추적해 SVG path로 그린다. 판정 문서의 w=192는 next 기본 sizes에 없어 400을 돌려주므로 구현이 w=256으로 바로잡았다.
- `BadgeGridCard`(서비스·DS 쌍): 비어 있는 슬롯은 이미지 없이 점선만(추적 실패·주소 없음이면 둥근 사각 점선), 넣을 수 있는 슬롯은 `outlined`로 회색 이미지 위 불투명 점선. 실루엣 상수·필터 삭제. 점선은 `--muted`, 2px, 3/4 간격, 모듈 캐시, 화면 200px 근처에서만 추적.
- `SlotCircleButton`에 `position="center"`(이미지 정중앙, 눌림 영역 40px)와 dense. `MixerSlot` 빈 칸은 검은 원 안 흰 +(`ActionCircle`을 − 버튼과 공유). `ItemBookHeroSection`은 `aspect-square` 해제. 레시피 상세 믹스하기 버튼 아이콘 제거.
- 게이트 WARN: 점선 실제 모양·iOS Safari 동작·+ 원 위치는 실렌더 미확인, CI 없음(push 안 함).
- 후속 후보: SlotOutline이 인스턴스마다 `<style>`을 렌더(30칸이면 30개, 통합 권장), 눌림 영역 40→44px, 최적화 불가 외부 이미지는 사각 점선으로 떨어지므로 운영 데이터 확인.
