## 배경 / 문제 정의

캔버스에서 사용자가 지시해 확정했다. 미션 상세는 레드로 꽉 찬 카드를 흰 카드에 레드 포인트(글자·막대·서클)로 바꾸고, 체크인 시트는 아이템 배지 상세와 같은 구조(시트 그레이·카드 흰색, 이미지·이름·설명이 한 카드)로 바꾸며, 선택 모드는 아래 시트의 «N/N개 골랐어요»와 «고르지 않은 N개는 받을 수 없어요» 문구를 없앤다.

## 상세 요구사항

### UI/UX 관점
- 미션 포인트 보상 행: 배경 흰색, 글자 `--point-text`. 미션 진행 카드: 배경 흰색, 진행 수치 글자 `--jam-red`, 막대 채움 `--jam-red`·두께 16px·트랙 연회색. 횟수 서클: 달성 레드+흰 글씨, 미달성 회색+검은 글씨, 테두리 없음.
- 체크인 시트: 시트 배경 `--background`, 이미지·이름·설명은 흰 카드 한 장, 그 아래 시리얼 → 흰 장소 카드 → 취소·픽업. 시트 전체 높이는 지금과 같게.
- 선택 모드 하단 시트: 제목·안내 문구 없이 «N개 담기» 버튼만. 시트 높이는 문구가 있던 만큼 줄인다.

## 구현 계획

위 지도의 순서. `BottomSheet`·`BadgeHeroSection` 공용화는 새 prop·새 공용 위치라 채원①이 `needsApproval`로 올릴 수 있다(사용자가 «근원적 수정»을 지시했으므로 승인된 것으로 본다).

## 완료 조건

- 미션 상세에서 포인트 보상 행이 흰 배경·주황 글자, 진행 상황 카드가 흰 배경·레드 수치·레드 16px 막대, 횟수 서클이 달성 레드/미달성 회색이다. 배지 보상 행은 그대로다.
- 체크인 아이템 상세 시트의 배경이 `--background`이고 이미지·이름·설명이 흰 카드 한 장에 있다. 같은 카드 구조를 배지 상세 페이지·체크인 시트가 한 컴포넌트로 쓴다(소스 중복 없음).
- 선택 모드 하단 시트에 «N/N개 골랐어요»·«고르지 않은 N개는…» 문구가 없다. 스토리·시험이 맞고 접근성 확인 결과가 완료 기록에 있다.
- `scripts/verify.sh`가 통과하고 DS 쌍이 어긋나지 않는다.
