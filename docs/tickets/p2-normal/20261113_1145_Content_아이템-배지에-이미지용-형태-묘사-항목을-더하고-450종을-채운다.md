# [Content] 아이템 배지에 이미지용 「형태 묘사」 항목을 더하고 450종을 채운다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-13): ① 아이템 배지 문서에 이름과 설명을 바탕으로 이미지를 만들 수 있게 사물의 형태를 묘사하는 설명문 항목을 더한다 ② 어드민 아이템 배지 상세의 「시선과 동작」 항목을 이 설명문으로 바꿔 보인다 ③ 의인화하지 않는다 ④ 텍스트 표현(글자·숫자·라벨·로고)을 넣지 않는다 ⑤ 의인화 금지를 이미지 생성 프롬프트에도 반영한다.
- 결정(사용자 답 2026-11-13): 「시선과 동작」은 원고와 DB에 그대로 둔다. 형태 묘사는 **한국어**로 쓰고, 이미지 생성기는 이 문장을 영어 프롬프트로 옮겨 생성한다.
- 구현 계획: `badges.form_description` 칸 추가(같은 아이템 4행에 같은 값, `gaze_motion`과 같은 방식) + 450종 값 채우기 마이그레이션, 원고 01~05 각 아이템의 「시선과 동작:」 줄 아래에 「형태 묘사:」 줄 추가, 어드민 배지 상세 표시 교체, 데이터 모델 문서 갱신.
- 관련 파일: `jam-web/supabase/migrations/338_badge_form_description.sql`(+`_down.sql`, 번호는 커밋 직전 재확인), `jam-web/src/components/admin/badges/BadgeDetail.tsx` 202~203줄, `jam-web/src/types/database.ts`(`BadgeRow`), `docs/service/prd/02_DATA_MODEL.md` «item_books.gaze_motion · badges.gaze_motion» 절, 원고 01~05.

## 작성 규칙 (형태 묘사)

1. 한국어 1~2문장, 공백 포함 40~100자, 「~입니다/~습니다」로 끝낸다.
2. 사물 하나(이름이 여러 개 모인 것을 뜻하면 같은 사물이 모인 한 덩어리)의 겉모습만: 형태, 크기감, 재질, 색, 지금 상태 하나, 조금 낡거나 불완전한 디테일 하나.
3. 근거는 아이템 이름, 4등급 설명(생김새는 주로 Common), 시선과 동작. 컬렉션·트라이브는 사물 판별에만 쓴다.
4. 쓰지 않는 것: 사람·손·몸·이름·장소·배경·이야기·감정, 의인화(눈·입·얼굴·표정·감정 형용사·사물이 스스로 하는 행동), 텍스트 표현(글자·글씨·숫자·문구·라벨 내용·로고·상표·「적힌/쓰인/인쇄된」, 개수를 세는 수사), 화풍·조명·각도·배경색, 평가 형용사.

## 완료 조건

- `badges.form_description`이 아이템 450묶음(1,800행) 모두 채워지고, 같은 묶음 4행의 값이 같다(실행 뒤 읽기 전용 확인).
- 450개 문장 모두 규칙 1·4를 기계 검사로 통과한다(길이, 숫자·금지어 검색).
- 원고 01~05의 450개 아이템에 「형태 묘사:」 줄이 있고 DB 값과 같다.
- 어드민 배지 상세 «기본 정보»의 해당 항목 이름이 「형태 묘사」이고 `form_description`을 보인다(값이 없으면 빈 표시).
- 데이터 모델 문서에 칸 설명이 있다.
