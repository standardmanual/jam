## 핵심 요약

- 요구사항: apply/route.ts 36~45줄: status 확인 뒤 갱신 사이에 조건부 update가 없어, 같은 generationId에 적용 요청이 겹치면 두 번 반영될 수 있다. 어드민 단독 사용이라 위험은 낮다.
- 구현 계획: 기록 갱신을 `status='generated'` 조건부 update로 바꿔 먼저 선점하고, 선점에 실패하면 409를 돌려준다.
- 관련 파일: `jam-web/src/app/api/admin/badge-image-generator/apply/route.ts`
