# [Admin] 이미지 생성 화면에서 아이템의 형태 묘사를 고칠 수 있게 한다

## 핵심 요약

- 요구사항(사용자 2026-11-13): 프롬프트의 바탕인 「형태 묘사」(`badges.form_description`, 한국어)를 이미지 생성 화면에서 바로 고칠 수 있게 한다. 고치면 같은 아이템의 4등급 행이 모두 바뀌고, 영어 프롬프트 문장도 새 형태 묘사로 다시 옮겨진다.
- 구현 계획: ① 새 라우트 `PATCH /api/admin/badge-image-generator/form-description` ② 화면 `ItemWorkbench.tsx`의 형태 묘사 영역(245~250줄)에 「수정」 → 텍스트 영역·「저장」·「취소」 ③ 저장 성공 뒤 기존 `describe`에 `force: true`를 불러 영어 문장을 다시 옮기고 화면을 갱신한다.
- 관련 파일: 새 `jam-web/src/app/api/admin/badge-image-generator/form-description/route.ts`, `jam-web/src/app/admin/image-generator/ItemWorkbench.tsx` 245줄 근처, `jam-web/src/app/admin/image-generator/imageGeneratorApi.ts`(호출 도우미를 두면), 참고 `describe/route.ts`(인증·입력 검사 패턴), `jam-web/src/lib/admin/badgeImageGenerator/items.ts`(아이템 판정: `item_book_id`·`name`·`form_description` 있는 행), 문서 `docs/service/prd/02_DATA_MODEL.md` «badges.form_description» 절.

## 상세 요구사항

### 서버
- `PATCH { bookId, itemName, formDescription }`. 관리자 아니면 401.
- `formDescription`은 앞뒤 공백을 지우고 줄바꿈을 공백으로 바꾼 뒤 10~200자. 벗어나면 400 「형태 묘사는 10~200자로 적어 주세요.」.
- 같은 (`item_book_id`, `name`)이고 `form_description`이 이미 있는 행만 갱신한다(아이템 배지만). 갱신된 행이 4행이 아니면 오류(500)로 보고 그대로 둔다 — 1131의 적용 라우트와 같은 기준.
- 응답 `{ formDescription }`. 영어 문장 표(`badge_image_item_prompts`)는 건드리지 않는다(원문 지문이 달라져 `stale`이 된다).

### 화면
- 형태 묘사 옆 「수정」 버튼 → 텍스트 영역(기존 값, 200자 표시)과 「저장」·「취소」. 저장 중 버튼 막기.
- 저장 성공 시: 「형태 묘사를 저장했어요. 영어 문장을 다시 만드는 중이에요.」 → `describe { force: true }` 호출 → 아이템 정보 다시 불러오기 → 「영어 문장을 다시 만들었어요.」. 다시 만들기가 실패해도 형태 묘사 저장은 유지되고, 기존 `stale` 안내와 「다시 만들기」 버튼이 보인다.
- 안내 한 줄(보조 문구): 「여기서 고친 형태 묘사는 원고 문서에는 자동으로 반영되지 않아요.」
- shadcn 컴포넌트만 쓴다. 문구는 해요체.

### 문서
- `02_DATA_MODEL.md` «badges.form_description» 절에 「어드민 이미지 생성 화면에서 고칠 수 있다(티켓 20261113_1411). 이때 원고와 달라질 수 있으므로, 원고를 정본으로 유지하려면 원고에도 같은 문구를 옮긴다」를 더한다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 라우트: 관리자 아님 401, 길이 검사 400, 4행이 아니면 500, 성공 시 4행 갱신과 `{ formDescription }` 응답(코드로 확인).
- 화면: 「수정」→저장 성공 뒤 `describe`를 `force: true`로 부르고 아이템을 다시 불러온다. 「취소」는 API를 부르지 않는다.
- 데이터 모델 문서 갱신.
- 변경 파일 eslint, tsc 통과.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤)
- 로컬 어드민에서 형태 묘사 1건 수정 → 영어 문장 갱신 확인 → 원래 문구로 되돌리기.
