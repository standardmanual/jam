# [UI] TopNav 동기화 버튼을 홈 밖에서는 아이콘 서클로 바꾼다

## 핵심 요약
> 카리나가 아현·민지 등에게 티켓 전체 대신 이 절만 전달할 수 있도록 한두 줄로 채운다.

- 요구사항: 홈을 뺀 모든 화면의 TopNav에서 «동기화» 글자 알약을 알림 종과 같은 아이콘 서클로 바꾼다. 홈은 지금의 글자 알약을 그대로 둔다. 시안은 클로드 캔버스 `https://claude.ai/artifact/QrcSZkKopYKHsFrcm2KZ3W`의 보드 «홈»(알약 유지)과 «미션 목록»·«배지»(아이콘 서클) 머리 줄이다(사용자 지시 2026-11-14).
- 구현 계획: TopNav 래퍼에 `syncStyle: 'icon' | 'pill'`(기본 `icon`)을 더하고, `icon`이면 중앙 슬롯 대신 우측 슬롯 `[호출부 rightSlot][동기화 서클][알림 종][아바타]` 순서로 그린다. 홈 `page.tsx`만 `syncStyle="pill"`을 넘긴다. 서클은 새 `SyncIconButton`이 그리고 모양은 `NotificationBell`을 따른다.
- 관련 파일(지도, jam-web/src 기준):
  - `components/ui/TopNav.tsx` — `TopNavProps`(약 83행~)에 `syncStyle`, 함수 본문의 `composedRightSlot`(약 119행)과 `centerSlot`(약 156행)·`return`(약 175행) 분기
  - `components/ui/SyncIconButton.tsx` — 신규. 44×44 터치 영역 + 36px 서클(`bg-border`) + 16px 아이콘, `-mr-1`, `aria-label`, 진행 중 `animate-spin motion-reduce:animate-none`
  - `components/ui/icons.tsx` — `SyncIcon` 신규(`BellIcon` 아래, 선 1.5px·24 viewBox·`currentColor`)
  - `components/SyncButton.tsx` — `variant?: 'pill' | 'icon'`(기본 `pill`) 추가, `icon`이면 `Button` 대신 `SyncIconButton`. 동기화 로직·`BadgeRevealOverlay`는 그대로
  - `app/(main)/page.tsx` — 117·119행 `TopNav` 두 곳에 `syncStyle="pill"`
  - `components/ui/__tests__/TopNav.test.tsx`, `TopNav-strava-state.test.tsx` — 지금 알약을 기대하는 단언에 `syncStyle="pill"`을 넘기고, 아이콘 모드 단언을 새로 추가
  - `components/ui/__tests__/SyncIconButton.test.tsx` — 신규(서버 렌더 마크업 고정)

## 배경 / 문제 정의
모든 하위 화면 머리에 검정 «동기화» 알약이 붙어 있어 화면 제목보다 눈에 띄는 가장 진한 면이 된다(스테이징 화면 리뷰 공통 개선 4번). 홈은 «Strava 동기화» 안내 카드와 같은 맥락이라 알약이 필요하지만, 그 밖의 화면에서는 아이콘으로도 충분하다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `syncStyle` 기본값은 `icon`이다. 홈만 `pill`을 명시한다.
- 연동 상태 4종(`connected`·`disconnected_error`·`none`·`disconnected_user`)은 모두 아이콘 모드에서 서클로 보인다. `connected`는 `SyncButton`(수동 동기화), 그 밖은 `/api/strava/auth`로 이동하는 서클이다. `disconnected_error`의 이름표는 «다시 동기화»(`d.stravaConnection.topNavReconnect`), 나머지는 «동기화»(`d.today.syncButton`)다.
- `centerSlotOverride`(온보딩 퀘스트 `sync` 차례)가 있으면 지금처럼 중앙 슬롯에 그대로 그린다(홈 전용).
- 동기화 동작(`POST /api/strava/sync`, 배지 연출, 토스트)은 바꾸지 않는다.

### UI/UX 관점
- 모양은 알림 종과 같다: 44×44 터치 영역 안에 36px 서클(`--border` 면), 16px 선 아이콘(`SyncIcon`), 서클 사이 간격 12px(`-mr-1`로 종과 같은 방식).
- 글자가 없으므로 `aria-label`이 이름을 맡는다. 진행 중에는 아이콘이 돌고 `aria-busy`가 켜진다. 움직임 줄이기 설정에서는 돌지 않는다.
- 배지 상세처럼 호출부가 `rightSlot`을 쓰는 화면은 `[공유][동기화][종][아바타]`가 된다.
- 새 토큰·새 색은 없다(`--border`, `--foreground`).

## 구현 계획
위 「관련 파일」의 파일 단위 지도를 따른다. 아이콘 경로는 `M20 11a8 8 0 00-14.3-4.3L4 9M4 4v5h5` 와 `M4 13a8 8 0 0014.3 4.3L20 15M20 20v-5h-5`(두 `path`)를 기본으로 하되, 채원 판정이 다르면 판정을 따른다. MODULAR(`design-system/`)는 건드리지 않는다 — 변경은 서비스 래퍼와 서비스 전용 부품 안에서 끝난다(DS TopNav의 `centerSlot`·`rightSlot` 계약은 그대로).

## 완료 조건
### 구현 범위 (게이트 판정 대상)
- 홈(`/`)의 TopNav는 지금처럼 글자 «동기화» 알약이고, 홈이 아닌 화면(예: 미션 목록, 배지 상세, 포인트)의 TopNav에는 «동기화» 글자 버튼이 없고 알림 종 왼쪽에 아이콘 서클이 있다.
- 아이콘 서클은 `aria-label`로 «동기화»(연동 오류 상태는 «다시 동기화»)를 가지며, 연동된 유저가 누르면 `SyncButton`과 같은 동기화가 돌고 진행 중에는 아이콘이 돈다.
- 미연동 유저가 서클을 누르면 `/api/strava/auth`로 이동한다.
- `npx vitest run src/components/ui/__tests__/TopNav.test.tsx src/components/ui/__tests__/TopNav-strava-state.test.tsx src/components/ui/__tests__/SyncIconButton.test.tsx`가 통과하고, `scripts/verify.sh`가 통과한다.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤)
- 로컬 `next dev`에서 홈과 하위 화면 머리 줄을 눈으로 확인한다(워크트리에서는 실렌더가 안 되므로 메인 트리에서).

## 주요 의사결정
- 홈만 알약을 남기는 기준은 사용자 지시다(2026-11-14): «홈피드를 제외하고 캔버스처럼 아이콘 서클로».
- 기본값을 `icon`으로 둔 이유: 새 화면이 늘어도 자동으로 아이콘이 되게 하려는 것이다. 홈만 예외를 명시한다.
