# [UI] 하단 탭바의 활성 탭에 이름표를 보인다

## 핵심 요약

- 요구사항: 하단 탭바(서비스 `TabBar.tsx`)에서 지금 활성인 탭에만 아이콘 옆에 글자 이름표를 보인다. 이름은 «투데이 · 배지 · 체크인 · 미션 · 인벤토리»이고 비활성 탭은 지금처럼 아이콘만이다. 시안은 클로드 캔버스 `https://claude.ai/artifact/QrcSZkKopYKHsFrcm2KZ3W`의 «홈»·«배지» 보드 탭바다(사용자 지시 2026-11-14, 캔버스 댓글과 채팅).
- 구현 계획: 활성 탭의 슬롯을 아이콘+이름표 폭만큼 넓히고, 활성 필(`jam-tabbar-pill`)이 그 슬롯 폭을 그대로 따라가게 한다(지금도 `offsetLeft`/`offsetWidth` 실측을 쓴다). 서비스 `TabBar.tsx`와 MODULAR `TabBar.jsx`는 쌍이라 둘을 함께 고친다. 세 번째 탭 이름은 `d.nav.drops`가 `JAM`이라 `체크인`으로 바꾼다.
- 관련 파일(지도):
  - `jam-web/src/components/ui/TabBar.tsx` — `baseTabs`(약 41~132행), 활성 판정 `isActive`(약 311행), 탭 렌더 `tabs.map`(약 395행~), 필 위치 `moveTo`(약 335행)·ResizeObserver 효과(약 363행)
  - `jam-web/design-system/components/navigation/TabBar.jsx` — 같은 구조(탭 목록 약 91행, 탭 렌더 약 205행). 이름표는 `label`을 그대로 쓴다. 지금 세 번째 이름은 «드랍»이므로 «체크인»으로 맞춘다
  - `jam-web/design-system/components/navigation/TabBar.d.ts`, `TabBar.stories.tsx`, `TabBar.prompt.md` — 이름표 설명과 Story(활성 탭별 이름표, 이름표가 가장 긴 «인벤토리») 추가
  - `jam-web/src/lib/i18n/ko.ts` 118~125행 `nav.drops: 'JAM'` → `'체크인'`(사용처는 `TabBar.tsx` 한 곳뿐이다)
  - `jam-web/src/app/transitions.css`(또는 `globals.css`)의 `.jam-tabbar-*` 규칙 — 슬롯 폭·필 전환이 한 곳에서 이어지도록 필요하면 손본다
  - 시험: `jam-web/src/components/ui/TabBar.inverse.test.tsx`를 확인하고, 이름표 단언을 담은 새 시험(`TabBar.label.test.tsx`)을 더한다

## 배경 / 문제 정의
탭 5개가 아이콘뿐이라 지도 핀(체크인)과 티켓(미션)처럼 이름을 알아야 구분되는 탭이 있다(스테이징 화면 리뷰 공통 개선 항목 «TabBar»). 활성 탭에만 이름표를 보이면 비활성 탭의 간결함은 지키면서 지금 어디인지 글자로 알려 준다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 활성 판정(`isActive`, 인벤토리에서 들어온 배지 상세 등 파생 경로 포함)은 바꾸지 않는다. 활성 탭이 없는 화면(프로필·검색·알림 등)에서는 이름표가 없다.
- 활성 탭이 바뀌면 이름표가 있는 슬롯이 옮겨 가고 필이 미끄러진다. 이때 폭이 바뀌는 슬롯과 필의 이동이 한 번에 이어져야 한다(필 위치를 폭이 확정되기 전의 값으로 재면 어긋난다).
- 링크 접근성 이름(`aria-label`)은 그대로 유지한다. 화면에 보이는 글자와 같은 값을 쓴다.
- 반전 상태(푸터 위)에서는 이름표 색이 활성 아이콘과 같다(`--snow`).

### UI/UX 관점
- 이름표: 12~13px 굵게, 아이콘 오른쪽 6px 간격. 새 색·새 토큰 없음(`--tabbar-icon-active` 계열).
- 360px 폭에서도 «인벤토리»가 한 줄로 들어가고 나머지 탭의 터치 영역이 44px 아래로 줄지 않는다.
- 움직임 줄이기 설정에서는 필이 즉시 이동한다(기존 규칙 유지).

## 구현 계획
위 「관련 파일」을 따른다. 채원 판정이 방식(활성 슬롯 `flex-grow`·필 측정 시점)을 정하면 그것을 따른다. MODULAR 쌍(`TabBar.jsx`)과 서비스 `TabBar.tsx`의 값이 어긋나지 않게 함께 고치고 Story를 같은 커밋에 넣는다.

## 완료 조건
### 구현 범위 (게이트 판정 대상)
- 활성 탭에만 아이콘 옆 이름표가 보이고, 비활성 탭은 아이콘뿐이다. 이름은 투데이·배지·체크인·미션·인벤토리다.
- 활성 탭이 없는 화면에서는 이름표가 없고 필도 숨는다.
- 탭 이동 시 필이 활성 슬롯 폭을 따라 어긋남 없이 미끄러진다(첫 배치는 무애니메이션).
- 서비스 `TabBar.tsx`와 DS `TabBar.jsx`·`.d.ts`·`.stories.tsx`가 함께 바뀌고 `scripts/verify.sh`의 `ds:check`를 포함한 검사가 통과한다. 새 시험이 통과한다.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤)
- 로컬 `next dev`에서 5개 탭과 푸터 반전 상태, 360px 폭을 눈으로 확인한다.

## 주요 의사결정

- 세 번째 탭 이름은 사용자가 «체크인»이라고 적어 `JAM`에서 바꾼다. MODULAR 쪽 «드랍»도 같은 이름으로 맞춘다.

### 구현 내용 요약
