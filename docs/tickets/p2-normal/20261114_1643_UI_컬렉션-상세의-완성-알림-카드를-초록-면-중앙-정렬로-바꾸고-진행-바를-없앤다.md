# [UI] 컬렉션 상세의 완성 알림 카드를 초록 면·중앙 정렬로 바꾸고 진행 바를 없앤다

## 핵심 요약

- 요구사항: 컬렉션 상세(`/collections/[id]`)에서 컬렉션을 완성하면 ① 완성 알림 카드를 캔버스 시안(초록 면, «완성» 칩, 제목 «컬렉션 완성!», 설명 «모든 아이템 배지를 장착했어요», 전부 가운데 정렬)으로 바꾸고 ② 그때는 진행 바(`ProgressCountBar`)를 그리지 않는다. 완성하면 진행 바가 사라지고 그 자리에 완성 알림이 놓이는 구조다(사용자 지시 2026-11-14, 캔버스 댓글).
- 구현 계획: 히어로 섹션(`ItemBookHeroSection`)이 children(완성 알림)이 있으면 진행 바를 그리지 않게 한다. 완성 알림 카드는 `Card` 대신 초록 면(`bg-jam-green`) 카드로 그리고, 안에 «완성» 칩(`ListRowChip`, accent 면)·제목·설명을 세로 중앙 정렬한다. 초록 면과 «완성» 칩은 컬렉션 카드(티켓 20261114_1502)와 같은 규칙이라 새 토큰은 없다.
- 관련 파일:
  - `jam-web/src/app/(main)/collections/[id]/page.tsx` 약 324~340행 — 완성 알림 카드(`isCompleted && <Card className="text-center">…`)를 초록 면 카드로 교체
  - `jam-web/src/app/(main)/collections/[id]/ItemBookHeroSection.tsx` 약 143~148행 — `children`이 있으면 `ProgressCountBar`를 그리지 않는다(`children` 설명 주석 갱신)
  - `jam-web/src/app/(main)/collections/[id]/__tests__/heroChildren.test.tsx` — «진행 바 앞» 단언을 «children이 있으면 진행 바(n/m)가 없다»로 고친다
  - `jam-web/src/lib/i18n/ko.ts` 1515·1523·1524행 — 기존 문구(`itembooks.completed`·`completedTitle`·`completedBody`)를 그대로 쓴다
  - 시안: 클로드 캔버스 `https://claude.ai/artifact/QrcSZkKopYKHsFrcm2KZ3W`의 «컬렉션 상세 · 완성» 보드(`.done`)
  - 같은 규칙: `jam-web/src/components/ui/CollectionGridCard.tsx` 33~36행(`bg-jam-green`), 88행(`ListRowChip` accent)

## 배경 / 문제 정의

완성한 컬렉션 카드는 초록 면에 «완성» 칩으로 바뀌었는데(티켓 20261114_1502), 상세 화면은 흰 알림 카드와 진행 바(예: 9/9)가 함께 남아 같은 사실을 두 번 말한다. 완성하면 진행 바를 걷고 초록 알림 하나만 두어 컬렉션 카드와 같은 신호로 맞춘다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 완성 판정(`isCompleted`)은 바꾸지 않는다. 완성이 아니면 지금처럼 진행 바를 그린다.
- 숫자(큰 «9/9» 등)는 더하지 않는다. 사용자가 시안에서 이미 지웠다.

### UI/UX 관점
- 초록 면 `--jam-green`, 모서리·간격은 시안(`radius 16`, 안쪽 여백 20/20/22, 요소 사이 6px)을 따르되 DS 눈금에 가장 가까운 값을 쓴다. 그림자·외곽선 없음.
- 칩·제목·설명은 가로 중앙 정렬, 글자는 가운데 맞춤. 제목 22px 굵게, 설명 14px.
- 글자색은 초록 면 위에서 읽히도록 `--foreground` 계열(설명은 약한 투명).

## 구현 계획
위 「관련 파일」을 따른다. 초록 면 알림이 컬렉션 카드 규칙(티켓 20261114_1502)과 같은 규칙의 재사용이라 경로 ② 가벼운 UI로 진행한다.

## 완료 조건

- 완성하지 않은 컬렉션은 지금처럼 진행 바가 보이고 알림 카드는 없다.
- `heroChildren.test.tsx`가 새 동작에 맞고 통과한다. tsc·eslint 0건.
