# [UI] 캔버스에서 확정한 단색 라인·채움 아이콘 세트를 서비스와 DS에 적용한다 (상위)

## 핵심 요약

- 요구사항: 캔버스 «JAM 화면 개선안 캔버스»의 «새 아이콘 제안 · 라인과 채움» 보드에서 사용자가 댓글로 다듬어 확정한 아이콘 39종을 서비스(`jam-web/src`)와 MODULAR DS(`jam-web/design-system`)에 적용한다. 사용자 요청: «지금까지 수정한 아이콘으로 서비스에 적용해. DS에도 반영해.»(캔버스 댓글, 2026-11-14 23:40 KST)
- 구현 계획: 세 회차로 나눈다. 1회차 아이콘 세트·DS 카탈로그(20261114_2345) → 2회차 이름 바뀐 아이콘의 사용처 교체(20261114_2346) → 3회차 탭바·지도 마커·화면 전용 인라인 SVG 교체(20261114_2347). 2·3회차는 1회차 머지 뒤에 시작한다.
- 관련 파일: 사양 `docs/assets/prototypes/icon-set-v2/spec.json`(아이콘별 48 격자 SVG·역할 클래스·옛 이름), 그림 `docs/assets/prototypes/icon-set-v2/board.png`(최종 보드 렌더).

## 배경 / 문제 정의

- 지금 서비스 아이콘은 세 체계가 섞여 있다: 선 아이콘 32종(`ui/icons.tsx`, 선 1.5px), 하단 탭바만 Material Symbols 채움형 인라인 SVG(`TabBar.tsx`), 지도 마커는 별도 육각형 면 그림(`MapView.tsx`).
- 캔버스에서 참고 이미지의 형태(둥글고 통통한 실루엣, 반짝이)를 가져와 색 없이 라인·채움 두 벌로 다시 그렸고, 사용자가 댓글로 개별 아이콘을 다듬었다(미션=티켓, 드랍·픽업=아래·위 화살표, 컬렉션=덮인 마법책, 진행 알림=원 안 반짝이, 믹스하기=거품기 그릇, Strava 연동=동기화 서클, 배지=톱니 원+넓은 리본 하나, 지도 마커 안=보물 상자 등).

## 상세 요구사항

### 서비스/코드베이스 관점

사용자 확인을 거친 결정(2026-11-14):

1. 색은 글자색(currentColor) 하나. 선 굵기는 24px 렌더에서 1.5px(지금과 같음).
2. 채움은 하단 탭바의 켜진 탭과 지도 마커(드랍 있음)에만 쓴다. 나머지는 라인이다. 동작 글리프 7종은 라인만 둔다.
3. 그림이 바뀐 10종은 컴포넌트 이름도 새 그림에 맞게 바꾼다(사용자 결정). 대응표는 spec.json의 `oldName`→`name`.
4. 지도 마커는 지금의 원(드랍 있음=초록, 없음=회색)을 그대로 두고, 원 안 그림만 보물 상자로 바꾼다(드랍 있음=채움, 없음=라인).
5. 현재 위치 버튼의 파란 점은 캔버스대로 단색으로 바꾼다.
6. 대상 아님: 구글 로고, 어드민 tabler 아이콘, 캔버스의 곁들임 장식·크기 시험.

### UI/UX 관점

- 하단 탭바 이름표는 투데이·배지·체크인·미션·인벤토리다(기존 캔버스 결정, 이름표 문구는 이 티켓 범위 밖).
