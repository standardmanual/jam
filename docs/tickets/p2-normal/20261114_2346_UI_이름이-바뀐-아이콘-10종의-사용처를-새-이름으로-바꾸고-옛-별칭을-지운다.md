# [UI] 이름이 바뀐 아이콘 10종의 사용처를 새 이름으로 바꾸고 옛 별칭을 지운다 (2회차)

## 핵심 요약

- 요구사항: 1회차(20261114_2345)에서 남긴 옛 이름 별칭 10개를 쓰는 곳을 모두 새 이름으로 바꾸고, `icons.tsx`·DS `IconCatalog`에서 별칭을 지운다. 화면 모양은 바뀌지 않는 이름 교체다.
- 구현 계획: 아래 대응표대로 import와 JSX 이름을 바꾼다. 시험·스토리·DS 패턴 파일도 포함한다. 1회차 머지 뒤에 시작한다.
- 관련 파일(이름 쓰는 곳, 2026-11-14 기준 `grep -w`):
  - 서비스: `src/app/(main)/FeedSection.tsx`, `badges/BadgesClient.tsx`, `badges/[id]/page.tsx`, `collections/[id]/ItemBookHeroSection.tsx`, `collections/[id]/page.tsx`, `combine/CombineClient.tsx`, `combine/PendingResultsSheet.tsx`, `combine/RecipeRewardRow.tsx`, `combine/TierUpPanel.tsx`, `inventory/[itemId]/LockedItemDetail.tsx`, `inventory/page.tsx`, `missions/MissionsListClient.tsx`, `missions/[id]/MissionDetailClient.tsx`, `notifications/NotificationsClient.tsx`, `dev-sample/item-badge-serial/page.tsx`, `components/PoiCarouselModal.tsx`, `components/admin/ops/OpsKindPreview.tsx`, `components/today/resourceIcon.ts`, `components/ui/CollectionGridCard.tsx`, `components/ui/icons.tsx`(별칭 삭제)

## 배경 / 문제 정의

사용자가 그림이 바뀐 아이콘은 이름도 바꾸라고 결정했다(상위 20261114_2344). 1회차는 화면이 깨지지 않게 옛 이름을 별칭으로 남겼으니, 이 회차에서 사용처를 옮기고 별칭을 없앤다.
