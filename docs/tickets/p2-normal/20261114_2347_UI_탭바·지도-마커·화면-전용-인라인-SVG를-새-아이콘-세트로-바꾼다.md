# [UI] 탭바·지도 마커·화면 전용 인라인 SVG를 새 아이콘 세트로 바꾼다 (3회차)

## 핵심 요약

- 요구사항: 컴포넌트 안에 직접 그린 아이콘을 1회차(20261114_2345)의 새 아이콘으로 바꾼다. 하단 탭바 5종(켜짐=채움, 꺼짐=라인), 지도 마커 원 안 그림(보물 상자, 드랍 있음=채움·없음=라인, 원 색은 그대로), 퀘스트 픽업 장면 마커, 지도 현재 위치 버튼, 오류 화면, 접근 불가 화면, 온보딩 체크. DS `navigation/TabBar.jsx` 사본도 맞춘다.
- 구현 계획: 아래 「구현 계획」. 1회차 머지 뒤에 시작한다.
- 관련 파일:
  - `jam-web/src/components/ui/TabBar.tsx` `baseTabs`(약 100~180줄, 탭마다 `iconFill`·`iconLine` 인라인 SVG, 체크인 탭의 `translate(-48,48) scale(1.1)` 보정 포함)
  - `jam-web/design-system/components/navigation/TabBar.jsx`(DS 사본)
  - `jam-web/src/components/map/MapView.tsx` `BADGE_FILL_PATH`·`BADGE_LINE_PATH`(약 168~175줄), `dropMarkerIconHtml`(약 190~202줄, HTML 문자열로 마커를 만든다), 현재 위치 버튼 SVG(약 643~650줄, 파란 점 `#4285F4`)
  - `jam-web/src/app/(main)/drops/QuestPickupScene.tsx`(약 141~150줄, `BADGE_FILL_PATH`를 `dangerouslySetInnerHTML`로 그림)
  - `jam-web/src/app/error.tsx` `WarningIcon`(8~24줄), `jam-web/src/app/forbidden/page.tsx` `ForbiddenIcon`(3~9줄), `jam-web/src/app/(onboarding)/onboarding/page.tsx`(약 460줄 체크 SVG)
  - 관련 시험: `QuestPickupScene.test.tsx`, MapView 마커 시험(있으면), `TabBar` 시험

## 배경 / 문제 정의

탭바만 Material Symbols 채움형을 따로 써서 다른 아이콘과 선·질감이 어긋났고, 지도 마커와 몇몇 화면은 컴포넌트 안에 각자 그린 그림을 쓴다. 새 세트로 모아 한 곳에서 관리한다.

## 상세 요구사항

### 서비스/코드베이스 관점

- **탭바**: 투데이=`HomeIcon`, 배지=`MedalIcon`, 체크인=`CheckinIcon`, 미션=`TicketIcon`, 인벤토리=`CrateIcon`. 켜진 탭은 `variant="fill"`, 꺼진 탭은 `"line"`. Material Symbols 경로와 체크인 탭 확대 보정은 지운다. 크기 `w-6 h-6`, 슬라이딩 필·이름표 동작은 그대로.
- **지도 마커**: 원(드랍 있음=`--jam-green`, 없음=`--muted`, 반투명·테두리 규칙)은 그대로 두고 원 안 그림만 `TreasureBoxIcon`으로 바꾼다. 드랍 있음=채움, 없음=라인. 글자색은 지금 규칙(초록 위 `--foreground`, 회색 위 `--snow`) 그대로. `dropMarkerIconHtml`은 HTML 문자열을 만드므로, 같은 그림의 SVG 문자열을 만드는 방법(예: `renderToStaticMarkup` 또는 1회차 렌더러가 내보내는 문자열 함수)을 쓴다. 채움 판의 비운 면은 초록이 비쳐 보여야 한다(흰색으로 칠하지 않는다).
- **퀘스트 픽업 장면**: 같은 마커 그림(채움)을 쓴다. `BADGE_FILL_PATH` 내보내기를 쓰는 곳이 없어지면 지운다.
- **현재 위치 버튼**: `LocateIcon`(라인). 파란 점은 없애고 단색으로(사용자 결정). 색은 지금 버튼 글자색(`text-muted`) 그대로.
- **오류 화면**: `WarningIcon`을 `AlertCircleIcon`(라인, 48px)으로. **접근 불가**: `ForbiddenIcon`을 `BanIcon`(라인, 48px)으로. **온보딩 체크**: 인라인 체크를 `CheckIcon`(라인)으로, 크기·색(`var(--foreground)`)은 그대로.
- **DS `navigation/TabBar.jsx`**: 서비스 탭바와 같은 아이콘·같은 켜짐/꺼짐 규칙으로 맞춘다.

## 구현 계획

1. `TabBar.tsx`: `baseTabs`의 `iconFill`·`iconLine`을 `<HomeIcon variant="fill" className="w-6 h-6" />` 꼴로 바꾼다.
2. `MapView.tsx`: 마커 그림을 `TreasureBoxIcon` 문자열로 만들고 `BADGE_FILL_PATH`·`BADGE_LINE_PATH`를 대체한다. 현재 위치 버튼을 `LocateIcon`으로.
3. `QuestPickupScene.tsx`: 마커 그림을 2번과 같은 것으로.
4. `error.tsx`·`forbidden/page.tsx`·`onboarding/page.tsx`: 인라인 SVG를 새 아이콘으로.
5. DS `TabBar.jsx` 동기화, 관련 시험 갱신, `scripts/verify.sh` 통과.

## 완료 조건

- 탭바 다섯 탭이 새 아이콘을 쓰고, 켜진 탭은 채움·꺼진 탭은 라인이다. `TabBar.tsx`에 `viewBox="0 -960 960 960"`이 남아 있지 않다.
- 지도 마커 원 색·투명도·테두리는 그대로이고, 원 안 그림이 보물 상자(드랍 있음=채움, 없음=라인)다. 채움 판 상자의 비운 면으로 원 색(초록)이 보인다.
- 퀘스트 픽업 장면 마커가 같은 그림이다.
- 현재 위치 버튼에 파란색(`#4285F4`)이 없다.
- 오류·접근 불가·온보딩 체크가 새 아이콘을 쓴다.
- DS `TabBar.jsx`가 서비스 탭바와 같은 아이콘을 쓴다. `scripts/verify.sh`가 통과한다.
