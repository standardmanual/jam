# [UI] 배지 공유를 투명 배지 이미지 한 장과 복사·저장·더보기 버튼으로 바꾼다 (상위)

## 핵심 요약

- 요구사항: 배지 상세의 «공유하기» 시트를 바꾼다. 사용자 요청 원문(2026-11-15 12:44 KST):
  «1. 배지 이미지만 투명 배경으로 공유함 2. 바텀시트에 투명 체크패턴 카드 안에 배지 이미지를 보여줌 3. 하단에 다음 기능 버튼 제공 — 복사하기: 클립보드에 복사함 / 저장: 기기 앨범에 저장(PC는 브라우저 지정 폴더에 저장) / 더보기: 모바일 기기의 공유 시트 호출 4. 각 버튼의 아이콘도 필요»
- 구현 계획: 두 회차로 나눈다. 1회차 아이콘 3종을 세트에 더한다(20261115_1248, ds) → 2회차 공유 시트를 바꾸고 기록 카드 코드를 지운다(20261115_1249, ui). 2회차는 1회차 머지 뒤에 시작한다(아이콘을 import하므로).
- 관련 파일: 1회차 `jam-web/src/components/ui/icons.tsx`·DS `IconCatalog`·사양 `docs/assets/prototypes/icon-set-v2/spec.json`, 2회차 `jam-web/src/app/(main)/badges/[id]/BadgeShareButton.tsx`·`buildBadgeShareBlob.ts`·`page.tsx`, `jam-web/src/app/api/badges/[id]/share-data/`, 문서 `docs/service/prd/badge-share/PRD.md`.

## 배경 / 문제 정의

- 지금 공유 시트는 캐러셀 두 장이다. 첫 장은 Strava 기록(거리·페이스·시간)을 넣은 1080×1920 카드, 둘째 장은 300px 배지 이미지다. 버튼은 «공유하기»(OS 공유 시트)와 «저장하기» 둘이다(티켓 20260911_1102, 20261111_0801).
- 사용자는 배지 이미지 한 장만 투명 배경으로 공유하고, 버튼을 복사·저장·더보기 셋으로 바꾸기를 원한다.

## 상세 요구사항

사용자 확인을 거친 결정(2026-11-15):

1. 시트 모양과 아이콘은 캔버스 확인 없이 바로 구현한다(채원 사전 판정을 따른다). 아이콘 3종의 조각은 카리나가 세트 규칙으로 그려 1회차 티켓에 넣었다.
2. OS 공유 시트를 열 수 없는 브라우저(주로 PC)에서는 «더보기» 버튼을 숨기고 두 버튼만 보인다.
3. 기록 카드(1080×1920)를 만드는 코드, 기록을 가져오는 `share-data` API, 관련 시험을 이번에 지운다.
4. 공유 이미지는 지금처럼 300×300 투명 PNG다(`buildBadgeImageBlob` 그대로).

카리나가 세운 가정(사용자에게 보인 목록, 이의 없음):

- 버튼 이름은 «복사하기 · 저장하기 · 더보기»로 끝맺음을 맞춘다.
- iPhone은 웹에서 사진 앱에 바로 쓰는 API가 없다. «저장하기»는 지금처럼 안내 토스트 뒤 OS 공유 시트를 연다(실기기에서 확인한 유일한 경로, 티켓 20260903_1122). Android는 다운로드 폴더(갤러리에 보임), PC는 브라우저 다운로드 폴더에 저장한다.
- 이미지 복사를 지원하지 않는 브라우저에서 «복사하기»를 누르면 오류 토스트로 «저장하기»를 안내한다.
- 아이콘은 새 세트 규칙(48 격자, 라인)으로 그린다.
- 바텀시트 캔버스 티켓(20261110_2150)의 ⑦ 배지 공유 미리보기 수치(좌우 24px, 버튼 56px)를 이번에 함께 반영한다.
