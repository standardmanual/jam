# [UI] 배지 공유 시트를 체크무늬 카드 한 장과 복사·저장·더보기 버튼으로 바꾸고 기록 카드를 지운다 (2회차)

## 상세 요구사항

### 서비스/코드베이스 관점

1. **공유 대상**: 배지 이미지 한 장, `buildBadgeImageBlob`이 만드는 300×300 투명 PNG 그대로다. 파일 이름은 `${badgeName}-badge.png`.
2. **시트 본문**: 캐러셀을 없애고 투명 체크무늬 카드 하나 안에 배지 이미지를 보인다. 체크무늬는 지금 슬라이드의 `repeating-conic-gradient`(20px, `--foreground` 8%)를 그대로 쓴다. 시트 높이(`detent`)·카드 비율·미리보기 배율은 채원 판정을 따른다. 로딩(`WanderingEyesLoader`, 디바운스)·오류(`errorCopy`의 일반 실패 문구)·스크린 리더 알림(`role="status"`) 동작은 지금과 같다.
3. **버튼 셋**(이미지가 준비됐을 때만 footer에 보인다, 지금과 같음):
   - **복사하기**(`CopyIcon`): `navigator.clipboard.write([new ClipboardItem({ 'image/png': blob })])`. Safari는 사용자 동작 안에서 바로 불러야 하므로 클릭 핸들러에서 `await` 없이 `write`를 시작한다. 성공 토스트, 실패 토스트를 띄운다. `ClipboardItem`이나 `clipboard.write`가 없으면 실패 토스트로 «저장하기»를 안내한다.
   - **저장하기**(`DownloadIcon`): 지금 `handleSave` 그대로(iOS는 안내 토스트 뒤 OS 공유 시트, 그 밖은 `<a download>` 뒤 성공 토스트).
   - **더보기**(`MoreIcon`): `navigator.share({ files: [file] })`. 이미지가 준비된 시점에 `navigator.canShare({ files: [file] })`가 참일 때만 보인다. 거짓이면(주로 PC) 버튼을 숨기고 두 버튼만 보인다. 취소(`AbortError`)는 조용히 넘긴다.
   - 아이콘은 라인(`variant` 생략)이다. 버튼 배치(아이콘·이름표 위치, 두 개일 때의 폭)는 채원 판정을 따른다. 바텀시트 캔버스 티켓 20261110_2150 ⑦의 수치(좌우 24px, 버튼 높이 56px)를 지킨다.
4. **지우는 것**:
   - `BadgeShareButton`: 캐러셀·`ShareItemKind`·카드 상태·카드 생성 effect·`KNOWN_ERROR_REASONS`·서버 문구 처리, 속성 `stravaConnected`·`subjectUsername`·`level`·`earnCount`
   - `buildBadgeShareBlob.ts`: 카드 합성 전부. 남는 `buildBadgeImageBlob`·`drawContain`은 `buildBadgeImageBlob.ts`로 파일 이름을 바꾼다.
   - `page.tsx`: 공유 전용이던 `strava_connections` 조회·`stravaConnected`·`resolveStravaConnectionState` import, 호출 3곳의 지운 속성. (`level`·`earnCount` 값을 다른 데서 쓰면 값은 그대로 둔다.)
   - `share-data` API 폴더 전체.
   - `ko.ts`: 쓰지 않게 되는 키(`shareActionShare`, `shareErrorStrava*`·`shareErrorNoTrigger*`·`shareErrorFetchFailed*`·`shareErrorActivityNotFound*`, `shareCarouselAriaLabel`·`shareCardGroupLabel`·`shareBadgeGroupLabel`). 지우기 전에 `src` 전체 grep으로 다른 사용처가 없는지 확인한다.
5. **새 문구**(`ko.ts` `badges`): 버튼 이름 `shareActionCopy: '복사하기'`, `shareActionDownload: '저장하기'`(기존), `shareActionMore: '더보기'`. 복사 성공 «이미지를 복사했어요», 복사 실패는 UX Writing 가이드의 [현상]→[원인]→[해결책] 구조로 쓴다(예: «이미지를 복사하지 못했어요. 이 브라우저는 이미지 복사를 지원하지 않아요. 저장하기를 눌러 주세요.»).

### UI/UX 관점

- 시트 진입 버튼(콘텐츠 끝의 전체 폭 «공유하기», 미획득 시 흐린 모양과 안내 팝오버)은 바꾸지 않는다.
- 공유 시트가 열려 있는 동안 탭바를 숨기는 동작(`pushTabBarHidden`)은 그대로다.

## 구현 계획

1. `buildBadgeShareBlob.ts` → `buildBadgeImageBlob.ts`: `drawContain`·`BADGE_IMAGE_ONLY_SIZE`·`buildBadgeImageBlob`만 남기고 나머지를 지운다. 머리 주석을 새 용도에 맞게 고친다.
2. `BadgeShareButton.tsx`: 상태를 `ShareItemState` 하나로 줄이고, 배지 이미지 effect만 남긴다. 본문은 체크무늬 카드 하나, footer는 버튼 셋(더보기는 `canShare` 판정으로 조건부). `handleCopy`를 새로 두고 `handleAction`은 `handleMore`로 이름을 바꿔 공유 시트만 연다(다운로드 대체 경로는 «더보기»가 숨겨지므로 지운다). `handleSave`의 iOS 경로가 쓰는 공유 시트 호출은 `handleMore`를 재사용한다.
3. `page.tsx`: 공유 전용 조회와 속성을 걷는다.
4. `share-data` 폴더 삭제.
5. `ko.ts`: 키 정리와 새 문구.
6. 시험: `shareButtonPlacement.test.ts`·`notEarnedCard.test.ts`를 새 구조에 맞추고, `BadgeShareButton.test.tsx`를 새로 쓴다(준비 뒤 버튼 셋, `canShare` 거짓이면 두 개, 복사 성공·미지원 토스트, 더보기가 `navigator.share`를 부르는지, 저장이 iOS가 아닐 때 내려받기를 하는지).
7. 문서: `docs/service/prd/badge-share/PRD.md`를 새 동작(한 장, 버튼 셋, 플랫폼별 저장 동작, 더보기 숨김 조건, 기록 카드 폐지와 근거 티켓)으로 갱신하고, 다른 `docs/service/` 문서의 현재 동작 서술을 맞춘다.
8. `scripts/verify.sh`를 돌린다.

## 완료 조건

- 시트에 캐러셀이 없고 체크무늬 카드 한 장 안에 배지 이미지가 보인다.
- 이미지가 준비되면 «복사하기»·«저장하기»·«더보기»가 각 아이콘과 함께 보이고, `canShare`가 거짓이면 «더보기»가 없다.
- 복사는 `image/png` 클립보드 쓰기를 하고, 성공·실패 토스트가 뜬다.
- `buildBadgeShareBlob`·`BadgeShareStats`·`share-data`·`stravaConnected`가 `jam-web/src`에 남아 있지 않다(`grep -rn "buildBadgeShareBlob\|BadgeShareStats\|share-data\|stravaConnected" jam-web/src`가 0건).
- `scripts/verify.sh`가 통과한다(staging에 원래 있던 실패 7건은 티켓 20261115_0030).
