# [UI] 아이폰 사파리에서 하단 탭 바가 떠 보이고 지도 화면 아래에 띠가 남는 문제를 고친다

## 핵심 요약

- 요구사항: 아이폰 12 mini 사파리(staging)에서 (1) 주소창 근처에 남는 여백이 화면마다 다르다. 체크인 지도 화면은 지도 아래에
  빈 띠가 보이고, 미션 화면은 본문이 주소창까지 이어진다. (2) 하단 탭 바를 더 아래로 붙이고 싶다(사용자 요청 2026-11-15, 캡처 2장).
- 구현 계획: 먼저 그 기기의 사파리가 화면 아래쪽을 어떻게 계산하는지 측정 화면으로 확인한다. 그 값으로 탭 바의 위치 식과
  지도 화면의 아랫변을 고친다. **측정 화면의 배포와 사용자 기기에서의 확인이 먼저 필요하다(승인 대기).**
- 관련 파일(지도):
  - `jam-web/src/components/ui/TabBar.tsx` 408행 `bottom: max(10px, calc(env(safe-area-inset-bottom) + 16px - 32px))`
  - `jam-web/design-system/components/navigation/TabBar.jsx`(같은 식을 쓰는 병존 구현)
  - `jam-web/src/app/(main)/drops/DropsClient.tsx` 336행(지도 화면 컨테이너 `fixed inset-0`), 302행(탭 바 높이를 전제한 아래 여백)
  - `jam-web/src/app/(main)/layout.tsx` 95~98행(본문 래퍼 `min-h-dvh`, 회색 바탕)
  - `docs/plan/jam2/11 JAM 2.0 디자인 시스템.md`(탭 바 위치 식의 서술)

## 범위 변경 (2026-11-15)

- **하단 탭 바를 더 아래로 내리는 요청은 사용자가 취소했다.** 탭 바의 위치 식과 최소 여백 10px은 그대로 둔다
- 지도 화면 아래에 남는 띠는 진행 여부가 정해지지 않았다. 원인이 탭 바와 같고(이 사파리의 `fixed` 기준선), 고치려면 아래의
  측정 화면 배포와 사용자 기기에서의 확인이 필요하다. 사용자 확인 전에는 아무것도 배포하지 않는다

## 배경 / 문제 정의

### 확인한 사실 (2026-11-15)

**캡처에서 잰 위치** (아이폰 12 mini, 화면 높이 780pt로 환산한 값이며 오차는 2pt 안팎이다)

| 위치 | 체크인 지도 화면 | 미션 화면 |
|---|---|---|
| 탭 바 아랫변 | 약 623pt | 약 623pt |
| 화면 내용의 아랫변 | 약 632pt(지도가 여기서 끝난다) | 약 648pt(본문이 사파리 도구 막대까지 이어진다) |
| 사파리 도구 막대 윗변 | 약 648pt | 약 648pt |

- 지도 화면에는 지도 아랫변과 사파리 도구 막대 사이에 약 16pt의 띠가 있고, 본문 래퍼의 회색 바탕이 보인다
- 탭 바 아랫변은 지도 아랫변에서 약 10pt 위, 사파리 도구 막대에서는 약 26pt 위에 있다

**코드**

- 탭 바는 `position: fixed`이고 아래 여백의 하한이 10px이다. 지도 화면 컨테이너도 `fixed inset-0`이다. 미션 화면의 본문은 문서 흐름이다
- 하한 10px은 사용자 결정이다. 티켓 20260824_013에서 하한을 0px로 두었다가, 탭 바가 화면 맨 아래에 붙어 버린다는 사용자 요청으로
  티켓 20260824_014에서 10px로 되돌렸다

**외부 보고** (직접 재현하지 못했다. 이 컴퓨터에는 iOS 시뮬레이터 런타임이 없다)

- iOS 26 사파리에서 `position: fixed` 내용이 브라우저 도구 막대 아래쪽 영역에 그려지지 않는다는 보고가 Apple 개발자 포럼에 있다
  (https://developer.apple.com/forums/thread/800798, https://developer.apple.com/forums/thread/800125)
- 같은 검색 결과에 «Safari 26.1 베타 릴리스 노트가 뷰포트 크기의 fixed 컨테이너 아래에 틈이 생기는 문제의 수정을 싣고 있다»는
  언급이 있다. 사용자 기기의 iOS 버전은 확인하지 못했다

### 판단

- 두 현상은 원인이 같다. 이 사파리에서는 `fixed` 요소의 아래 기준선이 도구 막대보다 약 16pt 위에 있고, 문서 흐름의 본문은
  도구 막대까지 그려진다. 그래서 `fixed`인 지도는 띠를 남기고, `fixed`인 탭 바는 의도한 10pt가 아니라 26pt 떠 보인다
- 하한 10px을 그냥 낮추면 이 사파리에서는 내려가지만, 다른 기기(안드로이드, 구형 아이폰)에서는 탭 바가 다시 맨 아래에 붙는다.
  2026-08-24에 되돌린 상태다. 그래서 «이 사파리의 16pt»만 보정해야 한다
- 보정 방법을 정하려면 그 기기에서 CSS·JS가 이 차이를 볼 수 있는지 알아야 한다. 후보는 `sticky` 배치, `dvh`·`svh`·`lvh` 단위,
  `visualViewport`와 `fixed` 요소 위치의 비교다. 어느 것이 통하는지는 실제 기기에서만 알 수 있다

## 상세 요구사항

### 진행 순서 (승인 대기)

1. **측정 화면**: `/spike/viewport-probe`(로그인 없이 열리는 경로)에 측정 화면을 둔다. `fixed`·`sticky` 표지선, `dvh`·`svh`·`lvh` 표지선,
   `innerHeight`·`visualViewport`·`safe-area-inset-bottom` 값, 브라우저 버전을 한 화면에 보인다. staging에 배포한다
2. **기기 확인**: 사용자가 아이폰 사파리로 그 화면을 열어 캡처를 보낸다
3. **수정**: 측정 결과로 탭 바의 위치 식(서비스와 디자인 시스템 두 곳)과 지도 화면의 아랫변을 고친다. 다른 기기에서의 여백 10px은 유지한다

### UI/UX 관점

- 눈에 보이는 변화가 있다(탭 바의 위치, 지도 화면의 아랫변). 3번은 채원 사전 판정을 거친다
- 목표: 이 사파리에서도 탭 바가 도구 막대 위 약 10pt에 놓이고, 지도가 도구 막대까지 이어진다

## 구현 계획

### 1단계: 측정 화면 (사용자 결정 2026-11-15, «띠는 진행»)

새 파일 하나만 만든다: `jam-web/src/app/spike/viewport-probe/page.tsx`. `/spike`는 로그인 없이 열리는 경로다(`jam-web/src/proxy.ts` 49·66행).
다른 파일은 고치지 않는다. 확인이 끝나면 이 화면은 지운다(2단계에서).

화면 구성

- 세로 띠 여섯 개를 나란히 그린다. 띠마다 아랫변을 정하는 방법이 다르다
  1. `fixed`, `top: 0; bottom: 0`
  2. `fixed`, `top: 0; height: 100dvh`
  3. `fixed`, `top: 0; height: 100lvh`
  4. `fixed`, `top: 0; bottom: -60px`
  5. `absolute`(문서 흐름), `top: 0; height: 100dvh`
  6. `absolute`(문서 흐름), `top: 0; height: 100lvh`
- 띠 안에는 20px 간격의 눈금과 100px마다 «띠 번호·세로 좌표» 글자를 넣는다. 캡처에서 어느 띠가 사파리 도구 막대까지 이어지는지 보인다
- 오른쪽에 문서 좌표 눈금자(높이 1,100px, 50px마다 숫자)를 둔다
- 위쪽에 수치 패널을 고정한다: `innerHeight`, `visualViewport`의 높이·`offsetTop`·`pageTop`, `documentElement.clientHeight`, `screen` 크기,
  배율, `safe-area-inset-top`·`bottom`, `100svh`·`100dvh`·`100lvh`·`100vh`의 px 값, 띠 여섯 개의 `getBoundingClientRect().bottom`,
  홈 화면 앱 여부, iOS·사파리 버전
- 크기 변화·스크롤 때 다시 잰다

코드는 아래를 그대로 쓴다. lint·타입 오류가 나면 동작을 바꾸지 않는 범위에서 고친다.

```tsx
'use client'

// 측정용 화면(티켓 20261115_1557) — 아이폰 사파리가 화면 아래쪽을 어떻게 계산하는지 캡처 한 장으로 확인한다.
// 주소: /spike/viewport-probe (로그인 없이 열린다). 확인이 끝나면 지운다.

import { useEffect, useRef, useState, type CSSProperties } from 'react'

const COLUMNS: { label: string; name: string; color: string; style: CSSProperties }[] = [
  { label: '1', name: 'fixed top0 bottom0', color: 'rgba(239,68,68,.5)', style: { position: 'fixed', top: 0, bottom: 0 } },
  { label: '2', name: 'fixed 100dvh', color: 'rgba(249,115,22,.5)', style: { position: 'fixed', top: 0, height: '100dvh' } },
  { label: '3', name: 'fixed 100lvh', color: 'rgba(234,179,8,.55)', style: { position: 'fixed', top: 0, height: '100lvh' } },
  { label: '4', name: 'fixed bottom-60', color: 'rgba(34,197,94,.5)', style: { position: 'fixed', top: 0, bottom: -60 } },
  { label: '5', name: 'abs 100dvh', color: 'rgba(59,130,246,.5)', style: { position: 'absolute', top: 0, height: '100dvh' } },
  { label: '6', name: 'abs 100lvh', color: 'rgba(168,85,247,.5)', style: { position: 'absolute', top: 0, height: '100lvh' } },
]
const UNITS = ['100svh', '100dvh', '100lvh', '100vh'] as const
const TICKS = 'repeating-linear-gradient(to bottom, rgba(0,0,0,.45) 0 1px, transparent 1px 20px)'
const MARKS = [300, 400, 500, 600, 700, 800, 900, 1000]
const RULER = Array.from({ length: 17 }, (_, i) => 250 + i * 50)

export default function Page() {
  const colRefs = useRef<(HTMLDivElement | null)[]>([])
  const unitRefs = useRef<(HTMLDivElement | null)[]>([])
  const safeRef = useRef<HTMLDivElement | null>(null)
  const [rows, setRows] = useState<string[]>([])

  useEffect(() => {
    const r1 = (n: number) => String(Math.round(n * 10) / 10)
    const measure = () => {
      const vv = window.visualViewport
      const safe = safeRef.current ? getComputedStyle(safeRef.current) : null
      const ua = navigator.userAgent
      const os = (ua.match(/OS (\d+[_\d]*)/) || [])[1]?.replace(/_/g, '.') ?? '?'
      const ver = (ua.match(/Version\/([\d.]+)/) || [])[1] ?? '?'
      const standalone = (navigator as Navigator & { standalone?: boolean }).standalone === true
      setRows([
        `inner ${window.innerWidth}x${window.innerHeight} · client ${document.documentElement.clientHeight} · scrollY ${r1(window.scrollY)}`,
        `visual h ${vv ? r1(vv.height) : '-'} · offsetTop ${vv ? r1(vv.offsetTop) : '-'} · pageTop ${vv ? r1(vv.pageTop) : '-'} · scale ${vv ? r1(vv.scale) : '-'}`,
        `screen ${screen.width}x${screen.height} · dpr ${window.devicePixelRatio} · safe top ${safe?.paddingTop ?? '-'} bottom ${safe?.paddingBottom ?? '-'}`,
        UNITS.map((u, i) => `${u.slice(3)} ${r1(unitRefs.current[i]?.getBoundingClientRect().height ?? 0)}`).join(' · '),
        COLUMNS.map((c, i) => `${c.label}=${r1(colRefs.current[i]?.getBoundingClientRect().bottom ?? 0)}`).join(' · '),
        `iOS ${os} · Safari ${ver} · standalone ${standalone ? 'Y' : 'N'}`,
      ])
    }
    measure()
    const vv = window.visualViewport
    window.addEventListener('resize', measure)
    window.addEventListener('scroll', measure, { passive: true })
    vv?.addEventListener('resize', measure)
    vv?.addEventListener('scroll', measure)
    const timer = setInterval(measure, 1000)
    return () => {
      window.removeEventListener('resize', measure)
      window.removeEventListener('scroll', measure)
      vv?.removeEventListener('resize', measure)
      vv?.removeEventListener('scroll', measure)
      clearInterval(timer)
    }
  }, [])

  return (
    <div style={{ position: 'relative', minHeight: 1100, background: '#f3f4f6', color: '#111', fontFamily: 'ui-monospace, Menlo, monospace' }}>
      {COLUMNS.map((c, i) => (
        <div
          key={c.label}
          ref={(el) => { colRefs.current[i] = el }}
          style={{ ...c.style, left: `${i * 14}%`, width: '13%', backgroundColor: c.color, backgroundImage: TICKS, overflow: 'hidden', zIndex: 1 }}
        >
          {MARKS.map((y) => (
            <span key={y} style={{ position: 'absolute', top: y, left: 2, fontSize: 11, fontWeight: 700, lineHeight: '12px' }}>
              {c.label}·{y}
            </span>
          ))}
        </div>
      ))}

      {/* 문서 좌표 눈금자 */}
      <div style={{ position: 'absolute', top: 0, left: '86%', width: '14%', height: 1100, backgroundColor: '#fff', backgroundImage: TICKS, zIndex: 1 }}>
        {RULER.map((y) => (
          <span key={y} style={{ position: 'absolute', top: y, left: 2, fontSize: 11, lineHeight: '12px' }}>{y}</span>
        ))}
      </div>

      {/* 수치 패널 */}
      <div style={{ position: 'fixed', top: 'env(safe-area-inset-top)', left: 0, right: 0, zIndex: 5, background: 'rgba(255,255,255,.94)', padding: '6px 8px', fontSize: 11, lineHeight: '15px', borderBottom: '1px solid #111' }}>
        <div style={{ fontWeight: 700 }}>맨 위에 둔 채로 캡처해 주세요</div>
        {rows.map((row) => (
          <div key={row}>{row}</div>
        ))}
        <div>{COLUMNS.map((c) => `${c.label} ${c.name}`).join(' / ')}</div>
      </div>

      {/* 단위와 안전 영역을 재는 보이지 않는 요소 */}
      {UNITS.map((u, i) => (
        <div key={u} ref={(el) => { unitRefs.current[i] = el }} style={{ position: 'fixed', top: 0, left: 0, width: 0, height: u, visibility: 'hidden', pointerEvents: 'none' }} />
      ))}
      <div ref={safeRef} style={{ position: 'fixed', top: 0, left: 0, width: 0, height: 0, paddingTop: 'env(safe-area-inset-top)', paddingBottom: 'env(safe-area-inset-bottom)', visibility: 'hidden', pointerEvents: 'none' }} />
    </div>
  )
}
```

### 1단계 결과: 측정 캡처 1 (2026-11-15 16:41, 아이폰 12 mini, 스크롤 0)

| 항목 | 값 |
|---|---|

| `100svh`·`100dvh` | 610 |
| `100lvh`·`100vh` | 704 |
| `safe-area-inset-top`·`bottom` | 0px·0px |

**캡처의 픽셀에서 잰 값** (캡처는 1,125×2,436px, 3px = 1pt)

| 캡처 | 내용이 끝나는 곳 | 그 아래 |
|---|---|---|
| 측정 화면 | 여섯 띠와 눈금자 모두 660pt(뷰포트 610) | 660~675pt는 단색 `#e1e1e1`, 676pt부터 사파리 도구 막대 |
| 지도 화면(15:50) | 지도가 약 657pt | 658~674pt는 단색 `#e8e8e8`~`#ebebeb` |
| 미션 화면(15:51) | 카드 그림이 약 674pt까지 보인다 | 675pt부터 도구 막대 |

- 처음에 캡처의 좌표를 화면 표시 크기(924×2,000)로 환산해 적은 값은 틀렸다. 위 표가 원본 픽셀로 다시 잰 값이다.
  뷰포트의 원점은 화면 50pt이고, 띠는 뷰포트 610~625 구간(약 15pt)이다

**판단**

- `fixed` 요소는 뷰포트 아랫변(610) 아래로 그려지지 않는다. 704까지 늘린 3번과 670까지 늘린 4번도 610에서 잘렸다.
  지도 화면은 `fixed inset-0`이므로, 지금 구조로는 띠를 채울 방법이 없다
- 문서 흐름인 5·6번과 눈금자도 스크롤 0에서는 띠에 보이지 않았다. 그런데 미션 화면에서는 본문이 띠까지 보인다.
  차이의 원인은 아직 모른다. 스크롤 상태에 따라 달라지는지를 측정 화면을 조금 스크롤한 캡처로 확인해야 한다
