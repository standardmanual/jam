# [Infra] JAM 2.0을 프로덕션에 올린 뒤 배지 그림의 변환본을 일괄 예열한다

## 핵심 요약

- 요구사항: 변환 캐시는 Vercel 프로젝트마다 따로다. staging에서 한 일괄 예열(티켓 20261115_1620)은 프로덕션에 적용되지 않는다.
- 구현 계획: JAM 2.0을 main에 올린 직후에 프로덕션 출처를 대상으로 일괄 예열 스크립트를 한 번 실행한다.
- 관련 파일: `jam-web/scripts/warm-badge-image-variants.mjs`, `docs/service/prd/asset-generator/PRD.md` §9.1

## 배경 / 문제 정의

- staging에서는 그림 599장, 요청 2,396건을 약 3분에 예열했고 실패가 없었다(2026-11-15)
- 대상 목록은 그날의 DB에서 다시 뽑는다. 활성 배지와 컬렉션의 저장소 주소에서 중복을 뺀다
- 프로덕션에 올라가 있는 코드가 JAM 2.0 이전이면 화면이 쓰는 폭이 다를 수 있다. 그래서 출시 뒤에 실행한다

## 완료 조건

- 프로덕션 출처로 실행한 결과(요청 수, `x-vercel-cache` 분포, 실패 수)가 완료 기록에 있다
- 같은 목록을 다시 요청했을 때 모두 HIT다
