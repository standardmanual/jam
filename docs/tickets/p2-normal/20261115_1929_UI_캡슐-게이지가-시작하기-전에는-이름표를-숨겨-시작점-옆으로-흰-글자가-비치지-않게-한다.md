# [UI] 캡슐 게이지가 시작하기 전에는 이름표를 숨겨 시작점 옆으로 흰 글자가 비치지 않게 한다

## 핵심 요약

- 요구사항: 홈 캡슐 게이지가 로딩될 때(채움이 2% 원일 때) 시작점(빨간 원) 뒤로 흰 글자가 보인다. 사용자 요청(2026-11-15 19:27경 KST, 아이폰 사파리 화면 캡처): «캡슐게이지가 로딩될때 시작점 뒤에 흰색 글씨가 보여. 수정해»
- 구현 계획: «캡슐» 이름표 두 겹(트랙 위 흰 글자, 채움 안쪽 어두운 글자)에 숫자와 같은 조건(`showNumber`)으로 `opacity: 0`을 걸고 240ms 페이드로 나타나게 한다.
- 관련 파일: `jam-web/src/components/capsule/CapsuleGauge.tsx`(`LABEL_CLASS` 약 70줄, `labelStyle` 약 168줄), 시험 `CapsuleGauge.test.tsx`·`CapsuleGauge.entry.test.tsx`

## 배경 / 문제 정의

- 게이지 높이 36px에서 채움 원의 지름은 28px인데 이름표 «캡슐»은 왼쪽 12px부터 약 25px 폭이라 오른쪽 끝이 37px 근처에 있다. 채움이 2% 원일 때는 원 밖으로 나온 글자 일부가 트랙 위 흰 글자(`--snow`)로 드러나 시작점 옆에 «술» 조각이 보였다(티켓 20261113_1521에서 이름표를 더한 뒤 생긴 현상).

## 상세 요구사항

- 채움이 시작하기 전에는 이름표 두 겹을 모두 숨긴다. 숫자가 켜지는 순간(`numberReady && arrived`)에 같이 240ms로 나타난다. 모션 줄이기에서는 전환 없이 바로 보인다.
- 값이 0이면 채움이 원 하나로 남으므로 이름표도 보이지 않는다(숫자 «0»이 보이지 않는 기존 동작과 같다).

## 구현 계획

1. `LABEL_CLASS`에 `transition-opacity duration-[240ms] ease-[var(--ease-smooth-out)] motion-reduce:transition-none`을 더한다.
2. `labelStyle`에 `opacity: showNumber ? undefined : 0`을 더한다(이름표 세 곳이 이 값을 함께 쓴다).
3. 시험: 처음 그릴 때 이름표 두 겹이 투명한 것, 채움이 시작하면 나타나는 것을 고정한다.

## 완료 조건

- 처음 그릴 때(채움 시작 전) 이름표 두 겹의 `opacity`가 0이고 원 옆으로 글자가 비치지 않는다.
- 채움이 시작되면(`GAUGE_ENTRY_DELAY_MS` 뒤) 이름표가 나타난다.
- 막힘 문구가 있을 때는 이름표를 그리지 않는 기존 동작이 그대로다.
- 캡슐 시험·린트·타입 검사가 통과한다.
