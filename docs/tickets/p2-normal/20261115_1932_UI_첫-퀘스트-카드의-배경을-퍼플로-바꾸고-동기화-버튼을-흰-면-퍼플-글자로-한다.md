# [UI] 첫 퀘스트 카드의 배경을 퍼플로 바꾸고 동기화 버튼을 흰 면·퍼플 글자로 한다

## 핵심 요약

- 요구사항: 첫 가입 뒤 홈에 노출되는 «JAM! 시작하기» 퀘스트 카드의 배경에 퍼플 컬러(`--jam-purple`, #BA8AF7)를 쓰고, 그 카드 안 «동기화» 버튼은 흰 면에 퍼플 글자로 한다. 사용자 요청(2026-11-15 KST): «첫 퀘스트 카드의 배경을 퍼플 컬러를 상용하고 동기화 버튼은 화이트에 퍼플 컬러 텍스트로 해»(«상용»은 «사용»의 오타로 읽었다)
- 구현 계획: 직전 티켓 20261115_1804에서 카드 CTA를 «퍼플 면 + 검정 글자»로 칠한 것을 뒤집는다. 카드가 퍼플이 되므로 CTA는 «흰 면(`--snow`) + 퍼플 글자(`--jam-purple`)»가 된다. 카드 안 다른 요소(제목·설명·진행 바·칩·구분선·체크 목록·건너뛰기)와 펄스 링은 퍼플 면 위에서 읽히도록 채원 사전 판정이 정한다.
- 관련 파일:
  - `jam-web/src/app/(main)/OnboardingQuestCard.tsx`: 카드 `Card`(`DemoCard` 약 220줄, `RealCard` 약 187줄의 `<Card role="group" … className={CARD_CLASS}>`), `CARD_CLASS`(약 56줄), `DESC_CLASS`·`PROGRESS_LABEL_CLASS`(글자색 `text-muted`·`text-link`), `Divider`(`bg-border`), `ChecklistRow`(`text-muted`·`text-foreground`), `CTA_ROW_CLASS`·`CTA_ROW_PULSE_CLASS`(약 58~66줄, `jam-quest-cta`)
  - `jam-web/src/components/transitions.css` 약 667~720줄: `@keyframes jam-quest-pulse`(링 색), `.jam-quest-cta:is(button), .jam-quest-cta > button`(지금은 퍼플 면 + `--foreground` 글자)
  - DS: `jam-web/design-system/components/cards/Card.jsx`(`tone`·`style`로 면을 덮을 수 있다), `cards/LabelChip.jsx`(칩 면 `--background-secondary`), `feedback/ProgressBar.jsx`(트랙 `--border`, 채움 `--accent`)
  - 같은 `.jam-quest-cta`를 쓰는 다른 자리(믹스하기 `combine/CombineClient.tsx` 약 1250줄, 장소 캐러셀 `PoiCarouselModal.tsx` 약 910·982줄)는 퍼플 카드 위가 아니라 그대로 «퍼플 면 + 검정 글자»를 유지한다. 카드 안 CTA만 바꾼다.
  - 시험: `OnboardingQuestCard.test.tsx`(클래스 부착 시험 갱신), 문서: `docs/service/prd/home-feed/PRD.md` 퀘스트 카드 절(pre-commit이 요구)

## 배경 / 문제 정의

- 직전 작업(20261115_1804)은 흰 카드 위에서 CTA를 퍼플 면으로 칠해 «지금 누를 곳»을 알렸다. 사용자는 카드 전체를 퍼플로 하고 CTA는 흰 면으로 하는 쪽을 원한다. 카드 자체가 눈에 띄는 신호가 되고 CTA는 퍼플 면 위에서 흰 알약으로 도드라진다.

## 상세 요구사항

### UI/UX 관점

- 퀘스트 카드(연출 구역·실제 구역 모두)의 면 = `--jam-purple`. 카드 모서리·패딩·구조는 그대로다.
- 카드 안 «동기화»(연출 CTA, 실제 구역의 연결·동기화·«인벤토리 가기» 포함) = 면 `--snow`(흰색), 글자 `--jam-purple`. 퍼플 면 위 흰 알약이다.
- 대비 주의(채원이 판정): #BA8AF7은 흰 면 위 글자로 쓰면 대비가 약 2.6:1이다(작은 글자 기준 4.5:1에 못 미친다). 사용자가 CTA 글자색으로 **B(`color-mix` 진한 퍼플)**를 골랐다(2026-11-15). 새 토큰은 만들지 않는다.
- 퍼플 면 위 글자는 `--foreground`로 읽힌다(퍼플 위 6.89:1). 설명의 `text-muted`(#666, 퍼플 위 2.21:1)는 모자라서 바꾼다. 분수 라벨의 `text-link`는 `--link`가 검정이라 모자라지 않다(처음 이 문장은 `text-link`도 모자라다고 적었으나 틀렸고, 채원 판정이 바로잡았다). 진행 바 트랙(`--border`)·채움(`--accent`), 칩, 구분선, 체크 아이콘, «건너뛰기»(검정 소형)도 퍼플 위에서 구분되는지 본다.
- 펄스 링: 퍼플 카드 위에서 퍼플 링은 보이지 않는다. 카드 안 CTA 줄의 링 색을 카드 위에서 보이는 색(예: 흰색)으로 한다. 믹스하기·캐러셀·칸·마커의 링은 그대로 퍼플이다.

### 서비스/코드베이스 관점

- 카드 면과 카드 안 색은 호출부에 hex를 적지 않고 토큰만 쓴다(`var(--jam-purple)`, `var(--snow)`). 카드 한 곳에서 정의한다(클래스 또는 `Card`의 `style`).
- 퀘스트 밖 화면의 `Card`·`Button`은 변하지 않는다. DS `Card.jsx`는 고치지 않는다(`style` 덮어쓰기로 해결할 수 있으면).
- `.jam-quest-cta`(믹스하기·캐러셀용 퍼플 면)는 그대로 두고, 카드 안 CTA에만 흰 면·퍼플 글자 변형을 더한다.

## 구현 계획

1. 채원 사전 판정: 퍼플 카드 위 글자·진행 바·칩·구분선·링·CTA 색, 대비 값.
2. `OnboardingQuestCard.tsx`와 `transitions.css`(또는 카드 클래스)에 판정대로 반영하고 시험·PRD를 갱신한다.

## 완료 조건

- 퀘스트 카드(연출·실제 두 구역)의 배경이 `--jam-purple`이고 CTA(«동기화» 등)는 흰 면 + 진한 퍼플 글자(B, `color-mix(in srgb, var(--jam-purple) 60%, var(--foreground))` = #795c9d, 흰 면 위 5.34:1)다. 카드 안 모든 글자·진행 바·칩이 퍼플 면 위에서 읽힌다(대비 값은 아래 «주요 의사결정»).
- 카드 안 CTA 펄스 링이 퍼플 카드 위에서 보인다. 믹스하기·캐러셀 버튼은 지금처럼 퍼플 면 + 검정 글자다.
- 퀘스트가 끝나 카드가 사라지면 홈의 다른 카드는 변하지 않는다.
- 리터럴 `#BA8AF7`을 새로 쓰지 않는다. 시험·린트·타입 검사가 통과한다.
- 232 계정 홈(로컬 next dev, 375×812)에서 퍼플 카드와 흰 CTA를 눈으로 확인한 기록이 있다.

## 주요 의사결정

- **CTA 글자색 = B(진한 퍼플), 사용자 선택(2026-11-15)**: `color-mix(in srgb, var(--jam-purple) 60%, var(--foreground))` = #795c9d. 흰 면(`--snow` #fcfcfc) 위 5.34:1(AA 통과). 순수 `--jam-purple`(#BA8AF7) 글자는 흰 면 위 약 2.6:1이라 쓰지 않았다.
- 대비 값(채원 사전 판정, 퍼플 #BA8AF7 위): `--foreground` 6.89:1, 기존 `text-muted` 2.21:1(설명은 `text-foreground`로 교체), 아직 안 한 체크 행 `color-mix(in srgb, var(--foreground) 80%, var(--jam-purple))` = #382e44 4.91:1(75% 이하는 AA 미달). `text-link`는 `--link`가 검정이라 그대로 둔다(처음 티켓의 «text-link 대비 부족» 서술은 틀렸다).
- 퍼플 면과 흰 CTA 알약의 경계 대비는 2.54:1이다. 글자 라벨이 있어 허용하고 테두리·그림자는 더하지 않는다.
- 카드 면은 `Card`의 `style`(`QUEST_CARD_STYLE`)로 칠한다. DS `Card.jsx`·tone은 건드리지 않는다. 진행 바는 트랙만 `--snow`로 바꾼다(채움은 기본 검정).
- 카드 안 CTA 줄은 `jam-quest-cta-snow`(흰 알약 + 진한 퍼플 글자, 직계 자식 button만)이고 `jam-quest-cta`는 함께 붙이지 않는다. 펄스 링은 같은 래퍼의 `--quest-pulse-color`(흰색)·`--quest-pulse-alpha`(85%)로 바꾼다. 믹스하기·캐러셀의 `.jam-quest-cta`는 그대로다.

## 실렌더 확인 (2026-11-15, 232 계정 홈, 375×812)
