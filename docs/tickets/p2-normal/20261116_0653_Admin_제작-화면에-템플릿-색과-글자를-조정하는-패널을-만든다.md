## 배경 / 문제 정의
사용자가 반드시 넣으라고 정한 기능이다(상위 티켓 「결정 사항」의 «색 프로퍼티»). 4-2까지는 템플릿이 올린 그대로만 그려진다. 5-1에서 색을 뽑고 바꾸는 계산과 조정값의 꼴을 만들었고, 이 티켓에서 그것을 화면에 붙인다.

## 상세 요구사항

### 서비스/코드베이스 관점

#### 그리기 (`renderTemplateBadge.ts`)
- 입력에 `params?: TemplateBadgeParams`를 더한다. 없으면 `DEFAULT_TEMPLATE_BADGE_PARAMS`로 본다.
- 색: `stripSlotText`로 예시 글자를 걷어 낸 SVG에서 `extractSvgColors`로 색을 뽑고, `buildColorMap`과 `applyColorMap`으로 바꾼 SVG를 이미지로 불러온다. 색 조정이 기본값이면 이 단계를 건너뛴다.
- 글자: 자리마다 `styleSlot(slot, params.text[자리])`로 조정을 얹은 자리 정보를 만든다.
  - 가운데 기준은 템플릿의 원래 글자로 잡는다. 예시 글자의 폭은 원래 자리 정보의 글꼴·굵기·크기로 잰다(원래 글꼴도 불러와야 한다). 조정한 글꼴이나 크기로 재면 가운데가 옮겨 간다.
  - 넣을 글자의 폭, 넘치면 줄이기, 그리기는 조정을 얹은 글꼴·굵기·크기·색으로 한다. `layoutSlotText`에는 `x`와 `textAnchor`는 원래 값을, `fontSize`는 조정한 값을 넘긴다.
  - 자간은 원래 자리 정보의 값(글자 크기 대비 배수)을 그대로 쓴다. 기준선 `y`는 바꾸지 않는다(크기를 키우면 글자가 기준선에서 위로 자란다).
  - 글꼴을 찾지 못했을 때의 처리와 `fontFallbacks`는 지금과 같다. 조정으로 고른 글꼴에도 똑같이 적용한다.

#### 화면
- `BadgeStudio.tsx`: 조정값 `params`를 상태로 들고(`DEFAULT_TEMPLATE_BADGE_PARAMS`로 시작) `BadgePreview`에 넘긴다. 다른 배지를 골라도 조정값은 그대로 둔다(같은 모양으로 여러 배지를 이어서 볼 수 있게 한다). «처음으로»를 누르면 기본값으로 돌아간다.
- `BadgePreview.tsx`: 정상 상태에서 캔버스 옆(좁은 화면에서는 아래)에 `<BadgeAdjustPanel …/>`을 그린다. 패널에 넘길 색 목록은 `extractSvgColors(stripSlotText(template.svg))`를 `useMemo`로 구한다. `params`가 바뀌면 다시 그린다.
- `BadgeAdjustPanel.tsx`(표시와 콜백만. 상태를 들지 않는다): props는 `params`, `onChange(next)`, `onReset()`, `colors`(뽑은 색 목록), `slots`(템플릿의 자리 정보)다.
- `TemplateFontField.tsx`: 글꼴 고르기. `TextLayerFields.tsx`의 콤보박스와 같은 구성(Popover + Command, `searchGoogleFonts(query, 50)`)으로 새로 만든다. 첫 항목은 «템플릿 글꼴»(값 `null`)이다. `TextLayerFields.tsx`는 고치지 않는다.

### UI/UX 관점 (해당 시)
어드민 화면이라 shadcn/ui(`@/components/admin/ui`)를 쓴다. 문구는 아래를 그대로 쓴다.

**조정 카드** (제목: 조정. 오른쪽 위에 버튼 «처음으로», 조정값이 기본값이면 비활성)

**묶음 «템플릿 색»**
- 줄 «색 계열»: 버튼 여덟 개 «빨강», «주황», «노랑», «초록», «청록», «파랑», «보라», «분홍». 버튼마다 그 계열의 색 점을 앞에 둔다. 누르면 `hueShift`를 `hueShiftForFamily(colors, 계열의 hue)`를 정수로 반올림한 값으로 바꾼다. 대표 색이 없으면(`dominantHue`가 `null`) 버튼을 비활성으로 두고 «이 템플릿에는 색 계열을 바꿀 색이 없어요»를 보인다.
- 슬라이더 세 줄(`SliderRow`): «색상»(`formatDegree`), «채도», «명도»(둘은 `formatPercent`). 범위는 `TEMPLATE_PARAM_RANGES`를 쓴다.
- 줄 «색 칸»: 설명 «템플릿에 쓰인 색이에요. 칸을 눌러 하나씩 바꿀 수 있어요». 뽑은 색마다 색 입력(`<Input type="color">`, 값은 `overrides[색] ?? 색`) 하나를 둔다. 바꾼 칸에는 작은 버튼 «되돌리기»를 붙인다. 뽑은 색이 없으면 «바꿀 수 있는 색이 없어요».

**묶음 «이름 글자»와 «값 글자»** (같은 구성 두 번)
- «색»: 색 입력(값은 `조정한 색 ?? 템플릿의 색 ?? #000000`). 조정한 색이 있으면 버튼 «템플릿 색으로».
- «글꼴»: `TemplateFontField`. 버튼 글자는 고른 글꼴 이름, 고르지 않았으면 «템플릿 글꼴». 검색 자리 표시 «구글 폰트 검색», 결과 없음 «검색 결과가 없어요».
- 슬라이더 «굵기»(`FONT_WEIGHT_RANGE`, `formatWeight`. 값은 `조정한 굵기 ?? parseFontWeight(템플릿의 굵기)`), «크기»(`TEMPLATE_PARAM_RANGES.sizeScalePct`, `formatPercent`).
