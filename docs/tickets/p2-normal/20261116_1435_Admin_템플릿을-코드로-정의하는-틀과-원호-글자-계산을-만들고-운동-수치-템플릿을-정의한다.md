## 배경 / 문제 정의
사용자가 정한 것(상위 티켓 「결정 사항」의 «템플릿을 넣는 방식», 2026-11-16 오후): 어드민에 SVG를 올리는 방식을 그만두고 템플릿마다 개발해서 넣는다. 디자인마다 글자가 놓이는 형태가 달라질 수 있어서다.

사용자가 준 첫 템플릿(운동 수치)은 이름이 위쪽 원호를, 값이 아래쪽 원호를 따라 돈다. 파일의 `name`·`value`는 글자를 모양으로 바꾼 `<path>`라서 글꼴 정보가 없고, 지금 제작 화면은 `<text>` 자리의 x·y에 직선으로만 그린다. 글꼴은 사용자가 알려 주었다(이름과 값 모두 Noto Sans KR Black). 글자 크기·자간·기준선 원의 반지름은 카리나가 원본에 겹쳐 맞췄다(상위 티켓 「원본에 겹쳐 맞춘 값」).

## 상세 요구사항

### 서비스/코드베이스 관점

#### 1. 자리 정의의 꼴 (`templateDef.ts`)
```ts
export interface TemplateArcSlot {
  kind: 'arc'
  cx: number
  cy: number
  /** 글자의 기준선이 놓이는 원의 반지름 */
  baselineRadius: number
  /** 글자 묶음의 가운데가 놓이는 각도. 12시가 0, 시계 방향이 +, 6시가 180 */
  centerDeg: number
  /** outward: 글자 윗부분이 바깥을 향한다(위쪽 호). inward: 글자 윗부분이 중심을 향한다(아래쪽 호) */
  facing: 'outward' | 'inward'
  /** 글자 묶음이 이 각도를 넘으면 넘는 만큼 줄인다 */
  maxSpanDeg: number
  fontFamily: string
  /** '900'처럼 숫자를 글자로 적는다(TemplateSlot.fontWeight와 같은 꼴이라 resolveTemplateFont에 그대로 넘길 수 있다) */
  fontWeight: string
  fontSize: number
  letterSpacingEm: number
  fill: string
}
export type TemplateSlotDef = TemplateSlot | TemplateArcSlot
export function isArcSlot(slot: TemplateSlotDef): slot is TemplateArcSlot
export interface TemplateDefSlots { viewBoxWidth: number; viewBoxHeight: number; name: TemplateSlotDef; value: TemplateSlotDef }
export interface BadgeTemplateDef { classKey: BadgeTemplateClassKey; svg: string; slots: TemplateDefSlots }
```
- 기존 `TemplateSlot`과 `TemplateSlots`(`templateSvg.ts`)는 이 회차에서 고치지 않는다. 화면이 쓰는 꼴을 바꾸는 일은 8-2회차다.

#### 2. 원을 따라 글자 놓기 (`arcText.ts`)
```ts
export interface ArcTextInput {
  /** 글자별 폭. fontSize로 잰 값이고 좌표 단위는 cx·cy와 같다 */
  advances: number[]
  fontSize: number
  letterSpacingEm: number
  cx: number
  cy: number
  baselineRadius: number
  centerDeg: number
  facing: 'outward' | 'inward'
  maxSpanDeg: number
}
export interface ArcGlyph { index: number; x: number; y: number; rotationDeg: number }
export interface ArcTextLayout { fontSize: number; scale: number; shrunk: boolean; spanDeg: number; glyphs: ArcGlyph[] }
export function layoutArcText(input: ArcTextInput): ArcTextLayout | null
```
계산 규칙(카리나가 원본과 맞출 때 쓴 규칙과 같아야 한다):
1. 글자 사이 간격은 `letterSpacingEm × fontSize`이고 글자 사이에만 들어간다(n글자면 n−1번). 전체 길이 `L = 폭의 합 + 간격 × (n−1)`.
2. 차지하는 각도는 `L ÷ baselineRadius`(라디안)다. 이 각도가 `maxSpanDeg`보다 크면 `scale = maxSpanDeg ÷ 차지하는 각도`를 폭·간격·글자 크기에 모두 곱한다(`shrunk: true`). 넘지 않으면 `scale`은 1이다. 돌려주는 `fontSize`와 `spanDeg`는 줄인 뒤의 값이다.
3. 글자 묶음의 시작은 `−L/2`다. 글자 i의 호 위 위치는 `시작 + 앞 글자들의 (폭 + 간격) + 자기 폭의 절반`이고, 이것을 `baselineRadius`로 나눈 값이 가운데에서 벌어진 각도 `a`다.
4. `outward`: `θ = centerDeg + a`, `x = cx + R·sin θ`, `y = cy − R·cos θ`, `rotationDeg = θ`.
5. `inward`: `θ = centerDeg − a`, `x = cx + R·sin θ`, `y = cy − R·cos θ`, `rotationDeg = θ − 180`.
6. 그리는 쪽은 `(x, y)`로 옮기고 `rotationDeg`만큼 시계 방향으로 돌린 뒤, 글자를 가로 가운데 맞춤·기준선(alphabetic) 맞춤으로 원점에 그린다. 이 회차에서는 그리지 않는다.
7. `advances`가 비면 `glyphs`는 빈 배열이다. `baselineRadius`·`fontSize`·`maxSpanDeg`가 0 이하이거나 유한한 수가 아니면 `null`을 돌려준다.

#### 3. 운동 수치 템플릿 정의 (`templates/metric.ts`)
`METRIC_TEMPLATE: BadgeTemplateDef` — `classKey: 'metric'`, `svg: METRIC_TEMPLATE_SVG`, `viewBoxWidth: 922`, `viewBoxHeight: 922`, 두 자리의 공통 값은 `kind: 'arc'`, `cx: 461`, `cy: 461`, `fontFamily: 'Noto Sans KR'`, `fontWeight: '900'`, `fill: '#FFFFFF'`.

| 자리 | baselineRadius | centerDeg | facing | maxSpanDeg | fontSize | letterSpacingEm |
|---|---|---|---|---|---|---|
| name | 302.56 | 0 | outward | 208.5 | 106.5 | -0.11 |
| value | 383.56 | 180 | inward | 91 | 107 | 0.06 |

- `templates/index.ts`: `BADGE_TEMPLATE_DEFS: Partial<Record<BadgeTemplateClassKey, BadgeTemplateDef>>`에 `metric`만 넣는다. `getBadgeTemplateDef(classKey)`는 없으면 `null`을 돌려준다.
- 수치에는 «원본에 겹쳐 맞춘 값이다. 그림을 바꾸면 다시 맞춘다»는 주석을 단다.

#### 4. 샘플 글자 걷어 내기 (`composeTemplate.ts`의 `stripSlotText`)
- id가 `name`·`value`인 요소가 `text`이면 그 요소를, `g` 안에 `text`가 있으면 그 `text`를 지운다(지금과 같다).
- **새로:** 그 밖의 경우(`path` 같은 모양이거나, `text`가 없는 `g`)에는 id가 붙은 요소를 통째로 지운다.
- 함수 설명 주석을 «샘플 글자(글자 요소든 모양이든)를 걷어 낸다»로 고친다. 이름은 바꾸지 않는다(제작 화면이 쓰고 있다).

#### 5. 원호 자리의 글자 조정 (`templateParams.ts`의 `styleArcSlot`)
- `styleArcSlot(slot: TemplateArcSlot, p: SlotTextParams): TemplateArcSlot`: `fill`은 `p.color ?? slot.fill`, `fontFamily`는 `p.fontFamily ?? slot.fontFamily`, `fontWeight`는 `p.fontWeight`가 있으면 그 수를 글자로, `fontSize`는 `slot.fontSize × p.sizeScalePct ÷ 100`. 나머지 칸은 그대로다. `styleSlot`은 고치지 않는다.

### 주요 의사결정 / 핵심 메모
- 템플릿의 SVG를 코드 파일(`metricSvg.ts`)에 글자로 담은 까닭: 제작 화면은 브라우저에서 SVG 글자를 색 조정한 뒤 캔버스에 그린다. 코드 파일이면 묶음 설정 없이 브라우저와 시험에서 같은 글자를 쓸 수 있고, 원본이 한 곳에만 있다.
- 샘플 글자를 파일에서 미리 지우지 않고 그릴 때 걷어 내는 까닭: 사용자가 준 파일을 고치지 않고 그대로 두면 그림을 바꿀 때 파일만 통째로 바꾸면 된다. 샘플 모양은 원본과 겹쳐 맞출 때도 다시 쓴다.
- 직선 자리(`TemplateSlot`)를 남기는 까닭: 다음 템플릿이 직선 글자를 쓸 수 있다. 계산과 시험이 이미 있다.
- 바뀌는 파일이 열 개쯤이고 100줄을 넘어 `plan_only` 기준을 넘는다. 파일 단위 계획과 수치를 이 티켓에 적었으므로 면제를 넘긴다.
- 원호의 각도 기준을 12시=0, 시계 방향=+로 통일했다. 아래쪽 호(`inward`)의 가운데는 180이다.
