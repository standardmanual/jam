# [Admin] 액티비티 배지 검색이 JAM! 카테고리 배지를 빼 조회되지 않는 문제를 고친다

## 핵심 요약
- 요구사항: 액티비티 배지 이미지 어드민에서 일부 배지가 조회되지 않는다(사용자 제보, 2026-11-18). 조회되지 않는 배지가 더 있는지 확인하고 고친다.
- 원인: 검색 API(`jam-web/src/app/api/admin/activity-badge-image/search/route.ts`)가 `admin_category = 'jam'` 배지를 후보에서 뺐다. 옛 이미지 생성 화면이 «배경 이미지가 필요 없다»는 이유로 넣은 조건(티켓 20260910_2055)이다. 지금 화면은 분류별 템플릿으로 이미지를 만들어 등록하므로 이 배지들도 조회돼야 한다.
- 확인 결과(DB, 2026-11-18): 삭제되지 않은 활동 배지 390건 중 `admin_category = 'jam'`이 70건(17개 이름)이고 모두 조회되지 않았다(바구니 속 한 짝, 엉뚱한 주제, 빌린 유리 칸, 봉투 속 한 장, 건너온 물건의 칸, 입양 칸에서 온 물건, 빨랫줄의 한 켤레 등). 나머지 320건은 `admin_category`가 NULL이라 조회된다. 다른 제외 조건은 없다(이름·분류·등급 필터는 사용자가 거는 조건이다).
- 변경: 검색 질의에서 `.or('admin_category.is.null,admin_category.neq.jam')`을 지웠다. 이 API의 호출처는 어드민 «액티비티 배지»(템플릿) 화면의 검색과 계열 불러오기 둘뿐이다(옛 화면은 삭제됨). 시험에 «카테고리를 거르는 조건이 질의에 없다»를 고정했다.
