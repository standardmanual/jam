# [Infra] 주간 루틴에서 채원이 미션의 색도 제시하게 한다

## 핵심 요약

- 요구사항: 티켓 20261118_1715로 미션도 `image_spec`을 내게 됐다. 이미지 제작은 `bg`·`end` 색이 없으면 실패하므로, 주간 루틴 3단계에서 채원이 «카드만»이 아니라 «카드와 미션»의 색을 제시하게 한다.
- 구현 계획: 두 파일의 한 문장씩만 고친다(경미 수정, 카리나 직접 처리).
- 관련 파일: `.claude/agents/jam-designer.md` 37줄 모드 ⑤ 행의 «you are called only for cards that need an image», `.claude/skills/jam-work/references/scheduled-jobs.md` 215줄 «채원(`jam-designer`, 이미지가 필요한 카드만)».

## 배경 / 문제 정의

주간 루틴(`trig_01LVVmr7eWsL1EKBfiRtn595`) 3단계는 «초안에서 이미지가 필요한 카드만 색을 제시한다»이고 색이 오지 않으면 «색 대기»로 둔다. 미션에는 «색 대기» 경로가 없어서(`color_pending`은 카드 칸이다) 미션이 `image_spec`을 내도 `bg`·`end`가 비어 승인 뒤 이미지 제작이 실패하고 «이미지 제작 필요»가 남는다.

루틴 저장 프롬프트는 «이 프롬프트와 다르면 `scheduled-jobs.md`의 해당 절을 따른다»고 하므로 클라우드 프롬프트는 바꾸지 않는다(프롬프트 3단계 문장과 문서가 일시적으로 다른 채로 남는다). 에이전트 정의는 루틴이 매번 staging에서 읽는다.
