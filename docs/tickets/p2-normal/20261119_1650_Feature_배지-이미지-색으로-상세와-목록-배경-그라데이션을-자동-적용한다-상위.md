# [Feature] 배지 이미지 색으로 상세와 목록의 배경 그라데이션을 자동 적용한다 (상위)

## 핵심 요약
- 요구사항: 배지 이미지에서 뽑은 3색으로 Aura 방식 그라데이션을 만들어 **배지 상세 히어로 카드 전체**와 **배지 목록 카드의 썸네일 면**(인벤토리·믹스하기 포함)에 자동으로 깐다. 색은 **미리 뽑아 DB에 저장**하고, **어드민에서 배지 이미지가 바뀌면 색도 같이 갱신**한다.
- 구현 계획: 하위 4건으로 나눠 순서대로 진행한다. 1651(색 저장·추출) → 1652(어드민 갱신) ∥ 1653(상세) → 1654(목록).
- 관련 파일: 하위 티켓에 있다.

## 배경 / 문제 정의
배지 상세의 히어로 카드는 배경이 없는 배지면 흰 카드(`--card-bg`)이고, 목록 카드의 썸네일 면은 회색(`--surface`) 정사각형이다. 사용자가 2026-11-19 샘플 아티팩트(https://claude.ai/artifact/Dka8FckETKS8HophC8nCmM)로 확정한 방식으로, 이미지 색을 읽어 배경에 은은한 그라데이션을 자동 적용한다. 색을 화면에서 매번 뽑으면 이미지가 뜬 뒤에야 배경이 생기고 한 화면에서 수십 장을 계산해야 하므로 **DB에 미리 저장**하기로 했다(사용자 결정).

## 확정 사양 (사용자 결정, 2026-11-19)
단일 원천은 메모리 `project_badge_detail_bg_gradient_spec.md`와 위 샘플이다. 요약:
- 진하기 «연하게», 색 기준 «배지 이미지 색», 입자 질감 켬, 블러 100px(상세 카드 높이 약 320px 기준 약 31%)
- Aura 구조: 세로 그라데이션 레이어 2장 `mix-blend-mode: multiply` + `blur`, 레이어는 카드 크기 그대로(`inset: 0`), 바탕 `#faf8f2`
- 정지점은 Midnight Sapphire 원본: 레이어1 `transparent 0 → 틴트(.12) 28% → 흰색 28% → 중간 68% → 진한색 100%`, 레이어2 `transparent 0 → rgba(219,219,219,.22) 34% → 흰색 66% → 중간 82% → 진한색 100%`
- 색 최대 3개, 위(틴트)→중간→아래(가장 진한 색). «연하게» 값: 명도 .92/.83/.74, 채도 = 원채도 ×.27 (.07~.32로 제한) 뒤 자리별 ×.65/.85/1
- 입자: SVG feTurbulence, `soft-light`, 불투명도 .55
- 배지 이미지의 drop-shadow는 쓰지 않는다
- 글자색은 글자 높이의 두 레이어 곱 밝기로 흰색/어두운 색 자동 선택

## 가정 목록 (카리나, 사용자 확인 필요 시 하위 티켓 착수 전 확인)
1. **목록은 썸네일 면에만 깐다**(이름·칩은 흰 카드 위 그대로). 사용자가 선택하지 않아 추천안으로 진행한다. 블러는 면 크기에 비례해 줄인다.
2. **이미 배경 테마가 설정된 배지**(`background_color`·`background_image_url`·`background_animation`·영상)는 지금 그대로 두고, **설정이 없을 때만** 자동 그라데이션을 쓴다.
3. 색 정보가 없는 배지(`bg_colors` NULL)는 지금 모습(흰 카드·회색 면) 그대로 둔다. 흑백 위주 배지의 대체색(청회색)은 1651에서 정한다.
4. 컬렉션(아이템북) 히어로(`ItemBookHeroSection`)와 컬렉션 카드는 배지가 아니라 범위 밖이다.
5. 잠긴(`locked`)·미발견(`undiscovered`) 칸은 이미지를 가리는 칸이라 그라데이션을 깔지 않는다. 미획득(`earned=false`) 썸네일은 지금처럼 회색조·반투명이 그라데이션까지 함께 적용된다.
