# [Admin] 어드민 배지 이미지 변경 경로에서 대표색도 같이 갱신한다

## 핵심 요약
- 요구사항: 어드민에서 배지 이미지(`badges.image_url`)가 바뀌는 모든 경로가 같은 요청 안에서 새 이미지의 대표색(`bg_colors`)을 함께 저장한다. 어드민 편집 화면의 미리보기도 새 색을 보인다.
- 구현 계획: 1651의 `extractBadgeColors`를 각 쓰기 경로에서 호출해 `image_url`과 `bg_colors`를 **같은 `update`/`insert`** 에 넣는다. 놓친 경로는 1651의 트리거가 색을 NULL로 비워 낡은 색이 남지 않는다.
- 관련 파일: 아래.

## 배경 / 문제 정의
상위 티켓 20261119_1650. 색을 미리 저장하므로 이미지가 바뀌면 색도 같이 바뀌어야 한다(사용자 지시). 이미지를 쓰는 서버 코드 경로가 여러 곳이다.

## 상세 요구사항

### 서비스/코드베이스 관점
`badges.image_url`을 쓰는 경로(2026-11-19 확인, 구현 때 `grep`으로 전수 재확인):
1. `src/app/api/admin/badges/route.ts` — 배지 생성(`image_url` 필수 입력)
2. `src/app/api/admin/badges/[id]/route.ts` — 배지 수정(약 137줄 `image_url: body.image_url !== undefined ? … : existing.image_url`). **이미지가 실제로 바뀐 경우에만** 새로 뽑는다. 안 바뀌었으면 기존 색을 그대로 둔다.
3. `src/app/api/admin/badge-image-generator/apply/route.ts` — 생성 이미지 적용(약 95줄, 여러 배지에 한 번에 적용)
4. `src/app/api/admin/badge-image-generator/revert/route.ts` — 이전 이미지로 되돌림(약 41줄). 되돌린 이미지의 색을 다시 뽑는다(옛 색을 따로 보관하지 않는다).
5. `src/app/api/admin/activity-badge-templates/register/route.ts` — 활동 배지 템플릿 등록(약 99줄)
6. `src/app/api/admin/badge-image/generate/route.ts` — 이미지 생성 후 저장(약 132줄)
- 위 외에 CLI 스크립트가 `badges.image_url`을 쓴다(`scripts/recraft/register-badge-images.js`, `scripts/gen-new-activity-badge-families.mjs` 등). 이들은 색을 같이 쓰도록 고치거나, 안 고치면 1651의 트리거와 일괄 계산 스크립트(재실행)로 메운다는 점을 티켓 완료 기록에 남긴다.
- 색 추출 실패(`null`)는 저장 실패로 만들지 않는다. 이때는 `bg_colors`를 건드리지 않아(= 이미지가 바뀐 경우 트리거가 NULL로 비움) 이미지 저장은 성공한다.
- 일괄 적용(3번)은 배지 수만큼 이미지를 내려받으므로 **같은 이미지는 한 번만** 뽑아 모든 대상 배지에 쓴다.

### UI/UX 관점
- 어드민 배지 상세 미리보기(`src/app/admin/badges/BadgeDetailPreviewFrame.tsx`)는 저장 전 편집 중 이미지를 보인다. 저장 전에는 색을 모르므로 **미리보기는 색 없는 상태(지금 모습)로 두고**, 저장 뒤 화면을 다시 불러오면 새 색이 보이는 것으로 충분하다. 미리보기에서 실시간 추출은 이 티켓 범위 밖이다(후속 후보로 기록).

## 구현 계획
- 공용 헬퍼 한 곳(`src/lib/admin/badgeBgColors.ts` 신규)에 «이미지 주소 → 저장할 필드(`{ bg_colors }` 또는 `{}`)»를 만들어 6개 경로가 같이 쓴다. 경로마다 추출 호출을 복사하지 않는다.
- 시험: 헬퍼 단위 시험(추출 성공 → 필드 포함, 실패 → 빈 객체, 이미지 미변경 → 빈 객체), 라우트 시험에서 `image_url`과 `bg_colors`가 **같은 update 인자**에 들어가는지 확인한다.

## 관련 파일
- 위 6개 라우트, `src/lib/admin/badgeBgColors.ts`(신규), `src/lib/badgeColorExtract.ts`(1651), `src/types/database.ts`
- 선행: 20261119_1651 머지·마이그레이션 347 실행

### 구현 내용 요약
- 배지 이미지(`badges.image_url`)를 쓰는 어드민 경로 **7곳**이 같은 update/insert에 `bg_colors`를 함께 담는다. 공용 헬퍼 `src/lib/admin/badgeBgColors.ts`: `badgeBgColorsFields(url)`(성공 `{bg_colors}`, 실패·주소 없음·예외 `{}`), `badgeBgColorsFieldsIfChanged(기존, 다음)`(이미지가 실제로 바뀐 경우에만 추출).
