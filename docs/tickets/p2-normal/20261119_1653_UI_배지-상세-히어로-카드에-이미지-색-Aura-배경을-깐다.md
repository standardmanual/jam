# [UI] 배지 상세 히어로 카드에 이미지 색 Aura 배경을 깐다

## 핵심 요약
- 요구사항: 배지 상세 히어로 카드(`BadgeHeroSection`)에 저장된 대표색(`bg_colors`)으로 Aura 그라데이션 배경을 깐다. 이미지 drop-shadow는 쓰지 않는다. 이후 목록(1654)이 같은 부품을 쓰도록 **배경 부품과 색 보정표를 한 곳에 만든다**.
- 구현 계획: ① `src/lib/badgeAura.ts`(색 보정표 + 그라데이션 CSS 계산 + 글자색 판정, 순수 함수) ② `BadgeAuraBackground` 부품(레이어 2장 + 입자) ③ 어댑터 `BadgeHeroSection.tsx`가 `backgroundSlot`으로 연결 ④ 호출부가 `bg_colors`를 넘기도록 조회·전달.
- 관련 파일: 아래.

## 배경 / 문제 정의
상위 티켓 20261119_1650, 확정 사양은 그 티켓과 메모리 `project_badge_detail_bg_gradient_spec.md`. 지금 배경 없는 배지의 히어로 카드는 흰 카드다.

## 상세 요구사항

### 서비스/코드베이스 관점
- **적용 조건**: 배지에 이미 배경 테마(`getBadgeBackgroundStyle`·`hasBadgeBackgroundTheme`·`background_animation`)가 있으면 지금 그대로, **없고 `bg_colors`가 비어 있지 않을 때만** Aura를 깐다. `bg_colors`가 NULL이면 지금 모습(흰 카드)이다. `[]`(색 없음)은 청회색 3색(샘플의 Silver Mist 계열)으로 깐다 — 단 이 대체색은 사용자가 보지 않았으므로 구현 뒤 사용자 확인 대상이다.
- `badgeAura.ts`는 순수 함수로 만들어 시험한다: `fill3`(3색 미만이면 색상 ±22°로 채움), 자리별 색 보정(연하게 값 표), `auraLayers(colors)`(레이어 1·2의 `linear-gradient` 문자열), `textMode(colors)`(글자 높이 약 85%에서 두 레이어를 곱한 밝기로 `light`/`dark`). 값은 확정 사양 그대로다. 보정표는 이름 있는 상수 한 곳에 두어 나중에 «보통»·«진하게»를 추가하기 쉽게 한다.
- 레이어는 카드 크기 그대로(`inset: 0`)이고 `mix-blend-mode: multiply`, 바탕 `#faf8f2`, 블러 100px(`size="page"` 기준). `BadgeAuraBackground`는 `blurPx`를 prop으로 받는다(1654가 작은 면에서 다른 값을 넘긴다). 카드 `isolation: isolate`로 블렌드가 카드 안에 갇히게 한다.
- 입자: SVG `feTurbulence`(baseFrequency .95, 2옥타브) 데이터 URI 배경, `mix-blend-mode: soft-light`, 불투명도 .55. 새 이미지 파일을 만들지 않는다.
- 어댑터(`src/components/BadgeHeroSection.tsx`)는 `BadgeRow`에서 `bg_colors`를 받는다(`Pick`에 추가, **선택 필드**라 어드민 미리보기·dev 샘플 호출부가 안 깨진다). 호출부 5곳은 조회 때 `bg_colors`를 가져와 넘긴다.
- 글자색은 `textMode`로 어댑터가 `onMedia`·`textStyle`을 정한다. Aura는 대부분 «연하게» 값이라 어두운 글자일 가능성이 높지만 판정 함수 결과를 따른다.
- 이미지 `drop-shadow`가 지금 어디서 걸리는지 확인해(상세 히어로의 이미지) 이 카드에서는 걸지 않는다. 다른 화면의 그림자는 건드리지 않는다.

### UI/UX 관점
- 카드 모서리 둥글림(`rounded-2xl`)과 안쪽 여백·이미지 크기(200)는 그대로다. 카드 높이는 내용이 정한다.
- 라이트 테마만 있다(다크 없음). 접근성: 배경은 장식이라 `aria-hidden`.
- 움직임 없음(정적).
