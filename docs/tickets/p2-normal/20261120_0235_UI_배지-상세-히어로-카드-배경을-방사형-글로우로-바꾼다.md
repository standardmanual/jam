# [UI] 배지 상세 히어로 카드 배경을 방사형 글로우로 바꾼다

## 핵심 요약
- 요구사항: 배지 상세 최상단 카드의 배경을 사용자가 첨부한 «Hum a tune» 카드처럼 부드러운 방사형 빛번짐으로 바꾼다. 색은 저장된 배지 대표색(`bg_colors`)을 쓴다. 목록 카드는 이번 범위가 아니다(사용자가 한 가지씩 조정하기로 함).
- 구현 계획: `BadgeAuraBackground`에 `variant="glow"`를 더하고, 상세 히어로(`BadgeHeroSection`)만 이 값을 쓴다. 목록 카드는 기존 띠 방식(`band`)을 유지한다.
- 관련 파일: `jam-web/src/lib/badgeAura.ts`(`AURA_GLOW_BASE_COLOR`·`AURA_GLOW_TUNING`·`auraGlowLayers`), `jam-web/src/components/BadgeAuraBackground.tsx`(`variant`), `jam-web/src/components/BadgeHeroSection.tsx`(`variant="glow"`, 글자색 판정 제거)

## 배경 / 문제 정의
상위 티켓 20261119_1650의 띠 방식 Aura가 좁은 카드에서 가운데 아래만 불룩해 보이고 기대한 분위기가 나지 않는다는 사용자 의견이 있었다(2026-11-19). 사용자가 새 참고 디자인을 첨부하며 상세 히어로부터 바꾸라고 지시했다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `glow`는 방사형 그라데이션 3장(위쪽 오른쪽·왼쪽 가운데·아래쪽 가운데)과 아래를 바탕색으로 푸는 선형 그라데이션 1장으로 구성한다. 블러·블렌드·입자는 쓰지 않는다.
- 색 자리는 위에서 아래로 맨 위 색 → 중간 색 → 마지막 색이다. 보정표는 띠 방식보다 명도를 높이고 채도를 살린 `AURA_GLOW_TUNING`이다.
- 글로우 면은 항상 연한 색이라 히어로 글자는 어두운 색 고정이다(옛 `textMode` 판정은 상세에서 쓰지 않는다).
- `bg_colors` NULL이거나 배경 테마가 있는 배지는 지금과 같다.

### UI/UX 관점
- 바탕색 `#fbfcff`, 모서리·크기·배치는 그대로다.

## 완료 조건
- 상세 히어로 카드가 글로우 배경으로 보인다(로컬 실렌더 360~430 폭 확인).
- 목록 카드와 다른 호출부는 변하지 않는다.
- `BadgeAuraBackground`·`BadgeHeroSectionAura` 시험과 `typecheck`·`eslint`가 통과한다.

## 완료 기록

### 구현 내용 요약
- `BadgeAuraBackground`에 `variant: 'band' | 'glow'`(기본 `band`)를 더했다. `glow`는 방사형 그라데이션만 쓰는 한 장짜리 면이다.
- 상세 히어로는 `glow`와 바탕색 `#fbfcff`를 쓰고, 글자색은 어두운 색으로 고정했다.
- 로컬 실렌더: «배달 헬멧»(청록·남색 계열)과 «양정역»(빨강·파랑·보라 계열)로 390px 폭에서 확인했다. 색이 옅은 편이라 더 진하게 할지는 사용자 판단이다.
