# [UI] 배지 상세 히어로 카드 배경을 세로 선형 글로우로 바꾼다

## 핵심 요약
- 요구사항: 배지 상세 최상단 카드의 배경을 사용자가 첨부한 «Hum a tune» 카드처럼 부드러운 빛번짐으로 바꾸되, 색은 위에서 아래로 한 줄로 쌓는다. 색은 저장된 배지 대표색(`bg_colors`)을 쓴다. 목록 카드는 이번 범위가 아니다(사용자가 한 가지씩 조정하기로 함).
- 구현 계획: `BadgeAuraBackground`에 `variant="glow"`·`gray`를 더하고, 상세 히어로(`BadgeHeroSection`)만 이 값을 쓴다. 목록 카드는 기존 띠 방식(`band`)을 유지한다.
- 관련 파일: `jam-web/src/lib/badgeAura.ts`(`AURA_GLOW_BASE_COLOR`·`AURA_GLOW_TUNING`·`AURA_GLOW_GRAY_COLORS`·`auraGlowLayers`), `jam-web/src/components/BadgeAuraBackground.tsx`(`variant`), `jam-web/src/components/BadgeHeroSection.tsx`(`variant="glow"`, 글자색 판정 제거)

## 배경 / 문제 정의
상위 티켓 20261119_1650의 띠 방식 Aura가 좁은 카드에서 가운데 아래만 불룩해 보이고 기대한 분위기가 나지 않는다는 사용자 의견이 있었다(2026-11-19). 사용자가 새 참고 디자인을 첨부하며 상세 히어로부터 바꾸라고 지시했다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `glow`는 두 장이다. ① 세로 선형: 맨 위 색 → 중간 색 → 마지막 색 → 바탕색 사이에 섞은 중간 정지점 8개를 촘촘히 두어 겹침 구간을 넓혔다(색 경계 선이 보이지 않게, 블러 대신). ② 아래 타원: 마지막 색이 아래 가운데(50% 84%, 105%×52%)에서 원형으로 퍼지다 투명으로 풀린다(첨부 디자인). 처음에는 방사형 3장으로 만들었으나 얼룩져 보인다는 사용자 의견(2026-11-20)으로 위에서 아래로 한 줄로 쌓는 방식으로 바꿨다. 블러·블렌드·입자는 쓰지 않는다.
- 3차(사용자 지시): 선 경계가 강하게 보이니 겹침을 넓히고 아래를 원형으로 퍼지게 하라는 요청으로 위 구성으로 바꿨다. 블러는 쓰지 않고 정지점으로 해결했다.
- 4차(사용자 지시, 두 번째 참고 이미지): ① 가장 아래는 반드시 흰색(`AURA_GLOW_BASE_COLOR`를 `#ffffff`로, 84~100% 구간 순백) ② 가장 진한 색이 위 가운데에서 퍼지고 좌우 모서리로 갈수록 옅어지는 위쪽 타원 ③ 카드 가운데가 살짝 밝아지는 흰빛 ④ 카드 안쪽 가장자리를 도는 밝은 색 inset 빛(`auraGlowInsetShadow`). 색 순서는 진한 색이 위, 밝은 색이 아래다. 중간 정지점 9개로 겹침을 더 넓혔다.
- 5차(사용자 지시): ① 대표색 3개 중 **2개(중간 색·진한 색)만** 쓴다(밝은 색은 쓰지 않음) ② 경계선을 더 흐리게: 선형 정지점 15개를 가우시안 번짐(σ 0.22)으로 계산해 제어점마다 기울기가 꺾이지 않게 하고, 위쪽 타원·중앙 하이라이트의 알파도 가우시안 9단계로 풀었다 ③ 안쪽 glow를 더 넓고 부드럽게(중앙 하이라이트 75%×46%, inset 64px+24px). 블러 필터는 쓰지 않는다.
- 미획득(`hasEarned=false`)은 대표색 대신 무채색 3색(`AURA_GLOW_GRAY_COLORS`)을 쓴다(사용자 지시). `bg_colors`가 NULL이면 미획득이어도 Aura가 없는 지금 모습 그대로다.
- 색 자리는 위에서 아래로 맨 위 색 → 중간 색 → 마지막 색이다. 보정표는 띠 방식보다 명도를 높이고 채도를 살린 `AURA_GLOW_TUNING`이다.
- 글로우 면은 항상 연한 색이라 히어로 글자는 어두운 색 고정이다(옛 `textMode` 판정은 상세에서 쓰지 않는다).
- `bg_colors` NULL이거나 배경 테마가 있는 배지는 지금과 같다.

### UI/UX 관점
- 바탕색 `#fbfcff`, 모서리·크기·배치는 그대로다.

## 완료 조건
- 상세 히어로 카드가 글로우 배경으로 보인다(로컬 실렌더 360~430 폭 확인).
- 목록 카드와 다른 호출부는 변하지 않는다.
- `BadgeAuraBackground`·`BadgeHeroSectionAura` 시험과 `typecheck`·`eslint`가 통과한다.

## 완료 기록

### 구현 내용 요약
- `BadgeAuraBackground`에 `variant: 'band' | 'glow'`(기본 `band`)를 더했다. `glow`는 세로 선형 그라데이션 한 장짜리 면이고, `gray`면 무채색으로 깐다.
- 상세 히어로는 `glow`와 바탕색 `#fbfcff`를 쓰고, 글자색은 어두운 색으로 고정했다.
- 로컬 실렌더(방사형 1차): «배달 헬멧»(청록·남색 계열)과 «양정역»(빨강·파랑·보라 계열)로 390px 폭에서 확인했다. 색이 옅은 편이라 더 진하게 할지는 사용자 판단이다.
- 2차(선형·그레이): «양정역»(미획득)에서 그레이 선형 그라데이션을 직접 확인했고, 획득 상태의 색 쌓임은 같은 값을 화면에 주입해 확인했다(테스트 계정에 색이 있는 획득 배지가 없음).
