# [UI] 배지 목록 카드 썸네일 면에 글로우 배경을 적용한다

## 핵심 요약
- 요구사항: 상세 히어로에서 확정한 «글로우» 배경(티켓 20261120_0235)을 배지 목록 카드(`BadgeGridCard`)의 썸네일 면에도 같은 방식으로 적용한다. 사용자가 시안(3열 그리드, 390px 폭)을 보고 «이대로 서비스에 적용»을 지시했다(2026-11-20).
- 구현 계획: `BadgeAuraBackground`의 `glow` 변형에 `glowSize`(없음=상세 px, 숫자=면 한 변 px, `'container'`=면 폭 cqw)를 더하고, 블러·면 여유·안쪽 빛 길이를 상세 카드(약 360px) 값에서 면 크기에 비례해 줄인다. `BadgeGridCard` 일반 면은 `glowSize={90}`, compact 면은 `'container'`를 쓴다. 미획득(`thumbDimmed`)은 그레이 글로우다.
- 관련 파일: `jam-web/src/lib/badgeAura.ts`(`auraGlowMetrics`, `auraGlowLayers`의 `bleed`, `auraGlowInsetShadow`의 `size`), `jam-web/src/components/BadgeAuraBackground.tsx`(`glowSize`), `jam-web/src/components/ui/BadgeGridCard.tsx`(두 면), 시험 3개

## 상세 요구사항
- 호출부는 바꾸지 않는다. 모두 `BadgeGridCard`의 `bgColors`를 거치므로 활동·체크인 탭, 인벤토리, 믹스하기, 컬렉션 칸, 드랍, 프로필이 함께 바뀐다(티켓 20261119_1654의 호출부 연결 그대로).
- `locked`·`undiscovered` 칸에는 깔지 않는다(그대로).
- 면이 작아지면 상세와 같은 비율로 줄인다: 블러 28px·여유 56px·안쪽 빛 192/72px(상세 기준 360px) → 90px 면에서 7px·14px·약 48/18px.
- 옛 띠 방식(`band`, `auraLayers`, `auraBlurPx` 등)은 이제 서비스에서 쓰지 않는다. 코드와 시험은 남겨 두었고 정리는 후속이다.

## 완료 조건
- 일반·compact 면 모두 글로우로 보이고 미획득은 그레이다.
- `bgColors`가 없으면 마크업이 변경 전과 같다.
- 서비스 화면 관련 시험, `typecheck`, `eslint` 통과.
