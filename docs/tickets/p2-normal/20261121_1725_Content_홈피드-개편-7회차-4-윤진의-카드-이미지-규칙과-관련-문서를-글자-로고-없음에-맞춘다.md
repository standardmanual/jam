# [Content] 홈피드 개편 7회차-4: 윤진의 카드 이미지 규칙과 관련 문서를 글자·로고 없음에 맞춘다

## 핵심 요약

- 요구사항: 7-1·7-2·7-3이 끝난 뒤 문서와 에이전트 정의를 새 이미지 규칙(카드 이미지에는 글자·로고를 넣지 않는다, 리본 J 무늬는 남는다)에 맞춘다. 코드·DB·실제 루틴은 바꾸지 않는다(`docs` 유형, 오케스트레이터 직접 수행).
- 관련 파일: `.claude/agents/jam-marketer.md`(⑧·⑨ 행의 `image_spec` 안내), `.claude/skills/jam-story/references/marketer-assets.md`, `docs/service/prd/content-automation/PRD.md` §6·§11(미션 소개 카드 이미지 등), `docs/service/prd/home-feed/PRD.md` §6(이미지 규칙, «아직 정하지 않은 것»의 이미지 관련 항목과 상태 표시), 7-1~7-3이 이미 고친 문서와 겹치지 않게 정본은 링크로 가리킨다(CLAUDE.md 규칙 5).
- 결정 대기로 남기는 것: 미션 이미지의 글자 제거(미션 프리셋은 7-2에서 건드리지 않았다. 옛 모양 `mission_spotlight`의 `resolveTitleInImage`와 함께 정해야 한다), 체크인 지점 이미지의 출처·저장·승인(웹 검색 사진), 저장한 대표 색을 쓰는 색 규칙.

## 구현 계획

| # | 파일 | 할 일 |
|---|---|---|
| 1 | `.claude/agents/jam-marketer.md` | 카드 항목의 `image_spec`은 `preset_id`와 `bg`·`end`만 쓰고 `values`(글자·로고)는 내지 않는다(영어 한 문장), 프리셋 ID 안내가 글자 층 없는 홈피드 프리셋을 가리키는지 확인. |
| 2 | `.claude/skills/jam-story/references/marketer-assets.md` | 홈피드 카드 이미지의 글자 수 가이드 서술(제목 11자·설명 22자)을 «글자 층 없음»으로 정리(정본은 `asset-generator/PRD.md` §8 링크). |
| 3 | `docs/service/prd/content-automation/PRD.md` | 카드 이미지 서술이 새 규칙과 일치하는지 점검해 최소로 고친다. |
| 4 | `docs/service/prd/home-feed/PRD.md` | §6 이미지 규칙 절에 7회차 구현 상태(프리셋 데이터·코드·대표 색 저장)와 남은 결정(위 세 가지)을 적고 개편 절 상태 표시를 갱신. |
| 5 | 생성 구간 | 근거가 바뀌면 `node scripts/gen-team-doc.mjs`. |

## 완료 조건

- 윤진이 읽는 파일에서 카드 이미지에는 글자·로고가 없고 `image_spec.values`를 내지 않는다는 규칙을 찾을 수 있고, 같은 사실이 두 곳에 적히지 않는다(링크로 가리킨다). `scripts/verify.sh`가 통과한다.
- 실제 클라우드 루틴 프롬프트는 바꾸지 않는다(필요한 문구 초안은 「잔여 이슈」에 적고 사용자 허락 뒤 교체).
