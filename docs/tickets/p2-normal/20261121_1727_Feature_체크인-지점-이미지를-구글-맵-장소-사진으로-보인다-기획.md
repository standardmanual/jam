# [Feature] 체크인 지점 이미지는 수동으로 넣는다 (결정 기록과 선택 후속)

## 핵심 요약

- 배경: 상위 티켓 15번 «체크인 지점을 보이는 자리에는 아이콘 대신 해당 지점의 이미지를 쓴다». 이미지 출처는 처음에 구글 맵으로 정했다가(2026-11-21), 같은 날 **사용자가 수동으로 넣는 방식으로 바꿨다**.
- **결정(2026-11-21): 체크인 지점 이미지는 사용자가 직접 올리고 고른다.** 에이전트가 웹에서 찾아 넣거나 구글 맵·장소 API에서 불러오지 않는다. 따라서 구글 지도 플랫폼 키·요금·약관(저장 금지, 작성자 표시)·장소 ID 매칭·`poi` 칸 추가는 **필요 없다**(이 방식으로는 만들지 않는다). 저작권은 사용자가 직접 쓸 수 있는 이미지를 골라 책임진다.

## 지금 코드로 되는 것 (조사 결과, 2026-11-21)

- 새 목록형 카드(`gallery_list`)의 항목마다 **이미지 주소**를 적는 칸이 있다(5회차-3, `list_items[].image_url`, 어드민 카드 작성 화면의 「목록 항목」 편집기). 체크인 지점을 소개하는 장소 목록 카드는 항목마다 지점 이미지를 이 칸에 직접 넣으면 된다. 코드 변경이 필요 없다.
- 이미지 파일을 올려 주소를 얻는 경로는 어드민 이미지 업로드(`/api/admin/upload-image`)다(`today_cards` 폴더). 목록 항목 편집기는 파일 업로드 버튼이 없고 주소 입력만 있다(5-3 결정, 기존 이미지 입력 부품이 폼 내부 코드라서).
- 지점 표 `poi`에는 이미지 칸이 없고(칸: id·name·latitude·longitude·radius_meters·category·linked_badge_id·osm_id·poi_tier·naver_id·is_active·naver_category·naver_keyword·pending_review·sido·gu), 서비스의 지도·드랍 화면은 지점을 아이콘·점·배지 그림으로 보인다. 이 화면들에서 지점 이미지를 쓰는 일은 상위 티켓의 범위가 아니다(카드에서 지점을 보이는 자리가 대상).

## 선택 후속 (사용자가 원할 때만)

1. **목록 항목 이미지 업로드 버튼**: 어드민 카드 작성 화면의 목록 항목 편집기에 «파일 올리기»를 더해, 주소를 직접 적지 않고 올릴 수 있게 한다(작은 어드민 변경, 기존 업로드 API 재사용).
2. **지점별 이미지 칸 `poi.image_url`**: 어드민 지점 화면에서 지점마다 이미지를 한 번 올려 두고, 카드 목록 항목·지점 소개에서 재사용한다. 지점이 많으면 같은 이미지를 카드마다 다시 올리지 않아도 된다. DB 칸 추가(확장 단계)와 어드민 지점 폼 업로드, 카드에서 읽기가 필요하다(작지 않은 변경).
3. 에이전트가 만드는 장소 목록 카드는 이미지를 직접 넣지 못하므로, 에이전트 묶음의 목록 항목은 이미지 없이 이름·링크만 내고 사용자가 승인 전에 어드민에서 이미지를 채우는 흐름이 된다(목록 항목의 이미지 칸은 선택이라 이미지가 없어도 칸 이름 글자로 보인다).

## 완료 조건

- 사용자가 선택 후속(위 1·2) 중 원하는 것을 정하면 그에 맞는 티켓으로 나눈다. 정하지 않으면 코드 변경 없이 이 결정 기록으로 둔다.
