# [UI] 배지 상세 화면을 티켓 디자인으로 리뉴얼한다 (상위)

## 핵심 요약

- 요구사항: 배지 상세 화면 3종(아이템·체크인·액티비티, `/badges/[id]`)을 홈피드 개편과 같은 «티켓» 디자인으로 바꾼다. 확정 시안은 캔버스 «배지 상세 티켓안» https://claude.ai/artifact/Sse8B3y6N75WPhPXEhs2pU (2026-11-22 사용자가 댓글로 다듬어 확정, 아래 「확정 규격」이 그 내용이다). 추가로 ① 티켓색은 진입할 때마다 원색 5개 중 랜덤 ② 로딩 때 컨텐츠가 먼저 보이고 티켓 디자인이 나중에 입혀지는 깜빡임이 없어야 한다.
- 구현 계획: 2회차로 나눈다. 1회차(20261122_1222) 티켓 틀·랜덤 색·토큰 덮어쓰기(카드 부품 무수정), 2회차(20261122_1223) 히어로 카드를 사진과 글자 상자로 나누고 이력·조건 부품의 제목을 숨기는 옵션(부품 수정).
- 후속(카리나): 배경색이 지정된 아이템 배지 10개의 `badges.background_color`를 NULL로 지운다(마이그레이션 353, 사용자 지시 2026-11-22).
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/page.tsx`(세 변형의 반환부), 하위 티켓 각자의 「관련 파일」.

## 배경 / 문제 정의

홈피드 카드가 티켓·우표 모양과 15색 컬러셋으로 개편됐다(상위 20261120_2026). 배지 상세는 여전히 회색 바탕에 흰 카드를 쌓은 옛 모양이라 홈피드에서 들어갔을 때 맥락이 끊긴다. 사용자는 영화제 티켓 레퍼런스(빨강·파랑 티켓)를 주고, 카드 부품 구조는 되도록 유지한 채 자리·컬러셋·페이지 배경만 바꾸는 방향을 정했다. 시안을 캔버스에서 댓글로 다듬은 뒤 «이대로 리뉴얼»을 지시했다.

## 사용자 확정 사항 (2026-11-22)

- 랜덤 후보 색은 **원색 5개**(`--jam-red`·`--jam-yellow`·`--jam-green`·`--jam-purple`·`--jam-blue`)다. 홈피드 색 덮어쓰기(`--feed-color-*`)는 쓰지 않는다(덮어쓰기는 홈피드 카드 전용이다).
- **배지 이미지 대표 색과 겹치는 색은 후보에서 뺀다**: 홈피드와 같은 규칙 `violatesImageColorRule(hex, badge.bg_colors)`(`lib/today/feedColorRules.ts:157`). 다 빠지면 5개 전체에서 고른다.
- 색은 **서버에서 요청마다** 고른다(진입·새로고침마다 바뀐다).
- **깜빡임 금지**: 색·티켓 모양·그라데이션을 서버 렌더 HTML과 라우트 CSS로 첫 화면부터 그린다. 클라이언트 컴포넌트·`useEffect`로 색을 칠하지 않는다.
- 범위는 배지 상세 페이지 3종(본인·타인 `?u=` 보기). 드랍 화면 시트형 상세(`BadgeDetailSheet`)와 어드민 미리보기, 잠긴 개체 상세(`LockedItemDetail`)는 이번 범위 밖이다.
- 전체 화면 배경 테마 레이어(`badgeBackgroundLayer`)는 그리지 않는다. 배경색이 지정된 아이템 배지 10개는 배경색 값을 지운다(마이그레이션, 카리나).
- 체크인 안내 문단(«표시된 위치 {radius}m 안을…», `d.badges.checkinSafetyNotice`)은 뺀다.
- 이력 목록 제목(체크인 «방문 기록», 아이템 «획득 정보»)과 액티비티 카드 안쪽 제목(«획득 조건», 획득 정보 카드의 «획득 정보»)은 뺀다.
- 히어로 카드의 등급·이름·설명은 사진 자리 밖 테두리 상자로 뺀다(«카드 무수정» 원칙의 유일한 예외).

## 확정 규격 (캔버스 최종본, 390px 화면 기준)

**페이지**
- 페이지 배경: 크림 `#F1E9D6`(페이지 범위에서 `--background`를 덮어쓴다. TopNav도 따라간다). TopNav는 그대로 둔다.
- 티켓: 좌우 16px 바깥 여백(`margin: 4px 16px 0`), 그 아래 티켓 밖에 공유 버튼(`padding: 24px 16px 32px`).

**티켓 머리**(티켓색 단색, 윗모서리 직각)
- 안쪽 여백 `20px 20px 24px`, 가로 배치 `justify-content: space-between; gap: 12px`.
- 왼쪽: JAM 로고. 새 이미지 없이 기존 `.jam-logo-mark`(알파 마스크 + 색, `globals.css:521`)를 본문색(`#171717`)으로 쓴다. 높이 44.5px(오른쪽 글자 묶음의 실제 글자 높이와 같다), `margin-top: 4px`.
- 오른쪽(오른쪽 정렬, 세로 gap 6px): 종류 글자 `ITEM` / `CHECK IN` / `ACTIVITY` — Noto Sans KR 900, 34px, line-height .92, letter-spacing -0.035em, `#171717`. 그 아래 날짜 `YYYY.MM.DD`(한국 시각) — Geist Mono(`--font-geist-mono`) 12px, line-height 16px, letter-spacing .08em. 날짜는 아이템=대표 개체 획득일, 체크인=마지막 방문일, 액티비티=획득일. 미획득이면 날짜 줄을 그리지 않는다. «EARNED»·«VISIT» 같은 말은 붙이지 않는다.

**절취선**(머리와 아래 블록 사이, 사진 구간과 카드 구간 사이 두 곳)
- 점선: 지름 4px 점, 10px 간격, 페이지 배경색, 좌우 26px 안쪽.
- 양끝 홈: 직선 삼각 홈(«<»·«>»), 깊이 20px·높이 40px(45°). 반원이 아니다.

**아래 블록**(사진 구간부터 티켓 끝까지 한 덩어리, 아래 모서리 12px 라운드, `padding-top: 20px`)
- 배경: `linear-gradient(180deg, 티켓색 0%, 끝색 100%)`. 끝색은 검정을 겹치지 않는다:
  - 일반: `oklch(from 티켓색 calc(l - 0.08) calc(c * 1.2) h)` (명도만 낮추고 채도는 올린다)
  - 노랑 계열(HSL 색상 40~70°, 원색 중 `--jam-yellow`): `oklch(from 티켓색 calc(l - 0.03) calc(c * 1.15) calc(h - 20))` (오렌지 쪽으로 조금 돌린다)
- 그레인: 히어로 오라와 같은 노이즈 SVG(data URI) 180px 타일, `mix-blend-mode: soft-light`, `opacity: .55`, 내용 아래 층.
- 사진 자리: 히어로 카드의 배경(오라)과 배지 이미지만, 원래 둥근 박스(모서리 16px). 바깥 래퍼가 좌우 16px 안쪽.
- 글자 상자: 2px `#171717` 테두리 상자 2칸을 위아래로 붙인다(`margin: 0 16px 24px`, 가운데 테두리는 한 줄). 위 칸(`padding: 20px 16px 18px`) 등급 칩 또는 레벨 칩(+체크인 방문 칩 ×N)과 이름(`text-3xl font-bold`), 아래 칸(`padding: 14px 16px 16px`) 설명(`text-base`). 가운데 정렬, 배경 투명.
- 아이템 일련번호(`ItemSerialCode` height 50): 글자 상자 아래(`pt-0 pb-6`).
- 카드 구간: 절취선 2 아래 `padding-top: 24px`.

**티켓 범위 토큰 덮어쓰기**(카드 부품은 고치지 않고 토큰만 받는다)
- `--card-bg`, `--surface`: `color-mix(in srgb, 티켓색 70%, #fff)`
- `--background-secondary`: `color-mix(in srgb, 티켓색 45%, #fff)`
- `--muted`: `rgba(23,23,23,.8)` (진해진 카드 위 라벨 대비 4.5:1 이상)
- `--border`: `rgba(23,23,23,.12)`
