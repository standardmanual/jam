## 상세 요구사항

### 서비스/코드베이스 관점
- 제목 숨김 prop은 기본값이 «보임»이다. 배지 상세 페이지만 끄고, 다른 곳(잠긴 개체 상세 `LockedItemDetail`, `dev-sample`)은 그대로다.
- 히어로 카드의 다른 사용처(드랍 화면 `BadgeDetailSheet`의 `size="sheet"`, 어드민 미리보기)는 지금 모습 그대로여야 한다.
- 레벨형 배지(`level` 있음)는 등급 칩 대신 레벨 칩, 체크인 2회 이상은 방문 칩(`VisitCountChip`)이 등급 칩 옆에 온다 — 지금 히어로 카드의 칩 규칙과 같다.
- 미획득 배지는 사진의 이미지가 지금처럼 흑백·반투명이고, 글자 상자는 그대로 보인다.

### UI/UX 관점
- 상위 티켓 「확정 규격」의 사진 자리·글자 상자·일련번호 위치를 따른다. 글자 상자: `margin: 0 16px 24px`, 위 칸 `padding: 20px 16px 18px`(칩 + 이름 `text-3xl font-bold`), 아래 칸 `padding: 14px 16px 16px`(설명 `text-base`, 문장 단위 줄바꿈 규칙은 지금 히어로 카드와 같다), 테두리 `2px solid #171717`, 가운데 테두리는 한 줄, 배경 투명, 가운데 정렬. 설명이 없는 배지는 아래 칸을 그리지 않는다.
- 일련번호 래퍼는 글자 상자 아래 `pt-0 pb-6`.

## 구현 계획

- 추천안(채원① 확정 대상): DS `BadgeHeroSection`은 고치지 않고, 배지 상세 전용 서비스 부품 두 개를 `badges/[id]/`에 만든다 — `TicketPhoto`(둥근 16px 박스 안에 `BadgeAuraBackground`·이미지 슬롯, 지금 히어로 카드와 같은 배경 규칙) / `TicketTitleBoxes`(DS `RarityBadge`·`BadgeLevelChip` 재사용, `splitDescriptionSentences`로 설명). 대안은 DS 카드에 «글자 없이» 변형 prop을 더하는 것이다.
- `PoiEarnHistory`·`ItemEarnHistory`·`BadgeConditionCard`에 `showTitle?: boolean`(기본 true).
- `page.tsx`: 세 변형의 `photo`에 사진 부품, `afterPhoto`에 글자 상자(+아이템은 일련번호), 세 부품에 `showTitle={false}`.

### 주요 의사결정 / 핵심 메모

- 제목 숨김 prop 이름은 티켓 본문의 `showTitle`이 아니라 채원 판정의 `hideTitle`을 따랐다. 숨긴 제목은 sr-only로 남겨 구획 이름을 스크린리더에 알린다.
- 머리 축소 계수는 «단위 없는 숫자»가 아니라 «줄어드는 1px»(길이)로 둔다. 길이÷길이 나눗셈(타입 있는 산술)은 지원 브라우저가 적다. 단위 시험(jsdom)은 CSS 계산을 못 잡으므로 CSS 수식은 실렌더로 확인해야 한다.
- 페이지 h1은 TopNav 제목과 배지 이름 두 개다. 옛 화면(TopNav + 히어로 h1)과 같아 이번 변경으로 생긴 것이 아니다.
