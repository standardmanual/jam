# [UI] 배지 상세 티켓 머리: 로고를 종류 글자 높이에 맞추고 70%로 줄인다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-22 14:0x): 티켓 머리의 로고 크기를 `ITEM` 등 종류 글자의 세로 크기에 맞춘 뒤, 로고와 종류 글자를 둘 다 70%로 줄인다.
- 구현 계획: 경미 수정(jam-work 0.1절, 카리나 직접). `BadgeTicket.module.css`의 `.logo` 높이·윗여백과 `.kind` 글자 크기만 바꾼다. 390px 미만 비율 축소(`--u`)는 그대로 따른다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/BadgeTicket.module.css`(`.logo`·`.kind`), `docs/service/prd/badge-detail/PRD.md` 「티켓 머리」.

## 상세 요구사항

- 종류 글자: 34px → 23.8px(70%).
- 로고 높이: 종류 글자 한 줄의 실제 글자 높이(«ITEM» 기준). 34px에서 25.33px 실측 → 23.8px에서 17.73px. 로고 윗선을 종류 글자 윗선에 맞춘다.
- 날짜 줄(12px)은 그대로 둔다. 70%면 8.4px라 읽기 어렵다(카리나 판단, 사용자에게 보고).

## 완료 조건

- 390px에서 로고 윗선·아랫선이 종류 글자의 실제 글자 윗선·아랫선과 같다(오차 0.5px 이내).
- 종류 글자 23.8px, 날짜 12px. 360px에서도 같은 비율로 줄고 겹치지 않는다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약

- `.kind` font-size `calc(23.8 * var(--u))`, `.logo` height `calc(17.73 * var(--u))`·margin-top `calc(3.73 * var(--u))`. 윗여백은 계산값(3.37px)으로 넣었다가 실측에서 0.36px 어긋나 3.73px로 맞췄다.
