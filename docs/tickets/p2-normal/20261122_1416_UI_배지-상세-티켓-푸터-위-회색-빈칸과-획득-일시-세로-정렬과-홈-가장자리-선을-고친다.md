# [UI] 배지 상세 티켓: 푸터 위 회색 빈칸, 획득 일시 세로 정렬, 홈 가장자리 선을 고친다

## 핵심 요약

- 요구사항(사용자 지적 2026-11-22, staging 확인 중): ① 내용이 짧은 배지에서 페이지와 푸터 사이에 회색 빈칸이 보인다 ② 획득 정보 카드의 «획득 일시» 줄이 카드 세로 가운데에 있지 않다 ③ 절취선 홈 오른쪽에 티켓색 1px 선이 남는다.
- 구현 계획: 경미 수정(jam-work 0.1절, 카리나 직접). 파일 2개.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/page.tsx`(세 변형 루트 `min-h-full` → `min-h-dvh`, 액티비티 획득 정보 카드 행 묶음 `-mb-3` → `-my-3`), `BadgeTicket.module.css`(`.tear::before/::after`).

## 원인과 수정

- ① 레이아웃 칸(`(main)/layout.tsx`의 `div.min-h-dvh`)은 최소 높이가 화면 높이인데, 배지 페이지 루트는 `min-h-full`이 걸리지 않아 내용 높이만큼만 크림색을 칠했다. 남는 부분이 레이아웃의 회색(`--background` #f0f0f0)으로 보였다 → 페이지 루트도 `min-h-dvh`.
- ② 액티비티 획득 정보 카드의 행 묶음이 제목(«획득 정보», 2회차에서 뺌)이 있던 때의 `-mb-3`(아래만 당김)를 그대로 갖고 있어 행이 아래로 치우쳤다 → `-my-3`(아이템 이력 카드와 같음).
- ③ 홈 삼각형(페이지 배경색, clip-path)의 바깥 변이 티켓 가장자리와 같은 줄이라 그 픽셀이 반만 덮였다 → 삼각형을 바깥으로 1px 내민다(폭 21px, 꼭짓점은 가장자리에서 20px 그대로).

## 완료 조건

- 내용이 화면보다 짧은 배지에서 페이지 루트 아래 끝이 푸터 위 끝과 같고, 그 사이가 크림색이다.
- 행 하나짜리 획득 정보 카드에서 «획득 일시» 위아래 여백이 같다.
- 두 절취선의 왼쪽·오른쪽 가장자리 픽셀이 페이지 배경색이다.
