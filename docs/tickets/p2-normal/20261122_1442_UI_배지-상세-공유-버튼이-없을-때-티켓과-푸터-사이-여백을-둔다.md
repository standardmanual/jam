# [UI] 배지 상세: 공유 버튼이 없을 때 티켓과 푸터 사이 여백을 둔다

## 핵심 요약

- 요구사항(사용자 지적 2026-11-22, staging 아이폰 확인): 아직 획득하지 못한 배지 상세에서 티켓 아래 끝이 푸터에 바로 붙는다. 간격이 필요하다.
- 원인: 티켓 아래 여백(32px + 안전영역)이 공유 버튼 래퍼(`shareWrapStyle`)에만 있고, 그 래퍼는 «본인이 획득한 배지»일 때만 그린다. 미획득·타인(`?u=`) 배지에는 여백이 통째로 없다.
- 구현 계획: 경미 수정(카리나 직접). 세 변형에서 공유 버튼이 없으면 같은 아래 여백의 빈 칸(`noShareSpacerStyle`, `aria-hidden`)을 그린다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/page.tsx`(세 변형의 공유 버튼 자리), `__tests__/shareButtonPlacement.test.ts`(조건식이 삼항식으로 바뀐 것을 받게), `__tests__/badgeTicket.test.tsx`(여백 칸 단언), `docs/service/prd/badge-detail/PRD.md` 「페이지」.

## 완료 조건

- 미획득 배지에서 티켓 아래 끝과 푸터 사이가 32px(+ 안전영역)이다.
- 획득한 본인 배지는 공유 버튼과 간격이 이전과 같다.
- 공유 버튼은 여전히 «본인 + 획득»에서만 그린다(시험).
