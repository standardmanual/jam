## 배경 / 문제 정의

- 앞선 홈피드 개편(상위 20261120_2026)과 배지 상세 티켓 리뉴얼(상위 20261122_1221)은 끝났다. 그 뒤 사용자가 레퍼런스(&Walsh Insomnia Cookies·Coconut Cult, Lex 스티커)와 비교하며 캔버스에서 색과 칩을 다시 정했다.
- 지금 색은 세 벌로 나뉘어 있다: 강조색 5개(`--jam-*`, 배지 상세 티켓색), 홈피드 15색(`FEED_COLORS`, 어드민에서 값 덮어쓰기 가능), 캔버스의 통합 8색. 이를 한 벌로 합친다.
- 지금 코드의 색 배제 계산(대비·키즈·명도)을 새 팔레트에 대면, 승인한 초록+분홍 카드와 노랑+보라 스티커가 걸러진다. 그래서 배제 규칙을 표로 바꾼다.
- staging DB에 등록된 홈피드 카드는 배지 소개·텍스트·히어로 유형뿐이다. 나머지 유형은 로컬 개발용 미리보기 화면으로 규칙을 확인했다(캔버스 «홈피드 유형별 미리보기»).
- 근거 미리보기는 캔버스 보드 Unified-Palette·Unified-Feed(통합 팔레트 홈피드), Types-Feed·Types-Sticker(유형별), Oval-Spec(스티커 견본), Drop-A·Drop-A5(드랍·픽업), Sian-*(배지 상세)다.

### 2. 홈 카드 색

- 바탕+박스 조합 9개: 노랑+초록, 초록+노랑, 노랑+짙은 초록, 초록+분홍, 하늘+노랑, 노랑+하늘, 분홍+노랑, 분홍+초록, 하늘+분홍. 노랑·초록 조합 세 개는 다른 조합보다 두 배 자주 나온다. 바로 앞 카드와 같은 바탕은 피한다.
- **짙은 초록 바탕 카드**: 다섯~여섯 장에 한 장꼴로 바탕이 짙은 초록(박스는 노랑 또는 분홍)인 카드를 넣어 피드에 쉬어 가는 자리를 만든다. 바탕 위 제목·설명은 흰색(대비 4.5), 박스 위 글자는 검정이다. `colors.css`의 «15색 위 흰 글자 금지» 규칙에 이 예외를 적는다.
- 짙은 초록 박스는 텍스트형 카드에 쓰지 않는다(검정 글자 대비 3.9).
- 기존 카드 121장은 모두 새 규칙으로 색을 다시 배정한다(결정 9). 운영자가 손으로 고른 옛 색도 바뀐다.

### 3. 칩

- 크기: 작은 칩 40px·글자 18px, 큰 칩 52px·글자 24px, 굵기 900. 테두리 2px.
- 문구: 분류 칩은 «배지»를 빼고 영어 대문자(ACTIVITY·ITEM·MISSION·CHECK IN·COLLECTION·DROP·PICKUP), 값 칩(2일 남음·Lv.1·누적 3일 등)은 한국어 그대로.
- 자리: 카드 모서리 영역. 기울어진 칩의 바깥 끝은 안쪽으로 카드 가로 6%·세로 5%까지 들어오고, 카드 밖으로는 최대 6px만 나간다. 카드 간격 8px는 그대로. 두 칩은 같은 줄에 서지 않는다(텍스트형은 대각선, 아래쪽에 글자가 있는 카드는 두 번째 칩을 카드 높이 12~22%로 내림).
- 각도: 3~12°, 한 카드의 두 칩은 반대 방향.
- 무작위(결정 4): 자리·기울기 방향·모양·색을 서로 묶지 않고 각자 무작위로 고른다. 같은 값은 연속 2장까지만 이어지고, 바로 앞 카드와 칩 배치 전체가 같으면 안 된다. 번갈아 쓰는 고정 패턴은 쓰지 않는다.
- 값 칩은 알약 모양만 쓴다(결정 2). 색은 노랑·초록·분홍·하늘·빨강·보라·흰색 중 무작위다.
- 분류 알약 칩은 검정을 유지한다(결정 3).
- 드랍·픽업의 DROP·PICKUP은 둘 다 분류 칩으로 다룬다.

### 4. 분류 스티커

- 분류 칩의 절반 정도를 카드마다 무작위로 스티커로 바꾼다. 칩이든 스티커든 같은 꼴이 세 장 넘게 이어지지 않는다.
- 모양 두 가지: 조약돌(116×84, 호의 굽기가 배지마다 다름), 물결 덩어리(112×92, 혹 7~9개·높이 4~8.5px, 크기·간격 불규칙). 모양은 카드마다 고정된 값으로 만들어 같은 카드는 늘 같은 모양이다. 테두리 2px.
- 둘레 글자: 분류 문구를 최소 두 번 되풀이해 한 바퀴 채운다(굵기 900, 조약돌 11px·물결 10px 기준, 길면 줄임). 글자 선은 조약돌 가장자리에서 17px, 물결은 혹을 뺀 바탕 모양에서 15px 안쪽.
- 가운데: JAM 로고에서 잘라 낸 J·a·m 중 한 글자를 색으로 칠하고 본문색 외곽선(약 1.6px)을 두른다. 바로 앞 스티커와 같은 글자는 피한다.
- 색: 보색 짝 8개(노랑+보라, 보라+노랑, 초록+분홍, 분홍+초록, 하늘+빨강, 빨강+하늘, 파랑+노랑, 노랑+파랑). 바탕은 카드 바탕과 다르고 바로 앞 스티커와 다르다.

### 5. 배제 조합 표 (결정 1)

- 지금의 대비·키즈·명도 계산 규칙 대신 표로 정한다. 초안: 같은 색끼리, 빨강과 초록·짙은 초록, 노랑 위 흰 칩, 분홍 위 보라 칩.
- 배지 그림 색과 겹치는지(규칙 ⑤⑥ `violatesImageColorRule`)는 계속 계산으로 본다. 컬렉션 소개는 대표 그림과 아이템 배지 4개의 색을 모두 본다.

### 6. 가리지 않기와 물러서기

- 칩·스티커는 제목·설명 글자와 배지 그림을 가리지 않는다. 그림은 **안전 구역 방식**으로 판단한다(결정 6): 그림 상자 가운데 일정 비율을 피할 영역으로 잡고, 이미지 모양을 재서 저장하지 않는다. 넓거나 한쪽으로 치우친 그림은 가장자리가 조금 가려질 수 있다.
- 컬렉션 소개는 퍼진 뒤의 아이템 배지 자리와 대표 그림을 피할 영역으로 잡는다. 모인 모습에서도 칩 자리는 같다.
- 자리를 못 찾으면 이 순서로 물러선다(결정 8): 기울기 3° → 스티커 80% → 검정 알약 분류 칩으로 바꾸기 → 값 칩 작게 → 분류 빼기. 칩이 하나뿐이면 그 칩만 작게 한다.

### 7. 카드 유형

- 텍스트형: 343×440 → 343×343(1:1).
- 사진 텍스트형(박스에 사진): 흰 글자와 어둠 막 32%(결정 7).
- 드랍·픽업: «흩뿌린 배지» 안. 박스 없이 아이템 배지를 크게 겹치고 기울여 흩뿌린다. 배지 수(1~5개)마다 배치 틀을 미리 정하고, 지금의 «앞 3개» 대신 5개까지 그린다(캔버스 Drop-A5).
- 전체 배경 이미지 유형은 서비스에서 꺼져 있으므로 이번 범위에서 뺀다.

### 8. 어드민

- «홈피드 컬러셋» 메뉴(`/admin/feed-colors`, 티켓 20261121_2146)를 없앤다. 팔레트 값은 이제 디자인 시스템 파일에서 바꾸는 브랜드 결정이다. `feed_color_overrides` 표는 확장→전환→축소 규칙에 따라 코드가 읽지 않게 된 뒤 따로 정리한다.
- 카드 폼: 바탕·박스는 쓰임 표에 맞는 색 안에서만 고른다. 칩 색도 고를 수 있다(결정 5). 기본값은 자동이고, 배제 표에 걸리면 경고한다(막지 않음).

### 9. 배지 상세

- 티켓색: 홈 카드에서 들어오면 그 카드 바탕색을 이어받는다. 짙은 초록 카드면 초록으로 바꾼다. 이어받은 색이 배지 그림 색과 겹치면 그 카드의 박스 색, 그것도 겹치면 겹치지 않는 색 중 무작위다. 다른 경로로 들어오면 노랑·초록·분홍·하늘·빨강·보라·파랑 중 무작위다(짙은 초록 제외).
- 사진 자리: 이미지 색 그라데이션(Aura)을 걷고 티켓색 70%+흰색 톤을 깐다. 그림자는 없다.
- 미획득 배지: 회색 대신 티켓색을 깊게 낮춘 단색 실루엣. 노랑 티켓은 오렌지 쪽으로 돌린다.
- 칩: 등급·레벨·방문 횟수 칩은 제목 상자 안에 그대로 둔다.
- «Strava에서 보기» 버튼: 검정 바탕에 흰 글씨(Strava 규정은 굵은 글씨로 충족).
