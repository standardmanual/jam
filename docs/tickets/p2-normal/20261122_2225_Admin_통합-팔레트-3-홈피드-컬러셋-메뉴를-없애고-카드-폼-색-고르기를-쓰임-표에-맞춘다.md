# [Admin] 통합 팔레트 3: 홈피드 컬러셋 메뉴를 없애고 카드 폼 색 고르기를 쓰임 표에 맞춘다

## 핵심 요약

- 요구사항: 상위 티켓 [20261122_2217](20261122_2217_Feature_홈피드와-배지-상세를-통합-팔레트와-새-칩-규칙으로-리뉴얼한다-상위.md) 「확정 결정 §8」. 어드민 «홈피드 컬러셋»(`/admin/feed-colors`, 티켓 20261121_2146)과 API·메뉴 항목·홈 화면 덮어쓰기 주입(`FeedColorStyle`)을 없앤다. 카드 폼은 바탕·박스를 쓰임 표 안의 색에서만 고르고, 칩 색도 고를 수 있게 한다(기본값 자동, 배제 표에 걸리면 경고만, 결정 5). `feed_color_overrides` 표는 이 티켓에서 지우지 않는다(코드가 읽지 않게만 하고, 표 삭제는 축소 단계로 따로).
- 구현 계획: 하위 2번 뒤에 한다(새 색 키와 배제 표가 필요). 어드민은 MODULAR 적용 제외, shadcn/ui 표준.
- 관련 파일: `jam-web/src/app/admin/feed-colors/`, `jam-web/src/app/api/admin/feed-colors/route.ts`, `jam-web/src/components/admin/adminNavItems.ts`, `jam-web/src/components/today/FeedColorStyle.tsx`, `jam-web/src/lib/today/feedColorOverrides.ts`·`feedColorOverridesServer.ts`, `jam-web/src/app/admin/today/FeedCardSection.tsx`(`FEED_COLOR_LABELS`, 색 경고), `jam-web/src/lib/admin/feedCardFields.ts`.

## 완료 조건

- `/admin/feed-colors`와 그 API가 없고, 어드민 메뉴에 항목이 없다. 홈 화면은 덮어쓰기 값을 읽지 않는다.
- 카드 폼의 바탕·박스·칩 색 고르기가 쓰임 표의 색만 보여 주고, 기본값은 자동이며, 배제 표에 걸리는 조합은 경고 문구가 보인다(막지 않음).
- 로컬 어드민 실렌더 확인(카리나, 머지 뒤 push 전, `ADMIN_EMAILS` 셸 변수)을 티켓에 기록한다.
