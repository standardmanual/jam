# [UI] 통합 팔레트 4: 배지 상세의 티켓색 이어받기·미획득 실루엣·사진 자리 톤·Strava 버튼을 바꾼다

## 핵심 요약

- 요구사항: 상위 티켓 [20261122_2217](20261122_2217_Feature_홈피드와-배지-상세를-통합-팔레트와-새-칩-규칙으로-리뉴얼한다-상위.md) 「확정 결정 §9」. ① 티켓색: 홈 카드에서 들어오면 그 카드 바탕색을 이어받는다(짙은 초록→초록, 배지 그림 색과 겹치면 그 카드의 박스 색, 그것도 겹치면 겹치지 않는 색 중 무작위). 다른 경로면 노랑·초록·분홍·하늘·빨강·보라·파랑 중 무작위(짙은 초록 제외). ② 사진 자리: Aura 그라데이션을 걷고 티켓색 70%+흰색 톤, 그림자 없음. ③ 미획득 배지: 회색 대신 티켓색을 깊게 낮춘 단색 실루엣(노랑 티켓은 오렌지 쪽). ④ «Strava에서 보기» 버튼: 검정 바탕+흰 글씨. 칩은 제목 상자 안에 그대로 둔다.
- 구현 계획: 하위 1번 뒤에 한다(이어받기는 2번의 새 색 키를 쓴다). 시안은 캔버스 보드 Sian-*·Flow-Sian.
- 관련 파일: `jam-web/src/lib/badgeTicket/ticketColor.ts`(`TICKET_COLOR_KEYS` 8줄, `pickTicketColor` 37줄), `jam-web/src/app/(main)/badges/[id]/page.tsx`(티켓색 122줄), `jam-web/src/app/(main)/badges/[id]/BadgeTicket.tsx`, 히어로 카드·Aura 부품, Strava 링크 버튼, 홈 카드 링크(카드 색을 상세로 넘기는 자리).

## 완료 조건

- 홈 카드에서 배지 상세로 들어가면 티켓이 카드 바탕색이고, 짙은 초록 카드면 초록이다. 배지 그림 색과 겹치는 경우의 대체 규칙이 단위 시험으로 고정돼 있다.
- 다른 경로로 들어가면 짙은 초록을 뺀 일곱 색 중 하나다.
- 사진 자리에 Aura 그라데이션과 그림자가 없고 티켓색 톤이다. 미획득 배지는 티켓색 실루엣이다.
- «Strava에서 보기» 버튼이 검정 바탕·흰 글씨다.

## 완료 기록

### 구현 요약
- 티켓색 이어받기: 홈 카드 링크가 `?tc=<바탕 키>&tb=<박스 키>`를 덧붙이고(`/badges/{id}` 한 건에만, `cardView.ts`에서 한 곳), 배지 상세가 `resolveTicketColor`로 색을 정한다. 바탕을 이어받되 짙은 초록이면 초록으로 접고, 배지 그림 색과 겹치면 박스 색, 둘 다 겹치면 겹치지 않는 색 중 무작위(같은 난수는 같은 결과)다. 다른 경로·잘못된 쿼리 값(배열·빈 값·흰색·옛 키)은 노랑·초록·분홍·하늘·빨강·보라·파랑 일곱 색 중 무작위다.
- 사진 자리: Aura 그라데이션을 걷고 티켓색 70%+흰색 단색(`--card-bg`), 그림자 없음. 미획득 배지는 같은 그림의 알파 모양을 티켓색을 낮춘 단색(`--ticket-silhouette`, 노랑만 오렌지 갈색 #B4600F)으로 칠한 실루엣이다(SVG 필터).
- «Strava에서 보기» 버튼: 검정 바탕·흰 글씨(굵게). 같은 부품을 쓰는 포인트 적립 내역 버튼도 같이 바뀐다.

### 주요 의사결정
- 쿼리 이름은 짧은 `tc`·`tb`로 확정(공유 링크가 길어지지 않게). 공유 버튼은 주소가 아닌 배지 그림 이미지를 내보내므로 `tc`·`tb`는 주소창을 직접 복사할 때만 딸려 가고, 받는 사람도 같은 티켓색을 본다(의도 여부는 사용자 확인 항목).
- 실루엣은 `mask-image`가 교차 출처 이미지에서 빌 수 있어 SVG 필터(`feFlood`+`SourceAlpha`)로 구현했다. 필터 id가 고정값이라 한 화면에 `TicketPhoto`가 둘 이상 생기면 겹친다(현재는 하나).
- 새 토큰은 만들지 않고 `--card-bg`(티켓색 70%+흰색)와 서비스 상수 표(`TICKET_SILHOUETTE`)를 썼다. 실루엣 대비는 단위 시험으로 3:1 이상을 고정했다(최소 3.26:1, 빨강).
