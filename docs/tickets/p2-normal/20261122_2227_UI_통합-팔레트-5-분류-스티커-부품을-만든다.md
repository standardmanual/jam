# [UI] 통합 팔레트 5: 분류 스티커 부품(조약돌·물결)을 만든다

## 핵심 요약

- 요구사항: 상위 티켓 [20261122_2217](20261122_2217_Feature_홈피드와-배지-상세를-통합-팔레트와-새-칩-규칙으로-리뉴얼한다-상위.md) 「확정 결정 §4」의 분류 스티커를 부품으로 만든다. 모양 두 가지(조약돌 116×84, 물결 덩어리 112×92), 둘레 글자(분류 문구 최소 두 번 반복, 굵기 900), 가운데 JAM 로고 글자(J·a·m, 색 채움+본문색 외곽선 약 1.6px), 보색 짝 8개, 카드마다 고정된 모양 값. 홈피드 배치(어느 카드에 붙일지·자리)는 6번 티켓이 한다.
- 구현 계획: 채원① 판정으로 MODULAR 확장인지 서비스 전용인지 정한다. 로고 글자는 PNG 자르기가 아니라 로고 원본에서 벡터로 만든다. 미리보기 생성 함수(캔버스 Oval-Spec의 근거, 스크래치패드 `oval.js`)는 참고만 한다.
- 관련 파일: `jam-web/src/components/today/feed/`(새 부품), 로고 원본, Storybook 스토리.

## 완료 조건

- 분류 다섯 가지(ACTIVITY·ITEM·MISSION·CHECK IN·COLLECTION)와 DROP·PICKUP이 두 모양 모두에서 둘레를 채우고, 긴 문구는 글자가 줄어 맞는다.
- 같은 시드는 늘 같은 모양이다(단위 시험).
- Storybook에 두 모양×보색 짝 8개 견본이 있다.
