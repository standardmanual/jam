# [UI] 통합 팔레트 5: 분류 스티커 부품(조약돌·물결)을 만든다

## 핵심 요약

- 요구사항: 상위 티켓 [20261122_2217](20261122_2217_Feature_홈피드와-배지-상세를-통합-팔레트와-새-칩-규칙으로-리뉴얼한다-상위.md) 「확정 결정 §4」의 분류 스티커를 부품으로 만든다. 모양 두 가지(조약돌 116×84, 물결 덩어리 112×92), 둘레 글자(분류 문구 최소 두 번 반복, 굵기 900), 가운데 JAM 로고 글자(J·a·m, 색 채움+본문색 외곽선 약 1.6px), 보색 짝 8개, 카드마다 고정된 모양 값. 홈피드 배치(어느 카드에 붙일지·자리)는 6번 티켓이 한다.
- 구현 계획: 채원① 판정으로 MODULAR 확장인지 서비스 전용인지 정한다. 로고 글자는 PNG 자르기가 아니라 로고 원본에서 벡터로 만든다. 미리보기 생성 함수(캔버스 Oval-Spec의 근거)는 참고만 한다. 파일 단위 계획(2026-11-23 카리나, 바뀌는 파일 약 6개·450줄로 계획 반환 기준을 넘어 면제를 함께 넘긴다):
  1. `jam-web/src/lib/today/feedSticker.ts`(새 파일, 순수 계산): `stickerSeedOf(id)`(FNV-1a), `stickerRandom(seed)`(xorshift), `smoothClosedPath(points, start)`(Catmull-Rom → 3차 베지어), `pebbleShape(seed)`(116×84, 72점, 낮은 주파수 일그러짐 0.06, 살짝 기울임, 글자 선은 가장자리에서 17px 안쪽), `waveShape(seed)`(112×92, 혹 7~9개·높이 4~8.5px·간격 불규칙, 180점 표본, 글자 선은 혹을 뺀 바탕 모양에서 15px 안쪽), `fitRingText(label, ringLength, baseSize)`(«문구 • »를 최소 두 번 되풀이하고 길면 글자 크기를 줄임, 조약돌 11px·물결 10px 기준). 반환값은 `{ width, height, outlineD, ringD, ringLength, center, glyphHeight }`(조약돌 글자 높이 30, 물결 26). `STICKER_COLOR_PAIRS`(보색 짝 8개, 바탕 키+로고 글자 키, 통합 팔레트 토큰 이름으로).
  2. `jam-web/src/lib/today/jamLogoGlyphs.ts`(새 파일): `jam-web/design-system/assets/logo/jam-logo.svg`(viewBox 0 0 2610 865)의 세 경로가 곧 J·m·a 글자다(첫 경로 J, 둘째 m, 셋째 a). 글자마다 경로 문자열과 경계 상자를 상수로 옮긴다.
  3. `jam-web/src/components/today/feed/FeedSticker.tsx`(새 파일): props `{ shape: 'pebble' | 'wave', label, seed, pair, glyph: 'J' | 'a' | 'm' }`. SVG 하나로 바탕 모양(색 채움, 본문색 테두리 2px), 둘레 글자(`textPath`, 굵기 900, 본문색), 가운데 로고 글자(색 채움 + 본문색 외곽선 약 1.6px, 외곽선이 글자 바깥에 서도록 그림)를 그린다. `textPath` id는 `useId()`로 겹치지 않게 한다. 색은 `var(--jam-*)` 토큰만 쓴다.
  4. `jam-web/src/lib/today/__tests__/feedSticker.test.ts`(새 파일): 같은 시드는 같은 `outlineD`, 다른 시드는 다른 모양, 두 모양 모두 상자 안, 물결 혹 개수 7~9, 일곱 문구(ACTIVITY·ITEM·MISSION·CHECK IN·COLLECTION·DROP·PICKUP)가 최소 두 번 되풀이되고 긴 문구는 글자가 기준보다 작아짐.
  5. `jam-web/src/components/today/feed/FeedSticker.stories.tsx`(새 파일): 두 모양 × 보색 짝 8개 견본, 일곱 문구 견본.
  6. `docs/service/prd/home-feed/PRD.md`: 분류 스티커 부품의 모양·글자·색 규격을 한 절로 적는다(배치 규칙은 6번 티켓이 적는다).
  - 참고 원본(읽을 수 있으면): `/private/tmp/claude-502/-Volumes---------JAM-/f16f361f-1c72-496e-b93d-ddb8c3b16260/scratchpad/sian/oval/oval.js`의 `ovalSvg`·`flowerSvg`·`__warp`·`__fit`·`ringText`. 못 읽어도 위 수치로 충분하다. 미리보기는 로고 글자를 PNG로 그렸지만 구현은 벡터로 한다.
