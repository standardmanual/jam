# [UI] 통합 팔레트 7: 드랍·픽업 카드를 «흩뿌린 배지» 디자인으로 바꾼다

## 핵심 요약

- 요구사항: 상위 티켓 [20261122_2217](20261122_2217_Feature_홈피드와-배지-상세를-통합-팔레트와-새-칩-규칙으로-리뉴얼한다-상위.md) 「확정 결정 §7」. 드랍·픽업 카드에서 박스 3칸을 없애고, 아이템 배지를 크게 겹치고 기울여 흩뿌린다. 배지 수(1~5개)마다 배치 틀을 미리 정하고(캔버스 Drop-A5), 지금의 «앞 3개» 대신 5개까지 그린다. DROP·PICKUP 칩은 둘 다 분류 칩으로 6번 티켓 규칙을 따른다.
- 구현 계획: 6번 뒤에 한다. 이 유형으로 등록된 카드는 아직 없다(2026-11-22 확인).
- 관련 파일: `jam-web/src/components/today/feed/FeedDropPickupCard.tsx`, `jam-web/src/lib/today/feedConstants.ts`(`FEED_DROP_PICKUP`), `jam-web/src/lib/today/cardView.ts`(배지 앞 3개를 고르는 곳), Storybook `FeedDropPickupCard.stories.tsx`.

## 완료 조건

- 배지 1·2·3·4·5개 카드가 각각 정해진 배치 틀로 그려지고, 6개 이상이면 앞 5개만 그린다.
- 칩이 배지 그림 안전 구역과 글자를 가리지 않는다.
- Storybook에 배지 수별 견본 다섯 장이 있다.
