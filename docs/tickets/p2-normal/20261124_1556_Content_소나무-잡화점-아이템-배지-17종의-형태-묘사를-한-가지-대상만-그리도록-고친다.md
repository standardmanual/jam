# [Content] 소나무 잡화점 아이템 배지 17종의 형태 묘사를 한 가지 대상만 그리도록 고친다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-24): 소나무 잡화점 아이템 배지 이미지를 만드는 설명(`badges.form_description`)을 다시 검토해, 한 가지 대상만 그려지도록(상황을 그리더라도 대상이 하나만 나오도록) 고친다.
- 검토 결과: 90종 가운데 17종이 여러 개체를 그리게 만드는 문장이었다(포개진 인형 둘, 흩어진 비즈, 한 켤레, 한 다스, 상자 안의 내용물, 유리 칸과 받침대의 이중 구도 등). 나머지 73종은 대상이 하나라 그대로 둔다.
- 구현: DB 값 갱신(마이그레이션 361), 원고 04의 「형태 묘사:」 17줄 갱신. 같은 이름의 등급 4행에 같은 값이므로 17종은 68행이 바뀐다.
- 관련 파일: `jam-web/supabase/migrations/361_pinegoods_form_single_object.sql`(+`_down.sql`), `docs/plan/jam2/tribe-rethink/manuscript/04 물건 덕후.md`.

## 배경 / 문제 정의

이미지 생성기는 `form_description`을 영어 프롬프트로 옮겨 Recraft에 보낸다. 문장에 «나란히», «포개져», «한 켤레», «가지런히 줄지어» 같은 복수 표현이나 상자 속 내용물이 있으면 한 배지 이미지에 개체가 여러 개 그려져, 배지 한 장에 대상 하나만 쓴다는 규칙이 깨진다.

## 상세 요구사항

### 컨텐츠 관점
- 한 문장 묶음 안에서 그려지는 대상이 하나다. 복수였던 것은 하나로(인형 둘 → 인형 하나, 한 켤레 → 한 짝, 연필 한 다스 → 연필 하나), 내용물이 있던 것은 용기만(마스킹테이프 상자, 비즈 상자, 육각렌치 케이스), 주변 사물이 있던 것은 대상만(유리 칸 안의 받침대 → 받침대, 벽에 댄 선반 → 선반) 그린다.
- 기존 작성 규칙(티켓 20261113_1145 규칙 1·4: 한국어 40~100자, 「~니다」 종결, 숫자·금지어 없음)을 그대로 지킨다. 이번에는 «나란히», «포개», «켤레», «더미», «무더기» 같은 복수 표현도 막는다.

## 완료 조건

- 17종 모두 4행의 `form_description`이 새 문장으로 같다(실행 뒤 읽기 전용 확인).
- 나머지 73종의 값은 바뀌지 않는다(옛 값이 그대로일 때만 바꾸는 조건으로 실행).
- 원고 04의 17개 「형태 묘사:」 줄이 DB 값과 같다.
