# [Content] 다른 4개 트라이브 아이템 배지 66종의 형태 묘사를 한 가지 대상만 그리도록 고친다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-24, 티켓 20261124_1556의 후속): 소나무 잡화점에 적용한 «한 가지 대상만» 기준을 한입만 연구회·찰칵단·비사이드 레코즈·혼자들 360종에도 적용한다.
- 검토 결과: 360종 가운데 66종이 여러 개체나 주변 사물(벽·문·책상·접시·내용물)을 함께 그리게 만드는 문장이었고, 나머지 294종은 대상이 하나라 그대로 둔다.
- 구현: DB 값 갱신(마이그레이션 362, 66종 × 등급 4행 = 264행), 원고 01·02·03·05의 「형태 묘사:」 66줄 갱신.
- 관련 파일: `jam-web/supabase/migrations/362_other_tribes_form_single_object.sql`(+`_down.sql`), `docs/plan/jam2/tribe-rethink/manuscript/01 미식.md`·`02 사진.md`·`03 음악.md`·`05 내향인.md`.

## 배경 / 문제 정의

이미지 생성기는 `form_description`을 영어 프롬프트로 옮겨 Recraft에 보낸다. 문장에 복수 표현(«한 줌», «나란히», «한 켤레», «두 쪽», «포개져»)이나 주변 사물(벽에 붙은, 문 위의, 책상 위에 놓인, 접시에 놓인, 상자 속 내용물)이 있으면 한 배지 이미지에 개체가 여러 개 그려진다.

## 상세 요구사항

### 컨텐츠 관점
- 복수는 하나로(한 줌 → 한 알, 한 켤레 → 한 짝, 나란히 두 장 → 한 장), 내용물은 용기만(상자, 바구니, 깡통, 통), 주변 사물은 대상만(벽·문·책상·접시·유리 칸·종이 받침을 뺌) 그린다.
- 작성 규칙은 티켓 20261113_1145 규칙 1·4와 티켓 20261124_1556을 따른다(한국어 40~100자, 「~니다」 종결, 숫자·금지어·복수 표현 없음).
- 하나의 덩어리로 묶인 것(인덱스 카드 묶음, 전단지 뭉치, 고무줄로 묶은 사진 뭉치, 단어장)과 용기에 담긴 한 그릇의 음식(국물, 가루, 볶음밥, 튀김 접시)은 한 대상으로 보고 그대로 둔다.

## 완료 조건

- 나머지 294종과 낭만 미식가(비어 있음)는 바뀌지 않는다.
- 원고 01·02·03·05의 66개 「형태 묘사:」 줄이 DB 값과 같다.
