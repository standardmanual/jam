# [Admin] 컬렉션 표지를 그리는 공용 모듈(배경색 생성·배치·배지 가리기·질감)을 만든다 (생성기 2회차)

## 핵심 요약

- 요구사항: 상위 티켓 20261124_1741 «표지 규칙»을 그대로 구현한 순수 모듈을 만든다. 브라우저 캔버스(미리보기)와 서버 캔버스(`@napi-rs/canvas`, 시험)에서 같은 결과를 낸다.
- 구현 계획: `jam-web/src/lib/collection-cover/`에 색(OKLCH 변환·최대 채도·시드 난수·배경색 생성·글자 기본색), 배지 분석(주된 색상·선화 여부·외곽선 마스크),
  배치(제목 줄 나눔·하단·배지 위치), 그리기(`renderCollectionCover(ctx, input, deps)`)를 나눠 둔다. 캔버스 생성·이미지 로드는
  `src/lib/asset-generator/render.ts`의 CanvasFactory·ImageLoader 인터페이스처럼 주입받는다. 아래 부록의 시안 스크립트가 참고 구현이다.
- 관련 파일: 새 `jam-web/src/lib/collection-cover/{color,badge,layout,render,index}.ts`와 `__tests__/`, 참고 `jam-web/src/lib/asset-generator/render.ts`(15~83줄 인터페이스)

## 상세 요구사항

- 입력: `{ titleEn, tribeEn, badgeImage, seed, rerolls, usedHues, bgOverride?, textColorOverrides?: { title?, tribe?, join? } }`.
  출력: 그린 캔버스와 `{ bgHex, bgSource, textColors, layout }`(적용 때 `cover_params`로 저장할 값).
- 시드 난수는 같은 입력이면 브라우저·서버 모두 같은 배경색을 낸다(그레인·얼룩 노이즈는 시드와 무관해도 된다).
- 글꼴은 호출부가 등록한다(모듈은 글꼴 이름만 받는다). 기본 `Sour Gummy` 800.
- 다른 시안 값(Permanent Marker, 팔레트 12색, 무드 태그, 배지 300px)은 쓰지 않는다. 부록 스크립트에 남은 옛 함수(`pickBackground`, `PALETTE`)는 옮기지 않는다.

## 완료 조건

- 시험: (1) 같은 시드 → 같은 배경색, 다시 뽑기 횟수가 다르면 다른 색 (2) 생성 색은 모두 OKLCH C ≥ 0.15, 검정 제목 대비 ≥ 4,
  배지 색상과 70° 이상(완화 단계 없이 찾은 경우) (3) 5개 샘플 제목의 줄 나눔이 ALLEY FILM / SNAPS, MIDNIGHT / SNACK / CHASERS,
  ANALOG / MIXTAPE, LONELY / SOCKS, THE / STATIONERY / BOX이고 가장 긴 줄 잉크 폭이 가로 89.5~90.5% (4) 흰 하단 글씨는 대비 3 이상일 때만
  (5) 속이 빈 고리 모양 알파 이미지의 외곽선 마스크가 고리 안쪽을 포함한다.
- `scripts/verify.sh`가 통과한다.

const hex2rgb = h => [1, 3, 5].map(i => parseInt(h.slice(i, i + 2), 16))
const rgb2hex = c => '#' + c.map(v => Math.round(Math.max(0, Math.min(255, v))).toString(16).padStart(2, '0')).join('')
const lin = v => { v /= 255; return v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4 }
const lum = c => 0.2126 * lin(c[0]) + 0.7152 * lin(c[1]) + 0.0722 * lin(c[2])
const contrast = (a, b) => { const [x, y] = [lum(a), lum(b)].sort((p, q) => q - p); return (x + 0.05) / (y + 0.05) }
function rgb2hsl([r, g, b]) {
  r /= 255; g /= 255; b /= 255
  const mx = Math.max(r, g, b), mn = Math.min(r, g, b), l = (mx + mn) / 2
  if (mx === mn) return [0, 0, l]
  const d = mx - mn, s = l > 0.5 ? d / (2 - mx - mn) : d / (mx + mn)
  const h = mx === r ? (g - b) / d + (g < b ? 6 : 0) : mx === g ? (b - r) / d + 2 : (r - g) / d + 4
  return [h * 60, s, l]
}
const hueDist = (a, b) => { const d = Math.abs(a - b) % 360; return d > 180 ? 360 - d : d }

// ── 배지 분석: 불투명 픽셀에서 주된 색상(채도 가중 원형 평균)·평균 휘도·짙은 강조색·선화 여부
async function analyzeBadge(file) {
  const { data, info } = await sharp(file).resize(128, 128, { fit: 'inside' }).ensureAlpha().raw().toBuffer({ resolveWithObject: true })
  let sx = 0, sy = 0, sw = 0, n = 0, L = 0, sat = 0, dark = [0, 0, 0, 0], ox = 0, oy = 0
  for (let i = 0; i < data.length; i += 4) {
    if (data[i + 3] < 128) continue
    const c = [data[i], data[i + 1], data[i + 2]]; const [h, s, l] = rgb2hsl(c)
    n++; L += lum(c)
    if (s > 0.25 && l > 0.12 && l < 0.9) { const [, oa, ob] = srgb2oklab(c); ox += oa; oy += ob; sat++; const w = s; sx += Math.cos(h * Math.PI / 180) * w; sy += Math.sin(h * Math.PI / 180) * w; sw += w }
    if (s > 0.35 && l < 0.35) { dark[0] += c[0]; dark[1] += c[1]; dark[2] += c[2]; dark[3]++ }
  }
  const chromatic = sat / n > 0.12
  return {
    hue: chromatic ? ((Math.atan2(sy, sx) * 180 / Math.PI) + 360) % 360 : null,
    meanLum: L / n,
    lineArt: !chromatic,
    okHue: chromatic ? ((Math.atan2(oy, ox) * 180 / Math.PI) + 360) % 360 : null,
    darkAccent: dark[3] > n * 0.02 ? [dark[0] / dark[3], dark[1] / dark[3], dark[2] / dark[3]] : null,
  }
}


// ── OKLCH(사람 눈 밝기 기준 색 공간) ↔ sRGB
const cbrt = Math.cbrt
function srgb2oklab([R, G, B]) {
  const r = lin(R), g = lin(G), b = lin(B)
  const l = cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b)
  const m = cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b)
  const s2 = cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b)
  return [0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s2, 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s2, 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s2]
}
function oklch2linear(L, C, h) {
  const a = C * Math.cos(h * Math.PI / 180), b = C * Math.sin(h * Math.PI / 180)
  const l = (L + 0.3963377774 * a + 0.2158037573 * b) ** 3, m = (L - 0.1055613458 * a - 0.0638541728 * b) ** 3, s2 = (L - 0.0894841775 * a - 1.2914855480 * b) ** 3
  return [4.0767416621 * l - 3.3077115913 * m + 0.2309699292 * s2, -1.2684380046 * l + 2.6097574011 * m - 0.3413193965 * s2, -0.0041960863 * l - 0.7034186147 * m + 1.7076147010 * s2]
}
const enc = v => 255 * (v <= 0.0031308 ? 12.92 * v : 1.055 * v ** (1 / 2.4) - 0.055)
const inGamut = c => c.every(v => v >= -0.0005 && v <= 1.0005)
function maxChroma(L, h) { let lo = 0, hi = 0.4; for (let i = 0; i < 24; i++) { const mid = (lo + hi) / 2; inGamut(oklch2linear(L, mid, h)) ? lo = mid : hi = mid } return lo }
const oklch2rgb = (L, C, h) => oklch2linear(L, C, h).map(v => Math.round(Math.max(0, Math.min(255, enc(Math.max(0, Math.min(1, v)))))))
// 시드 난수(컬렉션마다 같은 결과, 다시 뽑기는 시드를 바꾼다)
function rng(str) { let h = 1779033703 ^ str.length; for (let i = 0; i < str.length; i++) { h = Math.imul(h ^ str.charCodeAt(i), 3432918353); h = h << 13 | h >>> 19 }
  return () => { h = Math.imul(h ^ h >>> 16, 2246822507); h = Math.imul(h ^ h >>> 13, 3266489909); h ^= h >>> 16; return (h >>> 0) / 4294967296 } }

// ── 배경색 생성: 팔레트 없이 컬렉션마다 새로 만든다.
//    밝기 L 0.56~0.68(검정 제목·흰 하단 두 색), 25%는 0.80~0.90(노랑·라임처럼 밝아야 선명한 색), 그 색상에서 낼 수 있는 가장 높은 채도의 96%. 채도가 0.15에 못 미치는 색(칙칙한 청록 등)은 버린다.
//    배지 주된 색상과 70° 이상, 다른 컬렉션 표지 색상과 30° 이상 떨어져야 하고, 검정 제목 대비 4 이상(선화 배지면 4.5)
const C_MIN = 0.15
function genBackground(seed, badge, usedHues) {
  const r = rng(seed)
  const tries = [[70, 30], [50, 20], [30, 0]]
  for (const [badgeGap, usedGap] of tries) {
    for (let i = 0; i < 600; i++) {
      const h = r() * 360, bright = r() < 0.25, L = bright ? 0.80 + r() * 0.10 : 0.56 + r() * 0.12, cmax = maxChroma(L, h)
      if (cmax < C_MIN) continue
      if (badge.okHue != null && hueDist(h, badge.okHue) < badgeGap) continue
      if (usedHues.some(u => hueDist(h, u) < usedGap)) continue
      const rgb = oklch2rgb(L, cmax * 0.96, h)
      if (contrast(rgb, hex2rgb(INK)) < (badge.lineArt ? 4.5 : 4)) continue
      return { p: { key: `oklch(${L.toFixed(2)} ${(cmax * 0.96).toFixed(3)} ${h.toFixed(0)})`, hex: rgb2hex(rgb) }, rgb, h }
    }
  }
  throw new Error('배경색 후보 없음')
}

// ── (옛 팔레트 방식, 쓰지 않음) 배경색 자동 선택: 무드 태그 일치 후보 → 배지와 색상 거리(멀수록 좋음) → 배지 가독(선화면 밝은 배경) → 이미 쓴 색 제외
function pickBackground(moods, badge, used) {
  const scored = PALETTE.filter(p => !used.has(p.key)).map(p => {
    const rgb = hex2rgb(p.hex), [h, s] = rgb2hsl(rgb)
    const moodHits = p.moods.filter(m => moods.includes(m)).length
    // 무드 순서 가중: 앞쪽 태그일수록 크게
    const moodScore = moods.reduce((acc, m, i) => acc + (p.moods.includes(m) ? (moods.length - i) : 0), 0)
    const hueScore = badge.hue == null || s < 0.2 ? 90 : hueDist(h, badge.hue)
    const badgeContrast = badge.lineArt ? contrast(rgb, [22, 20, 18]) : 99
    return { p, rgb, moodHits, score: moodScore * 100 + hueScore, ok: moodHits > 0 && badgeContrast >= 4.5 }
  }).filter(x => x.ok).sort((a, b) => b.score - a.score)
  return scored[0]
}

// ── 하단 글씨 색: 흰색 → 배지 짙은 강조색 → 잉크 순으로 3:1 이상인 첫 색
function pickBottomColor(bgRgb, badge) {
  const cands = [[255, 255, 255], hex2rgb(INK)] // 흰색이 3:1 미만이면 검정
  return cands.find(c => contrast(c, bgRgb) >= 3) || hex2rgb(INK)
}

// ── 제목 줄 나누기: 단어 2개 이상이면 두 줄 중 가장 긴 줄이 가장 짧아지는 지점에서 나눈다
function splitTitle(ctx, words) {
  if (words.length < 2) return [words.join(' ')]
  let best = null
  for (let k = 1; k < words.length; k++) {
    const lines = [words.slice(0, k).join(' '), words.slice(k).join(' ')]
    const m = Math.max(...lines.map(t => ctx.measureText(t).width))
    if (!best || m < best.m) best = { lines, m }
  }
  return best.lines
}

    d[i] = r; d[i + 1] = g; d[i + 2] = bl; d[i + 3] = o
  }
  bx.putImageData(id, 0, 0); return b
}

  const TITLE_W = W * 0.9, TITLE_TOP = 64, TITLE_MAX_H = Number(process.env.TITLE_MAX_H || 540), LEAD = 0.86
  const inkAt = (t, f) => { x.font = `${f}px "${FONT}"`; x.textAlign = 'left'; const m = x.measureText(t)
    return { w: m.actualBoundingBoxLeft + m.actualBoundingBoxRight + STROKE * 2, left: m.actualBoundingBoxLeft + STROKE, asc: m.actualBoundingBoxAscent + STROKE, desc: m.actualBoundingBoxDescent + STROKE } }
  const blockH = (ls, f) => (ls.length - 1) * f * LEAD * SY + Math.max(...ls.map(t => inkAt(t, f).asc)) * SY
  const parts = []
  const rec = (i, acc) => { if (i === words.length) { if (acc.length <= 3) parts.push(acc); return } for (let j = i + 1; j <= words.length; j++) rec(j, [...acc, words.slice(i, j).join(' ')]) }
  rec(0, [])
  const cands = parts.map(ls => { const f = 100 * TITLE_W / Math.max(...ls.map(t => inkAt(t, 100).w)); return { ls, f, h: blockH(ls, f) } })
  const fits = cands.filter(c => c.h <= TITLE_MAX_H).sort((p, q) => q.f - p.f)
  let best = fits[0]
  if (!best) { best = cands.map(c => ({ ...c, f: c.f * TITLE_MAX_H / c.h })).sort((p, q) => q.f - p.f)[0] }
  const lines = best.ls, fs1 = best.f
  const lineH = fs1 * LEAD * SY
  const firstAsc = Math.max(...lines.map(t => inkAt(t, fs1).asc)) * SY
  const ys = lines.map((_, i) => TITLE_TOP + firstAsc + i * lineH)
  const metrics = lines.map(t => inkAt(t, fs1))
  x.drawImage(inkLayer(cx => {
    cx.font = `${fs1}px "${FONT}"`; cx.textAlign = 'left'; cx.textBaseline = 'alphabetic'
    lines.forEach((t, i) => { const m = metrics[i]; cx.save(); cx.translate((W - m.w) / 2 + m.left, ys[i]); cx.scale(1, SY)
      if (STROKE) { cx.lineWidth = STROKE * 2; cx.lineJoin = 'round'; cx.strokeText(t, 0, 0) }
      cx.fillText(t, 0, 0); cx.restore() })
  }, INK), 0, 0)
  const titleBottom = ys[ys.length - 1] + Math.max(...metrics.map(m => m.desc)) * SY
  titleInfo = { lines: lines.join(' / '), fontPx: Math.round(fs1), inkWidthPct: Math.round(Math.max(...metrics.map(m => m.w)) / W * 1000) / 10, blockH: Math.round(titleBottom - TITLE_TOP) }

  // 4) 하단: 트라이브 영문 이름(위) + JOIN AND MOVE(아래).
  //    JOIN AND MOVE는 첫 시안(가로 77%)의 절반인 가로 38.5%, 트라이브 이름은 그 글자 크기의 1.875배(가로 90% 상한)
  x.font = `100px "${FONT}"`; x.textAlign = 'center'
  const inkW = t => { const m = x.measureText(t); return m.actualBoundingBoxLeft + m.actualBoundingBoxRight }
  const fsJoin = 100 * (W * 0.385) / inkW('JOIN AND MOVE')
  const fsTribe = Math.min(fsJoin * 1.25 * 1.5, 100 * (W * 0.9) / inkW(tribe)) // 사용자 요청으로 1.5배, 가로 90% 상한
  const joinBase = H - 64
  const tribeBase = joinBase - fsJoin * 0.75 * SY - fsJoin * 0.42
  const bottomHex = rgb2hex(bottomRgb)
  const line = (cx, t, f, yb) => { cx.font = `${f}px "${FONT}"`; cx.textAlign = 'center'; cx.save(); cx.translate(W / 2, yb); cx.scale(1, SY); cx.fillText(t, 0, 0); cx.restore() }
  x.drawImage(inkLayer(cx => { line(cx, tribe, fsTribe, tribeBase); line(cx, 'JOIN AND MOVE', fsJoin, joinBase) }, bottomHex), 0, 0)
  const bottomTop = tribeBase - fsTribe * 0.75 * SY

  // 5) 대표 배지: 투명 여백을 잘라 최대 변 450px. 제목과 하단 글씨 사이에 들어가면 그 가운데,
  //    안 들어가면 하단 글씨 위에 붙이고 제목을 가린다. 배지 외곽선 안쪽(+6px)을 바탕으로 먼저 덮어
  //    선화처럼 속이 빈 배지도 제목 글자가 비쳐 보이지 않게 한다.
  const trimmed = await sharp(badgeFile).trim().png().toBuffer()
  const img = await loadImage(trimmed)
  const BADGE_MAX = Number(process.env.BADGE_MAX || 450), PAD = 36
  const k = BADGE_MAX / Math.max(img.width, img.height)
  const bw = Math.round(img.width * k), bh = Math.round(img.height * k)
  const zoneTop = titleBottom + PAD, zoneBottom = bottomTop - PAD
  const bx = Math.round((W - bw) / 2)
  const by = Math.round(bh <= zoneBottom - zoneTop ? (zoneTop + zoneBottom) / 2 - bh / 2 : zoneBottom - bh)
  // 외곽선 안쪽 마스크: 불투명 픽셀을 벽으로 보고 가장자리에서 바깥 영역을 채운 뒤, 바깥이 아닌 곳 전부
  const mc = createCanvas(bw, bh), mxx = mc.getContext('2d'); mxx.drawImage(img, 0, 0, bw, bh)
  const md2 = mxx.getImageData(0, 0, bw, bh), a2 = md2.data, outside = new Uint8Array(bw * bh), stack = []
  const solid = i => a2[i * 4 + 3] > 24
  for (let xx = 0; xx < bw; xx++) { stack.push(xx, (bh - 1) * bw + xx) }
  for (let yy = 0; yy < bh; yy++) { stack.push(yy * bw, yy * bw + bw - 1) }
  while (stack.length) { const i = stack.pop(); if (outside[i] || solid(i)) continue; outside[i] = 1
    const px = i % bw, py = (i - px) / bw
    if (px > 0) stack.push(i - 1); if (px < bw - 1) stack.push(i + 1); if (py > 0) stack.push(i - bw); if (py < bh - 1) stack.push(i + bw) }
  for (let i = 0; i < bw * bh; i++) { a2[i * 4] = a2[i * 4 + 1] = a2[i * 4 + 2] = 255; a2[i * 4 + 3] = outside[i] ? 0 : 255 }
  mxx.putImageData(md2, 0, 0)
  const halo = createCanvas(W, H), hx = halo.getContext('2d')
  hx.filter = 'blur(4px)'; hx.drawImage(mc, bx, by); hx.filter = 'none'
  const hd = hx.getImageData(0, 0, W, H), hdd = hd.data
  for (let i = 3; i < hdd.length; i += 4) hdd[i] = hdd[i] > 8 ? 255 : 0
  hx.putImageData(hd, 0, 0)
  hx.globalCompositeOperation = 'source-in'; hx.drawImage(bgSnap, 0, 0)
  x.drawImage(halo, 0, 0)
  x.drawImage(img, bx, by, bw, bh)
  const badgeInfo = { badgePx: [bw, bh], badgeY: by, overlapsTitle: by < titleBottom }

  // 6) 고운 그레인(전체에 흑백 단색 노이즈)
  const id = x.getImageData(0, 0, W, H), d = id.data
  for (let i = 0; i < d.length; i += 4) {
    const n = (Math.random() + Math.random() + Math.random() - 1.5) * 11
    d[i] += n; d[i + 1] += n; d[i + 2] += n
  }
  x.putImageData(id, 0, 0)

  const out = `${S}/out/${TAG}${slug}.png`
  fs.writeFileSync(out, c.toBuffer('image/png'))
  return { slug, ...titleInfo, ...badgeInfo, badgeOkHue: badge.okHue && Math.round(badge.okHue), tribeFontPx: Math.round(fsTribe), tribeWidthPct: Math.round(inkW(tribe) * fsTribe / W * 10) / 10, joinFontPx: Math.round(fsJoin), bg: bg.p.key, bgHex: bg.p.hex, bottom: rgb2hex(bottomRgb), badgeHue: badge.hue && Math.round(badge.hue), lineArt: badge.lineArt, titleContrast: contrast(hex2rgb(INK), bg.rgb).toFixed(1), bottomContrast: contrast(bottomRgb, bg.rgb).toFixed(1) }
}
