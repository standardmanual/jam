# [Admin] 컬렉션 상세 페이지에 표지 생성기 구역(미리보기·수동 변경·적용)을 붙인다 (생성기 3회차)

## 핵심 요약

- 요구사항: `/admin/itembooks/[id]`에 «대표 이미지 생성기» 구역을 더한다. 미리보기 캔버스, 컬렉션 영문 이름 입력, 대표 배지 선택,
  배경색 다시 뽑기·직접 지정, 글자색 3개(제목·트라이브·JOIN AND MOVE), 기본값으로 되돌리기, 적용 버튼을 둔다.
- 구현 계획: 2회차 모듈(`src/lib/collection-cover/`)을 브라우저 캔버스로 호출해 미리보기를 그린다. 적용은 1024 PNG를
  `/api/admin/asset-generator/apply`(`targetType: 'collection'`)로 올리고, 같은 흐름에서 `name_en`·`cover_params`를 저장한다.
- 관련 파일: `jam-web/src/app/admin/itembooks/[id]/page.tsx`(서버 조회에 name_en·cover_params·tribes.name_en·소속 배지 sort_order 추가,
  다른 컬렉션 cover_params 배경색 목록, 새 구역 배치), 새 `jam-web/src/components/admin/itembooks/CollectionCoverGenerator.tsx`(클라이언트),
  `jam-web/src/app/api/admin/itembooks/[id]/route.ts`(name_en·cover_params 저장 허용), `jam-web/src/app/api/admin/asset-generator/apply/route.ts`(필요 시만),
  `jam-web/src/lib/admin/policyDashboard/policiesData.ts` `ch19-english-names`

## 상세 요구사항

- 어드민 UI는 shadcn/ui(`components/admin/ui`)를 쓴다. 네이티브 select·color input을 그대로 노출하지 않는다(색 칸은 shadcn 입력 + 색 견본).
- 기본값: `cover_params`가 있으면 그 상태로 연다. 없으면 시드 = 컬렉션 id, 다시 뽑기 0회, 배지 = 소속 아이템 배지 중 이미지가 있는 첫 배지(sort_order),
  글자색은 모듈 기본 규칙. 컬렉션 영문 이름이 비어 있으면 입력을 요구하고 적용 버튼을 막는다. 트라이브 영문 이름은 DB 값을 읽기만 한다
  (비어 있으면 경고).
- 다시 뽑기: 횟수를 1 올려 새 시드로 배경색을 만든다. 직접 지정: 색을 고르면 `bgSource: 'manual'`. 다른 컬렉션 배경 색상 목록을
  모듈에 넘겨 30° 이내 색을 피한다.
- 글자색 3개는 각각 «자동»과 직접 지정을 오갈 수 있다. 자동이면 배경이 바뀔 때 기본 규칙으로 다시 정한다.
- 대표 배지: 소속 아이템 배지를 썸네일 목록으로 보여 주고 고른다(같은 이름의 등급 중복은 묶지 않아도 된다).
- 미리보기는 설정이 바뀔 때마다 다시 그린다(글꼴·배지 이미지 로드 완료 뒤). Sour Gummy 800은 브라우저에서도 굵기 800 파일을 쓴다
  (기존 `loadFontInBrowser`는 굵기 400만 받으므로 FontFace로 직접 로드).
- 적용: 확인창 → 업로드·교체 → 성공 시 `name_en`·`cover_params`(appliedAt 포함) 저장 → 화면 새로고침. 실패 시 [현상]→[원인]→[해결책] 문구.
- 정책 대시보드 `ch19-english-names`에 생성기(위치, 기본 규칙 요약, 수동 변경 항목, 적용 동작)를 반영한다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 구역의 상태(로딩·영문 이름 없음·적용 중·실패)가 모두 그려진다.
- 설정 변경 → 미리보기 갱신, 적용 → apply API 호출과 `name_en`·`cover_params` 저장이 시험으로 확인된다.
- `scripts/verify.sh`가 통과한다.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤 push 전)
- 로컬 next dev(`ADMIN_EMAILS` 셸 변수)로 컬렉션 상세를 열어 5개 샘플 컬렉션의 미리보기가 시안과 같은 규칙으로 나오는지 눈으로 확인한다.
