# [Content] 찰칵단·소나무 잡화점의 트라이브 영문 이름을 바꾼다

## 핵심 요약

- 요구사항: 사용자 결정(2026-11-24)으로 찰칵단은 한글 발음을 로마자로 그대로 적어 `CHALKAKDAN`, 소나무 잡화점은 `PINE TREE STORE`로 바꾼다.
- 구현 계획: `tribes.name_en` 두 행을 데이터 SQL로 바꾸고(카리나 직접 실행), 정책 항목 `ch19-english-names`의 현재 값과 `트라이브 보이스.md` 7.1절의 변경 기록을 맞춘다.
- 관련 파일: `jam-web/supabase/migrations/seed_tribe_name_en_20261124.sql`(신규), `jam-web/src/lib/admin/policyDashboard/policiesData.ts` `ch19-english-names`(1695줄 근처 currentSpec), `docs/plan/jam2/service-redesign/트라이브 보이스.md` 7.1절

## 배경 / 문제 정의

표지 생성기(티켓 20261124_1741)는 트라이브 영문 이름을 DB 칸에서 읽어 표지 하단에 쓴다. 사용자가 표지를 만들기 전에 두 이름을 고쳤다.
시험 파일의 `CLICK CREW`·`PINE TREE GENERAL STORE`는 그리기 입력 예시 문자열이라 바꾸지 않는다.

## 완료 조건

- 실행 전 드라이런·되돌림 실측, 실행 뒤 읽기 전용 확인(5행 중 두 값만 바뀜).
- 정책 대시보드와 문서가 새 값과 맞는다.
