# [Admin] 표지 생성기의 색 견본을 누르면 컬러 피커가 열리게 한다

## 핵심 요약

- 요구사항: 사용자 요청(2026-11-24) «컬러를 누르면 컬러피커를 보여줘». 배경색·글자색 3개 칸의 색 견본을 눌러 색을 고를 수 있게 한다.
- 구현 계획: 견본(장식용 span)을 다른 어드민 화면과 같은 shadcn `Input type="color"`로 바꾼다. 고른 색은 #rrggbb 입력 칸과 같은 경로(`onCommit`)로 들어가 직접 지정이 된다.
- 관련 파일: `jam-web/src/components/admin/itembooks/CollectionCoverGenerator.tsx` `ColorField`(86줄 근처)

## 배경 / 문제 정의

3회차(티켓 20261124_1744)는 «네이티브 color input을 그대로 노출하지 않는다»는 계획에 따라 견본을 보기 전용 상자로 두고 #rrggbb를 손으로 적게 했다. 사용자가 견본을 눌러 고르기를 원했다. 액티비티 배지 템플릿·에셋 제너레이터 어드민이 이미 shadcn `Input type="color"`를 쓰므로 같은 방식을 따른다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `ColorField`의 견본을 `Input type="color"`(라벨 «… 고르기», h-9 w-12)로 바꿨다. 고른 색은 `normalizeHex`를 거쳐 `onCommit`으로 들어가므로 배경색은 «직접 지정», 글자색은 그 줄의 «자동»이 꺼진다. #rrggbb 입력 칸은 그대로 둔다.
- 파일 1개·10줄 남짓이라 경미 수정으로 카리나가 직접 처리했다.

### 테스트 결과
- [x] `eslint` 통과, `collectionCoverState`·`CollectionCoverGenerator` 시험 18건 통과.
- [x] 로컬 `ADMIN_EMAILS` 실렌더(짝 잃은 양말, 적용은 누르지 않음): 색 칸 4개 모두 피커 입력이 있다. 견본을 누르면 피커가 열린다(운영체제 창이라 스크린샷에는 찍히지 않는다). 피커 값으로 배경 #3355ff를 넣자 «배경색(직접 지정)»과 미리보기 배경이 바뀌고, 제목 #ffe14d를 넣자 제목 줄 «자동»만 꺼지고 미리보기 제목이 바뀌었다.

### 주요 의사결정 / 핵심 메모
- 피커에서 색을 고르는 동안(드래그) 값이 바뀔 때마다 미리보기를 다시 그린다. 느리게 느껴지면 피커를 닫을 때만 반영하도록 바꾼다.
