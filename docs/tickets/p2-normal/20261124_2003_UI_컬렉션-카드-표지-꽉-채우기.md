# [UI] 컬렉션 목록 카드의 대표 이미지가 썸네일 칸을 꽉 채우게 한다

## 핵심 요약

- 요구사항: 사용자 지적(2026-11-24) «대표이미지가 컬렉션 목록에서 카드에 꽉차지 않아». 생성기로 만든 표지(꽉 찬 정사각형)가 카드 썸네일 안에서 여백을 두고 작게 보인다.
- 구현 계획: `CollectionGridCard` 썸네일 이미지의 안쪽 여백 `p-1.5`를 없앤다. `object-contain`은 그대로 둬 정사각형이 아닌 이미지는 잘리지 않는다.
- 관련 파일: `jam-web/src/components/ui/CollectionGridCard.tsx` 썸네일 `SafeImage`(70줄 근처)

## 배경 / 문제 정의

카드는 컬렉션 이미지를 투명 배경 배지 그림으로 가정해 6px 안쪽 여백을 두었다. 표지 생성기(티켓 20261124_1741)로 만든 표지는 배경색이 칸 끝까지 차 있어 여백이 테두리처럼 보인다.

---
## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `SafeImage` 클래스 `object-contain p-1.5` → `object-contain`. 썸네일 주석에 이유를 적었다. 카드 면의 바깥 여백 12px과 둥근 모서리(16px)는 그대로다.
- 배지 그림을 쓰는 다른 컬렉션 카드는 그림이 사방 6px씩 커진다.
- 파일 1개·두 줄이라 경미 수정으로 카리나가 직접 처리했다.

### 테스트 결과
- [x] `eslint` 통과, `CollectionGridCard.tagOrder`·`cardFacePairs` 시험 38건 통과.
- [x] 로컬 실렌더(`/badges#collection`, 2026-11-24): 골목길 필름 스냅 표지 이미지가 썸네일 칸(171×171)과 같은 크기로 꽉 찬다. 배지 그림 카드(매직 아워·겨울잠의 안식처 등)도 깨지지 않았다.

### 주요 의사결정 / 핵심 메모
- 사용자 화면에서 표지 색이 흐리게 보였는데, 로컬에서는 재현되지 않았다(이미지·부모 요소에 opacity·filter 없음, 저장된 WebP는 선명한 초록 #47a01e 근처).
- 카드 바깥 여백까지 없애 표지를 카드 가장자리까지 붙이는 방식은 하지 않았다. 원하면 카드 면 레시피(BadgeGridCard와 공유)를 바꾸는 별도 작업이다.
