## 상세 요구사항

### 서비스/코드베이스 관점
- 표지색 파생: `deriveCoverTicketColor(bgHex: string | null | undefined, delta = 0.10)` 같은 순수 함수를 `ticketColor.ts`에 둔다. hex를 OKLCH로 바꾸고 명도를 `max(0.2, L − 0.10)`로 낮춘 뒤 hex로 되돌린다(색역을 벗어나면 채도만 줄여 맞춘다). 입력이 없거나 `#rrggbb`가 아니면 `pickTicketColor(null)`처럼 통합 팔레트 일곱 색 중 하나로 대신한다.
- 파생 결과 타입은 팔레트 키가 없는 색도 담아야 하므로 `TicketColor`의 `key`·`cssVar` 의존을 풀거나 별도 타입(예: 임의 hex를 담는 `ticket`·`ticketEnd`·`text` 값)을 둔다. 배지 상세 호출부의 동작과 시험은 바뀌지 않는다.
- 끝색은 기존 `ticketEndColor(hex)` 문자열을 그대로 쓴다. 글자색은 티켓색 hex와 끝색 hex(OKLCH 상대색 문자열이 아니라 같은 공식으로 계산한 hex)에서 `#171717`의 대비가 둘 다 4.5 이상이면 `#171717`, 아니면 흰색이다(둘 다 안 되면 티켓색 기준으로 더 큰 쪽). 시안의 계산식(아티팩트 소스의 `ticketColors`)이 기준이다.
- 색은 서버에서 정한다. 클라이언트 훅·`useEffect`로 칠하지 않는다.
- 데이터 읽기는 바꾸지 않는다. `cover_params`는 `jsonb`라 `book.cover_params as { bgHex?: unknown } | null`로 좁혀 읽는다(`database.generated.ts`에 타입이 없으면 지역 타입으로).
- 진행 표시는 지금 그대로다(사용자 확정): 모으는 중 `ProgressCountBar`(초록 캡슐 바와 «n/N»), 완성(`isCompleted`) 초록 완성 알림(`d.itembooks.completed`·`completedTitle`·`completedBody`). 문구를 새로 만들지 않는다. 바 옆 «n/N» 글자색은 `--link` 대신 티켓 글자색(`--ticket-text`)을 따라 짙은 티켓에서도 읽히게 한다. 초록 완성 카드는 모양을 바꾸지 않는다.

### UI/UX 관점
- 짙은 티켓에서 `--muted`·`--border`·글자 상자 테두리·로고가 흰색 계열로 따라간다. 슬롯 칸의 점선(미획득)이 짙은 티켓과 연한 티켓 모두에서 보이는지 확인한다. 점선 표현 자체는 바꾸지 않는다.
- 슬롯 선택 시트·«모두 빼기» 시트 등 오버레이는 티켓 밖이라 모양을 바꾸지 않는다.
- 표지가 없으면(`image_url` null) 메달류 아이콘(기존 `MagicBookIcon`)을 `--card-bg` 사진 자리에 둔다.

- 티켓색은 통합 팔레트 무작위·홈 카드 색 이어받기를 쓰지 않고 표지색 파생으로 정했다(사용자). 명도 낮춤은 시안 슬라이더 기본 0.12에서 0.10으로 정했다.
- 진행 표시는 시안의 «n/N 모음» 칩 대신 지금 모양(진행 바·초록 완성 알림)을 유지한다(사용자 2차 답변). 완성 알림이 초록이라 초록 계열 표지 티켓에서는 면이 비슷한 색으로 겹칠 수 있다.
- 글자색 판정은 끝색을 빼고 «티켓색·중간색»으로 하고 `#000`을 허용한다(사용자). 카드 바탕은 흰 글자 티켓에서만 연하게 한다(사용자).
- MODULAR 승격(20261122_1351)은 하지 않고 서비스 전용을 유지한다(채원①). 어드민 미리보기(2254)까지 끝난 뒤 다시 판정한다.
- 첫 호출은 채원① 사전 판정이 `needsApproval`로 아현 호출 전에 멈췄다(오렌지 대비·카드 바탕 비율·칩 모양). 사용자 답을 티켓 2252·2253에 반영하고 판정을 `reuseDecision`으로 넘겨 재호출했다.

### 잔여 이슈
- 오렌지 표지(`#e38502`, «노을 헌터의 기록») 글자 대비가 중간색 위 4.40으로 4.5에 못 미친다(사용자 판단 대기).
- 초록 표지 위 초록 완성 알림의 색 겹침은 완성 상태의 컬렉션이 없어 보지 못했다(진행 중 화면은 정상).
- `BadgeTicket.module.css`의 `.faceKeepCards`가 `SlotGrid` 내부 클래스(`.grid-cols-3`, `.bg-card-bg`)를 전역 이름으로 잡는다. `SlotGrid` 마크업이 바뀌면 글자색이 조용히 어긋날 수 있다.
- 어드민 컬렉션 배경 설정 화면 정리는 병렬 티켓 20261124_2326이 맡는다.
