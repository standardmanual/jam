# [UI] 컬렉션 상세 티켓 2: 어드민 컬렉션 미리보기 프레임을 티켓 모양으로 맞춘다

## 핵심 요약

- 요구사항: 어드민 컬렉션 배경 제너레이터의 상세 미리보기 프레임(`ItemBookDetailPreviewFrame`)이 실제 서비스 화면과 다른 마크업이 되지 않도록, 1회차(20261124_2253)가 만든 티켓 틀·표지 사진 자리·글자 상자 부품을 그대로 쓰게 한다. 쓰는 곳이 없어진 `ItemBookHeroSection`과 그 시험을 지운다.
- 구현 계획: 1회차가 머지된 뒤에 한다(그 부품을 가져다 쓴다). 1회차 부품의 실제 파일명·props를 읽고 맞춘다.
- 관련 파일(지도):
  - `jam-web/src/app/admin/itembooks/ItemBookDetailPreviewFrame.tsx`(107줄) — `ItemBookHeroSection` 호출과 배경 레이어(`backgroundLayerStyle`·`backgroundLayerRef`·`liveNode`·`themed`).
  - 이 프레임을 쓰는 곳은 `grep -rn "ItemBookDetailPreviewFrame" jam-web/src`로 찾는다(어드민 컬렉션 배경 제너레이터 화면).
  - `jam-web/src/app/(main)/collections/[id]/ItemBookHeroSection.tsx`, `__tests__/heroChildren.test.tsx`, `__tests__/heroTextColor.test.tsx` — 쓰는 곳이 없어지면 삭제한다.
  - 문서: `docs/service/prd/badge-detail/PRD.md`의 «컬렉션 상세» 절(1회차가 만든다)에 어드민 미리보기 한 줄을 더한다.

## 배경 / 문제 정의

상위 티켓 20261124_2252 참고. 미리보기가 실제 화면과 마크업이 달라지는 사고를 막으려고 미리보기는 서비스 화면과 같은 컴포넌트를 재사용해 왔다(티켓 20260819_014). 1회차가 서비스 화면에서 `ItemBookHeroSection`을 걷으면 미리보기만 옛 모양으로 남는다.

## 상세 요구사항

- 프레임이 서비스 화면과 같은 티켓 부품으로 대표 이미지·이름·설명을 그린다. 티켓색은 미리보기에 넘어오는 컬렉션의 표지색(없으면 서비스와 같은 대체 규칙)이다. 진행 수 칩은 미리보기용 고정값(예: 0/0 또는 대표 값)으로 채운다.
- 배경 레이어(전체 화면 배경)는 서비스에서 그리지 않기로 했으므로 미리보기에서 서비스와 어긋나지 않게 정리한다. 배경 제너레이터의 저장(bake) 동작이 이 레이어 DOM 참조에 기대고 있으면 저장 동작을 깨지 않는 선에서만 바꾸고, 깨질 위험이 있으면 멈추고 보고한다(`halted`).
- 어드민 스코프의 토큰 덮어쓰기 때문에 프레임이 `data-service-theme`로 서비스 토큰을 되찾는 구조를 유지한다.

## 구현 계획

1. 1회차 머지본에서 티켓 부품 이름·props를 확인한다.
2. `ItemBookDetailPreviewFrame.tsx`를 그 부품으로 바꾼다. props가 바뀌면 호출부를 같이 고친다.
3. `ItemBookHeroSection`과 두 시험 파일을 지운다(다른 곳에서 import하지 않는지 grep으로 확인).
4. PRD 한 줄, `scripts/verify.sh` 통과.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 어드민 컬렉션 미리보기 프레임이 서비스 화면과 같은 티켓 부품으로 그려진다.
- `ItemBookHeroSection`과 그 시험이 없고, 저장소 어디서도 그 이름을 import하지 않는다.
- 배경 제너레이터의 저장(bake) 동작이 이전과 같다(관련 시험 통과).
- `scripts/verify.sh` 통과.
