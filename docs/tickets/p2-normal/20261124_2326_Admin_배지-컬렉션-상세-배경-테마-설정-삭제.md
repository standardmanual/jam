# [Admin] 배지·컬렉션 상세 화면에서 배경 테마(배경 방식·배경색) 설정 기능을 삭제한다

## 핵심 요약

- 요구사항: 어드민 «콘텐츠 > 배지 > 각 상세 페이지»(`/admin/badges/[id]`·`/admin/badges/[id]/edit`)와 «콘텐츠 > 컬렉션 > 각 상세 페이지»(`/admin/itembooks/[id]`)에서 배경 테마(배경 방식·배경색) 표시 및 설정 기능을 제거한다. DB 컬럼·API 병합 로직·트라이브 폼의 공용 컴포넌트(`BackgroundGeneratorPreview`·`ItemBookDetailPreviewFrame`·`BackgroundColorField`)는 유지한다.
- 구현 계획: `BadgeDetail.tsx`의 배경 읽기 항목과 배경 미리보기 전달을 제거하고, `BadgeForm.tsx`·`ItemBookForm.tsx`에서 `BackgroundGeneratorPreview` UI·배경 state·hex 검증·PUT/POST 전송 필드를 제거한다. `badge-sections.ts`의 디자인 섹션 설명·상태 계산에서 배경 항목을 정리한다.
- 관련 파일: `jam-web/src/components/admin/badges/BadgeDetail.tsx`(124·141~142·315~332·357~363줄), `jam-web/src/app/admin/badges/BadgeForm.tsx`(8·23·36·189~194·541~547·585~591·666~667·1351~1353·1367~1373·1397~1402줄), `jam-web/src/lib/admin/badge-sections.ts`(114~116·146~147·170~174줄), `jam-web/src/app/admin/itembooks/ItemBookForm.tsx`(10·22~24·28~29·87~93·107~115·122·136~140·160~164·417~452줄), `jam-web/src/lib/admin/__tests__/badge-sections.test.ts` 및 배지·컬렉션 폼 렌더/계약 테스트

## 배경 / 문제 정의

배지 상세 화면이 티켓 디자인으로 개편되며 전체 화면 배경 테마 레이어가 사라졌고, 컬렉션 대표 이미지는 표지 생성기(`CollectionCoverGenerator`)로 별도 관리한다. 어드민 배지 상세·수정 화면과 컬렉션 상세 편집 화면에 남아 있는 옛 «배경 테마(배경 방식·배경색)» 설정 영역이 불필요한 혼란을 주어 삭제한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- **배지 상세(`/admin/badges/[id]` — `BadgeDetail.tsx`)**:
  - 디자인 섹션의 «배경» 읽기 항목(애니메이션/색상 견본/기본 배경)을 제거한다.
  - 우측 레일 미리보기(`BadgeRailPreview`)에 배경 테마 값을 넘기지 않는다(전부 `null`).
- **배지 생성·수정 폼(`BadgeForm.tsx`, `/admin/badges/[id]/edit`·`/admin/badges/new`)**:
  - 디자인 섹션의 `<BackgroundGeneratorPreview>`를 제거하고 배지 이미지 업로드만 남긴다.
  - `backgroundColor`·`backgroundAnimation` 상태, `ImageUploadField`의 `onAverageColor` 콜백, 배경색 hex 검증을 제거한다.
  - 저장 요청(`PUT`/`POST`) 본문에서 `background_color`·`background_animation`을 생략한다(PUT API는 `undefined` 필드를 기존 DB 값으로 유지하고, POST API는 `null`로 저장한다).
  - 우측 레일 미리보기(`BadgeRailPreview`)에 배경 테마 값을 넘기지 않는다(전부 `null`).
- **배지 섹션 메타(`badge-sections.ts`)**:
  - `design` 섹션 설명을 «배지 이미지예요. 결과는 미리보기에 바로 반영돼요.»로 정리한다.
  - `BadgeSectionSnapshot`에서 `hasAnimation`·`hasBackgroundColor`를 제거하고, `design` 상태는 이미지 유무(`이미지 필요` / `완료`)만 판정한다.
- **컬렉션 상세 편집 폼(`ItemBookForm.tsx`, `/admin/itembooks/[id]`·`/admin/itembooks/new`)**:
  - «배경 테마» 카드 영역(`<BackgroundGeneratorPreview>` 및 `<ItemBookDetailPreviewFrame>`)을 제거한다.
  - `backgroundColor`·`backgroundAnimation` 상태, 배경색 hex 검증(`validate`), 저장 요청(`PUT`/`POST`) 본문의 `background_color`·`background_animation` 전송을 제거한다.
  - 컬렉션 상단의 «대표 이미지 생성기»(`CollectionCoverGenerator`)는 건드리지 않는다.
- **공용 컴포넌트·DB 보존**:
  - `TribeForm.tsx`·`Ops*`가 참조하는 `BackgroundGeneratorPreview.tsx`·`BlobAnimationFields.tsx`·`ItemBookDetailPreviewFrame.tsx`·`BackgroundColorField.tsx`는 삭제하지 않는다.
  - DB 컬럼 및 서버 API의 기존 병합/호환 로직은 변경하지 않는다.

## 구현 계획

1. `jam-web/src/lib/admin/badge-sections.ts` 및 `badge-sections.test.ts`: 디자인 섹션 설명·상태에서 배경 테마 의존성 제거.
2. `jam-web/src/components/admin/badges/BadgeDetail.tsx`: 디자인 섹션 «배경» 항목 및 배경 테마 전달 제거.
3. `jam-web/src/app/admin/badges/BadgeForm.tsx`: `BackgroundGeneratorPreview`, 배경 state·검증·전송·`onAverageColor` 제거.
4. `jam-web/src/app/admin/itembooks/ItemBookForm.tsx`: «배경 테마» 블록, 배경 state·검증·전송 및 미사용 import 제거.
5. 회귀/렌더 테스트 추가: `BadgeDetail`·`BadgeForm`·`ItemBookForm`에 «배경 테마»·«배경 방식» UI가 렌더되지 않고 저장 본문에 `background_color`·`background_animation`이 포함되지 않음을 테스트로 고정.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- `BadgeDetail.tsx`에 «배경» 항목이 없고, `BadgeForm.tsx`와 `ItemBookForm.tsx`에 «배경 테마»·«배경 방식» UI(`BackgroundGeneratorPreview`)가 렌더링되지 않는다(단위 테스트 검증).
- `BadgeForm.tsx`와 `ItemBookForm.tsx`의 저장 요청 본문에 `background_color`·`background_animation`이 포함되지 않는다(계약 테스트 검증).
- `badge-sections.ts`의 `design` 섹션 상태가 이미지 유무만으로 계산되고 기존/신규 단위 테스트가 통과한다.
- `CollectionCoverGenerator`(컬렉션 대표 이미지 생성기)와 `TribeForm.tsx`의 기존 동작 및 테스트에 회귀가 없다.
- `npm run lint:ci`, `npm run typecheck`, 관련 단위 테스트·`test:node`·정합성/슬롭 검사가 모두 통과한다.

### 후속 범위 (담당: 카리나/사용자, 시점: 머지 뒤)
- 로컬 `ADMIN_EMAILS` 어드민의 `/admin/badges/[id]`, `/admin/badges/[id]/edit`, `/admin/itembooks/[id]`에서 배경 테마 설정 영역이 사라진 것을 실렌더로 확인하고 티켓을 `CLOSED` 처리한다.
