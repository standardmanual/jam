# [UI] 서비스 DS·컴포넌트 통합 및 UI 소스 최적화

## 핵심 요약

- 요구사항: 최근 서비스 업데이트 이후 사용자 서비스(`jam-web/design-system/`, `src/components/`, `src/app/(main)|(auth)|(onboarding)|(legal)`) 전반에 쌓인 DS 원본 드리프트, 독립 UI 재구현, 하드코딩 색/데드 CSS, 가드레일 공백을 일괄 정리한다. 기존 UI 모양·값을 바꾸지 않는 무변화 최적화(사례 1~3)를 기본 전제로 하되, 아래 사용자 의사결정 5건에 한해 시각 통일 및 결함 수정을 함께 반영한다.
- 사용자 의사결정 (2026-11-25):
  1. **슬롯 +/− 원형 버튼 20px 통일**: `SlotCircleButton`과 DS `MixerSlot` 내부 `ActionCircle`의 `+`/`−` 원형 버튼을 모두 `20px × 20px`(터치 영역 44px 유지)로 통일하고 공유한다.
  2. **사례 4 — Button 혼용·raw CTA·링크 버튼 통일**: `@ds/components/buttons/Button` 직접 임포트 8곳, raw CTA `<button>` 3곳(`CombineClient`·`TierUpPanel`·`onboarding/page`), 중복 알약 링크 버튼 6곳(`ArticleView`·`inventory/page`·`badges/[id]/page`·`PoiMapButton`·`StravaLink`·`philosophy/page`)을 `@/components/ui/Button`(`href` 지원 포함)으로 일원화하고 DS `Button.jsx`와 `Button.tsx`의 패딩·스피너·`aria-busy`를 정합화한다.
  3. **사례 5 — 컬렉션 체크인 3열 그리드 & 인벤토리 빈 슬롯 치수 통일**: `collections/[id]/page.tsx`의 수동 체크인 3열 그리드를 `BadgeGridCard` + `ListRowChip`으로 교체하고, `InventoryGrid` 빈 슬롯에 `BadgeGridCard` 플레이스홀더를 적용해 채운 카드와 동일한 폭·높이(`aspect-square` + `text-sm`)로 맞춘다.
  4. **사례 6 — 검색창·온보딩·프로필 편집 폼 통일**: DS `Input`에 `prefix`/`suffix`/`leadingIcon`/`trailing` 슬롯을 추가하고 DS `Checkbox`의 레거시 오류·성공 토큰(`--rarity-*` → `--danger`/`--success`)을 정리한 뒤 `UserSearchBar`·`CombineClient` 검색창·`onboarding/page`·`profile/edit/page`에 적용한다.
  5. **사례 7 — 스크림 blur 꺼짐 버그 & CapsuleGauge 하단 그림자 수정**: `transitions.css`에서 표준 `backdrop-filter`와 쌍으로 적혀 lightningcss가 표준 속성을 제거하던 `-webkit-backdrop-filter`를 제거하고 `.t-toast-scrim`에 `prefers-reduced-transparency` 가드를 추가하며, `CapsuleGauge`의 금지된 드롭 섀도우(`boxShadow`)를 제거한다.
- 무변화 구조 최적화 (시각 100% 보존):
  - DS 원본 5종(`BadgeGridCard.jsx`, `Toast.jsx`, `BottomSheet.jsx`, `SlidingTabs.jsx`, `CollectionGridCard.jsx`)을 서비스 실물 치수·토큰에 맞춰 동기화하고, `ToastRow`에 `role="status" aria-live="polite"`, `SlidingTabs.tsx`에 화살표 키 내비게이션을 추가한다.
  - `PendingItemsPickOverlay`의 `phase === 'full'` 수동 모달/스크롤 잠금을 공용 확인 모달 표면 + `pushMainScrollLock()`으로 통합한다.
  - 9개 파일 11곳에 흩어진 원형 아바타를 공용 `src/components/ui/Avatar.tsx`로 통합하고, `FeedGalleryListCard`의 인라인 화살표 `<svg>`를 아이콘 세트로 교체한다.
  - `ProfileClient`·`WithdrawSheet` 수동 스켈레톤을 `@ds/components/feedback/Skeleton`으로, `PendingResultsSheet`·`SlotGrid`·`ItemCandidateSheet`의 중복 인라인 안내를 `InlineNotice`로 정리한다.
  - `BadgeTicket.module.css`의 `#fff`/`#171717`을 토큰(`var(--base-white)`/`var(--base-neutral-900)`)으로 치환하고, `globals.css`에 누락된 `@theme inline` 토큰을 등록(`text-snow/60·70·80` 제거)하며, 미사용 `dotmatrix-loader.css`(1,228줄)와 고아 로더·미사용 CSS 변수를 정리한다.
  - `spacing-baseline.json`을 최신화하고, `serviceLiteralColors.test.ts`·`commonLiteralColors.test.ts`·`scrimBlur.test.ts`의 가드레일 공백을 메운다.
