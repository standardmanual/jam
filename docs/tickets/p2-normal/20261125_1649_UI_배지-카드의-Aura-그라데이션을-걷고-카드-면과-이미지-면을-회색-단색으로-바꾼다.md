# [UI] 배지 카드의 Aura 그라데이션을 걷고 카드 면과 이미지 면을 회색 단색으로 바꾼다

## 핵심 요약
- 요구사항: `BadgeGridCard`(목록 카드, 일반·compact)와 `BadgeHeroSection`(큰 배지 카드)에서 배지 대표색 Aura 그라데이션을 걷어 내고, 카드 면과 이미지(썸네일) 면을 모두 `--background-secondary`(#e5e5e5)로 칠한다. 회색 면에 묻히는 **Lv 칩과 방문 횟수 칩(×N)** 은 Common 등급 칩 색(`--rarity-common` 면, `--rarity-common-foreground` 글자)을 쓴다. 등급 칩(`RarityBadge`)은 원래 색을 유지한다. Aura 부품(`BadgeAuraBackground.tsx`)과 `badgeAura.ts`의 Aura 코드·시험은 삭제하고, 배지 상세 티켓이 쓰는 그레인 질감 상수만 남긴다.
- 구현 계획: 아래 「구현 계획」 절의 파일 단위 목록대로 한다. 삭제 위주라 줄 수가 크다(계획 반환 면제, 근거는 「주요 의사결정」).
- 관련 파일: 「구현 계획」 절 표에 경로·함수·줄 위치를 적었다(줄 번호는 로컬 staging `96570c5be` 기준).

## 배경 / 문제 정의
2026-11-19에 배지 이미지에서 뽑은 대표색(`badges.bg_colors`)으로 목록 카드 썸네일 면과 큰 배지 카드에 Aura 그라데이션을 깔았다(상위 티켓 20261119_1650, 하위 1653·1654). 2026-11-25에 사용자가 실제 계정 데이터로 만든 배색 프로토타입(https://claude.ai/artifact/ABc9qMzQkLcfSY7WkLyTBG)을 보고 «배지 그림이 원색이라 배경 색이 더해지면 정신없다»고 판단했고, 비교 끝에 **카드 면·이미지 면 모두 #e5e5e5** 로 확정했다. 이어서 «기존 배지 이미지 배경의 그라데이션 소스코드를 제거하고 이 컬러값으로 변경»하라고 지시했고, 범위는 목록 카드와 큰 배지 카드 모두(«전부 제거»)로 골랐다.

카드 면이 회색이 되면 지금 `--default-soft`(#e5e5e5) 면을 쓰는 Lv 칩·방문 횟수 칩이 카드 면과 같은 색이 되어 보이지 않는다. 그래서 두 칩만 Common 칩 색으로 바꾼다(사용자 확정).

### UI/UX 관점
- 목록: 페이지 바탕 `--background`(#f0f0f0) 위에 #e5e5e5 카드. 바텀시트처럼 흰 면 위에 놓이는 그리드(드랍 고르기·아이템 후보·믹스 가방)에서도 같은 #e5e5e5다.
- 글자는 `--foreground`(검정) 그대로다. 이름 흐림(`nameMuted`)도 그대로다.
- 칩 색 정리: Lv 칩·방문 횟수 칩 = `--rarity-common` 면 + `--rarity-common-foreground` 글자. 등급 칩 = 원래 등급 색. Common 등급 칩과 Lv 칩이 같은 색이 되지만 글자(«Common»·«Lv.N»)로 구분한다(사용자 확인 사항).
- 참고 화면: 프로토타입의 «확정안» 프리셋.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- `BadgeGridCard` 일반·compact 모두 카드 면과 썸네일 면의 배경이 `var(--background-secondary)`다. `data-testid="badge-aura-background"` 요소가 어떤 경우에도 그려지지 않는다(`bgColors`를 넘겨도).
- `BadgeGridCard`에서 `level`이 있으면 Lv 칩, `visitCount`가 2 이상이면 방문 횟수 칩이 `--rarity-common` 면·`--rarity-common-foreground` 글자로 그려진다. `RarityBadge`의 Rare·Epic·Mystic·Common 색은 바뀌지 않는다. 썸네일 모서리 «×N» 필은 흰 면·외곽선 그대로다.
- `locked`·`undiscovered`·`outlined`·`earned=false`·`selected`·`highlighted`·`compact` 표현이 바뀌기 전과 같다(기존 `BadgeGridCard.locked/undiscovered/compact` 시험 통과).
- `BadgeHeroSection`은 배경 테마가 없으면 대표색 유무와 관계없이 바탕이 `--background-secondary`이고 Aura가 없다. 배경 테마가 있으면 지금과 같다. 카드 안 Lv·방문 칩은 Common 칩 색이다.
- `BadgeLevelChip`을 회색 면 밖에서 쓰는 곳(피드·배지 상세 티켓 등)의 칩 색은 바뀌지 않는다.
- `jam-web/src` 전체에서 `BadgeAuraBackground`·`resolveAuraColors`·`auraMesh`·`auraGlow`·`AURA_GLOW`·`AURA_MESH`·`AURA_FALLBACK`를 찾으면 결과가 없다(`grep -rn` 확인). 그레인 질감은 배지 상세 티켓 화면에서 이전과 같은 SVG·크기로 깔린다(`badgeTicket.test.tsx`·`TicketBoxes.test.tsx` 통과).
- `bgColors` prop은 타입에 남아 있지만 렌더링에 쓰이지 않고 `@deprecated` 주석에 후속 티켓 ID가 적혀 있다.
- `scripts/verify.sh`가 통과한다.
- `docs/service/prd/badge-detail/PRD.md`의 Aura 서술이 회색 단색으로 갱신돼 있다.

### 구현 내용 요약
- 목록 카드 `BadgeGridCard`(일반·compact)의 카드 면과 썸네일 면을 `bg-background-secondary`(#e5e5e5)로 통일하고 Aura 계산·렌더·`relative` 분기·import를 걷었다. `bgColors` prop은 `@deprecated`(후속 20261125_1650)로 남기고 읽지 않는다.

- 큰 배지 카드 `BadgeHeroSection`: 배경 테마가 없으면 `var(--background-secondary)` 바탕, 있으면 이전과 같다. DS 히어로가 Lv 칩 색을 받지 않아 회색 면에서는 Lv 칩을 `chipExtra` 쪽에서 직접 그리고, 방문 칩에는 `tone`을 덧입힌다.
