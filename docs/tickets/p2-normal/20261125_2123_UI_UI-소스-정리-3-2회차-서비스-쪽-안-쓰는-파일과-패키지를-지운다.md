## 구현 계획

1. 브랜치에서 `cd jam-web && npx knip --no-exit-code`로 위 목록이 여전히 미사용으로 나오는지 다시 확인한다(목록 밖 새 항목은 지우지 않고 보고).
2. 후보마다 `git grep`으로 import·동적 로딩 여부를 확인하고 지운다. 그 파일만 검사하는 시험도 함께 지운다.
3. 패키지는 `npm uninstall <이름>`으로 지운다(`package.json`의 `scripts` 칸은 건드리지 않는다 — 3-1회차가 같은 파일의 `scripts` 칸을 고친다).
4. `node scripts/check-ui-rules.mjs` 기준선이 지운 파일 때문에 줄면 `--write-baseline`으로 줄인다(늘리는 것은 금지).
5. `npm run typecheck`, `npm run lint`, `npm run build`(또는 `next build`가 너무 오래 걸리면 typecheck·lint·vitest로 대신하고 그 사실을 적는다),
   `scripts/verify.sh` 전체 통과.
