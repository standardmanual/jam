# [UI] UI 소스 정리 3-3a회차: 서비스와 공용 코드의 안 쓰는 내보내기를 정리한다

## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 3회차(미사용 제거)의 셋째 조각 앞부분. knip이 찾은 미사용 export·type 가운데 **어드민 밖**
  (서비스 화면·`src/lib`·`design-system`)의 것을 정리한다. 어드민(`/admin/`이 경로에 든 파일, 약 export 368·type 171건)은 3-3b회차로 미룬다.
- 사용자 결정(2026-11-25): 지워도 영향이 없는 값은 모두 지운다. 서비스·공용 코드부터, 어드민은 다음 조각(«그렇게 시작»).
- **화면·동작 변화가 없어야 한다.** 대부분은 파일 안에서는 쓰이는데 `export`만 불필요하게 붙은 경우다. `export`를 떼고, 그 결과 파일 안에서도
  안 쓰이는 것으로 드러난 선언만 지운다.
- 대상 규모(staging `88d43e846` 실측): 어드민 밖 미사용 export 약 217건·type 약 158건, 약 94개 파일.
- 관련 파일: knip이 고르는 파일 전체(어드민 경로 제외). 아래 「구현 계획」의 방법으로 정한다.

## 구현 계획

1. 브랜치에서 `cd jam-web && npx knip --fix --fix-type exports,types --no-exit-code`를 돌린다(파일 삭제 옵션은 쓰지 않는다).
2. **어드민 경로 되돌리기**: `git diff --name-only`에서 경로에 `/admin/`이 든 파일(`src/app/admin/**`, `src/components/admin/**`, `src/lib/admin/**` 등)은
   `git checkout -- <경로>`로 되돌린다. 3-3b회차 몫이다.
3. **Next.js·Storybook 약속 이름 보호**: diff에서 아래 이름의 `export`가 떼어졌으면 되돌린다(knip 플러그인이 알아야 하지만 확인한다) —
   `default`, `metadata`, `generateMetadata`, `generateStaticParams`, `viewport`, `generateViewport`, `dynamic`, `dynamicParams`, `revalidate`,
   `fetchCache`, `runtime`, `preferredRegion`, `maxDuration`, `GET`·`POST`·`PUT`·`PATCH`·`DELETE`·`HEAD`·`OPTIONS`, `config`, `middleware`,
   스토리 파일의 모든 export.
4. **이중 export 4건 중 어드민 밖 2건**(`src/lib/missions/condition-keys.ts`의 `MISSION_DB_CONDITION_KEY_LIST`·`MISSION_DB_RANGE_CHECKED_KEYS`,
   `src/lib/notifications/batch/shared.ts`의 `DAY_MS`·`FOLLOWING_WINDOW_MS`)은 같은 값을 두 이름으로 내보내는 것이다. 쓰이는 이름 하나만 남긴다.
   `scripts/gen-new-activity-badge-families.mjs`는 일회성 스크립트라 건드리지 않는다.
5. `npm run lint`에서 새로 생긴 `no-unused-vars`(내보내기를 뗀 뒤 파일 안에서도 안 쓰이는 선언)를 지운다. 지울지 애매하면(부작용 있는 초기화 등) 남기고 보고한다.
6. `npm run typecheck`, `npm run lint:ci`(경고 기준선 26 이하 유지), `npx knip --no-exit-code`로 어드민 밖 미사용 export·type이 0인지 확인,
   `scripts/verify.sh` 전체 통과. 워크트리 `node_modules`가 링크라 전체 vitest가 실패하면 `npm ci --ignore-scripts`로 실제 설치해서 확인한다.
7. 가능하면 `npm run build`(Next 빌드)로 라우트 약속 이름이 살아 있는지 확인한다. 너무 오래 걸리면 생략하고 그 사실을 적는다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- knip 기준 어드민 밖 미사용 export·type이 0이거나, 남은 것마다 남긴 이유가 `summary`에 있다.
- 어드민 경로(`/admin/`) 파일은 바뀌지 않는다.
- 3번의 약속 이름 `export`가 하나도 떼어지지 않았다.
- 바뀐 내용은 `export` 키워드 제거, 이중 export 정리, 그 결과 안 쓰이게 된 선언 삭제뿐이다. 로직·값·문구는 바뀌지 않는다.
- `scripts/ui-rules-baseline.json`·`scripts/spacing-baseline.json`은 늘지 않는다.
- `scripts/verify.sh` 전체 통과.
