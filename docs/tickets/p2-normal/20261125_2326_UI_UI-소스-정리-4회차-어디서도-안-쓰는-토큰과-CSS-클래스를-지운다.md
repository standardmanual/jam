## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 4회차(미사용 제거 2). 토큰 사용 스캐너(`npm run audit:tokens`)가 **`unused`(실행 코드·시험·스토리 어디서도
  참조 없음)** 로 분류한 CSS 변수 정의 140건과, 화면 코드가 쓰지 않는 CSS 클래스 6개를 지운다.
- 사용자 승인: 2026-11-25 — 4회차 범위를 «A(unused 토큰 140건 + CSS 클래스 6개)만 삭제, B(시험·스토리 전용 34건)와 C(확인 필요 21건)는 9회차로 미룸»으로 확정(«추천대로 진행»).

## 구현 계획

1. 시작할 때 `cd jam-web && npm ci --ignore-scripts`(링크 상태면 어드민 시험이 실패한다).
2. **지우기 전 기준 CSS 만들기**: `npx @tailwindcss/cli -i src/app/globals.css -o /tmp/before.css`(CLI가 없으면 `next build` 산출 CSS나 postcss로 같은 결과를 만든다.
   방법을 `summary`에 적는다). `transitions.css`·`transitions-pages.css`가 globals.css에서 `@import`되지 않으면 그 파일들도 함께 컴파일한다.
3. 삭제 목록 A를 지운다. `design-system/foundations/Typography.stories.tsx`는 `--text-${step}`로 단계를 돌며 보여 주므로, 지운 `3xl`·`4xl`·`5xl` 단계를 목록에서 뺀다.
4. **지운 뒤 CSS를 같은 방법으로 만들어 비교**한다. 차이는 «지운 변수 선언 줄»과 «지운 클래스 규칙·keyframes»뿐이어야 한다. 그 밖의 차이(예: Tailwind 기본값이
   되살아나 `html` 글꼴 값이 바뀜)가 나오면 **그 원인이 된 토큰은 지우지 말고 되돌린 뒤** `summary`에 적는다. 특히 `@theme` 안의 `--font-sans`(Tailwind 기본 글꼴 이름과 같음)를 확인한다.
5. 삭제한 이름마다 `git grep`이 0건인지 확인하고, `npm run audit:tokens`에서 `unused`가 0(되돌린 것 제외), `used` 개수는 그대로(350)인지 확인한다.
6. `node scripts/check-ui-rules.mjs`, `node scripts/check-spacing.mjs`, `scripts/verify.sh` 전체 통과. 커밋 직후 `git status`로 빠진 변경이 없는지 확인한다.
   pre-commit 문서 검사에 막히면 우회하지 말고 스테이징한 채 `halted`로 돌아온다. push하지 않는다(사용자 push 금지 지시).
