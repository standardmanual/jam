# [UI] UI 소스 정리 6-2b회차: 카드·목록 정본 4개에 상태별 스토리를 쓴다

## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 6회차의 둘째 조각 중 하나. 사용자 승인(2026-11-26, «6-2 시작»).
  6-2a(20261126_1025, 의존 없는 12개)와 동시에 돈다. 이 티켓은 스토리가 없는 카드·목록 정본 4개를 맡는다.

| 컴포넌트 | 제목 | 호출 파일 | 비고 |
|---|---|---|---|
| BadgeGridCard | `UI/Cards/BadgeGridCard` | 12 | `BadgeGridCardPlaceholder`(빈 슬롯)도 같은 파일에서 export한다 |
| CollectionGridCard | `UI/Cards/CollectionGridCard` | 2 | |
| ListCard | `UI/Cards/ListCard` | 1 | |
| ListRow | `UI/Cards/ListRow` | 22 | `ListRowEm`·`ListRowChip` 부품도 같은 파일에서 export한다 |

- 화면 변화 없음: 새 스토리 파일과 기준선·목록 문서만 바뀐다. 정본 컴포넌트 파일은 주석·JSDoc까지 포함해 고치지 않는다.
- 사용자 승인: 상위 티켓의 승인 줄(2026-11-25)과 6-2 진행 승인(2026-11-26)에 해당한다.
- **규칙은 6-2a 티켓의 «6-2 공통 규칙» 절(1~9번)을 그대로 따른다.** 이 티켓에는 다른 점만 적는다.

## 구현 계획

바뀌는 파일은 6개(새 스토리 4, 기준선 1, 목록 문서 1)이고 줄 수는 약 700줄이다.

1. 4개마다 공통 규칙 2번대로 호출부를 찾아 상태 목록을 정하고 스토리 파일을 쓴다. 특유한 것:
   - **BadgeGridCard**: 배지 이미지·등급 칩·레벨·방문 수·잠김처럼 인벤토리·컬렉션·검색 화면에서 실제로 나오는 상태. 빈 슬롯(`BadgeGridCardPlaceholder`)은 같은 파일의 별도 스토리로 둔다.
     카드 면·칩 색은 지금 컴포넌트가 그리는 그대로 둔다(티켓 20261125_1649·1650에서 정리됨). 스토리에서 덮어쓰지 않는다.
     이미지는 `jam-web/public`의 실제 배지 자산 경로를 쓴다(원격 Supabase 주소 금지). `SafeImage`가 이미지 실패 때 그리는 대체 상태가 서비스에 나오면 그것도 한 스토리로 둔다.
   - **CollectionGridCard·ListCard**: 호출부가 적어 상태가 적다. 호출부에 있는 상태만 쓴다.
   - **ListRow**: 호출부가 22곳이라 조합이 많다. 같은 모양으로 그려지는 호출을 묶는다(앞 아이콘·썸네일 유무, 오른쪽 칩·값·화살표, 줄 수 제한, 링크 여부 등 생김새를 가르는 props 기준).
     스토리 수는 많아도 15개 안쪽으로 한다. 부품 `ListRowEm`·`ListRowChip`은 ListRow 스토리 안에서 쓰이는 모습으로 보인다(따로 스토리를 만들지 않는다).
2. 기준선에서 4개를 지우고 목록 문서를 다시 만든다. 6-2a와 기준선·목록 문서가 충돌하는 것은 괜찮다(카리나가 머지 때 다시 만든다).
3. 6-2a 공통 규칙 8번 확인(실제 설치본 verify, `build-storybook`, 새 스토리 렌더 확인).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 표의 4개에 스토리 파일이 있고 제목이 표와 같다. 각 스토리가 서비스 호출부에서 실제로 쓰이는 상태이며, 스토리마다 그 출처를 적은 JSDoc 한 줄이 있다.
- 정본 컴포넌트 파일과 다른 스토리 파일은 바뀌지 않았다(`git diff --name-only`가 새 스토리 4개·기준선·목록 문서뿐).
- 스토리 안에 hex·rgb 색, 원격 이미지 주소, 컴포넌트 생김새를 덮어쓰는 `className`이 없다. 문구는 서비스 문구다.
- 기준선에서 4개가 빠졌고 `node scripts/gen-component-list.mjs --check`가 통과한다.
- 실제 설치본에서 `scripts/verify.sh` 전체 통과, `build-storybook` 성공, 새 스토리 렌더 확인 오류 0건.
