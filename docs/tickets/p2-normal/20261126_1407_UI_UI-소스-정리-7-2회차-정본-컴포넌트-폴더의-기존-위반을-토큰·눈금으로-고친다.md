  7-3(화면 A)과 동시에 돈다 — 7-3 파일(배지·컬렉션·믹스·인벤토리·드랍·연출 오버레이·지도·캡슐·랭킹 화면)은 고치지 않는다.

## 7회차 공통 규칙

바꾸는 방법은 아래 순서로 고른다. 위에서 맞는 것이 있으면 아래로 내려가지 않는다.

1. **표기만 다른 토큰 참조** → 같은 토큰의 유틸리티 클래스. `text-[color:var(--link)]` → `text-link`, `border-[color:var(--border)]` → `border-border`,
   `bg-[color:var(--snow)]` → `bg-snow`, `text-[color:var(--muted-on-inverse)]` → `text-muted-on-inverse`, `outline-[color:var(--link)]` → `outline-link`.
   `@theme inline`에 연결이 없는 토큰(예: `--base-black`)은 `bg-[var(--base-black)]`처럼 var 하나로 쓴다. 화면은 그대로다.
2. **값이 정확히 같은 토큰** → 그 토큰. 인라인 style은 var로(`fontWeight: 700` → `'var(--font-weight-bold)'`, 600 → `--font-weight-semibold`, 500 → `--font-weight-medium`,
   400 → `--font-weight-normal`, `lineHeight: 1.25` → `'var(--leading-tight)'`, `lineHeight: '1.6'` → `'var(--leading-loose)'`, `fontSize: 20` → `'var(--text-xl)'`),
   클래스는 토큰 클래스로(`text-[12px]` → `text-xs`, `text-[14px]` → `text-sm`, `text-[36px]` → `text-4xl`). `lineHeight: 1`은 var 토큰이 없으므로 그 요소의 클래스 `leading-none`으로 옮긴다.
   `text-[Npx]`는 글자 크기만 정하지만 `text-*` 토큰 클래스는 줄 높이도 정한다. 같은 요소에 행간 클래스가 없으면 줄 높이가 바뀔 수 있으니 «화면이 바뀌는 곳 목록»에 적는다.
   원형 `borderRadius: '50%'`는 정사각형 요소면 `'var(--radius-full)'`로 바꾼다(정사각형이 아니면 목록에 적는다).
3. **새 치수 토큰 18개** → var 하나로 쓴다. 예: `max-w-[var(--app-max-width)]`, `z-[var(--z-toast)]`, `h-[var(--tabbar-height)]`(기존 토큰), `pb-[var(--spacing-safe-bottom)]`(기존 토큰).
   토큰과 `100%`·`100dvh`·숫자·연산자만 섞인 계산식은 그대로 쓸 수 있다(7-1): `w-[calc(100%+var(--grid-thumb-bleed))]`.
4. **한 곳만 쓰는 치수 9개** → 가까운 4px 눈금 클래스. 26px 로고 → `h-6`(24px), 개수 칩 18px → `min-w-4 h-4`(16px), 이름 두 줄 최소 높이 30px → `min-h-7`(28px),
   공유 말풍선 폭 220px → `w-55`(같음), 정지 안내 항목 폭 39px → `w-10`(40px), 오늘 상태 띠 92px → `min-h-23`(같음), 온보딩 입력칸 70% → `w-7/10`(같음),
   사진 지우기 단추 22px → `size-5`(20px), 잠긴 배지 열림 시작 크기 0.96 → `scale-95`(0.95).
5. **토큰이 없는 시각 값** → 가까운 눈금. 두 눈금의 정가운데면 **작은 쪽**.
   - 글자 크기: 12·14·16·18·20·24·30·36px(`text-xs`~`text-4xl`) 중 가장 가까운 값. 15→14, 22→20, 13→12, 11→12.
   - 행간: 원래 줄 높이(px)에 가장 가까운 4px 눈금(`leading-4`=16px, `leading-5`=20px, `leading-6`=24px, `leading-7`=28px …). 원래 값이 비율 토큰(`--leading-tight` 1.25,
     `--leading-loose` 1.6)과 같으면 그 토큰. 글자 크기를 함께 바꾸는 경우 원래 줄 높이(px)를 기준으로 고른다.
   - 자간 −0.02em → `tracking-tight`(−0.025em). 회색 → 가장 가까운 `--base-neutral-*`. 흰색 반투명 → `color-mix(in srgb, var(--snow) N%, transparent)`(N은 가장 가까운 10% 단위).
   - 움직임 시간 → 가장 가까운 `--duration-*`(240ms → `--duration-fast` 250ms).
6. **리셋 키워드**(테두리 none, 배경 transparent·none, inherit, normal): Tailwind 기본 리셋(preflight: `<button>`·`<input>`의 배경 투명, 모든 요소 테두리 0)과 겹치면 지운다.
   같은 요소의 className에 배경·테두리 클래스가 있어 인라인 값이 그것을 덮고 있었다면 지우지 말고 그 클래스를 정리한다. 겹치지 않으면 유틸리티 클래스로 옮긴다
   (`bg-transparent`, `border-0`, `text-inherit`, `tracking-normal`). `borderRadius: 'inherit'`는 부모가 쓰는 반경 토큰을 그대로 쓴다.
7. **정본을 쓰지 않은 버튼·입력칸** → 가장 가까운 정본(`Button`의 variant·size, `IconButton` 등)으로 바꾼다. 채원①이 고른다. 맞는 정본이 없으면 새 정본·새 variant를 만들지 말고
   승인 필요로 멈춘다. 화면에 보이지 않는 파일 선택 입력(`<input type="file" className="hidden">`)은 `ui-allow: 화면에 보이지 않는 파일 선택 창 열기용`을 단다.
8. **외부가 정한 값**에는 같은 줄에 `ui-allow: <사유>`를 단다: 구글 로고 공식 4색, 구글 지도 내 위치 파란 점, 마스크 알파용 검정, `@supports` 기능 검사 문구.
9. **간격**(`spacing`): 32px 이상 단계는 2026-11-08 역할 눈금(화면 틀 좌우 16·위 16·아래 24, 구획 20, 목록 카드 사이 8, 상세 이어진 카드 12, 카드 안 16, 폼 간격 16)에 맞추고,
   역할을 정할 수 없으면 24px 이하에서 가장 가까운 눈금. 임의 px 간격은 가장 가까운 4px 눈금(정가운데면 작은 쪽). 버튼 여백은 13→12, 9→8, 17→16, 15→16, 23→24px.
10. **기준선 파일(`scripts/ui-rules-baseline.json`·`spacing-baseline.json`)은 고치지 않는다**(카리나가 머지 때 다시 쓴다). 조각을 마치면
    `node scripts/check-ui-rules.mjs --json`과 `node scripts/check-spacing.mjs`에서 이 조각 파일의 위반이 0인지 확인해 `summary`에 적는다.
11. 시험이 옛 클래스 문자열·값을 확인하면 새 값으로 고친다. 시험을 지우지 않는다.
12. `summary`에 **«화면이 바뀌는 곳 목록»**(파일·줄, 전 값 → 후 값, 어떤 화면의 무엇인지)을 적는다. 1·2·3번처럼 화면이 그대로인 교체는 목록에 넣지 않는다.
    카리나가 이 목록과 캡처 차이를 대조한다.
13. 확인: 아현은 바꾼 파일의 시험(임시 vitest 설정으로 해당 파일만)과 `node scripts/check-ui-rules.mjs`·`check-spacing.mjs`·`check-token-refs.mjs`, `npm run typecheck`·`npm run lint`만 돌린다.
    `bash scripts/verify.sh` 전체와 `build-storybook`은 두 조각이 동시에 돌 때 서로 시간 초과를 내므로(티켓 20261126_1154) 카리나가 머지 전에 실제 설치본에서 하나씩 돌린다.
14. 리뷰 브랜치는 로컬에만 커밋하고 **push하지 않는다**(사용자 지시: 요청 전 push 금지). push 시도는 자동 모드에 거부된다.
