## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 7회차의 세 번째 조각(화면 A). 사용자 승인(2026-11-26, «이대로 시작»)과 사용자 결정 1~3은 상위 티켓 «7회차 사용자 결정»에 있다.

- **바꾸는 방법은 7-2 티켓(20261126_1407)의 «7회차 공통 규칙» 1~14번을 그대로 따른다.** 이 티켓에는 파일별 대상과 다른 점만 적는다.
- 범위: 배지 목록·배지 상세(공유·티켓·획득 이력)·컬렉션 상세·믹스(레시피·등급 올리기)·인벤토리·드랍 화면과, 그 화면이 쓰는 도메인 컴포넌트(배지 머리 영역·배지 공개 연출·

- **화면이 바뀐다**(사용자 결정 2·3). 예: 배지 획득·방문 이력 제목 15→14px, 컬렉션 상세 제목 22→20px, 등급 상승 연출 배경 회색, 정본을 쓰지 않던 버튼 4곳(공유 동그라미·슬롯 알약·

- 로딩: SlotActionPill의 pending(라벨 대신 «…», 비활성)과 CapsuleWidget 로딩(스켈레톤, 건드리지 않음)은 지금 동작을 그대로 유지한다. Button 교체 후에도 pending은 disabled+«…»로 같아야 한다.
- 빈: 이 조각에서 새로 만드는 빈 화면은 없다. 기존 빈 상태(인벤토리 빈 격자, 믹스 빈 칸)는 건드리지 않는다.
- 오류: CapsuleWidget load==='error' 시 다시 시도 버튼(Button secondary), 다시 시도 중 눌림 효과가 나오는지 확인한다.
- 기본: Button xs 알약 두 톤(accent, neutral), 접기/펼치기 글자 버튼의 aria-expanded true/false 두 상태.
- 비활성: SlotActionPill disabled·pending 시 Button의 opacity-40이 적용된다. 지금 disabled:opacity-40과 같다.
- 선택: BadgesClient 탭의 aria-selected=true일 때 글자색 상속(text-inherit)을 유지한다.
- 열림/닫힘: LockedItemDetail 접힘 영역 .jam-collapse의 닫힘(0fr)·열림(1fr) 두 상태가 화면 같게 전환되는지 확인한다.
- 만료 임박 칩(InventoryGrid, ItemCandidateRow): 승인 전까지 지금 모양 유지.

### 모션

- 정본 Button 교체로 누름 효과가 붙는다. 정본은 transition-transform duration-100과 active:scale-95다. SlotActionPill은 지금 transition-all이라 누름 반응이 없었고, 이는 사용자 결정 2로 승인된 변화다.
- LockedItemDetail: 크로스페이드와 접힘 시간·곡선은 지금 토큰 그대로 클래스로만 옮긴다. 화면 움직임은 변하지 않는다. 열림 시작 크기만 0.96에서 0.95로 달라진다(눈에 거의 안 보인다).
- CapsuleGauge 240ms에서 250ms(--duration-fast)로 10ms 느려진다.
- prefers-reduced-motion을 쓰는 곳이 있으면 .jam-crossfade·.jam-collapse에서도 같은 처리를 유지한다.

### 기기 주의

- Button xs는 44px 터치 규칙의 명시적 예외다(약 31px). SlotActionPill은 컬렉션 칸 아래라 세로 공간이 좁아 xs를 골랐다. 터치 영역이 부족하면 칸 카드 전체 탭 영역과 겹치지 않도록 확인하고, 작은 화면(360px 폭)에서 칸 3~4열 아래 알약 두 개가 가로로 겹치지 않는지 본다.
- «더 보기/접기»는 원래 min-h-11(44px)이었다. xs로 바꾸면 31px가 되므로 터치 영역이 줄어든다. 줄지 않게 하려면 size="sm"(44px)이 대안이지만 글자가 16px가 되어 본문(14px)보다 커진다. 12px 유지가 맞다고 판단하되, 터치 영역이 중요하면 사용자가 정하게 한다. 이 선택은 승인 항목 4번에 포함한다.
- DropsClient 337행은 안전영역 값을 토큰(--spacing-safe-top)으로 바꾸는 것이라 노치 기기에서 위치가 같아야 한다.
- 공유 시트·말풍선은 작은 화면에서 w-55(220px)가 좌우를 넘지 않는지 확인한다.
- 지도 «내 위치» 버튼(44px)과 탭 바 사이 간격은 건드리지 않는다.

### 만듦새

- 정리 작업이므로 장식을 더하지 않는다. 그라디언트·유리질·그림자를 새로 넣지 않는다.
- TierUpRevealOverlay 무대 배경은 #343434에서 var(--base-neutral-700)(#404040)로 약 12 단계 밝아진다. 상단~하단 그라데이션이 의도한 연출이라 새로 만드는 그라디언트는 아니다. 값만 바꾸고 방향·단계는 그대로 둔다.
- 배경에 호버·누름 효과가 이미 쓰이던 곳(.jam-press)이 Button으로 바뀌면 누름 효과가 이중으로 걸리지 않게 한다(CapsuleWidget 101행의 jam-press).
- text-sm 같은 text-* 토큰 클래스는 줄 높이도 정한다. 15px에서 14px로 바꾸는 제목은 줄 높이가 바뀌는지 확인하고 «화면이 바뀌는 곳 목록»에 적는다.
- 가운데 정렬은 SlotActionPill의 mx-auto 한 곳뿐이고 그대로 둔다. 새 가운데 정렬을 추가하지 않는다.
- 접힘 글자 버튼의 밑줄이 사라진다. 링크처럼 보이던 단서가 약해지므로 --link 색으로 구분되는지 캡처에서 확인한다.
