# [UI] UI 소스 정리 7-3회차: 배지·컬렉션·믹스·인벤토리·드랍 화면의 기존 위반을 토큰·눈금·정본으로 고친다

## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 7회차의 세 번째 조각(화면 A). 사용자 승인(2026-11-26, «이대로 시작»)과 사용자 결정 1~3은 상위 티켓 «7회차 사용자 결정»에 있다.
  7-1(20261126_1310, 머지 `6ea2d6fa2`)이 검사기 주석 오탐을 없애고 새 치수 토큰 18개를 정의했다.
- **바꾸는 방법은 7-2 티켓(20261126_1407)의 «7회차 공통 규칙» 1~14번을 그대로 따른다.** 이 티켓에는 파일별 대상과 다른 점만 적는다.
- 범위: 배지 목록·배지 상세(공유·티켓·획득 이력)·컬렉션 상세·믹스(레시피·등급 올리기)·인벤토리·드랍 화면과, 그 화면이 쓰는 도메인 컴포넌트(배지 머리 영역·배지 공개 연출·
  등급 상승 연출·대기 배지 고르기·캡슐·지도·랭킹 줄). 7-2(정본 폴더 `jam-web/src/components/ui/`)와 동시에 돈다 — **정본 폴더 파일은 고치지 않는다.**
- **화면이 바뀐다**(사용자 결정 2·3). 예: 배지 획득·방문 이력 제목 15→14px, 컬렉션 상세 제목 22→20px, 등급 상승 연출 배경 회색, 정본을 쓰지 않던 버튼 4곳(공유 동그라미·슬롯 알약·
  펼치기 글자 버튼·캡슐 다시 시도)과 지도 «내 위치» 버튼, 잠긴 배지 상세 아래 여백 32px. 화면 캡처 비교는 카리나가 머지 전에 하고 사용자 승인을 받는다.
