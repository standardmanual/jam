# [UI] UI 소스 정리 7-4회차: 미션·홈피드·프로필·온보딩·로그인·약관 화면의 기존 위반을 토큰·눈금·정본으로 고친다

## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 7회차의 마지막 조각(화면 B). 사용자 승인(2026-11-26, «이대로 시작»)과 사용자 결정 1~3은 상위 티켓 «7회차 사용자 결정»에 있다.
  7-1·7-2·7-3(20261126_1310·1407·1408, 머지 `6ea2d6fa2`·`b0e1b7fb5`·`04d6b94a7`)이 끝난 뒤의 staging에서 시작한다.
- 7-3에서 넘어온 것과 사용자 결정(2026-11-26, 상위 티켓 «7-3 채원① 승인 항목 결정»·승인 줄): ① 배지 공유 시트의 «동그라미 아이콘 + 아래 글자» 버튼 → **정본을 새로 만든다**
  ② 지도 «내 위치» 버튼 → **정본 `IconButton`에 «내 위치» 아이콘을 더한 뒤** 그것으로 바꾼다 ③ 밑줄 글자 버튼(프로필 편집 «탈퇴») → 7-3 «더 보기»와 같이 `Button` ghost xs + 누르는 높이 44px.
  새 정본·새 아이콘은 사용자 승인이 끝났으므로 채원①은 이 둘을 승인 필요로 올리지 않는다(모양·이름·스토리 상태는 채원①이 정한다).
- **바꾸는 방법은 7-2 티켓(20261126_1407)의 «7회차 공통 규칙» 1~14번을 그대로 따른다.** 이 티켓에는 파일별 대상과 다른 점만 적는다.
- 이 조각이 끝나면 서비스 화면 소스의 `ui-rules`·`spacing` 위반이 모두 0이 된다(`ui-allow`·`spacing-allow` 사유가 붙은 줄 제외). 기준선 파일 비우기는 머지 때 카리나가 한다.
- **화면이 바뀐다**(사용자 결정 2·3). 큰 변화: 약관 3개 화면의 위아래 여백 64→16·24px와 구획 간격 48·32→20px, 로그인 로고 아래 간격 96→24px, 온보딩 위아래 48px→16·24px,
  미션 상세의 글자 크기·행간(15→14px 등), 홈피드 큰 제목 자간·행간, 프로필 편집·온보딩의 사진 고르기 버튼, VOC 페이지 번호 버튼, 프로필 탭, 로그인 구글 버튼.
  화면 캡처 비교는 카리나가 머지 전에 하고 사용자 승인을 받는다.
