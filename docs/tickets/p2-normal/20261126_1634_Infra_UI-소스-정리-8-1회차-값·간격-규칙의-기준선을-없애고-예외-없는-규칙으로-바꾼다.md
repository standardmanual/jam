# [Infra] UI 소스 정리 8-1회차: 값·간격 규칙의 기준선을 없애고 예외 없는 규칙으로 바꾼다

## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 8회차(관문 2차)의 첫 조각. 사용자 결정 2(2026-11-25: 기준선은 0이 되면 지우고 규칙을 예외 없는 규칙으로 바꾼다)와 7회차 완료(두 기준선 `{}`)에 따른다.
  사용자 승인: 상위 티켓의 승인 줄(2026-11-25·2026-11-26).
- 하는 일: `scripts/check-ui-rules.mjs`·`scripts/check-spacing.mjs`에서 기준선 개념을 없애 **위반이 하나라도 있으면 실패**하게 한다. 줄 단위 예외(`ui-allow: <사유>`·`spacing-allow: <사유>`)는 그대로 둔다.
  7회차에서 발견한 빈틈(계산식 허용 규칙이 단위 없는 숫자만 감싼 `scale-[calc(0.96)]`도 통과시킴)을 막는다.
- **화면 변화 없음**: 검사기·시험·문서만 바뀐다.
- 8-3(20261126_1635, 정본 닫힌 목록·버튼 여백)과 동시에 돈다. 정본 폴더 `jam-web/src/components/ui/`와 화면 파일은 고치지 않는다.

## 구현 계획

바뀌는 파일은 약 9개, 줄 수는 약 250줄이다.

1. `scripts/check-ui-rules.mjs`: `--write-baseline`·`--baseline` 인자, 기준선 읽기·비교·«기준선을 줄이세요» 안내(250~303행 부근)를 지운다. 대상 전체·`--files`·`--stdin-file` 모두 위반이 있으면 파일·줄·규칙과
   `FIXES` 안내를 내고 종료 코드 1, 없으면 «통과». 머리 주석 16~22행의 기준선 설명을 «위반은 예외 없이 실패한다. 줄 단위 예외는 `ui-allow: <사유>`»로 고친다.
2. 계산식 빈틈: `isTokenOnly`의 계산식 분기는 **`var(--…)`가 적어도 하나 있을 때만** 토큰 조합으로 본다(`calc(0.96)`·`calc(100%)`처럼 토큰 없는 식은 위반). 시험에 두 사례를 더한다.
3. `scripts/check-spacing.mjs`: 같은 방식으로 기준선(122~145행 부근)과 `--write-baseline`을 없앤다. 머리 주석 11~15행을 고친다.
4. `git rm scripts/ui-rules-baseline.json scripts/spacing-baseline.json`.
5. 시험: `check-ui-rules.test.mjs`(132행 부근 기준선 사례)·`check-spacing.test.mjs`(111행 부근)·`ui-guard.test.mjs`(23행: 임시 저장소에 기준선 파일을 쓰는 줄)를 새 동작에 맞춘다. «위반 1건이면 종료 코드 1», «`ui-allow` 사유가 있으면 통과», «사유가 비면 위반» 사례를 둔다.
6. `scripts/verify.sh` 134·142행 주석, `docs/agents/contract.json` 99행(기준선 파일 경로)을 고친다. 다른 문서가 기준선 파일을 가리키면 함께 고친다(`git grep -n "baseline.json"`으로 다시 확인).
7. 확인: 두 검사기 «통과»(지금 staging에 위반 0건), 새 시험 통과, `node scripts/check-contract.mjs` 통과. verify 전체는 카리나가 실제 설치본에서 돌린다. 로컬 커밋만 하고 push하지 않는다.
