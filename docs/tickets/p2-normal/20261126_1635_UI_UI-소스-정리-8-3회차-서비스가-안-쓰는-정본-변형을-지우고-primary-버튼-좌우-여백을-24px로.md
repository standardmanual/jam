# [UI] UI 소스 정리 8-3회차: 서비스가 쓰지 않는 정본 변형을 지우고 primary 버튼 좌우 여백을 24px로 맞춘다

## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 8회차. 사용자 결정(2026-11-26, 상위 티켓 «8회차·후속 티켓 사용자 결정»·승인 줄): ① 정본 `Button` primary 좌우 여백 32px → 24px
  ② 서비스가 쓰지 않는 정본 변형을 지워 «닫힌 목록»으로 만든다. 8-1(20261126_1634)과 동시에 돈다 — `scripts/`는 고치지 않는다.
- **화면이 바뀐다**: primary 버튼(검정 알약)이 좌우 8px씩 좁아진다. 변형 삭제는 서비스가 쓰지 않는 것만이라 화면 변화가 없어야 한다.
- 바꾸는 방법은 7-2 티켓(20261126_1407) «7회차 공통 규칙»을 따른다(특히 11·13·14번: 시험은 새 값으로, verify 전체는 카리나, push하지 않음).

## 구현 계획

1. `jam-web/src/components/ui/Button.tsx` 89행 primary `px-8` → `px-6`, 같은 줄 `spacing-allow` 주석을 지운다. 관련 시험(`__tests__/buttonVariantPairs.test.tsx` 등)의 기대값을 고친다.
2. 서비스 미사용 변형 삭제(6회차에 스토리에서 지운 것). **지우기 전에 변형마다 서비스 코드(`jam-web/src/app`·`jam-web/src/components`, 시험·스토리 제외)에서 쓰는 곳이 0인지 grep으로 확인하고 결과를 `summary`에 적는다.** 쓰는 곳이 있으면 지우지 않고 보고한다.
   - `ProgressBar`: outlined, track-gradient, fraction, percent 표시
   - `Input`: password 형식
   - `Select`: 오류·성공·비활성 상태
   - `BadgeLevelChip`·`RarityBadge`: 서비스가 넘기지 않는 크기(sm 등 — 호출부 grep으로 실제 쓰는 크기만 남긴다)
   props 타입·분기·스타일 맵에서 지우고, 그 변형만 확인하던 시험을 지우거나(시험 삭제는 커밋 메시지에 `테스트 삭제: <사유>`) 남은 변형 기준으로 고친다. 스토리·`@summary`가 지운 변형을 말하면 고친다.
3. `node scripts/gen-component-list.mjs`로 목록 문서를 다시 만든다(설명이 바뀐 경우).
4. 확인: 바꾼 파일 시험·`npm run typecheck`·`npm run lint`·`check-ui-rules`·`check-spacing`·`check-token-refs`·`gen-component-list --check`. `summary`에 «화면이 바뀌는 곳 목록». 로컬 커밋만, push하지 않는다.

## 완료 조건

- primary 버튼 좌우 여백이 24px이고 `Button.tsx`에 `spacing-allow`가 없다.
- 지운 변형마다 서비스 사용처 0을 확인한 기록이 `summary`에 있다.
