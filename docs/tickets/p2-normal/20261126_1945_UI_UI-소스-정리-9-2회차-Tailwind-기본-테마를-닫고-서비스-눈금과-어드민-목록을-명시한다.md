# [UI] UI 소스 정리 9-2회차: Tailwind 기본 테마를 닫고 서비스 눈금과 어드민 목록을 명시한다

## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 9회차 두 번째 조각. 사용자 결정(2026-11-26, 상위 티켓 «9회차 사용자 결정» ④와 승인 줄): Tailwind 기본 테마를 닫고, 서비스 눈금은 지금 렌더 값 그대로 JAM 테마로 다시 정의하며, 어드민이 쓰는 기본값은 어드민 층 목록으로 명시한다.
- **화면 변화 없음**: 컴파일된 유틸리티 규칙과 실제로 적용되는 변수 값이 전후 같아야 한다. 목록에 없는 기본값(예: 쓰지 않는 `text-6xl`, `bg-lime-500`)은 아예 만들어지지 않게 된다.
- 측정(9-1 머지 뒤, 상위 티켓 «9회차 준비»): 컴파일 결과 theme 층이 내보내는 변수 167개. 기본 팔레트 색은 어드민만 쓴다(925건·159파일, 서비스 0건). 반응형 접두사 `md:` 178·`sm:` 68·`lg:` 32·`xl:` 12, 컨테이너 쿼리 `@sm:` 8·`@lg:` 4·`@md:` 1.
- 바꾸는 방법은 7-2 티켓(20261126_1407) «7회차 공통 규칙»을 따른다(verify 전체는 카리나, push하지 않음).

## 지켜야 할 값 (숨은 덮어쓰기 — 지금 화면은 JAM 값으로 그려진다)

| 이름 | Tailwind 기본 | 지금 실제 적용 값(JAM `:root`가 이김) | 유지할 값 |
|---|---|---|---|
| `--leading-loose` | 2 | 1.6 (`primitive.css`) | 1.6 |
| `--ease-out` | `cubic-bezier(0, 0, 0.2, 1)` | CSS 키워드 `ease-out` (`primitive.css`) | `ease-out` |
| `--ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | CSS 키워드 `ease-in-out` (`primitive.css`) | `ease-in-out` |

- `--text-*`·`--radius-*`는 JAM 값과 Tailwind 기본값이 같다. 어드민은 `[data-admin-theme]` 안에서 `--radius-*`를 자기 값으로 덮는다(그대로 둔다).
- **JAM 간격 기본값 `--spacing-4`~`--spacing-96`을 `@theme`에 넣지 않는다.** Tailwind의 `--spacing-*` 이름 공간이라 `@theme`에 들어가면 `p-4`가 4px이 되어 화면이 깨진다. `--text-swap-*` 같은 컴포넌트 토큰도 `@theme`에 넣지 않는다.

## 구현 계획

1. `jam-web/src/app/globals.css`에서 Tailwind 기본 테마를 닫는다(`@theme { --*: initial; }` 또는 같은 효과). 닫은 뒤 다시 정의하는 값은 아래 두 묶음뿐이다.
2. **서비스 눈금(JAM 테마)**: 지금 컴파일 결과의 theme 층 변수 중 서비스·정본·DS가 쓰는 이름 공간을 지금 실제 적용 값 그대로 정의한다.
   간격 배수 `--spacing`, 글자 크기 `--text-xs`~`--text-5xl`과 줄 높이, 굵기 `--font-weight-*`, 자간 `--tracking-*`, 줄 간격 `--leading-*`(위 표의 1.6 포함), 모서리 `--radius-*`, 곡선 `--ease-*`(위 표의 키워드 포함),
   애니메이션 `--animate-spin`·`--animate-pulse`와 그 `@keyframes`, `--aspect-video`, `--container-*`, `--drop-shadow-xs`, `--default-transition-*`, `--default-font-family`·`--default-mono-font-family`, `--font-sans`·`--font-mono`, 반응형 `--breakpoint-*`(sm·md·lg·xl·2xl 등 쓰는 것), 컨테이너 쿼리 크기.
   같은 이름을 `@theme`와 토큰 파일 `:root`에 두 번 정의하지 않는다. 값의 원천이 `primitive.css`에 있으면 `@theme`는 그 값을 쓰거나 원천을 옮기되, 결과 값은 같아야 한다. 어느 방식으로 했는지 `summary`에 적는다.
3. **어드민 층 목록**: 어드민만 쓰는 기본값(기본 팔레트 색 약 100개, `--color-white`·`--color-black`, 그림자 등)을 새 파일(예: `jam-web/src/app/admin-theme.css`)에 지금 값 그대로 `@theme`로 명시하고 globals.css에서 불러온다.
   파일 머리 주석에 «어드민 전용. 서비스 화면에서 쓰면 9-4 검사기가 막는다(티켓 20261126_1945)»를 적는다. 어드민 화면 코드는 고치지 않는다.
4. `@theme inline`의 JAM 색 매핑(`--color-background` 등)과 `[data-admin-theme]`·`.dark` 블록은 그대로 둔다.
5. 확인(아현): 전후로 globals.css를 컴파일해 비교한다(커밋하지 않는 임시 스크립트, `postcss`+`@tailwindcss/postcss`).
   ① theme 층 밖의 규칙(유틸리티·base·components)이 전후 같다(순서만 다른 것은 같다고 본다).
   ② 브라우저 적용 순서대로 계산한 변수 값(theme 층 값에 토큰 파일 `:root`가 덮인 결과)이 전후 같다.
   ③ 닫힌 뒤 theme 층이 내보내는 변수 목록이 위 2·3번 묶음에 있는 것뿐이다. 결과(다른 규칙 수, 다른 변수 목록)를 `summary`에 적는다.
6. 바꾼 파일 시험·`npm run typecheck`·`npm run lint`·`check-ui-rules`·`check-spacing`·`check-token-refs`·`gen-component-list --check`. 로컬 커밋만 하고 push하지 않는다.
