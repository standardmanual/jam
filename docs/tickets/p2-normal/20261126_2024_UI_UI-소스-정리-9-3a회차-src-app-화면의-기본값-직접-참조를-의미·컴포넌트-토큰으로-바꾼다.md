## 기본값을 쓸 수 있는 곳과 없는 곳 (9-4 검사기가 이 경계로 막는다)

- 쓸 수 있다: 토큰 파일(`jam-web/design-system/tokens/*.css`), `jam-web/src/app/jam-theme.css`·`admin-theme.css`·`globals.css`, 정본 폴더 `jam-web/src/components/ui/`, 움직임 모음 `jam-web/src/components/transitions.css`, 스토리북 토큰 소개(`design-system/foundations`).
- 쓸 수 없다: 그 밖의 화면·도메인 코드(`src/app/(main)`·`(auth)`·`(onboarding)`·`(legal)`, `src/components/**`에서 정본 폴더 제외). 여기서는 의미·컴포넌트 토큰과 서비스 눈금 클래스만 쓴다.
- 기본값 이름: `--base-*`, `--jam-*`, `--spacing-N`(숫자), `--duration-*`, `--ease-*`, `--scale-*`, `--radius-*`, `--text-xs`~`--text-5xl`과 그 `--line-height`, `--leading-*`, `--font-weight-*`, `--tracking-*`, `--font-family-base`.
  `--text-swap-*`·`--tabbar-label-size` 같은 컴포넌트 토큰과 `--spacing-safe-*`·`--page-x` 같은 의미 토큰은 기본값이 아니다.

## 9-3 공통 규칙 (9-3b도 그대로 따른다)

바꾸는 방법은 아래 순서로 고른다. 위에서 맞는 것이 있으면 아래로 내려가지 않는다. 기본값 참조가 아닌 다른 값(리터럴 px 등)은 이번에 고치지 않는다.

1. **고정 값이고 요소가 `className`을 받으면 서비스 눈금 클래스**로 옮긴다.
   - 글자 크기+행간 쌍(`fontSize: 'var(--text-sm)'`+`lineHeight: 'var(--text-sm--line-height)'`) → `text-sm`.
   - 글자 크기만 있던 곳 → `text-sm/normal`(행간 1.5, 지금 상속받는 값과 같다). 같은 요소에 행간 클래스(`leading-5` 등)가 이미 있으면 `text-sm`만 쓴다. 부모가 행간을 따로 정하고 있으면 그 값에 맞는 행간 클래스를 붙인다.
   - 행간만 → 같은 값의 클래스: `var(--text-xs--line-height)`(12px 글자) → `leading-4`, `leading-[var(--leading-loose)]` → `leading-loose`, `leading-[var(--leading-reading)]` → `leading-reading`.
   - 모서리 → `rounded-*`(`'0 0 var(--radius-2xl) var(--radius-2xl)'` → `rounded-b-2xl`, `var(--radius-full)` → `rounded-full`).
   - 간격·위치 → 4px 단계 클래스(`--spacing-4` = 1, 8 = 2, 12 = 3, 16 = 4, 24 = 6): `gap-2`, `p-6`, `left-4` 등.
   - 인라인 style이 클래스보다 앞서므로, 같은 속성을 인라인과 클래스 양쪽에 남기지 않는다. 인라인 값이 같은 요소의 클래스를 덮고 있었다면 결과가 지금과 같도록 그 클래스를 정리한다.
2. **변수가 꼭 필요한 곳**(calc·max 식, CSS 모듈, HTML 문자열, 컴포넌트 속성으로 넘기는 값)은 값이 같은 기존 의미 토큰 중 역할이 맞는 것을 쓴다.
   16px → `--page-x`(좌우)·`--page-top`(위)·`--card-padding`(카드·시트 안), 24px → `--page-bottom`(아래)·`--gap-section-lg`, 12px → `--gap-group`, 8px → `--gap-text`·`--gap-actions`, 4px → `--gap-label`.
3. **승인된 새 토큰**은 이 티켓에 적힌 곳에만 쓴다. 목록에 없는 새 토큰·새 컴포넌트·새 variant가 필요하면 만들지 말고 멈춰 보고한다.
4. 상속값과 같은 지정(예: `fontFamily: 'var(--font-family-base)'` — body가 이미 같은 글꼴)은 지운다.
5. 시험이 옛 문자열(`var(--jam-red)` 등)을 확인하면 새 값으로 고친다. 시험을 지우지 않는다.
6. `summary`에 **«화면이 바뀌는 곳 목록»**(파일·줄, 전 값 → 후 값, 어느 화면의 무엇인지)을 적는다. 값이 같은 교체는 넣지 않는다. 카리나가 스토리북·화면 전후 캡처와 대조한다.
7. 확인(아현): 바꾼 파일의 시험(임시 vitest 설정으로 해당 파일만), `node scripts/check-ui-rules.mjs`·`check-spacing.mjs`·`check-token-refs.mjs`, `npm run typecheck`·`npm run lint`, 정본을 고쳤으면 `node scripts/gen-component-list.mjs --check`.
   그리고 이 티켓 「관련 파일」에서 기본값 참조가 0인지 아래 명령으로 확인해 결과를 `summary`에 적는다(주석 안 언급은 남아도 된다).
   `grep -nE "var\(--(base-|jam-|spacing-[0-9]|duration-|ease-|scale-|radius-|text-(xs|sm|base|lg|xl|[2-5]xl)|leading-|font-weight-|tracking-|font-family-)" <파일들>`
   `bash scripts/verify.sh` 전체와 `build-storybook`은 두 조각이 동시에 돌 때 서로 시간 초과를 내므로 카리나가 머지 전에 실제 설치본에서 돈다.
8. 리뷰 브랜치는 카리나가 로컬에 미리 만들어 두었다(아래 «작업 방법»). **push하지 않는다**(사용자 지시: 요청 전 push 금지, 시도하면 자동 모드에 거부된다).

## 새 토큰 (사용자 승인 2026-11-26)

`jam-web/design-system/tokens/component.css`의 첫 블록(`:root, [data-service-theme]`) 맨 끝, `--status-card-bg` 줄 바로 뒤에 한 묶음으로 더한다(9-3b는 다른 자리에 더하므로 겹치지 않는다).

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--mission-accent` | `var(--jam-red)` | 미션 화면의 빨강: 상세의 완료 면·보상 줄 면·진행 글자·진행 바, 상황 화면 바탕·순위 진행 바, 순위 줄의 «나» 원 |
| `--login-background` | `var(--base-black)` | 로그인 화면 바탕(2곳) |
| `--ticket-ink` | `var(--base-neutral-900)` | 배지 티켓 카드 안 글자색(지금 #171717) |
| `--ticket-paper` | `var(--base-white)` | 배지 티켓 카드 면에 티켓색을 섞는 흰 바탕 |

- `jam-web/src/app/jam-theme.css` `@theme`의 줄 간격 묶음에 `--leading-reading: 1.75;`를 `--leading-loose` 뒤에 더한다(값은 `primitive.css`와 같다, `jam-theme.test.ts`가 대조하면 기대값도 맞춘다). `leading-reading` 클래스가 생긴다.
- 정본 `Skeleton`(`jam-web/src/components/ui/Skeleton.tsx`): `borderRadius?: string`을 지우고 `radius?: 'lg' | '2xl' | 'full'`(기본 `'lg'`)을 둔다. 값은 정본 안에서 `var(--radius-lg)`·`var(--radius-2xl)`·`var(--radius-full)`로 칠한다.
  JSDoc의 `'50%'`·자유 문자열 안내를 걷는다. 스토리(`Skeleton.stories.tsx`)에 서비스가 쓰는 `2xl`(합성 결과 칸·프로필 카드)·`full`(캡슐 게이지) 상태를 더한다. 어드민은 다른 Skeleton(`components/admin/ui`)을 쓰므로 바꾸지 않는다.

## 배지 티켓 변수의 자리 (사용자 결정 2026-11-26)
