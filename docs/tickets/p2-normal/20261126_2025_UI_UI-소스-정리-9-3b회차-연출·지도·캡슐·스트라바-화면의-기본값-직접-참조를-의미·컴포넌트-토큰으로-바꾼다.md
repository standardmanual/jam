# [UI] UI 소스 정리 9-3b회차: 연출·지도·캡슐·스트라바 화면의 기본값 직접 참조를 의미·컴포넌트 토큰으로 바꾼다

## 핵심 요약

- 요구사항: 상위 티켓 20261125_1923 9회차 세 번째 조각의 뒤쪽 절반. `src/components`의 도메인 화면 6개가 기본값 층을 `var(--…)`로 직접 가리키는 곳(78곳)을 서비스 눈금 클래스·기존 의미 토큰·승인된 새 토큰으로 바꾼다.
  **화면 변화는 없어야 한다.** 9-3a(20261126_2024)와 동시에 돌고, 두 조각은 같은 파일을 고치지 않는다.
- **바꾸는 규칙은 9-3a 티켓의 «기본값을 쓸 수 있는 곳과 없는 곳»·«9-3 공통 규칙» 절을 그대로 따른다**(먼저 그 두 절을 읽는다).
- 사용자 승인: 2026-11-26 — 9-3b 새 의미 토큰 1개(`--overlay-foreground`)와 새 컴포넌트 토큰 9개(`--map-drop-marker-active`·`--map-label-bg`·`--tierup-stage-bg`·`--capsule-fade-dur`·`--capsule-ease`·`--poi-carousel-dur`·`--poi-carousel-ease`·`--pick-overlay-fade-dur`·`--pick-overlay-fade-ease`). `--map-label-bg`는 2026-10-16 결정 «이미지·지도 위 막은 새 토큰을 만들지 않는다»(문서 11 §5.7)를 바꾸는 것으로 사용자가 확인했다.
- 관련 파일: 아래 «구현 계획»의 파일 표(줄 번호는 로컬 staging `58fa5bf18` 기준).

## 새 토큰 (사용자 승인 2026-11-26)

색 토큰은 `:root, [data-service-theme]` 블록에, 움직임 토큰은 모션 레시피가 있는 `:root` 블록에 둔다. 9-3a는 `component.css` 첫 블록 맨 끝(`--status-card-bg` 뒤)에 더하므로 아래 자리와 겹치지 않는다.

| 이름 | 층·자리 | 값 | 쓰는 곳 |
|---|---|---|---|
| `--overlay-foreground` | `semantic.css` 글자 묶음, `--muted-on-inverse` 뒤 | `var(--base-white)` | 어두운 막·연출 무대 위 흰 글자(배지 공개 오버레이 218, 티어업 연출 546) |
| `--map-drop-marker-active` | `component.css` 첫 블록, `--capsule-ring` 뒤 새 «지도·연출» 묶음 | `var(--jam-green)` | 지도 배지 지점 마커 면(`MapView.tsx` 179) |
| `--map-label-bg` | 같은 묶음 | `color-mix(in srgb, var(--base-black) 65%, transparent)` | 지도 지점 이름표 바탕(`MapView.tsx` 265 HTML 문자열) |
| `--tierup-stage-bg` | 같은 묶음 | `radial-gradient(circle farthest-corner at 50% 42%, var(--base-neutral-700) 0%, var(--base-neutral-900) 38%, var(--base-black) 100%)`(지금 `STAGE_BACKGROUND` 값 그대로) | 티어업 연출 무대 바탕 |
| `--capsule-fade-dur` / `--capsule-ease` | `component.css` 둘째 `:root` 블록 맨 끝(`--reel-ease` 뒤) 새 «화면 전용 움직임» 묶음 | `var(--duration-fast)` / `var(--ease-smooth-out)` | 캡슐 게이지 글자 페이드(64·176)와 채움 폭(222) |
| `--poi-carousel-dur` / `--poi-carousel-ease` | 같은 묶음 | `var(--duration-medium)` / `var(--ease-smooth-out)` | 장소 캐러셀 넘김(`PoiCarouselModal.tsx` 870) |

### 문서

- `jam-web/design-system/tokens/primitive.css` 머리 주석의 «`--base-*`를 직접 쓰는 예외는 세 범주뿐이다 … grep으로 확인한다» 문장을 «화면 코드는 의미·컴포넌트 토큰과 서비스 눈금 클래스만 쓴다. 기본값을 직접 쓸 수 있는 곳은 토큰 파일·jam-theme.css·admin-theme.css·globals.css·정본 폴더(`src/components/ui`)·`src/components/transitions.css`·스토리북 토큰 소개뿐이다(티켓 20261126_2024·2025, 9-4 검사기가 막는다)»로 바꾼다.
- `jam-web/src/app/globals.css`의 «클래스가 아닌 곳은 tokens/의 평문 눈금(var(--spacing-16), var(--text-base))을 쓴다» 주석(약 111~116줄)을 같은 뜻으로 고친다. `primitive.css`의 간격·글자 묶음 주석에 있는 같은 안내(«인라인 style·CSS·calc() 안처럼 클래스가 아닌 곳이 참조한다»)도 «정본 폴더·토큰 파일 안에서» 참조한다로 맞춘다.
- `docs/plan/jam2/11 JAM 2.0 디자인 시스템.md` §5.7(약 249줄)의 «이미지·지도 위 막은 새 토큰을 만들지 않는다(사용자 결정)» 문장을 «지도 이름표 막은 `--map-label-bg`(검정 65%)로 둔다(2026-11-26 사용자 결정으로 2026-10-16 결정을 바꿈, 티켓 20261126_2025). 배지 획득·티어업 연출의 흰 글자는 `--overlay-foreground`다»로 고친다. 포스터 카드 막 언급이 지금 코드에 없으면 그 사실만 적는다.

- 규모: 코드·시험·토큰·문서를 합쳐 파일 약 12개, 100줄을 넘는다. 파일 단위 계획이 위에 있고 대상 줄은 카리나가 측정으로 확인했다(계획 반환 면제 근거).
