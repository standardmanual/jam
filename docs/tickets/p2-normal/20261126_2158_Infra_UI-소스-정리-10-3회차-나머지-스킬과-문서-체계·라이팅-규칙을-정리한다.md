2. 꺼진 기능 규칙 삭제: jam-sync «분리 구조 정리», jam-ship «주간 무인 배포와의 관계»(대응표는 `scheduled-jobs.md` «무인 경로에 적용하는 점검» 한 곳에만), UX 가이드의 배지 트리 용어.
