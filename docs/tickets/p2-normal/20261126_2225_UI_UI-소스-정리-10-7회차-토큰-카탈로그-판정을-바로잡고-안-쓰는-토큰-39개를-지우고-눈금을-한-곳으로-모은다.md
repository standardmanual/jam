## 구현 계획

1. 카탈로그 판정 보강: `gen-token-catalog.mjs`가 Tailwind 유틸리티 경유 사용(`font-*`→`--font-weight-*`, `tracking-*`, `leading-*`, `animate-*`, `aspect-*`, `--default-*`, 모든 간격 클래스의 배수 `--spacing`, `--text-*--line-height`), 어드민 단독 유틸리티(`rounded`→`--radius`, `shadow`→`--shadow`), 문자열 데이터(`var(${cssVar})`로 쓰는 `--jam-*` 이름), globals.css 일반 규칙(`--page-bg`), 살아 있는 토큰이 참조하는 재료를 «쓰임»으로 센다. 그 결과 «쓰는 곳 0»이 39개 + 20개로 줄어드는지 확인한다.
2. 어드민 `--radius` «주의»: 두 정의가 서로 다른 클래스(단독 `rounded` / `rounded-md` 이상)를 맡는 reference 블록 구조를 카탈로그가 구분해 «주의»에서 빼거나 설명으로 바꾼다.
3. 대비 표: 의미 토큰 중 함께 쓰이는 글자색×배경색 조합의 WCAG 대비를 카탈로그에 표로 보인다(4.5 미만·3.0 미만 표시, verify를 막지 않음). 9-1에서 사용자가 알고 받아들인 값(보조 글자 4.35 등)은 그 사실을 비고에 적는다.
4. 토큰 39개 삭제와 죽은 규칙 `transitions.css:424-429` 삭제. 스토리 `Spacing.stories.tsx`의 간격 역할 토큰 소개를 함께 정리한다.
5. 눈금 단일 원천: `jam-theme.css`의 서비스 눈금이 `primitive.css` 값을 참조하게 한다(준비 측정에서 사본 컴파일 결과 유틸리티 규칙 차이 0). `jam-theme.test.ts`와 카탈로그의 «두 정의 값 다름» 판정을 맞춘다.
6. 정본 폴더(`jam-web/src/components/ui/`)의 기본값 직접 참조(30개 파일 약 199곳)는 허용 구역으로 둔다는 것을 정본 목록 README «UI 규칙» 절에 한 줄로 적는다(근거 `scripts/check-ui-rules.mjs`의 허용 구역).
7. 낡은 주석: `BadgeTicket.module.css:37`의 옛 `var(--base-neutral-900)` 표기, `component.css:14` «common 5.74»(실제 4.74), `primitive.css:63` «짙은 초록 위 --snow 4.59»(실제 4.48).
8. 확인(아현): 바뀐 스크립트 시험, `gen-token-catalog --check`, `jam-theme.test.ts`, 컴파일 CSS 전후 비교(postcss + @tailwindcss/postcss로 `globals.css` 컴파일, 유틸리티 규칙 차이 0, 지운 토큰 선언 줄만 빠짐). **push하지 않는다.**
