# [Infra] 아현·민지 정의를 호출마다 필요한 핵심만 남기고 상황별 절차는 참고 문서로 옮긴다

## 핵심 요약

- 요구사항(사용자 «진행해», 2026-11-27): 티켓 20261125_1923 10회차는 장치로 옮겨 간 규칙 문장을 지웠지만, 워크플로 호출마다 실리는 아현(`.claude/agents/jam-developer.md`, 209줄·1만 3,914바이트)과 민지(`.claude/agents/jam-reviewer.md`, 201줄·1만 4,458바이트) 정의는 3~5%만 줄었다. 규칙을 빼지 않고 구조를 바꿔 호출마다 실리는 분량을 줄인다.
- 방식: 매 호출에 필요한 것(역할·원칙·절대 규칙의 한 줄 요지·정지 조건·반환 형식의 필수 칸·금지)만 정의에 남긴다. 상황에 따라서만 필요한 절차(예: push·커밋 훅의 세부, 재작업·옛 작업 폴더 처리, 반환 양식의 상세 예시, 확신도·alerts 기준 상세, 토큰 규율 세부, 민지 모드별 절차·점검표 항목별 상세, 작업 폴더 이동 금지 사례)는 참고 문서로 옮기고, 정의에는 «언제 그 문서를 읽는가»가 분명한 한 줄을 남긴다.
- 참고 문서 위치: `.claude/skills/jam-work/references/developer-*.md`·`reviewer-*.md`(채원 모드 파일 `designer-*.md`와 같은 자리). 격리 작업 폴더에서도 읽히도록 `docs/agents/contract.json` `worktree_contains.tracked_paths`에 더한다.
- 화면 변화: 없음.
