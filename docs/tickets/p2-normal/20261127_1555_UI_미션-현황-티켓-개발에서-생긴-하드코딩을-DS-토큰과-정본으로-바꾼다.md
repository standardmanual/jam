# [UI] 미션 현황 티켓 개발에서 생긴 하드코딩을 DS 토큰과 정본으로 바꾼다

## 핵심 요약

- 요구사항: 티켓 20261127_1145(미션 현황 티켓 리뉴얼)에서 생긴 **하드코딩**(토큰·정본을 거치지 않고 CSS·TSX에 직접 적은 값)을 모두 없앤다. 이 화면에만 쓰고 DS와 독립된 값이 남지 않게 한다(사용자 지시, 2026-11-27). **«하드코딩»은 사용자와 정한 용어다.**
- 사용자 지시: 기존 DS 토큰·정본 컴포넌트로 바꾼다. **신규 토큰이나 정본 컴포넌트·변형이 필요하면 구현 전에 사용자 확인을 받는다**(채원① `needsApproval`로 멈춘다).
- 범위: 20261127_1145가 **추가·변경한** 값만이다. 그 전부터 있던 `.titleBox`·`.titleTop` 등 기존 CSS의 px 값은 이번 범위 밖이다.
- 하드코딩 목록(지도):
  1. `jam-web/src/app/(main)/badges/[id]/BadgeTicket.module.css` `.titleStats`·`.titleStat`·`.titleStatLabel`·`.titleStatValue`(통계 칸): 값 글자 `28px/36px/700`(글자 눈금에 없음), 라벨 `12px/16px`, 안쪽 여백 `14px 8px 16px`, 간격 `2px`, 테두리 `2px`.
  2. `jam-web/src/app/(main)/missions/[id]/status/MissionStatus.module.css`: 간격·크기 `24px`·`16px`·`12px`·`8px`·`4px`(`--spacing-*` 토큰이 있다: 4·8·12·16·20·24·32·40·48·64·96), `.slot`의 `min-height: 320px`, `.name`의 `max-width: 280px`, `.avatar`의 `border: 3px`, `.cardTitle`의 `font-weight: 700`.
  3. 같은 파일 `.darkCard`: `--foreground`·`--muted`·`--link`를 CSS에서 직접 덮어쓴다(티켓 카드 구간이 되돌린 글자 토큰을 검정 `Card` 안에서 다시 흰색으로 읽히게 하는 임시 처방). 정본(`Card tone="inverse"` 또는 티켓 틀)이 티켓 안에서 스스로 해결해야 한다.
  4. 같은 파일 `.cardTitle`·`.cardCount`: 화면 전용 토큰(`--status-card-title-size`)과 `color: var(--snow)` 직접 지정이 정본 글자 눈금·카드 헤더와 독립이다.
  5. `jam-web/src/app/(main)/missions/[id]/status/MissionStatusClient.tsx`·`MissionSummary.tsx`·`MissionBoard.tsx`: 인라인 `style`은 없다. `w-6 h-6`·`w-8 h-8`은 눈금 클래스라 대상이 아니다. 그 밖에 화면 안에서만 의미 있는 클래스·값이 있는지 점검한다.
  6. `jam-web/src/components/ui/ListRow.tsx` `ListRowChip`·`RankingListRow`의 이번 추가분(`size="lg"`, `outline`·`ticket`·`on-inverse` 톤, `rowTone`)에 하드코딩이 있는지 점검한다(예: `inset 0 0 0 2px currentColor`).

## 배경 / 문제 정의

20261127_1145가 `ui-rules`·`spacing`·`token-refs` 검사를 통과했지만, 검사가 CSS 모듈 안의 px 값과 로컬 토큰 덮어쓰기까지는 막지 않는다. 사용자는 이 화면에만 쓰는 DS 밖 값이 남지 않기를 요구했다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 위 1~6의 값을 기존 토큰(`--spacing-*`, 글자 눈금, 반지름, 테두리)과 정본 컴포넌트로 바꾼다. 눈에 보이는 결과(크기·여백·색)는 바꾸지 않거나, 바뀌면 근접 눈금으로 맞춘 사실을 알린다.
- 기존 토큰에 대응 값이 없으면(예: 28px 글자, 3px 테두리, 280·320px) **임의로 만들지 않는다.** 가장 가까운 기존 눈금으로 맞추는 안과 신규 토큰을 만드는 안을 채원①이 판정하고, 신규가 필요하면 `needsApproval`로 사용자에게 올린다.
- `.darkCard`의 글자 토큰 덮어쓰기는 정본 쪽에서 해결할 수 있는지(예: `Card tone="inverse"`가 티켓 안에서 스스로 글자 토큰을 설정) 채원①이 판정한다. 정본 변경이면 사용자 승인 대상이다.

### UI/UX 관점
- 360px·390px에서 지금 화면과 같게 보인다(요약 상자 값이 칸을 넘치지 않는다, 검정 카드 안 글자가 흰색).

## 구현 계획

채원① 사전 판정(2026-11-27)을 따른다. 신규 토큰·신규 정본·신규 변형은 없다.
1. `jam-web/src/app/(main)/badges/[id]/TicketTitleBoxes.tsx`·`BadgeTicket.module.css`: `.titleStats`·`.titleStat`·`.titleStatLabel`·`.titleStatValue`를 지우고 TSX에서 눈금 클래스로 쓴다(통계 줄 `grid grid-flow-col auto-cols-fr border-t-2`, 칸 `min-w-0 flex flex-col items-center gap-1 pt-3 px-2 pb-4` + 둘째 칸부터 `border-l-2`, 라벨 `text-xs`, 값 `text-3xl font-bold tabular-nums whitespace-nowrap`).
2. `jam-web/src/app/(main)/missions/[id]/status/MissionStatus.module.css`: 파일을 지우고 세 TSX가 눈금 클래스를 쓴다(`min-h-80`·`max-w-70`·`border-2`·`text-xl` 등).
3. `jam-web/src/components/ui/Card.tsx` `tone="inverse"`: 글자 토큰(`--foreground: var(--snow)`, `--muted: var(--muted-on-inverse)`, `--link: var(--snow)`)을 자기 안에서 정한다. `Card.stories.tsx`에 잉크 구간 안 inverse 스토리 1개. `.darkCard`는 삭제.
4. `jam-web/design-system/tokens/component.css`: `--status-card-title-size`·`--status-card-title-line-height` 삭제, `tokens.md` 재생성.
5. `ListRow.tsx`·`RankingListRow.tsx`는 점검 결과 고치지 않는다(`inset 0 0 0 2px currentColor`는 기존 정본의 같은 관용구).
6. 범위 밖 발견(이번에 안 고침): `RankingListRow.tsx` `MeCircle`의 `width·height 22`, `BadgeTicket.module.css` 기존 `.titleBox`·`.titleTop`의 px.

## 주요 의사결정

- 사용자 승인: 2026-11-27 — 정본 `Card`의 `tone="inverse"`가 글자 토큰(`--foreground`·`--muted`·`--link`)을 자기 안에서 정하도록 바꾼다(화면의 `.darkCard` 덮어쓰기 제거).
- 사용자 승인: 2026-11-27 — 화면 전용 토큰 `--status-card-title-size`·`--status-card-title-line-height`를 삭제하고 카드 제목을 `text-xl`(20px)로 맞춘다.
- 사용자 승인: 2026-11-27 — 대응 토큰이 없는 값은 가장 가까운 기존 눈금으로 맞춘다: 통계 값 28→30px(`text-3xl`, 행간 36 그대로), 통계 칸 위 여백 14→12px·칸 안 간격 2→4px(칸 높이 불변), 아바타 테두리 3→2px. 통계 값이 360px에서 칸을 넘치면 `text-2xl`로 내리는 안도 포함한다.
- 용어 결정(사용자, 2026-11-27): 토큰·정본을 거치지 않고 직접 적은 값은 «하드코딩»이라 부른다.

## 완료 조건

- 위 1~6의 하드코딩이 토큰·정본으로 바뀌었거나, 대응 토큰이 없는 값은 채원 판정과 사용자 승인 줄이 티켓 「주요 의사결정」에 있다.
- `jam-web/src/app/(main)/missions/[id]/status/` 폴더의 CSS·TSX에 `px` 리터럴 크기·간격, 색 리터럴, 로컬 토큰 덮어쓰기가 남지 않는다(`git grep`으로 확인하고 결과를 완료 기록에 적는다).
- 눈에 보이는 변화는 근접 눈금으로 맞춘 5건뿐이다(통계 값 28→30px, 통계 칸 위 여백 14→12px·칸 안 간격 2→4px, 아바타 테두리 3→2px, 카드 제목 21→20px)이고 완료 기록에 적는다. 랭킹형·달성형 시험이 통과하고 브라우저 실측 360·390px에서 요약 값이 칸을 넘치지 않으며 검정 카드 안 글자가 흰색이다.
- `scripts/verify.sh`가 통과한다.
