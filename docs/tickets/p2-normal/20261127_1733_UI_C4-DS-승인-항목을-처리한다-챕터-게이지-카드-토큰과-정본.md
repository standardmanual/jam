## 배경 / 문제 정의

상위 티켓 20261127_1720의 단계 C(전환, 같은 배포 창)에 속하는 조각이다. 잼은 챕터를 올리는 경험치이고 포인트는 별도 재화이며, 캡슐은 폐지한다(2026-11-27 사용자 결정). 챕터 1~9의 필요 잼은 870, 1,120, 1,260, 1,600, 1,980, 2,205, 2,700, 3,300, 3,960이고, 넘친 잼은 이월한다.

## 확정 시안 (Claude 디자인 캔버스, 사용자가 직접 고친 값, 2026-11-27 읽음)

원본: `https://claude.ai/artifact/2UzUpS1Na3QnbBkifPzEhp`의 `project/ChapterCard.dc.html`(카드), `States.dc.html`(상태 5종), `Profile.dc.html`(내 프로필 배치). 아래는 그 파일에서 옮긴 값이다. **시안의 값은 참고이고, 실제 개발은 DS 토큰으로 한다(사용자 지시).** 시안에 있는 리터럴(`#636363` 등)을 코드에 그대로 옮기지 않는다.

- **카드 바깥**: 폭 100%(예시 358px 또는 398px), 바깥 둥근 모서리 16px, 안쪽 여백 12px, 세로 간격 12px, 글자색 `#fcfcfc`, 배경 위에서 아래로 `#636363`에서 `#282828`으로 가는 세로 그라디언트. 글자체 Noto Sans KR(`word-break: keep-all`).
- **윗줄**(좌우 안쪽 여백 18px, 아래 정렬, 양끝 정렬): 왼쪽 트라이브 이름(20px, 줄 높이 1.4, 굵기 800, 길면 줄바꿈 `overflow-wrap: anywhere`). 오른쪽은 «챕터 블록»: 영문 라벨 `CHAPTER`(12px, 굵기 800)와 챕터 번호(**36px**, 굵기 800, 숫자 폭 고정 `tabular-nums`)를 세로로 쌓고 **가운데 정렬**(사용자 코멘트: 라벨은 항상 아래 숫자와 중앙 정렬).
- **트랙**(게이지 바깥): 높이 36px, 안쪽 여백 **2px**, 완전 둥근 모양, 배경 `#171717`. 안쪽 높이 32px.
- **채움**(게이지): 완전 둥근 모양, 색 `#f94c31`(오렌지), 왼쪽 끝에서 시작. 길이 = 칩 폭(44px) + (남은 길이) × 진행 비율. 시작(0)이어도 칩이 있어 칩 아래에 가려진 채 시작한다.
- **JAM 워드마크 칩**(채움 앞, 위에 얹음): 폭 44px, 높이 32px, 완전 둥근 모양(가로로 늘린 칩), 배경 `#171717`, 안에 JAM 워드마크 SVG(26×9.4px, 흰색 `#fcfcfc`)를 가운데에 둔다. (캔버스 코멘트: 처음엔 단일 «J» 서클이었다가 사용자가 SVG 워드마크 칩으로 바꿨다. 칩의 글자는 «JAM 로고»이지 잼의 단위가 아니다.)
- **모은 잼 숫자**: 20px, 굵기 800, 색 `#171717`, `tabular-nums`. 채움 안에 들어갈 폭이면 채움 안쪽 오른쪽 끝(오른쪽 여백 12px), 안 들어가면 트랙 오른쪽 끝 바깥쪽(오른쪽 여백 16px)에 둔다(들어가는지는 칩 44 + 간격 4 + 글자 수 × 12.5 + 12px로 판단).
- **필요 잼 숫자**(목표): 트랙 아래 오른쪽 정렬(위쪽 간격 -8px로 트랙에 붙임, 오른쪽 18px), 16px, 굵기 800, 색 `#f94c31`, `tabular-nums`. 숫자는 천 단위 쉼표.
- **모션(페이지가 열릴 때)**: 화면에 들어온 뒤 0.26초 쉬고 시작. 채움 폭이 1500ms(`cubic-bezier(0.22, 1, 0.36, 1)`)로 0에서 자기 비율까지 늘어난다. 모은 잼 숫자의 자릿수가 아래에서 위로 8px 올라오며 흐림 2px에서 선명해지고 투명에서 불투명으로(500ms, `cubic-bezier(0.34, 1.45, 0.64, 1)`), 마지막 두 자리는 70ms·140ms 늦게 시작한다. **모션 줄이기(`prefers-reduced-motion`)에서는 모션 없이 바로 최종 모양이다.** 첫 화면 로딩 모션 유지는 사용자 요구다.
- **접근성**: 카드 `role="group"`, 라벨 «챕터 N, 트라이브 이름». 트랙은 `role="img"`, 라벨 «다음 챕터까지 잼 모은양 / 필요양». 칩은 장식(`aria-hidden`).
- **상태 5종**(States 보드): 시작(0 / 2,344, 챕터 1), 약 20%(465 / 2,344, 챕터 9999), 약 65%(1,500 / 2,344, 챕터 12), 가득(2,344 / 2,344, 챕터 99), 긴 트라이브 이름(465 / 2,344, 챕터 1, «도시의 새벽을 달리는 야간 러너 모임»). 챕터 10(마지막, 필요 잼 없음)은 시안에 없다(Q-e).
- **배치**: 내 프로필(Profile 보드)은 프로필 머리(아바타·닉네임), 팔로워·팔로잉·포인트 세 칸, **그 아래 카드**, 그 아래 피드·배지·컬렉션 탭. 홈의 위치는 시안에 없고 C5b에서 정한다. 배경은 중립 회색 `#f5f5f5`.
- **리터럴 목록(DS에 있는지 판정할 것)**: 카드 배경 그라디언트 두 색(`#636363`, `#282828`), 트랙·칩 배경(`#171717`), 오렌지(`#f94c31`), 글자 `#fcfcfc`, 크기 36px(챕터 번호), 20px(트라이브 이름·모은 잼), 16px(필요 잼), 12px(CHAPTER 라벨), 카드 안쪽 여백 12px, 윗줄 좌우 18px, 트랙 높이 36px·안쪽 여백 2px, 칩 44×32px, 둥근 모서리 16px, 모션 값.
- **열린 결정**: Q-k(영문 `CHAPTER` 라벨을 쓸지, 다른 화면처럼 한글 «챕터»로 할지, 윈터 의견은 한글이 더 단순) 그리고 Q-e(챕터 10의 표시). 둘 다 사용자 결정이고 승인 항목에 포함한다.

## 구현 계획

1. 채원 모드 ① 사전 판정을 받는다: 재사용·정본 변형·새 정본 중 무엇인지, 쓸 토큰, 텍스트 배치도, 상태 목록(시작 0, 20%, 65%, 가득, 긴 트라이브 이름, 챕터 10).
2. 승인 필요 항목을 사용자에게 보고하고 `- 사용자 승인: YYYY-MM-DD — <항목>` 줄을 티켓에 적는다(없으면 `.githooks/commit-msg`가 막는다).
3. 승인된 값만 `jam-web/design-system/tokens/primitive.css`, `component.css`에 더하고, 필요한 정본 변형을 `jam-web/src/components/ui/`에 더한다. 스토리를 함께 만든다.
4. 윈터 검수: 영문 «CHAPTER» 라벨과 JAM 워드마크 칩의 톤.
