# [Admin] C10b 밸런스 대시보드와 생태계 노드의 캡슐 지표를 바꾼다

## 핵심 요약

- 요구사항: 밸런스 대시보드, 생태계 노드, 아이템 경로 라벨에서 캡슐 지표를 챕터 신호로 바꾼다.
- 구현 계획: 아래 «구현 계획»의 단계를 파일 단위로 따른다(3단계).
- 관련 파일: `jam-web/src/lib/admin/balanceDashboard/load.ts`, `compute.ts`, `targets.ts`, `types.ts` / `jam-web/src/components/admin/balanceDashboard/PathReasonLabels.ts`, `jam-web/src/lib/admin/ecosystem/nodes.ts`와 시험
- 선행 티켓: 20261127_1741(C10a)
- 상위 티켓: 20261127_1720(챕터 게이지 카드로 전환하고 캡슐을 폐지한다). 기획 경위와 사용자 확정 결정은 상위 티켓에 있다.

## 배경 / 문제 정의

상위 티켓 20261127_1720의 단계 C(전환, 같은 배포 창)에 속하는 조각이다. 잼은 챕터를 올리는 경험치이고 포인트는 별도 재화이며, 캡슐은 폐지한다(2026-11-27 사용자 결정). 챕터 1~9의 필요 잼은 870, 1,120, 1,260, 1,600, 1,980, 2,205, 2,700, 3,300, 3,960이고, 넘친 잼은 이월한다.

## 구현 계획

1. `jam-web/src/lib/admin/balanceDashboard/{load,compute,targets,types}.ts`와 `jam-web/src/components/admin/balanceDashboard/PathReasonLabels.ts`: 캡슐 경로·지표를 챕터 오름 신호로 바꾼다.
2. `jam-web/src/lib/admin/ecosystem/nodes.ts`(6곳, 노드 `capsule`)와 `itemPaths`의 캡슐 경로를 정리한다.
3. 시험: `ecosystem/__tests__`, `api/admin/item-paths/__tests__`, `api/admin/balance/__tests__`.

## 완료 조건

- 밸런스 대시보드와 생태계 노드에 캡슐 지표가 없고 챕터 오름 신호가 보인다.
- 아이템 획득 경로 집계에서 캡슐 경로가 새 경로(챕터 보상)로 대체됐고 관련 시험이 통과한다.
- 카리나의 실렌더 확인 결과가 티켓에 있다.

## 규모와 체크포인트

- 규모: 파일 8개, 약 300줄(추정, 미검증). 분할된 둘째 조각
- 체크포인트: admin 유형: 머지 뒤 카리나 실렌더 검증.

## 주요 의사결정 / 핵심 메모

- 상위 티켓의 사용자 확정 결정과 «하지 않을 것»을 따른다. 확인하지 않은 수치는 «미검증»이다.
- 계획 반환 면제 전제: 이 티켓은 파일 5개 초과 또는 100줄 이상이 예상돼 위 «구현 계획»을 파일 단위로 적었다. 사용자가 이 방식을 승인했다(2026-11-27). `/jam-work` 호출 때 카리나가 `planOnlyWaiver`로 넘기고, 면제 사유를 여기에 이어서 남긴다.
