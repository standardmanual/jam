# [Service] C14a 운영 로직 문서에 새 챕터 구조를 반영한다

## 핵심 요약

- 요구사항: `10 JAM 2.0 서비스 운영 로직.md`의 4·5·12장과 2.2·7·13·15·16·18장의 캡슐 문장을 새 구조(필요 잼 도달로 챕터 상승, 챕터 오름 보상)로 고친다.
- 구현 계획: 아래 «구현 계획»의 단계를 파일 단위로 따른다(2단계).
- 관련 파일: `docs/plan/jam2/10 JAM 2.0 서비스 운영 로직.md`(4·5·12장 외)
- 선행 티켓: 20261127_1722(A2), 20261127_1730(C2b)
- 상위 티켓: 20261127_1720(챕터 게이지 카드로 전환하고 캡슐을 폐지한다). 기획 경위와 사용자 확정 결정은 상위 티켓에 있다.

## 배경 / 문제 정의

상위 티켓 20261127_1720의 단계 C(전환, 같은 배포 창)에 속하는 조각이다. 잼은 챕터를 올리는 경험치이고 포인트는 별도 재화이며, 캡슐은 폐지한다(2026-11-27 사용자 결정). 챕터 1~9의 필요 잼은 870, 1,120, 1,260, 1,600, 1,980, 2,205, 2,700, 3,300, 3,960이고, 넘친 잼은 이월한다.

## 구현 계획

1. `docs/plan/jam2/10 JAM 2.0 서비스 운영 로직.md`(캡슐 154곳): 4장(잼 적립), 5장(캡슐 → 챕터 진행·카드), 12장(챕터 승급과 표시), 5.3절·4.3절의 진행 수치 문장, 나머지 장의 캡슐 문장.
2. 대체된 결정(상위 티켓 표)을 날짜와 함께 남긴다.

## 완료 조건

- 운영 로직 문서에 기능 용어 «캡슐»이 남아 있지 않고(유지 목록 제외), 챕터 승급이 필요 잼 도달로 적혀 있다.
- 문서끼리 어긋나 있던 «진행 숫자» 서술(5.3절 ↔ 홈피드 PRD)이 한 가지로 맞춰져 있다.
