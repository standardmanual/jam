# [UI] 등급 올리기 화면을 가차머신 연출의 «등급 UP»으로 리뉴얼한다

## 핵심 요약

- 요구사항: `/combine?view=tier-up` 화면을 프로토타입(`docs/assets/prototypes/20261127_tier-up-gacha-prototype.html`)과 같은 가차머신 화면으로 바꾼다. 슬롯 6칸과 제출 버튼을 없애고, 기존 바텀시트에서 같은 등급 배지 6개를 다 고르면 자동으로 제출한다. 투명 가차볼이 유리 돔 안에서 섞이고, 하나가 중앙으로 나와 다크 유리볼이 된 뒤 진동하고, 상위 등급 배지가 공개되고, «한 번 더»로 처음 화면으로 돌아간다. 이름은 «등급 올리기»에서 «등급 UP»으로 바꾼다.

## 배경 / 문제 정의

지금 등급 올리기 화면은 슬롯 6칸 + 제출 버튼 + 검은 화면 결과 연출(JAM 로고로 재료가 모이는 `TierUpRevealOverlay`, 티켓 20261112_2141)이다. 사용자가 가차머신 영상 2개를 참고로 연출을 다시 설계했고, 아티팩트 프로토타입(https://claude.ai/artifact/4qXVBiobwE4juptr8NmGFG)에서 코멘트 14건 이상을 거쳐 확정했다. 확정본은 저장소에 `docs/assets/prototypes/20261127_tier-up-gacha-prototype.html`로 보관했다(커밋 f85087f99). **시각·모션 수치의 기준은 이 파일이다.**

## 상세 요구사항

### UI/UX 관점

**화면 구성 (대기 상태)** — 프로토타입 `.top`·`.machine` 구조와 수치를 따른다.
- 배경: 화면 전체가 어두운 원형 그라데이션(프로토타입 `.app` background). 하단 탭바 등 레이아웃 바깥은 기존대로 둔다.
- TopNav: 서비스 `TopNav`를 그대로 쓰되 네거티브로 보이게 한다 — 배경 투명(페이지 그라데이션이 비친다), 글자·뒤로가기 흰색. DS `TopNavBar`는 고치지 않는다(호출부 `headerStyle`로 처리, 예: `background: 'transparent'`, 지역 CSS 변수 `--foreground`를 흰색으로 덮기). 제목 «등급 UP».
- 헤더 아래 설명 문장(`tierUp.description`)과 «넣은 배지는 사라져요»(`burnNotice`)는 화면에서 뺀다.
- 가차머신(위→아래): 유리 돔(어두운 남색 원 + 파란 테두리 + 왼쪽 위 초승달 반사 + 약 4.6초마다 지나가는 반사광) → 레드 받침(사다리꼴, 손잡이 원) → 레드 직사각형 몸통(아래 소실점 투시 `perspective(380px) rotateX(17deg)`, 아래로 어두워지는 음영) → 몸통 안 메탈 JAM 로고(몸통 폭 28%, `/jam-logo-white.png` 마스크 + 은색 그라데이션·헤어라인·엠보싱) → 블랙 «배지 넣기» 버튼(글자 폭 + 좌우 28px, 높이 50, `#171717`, 흰 글자).
- 돔·받침·몸통은 같은 폭. 화면 높이가 낮으면 머신 전체가 비율을 유지하며 줄어든다(프로토타입 `--mw` 계산식).
- 돔 안: 행운 문구 1개(7개 중 무작위, 진입·«한 번 더» 때 새로 뽑고 대기 중 약 4.2초마다 페이드로 교체, 시트가 열려 있거나 연출 중이면 바꾸지 않음) + 개수 상자(위 줄 «n/6» 24px, 담은 수는 초록, «/»는 14px 회색 세로 가운데, 아래 줄 «BADGE», 배경 불투명도 38% + 흐림 4px).

**바텀시트** — 기존 `BottomSheet` + `TierUpSheetContent`를 그대로 쓴다(모양 변경 없음). «배지 넣기» 버튼으로 연다.
- 6개를 다 고르면 시트가 자동으로 닫히고 바로 제출·연출이 시작된다.
- 6개 전에 시트를 닫으면 고른 배지는 유지되고 돔의 «n/6»에 반영된다.
- 슬롯이 없으므로 선택 해제는 시트에서 한다: 이미 고른(`used`) 배지를 다시 누르면 빠진다.

**연출 순서** (프로토타입 `run()`·`again` 처리와 같은 시간값)
1. 시트가 닫히면 고른 배지 6개가 투명 가차볼(전체가 투명한 유리구, 안에 배지 그림이 비침)이 되어 돔 안 위쪽에 0.11초 간격으로 톡 생겨나 떨어진다.
2. 돔 안에서 섞인다 — 공마다 앞뒤 깊이가 있어 서로 겹쳐 지나가고, 아래쪽 1/3에서 위로 부는 바람 + 소용돌이 + 난류로 돔 전체를 돈다(프로토타입 `step()`). **최소 3초, 서버 응답이 늦으면 응답이 올 때까지 계속 섞는다.**
3. 가운데에 가깝고 가장 앞쪽인 공 하나가 화면 중앙(무대 높이 40%)으로 나오며 크게 커지고, 오는 동안 다크 유리볼(어두운 스모크 유리, 배지 안 보임)로 바뀐다. 동시에 머신(돔·받침·몸통·버튼)은 아래로 180px 내려가며 페이드 아웃된다.
4. 중앙의 다크 유리볼이 1.15초간 점점 세게 잔 진동한다.
5. 섬광 링과 함께 상위 등급 배지(지름 180)·등급 칩·배지 이름·«인벤토리에 담았어요»가 나타나고, 공은 작아지고 흐려지며 뒤로 빠르게 사라진다. 배지 뒤에 등급색 후광과 느리게 도는 빛살.
6. 화면 아래에 작은 «한 번 더» 버튼이 나온다. 누르면 결과가 사라지고 머신이 페이드 인으로 중앙에 다시 나타나며(행운 문구 새로 뽑음, 개수 0/6) 처음 상태로 돌아간다.
- 모션 줄이기 설정: 시간값을 줄이고(프로토타입 `T()`·`RM`) 반사광·빛살 회전을 끈다.

**결과 갈래**
- 잠기지 않은 단일 성공: 위 1~6.
- 잠긴 결과, 또는 빈칸이 모자라 받지 않은 결과(`resultStatus: 'pending'`): 4(진동)까지 같고, 그 뒤 스테이지를 처음 상태로 되돌리고 지금 쓰는 안내(가린 카드 `BadgeRevealOverlay` / 받지 않은 결과 문구)를 연다. 닫으면 지금과 같이 처리한다.
- 소각 전 거절·네트워크 오류: 섞기를 멈추고 공을 거둔 뒤 머신을 처음 상태로 되돌리고, 지금과 같은 안내(`tierUpRejection` 토스트 등)를 띄운다. 거절 사유가 담은 칸을 비우라고 하면(`clearSlots`) 고른 배지를 비운다.

**막힘 안내**
- 받지 않은 믹스 결과가 있으면(`pendingBlocked`) «배지 넣기»를 비활성으로 두고 지금 안내 문구(`pendingBlockedNote`)를 머신 아래에 둔다.
- 6개 이상 가진 등급이 없으면 «배지 넣기»를 비활성으로 두고 `noEnoughNotice`를 머신 아래에 둔다.

### 서비스/코드베이스 관점
- **DS에 추가하지 않는다(사용자 지시 2026-11-27).** 가차머신 색·치수·그림자·투시·버튼·문구 배치는 새 컴포넌트 안에 하드코딩한다. 새 토큰·새 정본 컴포넌트·정본 변형을 만들지 않는다. 기존 정본(`BottomSheet`, `RarityBadge`, `SafeImage`, `InlineNotice`, `TopNav`)은 그대로 재사용할 수 있다.
- 서버(`/api/combine/tier-up`)·`tierUpClient.ts` 규칙·응답 형식은 바꾸지 않는다.
- 결과 배지 그림은 응답의 `image_url`을 쓴다. 가차볼 안 배지 그림은 고른 재료의 `badge.image_url`이다(캔버스에 그리려면 이미지 로드 실패·CORS를 견뎌야 한다 — 실패하면 빈 투명구로 그린다).
- 물리 계산은 순수 함수(`gachaPhysics.ts`)로 분리해 시험한다. 프레임 루프는 다음 프레임을 먼저 예약하고 계산을 오류 처리로 감싼다. 공 반지름이 1.5 이하인 프레임은 그리지 않는다(프로토타입에서 음수 반지름 오류로 섞기가 멈췄던 버그, 2026-11-27 수정).
- 언마운트·라우트 이동·연타 때 애니메이션·타이머·rAF가 남지 않는다.
- `TierUpRevealOverlay`와 그 시험을 지운다. 그 컴포넌트만 쓰던 `--tierup-stage-bg` 토큰은 DS를 건드리지 않도록 이번에는 남겨 두고 잔여 이슈로 적는다.

## 구현 계획

파일 단위 계획 (규모: 바뀌는 파일 약 12개, 추가+삭제 수백 줄 — `plan_only` 임계값을 넘으므로 이 계획으로 면제한다)

### 구현 범위 (게이트 판정 대상)
- `/combine?view=tier-up` 화면에 슬롯 6칸·제출 버튼·설명 문장·«넣은 배지는 사라져요»가 없고, TopNav는 투명 배경·흰 글자로 «등급 UP»을 보이며, 유리 돔·레드 받침·투시 몸통·메탈 JAM 로고·블랙 «배지 넣기»가 프로토타입 수치대로 그려진다.
- 돔 안 행운 문구가 7개 중 하나로 보이고 대기 중 바뀌며, 개수 상자가 «n/6»·«BADGE»로 고른 수를 보인다.
- «배지 넣기»는 기존 바텀시트를 연다. 6개를 고르면 시트가 자동으로 닫히고 제출이 한 번만 일어난다(시험: 6번째 선택 → `fetch('/api/combine/tier-up')` 1회). 고른 배지를 다시 누르면 빠진다(시험).
- 잠기지 않은 성공 응답이면 섞기(최소 3초) → 다크 유리볼 → 진동 → 결과 배지·등급·이름 → «한 번 더»가 순서대로 나오고, «한 번 더»를 누르면 머신이 다시 나타나고 개수가 0/6이다.
- 잠긴 결과·받지 않은 결과는 진동 뒤 기존 오버레이/안내가 열린다(시험). 거절·오류는 섞기를 멈추고 머신을 되돌리고 기존 안내를 띄운다(시험).
- `pendingBlocked`이거나 6개 이상 가진 등급이 없으면 «배지 넣기»가 비활성이고 해당 안내가 보인다(시험).
- `gachaPhysics.test.ts`가 통과하고, 섞는 동안 공이 돔 밖으로 나가지 않으며 위쪽에 몰려 붙지 않는다.
- 새 토큰·새 정본 컴포넌트·정본 변형이 없다(`design-system/`·`src/components/ui/` 무변경).
- `TierUpRevealOverlay` 파일과 참조가 없다. `npm run lint`·타입 검사·시험이 통과한다(`scripts/verify.sh`).
- 사용자 노출 문구가 «등급 UP»으로 바뀌었고(`ko.ts`, `policiesData.ts` 이름), PRD 98행이 새 흐름을 서술한다.
