# [UI] 등급 UP 공개 화면의 버튼 겹침과 재료 시트 선택 표시를 고친다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-28, staging 실기기 화면 확인):
  1. 결과 배지가 나타날 때 «한 번 더» 버튼이 배지 설명 문장과 겹친다. 설명이 몇 줄이든 버튼이 설명 아래에 놓이고 하단 탭바에도 가리지 않게 한다.
  2. 재료 시트(«내 배지»)에서 배지를 고른 뒤에도 고르기 전과 같이 **전체를 등급 묶음으로** 보여 준다. 고른 배지 카드에는 **테두리**를 표시하고, «추가됨» 글자는 없앤다.
- 구현 계획:
  - (1) `TierUpGachaStage.tsx` — «한 번 더»를 화면 아래 고정 위치(`.again`, `bottom: 96px`)에서 빼고 결과 글자 묶음(`TierUpGachaResultMeta`, `.meta`)의 마지막 항목으로 옮긴다(설명 아래에 흐름대로 붙는다). 결과 배지 중심 `cy`를 정하는 3단계(약 400행 `centerY = stageRect.height * 0.4`)에서, 결과 글자 묶음과 버튼 높이를 실측해 무대 하단 여백(`.stage`의 `padding-bottom`, 탭바 자리) 위에 모두 들어가도록 `cy`를 올린다(이상값 40%, 넘치면 그만큼 위로, 너무 위로 가지 않게 하한을 둔다). 실측은 `flushSync`로 숨긴 측정용 묶음을 그려 `offsetHeight`로 읽는 방식처럼 추정이 아닌 값으로 한다(`jam-web/CLAUDE.md` 오버레이 규칙: 기하값은 실측). `.again`·`againIn`은 쓰지 않게 되면 지운다.
  - (2) `tierUpClient.ts`의 `buildTierUpSheet`(약 146~175행) — 첫 재료를 담은 뒤에도 `kind: 'groups'`로 전체 등급 묶음을 돌려준다. 고정된 등급 묶음의 셀은 고른 것 `selected`, 나머지 `active`이고, 다른 등급 묶음의 셀은 모두 `inactive`다. 고정 등급은 뷰에 `locked`(등급 또는 null)로 담아 시트 위 안내 줄 「지금은 Rare 아이템 배지만 넣을 수 있어요」를 그대로 보인다. `kind: 'locked'` 갈래와 `TierUpSheetCell`의 `used`를 정리한다. `pickableTierUpIds`는 `active`만 고르는 규칙 그대로다.
  - (3) `BagItemCell.tsx` — 등급 UP 전용 `selected` 상태를 더한다: 카드가 눌리고(다시 누르면 빠짐), 그림은 컬러 그대로이며, `BadgeGridCard`의 기존 `selected`(블랙 2px 링)와 `pressed`(aria-pressed)를 켠다. 칩은 붙이지 않는다. 등급 UP에서만 쓰던 `releasable` 속성은 지운다. 레시피 믹서 가방의 `used`(«추가됨» 칩)는 이번 범위가 아니므로 그대로 둔다.
  - (4) `TierUpPanel.tsx`의 `TierUpSheetContent`(약 70~105행) — `locked` 갈래를 지우고 묶음 보기 하나로 그린다. 고정 등급이 있으면 묶음 위에 안내 줄을 한 번 그린다.
- 관련 파일: `jam-web/src/app/(main)/combine/TierUpGachaStage.tsx`(400~480행 3~6단계, 650~735행 결과 렌더·`TierUpGachaResultMeta`), `TierUpGachaStage.module.css`(`.meta`·`.again`·`againIn`), `tierUpClient.ts`(130~182행 시트 뷰 타입·`buildTierUpSheet`·`pickableTierUpIds`), `TierUpPanel.tsx`(`SheetCells`·`TierUpSheetContent`), `BagItemCell.tsx`, 시험 `tierUpClient.test.ts`·`TierUpPanel.test.tsx`·`BagItemCell.test.tsx`·`CombineClient.tierUp.test.tsx`(263~266·391~394·464행 `locked` 기대값)

## 배경 / 문제 정의
티켓 20261127_2225(가차머신 리뉴얼) 배포 뒤 사용자가 staging에서 시험 계정(티켓 20261128_0743)으로 확인한 결과다.
- 겹침: `.again`은 무대 아래에서 `96px` 위에 고정되고, `.meta`는 `cy + 112px`에서 아래로 흐른다. 설명이 세 줄이면 두 요소가 겹친다(스크린샷: «깨진 프리즘», Epic).
- 시트: 첫 배지를 고르면 시트가 그 등급 묶음 하나로 바뀌고, 고른 배지는 회색 그림에 «추가됨» 칩으로 그려진다(스크린샷: Rare 묶음, «입구의 손등 도장 · 추가됨»).

## 완료 조건
- 설명이 0~4줄인 결과에서 «한 번 더»가 설명 아래에 놓이고 겹치지 않는다. 버튼이 하단 탭바 영역(`.stage` 하단 여백) 위에 있다.
- 첫 배지를 고른 뒤에도 시트에 모든 등급 묶음이 보이고, 다른 등급 묶음은 흐린 비활성 카드다.
- 고른 배지 카드에 블랙 링(`BadgeGridCard` `selected`)이 보이고 그림은 컬러이며 «추가됨» 글자가 없다. 다시 누르면 빠진다.
- 새 토큰·새 정본·정본 변형을 만들지 않는다(가차머신은 DS 밖 하드코딩 원칙 유지, 사용자 지시 2026-11-27).
- 바뀐 동작을 시험으로 고정하고 `scripts/verify.sh`가 통과한다.

## 주요 의사결정
- 2026-11-28: 선택 표시는 정본 `BadgeGridCard`의 기존 `selected` 링을 재사용한다(새 변형 없음).
- 2026-11-28: «추가됨» 제거는 등급 UP 재료 시트에만 적용한다. 레시피 믹서 가방의 «추가됨» 칩은 사용자가 따로 요청하지 않아 그대로 둔다.
- 2026-11-28: 고정 등급 안내 줄(「지금은 … 배지만 넣을 수 있어요」)은 유지한다. 다른 등급 묶음이 흐려진 까닭을 말 없이 두지 않기 위해서다.

### 구현 내용 요약
- 결과 공개(`TierUpGachaStage.tsx`·`.module.css`): «한 번 더»를 고정 위치(`.again`, `againIn`)에서 빼고 `TierUpGachaResultMeta`의 마지막 항목으로 옮겼다. 3단계에서 숨긴 측정용 묶음을 `flushSync`로 그려 묶음과 버튼 높이를 `offsetHeight`로 재고, `.stage` 하단 여백(`getComputedStyle`)을 뺀 자리에 들어오도록 `cy`를 올린다. 이상값은 무대 높이의 40%이고 하한은 `MIN_CY=110`이다.
- 재료 시트(`tierUpClient.ts`): `buildTierUpSheet`가 첫 재료 뒤에도 `kind: 'groups'`를 돌려주고 뷰에 `locked`를 담는다. 고정 등급 묶음은 고른 셀이 `selected`, 나머지가 `active`이고, 다른 등급 묶음은 모두 `inactive`다. `kind: 'locked'`와 셀의 `used`는 지웠다. 고른 셀은 묶음이 6개 밑으로 줄어도 `selected`로 남겨 다시 눌러 뺄 수 있게 했다.
- `BagItemCell.tsx`: `selected` 상태를 더해 `BadgeGridCard`의 `selected`(블랙 2px 링)와 `pressed`를 켠다. 그림은 컬러, 칩은 없다. `releasable`은 지웠다. 레시피 믹서의 `used`(«추가됨» 칩)는 그대로다.
- `TierUpPanel.tsx`: `locked` 갈래를 지우고 묶음 보기 하나로 그린다. 고정 등급이 있으면 묶음 위에 안내 줄을 한 번 그린다.
- 채원① 판정: 재사용(`BadgeGridCard` 수정 없음, 새 토큰·정본·변형 없음, 승인 항목 없음).
