# [UI] 등급 UP «한 번 더» 버튼이 눌리지 않는 회귀와 TopNav 원형 버튼 네거티브를 고친다

## 핵심 요약

- 요구사항(사용자 보고 2026-11-28, staging 실기기): ① 결과 공개 화면(Common 6개 → «한줄로 걸린 양말»)에서 «한 번 더»가 눌리지 않는다. ② 등급 UP 화면 TopNav의 동기화·알림 원형 버튼도 네거티브(어두운 원 + 흰 아이콘)로 바꾼다.
- 구현 계획:
  - ① `TierUpGachaStage.tsx`의 `TierUpGachaResultMeta`에서 «한 번 더» 래퍼에 `pointerEvents`를 보일 때만 `auto`로 준다. 결과 영역 `.reveal`이 `pointer-events: none`이라, 티켓 20261128_1203에서 버튼을 그 안(`.meta`)으로 옮긴 뒤 터치를 받지 못했다.
  - ② `gachaTheme.ts`의 `TIER_UP_NAV_STYLE`에 `--border`를 어두운 반투명 흰색으로 덮어쓴다. `SyncIconButton`·`NotificationBell`의 원은 `bg-border text-foreground`이고 Tailwind 테마가 `@theme inline`이라 헤더 범위의 변수 덮어쓰기가 그대로 먹는다. 글자색 `--foreground`는 이미 흰색이다. DS 컴포넌트는 고치지 않는다(가차머신 하드코딩 원칙, 사용자 지시 2026-11-27).
- 관련 파일: `jam-web/src/app/(main)/combine/TierUpGachaStage.tsx`(`TierUpGachaResultMeta`의 «한 번 더» 래퍼), `jam-web/src/app/(main)/combine/gachaTheme.ts`(`TIER_UP_NAV_STYLE`)

## 배경 / 문제 정의
티켓 20261128_1203이 만든 회귀(①)와, 티켓 20261127_2225의 TopNav 네거티브 처리에서 원형 버튼 배경이 빠진 것(②)이다.

## 완료 조건
- 결과 공개 뒤 «한 번 더»를 누르면 머신이 돌아온다.
- 등급 UP 화면 TopNav의 동기화·알림 원이 어두운 배경에 흰 아이콘이다. 다른 화면의 TopNav는 그대로다.
- 변경 파일 eslint와 combine 시험이 통과한다.
