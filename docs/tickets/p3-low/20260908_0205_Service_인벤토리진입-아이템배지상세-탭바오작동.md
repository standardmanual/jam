# [bug] 인벤토리에서 아이템배지 상세 진입 시 TabBar가 "배지" 탭을 활성화한다

## 배경 / 문제 정의

인벤토리 탭에서 아이템배지 카드를 눌러 상세 화면에 들어가면, 하단 TabBar는 "인벤토리" 탭이
아니라 **"배지" 탭**을 활성 상태로 표시한다(사용자 스크린샷으로 확인).

### 원인

티켓 [20260907_2059](20260907_2059_UI_아이템배지-개체별-상세라우팅-및-장착개체-선택.md)에서
`/inventory/[itemId]`가 `/badges/{badge_id}?item={itemId}`로 redirect하도록 바뀌었다. 그 결과
`TabBar`가 보는 최종 pathname은 항상 `/badges/...`라, 어디서 진입했든 기본 규칙(`isPathActive`)이
"배지" 탭을 켠다.

컬렉션 상세(`/collections/[id]?from=badges`)에는 "배지 탭에서 왔다"는 신호가 있어 `TabBar.tsx`의
`fromBadges` 분기가 이를 읽지만, 인벤토리 리다이렉트에는 **그런 신호가 URL에 없다** —
`inventory/[itemId]/page.tsx`가 `&from=...` 없이 `?item=`만 붙여 redirect한다.

`TabBar.tsx:144`의 주석("`/inventory/[itemId]?from=badges`")은 **이미 실효 없는 옛 케이스**다 —
그 URL을 실제로 만드는 곳이 코드베이스 어디에도 없다(20260907_2059 이전, `/inventory/[itemId]`가
아직 redirect가 아니라 실화면이던 시절의 흔적으로 추정).

## 상세 요구사항

### 서비스/코드베이스 관점
- `inventory/[itemId]/page.tsx`의 redirect에 진입 출처 표시를 추가한다(`&from=inventory`).
- `TabBar.tsx`에 `fromInventory` 판정을 추가한다 — `fromBadges`와 대칭되는 형태:
  `pathname.startsWith('/badges') && searchParams.get('from') === 'inventory'`이면
  `isActive()`가 `/inventory`만 참을 반환하게 한다.
- `TabBar.tsx:144`의 실효 없는 주석("`/inventory/[itemId]?from=badges`")을 현재 상태에 맞게
  정정한다(그 케이스는 더 이상 만들어지지 않음).

### 회귀 확인 포인트
- 컬렉션 상세(`/collections/[id]?from=badges`)에서 "배지" 탭이 그대로 활성 유지되는가
  (이번 변경과 무관한 경로)
- 컬렉션 슬롯에서 장착 배지를 눌러 `/badges/{id}?item=...`로 이동했을 때 "배지" 탭이 그대로
  활성 유지되는가(이 경로는 `from` 파라미터를 안 실으므로 영향받지 않아야 한다)
- 타인 프로필 열람(`?u=`) 중인 배지 상세에서 기존 `viewingOtherUser` 동작(탭 비활성)이
  이번 변경과 충돌하지 않는가
- 인벤토리 카드를 눌러 들어간 상세에서 "인벤토리" 탭이 활성화되는가(이번 수정의 핵심)
- 배지 탭 → 배지 목록 → 상세로 직접 들어간 경우(`from` 파라미터 없음) "배지" 탭이 그대로
  활성 유지되는가

## 구현 계획

**DB 변경 없음.** 2개 파일, 로직 변경 폭이 작아 파이프라인 없이 오케스트레이터가 직접 처리한다.
