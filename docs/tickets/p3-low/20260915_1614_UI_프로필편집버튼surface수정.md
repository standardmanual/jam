# [UI] 프로필 페이지 — 편집 버튼이 어두운 배경 위에서 거의 안 보임

## 배경 / 문제 정의

프로필 페이지 상단(닉네임·포인트 옆) "편집" 버튼이 어두운 배경 위에서 거의 안 보인다는
사용자 보고(스크린샷 확인).

## 사전 조사 결과

`ProfileClient.tsx`가 공용 `Button`(`src/components/ui/Button.tsx`)을
`surface="sub" variant="outline"`로 쓰고 있었다. `Button.tsx` 상단 주석에 명시된 대로
`surface`는 "이 버튼이 놓인 배경"을 뜻한다.

- `sub`(라이트 배경 위): outline = 4% 블랙 틴트 채움 + **검정 텍스트**
- `main`(다크 배경 위): outline = `--color-surface-elevated` 채움 + **흰 텍스트**

편집 버튼이 실제로 놓인 곳은 프로필 페이지 상단의 **어두운 배경** 영역인데
`surface="sub"`(라이트 배경 전용, 검정 텍스트)를 써서 어두운 배경 위에 검정에 가까운
글자가 거의 안 보이는 상태였다 — 버튼 자체의 디자인 결함이 아니라 이 위치에 맞지 않는
`surface` 값을 쓴 게 원인.

## 경미 수정 판정

컴포넌트 prop 값 하나(`surface="sub"` → `surface="main"`)만 바꾸는 원인-결과가 1:1로
명확한 변경이라 `/jam-work` 0.1절 기준 경미 수정으로 처리했다(Workflow 파이프라인 생략,
오케스트레이터 직접 구현). 신규 UI가 아니라 기존 공용 컴포넌트의 올바른 사용법으로
되돌리는 수정이라 MODULAR 탐색 단계도 해당 없음.
