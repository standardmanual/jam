# [Admin] 미션 관리 목록 테이블에 노출 설정값 표시

## 배경 / 문제 정의
어드민 미션 관리 목록에서 각 미션의 `exposure_mode`(노출 설정: 숨김/시작일 노출/예약 노출)를
확인하려면 개별 미션의 편집 폼을 열어야 했다. 목록만 보고는 어떤 미션이 숨김 상태인지
알 수 없어 운영 효율이 떨어졌다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `MissionTable.tsx` 목록에 `exposure_mode` 값을 뱃지로 표시하는 컬럼 추가
- `scheduled` 모드일 때는 `exposure_at` 날짜도 함께 표시

## 구현 계획
- `MissionForm.tsx`에 이미 정의돼 있던 `exposureModes` 라벨 매핑 배열을 export해 재사용
  (중복 정의 방지)
- `MissionTable.tsx`의 `status` 컬럼과 동일한 뱃지 패턴으로 `exposure` 컬럼 추가
- 0.1절 경미 수정 기준(파일 1~2개, diff 10줄 내외, 원인·수정 내용이 조사 없이 설명 가능)에
  해당해 Workflow 파이프라인 없이 오케스트레이터가 직접 구현

---
## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `MissionForm.tsx`: 지역 상수였던 `exposureModes`를 `export const`로 변경
- `MissionTable.tsx`: `exposureModes`를 import해 `status` 컬럼 뒤에 `exposure`(노출) 컬럼 추가.
  `hidden`은 회색, 그 외(`start_date`/`scheduled`)는 하늘색 뱃지로 구분. `scheduled`이고
  `exposure_at`이 있으면 날짜를 뱃지 안에 함께 표시

### 변경된 파일
```
jam-web/src/app/admin/missions/MissionForm.tsx
jam-web/src/app/admin/missions/MissionTable.tsx
```
