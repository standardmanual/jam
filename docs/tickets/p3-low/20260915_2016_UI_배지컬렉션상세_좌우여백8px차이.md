# [UI] 배지·컬렉션 상세화면 카드 좌우 여백 8px 불일치

## 배경 / 문제 정의
티켓 20260915_2006(컬렉션 상세화면을 배지 상세화면 카드 구조에 맞추는 작업)의 게이트
리뷰 과정에서 발견된 범위 밖 이슈. 컬렉션 상세 카드의 좌우 여백은 페이지 컨테이너의
`px-4`(16px)에 의존하는 반면, 배지 상세 카드는 컴포넌트 자체 `px-6`(24px) wrapper를
갖고 있어 두 화면의 카드 좌우 여백이 8px 차이난다.

## 상세 요구사항

### UI/UX 관점
- 배지 상세(`BadgeHeroSection.tsx`)와 컬렉션 상세(`ItemBookHeroSection.tsx`)의 카드
  좌우 여백을 통일할지 검토
- 통일한다면 어느 쪽 값(16px/24px)에 맞출지, 혹은 각 페이지 컨테이너 패딩과의 관계를
  함께 정리

## 구현 계획
> 조사 필요 — 두 화면의 페이지 컨테이너 패딩 구조를 먼저 대조해야 한다.
