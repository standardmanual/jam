# [UI] 배지 상세화면 레벨칩 크기가 다른 화면보다 작음

## 배경 / 문제 정의
> 왜 이 작업이 필요한가. 현재 상태와 기대 상태의 차이.

사용자가 배지 상세화면 하단의 "Lv.1" 칩(`BadgeHeroSection.tsx`)이 배지 트리의 무한레벨형
진행률 카드(`BadgeLevelGauge.jsx`)에 뜨는 "Lv.1" 칩보다 작아 보인다고 지적했다.

원인: 두 곳 모두 공통 컴포넌트 `BadgeLevelChip`(`design-system/components/cards/
BadgeLevelChip.jsx`)을 쓰지만, `BadgeLevelGauge.jsx:134`는 `size="md"`(11px)를 명시하는
반면 `BadgeHeroSection.tsx:110`은 `size`를 넘기지 않아 기본값 `sm`(8px)이 적용된다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `BadgeHeroSection.tsx:110`의 `<BadgeLevelChip level={badge.level} />` 호출에
  `size="md"`를 추가해 진행률 카드와 같은 크기로 맞춘다.

## 구현 계획
> 어떻게 구현할지. 접근 방법, 영향 범위, 주요 변경 포인트.

`BadgeHeroSection.tsx` 1개 파일, 1줄 변경. 신규 UI 없음, 기존 컴포넌트의 기존 size variant를
지정하는 것뿐이라 MODULAR 탐색 대상 아님.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
`BadgeHeroSection.tsx`의 `BadgeLevelChip` 호출에 `size="md"`를 추가해, 배지 트리 진행률
카드(`BadgeLevelGauge.jsx`)와 동일한 크기로 통일했다. 로컬 dev 서버에서 레벨형 배지
("걸어온 거리" Lv.2) 상세화면을 직접 렌더링해 칩 크기가 커진 것을 눈으로 확인했다.

### 주요 의사결정 / 핵심 메모
`RarityBadge`(등급형 배지가 같은 자리에 그려질 때)는 여전히 기본값 `sm`(8px)이라, 같은
컴포넌트(`BadgeHeroSection`) 안에서 레벨형은 md, 등급형은 sm으로 크기가 갈리는 잠재적
불일치가 남는다. 이번 요청 범위(레벨칩 크기 불일치)에는 포함되지 않아 별도로 판단하지
않았다 — 필요하면 후속 검토.

- `RarityBadge` 쪽도 `md`로 맞출지는 별도 판단 필요 (위 메모 참고)
