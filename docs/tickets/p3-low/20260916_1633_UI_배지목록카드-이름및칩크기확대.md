# [UI] 배지목록(그리드) 카드의 이름·등급/레벨칩 크기를 배지 트리 수준으로 확대

## 배경 / 문제 정의
> 왜 이 작업이 필요한가. 현재 상태와 기대 상태의 차이.

사용자가 배지목록(`/badges` 액티비티/체크인 탭, `BadgeGridCard`) 그리드 카드의 배지 이름과
등급/레벨칩이 배지 트리(`BadgeStageRail`/`BadgeLevelGauge`) 화면보다 작다고 지적했다.
직전 티켓(20260916_1443, 배지 상세화면 레벨칩)과 같은 종류의 문제다.

원인 조사 결과 최근 커밋에 의한 회귀는 아니었다(이름 13px·칩 기본 sm은 2026-09-09부터
그대로였다) — 배지 트리 쪽 패턴(`BadgeFamilyCardHeader` 16px, `BadgeLevelGauge`의
`BadgeLevelChip size="md"`)과 애초에 크기 체계가 달랐던 것. 사용자가 두 화면을 나란히
비교하며 통일을 요청해 확대로 처리한다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `src/components/ui/BadgeGridCard.tsx`와 병존 구현 `design-system/components/patterns/
  BadgeGridCard.jsx` 둘 다:
  - 이름 폰트를 하드코딩 `13px`에서 `var(--text-small)`(14px) 토큰으로 교체
  - `RarityBadge`·`BadgeLevelChip` 호출에 `size="md"` 추가 (기존 기본값 `sm`에서 확대)

## 구현 계획
> 어떻게 구현할지. 접근 방법, 영향 범위, 주요 변경 포인트.

파일 2개(서비스 컴포넌트 + 병존 DS 컴포넌트), 각 2줄 내외 변경. 신규 UI 없음 — 기존
컴포넌트의 기존 size variant 지정 + 하드코딩 px를 기존 토큰으로 교체하는 것뿐이라 MODULAR
탐색 대상 아님.

### 주요 의사결정 / 핵심 메모
이름 크기를 배지 트리와 완전히 같은 16px이 아니라 14px(`--text-small`)로 선택한 이유:
그리드가 3열(`grid-cols-3`)이라 카드 폭이 좁아(최대 90px), 16px까지 올리면 2줄 줄바꿈이
잦아지고 카드 높이가 흔들릴 위험이 있다. 14px은 기존 대비 눈에 띄게 커지면서도 좁은 카드
폭에서 줄바꿈 리스크를 낮게 유지한다.

`BadgeTrophyGridCard.tsx`(컬렉션 탭 등 다른 그리드 카드 변형)는 이번 요청 범위(사용자가
지적한 액티비티 탭 화면)에 포함되지 않아 건드리지 않았다.

### 잔여 이슈
- `BadgeTrophyGridCard.tsx`도 같은 이름/칩 크기 문제가 있는지는 별도 확인 필요
