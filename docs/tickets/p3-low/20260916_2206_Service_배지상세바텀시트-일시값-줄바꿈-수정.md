# [Service] 배지 상세 바텀시트 "체크인 지점"·"일시" 값이 2줄로 감싸지는 문제 수정

## 배경 / 문제 정의
마이페이지 > 최근 활동에서 배지를 탭하면 뜨는 상세 바텀시트(`FeedSection.tsx`의
`DetailSheet`/`Row`)에서, "일시" 같은 긴 값(예: "2026년 9월 8일 오후 7시 34분")이
`max-w-[60%]` 제약 때문에 2줄로 줄바꿈됐다. 경미 수정 기준(파일 1개, diff 2줄, 원인-결과
1:1 명확)에 해당해 오케스트레이터가 직접 처리했다.

## 상세 요구사항
### 서비스/코드베이스 관점
- `jam-web/src/app/(main)/FeedSection.tsx`의 `Row` 컴포넌트(라벨-값 쌍, 배지 상세
  바텀시트 전반에서 재사용 — 체크인 배지뿐 아니라 전체 배지 상세에 공통 적용)에서 값
  `<span>`의 `max-w-[60%]`를 제거하고 `whitespace-nowrap`으로 바꿔 한 줄을 유지하게 하고,
  라벨 `<span>`에는 `shrink-0`을 추가해 라벨이 줄어들지 않도록 한다.

## 구현 계획
`Row` 컴포넌트의 className 2줄만 수정.
