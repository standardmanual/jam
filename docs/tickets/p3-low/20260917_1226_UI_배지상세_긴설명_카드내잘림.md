# [UI] 배지 상세 카드 내 긴 설명 텍스트 잘림 가능성

## 배경 / 문제 정의
티켓 20260917_1211(배지 상세 카드 1:1 비율 확장 및 설명 통합) 작업 중 발견된 범위 밖
이슈. 이미지 크기(200×200)를 최우선으로 유지하고 요소 간 간격만 줄이는 방식으로 구현했기
때문에, 문장 수가 많은(설명이 매우 긴) 배지의 경우 1:1 카드 안에서 `overflow-hidden`으로
텍스트 일부가 잘릴 수 있다.

실제 배지 설명 컨텐츠 샘플 대부분은 짧아 당장 문제되지 않을 것으로 보이나, 향후 긴 설명을
가진 배지가 추가될 경우를 대비해 처리 방침을 정할 필요가 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/(main)/badges/[id]/BadgeHeroSection.tsx`의 설명 영역
  (`flex-1 min-h-0 overflow-hidden`)에서 실제 최장 설명 배지를 스테이징에서 렌더링해
  잘림 여부를 시각 확인한다.
- 잘림이 실제로 발생하면 다음 중 하나로 대응 방향을 정한다:
  - 설명 영역만 내부 스크롤 허용
  - 설명 길이에 따라 폰트 크기 축소
  - 컨텐츠 작성 가이드에 최대 글자 수 제한 명시 (컨텐츠 관점 해결)

## 구현 계획
> 스테이징 반영 후 최장 설명 배지로 실제 화면 확인 → 잘림 발생 여부에 따라 대응 방식 결정.
