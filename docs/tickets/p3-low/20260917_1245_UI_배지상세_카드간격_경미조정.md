# [UI] 배지 상세 페이지 카드 간격 경미 조정

## 배경 / 문제 정의
사용자(디자이너)가 배지 상세 페이지 스크린샷에 직접 표시해 요청한 두 가지 간격 조정.

1. `BadgeHeroSection.tsx`의 등급칩+배지이름 블록과 그 아래 설명 블록 사이 간격이 멀어
   보임 — 설명 블록의 `pt-2`(8px)가 이 간격을 만듦.
2. 배지 상세 페이지에서 "획득 조건" → "획득 정보"(또는 "획득 정보" → "획득 이력·컬렉션
   링크") 같은 카드 사이 세로 간격이 너무 넓음 — 인접한 두 섹션 wrapper가 각각
   `pb-[32px]`/`pt-[32px]`를 가져 경계에서 64px가 합산됨. 사용자는 26px 정도로 줄이고
   싶어 하며, 간격 토큰 중 유사한 값 사용을 요청함(가장 가까운 토큰: `--spacing-24`
   24px, 양쪽에서 절반씩 나눠 적용하면 `--spacing-12` 12px×2=24px).

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/app/(main)/badges/[id]/BadgeHeroSection.tsx`: 설명 블록의 `pt-2` → `pt-1`
- `jam-web/src/app/(main)/badges/[id]/page.tsx`: 배지 3변형(체크인·액티비티·아이템)에서
  섹션 경계의 `pb-[32px]`/`pt-[32px]`를 `pb-[var(--spacing-12)]`/`pt-[var(--spacing-12)]`로
  교체 (경계당 32+32=64px → 12+12=24px). 페이지 최하단 여백(`pb-[40px]`)은 카드 간
  간격이 아니므로 유지.

## 구현 계획
경미 수정으로 분류(파일 2개, 각 변경이 클래스명 치환 수준으로 원인-결과 명확) — jam-developer
위임 없이 오케스트레이터가 직접 처리.

### 주요 의사결정 / 핵심 메모
- 26px 정확히 맞추는 토큰은 없어 가장 가까운 `--spacing-24`(24px)를 채택. 경계 양쪽에 있는
  두 섹션이 각각 패딩을 갖는 구조라, 24px를 절반씩(`--spacing-12` 12px×2) 나눠 적용.
- 페이지 최하단 여백(`pb-[40px]`)과 히어로-이미지 내부 간격은 이번 요청 범위(카드-카드 간
  간격)에 해당하지 않아 그대로 유지.

### 잔여 이슈
- staging 배포 후 실제 화면에서 26px 근사치가 시각적으로 적절한지 확인 필요

### 보완 (2026-09-17), 1차
- 최초 수정(`pt-2`→`pt-1`)은 사용자 확인 결과 **전혀 반영되지 않음**. 원인: 설명 블록에
  `justify-center`가 걸려 있어 `flex-1`로 확보된 남은 공간(카드 하단까지)의 정중앙에 텍스트가
  배치되는 구조였다 — `pt` 값을 줄여도 컨테이너가 남은 공간 전체를 기준으로 중앙 정렬하므로
  시각적 차이가 거의 없었음.
- 수정: `BadgeHeroSection.tsx`의 설명 컨테이너를 `justify-center` → `justify-start`로 변경.
  이제 설명이 이름/등급칩 블록 바로 아래(`pt-1` 간격)에 붙고, 남은 공간은 카드 하단에 남는다.

### 보완 (2026-09-17), 2차
- 사용자 피드백: "설명이 위로 붙는 게 아니라 등급칩과 배지이름이 아래로 붙어야 한다." 1차
  보완은 이름 블록을 이미지 바로 아래(`flex-shrink-0`)에 고정한 채 설명만 끌어올린 것이라,
  실제로는 이름이 이미지에 붙어 있고 두 텍스트 블록의 관계만 바뀐 것처럼 보였다.
- 수정: 등급칩+이름 블록과 설명 블록을 하나의 `flex-1 justify-end` 그룹으로 묶었다. 이제
  이미지와 텍스트 그룹 사이의 남는 공간이 이미지 아래쪽에 모이고, 텍스트 그룹(칩+이름+설명)
  전체가 카드 하단 쪽으로 내려가 붙는다. 그룹 내부 간격(칩+이름 ↔ 설명)은 `gap-1`(4px)로 유지.
