# [Service] badgeProgressText.ts 주석의 옛 문구 드리프트 정리

## 배경 / 문제 정의
티켓 `20260918_0420`(에이전트 팀 도입 ① 선행 정리) 진행 중 게이트 리뷰(conservative-reviewer)가
발견한 범위 밖 항목이다.

`jam-web/src/lib/badgeProgressText.ts`의 주석(51, 104, 190, 207, 275, 424, 579, 599행 등)이
여전히 옛 문구("진행 표시 준비 중", "직전 동기화보다 ...")를 인용하고 있다. 실제 사용자 노출
문구는 티켓 `20260916_0734`에서 `ko.ts`가 이미 갱신되어 바뀌었지만, 이 파일의 주석은 함께
갱신되지 않았다.

동작에는 영향이 없는 문서 드리프트이며, 방치하면 향후 코드를 읽는 사람(또는 에이전트)이
주석만 보고 실제 문구를 오판할 위험이 있다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `jam-web/src/lib/badgeProgressText.ts`의 51·104·190·207·275·424·579·599행 등 옛 문구를
  인용하는 주석 전체를 `jam-web/src/lib/i18n/ko.ts`의 현재 `d.badges` 문구와 일치시킨다
- 코드 동작(로직) 변경은 없다 — 주석 텍스트만 수정

## 구현 계획
1. `badgeProgressText.ts`에서 옛 문구를 인용하는 주석 전체를 grep으로 찾는다
2. 각 주석을 `ko.ts`의 현재 문구로 갱신한다
3. `cd jam-web && npm test`로 회귀 없음을 확인한다 (로직 변경이 없으므로 결과는 그대로여야 한다)

## 완료 조건
- `badgeProgressText.ts` 주석이 `ko.ts` 현재 문구와 일치한다
- `npm test`가 기존과 동일하게 통과한다
