# [Infra] 개인 메모리의 운영 규칙을 처리 규칙표로 이관

## 핵심 요약
- 요구사항: 개인 메모리에 있는 프로젝트 운영 교훈을 `handling-rules.md`로 옮기고 메모리에서는 지운다.
- 구현 계획: 메모리 `project_*` 파일을 하나씩 분류해 운영 교훈은 규칙표 한 줄로 옮기고, 개인 선호는 메모리에 남긴다.
- 관련 파일: `.claude/skills/jam-work/references/handling-rules.md`, 개인 메모리(`~/.claude/projects/.../memory/`)
- 상위 티켓: [20260918_1101 에이전트 팀 운영 정비](../p1-high/20260918_1101_Infra_에이전트팀-운영정비-상위.md)
- 선행 티켓: 없음
- 경로: ① 카리나 직접 (개인 메모리는 저장소 밖이라 워크트리 에이전트가 만질 수 없다)

## 배경 / 문제 정의
같은 교훈이 메모리와 규칙표 두 곳에 있으면 어긋나고, 다른 PC는 메모리 쪽을 모른다. 안건 0-5에서 운영 규칙의 원본을 규칙표로 정했다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `project_*` 메모리(작성 시점 13개)를 운영 교훈 / 개인 선호 / 이미 문서에 있는 사실로 분류한다
- 운영 교훈은 `handling-rules.md`에 한 줄씩 추가하고 메모리 파일과 `MEMORY.md` 색인에서 지운다
- `feedback_*`·`user_*` 중 사용자 개인 선호는 메모리에 남긴다
- 이 작업은 메인 세션이 staging에서 직접 처리한다

## 구현 계획
메모리마다 옮길 곳을 표로 먼저 정리해 사용자에게 보여 준 뒤 옮긴다.

## 완료 조건
- `MEMORY.md`에 운영 교훈(티켓 번호 충돌·리베이스 동기화·격리 워크트리 등)이 남아 있지 않다
- 옮긴 교훈이 모두 `handling-rules.md`에 한 줄씩 있다 (완료 기록에 대응표를 남긴다)
- 개인 선호 메모리는 그대로 남아 있다
