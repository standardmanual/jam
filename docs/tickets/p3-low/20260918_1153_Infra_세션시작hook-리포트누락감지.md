# [Infra] 세션 시작 hook의 리포트 누락 감지

## 핵심 요약
- 요구사항: 예정 시각이 지났는데 이번 주·이번 달 리포트가 없으면 세션 시작 hook이 알린다.
- 구현 계획: `ticket-dashboard.mjs`에 `Reports/` 파일 존재 검사를 추가한다.
- 관련 파일: `scripts/ticket-dashboard.mjs`
- 상위 티켓: [20260918_1101 에이전트 팀 운영 정비](../P1-중요/20260918_1101_Infra_에이전트팀-운영정비-상위.md)
- 선행 티켓: 20260918_1146 (같은 스크립트), 20260918_1152 (Reports 폴더), 20260918_1155 (예약 시각 확정)
- 경로: ③ 표준 (infra 유형이라 채원 없이 아현→민지)

## 배경 / 문제 정의
예약 작업이 통째로 실패하면 리포트 파일이 아예 없어 아무도 모른다(상위 티켓 4-10).

## 상세 요구사항

### 서비스/코드베이스 관점
- 주간: 월요일 예약 시각이 지났는데 이번 주 `Reports/주간/YYYY-Www.md`가 없으면 경고 한 줄을 출력한다
- 월간: 1일 예약 시각이 지났는데 이번 달 `Reports/월간/YYYY-MM.md`가 없으면 경고 한 줄을 출력한다
- 예약 작업이 꺼져 있으면 경고하지 않는다 (켜짐 여부를 판단할 기준을 문서에서 읽는다)
- 카리나는 이 경고를 다음 세션 첫 보고로 알린다
- 카리나 카드 마커(`<!-- CARD:START -->`·`<!-- CARD:END -->`)를 찾지 못하면 카드를 조용히 건너뛰지 말고 경고 한 줄을 출력한다 (1146 민지 발견물)

## 구현 계획
예약 시각은 `scheduled-jobs.md`의 값을 기준으로 한다. 시각은 KST로 계산한다.

## 완료 조건
- 이번 주 리포트 파일이 없고 예약 시각이 지난 상태에서 hook을 실행하면 경고가 나온다
- 파일이 있으면 경고가 나오지 않는다
- 예약 작업이 꺼져 있으면 경고가 나오지 않는다
