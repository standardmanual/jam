# [UI] TopNav의 JAM 로고를 누르면 홈으로 이동

## 핵심 요약
- 요구사항: TopNav 좌측 JAM 로고를 누르면 홈(`/`)으로 이동한다.
- 구현 계획: 로고 `<Image>`를 `<Link href="/">`로 감싼다. 경로 ①(경미 수정, 카리나 직접).
- 관련 파일: `jam-web/src/components/ui/TopNav.tsx` 121~128 `logoNode` (123행 `<Image src="/jam-logo-white.png">`)

## 배경 / 문제 정의
사용자 요청(2026-09-18). 로고가 이미지로만 렌더링돼 눌러도 반응이 없다. 로고는 `logo=true`인 탭 최상위 화면(홈·배지·미션·인벤토리·드랍)에만 나온다.

## 완료 조건
- 로고를 누르면 `/`로 이동한다
- 옆의 '문의' 버튼 동작은 그대로다
