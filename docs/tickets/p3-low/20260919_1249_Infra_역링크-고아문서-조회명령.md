# [Infra] 역링크·고아 문서 조회 명령

> 상위 티켓: 20260919_1223(문서 체계 정비). 하위 T5. **선행: 20260919_1245(T1), 20260919_1248(T4). 착수 조건: T4 완료 후 사용자에게 필요성을 다시 확인한다.**

## 핵심 요약

- 요구사항: 특정 문서를 링크·`basis`·`related`로 가리키는 문서(역링크)와 어디서도 언급되지 않는 문서(고아)를 조회하는 명령을 만든다. 산출물을 커밋하지 않는다.
- 구현 계획: T1 엔진의 링크 수집 결과를 재사용해 필요할 때 실행하는 조회 명령을 추가한다.
- 관련 파일: T1의 엔진 스크립트(`scripts/`), `docs/specs/DOCUMENT_SCHEMA.md` §5

## 배경 / 문제 정의

`basis`로 적어 둔 상위 문서 관계는 "상위 문서를 바꿀 때 영향받는 문서"를 찾을 때만 값이 난다. 비티켓 문서가 약 70건이라 `grep`으로도 처리할 수 있어서 효용이 아직 불확실하므로 T4 완료 뒤에 필요성을 다시 확인한다. 커밋되는 색인 파일은 병렬 세션 충돌과 낡음 문제로 폐기한 `DASHBOARD.md`를 되풀이하므로 만들지 않는다.

## 상세 요구사항

### 서비스/코드베이스 관점

- `--backlinks <문서 경로>`: 그 문서를 마크다운 링크, `basis`, `related`로 가리키는 문서를 출력한다.
- `--orphans`: 어디서도 링크·`basis`·`related`로 언급되지 않고 태그도 없는 문서를 출력한다. 티켓은 대상에서 제외한다.
- 커밋되는 산출물이 없다. 필요할 때 실행하는 명령이다.
