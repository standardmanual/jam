# [BadgeEngine] Today에서 슬롯이 드랍 제외 배지뿐인 컬렉션이 「0/N 진행 중」으로 보일 수 있다

## 핵심 요약

- 현상: 컬렉션 완성 분모 통일(20260921_1113) 이후, 사용자가 장착한 슬롯이 드랍 제외 배지뿐인 컬렉션은 분자 0, 분모 N으로 계산돼 Today의 진행 중 컬렉션에 「0/N」으로 나올 수 있다.
- 요구사항: Today에 「채운 칸이 1 이상」일 때만 진행 중으로 볼지 정책을 정한다. 티켓에 이 조건이 없어 그대로 두었다.
- 관련 파일: `jam-web/src/lib/today/status.ts`(`buildCollectionProgress`)
- 출처: 티켓 20260921_1113 구현 보고와 게이트 리뷰(민지)의 범위 밖 발견물

## 배경 / 문제 정의

제외 배지는 앞으로 얻을 수 없는데 그 배지만 슬롯에 있는 컬렉션이 「진행 중」으로 보이면 사용자가 진행 상황을 오해할 수 있다. 사용자가 실제로 이 상태에 놓이는지(제외 배지만 장착한 컬렉션이 있는지) 데이터로 확인해 크기를 가늠한 뒤 결정한다.
