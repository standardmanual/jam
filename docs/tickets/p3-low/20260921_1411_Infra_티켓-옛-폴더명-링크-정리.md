# [Infra] 티켓 안의 옛 우선순위 폴더명 링크 정리

## 핵심 요약

- 요구사항: 티켓 파일이 존재하지 않는 옛 폴더명(`P1-중요`, `P2-일반`, `P3-낮음`)을 링크해서 `doc-check --all`이 깨진 링크를 낸다. 링크를 현재 폴더명(`p1-high`, `p2-normal`, `p3-low`)으로 바로잡을지, 이력 문서이므로 그대로 둘지 정한다
- 구현 계획: 조사 후 결정. 이력 보존 원칙과 검사 소음 감소 중 어느 쪽이 나은지 판단한다
- 관련 파일: `docs/tickets/` 전반, `scripts/doc-check.mjs`, `scripts/doc-check.config.json`

## 배경 / 문제 정의

- 2026-09-21 실측(티켓 20260921_1400 게이트 리뷰 중 발견): `docs/tickets/` 안에서 `../P1-중요/` 62건, `../P2-일반/` 58건, `../P3-낮음/` 32건을 링크한다

- 이 티켓은 20260921_1400의 범위 밖이라 분리했다
