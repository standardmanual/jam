# [Infra] INDEX.md 병합 충돌 시 재생성 안내 문서화

## 핵심 요약

- 요구사항: `docs/specs/INDEX.md`가 대상 폴더의 모든 문서 변경과 묶이므로, 서로 다른 브랜치에서 문서를 추가하면 INDEX.md에서 병합 충돌이 날 수 있다. 충돌 시 손으로 풀지 않고 재생성한다는 안내를 남긴다
- 구현 계획: 충돌 시 `node scripts/gen-doc-index.mjs`로 다시 생성한다는 한 줄을 `pre-commit` 차단 메시지와 `handling-rules.md` 카리나 표에 추가한다
