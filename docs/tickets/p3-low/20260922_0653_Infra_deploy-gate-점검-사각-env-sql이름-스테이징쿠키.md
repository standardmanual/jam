# [Infra] `deploy-gate`의 점검 사각을 줄인다 (따옴표 없는 `.env` 대입, 규칙 밖 이름의 `.sql`, 스테이징 쿠키)

## 핵심 요약

- 요구사항: 티켓 20260922_0001에서 만든 `scripts/deploy-gate.mjs`에 민지가 재현한 사각이 셋 있다. (1) 비밀 환경변수 대입 정규식이 따옴표를 요구해서 따옴표 없는 `.env` 형식(`STRAVA_CLIENT_SECRET=<hex 32자>`)과 백틱 문자열 대입을 못 잡는다. 이름과 `=`만으로 걸리던 옛 수동 `grep`이 잡던 형태가 이번에 빠졌다. (2) 번호·seed 이름 규칙 밖의 `.sql`(예: `180a_odd.sql`)은 참고 줄만 남기고 통과한다. (3) `served`가 쿠키를 저장하지 않아 자동 로그인 리다이렉트가 걸린 스테이징(`stage.j-a-m.app`)에서 `redirect count exceeded`(종료 코드 2)로 끝난다.
- 구현 계획: (1) `.env*` 파일(단 `.example`·`.sample`·`.template`은 제외)에서는 따옴표 없는 `NAME=<16자 이상>` 대입도 비밀로 본다. 코드 파일에서는 지금처럼 따옴표 대입만 본다(`process.env.X`류 오탐을 피하려는 이유가 같다). (2) 규칙 밖 이름의 `.sql`을 `others`로 분리해 차단하거나 경고를 키운다. 결정이 필요하다. (3) `served`에 리다이렉트별 쿠키 저장을 넣는다(스테이징에서도 서빙 id를 읽게 하면 롤백 연습 티켓 20260922_0002의 확인이 쉬워진다).
- 관련 파일: `scripts/deploy-gate.mjs`, `scripts/deploy-gate.test.mjs`
- 상위 티켓: 20260922_0001. 출처: 민지 게이트의 범위 밖 발견물. 경로: ③ 표준(infra)

## 배경 / 문제 정의

세 가지 모두 현재 저장소에서는 실제 위험이 아니다. `jam-web`에는 `.env` 계열 파일이 커밋돼 있지 않고(`.env.local`은 무시됨), 모든 마이그레이션이 규칙 안 이름이며, 무인 경로는 프로덕션에만 `served`를 쓴다. 다만 게이트는 "기준을 낮추는 변경을 기계가 막는다"는 목적이라, 옛 수동 점검이 잡던 형태를 조용히 놓치는 (1)은 고칠 가치가 있다.

## 상세 요구사항

### 서비스/코드베이스 관점

1. `.env*`(예시 파일 제외)에서 따옴표 없는 비밀 이름 대입을 잡는 테스트를 만든다(옛 코드에서 실패 확인). `.env.example`의 자리 표시 값(`your_..._here` 등)은 걸리지 않아야 한다.
2. 규칙 밖 이름의 `.sql` 처리 방침을 정한다(차단·경고·현행 유지)하고 테스트로 고정한다.
3. `served`가 자동 로그인 리다이렉트를 따라 스테이징에서도 식별자를 읽게 한다.

## 구현 계획

1. 재현 테스트 → 수정 → `scripts/verify.sh` 통과.

## 완료 조건

### 구현 범위 (게이트 판정 대상)

- 세 사각 각각의 테스트가 옛 코드에서 실패하고 수정 뒤 통과한다. 기존 `deploy-gate` 테스트가 그대로 통과한다. `scripts/verify.sh`가 통과한다.
