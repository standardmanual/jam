# [Admin] 주간 편성 후보안 승인 화면 어드민 이관 (리포트 방식 검증 후)

## 핵심 요약

- 요구사항: 운영자가 주간 리포트 문서 대신 어드민 화면에서 요일별 후보 중 하나를 클릭 한 번으로 고르고 승인하면
  투데이 카드가 등록된다. 전략 변경안·유형 리뷰 승인도 같은 화면에서 처리할지는 착수 시 판단.
- 구현 계획: 리포트 방식(20260923_2258)이 최소 4주 안정 운영된 뒤 착수 여부를 사용자와 다시 정한다. 착수하면 채원
  ①(컴포넌트 재사용 판정) → 아현 → 민지 → 채원 ② 표준 경로.
- 관련 파일: `jam-web/src/app/admin/today/`, `jam-web/src/components/admin/today/`. 스펙: PRD §3 ④·§8.

## 배경 / 문제 정의

사용자 결정: 제안 결과물은 리포트 문서로 시작하고 검증 후 어드민으로 이관한다. 이 티켓은 그 이관의 자리다.

## 상세 요구사항

### UI/UX 관점
- 요일별 후보 A/B/C와 윤진 1픽, 트라이브·유형 분포를 한 화면에서 보고 선택·승인한다.
- 승인 즉시 `today_cards`에 등록되고 유형 ID가 붙는다.

## 구현 계획
