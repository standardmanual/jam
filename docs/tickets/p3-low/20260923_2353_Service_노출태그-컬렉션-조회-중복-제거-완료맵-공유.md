# [Service] 노출 태그 계산의 컬렉션 조회 중복 제거 (완료 맵 공유)

> 티켓 20260923_2253 게이트 리뷰(민지)의 범위 밖 발견물 [구조]에서 자동 생성. P3.

## 핵심 요약

- 요구사항: `jam-web/src/lib/today/exposure.ts`에서 `minRemainingItemBookSlots`(신규)가 `hasIncompleteItemBook`(기존)과 같은 3개 쿼리(슬롯 → 완료 북 → 배지)를 독립적으로 다시 수행한다. 두 함수가 완료 맵을 공유하게 해 `computeUserExposureTags` 호출당 DB 왕복을 줄인다.
- 구현 계획: 컬렉션 진행 상태를 한 번 조회해 잔여 최소값과 미완성 여부를 함께 반환하는 내부 함수로 합치고, 두 태그가 그 결과를 쓰게 한다. 기존 단위 테스트가 그대로 통과해야 한다.
- 관련 파일: `jam-web/src/lib/today/exposure.ts` 97~134행(기존)·167~199행(신규), `jam-web/src/lib/today/__tests__/today-logic.test.ts`.

## 완료 조건

- 유저당 컬렉션 관련 쿼리가 3회로 줄고(현재 6회), 기존 태그 결과와 단위·통합 테스트가 변경 없이 통과한다.

크기 상한: 파일 2개, 60줄 이내.
