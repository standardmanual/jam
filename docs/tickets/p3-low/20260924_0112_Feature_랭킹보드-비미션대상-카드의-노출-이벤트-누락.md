# [Feature] 랭킹보드(미션 대상 아님) 카드의 노출 이벤트가 기록되지 않는다

> 티켓 20260924_0004 게이트 리뷰(민지)의 범위 밖 발견물에서 자동 생성.

## 핵심 요약

- 요구사항: `TodayCardStack.tsx`에서 미션 대상이 아닌 랭킹보드 카드는 `<div>{header}</div>` 분기라 `TodayCardTracker`로 감싸이지 않아 노출 이벤트가 전혀 쌓이지 않는다. 유형 리뷰 집계에서 항상 빠지므로 노출만 추적하도록 감싼다(클릭은 행별 링크라 제외 유지).
- 관련 파일: `jam-web/src/app/(main)/TodayCardStack.tsx` 257행 근방, `jam-web/src/app/(main)/TodayCardTracker.tsx`

## 완료 조건

- 비미션대상 랭킹보드 카드가 화면에 보이면 노출 이벤트 1건이 기록되고 클릭은 기록되지 않는다.

크기 상한: 파일 3개, 60줄 이내.

## 완료 기록

### 구현 내용 요약
경로 ① 경미 수정(카리나 직접). `RankingListCard`에서 미션 대상이 아닌 랭킹보드 카드의 `<div>{header}</div>` 분기를 `<TodayCardTracker cardId={card.id} trackClick={false}>{header}</TodayCardTracker>`로 바꿨다.
`TodayCardTracker`는 자식을 감싸는 순수 `<div>` 하나만 렌더하므로 DOM 구조는 기존과 같고, 노출 이벤트(`impression`)만 새로 쌓인다. 클릭은 행별 링크라 `trackClick={false}`로 제외를 유지했다.
