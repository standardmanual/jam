# [API] 이슈 입력층을 확장한다 (TourAPI·유튜브·빅카인즈 수집기)

> 성공 기준 밖의 확장 과제라 P3로 둔다.

## 핵심 요약

- 요구사항: PRD §7.1이 "자동화 1순위"로 적은 소스 중 아직 없는 세 곳(한국관광공사 TourAPI, 유튜브 Data API, 빅카인즈 Open API)의 수집기를 만든다. 지금 입력층은 기상청·특일정보 2종뿐이다.
- 구현 계획: 소스별 하위 티켓으로 나눈다. 각 수집기는 `jam-web/src/lib/inputs/`에 모듈을 두고 실패 시 null·빈 값으로 폴백하며, 값은 주간 루틴이 읽는 소재 카드 입력 형식(PRD §7.2)과 자동 제외 필터(§7.3)를 통과해야 한다. 외부 호출은 카드 조회 경로 밖에서만 한다(티켓 20260923_2333 방식).
- 관련 파일: `jam-web/src/lib/inputs/`, `docs/service/prd/content-automation/PRD.md` §7.1, `scripts/issue-filter-check.mjs`

## 배경 / 문제 정의

혜린 점검(발견 3·25): PRD는 입력층을 현재형으로 적지만 실제로는 기상청·특일정보 둘뿐이다. T05(지역 축제 소개)가 TourAPI 없이 "공휴일 태그"로 대체돼 편성됐다. 세 수집기는 티켓조차 없었다. 사용자 요청: "티켓 생성해".
