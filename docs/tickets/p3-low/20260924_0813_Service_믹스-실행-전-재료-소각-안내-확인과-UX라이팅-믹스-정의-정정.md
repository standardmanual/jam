# [Service] 믹스 화면이 실행 전에 재료 소각을 안내하는지 확인하고 UX 라이팅 문서의 믹스 정의를 정정한다

> 윈터 검수(2026-09-24)와 윤진 후보안 작성 중 나온 확인 사항이다. T10(픽업 후 미믹스 유도) 카드가 믹스 화면 유입을 늘리기 때문에 확인이 필요하다.

## 핵심 요약

- 요구사항: (1) 믹스 실행 전에 "넣은 재료는 성공·실패와 관계없이 사라진다"는 사실이 화면에서 안내되는지 확인하고, 없으면 안내 문구를 추가한다. (2) `docs/specs/UX_WRITING_GUIDELINE.md` §1.3이 믹스를 "확률에 따라"로 정의하는데 현행 정책(`jam-doc/planning/content/COMBINE_RECIPES.md`)은 레시피가 맞으면 확정 지급이라 어긋난다. 문서를 현행 정책에 맞춘다.
- 구현 계획: `/combine` 화면과 사용자 노출 사전(`jam-web/src/lib/i18n/ko.ts` 근방)에서 실행 전 소각 안내 문구를 찾는다. 없으면 문구 추가는 `copy` 유형으로 채원·윈터 검수를 거친다.
- 관련 파일: `jam-web/src/app/(main)/combine/`, `jam-web/src/lib/i18n/ko.ts`, `docs/specs/UX_WRITING_GUIDELINE.md` §1.3, `jam-doc/planning/content/COMBINE_RECIPES.md`

## 배경 / 문제 정의

이번 주 편성의 T10 카드(9/29, 10/2)는 전원에게 믹스 화면 이동을 유도한다. 윈터는 사용자 노출 사전에서 실행 전 소각 안내를 찾지 못했다고 밝혔다(확인 못 한 것이지 없다는 확정은 아니다).

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 믹스 실행 전 화면에 재료 소각 안내가 있거나, 없으면 추가된다.
- UX 라이팅 가이드 §1.3의 믹스 정의가 현행 정책과 맞는다.

크기 상한: 문서 위주, 문구 추가 시 2파일/20줄.
