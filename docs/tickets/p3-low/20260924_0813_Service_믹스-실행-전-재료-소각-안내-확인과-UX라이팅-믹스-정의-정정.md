# [Service] 믹스 화면이 실행 전에 재료 소각을 안내하는지 확인하고 UX 라이팅 문서의 믹스 정의를 정정한다

> 윈터 검수(2026-09-24)와 윤진 후보안 작성 중 나온 확인 사항이다. T10(픽업 후 미믹스 유도) 카드가 믹스 화면 유입을 늘리기 때문에 확인이 필요하다.

## 핵심 요약

- 요구사항: (1) 믹스 실행 전에 "넣은 재료는 성공·실패와 관계없이 사라진다"는 사실이 화면에서 안내되는지 확인하고, 없으면 안내 문구를 추가한다. (2) `docs/service/writing/UX_WRITING_GUIDELINE.md` §1.3이 믹스를 "확률에 따라"로 정의하는데 현행 정책(`docs/service/content/COMBINE_RECIPES.md`)은 레시피가 맞으면 확정 지급이라 어긋난다. 문서를 현행 정책에 맞춘다.
- 구현 계획(2026-09-24 확인 반영): 사용자 노출 사전(`ko.ts` combine 절)에는 실패 **뒤** 문구(`recipeFail: "재료가 뒤섞이더니 흔적도 없이 사라졌어요"`)만 있고 실행 **전** 소각 안내는 없다. ① 믹스 실행 버튼 근처에 "넣은 재료는 결과와 관계없이 사라진다"는 안내를 추가한다(화면 변경이라 `ui` 유형, 채원 사전 판정). 액티비티·체크인 슬롯은 소모되지 않으므로 아이템 슬롯이 있을 때만 보인다. ② UX 라이팅 가이드 §1.3 믹스 정의는 카리나가 현행 정책(매칭 시 확정 지급, 미매칭 시 고정 포인트, 아이템 재료 소각)으로 고쳤다(2026-09-24).
- 관련 파일: `jam-web/src/app/(main)/combine/`, `jam-web/src/lib/i18n/ko.ts`(1216행 combine 절), `docs/service/writing/UX_WRITING_GUIDELINE.md` §1.3, `docs/service/content/COMBINE_RECIPES.md`

## 배경 / 문제 정의

이번 주 편성의 T10 카드(9/29, 10/2)는 전원에게 믹스 화면 이동을 유도한다. 윈터는 사용자 노출 사전에서 실행 전 소각 안내를 찾지 못했다고 밝혔다(확인 못 한 것이지 없다는 확정은 아니다).

## 결정 기록 (사용자, 2026-09-24)

- 채원 사전 판정 승인: 버튼 아래 캡션 「넣은 재료는 성공·실패와 관계없이 사라져요」(`ko.ts` `combine.burnNotice`), 로딩·비활성 상태에도 항상 노출, 아이템 슬롯이 있는 레시피에서만 노출. 새 컴포넌트·토큰 없이 기존 "버튼 아래 캡션" 패턴(`joinNote`·`withdrawCaption`)을 재사용한다.

### 구현 내용 요약
① 믹스 화면에서 아이템 슬롯이 있는 레시피를 고르면 믹스하기 버튼 바로 아래에 「넣은 재료는 성공·실패와 관계없이 사라져요」를 항상 보인다(로딩·비활성·실패 뒤에도 유지, 액티비티·체크인 슬롯만 있는 레시피와 레시피 탐색 목록에서는 보이지 않음). 문구는 `ko.ts`의 `combine.burnNotice` 한 키로 관리한다. 채원 사전 판정대로 미션 참가 버튼 아래 안내(`joinNote`)와 같은 캡션 패턴을 재사용해 새 컴포넌트·토큰이 없다. ② UX 라이팅 가이드 §1.3의 믹스 정의는 카리나가 현행 정책(레시피 충족 시 확정 지급, 미충족 시 고정 포인트, 아이템 재료 소모)으로 고쳤다.
