## 핵심 요약

- 요구사항: `resolveRange`의 잘못된 from/to 폴백과 from이 to보다 늦은 경우, 노출 0일 때 열람률 null, `contentTypeId`가 null인 이벤트의 `unknown` 버킷, 유형 정렬, 집계 오류 시 500을 검증한다.
- 구현 계획: 코드 수정 없이 테스트만 추가한다. 필요하면 `resolveRange`를 export해 순수 함수 테스트로 확인한다.
