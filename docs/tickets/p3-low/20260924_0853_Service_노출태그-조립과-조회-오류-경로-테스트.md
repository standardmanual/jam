# [Service] 노출 태그 조립과 조회 오류 경로를 테스트로 고정한다

> 티켓 20260924_0811에서 나눈 하위 티켓이다.

## 핵심 요약

- 요구사항: (1) `computeUserExposureTags`가 날씨 값이 있을 때 `weather_${kind}`를, 특일 값이 있을 때 `specialDayTags` 결과를 다른 태그와 함께 내는지 확인한다(지금 통합 테스트는 두 값을 null·빈 배열로 고정해 조립이 검증되지 않는다). (2) `stravaStaleDays`와 `getItemBookProgress` 슬롯 조회가 Supabase `error`를 받지 않아 DB 오류 시 로그 없이 태그가 빠진다. 오류일 때 `console.error` 한 줄을 남기게 하고 테스트로 고정한다.
- 구현 계획: 기존 `exposure-tags-segment.test.ts`의 Supabase 목을 재사용한다. 코드 변경은 `console.error` 추가만이다.
- 관련 파일: `jam-web/src/lib/today/exposure.ts`(110·194·233행 근방), `jam-web/src/lib/today/__tests__/exposure-tags-segment.test.ts`

- 날씨·특일 태그가 실제로 조립되는 테스트가 있다.
