# [API] 한국관광공사 TourAPI로 지역 축제 소재를 수집한다

> 티켓 20260924_0807(입력층 확장)에서 나눈 하위 티켓이다. 세 소스 중 **첫 번째로 추천**한다(T05 지역 소개의 근거, 기존 공공데이터포털 키 재사용 가능).

## 핵심 요약

- 요구사항: 다음 주(월~일)에 열리는 지역 축제·행사를 가져와 주간 편성 후보안의 T05 소재 카드로 넘긴다. 결과는 이슈 필터(PRD §7.3)를 통과한 것만 쓴다.
- 구현 계획(2026-09-24 확정, 사용자 "진행해"): **`scripts/tour-festivals.mjs`(신규)**. ① 순수 함수를 export한다: `nextWeekRangeKst(now)`(다음 주 월~일, `YYYYMMDD`), `overlapsRange(item, from, to)`(`eventstartdate`~`eventenddate`가 기간과 겹침, 양끝 포함), `isSeoul(item)`(`lDongRegnCd === '11'`, 값이 없으면 `addr1`이 "서울"로 시작), `toSourceCard(item, observedAt)`(`issue-filter-check.mjs`의 `CARD_FIELDS` 키로 변환: title=행사명, category="지역 축제", source="TourAPI", validPeriod="YYYY-MM-DD~YYYY-MM-DD", region=`addr1`의 앞 두 단어(예: "서울 강동구"), tribeCandidates="", usagePath="T05", status="후보"). ② CLI `node scripts/tour-festivals.mjs [--from YYYYMMDD --to YYYYMMDD]`(기본 다음 주): `process.env.DATA_GO_KR_API_KEY`로 `searchFestival2`(KorService2, `eventStartDate=<from>`, `numOfRows=100`, `_type=json`)를 `totalCount`까지 페이지로 받고, 기간 겹침·서울만 남긴 뒤 `issue-filter-check.mjs`의 `applyJudgments`로 필터 판정을 채워 **JSON 배열을 표준 출력**에 쓴다. 키 없음·HTTP 오류·결과코드가 `0000`이 아니면 stderr 한 줄과 종료 코드 2, 0건이면 `[]`와 종료 코드 0. **`scripts/tour-festivals.test.mjs`(신규)**: 네트워크 없이 순수 함수만 테스트한다(기간 겹침 경계, 서울 판정 두 방식, 카드 변환, 다음 주 계산). `verify.sh`의 scripts-test가 실행한다. 두 파일 합계 100줄 미만으로 쓴다.
- 확인된 응답 사실(2026-09-24): 서울 행사는 `lDongRegnCd`가 `"11"`이고 `areacode`는 비어 있다(그래서 `areaCode=1` 조회가 0건이었다). 한 페이지 100건 중 서울은 16건이었다. `lDongRegnCd=11`을 요청 인자로 넣어 서버에서 거를 수 있으면 넣되, 응답에서도 한 번 더 거른다.
- 관련 파일: 신규 `scripts/tour-festivals.mjs`·`scripts/tour-festivals.test.mjs`, 재사용 `scripts/issue-filter-check.mjs`(`CARD_FIELDS`·`applyJudgments`, 가져올 때 CLI가 실행되지 않는지 확인). PRD §7.1·§15와 `scheduled-jobs.md`는 카리나가 머지 뒤 갱신한다(이 티켓에서 고치지 않는다).

## 사전 확인 (2026-09-24)

- 사용자가 공공데이터포털에서 「한국관광공사_국문 관광정보 서비스_GW」 활용신청을 마쳤다. 기존 `DATA_GO_KR_API_KEY`로 `searchFestival2`를 호출해 HTTP 200, 결과코드 `0000`, 10/1 이후 진행 행사 전국 241건을 확인했다(오전에는 403).
- `areaCode=1`(서울)로 거르면 0건이다. 전국 결과에는 서울 강동구 행사가 있어, KorService2에서는 지역 필터가 법정동 코드(`lDongRegnCd` 등)로 바뀐 것으로 보인다(추정, 구현 때 확인).
- `eventStartDate`는 그날 이후에도 진행 중인 행사를 돌려준다(9/18 시작 행사가 10/1 조회에 포함). 다음 주 행사를 고를 때 종료일도 함께 본다.
- 남은 사용자 작업: 루틴 연결 시 클라우드 환경 `jam-ops`의 네트워크 허용 목록에 `apis.data.go.kr` 추가.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 다음 주 서울 행사를 조회해 필터 판정이 채워진 소재 카드 JSON 배열로 출력한다.
- 키 미설정·호출 실패는 종료 코드 2와 한 줄 안내, 0건이면 `[]`와 종료 코드 0이다.
- 순수 함수 테스트가 있고 `verify.sh`에서 실행된다.

### 후속 범위 (담당: 사용자·카리나, 시점: 머지 뒤)
- 사용자: 클라우드 루틴 환경 `jam-ops`에 환경변수 `DATA_GO_KR_API_KEY` 등록, 네트워크 허용 목록에 `apis.data.go.kr` 추가.
- 카리나: `scheduled-jobs.md` 주간 절에 수집 단계 연결, PRD §7.1·§15 갱신.

크기 상한: 2파일/100줄 미만.
