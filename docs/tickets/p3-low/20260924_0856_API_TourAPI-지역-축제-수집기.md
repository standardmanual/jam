# [API] 한국관광공사 TourAPI로 지역 축제 소재를 수집한다

> 티켓 20260924_0807(입력층 확장)에서 나눈 하위 티켓이다. 세 소스 중 **첫 번째로 추천**한다(T05 지역 소개의 근거, 기존 공공데이터포털 키 재사용 가능).

## 핵심 요약

- 요구사항: 다음 주(월~일)에 열리는 지역 축제·행사를 가져와 주간 편성 후보안의 T05 소재 카드로 넘긴다. 결과는 이슈 필터(PRD §7.3)를 통과한 것만 쓴다.
- 구현 계획(2026-09-24 확정, 사용자 "진행해"): **`scripts/tour-festivals.mjs`(신규)**. ① 순수 함수를 export한다: `nextWeekRangeKst(now)`(다음 주 월~일, `YYYYMMDD`), `overlapsRange(item, from, to)`(`eventstartdate`~`eventenddate`가 기간과 겹침, 양끝 포함), `isSeoul(item)`(`lDongRegnCd === '11'`, 값이 없으면 `addr1`이 "서울"로 시작), `toSourceCard(item, observedAt)`(`issue-filter-check.mjs`의 `CARD_FIELDS` 키로 변환: title=행사명, category="지역 축제", source="TourAPI", validPeriod="YYYY-MM-DD~YYYY-MM-DD", region=`addr1`의 앞 두 단어(예: "서울 강동구"), tribeCandidates="", usagePath="T05", status="후보"). ② CLI `node scripts/tour-festivals.mjs [--from YYYYMMDD --to YYYYMMDD]`(기본 다음 주): `process.env.DATA_GO_KR_API_KEY`로 `searchFestival2`(KorService2, `eventStartDate=<from>`, `numOfRows=100`, `_type=json`)를 `totalCount`까지 페이지로 받고, 기간 겹침·서울만 남긴 뒤 `issue-filter-check.mjs`의 `applyJudgments`로 필터 판정을 채워 **JSON 배열을 표준 출력**에 쓴다. 키 없음·HTTP 오류·결과코드가 `0000`이 아니면 stderr 한 줄과 종료 코드 2, 0건이면 `[]`와 종료 코드 0. **`scripts/tour-festivals.test.mjs`(신규)**: 네트워크 없이 순수 함수만 테스트한다(기간 겹침 경계, 서울 판정 두 방식, 카드 변환, 다음 주 계산). `verify.sh`의 scripts-test가 실행한다. 두 파일 합계 약 160줄 이내로 쓴다(사용자 승인).
- 확인된 응답 사실(2026-09-24): 서울 행사는 `lDongRegnCd`가 `"11"`이고 `areacode`는 비어 있다(그래서 `areaCode=1` 조회가 0건이었다). 한 페이지 100건 중 서울은 16건이었다. `lDongRegnCd=11`을 요청 인자로 넣어 서버에서 거를 수 있으면 넣되, 응답에서도 한 번 더 거른다.
- 관련 파일: 신규 `scripts/tour-festivals.mjs`·`scripts/tour-festivals.test.mjs`, 재사용 `scripts/issue-filter-check.mjs`(`CARD_FIELDS`·`applyJudgments`, 가져올 때 CLI가 실행되지 않는지 확인). PRD §7.1·§15와 `scheduled-jobs.md`는 카리나가 머지 뒤 갱신한다(이 티켓에서 고치지 않는다).

## 사전 확인 (2026-09-24)

- 사용자가 공공데이터포털에서 「한국관광공사_국문 관광정보 서비스_GW」 활용신청을 마쳤다. 기존 `DATA_GO_KR_API_KEY`로 `searchFestival2`를 호출해 HTTP 200, 결과코드 `0000`, 10/1 이후 진행 행사 전국 241건을 확인했다(오전에는 403).
- `areaCode=1`(서울)로 거르면 0건이다. 전국 결과에는 서울 강동구 행사가 있어, KorService2에서는 지역 필터가 법정동 코드(`lDongRegnCd` 등)로 바뀐 것으로 보인다(추정, 구현 때 확인).
- `eventStartDate`는 그날 이후에도 진행 중인 행사를 돌려준다(9/18 시작 행사가 10/1 조회에 포함). 다음 주 행사를 고를 때 종료일도 함께 본다.
- 남은 사용자 작업: 루틴 연결 시 클라우드 환경 `jam-ops`의 네트워크 허용 목록에 `apis.data.go.kr` 추가.

## 1차 실행 기록 (2026-09-24)

- 아현이 계획대로 두 파일을 써 보니 합계 149줄로 당시 상한(100줄 미만)을 넘어 `plan_only`로 돌려줬다. 순수 함수 테스트는 모두 통과했다. 카리나의 사전 규모 판정이 빗나갔다(범위를 좁히면 100줄 안에 든다고 봤으나, 페이지 넘김·오류 3종·경계 테스트를 합치면 1.5배였다). 사용자가 A안(상한 약 160줄)을 승인했다.
- 격리 작업 공간은 비밀값 파일(`.env.local`)을 읽지 못하게 한 경계가 있어(티켓 20260924_0625) 아현은 실제 TourAPI 호출을 하지 않았다. 실호출 검증은 병합 뒤 카리나가 한다. 카리나가 "로컬 키를 써도 된다"고 지시한 것은 이 경계와 맞지 않는 지시였다.

### 주요 의사결정 / 핵심 메모
- 카리나의 사전 규모 판정이 빗나가 1차가 `plan_only`로 멈췄다(100줄 목표 → 실제 149줄). 사용자가 A안(상한 약 160줄)을 승인했다. 최종 165줄.
- **게이트 PASS만으로는 실제 동작을 보장하지 못했다.** 격리 작업 공간은 비밀값을 읽지 못해 아현·민지 모두 실호출을 못 했고, 카리나의 병합 전 실호출에서 인증 실패를 잡았다. 외부 API를 부르는 코드는 병합 전에 비밀값을 가진 세션이 실호출로 확인한다.
- 카리나가 처음에 아현에게 "로컬 키를 써도 된다"고 지시한 것은 격리 경계(티켓 20260924_0625)와 맞지 않았다.
- 서울 판정은 `areacode`가 비어 있어 법정동 코드(`lDongRegnCd`)로 한다(2026-09-24 응답 확인).
- 연중 상시 행사(1/1~12/31)도 후보에 섞여 나온다. 윤진이 고를 때 뒤로 미루면 된다.
