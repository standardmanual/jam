# [API] 유튜브 Data API로 국내 화제 영상 소재를 수집한다

> 티켓 20260924_0807에서 나눈 하위 티켓이다. 두 번째로 추천한다.

## 핵심 요약

- 요구사항: `videos.list`(`chart=mostPopular`, `regionCode=KR`)로 화제 영상을 가져와 밈·유행 소재 후보로 넘긴다. 메타데이터가 부족한 소재라 윤진 1차·윈터 최종 검수를 거친다(PRD §7.3).
- 구현 계획: `scripts/youtube-trends.mjs`(신규). 월간 트렌드 루틴이 호출한다. **선행(사용자)**: Google Cloud에서 YouTube Data API 키 발급(`YOUTUBE_API_KEY`), 루틴 환경 네트워크 허용 목록에 `www.googleapis.com` 추가.
- 관련 파일: `scripts/`(신규), `docs/specs/prd/content-automation/PRD.md` §7.1, `.claude/skills/jam-work/references/scheduled-jobs.md` 월간 절

- 키 등록 뒤 국내 인기 영상 목록을 소재 카드 형식으로 출력한다.
