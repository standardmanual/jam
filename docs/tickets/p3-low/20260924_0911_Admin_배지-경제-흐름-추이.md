# [Admin] 어드민 메인에 최근 배지 발급량과 앰비언트 드랍 추이를 표시한다

## 핵심 요약

- 요구사항: 최근 7일·30일의 일별 배지 발급량과 앰비언트 드랍 발생량을 캘린더 아래에 표나 막대그래프로 표시한다.
- 구현 계획: 일별 집계 함수를 `jam-web/src/lib/admin/`에 신설한다(배지 발급 테이블과 앰비언트 드랍 테이블을 KST 날짜로 묶음). 그래프 라이브러리를 새로 들이지 않고 CSS 막대로 그린다.
- 관련 파일:
  - `jam-web/src/lib/admin/kpiWeekly.ts` (배지 발급량 집계 방식 참고)
  - `jam-web/supabase/migrations/104_ambient_drop_reintroduce.sql`, `137_ambient_drop_schedule_hour.sql` (드랍 테이블 구조 참고)
  - `jam-web/src/app/admin/page.tsx`
  - 신규: `jam-web/src/lib/admin/economyTrend.ts`, `jam-web/src/app/admin/EconomyTrend.tsx`

## 배경 / 문제 정의

배지 발급이 갑자기 늘거나 줄었는지(포인트 인플레, 드랍 정지) 추이로 확인할 수단이 없다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 조회만 하며 경제 수치는 바꾸지 않는다.
- 어드민 유형이므로 MODULAR를 적용하지 않는다. 조회만 하며 DB 변경은 없다.
- 표시하는 시각은 모두 KST다. 데이터 하나를 불러오지 못해도 해당 영역만 오류 문구를 보이고 페이지 전체는 렌더된다(기존 `serviceError` 패턴).
- 실렌더 검증은 `docs/specs/DEV_PROCESS_GUARDRAILS.md` 패턴 13(로컬 `ADMIN_EMAILS` 셸 환경변수)으로 한다.

## 구현 계획

일별 집계 함수를 `jam-web/src/lib/admin/`에 신설한다(배지 발급 테이블과 앰비언트 드랍 테이블을 KST 날짜로 묶음). 그래프 라이브러리를 새로 들이지 않고 CSS 막대로 그린다.

## 완료 조건

- 7일·30일 전환이 되고, 일별 배지 발급량과 앰비언트 드랍량이 표시된다.
- 특정 날짜의 값이 DB를 직접 집계한 값과 일치한다(검증 SQL을 완료 기록에 남긴다).
- 날짜 묶음(KST 경계) 함수에 단위 테스트가 있다.
