# [UI] 활동 피드 가상 항목 확장과 미션 상단 상태 라벨 우선순위 테스트를 추가한다

> 티켓 20260924_0855를 착수 시 둘로 나눈 앞쪽 절반이다(나머지는 20260924_1147).

## 핵심 요약

- 요구사항: (1) 활동 피드 가상 항목 확장(`hydrate.ts`의 회차별 `flatMap`)의 결과 정렬·id 형식(`{id}::{index}`)·첫 회차에만 `point_reward` 유지와 `user_activity_badges` 조회 오류 시 단건 폴백을 테스트로 고정한다. (2) `MissionsListClient`의 상단 상태 라벨 우선순위(잠김 > 완료 > 참가중 > 시작 전 > 기간)를 테스트로 고정한다.
- 구현 계획: (1) 기존 `jam-web/src/lib/activity-feed/__tests__/hydrate.test.ts`에 케이스를 추가한다. (2) `MissionsListClient.tsx`의 `statusLabel`·`topStatusLabel`(180~205행 근방)은 사전(`d`)과 React 노드에 묶여 있어 node 환경 테스트가 어렵다. 우선순위 판정만 순수 함수(라벨 종류를 문자열로 반환)로 뽑아 별도 파일에 두고, 컴포넌트는 그 결과를 노드로 바꾸기만 한다. 화면 모양과 문구는 바꾸지 않는다.
- 관련 파일: `jam-web/src/lib/activity-feed/hydrate.ts`(128행 근방 `flatMap`), `jam-web/src/lib/activity-feed/__tests__/hydrate.test.ts`, `jam-web/src/app/(main)/missions/MissionsListClient.tsx`(180~205행), 신규 `jam-web/src/app/(main)/missions/missionStatusKind.ts`와 그 테스트

## 완료 조건

- 두 경로가 테스트로 고정된다.
