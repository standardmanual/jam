# [UI] 투데이 카드 추적 전송과 기사 CTA 대상 판정 테스트를 추가한다

> 티켓 20260924_0855를 착수 시 둘로 나눈 뒤쪽 절반이다(앞쪽은 20260924_1146).

## 핵심 요약

- 요구사항: (1) `TodayCardTracker`의 전송 동작(노출 임계 0.5, `sessionStorage` 중복 억제, `sendBeacon` 실패 시 `fetch` 폴백, `trackClick=false`일 때 클릭 미전송)을 테스트로 고정한다. (2) `resolveArticleCtaTarget`의 공백만 있는 `target_href` 처리와 우선순위(target_href > 컬렉션 > 미션 > null)를 테스트로 고정한다.
- 구현 계획: vitest 환경이 `node`(`vitest.config.ts` 31행)라 컴포넌트를 직접 렌더할 수 없다. `TodayCardTracker.tsx`의 `sendTodayCardEvent`(8~24행)와 노출 중복 억제 판정을 컴포넌트 밖의 순수 모듈로 옮기고 컴포넌트는 그 모듈을 호출하기만 한다. 전역(`navigator`·`fetch`·`sessionStorage`)은 `vi.stubGlobal`로 대체한다. 화면 모양과 전송 페이로드는 바꾸지 않는다.
- 관련 파일: `jam-web/src/app/(main)/TodayCardTracker.tsx`, `jam-web/src/lib/today/targetHref.ts`(83~101행 `resolveArticleCtaTarget`), 신규 `jam-web/src/lib/today/cardEventClient.ts`와 그 테스트, `jam-web/src/lib/today/__tests__/`(targetHref 테스트)

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- 두 경로가 테스트로 고정된다.
- 전송 페이로드(`cardId`·`event`)와 노출 임계값(0.5)은 이전과 같다.

크기 상한: 테스트 포함 4파일/90줄.
