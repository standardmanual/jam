# [Admin] 어드민 목록 공통 부품이 네트워크 오류일 때 브라우저 오류 문구를 그대로 보여 준다

## 핵심 요약

- 요구사항: 서버 응답을 받지 못한 실패(네트워크 오류)일 때 표 안 스위치·일괄 처리의 토스트가 고정된 한국어 문장을 보여 주게 한다.
- 구현 계획: `requestJson`·`runBulk`(`jam-web/src/components/admin/data-table/admin-fetch.ts`)에서 `fetch` 자체가 실패한 경우를 잡아
  "[현상] → [원인] → [해결책]" 구조의 문장으로 바꿔 throw한다. `InlineSwitchCell`은 그 메시지를 그대로 쓴다.
- 관련 파일: `jam-web/src/components/admin/data-table/admin-fetch.ts:16,64`, `jam-web/src/components/admin/data-table/data-table-inline-switch.tsx`,
  `docs/specs/UX_WRITING_GUIDELINE.md`

## 배경 / 문제 정의

티켓 20260924_0941의 머지 뒤 실측(카리나, 2026-09-24)에서 확인했다. 요청을 브라우저에서 막았을 때 토스트에 오류 객체의 문구가 그대로
나왔다. 실제 네트워크 장애라면 브라우저 문구(예: 영어 "Failed to fetch")가 노출된다. 서버가 돌려준 오류는 한국어 메시지로 나온다.

## 완료 조건

- `fetch`가 reject될 때 `requestJson`·`runBulk`가 고정 한국어 문장으로 throw한다(단위 테스트, 전역 fetch 스텁).
- 서버가 돌려준 오류 메시지는 지금처럼 그대로 쓴다(단위 테스트).

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- 묶음 티켓 20260926_1241로 처리했다. 상세와 실행 지표는 그 티켓의 완료 기록에 있다.
- `admin-fetch.ts`에 `NETWORK_ERROR_MESSAGE`("현상 → 원인 → 해결책" 구조의 고정 한국어 문장)와 `fetchOrThrow`를 추가했다. `fetch`가 reject되면 이 문장으로 던지고, 호출자가 취소한 `AbortError`는 그대로 던진다. `requestJson`(`runBulk`·`fetchListIds` 포함)과 `downloadResponseAsFile`이 쓴다. 서버가 돌려준 오류 메시지는 종전대로 쓴다. `InlineSwitchCell`은 `error.message`를 이미 그대로 토스트에 써서 수정하지 않았다.
