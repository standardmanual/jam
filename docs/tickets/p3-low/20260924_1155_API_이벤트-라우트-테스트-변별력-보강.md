# [API] 이벤트 기록 라우트 테스트의 변별력 약점 3가지를 보강한다

> 티켓 20260924_0850 게이트(민지)의 범위 밖 발견물이다.

## 핵심 요약

- 요구사항: 0850 테스트가 (1) '2000자 초과' 케이스를 JSON이 아닌 문자열(`'x'.repeat(2001)`)로 보내 길이 검사를 지워도 JSON 파싱 실패 분기가 같은 400을 돌려주므로 회귀를 못 잡는다. 유효한 JSON이면서 2000자를 넘는 본문으로 바꾼다. (2) 순서 중 인증 → 빈도 제한, 빈도 제한 → 본문 경계를 검증하지 않는다. 제한에 걸린 유저의 잘못된 본문이 400이 아니라 429인지 확인한다. (3) 카드 노출 검증 조회 오류 분기(`events.ts` 67행 '카드를 확인할 수 없습니다.')와 비활성·노출 기간 밖 카드 경로가 실행되지 않는다.
- 구현 계획: `jam-web/src/app/api/today/events/__tests__/route.test.ts`에 케이스를 추가한다. 코드는 바꾸지 않는다.
- 관련 파일: `jam-web/src/app/api/today/events/__tests__/route.test.ts`, `jam-web/src/lib/today/events.ts`(67행 근방), `jam-web/src/app/api/today/events/route.ts`
