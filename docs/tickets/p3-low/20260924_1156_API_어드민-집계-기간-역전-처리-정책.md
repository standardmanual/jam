# [API] 어드민 카드 집계 라우트가 from이 to보다 늦은 기간을 어떻게 처리할지 정한다

> 티켓 20260924_0851 게이트(민지)의 범위 밖 발견물이다.

## 핵심 요약

- 요구사항: `GET /api/admin/today/metrics`는 from이 to보다 늦은 역전 구간을 검증·보정하지 않고 집계기에 그대로 넘긴다. 0851 테스트가 이 현재 동작을 고정했다. 400으로 거부할지, 두 값을 맞바꿀지, 현재대로 둘지 정한다. 바꾸면 0851 테스트도 함께 바꾼다.
- 구현 계획: 정책을 정한 뒤 `route.ts`의 `resolveRange`(5~16행)를 고치고 테스트를 갱신한다.
- 관련 파일: `jam-web/src/app/api/admin/today/metrics/route.ts`(5~16행), `jam-web/src/app/api/admin/today/metrics/__tests__/route.test.ts`
