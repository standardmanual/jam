# [Admin] 배지 목록 일괄 비활성화가 이미 비활성인 배지의 비활성화 시각을 덮어쓴다

## 핵심 요약

- 요구사항: 이미 비활성(`deleted_at`이 있는)인 배지를 다시 비활성화해도 원래 비활성화 시각이 바뀌지 않게 한다.
- 구현 계획: `list-bulk`의 `deactivate`에서 `deleted_at is null`인 행만 갱신하고, 이미 비활성인 항목은 "이미 비활성"으로 건너뜀에 넣는다. 단건 PATCH도 같은 성격이라 함께 정리한다.
- 관련 파일: `jam-web/src/app/api/admin/badges/list-bulk/route.ts:81`, `jam-web/src/app/api/admin/badges/[id]/route.ts`(비활성화 분기)

## 배경 / 문제 정의

티켓 20260924_0944 게이트(민지)의 범위 밖 발견물이다(2026-09-24). `deactivate`가 이미 비활성인 배지에도 `deleted_at`을 현재 시각으로 다시 써서 기존 비활성화 시각을 덮어쓴다.

## 완료 조건

- 이미 비활성인 배지를 포함해 일괄 비활성화하면 그 배지는 건너뜀("이미 비활성")으로 보고되고 `deleted_at`이 바뀌지 않는다(단위 테스트, 기록형 스텁).
