# [Infra] 어드민 읽기 스크립트의 조회 실패 「확인 불가」 출력 경로에 테스트를 추가한다

> 티켓 20260924_1502 게이트(민지)의 범위 밖 발견물이다.

## 핵심 요약

- 요구사항: `scripts/admin-api-read.mjs`의 미션·배지 조회 실패 시 「- 공개 미션 점검: 확인 불가 (사유)」 출력은 단위 테스트가 없고 코드 검토로만 확인됐다. 스크립트가 `main()`을 import 즉시 실행하는 구조라 테스트하려면 출력 조립을 순수 함수로 분리해야 한다.
- 구현 계획: `main()`의 출력 조립 부분(공개 미션 점검 줄과 조회 실패 분기)을 `scripts/public-mission-check.mjs`의 순수 함수로 옮기고 `scripts/public-mission-check.test.mjs`에 실패 케이스를 추가한다. 출력 형식은 바꾸지 않는다.
- 관련 파일: `scripts/admin-api-read.mjs`(91~105행 근방), `scripts/public-mission-check.mjs`, `scripts/public-mission-check.test.mjs`

## 완료 조건

- 미션 조회 실패, 배지 조회 실패, 둘 다 실패인 경우의 출력이 테스트로 고정된다.
