## 배경 / 문제 정의

어드민 목록 공통화 상위 티켓(20260924_0916)의 하위 티켓 ⑥ 투데이·랭킹 규칙 게이트에서 나온 [참고] 항목 묶음이다(2026-09-24).

1. [참고] 투데이 export 라우트는 ids 개수 상한과 uuid 형식 검증이 없다. 어드민 전용이고 200개씩 청크로 읽어 당장 문제는 없다. bulk의 idFormat 검증과 다르다 — jam-web/src/app/api/admin/today/export/route.ts:243-250
2. [참고] 기존 PATCH /api/admin/today/[id]가 요청 본문을 검증 없이 update에 넘긴다. 이번 diff에서 새로 생긴 문제는 아니고, 스위치가 이 라우트에 의존한다 — jam-web/src/app/api/admin/today/[id]/route.ts:10-15
3. [참고] 랭킹 규칙 삭제 보호는 조회 후 삭제 사이에 카드가 활성화되는 경우를 막지 못한다(check-then-delete). DB FK가 SET NULL이라 트랜잭션 보호도 없고, 어드민 단독 운영이라 확률은 낮다 — jam-web/src/app/api/admin/ranking-modes/[id]/route.ts:62-66
