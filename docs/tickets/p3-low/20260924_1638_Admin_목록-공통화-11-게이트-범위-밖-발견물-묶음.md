## 배경 / 문제 정의

어드민 목록 공통화 상위 티켓(20260924_0916)의 하위 티켓 ⑪ 어뷰징 게이트에서 나온 [참고] 항목 묶음이다(2026-09-24).

1. [정합성/참고] 검색어 일치 id를 유저·POI 각 100건까지만 잡는다. 넓은 검색어는 결과가 조용히 잘리고 화면에 안내가 없다 — jam-web/src/lib/admin/abusing-list.ts:SEARCH_MATCH_LIMIT
2. [정합성/참고] 등급 전환은 `abusing_logs`에 기록되지 않는다(티켓이 해제만 요구). 누가 언제 soft에서 hard로 바꿨는지 추적할 수 없다 — jam-web/src/lib/abusing/shadow-ban.ts:changeBanLevel
3. [관측/참고] 해제 뒤 로그 기록이 실패하면 지운 행의 유일한 기록이 서버 로그(console.error)에만 남는다 — jam-web/src/lib/abusing/shadow-ban.ts:logAbusingEvents
4. [참고] `bans/bulk`·`poi-blocks/bulk`가 `readBulkRequest`를 써서 티켓 20260924_1555(배포 게이트 오탐)와 같은 유형이다. 머지 뒤 게이트가 걸 수 있다(아현 alerts와 동일).
