# [Admin] 에셋 제너레이터 뷰포트의 이미지·폰트 로드 대기 로직에 테스트를 붙인다

> 티켓 20260924_2157 게이트 WARN 사유와 20260924_2158 범위 밖 발견물(`[테스트]`)을 합쳐 3.2절대로 자동 티켓화했다.

## 핵심 요약

- 요구사항: `AssetGeneratorViewport.tsx`의 이미지 로드 대기(`pendingImageLoadCountRef`·`waitForImageAssets`·캐시 정리)와 폰트
  로드 대기(`pendingFontLoadCountRef`·`waitForFonts`·실패 시 family 제거 후 재시도·`cancelled` 플래그)는 코드 추적으로만
  정합성을 확인했고 자동 테스트가 없다. 회귀를 잡을 테스트를 붙인다.
- 구현 계획: 카운터·대기자·캐시 정리 로직을 뷰포트 컴포넌트에서 순수 모듈(예: `assetLoadTracker.ts`)로 분리해 단위 테스트한다.
  컴포넌트 렌더 테스트(jsdom)는 캔버스 의존이 커서 피한다.
- 관련 파일: `jam-web/src/app/admin/asset-generator/AssetGeneratorViewport.tsx`(이미지 캐시 ref 설명 279~284줄 근처,
  `waitForImageAssets`·`waitForFonts` 구현), 신규 `jam-web/src/app/admin/asset-generator/assetLoadTracker.ts` +
  `__tests__/assetLoadTracker.test.ts`

## 배경 / 문제 정의

2157에서 이미지 로드 완료 전 저장 시 레이어가 빠지는 경합을 카운터·대기자 방식으로 막았고, 2158이 폰트에 같은 패턴을 적용했다.
두 번 다 게이트가 "새 동작은 테스트로 덮여 있다" 기준 미달을 남겼다. 후속 티켓(2159 프리셋 불러오기)이 여러 레이어를 한꺼번에
로드하므로 이 로직의 회귀 위험이 커진다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 추적기: 시작/완료/실패 카운트, `waitUntilIdle()`이 모든 로드가 끝날 때 resolve, 실패 항목 수 조회, 항목 제거 시 캐시·대기자 정리.
- 동작 변화 없이 분리한다(리팩터). 뷰포트의 공개 핸들(`areImageAssetsReady` 등)은 그대로 둔다.

## 구현 계획
1. 추적기 순수 모듈 분리 + 테스트(동시 로드 2건 중 1건 실패, 대기 중 항목 제거, 취소 플래그).
2. 뷰포트가 추적기를 쓰도록 교체. 기존 테스트·CI 통과.

## 완료 조건
- 추적기 단위 테스트가 동시 로드·실패·제거·취소 시나리오를 덮는다(최소 6케이스).
- 뷰포트 동작은 바뀌지 않는다(카리나 실렌더, 머지 뒤: 이미지·텍스트 레이어 추가 직후 PNG 저장 시 대기 후 포함됨).
- `npm run lint`·`npm test` 통과.

### 주요 의사결정 / 핵심 메모
- 추적기를 키별 캐시(`loadMissing`·`prune`)까지 포함하는 하나의 객체로 만들었다. 카운터·대기자만 분리하면 "실패 시 캐시에서
  빼 재시도", "제거 시 캐시 정리"(티켓 요구)를 테스트할 수 없어서다. 이미지와 폰트는 같은 구현에 값 타입만 다르다.
- 동작 변화 없이 옮기는 것이 조건이라 기존 동작의 결함 두 가지는 고치지 않고 그대로 옮겼다(아래 잔여 이슈).

### 잔여 이슈
- `overlayLayers`가 바뀔 때마다 이전 이펙트의 `cancelled`가 true가 된다. 로드 중에 아무 레이어 값이나 바꾸면 그 로드 결과는
  버려지는데 "불러온 키" 표시는 남아 다음 이펙트가 다시 불러오지 않는다 — 이미지·폰트가 그대로 누락될 수 있는 기존 경합.
  테스트 "취소되면 …결과는 캐시에 반영하지 않는다"가 현 동작을 고정한다. 고치려면 취소 시 그 로드가 잡은 키의 표시를 풀어야 한다(별도 티켓 필요).
- 언마운트 이펙트가 진행 카운트를 0으로 되돌리므로(React StrictMode 개발 모드의 마운트-해제-마운트 등), 그 뒤 옛 로드가 끝나면
  카운트가 음수가 될 수 있다. `isIdle`은 `<= 0`으로 판정해 기존과 같게 동작한다.
