# [API] 프리셋 상세·삭제 라우트 테스트에 비관리자 403 분기를 추가한다

> 티켓 20260924_2159 게이트 리뷰에서 민지가 낸 범위 밖 발견물(`[참고]`)을 3.2절대로 자동 티켓화했다.

## 핵심 요약

- 요구사항: `presets/[id]` 라우트 테스트가 `getAdminUser`를 항상 관리자 반환으로 고정해 GET·DELETE의 403 분기가 테스트로 확인되지 않는다(코드 경로는 존재). 목록·저장 라우트 테스트에는 403 케이스가 있으므로 같은 수준으로 맞춘다.
- 구현 계획: `getAdminUser`가 null을 돌려주는 케이스를 GET·DELETE 각각 추가해 403과 "저장소·DB 호출이 일어나지 않음"을 확인한다.
- 관련 파일: `jam-web/src/app/api/admin/asset-generator/presets/[id]/__tests__/route.test.ts`(참고: `presets/__tests__/route.test.ts`의 403 케이스)

## 완료 조건
- GET·DELETE 비관리자 403 테스트 2건이 추가되어 통과한다. `npm run lint`·`npm test` 통과.
