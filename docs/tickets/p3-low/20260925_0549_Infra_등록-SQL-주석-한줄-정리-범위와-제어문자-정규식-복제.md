# [Infra] 등록 기록 SQL 주석의 한 줄 정리를 모든 주석 줄에 적용하고 제어 문자 정규식 복제를 없앤다

> 티켓 20260924_2202 보안 패치 재판정에서 민지가 낸 범위 밖 발견물(`[보안/참고]`·`[구조/참고]`)을 3.2절대로 자동 티켓화했다.

## 핵심 요약

- 요구사항: (1) `buildRegistrationSql`이 SQL `--` 주석 중 머리 3줄에만 `commentSafe`(개행·제어 문자를 공백으로)를 적용한다. 「이미지 파일」 주석 줄과 되돌림 SQL 주석 줄은 거치지 않는다. 지금 그 값은 상수와 `randomUUID()`라 사용자 입력이 닿지 않아 악용 경로는 없지만, 값의 출처가 바뀌면 같은 구멍이 다시 열린다. (2) 개행·제어 문자 범위 정규식이 `registerBundle.mjs`(`CONTROL_OR_LINE_BREAK`)와 `registerRecord.mjs`(`commentSafe`)에 같은 내용으로 두 번 적혀 있어 한쪽만 고치면 어긋난다.
- 구현 계획: SQL 주석에 들어가는 모든 보간 값을 한 함수로 감싼다(주석 줄을 만드는 작은 헬퍼로 모아 누락을 막는다). 정규식은 한 곳(예: `registerBundle.mjs`에서 export)에서 가져다 쓴다. 두 값의 정의가 갈라지지 않도록 기존 테스트에 "모든 주석 줄이 한 줄" 확인을 넣는다.
- 관련 파일: `jam-web/scripts/asset-generator/registerRecord.mjs`(`commentSafe` 79줄 근처, `buildRegistrationSql` 132·145줄의 이미지 파일·되돌림 주석 줄), `jam-web/scripts/asset-generator/registerBundle.mjs`(`CONTROL_OR_LINE_BREAK` 70줄 근처), `jam-web/scripts/asset-generator/__tests__/registerRecord.test.ts`(주석 주입 방어 테스트)

## 완료 조건
- SQL 기록의 모든 주석 줄이 어떤 record 값에서도 한 줄로 유지된다(개행·CRLF·U+2028이 섞인 모든 필드로 확인하는 테스트).
- 제어·개행 문자 정규식의 원본이 한 곳이다. `npm run lint`·`npm test` 통과.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `registerRecord.mjs`에 SQL 주석 줄을 만드는 태그드 템플릿 `sqlComment`를 두고 `buildRegistrationSql`의 모든 `--` 주석 줄(이미지 파일·되돌림 SQL 주석 포함)을 이 태그로 만들게 했다. 보간된 값은 전부 `commentSafe`를 거친다.
- 제어·개행 문자 정규식은 `registerBundle.mjs`의 `CONTROL_OR_LINE_BREAK`를 export해 원본으로 삼고, `registerRecord.mjs`는 그 `.source`에서 연속 구간 치환용 정규식을 만든다(범위를 다시 적지 않는다).
- 테스트: `bundle_id`·`author`·`registered_at`·`badge.name`·`badge.id`·`storage.bucket`·`png_path`·`webp_path` 8개 필드에 개행·CRLF·U+2028·U+2029·U+0085·NUL·ESC를 섞어도 줄 수와 실행되는(`--`로 시작하지 않는) 줄이 그대로임을 확인하고, `registerRecord.mjs` 소스에 범위 문자를 다시 적지 않았음을 확인한다.

### 주요 의사결정 / 핵심 메모
- 태그드 템플릿으로 모은 이유: 주석 줄마다 `commentSafe`를 손으로 감싸면 새 줄에서 빠뜨리기 쉬워서, 보간이 있는 주석 줄은 태그를 거치는 것을 구조로 강제했다.
- 이 티켓 범위는 배지 등록(`registerRecord.mjs`·`registerBundle.mjs`)이다. 묶음 실행 지시가 이 둘로 한정돼 있어 미션·홈피드 쪽 복제는 건드리지 않았다.

### 잔여 이슈
- 미션·홈피드 등록에도 같은 정규식 복제가 남아 있다: `registerMissionRecord.mjs:39`·`registerHomeFeedRecord.mjs:39`(`commentSafe`), `registerMissionBundle.mjs:67`·`registerHomeFeedBundle.mjs:105`(`CONTROL_OR_LINE_BREAK`). 완료 조건의 「원본이 한 곳」은 배지 등록 쌍(`registerBundle.mjs`↔`registerRecord.mjs`)에서만 충족했고 전체 스크립트 기준으로는 미충족이다. 후속 티켓이 필요하다.
