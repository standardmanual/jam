# [UI] 미션 필터 "제작 경로"의 jam-img 옵션이 항상 빈 결과

> 상위 티켓 [20260925_1404](../p2-normal/20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 티켓 [20260925_1407](../p2-normal/20260925_1407_Admin_에셋제너레이터-미션-적용탭-제작경로표시.md)
> 게이트(민지)의 범위 밖 발견물로 자동 생성.

## 핵심 요약

- 요구사항: `MissionFilterBar.tsx`의 "제작 경로" 필터가 배지·미션 공용
  `IMAGE_SOURCE_FILTER_OPTIONS`(3값: `admin-generator`·`agent-generator`·`jam-img`+미상)를 그대로
  쓰는데, `missions.image_source` CHECK 제약은 2값(`admin-generator`·`agent-generator`)만
  허용한다. 운영자가 "아이콘 파이프라인(jam-img)"을 고르면 항상 결과 0건이 떠서 왜 빈 목록이
  나오는지 알 수 없는 papercut이다.
- 구현 계획: 미션 전용 필터 옵션 목록을 따로 만들어(`jam-img` 제외) `MissionFilterBar.tsx`에
  적용하거나, `IMAGE_SOURCE_FILTER_OPTIONS`를 테이블별로 허용값을 받는 함수로 바꾼다.
- 관련 파일: `jam-web/src/app/admin/missions/MissionFilterBar.tsx`,
  `jam-web/src/lib/admin/contentImageSource.ts`

## 배경 / 문제 정의

1407(미션 적용탭) 구현 시 배지·미션 공용 필터 옵션 상수를 그대로 재사용했다. 아현도 이 문제를
인지했으나("해로움 없음"으로 판단해 그대로 진행) 결과 화면에서 운영자가 혼동할 수 있어 별도
티켓으로 분리한다.

## 완료 조건
- 미션 목록 화면의 "제작 경로" 필터에서 `missions.image_source` CHECK가 허용하지 않는 값을
  고를 수 없다(또는 골라도 항상 0건이 되는 대신 필터 자체가 노출되지 않는다).
- `scripts/verify.sh` 통과.
