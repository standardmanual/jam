# [UI] 제작 경로 필터의 jam-img 옵션이 미션·컬렉션·홈피드에서 항상 빈 결과

> 상위 티켓 [20260925_1404](../p2-normal/20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 티켓 [20260925_1407](../p2-normal/20260925_1407_Admin_에셋제너레이터-미션-적용탭-제작경로표시.md)
> 게이트(민지)의 범위 밖 발견물로 자동 생성.
>
> **범위 확장(2026-09-25, 티켓 1411 병합 세션).** 이 티켓은 처음 미션 필터만 다뤘으나, 컬렉션(1409)·
> 홈피드(1411)가 같은 필터 옵션 상수를 그대로 가져다 써서 같은 문제가 세 화면으로 늘었다. 새 티켓을
> 만들지 않고 이 티켓의 범위를 넓혔다. 파일명의 「미션필터」는 옛 범위 그대로다(이름을 바꾸면 링크가
> 끊겨 그대로 둔다).

## 핵심 요약

- 요구사항: 「제작 경로」 필터 옵션 상수 `IMAGE_SOURCE_FILTER_OPTIONS`(3값: `admin-generator`·
  `agent-generator`·`jam-img` + 미상)가 미션·컬렉션·홈피드 목록 화면에서도 그대로 쓰이는데,
  `missions`·`item_books`·`today_cards`의 `image_source` CHECK 제약은 2값(`admin-generator`·
  `agent-generator`)만 허용한다. 운영자가 "아이콘 파이프라인(jam-img)"을 고르면 세 화면 모두 항상
  결과 0건이 떠서 왜 빈 목록이 나오는지 알 수 없다.
- 구현 계획: 테이블별로 허용값을 받는 옵션 목록(예: 함수)으로 바꿔 미션·컬렉션·홈피드는 `jam-img`를
  뺀 목록을, 배지는 3값 목록을 쓰게 한다. 또는 미션·컬렉션·홈피드 전용 상수를 따로 둔다.
- 관련 파일: `jam-web/src/lib/admin/contentImageSource.ts`(`IMAGE_SOURCE_FILTER_OPTIONS` 47행 근방),
  `jam-web/src/app/admin/missions/MissionFilterBar.tsx`,
  `jam-web/src/app/admin/itembooks/ItemBookFilters.tsx`,
  `jam-web/src/app/admin/today/TodayFilterBar.tsx`,
  `jam-web/src/app/admin/badges/BadgesFilterBar.tsx`(배지는 `jam-img`가 유효해 3값 유지)

## 배경 / 문제 정의

### 사실 (2026-09-25 코드·마이그레이션을 읽어 확인한 결과)

- `IMAGE_SOURCE_FILTER_OPTIONS`를 import하는 어드민 필터 컴포넌트는 4개다: `TodayFilterBar`,
  `MissionFilterBar`, `ItemBookFilters`, `BadgesFilterBar`.
- `image_source` CHECK 제약이 허용하는 값: 배지(`186`)는 `admin-generator`·`agent-generator`·
  `jam-img` 3값이고, 미션(`188`)·컬렉션(`189`)·홈피드(`190`)는 `admin-generator`·`agent-generator`
  2값이다.
- 1411 로컬 실렌더(2026-09-25)에서 홈피드 목록 필터 선택지가 「수동 제작·윤진 자동·아이콘 파이프라인·
  미상」 4개임을 확인했다.

### 경위

1407(미션 적용탭) 구현 시 배지·미션 공용 필터 옵션 상수를 그대로 재사용했다. 아현도 이 문제를
인지했으나("해로움 없음"으로 판단해 그대로 진행) 결과 화면에서 운영자가 혼동할 수 있어 별도
티켓으로 분리했다. 이후 1409·1411이 같은 상수를 재사용하면서 대상 화면이 셋이 되었다.

## 완료 조건
- 미션·컬렉션·홈피드 목록 화면의 "제작 경로" 필터에서 해당 테이블의 `image_source` CHECK가
  허용하지 않는 값(`jam-img`)을 고를 수 없다(또는 골라도 항상 0건이 되는 대신 필터 자체가 노출되지
  않는다).
- 배지 목록 화면의 "제작 경로" 필터에는 `jam-img`가 그대로 남아 있다.
- 테이블별 옵션 구성이 테스트로 고정되어 있다.
- `scripts/verify.sh` 통과.
