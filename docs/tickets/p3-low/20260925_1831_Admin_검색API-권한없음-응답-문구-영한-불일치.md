# [Admin] 검색 API 권한 없음 응답 문구 영/한 불일치

> 상위 티켓 [20260925_1404](../p2-normal/20260925_1404_Feature_에셋제너레이터-2차-미션컬렉션홈피드확장-윤진신규기획-상위.md)
> 하위 티켓 [20260925_1411](../p2-normal/20260925_1411_Admin_에셋제너레이터-홈피드-적용탭-제작경로표시.md)
> 게이트(민지)의 범위 밖 발견물로 자동 생성.

## 핵심 요약

- 요구사항: `src/app/api/admin/today/search/route.ts`의 권한 없음 응답 문구가 `'Forbidden'`
  (영문)인데, `src/app/api/admin/asset-generator/apply/route.ts`는 `'권한이 없습니다.'`(국문)다.
  `itembooks/search/route.ts`에서 그대로 베껴 생긴 기존 불일치를 1411이 반복했다 — 이 티켓이
  새로 만든 문제는 아니다.
- 구현 계획: 어드민 검색 API 전반(`badges/search`·`itembooks/search`·`missions/search`·
  `today/search` 등)의 권한 없음 응답 문구를 국문으로 통일한다.
- 관련 파일: `jam-web/src/app/api/admin/today/search/route.ts`,
  `jam-web/src/app/api/admin/itembooks/search/route.ts` 등 검색 API 전반

## 배경 / 문제 정의

CLAUDE.md 절대 규칙 1(항상 한국어로 출력)이 사용자 노출 문구에 적용되는데, 어드민 검색 API
일부가 영문 `'Forbidden'`을 쓰고 있다. 어드민 화면 전용 응답이라 사용자 영향은 작지만
일관성 문제로 남겨둔다.

## 완료 조건
- 어드민 검색 API의 권한 없음 응답 문구가 전부 국문으로 통일된다.
- `scripts/verify.sh` 통과.
