# [Infra] 미션·홈피드 등록 스크립트에도 제어 문자 정규식 복제 제거와 dry-run 요약 표기 정정을 적용한다

> 티켓 20260925_0549·0542(묶음 D)의 게이트(민지) 범위 밖 발견물이다. 두 티켓은 **배지 등록 파일만** 고쳤다.

## 핵심 요약

- 요구사항: (1) 개행·제어 문자 정규식이 미션·홈피드 등록 쌍에도 두 번씩 복제돼 있다. 배지 쌍과 같이 원본을 한 곳으로 모은다.
  (2) 미션·홈피드 `--dry-run` 요약도 DB 읽기 검사를 건너뛰었는데 첫 줄에 `결과: 통과`만 찍는지 확인하고, 그렇다면 배지와 같이 「(DB 읽기 검사는 건너뜀 …)」을 첫 줄에 적는다.
- 구현 계획: 배지에서 한 방식(`registerBundle.mjs`가 `CONTROL_OR_LINE_BREAK`를 export하고 `registerRecord.mjs`가 `.source`로 파생)을 그대로 따른다.
- 관련 파일: `jam-web/scripts/asset-generator/registerMissionRecord.mjs:39`, `registerHomeFeedRecord.mjs:39`,
  `registerMissionBundle.mjs:67`, `registerHomeFeedBundle.mjs:105`(정규식 복제 위치, 민지 보고 기준 줄 번호),
  각 `Record` 파일의 `--dry-run` 요약 함수, 테스트 `__tests__/registerMissionRecord.test.ts`·`registerHomeFeedRecord.test.ts`,
  문서 `docs/service/prd/asset-generator/MISSION_REGISTRATION_BUNDLE.md`·`HOME_FEED_REGISTRATION_BUNDLE.md`.

## 배경 / 문제 정의

### 사실 (2026-09-26 묶음 D 게이트 보고)

- 0549의 완료 조건 「정규식 원본이 한 곳」은 배지 등록 쌍(`registerBundle.mjs`↔`registerRecord.mjs`)에서만 충족됐다. 미션·홈피드 쌍의 복제는 남아 있다(위 줄 번호).
- 0542는 배지 `--dry-run` 요약만 고쳤다. 미션·홈피드 요약이 같은 문제(DB 검사 건너뜀을 첫 줄에 드러내지 않음)를 갖는지는 **확인하지 않았다**.

### 아직 확인하지 않은 것

- 미션·홈피드 dry-run 요약에 「건너뜀」이 있는 경로가 있는지, 있다면 첫 줄 표기.
- 미션·홈피드 SQL 기록의 `--` 주석 줄에도 사용자 입력이 닿는지(0549는 배지만 확인했다).

## 완료 조건

- 미션·홈피드 등록 스크립트의 제어·개행 문자 정규식 정의가 각 쌍에서 한 곳이다(테스트에 「범위 문자를 다시 적지 않는다」 확인).
- 미션·홈피드 dry-run 요약이 DB 검사를 건너뛰면 첫 줄과 안내가 배지와 같은 방식으로 나온다(해당 경로가 없으면 그 사실을 기록).
- 스텁 테스트로 고정되어 있고 실제 DB·Storage에 쓰지 않는다. `scripts/verify.sh` 통과.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- 묶음 티켓 20260926_1441로 처리했다. 상세와 실행 지표는 그 티켓의 완료 기록에 있다.
- 개행·제어 문자 정규식의 원본을 `registerBundle.mjs`의 `CONTROL_OR_LINE_BREAK` 한 곳으로 모았다. `registerMissionBundle.mjs`·`registerHomeFeedBundle.mjs`의 로컬 복제는 지우고 import로 바꿨고, `registerMissionRecord.mjs`·`registerHomeFeedRecord.mjs`는 `.source`로 `commentSafe` 정규식을 파생한다(배지 방식과 같음). 문자 범위와 `+`·`g` 플래그는 이전과 같다.
