# [Infra] 배지 등록 `--undo`가 배열 컬럼 참조를 확인하지 않는다

> 2026-09-26 프로덕션 배포 전 점검(민지 모드 ③)의 발견물이다. 티켓 20260925_0540은 외래 키 10곳만 확인한다.

## 핵심 요약

- 요구사항: `--undo`가 지우려는 배지가 미션 보상·홈피드 카드·믹스 레시피의 **배열 컬럼**에 들어 있어도 지금은 확인하지 않는다. 확인 대상에 넣거나 명시적으로 안내한다.
- 관련 파일: `jam-web/scripts/asset-generator/registerFlow.mjs:52-63`(`UNDO_REFERENCE_TABLES`), `jam-web/src/lib/admin/badge-references.ts:160-230`(어드민 배지 삭제가 보는 참조 목록, 대조 기준).

## 배경 / 문제 정의

### 사실 (민지 보고, 2026-09-26)

- `--undo`의 참조 확인은 외래 키 10곳뿐이다. 어드민의 배지 참조 목록에 있는 배열 컬럼은 보지 않는다: `missions.reward_badge_ids`, `today_cards.badge_ids`, `combination_recipes.reward_badge_ids`, `combination_recipe_slots.allowed_badge_ids`.
- 등록한 배지를 미션 보상이나 레시피에 붙인 뒤 `--undo`를 하면 배지 행이 지워지고 이 참조는 남는다. 외래 키가 아니라 DB가 막지 않는다. 대응 테스트도 없다.
- 로컬 운영 스크립트라 서비스 런타임 영향은 없다. 미션·홈피드 `--undo`의 비외래 키 참조는 대조하지 못했다.

## 결정 필요

- A. 배열 컬럼 4곳을 참조 확인 표에 추가한다(배열 포함 조회). 카리나 추천이다(판단): 어드민 삭제와 같은 기준이 된다.
- B. 문서에 한계로 명시한다.

## 완료 조건

- (A) 배지가 위 배열 컬럼 어디에든 들어 있으면 `--undo`가 삭제 전에 중단하고 위치를 나열한다(스텁 테스트로 고정, 실제 DB 미접근).
- `scripts/verify.sh` 통과.
