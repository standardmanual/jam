# [API] 에셋 제너레이터 apply 라우트의 실패 경로 테스트를 채운다

> 2026-09-26 프로덕션 배포 전 점검(민지 모드 ③)의 발견물이다.

## 핵심 요약

- 요구사항: 운영자가 이미지를 반영하는 유일한 서버 경로(`apply`)의 실패 경로를 테스트로 고정한다.
- 관련 파일: `jam-web/src/app/api/admin/asset-generator/apply/route.ts`(:157·167·174·188-193), `apply/__tests__/route.test.ts`(9건).

## 배경 / 문제 정의

### 사실 (민지 보고)

- 현재 테스트는 성공 4건(배지·미션·컬렉션·홈피드)과 입력 검증 위주다. 다음이 비어 있다: WebP 변환 실패(500), PNG·WebP 업로드 실패(500), 업로드 뒤 컬럼 갱신 실패(파일만 남는 orphan), 소프트 삭제된 배지 404, 비 PNG·파일 없음 400.

## 완료 조건

- 위 경로가 스텁 테스트로 고정되어 있고(실제 DB·Storage 미접근), 특히 컬럼 갱신 실패 시 orphan 파일 처리 동작이 테스트에 드러난다. `scripts/verify.sh` 통과.
