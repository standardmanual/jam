# [UI] 로고 PNG가 2610 캔버스의 왼쪽에 붙어 오른쪽 끝 1px이 비어 있다

> 2026-09-26 티켓 20260925_1125 게이트(민지)의 범위 밖 발견물이다. 신호: 참고.

## 핵심 요약

- 요구사항: 로고를 캔버스 가운데에 놓을지 정한다. 화면에는 영향이 없다.
- 관련 파일: `jam-web/scripts/gen-brand-assets.mjs:45` 부근(`floor((2610-2609)/2)`로 왼쪽 0에 붙임).

## 배경 / 문제 정의

- SVG를 높이 925로 렌더하면 폭이 2609px가 되어 2610 캔버스에 넣을 때 1px 남는다. 현재는 왼쪽 0에 붙여 오른쪽 끝 1px이 투명하다.
- 티켓 20260925_1125는 "가운데 맞춤"이라고 적었지만 `floor`로 내림해 왼쪽에 붙는다. 1px 차이라 상단 바·로그인·배지 공유 이미지에서 눈에 띄지 않는다.
- 다음에 로고를 다시 만들 때 규격(폭)을 SVG 비율에 맞춰 정할 기회가 있으면 함께 다룬다. 단독으로 서두를 이유는 없다.

## 완료 조건

- 로고가 캔버스에서 좌우 여백이 같도록 배치되거나, 1px 치우침을 의도로 문서화하고 닫는다.
