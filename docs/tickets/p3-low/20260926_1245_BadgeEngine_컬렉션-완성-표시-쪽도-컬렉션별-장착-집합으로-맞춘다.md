# [BadgeEngine] 컬렉션 완성 표시 쪽(`completable.ts`)도 컬렉션별 장착 집합으로 센다

> 2026-09-26 티켓 20260924_0937 게이트(민지)의 범위 밖 발견물이다. 신호: 참고.

## 핵심 요약

- 요구사항: 보정 함수(`checker.ts`)는 이제 컬렉션별 집합으로 분자를 세지만, 표시 쪽은 여전히 슬롯 배지를 하나의 집합에 모아 모든 북에 공통으로 쓴다. 컬렉션이 바뀐 배지가 있으면 두 곳이 다른 완성 결과를 낼 수 있다. 표시 쪽도 같은 기준으로 맞춘다.
- 구현 계획: `computeBookCompletion`의 `filledByBook` 옵션(0937에서 추가)을 `completable.ts:152` 호출에도 넘기고, 표시 4곳과의 연동을 티켓 20260921_1129와 함께 확인한다.
- 관련 파일: `jam-web/src/lib/itembook/completable.ts:152`, `jam-web/src/lib/itembook/completion-basis.ts`, 관련 티켓 20260921_1114·1115·1129·1135.

## 완료 조건

- A에 장착된 배지의 컬렉션이 B로 바뀐 경우 표시 쪽도 B의 분자에 그 배지를 세지 않는다(단위 테스트).
- 보정 함수와 표시가 같은 입력에서 같은 완성 결과를 낸다.
