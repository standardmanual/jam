# [Infra] 클라이언트→서버 전용 import 검사가 정규식 기반이라 오탐 가능성이 있고 동적 `import()`를 따라가지 않는다

> 2026-09-26 티켓 20260926_1239 게이트(민지)의 범위 밖 발견물이다. 신호: 참고.
>
> 2026-10-23 갱신: 동적 `import()` 미추적은 티켓 20261017_1638에서 해결했다(`/profile/edit` 500 사고로 사례가 생겼다). 이 티켓에 남은 것은 정규식 오탐 가능성뿐이다.

## 핵심 요약

- 요구사항: `scripts/check-client-server-imports.mjs`는 소스를 정규식으로 파싱해서 문자열·템플릿 안의 줄 첫머리 `import` 문을 잘못 잡을 수 있고, 동적 `import()`로 서버 전용 모듈에 닿는 경우는 따라가지 않는다. 현재 저장소에서는 둘 다 발생하지 않는다. 필요해지면 보강 방식을 정한다.
- 구현 계획: (착수 전 검토) 오탐이 실제로 나오면 TypeScript 파서 기반으로 바꾸거나 해당 패턴만 예외로 처리한다. 동적 `import()` 추적은 서버 전용 모듈로 우회하는 사례가 생길 때 추가한다.
- 관련 파일: `scripts/check-client-server-imports.mjs:48` 부근, `scripts/check-client-server-imports.test.mjs`.

## 완료 조건

- 오탐 또는 미추적으로 검사가 잘못 판정하는 실제 사례가 나왔을 때만 착수한다. 그때 재현 픽스처를 테스트에 추가하고 고친다. 사례가 없으면 두고 본다는 결정을 완료 기록에 남기고 닫는다.
