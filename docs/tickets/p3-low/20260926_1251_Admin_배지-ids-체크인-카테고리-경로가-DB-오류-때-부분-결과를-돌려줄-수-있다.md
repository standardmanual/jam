# [Admin] `fetchBadgeListIds`의 체크인 지점 카테고리 필터 경로(`fetchAllRows`)가 DB 오류 시 부분 결과를 돌려줄 수 있다

> 2026-09-26 티켓 20260926_1241 게이트(민지)의 범위 밖 발견물이다. 신호: 참고.

## 핵심 요약

- 요구사항: 배지 목록 ids 조회에서 체크인 지점 카테고리 필터 경로는 `fetchAllRows`로 여러 쪽을 읽다가 오류가 나면 그때까지 읽은 부분 목록을 돌려줄 수 있다. 그러면 `ids` 라우트가 조용히 틀린 건수를 낼 수 있다. 목록 화면은 같은 동작을 의도된 설계로 두었지만 ids(전체 선택·내보내기)는 정확한 전체가 필요하다.
- 구현 계획: 이 경로에서도 오류를 던지게 하거나 부분 결과 여부를 표시해 라우트가 500과 안내로 처리하게 한다.
- 관련 파일: `jam-web/src/lib/admin/badge-list-query.ts:299` 부근, `jam-web/src/app/api/admin/badges/ids/route.ts`.

## 완료 조건

- 체크인 카테고리 경로에서 DB 오류를 만나면 `ids`가 부분 목록이 아니라 500과 한국어 안내를 응답한다(단위 테스트).
