# [Infra] 공유 작업 폴더가 분리된 HEAD일 때 커밋·push를 훅으로 막는다 (0121의 B안)

> 2026-09-26 티켓 20260926_0121에서 A안(민지 정의·게이트 프롬프트에 금지 명시)만 반영하고 B안을 분리했다.

## 핵심 요약

- 요구사항: 게이트 에이전트가 공유 작업 폴더의 HEAD를 옮기는 문제는 지시(A안)만으로는 보장되지 않는다. 작업 폴더가 분리된 HEAD인 채로 커밋·push되면 유실되거나 push가 조용히 no-op이 된다. 이를 `pre-commit`·`pre-push` 훅이 감지해 막고 복구 안내를 낸다.
- 구현 계획: **착수 전에 다음 게이트 실행의 reflog로 A안이 통하는지 먼저 확인한다.** 통하면 이 티켓은 두고 본다. 통하지 않으면 훅을 만든다. 주의점: 격리 워크트리(`wf_*`)는 정상적으로 분리된 HEAD이므로 훅은 "메인 작업 폴더이면서 분리된 HEAD"만 막아야 한다(정상 커밋까지 막으면 병렬 세션 작업이 멈춘다).
- 관련 파일: `.githooks/pre-commit`, `.githooks/pre-push`, `scripts/ensure-hooks-path.sh`.

## 완료 조건

- 메인 작업 폴더가 분리된 HEAD일 때 커밋 또는 push가 막히고 복구 안내가 나온다(임시 저장소 재현). `wf_*` 워크트리와 `karina-merge` 같은 임시 워크트리는 막히지 않는다.
