# [API] 포인트 원장 사유 문자열(`combine_fail_reward`·`combine_recipe_reward`)이 상수 없이 여러 곳에 리터럴로 중복된다

> 2026-09-26 티켓 20260924_1455 게이트(민지)의 범위 밖 발견물이다.

## 핵심 요약

- 요구사항: `lib/points`에 포인트 원장 사유 상수가 없어 같은 문자열이 `kpiWeekly.ts`(:131 부근), `combine/index.ts:242`, 마이그레이션 CHECK 목록 등에 흩어져 있다. 사유를 상수 한 곳에 모으고 사용처가 그것을 참조하게 한다. 오타가 나도 타입 검사가 잡지 못하는 상태다.
- 구현 계획: `lib/points/`에 사유 상수(또는 유니온 타입)를 두고 새로 만든 `kpiWeekly.ts`와 `combine/index.ts` 등이 참조하게 한다. DB CHECK 목록과의 일치는 테스트로 고정할 수 있는지 함께 본다.
- 관련 파일: `jam-web/src/lib/admin/kpiWeekly.ts:131`, `jam-web/src/lib/combine/index.ts:242`, `jam-web/src/lib/points/index.ts`.
