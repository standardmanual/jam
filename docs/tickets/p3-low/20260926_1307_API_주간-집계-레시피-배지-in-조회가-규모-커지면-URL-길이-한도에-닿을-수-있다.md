# [API] 주간 집계의 `combination_recipes` 전체 조회와 `badges .in(badgeIds)` 조회가 규모가 커지면 URL 길이 한도에 닿을 수 있다

> 2026-09-26 티켓 20260924_1455 게이트(민지)의 범위 밖 발견물이다.

## 핵심 요약

- 요구사항: `computeKpiWeeklyMetrics`가 결과물 배지 유효성을 보려고 레시피의 배지 id 목록을 `.in()`으로 넘긴다. 레시피·배지 수가 크게 늘면 요청 주소가 길어져 조회가 실패할 수 있다. 현재 규모에서는 문제없다. 규모가 커지기 전에 묶음 조회로 나누거나 다른 방식으로 바꾼다.
- 구현 계획: 배지 id를 일정 개수 단위로 나눠 조회하거나 DB 쪽에서 판정하는 방식을 검토한다. 같은 성격의 티켓(20260924_1636 유저 제재 필터)과 조회 관례를 함께 정한다.
- 관련 파일: `jam-web/src/lib/admin/kpiWeekly.ts:157` 부근.

## 완료 조건

- 레시피·배지 수가 수백 건을 넘어도 조회가 실패하지 않는다(분할 조회 단위 테스트). 또는 현재 규모에서는 두고 보기로 한 근거를 남기고 닫는다.
