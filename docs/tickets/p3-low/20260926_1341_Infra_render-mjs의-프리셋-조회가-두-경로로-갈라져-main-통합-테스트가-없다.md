> 2026-09-26 프로덕션 배포 전 점검(민지 모드 ③) 발견물이다. 신호: 참고(정확성).
>

## 핵심 요약

- 요구사항: `jam-web/scripts/asset-generator/render.mjs`(:79-110)가 프리셋을 어드민 읽기 API 경로와 서비스 롤 경로 두 가지로 읽는다. 부품인 `presetSource`만 단위 테스트가 있고 `main()`의 배선은 통합 테스트가 없다. 배선 실수는 예약 실행에서야 드러날 수 있다.
- 구현 계획: `main()`을 두 경로 각각에서 스텁(가짜 fetch·가짜 클라이언트)으로 돌려 프리셋 조회 → 텍스트 레이어 채움까지 이어지는지 확인하는 테스트를 추가한다.
- 관련 파일: `jam-web/scripts/asset-generator/render.mjs:79-110`, `presetSource.mjs`.

## 완료 조건

- 어드민 API 경로와 서비스 롤 경로 각각에서 `main()`의 프리셋 조회 배선이 테스트로 고정된다.
