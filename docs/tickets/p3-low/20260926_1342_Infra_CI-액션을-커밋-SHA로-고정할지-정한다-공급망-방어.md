# [Infra] CI 워크플로의 액션을 변경 가능한 태그(`@v7`) 대신 커밋 SHA로 고정할지 정한다

> 2026-09-26 프로덕션 배포 전 점검(민지 모드 ②) 발견물이다. 신호: 참고(보안).

## 핵심 요약

- 요구사항: `.github/workflows/verify.yml:30,70`이 `actions/checkout@v7`, `actions/setup-node@v7`처럼 변경 가능한 태그를 쓴다. 커밋 SHA로 고정하는 방식보다 공급망 방어가 약하다. 기존 v4도 같은 방식이었으므로 이번 변경이 만든 회귀는 아니다. 고정할지, 고정하면 갱신은 어떻게 할지(Dependabot 등) 정한다.
- 구현 계획: 두 액션을 릴리스 커밋 SHA로 고정하고 주석에 버전을 남긴다. 갱신 방식(자동 PR 도구 도입 여부)을 함께 정한다.
- 관련 파일: `.github/workflows/verify.yml:30,70`.

## 완료 조건

- 고정하기로 하면 두 액션이 커밋 SHA로 고정되고 CI가 성공한다. 하지 않기로 하면 근거를 완료 기록에 남기고 닫는다.
