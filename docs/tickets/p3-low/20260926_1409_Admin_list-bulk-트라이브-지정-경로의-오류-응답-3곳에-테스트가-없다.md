# [Admin] `list-bulk` 트라이브 지정(assign) 경로의 DB 오류 응답 3곳에 테스트가 없다

> 2026-09-26 프로덕션 배포(`8265beec`) 전 점검(민지 모드 ③) 발견물이다.

## 핵심 요약

- 요구사항: 티켓 20260926_1345에서 `list-bulk`의 DB 오류 응답 6곳을 고정 한국어 문장으로 바꿨지만, 테스트는 deactivate 사전 조회·드랍 수 집계·delete 삭제 3곳만 덮는다. 트라이브 지정 경로의 세 곳은 테스트가 없다: `tribeError`(트라이브 조회, `route.ts:56-59`), `booksError`(`item_books` 전량 조회, `route.ts:165-168`), `fetchBadgeTribeCandidates`의 `.in()` 조회 오류(`route.ts:177-180`). 테스트 파일에 tribe·item_books·assign 관련 문자열이 하나도 없어서, 이 경로에서 DB 원문을 다시 응답에 싣는 회귀가 생겨도 잡히지 않는다.
- 구현 계획: 기존 `fakeClient`에 트라이브·`item_books` 오류 주입을 추가하고, 세 곳에서 500과 고정 한국어 문장이 나오고 DB 원문이 응답에 없으며 `console.error`로 원문이 남는지 확인한다. 티켓 20260925_0238(공용 헬퍼 `update.error` 노출 3곳)과 같은 파일이라 함께 처리하면 효율적이다.
- 관련 파일: `jam-web/src/app/api/admin/badges/list-bulk/route.ts:56-59,165-168,177-180`, `.../list-bulk/__tests__/route.test.ts`.

## 완료 조건

- 위 세 곳의 오류 응답이 500과 고정 문장이고 DB 원문이 응답에 없음을 단위 테스트가 고정한다.
