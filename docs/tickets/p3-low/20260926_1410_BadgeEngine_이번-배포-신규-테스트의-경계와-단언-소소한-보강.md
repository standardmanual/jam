# [BadgeEngine] 이번 배포의 신규 테스트(제재 필터 경계·`buildFilledByBook`)의 경계값과 느슨한 단언을 보강한다

> 2026-09-26 프로덕션 배포(`8265beec`) 전 점검(민지 모드 ③) 발견물이다.

## 핵심 요약

- 요구사항: 민지 모드 ③이 남긴 [참고] 세 가지를 한 번에 정리한다. (1) 제재 필터 경계 테스트가 `BAN_FETCH_LIMIT-3`(997건)과 정확히 1,000건만 있고 999건(한도 바로 아래)과 0건이 없다(`user-list.test.ts`). `>=`를 `>`로 바꾸는 회귀는 1,000건 테스트가 잡으므로 위험은 낮다. (2) `buildFilledByBook`의 빈 입력(`slots: []`와 빈 `checkinBadgesByBook` 동시) 결과가 빈 Map인지 확인하는 테스트가 없다(`filled-by-book.test.ts`). (3) 새 테스트의 단언이 일부 느슨하다: `get('B')?.has('X') ?? false`와 `get('C')?.size ?? 0`는 키가 없는 경우와 빈 집합인 경우를 구분하지 않고, `expect(console.error).toHaveBeenCalledWith(expect.any(String), RAW)`는 로그 접두어를 검증하지 않는다.
- 구현 계획: 경계 케이스 두 개와 빈 입력 케이스를 추가하고, 키 없음·빈 집합을 구분하는 단언과 로그 접두어 단언으로 바꾼다. 코드 변경은 없다.
- 관련 파일: `jam-web/src/lib/admin/__tests__/user-list.test.ts`, `jam-web/src/lib/itembook/__tests__/filled-by-book.test.ts`, `jam-web/src/app/api/admin/badges/list-bulk/__tests__/route.test.ts`.

## 완료 조건

- 위 경계·빈 입력 케이스가 추가되고 단언이 계약을 더 좁게 고정한다. `scripts/verify.sh` 통과.

### 배포 전 점검에서 추가 확인 (2026-09-26, 프로덕션 배포 `828eceba`, 민지 모드 ③, 모두 [참고])

CSV 본문·헤더·청크 처리는 `badges/export` 테스트에만 있다. `call()`이 예외를 삼켜 null을 돌려주고 `res?.status).not.toBe(400)`이 null에서도 통과하는 점은 `createServiceClient` 호출 단언이 함께 걸려 있어 거짓 통과 여지는 좁다.
- **프리셋 POST의 `layers` 배열 원소가 null이거나 객체가 아니면 `layer.type` 접근에서 예외가 난다**(`presets/route.ts:110`, 기존 동작). 원소 형태 400 테스트가 없고, 같은 id의 이미지 레이어가 둘이면 서로 덮어쓰는 경우도 미검증이다. (같은 내용을 담은 티켓 20260926_1456에서 처리한다.)
- **드랍 제외 일괄 라우트**의 삭제 배지 필터 테스트에 조회 DB 오류(500)와 `ID_CHUNK_SIZE` 초과 다중 묶음이 없다. 삭제된 배지가 "아이템배지가 아닙니다"로 안내되는 문구는 오해를 줄 수 있어 문구를 다듬을지 본다.
- **`probeWorkflowFreeze`**(`scripts/check-contract.mjs:555-571`)의 두 분기가 테스트되지 않는다: 훅이 예외 파일(README)까지 막는 경우, 임시 저장소 생성 실패로 notes에 건너뜀.
- **배포 게이트 쿠키 저장소의 삭제 경로**(`scripts/deploy-gate.mjs:637-660`)가 미검증이다: `Max-Age<=0`이나 빈 값으로 쿠키를 지우는 분기, `Expires` 미처리.
- **`buildPublicMissionCheckLines`의 응답 모양 경계**(`scripts/public-mission-check.mjs:59-70`): 배지 응답에 `badges` 키가 없거나 null인 경우. **`RecipeTable` 삭제 제외 안내 문구**를 두 문단으로 나눈 변경에 테스트가 없다(`RecipeTable.tsx:258-270`, 기능 회귀 위험 낮음).
