# [Admin] 어드민 문구·주석·문서의 소소한 정리 묶음: 삭제 미리보기 문구, 합쇼체 혼용, 낡은 주석, 종료 판정 경계, API 표 누락

> 어드민 목록 공통화(20260924_0916)의 범위 밖 발견물 묶음 티켓들에서 결함성 항목만 골라 한 번의 구현·게이트·병합으로 처리하는 묶음 티켓이다(사용자 지시, 2026-09-26). 원본 항목은 각 하위 발견물 티켓의 「배경」에 있다. 처리하지 않는 항목은 그 티켓을 닫을 때 항목별로 사유를 적는다.

## 핵심 요약

- 요구사항: 동작 변경이 거의 없는 소소한 정리 다섯 가지. (1) 레시피 삭제 미리보기 문구가 `삭제할 수 없어 제외됩니다(라벨: 삭제할 수 없습니다. 이 레시피를 가리키는 참조가 N건 있습니다.)`로 나와 "삭제할 수 없"이 두 번 겹치고 괄호 안에 문장이 들어간다(티켓 1633 #1, `RecipeTable.tsx` 삭제 미리보기 impact 블록). 하나의 자연스러운 문장으로 고친다. (2) `mission-bulk.ts:104`의 일부 오류 문구(`일부만 반영됐습니다`)가 같은 파일의 해요체와 합니다체로 섞인다(티켓 1630 #4). `docs/specs/UX_WRITING_GUIDELINE.md`의 어투 기준으로 통일한다. (3) `MissionForm.tsx:103-105` 주석 2곳이 삭제된 `MissionList.tsx`를 가리킨다(티켓 1630 #6). 현재 상태에 맞게 고치거나 이력 서술로 분명히 표시한다. (4) 종료 판정 경계가 서로 다르다: 목록 상태는 `ends_at < now`가 종료(`mission-list-query.ts:57`)인데 기간 종료 일괄은 `ends_at <= now`를 이미 끝난 것으로 건너뛴다(`mission-bulk.ts:126`, 티켓 1630 #3). 같은 판정으로 맞춘다. (5) `docs/specs/SERVICE_OPERATIONS.md:1057-1058` 어드민 API 표에 신설된 `review/ids`, `drop-policy/exclusions/bulk`, `drop-policy/exclusions/ids`가 없다(티켓 1632 #1). 표에 추가한다.
- 관련 파일: `jam-web/src/app/admin/recipes/RecipeTable.tsx`, `jam-web/src/lib/admin/mission-bulk.ts:104,126`, `jam-web/src/lib/admin/mission-list-query.ts:57`, `jam-web/src/app/admin/missions/MissionForm.tsx:103-105`, `docs/specs/SERVICE_OPERATIONS.md:1057-1058`.

## 상세 요구사항

### 서비스/코드베이스 관점

- (4)는 어느 쪽 경계가 맞는지(목록 상태의 `<` 또는 일괄의 `<=`)를 코드의 "종료" 정의를 확인해 정하고 근거를 완료 기록에 남긴다. 실제 시각이 정확히 같을 확률은 사실상 없으므로 동작 차이는 없다.
- (1)·(2)의 사용자 노출 문구는 `docs/specs/UX_WRITING_GUIDELINE.md`와 `.claude/output-styles/fluent-korean.md`를 따른다.
