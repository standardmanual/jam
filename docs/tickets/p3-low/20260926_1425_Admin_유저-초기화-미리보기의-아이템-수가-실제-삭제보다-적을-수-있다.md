# [Admin] 유저 초기화 미리보기의 아이템 수가 실제 삭제되는 수보다 적을 수 있다

> 2026-09-26 티켓 20260924_1637 #1(어드민 목록 공통화 ⑩ 게이트 발견물)에서 분리한 티켓이다.

## 핵심 요약

- 요구사항: 유저 초기화 미리보기의 아이템 수(`computeUserBulkImpact`)는 유저 **인벤토리 보유분만** 센다. 실행(`user-actions.ts` 1.5단계)은 이 유저가 드랍했고 타인이 주운 아이템과 미소유 드랍 개체도 삭제한다. 파괴적 작업의 미리보기가 실제보다 적게 보여 운영자가 영향을 과소평가할 수 있다. 미리보기가 실행이 지우는 범위를 모두 세게 한다.
- 구현 계획: 실행이 삭제하는 모든 경로를 나열하고 각각의 건수를 미리보기 조회에 추가한다. 실행 로직 변경은 없다.
- 관련 파일: `jam-web/src/lib/admin/user-bulk-impact.ts`(`computeUserBulkImpact`), `jam-web/src/lib/admin/user-actions.ts`(1.5단계).

## 완료 조건

- 미리보기의 아이템 수가 실행이 삭제하는 항목 수와 일치한다(단위 테스트 또는 근거).
