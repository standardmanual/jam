# [Admin] 어뷰징 화면의 검색어 잘림 안내 없음, 등급 전환 기록 부재, 해제 로그 실패 시 유일 기록이 서버 로그뿐인 문제를 정리한다

> 2026-09-26 티켓 20260924_1638(어드민 목록 공통화 ⑪ 게이트 발견물)의 #1~#3에서 분리한 티켓이다.

## 핵심 요약

- 요구사항: (1) 검색어 일치 id를 유저·POI 각 100건까지만 잡아(`abusing-list.ts` `SEARCH_MATCH_LIMIT`) 넓은 검색어는 결과가 조용히 잘리고 화면에 안내가 없다. 잘림을 표시한다. (2) 등급 전환(soft에서 hard)은 `abusing_logs`에 기록되지 않는다(`shadow-ban.ts` `changeBanLevel`). 누가 언제 바꿨는지 추적할 수 없다. 기록할지 정한다(정책 결정, 원 티켓은 해제만 요구). (3) 해제 뒤 로그 기록이 실패하면(`logAbusingEvents`) 지운 행의 유일한 기록이 서버 로그(`console.error`)에만 남는다. 로그 실패 시 처리(재시도·감사 기록)를 정한다.
- 구현 계획: (1)은 결과가 한도에 닿았을 때 화면에 안내 문구를 표시한다. (2)는 결정 뒤 `changeBanLevel`에서 로그를 남긴다. (3)은 실패 시 대응을 정한다.
- 관련 파일: `jam-web/src/lib/admin/abusing-list.ts`, `jam-web/src/lib/abusing/shadow-ban.ts`.

## 완료 조건

- 세 항목 각각에 대해 (a) 고쳤고 확인 방법을 남겼거나 (b) 고치지 않기로 한 사유가 완료 기록에 있다.
