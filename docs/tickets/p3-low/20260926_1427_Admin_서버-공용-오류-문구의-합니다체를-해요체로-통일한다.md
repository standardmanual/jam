# [Admin] 어드민 서버 쪽 공용 오류 문구(합니다체)를 해요체로 통일한다

> 2026-09-26 티켓 20260926_1414 게이트(민지)의 [참고/주의] 발견물이다.

## 핵심 요약

- 요구사항: `mission-bulk.ts`의 오류 문구를 해요체로 통일했지만(UX Writing 가이드 §2.1 해요체 기본), 서버 공용 문구(`jam-web/src/lib/admin/bulk/server.ts:182`, `jam-web/src/app/api/admin/missions/bulk/route.ts:97` 외 각 bulk 라우트의 "반영에 실패했습니다.")는 여전히 합니다체다. 그 결과 사용자에게 보이는 한 문장 안에서 "일부만 반영됐어요. 반영 실패: …합니다."처럼 어투가 섞일 수 있다. 어드민 전용 화면의 문구라 어투 기준을 어디까지 적용할지(어드민은 합니다체 유지 등)를 먼저 정하고 통일한다.
- 구현 계획: 어드민 문구의 어투 기준을 정한 뒤 `bulk/server.ts`와 각 bulk 라우트의 공용 문구를 맞춘다. 테스트의 문구 단언도 함께 고친다.

## 완료 조건

- 어드민 오류 문구의 어투 기준이 정해져 있고 한 화면 안에서 섞이지 않는다.
