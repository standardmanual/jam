# [Infra] 등록·읽기 스크립트 묶음: 정규식 단일화·dry-run 문구(0120), `--undo` 배열 컬럼 참조(0200), 읽기 실패 출력 테스트(1512)

> 하위 티켓들을 한 번의 구현·게이트·병합으로 처리하기 위한 묶음 티켓이다(사용자 지시, 2026-09-26). 끝나면 하위 티켓도 함께 닫는다. **각 하위 티켓의 「구현 계획」과 「완료 조건」이 세부 기준이다. 아래 표는 파일 단위 실행 범위이고, 세부 요구사항은 하위 티켓 본문(`docs/tickets/`)을 읽는다.**

## 핵심 요약

- 요구사항: (1) 미션·홈피드 등록 쌍의 개행·제어 문자 정규식 복제를 배지 방식(`registerBundle.mjs`가 `CONTROL_OR_LINE_BREAK`를 export하고 `registerRecord.mjs`가 `.source`로 파생)으로 한 곳에 모으고, `--dry-run` 요약 첫 줄에 「DB 읽기 검사는 건너뜀」을 적는다(0120). (2) 배지 등록 `--undo`가 미션 보상·홈피드 카드·믹스 레시피의 **배열 컬럼**에 들어 있는 배지 참조를 확인하지 않는 문제를 고친다(0200). (3) `admin-api-read.mjs`의 조회 실패 「확인 불가」 출력 분기에 테스트가 없다(1512).
- 관련 파일: `jam-web/scripts/asset-generator/registerMissionRecord.mjs:39`, `registerHomeFeedRecord.mjs:39`, `registerBundle.mjs`, `registerFlow.mjs:52-63`(`UNDO_REFERENCE_TABLES`), `jam-web/src/lib/admin/badge-references.ts:160-230`(참조 대조 기준), `scripts/admin-api-read.mjs:91-105`, `scripts/public-mission-check.mjs`, `scripts/public-mission-check.test.mjs`.
