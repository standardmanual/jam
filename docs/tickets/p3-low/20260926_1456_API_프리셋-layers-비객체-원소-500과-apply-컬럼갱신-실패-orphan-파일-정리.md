# [API] 프리셋 `layers` 배열의 비객체 원소가 500을 내는 문제와 `apply`의 컬럼 갱신 실패 시 orphan 파일 정리를 다룬다

> 2026-09-26 티켓 20260926_1442 게이트(민지)의 [참고] 발견물 두 건을 묶은 티켓이다.

## 핵심 요약

- 요구사항: (1) 프리셋 저장에서 `layers` 배열에 `null` 같은 비객체 원소가 있으면 `layer.type` 접근에서 던져 500이 된다(`presets/route.ts:110`, 기존부터 있던 동작). 400으로 거절한다. (2) `apply`가 컬럼 갱신에 실패하면 이미 올라간 파일 두 개(PNG·WebP)를 정리하지 않고 남긴다(`apply/route.ts`). 같은 경로 upsert라 재시도하면 덮어쓰므로 급하지 않지만, 재시도가 없으면 orphan 파일이 남는다. 정리(삭제 시도)를 넣을지 정한다.
- 관련 파일: `jam-web/src/app/api/admin/asset-generator/presets/route.ts:110`, `jam-web/src/app/api/admin/asset-generator/apply/route.ts`.

## 완료 조건

- 비객체 원소가 있는 `layers`가 400이다(단위 테스트). `apply`의 컬럼 갱신 실패 시 처리(정리 또는 두고 보기로 한 근거)가 정해져 있다.
