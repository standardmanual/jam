# [Infra] 등록 SQL 기록 주석의 효과 문구가 배열 컬럼 참조(삭제해도 배열에 id가 남음)를 설명하지 않는다

> 2026-09-26 티켓 20260926_1441 게이트(민지)의 [참고] 발견물이다.

## 핵심 요약

- 요구사항: `buildRegistrationSql`이 SQL 기록 주석에 쓰는 문구 "일부는 삭제 시 함께 사라지거나 연결이 끊기고, 일부는 삭제가 막혀요"가, 표 이름 목록에 배열 컬럼 표(`missions`·`today_cards`·`combination_recipes`·`combination_recipe_slots`)가 합쳐졌는데도 "삭제해도 배열에 id가 남는" 효과를 설명하지 않는다. 문구에 배열 컬럼 효과를 더한다.
- 관련 파일: `jam-web/scripts/asset-generator/registerRecord.mjs:158`, 대응 테스트.

## 완료 조건

- SQL 기록 주석이 배열 컬럼 참조의 효과("삭제해도 배열에 id가 남음")를 설명하고 테스트가 이를 확인한다.
