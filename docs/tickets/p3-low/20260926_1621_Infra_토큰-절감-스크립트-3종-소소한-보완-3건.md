# [Infra] 토큰 절감 스크립트 3종의 소소한 보완 3건(doc-section 접두, 이메일 마스킹, contrast 종료 코드)

> 2026-09-26 티켓 1543·1544·1545 게이트(민지)의 [참고] 발견물이다. 모두 동작 결함은 아니고, 배포를 막지 않는다.

## 핵심 요약

- 요구사항: 세 스크립트의 다음 세 가지를 다듬는다.
  1. `scripts/doc-section.mjs` 47행 부근: `#` 없는 접두 `8.`이 `## 8.`뿐 아니라 `### 8.1` 같은 하위 제목도 잡아 다중 일치로 종료 코드 1이 된다. 정확히 같은 제목을 우선하거나 같은 수준 제목끼리만 비교하는 규칙을 검토한다.
  2. `scripts/weekly-collect.mjs`의 `sanitize`: `@`가 든 모든 토큰을 `[이메일 생략]`으로 바꿔 `@types/foo` 같은 커밋 제목도 가려진다. 이메일 형태(`이름@도메인.도메인`)로만 좁힌다.
  3. `jam-web/scripts/asset-generator/contrast.mjs`: 기준 미달이어도 종료 코드 0이다. 호출부가 출력의 pass 필드를 직접 읽어야 한다는 점을 사용법에 밝히거나 `--strict` 옵션으로 종료 코드를 나누는 안을 검토한다.
- 구현 계획: 세 건은 서로 독립이라 한 티켓에서 함께 처리하고 각각 테스트를 더한다.
- 관련 파일: `scripts/doc-section.mjs`·`doc-section.test.mjs`, `scripts/weekly-collect.mjs`·`weekly-collect.test.mjs`, `jam-web/scripts/asset-generator/contrast.mjs`·`contrastMath.mjs`.

## 완료 조건
