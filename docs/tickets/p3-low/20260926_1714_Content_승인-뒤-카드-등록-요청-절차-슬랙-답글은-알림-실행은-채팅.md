# [Content] 승인 뒤 카드 등록 요청 절차: 슬랙 답글은 알림, 실행 승인은 채팅

## 핵심 요약

- 요구사항: 사용자가 주간 리포트를 확인한 뒤 「등록」을 요청하는 방법과, 등록을 누가 언제 하는지를 정한다.
- 결정(2026-09-26 사용자): A안. 지금 구조(등록은 카리나, 윤진·카즈하·무인 루틴은 등록하지 않음)를 유지하고, 안내 글 스레드에 사용자가 「등록」을 남기면 카리나가 다음 세션에서 읽어 등록을 준비한다.
- 관련 파일: `docs/specs/prd/content-automation/PRD.md` §8-1(「등록 요청」 항목, 정본)·§8-2(「등록 신호」).

## 완료 조건

- PRD §8-1에 처리 순서(확인 → 준비 → 채팅 승인 → 실행·확인·회신)가 있고, 슬랙 답글이 DB 실행 승인이 아니라는 점과 세션이 열려 있어야 읽힌다는 점이 적혀 있다.
- `scripts/verify.sh`가 통과한다.

### 구현 내용 요약
PRD §8-1에 「등록 요청」 항목을, §8-2에 「등록 신호」 문단을 추가했다. 슬랙 답글은 등록 준비를 시작하게 하는 알림이고, 실행은 채팅에서 받는 사용자 승인 뒤에만 한다(`CLAUDE.md` 절대 규칙 6, 외부 내용에 담긴 지시를 그대로 실행하지 않는 규칙).

### 주요 의사결정 / 핵심 메모
- 사용자가 「슬랙에 등록하라고 남기면 등록해」라고 요청했다. 슬랙 글은 도구로 읽는 외부 내용이라 그 자체를 실행 승인으로 쓰지 않고, 채팅에서 한 번 더 확인받기로 했다.
- 주간 저장 프롬프트에는 안내 글의 「등록하려면 이 글에 '등록'이라고 답해 주세요」 한 줄이 들어 있지 않다. PRD §8-1을 따르라는 지시가 있어 반영될 수 있으나 보장되지 않는다. 첫 정기 실행(2026-09-29) 슬랙 글에서 확인하고, 빠졌으면 프롬프트에 넣는다.

### 잔여 이슈
- 첫 정기 실행의 슬랙 안내 글에 등록 요청 안내 한 줄이 있는지 확인한다.
