# [Admin] 곡선 후보 선택 보정이 최소 회전 반경 기준(RADIUS_MIN)의 효과를 약하게 만든다

> **연결 메모 (2026-09-30 티켓 20260930_1451 사용자 결정):** 20260930_1501(운영툴 미리보기·이미지) 착수 때 함께 판단한다. 07 블루프린트 4.5가 승인 때 에셋 제너레이터의
> 서버 렌더를 재사용하므로 에셋 제너레이터의 역할이 커진다.

## 핵심 요약

- 요구사항: 시드 여러 개로 1순위(반경·중앙 모두 충족) 후보가 실제로 얼마나 뽑히는지 실측하고, 2순위가 대부분이면 기준 상수를 정리한다.
- 구현 계획: 미정(착수 전 실측부터)
- 관련 파일: `jam-web/src/lib/asset-generator/curve.ts`(`pickCandidate`, 약 273~316줄)

## 배경 / 문제 정의

티켓 20260926_1756 게이트 리뷰(민지)의 범위 밖 발견물 [참고]다. `CENTER_MARGIN`·2순위 보정으로 1순위 조건이 드물어졌고 주석에도 2순위가 흔하다고 적혀 있다. 이 경우 `RADIUS_MIN` 0.15의 실질 효과가 약하다.

## 완료 조건

- 시드 0~199에서 1순위·2순위·fallback 비율을 측정해 티켓에 기록하고, 2순위가 과반이면 `RADIUS_MIN`과 보정 상수를 실제 동작에 맞게 정리한다.
