# [Admin] 곡선 변경으로 같은 시드의 결과가 바뀐 사실을 테스트로 남기고, 프리셋 하위 호환·이미지 경계 테스트를 보완한다

## 핵심 요약

- 요구사항: 곡선 변경으로 같은 시드의 결과가 바뀐 사실을 테스트로 남기고, 프리셋 하위 호환·이미지 경계 테스트를 보완한다
- 구현 계획: 미정(착수 전 실측부터)
- 관련 파일: `curve.test.ts`, `presets/[id]/__tests__/route.test.ts`(135줄), `presetSource.test.ts`, `render.test.ts`, `assetGeneratorHelpers.test.ts`

## 배경 / 문제 정의

프로덕션 배포 전 점검(민지 모드 ②·③, 티켓 1741·1756 배포)의 범위 밖 발견물이다. (1) `pickCandidate`가 `rnd()`를 하나 더 쓰고 상수가 바뀌어 예전 시드는 같은 이미지가 다시 나오지 않는데 이를 고정하거나 의도를 남기는 테스트가 없다(PRD §11). (2) 예전 형태(`heightPct` 포함) 레이어가 API GET에서 정리되는지, `overlayEnabled: true`인데 `overlayColor`가 없을 때 조용히 꺼지는 동작, 극단 종횡비·회전+오버레이·`NaN` 입력 경계가 테스트에 없다.

## 완료 조건

- (1)·(2)의 테스트가 있거나, 의도된 동작이라면 PRD §11에 예전 시드 비재현을 명시한다.
