# [Infra] 신규 스크립트의 CLI 연결부(종료 코드·출력 형식·배선)를 테스트한다

## 핵심 요약

- 요구사항: 신규 스크립트의 CLI 연결부(종료 코드·출력 형식·배선)를 테스트한다
- 구현 계획: 미정(착수 전 실측부터)
- 관련 파일: `jam-web/scripts/asset-generator/{contrast.mjs,make-home-feed-card.mjs}`, `scripts/weekly-collect.mjs`, `scripts/doc-section.mjs`

## 배경 / 문제 정의

프로덕션 배포 전 점검(민지 모드 ②·③, 티켓 1741·1756 배포)의 범위 밖 발견물이다. 핵심 로직은 테스트가 있으나 다음이 없다: contrast의 두 색 AND 판정·오류 종료 코드 1·한 줄 JSON, make-home-feed-card의 `@/` 별칭 오류 안내와 `process.exitCode`, weekly-collect의 출처 7개 배선·90초 타임아웃·8자 미만 비밀 마스킹 경계, doc-section의 인자 누락·없는 파일 종료 코드 2·CRLF·빈 파일.

## 완료 조건

- 위 항목의 테스트가 있고 통과한다.
