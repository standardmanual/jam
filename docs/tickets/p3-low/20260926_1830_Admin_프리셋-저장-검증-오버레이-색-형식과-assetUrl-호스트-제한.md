# [Admin] 프리셋 저장 라우트가 오버레이 색 형식과 이미지 URL 호스트를 검증하도록 한다

> **연결 메모 (2026-09-30 티켓 20260930_1451 사용자 결정):** 20260930_1501(운영툴 미리보기·이미지) 착수 때 함께 판단한다. 07 블루프린트 4.5가 승인 때 에셋 제너레이터의
> 서버 렌더를 재사용하므로 에셋 제너레이터의 역할이 커진다.

## 핵심 요약

- 요구사항: 프리셋 저장 라우트가 오버레이 색 형식과 이미지 URL 호스트를 검증하도록 한다
- 구현 계획: 미정(착수 전 실측부터)
- 관련 파일: `jam-web/src/app/api/admin/asset-generator/presets/route.ts`(109~117·144줄), `jam-web/scripts/asset-generator/renderCard.mjs`(`serverImageLoader`)

## 배경 / 문제 정의

프로덕션 배포 전 점검(민지 모드 ②·③, 티켓 1741·1756 배포)의 범위 밖 발견물이다. 저장 라우트가 레이어 JSON을 타입 단언만 하고 `overlayColor` 형식(`#rrggbb`)을 검증하지 않는다. `assetUrl`은 `^https?://`이면 그대로 통과해 서버 스크립트가 그 URL을 내려받는다(어드민이 임의 URL을 저장하면 CLI 실행 환경이 요청을 보내는 형태). 어드민 인가 뒤에서만 저장되고 이번 변경으로 새로 생긴 경로는 아니라 위험은 낮으나 윤진의 예약 루틴이 이 스크립트를 쓰게 되어 참고로 남겼다.

## 완료 조건

- 색 형식과 `assetUrl` 허용 호스트(이 프로젝트 저장소)를 검증하고 테스트가 있다.
