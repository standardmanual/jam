# [Infra] 예약 루틴 환경에서 `pickPresetSource`가 서비스 롤 키 대체 경로로 빠질 수 있는지 확인한다

> **연결 메모 (2026-09-30 티켓 20260930_1451 사용자 결정):** 20260930_1504가 루틴을 바꿀 때 함께 정리한다.

## 핵심 요약

- 요구사항: 예약 루틴 환경에서 `pickPresetSource`가 서비스 롤 키 대체 경로로 빠질 수 있는지 확인한다
- 구현 계획: 미정(착수 전 실측부터)
- 관련 파일: `jam-web/scripts/asset-generator/presetSource.mjs`(`pickPresetSource`)

## 배경 / 문제 정의

프로덕션 배포 전 점검(민지 모드 ②·③, 티켓 1741·1756 배포)의 범위 밖 발견물이다. `ADMIN_API_*`가 없으면 서비스 롤로 대체한다. 예약 환경에 서비스 키가 있으면 대체 경로가 열려 있다는 점만 참고로 남겼고, 그 환경 구성은 확인하지 못했다.

## 완료 조건

- 예약 환경에 서비스 롤 키가 없음을 확인하거나, 있다면 대체 경로를 막을지 정한다.
