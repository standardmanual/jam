# [Content] 서비스 플랜의 에셋 제너레이터 WebP 서술을 1280px 규격에 맞게 정리

## 핵심 요약

- 요구사항: `docs/plan/vision/02 JAM! 서비스 플랜.md` 22줄 부근의 "서비스 표시 크기에 맞춘 WebP를 자동 생성"이 새 규격(원본과 같은 긴 변 1280px 이하, 표시 크기의 2배)과 완전히 맞지 않는다. 326~327줄은 티켓 20260926_2312에서 이미 고쳤다.
- 구현 계획: 22줄 서술을 "화면에서 선명하게 보이는 크기(긴 변 1280px 이하)의 WebP를 자동 생성"처럼 정리한다.
- 관련 파일: `docs/plan/vision/02 JAM! 서비스 플랜.md`(22줄 부근), 규격 근거는 `docs/service/prd/asset-generator/PRD.md` §9.

## 배경 / 문제 정의

티켓 20260926_2312의 게이트 리뷰(민지)가 남긴 범위 밖 발견물(참고)이다. 400px를 말하지는 않지만 새 규격과 표현이 어긋난다.

## 완료 조건

- 22줄 서술이 PRD §9의 규격(긴 변 1280px 이하)과 모순되지 않는다.
