# [Admin] 에셋 제너레이터 정렬 앵커와 WebP 경계 테스트 보강

## 핵심 요약

- 요구사항: 배포 전 테스트 공백 점검(민지 모드 ③, 티켓 20260926_2213·2229·2312 배포)에서 나온 주의·참고 공백을 테스트로 메운다. 동작 결함은 없고 해피 패스 테스트는 이미 있다.
- 구현 계획: 아래 관련 파일의 테스트를 보강한다.
- 관련 파일:
  - `jam-web/src/lib/asset-generator/__tests__/render.test.ts`: (주의) `align: 'left'|'right'`에서 `yPct`·`cx`·`cy` 유지, `rotationDeg` ≠ 0일 때 앵커가 회전 피벗인지(`setTransform`의 `cx`/`cy`와 `fillText` 좌표) 단언, 정렬별 여러 줄 `lineY` 동일성, 빈 줄·빈 `content`
  - `jam-web/src/lib/asset-generator/__tests__/presetSerialize.test.ts`: `content`가 `null`·숫자일 때 `''`로 채우는지, 왼쪽·오른쪽 정렬로 저장된 옛 프리셋을 불러올 때의 동작
  - `jam-web/src/lib/admin/__tests__/badgeImageWebp.test.ts`: 1279·1281px 경계, 1280 이하 비정사각(예: 800×1000)이 확대되지 않는지
  - `jam-web/scripts/asset-generator/__tests__/registerMissionRecord.test.ts`(222줄 부근): 「긴 변 1280px 이하」 문구 단언 추가(배지·홈피드 기록 테스트에는 이미 있음)

## 배경 / 문제 정의

세 티켓 배포 전 점검에서 테스트 공백이 보고됐다. 차단 사유가 아니라 주의·참고여서 이번 배포에는 포함하지 않았다. 정렬 앵커 변경은 `startX`만 바뀌었고 세로 위치·회전 계산은 그대로라 구조상 안전하지만, 그 근거가 테스트가 아니라 코드 읽기다.

## 완료 조건

- 위 네 파일에 각 항목을 검증하는 테스트가 있고 `scripts/verify.sh`가 통과한다.
