# [Admin] 미션 이미지 일괄 적용 도구 넘침 검사·모아보기 테스트 보강

## 핵심 요약

- 요구사항: 티켓 20260926_2346의 게이트 리뷰(민지)가 남긴 범위 밖 발견물(참고)을 처리한다. 동작 결함은 없고, 실제 미리보기 실행(2026-09-27, 미션 55장)에서 두 기능 모두 정상 동작했다.
- 구현 계획: (1) `createTextOverflowDetector`(오른쪽 3% 여백 검사)와 `makeContactSheet`에 단위 테스트를 추가한다. 글꼴 다운로드·프리셋 조회를 스텁으로 대체하도록 구조를 조금 나눠야 할 수 있다. (2) 롤백이 백업이 없던 경로(기존 이미지가 없던 미션)에 새로 올린 PNG·WebP를 삭제하지 않아 저장소에 미참조 파일이 남는 점(55건 롤백 시 약 108개)을 처리할지 정한다. 삭제 옵션(`--rollback` 시 명시적 플래그)을 추가하거나 현재 동작을 문서에 그대로 두는 것 중 하나로 결정한다.
- 관련 파일: `jam-web/scripts/asset-generator/apply-mission-images.mjs`(`createTextOverflowDetector`, `makeContactSheet`), `jam-web/scripts/asset-generator/applyMissionImagesFlow.mjs`(`runRollback`), `jam-web/scripts/asset-generator/__tests__/applyMissionImagesFlow.test.ts`, `docs/specs/prd/asset-generator/PRD.md` §8(롤백 서술)

## 완료 조건

- 넘침 검사가 오른쪽 여백을 넘는 글자를 경고로 잡고, 여백 안에 들어오는 글자는 잡지 않는 것이 테스트로 확인된다.
- 모아보기 이미지가 미션 수만큼 칸을 만들고 번호표를 붙이는 것이 테스트로 확인된다.
- 롤백 시 새로 올린 파일의 처리 방침이 PRD와 도구 동작에서 일치한다.
- `scripts/verify.sh`가 통과한다.
