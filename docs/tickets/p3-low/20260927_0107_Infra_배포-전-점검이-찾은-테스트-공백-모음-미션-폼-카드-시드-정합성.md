# [Infra] 배포 전 점검이 찾은 테스트 공백 모음 미션 폼 카드 시드 정합성

> 발견 경위: 2026-09-27 `/jam-ship` 배포 전 점검(민지 모드 ②·③)의 범위 밖 발견물(참고)

## 핵심 요약

- 요구사항: 테스트가 없는 분기 모음이다. (1) `MissionForm`·`GateMissionForm`의 `condition_text` 변환(`trim() || null`)·수정 폼 초기값·요청 본문 구간(저장소에 jsdom·testing-library가 없어 컴포넌트 검증이 어렵다). (2) `MissionDetailClient` 테스트가 픽스처 하나(engine_condition + running)에만 의존하고, `condition_text`가 있는데 `activity_type`이 없는 조합과 `checkin`·`item_collect` 같은 다른 유형은 검증하지 않는다. (3) 마이그레이션 194의 40개 제목·53행 목표와 `seed_v5_gate_missions.sql`이 서로 맞는지 확인하는 자동 검사가 없다(실행 시 갱신 건수를 사람이 확인하는 절차로만 막혀 있다). 에셋 제너레이터 쪽 공백은 그 담당 티켓에서 다룬다(레이어 번호 화면 표시 `LayerSidebar.tsx`·`AssetGeneratorPanel.tsx`, `apply-mission-images.mjs`의 `createPresetLoader`·`createTextOverflowDetector`·`makeContactSheet` 단위 테스트 없음).
- 구현 계획: 결정 후 작성한다.
- 관련 파일: `jam-web/src/app/admin/missions/MissionForm.tsx` 179줄, `jam-web/src/app/admin/gate-missions/GateMissionForm.tsx` 394줄, `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.test.tsx`, `jam-web/supabase/migrations/194_missions_condition_text_backfill.sql`
