# [UI] 미션 목록 카드의 「획득」 레이블 제거

## 핵심 요약

- 요구사항: 미션 목록 카드의 보상 행에서 보상 앞에 붙는 「획득」 레이블을 제거한다(사용자 요청, 2026-09-27).
- 구현 계획: 보상 행의 레이블 `<span>`을 지우고, 더 쓰지 않는 사전 키 `cardRewardLabel`을 지운다. 「조건」 레이블(잠김 카드의 조건 행)은 그대로 둔다.
- 관련 파일: `jam-web/src/app/(main)/missions/MissionsListClient.tsx` 463~467줄(보상 행 `reward` 렌더), `jam-web/src/lib/i18n/ko.ts` 695~698줄(`cardConditionLabel`·`cardRewardLabel`)

## 배경 / 문제 정의

티켓 20260923_1353에서 목록 카드에 「조건」과 「획득」 두 행 레이블을 넣었다. 보상 행은 보상 배지 칩과 배지 이름만으로 뜻이 전달되므로 「획득」 글자를 없애 달라는 요청이 있었다.

## 상세 요구사항

- 목록 카드 보상 행에 「획득」 글자가 보이지 않고, 보상(배지 칩·이름·포인트)만 표시된다.
- 잠김 카드의 「조건」 행과 문장 안의 「획득하면」 같은 문구는 바꾸지 않는다(레이블이 아니다).
- 상세 화면과 다른 목록·문구는 바꾸지 않는다.

## 구현 계획

경미 수정(경로 ①): 파일 2개, 삭제 3줄. `cardRewardLabel` 참조를 `git grep`으로 확인했고 사용처는 이 화면 1곳뿐이다(문서·테스트·스토리 참조 없음).

## 완료 조건

- 미션 목록에서 「획득」만 있는 레이블이 없다. 「조건」 레이블은 그대로다.
- `npx eslint`와 `npm run typecheck`가 통과한다.
