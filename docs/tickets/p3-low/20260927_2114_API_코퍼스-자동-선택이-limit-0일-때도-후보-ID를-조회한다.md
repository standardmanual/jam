# [API] 코퍼스 자동 선택이 limit 0 이하일 때도 후보 ID를 조회한다

## 핵심 요약

- 요구사항: `selectCorpusForType`의 `resolveIds()`가 `limit <= 0`이고 명시 ID가 없을 때도 `listActive*Ids()`로 후보 전체를 조회한 뒤 `pickRotating`에서 버린다(불필요한 DB 조회). `limit <= 0`이면 조회 없이 빈 목록을 돌려준다.
- 구현 계획: `resolveIds()` 앞머리에 `limit <= 0` 조기 반환 1줄 + 테스트 1건(조회 함수가 불리지 않음).
- 관련 파일: `jam-web/src/lib/content-corpus/select.ts` 약 83~93행 `resolveIds`, `jam-web/src/lib/content-corpus/__tests__/content-corpus.test.ts`

## 배경 / 문제 정의

티켓 20260927_2034 게이트 리뷰(민지)의 범위 밖 발견물 `[성능/참고]`. 동작 결과는 맞고(빈 결과) 조회 1회가 낭비될 뿐이다. 라우트는 `limit` 파라미터가 0 이하이면 기본값 3으로 바꾸므로 API 경로에서는 발생하지 않고, 함수를 직접 부르는 경로에서만 생긴다.

## 완료 조건

- `limit = 0`으로 부르면 `listActive*Ids`가 호출되지 않는다(단위 테스트).
- 기존 테스트가 통과한다.
