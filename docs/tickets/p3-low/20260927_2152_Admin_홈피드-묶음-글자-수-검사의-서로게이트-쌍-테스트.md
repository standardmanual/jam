# [Admin] 홈피드 묶음 글자 수 검사에 이모지(서로게이트 쌍) 테스트를 더한다

## 핵심 요약

- 요구사항: `visibleLength`가 `[...s].length`를 쓰는 이유(이모지·서로게이트 쌍 보정)를 검증하는 테스트가 없다. 경계값 테스트가 모두 한글이다.
- 구현 계획: 테스트만 추가한다. 테스트가 결함을 드러내면 같은 티켓에서 고친다.
- 관련 파일: `jam-web/scripts/asset-generator/registerHomeFeedBundle.mjs` 약 133~135행, 테스트 `jam-web/scripts/asset-generator/__tests__/registerHomeFeedBundle.test.ts` 약 374~403행

## 배경 / 문제 정의

2026-09-27 `/jam-ship` 5단계 병렬 점검(민지 모드 ③, 범위 `origin/main..origin/staging` = 2c7e909..b491fbe)의 테스트 공백 발견물이다. 승격을 막지 않는 항목이라 범위 밖 발견물 규칙(`jam-work` SKILL 3.2절)으로 티켓화했다. 원 티켓: 20260927_2034·2035·2036.
