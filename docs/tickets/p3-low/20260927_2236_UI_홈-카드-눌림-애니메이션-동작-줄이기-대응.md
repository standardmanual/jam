# [UI] 홈 카드의 눌림 애니메이션이 동작 줄이기 설정(prefers-reduced-motion)을 따르게 한다

> **연결 메모 (2026-09-30 티켓 20260930_1451 사용자 결정):** 20260930_1453(홈피드 카드 표현 형식 리뉴얼) 구현 뒤로 미룬다. 리뉴얼 전에 고치면 다시 뜯긴다.
>
> **연결 메모 (2026-09-30 티켓 20260930_1453 설계 결정 15):** 1453-b 구현 조각에 흡수한다(`.jam-press`와 새 토큰 `--scale-press-card`, 사용자 승인).

## 핵심 요약
- 요구사항: 홈 카드의 `active:scale-[0.98] transition-transform`이 운영체제의 동작 줄이기 설정을 켠 유저에게도 그대로 동작한다. 설정을 켠 유저에게는 확대·축소를 끈다.
- 구현 계획: 전역 규칙(예: `motion-reduce:` 변형 또는 전역 CSS) 중 어느 쪽이 맞는지 채원이 판정한다.
- 관련 파일: `jam-web/src/app/(main)/TodayStatusStrip.tsx`, `jam-web/src/app/(main)/TodayCardStack.tsx`, `jam-web/src/app/(main)/OnboardingQuestCard.tsx`

## 배경 / 문제 정의
티켓 20260927_2133 채원 사후 리뷰가 지적했다. 새 카드만의 문제가 아니라 기존 홈 카드들의 공통 관례라 서비스 전체 개선 대상이다(범위 밖 발견물).

## 상세 요구사항
- 함께 처리: 홈 카드 세 곳의 눌림 효과 값(`active:scale-[0.98]`, `duration-100`)이 모션 토큰(`--scale-press: 0.96`, `--duration-micro` 80ms·`--duration-quick` 150ms)과 다르다. 토큰 값으로 맞출지, 100ms·0.98을 토큰으로 새로 등록할지 채원이 판정한다(티켓 20260927_2133 채원② 사후 리뷰 지적).
- 동작 줄이기 설정을 켠 환경에서 홈 카드를 눌러도 크기가 변하지 않는다.
- 설정을 끈 환경에서는 기존과 같이 동작한다.

## 구현 계획
채원 사전 판정(ds 연결 범위 포함) → 구현 → Story 동반 확인.

## 완료 조건
- 브라우저 개발자 도구에서 `prefers-reduced-motion: reduce`를 에뮬레이션하면 홈 카드 세 종류의 눌림 확대·축소가 사라진다.
- 에뮬레이션을 끄면 기존 눌림 효과가 그대로다.
- `scripts/verify.sh`가 통과한다.
