# [UI] TopNav 표시 전용(decorative) 모드의 동작 차단을 테스트로 고정한다

## 핵심 요약
- 요구사항: `decorative` 모드에서 로고·동기화 버튼·알림 종·아바타 네 요소가 클릭·포커스를 받지 않고, 기본 모드에서는 그대로 동작함을 자동 테스트로 고정한다.
- 구현 계획: TopNav 렌더 테스트(`inert` 속성 존재·부재 확인)를 추가한다.
- 관련 파일: `jam-web/src/components/ui/TopNav.tsx`(L94~161, `decorative` 래핑 4곳), 테스트 신규

## 배경 / 문제 정의
티켓 20260927_2330 게이트 리뷰(민지)의 범위 밖 발견물이다. 표시 전용 래핑 4곳에 자동화 테스트가 없어, 이후 리팩터링에서 조용히 깨져도 CI가 잡지 못한다.

## 상세 요구사항
- `decorative`가 true일 때 네 요소의 래퍼에 `inert`가 있다.
- `decorative`를 넘기지 않으면 `inert`가 없다.

## 구현 계획
TopNav 렌더 테스트 한 파일을 추가한다.

## 완료 조건
- 새 테스트가 두 경우를 모두 다루고 `scripts/verify.sh`가 통과한다.
