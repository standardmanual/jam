# [UI] 믹서 슬롯의 가방 열기 onClick이 Promise를 반환하지 않도록 정리한다

## 핵심 요약
- 요구사항: `CombineClient.tsx`의 슬롯 onClick `() => (fill ? undefined : openBagFor(slot))`가 async `openBagFor`의 Promise를 그대로 반환한다. 런타임 문제는 없지만 핸들러가 void를 반환하도록 `() => { if (!fill) void openBagFor(slot) }` 형태로 바꾼다.
- 구현 계획: 경미 수정(파일 1개·1줄). 동작 변화 없음.
- 관련 파일: `jam-web/src/app/(main)/combine/CombineClient.tsx` 슬롯 렌더부(약 L289, `MixerSlot` onClick)

## 배경 / 문제 정의
티켓 `20260927_2127`(온보딩 퀘스트 4~5단계)에서 `openBagFor`가 async가 되면서 생긴 형태다. 채원 사후 리뷰의 제안 항목(범위 밖 발견물)으로 자동 생성했다.

## 완료 조건
- onClick 핸들러가 값을 반환하지 않는다.
- 슬롯 탭 시 가방 시트가 열리는 기존 동작과 온보딩 퀘스트 `mix_fail` 기록 동작이 그대로다.
