# [Infra] jam-docs 스킬이 ACTIVITY_BADGES.md를 「액티비티배지 전체 목록」이라 서술하는 것을 실제 범위에 맞게 고친다

## 핵심 요약
- 요구사항: `.claude/skills/jam-docs/SKILL.md` L190은 `docs/service/content/ACTIVITY_BADGES.md`를 「액티비티배지 전체 목록」이라 서술한다. 실제로 이 문서는 v5 카탈로그(194계열·630종) 전용 생성 문서이며, `v5_doc_build.mjs`가 매번 전량 덮어쓴다. 그래서 JAM! 카테고리 배지(마이그레이션 156)와 퀘스트 클리어 배지(마이그레이션 196)는 이 문서에 없다.
- 구현 계획: 스킬 서술을 실제 범위로 고치고, 카탈로그 밖 액티비티 배지를 어디에 기록할지(생성 원천 확장 또는 별도 문서) 정한다.
- 관련 파일: `.claude/skills/jam-docs/SKILL.md` L190, `docs/assets/content-seed/v5_doc_build.mjs`, `docs/service/content/ACTIVITY_BADGES.md`

## 배경 / 문제 정의
티켓 `20260928_1212`(T7a) 게이트 리뷰에서 민지가 발견한 범위 밖 항목이다([정합성/참고]). T7a는 이 불일치 때문에 ACTIVITY_BADGES.md에 새 배지를 반영하지 않았다.

## 완료 조건
- 스킬 서술과 문서 실제 범위가 일치한다.
- 카탈로그 밖 액티비티 배지의 기록 위치가 정해져 있다.
