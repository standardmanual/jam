# [UI] 퀘스트 건너뛰기 실패 토스트가 서버 거부와 네트워크 오류를 구분하게 한다

## 핵심 요약
- 요구사항: `OnboardingQuestSkipSheet.tsx`의 `handleSkip()`은 응답 실패(`res.ok` false)와 네트워크 예외를 모두 `onboardingQuest.skip.saveFailed` 하나로 보여 준다. 기존 단계 기록 호출부처럼 네트워크 예외는 `d.common.networkError`로 나눌지 정한다.
- 구현 계획: 두 갈래 토스트로 나누고, 서버 거부 코드(`ALL_STEPS_DONE` 등)별 처리 필요 여부를 함께 판단한다.
- 관련 파일: `jam-web/src/app/(main)/OnboardingQuestSkipSheet.tsx` L16~24 `handleSkip`, `jam-web/src/lib/i18n/ko.ts` `onboardingQuest.skip.saveFailed`

## 배경 / 문제 정의
티켓 `20260927_2131`(T8) 게이트 리뷰에서 민지가 올린 범위 밖 발견물이다([주의]). T8은 채원 판정의 상태 표가 한 문구만 요구해 의도적으로 단순화했다. 우선순위는 기본값 P2에서 P3로 낮췄다 — 기능 스위치가 꺼져 있고, 문구가 틀린 것이 아니라 원인 안내가 덜 구체적인 수준이다.

## 완료 조건
- 네트워크 예외와 서버 거부가 서로 다른 토스트 문구로 안내된다.
