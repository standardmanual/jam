- 요구사항: 같은 확인 시트 조합(서비스 `BottomSheet` `detent="compact"` + 중앙 정렬 본문 + outline/primary 버튼 두 개)이 세 곳에 복제돼 있다. 공용 컴포넌트로 승격할지 채원 판정을 받는다.

- 관련 파일: `jam-web/src/app/(main)/OnboardingQuestSkipSheet.tsx`(T8 신규), `jam-web/src/app/(main)/drops/BadgeDetailSheet.tsx` L189~198(픽업 확정), `jam-web/src/components/PoiCarouselModal.tsx` L833~843(드랍 확정)
