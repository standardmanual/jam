# [Infra] 문서 카테고리 표가 루트 CLAUDE.md와 /jam-docs 스킬 두 곳에 있고 이미 서로 어긋났다

## 핵심 요약
- 요구사항: 문서 카테고리 5종과 위치를 한 곳(루트 `CLAUDE.md` 「문서 체계 개요」 표)에만 두고, `/jam-docs`는 그 표를 참조만 하게 한다(루트 CLAUDE.md 규칙 5 "같은 사실을 여러 문서에 적지 않는다").
- 구현 계획: 경미 수정(0.1절). `.claude/skills/jam-docs/SKILL.md` 「카테고리 판정 먼저」 절의 표 7줄을 참조 문장 3줄로 바꾼다.
- 관련 파일: `.claude/skills/jam-docs/SKILL.md` L10-20, 기준 `CLAUDE.md` L68-81·L88-98

## 배경 / 문제 정의
2026-09-28 `/doctor` 점검에서 찾았다. 두 표가 이미 달랐다:
- ③ 컨텐츠 대상: 루트 "액티비티배지·아이템북·아이템배지·트라이브·POI" / 스킬 "배지·아이템북·트라이브·POI"
- ④ 배지엔진 위치: 루트 `docs/specs/badge-engine/`(폴더) / 스킬 `docs/specs/badge-engine/BADGE_ENGINE_UNIFIED.md`(파일 하나). 실제 폴더에는 `CONDITION_JSON_SPEC.md`도 있어 루트 쪽이 맞다.

루트 CLAUDE.md를 단일 원천으로 정한 이유: 모든 에이전트 호출에 자동으로 포함되어, 스킬을 읽지 않는 서브에이전트(아현 등)도 문서를 고칠 때 같은 표를 본다.

## 완료 조건
- `/jam-docs`에 카테고리·위치 표가 없고, 루트 CLAUDE.md 표와 「폴더 = 수명주기」 표를 가리킨다.
- 스킬의 다른 절이 지운 표를 참조하지 않는다(`grep`으로 확인).
