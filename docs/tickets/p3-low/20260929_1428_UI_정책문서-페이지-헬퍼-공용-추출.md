# [UI] 정책 문서 페이지 헬퍼(Section·P·OrderedList·DefCard)를 공용 위치로 추출한다

## 핵심 요약
- 요구사항: `/privacy`와 `/location-terms`가 같은 로컬 헬퍼를 한 벌씩 들고 있다. 세 번째 정책 문서(서비스 이용약관, 티켓 20260929_1303 하단 B-6)가 생기기 전에 공용 위치로 뽑아 두 벌이 어긋나지 않게 한다.
- 구현 계획: `jam-web/src/components/legal/`(가칭)에 헬퍼를 옮기고 두 페이지가 import하도록 바꾼다. 클래스·토큰은 글자 그대로 유지해 화면 변화가 없어야 한다. MODULAR 승격 여부는 채원①이 그 시점에 다시 판정한다.
- 관련 파일: `jam-web/src/app/(main)/privacy/page.tsx`(31~92행 헬퍼), `jam-web/src/app/(main)/location-terms/page.tsx`(31~93행 헬퍼, `BulletList` 포함)

## 배경 / 문제 정의
티켓 20260929_1359에서 채원① 판정은 게시 일정과 회귀 위험을 이유로 헬퍼를 복사하게 했고, 공용 추출을 후속 P3로 제안했다. 민지도 같은 내용을 범위 밖 발견물([참고])로 올렸다.

## 완료 조건
- 두 페이지에 헬퍼 정의가 없고 공용 모듈을 import한다.
- 두 페이지의 렌더 결과(DOM 클래스)가 추출 전과 같다.
