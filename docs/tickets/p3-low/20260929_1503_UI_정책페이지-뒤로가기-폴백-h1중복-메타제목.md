# [UI] 정책 페이지의 뒤로가기 폴백·제목 h1 중복·탭 제목을 다듬는다

## 핵심 요약
- 요구사항: 티켓 20260929_1400에서 `(legal)` 라우트 그룹으로 옮긴 `/privacy`·`/location-terms`의 남은 문제 세 가지를 고친다.
  1. `LegalTopNav`의 뒤로가기는 `window.history.length > 1`이면 `router.back()`이다. 검색 결과·새 탭 페이지처럼 사이트 밖에서 들어오면 그 이전 페이지로 나가고, 빈 새 탭에서 주소를 입력해 들어온 경우 로컬 미리보기에서는 버튼을 눌러도 반응이 없었다(2026-09-29 카리나 실측). 사이트 안에서 온 경우만 `back()`하고 나머지는 `/`로 보내는 판정으로 바꾼다.
  2. DS `TopNav`가 제목을 `h1`로 그리고 본문에도 `h1`이 있어 문서에 `h1`이 두 개다(채원① 발견).
  3. 두 페이지에 `metadata.title`이 없어 공개 URL을 공유하면 탭 제목이 서비스 기본값 "JAM!"이다(채원① 제안).
- 관련 파일: `jam-web/src/app/(legal)/LegalTopNav.tsx`(14~20행 뒤로가기), `jam-web/src/app/(legal)/privacy/page.tsx`, `jam-web/src/app/(legal)/location-terms/page.tsx`, `jam-web/design-system/components/navigation/TopNav.jsx`(제목 태그)

## 완료 조건
- 사이트 밖에서 들어온 경우(첫 문서 로드의 `document.referrer`가 다른 출처이거나 비어 있음, 앱 안 이동 기록 없음) 뒤로 버튼을 누르면 `/`로 간다. 앱 안에서 들어온 경우는 이전 화면으로 간다.
- 두 페이지 문서의 `h1`이 하나다.
- 두 페이지의 브라우저 탭 제목이 각 문서 이름을 포함한다.
