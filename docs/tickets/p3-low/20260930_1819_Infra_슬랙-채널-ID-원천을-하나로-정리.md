# [Infra] 슬랙 채널 ID의 원천을 하나로 정리한다

> 상위: 20260930_1450 · 영향 티켓(진행 규칙 4) · 1455 시작 검토 D5에서 생성

## 핵심 요약

- 요구사항: `#jam-alert`·`#jam-report` 채널 ID가 두 문서에 함께 적혀 있고, 어느 쪽이 단일 원천인지 문서마다 다르게 말한다. 원천을 하나로 정하고
  나머지는 참조만 하게 고친다. 1816이 서버 환경변수로 채널 ID를 하나 더 두므로, 그 환경변수와 원천의 관계도 함께 적는다.
- 구현 계획: 원천 후보는 `.claude/skills/jam-work/references/scheduled-jobs.md` 「Slack 알림」 절(카리나 카드·운영툴 PRD §9가 가리킴)이다.
  `automation-list.md`와 `scripts/slack-post.mjs` 머리말의 ID와 원천 문장을 참조로 바꾸고, 필요하면 `contract.json`에 두 값이 같은지 검사하는 줄을 더한다.
- 관련 파일: `.claude/skills/jam-work/references/scheduled-jobs.md:156-157`, `.claude/skills/jam-work/references/automation-list.md:56-57`,
  `scripts/slack-post.mjs:9-12`, `docs/agents/orchestrator.md`(카드의 Slack 문단), `docs/specs/prd/ops-tool/PRD.md` §9, `docs/agents/contract.json`.

## 배경

CLAUDE.md 규칙 5는 같은 사실을 여러 문서에 적지 않는다고 정한다. 지금은 `scheduled-jobs.md`와 `automation-list.md`에 같은 채널 ID가 있고,
`slack-post.mjs` 머리말은 `automation-list.md`를, 카리나 카드와 운영툴 PRD §9는 `scheduled-jobs.md`를 원천이라고 적는다.

## 완료 조건

- 채널 ID 값이 원천 문서 한 곳에만 있고, 나머지 문서와 스크립트 머리말은 그 절을 가리킨다.
- 1816의 서버 환경변수(채널 ID)가 원천 값과 같아야 한다는 문장이 원천 문서에 있다.
- `scripts/verify.sh`가 통과한다.

### 구현 내용 요약

- 원천을 `.claude/skills/jam-work/references/scheduled-jobs.md` 「Slack 알림」 표로 정했다. 카리나 카드(`docs/agents/orchestrator.md`)·
  운영툴 PRD §9·`docs/specs/prd/04_PROJECT_SPEC.md` 환경변수 표가 이미 이 절을 가리키고 있어 가장 적게 바꾸는 쪽이다.
- 원천 절에 「단일 원천은 이 표다」 문장과, 1816의 Vercel 환경변수 `SLACK_CHANNEL_JAM_REPORT`·`SLACK_CHANNEL_JAM_ALERT`가
  표의 값과 같아야 하고 ID를 바꾸면 같은 날 Vercel 두 프로젝트 값도 바꾼다는 문장을 넣었다.
- `automation-list.md` 「Slack 채널」 표에서 ID 열을 빼고 원천을 가리키는 줄로 바꿨다. `scripts/slack-post.mjs` 머리말은 원천을
  `scheduled-jobs.md`로 고치고 ID와 실제 ID가 든 사용 예시를 `<채널 ID>`로 바꿨다.
- 티켓 「관련 파일」에 없던 카즈하 정의 `.claude/agents/jam-ops.md`(옛 139~140줄)에도 ID가 있어 같은 방식으로 원천을 가리키게 했다.
- `scripts/slack-post.test.mjs`의 시험용 채널 값을 실제 ID에서 가짜 값 `C0TESTCHAN1`로 바꿨다(게시 값 전달만 검증하므로 실제 ID가 필요 없다).
- `docs/agents/contract.json` `stale_phrases`에 두 ID(허용 위치: `scheduled-jobs.md`만)와 옛 원천 문장 「automation-list.md "Slack 채널" 절이다」를
  더해, 원천 밖에 ID가 다시 적히면 커밋이 막히게 했다.

### 주요 의사결정 / 핵심 메모
- 유형은 `docs`(카리나 직접)로 판정했다. 바뀐 것이 문서·에이전트 정의·스크립트 머리말 주석·시험 값뿐이고 동작 로직은 없다.
- `scheduled-jobs.md` 윤진 주간 프롬프트 초안 안의 `--channel C0C2U1T186M`은 원천 파일 안에 있고, 루틴 저장 프롬프트와 글자 단위로 대조하는 초안이라 그대로 뒀다.
  저장 프롬프트(저장소 밖)는 `stale_phrases`가 볼 수 없으므로 ID를 바꿀 때 함께 고친다는 문장을 원천 절에 넣었다.
- `contract.json`에 「두 값이 같은지」를 비교하는 새 검사 종류를 만드는 대신, 기존 `stale_phrases`의 `allow_in`으로 「원천 밖 재기재 금지」를 걸었다.
  값이 한 곳에만 있으면 비교할 짝이 없으므로 이쪽이 더 단순하다. Vercel 환경변수 값은 저장소 밖이라 기계 검사하지 않는다.
