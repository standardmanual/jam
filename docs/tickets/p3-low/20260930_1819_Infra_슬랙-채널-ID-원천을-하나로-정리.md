# [Infra] 슬랙 채널 ID의 원천을 하나로 정리한다

> 상위: 20260930_1450 · 영향 티켓(진행 규칙 4) · 1455 시작 검토 D5에서 생성

## 핵심 요약

- 요구사항: `#jam-alert`·`#jam-report` 채널 ID가 두 문서에 함께 적혀 있고, 어느 쪽이 단일 원천인지 문서마다 다르게 말한다. 원천을 하나로 정하고
  나머지는 참조만 하게 고친다. 1816이 서버 환경변수로 채널 ID를 하나 더 두므로, 그 환경변수와 원천의 관계도 함께 적는다.
- 구현 계획: 원천 후보는 `.claude/skills/jam-work/references/scheduled-jobs.md` 「Slack 알림」 절(카리나 카드·운영툴 PRD §9가 가리킴)이다.
  `automation-list.md`와 `scripts/slack-post.mjs` 머리말의 ID와 원천 문장을 참조로 바꾸고, 필요하면 `contract.json`에 두 값이 같은지 검사하는 줄을 더한다.
- 관련 파일: `.claude/skills/jam-work/references/scheduled-jobs.md:156-157`, `.claude/skills/jam-work/references/automation-list.md:56-57`,
  `scripts/slack-post.mjs:9-12`, `docs/agents/orchestrator.md`(카드의 Slack 문단), `docs/specs/prd/ops-tool/PRD.md` §9, `docs/agents/contract.json`.

## 배경

CLAUDE.md 규칙 5는 같은 사실을 여러 문서에 적지 않는다고 정한다. 지금은 `scheduled-jobs.md`와 `automation-list.md`에 같은 채널 ID가 있고,
`slack-post.mjs` 머리말은 `automation-list.md`를, 카리나 카드와 운영툴 PRD §9는 `scheduled-jobs.md`를 원천이라고 적는다.

## 완료 조건

- 채널 ID 값이 원천 문서 한 곳에만 있고, 나머지 문서와 스크립트 머리말은 그 절을 가리킨다.
- 1816의 서버 환경변수(채널 ID)가 원천 값과 같아야 한다는 문장이 원천 문서에 있다.
- `scripts/verify.sh`가 통과한다.
