# [Admin] 어드민 편집 화면 상태 칩의 「bad」 톤 글자 대비가 기준에 못 미친다

## 핵심 요약

- 요구사항: `SectionStatusBadge`의 bad 톤(연한 붉은 배경 위 붉은 글)이 대비 3.99로, 12px 글자 기준 4.5에 못 미친다. 흰 배경에 붉은 테두리·붉은 글처럼
  기준을 넘는 조합으로 바꾼다.
- 구현 계획: 운영툴 상태 칩(티켓 20260930_1817 「채원 화면 설계」의 상태 표)에서 채원이 대비를 실측해 고른 조합(`border-destructive bg-background text-destructive`,
  흰 배경 위 4.76)을 따른다.
- 관련 파일: `jam-web/src/components/admin/AdminEditorLayout.tsx`(116 `SectionStatusBadge`의 톤 분기).

## 배경

2026-09-30 티켓 20260930_1817의 화면 설계 중 채원이 발견했다(범위 밖 발견물, `/jam-work` 3.2절 자동 티켓화). `bg-destructive/10` 위 `text-destructive`는 3.99다.

## 완료 조건

- bad 톤 칩의 글자와 배경의 대비가 4.5 이상이다(계산 근거를 완료 기록에 남긴다).
- 상태를 색만으로 구분하지 않는다(글자가 함께 있다).
- `scripts/verify.sh`가 통과한다.
