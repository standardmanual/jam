# [API] 운영 묶음과 홈피드 등록 묶음의 날짜 검사가 없는 날짜(2월 31일)를 통과시킨다

## 핵심 요약

- 요구사항: 시각 검사가 `Date.parse`를 쓰므로 `2026-02-31T00:00:00Z` 같은 없는 날짜가 통과해 3월 3일로 저장된다. 두 검증에서 함께 거른다.
- 구현 계획: ISO 문자열의 연·월·일을 직접 꺼내 달력에 있는 날짜인지 확인한다. 등록 스크립트와 운영 묶음 검증이 같은 결과를 내는 대조 테스트(1816)를 유지하도록 두 곳을 함께 고친다. 등록 스크립트는 지금 운영 절차가 쓰므로(1450 진행 규칙 7) 동작 변화를 티켓에 적는다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/validate.ts`(72-74, 206 부근 시각 검사), `jam-web/scripts/asset-generator/registerHomeFeedBundle.mjs`(시각 검사 함수), 두 곳의 테스트.

## 배경

2026-09-30 1816 게이트에서 민지가 찾았다(sideFindings 3, 정확성/참고). 등록 스크립트와 같은 동작이라 1816의 「같게 구현」 계획에는 맞다.

## 완료 조건

- `2026-02-31T00:00:00Z`처럼 달력에 없는 날짜는 두 검증 모두에서 형식 오류다(테스트).
- 정상 날짜와 시간대 표기는 지금처럼 통과한다.
