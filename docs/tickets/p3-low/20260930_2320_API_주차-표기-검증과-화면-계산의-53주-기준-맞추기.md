# [API] 제출 검증과 받은 기획함 화면이 53주차를 다르게 판정하는 문제를 맞춘다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20260930_1817, 2026-09-30)이다.

## 핵심 요약

- 요구사항: 제출 검증은 `week`의 주 번호를 1~53이면 모두 받는데, 받은 기획함 화면은 53주가 없는 해(예: 2025-W53)를 「주차 없음」으로 그린다. 두 판정을 ISO 주차 기준 하나로 맞춘다.
- 구현 계획: 착수 때 관련 파일의 해당 함수를 열어 고친다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/validate.ts:302`(`weekNo > 53` 검사, 주차 형식 검증), `jam-web/src/lib/admin/opsInbox/labels.ts:154`(`formatWeekRange`), 운영툴 PRD §3.1

## 완료 조건

- 53주가 없는 해의 W53을 제출하면 주차 형식 오류로 저장되고 응답의 형식 오류 목록에 나온다. 53주가 있는 해(예: 2026-W53)는 오류가 없고 화면이 월~일 범위를 그린다. 두 경우를 validate·labels 테스트가 같은 입력으로 고정한다.
