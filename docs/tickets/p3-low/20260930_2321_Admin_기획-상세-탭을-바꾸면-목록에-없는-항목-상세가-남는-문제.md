# [Admin] 기획 상세의 가운데 탭을 바꿔도 목록에 없는 항목의 상세가 남는 문제를 고친다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20260930_1817, 2026-09-30)이다.

## 핵심 요약

- 요구사항: 기획 상세(S3)에서 가운데 탭을 바꿔도 선택 항목이 전체 항목 기준으로 유지돼, 「멈춘 것」 탭에서 결정 전 항목의 상세가 보이는 식으로 목록과 상세가 어긋날 수 있다. 탭을 바꿨을 때 선택 항목이 그 탭 목록에 없으면 그 탭의 첫 항목(없으면 빈 상세)으로 옮긴다.
- 구현 계획: 착수 때 관련 파일의 해당 함수를 열어 고친다.
- 관련 파일: `jam-web/src/components/admin/ops/OpsBundleWorkspace.tsx:116`(`selectedItem` 계산, 가운데 탭 상태), 티켓 20260930_1817 「채원 화면 설계」 S3 가운데 열

## 완료 조건

- 가운데 탭을 바꾸면 상세 카드가 늘 지금 탭 목록에 있는 항목이거나, 목록이 비었으면 빈 상태 문구를 보인다. `?item=`도 같은 항목을 가리킨다. 렌더 테스트가 탭 전환 뒤 선택 항목을 고정한다.
