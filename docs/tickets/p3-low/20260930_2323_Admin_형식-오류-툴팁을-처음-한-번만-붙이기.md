# [Admin] 「형식 오류」 풀이 툴팁을 설계대로 화면에서 처음 한 번만 붙인다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20260930_1817, 2026-09-30)이다.

## 핵심 요약

- 요구사항: 채원 설계는 「형식 오류」를 처음 한 번만 툴팁으로 「제출 형식에 맞지 않는 곳」이라 풀어 준다고 했는데, 구현은 요약 알림과 항목 상세 제목마다 툴팁을 붙인다. 동작에는 문제가 없어 우선순위가 낮다.
- 구현 계획: 착수 때 관련 파일의 해당 함수를 열어 고친다.
- 관련 파일: `jam-web/src/components/admin/ops/OpsFormatErrors.tsx:24`(툴팁 부품), 티켓 20260930_1817 「채원 화면 설계」 크래프트 항목

## 완료 조건

- 한 화면(S2 또는 S3)에서 「형식 오류」 풀이 툴팁이 처음 나오는 한 곳에만 붙는다. 렌더 테스트가 툴팁 개수를 고정한다.
