# [Admin] 어드민 공용 일괄 확인창의 「처리 중...」 문구를 UX 라이팅 규칙의 진행형으로 바꾼다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20260930_1818, 2026-10-01)이다.

## 핵심 요약

- 요구사항: 공용 `BulkConfirmDialog`의 처리 중 버튼 문구가 「처리 중...」이다. UX 라이팅 가이드 §5.3은 이 표기를 금지하고 「…하는 중」 진행형을 쓰게 한다. 운영툴의 시험 묶음 지우기 창을 포함해 이 부품을 쓰는 모든 일괄 처리 창에 해당한다. 호출부가 동사를 넘기게 하거나 기본 문구를 바꾼다.
- 구현 계획: 착수 때 관련 파일의 해당 구간을 열어 고친다.
- 관련 파일: `jam-web/src/components/admin/data-table/data-table-bulk-confirm-dialog.tsx:107`, 호출부(`grep -rn BulkConfirmDialog jam-web/src`), `docs/service/writing/UX_WRITING_GUIDELINE.md` §5.3

## 완료 조건

- 일괄 확인창이 처리 중일 때 「처리 중...」 대신 「삭제하는 중」처럼 그 동작의 진행형이 보인다. 호출부마다 알맞은 동사가 들어간다. 렌더 테스트가 문구를 고정한다.
