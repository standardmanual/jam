# [Infra] 운영 결정 기록 테이블의 action 컬럼 주석을 지금 쓰는 값에 맞춘다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20260930_1818, 2026-10-01)이다.

## 핵심 요약

- 요구사항: `ops_decisions.action` 컬럼 주석이 「이 티켓은 submit만 쓴다」로 남아 있는데 1818부터 approve·reject·edit·revert도 쓴다. PRD와 02_DATA_MODEL은 갱신됐다. 이미 적용된 198 파일은 고치지 않고, `COMMENT ON COLUMN`만 담은 새 마이그레이션을 만든다.
- 구현 계획: 착수 때 관련 파일의 해당 구간을 열어 고친다.
- 관련 파일: `jam-web/supabase/migrations/198_ops_inbox.sql:114`(지금 주석), 새 마이그레이션(번호는 원격 staging 기준으로 확인), `.claude/skills/jam-work/references/db-migration-rules.md`, `docs/specs/prd/02_DATA_MODEL.md`

## 완료 조건

- DB에서 `ops_decisions.action` 주석이 submit·approve·reject·edit·revert를 적는다(`col_description`으로 확인). 마이그레이션 파일에 되돌림 SQL(이전 주석)이 있다. 실행은 사용자 승인 뒤 메인 세션이 한다.
