# [Admin] 색 입력칸의 견본이 검증하지 않은 색 문자열을 그대로 style에 넣는 문제를 막는다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20260930_1818, 2026-10-01)이다.

## 핵심 요약

- 요구사항: 어드민 공용 `BackgroundColorField`의 견본이 들어온 색 문자열을 검증 없이 `style.backgroundColor`에 넣는다. 잘못된 CSS는 브라우저가 무시해 실해는 없지만, 운영툴 수정 양식은 에이전트가 제출한 색을 그대로 넘기므로 PRD §6.1 「색 견본은 #rrggbb일 때만 그린다」와 어긋난다. 같은 파일의 `HEX_COLOR_PATTERN`을 통과할 때만 견본을 칠한다.
- 구현 계획: 착수 때 관련 파일의 해당 구간을 열어 고친다.
- 관련 파일: `jam-web/src/components/admin/BackgroundColorField.tsx:38`(견본 style), 같은 파일 12줄 `HEX_COLOR_PATTERN`, 운영툴 PRD §6.1

## 완료 조건

- `#rrggbb`가 아닌 값을 넣으면 견본이 빈 칸(또는 무늬)으로 보이고 style에 그 값이 들어가지 않는다. 올바른 값은 지금처럼 칠해진다. 렌더 테스트가 두 경우를 고정한다.
