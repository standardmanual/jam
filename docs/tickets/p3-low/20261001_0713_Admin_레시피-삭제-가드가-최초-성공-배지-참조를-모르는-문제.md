# [Admin] 레시피 삭제 가드가 「레시피 최초 성공」 배지의 참조를 모르는 문제를 고친다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20261001_0631, 2026-10-01)이다.

## 핵심 요약

- 요구사항: 레시피 삭제 가드의 참조 목록이 비어 있어(`recipe-references.ts:19-21`) `recipe_first_success` 조건이 가리키는 레시피도 지울 수 있다. 지우면 그 배지는 영원히 발급되지 않고, 그 배지를 수정 저장하면 병합된 조건이 「존재하지 않는 레시피 ID」로 막혀 이름조차 고칠 수 없다. 삭제 가드가 이 참조를 알게 하거나, 수정 저장 때 조건이 바뀌지 않았으면 존재 검증을 건너뛴다.
- 구현 계획: 착수 때 관련 파일의 해당 구간을 열어 고친다.
- 관련 파일: `jam-web/src/lib/admin/recipe-references.ts:19-21`, `jam-web/src/app/api/admin/badges/[id]/route.ts:74-79`, `jam-web/src/lib/admin/badge-validation.ts`(`findRecipeFirstSuccessNotFoundError`)

## 완료 조건

- `recipe_first_success` 배지가 가리키는 레시피를 지우려 하면 막히거나 경고가 나온다(테스트). 레시피가 없어진 배지도 이름·설명은 고쳐 저장할 수 있다(테스트).
