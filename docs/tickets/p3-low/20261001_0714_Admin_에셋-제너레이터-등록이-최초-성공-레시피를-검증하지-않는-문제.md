# [Admin] 에셋 제너레이터 배지 등록이 「레시피 최초 성공」 레시피 존재를 검증하지 않는 문제를 고친다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20261001_0631, 2026-10-01)이다.

## 핵심 요약

- 요구사항: 어드민 API는 `recipe_first_success`의 레시피 ID 형식·존재를 검증하지만, 에셋 제너레이터 등록 경로는 `checkin_badge_count`만 DB로 검증하고 이 키는 타지 않는다. 등록 경로도 같은 검증을 거치게 한다.
- 구현 계획: 착수 때 관련 파일의 해당 구간을 열어 고친다.
- 관련 파일: `jam-web/scripts/asset-generator/registerFlow.mjs:146`, `jam-web/src/lib/admin/badge-validation.ts`

- 참고(민지, 티켓 20261001_0712 게이트): 에셋 제너레이터의 `jam-web/scripts/asset-generator/registerBundle.mjs:219`는 동기 형태 검사 `findBadgeConditionSaveError`를 이미 부른다.
  그래서 「사용량 지표 둘 이상」 같은 형태 가드는 등록 경로에도 걸린다. 빠진 것은 비동기 레시피 존재 검사(`findRecipeFirstSuccessNotFoundError`)뿐이다.

## 완료 조건

- 없는 레시피 ID를 가진 `recipe_first_success` 배지를 에셋 제너레이터로 등록하면 거절된다(테스트).
