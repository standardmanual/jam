# [BadgeEngine] 「레시피 최초 성공」 배지를 같은 계열·이름으로 여러 개 두면 일부가 발급되지 않는 문제를 막는다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20261001_0631, 2026-10-01)이다.

## 핵심 요약

- 요구사항: 공용 발급기는 레벨형이면 보유 레벨+1부터, 등급형이면 같은 이름 그룹의 최상위 1개만 발급한다. `recipe_first_success` 배지를 같은 `family_key`나 같은 이름으로 레시피만 달리해 여러 개 만들면, 조건을 채운 유저가 일부만 받거나 못 받는다. 저장 때 이 조합을 막거나 운영 규칙과 어드민 안내로 둔다.
- 구현 계획: 착수 때 관련 파일의 해당 구간을 열어 고친다.
- 관련 파일: `jam-web/src/lib/badge-engine/usageBadges.ts:157-192`, `jam-web/src/lib/admin/badge-condition-guards.ts`

## 완료 조건

- 같은 계열·이름으로 레시피만 다른 `recipe_first_success` 배지를 저장하려 하면 막히거나 경고가 나온다(테스트).
