# [BadgeEngine] 사용량 지표 가드를 레지스트리로 옮긴 뒤 남은 주석을 정리한다

> 민지 게이트 리뷰의 범위 밖 발견물(티켓 20261001_0631, 2026-10-01)이다.

## 핵심 요약

- 요구사항: 가드 배열을 지운 뒤 `badge-condition-guards.ts`에 고아 JSDoc 블록이 남아 두 개가 연달아 붙어 있고, `badge-labels.ts:91`의 「비공개 USAGE_METRIC_CONDITION_KEYS」 설명이 이제 사실과 다르다(레지스트리의 공개 목록이 단일 정의다). 1456 하위 ②(20261001_0632)가 같은 파일을 만지면 그때 함께 고쳐도 된다.
- 구현 계획: 착수 때 관련 파일의 해당 구간을 열어 고친다.
- 관련 파일: `jam-web/src/lib/admin/badge-condition-guards.ts:86-94`, `jam-web/src/lib/admin/badge-labels.ts:91`

- 추가(민지, 티켓 20261001_0712 게이트): 테스트 describe 제목 「네 검사를 한 진입점에서 돌린다」(`jam-web/src/lib/admin/__tests__/badge-condition-guards.test.ts:388`)가
  `findConditionShapeSaveError`가 돌리는 검사 수와 맞지 않는다. 개수를 빼는 쪽으로 함께 고친다.

## 완료 조건

- 두 파일의 주석이 지금 코드(레지스트리의 `USAGE_METRIC_CONDITION_KEYS`가 단일 정의)와 맞는다.
