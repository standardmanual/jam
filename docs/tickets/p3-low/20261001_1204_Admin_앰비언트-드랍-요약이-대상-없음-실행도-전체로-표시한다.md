# [Admin] 앰비언트 드랍 실행 요약과 크론 로그가 «대상 컬렉션 없음»으로 건너뛴 실행도 「전체 컬렉션」으로 표시한다

> 아현 구현 요약과 민지 게이트 리뷰의 범위 밖 발견물 [참고](티켓 20260930_1516, 2026-10-01)이다.

## 핵심 요약

- 요구사항: 1516 이후 앰비언트 드랍은 노출 중 컬렉션이 없으면 `no_eligible_collection`으로 건너뛰고 `effectiveCollectionIds`를 빈 배열로 남긴다. 어드민 실행 요약과 크론 로그는
  빈 배열을 「전체 컬렉션」으로 표시해서, 건너뛴 실행이 전체에 드랍한 것처럼 읽힐 수 있다.
- 구현 계획: 건너뛴 사유가 있으면 「대상 컬렉션 없음(건너뜀)」으로 표시하고, 사유 원문 대신 한국어 문구를 쓴다.
- 관련 파일: `jam-web/src/app/admin/ambient-drop/AmbientDropForm.tsx:62`, `jam-web/src/app/api/cron/ambient-drop/route.ts:51`, `jam-web/src/lib/ambient-drop/index.ts`(`excludedCollectionIds`·스킵 사유)

## 완료 조건

- `no_eligible_collection`으로 건너뛴 실행은 어드민 요약과 크론 로그에서 「전체 컬렉션」으로 표시되지 않는다(테스트 또는 로컬 실렌더).
