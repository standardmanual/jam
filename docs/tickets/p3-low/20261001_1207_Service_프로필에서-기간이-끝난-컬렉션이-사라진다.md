# [Service] 프로필 컬렉션 목록에서 기간이 끝난 컬렉션이 사라진다 (결정 E1과의 판정 차이)

> 민지 게이트 리뷰의 범위 밖 발견물 [참고](티켓 20260930_1516, 2026-10-01)이다. 기획 판단이 먼저 필요하다.

## 핵심 요약

- 요구사항: 1516 결정 E1은 «기간이 끝난 컬렉션은 드랍만 멈추고 화면은 유지한다»다. 그런데 프로필 컬렉션 목록은 «노출 중» 판정을 써서 기간이 끝난 컬렉션을 숨긴다.
  보유자는 프로필에서 종료된 컬렉션을 찾을 수 없고 주소로만 닿는다. 프로필도 «공개됨» 판정으로 바꿀지(종료 표시 포함) 정한다.
- 구현 계획: 착수 때 혜린 검토로 정한다. 바꾸기로 하면 프로필 목록·유저 컬렉션 API의 조회를 «공개됨» 판정으로 바꾸고 종료 상태를 표시한다.
- 관련 파일: `jam-web/src/app/(main)/[username]/collections/page.tsx:100`, `jam-web/src/app/(main)/[username]/page.tsx:140`, `jam-web/src/app/api/users/[username]/itembooks/route.ts:75`,
  `docs/service/prd/02_DATA_MODEL.md` «컬렉션 노출 판정»

## 완료 조건

- 프로필에서 기간이 끝난 컬렉션을 어떻게 보여 줄지 결정이 이 티켓에 있다.
- 결정대로 바뀌어 있고 테스트가 있다(바꾸지 않기로 했으면 그 사유와 02 문서 기재).
