# [Admin] 운영툴 설정 화면(S7)의 슬랙 알림 대상과 제출 토큰 상태 구역

> 상위: 20260930_1450 · 20260930_1459 시작 검토에서 분리(담당 티켓이 없던 구역, 2026-10-01 사용자 승인)

## 핵심 요약

- 요구사항: 07 4.3의 S7은 밸런스 규칙 값, 슬랙 알림 대상, 제출 토큰 상태의 세 구역인데 담당 티켓은 밸런스 규칙(1459)뿐이다. 나머지
  두 구역을 만든다.
- 선행 조건: 20260930_1819(슬랙 채널 ID의 원천이 두 문서로 나뉜 문제)를 먼저 정리한다. 슬랙 알림 대상을 화면에서 고치게 하면 원천이
  하나 더 생길 수 있기 때문이다. S7 화면 골격은 1459의 조각 B가 만든다.
- 관련 파일: `docs/specs/prd/ops-tool/PRD.md` §6(S7), `jam-web/src/lib/admin/opsInbox/slack.ts`, `jam-web/src/lib/admin/opsInbox/auth.ts`.

## 완료 조건

- S7에서 슬랙 알림 대상과 제출 토큰 상태를 볼 수 있다. 무엇을 화면에서 고칠 수 있게 할지는 착수할 때 혜린 검토와 사용자 질문으로 정한다.
