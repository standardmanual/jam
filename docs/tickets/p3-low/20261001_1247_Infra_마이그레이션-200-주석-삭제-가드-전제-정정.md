# [Infra] 마이그레이션 200의 주석이 「레시피 삭제 가드는 참조가 없다는 전제」를 서술한다

> 티켓 20261001_1200 게이트 리뷰(민지)의 범위 밖 발견물 `[정확성/참고]`

## 핵심 요약

- 요구사항: `jam-web/supabase/migrations/200_user_combine_success_logs.sql:12-13`의 주석이 레시피 삭제 가드가 「이 레시피를 참조하는 행이 없다」는 전제로 동작한다고 적는다.
  1200부터 가드가 배지 조건 `recipe_first_success`를 센다. 지금 사실의 원천은 `docs/service/prd/02_DATA_MODEL.md`다.
- 구현 계획: 이미 적용된 마이그레이션 파일의 주석만 고칠지, 그대로 두고 02_DATA_MODEL을 원천으로 삼는다는 관례만 확인할지 정한다. 실행 SQL은 바꾸지 않는다.
- 관련 파일: `jam-web/supabase/migrations/200_user_combine_success_logs.sql:12-13`, `.claude/skills/jam-work/references/db-migration-rules.md`(적용된 파일 수정 관례).

## 완료 조건

- 주석을 고쳤거나, 고치지 않는 근거(적용된 마이그레이션은 이력이라 손대지 않는다)를 이 티켓에 남겼다.
