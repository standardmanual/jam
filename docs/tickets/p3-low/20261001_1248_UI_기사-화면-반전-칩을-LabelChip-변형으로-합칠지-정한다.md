# [UI] 기사 화면의 반전 색조 칩을 `LabelChip tone="inverse"`로 합칠지 정한다

## 핵심 요약

- 요구사항: 기사 화면 `jam-web/src/app/(main)/today/[cardId]/page.tsx` 50줄의 칩(`bg-surface-inverse text-text-inverse`, `leading-none` 없음)이
  MODULAR `LabelChip`(티켓 20261001_1204)의 네 번째 복제다. 색조와 줄 높이가 달라 1204의 「픽셀 동일」 범위에서 뺐다.
- 구현 계획: `LabelChip`에 `tone="inverse"` 변형을 더할지 채원이 판정한다. 변형 추가는 새 디자인 결정이라 **사용자 승인이 필요하다**.
  기사 화면은 1453-b3에서 다시 그리므로, b3 착수 때 함께 판정하는 것이 가장 싸다.
- 관련 파일: `jam-web/src/app/(main)/today/[cardId]/page.tsx` 50~52줄, `jam-web/design-system/components/cards/LabelChip.jsx`·`.d.ts`·`.stories.tsx`

## 배경 / 문제 정의

- 티켓 20261001_1204 채원② 사후 리뷰 승격 후보와 민지 범위 밖 발견물 [구조/참고]이다.

## 완료 조건

- 채원 판정(변형 추가 또는 현행 유지)과 사용자 승인이 이 티켓에 적혀 있다.
- 변형을 추가하면 기사 화면 칩이 `LabelChip`을 쓰고 Story에 반전 색조가 있으며 `npm run ds:check`가 통과한다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
1453-b3(티켓 20261001_1737)에서 함께 처리했다. 채원 판정은 「변형 추가」이고 사용자가 승인했다(2026-10-01). MODULAR `LabelChip`에 `tone?: 'default' | 'inverse'`를 더했다.
`inverse`는 배경 `--color-surface-inverse`·글자 `--color-text-inverse`이고 나머지 규격(12px 굵게 대문자·안쪽 여백 6px 10px·`--radius-tags`·줄 높이 1)은 `default`와 같다.
기본값이 `default`라 기존 호출부 4곳(`TodayStatusStrip`·`OnboardingQuestCard`·`TodayCardStack`·`BriefCard`)의 출력은 그대로다. 기사 화면 칩(`components/today/ArticleView.tsx`)이 `tone="inverse"`를 쓰고,
높이가 홈 카드 칩과 같은 24px가 됐다(실측). 연결 범위는 「연결된 컴포넌트 — 서비스에 즉시 반영」이다.
