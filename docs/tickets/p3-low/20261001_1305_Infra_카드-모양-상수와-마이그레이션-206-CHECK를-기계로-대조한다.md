# [Infra] 카드 모양 상수와 마이그레이션 206의 CHECK 목록을 기계로 대조한다

> 출처: 티켓 20261001_1152 게이트 리뷰(민지) 범위 밖 발견물 `[구조/참고]`

## 핵심 요약

- 요구사항: `jam-web/src/lib/today/shape.ts`의 `CARD_SHAPES`(5개)와 마이그레이션 206의 `today_cards_shape_check` 허용값이 어긋나면 검사에서
  잡히게 한다. 지금은 주석 「206 CHECK와 함께 바꾼다」로만 이어져 있어 사람이 지켜야 한다.
- 구현 계획: 마이그레이션 206이 staging에 들어온 뒤(1453 세션, 2026-10-01 실행 완료 통보), 마이그레이션 SQL에서 CHECK 목록을 읽어 상수와
  비교하는 테스트를 하나 둔다. 이후 모양을 바꾸는 새 마이그레이션이 생기면 가장 최근 정의를 기준으로 삼는다.
- 관련 파일: `jam-web/src/lib/today/shape.ts`(3~9행), `jam-web/supabase/migrations/206_*.sql`, `jam-web/src/lib/today/__tests__/shape.test.ts`.

## 완료 조건

- 상수에서 값 하나를 빼거나 더하면 테스트가 실패하고, 지금 상태에서는 통과한다.
- 206이 staging에 없으면 이 티켓은 착수하지 않는다(선행: 1453의 206 반영).
