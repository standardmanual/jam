# [Admin] 공개된 레시피에 같은 공개 시각을 다시 보내면 400이 난다

> 티켓 20261001_1158 게이트 리뷰(민지)의 범위 밖 발견물

## 핵심 요약

- 요구사항: `PATCH /api/admin/recipes/[id]`에서 이미 공개된 레시피의 지난 `valid_from`을 그대로 다시 보내면, `assertValidFromChange`의 「같은 시각이면 통과」 분기에 닿기 전에
  `normalizeValidFrom`이 「이미 지났어요」(400)를 낸다(`jam-web/src/lib/combine/recipe-payload.ts:91`, `jam-web/src/lib/admin/recipe-write.ts:259`). 폼은 공개된 레시피에 공개 시각을
  보내지 않아 화면 영향은 없다. 1500이나 토큰 쓰기 경로가 행 전체를 다시 보낼 때 걸릴 수 있다.
- 구현 계획: PATCH에서는 기존 값과 같으면 과거 검증을 건너뛰거나, 같은 값이면 필드를 빼고 처리한다. 둘 중 하나를 고르고 테스트로 고정한다.
- 관련 파일: 위 두 파일, `jam-web/src/app/api/admin/recipes/[id]/route.ts`(PATCH), `[id]/__tests__/patch.test.ts`.

## 완료 조건

- 공개된 레시피에 같은 `valid_from`을 다시 보낸 PATCH가 200이고 값이 바뀌지 않는다(테스트).
