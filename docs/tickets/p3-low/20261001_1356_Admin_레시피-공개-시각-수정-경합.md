# [Admin] 레시피 공개 시각 수정이 공개되는 순간과 겹치면 방금 공개된 레시피의 시각이 바뀔 수 있다

> 티켓 20261001_1158 게이트 리뷰(민지)의 범위 밖 발견물

## 핵심 요약

- 요구사항: PATCH는 기존 행 읽기와 update가 별개 쿼리다(`jam-web/src/app/api/admin/recipes/[id]/route.ts:66-86`). 읽을 때는 예약 상태였는데 update 직전에 공개 시각이 지나면,
  방금 공개된 레시피의 시각이 바뀐다(A5 「공개된 레시피는 시각 변경 거절」의 좁은 틈). 취소는 조건부 DELETE 한 번이라 이 틈이 없다.
- 구현 계획: `valid_from` 변경을 포함한 update에 `.gt(valid_from, now)` 조건을 걸고, 갱신 행이 0이면 409로 돌려준다(취소와 같은 방식).
- 관련 파일: 위 라우트, `jam-web/src/lib/admin/recipe-write.ts`(`assertValidFromChange`), 테스트.

## 완료 조건

- 공개 시각이 지난 레시피에는 조건부 update가 0행을 갱신하고 409가 난다(테스트).
- 레시피 수정이 드물어 실제 위험은 낮다. 1500이 레시피 시각 수정을 자동으로 부르기 전에 하면 충분하다.
