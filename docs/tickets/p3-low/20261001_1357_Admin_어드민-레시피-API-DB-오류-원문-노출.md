# [Admin] 어드민 레시피 API가 DB 오류 원문을 응답에 담는다

> 티켓 20261001_1158 게이트 리뷰(민지)의 범위 밖 발견물

## 핵심 요약

- 요구사항: 레시피 쓰기 경로 일부가 `error.message`를 응답 본문에 그대로 담는다(`jam-web/src/lib/admin/recipe-write.ts:169`, `jam-web/src/app/api/admin/recipes/[id]/route.ts:93`).
  어드민 전용 경로라 노출 대상은 운영자뿐이지만, 테이블·제약 이름이 응답에 실린다. 1158이 만든 문제는 아니다(이동한 기존 코드). 새 취소 경로는 원문을 담지 않는다(테스트 있음).
- 구현 계획: 서버 로그에는 원문을 남기고 응답은 일반 문구로 바꾼다. 다른 어드민 라우트의 같은 패턴도 함께 훑는다.
- 관련 파일: 위 두 파일, 같은 패턴을 쓰는 `jam-web/src/app/api/admin/` 라우트.

## 완료 조건

- 레시피 쓰기 API의 500 응답에 DB 오류 원문이 없다(테스트).
