# [Service] 컬렉션 보상 배지 보정이 동기화마다 북마다 보유 확인 쿼리를 반복한다

> 티켓 20261001_0635 게이트(민지) 범위 밖 발견물.

## 핵심 요약

- 요구사항: 보정이 완성 기록이 있는 컬렉션까지 보상 후보로 넣어, 1500이 `reward_badge_id`를 채운 뒤에는 매 동기화마다 완성한 컬렉션 가운데 보상 배지가 있는 것 수만큼 `user_activity_badges` 보유 확인 쿼리가 반복된다. 지금은 보상 배지가 지정된 컬렉션이 0개라 추가 쿼리가 없다. [성능/참고]
- 구현 계획: 보유 확인을 `in('badge_id', ids)` 한 번으로 묶는다. 컬렉션 런칭 규모가 커질 때 한다.
- 관련 파일: `jam-web/src/lib/itembook/checker.ts`(`issueItemBookRewardBadges`의 보유 확인 루프, 230~252줄 부근)

## 완료 조건

- 보유 확인이 북 수와 무관하게 쿼리 1회다(테스트).
