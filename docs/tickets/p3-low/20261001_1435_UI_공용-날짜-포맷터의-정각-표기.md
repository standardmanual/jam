# [UI] 공용 날짜 포맷터가 정각을 「오후 3시 00분」으로 낸다

> 티켓 20261001_1159(레시피 공개 시각 ③) 범위 밖 발견물. 채원① 사전 판정의 제안과 민지 `[가독성/참고]`. 카리나 실렌더(2026-10-01)에서 「12월 24일 오후 12시 00분」으로 보이는 것을 확인했다.

## 핵심 요약

- 요구사항: 정각을 어떻게 적을지 `docs/specs/UX_WRITING_GUIDELINE.md` §3에 정하고(예: 「오후 3시」), 공용 포맷터가 그 규칙대로 내게 한다. 지금 가이드에는 정각 규칙이 없다.
- 구현 계획: 가이드에 정각 행을 먼저 더한 뒤 포맷터의 시·분 조립 함수만 고친다. 포맷터를 쓰는 화면이 15개 파일이라 화면별 변경은 없고 결과 문자열만 바뀐다.
- 관련 파일: `jam-web/src/components/LocalDate.tsx`(시·분 조립 함수 `formatKoreanTime` 36줄 근처, `formatKoreanDateTime` 54줄 근처), `docs/specs/UX_WRITING_GUIDELINE.md` §3(283~299줄 날짜·시간 표기 표). 포맷터 테스트가 있으면 함께 고친다.

## 배경 / 문제 정의

`formatKoreanDateTime(iso, { time: true })`는 분을 두 자리로 내서 정각이 「오후 3시 00분」이 된다. 레시피 공개 시각(1159)처럼 운영자가 정하는 시각은 정각이 많아서 자주 보이는 형태다.
가이드 §3은 「오후 3시 30분」 형태만 정하고 정각은 다루지 않는다.

## 구현 계획

1. 가이드 §3 표에 정각 표기를 정한다(사용자 확인 필요: 「오후 3시」로 분을 뺄지, 「오후 3시 00분」을 유지할지).
2. `LocalDate.tsx`의 `formatKoreanTime`에서 분이 `00`이면 정한 형태로 낸다. 한 자리 분(「10시 05분」)을 어떻게 쓸지도 같은 절에서 함께 정한다.
3. 포맷터를 쓰는 화면(15개 파일)은 고치지 않는다. 문자열을 고정한 테스트가 있으면 기대값만 바꾼다.

## 완료 조건

- 가이드 §3에 정각 표기 규칙이 있다.
- 정각 입력에 대해 포맷터가 그 규칙대로 낸다(테스트).
