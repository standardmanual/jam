# [Admin] 운영툴 직접 수정으로 포인트를 고칠 수 없어 R5·R6 밸런스 경고를 툴에서 풀 수 없다

> 상위: 20260930_1450 · 20260930_1459 조각 A 게이트(민지) 범위 밖 발견물 [정확성/참고]

## 핵심 요약

- 요구사항: 기획 상세의 직접 수정 칸에는 `resource`가 없어서, 포인트가 기준을 넘는 항목(R5·R6 경고)을 툴 안에서 고칠 수 없다. 지금은
  반려하거나 다시 제출해야만 경고가 풀린다. 포인트 같은 자원 값을 툴에서 고칠지, 반려·재제출로 둘지 정한다.
- 구현 계획: 착수할 때 정한다. 자원 종류별 등록 필드는 1500(자원 연결)이 정하므로, 1500 시작 검토 때 함께 판단하는 것이 자연스럽다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/edit.ts` 23행 근처(직접 수정할 수 있는 칸 목록), `jam-web/src/lib/admin/opsInbox/balance/evaluate.ts`
  (평가는 수정본의 `resource`를 먼저 읽는다), 운영툴 PRD §5.2 「규칙이 읽는 자리」·§7.3.

## 완료 조건

- 포인트 초과 항목의 처리 방식(툴에서 고침 또는 반려·재제출)이 정해져 운영툴 PRD에 적혀 있다. 툴에서 고치기로 했다면, 고친 뒤 기획 상세를
  다시 열었을 때 R5·R6 경고가 사라진다.
