# [Admin] 신호 엔진이 운영 묶음 항목을 조건 없이 전부 읽는다

> 출처: 티켓 20261001_1155 게이트 리뷰(민지) 범위 밖 발견물 `[성능/참고]`

## 핵심 요약

- 요구사항: 신호 조회가 `ops_bundle_items`를 조건 없이 전부 읽는다. 끝난 묶음의 항목과 제출 원본(`original`) JSON까지 매번 읽으므로, 묶음이
  주마다 쌓이면 읽는 양이 계속 늘어난다. 지금은 시험 묶음 1개뿐이라 영향이 없다.
- 구현 계획: 신호와 날짜 구성에 필요한 항목만 읽는다. 예: 끝나지 않은 묶음의 항목과 검사 범위(지난 6일~다음 주 일요일)에 걸치는 항목, 최근 7일 안에
  실패한 항목. 거르는 조건이 신호 규칙(A2·A3·A4, 가정 15)과 어긋나지 않는지 시험으로 지킨다.
- 관련 파일: `jam-web/src/lib/admin/opsSignals/load.ts`(206행 부근 항목 조회), 규칙은 티켓 20261001_1155 「착수 가정」.

## 완료 조건

- 끝난 지 오래된 묶음의 항목을 읽지 않는다(가짜 DB 시험).
- 신호 13종의 결과가 거르기 전과 같다(기존 시험 통과).
