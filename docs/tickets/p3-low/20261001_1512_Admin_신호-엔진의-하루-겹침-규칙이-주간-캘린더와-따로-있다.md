# [Admin] 신호 엔진의 하루 겹침·다음 주 검사 요일 규칙이 주간 캘린더와 따로 있다

> 출처: 티켓 20261001_1155 게이트 리뷰(민지) 범위 밖 발견물 `[구조/참고]`

## 핵심 요약

- 요구사항: 신호 엔진의 하루 겹침 판정과 다음 주 검사 요일 규칙이 `weeklyCards.ts`·`contentGaps.ts`와 따로 구현돼 있다. 요일 상수는 시험이
  대조하지만 하루 겹침 규칙(`starts_at <= 하루 끝` 그리고 `ends_at >= 하루 시작`, KST)은 대조가 없어 한쪽만 바뀌면 일정표와 신호가 다른 날을 볼 수 있다.
- 구현 계획: 하루 겹침 판정을 한 곳(예: `weeklyCards.ts`의 `overlapsDay`를 내보내 공용으로)에 두고 양쪽이 가져다 쓴다. 주간 캘린더가 일정표(③,
  티켓 20261001_1153)로 옮겨질 때 함께 정리하면 한 번에 끝난다.
- 관련 파일: `jam-web/src/lib/admin/opsSignals/composition.ts`(286행·434행 부근), `jam-web/src/lib/admin/weeklyCards.ts`(`overlapsDay`),
  `jam-web/src/lib/admin/contentGaps.ts`(`checksNextWeek`).

## 완료 조건

- 하루 겹침 판정이 한 곳에 있고 신호 엔진과 주간 캘린더(또는 일정표)가 같은 함수를 쓴다.
- 기존 시험(신호 엔진·주간 캘린더·컨텐츠 공백)이 그대로 통과한다.
