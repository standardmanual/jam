# [Admin] 신호 엔진이 「모름」 값을 상수 대신 글자로 비교한다

> 출처: 티켓 20261001_1155 게이트 리뷰(민지) 범위 밖 발견물 `[가독성/참고]`

## 핵심 요약

- 요구사항: 신호 엔진이 칸 읽기 함수의 「모름」 값을 `fields.ts`의 `OPS_FIELD_UNKNOWN` 대신 `'unknown'` 글자로 7곳에서 비교한다. 상수 값이 바뀌면
  비교가 조용히 어긋난다.
- 구현 계획: 비교를 모두 `OPS_FIELD_UNKNOWN`으로 바꾼다. 동작은 바뀌지 않는다. 티켓 20261001_1512와 함께 처리해도 된다.
- 관련 파일: `jam-web/src/lib/admin/opsSignals/dayRules.ts`(38·115·187·194·240·278행 부근), 상수는 `jam-web/src/lib/admin/opsInbox/fields.ts`.

## 완료 조건

- `opsSignals/` 안에 「모름」을 글자로 비교하는 곳이 없다.
- 기존 시험이 그대로 통과한다.
