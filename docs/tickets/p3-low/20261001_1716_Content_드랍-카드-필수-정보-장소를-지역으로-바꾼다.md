# [Content] 드랍 카드 필수 정보 「장소 ○○」를 「지역 ○○」으로 바꾼다

> 출처: 티켓 20261001_1458(1453-b2) 게이트 WARN · 2026-10-01 사용자 결정 · 로직 변경 없음(문자열·주석·문서만)

## 핵심 요약

- 요구사항: 투데이 카드 드랍 자원의 필수 정보 줄 문구를 「장소 {지역명}」에서 「지역 {지역명}」으로 바꾼다. 같은 줄을 가리키는 테스트 기대값·Story 예시·주석·
  홈피드 PRD 서술도 「지역」으로 맞춘다. 화면 구조·판정 로직은 바꾸지 않는다.
- 구현 계획: 아래 「바꿀 곳」 표의 문자열만 고친다.
- 관련 파일: `jam-web/src/lib/i18n/ko.ts` 374줄 `factPlace`, `jam-web/src/lib/today/cardView.ts` 70·130줄(주석), `jam-web/src/lib/today/__tests__/cardView.test.ts` 175~179·492~494줄,

  `jam-web/src/components/today/BriefCard.stories.tsx` 61·169·408·412줄, `docs/service/prd/home-feed/PRD.md` 247줄

## 배경 / 문제 정의

- UX Writing 가이드 §1.3 용어표(`docs/service/writing/UX_WRITING_GUIDELINE.md` 69줄)는 드랍·픽업·체크인이 일어나는 실제 위치를 「지점」으로 고정하고 「장소」를 금지 표기로 둔다.
  1458 게이트(민지 점검표 12번)가 이 충돌을 WARN으로 올렸다.
- 이 줄에 들어가는 값은 좌표·반경을 가진 지점이 아니라 카드의 지역명(`today_cards.region_label`)이다. 그래서 사용자가 「지점」 대신 「지역」을 골랐다(2026-10-01).
  드랍 지점 예약(티켓 20260930_1457)으로 실제 지점 값이 생기면 그때 「지점」으로 바꾼다.
- 지금 홈 화면에는 영향이 없다. 이 문구는 모양이 `brief`로 저장된 카드에서만 보이고, 2026-10-01 기준 그런 카드는 0장이다.

## 완료 조건

- 드랍 자원의 필수 정보 줄이 「지역 {지역명}」으로 만들어진다(`buildFacts('drop', { place: '한강공원' })` → `['지역 한강공원']`, 기존 테스트 기대값 갱신).
- 위 표의 파일에 이 줄을 가리키는 「장소」 표기가 남지 않는다. 다른 문맥의 「장소」(예: 홈피드 PRD 185줄 T01 유형 이름)는 건드리지 않는다.
- 사용자에게 보이는 새 문구가 UX Writing 가이드 용어표와 충돌하지 않는다(민지 점검표 12번).
- `scripts/verify.sh`와 `node scripts/gen-home-feed-doc.mjs --check`가 통과한다.
