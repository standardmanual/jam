# [Admin] 운영 설정의 신호 기준값 칸 라벨을 해요체로 다듬는다

> 상위: 20260930_1450 · 20260930_1459 조각 C 카리나 실렌더(2026-10-01)에서 발견

## 핵심 요약

- 요구사항: 운영 설정(`/admin/ops-settings`) 「신호 기준값」 구역의 칸 라벨이 기준값 정의의 `label`을 그대로 써서, 9개가 해라체나 메모체로
  보인다(예: 「하루에 게재할 카드의 최소 장수(이보다 적으면 뜬다)」, 「공개 시각 몇 시간 전까지 승인되지 않으면 띄우는지」). 화면 라벨을 UX
  Writing 가이드의 해요체·명사형 라벨로 다듬는다.
- 구현 계획: `label`은 운영툴 PRD §5.1 표의 「뜻」 열과 글자 단위로 대조된다(`jam-web/src/lib/admin/opsSignals/__tests__/thresholds.test.ts` 175행).
  둘 중 하나를 고른다: (a) `label`과 PRD 표를 함께 고친다 (b) 화면 전용 라벨을 `jam-web/src/lib/admin/opsSignals/thresholdSettings.ts`의 UI 전용
  문구 표에 더한다. 문구는 채원 확인을 거친다.
- 관련 파일: `jam-web/src/lib/admin/opsSignals/thresholds.ts`(`label`), `thresholdSettings.ts`(UI 전용 문구), 운영툴 PRD §5.1 표.

## 완료 조건

- 신호 기준값 구역의 칸 라벨에 해라체(「뜬다」 「띄우는지」 등)가 없고, `thresholds.test.ts`의 코드와 PRD 대조가 통과한다.
