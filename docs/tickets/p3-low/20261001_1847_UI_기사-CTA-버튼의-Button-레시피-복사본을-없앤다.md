# [UI] 기사 화면 CTA 버튼이 `Button` primary 레시피를 복사해 쓰는 구조를 정리한다

## 핵심 요약

- 요구사항: 기사 화면 CTA(`jam-web/src/components/today/ArticleView.tsx` 20~26줄)는 `<a>` 안에 `<button>`을 넣을 수 없어서 `Button.tsx`
  `variant="primary" surface="main"`의 클래스를 복사해 쓴다. `Button` 쪽이 바뀌면 기사 CTA만 옛 모양으로 남는다(드리프트 위험).
- 구현 계획: 채원이 판정한다. 후보는 (가) `Button`에 링크로 그리는 방법(`asChild`·`href` 등)이 있는지 확인해 그것을 쓴다,
  (나) 레시피 클래스를 한 곳의 상수로 빼서 `Button`과 기사 CTA가 함께 쓴다, (다) 현행 유지와 이유 기록이다.
  `Button`을 고치는 안이면 MODULAR 변경이라 사용자 승인이 필요하다.
- 관련 파일: `jam-web/src/components/today/ArticleView.tsx` 20~26줄(CTA 클래스, 미리보기용 정적 필 변형 포함), `jam-web/src/components/ui/Button.tsx`(primary 레시피)

## 배경 / 문제 정의

- 티켓 20261001_1737(1453-b3) 민지 범위 밖 발견물 [구조/참고]이다. 구조는 티켓 20260924_0107에서 생겼고 b3는 페이지에서 `ArticleView`로 옮기며
  미리보기용 정적 필 변형만 더했다.

## 완료 조건

- 채원 판정과(필요하면) 사용자 승인이 이 티켓에 적혀 있다.
- 정리안을 택했으면 기사 CTA와 `Button` primary의 클래스가 한 원천에서 나오고, 기사 화면 CTA의 출력은 지금과 같다(링크·정적 필 두 경우).
