# [Admin] 시뮬레이터의 섀도우밴 상한표가 조회를 8번 하고 엔진 로그처럼 찍힌다

> 출처: 20261001_1219 게이트(민지) 범위 밖 발견물 [성능/참고].

## 핵심 요약

- 요구사항: 밴 수준·어뷰징 정책을 한 번만 읽고 `shouldAllowDrop`으로 상한표를 만든다. 시뮬레이터 경로에서는 엔진 로그 접두를 남기지 않는다.
- 구현 계획: 착수할 때 관련 파일을 읽고 파일 단위로 적는다.
- 관련 파일: `jam-web/src/lib/drop-engine/preview.ts` 231~232행, `jam-web/src/lib/drop-engine/index.ts` 472~481행(`applyShadowBanCap`)

## 배경 / 문제 정의

`previewItemDrop`이 섀도우밴 상한표를 만들려고 `applyShadowBanCap`을 등급 4개에 모두 부른다. 호출마다 밴 수준과 어뷰징 정책을 조회해 총 8번 조회하고, 밴 유저는 굴리지 않은 등급의 「[tryItemDrop] 섀도우밴 강등/차단」 console.info가 서버 로그에 남아 실제 엔진 로그로 오인될 수 있다.

## 완료 조건

- 시뮬레이터 1회 실행에서 밴 수준·어뷰징 정책 조회가 각 1번이다(테스트).
- 시뮬레이터 실행이 `[tryItemDrop]` 접두 로그를 남기지 않는다.
