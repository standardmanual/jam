# [Content] 운영 패턴 사전 원고의 장소 손잡이를 O6 기준으로 갱신

> 상위: 20260930_1450 · 영향 티켓(진행 규칙 4) · 1457 시작 검토에서 혜린이 발견

## 핵심 요약

- 요구사항: `jam-doc/planning/content/OPS_PATTERNS.md` 150·168행 부근에 「특정 지점 지정은 O6가 있어야 한다」는 닫은 값이 있다. 1457 하위 ①(20261001_2051)이
  끝나면 날짜 예약과 지점·아이템 지정이 가능해지므로, 장소 손잡이의 열 수 있는 값·닫은 값을 O6 기준으로 고친다.
- 구현 계획: 닫은 값을 여는 것은 사용자가 승인한 운영 정책을 바꾸는 일이라 **문장 초안을 보이고 사용자 승인**을 받은 뒤 고친다. 윈터 검수가 필요한 세계관 문장은
  바꾸지 않는다.
- 관련 파일: `jam-doc/planning/content/OPS_PATTERNS.md` 150·168행 부근(장소 손잡이), O6를 쓰는 패턴(06 옵션 1·13·64·65와 연결된 패턴).

## 배경 / 문제 정의

1503(패턴 사전·학습)이 이 원고를 파서로 읽어 툴 초기 데이터로 넣는다(1503 하위 ③). 그 전에 고치지 않으면 낡은 닫은 값이 툴의 정본으로 들어간다.
