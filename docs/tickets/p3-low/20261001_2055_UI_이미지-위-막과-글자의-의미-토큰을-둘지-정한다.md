# [UI] 이미지 위 어두운 막과 그 위 글자의 의미 토큰을 둘지 정한다

## 핵심 요약

- 요구사항: 투데이 포스터 카드(`jam-web/src/components/today/PosterCard.tsx`)의 어두운 막은 모달·시트 배경용 토큰 `--color-overlay`
  (`jam-web/design-system/tokens/colors.css` 65줄, `rgba(0, 0, 0, 0.6)`)를 빌려 쓰고, 막 위 글자는 의미 토큰 없이 `text-white`를 직접 쓴다
  (`PosterCard.tsx` 42~60줄, `CardChipRow.tsx` 41줄 `on="scrim"`). 모달 배경 값을 바꾸면 포스터 막의 대비 보증(글자 첫 줄에서 진하기 60% 이상)이 깨진다.
- 구현 계획: 채원이 판정한다. 후보는 (가) 「이미지 위 막」·「이미지 위 글자」 의미 토큰을 MODULAR에 새로 두고 포스터가 그것을 쓴다,
  (나) 지금처럼 `--color-overlay`를 쓰되 vitest 안전장치(토큰 파일에서 알파 0.6 이상을 단언)를 유지한다, 이다. 새 토큰은 디자인 시스템 추가라 사용자 승인이 필요하다.
- 관련 파일: `jam-web/design-system/tokens/colors.css` 65줄, `jam-web/src/components/today/PosterCard.tsx`, `jam-web/src/components/today/CardChipRow.tsx`,
  `jam-web/src/components/today/__tests__/PosterCard.test.tsx`(알파 단언)

## 배경 / 문제 정의

- 티켓 20261001_2013(1453-b4) 민지 범위 밖 발견물 2건([정확성/참고] 막의 대비 보증이 모달 배경 토큰에 의존, [가독성/참고] 「이미지 위 글자」 의미 토큰 없음)과
  아현의 사후 제안을 묶었다. 같은 주제라 한 티켓으로 다룬다.
- 같이 판단할 값(2026-10-01 티켓 20261001_2104 채원 판정 제안): 흰 카드 위 옅은 면 `bg-black/[0.04]`가 날값으로 여러 곳에 있다(`jam-web/src/components/today/CardThumb.tsx`,
  옛 렌더러 `jam-web/src/app/(main)/TodayCardStack.tsx`). 의미 토큰을 둔다면 이 값도 포함할지 채원이 함께 판정한다.

## 완료 조건

- 채원 판정과(새 토큰이면) 사용자 승인이 이 티켓에 적혀 있다.
- 새 토큰을 두면 포스터 막과 막 위 글자가 그 토큰을 쓰고, 포스터의 출력은 지금과 같으며 `npm run ds:check`가 통과한다.
