# [Infra] 앰비언트 cron 한 호출이 큰 예약 여러 건과 매일 배포를 60초 안에 끝내야 한다

> 출처: 20261001_2051(1457-①) 게이트(민지) 범위 밖 발견물

## 핵심 요약

- 요구사항: 예약 예산을 매일 배포 시각에는 줄이거나, 매일 배포를 먼저 돌리거나, 예약이 남으면 다음 정시로 미루는 규칙을 정한다. 실측(예약 1건 100개의 실행 시간) 뒤에 정한다.
- 구현 계획: 착수할 때 관련 파일을 읽고 파일 단위로 적는다.
- 관련 파일: `jam-web/src/lib/ambient-drop/scheduleRun.ts` 31행(`budgetMs`), `jam-web/src/app/api/cron/ambient-drop/route.ts` 28행

## 배경 / 문제 정의

cron 한 호출은 예약 예산 40초 + 마지막 예약 실행 시간 + 매일 배포가 `maxDuration` 60초 안에 끝나야 한다. 매일 배포는 선점 뒤 실행이라 도중에 끊기면 그날 재시도가 없다. 같은 정시에 큰 예약이 여러 건 겹칠 때만 해당한다.

## 완료 조건

- 예약이 많아도 매일 배포가 그날 빠지지 않는다(테스트 또는 실측 근거).
