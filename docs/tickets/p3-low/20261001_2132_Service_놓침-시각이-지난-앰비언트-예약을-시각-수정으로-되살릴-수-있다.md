# [Service] 「놓침」 시각이 지난 앰비언트 예약을 시각 수정으로 되살릴 수 있다

> 출처: 20261001_2051(1457-①) 게이트(민지) 범위 밖 발견물

## 핵심 요약

- 요구사항: 의도라면 BADGE_ENGINE §3.12와 운영툴 PRD에 한 줄 적고, 아니면 파생 상태가 `missed`일 때 409로 거절한다. 어드민 화면(20261001_2052)이 생기기 전에 정한다.
- 구현 계획: 착수할 때 관련 파일을 읽고 파일 단위로 적는다.
- 관련 파일: `jam-web/src/lib/ambient-drop/scheduleStore.ts` 187행(`rescheduleAmbientDrop`), `jam-web/src/lib/ambient-drop/scheduleSpec.ts`(`ambientDropScheduleState`)

## 배경 / 문제 정의

DB 상태가 `scheduled`이면 파생 상태가 `missed`(예정 시각 + 3시간 경과, cron이 아직 표시 전)여도 `rescheduleAmbientDrop`이 통과해 예약이 되살아난다. 의도인지 정해지지 않았다.

## 완료 조건

- 파생 상태가 `missed`인 예약의 시각 수정 동작이 문서와 테스트로 정해져 있다.
