# [UI] 투데이 목록 카드의 미보유 타일과 랭킹 제목 링크를 알아보기 쉽게 한다

> 출처: 티켓 20261001_2104(1453-b5 `list` 모양) 채원 사후 리뷰 제안 2건(범위 밖 발견물)

## 핵심 요약

- 요구사항: `list` 모양에서 두 가지를 보완한다. (1) 미보유 배지 타일은 흑백으로만 구분돼 색 외의 단서가 없다. 스크린리더가 「미보유」를 읽을 수 있게 한다.
  (2) 랭킹 행형 카드의 제목 영역은 미션 대상 랭킹일 때만 링크인데, 눌리는지 알아볼 단서가 없다(채원이 「알려진 한계」로 남겼다).
- 구현 계획: 채원 판정 뒤 정한다. (1)은 문구가 새로 생기므로 한국어 자연스러움 판정을 받는다. (2)는 끝 줄·화살표 같은 시각 단서를 더할지 채원이 판정한다.
- 관련 파일: `jam-web/src/components/today/ListCard.tsx`(타일 줄 53줄 부근 `w-max` `ul`, 행형 제목 영역 `CardLink`, `live` 변수), `jam-web/src/components/today/CardThumb.tsx`(64px 칸, 흑백 `grayscale`),
  `jam-web/src/lib/i18n/ko.ts`(문구를 더하면), `jam-web/src/components/today/ListCard.stories.tsx`, `docs/service/prd/home-feed/PRD.md` §6 `list` 항목.

## 배경 / 문제 정의

- 2104 채원 판정: 타일 그림 `alt`는 빈 값이고 이름이 바로 아래 글자로 보인다. 미보유는 그림에만 `grayscale`을 건다. 그래서 스크린리더 사용자는 보유·미보유를 구분할 수 없다.
- 2104 채원 판정: 행형은 끝 줄이 없다(끝 줄은 「카드 전체가 눌린다」는 신호인데 행형은 카드 전체 링크가 없다). 제목 영역 링크는 미션 대상일 때만 생기므로 링크인 카드와 아닌 카드가 겉모습으로 갈리지 않는다.
- 지금은 `shape`가 저장된 카드가 0장이라 홈 화면에 영향이 없다. 1453-b7(옛 카드 전환) 뒤에는 옛 `badge_gallery`·`ranking_list` 카드가 이 모양으로 그려진다.

## 완료 조건

- 미보유 타일은 스크린리더에서 보유 타일과 구분되어 읽힌다(렌더 테스트로 확인). 화면에 보이는 모습은 채원 판정대로다.
- 랭킹 제목 영역이 링크인 카드와 아닌 카드를 보고 구분할 수 있다(채원 판정, Story로 확인). 링크가 아닌 카드에는 링크 단서가 없다.
- 새 문구가 한국어 자연스러움 판정을 통과하고, 홈피드 PRD §6 `list` 항목이 갱신됐다.
