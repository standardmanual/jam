# [API] 패턴 사전 읽기가 행 수 상한에 걸리면 조용히 잘린다

> 출처: 20261001_2134(1503-②) 게이트(민지) 범위 밖 발견물 `[성능/참고]`

## 핵심 요약

- 요구사항: 패턴·취향 신호·공통 규칙 조회에 `range`·`limit`이 없어, 프로젝트의 PostgREST 최대 행 수(기본 1000)를 넘으면 응답이 오류 없이 잘릴 수 있다.
  상한을 실측하고, 넘을 수 있으면 쪽 나눠 읽기나 개수 확인으로 잘림을 드러낸다.
- 구현 계획: 착수할 때 관련 파일을 읽고 파일 단위로 적는다.
- 관련 파일: `jam-web/src/lib/admin/opsPatterns/read.ts` 171~205행(`listOpsPatterns`·`listOpsTasteSignals`·`listOpsCommonRules`)

## 배경 / 문제 정의

지금 규모는 패턴 18·취향 신호 43·공통 규칙 7이라 당장 걸리지 않는다. 새 패턴 제안(⑪)이 쌓여 취향 신호가 수백 건이 될 때 확인하면 된다.
최대 행 수 값은 이번 검토에서 실측하지 않았다.

## 완료 조건

- PostgREST 최대 행 수를 실측해 적었고, 그 값을 넘는 사전에서도 읽기 응답이 빠짐없이 오거나 잘림이 오류로 드러난다(테스트).
