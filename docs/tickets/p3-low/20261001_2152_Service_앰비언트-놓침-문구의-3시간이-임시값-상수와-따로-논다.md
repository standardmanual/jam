# [Service] 앰비언트 놓침 문구의 「3시간」이 임시값 상수와 따로 논다

> 출처: 20261001_2132 게이트(민지) 범위 밖 발견물 `[정확성/참고]`

## 핵심 요약

- 요구사항: 놓침 409 문구의 「3시간」은 고정 표기인데, 기준인 `AMBIENT_SCHEDULE_LATE_WINDOW_MS`는 임시값이다. 상수를 바꾸면 문구와 BADGE_ENGINE §3.12의
  「3시간」이 함께 어긋난다. 상수를 확정할 때 문구를 상수에서 만들거나, 상수와 문구를 함께 바꾸라는 검사를 둔다.
- 구현 계획: 착수할 때 관련 파일을 읽고 파일 단위로 적는다.
- 관련 파일: `jam-web/src/lib/ambient-drop/scheduleStore.ts` 64행 부근(`notScheduledMessage`의 `case 'missed'`), `jam-web/src/lib/ambient-drop/scheduleSpec.ts` 32행
  (`AMBIENT_SCHEDULE_LATE_WINDOW_MS`), `docs/service/badge-engine/BADGE_ENGINE_UNIFIED.md` §3.12 상태 표

## 완료 조건

- 놓침 기준 시간을 바꿨을 때 사용자 문구가 같이 바뀌거나, 테스트가 어긋남을 잡는다.
