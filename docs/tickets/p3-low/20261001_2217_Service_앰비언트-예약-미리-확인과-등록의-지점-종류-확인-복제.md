# [Service] 앰비언트 예약 미리 확인과 등록의 지점 종류 확인 복제

> 출처: 20261001_2052(조각 A) 게이트(민지) 범위 밖 발견물 `[구조/참고]`

## 핵심 요약

- 요구사항: 미리 확인(`schedulePreview.ts`)이 지점 종류 존재 확인 로직과 문장 2개(`TARGET_CHECK_FAILED`·`CATEGORY_NOT_FOUND`)를 `scheduleStore.createAmbientDropSchedule`
  91~104행에서 복제했다(2052가 `scheduleStore.ts`를 고치지 않는다는 조건이라 허용된 구조). 한쪽만 바뀌면 미리 확인과 등록의 안내가 갈라지므로 공용 함수로 뺀다.
- 구현 계획: 착수할 때 관련 파일을 읽고 파일 단위로 적는다.
- 관련 파일: `jam-web/src/lib/ambient-drop/schedulePreview.ts` 22행 부근, `jam-web/src/lib/ambient-drop/scheduleStore.ts` 91~104행

## 완료 조건

- [ ] 지점 종류 확인과 그 문장이 한 곳에 있고, 미리 확인과 등록이 같은 함수를 부른다. 기존 테스트 결과는 바뀌지 않는다.
