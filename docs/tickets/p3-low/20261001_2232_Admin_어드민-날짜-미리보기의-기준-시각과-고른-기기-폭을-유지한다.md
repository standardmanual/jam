# [Admin] 어드민 날짜 미리보기의 기준 시각을 하나로 맞추고 고른 기기 폭을 유지한다

> 출처: 티켓 20261001_2208(1453-b6 어드민 미리보기 교체) 민지 범위 밖 발견물 2건(모두 참고)

## 핵심 요약

- 요구사항: 어드민 투데이 날짜 미리보기의 사소한 동작 두 가지를 고친다.
  (1) 오늘 날짜를 볼 때 「N일 남음」은 클라이언트가 조회 완료 시각으로, 컬렉션 공개 판정은 서버가 요청 시각으로 따로 기준 시각을 구한다. 규칙은 같지만 오늘은 왕복 시간만큼 값이 어긋날 수 있다(체감 영향 없음).
  (2) 「기기 폭」 탭에서 430을 고른 뒤 날짜를 바꾸면 다시 조회하는 동안 목록이 사라졌다가 360으로 돌아온다.
- 구현 계획: (1) 서버가 쓴 기준 시각을 미리보기 API 응답에 실어 클라이언트가 그 값을 `toCardView`의 `now`로 쓴다. (2) 고른 폭을 모달 쪽 상태로 올려 다시 조회해도 유지한다.
- 관련 파일: `jam-web/src/app/admin/today/TodayPreviewModal.tsx`(54줄 부근 기준 시각, 92줄 부근 로딩 중 목록 언마운트), `jam-web/src/app/api/admin/today/preview/route.ts`(14줄 부근),
  `jam-web/src/app/admin/today/TodayCardPreview.tsx`(폭 상태), `jam-web/src/lib/admin/today-calendar.ts`(`previewBaseTime`), 테스트 `jam-web/src/lib/admin/__tests__/todayPreview.test.ts`·`jam-web/src/app/admin/today/__tests__/TodayCardPreview.test.tsx`

## 배경 / 문제 정의

- b6은 기준 시각 규칙(오늘이면 지금, 아니면 그날 00:00 KST)을 서버와 클라이언트가 같은 함수(`previewBaseTime`)로 구하게 했다. 오늘이 아닌 날짜는 값까지 같고, 오늘만 두 시각이 다르다.
- 폭 전환은 b6에서 처음 생겼고 기본값은 360이다.

## 완료 조건

- 오늘 날짜 미리보기에서 「N일 남음」과 컬렉션 공개 판정이 같은 기준 시각 값을 쓴다(테스트).
- 430을 고른 뒤 날짜를 바꿔도 430이 유지된다(테스트 또는 실렌더 기록).
- 홈피드 PRD §6 「어드민 미리보기」 항목이 바뀐 동작과 맞다.
