# [Admin] 지정 배포 이력 문구와 갱신·대화상자 닫힘 문구를 다듬는다

## 핵심 요약

- 이력 문구: 지정 배포 한 건이 실행 이력에 「[수동] 카테고리: 전체 · 컬렉션 1개 · 배치 1개」로 보인다. 실제로는 지점 직접 선택·아이템 직접 선택이었다. `formatAmbientBatchSummary`(`jam-web/src/lib/ambient-drop/scheduleView.ts`)가 `ambient_batch_result`의 지점·아이템 모드를 구분해 보이게 한다(기록에 모드가 없으면 `logAmbientBatchResult` 입력에 더할지 먼저 확인).
- 갱신: 지정 배포 뒤 `AmbientDropForm`의 실행 이력이 자동으로 갱신되지 않아 새로고침해야 `[수동]`이 보인다(`ScheduleSection.tsx` 104행 부근 `onDeployed`).
- 닫힘 문구: 성공해서 폼이 비워지면 확인 대화상자가 닫히는 동안 문구가 「0곳에 0개를 지금 드랍해요」로 잠깐 바뀐다(`ScheduleForm.tsx`, 대화상자 문구가 폼 상태를 읽음).
- 거절 문구: 지정 배포가 지난 시각 `scheduled_at`도 「미래 시각」 문구의 400으로 거절한다(`deploy/route.ts` 61행 부근). 지난 시각에 맞는 문장으로 나누거나 두 경우를 아우르는 문장으로 고친다(티켓 20261002_0140 게이트 발견물).
- 출처: 티켓 20261001_2053 게이트·실렌더 발견물.

## 완료 조건

- [ ] 지정 배포 이력 줄이 실행 내용과 맞는다.
- [ ] 지정 배포가 끝나면 실행 이력이 새로고침 없이 갱신된다.
- [ ] 확인 대화상자가 닫히는 동안 문구가 바뀌지 않는다.
- [ ] 지난 시각 거절 문구가 상황에 맞다.
