# [Admin] 종료된 레시피의 안내 문구 두 곳과 운영자 필터 테스트

> 범위 밖 발견물(티켓 20261002_0710 게이트, 민지 `sideFindings` 두 건과 WARN 사유 하나). 같은 기능의 작은 정리라 한 티켓에 모았다.

## 핵심 요약

- 요구사항: 이미 종료된 레시피에서만 사실과 어긋나는 안내 문구 두 곳을 상태에 맞게 고치고, 운영자에게도 종료된 레시피를 빼는 믹스 화면 필터에 직접 테스트를 더한다.
- 구현 계획: 문구는 레시피 상태(`recipeReleaseState`)로 갈라 쓴다. 필터는 `page.tsx`의 목록 거르기를 순수 함수로 빼서 테스트한다.
- 관련 파일:
  - `jam-web/src/app/admin/recipes/RecipeForm.tsx` 196~198행: 종료 시각을 지난 시각으로 저장할 때의 확인창 「저장하면 이 레시피가 바로 유저에게서 사라져요.」. 이미 종료된 레시피의
    종료 시각을 다른 지난 시각으로 바꿀 때도 떠서 사실과 다르다(동작 피해는 없다).
  - `jam-web/src/lib/admin/recipe-write.ts` 249~254행: 예약 취소 409 문구 「이미 공개된 레시피는 예약을 취소할 수 없어요. 내리려면 종료 시각을 정하거나…」. 이미 종료된 레시피에서
    직접 호출하면 어색하다(화면에는 예약 취소 버튼이 공개 전에만 보인다).
  - `jam-web/src/app/(main)/combine/page.tsx` 49~52행(운영자 목록 거르기)·136행(`releaseAt` 판정): 운영자도 종료된 레시피를 보지 않는다는 규칙(0710 G7)에 직접 테스트가 없다.

## 완료 조건

- 이미 종료된 레시피의 종료 시각을 다른 지난 시각으로 바꿀 때 「사라져요」 확인창이 뜨지 않는다(또는 상태에 맞는 문구다).
- 종료된 레시피의 예약 취소 409 문구가 종료 상태에 맞는다. 공개 중 레시피의 문구는 그대로다.
- 운영자 목록 거르기가 공개 중·공개 전만 남기고 종료된 레시피를 빼는 것을 테스트가 확인한다.
