# [Admin] 운영툴 공개 시각 읽기 규칙을 한 함수로 합친다

> 범위 밖 발견물(티켓 20261002_1122 게이트, 민지 `sideFindings`).

## 핵심 요약

- 요구사항: 운영 항목의 공개 시각을 읽는 규칙(수정본의 시간대 붙은 ISO → 없으면 행 칸 → 값이 있는데 ISO가 아니면 읽을 수 없음)이 세 곳에 따로 있다. 한쪽만 고치면 사전 점검·밸런스 평가·변환이
  서로 다른 시각을 읽는다. 순수 함수 하나로 합친다.
- 구현 계획: `jam-web/src/lib/admin/opsInbox/`에 Supabase·배지 엔진 의존이 없는 순수 모듈(예: `itemTime.ts`)을 두고 세 곳이 그 함수를 쓴다. 동작은 바꾸지 않는다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/execute/precheck.ts` 107–114행(`readStart`), `opsInbox/balance/evaluate.ts` 118–126행(`readTimeValue`, 이 파일은 배지 엔진 모듈을 끌어와 사전
  점검이 직접 가져오지 않았다), `opsInbox/registerInput.ts` 124–131행(`readTimeString`).

## 완료 조건

- 세 곳이 같은 순수 함수를 쓰고, 기존 테스트(`execute/__tests__/precheck.test.ts`, `balance/__tests__/`, `__tests__/registerInput.test.ts`)가 고치지 않고 통과한다.
- 새 모듈에 Supabase 값 import와 배지 엔진 import가 없다.
