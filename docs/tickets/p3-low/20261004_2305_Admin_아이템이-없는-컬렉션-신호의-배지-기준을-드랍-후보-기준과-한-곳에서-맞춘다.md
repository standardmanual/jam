# [Admin] 「아이템이 없는 컬렉션」 신호의 배지 기준을 드랍 후보 기준과 한 곳에서 맞춘다

> 출처: 티켓 20261004_2242(1500 ⑩-b) 게이트의 민지 범위 밖 발견물 두 건([정확성/참고]·[구조/참고])을 하나로 묶었다.

## 핵심 요약

- 요구사항: 운영 신호 「아이템이 없는 컬렉션」은 컬렉션의 아이템 배지를 `type = 'item'`·`deleted_at is null`로만 센다. 드랍 실행기의 후보 풀은 여기에 배지 유효기간(`validAt`)까지 거른다.
  그래서 유효기간이 지났거나 아직 시작 전인 배지만 있는 컬렉션은 신호가 뜨지 않는데, 예정 시각의 드랍은 「후보 배지 없음」으로 건너뛰어 실패할 수 있다. 또 같은 조건이 두 곳에 따로 적혀 있어 한쪽만 바뀌면 어긋난다.
  기준을 한 곳(공용 상수나 함수)으로 모으고, 신호가 유효기간을 볼지(어느 시각 기준: 컬렉션 공개 시각·지금) 정한다.
- 구현 계획: 착수 때 정한다. 후보: 아이템 배지 조건을 `lib/ambient-drop/`의 순수 파일로 옮겨 두 곳이 같이 쓰고, 신호는 `valid_from`·`valid_until`도 읽어 컬렉션 공개 시각에 유효한 배지만 센다.
- 관련 파일: `jam-web/src/lib/admin/opsSignals/load.ts` `loadCollectionItemCounts`(263–282 부근), `jam-web/src/lib/ambient-drop/scheduleTargets.ts` 컬렉션 모드 배지 읽기(267–281 부근, `validAt`),
  `jam-web/src/lib/admin/opsSignals/statusRules.ts` `evaluateEmptyCollections`. 문서: 운영툴 PRD §5 「비어 있는 컨텐츠」 판정 규칙.

## 완료 조건

- 아이템 배지 조건(종류·삭제 여부, 정하면 유효기간)이 한 곳에 정의되고 신호 읽기와 드랍 대상 판정이 그것을 쓴다(테스트).
- 유효기간 기준을 넣기로 했다면, 컬렉션 공개 시각에 유효한 아이템 배지가 없는 컬렉션에서 신호가 뜬다(테스트). PRD §5 판정 규칙이 같은 기준을 적는다.
