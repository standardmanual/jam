# [Admin] 어드민 컬렉션·배지 상세 화면의 기간을 KST 날짜·시각으로 보인다

> 발견: 티켓 20261004_2043(E5, 어드민 컬렉션·배지 폼의 기간 입력) 게이트의 민지 범위 밖 발견물([정확성/참고]).

## 핵심 요약

- 현상(확인한 사실, 2026-10-05 코드): E5로 두 폼의 기간 입력이 KST 날짜·시각(`datetime-local`)이 됐지만, 상세 화면은 기간을 날짜(`formatKstYmd`)로만 보인다.
  `jam-web/src/components/admin/itembooks/ItemBookDetail.tsx` 74행 부근, `jam-web/src/components/admin/badges/BadgeDetail.tsx` 280행 부근.
- 영향: 운영툴이 만든 컬렉션·JAM! 배지는 공개 시각이 KST 시각까지 정해져 있는데 상세 화면에서는 시각이 보이지 않는다(폼을 열어야 보인다).
- 요구사항: 두 상세 화면의 기간 표시를 `formatKstYmdHm`(같은 파일 `jam-web/src/lib/admin/kst-format.ts`)처럼 날짜·시각으로 바꾼다. 목록 화면 표시도 같은 기준인지 함께 확인한다.
- 관련 파일: 위 두 상세 컴포넌트, `kst-format.ts`, 어드민 PRD 5-2·5-4(E5가 기간 입력 서술을 더한 곳).

## 완료 조건

- 두 상세 화면이 기간을 KST 날짜·시각으로 보인다. `scripts/verify.sh` 전 항목 통과. 어드민 실렌더는 카리나가 머지 뒤 push 전에 `DEV_PROCESS_GUARDRAILS.md` 패턴 13대로 한다(`admin` 유형).
