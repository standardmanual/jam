# [API] 결정 기록 집계 실패 로그에 다른 기능 이름(`[notifications-batch]`)이 찍힌다

> 티켓 20261004_1639(1503 ⑤) 게이트 범위 밖 발견물 [참고/관측](민지, 2026-10-05).

## 핵심 요약

- 요구사항: `fetchAllRows`(`jam-web/src/lib/db/fetchAllRows.ts` 75행)는 조회 실패 오류 문구에 늘 `[notifications-batch]` 접두를 붙인다. 결정 기록 집계(`jam-web/src/lib/admin/opsDecisions/read.ts` 348행
  `loadByPattern`)가 이 오류를 그대로 쓰므로 집계 실패 로그에 알림 배치 이름이 찍혀 로그 검색 때 혼동된다. 같은 헬퍼를 쓰는 다른 곳(⑨-b `execute/badgePreview.ts`의 유저 목록 등)도 같다.
- 구현 계획: `fetchAllRows`가 접두를 호출부에서 받게 하거나(기존 호출부는 지금 접두를 넘김), 접두 없이 `label`만 쓰게 바꾼다. 기존 알림 배치 로그 검색어가 바뀌지 않게 한다.
- 관련 파일: `jam-web/src/lib/db/fetchAllRows.ts`(75행), `jam-web/src/lib/admin/opsDecisions/read.ts`(348행), `jam-web/src/lib/admin/opsInbox/execute/badgePreview.ts`, 알림 배치 호출부(`lib/notifications/batch/*`)

## 완료 조건

- 결정 기록 집계와 미리 세기의 조회 실패 로그에 `[notifications-batch]`가 찍히지 않고, 알림 배치 로그는 지금과 같은 접두를 유지한다(테스트).
