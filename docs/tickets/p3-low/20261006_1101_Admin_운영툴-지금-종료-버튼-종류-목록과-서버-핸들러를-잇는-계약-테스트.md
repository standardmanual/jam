# [Admin] 운영툴 「지금 종료」 버튼 종류 목록과 서버 핸들러를 잇는 계약 테스트

> 출처: 1500 ⑪-b(20261006_1038) 게이트 범위 밖 발견물 [구조/참고], 2026-10-06.

## 핵심 요약

- 요구사항: 화면이 [지금 종료하기]를 보이는 종류 목록 `END_SUPPORTED_KINDS`(`jam-web/src/lib/admin/opsInbox/executeView.ts` 471행 근처)는 서버 레지스트리(`execute/registry.ts` `EXECUTE_HANDLERS`)에서
  `end` 메서드가 있는 종류와 같아야 한다. 지금은 `executeView.test.ts` 622행 근처가 목록을 리터럴로만 고정해, 핸들러에 `end`가 늘거나 줄어도 화면 조건이 조용히 어긋난다.
  두 목록이 같은지 단언하는 계약 테스트를 더한다.
- 구현 계획: 테스트 파일 하나에서 `EXECUTE_HANDLERS`를 값으로 가져와 `end`가 있는 종류 집합과 `END_SUPPORTED_KINDS`를 비교한다. `executeView.ts`는 `execute/*`를 값으로 가져오지 않는 머리말 계약이 있으므로
  비교는 테스트 쪽에서만 한다(제품 코드는 바꾸지 않는다). 위치는 `execute/__tests__/pureModules.test.ts` 같은 계약 테스트 파일이나 새 파일 중 착수 때 정한다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/executeView.ts`(`END_SUPPORTED_KINDS`·`canEndItem`), `jam-web/src/lib/admin/opsInbox/execute/registry.ts`(`EXECUTE_HANDLERS` 17행),
  `jam-web/src/lib/admin/opsInbox/execute/handlers.ts`(`ExecuteHandler.end?`), `jam-web/src/lib/admin/opsInbox/__tests__/executeView.test.ts`(622행 근처).

## 완료 조건

- `END_SUPPORTED_KINDS`와 「`end`가 있는 핸들러의 종류」가 다르면 실패하는 테스트가 있고, 지금은 통과한다(변이 확인: 한쪽에서 종류 하나를 빼면 실패).
