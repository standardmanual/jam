# [Admin] 중단 신호 점검이 매시 운영 신호 전체를 읽는다

## 핵심 요약

- 요구사항: 매시 중단 신호 점검이 예약 누락·루틴 실패 두 신호만 쓰는데 `loadOpsSignals`로 카드·미션·행동 건수까지 모두 읽는다. 데이터가 늘어도 `maxDuration` 60초 안에 끝나게 한다.
- 구현 계획: 먼저 프로덕션 반영 뒤 크론 소요 시간을 실측한다. 여유가 줄면 두 신호에 필요한 묶음·항목만 읽는 좁은 읽기 함수를 둔다.
- 관련 파일: `jam-web/src/lib/admin/opsSignals/stopAlert.ts`(120행 `loadOpsSignals` 호출), `jam-web/src/lib/admin/opsSignals/load.ts`, `jam-web/src/app/api/cron/ops-stop-signals/route.ts`(`maxDuration`)

## 배경 / 문제 정의

티켓 20261001_1154(1502 ④) 게이트에서 민지가 남긴 범위 밖 발견물 [참고]다. 크론 한 회차가 상태 맞추기와 신호 읽기를 순서대로 해서, 데이터가 늘면 60초 여유를 지켜봐야 한다.

## 완료 조건

- 프로덕션 크론 응답 시간의 실측값이 티켓에 적혀 있고, 60초의 절반을 넘으면 두 신호에 필요한 데이터만 읽도록 바뀌어 있다.
