# [Content] 레시피 공개 카드의 「재료 N개」가 조건 슬롯까지 센다

## 핵심 요약

- 요구사항: 홈 레시피 공개 카드의 정보 줄 「재료 {count}개」는 슬롯 수라, 믹스 때 소모되지 않는 활동·체크인 조건 슬롯도 센다. UX Writing 용어표의 「재료」(소모되는 아이템)와 맞출지 정한다.
- 구현 계획: 문구를 바꾸거나(예: 아이템 슬롯만 세기, 다른 낱말) 지금대로 두는 것 중 하나를 사용자에게 확인한 뒤 정한다. 조건 슬롯이 든 레시피가 실제로 몇 개인지 먼저 DB로 센다.
- 관련 파일: `jam-web/src/lib/i18n/ko.ts`(378행 근처 `factIngredientCount`), `jam-web/src/lib/today/cards.ts`(`fetchRecipesById` 재료 수 계산), `docs/service/writing/UX_WRITING_GUIDELINE.md`(용어표), `docs/service/prd/home-feed/PRD.md`(레시피 행)

## 배경 / 문제 정의

티켓 20261006_1217(1500 ⑫-a) 게이트에서 민지가 남긴 범위 밖 발견물 [참고]다. 문구 「재료 N개」는 홈피드 PRD 237행 「재료 수·공개일」과 1453 결정 1을 따른 것이라 이번 판정 대상은 아니었다.

## 완료 조건

- 조건 슬롯이 든 레시피의 카드에서 정보 줄의 수와 낱말이 용어표와 어긋나지 않는다(바꾸기로 했으면 테스트), 또는 지금대로 두기로 한 결정이 이 티켓에 남아 있다.
