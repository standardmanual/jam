# [Admin] 어드민 드랍 예약 폼의 선택 목록이 드랍 제외 항목도 보인다

## 핵심 요약

- 요구사항: 어드민 앰비언트 드랍 예약 폼(`ScheduleForm.tsx`)의 아이템·컬렉션 선택 목록이 드랍 제외 항목도 보여 주고, 고르면 등록 판정이 「드랍 제외 아이템」·「드랍 제외 컬렉션」으로 막는다. 목록에서 미리 거르거나 표시할지 정한다.
- 구현 계획: 착수 때 정한다(⑬ 「컬렉션별 아이템 획득 경로」 화면 문구와 함께 보는 편이 좋다).
- 관련 파일: `jam-web/src/app/admin/ambient-drop/` 아래 `ScheduleForm.tsx`, `jam-web/src/lib/ambient-drop/scheduleTargets.ts`(사유 라벨)

## 배경 / 문제 정의

티켓 20261005_1957 게이트에서 민지가 남긴 범위 밖 발견물 [참고/UX]다. 지금도 등록 판정이 막아 잘못 놓이는 일은 없다.

## 완료 조건

- 드랍 제외 항목이 선택 목록에서 빠지거나 「드랍 제외」 표시와 함께 고를 수 없게 보이고, 지금처럼 등록 판정도 막는다(테스트).
