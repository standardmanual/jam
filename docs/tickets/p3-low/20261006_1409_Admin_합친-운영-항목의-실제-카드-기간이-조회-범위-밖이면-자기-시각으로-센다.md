# [Admin] 합친 운영 항목의 실제 카드 기간이 조회 범위 밖이면 항목이 자기 시각으로 세어진다

## 핵심 요약

- 요구사항: 날짜 구성 합치기는 합친 칸의 날짜 겹침에 실제 카드 기간을 쓰는데, 카드는 조회 창(from~to) 안에 걸치는 것만 읽는다. 항목의 자기 시각은 창 안인데 연결된 실제 카드의 기간이 창 밖이면
  그 카드를 읽지 못해 항목이 자기 시각으로 세어진다(이중 집계는 아니고, 항목 시각과 카드 시각이 어긋난 드문 경우의 표시 차이). 필요하면 연결된 카드 ID로 창 밖 카드도 읽는다.
- 구현 계획: 실제로 어긋난 항목이 있는지 먼저 DB로 센다. 있으면 `loadDayCompositions`가 세는 항목의 `created_resource` ID로 카드를 추가로 읽는다.
- 관련 파일: `jam-web/src/lib/admin/opsSignals/load.ts`(418행 근처 카드 조회), `jam-web/src/lib/admin/opsSignals/composition.ts`(합치기)

## 배경 / 문제 정의

티켓 20261006_1339(1502 ②-a) 게이트에서 민지가 남긴 범위 밖 발견물 [정확성/참고]다.

## 완료 조건

- 어긋난 항목 수 실측이 티켓에 있고, 고치기로 했으면 창 밖 기간의 연결 카드도 합친 칸의 날짜로 쓰인다(테스트).
