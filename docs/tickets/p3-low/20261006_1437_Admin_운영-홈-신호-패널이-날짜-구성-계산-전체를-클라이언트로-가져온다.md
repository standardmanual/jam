# [Admin] 운영 홈 신호 패널이 날짜 구성 계산 전체를 클라이언트 번들로 가져온다

## 핵심 요약

- 요구사항: 클라이언트 컴포넌트 `OpsSignalPanel`이 `homeView.ts`를 불러오고, `homeView.ts`가 `composition.ts`(약 1.8천 줄 순수 TS)를 값으로 가져와 클라이언트 번들에 들어간다. 패널이 쓰는 것은 `zoneSignals`·`signalLevelCounts`·`noRaisedSignalsText`뿐이다.
- 구현 계획: 신호 구역 함수만 별도 모듈(`opsHome/signalZones.ts` 등)로 나눠 패널이 그것만 가져오게 한다.
- 관련 파일: `jam-web/src/lib/admin/opsHome/homeView.ts`(27–37행 import), `jam-web/src/components/admin/ops/OpsSignalPanel.tsx`

## 배경 / 문제 정의

티켓 20261006_1340(1502 ②-b) 게이트에서 민지가 남긴 범위 밖 발견물 [구조/참고]다. `client-server-imports` 검사는 통과했다.

## 완료 조건

- `OpsSignalPanel`의 import 그래프에 `composition.ts`가 없고, 운영 홈 렌더 테스트가 그대로 통과한다.
