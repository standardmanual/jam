# [Admin] 운영툴 구역 안내의 [새로 고치기] 크기와 신호 「N건 더 보기」 뒤 포커스

## 핵심 요약

- 요구사항: (1) `NoticeCard`(`OpsRuleCardParts.tsx` 126행 근처)의 버튼에 크기 지정이 없어 40rem 미만에서 44px(`h-11`) 규칙이 적용되지 않는다(`OpsSectionNotice`의 [새로 고치기]도 같다). (2) 신호 패널의 「N건 더 보기」를 누르면 버튼이 사라져 키보드 포커스가 문서로 돌아간다.
- 구현 계획: (1) 버튼에 좁은 폭 `h-11`을 준다(S7 전례). (2) 펼친 뒤 새로 보인 첫 신호 줄로 포커스를 옮긴다.
- 관련 파일: `jam-web/src/components/admin/ops/OpsRuleCardParts.tsx`, `jam-web/src/components/admin/ops/OpsSectionNotice.tsx`, `jam-web/src/components/admin/ops/OpsSignalPanel.tsx`(66–70행)

## 배경 / 문제 정의

티켓 20261006_1340(1502 ②-b) 게이트에서 민지가 남긴 범위 밖 발견물 [정확성/참고] 둘이다. (1)은 S7이 이미 쓰는 기존 부품의 문제다.

## 완료 조건

- 40rem 미만에서 구역 안내 버튼이 44px이고, 「N건 더 보기」를 누른 뒤 포커스가 펼쳐진 줄에 있다(테스트 또는 실렌더 기록).
