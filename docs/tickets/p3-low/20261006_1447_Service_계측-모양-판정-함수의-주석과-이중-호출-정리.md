# [Service] 계측 모양 판정 함수의 주석과 이중 호출 정리

## 핵심 요약

- 요구사항: `jam-web/src/lib/today/events.ts`의 `resolveDrawnShape`(127–145행)는 주석이 길고, 레시피를 읽을지 정하려고 `fallbackEmptyTileShape`를 타일 수 0으로 한 번, 실제 타일 수로 한 번 부른다.
  동작은 맞다. 읽기 쉽게 정리한다(예: 「타일 수가 판정에 쓰이는 모양인가」를 `shape.ts`의 이름 붙은 함수로 드러냄).
- 구현 계획: 착수 때 정한다. 기록 결과와 레시피 읽기 횟수는 그대로여야 한다.
- 관련 파일: `jam-web/src/lib/today/events.ts` 127–145, `jam-web/src/lib/today/shape.ts` 162–164(`fallbackEmptyTileShape`), `jam-web/src/lib/today/__tests__/events.test.ts`
