# [Admin] 운영 홈 서비스 점검이 쓰지 않는 「카드 편성」 조회를 매번 함께 한다

## 핵심 요약

- 요구사항: `ServiceCheckSection`은 미션 공백만 쓰는데 `fetchContentGaps`가 카드 편성 조회까지 함께 해서, 화면이 쓰지 않는 조회가 매 렌더에 남는다.
- 구현 계획: 미션 공백만 읽는 함수로 나누거나 카드 편성 조회를 옵션으로 끈다(`contentGaps.ts` 판정은 그대로).
- 관련 파일: `jam-web/src/app/admin/_home/sections.tsx`(183행 근처), `jam-web/src/lib/admin/contentGaps.ts`

## 배경 / 문제 정의

티켓 20261006_1341(1502 ②-c) 게이트에서 민지가 남긴 범위 밖 발견물 [성능/참고]다. ②-c 완료 조건(「`contentGaps.ts` 판정은 바뀌지 않는다」) 때문에 그대로 뒀다.

## 완료 조건

- 운영 홈 렌더에서 카드 편성 조회가 일어나지 않고, 미션 공백 판정과 기존 테스트가 그대로다.
