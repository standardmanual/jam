# [Admin] 운영 홈 「예약 등록 대기」 칸 이름이 좁은 화면에서 낱말 중간에서 줄바꿈된다

## 핵심 요약

- 요구사항: 화면 폭 약 800px(사이드바 펼침)에서 이번 주 상태 5칸이 한 줄로 나오면서 「예약 등록 대기」 라벨이 「예약 등록 대 / 기」로 낱말 중간에서 줄바꿈된다.
- 구현 계획: 라벨에 `break-keep`(한국어 낱말 단위 줄바꿈)을 주거나, 5칸 한 줄 전환 기준을 컨테이너 폭으로 바꾼다(채원 판정 「1024px 이상 5칸, 40rem 미만 2열」).
- 관련 파일: `jam-web/src/components/admin/ops/OpsWeekStatus.tsx`

## 배경 / 문제 정의

2026-10-06 ②-c 리뷰 브랜치 로컬 실렌더(카리나)에서 발견했다.

## 완료 조건

- 800px 폭에서 칸 이름이 낱말 단위로만 줄바꿈되거나 한 줄로 보인다(실렌더 스크린샷).
