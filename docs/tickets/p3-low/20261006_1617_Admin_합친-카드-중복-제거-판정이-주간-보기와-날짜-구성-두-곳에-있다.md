# [Admin] 합친 카드의 중복 제거 판정이 일정표 주간 보기와 날짜 구성 두 곳에 있다

## 핵심 요약

- 요구사항: 실제 카드·미션과 운영 항목을 한 번만 보이게 하는 판정이 `weekView.ts`(`mergedResourceIds`, 150–165행 근처)와 `composition.ts`(합치기) 두 곳에 있다. 지금은 `isCountedItemStatus`·`readMergeResourceId`를 공유해 같지만, 한쪽만 고치면 일정표에 중복 표시가 생긴다.
- 구현 계획: 합칠 자원 ID 집합을 만드는 함수 하나를 두고 두 곳이 같이 쓴다.
- 관련 파일: `jam-web/src/lib/admin/opsSchedule/weekView.ts`, `jam-web/src/lib/admin/opsSignals/composition.ts`

## 배경 / 문제 정의

티켓 20261006_1536(1502 ③-a) 게이트에서 민지가 남긴 범위 밖 발견물 [참고/가독성]이다.

## 완료 조건

- 두 곳이 같은 함수로 합칠 자원 ID를 정하고, 주간 보기·날짜 구성 테스트가 그대로 통과한다.
