# [Admin] 레거시 ADMIN_SECRET 쿠키 인증 경로가 관리자 판정과 따로 있다

## 핵심 요약

- 요구사항: `/api/admin/auth`와 `/api/admin/test/simulate`는 `hasAdminAccess`가 아니라 레거시 `ADMIN_SECRET` 쿠키(`admin_token`)로 인증한다. 인가 경로가 둘이라 한쪽에 넣은 규칙(예: P1
  20261006_1527의 staging 자동 로그인 계정 차단)이 다른 쪽에는 걸리지 않는다. 이 경로를 아직 쓰는지 확인하고, 쓰지 않으면 지우거나 `hasAdminAccess`로 옮긴다.
- 구현 계획: 착수 때 사용처를 확인해 정한다.
- 관련 파일: `jam-web/src/app/api/admin/auth/route.ts`, `jam-web/src/app/api/admin/test/simulate/route.ts` 5–8, `jam-web/src/lib/admin/auth.ts`

## 배경 / 문제 정의

2026-10-06 P1 20261006_1527 게이트(민지)의 범위 밖 발견물 [보안/참고]이다. dev-tester와는 무관하다. jam-stage에는 `ADMIN_SECRET`이 없고 프로덕션 환경변수 목록에도 없다(2026-10-06 `/jam-ship` 환경변수 대조).

## 완료 조건

- 어드민 인가 경로가 `hasAdminAccess` 하나로 모이거나, 남겨 두는 이유가 기록된다.
