# [Infra] 배포 게이트의 크론 선검사 판정이 모양만 본다

## 핵심 요약

- 요구사항: 20261006_1540으로 배포 게이트가 `CRON_SECRET` 라우트의 빈 값 선검사(`!<변수>`)를 요구하게 됐지만 두 한계가 남았다. (1) `if (!secret) {}`처럼 막지 않는 무동작 검사도
  통과한다(`scripts/deploy-gate.mjs` 238–243) (2) `CRON_SECRET`을 쓰는 라우트는 `public_routes`에 등록돼 있어도 크론 분기가 먼저 걸려 공개 라우트로 갈 수 없다(500–504, 지금 해당 라우트 없음).
  크론 인증을 공용 함수 하나로 모으고 게이트가 그 호출을 보게 하는 방식 등으로 정리할지 정한다.
- 구현 계획: 착수 때 정한다.
- 관련 파일: `scripts/deploy-gate.mjs` 238–243·500–504, `scripts/deploy-gate.test.mjs` 11-1절, `jam-web/src/app/api/cron/*/route.ts`

## 배경 / 문제 정의

2026-10-06 P2 20261006_1540 게이트(민지)의 범위 밖 발견물 [정확성/참고] 둘이다. 지금 크론 6종은 모두 실제로 막는 선검사를 쓴다.

## 완료 조건

- 무동작 선검사가 게이트를 통과하지 못하거나, 남기는 이유가 기록된다.
