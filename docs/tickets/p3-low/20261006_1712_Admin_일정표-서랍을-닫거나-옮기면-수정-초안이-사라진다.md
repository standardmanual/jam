# [Admin] 일정표 서랍을 닫거나 다른 항목으로 옮기면 적던 수정 초안이 조용히 사라진다

## 핵심 요약

- 요구사항: 일정표 항목 서랍에서 수정 양식을 연 채 [닫기]를 누르거나 다른 칸·항목으로 옮기면 초안이 경고 없이 사라진다(Esc만 막혀 있음).
- 구현 계획: 초안이 바뀌어 있으면 닫기·옮기기 전에 확인창을 띄운다(받은 기획함 S3의 동작과 맞출지 함께 본다).
- 관련 파일: `jam-web/src/components/admin/ops/OpsScheduleDrawer.tsx`(185행 근처), `jam-web/src/app/admin/ops-schedule/OpsScheduleBoard.tsx`(123행 근처)

## 배경 / 문제 정의

티켓 20261006_1537(1502 ③-b) 게이트에서 민지가 남긴 범위 밖 발견물 [정확성/참고]이고 아현도 보고했다.

## 완료 조건

- 수정 초안이 있는 채 닫거나 옮기면 확인을 거치고, 취소하면 초안이 남는다(테스트 또는 실렌더 기록).
