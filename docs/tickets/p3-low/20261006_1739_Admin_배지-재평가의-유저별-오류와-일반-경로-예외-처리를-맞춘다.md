# [Admin] 배지 재평가의 유저별 오류 문장과 일반 경로 예외 처리를 맞춘다

## 핵심 요약

- 요구사항: (1) `previewUpcomingJamBadges`의 유저별 실패가 `errors[]`에 `err.message` 원문을 담아 HTTP 200 응답으로 나간다(관리자 전용). 20261006_1529로 500 응답은 고정 문장이 됐으니
  같은 방침으로 맞출지 정한다. (2) 일반 재평가 경로의 `reevaluateUsersForCatalog` 호출(`route.ts` 135행)에는 try/catch가 없어, 던지면 Next 기본 500이 나가고 서버 로그에 식별 문구가 없다.
  미리보기 경로처럼 잡아서 고정 문장과 식별 로그를 남긴다.
- 구현 계획: 착수 때 정한다.
- 관련 파일: `jam-web/src/lib/badge-engine/reevaluateCatalog.ts` 364–367, `jam-web/src/app/api/admin/badges/reevaluate-all/route.ts` 135

## 배경 / 문제 정의
