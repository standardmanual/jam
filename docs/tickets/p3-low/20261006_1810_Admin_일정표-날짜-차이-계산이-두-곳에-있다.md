# [Admin] 일정표의 날짜 차이 계산이 두 곳에 같은 본문으로 있다

## 핵심 요약

- 요구사항: 타임라인의 `dayOffset`과 기간 계산의 `daysBetween`이 같은 본문이다. 한쪽만 고치면 두 보기의 날짜 계산이 어긋날 수 있다.
- 구현 계획: `params.ts`의 `daysBetween`을 내보내고 `timeline.ts`가 그것을 쓰게 한다(동작 변화 없음, 기존 테스트로 확인).
- 관련 파일: `jam-web/src/lib/admin/opsSchedule/timeline.ts`(189행 `dayOffset`), `jam-web/src/lib/admin/opsSchedule/params.ts`(140행 `daysBetween`)

## 배경 / 문제 정의

티켓 20261006_1538(1502 ③-c) 게이트에서 민지가 남긴 범위 밖 발견물 [구조/참고]이다.

## 완료 조건

- 날짜 차이 계산이 한 곳에만 있고, `timeline`·`params` 기존 테스트가 수정 없이 통과한다.
