# [Admin] 타임라인에서 승인됨·예약 등록 중 막대의 점선 표시가 채원 판정과 다르다

## 핵심 요약

- 요구사항: `PRE_APPROVAL_STATUSES`에 승인됨·예약 등록 중(`approved`·`preparing`)이 들어 있어 이 막대들도 `dashed: true`다. 하지만 이 막대의 색(secondary)은 `border-transparent`라 점선이 화면에 보이지 않는다. 채원 판정은 「승인 전 neutral 점선」(`arrived`·`reviewing`)이라 데이터 표시와 판정이 다르다.
- 구현 계획: 판정 정본(상위 티켓 20260930_1502 「채원 S1·S4 사전 판정」 S4)과 대조해 점선 대상을 `arrived`·`reviewing`으로 줄일지, 승인됨·예약 등록 중도 점선으로 보이게 할지 정하고 테스트 기대를 맞춘다.
- 관련 파일: `jam-web/src/lib/admin/opsSchedule/timeline.ts`(65행 `PRE_APPROVAL_STATUSES`, 420행 `dashed`), `jam-web/src/lib/admin/opsSchedule/__tests__/timeline.test.ts`(193행)

## 배경 / 문제 정의

티켓 20261006_1538(1502 ③-c) 게이트에서 민지가 남긴 범위 밖 발견물 [정확성/참고]이다.

## 완료 조건

- 점선 대상 상태가 채원 판정과 같고, 화면에서 점선이 보이는 상태와 `dashed` 값이 일치한다(테스트).
