# [Admin] 타임라인 내용 개수가 막대와 날짜 칸 항목을 이중으로 센다

## 핵심 요약

- 요구사항: `buildTimeline`의 `contentCount`가 `placed.length + dayContent`라 같은 항목을 막대와 날짜 칸에서 두 번 센다. 지금은 0인지 판정할 때만 써서 무해하지만, 개수로 쓰기 시작하면 틀린 값이 된다.
- 구현 계획: 이중 계산을 없애거나, 0 판정 전용임을 이름(`hasContent` 등)으로 드러낸다.
- 관련 파일: `jam-web/src/lib/admin/opsSchedule/timeline.ts`(157행 타입, 515행 조립부 `contentCount`)

## 배경 / 문제 정의

티켓 20261006_1538(1502 ③-c) 게이트에서 민지가 남긴 범위 밖 발견물 [정확성/참고]이다.

## 완료 조건

- 타임라인 내용 개수가 항목을 한 번씩만 세거나 0 판정 전용 값으로 바뀌고, 기존 테스트가 통과한다.
