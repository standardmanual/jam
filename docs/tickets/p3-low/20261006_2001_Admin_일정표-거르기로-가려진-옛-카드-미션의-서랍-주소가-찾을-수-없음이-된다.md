# [Admin] 일정표 거르기로 가려진 옛 카드·미션의 키로 서랍 주소를 열면 「찾을 수 없음」이 된다

## 핵심 요약

- 요구사항: 트라이브·패턴 거르기를 켜면 옛 카드·미션이 일정표에서 빠지는데, 서랍은 거르기 결과와 독립이라 `item=card:<uuid>`·`mission:<uuid>` 주소를 그대로 열면 찾지 못할 수 있다. 운영 항목은 API로 읽어서 영향이 없다.
- 구현 계획: 서랍이 거르기를 무시하고 그 항목을 직접 읽게 할지, 아니면 「거르기 때문에 보이지 않아요」 안내를 줄지 정한다(현재는 정해지지 않음).
- 관련 파일: `jam-web/src/lib/admin/opsSchedule/filters.ts`(62행 근처), `jam-web/src/app/admin/ops-schedule/ScheduleBody.tsx`

## 배경 / 문제 정의

티켓 20261006_1539(1502 ③-d) 게이트에서 민지와 아현이 남긴 범위 밖 발견물 [참고]이다.

## 완료 조건

- 거르기를 켠 상태에서 옛 카드·미션 서랍 주소를 열었을 때 「찾을 수 없음」 대신 항목이 열리거나 이유를 알리는 안내가 뜬다.
