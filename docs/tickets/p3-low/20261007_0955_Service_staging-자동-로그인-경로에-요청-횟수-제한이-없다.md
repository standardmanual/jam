# [Service] staging 자동 로그인 경로에 요청 횟수 제한이 없다

## 핵심 요약

- 요구사항: `/api/dev-login`은 staging(`STAGING_MODE=true`)에서 비로그인 방문자에게 열려 있고, 호출마다 service role로 `createUser`·`generateLink`를 하고 `verifyOtp`로 세션을 만든다. 요청 횟수 제한이 없다. 어드민 경로는 20261006_1527로 막혔고, 방문자가 얻는 세션은 공용 DB의 일반 유저 권한(RLS 범위)이다. 이번 배포가 들인 위험은 아니다.
- 구현 계획: 요청 횟수 제한(또는 staging 접근 보호)을 둘지 정한다. P2 20261006_1629(staging 자동 로그인 세션의 일반 API 노출)와 함께 판단한다.
- 관련 파일: `jam-web/src/app/api/dev-login/route.ts`(25–75행), `jam-web/src/proxy.ts`(84–91행)

## 배경 / 문제 정의

2026-10-07 `/jam-ship` 5단계 병렬 점검(민지 모드 ② 보안, 범위 565c3067b..9142afab7)의 범위 밖 발견물 [보안/참고] 3번이다. 승격을 막지 않는 항목이라 배포와 별도로 처리한다.
