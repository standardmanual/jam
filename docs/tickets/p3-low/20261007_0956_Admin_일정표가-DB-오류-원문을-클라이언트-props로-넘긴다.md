# [Admin] 일정표가 DB 오류 원문을 클라이언트 props로 넘긴다

## 핵심 요약

- 요구사항: 일정표가 읽기에 실패한 재료의 사유로 DB 오류 원문(`error.message`)을 `sourceErrors`에 담고, 이 값이 클라이언트 컴포넌트 `OpsScheduleBoard`의 props로 넘어가 RSC 페이로드에 실린다. 화면에는 고정 문장만 그려지고 어드민 세션 한정이라 실제 노출은 없다.
- 구현 계획: `sourceErrors` 값을 실패 여부(불리언)나 고정 코드로 바꾸고 원문은 서버 로그에만 남긴다.
- 관련 파일: `jam-web/src/lib/admin/opsSchedule/load.ts`(76–86행), `jam-web/src/app/admin/ops-schedule/ScheduleBody.tsx`(75–90행)

## 배경 / 문제 정의

2026-10-07 `/jam-ship` 5단계 병렬 점검(민지 모드 ② 보안, 범위 565c3067b..9142afab7)의 범위 밖 발견물 [보안/참고] 4번이다. 승격을 막지 않는 항목이라 배포와 별도로 처리한다.

## 완료 조건

- 클라이언트로 넘어가는 값에 DB 오류 원문이 없고 테스트로 고정된다.
