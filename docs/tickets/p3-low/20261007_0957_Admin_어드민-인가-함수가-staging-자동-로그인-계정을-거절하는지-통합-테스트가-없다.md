# [Admin] 어드민 인가 함수가 staging 자동 로그인 계정을 거절하는지 통합 테스트가 없다

## 핵심 요약

- 요구사항: `getAdminUser`·`requireAdmin`이 staging의 자동 로그인 계정 세션을 403으로 거절하는지 테스트가 없다. `auth.test.ts`는 `hasAdminAccess` 단위만 보고 `getUser`를 null로 고정하며, proxy 테스트도 `/admin`에서 이 계정이 `/forbidden`으로 가는 경로를 덮지 않는다.
- 구현 계획: `STAGING_MODE=true`에서 자동 로그인 계정 세션으로 `getAdminUser`·`requireAdmin`·proxy `/admin` 경로를 부르는 테스트를 추가한다.
- 관련 파일: `jam-web/src/lib/admin/__tests__/auth.test.ts`, `jam-web/src/lib/admin/__tests__/proxy-token-gate.test.ts`

## 배경 / 문제 정의

2026-10-07 `/jam-ship` 5단계 병렬 점검(민지 모드 ③ 테스트 공백, 범위 565c3067b..9142afab7)의 범위 밖 발견물 [테스트/참고] 6번이다. 승격을 막지 않는 항목이라 배포와 별도로 처리한다.

## 완료 조건

- 세 경로가 자동 로그인 계정을 거절하는 것이 테스트로 고정된다.
