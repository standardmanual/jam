# [Admin] 카드 조립이 어드민 화면·서버 스크립트·브라우저 모듈 세 벌로 갈라졌다

## 핵심 요약

- 요구사항: 같은 카드 조립 흐름과 브랜드 글자 J 값이 `AssetGeneratorViewport.tsx`(어드민 화면), `scripts/asset-generator/renderCard.mjs`(서버 스크립트), `lib/asset-generator/renderPreset.ts`(③-a)에 따로 있다. 한쪽만 고치면 그림이 어긋난다.
- 구현 계획: `renderPreset.ts`를 단일 조립으로 삼아 어드민 화면과 서버 스크립트가 쓰게 한다(동작 변화 없음, 기존 호출 기록 테스트로 확인). 서버 스크립트는 `@napi-rs/canvas` 의존 주입으로 맞춘다.
- 관련 파일: `jam-web/src/app/admin/asset-generator/AssetGeneratorViewport.tsx`(132·162·201·233·282·297줄), `jam-web/scripts/asset-generator/renderCard.mjs`(33~168줄), `jam-web/scripts/asset-generator/brandLetters.mjs`, `jam-web/src/lib/asset-generator/renderPreset.ts`

## 배경 / 문제 정의

티켓 20261007_0945(1803 ③-a) 게이트에서 민지와 아현이 남긴 범위 밖 발견물 [참고]이다. ③-b 서랍 실렌더로 브라우저 모듈의 그림이 확인된 뒤에 합치는 편이 안전하다.

## 완료 조건

- 카드 조립 흐름과 브랜드 글자 값이 한 곳에만 있고, 어드민 화면·서버 스크립트의 기존 테스트가 수정 없이 통과한다.
