# [Admin] 이미지 값 형식 판정이 서버 스크립트와 브라우저 모듈에서 다르다(Windows 경로)

## 핵심 요약

- 요구사항: `renderPreset.ts`의 `isImageSourceFormat`(50줄)은 절대 경로를 `startsWith('/')`로 판정해 Windows 경로를 다루지 않고, `applyLayerValues.mjs`는 `path.isAbsolute`를 쓴다. 두 곳의 판정을 맞춘다.
- 구현 계획: 브라우저에는 로컬 파일 경로 값이 들어오지 않으므로 판정을 `http(s)` URL만 받도록 좁히거나, 서버 스크립트와 같은 규칙으로 맞추고 대조 테스트를 추가한다.
- 관련 파일: `jam-web/src/lib/asset-generator/renderPreset.ts`(50줄), `jam-web/scripts/asset-generator/applyLayerValues.mjs`

## 배경 / 문제 정의

티켓 20261007_0945(1803 ③-a) 게이트에서 민지가 남긴 범위 밖 발견물 [참고]이다.
