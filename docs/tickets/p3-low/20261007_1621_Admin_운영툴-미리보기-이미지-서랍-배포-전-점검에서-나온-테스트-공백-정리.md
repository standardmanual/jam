# [Admin] 운영툴 미리보기·이미지 서랍 배포 전 점검에서 나온 테스트 공백 정리

> 출처: /jam-ship 2026-10-07 병렬 점검(민지 모드 ③). 높음 공백은 없었고 보통·낮음 공백을 한 티켓으로 모았다. 이번 배포를 막지 않는다.

## 핵심 요약

- 요구사항: 아래 공백에 테스트를 더한다. 이 저장소에는 jsdom·testing-library가 없어 컴포넌트 테스트가 `renderToStaticMarkup`과 순수 함수에 한정된다(클릭·상태 전이·effect는 닿지 않음). 훅·상호작용 공백은 순수 함수로 뽑아 테스트하거나 jsdom 도입을 별도로 판단한다.
- 보통 위험(우선):
  1. `jam-web/src/components/admin/ops/useItemImageProduction.ts` 훅 본체: 중복 시작 방지(`inFlight`), 실패 시 `IMAGE_FAILED_TOAST`, `finally`의 `onDone`, 없는 id의 early return.
  2. `jam-web/src/components/admin/ops/OpsItemFooter.tsx` `onDecided`: 승인하면 `imageProduction.start`가 불리고 반려하면 불리지 않는 연결(「승인 직후 자동 제작」의 유일한 접점, 빠져도 실패하는 테스트가 없다).
  3. `jam-web/src/components/admin/ops/OpsColorPairPicker.tsx` `apply`: 성공 시 `setColorPick(null)`·`onFilled`, 409 시 `onConflict`, 서버 `fieldErrors` 표시, `pending` 중 버튼 잠금.
  4. `jam-web/src/lib/admin/opsInbox/imageRender.client.ts`: `cropToAlphaBounds`(알파 임계값 8 경계, 불투명 픽셀 없음일 때 null), `browserImageLoader`(blob URL·`revoke`·타임아웃), 성공 경로.
  5. `jam-web/src/lib/asset-generator/renderPreset.ts`·`imageSpec.ts`: `bg`·`end`가 빈 문자열일 때 렌더가 실제로 던지는지(제출 경고 「색이 없으면 이미지가 만들어지지 않아요」의 약속을 뒷받침하는 테스트가 없다).
  6. `jam-web/src/components/ui/CollectionGridCard.tsx` `hideProgress`: 켜면 진행 바·「0/0」이 없고, 기본값이면 「1/4」가 그대로 나오는 직접 단언(서비스 컬렉션 목록 회귀를 지키는 단언이 없다).
  7. `jam-web/src/app/admin/today/TodayCardPreview.tsx`: effect(`ResizeObserver` 측정, 높이 보정)와 미지원 환경. 판이 `overflow-x-auto`에서 `overflow-hidden` 프레임으로 바뀌어, 측정이 안 되면(`scale`이 1로 남으면) 폭 360·430 카드가 잘릴 수 있다는 점(추측). `TodayPreviewModal`·`TodayCardForm`에서의 폭 전환.
- 낮음 위험: `decide.ts` `fillColor` 경계(`OPS_FIELD_UNKNOWN` 분기, 항목 없음 404, `image_spec` 없는 카드, `bg`만 맞고 `end` 비었을 때), `imageSpecToRenderArgs`의 시드 경계·`values` 배열/null, `validate.ts`의 이미지 칸 없는 종류가 `image_spec`을 틀리게 넣은 경고, `OpsCardPreview`의 배지·미션·컬렉션 승인됨·준비중 문구, `cardPreview.ts` `dropPreviewOf` 빈 입력, `BackgroundColorField` `compact`, `presetValidate.ts` 단위 테스트(null 레이어·대문자 스킴·덮어쓰기 경로), `loadLayerImage.mjs` 본문 읽는 중 타임아웃, `textOverflow.mjs` 경계 픽셀.
- 안티패턴(정리 후보): `itemImageProduction.test.ts`의 `OpsBulkApprove.tsx` 소스 정규식 검사(일괄 승인 제외를 소스 문자열로 단언), `no-html.test.ts`의 `style={` 사용 파일 인덱스 고정, `scheduleDrawer.test.tsx`의 `bundleId` 개수 단언.
