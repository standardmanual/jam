# [Infra] 패턴 사전 파서의 오류 경로와 SQL 확인 블록에 테스트가 없다

> 출처: 2026-10-07 `/jam-ship` 5단계 민지 모드 ③(배포 전 테스트 공백 점검)의 [정확성/참고] 3건. 자동 티켓화(`/jam-work` 3.2절).

## 핵심 요약

- 요구사항: `scripts/ops-patterns-seed.mjs`의 오류 경로 중 테스트가 없는 분기에 테스트를 더한다. 동작은 바꾸지 않는다.
  - 멈춤 조건마다 한 분기씩만 테스트되어 있다. 테스트가 없는 분기: 멈춤 2 샘플 중복 소속(309행), 멈춤 4 번호 비연속(322행), 멈춤 6 「샘플별 구현」 번호 중복·주보조 아님(336~337행),
    멈춤 7 표에 없는 패턴·본문에 없는 표 행·절 없음(342·348·357행), 멈춤 8 부록 행 수 ≠ 63·부록에만 없는 본문 샘플·절 없음(364·367·374행).
  - 「[원고 형식]」 오류: 필수 줄 누락(175행), 샘플 줄 꼴 오류(201행), 샘플 항목 읽기 실패(102행), 취향 신호 줄에 「: 」 없음(162행)·값 혼재(218행), 빈 문자열 입력,
    괄호가 닫히지 않은 메뉴 줄(`splitTopLevel` 49~65행, 나머지를 한 조각으로 삼킨다 — 이 동작을 멈춤으로 바꿀지는 착수 때 정한다).
  - SQL 구조 테스트(`scripts/ops-patterns-seed.test.mjs` 195~208행)가 `sql.includes('RAISE EXCEPTION')`만 본다. 확인 블록에 박힌 개수(18·43·7)와 취향 신호 쌍 목록이
    파싱 결과와 같은지 단정한다.
- 구현 계획: 착수 때 정한다. 티켓 20261007_1705(테스트를 원고 본문에서 떼어 내기)와 같은 파일을 고치므로 1705와 함께 처리하는 것을 추천한다.
- 관련 파일: `scripts/ops-patterns-seed.mjs`(위 행 번호), `scripts/ops-patterns-seed.test.mjs`.

## 완료 조건

- 위 분기마다 해당 문제 문장이 나오는지 단정하는 테스트가 있다. SQL 확인 블록의 개수·쌍 목록이 파싱 결과와 같은지 단정한다.
- `scripts/verify.sh`가 통과한다.
