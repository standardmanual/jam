# [Infra] 패턴 사전 시드 CLI에서 `--output` 뒤에 값이 없으면 커밋된 시드 파일을 덮어쓴다

> 출처: 2026-10-07 `/jam-ship` 5단계 민지 모드 ③(배포 전 테스트 공백 점검)의 [정확성/참고]. 자동 티켓화(`/jam-work` 3.2절).

## 핵심 요약

- 요구사항: `scripts/ops-patterns-seed.mjs` `main`의 `opt()`(520~523행)는 옵션 뒤에 값이 없으면 오류 없이 기본값으로 대체한다. 그래서 `--output`만 쓰고 경로를 빠뜨리면
  커밋된 `jam-web/supabase/migrations/212_ops_patterns_seed.sql`을 덮어쓴다. `--input`도 같은 방식이다. 값이 빠진 옵션은 오류(종료 1)로 멈추게 고친다.
- 구현 계획: `opt()`가 옵션은 있는데 값이 없거나 값이 `--`로 시작하면 오류를 내도록 바꾸고, 테스트를 더한다. `--check`에서 출력 파일이 없는 경로(527행 `existsSync`)는 이미 종료 1로 처리되므로
  그 경로의 테스트만 더한다.
- 관련 파일: `scripts/ops-patterns-seed.mjs` `main`(515~545행), `scripts/ops-patterns-seed.test.mjs` CLI 테스트(293행 부근).

## 배경 / 문제 정의

- 덮어쓰는 내용은 같은 원고로 만든 같은 SQL이라 지금은 피해가 없다. 원고가 DB의 사본(`source_of_truth: db`)이 된 뒤에는 원고만 고친 상태에서 실수로 덮어쓰면 커밋된 시드가 바뀐다.

## 완료 조건

- `--output`·`--input` 뒤에 값이 없으면 종료 코드 1과 안내 문장을 낸다. 테스트가 있다.
- `scripts/verify.sh`가 통과한다.
