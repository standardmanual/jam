# [Admin] 패턴 사전 목록이 요청마다 승인 이후 항목 전체를 읽어 사용 횟수를 센다

## 핵심 요약

- 요구사항: `/admin/ops-patterns` 목록의 「최근 4주」·「마지막 사용」은 `loadDrawUsageRows`로 승인 이후 상태의 운영 항목 **전체**를 요청마다 읽어 센다(`jam-web/src/app/admin/ops-patterns/page.tsx` 93행 부근,
  `jam-web/src/lib/admin/opsPatterns/draw.ts` `loadDrawUsageRows`). 항목이 쌓이면 화면 열기가 느려진다. 조합 뽑기 API의 같은 문제는 P3 20261007_2240에 있다.
- 구현 계획: 2240과 함께 정한다(읽는 기간을 「최근 28일 + 패턴별 마지막 사용 한 번」으로 좁히거나, 마지막 사용을 DB 집계로 읽기). 둘이 같은 세기 함수(`countOpsPatternUsage`)를 쓰므로 한 번에 고친다.
- 관련 파일: `jam-web/src/lib/admin/opsPatterns/draw.ts`(`loadDrawUsageRows`·`countOpsPatternUsage`), `jam-web/src/app/admin/ops-patterns/page.tsx`.

## 완료 조건

- 목록과 조합 뽑기가 같은 값을 내면서 읽는 행 수가 기간에 묶인다(테스트). 2240과 함께 닫는다.
