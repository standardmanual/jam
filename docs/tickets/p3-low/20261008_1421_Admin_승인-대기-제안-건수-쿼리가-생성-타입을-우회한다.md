# [Admin] 승인 대기 패턴 제안 건수 쿼리가 생성 타입을 우회해 칸 이름 오타를 못 잡는다

## 핵심 요약

- 요구사항: `countPendingPatternProposals`(`jam-web/src/lib/admin/opsPatterns/read.ts` 236행 부근)가 `as unknown as` 캐스팅으로 쿼리를 만든다. 칸 이름(`kind`·`status`·`ops_bundles.is_sample`)을 잘못 써도
  타입 검사가 못 잡고, 실행 때 오류가 나면 화면은 「승인 대기 제안을 읽지 못했어요」만 보인다.
- 구현 계획: 생성 타입(`database.generated.ts`)으로 쿼리를 쓰고 캐스팅을 없앤다. 내장 조인(`ops_bundles!inner`) 때문에 타입이 막히면, 같은 패턴을 쓰는 기존 읽기(`opsDecisions/read.ts`의 시험 묶음 거르기)의 방식을 따른다.
- 관련 파일: `jam-web/src/lib/admin/opsPatterns/read.ts`, `jam-web/src/lib/admin/opsPatterns/__tests__/read.test.ts`.

## 완료 조건

- 캐스팅 없이 typecheck가 통과하고, 칸 이름을 틀리게 바꾸면 typecheck가 실패한다. 기존 테스트 통과.
