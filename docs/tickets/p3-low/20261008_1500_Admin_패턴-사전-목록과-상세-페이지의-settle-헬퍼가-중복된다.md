# [Admin] 패턴 사전 목록과 상세 페이지의 settle 헬퍼가 중복된다

> 출처: 티켓 20261008_1435(⑨b) 민지 게이트의 범위 밖 발견물 [참고].

## 핵심 요약

- 요구사항: 읽기 실패를 기록하고 `{ ok: false }`로 바꾸는 `settle` 헬퍼가 `jam-web/src/app/admin/ops-patterns/page.tsx`(43행 부근)와 `jam-web/src/app/admin/ops-patterns/[patternNo]/page.tsx`(41행 부근)에
  같은 모양으로 두 벌 있다. 로그 라벨 접두(`ops-patterns/…`)만 다르다. 한쪽만 고치면 실패 처리 방식이 갈라진다.
- 구현 계획: `jam-web/src/lib/admin/opsPatterns/`(또는 어드민 공용 위치에 같은 헬퍼가 이미 있으면 그것)에 `settle(label, read)`와 `Settled<T>` 타입을 한 벌 두고 두 페이지가 가져다 쓴다.
  ⑩a·⑫a가 같은 구역 격리 패턴을 더 쓸 예정이라 그 전에 처리하면 좋다.
- 관련 파일: 위 두 페이지, `jam-web/src/lib/admin/queryError.ts`(`logQueryError`).

## 완료 조건

- `settle` 정의가 한 곳에만 있고 두 페이지의 로그 라벨은 지금과 같다. 기존 테스트 통과, 화면 동작 불변.
