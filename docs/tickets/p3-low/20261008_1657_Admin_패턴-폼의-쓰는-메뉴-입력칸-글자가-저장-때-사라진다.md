# [Admin] 패턴 폼의 쓰는 메뉴 입력칸에 적은 글자가 Enter 없이 저장하면 사라진다

> 출처: 티켓 20261008_1617(⑩a-2) 민지 게이트의 범위 밖 발견물 [참고] 1. 사용자 지시(2026-10-08 「머지하고 ① 같이 고쳐」)로 경미 수정(경로 ①) 처리.

## 핵심 요약

- 요구사항: `MenuChips`(`jam-web/src/components/admin/ops/OpsPatternFormParts.tsx` 186행 부근)는 칩 입력 글자를 자기 상태에만 둔다. 글자를 적고 Enter·[더하기]를 누르지 않은 채 [저장하기]를 누르면 그 글자는 저장 본문에 실리지 않고 사라지며 바뀐 칸 수에도 잡히지 않는다.
- 구현 계획: 메뉴 입력칸 `Input`에 `onBlur={add}`를 붙여, 칸을 떠나면 적어 둔 글자를 칩으로 넣는다(빈 글자·10개 상한은 `add`가 이미 거른다).
- 관련 파일: `jam-web/src/components/admin/ops/OpsPatternFormParts.tsx`(`MenuChips`의 `Input`).

## 완료 조건

- 메뉴 글자만 적고 Enter 없이 [저장하기]를 누르면 그 글자가 칩이 되고 저장 본문 `menus`에 실린다.

- 컴포넌트 상호작용 테스트는 jsdom이 없어 넣지 못했다(⑩a-2와 같은 제약). 실렌더로 확인했다.
