# [Admin] 패턴 폼 저장 뒤 화면 이동이 실패하면 저장 버튼이 다시 켜지지 않는다

> 출처: 티켓 20261008_1617(⑩a-2) 민지 게이트의 범위 밖 발견물 [참고] 2.

## 핵심 요약

- 요구사항: `OpsPatternForm`(`jam-web/src/components/admin/ops/OpsPatternForm.tsx` 187행 부근)은 저장 성공 뒤 `done`을 true로 두고 `router.push`를 부른다. 이동이 실패하거나 늦으면 저장 버튼과 이탈 경고가 꺼진 채로 남는다(새로 고치면 풀린다).
  저장은 이미 끝났으므로 데이터 손실은 없다.
- 구현 계획: 이동 뒤 일정 시간 안에 화면이 바뀌지 않으면 상세 링크를 안내하거나, `done` 상태에서도 「상세로 가기」 링크를 레일에 보인다. 방식은 착수 때 정한다.
- 관련 파일: `jam-web/src/components/admin/ops/OpsPatternForm.tsx`, `jam-web/src/components/admin/ops/patternSubmit.ts`.

## 완료 조건

- 저장 성공 뒤 이동이 되지 않아도 운영자가 상세로 갈 길이 화면에 있다. 기존 테스트 통과.
