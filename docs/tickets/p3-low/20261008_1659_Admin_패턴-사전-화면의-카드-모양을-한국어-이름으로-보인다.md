# [Admin] 패턴 사전 화면의 카드 모양을 코드 대신 한국어 이름으로 보인다

> 출처: 티켓 20261008_1435(⑨b) 잔여 이슈, 20261008_1617(⑩a-2) 민지 게이트의 범위 밖 발견물 [참고] 3.

## 핵심 요약

- 요구사항: 카드 모양 한국어 이름 상수가 없어 패턴 상세(⑨b)와 만들기·고치기 폼의 모양 선택(⑩a-2)이 `hero`·`poster`·`square`·`brief`·`list`를 코드 그대로 보인다.
- 구현 계획: 홈피드 카드 쪽에 이미 쓰는 모양 이름(어드민 홈피드 편집 화면·UX 라이팅 가이드)이 있으면 그것을, 없으면 이름을 정해 `CARD_SHAPES` 옆(`jam-web/src/lib/today/shape.ts`)에 한국어 이름 상수를 두고 두 화면이 같이 쓴다.
  새 용어면 `docs/service/writing/UX_WRITING_GUIDELINE.md`에 먼저 올린다.
- 관련 파일: `jam-web/src/lib/today/shape.ts`, `jam-web/src/lib/admin/opsPatterns/detailView.ts`, `jam-web/src/components/admin/ops/OpsPatternFormParts.tsx`(`CARD_SHAPE_OPTIONS` 152행 부근).

## 완료 조건

- 상세와 폼에서 카드 모양이 같은 한국어 이름으로 보이고, 저장 값은 코드 그대로다. 목록에 없는 모양은 지금처럼 「목록에 없는 모양」.
