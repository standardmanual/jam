# [Admin] 패턴 제안 승인 확인창이 「승인됨」·예약 등록 안내를 그대로 보인다

> 출처: 티켓 20261008_1845(⑪) 민지 게이트의 범위 밖 발견물 [참고] 1.

## 핵심 요약

- 요구사항: 받은 기획함 승인 확인창(`jam-web/src/components/admin/ops/OpsItemActions.tsx` 206~207행)은 종류와 관계없이 「승인하면 「승인됨」으로 바뀌고 기록이 남아요. 승인은 되돌릴 수 없어요.」·「예약은 승인한 뒤 [예약 등록하기]에서 해요.」를 보인다.
  ⑪ 이후 패턴 제안(`kind = 'pattern_proposal'`)은 승인하면 바로 「종료」되고 패턴 사전에 들어가며 예약 등록 대상이 아니므로, 이 안내가 틀린다.
- 구현 계획: 패턴 제안이면 확인창 문장을 「승인하면 패턴 사전에 새 패턴으로 넣고 이 항목은 종료돼요. 승인은 되돌릴 수 없어요.」 정도로 바꾼다(시험 묶음이면 「시험 묶음이라 패턴 사전에는 넣지 않아요」). 문장 고르기는 순수 함수로 두고 테스트한다.
- 관련 파일: `jam-web/src/components/admin/ops/OpsItemActions.tsx`, 해당 화면 테스트.

## 완료 조건

- 패턴 제안 승인 확인창에 「승인됨」·예약 등록 안내가 나오지 않고 사전 입력·종료 안내가 나온다. 다른 종류의 확인창 문장은 그대로다.
