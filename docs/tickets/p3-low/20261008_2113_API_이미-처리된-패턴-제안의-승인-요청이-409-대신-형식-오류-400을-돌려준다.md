# [API] 이미 처리된 패턴 제안의 승인 요청이 409 대신 형식 오류 400을 돌려준다

> 출처: 티켓 20261008_1845(⑪) 민지 게이트의 범위 밖 발견물 [참고] 2.

## 핵심 요약

- 요구사항: `approvePatternProposal`(`jam-web/src/lib/admin/opsInbox/decide.ts` 273행 부근)은 형식 검사(`readOpsPatternProposal`)를 상태 검사보다 먼저 한다. 그래서 이미 종료·반려된 패턴 제안의 내용 형식이 틀렸으면 「이미 다른 곳에서 처리한 항목이에요(409)」 대신 「…반려해 주세요(400)」가 나온다. DB는 바뀌지 않아 해롭지는 않다.
- 구현 계획: 형식 검사 전에 읽어 둔 항목 상태가 `reviewing`이 아니면 409를 먼저 돌려준다(조건부 update는 그대로 둔다 — 동시 처리 방어는 거기서 한다).
- 관련 파일: `jam-web/src/lib/admin/opsInbox/decide.ts`, `jam-web/src/lib/admin/opsInbox/__tests__/decide.test.ts`.

## 완료 조건

- 검토중이 아닌 패턴 제안을 승인하면 형식과 관계없이 409다. 검토중인 형식 오류 제안은 지금처럼 400이다. 기존 테스트 통과.
