# [Infra] 저장소 워크트리·브랜치 정리와 유실 위험 티켓 8건 복구

## 핵심 요약

- 요구사항: 쌓인 워크트리·로컬 브랜치·임시 보관(stash)을 정리하고, 정리 중 발견한 「staging에 없는 티켓」을 복구한다.
- 구현 계획: 코드 변경은 없다. 삭제 기준은 「staging에 병합됨」 「패치가 staging에 있음」 「파일이 staging에 있거나 이동됨」 「원격에 있음」이다. 복구한 티켓은 `git cherry-pick -x`로 옮겨 원래 커밋 해시가 메시지에 남는다.
- 관련 파일: 복구한 티켓 8건(`docs/tickets/p1-high/`, `p2-normal/`, `p3-low/`), `docs/agents/orchestrator.md`

## 배경 / 문제 정의

2026-10-14 사용자가 워크트리·커밋·브랜치를 점검해 정돈해 달라고 요청했다. 점검 중 2026-10-08에 만든 티켓 7건과 2026-09-25 티켓 1건이 staging 어디에도 없고 로컬 브랜치 둘과 원격 브랜치 하나에만 있다는 사실이 드러났다. 그중에는 P1 보안 권고(Next.js)와 P2 개인정보 노출 가능성 티켓이 있었고, 현황판에는 보이지 않았다.
