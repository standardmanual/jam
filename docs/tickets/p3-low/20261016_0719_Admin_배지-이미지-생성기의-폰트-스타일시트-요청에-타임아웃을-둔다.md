# [Admin] 배지 이미지 생성기의 폰트 스타일시트 요청에 타임아웃을 둔다

## 핵심 요약

- 요구사항: `jam-web/src/lib/admin/composeActivityBadgeImage.ts`의 `loadFontStylesheet()`(149~165행 부근)는 `<link>`의 `onload`·`onerror`가 둘 다 오지 않으면 promise가 끝나지 않아, CDN 연결이 걸린 채 대기하면 어드민의 배지 이미지 생성이 멈춘 것처럼 보인다. 이전에는 CDN 응답과 무관하게 진행했다.
- 구현 계획: 일정 시간(예: 5초) 뒤 resolve하는 타임아웃 경합을 두어 「실패해도 폴백으로 계속 굽는다」는 의도와 맞춘다.
- 근거: 티켓 20261015_2132 민지·채원②의 범위 밖 발견물.
