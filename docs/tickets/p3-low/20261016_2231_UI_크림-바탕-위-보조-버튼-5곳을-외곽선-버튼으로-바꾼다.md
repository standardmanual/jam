# [UI] 크림 바탕 위 보조 버튼 5곳을 외곽선 버튼으로 바꾼다

## 핵심 요약

- 요구사항: 보조 버튼(`variant="secondary"`, 면 `--default` #f2f2f2)은 크림 바탕(#fafaf0) 위에서 면 대비가 1.07:1이라 알약 윤곽이 거의 안 보이고 글자만 떠 보인다. 크림 바탕 위에 놓이는 5곳만 외곽선 버튼(`variant="outline"`, 투명 면 + `--foreground` 글자 + 1px `--field-border`)으로 바꾼다. 사용자가 추천안으로 승인했다(2026-10-16).
- 구현 계획: 아래 5곳의 `variant="secondary"`를 `variant="outline"`로 바꾼다. `Button`의 높이는 모든 변형이 1px 테두리 + 세로 패딩 보정으로 같게 맞춰져 있어(2133 2회) 높이가 바뀌지 않아야 한다. 클래스·변형을 단언하는 테스트가 있으면 함께 고친다.
- 관련 파일:
  - `jam-web/src/components/ui/TopNav.tsx:135` 문의 버튼(`size="xs"`)
  - `jam-web/src/app/(main)/profile/ProfileClient.tsx:628` 프로필 편집(`size="xs"`), `:708` 로그아웃
  - `jam-web/src/app/(main)/drops/DropsClient.tsx:237` 위치 권한 재시도
  - `jam-web/src/app/(main)/FeedSection.tsx:803` 더보기

## 배경 / 문제 정의

2133 2회에서 보조 버튼을 `--default`로 정했는데(시작 전 결정 2), 크림 바탕 위에서는 면이 1.07:1이라 보이지 않는다(민지·채원② 지적, 완료 기록 3:1 예외 표에 올라 있다). 글자 대비는 16.01:1이라 식별은 되지만 눌러야 하는 자리라는 신호가 약하다.

## 완료 조건

- 위 5곳이 외곽선 버튼으로 바뀌고 `Button` 높이가 바뀌기 전과 같다(`getBoundingClientRect`).
- `scripts/verify.sh`가 통과한다.
- 393px 폭 로컬 렌더(`next dev`)에서 문의·프로필 편집·로그아웃·더보기·위치 재시도 윤곽이 보인다.

## 범위 밖(사용자 판단 대기)

- 같은 크림 바탕이지만 시트 패널 안에 있는 보조 버튼: `OnboardingQuestSkipSheet.tsx:67`, `drops/BadgeDetailSheet.tsx:193`, `badges/[id]/BadgeShareButton.tsx:411`, `components/PoiCarouselModal.tsx:850`. 서비스 시트 패널이 크림(`--background`)이라 같은 문제가 있다. 이번에는 사용자가 승인한 5곳만 바꾸고 시트 쪽은 5곳을 본 뒤 정한다.
- 흰 카드 안(`MissionDetailClient.tsx:443`, `points/page.tsx:106`)과 `--warning` 면 위(`QuestPreviewBanner.tsx:92`)의 보조 버튼은 면 대비가 맞아 바꾸지 않는다.
