# [Feature] JAM2 노출·표기용 시간대 경계를 배지 시간대 상수와 맞출지 정한다

## 핵심 요약

- 요구사항: 4-4 1회가 배지 시간대 6구간을 상수 하나(`lib/badge-engine/timeBands.ts`, 새벽 5~7·오전 7~11·점심 11~14·오후 14~18·저녁 18~22·밤 22~5시, KST)로 합쳤다. 판정이 아닌 노출·표기 두 곳은 다른 경계와 이름을 그대로 쓴다. 같은 시간대인데 화면에 따라 이름이 다르게 보이면 헷갈리므로 맞출지 정한다.
- 구현 계획: 시작 때 두 곳이 배지 시간대와 같은 이름·경계여야 하는지 사용자에게 묻는다(홈 문구는 시간대 인사말이라 다를 수 있다). 맞추기로 하면 상수를 읽게 하고 문구·시험을 갱신한다.
- 관련 파일(2026-10-18 4-4 1회 게이트 지적): `jam-web/src/lib/today/exposure.ts` 36줄(`timeOfDayTag`: 5·8·11·17·22시 경계), `jam-web/src/lib/ambient-drop/schedule.ts` 72줄(`dayBandLabel`: 새벽·아침·오전 구분).

## 완료 조건

- 두 곳을 맞추거나 «인사말·예약 표기용이라 다르게 둔다»는 결정을 주석과 문서에 남긴다.
