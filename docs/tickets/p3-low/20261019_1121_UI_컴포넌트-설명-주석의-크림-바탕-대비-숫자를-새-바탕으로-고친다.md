# [UI] 컴포넌트 설명 주석의 크림 바탕 대비 숫자를 새 바탕(#f1f0eb)으로 고친다

## 핵심 요약

- 요구사항: 기본 배경이 #fafaf0에서 #f1f0eb로 바뀌고(티켓 20261019_1120) 회색 면이 #e9e7e0로 바뀌어, 컴포넌트 설명 주석과 프롬프트 문서에 적힌 「크림 바탕 대비」 숫자가 낡았다. 사용자가 1120에서 이 정리를 후속으로 미뤘다.
- 구현 계획: 아래 후보 파일에서 크림 바탕 또는 회색 면과의 대비 숫자를 찾아, 1120 티켓의 대비 표(또는 같은 공식의 계산)로 고친다. 동작은 바뀌지 않는다(주석·문서만).
- 관련 파일: 아래 「후보 파일」

## 배경 / 문제 정의

값(색)은 1120에서 모두 바꿨지만 컴포넌트 설명에는 「흰 카드와 크림 바탕의 대비 1.05:1」 「크림 위 5.18:1」 같은 숫자가 흩어져 있다(2026-10-19 `git grep` 기준 약 20개 파일). 같은 사실이 여러 곳에 적혀 있어 값이 바뀔 때마다 낡는 구조다(CLAUDE.md 규칙 5). 이번 정리에서 숫자를 새 값으로 맞추되, 단일 원천(디자인 시스템 문서 11, 토큰 파일)을 가리키는 문장으로 바꾸는 것이 낫다면 그렇게 줄여도 된다.

## 새 값 (WCAG 상대 휘도 공식, 새 바탕 #f1f0eb)

| 쌍 | 기존 | 새 값 |
|---|---|---|
| `foreground` #171717 | 17.07 | 15.71 |
| `muted` #666666 | 5.47 | 5.03 |
| `link` #0e7a38 | 5.18 | 4.77 |
| `accent` #19b551 | 2.57 | 2.37 |
| 흰 카드 #ffffff | 1.05 | 1.14 |
| `border` #cfc9b4 | 1.58 | 1.45 |
| 회색 면 #e9e7e0 (바탕 / 흰 면 / `muted` 글자 / `border`) | 해당 없음 | 1.08 / 1.24 / 4.64 / 1.34 |

표에 없는 쌍은 같은 공식으로 계산한다(손으로 추정하지 않는다).

- 후보 파일의 크림 바탕·회색 면 대비 숫자가 위 표의 값과 같거나, 단일 원천을 가리키는 문장으로 바뀌어 있다.
