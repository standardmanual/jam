# [Service] JAM2 공개 전 레시피의 운영자 시험 믹스가 포인트를 실제로 지급한다

## 핵심 요약

- 요구사항: 어드민이 공개 전 레시피를 확인하려고 돌리는 시험 믹스(`allowUnreleased`, 코드의 `testMix`)가 개체와 포인트를 실제로 지급한다. 시험 계정이 레시피 보상 포인트(`combine_recipe_reward`)와 결과 아이템 배지의 배지 포인트를 받는지, 받아도 되는지를 정한다.
- 확인한 사실(2026-10-20, 5-4 조사·2회): `jam-web/src/lib/combine/index.ts` 336~344줄의 `awardPoints(userId, matched.reward_points, 'combine_recipe_reward')`는 시험 믹스에서도 가드 없이 실행되고, 기록 쪽만 347줄 근처에서 `!testMix`로 가린다. 5-4 2회(티켓 `20261019_1314`)가 더한 `followUpCombineResultPoints`(`lib/combine/resultPointFollowUp.ts`)도 시험 믹스가 개체를 실제로 주므로 배지 포인트를 지급한다(운영자 시험 계정이 받는다). 5-4 시작 때 사용자 결정 5-d는 «의도 확인이 필요해 기록만 하고 고치지 않는다»였다.
- 구현 계획: 시작 때 두 가지를 사용자에게 묻는다. (1) 시험 믹스의 레시피 보상 포인트와 배지 포인트를 지급할지(추천: 지급하지 않는다, 시험 계정 원장이 어지러워지고 금고 집계(`point_treasury`)에 시험 포인트가 섞인다). (2) 시험 믹스가 개체와 재료 소모를 실제로 하는 현재 동작을 유지할지. 정해지면 시험 믹스일 때 지급을 건너뛰고 시험으로 고정한다.
- 관련 파일: `jam-web/src/lib/combine/index.ts`, `jam-web/src/lib/combine/resultPointFollowUp.ts`.

## 완료 조건

- 시험 믹스의 포인트 지급 여부가 결정되어 이 티켓에 기록되어 있고, 결정대로 동작한다(시험으로 확인).
