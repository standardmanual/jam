# [UI] 포인트 내역 행의 날짜가 320px에서 «오후»를 쪼개 줄바꿈한다

## 핵심 요약

- 요구사항: 포인트 화면의 내역 행은 날짜 줄(`2026년 9월 17일 오후 6시 58분`)이 320px 너비에서 «오 / 후»로 낱말 가운데에서 줄바꿈된다. 어절 단위로만 접히게 한다.
- 구현 계획: 날짜 줄(`<span className="text-xs text-muted">`)에 `break-keep`을 더한다. 같은 모양의 날짜 줄이 다른 목록 행에도 있는지 찾아 함께 본다.
- 관련 파일: `jam-web/src/app/(main)/points/page.tsx` 134~139줄(`ListRowCard`의 `subtitle` 안 날짜 `span`과 `note` `span`), `jam-web/src/components/ui/ListRowCard.tsx`(부제 래퍼), 날짜 문자열은 `jam-web/src/components/LocalDate.tsx`의 `formatKoreanDateTime`.

## 배경 / 문제 정의

티켓 20261019_1317 3회의 머지 뒤 로컬 화면 확인에서 발견했다(2026-10-21, 로컬 개발 서버, `/api/dev-login` 시험 계정). 320×568에서 «믹스 보상» 행 둘의 날짜가 «2026년 9월 17일 오 / 후 6시 58분»처럼 «오후» 가운데에서 갈렸다. 375px에서는 «오후 11시 / 31분»처럼 어절 사이에서 접혔다. 이번 티켓이 바꾼 코드가 아니라 원래 있던 모양이다. 가로 넘침은 없다.

## 상세 요구사항

### UI/UX 관점

- 320~430px에서 날짜가 어절 단위로만 접힌다.
- 간격이나 글자 크기는 바꾸지 않는다.

## 완료 조건

- [ ] 320px에서 날짜 줄이 낱말 가운데에서 끊기지 않는다
- [ ] 375·430px 모양이 그대로다
