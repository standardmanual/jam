# [UI] 미션 양식의 트라이브 관련 오류가 저장 버튼에서 먼 곳에 보인다

## 핵심 요약

- 요구사항: 어드민 미션 양식에서 저장할 때 트라이브 오류(없는 트라이브, 트라이브 미선택, «미션은 저장했지만 트라이브를 바꾸지 못했어요»)가 화면 중간의 달성 조건 구역(`conditionError`)에 보인다. 저장 버튼 옆 오류 칸(`saveError`)에는 접근을 줄이는 변경의 409만 보인다. 저장을 누른 자리에서 오류가 보이게 한다.
- 구현 계획: 트라이브 관련 오류를 `saveError` 칸으로 보내거나, 오류를 보인 구역으로 화면을 스크롤한다. 어느 쪽이든 조건 오류(`conditionError`)와 겹치지 않게 한다. 어드민은 shadcn/ui 표준을 따르며 채원 판정 대상이 아니다.
- 관련 파일: `jam-web/src/app/admin/missions/MissionForm.tsx` 268~276줄(오류 표시)과 `handleSave`, 시험 `jam-web/src/app/admin/missions/MissionForm.test.tsx`(서버 렌더)와 `missionFormRules.test.ts`.

## 배경 / 문제 정의

티켓 20261019_1318 1회 게이트(민지, 참고)가 발견했다. 폼이 닫히지 않아 오류는 보이지만 저장 버튼에서 멀어 놓칠 수 있다. 동작은 맞고 위치만의 문제다.

발견: 2026-10-21 티켓 20261019_1318 1회 게이트.
