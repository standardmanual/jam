# [Infra] 트라이브 고르기 화면 경로 이동 뒤, 기획과 현재 서비스 지도 문서의 옛 코드 경로를 고친다

## 핵심 요약

- 요구사항: 티켓 20261021_1247 1회에서 온보딩 화면(`/onboarding`)의 코드 위치가 `jam-web/src/app/(main)/onboarding`에서 `jam-web/src/app/(onboarding)/onboarding`으로 옮겨졌다(주소는 그대로). 기획과 현재 서비스 지도 문서가 옛 경로를 코드 위치로 적고 있어 정정한다. 정확한 문장은 문서를 열어 확인한다.
- 구현 계획: 아래 문서에서 `(main)/onboarding`을 찾아 새 경로로 고친다. 기획 스냅샷이라 고치지 않기로 한 문서가 있으면 그 문서는 경로 옆에 «2026-10-21에 옮겨짐» 한 줄만 더한다. 고친 뒤 `grep -rn "(main)/onboarding" docs`가 비어야 한다(이력 문서인 옛 티켓은 제외).
- 관련 파일(민지 보고, 줄 위치는 카리나가 직접 확인하지 않았다): `docs/plan/jam2/service-redesign/13 온보딩과 기존 유저·데이터.md` 96줄 근처, `docs/plan/jam2/service-redesign/14 안전과 윤리.md` 127줄 근처, `docs/plan/jam2/service-redesign/04 트라이브, 출신, 레벨.md` 83줄 근처, `docs/plan/jam2/service-redesign/current-service-map/06 트라이브, 온보딩, 계정, 소셜.md` 34줄 근처.
