# [UI] 홈의 Strava 동기화 길이 상단 바, 현황 스트립, 카드에 겹치고 연출 단계 설명의 마침표가 가이드와 다르다

## 핵심 요약

- 요구사항: (1) 미연동 유저의 홈에는 Strava 동기화로 가는 길이 상단 바의 «동기화» 버튼, 퀘스트 카드(지금 모양은 «JAM! 시작하기» 카드)의 버튼, 현황 스트립의 «Strava 동기화하면 시작해요» 세 곳에 있다. 첫 화면에서 같은 행동이 여러 번 보이므로 어느 쪽을 남길지 정한다. (2) 연출 단계 설명(`lib/i18n/ko.ts`의 `onboardingQuest.steps`)에 한 문장인데도 마침표가 붙은 문구가 있다. UX 라이팅 가이드 §3은 한 문장은 마침표를 쓰지 않고 두 문장 이상은 마침표를 쓴다. 가이드에 맞춘다.
- 구현 계획: (1)은 눈에 보이는 변경이라 채원 사전 판정을 받고 사용자에게 어느 길을 남길지 묻는다. (2)는 문구 몇 개의 마침표 정리와 문구 시험 갱신이다.
- 관련 파일: `jam-web/src/app/(main)/page.tsx`(현황 스트립), `jam-web/src/app/(main)/OnboardingQuestCard.tsx`, `jam-web/src/lib/i18n/ko.ts` 253줄 근처. 줄 위치는 아현과 민지 보고이며 카리나가 직접 확인하지는 않았다.

## 배경 / 문제 정의

티켓 20261021_1248 2회 게이트(민지)와 채원 사전 판정이 발견했다. 2회는 카드 안의 실제 단계 문구만 가이드에 맞췄고, 연출 단계 본문과 홈의 다른 동기화 길은 범위 밖이라 고치지 않았다.

발견: 2026-10-21 티켓 20261021_1248 2회 게이트.

## 상세 요구사항

### UI/UX 관점

- 한 화면에서 같은 행동의 입구가 몇 개인지 정하고(채원 판정), 하나의 주된 입구와 나머지의 위계를 정한다.
- 연출 단계 설명의 마침표를 가이드대로 정리한다.
