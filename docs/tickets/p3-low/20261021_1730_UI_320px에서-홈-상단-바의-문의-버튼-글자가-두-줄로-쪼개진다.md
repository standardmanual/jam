# [UI] 320px에서 홈 상단 바의 «문의» 버튼 글자가 두 줄로 쪼개진다

## 핵심 요약

- 요구사항: 폭 320px에서 홈을 열면 상단 바의 «문의» 버튼이 «문»과 «의»로 두 줄에 쪼개져 보인다(2026-10-21 개발 서버 로컬 확인, 폭 390px에서는 한 줄). 로고, «문의», «동기화», 알림, 프로필 아이콘이 한 줄에 들어가지 못해 «문의»가 가장 좁게 눌린다. 버튼이 줄바꿈하지 않게 하고(`whitespace-nowrap`) 좁은 폭에서 다른 요소가 줄어들거나 간격이 줄도록 맞춘다.
- 구현 계획: 상단 바 구성 요소의 폭 배분을 읽고 가장 작은 변경(글자 줄바꿈 금지와 간격·크기 조정)을 정한다. 눈에 보이는 변경이라 채원 사전 판정을 받는다.
- 관련 파일: 홈 상단 바(`jam-web/src/components/` 아래 TopNav 계열, `(main)/layout.tsx`가 쓰는 것). 파일과 줄은 시작 때 확인한다. 카리나는 실화면에서만 확인했고 코드는 읽지 않았다.

## 배경 / 문제 정의

티켓 20261021_1248 2회 머지 뒤 로컬 확인(320px)에서 카리나가 발견했다. 이번 변경은 상단 바를 건드리지 않았고 이전부터 있던 문제로 보인다(이 티켓에서는 이전 커밋과 대조하지 않았다).

발견: 2026-10-21 티켓 20261021_1248 2회 로컬 확인.

## 상세 요구사항

### UI/UX 관점

- 320px에서 상단 바의 모든 버튼 글자가 한 줄로 보이고 가로 넘침이 없다.
- 390px 이상의 모양은 바뀌지 않는다.

## 완료 조건

- [ ] 320px에서 «문의»가 한 줄로 보인다
- [ ] 320px와 390px에서 상단 바가 가로로 넘치지 않는다
- [ ] 관련 시험이 통과한다
