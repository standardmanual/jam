# [Infra] 소스 트리를 훑는 시험 여러 건이 전체 실행에서 1초 넘게 걸린다

## 핵심 요약

- 요구사항: `pressClass.test.tsx`, `orphaned-contract.test.ts`, `pending-items.test.ts` 같은 시험이 소스 트리를 직접 훑어 전체 실행에서 1.3~2.1초를 쓴다. 아직 5초 제한에는 못 미친다. 같은 방식으로 훑는 시험이 더 늘면 티켓 `20261021_1019`와 같은 부하 실패가 다시 생길 수 있으므로, 어디까지 손볼지 정한다.
- 구현 계획: ① 소스 트리를 훑는 시험을 `grep`으로 모두 찾아 전체 실행에서 각각 얼마나 걸리는지 잰다. ② 1초 이상인 시험만 대상으로 삼아 파일 목록과 파일 내용을 시험 사이에서 공유하는 방법(공용 보조 파일 하나)을 정한다. 티켓 `20261021_1733`의 크롤러 통합과 함께 처리하는 편이 낫다. ③ 손볼 만한 시험이 없으면 이 티켓을 «남김, 사유»로 닫는다.
- 관련 파일: `jam-web/src/components/ui/__tests__/pressClass.test.tsx`, `jam-web/src/app/admin/item-badges/__tests__/orphaned-contract.test.ts`, `jam-web/src/lib/strava/__tests__/pending-items.test.ts`. 소요 시간은 민지 보고이며 카리나가 다시 재지는 않았다.

## 배경 / 문제 정의

티켓 20261021_1019 게이트(민지)가 참고로 지적했다. 1019는 `'use client'` 파일에서 출발해 import 사슬을 따라가는 시험 두 건만 고쳤다(파일별 import 목록을 한 번만 만든다). 소스 트리를 훑는 다른 시험은 손대지 않았다.

발견: 2026-10-21 티켓 20261021_1019 게이트.
