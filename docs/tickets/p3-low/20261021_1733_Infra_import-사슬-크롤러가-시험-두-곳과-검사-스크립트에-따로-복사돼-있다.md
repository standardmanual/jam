# [Infra] import 사슬 크롤러가 시험 두 곳과 검사 스크립트에 따로 복사돼 있다

## 핵심 요약

- 요구사항: 클라이언트·서버 경계를 확인하는 크롤러(`resolveLocal`·`specifiersOf`·`crawl`·`walk`)가 시험 파일 두 곳에 복사돼 있고, 같은 규칙을 `scripts/check-client-server-imports.mjs`도 따로 본다. 티켓 `20261021_1019`에서 캐시를 넣을 때 두 곳에 서로 다른 모양으로 각각 넣어야 했다. 한 곳으로 모을지 정한다.
- 구현 계획: ① 세 곳의 규칙이 실제로 같은지 비교한다(타입만 가져오는 import를 거르는지, 동적 import와 `require`를 보는지 등). ② 같다면 시험에서 함께 쓰는 보조 파일 하나로 모으고 캐시도 거기에 둔다. 다르다면 차이가 의도인지 확인하고 의도가 아니면 맞춘다. ③ 모으지 않기로 하면 이 티켓을 «남김, 사유»로 닫는다.
- 관련 파일: `jam-web/src/lib/capsule/__tests__/capsule-boundary.test.ts` 49~82줄 근처, `jam-web/src/lib/inventory/__tests__/lockedItemFill.test.ts` 593~609줄 근처, `scripts/check-client-server-imports.mjs`. 줄 위치는 민지 보고이며 카리나가 직접 확인하지는 않았다.

## 배경 / 문제 정의

티켓 20261021_1019 게이트(민지)가 참고로 지적했다. 복사본이 서로 어긋나면 한 곳의 판정만 바뀌어도 알아차리기 어렵다. 티켓 `20261021_1732`(소스 트리를 훑는 다른 시험)와 함께 처리하면 보조 파일을 한 번만 만든다.

발견: 2026-10-21 티켓 20261021_1019 게이트.
