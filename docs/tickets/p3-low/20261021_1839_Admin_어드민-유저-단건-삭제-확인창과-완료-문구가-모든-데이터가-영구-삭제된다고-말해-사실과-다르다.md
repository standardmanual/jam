# [Admin] 어드민 유저 단건 삭제의 확인창과 완료 문구가 «모든 데이터를 영구 삭제»라고 말해 사실과 다르다

## 핵심 요약

- 요구사항: 어드민 유저 상세의 완전 삭제 확인창은 «보유한 모든 배지·아이템·활동 기록까지 사라집니다», 완료 문구는 «모든 데이터를 영구적으로 삭제했습니다»라고 말한다. 티켓 `20261021_1249` 1회부터 아이템 배지는 «없어짐» 처리되고(개체 행은 번호와 함께 남는다), 위치정보 확인자료와 부정 이용 탐지 기록 일부는 법정 기간(6개월·3개월) 보관 표로 복사된다. 문구를 사실에 맞게 고치고, 단건 삭제에도 일괄 삭제 미리보기처럼 지워지는 범위를 보여 줄지 정한다.
- 구현 계획: ① 일괄 삭제 미리보기(`UserBulkImpactSummary.tsx`, 1회에서 «없어짐으로 처리돼요»와 보관 건수 한 줄을 더했다)와 같은 표현으로 단건 문구를 맞춘다. ② 단건 경로에 `dry_run` 미리보기를 붙일지 정한다(붙이면 `api/admin/users/[id]/route.ts`에 GET 또는 POST `dry_run`). 어드민 화면은 MODULAR 적용 대상이 아니다.
- 관련 파일: `jam-web/src/app/admin/users/DeleteUserButton.tsx` 77줄과 92줄(민지 보고, 카리나가 직접 확인하지는 않았다), `jam-web/src/lib/i18n/ko.ts`(문구가 있다면).

## 배경 / 문제 정의

티켓 20261021_1249 1회 게이트(민지, 주의)가 발견했다. 이 티켓은 문구만 사실에 맞추는 작은 일이다. 6-3 3회에서 유저용 탈퇴 화면을 만들 때 같은 표현을 쓰므로, 그 전에 맞추면 문구가 한 갈래로 모인다.

발견: 2026-10-21 티켓 20261021_1249 1회 게이트.

## 상세 요구사항

### UI/UX 관점

- 문구는 `UX_WRITING_GUIDELINE.md`와 fluent-korean 지침을 따른다.
- 일괄 삭제 미리보기와 단건 확인창이 같은 사실을 같은 말로 알린다.
