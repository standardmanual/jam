# [UI] Strava 연결 끊기 시트의 본문 가장자리가 제목과 8px 어긋난다

## 핵심 요약

- 요구사항: `StravaDisconnectSheet`의 본문 문단은 `px-4`인데 제목은 `px-6`이라 왼쪽 가장자리가 8px 어긋난다. 같은 시트 계열인 탈퇴 시트(`WithdrawSheet`)와 중복 안내 시트(`StravaDuplicateSheet`)는 본문을 제목과 같은 `px-6`으로 맞췄다. 연결 끊기 시트도 `px-6`으로 맞춘다.
- 구현 계획: `StravaDisconnectSheet.tsx`의 본문 래퍼 패딩을 `px-6`으로 바꾸고, 본문이 4문단으로 늘어난 뒤(티켓 `20261021_1249` 4회) 360×640에서 스크롤로 끝까지 닿는지 `offsetHeight`로 잰다. 시험 `StravaSheets.test.tsx`의 클래스 단언이 있으면 같이 고친다.
- 관련 파일: `jam-web/src/components/strava/StravaDisconnectSheet.tsx` 67줄 근처(민지·채원 보고, 카리나가 직접 확인하지는 않았다).

## 배경 / 문제 정의

6-3 4회 채원 사전 판정과 사후 리뷰가 계획 밖이라 고치지 않고 후속으로 제안했다. 4회가 이 시트의 본문 한 줄을 더해 어긋남이 조금 더 눈에 띈다.

발견: 2026-10-22 티켓 20261021_1249 4회 채원 사전 판정.

## 상세 요구사항

### UI/UX 관점

- 제목과 본문의 왼쪽 가장자리가 같아야 한다. 새 토큰과 리터럴 값을 쓰지 않는다.
