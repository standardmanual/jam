# [UI] 친구 활동 피드(`/feed`)가 카드에 누구의 활동인지 보이지 않아 챕터 오름이 누구의 것인지 알 수 없다

## 핵심 요약

- 요구사항: `/feed`(팔로우한 유저들의 피드)는 카드에 활동의 주체(이름이나 아바타)를 표시하지 않는다(`FeedSection.tsx` 주석 «이벤트별 주체 표시는 없다»). 티켓 `20261021_1249` 5회가 더한 챕터 오름 카드는 대상이 «챕터 3»뿐이라 친구 피드에서 누가 올랐는지 알 수 없다. 운영 로직 15.3이 노린 소셜 효과(친구의 챕터 오름과 컬렉션 완성을 보는 것)가 프로필 화면에서만 온전하다. 모든 카드에 주체를 더할지 정한다.
- 구현 계획: ① `/feed`에서 카드마다 주체(이름 또는 아바타, 탈퇴 유저는 `₩*&%#@`)를 보이는 모양을 채원 판정으로 정한다. ② `feed/page.tsx`가 피드 행에 유저 정보를 함께 읽고(`user_id` → `users` 조인), `FeedSection`이 주체 표시 모드를 받게 한다(프로필 화면은 본인 피드라 표시하지 않는다). ③ 기존 6종 카드와 새 2종이 같은 모양으로 바뀐다.
- 관련 파일: `jam-web/src/app/(main)/feed/page.tsx` 18줄·54~66줄, `jam-web/src/app/(main)/FeedSection.tsx`(카드와 시트, 채원 보고, 카리나가 직접 확인하지는 않았다).

## 배경 / 문제 정의

6-3 5회 채원 사전 판정이 고지했고 게이트(민지)도 참고로 적었다. 5회는 기존 카드와 같게 두기로 했고(모든 카드 변경은 `/feed` 전체 변경이라 범위가 커진다), 후속으로 분리했다.

발견: 2026-10-22 티켓 20261021_1249 5회 채원 사전 판정.

## 상세 요구사항

### UI/UX 관점

- 새 컴포넌트와 새 토큰 없이 기존 아바타·이름 부품으로 푼다. 공개 범위(팔로우한 유저의 활동만)는 바꾸지 않는다.

## 완료 조건

- [ ] 친구 피드의 모든 카드에서 누구의 활동인지 알 수 있다
- [ ] 프로필 화면(본인 피드)의 모양은 그대로다
