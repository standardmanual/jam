# [UI] 정지됨 소식 문구의 «문의로 알려 드려요»가 누가 누구에게 알리는지 모호하다

## 핵심 요약

- 요구사항: 티켓 `20261021_1249` 5회의 정지됨 소식 문구는 «이용이 정지됐어요. 정지 사유와 해제 방법은 문의로 알려 드려요»다(채원 사전 판정 원문). «문의로 알려 드려요»는 유저가 문의로 물으면 서비스가 알려 준다는 뜻과 서비스가 문의 채널로 따로 연락한다는 뜻 모두로 읽힌다. 착지가 홈이라 정지 안내 배너(사유, 정지일, 문의하기 버튼)가 바로 보여서 실사용 혼동은 작지만 문장을 분명히 한다.
- 구현 계획: 후보 문장 «이용이 정지됐어요. 정지 사유는 홈의 안내에서 볼 수 있고, 궁금한 점은 문의로 남겨 주세요.»처럼 사유를 보는 곳과 문의하는 쪽(유저)을 나눠 쓴다. 문구는 `ko.ts`의 `msgSuspensionStarted`(1829줄 근처, 민지 보고)이고 정지됨 소식은 사유를 싣지 않는다는 원칙은 그대로다. 채원과 UX 라이팅 가이드(§2.3 차분 · 공감, §4.1)로 확정하고 `message-href.test.ts`의 문구 단언을 같이 고친다.
- 관련 파일: `jam-web/src/lib/i18n/ko.ts` 1829줄 근처, `jam-web/src/lib/notifications/__tests__/message-href.test.ts`.

## 배경 / 문제 정의

6-3 5회 게이트(민지, 참고)가 발견했다. 채원 판정 원문 그대로라 5회에서는 건드리지 않았다.

발견: 2026-10-22 티켓 20261021_1249 5회 게이트.
