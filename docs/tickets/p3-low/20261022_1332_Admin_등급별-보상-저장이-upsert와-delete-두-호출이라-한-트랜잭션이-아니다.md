# [Admin] 등급별 보상 저장이 upsert와 delete 두 호출이라 한 트랜잭션이 아니다

## 핵심 요약

- 요구사항: `itembookTierRewards.ts`의 저장은 값이 있는 등급은 upsert, 두 칸이 모두 빈 등급은 delete로 두 번 나뉘어 호출한다. upsert가 성공하고 delete가 실패하면 일부만 반영된 채 500이 나가고, 같은 값으로 다시 저장하면 복구된다. 4등급 컬렉션이 0개라 지금은 영향이 없다. 한 DB 함수로 묶을지 정한다.
- 구현 계획: 후보: (가) 지금처럼 두고 다시 저장하면 복구된다는 안내를 유지한다. (나) 저장을 한 DB 함수로 묶는다(마이그레이션이 필요하다). 비용 대비 효과를 보고 정한다.
- 관련 파일: `jam-web/src/lib/admin/itembookTierRewards.ts` 198~228줄(민지 보고).

## 배경 / 문제 정의

민지 게이트(참고)가 발견했다. 구현자가 이미 같은 사실을 밝혔다.

발견: 2026-10-22 티켓 20261022_1139(7-8) 2회 게이트(민지).
