# [Admin] 등급별 보상 포인트 칸에 잘못된 입력을 넣으면 오류 안내 없이 기본값으로 저장될 수 있다

## 핵심 요약

- 요구사항: 포인트 칸이 `type=number`라 브라우저가 잘못된 입력(예: «1e»)을 빈 문자열로 넘기면 `parsePointsText`가 빈 칸(기본값)으로 읽어 오류 안내 없이 기본값으로 저장될 수 있다. 확신도는 낮고 실렌더로 확인하지 않았다. 확인해서 필요하면 입력 검증을 보강한다.
- 구현 계획: 로컬에서 «1e», «-1», «1.5»를 넣어 저장 직전 값을 확인한다(저장은 누르지 않고 임시 미리보기 페이지를 쓴다). 문제가 확인되면 `type=text`와 `inputMode`로 바꾸거나 `validity.badInput`을 검사한다.
- 관련 파일: `jam-web/src/components/admin/itembooks/ItemBookTierRewards.tsx` 115줄 근처(민지 보고), `jam-web/src/lib/admin/itembookTierRewards.ts`.

## 배경 / 문제 정의

민지 게이트(참고)가 발견했다.

발견: 2026-10-22 티켓 20261022_1139(7-8) 2회 게이트(민지).

## 상세 요구사항

### 서비스/코드베이스 관점

- 정상 입력과 «비우면 기본값»은 바꾸지 않는다.

## 완료 조건

- [ ] 잘못된 입력이 기본값으로 조용히 저장되지 않는다(확인 결과를 기록하고 필요하면 시험으로 고정)
