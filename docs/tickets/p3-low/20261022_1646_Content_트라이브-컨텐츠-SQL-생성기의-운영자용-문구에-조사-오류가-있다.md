# [Content] 트라이브 컨텐츠 SQL 생성기가 만드는 운영자용 문구의 조사가 받침에 맞지 않는다

## 핵심 요약

- 요구사항: 7-6 생성기가 SQL 머리말과 예외 메시지에 넣는 트라이브 이름 뒤 조사(`는`, `가`)를 이름의 받침에 맞게 바꾼다.
- 구현 계획: 받침 여부로 `은/는`, `이/가`를 고르는 작은 함수를 생성기에 두고, 두 곳의 고정 조사를 그 함수로 바꾼다. 생성기 시험의 기대 문자열도 함께 고친다.
- 관련 파일: `jam-web/scripts/jam2-content/gen-content-sql.mjs`의 머리말 문구(366줄 부근)와 트라이브 확인 예외 메시지(464줄 부근), 시험 `jam-web/scripts/jam2-content/__tests__/gen-content-sql.test.mjs`.

## 배경 / 문제 정의

7-6 2회 게이트(민지)가 참고 등급으로 발견한 사항이다. 트라이브 이름에 조사를 붙이는 두 곳이 `«${tribeName}»는`, `«${tribeName}»가`처럼 조사를 고정해 두어, 이름에 따라 `«혼자들»가 0개입니다`처럼 받침과 맞지 않는 문장이 나온다. 이 문구는 SQL 주석과 `RAISE EXCEPTION` 메시지에만 들어가며 사용자 화면에는 나오지 않는다. 1회부터 있던 문제이고, 7-6 판정에는 영향을 주지 않았다.

## 상세 요구사항

- 생성기가 만드는 모든 문구에서 트라이브 이름 뒤 조사가 받침에 맞아야 한다(5개 트라이브 이름 전부).
- 이미 만든 SQL 275~280은 생성기를 고친 뒤 다시 생성하면 머리말과 메시지 한 줄씩만 달라진다. 이 파일들이 DB에 적용되기 전이면 같은 PR에서 다시 생성하고, 적용된 뒤라면 파일은 두고 생성기만 고친다(적용된 마이그레이션 파일은 고치지 않는다).

## 진행 기록

- 2026-10-22: 7-6 2회 게이트의 범위 밖 발견물로 만들었다.
