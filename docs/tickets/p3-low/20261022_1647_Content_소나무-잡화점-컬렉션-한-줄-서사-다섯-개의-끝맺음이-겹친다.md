# [Content] 소나무 잡화점 컬렉션 한 줄 서사 열 개 중 다섯 개의 끝맺음이 겹친다

## 핵심 요약

- 요구사항: 소나무 잡화점의 컬렉션 한 줄 서사 10개를 윈터가 검수해, 컬렉션 목록에 나란히 보일 때 문장 끝맺음이 겹치는 곳을 다듬을지 정한다.
- 구현 계획: 윈터가 원고의 한 줄 서사 10개를 읽고 고칠 항목을 제안한다. 고치기로 하면 원고를 고친 뒤 279를 다시 생성한다(적용 전이면 파일을 다시 쓰고, 적용 뒤면 설명 고치기 SQL을 따로 쓴다).
- 관련 파일: `docs/plan/jam2/tribe-rethink/manuscript/04 물건 덕후.md`(원고, 단일 원천), `jam-web/supabase/migrations/279_tribe_content_sonamu.sql`의 컬렉션 행 120~130줄 부근.

## 배경 / 문제 정의

7-6 2회 게이트(민지)가 참고 등급으로 발견한 사항이다. 소나무 잡화점 컬렉션 10개의 한 줄 서사 가운데 1·4·5·7·9번이 «~의 칸입니다»로 시작하거나 끝나서, 컬렉션 목록에 나란히 보이면 리듬이 겹친다. 문구는 원고 글자 그대로이며 트라이브 목소리는 윈터의 검수 범위(`SLOP_DICTIONARY` 예외)라서 판정에는 반영하지 않았다.

## 상세 요구사항

- 윈터가 목소리를 해치지 않는 범위에서 겹침을 줄일지 판단한다. 고치지 않기로 하면 이 티켓에 이유를 적고 닫는다.
- 고치기로 하면 컨텐츠 문서와 DB 값이 같은 문장을 가리키는지 확인한다(원고가 단일 원천이다).

## 진행 기록

- 2026-10-22: 7-6 2회 게이트의 범위 밖 발견물로 만들었다.
