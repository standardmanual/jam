# [API] 소속 트라이브가 없는 호출을 등급 올리기 API가 전용 코드와 문구로 거절한다

## 핵심 요약

- 요구사항: 소속 트라이브가 없는 유저가 `POST /api/combine/tier-up`을 부르면 `loadRollData`가 `CapsuleError('no_tribe')`를 던져 라우트가 일반 500과 `genericFail` 문구를 돌려준다. 재료는 소각 전이라 안전하지만 원인을 알 수 없다. 전용 코드와 문구로 거절한다.
- 구현 계획: 라우트의 오류 처리에서 `no_tribe`를 409(또는 200 `success:false`)와 전용 `reason`으로 바꾸고, 클라이언트 `tierUpClient.ts`의 거절 처리와 문구(`ko.ts`)를 더한다. 문구는 UX 라이팅의 [현상, 원인, 해결책] 구조를 따른다.
- 관련 파일: `jam-web/src/app/api/combine/tier-up/route.ts`(76~79행), `jam-web/src/lib/combine/tierUp.ts`, `jam-web/src/lib/capsule/open.ts`(87행 `loadRollData`), `jam-web/src/app/(main)/combine/tierUpClient.ts`

## 배경 / 문제 정의

티켓 `20261022_2119` 2회 게이트가 남긴 참고였고 3회에서 확인했다. `(main)` 레이아웃이 트라이브가 없는 유저를 트라이브 선택 화면으로 보내므로 화면에서는 이 경우에 닿을 수 없다. API를 직접 부를 때만 일어나서 우선순위가 낮다.

## 완료 조건

- 소속 트라이브가 없는 호출이 500이 아니라 전용 코드로 거절되고 재료는 그대로다.
- 시험이 이 경로를 고정한다. 화면 쪽 문구가 UX 라이팅 가이드를 따른다.
