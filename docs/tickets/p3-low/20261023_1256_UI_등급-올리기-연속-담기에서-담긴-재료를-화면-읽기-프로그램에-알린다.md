# [UI] 등급 올리기 연속 담기에서 담긴 재료를 화면 읽기 프로그램에 알린다

## 핵심 요약

- 요구사항: 등급 올리기 재료 시트에서 연속으로 담을 때, 슬롯이 시트 뒤에 있어 화면 읽기 프로그램 사용자는 재료가 담겼다는 말을 듣지 못한다. 눌린 셀이 비활성이 되거나 묶음 보기가 고정 보기로 바뀌면 포커스가 빠진다(지금은 BottomSheet의 포커스 트랩이 첫 셀로 복구한다).
- 구현 계획: 담을 때마다 담은 배지 이름만 읽어 주는 `sr-only` `aria-live="polite"` 알림을 더한다. 진행률 숫자(«2/5» 같은 말)는 쓰지 않는다(MixerSlot 문서의 확정 사항). 포커스가 어디로 가는지도 함께 확인한다.
- 관련 파일: `jam-web/src/app/(main)/combine/TierUpPanel.tsx`, 문구는 `jam-web/src/lib/i18n/ko.ts`의 `combine.tierUp`

## 배경 / 문제 정의

티켓 `20261022_2119` 3회의 채원 사후 리뷰 제안이다. 사용자 노출 문구가 늘어나므로 UX 라이팅 가이드를 확인한다.

## 완료 조건

- 재료를 담을 때마다 배지 이름이 화면 읽기 프로그램에 읽히고 진행률 숫자는 없다.
- 담은 직후 포커스가 시트 안에서 자연스러운 곳에 있다. 해당 시험이 통과한다.
