# [UI] 믹스 화면의 «확률 안내» 링크가 등급 올리기 섹션으로 바로 열리게 한다

## 핵심 요약

- 요구사항: 등급 올리기 화면의 «확률 안내» 링크(`/probability`)를 누르면 페이지 맨 위로 열려서, 등급 올리기 표까지 2~3화면을 스크롤해야 한다. 링크가 새 «등급 올리기» 섹션으로 바로 열리게 한다. 티켓 `20261022_2119`(7-7a) 4회의 채원 사전 판정이 후속 제안으로 남겼다.
- 구현 계획: 링크를 `/probability#tier-up`으로 바꾸고, 확률 안내 페이지의 «등급 올리기» 섹션에 `id="tier-up"`과 고정 상단 바에 가리지 않게 하는 `scroll-mt`를 둔다. `(legal)` 레이아웃의 스크롤 컨테이너가 window인지 먼저 실측한다(컨테이너가 따로 있으면 해시 이동이 동작하지 않을 수 있다).
- 관련 파일: 링크는 `jam-web/src/app/(main)/combine/TierUpPanel.tsx`(확률 안내 링크, 시험은 `TierUpPanel.test.tsx`), 섹션은 `jam-web/src/app/(legal)/probability/page.tsx`의 `TierUpSection`(4회가 만든다), 레이아웃은 `jam-web/src/app/(legal)/`의 레이아웃 파일

## 배경 / 문제 정의

4회가 확률 안내 페이지에 «등급 올리기» 섹션을 더하면 그 섹션은 시스템 드랍 아래에서 시작한다. 믹스 화면의 링크는 지금 페이지 맨 위로 열리므로 유저가 표를 찾으려면 스크롤해야 한다. 3회(믹스 화면)와 4회(확률 안내 페이지)가 서로 다른 화면이라 4회에는 넣지 않았다. 4회가 머지된 뒤에 한다.

## 완료 조건

- 믹스 화면 등급 올리기 화면의 «확률 안내» 링크를 누르면 `/probability`가 «등급 올리기» 섹션에서 열리고 제목이 고정 상단 바에 가려지지 않는다(스크롤 컨테이너 실측 결과에 맞는 방식으로).
- 시험이 링크 주소와 섹션 `id`를 고정한다. 기존 확률 안내 페이지 시험이 통과한다.
