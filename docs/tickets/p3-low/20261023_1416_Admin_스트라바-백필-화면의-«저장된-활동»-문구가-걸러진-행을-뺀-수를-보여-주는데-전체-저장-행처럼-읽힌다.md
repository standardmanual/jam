# [Admin] 스트라바 백필 화면의 «저장된 활동» 문구가 걸러진 행을 뺀 수를 보여 주는데 전체 저장 행처럼 읽힌다

## 핵심 요약

- 요구사항: 어드민 스트라바 백필 화면의 표 머리글 «저장된 활동»과 확인창의 «저장된 활동»이, 티켓 `20261017_1459`로 걸러진 행을 뺀 수를 보여 주게 됐다. 문구는 DB에 저장된 전체 행처럼 읽혀서 운영자가 걸러진 행이 사라졌다고 오해할 수 있다. 문구를 «인정된 활동» 등 실제 의미에 맞게 고친다.
- 구현 계획: 한 번에 돌린다. 두 곳의 문구를 정하고, 같은 뜻으로 쓰는 다른 어드민 문구가 있는지 검색한다. 문구 규칙은 UX Writing 가이드라인을 따른다.
- 관련 파일: `jam-web/src/app/admin/strava-backfill/StravaBackfillClient.tsx` 180줄(표 머리글), 261줄(확인창). 숫자의 출처는 `jam-web/src/lib/strava/backfillStats.ts`의 `fetchActivityStatRows`다.

## 배경 / 문제 정의

티켓 `20261017_1459`의 게이트(민지)가 2026-10-23에 범위 밖 발견물로 남겼다([참고/가독성]). 숫자의 뜻이 바뀌었는데 문구는 그대로다.

## 상세 요구사항

### UI/UX 관점

- 어드민 화면이라 MODULAR 적용 대상이 아니다. 문구만 고친다.
