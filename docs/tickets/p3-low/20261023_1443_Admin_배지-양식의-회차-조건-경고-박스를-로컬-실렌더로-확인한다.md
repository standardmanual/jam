# [Admin] 배지 양식의 회차 조건 경고 박스를 로컬 실렌더로 확인한다

## 핵심 요약

- 요구사항: 티켓 `20261021_1426`이 `BadgeConditionSection`에 저장 전 조건 영역 경고 박스를 새로 그리게 했는데, 격리 작업 환경에서는 어드민 화면을 열 수 없어 실제 화면으로 확인하지 못했다(게이트 WARN, 사용자가 «머지하고 화면 확인은 별도로»를 선택). 로컬 개발 서버에서 어드민 배지 양식을 열어 경고 박스가 의도대로 뜨는지 확인한다.
- 구현 계획: 메인 작업 폴더에서 `DEV_PROCESS_GUARDRAILS.md` 패턴 13대로 로컬 `next dev`를 `ADMIN_EMAILS` 셸 환경변수와 함께 띄운다. 일반 배지 양식에서 `repeat_count`와 회차가 다루지 못하는 키(예: `duration_minutes`, `season`)를 함께 입력해 경고 박스가 보이는지, 조건을 고치면 사라지는지 본다. 저장 버튼은 누르지 않는다.
- 관련 파일: `jam-web/src/app/admin/badges/BadgeConditionSection.tsx`(경고 박스), `jam-web/src/app/admin/badges/BadgeForm.tsx`, `jam-web/src/lib/admin/badge-condition-guards.ts`의 `findConditionShapeSaveWarning`.

## 배경 / 문제 정의

1426의 게이트(민지) WARN 사유다. 동작은 시험으로 확인됐고 화면만 눈으로 확인하지 못했다. 다른 세션이 메인 작업 폴더를 쓰고 있지 않을 때 확인한다.

## 완료 조건

- [ ] 잘못된 조합을 입력하면 조건 영역에 경고 박스가 뜬다(문구는 현상, 원인, 해결책 3단계)
- [ ] 조합을 고치면 경고 박스가 사라진다
- [ ] 320px 폭에서 박스가 잘리지 않는다
