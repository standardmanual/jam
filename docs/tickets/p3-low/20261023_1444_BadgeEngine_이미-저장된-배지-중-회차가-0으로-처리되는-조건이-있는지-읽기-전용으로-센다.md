# [BadgeEngine] 이미 저장된 배지 중 회차가 0으로 처리되는 조건이 있는지 읽기 전용으로 센다

## 핵심 요약

- 요구사항: 티켓 `20261021_1426`의 경고는 새로 저장할 때만 뜬다. 이미 DB에 저장된 일반 배지 중에 «회차가 다루지 못하는 키가 낀 회차 조건»이 있으면 발급이 멈춘 채 아무도 모른다. 티켓 1426이 «착수 때 판단»으로 남긴 읽기 전용 집계를 수행한다.
- 구현 계획: 일반 배지(`type`·`admin_category`·`condition_json`)를 읽기 전용으로 가져와 `findConditionShapeSaveWarning`을 돌려 경고가 붙는 배지 목록을 센다. DB를 바꾸지 않는다. 조회 방식은 `jam-web/.env.local`의 서비스 키가 필요하므로 키 값은 출력하지 않는다(Supabase는 staging·프로덕션 공용 단일 DB다).
- 관련 파일: `jam-web/src/lib/admin/badge-condition-guards.ts`의 `findConditionShapeSaveWarning`, 엔진의 `jam-web/src/lib/badge-engine/repeatOccurrences.ts` `unconsumedRepeatConditionKeys`.

## 배경 / 문제 정의

1426 게이트(민지)가 [참고/정합성]으로 짚었다. 아현에게 DB 권한이 없어 건너뛰었다. 결과가 0건이면 닫고, 있으면 해당 배지를 어떻게 고칠지(조건 수정, 비활성화)를 사용자에게 묻는다.

## 완료 조건

- [ ] 경고가 붙는 기존 배지의 수와 목록이 티켓에 기록돼 있다
- [ ] 1건 이상이면 처리 방침이 사용자 결정으로 기록돼 있다

## 진행 기록
