# [Admin] 정책 대시보드의 «바꾸기» 링크 화면을 로컬 실렌더로 확인한다

## 핵심 요약

- 요구사항: 티켓 `20261022_1717`이 `/admin/policy-dashboard`의 수정 칸을 링크로 바꾸고 직접 저장 경로를 없앴는데, 격리 작업 환경에서는 어드민 화면을 열 수 없어 실제 화면으로 확인하지 못했다. 로컬 개발 서버에서 대시보드를 열어 카드, 링크 글자, 줄바꿈이 의도대로인지 확인한다.
- 구현 계획: 메인 작업 폴더에서 `DEV_PROCESS_GUARDRAILS.md` 패턴 13대로 로컬 `next dev`를 `ADMIN_EMAILS` 셸 환경변수와 함께 띄운다. 링크만 누르고 값은 바꾸지 않는다. 티켓 `20261023_1443`(배지 양식 경고 박스 확인)과 같은 세션에서 묶어 한 번에 한다.
- 관련 파일: `jam-web/src/components/admin/policyDashboard/PolicyDashboardClient.tsx`, `jam-web/src/lib/admin/policyDashboard/policiesData.ts`.

## 배경 / 문제 정의

1717 게이트(민지) 판정 밖 항목이다. 서버 렌더 시험으로 링크와 직접 수정 컨트롤의 부재는 고정돼 있으나 레이아웃은 눈으로 보지 못했다.
