# [Admin] 미션 양식의 위임 키 입력 칸 배치를 로컬 실렌더로 확인한다

## 핵심 요약

- 요구사항: 티켓 `20261021_1114` 1회가 미션 양식에 위임 키 12개의 입력 칸을 만들었는데, 격리 작업 환경에서는 어드민 화면을 열 수 없어 레이아웃을 눈으로 확인하지 못했다(게이트 WARN, 사용자가 같은 사유는 머지 뒤 별도 확인으로 처리하기로 했다). 로컬 개발 서버에서 어드민 미션 양식을 열어 확인한다. 기존 위임 키 14개도 레지스트리의 `min`·`max`·`step`과 칸 너비(`same_activity` 3칸, `repeat_count` 2칸)가 새로 적용돼 화면 배치와 증감 단위가 달라질 수 있어 함께 본다.
- 구현 계획: 메인 작업 폴더에서 로컬 `next dev`를 `ADMIN_EMAILS` 셸 환경변수와 함께 띄운다. 티켓 `20261023_1443`(배지 양식 경고 박스), `20261023_1507`(정책 대시보드)과 같은 세션에서 묶어 한 번에 한다. 저장 버튼은 누르지 않는다.
- 관련 파일: `jam-web/src/app/admin/missions/MissionConditionSection.tsx` 487줄 근처(`renderDelegatedField`), 555줄 근처(요일 칩), `jam-web/src/app/admin/missions/missionConditionFields.ts`.

## 배경 / 문제 정의

1114 1회 게이트 WARN 사유 1·3이다. 서버 렌더 시험은 값 채움, 체크 상태, `min`·`max` 속성만 고정하고 레이아웃은 보지 못한다.
