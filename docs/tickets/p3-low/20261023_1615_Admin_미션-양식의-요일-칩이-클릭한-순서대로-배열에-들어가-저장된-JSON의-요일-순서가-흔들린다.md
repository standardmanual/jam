# [Admin] 미션 양식의 요일 칩이 클릭한 순서대로 배열에 들어가 저장된 JSON의 요일 순서가 흔들린다

## 핵심 요약

- 요구사항: 미션 양식의 `day_of_week` 요일 칩이 누른 순서대로 배열에 들어간다(일요일 다음 토요일을 누르면 `["sunday","saturday"]`). 판정에는 영향이 없으나 같은 선택이 누른 순서에 따라 다른 JSON으로 저장돼 원본 비교 때 순서가 달라 보인다. 저장할 때 월~일 고정 순서로 정렬한다.
- 구현 계획: 한 번에 돌린다. `writeDayOfWeek`(또는 칩 선택 처리)에서 배열을 월~일 순서로 정렬하고 시험으로 고정한다.
- 관련 파일: `jam-web/src/app/admin/missions/MissionConditionSection.tsx` 555줄 근처, `jam-web/src/app/admin/missions/missionConditionFields.ts`의 `readDayOfWeek`·`writeDayOfWeek`.

## 배경 / 문제 정의

티켓 `20261021_1114` 1회의 게이트(민지)가 2026-10-23에 [정확성/참고]로 남겼다.
