# [Admin] 정수 칸 검사의 정리 거리: 미션 직접 읽는 칸의 화면 라벨 대조 시험, 정수 칸 문서 단락 위치

## 핵심 요약

- 요구사항: 티켓 `20261023_1748` 게이트(민지)가 남긴 참고 2건을 정리한다. (1) 미션 양식에서 직접 읽는 정수 칸의 라벨(`MISSION_DIRECT_INTEGER_INPUTS`)이 `MissionConditionSection.tsx`의 화면 라벨과 손으로 맞춰져 있다. 지금은 9칸이 모두 일치하지만 시험으로 대조하지 않아 한쪽 라벨만 바뀌면 안내 문구의 칸 이름이 화면과 어긋난다. (2) 정수 칸 검사 단락이 `CONDITION_JSON_SPEC.md` 4절 «필드 조합 규칙»의 fail-closed 목록 끝에 붙어 있어 주제가 다르다. 티켓 계획은 «양식 입력 절»이었다.
- 구현 계획: (1)은 화면 라벨과 `MISSION_DIRECT_INTEGER_INPUTS`의 라벨이 같은지 대조하는 시험을 더하거나, 화면이 이 상수를 읽게 해 한 곳에서 관리한다. (2)는 단락을 양식 입력을 다루는 절로 옮긴다.
- 관련 파일: `jam-web/src/app/admin/missions/missionConditionFields.ts` 786~800줄 근처, `jam-web/src/app/admin/missions/MissionConditionSection.tsx`, `docs/service/badge-engine/CONDITION_JSON_SPEC.md` 554줄 근처.
