# [Infra] 승인 정책 문서의 «항상 승인» 경로 표가 지운 어드민 화면을 가리키고, 밸런스 설정의 새 쓰기 경로가 표에 없다

## 핵심 요약

- 요구사항: 승인 정책 문서의 «항상 승인» 경로 표에 지워진 어드민 화면(`inventory-policy`, `combine-policy`, `drop-policy`)이 남아 있고, 밸런스 설정이 쓰는 새 저장 경로(`/api/admin/balance/[section]`)는 표에 없다. 표를 어떻게 고칠지 사용자가 정한다.
- 구현 계획: 사용자가 방침을 정한 뒤 정한다. 후보는 (가) 지운 경로를 빼고 밸런스 설정 저장 경로를 «항상 승인»에 더한다, (나) 지운 경로만 빼고 새 경로는 더하지 않는다. 7-2(`20261022_1133`)와 7-3(`20261022_1134`)이 사용자 결정으로 미결로 넘겼다.
- 관련 파일: `.claude/skills/jam-work/references/automation-list.md` 46줄 근처, `docs/agents/workflow/05_자동화목록.md` 47줄. 뒤의 파일은 `docs/agents/workflow/` 아래라 동결된 기록이므로 고치지 않고, 현재 정의는 앞의 파일 하나다.

## 배경 / 문제 정의

밸런스 설정 화면이 옛 어드민 화면을 대신하면서 쓰기 경로가 `/api/admin/balance/[section]` 하나로 모였다. 승인 정책 표는 옛 화면의 경로를 «항상 승인»으로 적고 있어, 지운 경로가 남고 새 경로는 어느 쪽으로도 분류되지 않는다.

## 완료 조건

- 사용자가 (가)와 (나) 중 하나를 정해 이 티켓에 적었다.
- `automation-list.md`의 표가 정한 대로 고쳐져 있고 지운 경로가 남지 않는다.
