# [Service] 잠긴 개체를 열 때 포인트 소식을 내고 `capsule_changed` 안내 문구를 정한다

## 핵심 요약

- 요구사항: 묶음 3(`20261018_0050`)에 남았던 사용자 결정 둘을 구현한다(사용자가 채원 추천을 승인, 2026-10-26). ① 잠긴 개체를 열 때 **열린 채 받을 때와 같은 포인트 소식**을 내고, 피드는 만들지 않는다(받을 때 `item_dropped`가 이미 나가서 중복). ② `capsule_changed`(캡슐이 열리는 사이 바뀐 경우)의 안내 문구를 «캡슐이 방금 바뀌었어요. 다시 시도해 주세요.»로 한다(고정 용어 «다시 시도»).
- 구현 계획: 서버 변경이다. 잠긴 개체 열기 서버(`20261018_0053`이 만든 열기 경로, `jam-web/src/lib/capsule/` 또는 `lib/inventory/` 아래)의 성공 뒤에 포인트 알림을 보내는 지점을 시작 때 확인한다. 알림 종류는 열린 채 받는 경로가 쓰는 것을 재사용하고 새 종류가 필요하면 마이그레이션이 따른다. 문구는 `jam-web/src/lib/i18n/ko.ts`에서 `capsule_changed`를 찾아 바꾼다.
- 관련 파일: 잠긴 개체 열기 서버, `jam-web/src/lib/notifications/`, `jam-web/src/lib/i18n/ko.ts`, 시험.

## 배경 / 문제 정의

잠긴 개체를 열면 배지 포인트가 지급되는데 소식이 없어 유저가 포인트가 들어온 걸 알 수 없다. `capsule_changed` 거절 문구는 아직 정해지지 않았다.

## 완료 조건

- 잠긴 개체를 열면 포인트 소식이 한 번 나가고 피드는 나가지 않는다(시험).
- `capsule_changed` 거절이 지정한 문구로 보인다(시험).
- 새 알림 종류가 필요하면 마이그레이션과 롤백 실측 기록이 있다.
