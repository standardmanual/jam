# [Infra] 엔진 스펙 3.18절 마지막 «영향 범위» 줄이 같은 절의 발급 자격 심사 항목과 어긋난다

## 핵심 요약

- 요구사항: `docs/service/badge-engine/BADGE_ENGINE_UNIFIED.md` 3.18절 마지막 «영향 범위» 줄(2505줄 근처)이 «지도 마커 노출 로직에만 적용되는 조건»이라고 적는데, 같은 절의 «적용 지점» 발급 자격 심사 항목과 POI 발급 경로 항목(티켓 `20260930_0015` 2회가 더함)은 공개 기간이 발급에도 적용된다고 적는다. 줄을 현재 사실에 맞게 고친다.
- 구현 계획: 문서만. 3.18절의 «영향 범위»를 «지도 마커 노출과 체크인 배지 발급 자격 심사(동기화, 어드민 시뮬레이터)»로 바로잡는다.
- 관련 파일: `docs/service/badge-engine/BADGE_ENGINE_UNIFIED.md` 3.18절.

## 배경 / 문제 정의

티켓 `20260930_0015` 2회(v2)의 게이트(민지, 2026-10-26) 범위 밖 발견물이다(정확성/참고, 기존 서술).

## 완료 조건

- 3.18절 «영향 범위» 줄이 적용 지점 항목과 서로 맞는다.
