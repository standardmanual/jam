# [UI] 토스트 문구에 `break-keep`을 더해 긴 한국어 문구가 어절 중간에서 꺾이지 않게 한다

## 핵심 요약

- 요구사항: `jam-web/src/components/ui/Toast.tsx` 66줄 `<span>{item.message}</span>`에 `break-keep` 계열 클래스가 없어, 폭이 모자라면 한국어 문구가 어절 중간에서 꺾이고 `rounded-full` 알약이 두 줄로 찌그러진다. 티켓 `20261025_2050`의 «이번에 잼 {n}만큼 받았어요»가 5자리 이상 합계에서 처음 닿을 수 있다.
- 구현 계획: 문구 `<span>`에 `break-keep wrap-break-word`를 더하고, 두 줄이 될 때 알약 모양(`rounded-full`)이 어색하지 않은지 320px에서 확인한다. 채원 사후 리뷰의 제안 `toast_text_wrapping_device_320px_candidates`를 참고한다. 기존 토스트 사용처의 시험이 통과해야 한다.
- 관련 파일: `jam-web/src/components/ui/Toast.tsx`, 토스트 시험, 채원 사후 리뷰 제안(티켓 `20261025_2050` 게이트 결과).

## 배경 / 문제 정의

티켓 `20261025_2050`의 게이트(민지)와 채원 사후 리뷰(2026-10-26) 범위 밖 발견물이다. 이번 티켓 이전부터 있던 구조다. 보류 고르기 뒤 배지 0개 갈래(c)에서는 토스트 두 개가 쌓이므로 320px에서 두 줄이 하단 탭바와 겹치지 않는지도 함께 본다.

## 완료 조건

- 긴 한국어 문구가 320px에서 어절 중간에서 꺾이지 않고, 두 줄이 되어도 모양이 깨지지 않는다.
- 토스트 두 개가 쌓여도 하단 탭바와 겹치지 않는다(로컬 화면 확인).
