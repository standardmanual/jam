# [API] 루틴 「시작」 기록 경로에 시간당 건수 제한을 둔다 (2032 후속)

> 상위: 20261026_2020

## 핵심 요약

- 요구사항: `POST /api/admin/ops-inbox/routine-start`에 시간당 받는 건수 상한을 둔다. 지금은 읽기 토큰을 가진 쪽이 `run_key`를 바꿔 가며 행을 쌓을 수 있다(본문 16KB 한도만 있음).
- 구현 계획: 제출 경로(`ops-inbox/route.ts`)의 최근 1시간 제출 수 확인(`MAX_SUBMISSIONS_PER_HOUR`)과 같은 방식으로 `ops_routine_starts`의 최근 1시간 행 수를 센다.
- 관련 파일: `jam-web/src/app/api/admin/ops-inbox/routine-start/route.ts`, `jam-web/src/lib/admin/opsInbox/routineStart.ts`, `jam-web/src/lib/admin/opsInbox/constants.ts`, 참고 `jam-web/src/app/api/admin/ops-inbox/route.ts`(⑤ 최근 1시간 제출 수)

## 완료 조건

- 상한을 넘긴 요청은 429와 쉬운 문장을 받고 행이 늘지 않는다(단위 테스트).
- 정상 루틴(주 1~2회)은 영향을 받지 않는다.
