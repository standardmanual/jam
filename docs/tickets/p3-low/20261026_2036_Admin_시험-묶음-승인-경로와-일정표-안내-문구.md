# [Admin] 시험 묶음의 승인 경로와 일정표 서랍 안내 문구를 새 흐름에 맞춘다 (2031 후속)

> 상위: 20261026_2020

## 핵심 요약

- 요구사항: ① 시험 묶음에서는 서버가 승인 모드를 꺼 두어 검토중 항목을 승인할 방법이 없다. 시험 묶음 리허설에서 승인 단계까지 보여 줄지 정한다. ② 일정표 서랍의 `SCHEDULE_APPROVED_NOTICE`(「예약 등록은 기획 상세에서 해요」)와 서랍의 검토중 항목 안내를 새 버튼 이름(「승인하고 예약」)에 맞춘다.
- 관련 파일: `jam-web/src/lib/admin/opsInbox/execute/run.ts`(`includeReviewing` 시험 묶음 처리), `jam-web/src/app/admin/ops-schedule/`(서랍), `jam-web/src/lib/admin/opsInbox/deleteSample` 관련 `decide.ts`의 `deleteSampleBundle`

## 완료 조건

- 시험 묶음에서 운영자가 할 수 있는 일(검증만, 삭제)이 화면에 한 줄로 안내된다.
- 일정표 서랍의 안내 문구가 새 버튼 이름과 맞는다(문구 검색 + 컴포넌트 테스트).
