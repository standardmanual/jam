# [Admin] 주간 흐름 지도의 문제·결정 정류장이 같은 주의 다른 묶음으로 갈 수 있다 (2023 후속)

> 상위: 20261026_2020

## 핵심 요약

- 문제: 한 주에 묶음이 둘 이상이면 행 하나가 링크 하나(`rowLinks.ts`의 `flowRowHrefs`: 결정할 항목이 있는 묶음 중 가장 늦게 받은 것)만 갖는다. 그래서 「문제 N」 정류장이 실패 항목이 없는 묶음의 결정 패널로 가거나 「결정 필요」 정류장이 반대가 될 수 있다.
- 확인한 사례(2026-10-27 실화면): 44주차 행의 「문제 2」(실패 항목은 다른 묶음에 있음)가 「결정 필요」 묶음으로 간다. 42주차 「문제 5」는 실패 1건이 있는 묶음으로 가고 나머지 4건은 다른 묶음에 있다.
- 구현 계획: `flowRowHrefs`가 주마다 `{ decide, problem }` 두 경로를 돌려주고(`decide` = 도착·검토중 항목이 있는 묶음, `problem` = 실패 항목이 있는 묶음, 없으면 지금 규칙), `OpsWeekFlowMap`이 정류장 종류에 맞는 경로를 쓴다.
- 관련 파일: `jam-web/src/lib/admin/opsBoard/rowLinks.ts`, `jam-web/src/components/admin/ops/board/OpsWeekFlowMap.tsx`(`rowHrefs` 속성), `jam-web/src/app/admin/_home/sections.tsx`(`BoardSection`), 시험 `rowLinks.test.ts`·`OpsWeekFlowMap.test.tsx`

## 완료 조건

- 한 주에 「결정 필요」 묶음과 「문제」 묶음이 따로 있을 때 각 정류장이 해당 묶음으로 간다(단위 시험).
- 한 주에 묶음이 하나이거나 해당 묶음이 없으면 지금과 같다.
