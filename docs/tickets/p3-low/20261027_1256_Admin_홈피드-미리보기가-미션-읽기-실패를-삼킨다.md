# [Admin] 홈피드 미리보기가 미션 읽기 실패를 삼켜 수동 비노출 미션 카드를 못 거른다 (2025 후속)

> 상위: 20261026_2020

## 핵심 요약

- 문제: `jam-web/src/lib/today/cards.ts`의 `fetchMissionsById`는 읽기에 실패해도 던지지 않고 빈 맵을 돌려준다(실제 홈 조회와 같은 동작). 홈피드 미리보기(`jam-web/src/lib/admin/homePreview/load.ts`)는 이 빈 맵을 받으면 「읽은 미션이 하나도 없으면 카드를 그대로 둔다」 규칙에 따라 수동 비노출 미션의 소개 카드를 거르지 못하고 오류 없이 그대로 보인다. 1회차의 「읽기 실패는 던진다」 규칙과 어긋난다.
- 구현 계획: 미리보기는 미션 읽기 실패를 알아야 한다. `fetchMissionsById`가 실패를 돌려주는 방식(예: 결과에 실패 표시)으로 바꾸거나 미리보기가 쓰는 읽기만 던지는 변형을 두고, 실제 홈 조회의 동작(실패해도 던지지 않음)은 바꾸지 않는다.
- 관련 파일: `jam-web/src/lib/today/cards.ts`(`fetchMissionsById`), `jam-web/src/lib/admin/homePreview/load.ts`, `jam-web/src/lib/admin/homePreview/__tests__/load.test.ts`

## 완료 조건

- 미션 읽기가 실패하면 미리보기 API가 500으로 실패한다(시험). 실제 홈 조회 시험은 그대로 통과한다.
