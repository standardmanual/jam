# [Admin] 트렌드 걸러 보기 중 `?item=`으로 목록 밖 항목을 가리키면 걸러 보기가 풀리지 않는다 (2033 후속)

> 상위: 20261026_2020

## 핵심 요약

- 문제: 기획 상세를 `?trend=N`으로 열어 걸러 보는 중에 `?item=`이 걸러 낸 목록 밖의 항목을 가리키면(주소를 직접 고쳐 들어온 경우) 셸이 전체 항목에서 그 항목을 찾아 선택한다. 항목을 눌러 고를 때(`selectItem`)는 걸러 보기를 끄는데 주소로 들어오는 경로는 끄지 않아 목록에 없는 항목이 상세에 보인다.
- 구현 계획: 선택 규칙(`OpsBundleWorkspace.tsx`의 `selectedItem` 계산)이 걸러 보기 중에는 걸러 낸 목록 안에서만 `?item=`을 받게 하거나, 목록 밖이면 걸러 보기를 끈다. 어느 쪽인지는 걸러 보기 알림 문구와 맞춰 정한다.
- 관련 파일: `jam-web/src/components/admin/ops/OpsBundleWorkspace.tsx`(`selectedItem`, `selectItem`), `jam-web/src/components/admin/ops/__tests__/trendFilter.test.tsx`

## 완료 조건

- 걸러 보기 중 목록 밖 항목을 주소로 가리켜도 상세와 목록이 어긋나지 않는다(시험).
