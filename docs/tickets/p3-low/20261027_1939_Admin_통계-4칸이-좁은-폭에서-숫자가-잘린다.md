# [Admin] 통계 4칸이 좁은 폭에서 숫자가 잘린다 (2027 3-2 후속)

> 상위: 20261026_2020

## 핵심 요약

- 문제: 통계 구역(`StatsSection`)은 `grid-cols-4`·`p-5`·`text-3xl`로 고정돼 있어 사이드바가 열린 좁은 폭(약 600px)에서 「4,437」이 「4,4」로 잘려 보인다. 운영 홈에서 그대로 옮긴 코드라 같은 문제가 원래 있었고, 생태계 상황판에서 폭이 더 좁아 눈에 띄었다(3-2 실화면 확인, 2026-10-27).
- 구현 계획: 좁은 폭에서는 2칸으로 줄이고(`grid-cols-2 lg:grid-cols-4`), 숫자 글자 크기를 폭에 맞춘다. 칸의 값·링크·오류 표시는 바꾸지 않는다.
- 관련 파일: `jam-web/src/app/admin/ecosystem/_sections.tsx`(`StatsSection`의 `<section aria-label="통계">`), `jam-web/src/app/admin/ecosystem/__tests__/sections.test.tsx`

## 완료 조건

- 약 600px 폭에서 통계 4칸의 숫자가 잘리지 않는다(실화면).
- 칸의 값·링크·불러오지 못했어요 표시는 그대로다(시험).
