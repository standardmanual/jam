# [UI] 배지 공유 이미지 로고 크기 머리 주석을 현재 값으로 고친다

> 출처: 티켓 20261028_0944 게이트(민지)의 범위 밖 발견물.

## 핵심 요약

- 요구사항: `buildBadgeShareBlob.ts` 18줄 머리 주석이 「로고 174.2336×72」를 적고 있어, 35~36줄의 `LOGO_WIDTH`(217.2486)와 읽을 때 어긋난다. 현재 값으로 맞춘다.
- 구현 계획: 18줄 주석의 로고 크기를 `217.2486×72`로 고치거나, Figma 원본 좌표 기록임을 밝히는 문구로 바꾼다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/buildBadgeShareBlob.ts` 18줄(머리 주석), 35~36줄(`LOGO_WIDTH`·`LOGO_HEIGHT`).

## 배경 / 문제 정의

- 티켓 20261028_0944가 로고 폭을 새 비율(2610:865)에 맞춰 174.2336에서 217.2486으로 바꿨다. 35줄 주석은 옛 값이 Figma 칸 폭이었다고 밝히지만 18줄 머리 주석은 옛 값 그대로다. 동작에는 영향이 없다.

## 상세 요구사항

### 서비스/코드베이스 관점

- 주석만 고친다. 코드 변경은 없다.

## 구현 계획

1. 18줄 주석의 로고 크기 표기를 현재 값이나 「Figma 원본 기록」 표기로 바꾼다.

## 완료 조건

- `buildBadgeShareBlob.ts`에서 `174.2336`이 35줄의 설명 주석에만 남는다. 확인: `grep -n 174.2336 'jam-web/src/app/(main)/badges/[id]/buildBadgeShareBlob.ts'`.
