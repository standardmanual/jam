# [UI] 배지·미션·인벤토리 페이지의 상단 타이틀 텍스트를 제거한다

## 핵심 요약

- 요구사항(사용자, 2026-10-31): 배지, 미션, 인벤토리 페이지의 상단 타이틀 텍스트를 제거한다.
- 구현 계획: 세 페이지의 큰 `h1`(`text-5xl`) 블록을 없앤다. 경로는 로직 변경이 없는 가벼운 UI(`route: 'light'`)다.
- 관련 파일: `jam-web/src/app/(main)/badges/BadgesClient.tsx`(184~187줄 헤더 블록, 195줄 탭의 `aria-label`), `jam-web/src/app/(main)/missions/MissionsListClient.tsx`(323~325줄 헤더 블록, 334줄 `aria-label`), `jam-web/src/app/(main)/inventory/page.tsx`(84~96줄 제목과 «믹스하기» 버튼 행). 문구 `d.badges.title`·`d.missions.title`·`d.inventory.title`은 `lib/i18n/ko.ts`(520·821·616줄).

## 배경 / 문제 정의

세 페이지는 TopNav 아래에 «배지»·«미션»·«인벤토리» 큰 제목이 한 줄씩 있다. 사용자가 이 제목을 없애기로 했다. 하단 탭바와 탭 헤더(`SlidingTabs`)가 어느 페이지인지 이미 알려 준다.

## 상세 요구사항

### UI/UX 관점

- **배지·미션**: 제목 블록(`<div className="px-4 pt-6"><h1 …/></div>`)을 없앤다. 그 아래 탭 헤더 묶음(`px-4 py-4`)이 TopNav 바로 아래로 올라온다. 위 여백이 16px이 되는 것으로 두고 따로 늘리지 않는다.
- **인벤토리**: 제목을 없애면 «믹스하기» 버튼이 줄에 혼자 남는다. 버튼은 지금처럼 오른쪽 끝에 두고(`justify-end`) 아래 슬롯 프로그레스·안내와의 간격(`mb-4`)은 그대로 둔다.
- **접근성**: 화면 제목이 사라지면 스크린리더가 페이지 제목을 읽을 수 없다. `h1`은 지우지 않고 `sr-only`로 바꿔 글자만 시각적으로 숨긴다(세 페이지 모두). 보이는 글자는 없다.
- 새 문구를 만들지 않는다. 탭의 `aria-label`은 그대로 둔다.

### 서비스/코드베이스 관점

- 제목 문구 3개는 다른 곳에서도 쓰이면 지우지 않는다(`d.inventory.title` 등은 `sr-only` `h1`이 계속 쓴다).
- 시험이 제목 글자나 `h1`을 찾으면 맞춘다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)

- `/badges`, `/missions`, `/inventory` 상단에 보이는 제목 글자가 없고, 각 페이지에 `sr-only` `h1`이 하나씩 있다.
- 인벤토리의 «믹스하기» 버튼이 오른쪽 끝에 남는다. 배지·미션의 탭 헤더가 TopNav 바로 아래에서 시작한다.
- `scripts/verify.sh`가 통과한다.

### 후속 범위 (담당: 카리나, 시점: 머지와 push 뒤)

- 스테이징(232 계정)에서 세 페이지를 읽어 제목 글자가 없고 버튼·탭이 그대로인지 확인한다.

## 완료 기록

### 구현 내용 요약

세 페이지의 큰 제목(`text-5xl` `h1`)을 화면에서 없애고, 같은 문구의 `h1`을 `sr-only`로 바꿔 스크린리더용 페이지 제목만 남겼다. 배지·미션은 제목 `div`(`px-4 pt-6`)를 지워 탭 헤더가 TopNav 바로 아래에서 시작한다(위 여백은 탭 헤더의 `py-4` 16px). 인벤토리는 행을 `justify-end`로 바꿔 «믹스하기» 버튼이 오른쪽 끝에 남는다. 새 문구와 시험 변경은 없다. 경로는 가벼운 UI(`route: 'light'`)라 채원 판정·사후 리뷰는 생략했다.
