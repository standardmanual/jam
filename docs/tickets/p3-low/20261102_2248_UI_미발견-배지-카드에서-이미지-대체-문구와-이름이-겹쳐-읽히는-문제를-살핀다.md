# [UI] 배지 카드에서 이미지 대체 문구(alt)와 이름 줄이 같은 말로 두 번 읽히는지 살핀다

## 핵심 요약

- 요구사항: 미발견 아이템 배지 카드는 `<img alt={name}>`과 이름 줄 `<p>{name}</p>`이 같은 문구라 화면 낭독기가 이름을 두 번 읽을 수 있다. 실제로 중복되어 읽히는지 확인하고, 그렇다면 장식 이미지(`alt=""`)로 바꿀지 정한다.
- 구현 계획: 화면 낭독기로 확인 → 필요하면 서비스·디자인시스템 두 곳에서 `alt`를 비운다.
- 관련 파일: `jam-web/src/components/ui/BadgeGridCard.tsx`(`SafeImage`의 `alt`), `jam-web/design-system/components/patterns/BadgeGridCard.jsx`.

## 배경 / 문제 정의

- 티켓 20261102_1834에서 미발견 카드의 `alt`를 `???`에서 이름으로 바꿨다. 획득한 카드도 원래 `alt={name}`과 이름 줄이 같으므로 새로 생긴 문제가 아니라 기존 방식과 같다. 다만 접근성 관점에서 한 번 확인할 만하다.

## 완료 조건

- 낭독기에서 이름이 두 번 읽히는지 확인한 결과가 적혀 있고, 중복이면 `alt` 처리가 정해져 두 곳에 반영돼 있다.
