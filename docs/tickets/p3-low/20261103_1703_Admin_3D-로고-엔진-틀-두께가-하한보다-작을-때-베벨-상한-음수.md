# [Admin] 3D 로고 형상 엔진 — 틀 두께가 윗면 띠 폭 하한보다 작으면 베벨 상한이 음수가 된다

> 티켓 20261103_1352(3D 로고 화면) 게이트 리뷰·로컬 실렌더 확인의 범위 밖 발견물로 자동 생성한 티켓이다.

## 핵심 요약

- 요구사항: 틀 두께(`frameSpan`)가 0.0003보다 작아도 베벨 상한이 음수가 되지 않게 0 이상으로 자른다.
- 구현 계획: `buildGeometry.ts`에서 `(frameSpan - MIN_LID_BAND) / 2`를 0 이상으로 자르고, 이 경로의 시험을 더한다.
- 관련 파일: `jam-web/src/lib/logo-3d/buildGeometry.ts`(`limitFrame` 호출부, 213줄 근처), `jam-web/src/lib/logo-3d/__tests__/buildGeometry.test.ts`

## 배경 / 문제 정의

`frameSpan - MIN_LID_BAND`가 음수면 틀 베벨이 음수가 되어 `extrude()`에서 `bevel > 0`이 거짓이 되고 베벨이 꺼지며 `bodyDepth`만 커진다. 얇은 SVG 고리에서 생길 수 있다. 기본 입력과 경계 12개 조합에서는 발생하지 않고 이 경로의 시험도 없다(게이트 WARN 사유 3).

## 상세 요구사항

### 서비스/코드베이스 관점
- 기본 입력과 기존 경계 조합의 결과는 그대로여야 한다.

## 구현 계획

`buildGeometry.ts`에서 `(frameSpan - MIN_LID_BAND) / 2`를 0 이상으로 자르고, 이 경로의 시험을 더한다.

## 완료 조건

- 틀 두께가 0.0003 미만인 입력에서 베벨 반지름이 음수가 되지 않고(0 이상) `warnings`에 사유가 남는다(단위 테스트).
- 기존 `buildGeometry`·`logo3dParamRange` 시험이 그대로 통과한다.
- `npm run lint`·`typecheck`·`test`가 통과한다(`scripts/verify.sh`).
