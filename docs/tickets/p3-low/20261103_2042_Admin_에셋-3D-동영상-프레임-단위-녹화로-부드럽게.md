# [Admin] 에셋 3D 동영상 — 시간 비례 대신 프레임 단위로 그려, 창 상태와 무관하게 매끄럽고 끝 프레임이 정확히 360°가 되게 한다

> 티켓 20261103_1737(3D 동영상 턴테이블) 게이트 리뷰와 로컬 실녹화의 범위 밖 발견물로 자동 생성한 티켓이다.

## 핵심 요약

- 요구사항: 3D 턴테이블 영상이 브라우저 창이 가려지거나 그레인 계산이 무거워도 일정한 프레임 수(예: 초당 30장 × 15초)로 매끄럽게 돌고, 마지막 프레임이 시작 자세와 정확히 같다.
- 구현 계획 (2026-11-03 카리나 확정, 실측은 머지 뒤로 미룬다): 경과 시간 비례 회전을 **프레임 번호 기준**으로 바꾼다. 총 프레임 수 `N = VIDEO_FPS(30) × VIDEO_SEC`을 정하고 i번째 프레임(0~N)의 rotY를 `start + 360 × i / N`으로 그린다(마지막 프레임 i=N이 시작 자세와 정확히 같다). 스트림은 `captureStream(0)`으로 열고 프레임을 그릴 때마다 `track.requestFrame()`으로 한 장씩 밀어 넣는다. 다음 프레임까지는 `requestAnimationFrame` 대신 프레임 간격(1000/30ms)에서 그리기 시간을 뺀 만큼 `setTimeout`으로 기다린다(숨겨진 창의 rAF 지연을 피한다). 취소 경로(`cancelVideo`)와 녹화 뒤 크기·자세 복원은 지금 동작을 그대로 지킨다. 각도 계산은 `turntable.ts`에 순수 함수(예: `turntableFrameRotY(start, i, n)`, `turntableFrameCount(fps, sec)`)로 두고 시험한다. Shape 녹화(`ShapeStudioViewport.recordVideo`)는 건드리지 않는다.
- 관련 파일: `jam-web/src/app/admin/assets/logo3d/Logo3DViewport.tsx`(`recordVideo`), `logo3d/turntable.ts`, `videoRecording.ts`, `logo3d/stageCompose.ts`(그레인 `getImageData`, 57~75줄)

## 배경 / 문제 정의

2026-11-03 로컬 실녹화 결과 14.6초 영상에 프레임이 17장뿐이었다(초당 약 1.2장). 녹화 중 앱 창이 화면에 보이지 않아 브라우저 패널이 숨김 상태였고 숨겨진 페이지는 `requestAnimationFrame`이 크게 늦춰진다 — 그래서 이 수치가 실제 사용 환경을 대표하지는 않는다. 다만 회전이 경과 시간 비례라 프레임이 빠지면 영상이 끊기고, 끝 프레임도 시작 자세와 정확히 맞지 않았다(PSNR 18.3). 우선순위는 실제 창에서의 실측 결과로 다시 정한다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- `turntable.ts`의 프레임 번호 기준 함수가 시험된다: i=0과 i=N의 각도 차가 정확히 360°, 각도가 i에 비례한다, N이 30 × `VIDEO_SEC`이다.
- 3D `recordVideo`가 프레임 번호로 각도를 정하고 `captureStream(0)` + `requestFrame()`으로 프레임을 밀어 넣는다. `requestFrame`이 없는 브라우저에서는 지금 방식(`captureStream(30)`)으로 물러선다(코드 확인).
- 취소·복원 동작과 Shape 녹화는 바뀌지 않는다.
- `scripts/verify.sh`가 통과한다.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤, push 전)
- Browser 창이 화면에 보이는 상태에서 15초 영상을 녹화해 ffprobe로 프레임 수(목표 450장의 90% 이상)와 첫·끝 프레임 PSNR을 잰다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- 3D 동영상 회전을 경과 시간 비례에서 프레임 번호 기준으로 바꿨다. N = 30 × 15 = 450, i번째(0~N) 프레임의 rotY = 시작 + 360 × i / N.
- 스트림은 `captureStream(0)`으로 열고 프레임마다 `requestFrame()`으로 밀어 넣는다. 다음 프레임은 `setTimeout`으로 기다린다. `requestFrame`이 없으면 `captureStream(30)`으로 물러선다. 취소·복원·Shape 녹화는 그대로다.
- `turntable.ts`에 `VIDEO_FPS`·`turntableFrameCount`·`turntableFrameRotY`를 더하고 `turntableProgress`를 없앴다. 머지 뒤 카리나가 시험 파일 머리 주석을 프레임 번호 기준으로 고쳤다.
