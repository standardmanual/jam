# [Admin] 에셋 3D 팔레트를 고른 뒤 되돌리기로 이전 배경이 돌아오는지 화면 단위 시험으로 확인한다

## 핵심 요약

- 요구사항: 3D 팔레트를 누르면 공유 배경이 바뀌고, 되돌리기를 누르면 이전 배경이 돌아와야 한다. 지금은 이 동작을 코드 확인으로만 보장한다(티켓 20261103_1718 민지 게이트의 범위 밖 발견물, 참고).
- 구현 계획: `page.tsx`의 `handleSelectLogo3dPalette`를 거치는 화면 단위 시험을 더한다. 팔레트를 누른 뒤 `bgA`·`bgB`·`bgAngle`이 팔레트 값이고, 되돌리기 뒤 이전 값이며, `bgMode`는 그대로인지 확인한다.
- 관련 파일: `jam-web/src/app/admin/assets/page.tsx`(708~716줄 근처 `handleSelectLogo3dPalette`, `remember(stateRef.current)`), `jam-web/src/app/admin/assets/__tests__/`(새 시험)

## 배경 / 문제 정의

1718에서 팔레트 선택 처리기를 만들 때 시험은 순수 함수(`paletteStagePatch`)와 버튼 호출(`Logo3DColorSection`)까지만 두었다. 처리기 안에서 `remember`를 빠뜨리거나 순서를 바꾸는 회귀가 생겨도 지금 시험은 잡지 못한다.

## 완료 조건

- 팔레트 선택 → 되돌리기 흐름을 확인하는 시험이 있고 통과한다.
- `scripts/verify.sh`가 통과한다.
