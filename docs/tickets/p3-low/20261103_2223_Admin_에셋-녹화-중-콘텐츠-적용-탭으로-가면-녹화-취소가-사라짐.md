# [Admin] 에셋 화면 — 녹화 중에 「콘텐츠 적용」 탭으로 옮기면 「녹화 취소」 버튼이 사라진다

> 티켓 20261103_2041 민지 게이트의 범위 밖 발견물(참고/UX)로 자동 생성한 티켓이다.

## 핵심 요약

- 요구사항: 녹화 중에는 취소 수단이 항상 보여야 한다. 지금은 상단 화면 탭(제작·콘텐츠 적용)이 비활성 영역 밖이라 녹화 중에도 눌리고, 콘텐츠 적용 탭으로 가면 `screenTab !== 'apply'` 조건 때문에 Export 섹션과 「녹화 취소」가 함께 사라진다. 2041 이전부터 있던 동작이다.
- 구현 계획: 녹화 중(`exportBusy`)에는 화면 탭 전환을 막거나, 녹화 중이면 탭과 상관없이 「녹화 취소」를 보여 준다. 둘 중 단순한 쪽(탭 전환 막기)을 기본으로 한다.
- 관련 파일: `jam-web/src/app/admin/assets/ShapeStudioPanel.tsx`(437~458줄 화면 탭, 1327줄 근처 `screenTab !== 'apply'` 조건)

## 완료 조건

- 녹화 중에 화면 탭이 눌리지 않거나, 콘텐츠 적용 탭에서도 「녹화 취소」가 보인다(시험).
- `scripts/verify.sh`가 통과한다.
