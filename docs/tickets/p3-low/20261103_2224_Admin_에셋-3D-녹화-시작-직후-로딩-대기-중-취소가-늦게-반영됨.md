# [Admin] 에셋 3D 녹화 — 시작 직후 이미지·폰트 로딩을 기다리는 동안 취소하면 대기가 끝난 뒤에야 멈춘다

> 티켓 20261103_2041 구현 보고와 민지 게이트의 범위 밖 발견물(참고/UX)로 자동 생성한 티켓이다.

## 핵심 요약

- 요구사항: 3D 동영상 녹화를 누른 직후(오버레이 이미지·폰트 로딩 대기 중) 「녹화 취소」를 누르면 바로 멈춰야 한다. 지금은 대기(`waitUntilIdle`)가 끝나고 첫 프레임을 그릴 때 취소가 반영된다.
- 구현 계획: 로딩 대기 직후와 녹화기 생성 전에 `recAbortRef.current`를 확인해 바로 빠져나오게 한다. 대기가 길 수 있으면 대기 자체를 취소 신호로 끊는 방식을 검토한다.
- 관련 파일: `jam-web/src/app/admin/assets/logo3d/Logo3DViewport.tsx`(677~740줄 `recordVideo`의 대기·녹화 시작 구간)

## 완료 조건

- 로딩 대기 중 취소하면 녹화기를 만들지 않고 끝나며, 크기·자세가 복원된다(시험 또는 코드 확인).
- `scripts/verify.sh`가 통과한다.
