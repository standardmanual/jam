# [Infra] jam-work `plan_only` 크기 기준의 「100줄」을 추가만 셀지, 추가+삭제로 셀지 정한다

> 티켓 20261103_2042 아현 보고와 민지 게이트의 범위 밖 발견물(주의/범위)로 자동 생성한 티켓이다.

## 핵심 요약

- 요구사항: `stop-conditions.md`는 「파일 5개 초과 또는 100줄 이상」이라고만 적고 줄을 어떻게 세는지 정하지 않았다. 2042는 추가 73줄 + 삭제 41줄 = 114줄이어서, 세는 방식에 따라 기준을 넘기도 하고 넘지 않기도 했다. 아현과 민지가 같은 숫자를 다르게 읽을 수 있다.
- 구현 계획: 세는 방식을 하나로 정해 `stop-conditions.md`에 적는다. `git diff --numstat`의 추가+삭제 합계를 기본안으로 하고(채원②의 `diffLineCount`와 같은 기준), 카리나의 1단계 규모 사전 판정에도 같은 기준을 쓴다고 명시한다.
- 관련 파일: `.claude/skills/jam-work/references/stop-conditions.md`(24~47줄 「`plan_only` 판정 기준」), `.claude/skills/jam-work/SKILL.md`(1단계 3번 규모 사전 판정)

## 완료 조건

- `stop-conditions.md`에 줄 수를 세는 방식이 한 문장으로 적혀 있고, SKILL.md 1단계 3번이 그 기준을 참조한다.
