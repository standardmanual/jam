# [Admin] 서비스 (main) 페이지 면이 흰색이 되면, 어드민 배지·아이템북 상세 미리보기 프레임이 크림 배경이라 실제 화면과 어긋난다

> 티켓 20261104_1642 채원 사전 판정과 사후 리뷰, 민지 게이트의 범위 밖 발견물(참고)로 자동 생성한 티켓이다.

## 핵심 요약

- 요구사항: 어드민의 서비스 화면 미리보기가 실제 서비스 화면과 같은 배경(흰색 `--surface`)을 쓰도록 맞춘다. 1642에서 서비스 `(main)` 페이지 면과 TopNav 기본 배경이 `--surface`(흰색)로 바뀌었는데, 어드민 미리보기는 크림 `--background`를 넘기거나 `bg-background`를 써서 어긋난다.
- 구현 계획: 두 프레임의 헤더 `headerStyle.background`와 프레임 바닥 배경을 서비스 `(main)`과 같은 값(`MAIN_PAGE_BACKGROUND` 또는 `--surface`)으로 바꾸고, 미리보기에서 푸터·로고가 보이는 경우 함께 확인한다.
- 관련 파일: `jam-web/src/app/admin/badges/BadgeDetailPreviewFrame.tsx`(96줄 근처 `headerStyle`, 프레임 바닥 `bg-background`), `jam-web/src/app/admin/**/ItemBookDetailPreviewFrame.tsx`(같은 구조), 기준 값 `jam-web/src/lib/pageBackground.ts`의 `MAIN_PAGE_BACKGROUND`

## 완료 조건

- 두 미리보기 프레임의 면이 서비스 화면과 같은 흰색이다(시험 또는 코드 확인).
- 어드민 화면은 MODULAR 적용 대상이 아니므로 바로 서비스 전용 구현으로 한다.
- `scripts/verify.sh`가 통과한다. 실렌더는 카리나가 머지 뒤 로컬 어드민으로 확인한다.
