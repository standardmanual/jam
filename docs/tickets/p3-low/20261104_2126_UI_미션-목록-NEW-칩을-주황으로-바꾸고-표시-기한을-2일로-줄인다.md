# [UI] 미션 목록 NEW 칩을 주황으로 바꾸고 표시 기한을 2일로 줄인다

## 핵심 요약

- 요구사항: 미션 목록의 NEW 칩 색을 주황으로 바꾸고, NEW 칩을 보여 주는 기간을 최대 2일로 한다.
- 구현 계획: `MissionsListClient.tsx`의 `C_NEW_BADGE_BG`를 `--accent`(초록)에서 `--warning`(주황)으로, `NEW_MISSION_WINDOW_MS`를 7일에서 2일로 바꾼다. 글자색은 `--accent-foreground`(검정)를 유지한다.
- 관련 파일: `jam-web/src/app/(main)/missions/MissionsListClient.tsx`, `jam-web/src/app/(main)/missions/MissionsListClient.new-chip.test.tsx`

## 배경 / 문제 정의

NEW 칩이 «참가중» 칩과 같은 초록 면이라 두 칩이 한눈에 구분되지 않았고, 생성 후 7일 동안 붙어 있어 새 미션이라는 신호가 흐려졌다. 사용자가 주황 칩과 2일 기한으로 바꾸라고 요청했다(2026-11-04).

## 상세 요구사항

### UI/UX 관점
- 색: 디자인시스템 상태 토큰 `--warning`(#f5a300)을 면으로 쓴다. 새 토큰은 만들지 않는다. 글자 `--accent-foreground`(#171717)와의 대비는 약 9:1로 10px 굵은 글자에도 충분하다(계산값).
- 크기·모서리·글자 크기는 그대로다.

### 로직 관점
- 판정은 `created_at` 기준 생성 후 2일(48시간) 이내이며, 경계는 «이하»다.
- NEW 칩이 붙는 곳은 미션 목록 하나뿐이다(`isNewMission`의 사용처 확인).

## 완료 조건
- NEW 칩이 주황 면에 검정 글자로 보이고 «참가중» 칩(초록)과 구분된다.
- 생성 후 48시간이 지난 미션에는 NEW 칩이 붙지 않는다.
- 시험·타입 검사·린트 통과, staging 실화면에서 확인.
