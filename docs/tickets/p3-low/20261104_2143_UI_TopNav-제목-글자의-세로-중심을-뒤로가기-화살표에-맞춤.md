# [UI] TopNav 제목 글자의 세로 중심을 뒤로가기(<) 화살표 중심에 맞춘다

## 핵심 요약

- 요구사항: 「< 미션」에서 글자가 화살표보다 조금 아래로 내려와 보인다. 시각적 중심을 맞춘다. (사용자 지시)
- 구현 계획: DS `TopNav.jsx`의 제목 `<h1>`에 `position: relative; top: -1px`를 준다.
- 관련 파일: `jam-web/design-system/components/navigation/TopNav.jsx`(`<h1>` style), `jam-web/src/components/ui/__tests__/TopNav.test.tsx`(시험 1건 추가)

## 배경 / 문제 정의

줄 상자(24px)를 가운데에 맞춰도 한글 글자 모양은 줄 상자 안에서 아래로 치우친다. 로컬 실측에서 글자 모양 중심이 29.0px, 화살표 중심이 28px였다.

## 완료 조건

- 제목 글자 모양의 세로 중심이 화살표 중심과 0.5px 안으로 일치한다. (실측: 28.01px와 28px)
- 관련 시험·lint 통과.

---
## 완료 기록

### 구현 내용 요약
- 제목 `<h1>`을 1px 위로 올렸다. 경미 수정이라 카리나가 직접 처리했고 게이트 리뷰는 거치지 않았다.
- 글자 모양 중심은 canvas `measureText`의 글자 경계 값으로 계산했다. 폰트가 바뀌면 오차가 달라질 수 있다.
