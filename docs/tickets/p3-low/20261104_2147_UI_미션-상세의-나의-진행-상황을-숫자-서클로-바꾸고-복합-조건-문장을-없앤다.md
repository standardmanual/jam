# [UI] 미션 상세의 나의 진행 상황을 숫자 서클로 바꾸고 복합 조건 문장을 없앤다

## 핵심 요약

- 요구사항: 미션 상세 «나의 진행 상황»에서 «아직 미션을 달성하지 못했어요» 문장을 없애고, 연속 일수와 활동 횟수는 프로그래스바 없이 숫자 서클과 서클의 채워짐으로만 보여 준다. 단위(일·회)는 마지막 서클 뒤에 붙인다. 서클이 많아도 모두 그린다.
- 구현 계획: `MissionDetailClient.tsx`에 로컬 컴포넌트 `CountCircles`를 두고 `streak_days`·`activity_count`가 함께 쓴다. 복합 조건(`engine_condition`) 분기는 지우고 달성형 칩 분기로 떨어뜨리되 «미션 완료» 라벨은 그리지 않는다.
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`, `MissionDetailClient.test.tsx`, `jam-web/src/lib/i18n/ko.ts`

## 배경 / 문제 정의

복합 조건 미션의 진행 상황 카드는 «아직 미션을 달성하지 못했어요» 한 문장뿐이라 실제 상태가 보이지 않았다. 사용자가 유형별 프로토타입을 보고 연속 일수·회차는 서클만 쓰는 안을 확정했다(2026-11-04).

## 상세 요구사항

### UI/UX 관점 (채원 사전 판정, 2026-11-04)
- 재사용할 서클 컴포넌트가 디자인시스템에 없어 서비스 전용 로컬 컴포넌트로 묶는다. 두 번째 화면(미션 상황 화면·홈피드 카드)에서 필요해지면 `components/feedback/` 승격 후보다.
- 서클 28px, 간격 6px(줄 사이도 6px), 안 글자 12px 굵게·`tabular-nums`. 끝낸 칸은 `--accent` 채움+`--accent-foreground`, 지금 칸은 `--link` 2px 테두리+`--link` 글자, 남은 칸은 `--background-secondary`+`--muted`.
- 단위 글자는 14px `--muted`. 마지막 서클과 단위를 `whitespace-nowrap` 한 묶음으로 두어 줄이 넘쳐도 함께 내려간다. 서클 수는 줄이지 않는다.
- 접근성: 컨테이너에 `role="img"`와 «7일 중 3일» 형식의 `aria-label`, 서클 숫자는 `aria-hidden`.
- 달성하면 전부 채우고 지금 칸은 없다. 모션은 넣지 않는다.

### 로직 관점
- 서클 개수는 목표값(`streak_days`·`count`), 채움 수는 `floor(progress_value)`(완료 기록이 있으면 전부)다. 달성 판정은 완료 기록으로만 한다.
- 복합 조건은 조건별 현재 값을 서버가 계산하지 않아(달성 여부만 판정, 진행값 0) 조건별 진행 표시는 이번 범위가 아니다. 달성·미달성 칩만 보인다.
- 범위 밖: 랭킹형의 «내 순위», 복합 조건의 조건별 체크리스트(후속).

## 완료 조건
- 연속 일수·활동 횟수 카드에 프로그래스바·퍼센트·«N일 중 N일» 문장이 없고 서클과 단위만 보인다.
- 복합 조건 카드에 옛 문장이 없고 달성·미달성 칩만 보인다.
- 시험·타입 검사·린트 통과, staging 실화면 확인.
