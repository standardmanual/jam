# [UI] 미션 상세 조건 행의 죽은 muted 분기와 불릿 key를 정리한다

## 핵심 요약

- 요구사항: 1회차(`20261104_2148`) 게이트에서 민지가 남긴 참고 두 건을 정리한다.
- 구현 계획: 아래 두 항목만 고친다(2줄 안팎).
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx` — `ConditionRow`(약 113~135줄 `tone` 분기), 달성 조건 카드의 불릿 반복(약 575~580줄 `key={bullet}`).

## 배경 / 문제 정의

1. 회색 보조 문구 줄을 삭제해 `ConditionRow`의 `tone="muted"` 분기를 쓰는 곳이 없어졌다. 병렬 티켓 `20261104_2210`과 같은 파일을 고치는 시기라 1회차에서는 남겼다.
2. 불릿 `key`가 문자열 자체라, 서로 다른 지표 키의 라벨과 값이 같게 시드되면 key 중복 경고가 날 수 있다(지금은 레지스트리 키마다 라벨이 달라 없다).

## 상세 요구사항

- `tone` prop에서 `muted`를 빼고 관련 클래스를 정리한다(사용처가 없는지 `git grep`으로 먼저 확인한다).
- 불릿 반복의 `key`를 `` `${index}-${bullet}` ``처럼 위치를 포함한 값으로 바꾼다.

## 완료 조건

- `ConditionRow`가 `muted` 분기 없이 동작하고 `MissionDetailClient.test.tsx`가 그대로 통과한다.
- 불릿 `key`가 중복되지 않는다(같은 문구 두 줄을 넣는 시험 한 건).
