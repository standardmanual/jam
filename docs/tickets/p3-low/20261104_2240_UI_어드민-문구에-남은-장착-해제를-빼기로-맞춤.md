# [UI] 어드민 문구에 남은 «장착 해제»를 «빼기»로 맞춘다

## 핵심 요약

- 요구사항: UX Writing 가이드 §1.3이 «해제 (UNEQUIP)»를 «빼기»로 바꿨다(티켓 20261104_2153). 컬렉션 상세 밖에서 장착의 반대 뜻으로 «해제»를 쓰는 어드민 문구를 맞출지 정한다. 어드민 전용이라 유저 화면 영향은 없다.
- 관련 파일: `jam-web/src/lib/admin/item-badge-status.ts:61`(상태 라벨 «장착 해제»), `jam-web/src/lib/badge-engine/conditionRegistry.ts:2110`(조건 도움말 «장착을 해제해도»)

## 완료 조건
