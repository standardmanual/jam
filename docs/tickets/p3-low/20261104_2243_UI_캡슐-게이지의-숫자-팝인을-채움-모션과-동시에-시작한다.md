# [UI] 캡슐 게이지의 숫자 팝인을 채움 모션과 동시에 시작한다

## 핵심 요약

- 요구사항: 홈피드와 프로필의 캡슐 게이지에서 채움이 다 차오른 뒤에야 숫자가 나오던 순서를 바꿔, 채움 모션과 숫자 팝인이 같은 순간에 시작하게 한다.
- 구현 계획: `CapsuleGauge.tsx`의 숫자 켜기 타이머에서 모션 시간(`motion.durationMs`) 대기를 없앤다. 채움이 값을 향해 움직이기 시작하는 렌더(`arrived`)에 바로 켠다. 서버 렌더·첫 그리기에서는 꺼 두는 효과 방식은 그대로다(하이드레이션 어긋남 방지).
- 관련 파일: `jam-web/src/components/capsule/CapsuleGauge.tsx`, `CapsuleGauge.test.tsx`, `docs/service/prd/home-feed/PRD.md`, `jam-web/src/lib/admin/policyDashboard/policiesData.ts`

## 배경 / 문제 정의

20261104_1710에서 숫자 팝인을 «채움이 값에 닿은 뒤»로 정했는데, 사용자가 채움이 끝나고 숫자가 따로 나오는 순서가 어색하다며 동시에 시작하라고 요청했다(2026-11-04).

## 상세 요구사항

### UI/UX 관점
- 진입 모션: 260ms 쉰 뒤 채움이 시작되는 순간 숫자 팝인(각 자리 블러와 함께 아래에서 들어옴, 끝 두 자리가 뒤따름)도 시작한다. 팝인은 PopInNumber 자체 시간이 있어 채움(1,500ms)보다 먼저 끝난다.
- 같은 화면에서 값이 바뀌면 새 값으로 옮겨 가기 시작할 때 다시 팝인한다. 모션 줄이기에서는 전환 없이 바로 보인다.
- 합친 연출이 게이지를 붙드는 동안 숨김, 숫자 자리(채운 비율 50% 기준)는 그대로다.

## 완료 조건
- 채움과 숫자 팝인의 시작 시각이 같다(실측).
- 시험·타입 검사·린트 통과, 홈 staging 실화면에서 확인.
