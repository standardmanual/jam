# [BadgeEngine] 조건 레지스트리의 repeat_count 라벨을 DB 라벨과 맞춘다

## 핵심 요약

- 요구사항: 3회차 3-A(`20261104_2321`)가 `badge_metric_labels.repeat_count`의 라벨을 「충족 횟수」에서 「활동 횟수」로 바꿨다(「충족」은 UX 라이팅 가이드 금지어). 조건 레지스트리와 시드의 라벨은 아직 「충족 횟수」라 둘이 갈린다. 레지스트리 쪽도 금지어 없이 맞춘다.
- 관련 파일: `jam-web/src/lib/badge-engine/conditionRegistry.ts`(1614줄 부근 `repeat_count`), `jam-web/supabase/migrations/132_repeat_earn_counter.sql`(139줄 부근 «한 글자도 다르면 안 된다» 주석). 라벨을 대조하는 시험은 131·132·133·140 시드 파일을 읽으므로, 시드 대조 방식도 함께 확인한다.

## 배경 / 문제 정의

민지가 3-A 게이트에서 남긴 [주의]다. DB 라벨(어드민 편집 표)과 레지스트리 라벨이 서로 다르면, 배지 어드민·판정 사유가 쓰는 「충족 횟수」와 미션 상세가 쓰는 「활동 횟수」가 한 지표를 두 이름으로 부른다. 132 시드 주석은 둘이 한 글자도 다르면 안 된다고 적어 두었다.

## 완료 조건

- 레지스트리의 `repeat_count` 라벨이 「충족」 없이 DB 라벨과 같은 말이다(어느 말로 통일할지는 배지 화면 문맥을 보고 정한다).
- 라벨을 대조하는 시험이 새 값 기준으로 통과한다.
