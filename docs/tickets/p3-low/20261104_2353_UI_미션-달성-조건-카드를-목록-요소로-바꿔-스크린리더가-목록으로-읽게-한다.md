# [UI] 미션 달성 조건 카드를 목록 요소로 바꿔 스크린리더가 목록으로 읽게 한다

## 핵심 요약

- 요구사항: 달성 조건 카드의 불릿 행이 `div` 나열이라 스크린리더가 목록으로 읽지 않는다. `ul`·`li`로 바꾸고 불릿 점은 지금처럼 `aria-hidden`으로 둔다.
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`(`ConditionRow` 154줄 부근, 달성 조건 카드 570줄 부근), `MissionDetailClient.test.tsx`.

## 배경 / 문제 정의

3-A(`20261104_2321`) 채원 판정이 범위 밖으로 두고 후속 제안으로 남긴 항목이다. 불릿이 한 줄에서 여러 줄로 늘어난 뒤로 «몇 개의 조건이 있는지»가 보조기기에서 전달되지 않는다.

## 완료 조건

- 달성 조건 카드가 `ul`·`li` 구조이고 시각 결과(점·간격·글자 크기)가 그대로다(시험으로 `list` 역할과 항목 수를 확인한다).
