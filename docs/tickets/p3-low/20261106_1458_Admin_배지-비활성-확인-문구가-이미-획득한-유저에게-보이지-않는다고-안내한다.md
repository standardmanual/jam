# [Admin] 배지 비활성 확인 문구가 이미 획득한 유저에게 보이지 않는다고 안내한다

## 핵심 요약

- `jam-web/src/components/admin/badges/BadgeActiveToggleButton.tsx` 94행의 확인 창이 «이 배지를 비활성화하면 이미 획득한 유저에게 더 이상 보이지 않습니다»라고 안내한다. 아이템 배지는 1단계(마이그레이션 327·328) 이후 개체가 한 번이라도 만들어졌으면 비활성이어도 계속 보인다.
- 액티비티 배지 등 다른 종류의 배지에도 같은 문구를 쓰는지, 배지 종류별로 실제 동작이 어떤지 먼저 확인한 뒤 문구를 맞춘다. 확신도 낮음(민지 범위 밖 발견물).

## 완료 조건

- 배지 종류별 비활성의 실제 동작을 확인해 문구가 동작과 일치한다(필요하면 종류별로 문구를 나눈다). `scripts/verify.sh`가 통과한다.

## 잔여 이슈

- 발견 경위: 티켓 20261106_1232 게이트 리뷰(민지 sideFindings).
