# [UI] 내 프로필의 «최근 활동» 제목과 «n개» 줄을 뺀다

## 핵심 요약

- 요구사항: 프로필 페이지의 활동 목록 위에 있는 «최근 활동» 제목과 «n개» 개수 텍스트 줄을 화면에서 없앤다(사용자 요청 2026-11-06).
- 구현 계획: `FeedSection`에 `hideHeader` 옵션을 더하고 프로필(`ProfileClient`)에서만 켠다. 친구 활동 `/feed`는 그대로 둔다. 제목은 스크린리더용 `sr-only` 제목과 탭 이름(`aria-label`)으로 남긴다.
- 관련 파일: `jam-web/src/app/(main)/FeedSection.tsx`(`Props`, `FeedSection` 머리 줄 828줄 부근), `jam-web/src/app/(main)/profile/ProfileClient.tsx`(738줄 `FeedSection` 호출), `jam-web/src/app/(main)/FeedSection.test.tsx`, `docs/service/prd/chapter/PRD.md`(181줄)

## 배경 / 문제 정의

프로필의 활동 목록 맨 위에 제목 «최근 활동»(왼쪽)과 개수 «n개»(오른쪽)가 한 줄로 있었다. 사용자가 이 줄을 없애길 원한다.

## 상세 요구사항

- 프로필 화면(본인·타인 프로필이 같은 `ProfileClient`를 쓴다)에서 제목·개수 줄이 보이지 않는다. 필터 탭과 카드 목록은 그대로다.
- `/feed`(친구 활동)는 제목 «친구 활동»과 개수 줄을 그대로 그린다.
- 스크린리더 사용자는 제목을 계속 듣는다(`sr-only` 제목).

## 구현 계획

1. `FeedSection` Props에 `hideHeader?: boolean`(기본 false)을 더하고 참이면 `<h2 className="sr-only">`만 그린다.
2. `ProfileClient`의 `FeedSection` 호출에 `hideHeader`를 준다.
3. 서버 렌더 시험 2건: 기본은 제목과 개수를 그리고, `hideHeader`면 `sr-only` 제목만 남는다.

## 완료 조건

- `npx vitest run "src/app/(main)/FeedSection.test.tsx"`가 통과하고, `hideHeader` 렌더에 «1개»가 없고 `sr-only` 제목이 있다.
- 프로필 `FeedSection` 호출에만 `hideHeader`가 있고 `/feed` 호출은 바뀌지 않았다.
