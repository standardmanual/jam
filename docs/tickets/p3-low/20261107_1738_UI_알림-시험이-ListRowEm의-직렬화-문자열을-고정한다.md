# [UI] 알림 시험이 ListRowEm의 직렬화 문자열을 고정한다

## 핵심 요약

- 요구사항: `NotificationsClient.test.tsx`의 일부 단언이 `ListRowEm`이 그리는 마크업 문자열(클래스·태그)을 그대로 고정한다. `ListRow` 쪽 마크업이 바뀌면 알림 문구와 무관한데도 시험이 깨지므로, 굵게 처리됐다는 의미(예: `<strong>` 안의 텍스트)로 단언을 바꾼다.
- 구현 계획: 미정(착수 전 규모 판정).
- 관련 파일: `jam-web/src/app/(main)/notifications/NotificationsClient.test.tsx`

## 배경 / 문제 정의

티켓 20261107_0010 게이트 리뷰의 참고 발견이다. 알림 29종의 문구 시험이 마크업 문자열에 묶이면 `ListRow` 개편 때마다 시험을 같이 고쳐야 한다.

## 완료 조건

- 알림 시험이 굵게 처리된 토큰의 텍스트와 요소 종류만 확인하고, 클래스 문자열에는 의존하지 않는다.
- `NotificationsClient.test.tsx`와 `scripts/verify.sh`가 통과한다.
