# [UI] 프로필 팔로워·팔로잉 탭 행에 시험이 없다

## 핵심 요약

- 요구사항: `ProfileClient.tsx`의 팔로워·팔로잉 탭 행(`ListRow`)을 직접 확인하는 시험을 추가한다. 이동 직전에 URL 해시(`#followers`)를 지우는 `onClick`, 본인 행에는 팔로우 버튼이 없음, 다른 행에는 버튼이 있고 눌러도 행 이동이 일어나지 않음을 고정한다.
- 구현 계획: 미정(착수 전 규모 판정).
- 관련 파일: `jam-web/src/app/(main)/profile/ProfileClient.tsx`(탭 행 502줄 근처, `clearProfileHash`), 새 시험은 `ProfileClient.capsule.test.tsx`·`ProfileClient.chapter.test.tsx` 옆.

## 배경 / 문제 정의

티켓 20261107_1943 게이트 리뷰의 참고 발견이다. 지금은 `FollowUserList` 시험으로만 같은 구조가 부분적으로 고정돼 있고, 프로필 탭의 해시 제거는 정적 마크업으로 볼 수 없어 3-1에서 실렌더로만 확인했다.

## 완료 조건

- 해시 제거 `onClick`, 본인 행 버튼 없음, 버튼 클릭 시 행 이동 없음을 확인하는 시험이 있고 통과한다.
- `scripts/verify.sh`가 통과한다.
