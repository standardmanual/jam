# [UI] 방문 기록 첫 카드의 LabelChip을 호출부 클래스로 덮고 있다

## 핵심 요약

- 요구사항: `PoiEarnHistory.tsx`의 첫 카드(`EarnCardContent`, 24줄 근처)가 `LabelChip`에 `break-keep`·`wrap-break-word`·`whitespace-nowrap` 클래스를 호출부에서 덮어 쓴다. 칩 규격을 호출부에서 덮지 않는 규칙(티켓 20261106_2322)에 어긋나므로, 첫 카드 자체를 `ListRow`/`Card` 규격으로 옮길 때 함께 정리한다.
- 구현 계획: 미정(착수 전 규모 판정).
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/PoiEarnHistory.tsx`(`EarnCardContent`, 24~25줄), `LabelChip` 컴포넌트.

## 배경 / 문제 정의

티켓 20261107_1944 게이트 리뷰의 참고 발견이다. 2번째부터의 행은 3-2에서 `ListRowChip`으로 옮겨졌지만, 첫 카드는 범위 밖이라 `LabelChip`과 호출부 클래스가 그대로 남았다. 같은 «처음 받은 날» 칩이 카드와 행에서 다른 규격으로 그려진다.

## 완료 조건

- 첫 카드의 칩이 호출부 클래스 덮어쓰기 없이 규격 안에서 그려진다.
- 행과 카드의 «처음 받은 날» 칩 모양이 같은 규칙을 따른다(통일할지 둘지는 채원이 판정한다).
