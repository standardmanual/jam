# [Infra] 홈피드 문서 검사가 today 스토리의 주석만 바꾼 커밋을 막는 오탐

## 핵심 요약
- 요구사항: 컬러 개편 2·3회차(`20261107_2203`·`20261107_2246`)에서 `jam-web/src/components/today/*.stories.tsx`의 주석만 바꾼 커밋이 pre-commit 홈피드 문서 검사에 걸려 `JAM_SKIP_DOCLINT=1` 우회가 두 번 있었다. 스토리·주석만 바뀐 경우는 홈피드 PRD 갱신 대상이 아니므로 검사가 막지 않게 한다.
- 구현 계획: `.githooks/pre-commit`의 홈피드 문서 검사가 대상 파일을 고르는 규칙을 찾아 `*.stories.tsx`를 빼거나, 주석만 바뀐 diff를 구분할 수 있는지 본다.
- 관련 파일: `.githooks/pre-commit`(홈피드 문서 검사 구간), 검사 스크립트(`scripts/` 아래 doclint 관련)

## 완료 조건
- today 스토리 파일의 주석만 바꾼 커밋이 우회 없이 통과한다
- 홈피드 코드(스토리 아닌 파일) 변경은 지금처럼 걸린다(시험으로 확인)
