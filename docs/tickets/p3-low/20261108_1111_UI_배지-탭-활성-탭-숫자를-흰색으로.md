# [UI] 배지 화면 상단 탭에서 활성 탭의 숫자를 흰색으로

## 핵심 요약
- 컬러 개편 뒤 `--link`가 블랙이 되어, 배지 화면 상단 탭에서 활성 탭(블랙 면)의 획득 수가 보이지 않았다(사용자 제보, stage 스크린샷).
- 관련 파일: `jam-web/src/app/(main)/badges/BadgesClient.tsx` `tabLabel` 함수(71~77줄)

## 완료 조건
- 활성 탭 숫자는 탭 글자색(흰색)을 따르고, 비활성 탭 숫자는 기존처럼 블랙 굵은 글자로 남는다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- 경미 수정(경로 ①). 숫자에 `[[aria-selected=true]_&]:text-[color:inherit]`를 더해, 선택된 탭 안에서는 탭의 활성 글자색(`--tabs-text-active`, `--snow`)을 물려받게 했다.

### 변경된 파일
```
jam-web/src/app/(main)/badges/BadgesClient.tsx
```
