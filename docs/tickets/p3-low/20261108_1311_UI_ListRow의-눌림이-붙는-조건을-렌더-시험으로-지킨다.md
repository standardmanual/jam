# [UI] ListRow의 눌림이 붙는 조건을 렌더 시험으로 지킨다

## 핵심 요약

- 요구사항: 삭제한 `ListRowCard`는 «비활성·비링크 행에는 눌림이 붙지 않는다»를 렌더 시험으로 지켰는데, `ListRow`에는 같은 렌더 단언이 없다. `ListRow.test.tsx` 159~165줄은 눌림 CSS 문자열만 확인한다. `data-interactive`가 `href`·`onClick`이 있고 비활성이 아닐 때만 `"true"`가 되는지 렌더 시험으로 지킨다.
- 구현 계획: `renderToStaticMarkup`로 `href`·`onClick`·`disabled`·표시 전용 네 경우의 `data-interactive`를 단언하는 시험을 `ListRow.test.tsx`에 더한다(`<style>`을 먼저 걷는다).
- 관련 파일: `jam-web/src/components/ui/ListRow.test.tsx`(159줄 부근), `jam-web/src/components/ui/ListRow.tsx`(65줄 `interactive` 판정)

## 배경 / 문제 정의

목록 행 4단계 5-2(티켓 20261108_1220)의 게이트·사후 리뷰가 범위 밖 발견물로 올렸다. 이번 티켓에서는 고치지 않았다.

## 완료 조건

- 위 요구사항이 코드·문서에서 확인된다(상세는 착수할 때 채원·카리나가 확정한다).
