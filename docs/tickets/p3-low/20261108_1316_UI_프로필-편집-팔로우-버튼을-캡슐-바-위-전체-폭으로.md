# [UI] 프로필의 편집·팔로우 버튼을 캡슐 바 위 전체 폭 작은 버튼으로 옮긴다

## 핵심 요약
- 사용자 요청(2026-11-08): 내 프로필의 편집 버튼과 친구 프로필의 팔로우/언팔로우 버튼을 캡슐 바 위에 가로로 길게 넣고, 높이는 작은 버튼으로 줄인다.
- 배경: 티켓 20261108_1216 이후 편집 버튼(숫자 줄 오른쪽)과 팔로우 버튼(헤더 오른쪽)이 숫자 줄 칸을 좁혀 375px에서 줄이 바뀌었다.
- 관련 파일: `jam-web/src/app/(main)/profile/ProfileClient.tsx` 헤더(숫자 줄 묶음, 팔로우 버튼)와 캡슐 위젯 앞

## 완료 조건
- 본인: 헤더 아래·캡슐 바 위에 전체 폭 «편집» 버튼(size xs). 타인: 같은 자리에 전체 폭 팔로우/언팔로우 버튼(size xs), 그 아래 챕터 줄.
- 헤더 안에는 버튼이 없고 숫자 줄이 넓은 칸을 쓴다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- 편집 버튼(`variant=outline`, xs)과 팔로우 버튼(`primary`/`secondary`, 기존 기본 크기 52px → xs 약 31px)을 헤더에서 빼서 헤더 바로 아래에 `fullWidth`로 둔다. 동작(`/profile/edit` 이동, `handleFollow`, SwapText)은 그대로다.
- 처음에는 sm으로 넣었으나 stage에서 높이가 52px로 나왔다. Button.tsx에서 sm의 `py-[9px]`가 알약 모양의 `py-[13px]`에 밀리기 때문이다(임의값끼리는 큰 값이 이긴다). 사용자가 «작은 버튼»을 요청했고 예전 편집 버튼도 xs였으므로 xs로 바꿨다. xs는 44px 터치 규칙의 명시적 예외다.

### 변경된 파일
```
jam-web/src/app/(main)/profile/ProfileClient.tsx
```

### 테스트 결과

- [x] stage 실렌더(375px): 버튼 폭 343px(전체 폭), 본인은 헤더 아래·캡슐 바 위, 타인은 헤더 아래·챕터 줄 위. 숫자 줄은 본인 «팔로워·팔로잉» 한 줄 + «포인트» 둘째 줄, 타인 «팔로워·팔로잉» 한 줄
- [x] xs 수정 뒤 stage(375px): 편집·팔로우 버튼 모두 높이 34px, 폭 343px
