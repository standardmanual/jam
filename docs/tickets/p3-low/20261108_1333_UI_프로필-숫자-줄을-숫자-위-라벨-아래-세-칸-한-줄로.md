# [UI] 프로필 숫자 줄을 숫자 위·라벨 아래 세 칸 한 줄로 바꾼다

## 핵심 요약
- 사용자 요청(2026-11-08, 인스타그램 참고 이미지): 팔로워·팔로잉·포인트를 한 줄에 넣는다. 참고 이미지는 숫자(굵게, 크게)가 위, 라벨이 아래인 칸 세 개다.
- 배경: 티켓 20261108_1316 뒤에도 본인 프로필은 «라벨 숫자» 가로 배치가 아바타 옆 칸(약 231px)에 다 들어가지 않아 «포인트»가 둘째 줄로 내려갔다.
- 관련 파일: `jam-web/src/app/(main)/profile/ProfileClient.tsx` `statRow`, `ProfileClient.capsule.test.tsx` 숫자 줄 시험

## 완료 조건
- 본인 «팔로워·팔로잉·포인트», 타인 «팔로워·팔로잉»이 375px에서 한 줄이다. 칸마다 숫자 위, 라벨 아래다. 선택 표시(라벨만 블랙)와 누르는 동작은 그대로다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- `statRow`를 `grid grid-cols-3`(칸 3등분)로 바꾸고, 칸 안을 숫자(`text-xl` 굵게) 위·라벨(`text-sm`, `--muted`/선택 시 `--foreground`) 아래로 쌓았다. 타인 프로필은 두 칸만 채워 칸 위치가 본인과 같다.
- 시험의 문자열 순서 기대값을 «숫자→라벨»로 맞췄다.
