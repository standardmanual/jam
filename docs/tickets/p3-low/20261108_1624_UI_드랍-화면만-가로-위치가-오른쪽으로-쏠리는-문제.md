# [UI] 드랍 화면만 가로 위치가 오른쪽으로 쏠리는 문제를 고친다

## 핵심 요약
- 사용자 제보(2026-11-08): 드랍(JAM) 메뉴 화면만 다른 메뉴보다 가로 위치가 조금 오른쪽으로 쏠려 있다.
- 원인: 데스크톱 브라우저에서 다른 화면은 내용이 길어 문서 스크롤바(15px)가 생겨 가운데 정렬 기준 폭이 1009px로 줄어든다. 드랍 화면은 `position: fixed` 지도라 스크롤바가 없어 폭이 1024px 그대로다. 그래서 430px 컨테이너의 왼쪽 끝이 다른 화면 289.5px, 드랍 화면 297px로 7.5px 오른쪽에 놓였다(stage 1024px 실측).
- 관련 파일: `jam-web/src/app/globals.css`(`html` 규칙, 423줄 부근)

## 완료 조건
- 드랍 화면과 다른 메뉴 화면의 430px 컨테이너 왼쪽 끝이 같은 위치다. 휴대폰(겹침 스크롤바) 화면은 그대로다.

## 완료 기록 *(작업 완료 후 작성)*

### 구현 내용 요약
- 경미 수정(경로 ①). `html`에 `scrollbar-gutter: stable`을 더해 스크롤바가 없는 화면도 스크롤바 자리를 비워 두게 했다. 모든 화면의 가운데 정렬 기준 폭이 같아진다.
- 배포 전 stage 드랍 화면에서 같은 값을 임시로 넣어 컨테이너 왼쪽 끝이 297px에서 289.5px로 옮겨지는 것을 확인했다(다른 화면 289.5px).

### 변경된 파일

```
jam-web/src/app/globals.css
```
