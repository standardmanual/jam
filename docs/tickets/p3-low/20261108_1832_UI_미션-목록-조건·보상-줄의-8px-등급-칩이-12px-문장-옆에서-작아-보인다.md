# [UI] 미션 목록 조건·보상 줄의 8px 등급 칩이 12px 문장 옆에서 작아 보인다

## 핵심 요약

- 요구사항: 미션 목록의 조건·보상 줄에 있는 등급 칩(`RarityBadge`·`BadgeLevelChip` `sm`, 글자 8px)이 같은 줄의 문장(12px) 옆에서 작아 보이는 문제를 정한다. 칩 12px 통일(`20261106_2322`)에서 `ListRow` eyebrow의 칩만 `row`(12px)로 바꾸기로 하면서 이 줄들은 범위에서 뺐다. 크기를 올릴지, 지금 그대로 둘지를 사용자와 정한다.
- 구현 계획: 미정(착수 전 실렌더로 정도를 본다). 채원 판정으로 시작한다.
- 관련 파일: `jam-web/src/app/(main)/missions/MissionsListClient.tsx`(`rewardBadgeNode` 73~83줄, `lockedRewardNode` 87~94줄, `conditionBadgeNode` 168~174줄).
- 담당 에이전트: 채원(판정), 필요하면 아현.

## 배경 / 문제 정의

세 함수 모두 `<span style="display:inline-flex; alignItems:center; gap:4px">` 안에 칩과 문장(배지 이름·«잠긴 아이템 배지»)을 나란히 둔다. 문장은 12px(`footer` 줄)이고 칩은 `sm` 8px라 칩이 문장보다 작게 보인다. `20261106_2322`의 사전 판정(2026-11-08)이 이 줄들을 «`ListRow` eyebrow가 아닌 인라인 줄»이라 범위에서 뺐고 사용자가 승인했다.

## 완료 조건

- 사용자가 방향을 정한다: 칩을 키운다(`md` 22px나 `row` 20px 중 줄 높이에 맞는 것), 또는 현재 크기를 확정한다.
- 키우면 미션 목록 조건·보상 줄의 줄바꿈·넘침이 320px에서 깨지지 않는다(실렌더 확인).

---
## 완료 기록

- **결정(2026-11-09, 사용자)**: 칩을 `row`(12px 글자, 20px 높이)로 키운다. 같은 줄의 문장(12px)과 크기가 맞고, 행 안 칩을 `row`로 통일한 `20261106_2322`의 방향과 같다. 현재 크기(8px)를 확정하는 안은 택하지 않았다.
- **경로**: 경미 수정(파일 1개, 코드 3줄, 원인과 수정이 명백)이라 오케스트레이터가 직접 처리했다. 채원 판정과 민지 게이트는 거치지 않았다. 사용자가 크기를 직접 정했고 `row`는 이미 `2322`에서 판정을 받은 크기다.
- **변경**: `jam-web/src/app/(main)/missions/MissionsListClient.tsx`의 `rewardBadgeNode`(레벨 칩과 등급 칩 둘 다), `lockedRewardNode`, `conditionBadgeNode`에서 칩에 `size="row"`를 넘겼다.
- **검증**: 변경 파일 eslint 통과, `src/app/(main)/missions` 시험 11개 파일 151건 통과. 320px에서 실렌더를 시도했으나 공용 DB의 미션 6개 중 배지 보상이 있는 미션이 0개라 실제 줄은 화면에 없다. 대신 같은 마크업(칩 + 이름, `inline-flex`, 간격 4px)을 실제 미션 목록의 보상 줄에 주입해 측정했다. 칩 높이는 8px일 때 16px, `row`일 때 20px였다. 보상 줄은 한 줄일 때 16px에서 20px로 커지고, 이름이 길거나 배지가 셋이면 줄바꿈으로 높이가 늘지만 가로 넘침은 없었다(문서와 줄 모두).
- **확인하지 못한 것**: 실제 배지 보상·조건 데이터가 들어간 미션 카드의 실렌더(주입한 마크업은 구현과 같은 스타일 값을 손으로 옮겼다). 배지 보상 미션이 생기면 한 번 눈으로 볼 것. 잠긴 아이템 배지 줄(`lockedRewardNode`)과 조건 줄(`conditionBadgeNode`)은 주입 측정에서 같은 마크업으로 대표했다.
