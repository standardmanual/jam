# [UI] 미션 목록 조건·보상 줄의 8px 등급 칩이 12px 문장 옆에서 작아 보인다

## 핵심 요약

- 요구사항: 미션 목록의 조건·보상 줄에 있는 등급 칩(`RarityBadge`·`BadgeLevelChip` `sm`, 글자 8px)이 같은 줄의 문장(12px) 옆에서 작아 보이는 문제를 정한다. 칩 12px 통일(`20261106_2322`)에서 `ListRow` eyebrow의 칩만 `row`(12px)로 바꾸기로 하면서 이 줄들은 범위에서 뺐다. 크기를 올릴지, 지금 그대로 둘지를 사용자와 정한다.
- 구현 계획: 미정(착수 전 실렌더로 정도를 본다). 채원 판정으로 시작한다.
- 관련 파일: `jam-web/src/app/(main)/missions/MissionsListClient.tsx`(`rewardBadgeNode` 73~83줄, `lockedRewardNode` 87~94줄, `conditionBadgeNode` 168~174줄).
- 담당 에이전트: 채원(판정), 필요하면 아현.

## 배경 / 문제 정의

세 함수 모두 `<span style="display:inline-flex; alignItems:center; gap:4px">` 안에 칩과 문장(배지 이름·«잠긴 아이템 배지»)을 나란히 둔다. 문장은 12px(`footer` 줄)이고 칩은 `sm` 8px라 칩이 문장보다 작게 보인다. `20261106_2322`의 사전 판정(2026-11-08)이 이 줄들을 «`ListRow` eyebrow가 아닌 인라인 줄»이라 범위에서 뺐고 사용자가 승인했다.

## 완료 조건

- 사용자가 방향을 정한다: 칩을 키운다(`md` 22px나 `row` 20px 중 줄 높이에 맞는 것), 또는 현재 크기를 확정한다.
- 키우면 미션 목록 조건·보상 줄의 줄바꿈·넘침이 320px에서 깨지지 않는다(실렌더 확인).
