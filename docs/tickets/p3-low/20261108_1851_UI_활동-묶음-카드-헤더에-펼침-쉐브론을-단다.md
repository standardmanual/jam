# [UI] 활동 묶음 카드 헤더에 펼침 쉐브론을 단다

## 핵심 요약

- 요구사항: 활동 묶음 카드(`ActivityGroupCard`) 헤더에 쉐브론이 없어서, 눌러서 펼칠 수 있다는 단서가 약하다. ListRow의 `chevron` prop은 `aria-expanded`와 함께 쓰면 펼침 상태에서 180도 회전한다.
- 구현 계획: 헤더 ListRow에 `chevron`을 준다. 눈에 보이는 새 요소이므로 채원① 판정과 사용자 확인을 거친다.
- 관련 파일: `jam-web/src/app/(main)/FeedSection.tsx` — `ActivityGroupCard` 헤더 ListRow(약 804행)

## 배경 / 문제 정의

티켓 20261108_1830에서 채원①이 후속 제안으로 남겼고, 민지도 범위 밖 발견물([참고])로 같은 내용을 지적했다.

## 완료 조건
- 묶음 카드 헤더 오른쪽에 쉐브론이 보이고, 펼치면 회전한다. `scripts/verify.sh` 통과.
