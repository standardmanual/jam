# [UI] 미션 종료 탭에서 참가한 미션의 칩 문구를 «참가종료»로 바꾼다

## 핵심 요약

- 요구사항: 미션 목록의 종료 탭에서, 내가 참가한 미션이 종료된 경우 카드 상단 상태 칩 문구를 «참가종료»로 한다(사용자 지시, 2026-11-09).
- 현재 동작: 종료 탭의 참가한 미션도 상태 판정이 `joined`로 떨어져 «참가중» 칩이 보였다. 이미 끝난 미션에 «참가중»이 붙는 것이 어긋난다.
- 구현 계획: 상태 판정 `missionStatusKind`에 종료 여부 인자를 더해 `joinedEnded`를 만들고, 칩 문구 `d.missions.tagJoinedEnded`(«참가종료»)를 쓴다.
- 관련 파일: `jam-web/src/app/(main)/missions/missionStatusKind.ts`, `MissionsListClient.tsx`(`topStatusLabel`), `jam-web/src/lib/i18n/ko.ts`(`missions.tagJoinedEnded`).
- 담당 에이전트: 오케스트레이터(경미 수정).

## 완료 조건

- 종료 탭에서 내가 참가한 미션의 칩이 «참가종료»로 보인다.
- 완료한 미션(«완료»)과 잠김은 우선순위가 그대로다. 참가하지 않은 종료 미션은 «종료됨», 진행·참가중 탭의 참가한 미션은 «참가중»이 그대로다.

## 완료 기록

- **결정(2026-11-09, 사용자)**: 종료 탭에서 참가한 종료 미션의 칩 레이블을 «참가종료»로 한다.
- **우선순위**: 완료 > 잠김 > 참가종료 > 참가중 > 시작 전 > 기간. 완료한 종료 미션은 이전처럼 «완료»다.
- **칩 모양**: 중립 톤(`ListRowChip` 기본). «참가중»의 done 톤(검정 면)은 진행 중이라는 강조이므로 끝난 미션에는 쓰지 않았다. 색을 다르게 하길 원하면 알려 달라.
- **경로**: 경미 수정(코드 파일 2개 수정 + 사전 1줄, 로직 한 줄)이라 오케스트레이터가 직접 처리했다. 채원 판정과 민지 게이트는 거치지 않았다.
- **변경**: `missionStatusKind.ts`(세 번째 인자 `ended`, 종류 `joinedEnded`), `MissionsListClient.tsx`(`topStatusLabel`이 `tab === 'ended'`를 넘기고 `joinedEnded`일 때 중립 칩), `ko.ts`(`tagJoinedEnded: '참가종료'`), `missionStatusKind.test.ts`(2건 추가), 디자인 시스템 문서 §4 상태 칩 색 매핑의 중립 목록에 «참가종료» 추가.
- **검증**: eslint 통과, `missions`·`i18n` 시험 16개 파일 229건 통과, `tsc --noEmit` 통과, 슬롭 검사 통과. 로컬 실렌더(테스트 계정, 종료 탭)에서 참가한 종료 미션 4건이 모두 «참가종료»로 보였다(이전에는 «참가중»).
- **확인하지 못한 것**: 완료한 종료 미션(«완료» 칩)과 참가하지 않은 종료 미션(«종료됨» 칩)의 실렌더(테스트 계정에 해당 미션이 없다. 판정은 단위 시험으로 확인).
