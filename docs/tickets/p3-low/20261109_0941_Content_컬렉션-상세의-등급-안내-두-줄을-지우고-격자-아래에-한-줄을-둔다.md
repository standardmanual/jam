# [Content] 컬렉션 상세의 등급 안내 두 줄을 지우고 격자 아래에 한 줄을 둔다

## 핵심 요약

- 요구사항: 컬렉션 상세 격자 위의 두 줄 안내(«xxx 등급으로 모으고 있어요. 장착한 배지를 모두 빼면 다른 등급으로 다시 정할 수 있어요.»)를 지운다. 대신 슬롯 영역 아래에 같은 등급의 배지로만 장착할 수 있다는 짧은 안내 한 줄을 둔다. 길고 구구절절한 문장은 쓰지 않는다(사용자 지시, 2026-11-09).
- 구현 계획: 페이지(`page.tsx`)의 격자 위 안내와 그 값(`tierLabel`)을 지우고, 사전 `d.itembooks.tierFixedHint`를 `tierFixedNote`(«같은 등급 배지만 장착할 수 있어요.»)로 바꿔 `SlotGrid`가 격자 아래에 그린다.
- 관련 파일: `jam-web/src/app/(main)/collections/[id]/page.tsx`, `SlotGrid.tsx`, `jam-web/src/lib/i18n/ko.ts`, 시험 `__tests__/page.test.tsx`·`SlotGrid.test.tsx`, `jam-web/src/lib/admin/policyDashboard/policiesData.ts`, `docs/service/prd/02_DATA_MODEL.md`.
- 담당 에이전트: 오케스트레이터(경미 수정).

## 완료 조건

- 격자 위의 두 줄 안내가 보이지 않는다.
- 컬렉션 등급이 정해진 본인 화면에서만 격자 아래에 «같은 등급 배지만 장착할 수 있어요.» 한 줄이 보인다.
- 등급이 없는 상태와 타인 열람에서는 이 줄이 없다.

## 완료 기록

- **결정(2026-11-09, 사용자)**: 두 줄 안내를 제거하고 격자 아래에 짧은 한 줄을 둔다. 문장은 «같은 등급 배지만 장착할 수 있어요.»로 정했다. 등급 이름과 풀리는 방법은 쓰지 않는다. 등급은 격자에 이미 한 등급의 칸만 보여서 드러나고, 풀리는 방법은 «한번에 빼기» 시트가 설명한다.
- **노출 조건**: 이전 안내와 같다(등급이 정해졌고 본인 화면). `SlotGrid`의 `tierFixed`와 `readOnly`로 판정한다. 위치는 격자와 «한번에 빼기» 버튼 사이다.
- **용어**: «장착»은 UX Writing 가이드의 고정 용어다. 사용자 말씀의 «추가»는 가이드에서 쓰지 않는 말이라 «장착»으로 적었다.
- **경로**: 경미 수정이라 오케스트레이터가 직접 처리했다.
- **변경**: `page.tsx`(안내 블록, `tierLabel`, 쓰지 않게 된 import 3개 삭제), `SlotGrid.tsx`(새 한 줄), `ko.ts`(`tierFixedHint` → `tierFixedNote`), 시험(`page.test.tsx`에서 문구 검사를 `tierFixed` 전달 검사로 바꾸고 쓰지 않는 도우미 삭제, `SlotGrid.test.tsx`에 2건 추가), 정책 대시보드 컬렉션 항목(새 안내 반영, «모두 빼기» → «한번에 빼기»), 데이터 모델 PRD.
- **앞선 변경의 누락 보완**: 직전 티켓 `20261109_0935`에서 정책 대시보드 항목의 버튼 이름 «모두 빼기»를 바꾸지 못했다. 이번에 함께 «한번에 빼기»로 맞췄다.
- **검증**: eslint 통과, `tsc --noEmit` 통과, `collections`·`i18n`·정책 대시보드 시험 통과(컬렉션 상세 시험 9개 파일 139건, 정책 대시보드 포함 5개 파일 108건), 슬롭 검사 통과.
- **확인하지 못한 것**: 실제 화면 렌더. 로컬 테스트 계정에 등급이 정해진 컬렉션이 없다. 문구는 사전 값 하나이고 위치·노출 조건은 마크업 시험으로 확인했다. 한 줄이 320px에서 줄바꿈 없이 들어가는지는 눈으로 보지 못했다(글자 수가 짧아 한 줄에 들어갈 것으로 본다).
