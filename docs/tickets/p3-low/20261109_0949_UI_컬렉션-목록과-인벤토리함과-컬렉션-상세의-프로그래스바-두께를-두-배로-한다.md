# [UI] 컬렉션 목록·인벤토리함·컬렉션 상세의 프로그래스바 두께를 두 배로 한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-09): 컬렉션 목록, 인벤토리함, 컬렉션 상세 화면의 프로그래스바 두께를 두 배로 한다. 처음 지시(«배지 프로그래스바»)가 어느 바인지 모호해 사용자에게 확인했고, 위 세 화면이라고 답을 받았다.
- 구현 계획: 세 곳이 쓰는 `ProgressBar`의 `height`만 두 배로 넘긴다. 공용 컴포넌트의 기본값(8px)은 바꾸지 않는다. 쓰는 곳이 8곳이라 다른 화면(미션 상세, 오늘 현황 줄, 온보딩 카드, 랭킹 행 등)이 함께 바뀌지 않게 하기 위해서다.
- 관련 파일: `jam-web/src/components/ui/CollectionGridCard.tsx`(컬렉션 목록 카드, 6 → 12), `jam-web/design-system/components/patterns/CollectionGridCard.jsx`와 `.prompt.md`(같은 값의 디자인 시스템 사본), `jam-web/src/app/(main)/inventory/page.tsx`(인벤토리 칸 사용량 바, 6 → 12), `jam-web/src/app/(main)/collections/[id]/ItemBookHeroSection.tsx`(컬렉션 상세 진행도 바, 기본 8 → 16).
- 담당 에이전트: 오케스트레이터(값 변경 4곳).

## 완료 조건

- 컬렉션 목록 카드의 바가 12px, 인벤토리함의 바가 12px, 컬렉션 상세의 바가 16px이다.
- 이 세 곳 밖의 `ProgressBar`는 그대로다.

## 완료 기록

- **결정(2026-11-09, 사용자)**: 대상은 컬렉션 목록·인벤토리함·컬렉션 상세의 바다. 두 배의 기준은 각 화면의 현재 두께다(6 → 12, 8 → 16).
- **디자인 시스템 사본**: 컬렉션 목록 카드는 서비스 사본과 디자인 시스템 사본이 같은 값을 써서 둘 다 바꾸고 `CollectionGridCard.prompt.md`의 «높이 6px»도 12px로 고쳤다. `ds:check`는 오류 0이다.
- **다른 화면**: 컬렉션 목록 카드를 쓰는 관리자 미리보기(`OpsKindPreview`)의 바도 같은 컴포넌트라 함께 12px가 된다. 이 부분은 의도한 범위 밖의 부수 효과다.
- **검증**: eslint·`tsc --noEmit` 통과, `ds:check` 오류 0(경고는 기존), `src/components/ui`·`src/components/inventory`·`src/app/(main)` 시험 74개 파일 1,330건 통과. 로컬 실렌더(테스트 계정)에서 실제 두께를 쟀다: 인벤토리함 12px(폭 398px), 컬렉션 목록 카드 12px(폭 144px, 카드 9개), 컬렉션 상세 16px(폭 350px). 컬렉션 상세 화면은 스크린샷으로 모양도 확인했다.
- **참고(이번 변경과 무관한 기존 실패)**: `src/components/admin/` 아래 관리자 시험 27개 파일 401건이 `Invalid hook call`로 실패한다. 이번 변경 5개 파일을 빼고 같은 시험(`drawer.test.tsx`, 17건)을 돌려도 똑같이 실패해 기존 문제로 확인했다. 원인은 따로 조사하지 않았다.
- **확인하지 못한 것**: 컬렉션 목록과 인벤토리함의 스크린샷 육안 확인(두께 수치만 쟀다). 12px 바가 카드 안 숫자(`n/m`)와 줄 높이 맞는지는 눈으로 보지 못했다.
