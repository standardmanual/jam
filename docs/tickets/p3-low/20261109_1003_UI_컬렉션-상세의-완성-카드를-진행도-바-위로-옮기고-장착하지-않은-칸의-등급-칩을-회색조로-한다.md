# [UI] 컬렉션 상세의 완성 카드를 진행도 바 위로 옮기고, 장착하지 않은 칸의 등급 칩을 회색조로 한다

## 핵심 요약

- 요구사항 1(사용자 지시, 2026-11-09): 컬렉션 상세에서 «컬렉션 완성!» 알림 카드를 진행도 바 위로 옮긴다. 이전에는 화면 맨 아래(격자와 체크인 배지 섹션 뒤)에 있었다.
- 요구사항 2(같은 날 사용자 지시): 빈 슬롯에 비활성 아이템 배지를 보일 때 등급 칩도 그레이 컬러로 한다.
- 구현 계획: `ItemBookHeroSection`에 `children` 자리를 더해 대표 카드와 진행도 바 사이에 그리고, `page.tsx`가 완성 카드를 그 자리에 넘긴다. 서비스 어댑터 `BadgeGridCard`에 `chipGray`를 더해 장착하지 않은 칸에서 켠다.
- 관련 파일: `jam-web/src/app/(main)/collections/[id]/page.tsx`, `ItemBookHeroSection.tsx`, `SlotGrid.tsx`, `jam-web/src/components/ui/BadgeGridCard.tsx`, 시험 `__tests__/heroChildren.test.tsx`(신규), `page.test.tsx`, `SlotGrid.test.tsx`.
- 담당 에이전트: 오케스트레이터(위치와 색을 사용자가 직접 정함).

## 완료 조건

- 완료한 컬렉션에서 «컬렉션 완성!» 카드가 대표 카드 아래, 진행도 바 위에 보이고 화면 맨 아래에는 없다.
- 장착하지 않은 칸(추가할 수 있는 칸)의 등급 칩이 회색조이고, 장착된 칸의 칩은 그대로다.

---
## 완료 기록

- **결정(2026-11-09, 사용자)**: 위 두 지시. «진행도 바 위»는 대표 카드와 진행도 바 사이로 읽었다(맨 위가 아니다). 진행도 바가 `ItemBookHeroSection` 안에 있어 컴포넌트에 `children` 자리를 더했다. 어드민 배경 미리보기도 같은 컴포넌트를 쓰는데 `children`은 선택이라 영향이 없다.
- **칩 회색조**: 칩의 면 색(`--rarity-*`)은 디자인 시스템 규칙상 바꾸지 않는다. 칩을 `grayscale` 필터 래퍼로 감싸 그려진 뒤 회색이 되게 했다. 불투명도는 건드리지 않아 글자를 읽을 수 있다. 장착하지 않은 칸 중 칩이 있는 칸은 «추가할 수 있는 칸»이다. 미발견 칸은 칩 자체가 없는 기존 결정이라 그대로다. 이전 지시로 이름도 같은 칸에서 `text-muted`다.
- **검증**: eslint, `tsc --noEmit` 통과, 컬렉션 시험 72건 통과(`heroChildren.test.tsx`로 카드 → children → 진행도 바 순서를 고정하고, 페이지 시험에서 완성 컬렉션은 Hero 안에 카드를 넘기는지, `SlotGrid.test.tsx`에서 칩 회색조 범위를 확인). 로컬 실렌더에서 빈 칸(추가 가능)의 칩 필터가 `grayscale(1)`이고 이름이 `text-muted`임을 확인하고 스크린샷으로 봤다.
- **확인하지 못한 것**: 완성 카드의 실제 화면 위치. 확인 시점에 테스트 계정의 컬렉션이 9칸 중 8칸이 장착된 상태(8/9)라 완성 카드가 나오지 않았다. 위치는 단위 시험(서버 렌더 순서)으로만 확인했다.
- **후속(2026-11-09, 사용자)**: «추가» 알약도 «빼기»와 같은 방식으로 없애고 «+» 검은 원 버튼으로 바꾸게 했다. «교체» 알약은 그대로 둔다. 원 버튼은 `SlotRemoveButton`을 `SlotCircleButton`(`icon` = `minus`·`plus`)으로 바꿔 한 컴포넌트가 두 모양을 맡고, `icons.tsx`에 `PlusIcon`을 더했다. 위치·크기·눌림 영역은 «−»와 같다(24px, 가장자리에서 6px 안쪽, 눌림 40px). 한 칸에는 하나만 나온다(장착된 칸은 «−», 넣을 수 있는 칸은 «+»).
- **후속 검증**: 컬렉션 시험을 포함한 `src/app/(main)` 시험 1,019건과 eslint, `tsc --noEmit` 통과. 로컬 실렌더에서 «+» 버튼이 24px에 안쪽 6px이고 칸 아래 «추가»·«빼기» 알약이 0개임을 쟀고 스크린샷으로 봤다. «교체» 알약이 있는 칸은 이 계정에 없어 시험으로만 확인했다.
