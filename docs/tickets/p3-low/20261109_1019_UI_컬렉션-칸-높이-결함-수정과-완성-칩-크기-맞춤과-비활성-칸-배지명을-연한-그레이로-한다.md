# [UI] 컬렉션 칸 높이 결함 수정, 완성 칩 크기 맞춤, 비활성 칸 배지명을 연한 그레이로 한다

## 핵심 요약

- 요구사항 1(사용자 제보, 2026-11-09): 같은 칸이 «+»(비어 있음) 상태일 때 «−»(장착) 상태보다 세로로 더 컸다. 같은 크기여야 한다.
- 요구사항 2(사용자 지시): 컬렉션 목록 카드의 «완성» 칩 크기를 등급 칩과 같게 한다.
- 요구사항 3(사용자 지시): 컬렉션 상세의 비활성(추가할 수 있는)·빈 칸의 배지명을 더 흐린 그레이로 한다.
- 관련 파일: `jam-web/src/components/ui/BadgeGridCard.tsx`, `jam-web/src/components/ui/CollectionGridCard.tsx`, 시험 `src/components/ui/__tests__/CollectionGridCard.tagOrder.test.tsx`, `jam-web/src/app/(main)/collections/[id]/__tests__/SlotGrid.test.tsx`. 선 두께 변경(요구사항 4)은 `SlotCircleButton.tsx`, `design-system/components/patterns/MixerSlot.jsx`.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 같은 칸이 «+» 상태와 «−» 상태에서 높이가 같다.
- 컬렉션 목록 카드의 «완성» 칩이 등급 칩과 같은 크기(글자 8px, 패딩 4px 9px, 높이 16px)다.
- 비활성·빈 칸의 배지명이 연한 그레이(중립 400)다.
- «+»·«−» 아이콘 선이 더 굵다.

## 완료 기록

- **칸 높이 결함**: 앞선 티켓 `20261109_1003`에서 장착하지 않은 칸의 등급 칩을 회색조로 만들려고 칩을 `grayscale` 래퍼로 감쌌다. Common처럼 칩이 아무것도 그리지 않는 배지에서도 빈 래퍼가 남아 이름과 칩 사이 간격(4px)만큼 칸이 커졌다. 래퍼를 없애고 칩 컴포넌트의 `className`에 `grayscale`을 바로 걸도록 고쳤다. 시험은 래퍼가 없음과 Common 칸의 이름 뒤 구조가 장착 여부와 같음을 고정한다.
- **완성 칩 크기**: 서비스 카드의 «완성» 칩이 글자 12px(`text-xs`)·패딩 `px-2 py-0.5`라 옆의 등급 칩(`RarityBadge` sm: 8px, 4px 9px, 줄 높이 1)보다 컸다. 등급 칩과 같은 값(`text-[8px] leading-none px-[9px] py-1`)으로 바꿨다. 디자인 시스템 사본(`CollectionGridCard.jsx`)은 이미 같은 값이라 손대지 않았고, 서비스가 사본과 같아졌다. 사용자가 말한 «등급 칩과 같은 크기»를 등급 칩을 기준으로 완성 칩을 줄이는 것으로 읽었다. 실렌더에서 완성 칩은 높이 16px, 글자 8px, 패딩 4px 9px다.
- **연한 그레이 배지명**: `BadgeGridCard`의 `nameMuted`가 `text-muted`(#666)에서 `text-muted opacity-60`으로 바뀌었다. 흰 카드 면 위에서 #a3a3a3(중립 400)과 같은 밝기라 썸네일 별과 미발견 실루엣의 회색과 같은 단계다. 처음에는 원시 토큰 `--base-neutral-400`을 직접 썼으나 공통 컴포넌트가 원시 색 토큰을 쓰지 못하게 하는 시험(`commonLiteralColors`)에 걸려 역할 토큰과 불투명도로 바꿨다. 실렌더에서 비활성·빈 칸 이름의 글자색이 `rgb(102,102,102)`, 불투명도가 0.6임을 확인하고 스크린샷으로 봤다. **흰 면 위 대비가 약 2.5:1로 낮다.** 비활성 칸이라는 뜻을 우선한 선택이며, 더 읽기 쉬운 값이 필요하면 `opacity-75` 안팎으로 올리면 된다.
- **아이콘 선 두께**: «+»·«−»와 믹서 슬롯 제거 아이콘의 선 두께를 3에서 4.5로 키웠다(사용자 지시).
- **검증**: eslint, `tsc --noEmit` 통과, `src/components/ui`·`src/app/(main)` 시험 1,314건 통과. 컬렉션 상세 실렌더에서 완성한 컬렉션의 «컬렉션 완성!» 카드가 대표 카드와 진행도 바 사이에 있음을 확인했다(앞선 티켓에서 확인하지 못했던 부분).
- **확인하지 못한 것**: 컬렉션 목록에서 «완성» 칩과 등급 칩이 같은 카드에 함께 있는 모습. 이 계정의 목록 카드는 Common이라 등급 칩이 없어 나란히 비교하지 못했고, 같은 값임은 시험으로 고정했다. 같은 칸의 «+» 상태와 «−» 상태의 높이를 같은 칸에서 직접 비교하는 것도 하지 못했다(장착을 바꿔야 해서 사용자 데이터를 건드리지 않았다).
