# [UI] 배지 상세 히어로 카드의 세로 고정과 설명 줄 균형을 해제한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-09): 배지 상세 페이지에서 배지 이미지·이름·설명이 나오는 카드의 세로 크기를 고정하지 않는다. 설명 영역의 CSS `balance` 옵션을 해제한다.
- 구현 계획: `BadgeHeroSection`의 카드에서 `aspect-square`를 빼고 이미지와 글자 블록 사이에 `gap-4`를 둔다. 설명 문단에 `text-wrap!`를 걸어 전역 `p { text-wrap: balance }`를 끈다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/BadgeHeroSection.tsx`, 시험 `__tests__/heroLayout.test.tsx`(신규).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 카드 높이가 내용(이미지·칩·이름·설명 줄 수)으로 정해지고 1:1로 고정되지 않는다.
- 설명 문단의 `text-wrap`이 `balance`가 아니다.

---
## 완료 기록

- **카드 높이**: 1:1 비율(`aspect-square`)을 없앴다. 고정이던 때는 이미지·이름·설명 사이의 빈 공간이 카드 높이에 맞춰 남았고, 지금은 이미지(200px)와 글자 블록 사이를 `gap-4`(16px)가 띄운다. 실렌더에서 비율은 `auto`, 높이는 378px(설명 두 줄)이다.
- **줄 균형 해제**: 전역 CSS(`globals.css`)에 `p { text-wrap: balance }`가 있고 이 규칙이 레이어 밖이라, Tailwind 유틸리티 `text-wrap`을 넣어도 이기지 못했다(처음 시도에서 계산값이 `balance` 그대로였다). 중요도 접미사를 붙인 `text-wrap!`로 바꿔 계산값이 `wrap`이 됨을 실렌더에서 확인했다. 적용 범위는 이 카드의 설명 문단뿐이다. 제목과 다른 화면은 그대로다.
- **같은 컴포넌트를 쓰는 곳**: `BadgeHeroSection`은 배지 상세 세 갈래(활동·체크인·아이템 배지 상세)와 어드민 배지 미리보기가 함께 쓴다. 모두 같은 카드로 바뀐다. 컬렉션 상세의 대표 카드(`ItemBookHeroSection`)는 별도 컴포넌트이고 사용자 말씀이 배지 상세라 그대로 두었다(여전히 1:1이다).
- **검증**: eslint 통과, `src/app/(main)/badges`·`src/app/(main)/__tests__` 시험 통과(`heroLayout.test.tsx` 2건 추가).
- **확인하지 못한 것**: 설명이 매우 길 때와 설명이 없을 때의 카드 모양, 어드민 배지 미리보기 화면의 실제 모양.
- **후속(2026-11-09, 사용자 질문 «획득조건 카드 위의 간격이 너무 넓은데 이유가 있는건지»와 지시 «다른 영역의 카드간 간격 기준에 맞춰서 줄여»)**: 간격은 64px였고 이유는 의도가 아니라 여백 두 개가 겹친 것이었다(히어로 감싸는 곳 `pb-[32px]` + 다음 정보 영역 `pt-[32px]`). 다른 영역의 카드 사이 기준은 `gap-5`(20px)라(컬렉션 상세 블록 사이, 배지 상세 정보 영역의 카드 사이) 히어로 아래 여백을 `pb-5`로 줄이고 세 갈래(활동·체크인·아이템 배지 상세)의 정보 영역에서 위 여백을 뺐다. 아이템 배지 상세의 일련번호 블록은 히어로와의 간격(32px)을 그대로 두려고 `pt-3`을 더했고 일련번호가 없을 때만 걸던 `pt-[32px]` 분기와 쓰지 않게 된 `showSerial`을 지웠다. 실렌더에서 히어로 카드와 «획득 조건» 카드 사이가 64px에서 20px가 됐다. 체크인·아이템 배지 상세는 실렌더로 보지 못했다(같은 구조를 시험과 코드로만 확인).
