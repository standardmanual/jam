# [Service] 믹스로 받은 아이템 배지 개체의 발급 경로를 기록한다

## 핵심 요약

- 요구사항: 잠긴 아이템 배지 상세의 «획득 경로»가 믹스 결과로 받은 개체를 «믹스 보상» 등으로 구분할 수 있도록, 믹스가 개체를 줄 때 어디서 왔는지 기록을 남긴다(티켓 `20261109_1127`의 범위 밖 발견물).
- 구현 계획(초안): `combine_grant_results`·`combine_claim_pending`이 개체를 줄 때 `item_issue_log`에 경로 `combine`으로 한 줄을 남기거나, 받은 개체를 `combine_pending_results`처럼 연결하는 기록을 남긴다. 어느 쪽인지는 발급 기록 표의 다른 사용처(밸런스 대시보드 지표 3·4, 피드 판정 `lockedItemFill`)에 주는 영향을 보고 정한다.
- 관련 파일: DB 함수 `combine_grant_results`·`combine_claim_pending`(마이그레이션 236 이후 최신 정의), `jam-web/src/lib/inventory/obtainRoute.ts`, `jam-web/src/lib/admin/balanceDashboard/load.ts`(발급 기록 집계).

## 배경 / 문제 정의

- 믹스로 바로 받은 개체는 `obtained_by = system_event`이고, 발급 기록·보상 기록 어디에도 개체 id가 남지 않는다. 빈칸이 모자라 보류됐다 받은 경우만 `combine_pending_results.inventory_item_id`에 남는다(2026-11-09 DB 함수 정의로 확인).
- 그래서 지금은 믹스 결과가 «시스템 지급»으로 보이고, 기록 없이는 화면에서 가를 수 없다.

## 완료 조건

- 믹스로 받은 개체(바로 받은 것, 보류됐다 받은 것 모두)의 획득 경로가 구분돼 보인다.
- 발급 기록을 쓰는 다른 화면의 수치가 의도와 다르게 바뀌지 않는다.
