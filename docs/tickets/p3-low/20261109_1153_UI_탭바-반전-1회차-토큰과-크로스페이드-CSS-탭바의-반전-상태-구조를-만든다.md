# [UI] 탭바 반전 1회차: 토큰과 크로스페이드 CSS, 탭바의 반전 상태 구조를 만든다

## 핵심 요약

- 요구사항: 상위 티켓 20261109_1143의 「확정 사항」(푸터보다 밝고 불투명한 어두운 회색 면, 링 없음, 250ms 크로스페이드)을 따라, 탭바가 반전 상태를 받아 밝은 모양과 반전 모양 사이를 교차 페이드하는 구조를 만든다. 푸터 감지는 이번 범위가 아니다(2회차 20261109_1154).
- 구현 계획: 토큰 3종을 기존 토큰 별칭으로 정의하고, `TabBar.tsx`가 `inverted` 값(기본 `false`)을 받아 캡슐 면을 두 레이어로 나눠 opacity를 교차시키며 아이콘·활성 필 색을 바꾼다.
- 관련 파일(4개, 예상 추가+삭제 약 90줄. 크기 기준 초과 가능성이 있어 사용자가 검토한 계획으로 `planOnlyWaiver`를 넘긴다):
  - `jam-web/design-system/tokens/materials.css`: `--tabbar-background-inverse`, `--tabbar-selection-inverse` 추가(기존 `--tabbar-*` 정의 옆, +3줄 안팎). 면은 `--background-inverse` 위에 `--surface-on-inverse`(snow 15%)를 합성한 불투명 색에서 시작해 20~25% 오버레이로 올린다. 새 색 수치는 만들지 않는다.
  - `jam-web/design-system/tokens/colors.css`: `--tabbar-icon-inverse` 추가, `prefers-contrast: more` 블록(121~127줄 부근)이 «아이콘은 항상 흰 필 위»라는 전제로 쓰였으므로 반전 상태를 포함하도록 주석과 규칙을 고친다(+8줄 안팎).
  - `jam-web/src/components/transitions.css` 496~534줄 부근: `.jam-tabbar-chrome` 아래에 반전 면 레이어와 두 레이어 opacity 교차 규칙(250ms, `--duration-fast`, `--ease-smooth-out`), `.jam-tabbar-pill`의 `background-color` 트랜지션(위치 `transform` 트랜지션은 건드리지 않는다). `prefers-reduced-motion`은 `transition: none !important`, `prefers-reduced-transparency`는 밝은 면이 `--surface`가 되는 기존 동작을 유지한다(+35줄 안팎).
  - `jam-web/src/components/ui/TabBar.tsx`: `TabBarProps`에 선택 속성 `inverted?: boolean`(기본 `false`)을 더하고, `<nav>`(className `jam-tabbar-chrome`)를 두 레이어 구조로 바꾸며 활성·비활성 아이콘 색(`color: active ? ... : ...` 부분)과 활성 필(`pillRef` span `background`)에 반전 색을 준다(+40줄 안팎). 마크업의 Link 5개, `moveTo`, `ResizeObserver`는 건드리지 않는다.
- 시험은 2회차에서 한꺼번에 쓴다. 이번 회차에서는 기존 시험이 깨지지 않는지만 본다.

## 상세 요구사항

### UI/UX 관점

- 반전 면은 푸터보다 밝고 불투명하며 링이 없다. 반투명 어두운 면은 쓰지 않는다(밝은 페이지 위에서 아이콘이 읽히지 않는다).
- 두 레이어(밝은 면, 반전 면)의 opacity를 교차시킨다. `background-color`를 직접 보간하지 않는다(중간에 탁한 회색이 거쳐 간다). `backdrop-filter` blur 값은 보간하지 않고 밝은 레이어에만 둔다.
- 활성 아이콘(채운 아이콘)과 비활성 아이콘(선 아이콘) 모두 반전 색을 따로 가진다. 활성은 `--snow`, 비활성은 `--tabbar-icon-inverse`다. 활성 필은 반전 면보다 한 단계 더 밝다.
- 활성 탭이 없는 화면(프로필·검색·알림함)에서는 필이 숨은 채 아이콘만 반전 색으로 바뀐다.
- 필 슬라이딩(`transform`)과 반전은 독립이다. 반전이 켜져 있어도 필 위치는 같다.
- `prefers-reduced-motion`에서는 전환 없이 즉시 바뀐다.

## 완료 조건

- `TabBar`에 `inverted`를 `true`로 주면 캡슐 면, 활성 필, 아이콘 5개가 모두 반전 색으로 바뀌고, `false`로 되돌리면 원래 모양으로 돌아온다. 바뀌는 동안 250ms 교차 페이드이고 중간에 탁한 회색 순간이 없다.
- `inverted`를 주지 않으면(기본 `false`) 지금과 시각·동작이 같다.
- 활성(채운 아이콘+필)과 비활성(선 아이콘)이 반전 상태에서도 구분된다.
- 토큰 3종은 기존 토큰의 별칭이고 새 색 수치가 없다. 정의 위치는 위 두 파일이다.
- 기존 시험이 모두 통과한다.

## 완료 기록

### 구현 내용 요약

- `TabBar`가 `inverted?: boolean`(기본 `false`)을 받는다. `<nav>`는 배경 없이 `data-inverted`만 들고, 안에 밝은 면 레이어(`.jam-tabbar-chrome`)와 반전 면 레이어(`.jam-tabbar-chrome-inverse`)가 있다. 두 레이어의 opacity만 250ms(`--duration-fast`, `--ease-smooth-out`)로 교차한다. blur는 밝은 레이어에만 있고 보간하지 않는다.
- 활성 필에 `background-color` 트랜지션을 더했고 위치 `transform` 트랜지션은 그대로다. 아이콘은 `.jam-tabbar-icon`의 color 트랜지션이다. 반전 상태에서 활성 아이콘은 `--snow`, 비활성은 `--tabbar-icon-inverse`다.
- 토큰 3종은 기존 토큰의 별칭·합성이다. `--tabbar-background-inverse`는 `color-mix(in srgb, var(--snow) 22%, var(--background-inverse))`(확정 범위 20~25%의 시작값), `--tabbar-selection-inverse`는 `--surface-on-inverse`, `--tabbar-icon-inverse`는 `--muted-on-inverse`다. `prefers-contrast: more` 블록은 반전 상태를 포함하도록 고쳤다.
- reduced-motion은 세 요소 모두 `transition: none !important`다. reduced-transparency는 밝은 면만 `--surface`가 되는 기존 규칙을 유지했고 반전 면은 불투명이라 따로 두지 않았다.
- 푸터 감지는 2회차(20261109_1154)다. 이 회차만 반영해서는 화면이 그대로다.
