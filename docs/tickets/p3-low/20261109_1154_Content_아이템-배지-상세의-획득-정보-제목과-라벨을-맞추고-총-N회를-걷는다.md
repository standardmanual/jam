# [Content] 아이템 배지 상세의 획득 정보 제목과 라벨을 맞추고, 배지 상세의 일시를 년월일시로 통일한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-09), 아이템 배지 상세 페이지:
  1. «획득 이력» 오른쪽의 «총 n회» 텍스트를 없앤다.
  2. «획득 이력» → «획득 정보»로 바꾼다.
  3. «획득일»·«만료일» → «획득 일시»·«만료 일시»로 바꾼다.
- 구현 계획: `ItemEarnHistory`의 제목을 다른 배지 상세와 같은 `d.badges.earnInfoTitle`로 바꾸고 «총 N회»를 지운다. 문구 사전 `inventory.obtainedAt`·`inventory.expiresAt`의 값을 바꾼다. 쓰지 않게 된 `badges.earnHistoryTitle`·`earnHistoryCount` 키를 지운다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/ItemEarnHistory.tsx`, `jam-web/src/app/dev-sample/item-badge-serial/page.tsx`(같은 화면의 개발 샘플), `jam-web/src/lib/i18n/ko.ts`, 시험 `__tests__/ItemEarnHistory.test.tsx`.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 제목이 «획득 정보»이고 오른쪽에 «총 N회»가 없다.
- 라벨이 «획득 일시»·«만료 일시»다.

## 완료 기록

- **변경**: 제목은 다른 배지 상세(활동 배지)의 «획득 정보» 카드와 같은 문구 키를 쓴다. 이력 항목이 여러 개여도 제목 오른쪽에 개수를 쓰지 않는다. `inventory.obtainedAt`(«획득일» → «획득 일시»)·`inventory.expiresAt`(«만료일» → «만료 일시»)는 이 화면과 개발 샘플만 쓰는 키라 값만 바꿨다. 이 화면의 바텀시트(이력 상세)도 같은 카드 내용이라 같이 바뀐다.
- **알아 둘 점**: 값 줄은 지금도 날짜만 보인다(예: 2026년 11월 9일). 라벨이 «일시»가 됐지만 값에 시각을 더하지는 않았다. 활동·체크인 배지 상세는 시각까지 보인다. 아이템 배지도 시각까지 보이길 원하면 값 형식 한 줄(`korean={{ year: true }}` → `{{ year: true, time: true }}`)이다.
- **그대로 둔 것**: 체크인 배지 상세의 «방문 기록»(별도 티켓 `20261109_1150`에서 «총 N회» 제거). 데이터·엔진 문서의 일반 용어 «획득 이력»은 화면 문구가 아니라 그대로다. 기능 설명 두 곳(`01_PRD.md`, UX 라이팅 재정비)의 «아이템 상세 획득 이력»은 «획득 정보»로 고쳤다.
- **검증**: eslint, `tsc --noEmit`, `ds:check`(오류 0), 슬롭 검사, 관련 시험 14,741건 통과(제목·라벨·«총 N회» 없음 시험 2건 추가). 실렌더(인벤토리에서 연 아이템 배지 상세)에서 제목 «획득 정보», 라벨 «획득 일시»·«만료 일시», «총 N회»와 «획득 이력»이 없음을 확인하고 스크린샷으로 봤다.
- **확인하지 못한 것**: 개체를 여러 개 가진 배지(이력 행이 여러 줄)와 이력 상세 바텀시트의 실제 화면.
- **후속 1(2026-11-09, 사용자 지시): 일시를 모두 년월일시로 통일**: 배지 상세에는 «년월일»(날짜만)과 «년월일시» 두 형식이 섞여 있었다. 날짜만 보이던 곳을 모두 `korean={{ year: true, time: true }}`로 바꿨다: 아이템 배지 상세의 획득 일시·만료 일시와 이력 행 제목, 체크인 방문 기록과 활동 배지 상세의 «활동 일자»(값은 시각이 있는 값이라 시각까지 보인다, 라벨도 «활동 일시»로 맞췄다), 개발 샘플. 활동·체크인 상세의 획득 일시와 잠긴 상세의 획득 일시는 이미 년월일시였다. UX Writing 가이드 §3의 «날짜만으로 충분한 경우(만료일 등)는 날짜만» 규칙에 «배지 상세의 일시는 예외, 모두 년월일시»를 적었다.
- **후속 2(같은 날, 사용자 지시): 만료가 없는 아이템 배지는 만료 일시를 표시하지 않는다**: 이전에는 «만료 일시 없음»을 보였다. 만료가 있는 개체에만 «만료 일시» 줄을 그린다. 쓰지 않게 된 문구 키 `inventory.expiresNone`을 지웠다. 실렌더(만료 없는 아이템 배지)에서 획득 일시 «2026년 11월 9일 오전 9시 26분»만 있고 «만료 일시»·«없음»이 없음을 확인하고 스크린샷으로 봤다. 만료가 있는 개체(만료 일시 줄이 있는 모양)는 실렌더로 보지 못했고 시험으로만 확인했다.
- **후속 검증**: eslint, `tsc --noEmit`, `ds:check`(오류 0), 슬롭 검사, 관련 시험 14,743건 통과(일시 형식, 만료 일시 생략 시험 추가).
- **후속 3(같은 날, 사용자 지시): 일시 형식을 `2026-12-22 AM 02:22:33`으로 바꾼다**: 배지 상세의 일시를 한글 서술(`2026년 11월 9일 오전 9시 26분`) 대신 KST 12시간제 숫자 형식으로 보인다. `LocalDate`에 `stamp` 속성과 `formatDateTimeStamp`를 더했고(자정·정오는 `12`, 시·분·초는 두 자리), 아이템 배지 상세의 획득 일시·만료 일시·이력 행 제목, 체크인 방문 기록, 활동 배지 상세의 획득 일시·활동 일시, 잠긴 아이템 상세의 획득 일시, 개발 샘플이 쓴다. 포인트 내역·문의·설정·피드 상세 시트의 일시는 지시 범위 밖이라 한글 서술 그대로다. UX Writing 가이드 §3의 예외 문장을 새 형식으로 고쳤다.
