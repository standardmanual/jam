# [UI] 인벤토리의 슬롯 진행도 바를 컬렉션 상세의 바로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-09): 인벤토리의 진행도 바를 컬렉션 상세 페이지의 진행도 바로 바꾼다. 바 밑의 메시지는 삭제하고, «n/n» 수치를 바 오른쪽에 표시한다.
- 구현 계획: 컬렉션 상세의 «바 + 오른쪽 수치» 한 줄을 공용 부품 `ProgressCountBar`로 빼서 인벤토리와 컬렉션 상세가 같이 쓴다. 인벤토리는 바 아래 문장(«N/50개 사용 중 · N개 남음», «N개만 남았어요»)을 지운다.
- 관련 파일: `jam-web/src/components/ui/ProgressCountBar.tsx`(신규), `jam-web/src/app/(main)/inventory/page.tsx`, `jam-web/src/app/(main)/collections/[id]/ItemBookHeroSection.tsx`, `jam-web/src/lib/i18n/ko.ts`, 시험 `inventory/__tests__/page.test.tsx`.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 인벤토리 바가 컬렉션 상세의 바와 같은 모양(높이 16px, 오른쪽에 13px 굵은 «사용/전체»)이다.
- 바 아래에 문장이 없다.

## 완료 기록

- **공용 부품**: 컬렉션 상세의 진행도 한 줄(바 16px + 오른쪽 수치, 13px 굵게 `--link` 색, 숫자 폭 고정)을 `ProgressCountBar`로 옮기고 두 화면이 같이 쓴다. 컬렉션 상세의 렌더는 그대로다(바깥 간격은 호출부 `className`).
- **삭제한 것**: 바 아래 문장 두 갈래를 모두 지웠다. 평소 «46/50개 사용 중 · 4개 남음»과, 남은 칸 1~3개일 때 «N개만 남았어요»를 굵게 올리던 강조(티켓 20261018_0056)다. 문구 키 `inventory.slotsDetail`·`slotsDetailLowLead`·`slotsDetailLowEmphasis`도 지웠다. 남은 칸이 적다는 신호는 이제 수치(예: 48/50)로만 읽힌다.
- **그대로 둔 것**: 남은 칸이 0개일 때의 한 줄 안내 카드(«인벤토리가 꽉 찼어요.»)는 그대로다. `isInventorySlotsLow`(`lib/inventory/slots.ts`)는 화면에서 더 쓰지 않지만 자체 시험이 있어 남겼다(필요 없으면 정리할 수 있다).
- **검증**: eslint, `tsc --noEmit`, `ds:check`(오류 0), 슬롭 검사, 관련 시험 14,743건 통과(인벤토리 시험을 새 표시로 고쳤다). 실렌더에서 바 높이 16px, 오른쪽 수치 «24/30», 바 아래 문장 없음을 확인하고 스크린샷으로 봤다.
- **확인하지 못한 것**: 가득 찬 상태(50/50)와 남은 칸이 적은 상태의 실제 화면(이 계정은 24/30).
