# [UI] 디자인 시스템 토큰 색인에 탭바 반전 토큰 3종을 반영한다

## 핵심 요약

- 요구사항: 탭바 반전 1회차(20261109_1153)가 정의한 토큰 3종(`--tabbar-background-inverse`, `--tabbar-selection-inverse`, `--tabbar-icon-inverse`)을 디자인 시스템 색인 세 곳에 올린다. 값은 이미 `design-system/tokens/materials.css`·`colors.css`에 있고, 이 티켓은 색인과 Story 표기만 맞춘다. 로직 변경이 없고 기존 항목의 모양을 그대로 따르는 작업이다(경로 ② 가벼운 UI, 채원 생략).
- 구현 계획: 기존 `--tabbar-*` 항목 바로 옆에 같은 형식으로 3종을 더한다.
- 관련 파일(3개, 예상 추가 약 30줄):
  - `jam-web/design-system/_ds_manifest.json` 672~705줄 부근: `--tabbar-icon`·`--tabbar-icon-active`·`--tabbar-background`·`--tabbar-blur`·`--tabbar-selection` 항목(각 `name`·종류·설명 형식)을 따라 3종을 더한다.
  - `jam-web/design-system/_adherence.oxlintrc.json` 256~260줄(허용 토큰 목록)과 374~378줄(토큰 종류 매핑): `--tabbar-background-inverse`·`--tabbar-selection-inverse`는 `"other"`, `--tabbar-icon-inverse`는 `"color"`로 더한다(기존 `--tabbar-selection`: other, `--tabbar-icon`: color와 같은 분류).
  - `jam-web/design-system/foundations/Colors.stories.tsx` 179~182줄: `Swatch` 항목(`<Swatch token="--tabbar-icon" desc="비활성 아이콘" />` 형식)에 반전 면·반전 필·반전 아이콘 3개를 더한다.

## 상세 요구사항

- 설명 문구는 토큰 정의 주석과 맞춘다: 반전 면 «푸터보다 밝은 불투명 면(snow 22%)», 반전 필 «반전 상태의 활성 필», 반전 아이콘 «반전 상태의 비활성 아이콘(활성은 --snow)».
- 새 색 수치는 만들지 않는다. 토큰 값은 건드리지 않는다.

## 완료 조건

- 세 파일에 토큰 3종이 기존 항목과 같은 형식으로 올라 있고 `npm run ds:check`가 통과한다.
- 기존 시험이 모두 통과한다.
