# [UI] 반전 탭바 면을 85% 반투명으로 바꾸고 blur를 더한다

## 핵심 요약

- 요구사항: 반전 상태의 탭바 면을 지금의 불투명 회색(`--snow` 22% 합성)에서 85% 불투명도로 바꿔 뒤가 살짝 비치게 한다(사용자 결정 2026-11-09, 시안 100·85·70·55% 중 85%). 반투명 면 뒤의 글자가 뭉개져 읽히도록 반전 레이어에도 밝은 레이어와 같은 blur를 둔다.
- 구현 계획: 토큰 `--tabbar-background-inverse`에 알파를 더하고, 서비스·디자인 시스템 CSS의 반전 레이어에 `backdrop-filter`를 더하고, 투명도 줄이기 설정에서는 불투명 면으로 돌린다. 색인 설명 문구를 «불투명»에서 바꾼다. 형제 티켓 20261109_1310(디자인 시스템 `TabBar`)·20261109_1312(토큰 색인)가 머지된 뒤에 시작한다.
- 관련 파일(6개 이내, 예상 추가+삭제 약 30줄):
  - `jam-web/design-system/tokens/materials.css` 15~16줄: `--tabbar-background-inverse`를 `color-mix(in srgb, color-mix(in srgb, var(--snow) 22%, var(--background-inverse)) 85%, transparent)`로 바꾸고 주석(«불투명»)을 맞춘다. 새 색 수치는 만들지 않는다(22%와 85%는 확정값). 불투명 면이 필요한 곳을 위해 `--tabbar-background-inverse-solid`(기존 22% 합성 불투명 값)를 둔다.
  - `jam-web/src/components/transitions.css` 534~559줄: `.jam-tabbar-chrome-inverse`에 `backdrop-filter: blur(var(--tabbar-blur)) saturate(180%)`와 `-webkit-` 접두를 더한다(값은 보간하지 않고 opacity만 교차한다). 파일 상단 주석(«반전 면은 불투명이라 blur가 없다», «따로 바꿀 것이 없다»)을 고친다. `prefers-reduced-transparency: reduce`에서는 반전 면을 `--tabbar-background-inverse-solid`로, `backdrop-filter`는 `none`으로 둔다(기존 `.jam-tabbar-chrome` 규칙 527~533줄과 같은 방식).
  - `jam-web/design-system/components/navigation/TabBar.jsx`의 `STATIC_CSS`: 1310이 옮긴 `.ds-tabbar-chrome-inverse` 규칙에 같은 blur와 reduced-transparency 규칙을 더한다.
  - `jam-web/design-system/_ds_manifest.json`, `jam-web/design-system/_adherence.oxlintrc.json`: 1312가 올린 `--tabbar-background-inverse` 항목의 설명을 «푸터보다 밝은 반투명 면(snow 22% 합성, 85%)»으로 고치고 `--tabbar-background-inverse-solid`를 같은 형식으로 더한다.
  - `jam-web/design-system/foundations/Colors.stories.tsx`: `Swatch` 설명을 맞추고 `--tabbar-background-inverse-solid`를 더한다.

## 배경 / 문제 정의

- 탭바 반전(20261109_1143)을 22% 불투명 회색으로 확정했는데, 사용자가 «좀더 투명하게»를 원해 시안 4단계를 보고 85%를 골랐다.
- 반투명이 되면 밝은 페이지 위에서 흰 아이콘의 대비가 약해지고, 푸터 위에서는 윤곽이 흐려진다. blur로 뒤 글자를 뭉개 읽기를 살린다.

## 상세 요구사항

- 반전 면은 85% 불투명이고 밝은 레이어와 같은 blur(`--tabbar-blur`)·saturate를 가진다. blur 값은 보간하지 않는다. 교차 전환(opacity 250ms)과 레이어 구조는 그대로다.
- 반전 상태의 아이콘 색(`--snow`, `--tabbar-icon-inverse`)과 활성 필(`--tabbar-selection-inverse`)은 그대로 둔다. 대비가 부족해 보이면 완료 기록에 남기고 조정은 사용자와 정한다.
- `prefers-reduced-transparency`에서는 반투명을 쓰지 않고 지금의 불투명 면으로 돌린다. `prefers-reduced-motion`은 기존대로 전환을 끈다.

## 완료 조건

- 반전 상태에서 탭바 면이 85% 불투명이고 뒤의 흰 카드·푸터 글자가 blur로 뭉개져 은은히 비친다.
- 교차 전환 중에 탁한 얼룩 없이 자연스럽다(staging 실화면 확인, 375px).
- 투명도 줄이기 설정에서는 불투명 면이고 blur가 없다.
- 토큰 색인과 Story 표기가 «불투명»이라고 적은 곳이 남지 않는다. `ds:check`가 통과하고 기존 시험이 통과한다.
