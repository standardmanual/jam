# [UI] 홈 Strava 동기화 끊김 카드를 캔버스 시안대로 바꾼다 (제목·칩 배치·작은 버튼)

## 핵심 요약

- 요구사항: 홈 Strava 동기화 끊김 카드(`StravaDisconnectedCard`)를 디자이너가 캔버스에서 고친 시안(https://claude.ai/artifact/G7eE6dThELeyWBPxuN7Eut 의 `project/HomeTop2.dc.html` 마지막 «Strava 동기화 끊김 카드» 구간, 로컬 사본 `/private/tmp/claude-502/-Volumes---------JAM-/94270d43-5685-4b5c-bbf5-95a68f60f79c/scratchpad/artifact-files/7a667bd6-743f-4e82-8081-1930fd719d4f/project/HomeTop2.dc.html`)대로 바꾼다. 시안과 «버튼도 작은 버튼을 쓴다»는 지시는 사용자가 직접 정했다(2026-11-09). 변경 3가지:
  1. 칩 «Strava 동기화»와 제목을 위아래가 아니라 한 줄(가로, gap 8px)로 놓는다. 칩은 `self-start`다. (이 줄 배치는 같은 날 이용 정지 배너 티켓 `20261109_1414`의 칩·제목 줄과 같은 모양이다)
  2. 제목 문구를 «Strava 동기화가 끊겼어요» → «동기화가 끊겼어요»로 줄인다. 칩에 이미 «Strava 동기화»가 있어 같은 말이 겹치지 않게 한 시안이다. 고치는 값은 `d.stravaConnection.card.title` 하나이고, 같은 말을 쓰는 다른 문구(소식 #40, 공유 오류 `shareErrorStravaDisconnectedTitle`, 설정 구획 등)는 건드리지 않는다.
  3. 카드의 «Strava 다시 동기화하기» 버튼을 «건너뛰기» 버튼(온보딩 카드, `Button variant="primary" surface="main" size="xs"`, `OnboardingQuestSkipModal.tsx` 55~60줄)과 같은 작은 크기 `size="xs"`로 한다. `fullWidth`는 시안대로 유지한다. `xs`는 44px 터치 타겟 규칙의 명시적 예외(조밀한 컨텍스트 전용)라서, 본문 액션에 쓰는 것은 사용자 결정이라는 점을 판정 보고 `[참고]`에 남긴다.
  본문(«비밀번호를 바꿨거나 …»)과 버튼 문구(«Strava 다시 동기화하기»)는 시안에서 바뀌지 않았으니 그대로 둔다.
- 구현 계획: ① `StravaDisconnectedCard.tsx`의 `LabelChip`과 제목 `<p>`를 `flex flex-row gap-2` 한 줄로 묶고, `Button`에 `size="xs"`를 더한다. ② `ko.ts`의 `stravaConnection.card.title` 값을 바꾼다. ③ `StravaCardAndSection.test.tsx`의 끊김 카드 시험(32~45줄 근처)에서 칩·제목 한 줄 배치와 버튼 `xs`(시험은 `min-height:calc(44px * var(--scale-compact))` 인라인 스타일 같은 `xs` 표지를 확인)를 고정한다. ④ `docs/service/prd/home-feed/PRD.md` 112줄의 «제목(「Strava 동기화가 끊겼어요」)»과 버튼 설명을 새 제목·작은 버튼으로 맞춘다.
- 관련 파일:
  - `jam-web/src/components/strava/StravaDisconnectedCard.tsx` (카드 전체, 22~41줄: 칩 27줄, 제목 28줄, 본문 29줄, `Button` 30~38줄)
  - `jam-web/src/lib/i18n/ko.ts` (`stravaConnection.card` 1248~1252줄, `title` 1249줄)
  - `jam-web/src/components/strava/StravaCardAndSection.test.tsx` (끊김 카드 시험 32~45줄, 버튼 `w-full` 확인 45줄)
  - `jam-web/src/components/ui/Button.tsx` (`size="xs"` 정의 참고용, 수정 없음)
  - `docs/service/prd/home-feed/PRD.md` (53줄 표의 끊김 카드 행, 111~112줄 설명)

## 배경 / 문제 정의

디자이너가 Design 캔버스에서 홈 Strava 끊김 카드를 고쳤다(2026-11-09). 칩과 제목을 한 줄로 묶고 제목을 줄였다. 버튼은 작은 크기를 쓰라고 정했다. 같은 날 처리하는 이용 정지 배너(`20261109_1414`)와 같은 줄 배치·작은 버튼 규칙이라 홈 상단의 안내 카드끼리 모양이 맞는다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `d.stravaConnection.card.title` 외의 문구 키와 값은 바꾸지 않는다. 끊김 카드가 나오는 조건(`showsStravaDisconnectedCard`)과 버튼 동작(`/api/strava/auth` 이동)은 바꾸지 않는다.
- 이 티켓과 `20261109_1414`는 둘 다 `ko.ts`를 고치지만 서로 다른 블록(`d.suspension` / `d.stravaConnection`)이다. 병렬 작업이라 머지는 순차로 한다.

### UI/UX 관점
- 새 컴포넌트·새 토큰·새 색을 만들지 않는다. 기존 `Card`·`LabelChip`·`Button`만 쓴다.

### 컨텐츠 관점
- 사용자 노출 문구 변경은 제목 한 곳이다. 값은 «동기화가 끊겼어요»다.

## 구현 계획

핵심 요약의 구현 계획 ①~④와 같다. 변경 파일은 4개, 예상 변경 줄은 30~50줄이다.

## 완료 조건

### 구현 범위 (게이트 판정 대상)
- `d.stravaConnection.card.title`이 «동기화가 끊겼어요»이고, `chipLabel`·`card.body`·`card.cta` 값과 `d.stravaConnection`의 다른 키는 그대로다.
- 카드에서 칩과 제목이 한 줄(가로 flex)로 놓이고 칩은 `self-start`다.
- 카드 버튼이 `Button variant="primary" surface="main" size="xs" fullWidth`로 그려진다(«건너뛰기»와 같은 `size="xs"`). 누르면 `/api/strava/auth`로 이동하는 동작은 그대로다.
- `StravaCardAndSection.test.tsx`가 새 제목·한 줄 배치·`xs` 버튼을 고정하고 통과한다. `scripts/verify.sh`가 통과한다.
- `docs/service/prd/home-feed/PRD.md`의 끊김 카드 설명이 새 제목·작은 버튼과 맞다.
- 판정 보고에 «`size="xs"`는 44px 터치 타겟 예외, 사용자 결정»이 `[참고]`로 남는다.

### 후속 범위 (담당: 카리나, 시점: 머지 뒤)
- 두 하위 UI 변경(`20261109_1414`, 이 티켓)을 순서대로 머지하고 한 번에 staging에 push한다. 끊김 상태 유저 화면 확인은 해당 계정이 없으면 시험 통과로 갈음한다고 기록한다.
