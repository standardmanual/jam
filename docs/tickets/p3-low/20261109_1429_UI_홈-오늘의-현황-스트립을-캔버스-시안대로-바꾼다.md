# [UI] 홈 오늘의 현황 스트립을 캔버스 시안대로 바꾼다 (라벨·아이콘·진행률 표기 위치)

## 핵심 요약

- 요구사항: 홈 «오늘의 현황» 스트립(`TodayStatusStrip`)을 디자이너가 캔버스에서 고친 시안(https://claude.ai/artifact/G7eE6dThELeyWBPxuN7Eut 의 `project/HomeTop3.dc.html`, 로컬 사본 `/private/tmp/claude-502/-Volumes---------JAM-/94270d43-5685-4b5c-bbf5-95a68f60f79c/scratchpad/artifact-files/7a667bd6-743f-4e82-8081-1930fd719d4f/project/HomeTop3.dc.html`)대로 바꾼다. 시안과 진행률 위치 지시는 사용자가 직접 정했다(2026-11-09). 변경 3가지:
  1. 카드 라벨 문구: 왼쪽 «내 진행도» → «진행상황», 오른쪽 «팔로잉 소식» → «팔로잉». 값은 `d.todayStatus.myProgressLabel`과 `d.todayStatus.friendActivityLabel`이다.
  2. 아이콘 삭제: 왼쪽 제안 카드(`suggestion`, 미션 `TargetIcon`·드랍 `PackageIcon`)와 오른쪽 «팔로우한 친구가 없어요» 카드(`no_following`, `UsersIcon`)에 있던 흐린 아이콘(`text-muted opacity-50`)을 없앤다. 문구만 남는다.
  3. 진행 바가 있는 카드(`progress`: 미션 진행·컬렉션 진행)의 «n/n» 표기를 이름 줄에서 빼서 **진행 바의 오른쪽으로 옮기고 글자를 작게** 한다. 지금은 이름과 같은 줄(`text-base font-bold`) 끝에 «6.4/10.0»이 붙어 있다. 바꾼 뒤: 윗줄에는 이름만(`text-base font-bold`), 아랫줄은 «진행 바(가로로 늘어남) + 오른쪽에 n/n»이다. n/n은 `text-xs`(12px)로 줄이고 `tabular-nums whitespace-nowrap`을 유지하며 굵기·색은 지금 값(굵게, 본문색)을 따른다. 숫자 자릿수 규칙(`formatMissionProgress`, 거리 미션은 소수 1자리)은 그대로다. 보이는 글자로 n/n이 남아 있어 스크린리더에도 그대로 읽힌다.
- 구현 계획: ① `TodayStatusStrip.tsx`의 `LeftCell`(progress 분기 55~71줄 근처)에서 이름 `<p>`와 진행 바·n/n 줄을 나누고 n/n을 바 오른쪽 `flex items-center gap-2` 줄로 옮긴다. DS `ProgressBar`(`@ds/components/feedback/ProgressBar`)가 `labelType`(n분의n 표기)으로 오른쪽 라벨을 이미 지원하면 그 기능을 쓰고, 맞지 않으면 바깥 flex 줄로 직접 짠다(DS 컴포넌트는 고치지 않는다). ② `suggestion` 분기와 `no_following` 분기에서 아이콘 `<span>`을 지우고 쓰지 않게 된 아이콘 import(`PackageIcon`·`TargetIcon`·`UsersIcon`)를 정리한다. ③ `ko.ts`의 `todayStatus.myProgressLabel`·`friendActivityLabel` 값을 바꾸고 주석(`// 좌: 내 진행도`, `// 우: 팔로잉 소식`)을 새 이름에 맞춘다. ④ `TodayStatusStrip.test.tsx`를 새 라벨·아이콘 없음·n/n 위치(바 오른쪽 줄, `text-xs`)에 맞춰 고친다. ⑤ `docs/service/prd/home-feed/PRD.md`의 «내 진행도»·«친구 활동» 라벨 설명(54줄, 129줄 근처)을 새 이름·모양에 맞춘다.

## 배경 / 문제 정의

디자이너가 Design 캔버스에서 «오늘의 현황» 카드를 고쳤다(2026-11-09). 라벨을 줄이고 문구 카드의 흐린 아이콘을 걷었다. 진행률은 이름 끝에 붙어 줄이 길어지면 이름과 섞이므로, 바 오른쪽으로 옮기고 작게 해 달라는 지시를 더했다.

## 상세 요구사항

### 서비스/코드베이스 관점
- 카드 분기(`strava_not_connected`·`progress`·`suggestion`, `friend_activity`·`no_following`)와 링크 동작, `right.kind === 'none'`일 때 왼쪽 카드만 그리는 동작은 바꾸지 않는다.
- `d.todayStatus`의 다른 키(`greeting`·`stravaCta`·`noFollowing`·`friendActivity*`·`suggestion*`)는 바꾸지 않는다. 라벨 값이 서비스의 다른 곳(어드민 미리보기 등)에서 쓰이는지 검색하고, 쓰이면 같이 맞추거나 보고한다.
- 새 컴포넌트·새 토큰·새 색을 만들지 않는다.

### UI/UX 관점
- 진행 바는 카드 폭 안에서 n/n 때문에 너무 짧아지지 않아야 한다. 컬렉션처럼 n/n이 짧은 경우(3/8)와 «6.4/10.0»처럼 긴 경우가 모두 한 줄에 들어간다. 이름은 길어도 줄바꿈으로 이어지고(`break-words`) n/n은 줄바꿈하지 않는다.
- 카드 높이(`min-h-[92px]`)와 왼쪽·오른쪽 카드의 높이 맞춤(`h-full`)은 그대로다.

### 컨텐츠 관점
- 사용자 노출 문구 변경은 라벨 두 개뿐이다. 값은 «진행상황»·«팔로잉»이다.
