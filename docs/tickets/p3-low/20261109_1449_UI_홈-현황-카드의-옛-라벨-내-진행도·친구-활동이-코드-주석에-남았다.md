# [UI] 홈 현황 카드의 옛 라벨 «내 진행도·친구 활동»이 코드 주석에 남았다

## 핵심 요약

- 요구사항: 티켓 `20261109_1429`에서 홈 «오늘의 현황» 카드의 라벨이 «진행상황»·«팔로잉»으로 바뀌었다. 코드 주석에는 옛 이름이 남아 있어 읽는 사람이 화면과 코드를 연결하기 어렵다. 주석의 옛 라벨을 새 이름에 맞춘다(동작 변경 없음).
- 구현 계획: 아래 주석 세 곳의 «내 진행도»·«친구 활동»을 «진행상황»·«팔로잉»으로 고친다. 코드 식별자(`getTodayLeftStatus` 등 이름)는 바꾸지 않는다.
- 관련 파일:
  - `jam-web/src/app/(main)/page.tsx` (157줄 근처 «오늘의 현황 스트립» 주석)
  - `jam-web/src/lib/today/status.ts` (4줄, 19줄 근처 «좌: 내 진행도», «우: 친구 활동» 주석)

## 배경 / 문제 정의

20261109_1429 게이트에서 민지가 발견했다(참고). 상위 PRD(`docs/service/prd/01_PRD.md`)의 옛 라벨은 카리나가 머지 때 이미 고쳤다.

## 완료 조건

- 위 두 파일의 주석에서 옛 라벨 «내 진행도»·«친구 활동»이 화면 라벨을 뜻하는 곳이 모두 새 이름으로 바뀐다. 코드 동작 변경이 없다.
