# [UI] 반전 탭바 면의 불투명도를 85%에서 75%로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-09): 탭바가 푸터 영역과 만나 반전될 때의 면 불투명도를 85%에서 75%로 바꾼다. 티켓 `20261109_1325`가 고른 85%를 대체한다.
- 구현 계획: 토큰 `--tabbar-background-inverse`의 알파를 85%에서 75%로 바꾸고, 같은 값을 적은 토큰 색인·Story·주석을 맞춘다.
- 관련 파일: `jam-web/design-system/tokens/materials.css` 14~16줄, `jam-web/design-system/_ds_manifest.json`(719줄), `jam-web/design-system/foundations/Colors.stories.tsx`(183줄), `jam-web/design-system/components/navigation/TabBar.stories.tsx`(108줄), `jam-web/src/components/transitions.css`(538줄).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 반전 상태의 탭바 면이 75% 불투명이다. 밝은 면, blur, 교차 전환(250ms), 투명도 줄이기 설정의 불투명 면은 그대로다.
- 85%라고 적은 토큰 색인·Story·주석이 남지 않는다.

---
## 완료 기록

- **변경**: `--tabbar-background-inverse`를 `color-mix(in srgb, var(--tabbar-background-inverse-solid) 75%, transparent)`로 바꿨다. 불투명 합성색(`-solid`, snow 22% 합성)과 투명도 줄이기 설정의 불투명 면은 그대로다. 서비스 탭바와 디자인 시스템 탭바가 같은 토큰을 읽으므로 둘 다 바뀐다.
- **알아 둘 점**: 75%는 85%보다 뒤가 더 비친다. 밝은 페이지 위에서 흰 아이콘의 대비는 85%보다 약해질 수 있다. 아이콘·활성 필 색은 그대로 뒀고, 읽기 어려우면 알려 달라.
- **검증**: `ds:check`(오류 0), 슬롭 검사, 탭바·디자인 시스템 시험 456건 통과. `src/components/admin/`의 기존 «Invalid hook call» 실패는 이번 변경과 무관하다.
- **확인하지 못한 것**: 실렌더(개발 서버가 꺼져 있었다). staging 배포 뒤 375px에서 푸터 경계에 걸친 탭바를 눈으로 확인해야 한다.
