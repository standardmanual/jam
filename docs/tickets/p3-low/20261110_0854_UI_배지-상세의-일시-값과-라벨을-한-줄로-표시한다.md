# [UI] 배지 상세의 일시 값과 라벨을 한 줄로 표시한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 배지 상세 «획득 정보»의 획득 일시가 «2026-11-07 / PM 05:38:33»처럼 두 줄로 꺾인다. 날짜와 시간을 한 줄로 보이게 하고, «획득 일시» 라벨도 한 줄로 둔다.
- 원인: 값 행(label + value)의 값 칸이 행 폭의 60%까지만 늘어나는데, `2026-11-07 PM 05:38:33`(16px 굵게)은 375px 폭에서 그 상한을 넘는다.
- 구현 계획: `ListRow`에 `valueNoWrap`을 더한다. 값 칸의 60% 상한을 풀고 줄바꿈하지 않으며, 라벨도 줄바꿈하지 않는다. 340px 이하에서는 값 글자를 한 단계(text-sm) 줄여 한 줄에 맞춘다. 일시 값(`LocalDate stamp`)을 쓰는 값 행 7곳에 적용한다. 서비스 `ListRow`와 디자인 시스템 `ListRow`에 같은 규칙을 넣고 Story를 더한다.
- 관련 파일: `jam-web/src/components/ui/ListRow.tsx`(`valueNoWrap`, `bodyStyle`, `rightArea`), `jam-web/design-system/components/patterns/ListRow.jsx`·`.d.ts`·`.stories.tsx`, 호출부 `badges/[id]/page.tsx`·`ItemEarnHistory.tsx`·`PoiEarnHistory.tsx`, `inventory/[itemId]/LockedItemDetail.tsx`, 시험 `ListRow.test.tsx`·`FeedSection.test.tsx`.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 배지 상세·잠긴 아이템 상세의 일시 값(획득 일시·만료 일시·활동 일시)과 라벨이 모든 폭(320px 이상)에서 한 줄이다.
- `valueNoWrap`을 쓰지 않는 값 행의 모양은 바뀌지 않는다.

---
## 완료 기록

- **변경**: `valueNoWrap`이 켜진 값 행은 값 칸의 `max-width: 60%`와 줄바꿈을 풀고(`flex-shrink: 0`), 라벨 칸도 `white-space: nowrap`으로 둔다. 340px 이하에서는 클래스 `.ds-list-row-value-nowrap`이 값 글자를 `--text-sm`(14px)으로 줄인다. 기본값(생략)은 지금과 같다. 일시 값을 쓰는 값 행 7곳(배지 상세 획득·활동 일시, 아이템 이력 획득·만료 일시, 체크인 방문 기록 두 줄, 잠긴 상세 획득 일시)에 적용했다.
- **실렌더 확인**(잠긴 아이템 상세 «획득 일시», 폭별): 375px에서 값 한 줄·16px, 341px에서 라벨·값 모두 한 줄·16px, 320px에서 라벨·값 모두 한 줄이고 값은 14px이며 넘침 없음.
- **알아 둘 점**: 320px(와 340px 이하)에서는 값이 14px로 작아진다. 같은 줄에 라벨과 값을 모두 넣을 폭이 모자라서다. 글자를 줄이지 않고 두 줄을 허용하려면 이 규칙을 빼면 된다. 일시 값이 더 길어지는 형식(예: 영문 월 이름)으로 바뀌면 이 폭 계산을 다시 해야 한다.
- **시험 보정**: 컴포넌트가 함께 내보내는 `<style>` 안의 규칙에 `font-size:var(--text-sm)`가 들어가 기존 시험 두 곳(`ListRow.test.tsx`, `FeedSection.test.tsx`)의 «마크업에 없음» 단정이 걸렸다. 두 시험이 `<style>`을 걷어 내고 보도록 고쳤다.
- **검증**: eslint, `tsc --noEmit`, 슬롭 검사, `src/app/(main)`·`src/components/ui`·`src/lib`·`scripts`·`design-system` 시험 통과(`valueNoWrap` 시험 추가). `ds:check` 오류 0, 경고 46건(`PROPS_DRIFT` ListRow는 기존 `38` 항목 하나만 남음).
- **확인하지 못한 것**: 배지 상세(활동·체크인 배지)의 실화면. 실계정에서 확인한 것은 잠긴 아이템 상세 한 곳이고, 나머지 6곳은 같은 속성을 쓴다.
