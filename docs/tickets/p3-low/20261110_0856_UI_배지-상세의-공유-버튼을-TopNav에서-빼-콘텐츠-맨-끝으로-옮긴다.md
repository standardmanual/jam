# [UI] 배지 상세의 공유 버튼을 TopNav에서 빼 콘텐츠 맨 끝으로 옮긴다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 배지 상세 페이지의 TopNav에 보이는 공유 버튼을 없애고, 배지 상세 콘텐츠의 맨 마지막에 «공유하기» 버튼을 둔다.
- 구현 계획: 세 갈래(아이템·체크인·활동)의 `TopNav rightSlot`에서 `BadgeShareButton`을 빼고, 각 갈래의 콘텐츠 맨 끝에 본인 배지일 때만 그린다. `BadgeShareButton`의 아이콘 버튼(`IconButton`)을 전체 폭 `Button`(primary)으로 바꾸고 문구 `d.badges.shareButtonLabel`을 «공유»에서 «공유하기»로 바꾼다. 막힌 사유 팝오버는 버튼 위쪽에 띄운다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/page.tsx`(세 갈래 TopNav와 끝부분), `jam-web/src/app/(main)/badges/[id]/BadgeShareButton.tsx`(버튼·팝오버), `jam-web/src/lib/i18n/ko.ts`(`shareButtonLabel`), 시험 `__tests__/shareButtonPlacement.test.ts`(신규), PRD `docs/service/prd/badge-share/PRD.md`·`notification/PRD.md`.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 배지 상세 TopNav에 공유 아이콘이 없다.
- 본인 배지의 상세 맨 끝(3타입 모두)에 «공유하기» 버튼이 있고, 타인 배지에는 없다.
- 공유가 막힌 배지(미획득, 스트라바 연동 끊김)는 버튼이 흐리고, 누르면 사유 안내가 버튼 위쪽에 뜬다.

---
## 완료 기록

- **변경**: 세 갈래의 `rightSlot`을 지우고, 아이템 갈래는 정보 영역 아래에 따로 감싼 칸으로, 체크인 갈래는 하단 액션 영역 맨 끝에, 활동 갈래는 정보 영역 맨 끝에 버튼을 놓았다. 공유 시트 동작(캐러셀, 저장·공유)은 그대로다.
- **막힘 표현**: 이전 아이콘 버튼처럼 네이티브 `disabled`를 쓰지 않고 `aria-disabled`만 준다. 눌러야 사유 안내가 뜨기 때문이다. 흐린 모양은 `Button`이 자체 스타일로 `opacity`를 정해 `className`으로 바꿀 수 없어서 버튼을 감싼 칸에 준다(팝오버는 그 칸 밖이라 흐려지지 않는다).
- **문서**: 공유 PRD의 «TopNav 우측 공유 아이콘» 서술 두 곳과 알림 PRD의 `rightSlot` 충돌 문장을 새 위치에 맞게 고쳤다.
- **검증**: eslint, `tsc --noEmit`, `ds:check`(오류 0), 슬롭 검사, `src/app/(main)`·`src/components`·`src/lib`·`scripts`·`design-system` 시험 17,191건 통과(위치 시험 4건 추가, 실패 406건은 기존 `src/components/admin/` «Invalid hook call»뿐). 실렌더(375px, 활동 배지 상세)에서 TopNav에 공유 아이콘이 없고, 정보 카드 아래 전체 폭 «공유하기» 버튼이 있으며, 스트라바 미연동 계정이라 버튼이 흐리고 눌렀을 때 «Strava 동기화가 끊겼어요» 안내가 버튼 위쪽에 뜨는 것을 확인하고 스크린샷으로 봤다.
- **확인하지 못한 것**: 공유가 가능한 상태(활성 버튼 → 공유 시트 열림)의 실화면, 아이템·체크인 배지 상세의 실화면(같은 코드 패턴이라 시험으로만 확인), 배경 테마가 있는 배지 위에서 검은 버튼의 대비.
