# [UI] 잠긴 아이템 배지 상세의 이름을 특수문자 6글자로, 설명을 세계관 말투로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 잠긴 아이템 배지 상태에서 보이는 이름을 `@&₩-)/(!?%^£¥` 같은 특수문자를 무작위로 섞은 6글자로 표시한다(배지마다 다르고, 같은 조합이 나와도 된다). 아래 설명은 트라이브 감성으로 숨겨진 무언가가 있다는 뉘앙스의 짧은 문장으로 바꾼다.
- 구현 계획: 개체 id를 시드로 쓰는 결정적 생성기 `lockedItemMaskName`(특수문자 13종 중 6글자)을 만들어 잠긴 상세의 제목에 쓴다. 설명 문구 키 `d.lockedItem.detail.description`을 바꾼다. 열리면 `SwapText`가 실제 이름으로 바꾸는 기존 전환은 그대로다.
- 관련 파일: `jam-web/src/lib/inventory/lockedItemMask.ts`(신규), `jam-web/src/app/(main)/inventory/[itemId]/LockedItemDetail.tsx`(제목), `jam-web/src/lib/i18n/ko.ts`(`detail.description`), 시험 `src/lib/inventory/__tests__/lockedItemMask.test.ts`(신규)·`LockedItemDetail.test.tsx`, 문서 인벤토리 PRD·UX Writing 가이드.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 잠긴 아이템 배지 상세의 제목이 특수문자 6글자이고, 같은 배지는 새로고침해도 같은 글자다.
- 설명이 «숨겨진 무언가가 있다»는 느낌의 짧은 문장이고 트라이브·종류·숫자를 드러내지 않는다.

## 완료 기록

- **이름**: 특수문자 `@ & ₩ - ) / ( ! ? % ^ £ ¥` 13종에서 6번 뽑는다. 뽑는 순서는 개체 id를 해시(FNV-1a)한 값으로 시드를 정하는 난수 생성기(mulberry32)가 정한다. 그래서 배지마다 다르게 보이지만 같은 개체는 언제나 같은 글자다. 렌더마다 새로 뽑지 않은 이유는 서버 렌더와 클라이언트 렌더의 글자가 달라지는 하이드레이션 오류(React #418)와, 새로고침할 때마다 이름이 바뀌는 문제를 피하려는 것이다. 이름은 개체 id에서만 나오므로 어떤 아이템 배지인지 알려 주지 않는다(운영 로직 7.3절 가림 원칙).
- **설명**: «도시의 뒷면에 숨어 있던 무언가가 기다리고 있어요». 트라이브 문서의 총괄 컨셉(도시의 밤낮에 겹쳐진 비밀스러운 세계, 파편)과 미스터리 헌터의 «세상의 뒷면»을 따랐다. 열기 전에는 어느 트라이브인지 숨겨야 해서 특정 트라이브의 말씨가 아니라 세계관 공통의 말투로 썼다. 열기 문구에 쓰지 않는 «획득»·«얻었어요»·«잠금»과 숫자·«트라이브»가 없음을 시험이 지킨다.
- **범위**: 잠긴 아이템 배지 **상세 화면의 제목과 설명**만 바꿨다. 목록 카드·선택 시트·미션 보상 줄·드랍 연출·피드 등 `d.lockedItem.card.name`(«잠긴 아이템 배지»)을 쓰는 다른 화면은 그대로다(서버 API가 이 이름을 응답에 담는 곳도 있어 서버·클라이언트가 함께 바뀌어야 한다). 같은 처리를 다른 화면에도 원하면 `lockedItemMaskName`에 개체 id를 넘겨 쓰면 된다.
- **검증**: eslint, `tsc --noEmit`, 슬롭 검사(주석의 «진짜»를 «실제»로 고침), `src/app/(main)`·`src/components`·`src/lib`·`scripts`·`design-system` 시험 15,701건 통과(생성기 시험 5건, 상세 시험 2건 추가). 실렌더(375px, 잠긴 상세)에서 제목 «(/%!¥@», 설명 «도시의 뒷면에 숨어 있던 무언가가 기다리고 있어요»를 확인하고 스크린샷으로 봤고, 새로고침해도 같은 글자이며 하이드레이션 오류가 없다.
- **확인하지 못한 것**: 설명 문구의 세계관 감수. 윈터(세계관 에이전트)를 거치지 않고 문서의 톤만 보고 썼다. 다른 후보로 바꾸길 원하면 문구 키 한 줄이다. 열린 뒤 이름이 실제 이름으로 바뀌는 전환의 실화면(열면 포인트가 빠져 열지 않았다).
