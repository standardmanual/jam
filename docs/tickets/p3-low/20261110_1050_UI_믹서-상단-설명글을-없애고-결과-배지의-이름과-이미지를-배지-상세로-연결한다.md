# [UI] 믹서 상단 설명글을 없애고 결과 배지의 이름과 이미지를 배지 상세로 연결한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10), 레시피 상세(믹서) 화면:
  1. 첫 번째 카드(요약 행) 아래의 설명글을 없앤다.
  2. 믹스로 생성되는 배지의 이름과 이미지를 누르면 그 배지 상세 페이지로 이동한다.
- 구현 계획: 믹서가 그리던 `RecipeDescription` 영역을 걷는다. `RecipeRewardRow`에 `linkBadge`를 더해 표시 전용 요약 행에서 대표 보상 배지의 이미지(`ListRow`의 `leadHref`)와 이름(`Link`)을 `/badges/{id}`로 잇는다.
- 관련 파일: `jam-web/src/app/(main)/combine/CombineClient.tsx`(요약 행 호출부, 설명 영역), `jam-web/src/app/(main)/combine/RecipeRewardRow.tsx`(`linkBadge`), 시험 `CombineClient.test.tsx`, 문서 `docs/service/content/COMBINE_RECIPES.md`·`docs/service/prd/02_DATA_MODEL.md`.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 믹서 화면에 레시피 설명이 없다.
- 요약 행의 배지 이미지와 이름을 누르면 그 배지 상세로 이동한다. 레시피 목록 행(행 전체가 버튼)은 그대로 레시피를 고르는 동작이다.

## 완료 기록

- **설명 제거**: 믹서에서 설명 영역을 그리지 않는다. 어드민의 «레시피 설명» 입력 칸과 DB 값은 그대로 남아 있다. `RecipeDescription` 부품과 그 시험은 코드에 남겨 두었다(어디서도 쓰지 않는다).
- **링크**: 이름은 밑줄이 있는 링크이고 이미지는 같은 주소의 링크다(접근 가능한 이름은 배지명). 보상 배지가 여러 개면 대표(첫 번째) 배지로 간다(이름 뒤 «+N» 글자도 같은 링크 안이다). 눌림 행(`onClick`)에서는 링크를 만들지 않는다(버튼 안에 링크를 둘 수 없다). 레시피 이름(제목)과 포인트는 링크가 아니다.
- **검증**: eslint, `tsc --noEmit`, 슬롭 검사, `combine` 시험 210건 통과(링크 시험 2건 추가, 설명 영역 시험은 «그리지 않는다»로 교체). 실렌더(375px, «노트 위의 별»)에서 설명이 없고, 이미지·이름 링크가 같은 배지 상세로 향하며, 이름을 누르면 «접이식 테이블» 배지 상세(`/badges/{id}`)로 이동함을 확인했다.
- **알아 둘 점**: 결과 배지가 «잠긴 채 지급»되는 레시피(`reward_locked`)도 지금은 실제 배지 이름과 이미지를 보여 주던 행이라 같은 링크가 걸린다. 잠긴 채 지급하는 레시피의 결과를 상세에서 보여 주면 안 되는 정책이라면 알려 달라. 이 경우만 링크를 빼면 된다.
- **확인하지 못한 것**: 미획득 배지 상세로 이동했을 때의 화면 전체(이동과 제목만 확인), 보상 배지가 여러 개인 레시피의 «+N» 링크 모양.
