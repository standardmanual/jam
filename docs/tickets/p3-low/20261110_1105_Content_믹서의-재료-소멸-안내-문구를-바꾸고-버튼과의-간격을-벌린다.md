# [Content] 믹서의 재료 소멸 안내 문구를 바꾸고 버튼과의 간격을 벌린다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 레시피 상세(믹서) 화면 아래의 «넣은 재료는 성공·실패와 관계없이 사라져요»를 «사용한 배지는 사라져요.»로 고치고, 버튼과의 간격을 조금 더 띄운다.
- 구현 계획: 문구 키 `d.combine.burnNotice`의 값을 바꾸고, 안내 문장(`p`)에 위쪽 여백 8px(`mt-2`)를 더해 버튼과의 간격을 8px에서 16px로 한다.
- 관련 파일: `jam-web/src/lib/i18n/ko.ts`(`combine.burnNotice`, 약 1903줄), `jam-web/src/app/(main)/combine/CombineClient.tsx`(안내 문장, 약 1092줄).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 믹서의 «믹스하기» 버튼 아래 안내가 «사용한 배지는 사라져요.»이고 버튼과의 간격이 16px다.

---
## 완료 기록

- **변경**: 문구 값 하나와 안내 문장의 위쪽 여백 하나를 고쳤다. 사용자 요청대로 끝에 마침표를 붙였다.
- **알아 둘 점**: 같은 화면의 다른 안내 문구들(예: 공개 시각 전 안내, 등급 올리기 화면의 `tierUp.burnNotice` «넣은 재료는 사라져요»)에는 마침표가 없고 재료를 «재료»라 부른다. 이 안내만 마침표가 있고 «배지»라고 말해 서로 말투가 다르다. 화면이 하나라 지금은 눈에 띄지 않지만, 맞추길 원하면 알려 달라. 이전 문구에 있던 «성공·실패와 관계없이»가 빠져 실패해도 사라진다는 뜻은 더 이상 말하지 않는다.
- **검증**: eslint, `combine`·문구 사전 시험 286건 통과(이 문구를 직접 단정하는 시험이 없었다). 실렌더(375px, «노트 위의 별» 믹서)에서 새 문구가 보이고 이전 문구가 없으며, 버튼 아래 간격이 측정값 16px임을 확인하고 스크린샷으로 봤다.
- **확인하지 못한 것**: 슬롯이 아이템 배지가 아닌 조건 배지로만 이뤄진 레시피(이 안내를 그리지 않는다)의 모양.
