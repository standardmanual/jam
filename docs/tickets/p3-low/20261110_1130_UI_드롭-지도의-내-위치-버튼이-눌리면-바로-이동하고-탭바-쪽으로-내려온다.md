# [UI] 드롭 지도의 내 위치 버튼이 눌리면 바로 이동하고 탭바 쪽으로 내려온다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 드롭 화면 지도 위의 «내 위치» 버튼이 동작하지 않는다. 누르면 내 위치가 화면 중앙에 오도록 이동해야 한다. 버튼이 탭바와 너무 떨어져 있으니 간격의 절반 정도로 아래로 내린다.
- 원인(코드로 확인): 버튼이 눌릴 때마다 위치를 새로 조회하고 응답이 와야만 지도를 움직였다. 조회에 시간 제한이 없어 응답이 늦거나 오지 않으면 눌러도 아무 반응이 없고, 그동안 버튼은 비활성(`disabled`) 상태로 남았다. 실기기에서 같은 증상이 나는 정확한 환경은 재현하지 못했다.
- 구현 계획: 부모(`DropsClient`)가 이미 감시 중인 최신 위치(`userLat`·`userLng`)를 기억해 두었다가, 버튼을 누르면 조회 응답을 기다리지 않고 그 위치로 즉시 이동한다. 위치를 새로 조회하되 8초 제한을 두고, 결과가 약 3m 넘게 다를 때만 한 번 더 보정한다. 버튼 위치는 탭바 하단 공식에 맞춰 탭바 윗면에서 18px 위로 한다.
- 관련 파일: `jam-web/src/components/map/MapView.tsx`(`handleLocateClick`, `moveToUser`, `latestUserPosRef`, `LOCATE_*` 상수).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 버튼을 누르면 위치 조회 응답과 관계없이 지도 중심이 최신 내 위치로 이동하고 파란 점도 같은 자리에 놓인다.
- 위치 조회가 실패하거나 시간이 지나도 버튼이 다시 눌린다.
- 버튼과 탭바 사이 간격이 이전(37px)의 절반 정도(18px)다.

---
## 완료 기록

- **변경**: `MapView.tsx` 한 파일. 즉시 이동(`moveToUser`)과 최신 위치 기억(`latestUserPosRef`)을 더하고, `getCurrentPosition`에 `timeout 8초`·`maximumAge 10초`를 줬다. 버튼 하단 값은 `안전 영역 + 96px` 고정에서 탭바 하단 공식 + 49px(탭바 높이) + 18px로 바꿨다. 홈 인디케이터가 있는 기기에서도 탭바와의 간격이 같다.
- **검증(로컬 개발 서버, 430×800)**: 로컬 도메인은 네이버 지도 인증이 막혀 실제 지도는 뜨지 않는다. 그래서 가짜 `naver.maps`를 심어 호출을 기록했다. 위치 조회가 응답하지 않을 때도 누르는 즉시 `morph`·마커·서클이 최신 위치로 호출됨, 늦게 도착한 조회가 다른 위치면 한 번 더 이동함, 거의 같은 위치(약 1m)면 더 움직이지 않음, 조회가 실패하면 버튼이 다시 활성화됨을 확인했다. 버튼과 탭바 사이 간격은 37px에서 18px로 줄어든 것을 측정했다. eslint와 타입 검사 통과.
- **확인하지 못한 것**: 실제 네이버 지도 위에서의 이동 애니메이션, 실기기의 위치 권한 거부 상태(이때는 최신 위치가 없어 지도가 처음 위치에 머문다), 홈 인디케이터가 있는 기기에서의 실제 간격(공식으로만 확인).
- **알아 둘 점**: 파란 점은 버튼을 눌렀을 때만 따라온다. 걸어서 움직이는 동안 점이 실시간으로 따라가게 할지는 따로 정하지 않았다.
