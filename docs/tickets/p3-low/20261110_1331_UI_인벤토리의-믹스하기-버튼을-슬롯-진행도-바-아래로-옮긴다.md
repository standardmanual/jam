## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 인벤토리 페이지의 «믹스하기» 버튼을 진행도 바 아래로 옮긴다. 버튼 색은 그대로 둔다.
- 변경: 버튼이 진행도 바 위쪽 줄(오른쪽 정렬)에 있었다. 바 바로 아래(간격 12px) 오른쪽 정렬로 옮겼다. 클래스에서 위쪽 여백(`mt-1`)만 걷고 배경(`bg-surface`)·모양·높이는 그대로다.
- 관련 파일: `jam-web/src/app/(main)/inventory/page.tsx`(헤더 블록, `ProgressCountBar` 앞뒤).
- 담당 에이전트: 오케스트레이터.
