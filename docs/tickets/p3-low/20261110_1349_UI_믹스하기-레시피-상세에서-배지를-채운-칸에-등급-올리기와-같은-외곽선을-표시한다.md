# [UI] 믹스하기 레시피 상세에서 배지를 채운 칸에 등급 올리기와 같은 외곽선을 표시한다

## 핵심 요약

- 요구사항: 디자이너가 «레시피 상세에서 슬롯에 배지를 추가하면 등급 올리기 슬롯처럼 외곽선을 표시하라»고 했다(2026-11-10). 등급 올리기에서 외곽선(3px 회색 테두리, `MixerSlot`의 `--muted`)은 비어 있는 칸에 있고 채운 칸은 테두리가 없어, 어느 칸에 외곽선을 둘지 질문으로 확인했다. 디자이너가 «배지를 채운 칸»으로 정했다.
- 구현 계획: `RecipeSlotCard`의 `filled` 상태 카드에만 `ring-3 ring-inset ring-muted`(3px 회색 안쪽 링)를 건다. 칸 크기·이미지 위치는 밀리지 않는다.
- 관련 파일: `jam-web/src/app/(main)/combine/RecipeSlotCard.tsx`, `jam-web/src/app/(main)/combine/RecipeSlotCard.test.tsx`, `docs/service/prd/01_PRD.md`(믹스 설명)

## 배경 / 문제 정의

슬롯을 컬렉션 칸처럼 바꾼 뒤(티켓 20261110_1115) 채운 칸과 «+» 칸이 버튼 모양(«−»/«+»)으로만 구분되어, 게이트 리뷰도 «헷갈릴 수 있다»고 지적했다. 외곽선으로 «채움»을 한눈에 알리게 한다.

## 완료 조건

- 채운 칸에만 3px 회색 외곽선이 보이고, «+» 칸과 흐린 칸에는 없다.
- 4열(`dense`)에서도 같다. 칸 크기와 이미지 위치는 변하지 않는다.
- 시험이 통과한다.

## 완료 기록

### 구현 내용 요약
`RecipeSlotCard`가 채운 칸(`filled`)에만 `ring-3 ring-inset ring-muted`를 건다. 안쪽 링(box-shadow inset)이라 칸 크기와 이미지 위치가 밀리지 않고, 색은 등급 올리기 `MixerSlot`의 테두리와 같은 `--muted`다(실화면에서 `rgb(102, 102, 102)` 3px inset 확인).
