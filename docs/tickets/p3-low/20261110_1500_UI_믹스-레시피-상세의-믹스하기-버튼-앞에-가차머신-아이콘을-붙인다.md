# [UI] 믹스 레시피 상세의 믹스하기 버튼 앞에 가차머신 아이콘을 붙인다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 믹스 레시피 상세 화면의 «믹스하기» 버튼에서 글자 앞에 첨부한 그림 같은 가차머신 아이콘을 SVG로 추가한다. 기존 서비스 아이콘 스타일에 맞춰 미니멀하게 그리고 크기도 맞춘다.
- 구현: 서비스 아이콘 파일(`src/components/ui/icons.tsx`)의 규칙(24 상자, 선 1.5px, 둥근 끝, `currentColor`, 채움 없음)을 그대로 따라 `GachaMachineIcon`을 더했다. 사각형 유리창(위) 안에 알 두 개, 그 아래 더 넓은 사각형 몸통에 돌리개 하나와 투입구 한 줄로 줄였다. 버튼에서는 20px(`w-5 h-5`, 16px 글자와 균형)로 글자 왼쪽에 놓고 `gap-2`(8px)를 둔다. 처리 중에는 아이콘 대신 기존 회전 표시가 나온다.
- 그림을 다듬은 과정: 처음 안은 둥근 유리통이라 자물쇠처럼 읽혔고, 알 두 개가 같은 높이면 얼굴로 읽혔다. 사용자가 «더 단순화, 첨부한 것 같은 사각형 박스 형태»를 지시해 유리창과 몸통을 모두 사각형으로 바꾸고, 알은 서로 다른 높이로 두고 겹치지 않게 했다.
- 관련 파일: `jam-web/src/components/ui/icons.tsx`(`GachaMachineIcon`), `jam-web/src/app/(main)/combine/CombineClient.tsx`(믹스하기 버튼, `combineButton`).
- 디자인 시스템(MODULAR) 아이콘 카탈로그는 서비스 `icons.tsx`의 사본이라 이번에는 더하지 않았다(서비스 전용 아이콘).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 레시피 상세의 믹스하기 버튼 글자 앞에 가차머신 아이콘이 보인다.
- 아이콘은 버튼 글자 색을 따르고(활성·비활성 모두), 크기는 20px다.
- 처리 중에는 아이콘 대신 회전 표시가 나온다.

## 완료 기록

- **검증(로컬 개발 서버, 430×800)**: 믹스 레시피 상세 화면에서 버튼 안 아이콘이 20×20px, 글자와 같은 색(`rgb(240, 240, 240)`), 버튼 배경 `rgb(23, 23, 23)`임을 측정했다. 120px로 키운 모양과 20px 실제 크기 모두 눈으로 확인했다(사각형 상자 형태로 바꾼 뒤 다시 확인). 믹스 관련 시험 243건, eslint 통과.
- **확인하지 못한 것**: 재료를 채워 활성화된 버튼의 모양, 처리 중 상태, 실기기에서의 선명도(20px에서 알 두 개의 선이 가늘게 보일 수 있다).
- **알아 둘 점**: 인벤토리 화면의 «믹스하기» 버튼에는 붙이지 않았다(지시가 레시피 상세 화면이었다).
