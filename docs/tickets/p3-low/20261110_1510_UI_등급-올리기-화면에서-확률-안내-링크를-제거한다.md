# [UI] 등급 올리기 화면에서 확률 안내 링크를 제거하고 설명문을 한 문장의 게임 메시지로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 믹스하기 > 등급 올리기 화면에서 «확률 안내» 링크를 없앤다. 같은 지시에서 설명문을 UI 설명이 아닌 게임 속 짧은 메시지로 바꾸는 안을 여럿 제안해 달라고 했다.
- 변경: `TierUpPanel`의 설명 문단 아래 «확률 안내» 링크 블록과 `Link` 가져오기를 걷었다. 확률 안내는 푸터 링크로만 들어간다(`/probability` 자체는 그대로).
- 관련 파일: `jam-web/src/app/(main)/combine/TierUpPanel.tsx`(링크 블록), `TierUpPanel.test.tsx`(순서·링크·줄바꿈 시험), `tierUpClient.ts`(머리 주석), `docs/service/prd/probability/PRD.md`(§4 입구 표).
- 설명문(사용자 결정 2026-11-10, 4안 중 C 방향을 한 문장으로): 세 문장의 규칙 설명(「같은 등급 아이템 배지 6개를 넣으면 내 트라이브의 새 아이템 배지 1개를 받아요. 윗등급이 나오거나 같은 등급이 나와요. Mystic 6개를 넣으면 Mystic을 받아요.」)을 먼저 「같은 등급 아이템 배지 6개가 모이면 같거나 더 높은 등급의 새 배지 1개로 다시 태어나고, Mystic은 끝까지 Mystic이에요.」로 바꿨고, 이어서 «더 짧게, 해 봐 느낌»을 지시해 「같은 등급 6개를 모아 새 배지로 바꿔 봐요! 등급은 그대로거나 올라가요.」(41자)로 줄였고, 다시 «배지 6개로 한 등급 레벨업! 도전» 뉘앙스를 원한다고 해 「같은 등급 배지 6개로 윗등급에 도전해 봐요!」(22자)로 바꿨고, 이어서 사용자가 「배지 6개로 등급 업!」(11자)을 직접 제시해 적용했고, 마지막으로 「같은 등급 배지 6개로 등급 업! 도전!」(20자)으로 바꾸라고 지시해 그대로 적용했다. (직전 안에서는 «레벨업»은 트라이브 레벨의 용어라 «윗등급»(결과 오버레이 «윗등급이 나왔어요!»와 같은 말)으로 쓰고, 같은 등급이 나올 수도 있어 «올라가요» 대신 «도전»으로 썼다으로 썼다.) 「등급 업!」은 결과가 오른다는 쪽으로 읽히지만 「도전!」이 보장이 아님을 알리고, 같은 등급이 나올 수 있다는 점은 확률 안내 페이지에만 있다. `/probability` 페이지의 소개 문단은 법적 고지 문구라 그대로다.
- 관련 파일(문구): `jam-web/src/lib/i18n/ko.ts`(`combine.tierUp.description`), `TierUpPanel.test.tsx`·`tierUpClient.test.ts`(문구 시험).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 등급 올리기 화면에 «확률 안내» 링크와 `/probability` 이동이 없다.
- 설명문이 한 문장이고 같거나 더 높은 등급과 Mystic 규칙을 모두 담는다.
- 슬롯 6칸 이하의 구성은 그대로이고, 숫자·퍼센트가 어디에도 없다.

## 완료 기록

- **변경**: 링크 블록 제거, 시험 3곳 정정(본문 순서에서 링크 제거, «링크가 없고 숫자·퍼센트가 없다» 확인으로 교체, 줄바꿈 시험에서 링크 제외), 확률 PRD §4 입구 표에서 등급 올리기 행 삭제.
- **검증**: 믹스·확률 페이지·문구 시험 396건 통과(문구 시험은 새 문장에 맞춰 고쳤고 «두 문장 이하, 45자 안쪽, 레벨업·올랐·항상 없음»을 확인하는 시험을 더했다), eslint·타입 검사 통과. 화면은 링크가 있던 자리가 단순히 사라지는 변경이라 따로 열어 보지 않았다.
- **알아 둘 점**: 줄이면서 «내 트라이브의 새 배지», «같은 등급이 나올 수 있다», «Mystic은 Mystic을 받는다» 설명이 문구에서 빠졌다. 「도전」이 결과가 보장되지 않음을 알리고, 나머지 규칙을 알리는 곳은 확률 안내 페이지뿐이다. Mystic은 올라갈 윗등급이 없는데 「윗등급에 도전」이라고 읽히는 점은 남아 있다. 받는 배지가 내 트라이브 것이라는 사실도 결과 화면과 확률 안내 페이지에 있다.
- **알아 둘 점**: 확률 안내로 가는 길은 푸터 링크 하나만 남았다. 등급 올리기는 결과가 확률로 정해지므로, 이 변경이 확률 고지 의무에 영향을 주는지는 운영 쪽에서 한 번 확인하는 편이 안전하다.
