# [UI] 믹스 레시피 상세의 믹스하기 버튼 아래에 유의사항 구역을 더한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 첨부한 «슈퍼특가 유의사항» 예시처럼 믹스하기 버튼 아래에 유의사항 구역을 더한다. 확률 정보 등은 노출하지 않는다.
- 구현: 버튼 아래 CTA 영역 다음에 폭 전체의 띠(`bg-background-secondary px-4 py-6`, 서비스 열 바탕 `#f0f0f0`보다 한 단계 어두운 `#e5e5e5`. 처음에는 흰 띠였으나 «배경을 전체 페이지 배경보다 더 어둡게»라는 사용자 지시로 바꿨다)를 두고, 제목 «유의사항»(굵은 글씨)과 점 목록(`text-sm text-muted`)을 놓았다. 항목은 다섯 줄이다: ① 믹스에 사용한 아이템 배지는 사라져요(아이템 칸이 있는 레시피만, 이전에 버튼 아래 한 줄로 있던 `burnNotice`를 옮김), ② 액티비티·체크인 배지는 보유 여부만 확인하고 사라지지 않아요(그 칸이 있는 레시피만), ③ 잠긴 아이템 배지는 믹스에 사용할 수 없어요, ④ 인벤토리에 빈칸이 모자라면 결과를 바로 받지 못하고 비운 뒤 믹스 화면에서 받을 수 있어요, ⑤ 받지 않은 결과가 남아 있으면 새로 믹스할 수 없어요.
- 확률·결과가 갈리는 내용(실패 시 포인트, 보상 확률)은 싣지 않았다. 항목은 모두 믹스 정책(`docs/service/content/COMBINE_RECIPES.md` §1)과 화면 규칙(잠긴 개체 제외, 받지 않은 결과 막힘)에서 확인한 사실이다.
- 관련 파일: `jam-web/src/app/(main)/combine/CombineClient.tsx`(CTA 영역 아래 `<section>`, `hasKeptSlot`), `jam-web/src/lib/i18n/ko.ts`(`combine.notice`, `combine.burnNotice` 문구를 목록 항목에 맞게 «믹스에 사용한 아이템 배지는 사라져요.»로 고침).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 레시피 상세의 믹스하기 버튼 아래에 «유의사항» 제목과 점 목록이 보인다.
- 확률·확률 안내·실패 시 보상 문구가 없다.
- 버튼 아래의 한 줄 재료 소각 안내는 목록 첫 항목으로 옮겨져 중복되지 않는다.

## 완료 기록

- **검증(로컬 개발 서버, 430×800)**: 믹스 레시피 상세에서 구역이 화면 폭 전체(0~430px)로 그려지고, 제목 `rgb(23, 23, 23)`·본문 14px `rgb(102, 102, 102)`임을 측정했다. 띠 바탕은 `rgb(229, 229, 229)`, 서비스 열 바탕은 `rgb(240, 240, 240)`이다(본문 글자와의 대비는 약 4.5:1). 항목 4개가 보였고(이 레시피는 아이템 칸만 있어 액티비티·체크인 줄은 없었다), 눈으로 확인했다. 믹스·i18n 시험 319건, eslint 통과.
- **확인하지 못한 것**: 액티비티·체크인 칸이 있는 레시피에서 둘째 항목이 보이는 모습, 어두운 테마, 바닥 탭바와 겹치는 높이.
- **알아 둘 점**: 이전에 버튼 아래 가운데 정렬 한 줄이던 재료 소각 안내(티켓 20260924_0813, 20261110_1105)는 목록 첫 항목으로 합쳐 따로 그리지 않는다. 문구는 «사용한 배지는 사라져요.»에서 «믹스에 사용한 아이템 배지는 사라져요.»로 늘렸다. 항목 문구는 사용자 확인 전의 초안이다.
- **후속 지시 3건(같은 날, 사용자)**:
  1. **유의사항과 푸터 사이 공백**: 레시피 상세에서 유의사항 구역 아래로 서비스 열 바탕색(`#f0f0f0`)의 빈 면이 보였다. 레시피 상세일 때만 루트를 `min-h-dvh`로 두고(`min-h-full`은 부모 높이가 정해지지 않아 풀리지 않는다) 유의사항 `<section>`에 `flex-1`을 주어 같은 회색(`#e5e5e5`)이 푸터 윗변까지 이어지게 했다. 믹서 슬롯 그리드 래퍼의 `flex-1`은 남는 높이를 나눠 갖지 않도록 걷었다(버튼 위치는 그대로).
  2. **배지 이름 밑줄 제거**: `RecipeRewardRow`의 제목 링크(`linkBadge`)에서 `underline underline-offset-2`를 뺐다. 링크 동작은 그대로다. 시험은 «밑줄 없음»을 확인하도록 고쳤다.
  3. **인벤토리의 믹스하기 버튼**: 레시피 상세의 믹스하기 버튼과 같은 `GachaMachineIcon`(20px, `gap-2`)을 글자 앞에 붙이고, 버튼 줄을 `justify-end`에서 `justify-center`로 바꿔 가로 중앙에 두었다. 버튼 색은 그대로(흰 바탕).
- **후속 검증(로컬 430×900)**: 레시피 상세에서 유의사항 구역 아래끝과 푸터 윗변이 같은 높이(900px)이고 구역 바탕이 `rgb(229, 229, 229)`임을 측정하고 눈으로 확인했다. 배지 제목 링크의 `text-decoration-line`은 `none`이다. 인벤토리 버튼은 열 중심과 버튼 중심이 0px 차이이고 아이콘이 20×20px, 글자와 같은 색(`rgb(23, 23, 23)`)이다. 믹스·인벤토리 시험 320건, 변경 파일 eslint 통과.
- **확인하지 못한 것(후속)**: 레시피 목록·등급 올리기 화면에서 루트 높이 변경이 없는지는 코드로만 확인했다(조건이 레시피 상세일 때만 켜진다). 내용이 화면보다 긴 작은 휴대폰에서 푸터와 맞닿는 모습.
