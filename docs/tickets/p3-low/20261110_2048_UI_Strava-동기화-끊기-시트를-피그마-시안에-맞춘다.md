# [UI] Strava 동기화 끊기 시트를 피그마 시안에 맞춘다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-10): 피그마 파일 `asset`(`UXcBEgFagmO5ARwH5F0mMW`)의 시안 노드 `52:28`(01 Strava 동기화 끊기)을 참고해 시트를 바꾼다. 토큰 값은 JAM! 디자인시스템에서 비슷한 것을 고른다.
- 시안과 코드의 차이는 두 가지였다. ① 제목: 16px 보통 굵기 → 20px 굵은 글씨(행간 24px). 디자인시스템 토큰 `text-xl`, `font-bold`, `leading-6`을 `BottomSheet`의 `titleClassName`으로 넘겼다. 헤더 여백(`px-6 pb-4`), 본문 여백(`px-4 py-6`), 버튼(취소 secondary, 동기화 끊기 danger, `px-3`, 간격 16), 푸터 아래 여백(탭바 위 92px)은 시안과 이미 같아서 건드리지 않았다. ② 본문: 네 문단 → 두 문단(«끊으면 새 활동이 배지에 반영되지 않아요.», «계정의 컨텐츠는 그대로 남아요.»).
- 알아 둘 점: 시안에서 아래 두 안내가 빠졌다. «다만 마지막 위치와 활동에 담긴 좌표는 지워져요.»(위치정보 수집 동의 철회 안내, 티켓 20261021_1249 4회), «Strava의 앱 목록에서도 JAM!이 빠져요. 다시 동기화하면 …». 서버 동작(좌표 삭제, 마이그레이션 265)은 그대로이고 화면 안내만 사라졌다. 법적 고지 성격이 있으면 문구를 되살려야 하므로 사용자 확인이 필요했고, 사용자가 «시안대로 유지»로 결정했다(2026-11-10).
- 연장(같은 날, 사용자): ① 시안을 다시 확인하니 첫 문단이 «끊으면 활동이 반영되지 않아요.»로 바뀌어 있어 그대로 반영했다. ② 시안의 스크림이 회색(#929292, 50%)으로 바뀌어 있었으나 `--backdrop`은 검정 50%를 유지하기로 했다(사용자 결정, 회색이면 시트와 뒤 화면 경계가 약 1.8:1로 흐려져 티켓 20261015_2133의 3.94:1 기준을 깬다). ③ 바텀시트 디자인 가이드로 «제목은 크고 굵게»를 정했다: `BottomSheet`의 기본 제목을 `text-xl font-bold leading-6`(20px·굵게·행간 24px)으로 올려 시트 전체에 적용하고, MODULAR `BottomSheet.jsx`도 같은 값(`--text-xl`·700·`--spacing-24`)으로 맞췄다. 개별 시트의 제목 지정은 줄바꿈 클래스를 더하는 `PendingResultsSheet`(`TITLE_CLASS`도 같은 서체로 맞춤)와 배지 이름이 제목인 `ItemCandidateSheet`(`text-2xl font-bold`, 이전 `font-medium`)만 남는다. 가이드 문장은 `docs/plan/jam2/11 JAM 2.0 디자인 시스템.md` 5.6절에 적었다.
- 관련 파일: `jam-web/src/lib/i18n/ko.ts`(`stravaConnection.disconnectSheet.body`), `jam-web/src/components/ui/BottomSheet.tsx`(`TITLE_CLASS_DEFAULT`), `jam-web/design-system/components/navigation/BottomSheet.jsx`, `jam-web/src/components/ui/__tests__/bottomSheetFaces.test.tsx`, `jam-web/src/components/strava/StravaDisconnectSheet.tsx`, `jam-web/src/components/strava/StravaSheets.test.tsx`.
- 담당 에이전트: 오케스트레이터(경미 수정 경로, 시험 파일 포함 3개).

## 완료 조건

- 시트 제목이 20px 굵은 글씨로 보이고, 본문이 두 문단이다.
- 취소·동기화 끊기 버튼과 여백이 시안과 같다.
- 관련 시험이 통과한다.

## 완료 기록

- **검증**: 끊기 시트·Strava 문구 시험 포함 99건 통과, 변경 파일 eslint 통과. 연장 뒤에는 시트·i18n·믹스·컬렉션 시험 856건 통과, eslint 통과, `npm run ds:check` 종료 코드 0(`BottomSheet` 쌍은 기존과 같은 △ 해석 불가 경고). 어드민 시험(`src/components/admin`) 수백 건이 실패하는데 이 변경을 되돌려도(stash) 같게 실패해 기존 문제다.
- **하지 않은 것**: 파이프라인(아현·민지·채원)은 돌리지 않았다(리뷰 브랜치 push가 필요해 «요청 전에는 push하지 않는다» 지시와 부딪힘). `tsc` 전체 검사는 메모리 오류로 끝나지 않았다. 시트별 실제 화면 확인도 못 했다.
- **확인하지 못한 것**: 실제 화면 렌더링. 시트가 프로필 편집의 Strava 동기화 상태에서만 열려서 눈으로 확인하지 않았다. 20px 제목이 긴 제목에서 두 줄이 되는 모습도 보지 못했다.
