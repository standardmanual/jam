# [UI] 스트라바 연동이 끊긴 배지의 공유를 막지 않고 배지 이미지만 공유한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 배지 상세의 «공유하기»가 스트라바 동기화가 끊기면 막혀 있었다. 이 경우 스트라바 데이터로 만드는 이미지는 빼고 배지 이미지만 공유할 수 있게 한다.
- 변경: `BadgeShareButton`에서 «스트라바 끊김 → 버튼 비활성·팝오버» 분기를 걷었다. 끊긴 activity/poi 배지는 시트에 «배지 이미지만» 한 장만 놓고(`BADGE_ONLY_KINDS`), 공유 카드를 만드는 효과와 `share-data` 호출을 건너뛴다. 연동돼 있거나 아이템 배지는 그대로 두 장(공유 카드·배지 이미지)이다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/BadgeShareButton.tsx`(`cardAvailable`, `shareKinds`, 카드 생성 효과), `docs/service/prd/badge-share/PRD.md`(스트라바 연동 해제 절).
- 서버 `share-data` API의 `strava_disconnected` 응답과 문구(`d.badges.shareErrorStravaDisconnected*`)는 그대로다(시트를 연 뒤 토큰 갱신이 실패하는 경우에 쓰인다).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 스트라바 연동이 없는 계정의 획득한 activity 배지에서 공유하기 버튼이 눌리고(흐리지 않다) 시트가 열린다.
- 시트에는 «배지 이미지만» 한 장만 있고, 공유·저장 버튼이 나온다. `share-data` 요청이 나가지 않는다.
- 연동된 계정과 아이템 배지는 공유 카드·배지 이미지 두 장이 그대로 보인다.

---
## 완료 기록

- **검증(로컬 개발 서버, 430×900)**: 스트라바 연결 기록이 없는 테스트 계정(3332)의 획득한 activity 배지 상세에서 버튼이 활성(`aria-disabled` 없음, 투명도 1)이고, 눌렀을 때 시트에 «배지 이미지만» 그룹 하나만 있으며 공유하기·저장하기 버튼이 나왔다. `share-data` 요청은 없었다. 타입 검사와 eslint 통과.
- **확인하지 못한 것**: 연동된 계정에서 두 장이 그대로 나오는 모습(코드상 `cardAvailable`이 참이라 분기가 달라지지 않는다), 실기기의 OS 공유시트. 이 컴포넌트에는 시험이 없어 시험을 더하지 않았다.
- **알아 둘 점**: 시트에 한 장뿐이라 캐러셀은 한 칸으로 보인다. 연동이 끊긴 배지에서는 스트라바 기록(거리·페이스·시간)이 들어간 카드를 만들 수 없고, 레벨·횟수만 든 카드도 만들지 않는다.
