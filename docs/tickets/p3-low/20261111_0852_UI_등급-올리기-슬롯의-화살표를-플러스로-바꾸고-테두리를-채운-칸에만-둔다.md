# [UI] 등급 올리기 슬롯의 화살표를 «+»로 바꾸고 테두리를 채운 칸에만 둔다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 등급 올리기 페이지의 슬롯에서 (1) 표시된 화살표를 «+»로 바꾼다. (2) 슬롯에 넣지 않은 상태에 있던 외곽선을, 믹스 레시피 슬롯처럼 넣은 뒤에 표시되도록 바꾼다.
- 변경: 등급 올리기가 쓰는 MODULAR `MixerSlot`을 고쳤다. 빈 칸(`empty`)은 가운데 아래 화살표 대신 «+» 아이콘을 그리고 3px 그레이 테두리를 없앴다. 채운 칸(`filled`)에는 레시피 믹서의 채운 칸(`RecipeSlotCard`)과 같은 3px 그레이(`--muted`) 안쪽 테두리를 `box-shadow: inset`으로 더했다(칸 크기·이미지 위치를 밀지 않는다). 잠긴 칸(`locked`)은 그대로다(점선·흐린 «+»).
- 관련 파일: `jam-web/design-system/components/patterns/MixerSlot.jsx`(`baseStyle.border`·`boxShadow`, `fillable` 아이콘), `MixerSlot.d.ts`(`status` 주석), `MixerSlot.stories.tsx`(Empty·Filled 스토리 설명과 검증). `MixerSlot`을 쓰는 곳은 등급 올리기(`TierUpPanel.tsx`) 하나뿐이라 서비스 쪽 코드는 바꾸지 않았다.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 빈 슬롯에 «+»가 보이고 화살표와 외곽선이 없다.
- 슬롯에 배지를 넣으면 3px 그레이 외곽선이 생긴다(레시피 믹서의 채운 칸과 같은 값).
- 잠긴 슬롯과 칸 크기(3열 정사각)는 그대로다.

---
## 완료 기록

- **검증(로컬 개발 서버, 430×900)**: 등급 올리기 화면에서 빈 슬롯 6칸이 모두 «+» 경로를 그리고 `border 0`·`box-shadow none`임을 측정했고 눈으로 확인했다. 첫 칸에 재료를 담자 그 칸만 `box-shadow: rgb(102, 102, 102) 0 0 0 3px inset`이 생겼고, 칸 크기는 빈 칸과 같은 127×127px이다. 믹스·DS 색 시험 344건, 타입 검사, 변경 파일 eslint(기존 `<img>` 경고만) 통과.
- **확인하지 못한 것**: 잠긴 슬롯(재료가 하나도 없는 계정) 화면, 스토리북에서 Empty·Filled 스토리 실행(스토리에 단언을 더했지만 돌려 보지 않았다), 설치된 MODULAR 업로드본(claude.ai/design)과의 동기화.
- **알아 둘 점**: 빈 슬롯의 «+»는 가운데에 있고 레시피 믹서의 «+»는 카드 오른쪽 위 원 버튼이라 모양이 다르다. 이번 지시는 테두리 규칙과 화살표 교체까지였다. MODULAR 사본·업로드본 동기화는 `/jam-ds`로 따로 맞춰야 한다.
