# [Feature] 컬렉션 등급 미정에서도 후보가 1개면 시트 없이 바로 장착한다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 컬렉션 상세에서 4등급 컬렉션의 등급이 아직 정해지지 않았을 때도 바텀시트를 띄우지 않는다. 컬렉션 등급은 첫 아이템 배지의 등급으로 정해진다.
- 변경: `shouldOpenCandidateSheet(candidateCount)`가 `candidateCount !== 1`만 본다(이전에는 `tierUndecided || candidateCount !== 1`). 후보가 1개면 등급이 정해졌든 아니든 바로 장착하고, 2개 이상이면 시트를 열어 일련번호를 고르게 한다. 호출부 `SlotGrid.handleSlotButton`의 인자도 맞췄다.
- 정하지 않은 것: 후보가 2개 이상인 등급 미정 칸은 어느 개체를 꽂을지 정해야 해서 시트를 그대로 둔다(등급 칩·일련번호와 «처음 장착하는 배지의 등급이…» 안내문 포함). 시트 없이 두 개 중 하나를 자동으로 고를 수는 없다.
- 관련 파일: `jam-web/src/lib/itembook/tier-badge-slots.ts`(`shouldOpenCandidateSheet`), `jam-web/src/app/(main)/collections/[id]/SlotGrid.tsx`(`handleSlotButton`), `jam-web/src/lib/itembook/__tests__/tier-badge-slots.test.ts`, `jam-web/src/lib/i18n/ko.ts`(`selectTierBody` 주석), `docs/service/prd/02_DATA_MODEL.md`(컬렉션 상세 칸, 등급 없음 문단).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 컬렉션 등급이 없는 칸에서 «+»를 눌렀을 때 후보가 1개면 시트 없이 바로 장착된다.
- 후보가 2개 이상이면 이전처럼 시트가 열린다.
- 등급이 정해진 뒤의 동작은 그대로다.

---
## 완료 기록

- **검증**: 판정 시험을 새 규칙으로 고쳐(1개 → 바로 장착, 2·3개 → 시트) 컬렉션·문구·정책 시험 440건, 변경 파일 eslint, 타입 검사 통과. 바로 장착 경로(`handleSlot` → `requestSlot`)와 시트 선택 경로(`handleSelectCandidate` → `requestSlot`)가 같은 요청이라 서버 규칙은 달라지지 않는다.
- **확인하지 못한 것**: 실제 화면에서 눌러 보지 않았다. 공용 DB에 장착 기록이 남는 조작이라 로컬 테스트 계정으로도 하지 않았다. 장착 직후 칸이 등급 칸으로 바뀌는 모습(칸 `key`를 `cellKey`로 둔 기존 장치가 처리)은 이전 시트 경로와 같은 흐름이다.
- **알아 둘 점**: 이전 승인(2026-10-28, 티켓 20261028_1408)은 «첫 장착이 되돌릴 수 없으니 등급 칩과 일련번호를 확인하게 한다»였다. 이번 지시로 후보가 1개면 확인 없이 바로 등급이 정해진다. 모두 빼면 등급이 풀리는 규칙은 그대로다.
