# [UI] 컬렉션·인벤토리의 진행도 바 채움을 강조색 그린으로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 컬렉션 목록, 컬렉션 상세, 인벤토리 페이지의 진행도 바 색을 강조색 중 그린으로 한다.
- 변경: 강조색 5가지 중 `--jam-green`(#5BEA07)을 채움 색으로 넘겼다. 컬렉션 상세와 인벤토리는 공용 `ProgressCountBar`(`<ProgressBar color="var(--jam-green)">`), 컬렉션 목록은 `CollectionGridCard`의 바가 쓴다. 디자인 시스템 사본 `CollectionGridCard`도 같은 색으로 맞췄다. 트랙(`--border`)과 «n/n» 수치(`--link`)는 그대로다. 공용 `ProgressBar`의 기본 채움(`--accent`)은 바꾸지 않아 미션·온보딩·랭킹 등 다른 화면의 바는 그대로 검정이다.
- 토큰 주석: `colors.css`의 «강조색 5가지: 정의만 한다, 소비처 없음»을 «사용처는 사용자가 따로 지정, 지정된 사용처: `--jam-green` = 진행도 바 채움»으로 고쳤다. `Colors.stories.tsx`의 칩 설명과 섹션 제목도 맞췄다.
- 관련 파일: `jam-web/src/components/ui/ProgressCountBar.tsx`, `jam-web/src/components/ui/CollectionGridCard.tsx`, `jam-web/design-system/components/patterns/CollectionGridCard.jsx`·`.prompt.md`, `jam-web/design-system/tokens/colors.css`, `jam-web/design-system/foundations/Colors.stories.tsx`.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 컬렉션 목록 카드, 컬렉션 상세, 인벤토리의 진행도 바 채움이 그린(`rgb(91, 234, 7)`)이다.
- 다른 화면(미션·온보딩·랭킹)의 바 색은 그대로다.

## 완료 기록

- **검증(로컬 개발 서버, 430×900)**: 인벤토리(높이 16px), 컬렉션 목록(`/badges#collection`, 카드 9장 모두 12px)과 컬렉션 상세(16px) 세 곳에서 채움의 계산 색이 `rgb(91, 234, 7)`임을 측정했고 목록과 인벤토리는 눈으로도 확인했다. `ds:check` 통과(종료 코드 0, 기존 «미해석 클래스» 안내만 남음), 변경 파일 eslint 오류 없음. 비어드민 시험은 모두 통과했다(`src/components`의 어드민 시험 29개 파일은 기존 «Invalid hook call» 문제로 실패하며 이번 변경과 무관하다, 티켓 20261110_1157).
- **확인하지 못한 것**: 어두운 테마, 실기기 색 재현, 스토리북에서 `CollectionGridCard`·Colors 스토리 화면.
- **알아 둘 점**: 그린 `#5BEA07`은 트랙(`--border` #e5e5e5)과의 명도 대비가 약 1.5:1로 낮다. 면이 채워지는 양은 이 바 옆의 «n/n» 수치로도 읽힌다. 컬렉션 완성 카드(100%)의 바도 같은 그린이다. 이전 규칙의 «정의만, 사용처 미지정» 표기는 그린에 한해 지웠고 나머지 네 강조색(red·yellow·purple·blue)은 그대로 미지정이다.
