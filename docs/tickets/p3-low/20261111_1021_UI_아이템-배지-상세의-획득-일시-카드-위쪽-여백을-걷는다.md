# [UI] 아이템 배지 상세의 획득 일시 카드 위쪽 여백을 걷는다

## 핵심 요약

- 문의(사용자, 2026-11-11): 232 계정의 아이템 배지 상세에서 획득 일시가 두 번 보이는 이유, 그리고 «획득 일시» 위의 여백이 너무 넓다.
- **두 번 보이는 이유(버그가 아니다)**: 같은 배지를 두 개 가진 계정이다. 232 계정의 「길거리 뻥튀기」는 개체가 둘이다. 위의 카드는 화면 위쪽 일련번호(UMOM684073)가 가리키는 개체의 획득 일시(2026-11-10 13:28:08)이고, 아래 화살표 줄은 다른 개체(MAVL670661, 컬렉션에 장착 중)의 획득 일시(2026-10-29 02:23:20)다. 눌러 열면 그 개체의 획득·만료 일시가 시트로 열린다(`ItemEarnHistory`의 «2번째부터» 줄). 두 줄이 같은 일시가 아니라 서로 다른 개체의 일시다.
- 변경: `ItemEarnHistory`의 카드 안 행 묶음을 `-mb-3`에서 `-my-3`으로 바꿔 위쪽 여백도 걷었다. 행(`ListRow`)은 위아래 12px 안쪽 여백이 있는데, 이 카드는 제목이 카드 밖이라 위쪽 12px이 걷히지 않고 아래쪽만 걷혀 위가 더 넓었다. 활동·체크인 배지의 «획득 정보» 카드는 제목이 카드 안이라 이전 그대로다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/ItemEarnHistory.tsx`(`ItemCardContent`).
- 함께 고친 것: 이전 변경(티켓 20261111_0801, 스트라바 끊김 공유)이 깨뜨린 시험 하나(`notEarnedCard.test.ts`의 «공유 시트의 미획득 안내» 기대 문자열)를 새 코드에 맞게 고쳤다.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 아이템 배지 상세의 획득 일시 카드에서 글자 위아래 여백이 같다.
- 시트 안의 같은 행 묶음(`inSheet`)과 활동·체크인 배지 상세는 그대로다.

## 완료 기록

- **검증(로컬 개발 서버, 430×900, 232 계정 = 로컬 테스트 로그인 계정)**: 카드 윗변에서 «획득 일시» 글자까지 17px, 글자에서 아랫변까지 17px로 위아래가 같다(이전에는 사용자 화면 기준 위가 아래보다 약 16px 넓었다). DB에서 같은 배지의 개체가 둘(UMOM684073, MAVL670661)이고 획득 시각이 화면의 두 값과 같음을 확인했다. 배지 화면 시험 67건 통과.
- **확인하지 못한 것**: 만료일이 있는 아이템 배지(행이 둘인 카드), 실기기.
- **알아 둘 점**: 두 번째 줄이 날짜만 보여 같은 정보가 두 번 나오는 것처럼 읽힌다. 어느 개체인지 구분하려면 줄에 일련번호나 «장착 중» 표시를 더하는 방법이 있다(이번 지시 범위 밖이라 하지 않았다).
