# [UI] 드랍 지도에서 배지가 있는 지점 마커를 강조색 그린으로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 드랍 메뉴의 지도 위 체크인 지점 중 배지가 있는 지점의 마커 색을 강조색 그린으로 한다.
- 변경: `MapView`의 지점 마커(`dropMarkerIconHtml`)에서 «픽업할 드랍이 있는 지점»(`hasDrops`)의 면을 `--accent`(검정)에서 `--jam-green`(#5BEA07)으로 바꿨다. 밝은 그린 위에서 흰 아이콘은 보이지 않아 아이콘은 `--foreground`(검정)로 바꿨다. 드랍이 없는 지점은 그대로 회색(`--muted` 면 + 흰 선 아이콘)이고, 드랍 범위 밖은 같은 색에 반투명(0.5)이다. 색은 `DROP_MARKER_ACTIVE_BG`·`DROP_MARKER_ACTIVE_GLYPH` 상수 두 개로 모았다.
- 온보딩 연출의 정지 마커(`QuestPickupScene`)는 «실제 드랍 마커와 같은 모양»이라는 약속(사용자 결정 2026-09-28)이 있어 같은 상수를 쓰게 함께 바꿨다.
- 안 바꾼 것: 개별 체크인 배지 이미지 마커(`badgeMarkerIconHtml`, 배지 그림 자체)와 클러스터 마커(`--accent` 그라데이션). 지시는 «배지가 있는 지점의 마커»였고 두 마커는 배지 그림과 개수 표시라 지점 마커와 다른 요소다.
- 관련 파일: `jam-web/src/components/map/MapView.tsx`(`DROP_MARKER_ACTIVE_*`, `dropMarkerIconHtml` 내보냄), `jam-web/src/app/(main)/drops/QuestPickupScene.tsx`, `QuestPickupScene.test.tsx`(색 시험 2건 추가).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 드랍이 있는 지점의 마커 면이 그린(`rgb(91, 234, 7)`)이고 아이콘이 검정이다.
- 드랍이 없는 지점은 회색 마커 그대로다.
- 온보딩 연출의 마커도 같은 색이다.

---
## 완료 기록

- **검증(로컬 개발 서버)**: 지도 자체는 로컬 브라우저에서 위치 권한을 받지 못해(«위치 권한을 허용해 주세요») 열리지 않았다. 대신 마커 HTML을 같은 크기로 화면에 직접 그려 계산 색을 확인했다: 드랍 있음 면 `rgb(91, 234, 7)`·아이콘 `rgb(23, 23, 23)`, 드랍 없음 면 `rgb(102, 102, 102)`·아이콘 `rgb(252, 252, 252)`, 범위 밖은 그린 반투명. 눈으로도 확인했다. 드랍 화면 시험 26건(색 시험 2건 추가), 변경 파일 eslint 통과.
- **확인하지 못한 것**: 실제 네이버 지도 위에서의 모습(지도 타일 위 그린의 가독성), 선택된 마커(26px 확대) 모양, 어두운 테마.
- **알아 둘 점**: 밝은 그린 위의 아이콘이 검정이라 이전의 «검은 원 + 흰 아이콘»에서 «그린 원 + 검은 아이콘»으로 바뀐다. 지도 타일이 밝은 연두·초록 계열인 곳(공원 등)에서는 마커가 묻힐 수 있으니 실기기에서 확인이 필요하다.
