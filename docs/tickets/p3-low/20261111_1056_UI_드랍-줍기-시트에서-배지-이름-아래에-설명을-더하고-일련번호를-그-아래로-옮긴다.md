# [UI] 드랍 줍기 시트에서 배지 이름 아래에 설명을 더하고 일련번호를 그 아래로 옮긴다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 체크인 지점(드랍 지도)에서 배지를 고르면 열리는 바텀시트(`BadgeDetailSheet`)에서 배지 이름 아래에 배지 설명을 추가하고, 그 아래로 일련번호를 옮겨 보인다.
- 변경: (1) `/api/drops/poi/[poiId]`가 `badges.description`을 같이 조회해 `badge_description`으로 내려 준다. 잠긴 개체의 응답에는 싣지 않는다(이름·그림과 같은 이유). (2) `BadgeDetailSheet`가 이름·등급 칩 아래에 설명을 문장 단위(`splitDescriptionSentences`, 배지 상세의 히어로와 같은 방식)로 muted 글자로 그리고, 그 아래에 일련번호(`ItemSerialCode`, 높이 40)를 놓는다. 장소 이름·드랍한 사람 카드는 일련번호 아래로 그대로 있고 카드 안의 일련번호와 구분선은 없앴다. 잠긴 개체는 설명도 일련번호도 그리지 않는다.
- 관련 파일: `jam-web/src/app/api/drops/poi/[poiId]/route.ts`(select·`PoiDropRow`·열린 개체 응답), `jam-web/src/app/(main)/drops/BadgeDetailSheet.tsx`(`PickupDrop.badge_description`, 헤더 영역), `BadgeDetailSheet.test.tsx`(4건 추가), `docs/service/prd/inventory/PRD.md`(줍기 시트 구성).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 열린 개체 시트에서 이름 아래에 배지 설명이 문장 단위로 보이고, 그 아래에 일련번호, 다음에 장소·드랍한 사람 카드가 온다.
- 설명이 없는 배지는 설명 줄 없이 일련번호가 이름 아래에 온다.
- 잠긴 개체에는 설명·일련번호가 DOM에 없다.

## 완료 기록

- **검증(로컬 개발 서버, 430×900)**: 지도는 위치 권한 때문에 로컬에서 열리지 않아, 임시 페이지(확인 뒤 삭제)에 샘플 개체로 시트를 직접 그려 눈으로 확인했다: 이름 → 설명 두 줄(muted, 가운데) → 일련번호 → 장소·드랍한 사람 카드 → 취소·픽업 순이다. 시트 시험 4건 추가(설명 위치, 일련번호가 설명 아래·카드 위, 설명 없음, 잠긴 개체 비노출), 드랍·API 시험 30건과 변경 파일 eslint 통과.
- **확인하지 못한 것**: 실제 드랍 데이터로 내려오는 `badge_description`(API 응답을 호출해 보지 않았다, 쿼리는 컬럼 하나를 더한 것), 설명이 긴 배지에서 작은 화면의 스크롤, 어두운 테마.
- **알아 둘 점**: `/api/drops/[dropId]`(단건 조회)와 온보딩 연출 데이터(`toDemoDroppedPickup`)는 설명을 싣지 않아 그 경로로 여는 시트에는 설명이 없다(필드가 선택이라 깨지지 않는다). 일련번호가 이름 바로 아래로 올라가면서 시트가 이전보다 위쪽이 길어졌다.
