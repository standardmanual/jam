# [UI] 탭 최상위 화면의 상단 로고를 한글 탭 이름으로 바꾸는 시안

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 배지·드랍·미션·인벤토리 페이지의 상단 내비게이션에서 로고를 빼고 한글 텍스트 «배지·체크인·미션·인벤토리»를 적용한다. 크기와 굵기는 우선 오케스트레이터가 정해 **시안을 먼저 보여 주고**, 사용자의 확인(필요하면 크기·굵기 조정) 뒤에 확정한다.
- 시안 값: 24px(`text-2xl`), 굵게(700), 줄 높이 1, 글자색 `--foreground`, 한글 글자 중심을 맞추려고 1px 올림. 글자 왼쪽은 화면 여백과 같은 16px에 놓인다(로고 높이 26px과 비슷한 시각 크기).
- 구현: `TopNav`에 `logoText` prop을 더했다. `logo`와 함께 쓰고, 값이 있으면 로고 링크 대신 글자만 그린다(눌리지 않는다, 이동은 하단 탭바). 값이 없으면 지금처럼 로고라 홈·내 프로필은 그대로다. 배지(`d.badges.title`), 미션(`d.missions.title`), 인벤토리(`d.inventory.title`)는 기존 문구를 쓰고, 드랍 화면용 `d.drops.screenTitle`(«체크인»)을 새로 더했다. 드랍 화면의 TopNav 두 곳(온보딩 연출 포함)에 적용했다.
- 관련 파일: `jam-web/src/components/ui/TopNav.tsx`(`logoText`), `BadgesClient.tsx`, `MissionsListClient.tsx`, `inventory/page.tsx`, `drops/DropsClient.tsx`, `lib/i18n/ko.ts`(`drops.screenTitle`).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 네 화면 상단 왼쪽에 로고 대신 «배지», «체크인», «미션», «인벤토리»가 보인다.
- 홈과 내 프로필의 로고는 그대로다.
- 사용자가 시안(크기·굵기)을 확인하면 이 티켓을 닫는다.

---
## 시안 확인 기록

- 로컬 개발 서버(430px)에서 배지·미션·인벤토리 화면을 실제로 열어 확인했다. 미션 화면 측정: 글자 24px/700, 왼쪽 16px, 세로 중심이 헤더 중심보다 1px 위. 배지·인벤토리는 눈으로 확인했다.
- 드랍(체크인) 화면은 로컬 브라우저가 위치 권한을 받지 못해 지도가 열리지 않아 헤더를 직접 보지 못했다. 같은 TopNav라 미션 화면의 글자를 «체크인»으로 바꿔 모양만 확인했다.
- TopNav·네 화면·문구 시험 420건, 변경 파일 eslint 통과.
- 아직 정하지 않은 것: 시안 크기·굵기 확정, 홈·내 프로필도 같은 방식으로 바꿀지, 하단 탭 이름(드랍 탭은 «JAM»)과 화면 위 이름(«체크인») 불일치.
