# [UI] 탭 최상위 화면의 상단 로고를 한글 탭 이름으로 바꾸는 시안

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 배지·드랍·미션·인벤토리 페이지의 상단 내비게이션에서 로고를 빼고 한글 텍스트 «배지·체크인·미션·인벤토리»를 적용한다. 크기와 굵기는 우선 오케스트레이터가 정해 **시안을 먼저 보여 주고**, 사용자의 확인(필요하면 크기·굵기 조정) 뒤에 확정한다.
- 시안 값(2차, 사용자 지시 2026-11-11): 첫 시안(글자만 24px)을 확정하려던 중 «텍스트 앞에 jam 로고를 추가하고, 텍스트는 크기를 줄여 로고와 밸런스를 맞추며, 헤더 세로 가운데에 놓는다»로 바뀌었다. 지금 값은 로고 높이 20px(폭 60px) + 간격 8px + 글자 18px 굵게(700)이고 글자색은 `--foreground`다. 로고는 홈 링크로 남고 글자는 누르지 않는다. 한글 글자 모양이 줄 상자 안에서 아래로 치우쳐 글자만 1px 올렸다. 로고(26px)는 홈·내 프로필에서만 지금 크기 그대로다.
- 구현: `TopNav`에 `logoText` prop을 더했다. `logo`와 함께 쓰고, 값이 있으면 로고(작게)와 글자를 한 줄에 함께 그린다(글자는 눌리지 않고 이동은 하단 탭바). 값이 없으면 지금처럼 로고만이라 홈·내 프로필은 그대로다. 배지(`d.badges.title`), 미션(`d.missions.title`), 인벤토리(`d.inventory.title`)는 기존 문구를 쓰고, 드랍 화면용 `d.drops.screenTitle`(«체크인»)을 새로 더했다. 드랍 화면의 TopNav 두 곳(온보딩 연출 포함)에 적용했다.
- 관련 파일: `jam-web/src/components/ui/TopNav.tsx`(`logoText`), `BadgesClient.tsx`, `MissionsListClient.tsx`, `inventory/page.tsx`, `drops/DropsClient.tsx`, `lib/i18n/ko.ts`(`drops.screenTitle`).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 네 화면 상단 왼쪽에 로고와 «배지», «체크인», «미션», «인벤토리»가 함께 보이고 둘 다 헤더 세로 가운데에 놓인다.
- 홈과 내 프로필의 로고는 그대로다.
- 사용자가 크기·굵기를 확정했다(2026-11-11): 로고 높이 20px + 간격 8px + 글자 18px 굵게.

## 완료 기록 (시안 확인 후 확정)

- 로컬 개발 서버(430px)에서 확인했다. 2차 시안 미션 화면 측정: 로고 60×20px(왼쪽 16px, 세로 중심 28px), 글자 18px/700(왼쪽 84px, 세로 중심 27px), 헤더 중심 28px. (1차 시안: 글자만 24px/700.)
- 드랍(체크인) 화면은 로컬 브라우저가 위치 권한을 받지 못해 지도가 열리지 않아 헤더를 직접 보지 못했다. 같은 TopNav라 미션 화면의 글자를 «체크인»으로 바꿔 모양만 확인했다.
- TopNav·네 화면·문구 시험 420건, 변경 파일 eslint 통과.
- 확정: 사용자가 2차 시안(로고 20px + 글자 18px)을 그대로 확정했다.
- 정하지 않고 남긴 것: 홈·내 프로필을 같은 방식으로 바꿀지(지금은 로고만), 하단 탭 이름(드랍 탭은 «JAM»)과 화면 위 이름(«체크인»)이 다른 점, 체크인 화면의 실제 헤더 확인(로컬에서 위치 권한이 없어 지도가 열리지 않았다).
