# [UI] 컬렉션 목록 카드의 완성 칩과 등급 칩을 일반 등급 칩 크기로 키운다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 컬렉션 목록 카드의 «완성» 칩 크기를 등급 칩과 같게 한다.
- 확인한 사실: 목록 카드의 완성 칩은 이미 같은 카드의 등급 칩(`RarityBadge` sm: 글자 8px, 패딩 4px 9px, 높이 16px)과 같은 크기였다(2026-11-09 티켓 20261109_1019에서 맞춤). 그래서 어느 «등급 칩» 크기를 말씀하신 것인지 물었고, 사용자가 **일반 등급 칩(`RarityBadge` md)으로 키우기**를 골랐다.
- 변경: 완성 칩과 같은 카드의 등급 칩을 함께 md로 키웠다: 글자 12px(`--text-xs`), 패딩 5px 10px, 줄 높이 1(높이 22px). 둘이 계속 같은 크기다. 서비스 카드(`CollectionGridCard.tsx`)와 디자인 시스템 사본(`CollectionGridCard.jsx`의 `TAG_STYLE`, 등급 칩 `size="md"`)에 같은 값을 적용했다.
- 관련 파일: `jam-web/src/components/ui/CollectionGridCard.tsx`, `jam-web/design-system/components/patterns/CollectionGridCard.jsx`, `jam-web/src/components/ui/__tests__/CollectionGridCard.tagOrder.test.tsx`(크기 시험 2건을 md 기준으로 고침).
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- 컬렉션 목록 카드의 완성 칩이 글자 12px·높이 22px이다.
- 같은 카드의 등급 칩(`RarityBadge`)도 md라 완성 칩과 크기가 같다(서비스·MODULAR 둘 다).

---
## 완료 기록

- **검증(로컬 개발 서버, 430×900)**: 컬렉션 목록 카드의 완성 칩이 글자 12px, 패딩 5px 10px, 높이 22px임을 측정하고 눈으로 확인했다(이전 16px). 크기 시험이 서비스와 MODULAR 둘 다에서 완성 칩과 등급 칩의 글자·패딩·줄 높이가 같음을 확인한다. UI 시험 312건, `ds:check`, 변경 파일 eslint(기존 `<img>` 경고만) 통과.
- **확인하지 못한 것**: 등급 칩이 함께 있는 카드의 실제 모습(로컬 데이터에는 등급이 Common이라 칩이 그려지지 않았다), 폭 320px 2열에서 두 칩이 한 줄에 들어가는지(두 칩은 줄바꿈하도록 되어 있다), 컬렉션 상세의 슬롯 카드 안 등급 칩은 이미 md였다.
- **알아 둘 점**: 칩이 커져 썸네일 왼쪽 위를 이전보다 더 덮는다(높이 16 → 22px).
