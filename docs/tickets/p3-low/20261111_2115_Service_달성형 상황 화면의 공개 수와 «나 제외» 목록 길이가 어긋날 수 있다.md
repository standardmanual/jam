# [Service] 달성형 상황 화면의 공개 수와 «나 제외» 목록 길이가 어긋날 수 있다

## 핵심 요약

- 요구사항: 달성형은 서버가 `visible_rank_count`로 자른 뒤 클라이언트가 내 행을 빼서, 내가 공개 범위 안이면 목록이 하나 적게 나온다. 정확히 N명을 보일지, 지금 동작을 그대로 둘지 정한다.
- 구현 계획: (고친다면) API가 내 행을 먼저 빼고 자르게 하거나, 응답에 내 행 여부를 실어 클라이언트가 처리한다.

- 관련 파일: `jam-web/src/app/api/missions/[id]/status/route.ts`(달성형 분기), `jam-web/src/app/(main)/missions/[id]/status/MissionStatusClient.tsx`(달성형 블록)
