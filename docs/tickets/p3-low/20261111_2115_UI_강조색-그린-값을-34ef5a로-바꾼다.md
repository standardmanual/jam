# [UI] 강조색 그린 값을 #34ef5a로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시, 2026-11-11): 강조색 그린 값을 `#34ef5a`로 바꾼다. 이전 값은 `#5BEA07`이다.
- 변경: 토큰 `--jam-green`의 정의(`jam-web/design-system/tokens/colors.css`)와 디자인 시스템 목록의 같은 값(`jam-web/design-system/_ds_manifest.json`)을 바꿨다. 이 토큰을 쓰는 곳(컬렉션 목록·상세·인벤토리의 진행도 바 채움, 드랍 지도에서 배지가 있는 지점 마커, 온보딩 연출 마커)은 색값을 직접 적지 않고 `var(--jam-green)`을 읽어 코드 수정 없이 같이 바뀐다.
- 건드리지 않은 것: 옛 값이 적힌 지난 티켓(20261111_1005·1034, 20261107_2201)은 당시 기록이라 그대로 둔다. `ds:manifest`를 쓰기 모드로 돌리면 다른 세션이 더한 토큰(`--gap-actions`)까지 목록에 들어와서, 값 한 줄만 직접 고쳤다.
- 담당 에이전트: 오케스트레이터.

## 완료 조건

- `--jam-green`이 `#34ef5a`다.
- 진행도 바 채움과 지점 마커가 새 색(`rgb(52, 239, 90)`)으로 그려진다.

---
## 완료 기록

- **검증(로컬 개발 서버, 430×900)**: 인벤토리의 진행도 바 채움 계산 색이 `rgb(52, 239, 90)`이고 토큰 값이 `#34ef5a`임을 확인하고 눈으로도 봤다. `ds:check` 통과, 목록 파일은 JSON으로 읽힌다. 어드민을 제외한 UI·디자인 시스템 시험은 모두 통과했다(어드민 시험의 기존 «Invalid hook call» 실패는 이번 변경과 무관하다).
- **확인하지 못한 것**: 컬렉션 목록·상세와 지도 마커의 새 색을 화면에서 하나씩 보지는 않았다(같은 토큰을 읽는다). 어두운 테마.
- **알아 둘 점**: 새 그린은 더 밝고 채도가 높다. 지점 마커 안쪽 아이콘은 검정(`--foreground`)이라 대비는 계속 충분하다. 연한 회색 트랙과 바 채움의 명도 대비는 이전보다 약간 더 낮을 수 있다.
