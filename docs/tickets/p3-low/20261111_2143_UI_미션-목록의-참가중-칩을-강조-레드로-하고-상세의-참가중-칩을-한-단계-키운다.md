# [UI] 미션 목록의 «참가중» 칩을 강조 레드로 하고 상세의 «참가중» 칩을 한 단계 키운다

## 핵심 요약

- 요구사항: ① 미션 목록의 «참가중» 칩 색을 강조 레드로 한다. ② 미션 상세의 «참가중» 칩 크기를 한 단계 키운다(사용자 지시, 2026-11-11).
- 구현: ① `MissionsListClient.tsx` `topStatusLabel`의 `joined` 칩에 면 `--jam-red`·글자 `--foreground`를 준다(`ListRowChip`의 style 덮기, 다른 곳의 `done` 톤 칩은 그대로). ② `MissionDetailClient.tsx` 참가중 칩을 11px·좌우 10(`px-2.5`)에서 14px(`text-sm`, `--text-sm`)·좌우 12(`px-3`)로 키운다.
- 관련 파일: `jam-web/src/app/(main)/missions/MissionsListClient.tsx`(152~156행), `MissionsListClient.list-row.test.tsx`(103행), `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`(200~207행).

## 상세 요구사항

- 목록 칩 글자색: 12px 글자라 대비 4.5:1이 필요하다. `--snow`는 레드 면 위에서 약 3.7:1이라 `--foreground`(약 4.6:1)로 했다. 사용자가 글자색을 따로 정하지 않았다.
- 상세 칩의 색(`--accent` 면)은 그대로다. 색을 레드로 바꾸라는 지시는 목록 칩에만 있었다.
- «한 단계»는 글자 크기 눈금(--text-xs 12 → --text-sm 14)의 한 단계로 해석했다.

## 완료 조건

- 목록의 «참가중» 칩이 `--jam-red` 면이다. 완료·종료 칩은 그대로다.
- 상세의 «참가중» 칩이 14px로 커졌다.

### 주요 의사결정 / 핵심 메모
- 글자색은 대비 때문에 `--foreground`로 했다. `--snow`로 바꾸려면 사용자 결정이 필요하다(큰 글자가 아니면 4.5:1 미달).
- 상세 칩 크기는 14px 한 단계로 해석했다. 다른 크기를 원하면 알려야 한다.
