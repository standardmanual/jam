# [UI] 미션 상세의 «랭킹» 버튼을 «랭킹 보기»로 바꾸고 검정 면에 흰 글자로 한다

## 핵심 요약

- 요구사항: 미션 상세의 랭킹형 버튼 글자를 «랭킹»에서 «랭킹 보기»로 바꾸고, 색을 검정 면 + 흰 글자로 한다(사용자 지시, 2026-11-11).
- 구현: `ko.ts`의 `missions.statusViewButton`을 «랭킹 보기»로, `MissionDetailClient.tsx`의 버튼 면을 `bg-foreground`·글자를 `text-snow`(전에는 `bg-card-bg`·`text-muted`)로 바꾼다. 시험과 UX_WRITING_GUIDELINE 98행(진입 버튼 글자)도 맞춘다.
- 관련 파일: `jam-web/src/lib/i18n/ko.ts`, `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`(랭킹 보기 버튼 블록), `MissionDetailClient.test.tsx`, `docs/service/writing/UX_WRITING_GUIDELINE.md`.

## 완료 조건

- 랭킹형 미션 상세의 버튼이 검정 면·흰 글자의 «랭킹 보기»다.

- 리뷰 중인 미션 상황 개편 브랜치(`claude/jamwork-20261111_2049-mission-status-canvas`)도 같은 버튼 블록과 `statusViewButton` 키를 둘로 나누고 있어서, 그 브랜치를 머지할 때 이 변경과 충돌한다. 머지할 때 랭킹형 버튼은 «랭킹 보기»·검정 면·흰 글자로, 달성형 버튼도 같은 모양으로 맞춰 해결한다.
