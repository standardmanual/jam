# [UI] 미션 상세의 «나의 진행 상황» 카드를 강조 레드 면으로 한다

## 핵심 요약

- 요구사항: «나의 진행 상황» 카드 면을 강조 레드(`--jam-red`)로 하고 글자는 흰색과 검정, 회차 서클과 «달성» 칩은 검정 면에 흰 글자로 한다(사용자 지시, 2026-11-11). 직전 티켓 20261111_2158에서 «검정으로 되돌려라»를 카드 전체가 아니라 서클·칩만 가리키는 말로 읽고 카드 면까지 흰색으로 되돌린 것을 바로잡는다.
- 구현: `InfoCard`가 `style`을 받아 진행 상황 카드만 `background: var(--jam-red)`로 둔다. 수치형은 현재 값 `--snow`(22px 굵게, 큰 글자)·막대 채움 `--snow`·막대 빈 칸 `color-mix(--foreground 20%)`, 나머지 글자는 `--foreground`(레드 위 대비 약 4.6:1). 회색(`text-muted`)이던 달성형 라벨·«/»·서클 단위 글자는 레드 위에서 읽히지 않아 `--foreground`로 바꿨다.
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`(`InfoCard`, `CountCircles`, 진행상황 카드 블록), `MissionDetailClient.test.tsx`.
