# [UI] 미션 상세에서 완료한 미션도 «종료» 칩으로 하고 하단 «종료» 버튼을 없앤다

## 핵심 요약

- 요구사항: 미션을 완료해도 기간이 지나면 미션은 끝나므로, 완료한 미션의 상세 칩을 «완료» 대신 «종료»로 하고 맨 아래 비활성 «종료» 버튼은 지운다(사용자 지시, 2026-11-11).
- 구현: `StatusChip`의 완료 분기가 `d.missions.tagJoinedEnded`(«종료»)를 그린다. 맨 아래 CTA의 완료 분기(비활성 «종료» 버튼)는 `null`이다(이 분기를 지우면 «참가하기»가 뜰 수 있어 분기는 남겼다). 안 쓰게 된 문구 키 `missions.ctaEnded`는 지웠다.
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`(`StatusChip` 190행 부근, CTA 블록 660행 부근), `MissionDetailClient.test.tsx`, `jam-web/src/lib/i18n/ko.ts`.

## 상세 요구사항

- 완료한 미션은 기간이 남아 있어도 «종료» 칩이다. 진행 중인 미션을 막 완료한 사람에게도 «종료»로 보인다(지시대로다. 사용자가 이 점을 알고 정했는지는 확인하지 않았다).
- 목록의 «완료» 칩(`MissionsListClient`)은 이번에 바꾸지 않았다. 목록과 상세의 글자가 달라진다.
