# [UI] 미션 상황 화면의 레드 배경을 푸터 위까지 채운다

## 핵심 요약

- 요구사항: 참가자가 적어 내용이 짧을 때, 레드 배경이 카드 아래에서 끊기고 푸터까지 회색 여백이 남았다. 이 여백을 레드로 채운다(사용자 지시, 2026-11-11, 스크린샷 첨부).
- 원인: 화면 최상위 요소가 `min-h-full`(퍼센트 높이)이었다. `(main)/layout.tsx`의 컨텐츠 래퍼는 `min-h-dvh`만 지정하고 `height`는 auto라서 퍼센트가 높이로 해석되지 않는다. 같은 사정은 레이아웃 주석(119~125행)에 이미 적혀 있다.
- 구현: 최상위 요소를 `min-h-dvh`로 바꿨다.
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/status/MissionStatusClient.tsx`(`min-h-dvh relative text-foreground` 줄).
