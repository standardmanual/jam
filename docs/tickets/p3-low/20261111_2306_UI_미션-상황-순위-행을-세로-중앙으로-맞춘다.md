# [UI] 미션 상황 순위 행을 세로 중앙으로 맞춘다

## 핵심 요약

- 요구사항: 순위 행의 내용이 시각적으로 세로 중앙에 놓이지 않는다. 시각적으로 중앙에 맞춘다(사용자 지시, 2026-11-11, 스크린샷 첨부).
- 원인 두 가지: (1) 진행 바 트랙 색(`--border` #e5e5e5)이 행 면(`--background-secondary` #e5e5e5)과 같아 트랙이 보이지 않았다. 이름과 막대가 한 덩어리로 중앙에 놓이는데 막대가 안 보여 이름만 4px 위로 떠 보였다. (2) «나» 원이 이름 줄(기준선 정렬) 안에 있어 순위·아바타·값보다 어긋났다.
- 구현: `RankingListRow`에 `trackColor` prop(기본 `var(--border)`)을 더하고 미션 상황 화면이 행 면보다 짙은 색(`foreground` 12% 혼합)을 넘긴다. `meMarker="circle"`일 때 원을 이름 줄이 아니라 값 칸에 둔다(값 칸은 행 세로 중앙). 홈 랭킹보드(기본값)는 바뀌지 않는다.
- 관련 파일: `jam-web/src/components/ranking/RankingListRow.tsx`, `jam-web/src/app/(main)/missions/[id]/status/MissionStatusClient.tsx`(`RankingListRow` 호출부 268행 부근).
