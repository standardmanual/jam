# [UI] 미션 상세 보상 영역을 레드 면으로 하고 포인트를 흰색으로 한다

## 핵심 요약

- 요구사항: 미션 상세의 보상 영역을 레드 배경으로 하고, 아이콘과 서클은 블랙을 유지하며, 포인트 글자는 흰색으로 한다. 포인트가 아닌 보상이 있는 경우를 스크린샷으로 보여 달라(사용자 지시, 2026-11-11).
- 구현: 보상 행(열린 배지·잠긴 배지·포인트) 전부의 면을 `--jam-red`로 했다(`REWARD_ROW_STYLE`). 배지 행의 «아이템 배지» 캡션은 `--foreground`다(`--muted`는 레드 위에서 대비가 낮다). 포인트 문구는 `PointText`(오렌지) 대신 `--foreground`(검정) 일반 문구다. 처음에는 흰색(`--snow`)으로 했다가 사용자가 검정으로 되돌리게 했다(2026-11-11). 포인트 아이콘 서클은 `--accent`(블랙) 그대로다.
- 관련 파일: `jam-web/src/app/(main)/missions/[id]/MissionDetailClient.tsx`(`REWARD_ROW_STYLE`, `LockedRewardRow`, 보상 블록 540행 부근), `MissionDetailClient.notice.test.tsx`.

## 상세 요구사항

- 검정(#171717) 포인트와 레드(#FF1D1D)의 대비는 약 4.6:1로 일반 글자 기준(4.5:1)을 넘는다. 흰색일 때는 약 3.9:1로 못 미쳤다.
- `tPoint` 규칙(포인트 색은 PointText 한 곳)의 예외다. 이 행에서만 `t()`로 문구를 만든다.
