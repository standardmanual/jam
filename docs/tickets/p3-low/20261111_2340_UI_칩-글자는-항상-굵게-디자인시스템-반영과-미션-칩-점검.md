# [UI] 칩 글자는 항상 굵게: 디자인시스템 반영과 미션 칩 점검

## 핵심 요약

- 요구사항: 칩 글자는 항상 볼드여야 한다. 디자인시스템에 반영한다. 미션 페이지와 하위 화면의 칩 색·글자 상태를 점검해 다른 점이 있는지 보고한다(사용자 지시, 2026-11-11).
- 구현: `ListRowChip`의 글자 굵기를 400에서 700(`ROW_WEIGHT.strong`)으로 올렸다. 원본(`design-system/components/patterns/ListRow.jsx`)과 서비스 사본(`src/components/ui/ListRow.tsx`)을 함께 바꿨다. 등급 칩(`RarityBadge`)과 레벨 칩(`BadgeLevelChip`)은 이미 700이었다. 직전 티켓 20261111_2330에서 목록 칩마다 넣은 `fontWeight: 700`은 걷었다.
- 문서: `ListRow.prompt.md`와 `docs/plan/jam2/11 JAM 2.0 디자인 시스템.md` 5.7절에 규칙을 적었다.
- 관련 파일: `jam-web/design-system/components/patterns/ListRow.jsx`(`ListRowChip` 117행 부근), `jam-web/src/components/ui/ListRow.tsx`, `jam-web/src/app/(main)/missions/MissionsListClient.tsx`.

## 점검 결과 (미션 목록·상세·상황, 개발 서버 실측 + 이 계정에 없는 상태는 같은 마크업으로 구움)

글자 굵기는 전부 700으로 같다. 어긋나는 것은 크기와 색이다.

| 칩 | 목록 | 상세 | 상황 |
|---|---|---|---|
| 참가중 | 12px, 레드 면·검정 글자(4.65) | **14px, 블랙 면·흰 글자(17.47)** | - |
| 종료 | 12px, 연회색 면·검정 글자(14.23) | **11px, 회색 면·`--muted` 글자(4.56)** | - |
| 잠김 | 12px, 연회색 면·검정 글자 | **11px**, `--border` 면·검정 글자 | - |
| 달성 | - | 14px, 블랙 면·흰 글자 | 12px, 블랙 면·흰 글자 |
| 미달성 | - | **14px, 연회색 면·`--muted` 글자(4.56)** | **12px, 진회색 면·흰 글자(5.60)** |

- 상세의 칩은 `ListRowChip`이 아니라 손으로 만든 `<span>`이라 크기·색이 목록과 따로 간다(`MissionDetailClient.tsx` `StatusChip`, 달성 칩).
- 같은 «종료»가 목록은 검정 글자, 상세는 muted 글자다. 같은 «미달성»이 상세는 연회색, 상황은 진회색이다(상황 화면은 사용자가 진회색으로 지시했다).
- 상세 «참가중»은 목록처럼 레드 면이 아니라 블랙 면이다(사용자 지시는 목록만 레드였다).
- 「이 계정에 없는 상태」(완료·잠김·시작전·NEW·남은 시간)는 실제 화면이 아니라 같은 컴포넌트·같은 마크업으로 구운 비교판으로 봤다.
