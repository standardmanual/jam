# [UI] 랭킹 행의 진행 막대를 16px로 통일한다

## 핵심 요약

- 요구사항: 사용자가 staging 확인 중 «랭킹 페이지의 프로그래스 바 두께가 두꺼워지지 않았다»고 지적했다. 랭킹 행(`RankingListRow`)의 막대는 6px였고, 컬렉션 상세·미션 상세의 막대는 16px였다. 사용자 결정(2026-11-12)으로 16px로 통일한다.
- 구현 계획: `RankingListRow`의 `ProgressBar`를 `height={16}`으로 올리고 6px 전용 모서리(`radius="3px"`)를 지워 기본 알약 모양에 맞춘다.
- 관련 파일(지도, 경로 기준 `jam-web/`): `src/components/ranking/RankingListRow.tsx`(109~117행 `ProgressBar`). 사용처는 `src/app/(main)/missions/[id]/status/MissionStatusClient.tsx`(전체 랭킹)와 `src/components/today/ListCard.tsx`(홈 순위 카드) 두 곳이 같은 부품을 쓴다.

## 배경 / 문제 정의

4회차의 캔버스 댓글 «두께를 컬렉션 상세페이지의 프로그래스바 두께로»는 미션 상세의 «나의 진행 상황» 막대 한 곳에만 걸려 있어 그 막대만 16px로 바뀌었다. 랭킹 행은 캔버스와 서비스 모두 6px였으므로 지시 누락이 아니라 범위 밖이었고, 사용자가 같은 두께로 통일하길 원한다고 확정했다.

## 완료 조건

- 미션 현황 «전체 랭킹»과 홈 순위 카드의 막대가 16px 알약 모양이다. 행 높이가 그만큼 늘어난다.
- 관련 시험(`ranking`·`today`·`missions`)이 통과한다.

## 완료 기록

- `RankingListRow`의 막대를 16px로 바꿨다(모서리는 `ProgressBar` 기본 알약). 개발 서버 `/dev-sample/home-feed-cards`에서 트랙 높이 16px·모서리 9999px, 행 높이 72px를 확인했다. 시험 680건 통과.
- 확인하지 못한 항목: 미션 현황 «전체 랭킹» 화면 실렌더(로그인 필요).
- 경미 수정이라 워크플로 없이 직접 처리했다.
