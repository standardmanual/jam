# [UI] 등급 올리기 재료 시트를 캔버스대로 바꾼다

## 핵심 요약

- 요구사항: 캔버스에 새로 추가한 «등급 올리기 · 슬롯을 눌렀을 때 / 배지를 한 장 담은 뒤» 시트 화면의 사용자 수정을 서비스에 반영한다. ① 이미 추가된 배지는 그림을 그레이로, «사용 중» 글자를 지우고 이름 아래 가운데에 «추가됨» 칩을 둔다. ② 등급 칩(묶음 제목)을 가로 가운데로. ③ 안내 문구(«지금은 Common 아이템 배지만 넣을 수 있어요»)를 가운데로.
- 구현 계획: ①은 `BagItemCell`(믹스 가방과 등급 올리기 재료 시트가 공유)의 `used` 상태, ②·③은 `TierUpPanel`의 묶음 제목 `h3`와 등급 고정 안내 `p`.
- 관련 파일(지도, 경로 기준 `jam-web/`): `src/app/(main)/combine/BagItemCell.tsx`(`used` 처리, `earned` 판정과 children 칩), `src/app/(main)/combine/TierUpPanel.tsx`(`TierUpSheetContent`의 locked 안내 `p`, 묶음 제목 `h3`), `src/lib/i18n/ko.ts`(`combine.bagUsedLabel` «사용 중»→«추가됨»), 시험 `BagItemCell.test.tsx`·`TierUpPanel.test.tsx`. 칩은 DS `LabelChip`(회색 알약, 12px 볼드, 높이 20px)을 쓴다.

## 상세 요구사항

- `BagItemCell`은 믹스 가방 시트와 등급 올리기 재료 시트가 함께 쓰므로 **두 시트의 «담은 칸» 표시가 같이 바뀐다**(같은 뜻의 상태라 한 부품에서 바꿨다).

## 완료 조건

- 추가된 배지는 그림이 흑백·흐림이고 이름 아래 가운데에 «추가됨» 칩이 있다(«사용 중» 없음). 등급 칩과 안내 문구가 시트 안에서 가운데다. 관련 시험이 통과한다.

---
## 완료 기록

- 위 세 가지를 반영했다. `used` 셀은 `earned={false}`로 그려 «넣을 수 있는 슬롯»과 같은 그레이 처리(그림만 흑백 40%)를 쓰고, 카드 전체의 흐림은 걸지 않는다. 시험 247건(combine) 통과, `tsc` 오류 0, eslint 오류 0.
- 개발 서버에서 staging 테스트 계정으로 등급 올리기 → 슬롯 선택 → 한 장 담기를 재현해 캔버스와 같은 모습을 확인했다(회색 그림, 가운데 «추가됨» 칩, 가운데 안내 문구). 등급 칩 가운데 정렬은 시험의 클래스 단언으로 확인했고 눈으로는 묶음 보기 상태를 열어 보지 않았다.
- 믹스 레시피의 가방 시트에서 «담은 칸»이 같은 표시로 바뀐다. 이 시트는 캔버스에 화면이 없어 눈으로 확인하지 못했다.
- 경미한 수정이라 워크플로 없이 직접 처리했다.
