# [UI] 캡슐 게이지의 알약 아이콘을 삭제하고 등급 올리기 안내를 가운데로 맞춘다

## 핵심 요약

- 요구사항: 캔버스에서 사용자가 ① 홈·프로필 캡슐 게이지의 알약 아이콘 삭제, ② 등급 올리기 안내 문구 «같은 등급 배지 6개로 등급 업! 도전!» 가운데 정렬을 지시했다. 서비스에 반영한다.
- 구현 계획: ① `CapsuleGauge`에서 알약 아이콘과 그에 딸린 회전·갈라짐 모션을 걷어내고, 더 이상 쓰이지 않는 `CapsulePillIcon`·`capsuleSpinTurns`·`GAUGE_SPIN_TURN_MS`를 지운다. ② `TierUpPanel`의 설명 문단에 `text-center`.
- 관련 파일(지도, 경로 기준 `jam-web/`): `src/components/capsule/CapsuleGauge.tsx`(아이콘 span, `open` 효과, `spun`), `CapsulePillIcon.tsx`(삭제), `src/lib/capsule/capsule-gauge.ts`(`capsuleSpinTurns`), `src/app/(main)/combine/TierUpPanel.tsx`, 시험 `CapsuleGauge.test.tsx`·`capsule-gauge.test.ts`·`TierUpPanel.test.tsx`, PRD `docs/service/prd/home-feed/PRD.md`(게이지 절).

## 완료 조건

- 홈과 내 프로필의 게이지에 `<svg>` 아이콘이 없고 채움·점·숫자는 그대로다. 등급 올리기 안내 문단이 가운데다. 관련 시험·`tsc`·eslint 통과.

---
## 완료 기록

- 게이지는 홈과 프로필이 같은 컴포넌트(`CapsuleGauge`)를 쓰므로 한 곳에서 두 화면이 함께 바뀐다. 아이콘이 쓰던 회전·갈라짐 모션과 `open` 상태, 아이콘 전용 상수·함수·파일은 같이 지웠다(이전 티켓 20261110_1346의 산출물). 안쪽 숫자가 비워 두던 끝 원 자리(원 지름)는 캔버스와 같게 그대로 두었다.
- 개발 서버에서 홈 게이지를 확인했다(아이콘 없음, 채움·점·숫자 «80» 정상). 시험 combine 247건·capsule 일대 통과, `tsc`·eslint 오류 0.
- 내 프로필 게이지 화면은 직접 열어 보지 않았다(같은 컴포넌트).
- 캔버스 쪽: 아이콘 삭제 때 제가 채움 막대까지 지운 오류가 있었고, 홈은 사용자 쪽에서 되돌려져 있었다. 홈·프로필 모두 아이콘만 지우도록 바로잡아 게시했다.
