# [UI] 로그인 화면을 캔버스의 검정 바탕·흰 로고·흰 버튼 수정대로 바꾼다

## 핵심 요약

- 요구사항: 사용자가 캔버스 «가입·로그인» 보드의 로그인 화면을 직접 고쳤다(검정 바탕, 큰 흰 로고, 흰 «구글로 시작하기» 버튼, 밝은 약관 문구). 서비스 로그인 화면을 같게 바꾼다. 속성값은 디자인 토큰에 가까운 값으로 옮긴다(사용자 지시).
- 관련 파일(경로 기준 `jam-web/`): `src/app/(auth)/login/page.tsx`(`LoginContent` 마크업, `LoginPage` 폴백).

## 상세 요구사항 / 구현

캔버스 값 → 서비스 값(토큰 근사):
- 바탕 `#000` → `--base-black`, 좌우 여백 16 → `px-4`.
- 로고 204×67, 흰색 → 높이 `h-16`(64), 색 `--snow`(FooterLogo와 같은 방식). 로고 아래 간격 88 → `mb-24`(96).
- 버튼 폭 261, 흰 면·검정 글자 → `max-w-64`(256), 서비스 `Button variant="secondary"`(`--btn-secondary` 면·`--foreground` 글자, md 52px). 완전한 흰색 면은 서비스 Button에 없어 회색 쪽으로 근사했다.
- 약관 문구 12px, `#e5e5e5` → `text-xs`, `--snow`.
- 개발 전용 로그인 버튼 테두리·글자는 검정 바탕에서 보이게 `--snow` 계열로 바꿨다. 오류 배너와 탈퇴 안내(InlineNotice)는 그대로다.

## 완료 기록

- 구현: 위 값대로 `page.tsx`만 고쳤다(경미 수정 경로, 파일 1개). `login/__tests__` 7건 통과, eslint 통과.
- 실렌더(메인 트리 `next dev`, 393×852, 새 세션): 로고 193×64, 버튼 256×52, 약관 12px 두 줄, 바탕 검정.
- 확인하지 못한 항목: 오류 배너(`?error=`)와 탈퇴 안내(`?withdrawn=1`)가 검정 바탕 위에서 보이는 모양을 눈으로 보지 않았다. 실제 Google 로그인 흐름은 시험하지 않았다.
