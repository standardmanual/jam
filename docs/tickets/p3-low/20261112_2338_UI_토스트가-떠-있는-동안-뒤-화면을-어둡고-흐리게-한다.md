# [UI] 토스트가 떠 있는 동안 뒤 화면을 어둡고 흐리게 한다

## 핵심 요약

- 요구사항: 토스트가 나타나는 동안 뒤 화면이 조금 어두워지고 흐려졌다가, 토스트가 사라지면 함께 풀린다. 사용자가 프로토타입(https://claude.ai/artifact/HB7VfWHF7iuLdgrqC3hqKu)을 보고 «이대로 반영해»로 확정했다(2026-11-12).
- 관련 파일(경로 기준 `jam-web/`): `src/components/ui/Toast.tsx`(`ToastProvider` 렌더부, 새 `ToastScrim`), `src/components/transitions.css`(`.t-toast-scrim`), `src/app/globals.css`(`--toast-scrim`·`--toast-scrim-blur`), 시험 `src/components/ui/__tests__/Toast.test.tsx`.

## 구현·값

- 막은 컨테이너(z-60) 바로 아래 층(z-59), `fixed inset-0`, `pointer-events-none`. 검정 16%(`--toast-scrim`)와 흐림 4px(`--toast-scrim-blur`).
- 나타남 350ms, 사라짐 250ms, 곡선은 토스트와 같은 `--toast-ease`. 닫히기 시작한 토스트는 세지 않아 마지막 토스트가 닫히기 시작하면 막이 함께 풀린다. 토스트가 겹치면 마지막 것이 닫힐 때 풀린다.
- 모션 줄이기에서는 전환 없이 바로 바뀐다.

## 완료 기록

- 이 변경은 서비스 `ToastProvider` 한 곳이라 토스트를 쓰는 모든 화면에 같이 적용된다. DS `Toast`(MODULAR) 쪽은 건드리지 않았다(`ds:check` 오류 0).
- 시험: `Toast.test.tsx` 11건 통과(막의 켜짐·꺼짐 속성, 눌림 통과, 층), ui 시험 전체 311건 통과, eslint 통과.
- 실렌더(메인 트리 `next dev`, 393×852): 다른 사용자 프로필에서 팔로우 요청을 일부러 실패시켜 오류 토스트를 띄웠다. 토스트가 뜨는 동안 상단 바·본문·탭바까지 흐리고 어두워졌고, 3초 뒤 토스트와 함께 모두 풀렸다.
- 경미 수정 경로로 직접 처리했다(파일 3개 안팎, 값 확정). 확인하지 못한 항목: iOS Safari와 구형 기기에서 흐림의 부드러움, 바텀시트가 열린 상태에서 토스트가 뜰 때의 모양.
