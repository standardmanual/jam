# [API] 이미지 생성기: 적용 중 기록 갱신만 실패하면 되돌리기가 막힌다

## 핵심 요약

- 요구사항: apply/route.ts 128~135줄: 4행 이미지 갱신은 성공하고 생성 기록 갱신이 실패하면 이미지는 반영됐는데 기록은 generated로 남아 되돌리기를 할 수 없다.
- 구현 계획: 기록 갱신 실패 시 4행을 previous_image_url로 되돌리거나, 기록을 먼저 applying 상태로 선점한 뒤 이미지를 갱신한다.
- 관련 파일: `jam-web/src/app/api/admin/badge-image-generator/apply/route.ts`
- 출처: 티켓 20261113_1131 게이트(민지) 범위 밖 발견 [참고]

## 완료 조건

- 위 상황을 재현하는 시험(모의 클라이언트)에서 이미지 반영과 생성 기록이 어긋나지 않는다.
