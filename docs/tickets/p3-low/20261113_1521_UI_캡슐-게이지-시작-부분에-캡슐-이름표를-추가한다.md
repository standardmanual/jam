# [UI] 캡슐 게이지 시작 부분에 «캡슐» 이름표를 추가한다

## 핵심 요약

- 요구사항(사용자, 2026-11-13): 캡슐 프로그레스 바의 시작 부분, 바 안쪽에 «캡슐» 글자를 넣는다.
- 관련 파일(경로 기준 `jam-web/`): `src/components/capsule/CapsuleGauge.tsx`(렌더 끝부분, 새 상수 `LABEL_*`), `src/lib/i18n/ko.ts`(`capsule.gaugeLabel`), 시험 `src/components/capsule/CapsuleGauge.test.tsx`·`CapsuleWidget.test.tsx`.

## 구현

- 글자는 두 겹이다. 트랙 위에는 밝은 글자(`--snow`), 채움 안쪽에는 어두운 글자(`--capsule-track`)를 같은 자리(왼쪽 안쪽 12px)에 그려, 채움이 글자 아래를 지나는 곳에서 색이 바뀐다. 오렌지 위 흰 글자는 약 3.4:1이라 작은 글자에 쓰지 않으려는 선택이다.
- 채운 비율이 50% 이상이면 이름표가 숫자 앞에 같은 줄로 놓인다(간격 8px). 막힘 문구(`message`)가 있으면 그 자리를 문구가 쓰므로 이름표를 그리지 않는다. 12px 굵은 글자이고 `aria-hidden`이다.
- 같은 게이지를 쓰는 홈 위젯·프로필·막힘 카드에 모두 적용된다.

## 완료 기록

- 시험: 캡슐·i18n·`(main)` 관련 98개 파일 1,646건 통과(이름표 두 겹·위치·막힘 문구 없음 단언을 더했고 글자 추출 도우미는 이름표를 뺀다). `ListRow` 반경 변경(티켓 20261113_1452)에 걸리던 알림·믹스 시험의 기대값(`--radius-xl`)도 이 커밋에서 함께 고쳤다. `src/components` 전체의 406건 실패는 이 변경 전에도 같은 수로 실패하는 환경 문제(어드민 Invalid hook call)다.
- 실렌더(메인 트리 `next dev`): 홈 게이지에서 «캡슐» 이름표와 숫자가 겹치지 않고 보였다. 확인하지 못한 항목: 채운 비율 50% 미만·막힘 문구 상태의 실화면(시험으로만 확인).
- 캔버스: 홈 보드와 프로필 보드의 게이지 6개에 같은 이름표를 넣었다. 프로필 보드에 남아 있던 알약 아이콘(티켓 20261112_1944에서 뺀 것)이 되살아나 있어 같이 지웠다.
