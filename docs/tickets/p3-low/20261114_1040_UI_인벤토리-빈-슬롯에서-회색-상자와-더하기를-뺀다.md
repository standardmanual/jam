# [UI] 인벤토리 빈 슬롯에서 회색 상자와 «+»를 뺀다

## 핵심 요약

- 요구사항(사용자, 2026-11-14): 인벤토리의 빈 슬롯은 흰 카드만 표현하고, 카드 안의 회색 상자와 «+»는 제거한다.
- 관련 파일(경로 기준 `jam-web/`): `src/components/inventory/InventoryGrid.tsx`(빈 슬롯 placeholder, 137행 부근), 시험 `src/components/inventory/InventoryGrid.test.tsx`.

## 구현

- 빈 슬롯 카드(`bg-card-bg rounded-2xl p-3 opacity-30`)는 그대로 두고, 안쪽의 90px 회색 상자(`bg-background-secondary`)와 «+» 글자를 지웠다. 행 높이가 아이템 카드와 어긋나지 않도록 90px 자리는 빈 `div`로 남겼다.
- 빈 슬롯은 아이템이 6개 미만일 때만 보인다(`inventory/page.tsx`의 `emptySlots`). 온보딩 퀘스트 `bag` 차례(`QuestBagGrid`)도 같은 컴포넌트라 같이 바뀐다.

## 완료 기록

- 시험 6개 파일 105건 통과(빈 슬롯에 «+»·회색 상자가 없고 90px 자리가 남는 단언 2건 추가), eslint 통과. 경미 수정 경로로 직접 처리했다.
- 확인하지 못한 항목: 실제 화면. 아이템이 6개 미만인 계정이 필요해 로컬 시험 계정(232, 아이템 16개)으로는 빈 슬롯이 나오지 않는다.
- 캔버스 인벤토리 보드에는 빈 슬롯 화면이 없어 캔버스는 바꾸지 않았다. 빈 슬롯이 여전히 30% 투명도로 흐릿하게 그려진다(그대로 둠).
