# [Infra] DESIGN_RENEWAL_SPEC의 탭바 구성 표가 현행과 다르다

## 핵심 요약
- 요구사항: `docs/service/prd/2026-08-15 DESIGN_RENEWAL_SPEC.md` 408~416행 탭바 구성 표가 세 번째 탭을 «JAM(드랍) / JAM»으로, 프로필 탭까지 적어 두어 현행(투데이·배지·체크인·미션·인벤토리, 프로필 탭 없음)과 다르다. 날짜 스냅샷 문서라 고칠지, 현행 문서로 환류할지 정한다.
- 구현 계획: 문서 담당(하니)이 판단한다.
- 관련 파일: docs/service/prd/2026-08-15 DESIGN_RENEWAL_SPEC.md 408~416행

## 배경 / 문제 정의
티켓 20261114_1418(탭바 활성 이름표) 게이트 리뷰에서 나온 범위 밖 발견물이다. 세 번째 탭 이름이 «체크인»으로 바뀌면서 표의 «JAM» 표기가 더 낡았다.

## 완료 조건
- 표가 현행과 맞거나, 스냅샷 문서임이 표 옆에 적혀 현행 근거가 다른 문서를 가리킨다.
