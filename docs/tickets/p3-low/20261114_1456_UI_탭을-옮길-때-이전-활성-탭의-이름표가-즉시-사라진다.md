# [UI] 탭을 옮길 때 이전 활성 탭의 이름표가 즉시 사라진다

## 핵심 요약
- 요구사항: 탭을 옮기면 이전 활성 탭의 이름표가 즉시 사라지고 그 아이콘이 슬롯 가운데로 옮겨 간다. 사라지는 쪽도 부드럽게 이어지게 할지 정한다(비활성 이름표를 두지 않는 요구와의 균형 포함).
- 구현 계획: 다음 작업에서 정한다.
- 관련 파일: jam-web/src/components/ui/TabBar.tsx 482~518행, jam-web/design-system/components/navigation/TabBar.jsx

## 배경 / 문제 정의
티켓 20261114_1418(탭바 활성 이름표) 재작업의 게이트 리뷰에서 나온 범위 밖 발견물이다.

## 완료 조건
- 채원이 방식을 판정하고, 실렌더에서 이름표 퇴장이 거슬리지 않는다.
