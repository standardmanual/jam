# [UI] 탭바 DS 검사의 경고 두 가지가 계속 남는다

## 핵심 요약
- 요구사항: ds:check의 PROPS_DRIFT(DS 타입에만 active가 있음)와 PAIR_GEOMETRY(MODULAR에만 있는 gap: 6px) 경고가 TabBar에서 남는다. 서비스는 같은 값을 .jam-tabbar-icon CSS가 주므로 의도된 차이로 보이나, 허용 목록에 사유를 적어 경고를 없앨지 정한다.
- 구현 계획: 다음 작업에서 정한다.
- 관련 파일: jam-web/design-system/components/navigation/TabBar.d.ts, TabBar.jsx, scripts의 ds:check 허용 목록

## 배경 / 문제 정의
티켓 20261114_1418(탭바 활성 이름표) 재작업의 게이트 리뷰에서 나온 범위 밖 발견물이다.

## 완료 조건
- ds:check에서 TabBar 경고가 사라지거나 사유가 허용 목록에 남는다.
