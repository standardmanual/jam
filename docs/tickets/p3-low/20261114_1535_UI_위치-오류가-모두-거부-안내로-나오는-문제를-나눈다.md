# [UI] 위치 오류가 모두 «거부» 안내로 나오는 문제를 나눈다

## 핵심 요약
- 요구사항: `/drops`의 위치 오류 콜백이 시간 초과·위치 확인 불가까지 전부 `locationDenied`로 처리해 «권한을 허용해 주세요» 안내가 뜬다. 오류 코드(PERMISSION_DENIED·POSITION_UNAVAILABLE·TIMEOUT)를 나눠 거부일 때만 허용 방법 카드를 보이고, 나머지는 «위치를 확인하지 못했어요» 류 안내와 다시 시도만 보인다.
- 구현 계획: `DropsClient.tsx` 157행 부근 오류 콜백에서 `error.code`로 상태를 나누고 `LocationPermissionCard`에 `kind`(예: `unavailable`)를 더한다. 위치 조회 로직 변경이라 판정과 게이트를 거친다. 함께 `d.drops.retry` 키(이제 쓰는 곳 없음)를 정리한다.
- 관련 파일(jam-web/src): `app/(main)/drops/DropsClient.tsx`, `app/(main)/drops/LocationPermissionCard.tsx`, `lib/i18n/ko.ts` 652행 `drops.retry`

## 배경 / 문제 정의
티켓 20261114_1507 게이트 리뷰의 범위 밖 발견물이다. 기존 동작이지만 새 카드가 «허용 방법»을 앞세우면서 권한 문제가 아닌 오류에도 허용 방법이 나오게 된다.

## 완료 조건
- 권한 거부일 때만 허용 방법 카드가 보이고, 시간 초과·위치 확인 불가는 별도 안내와 다시 시도가 보인다.
- 오류 코드별 시험이 있다.
