# [UI] 인벤토리의 믹스하기 버튼을 페이지 폭으로 늘린다

## 핵심 요약
- 요구사항: 인벤토리 페이지의 «믹스하기» 버튼을 가운데 정렬된 작은 알약에서 페이지 폭을 가득 채우는 긴 버튼으로 바꾼다(사용자 지시 2026-11-14, 캔버스 «인벤토리» 보드와 같은 모양). 버튼 색(`bg-surface`)·아이콘·글자는 그대로다.
- 구현 계획: 경미 수정(파일 1개, 2줄). 바깥 `flex justify-center` 래퍼를 일반 블록으로 바꾸고 `Link`를 `inline-flex`에서 `flex w-full`로 바꾼다.
- 관련 파일: `jam-web/src/app/(main)/inventory/page.tsx` 89~98행

## 완료 조건
- 인벤토리의 믹스하기 버튼이 좌우 여백(16px)을 뺀 페이지 폭 전체를 채우고 높이 44px 이상, 아이콘·글자는 가운데다.
- 인벤토리 시험이 통과한다.

## 완료 기록

### 구현 내용 요약
- `Link`를 `flex w-full`로 바꾸고 래퍼의 `flex items-start justify-center`를 걷었다. 색·반경·눌림·아이콘은 그대로다.
