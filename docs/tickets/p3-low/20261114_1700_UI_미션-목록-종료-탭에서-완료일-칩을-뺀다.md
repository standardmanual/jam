# [UI] 미션 목록 종료 탭에서 완료일 칩을 뺀다

## 핵심 요약

- 요구사항(사용자, 2026-11-14): 미션 목록의 종료 탭 카드에서 날짜 칩(완료한 날, 예: «2026년 11월 10일»)을 제거한다. 상태 칩 «완료»와 보상 «10 포인트»는 그대로다.
- 관련 파일(경로 기준 `jam-web/`): `src/app/(main)/missions/MissionsListClient.tsx`(`periodChip`, 170행 부근), 시험 `src/app/(main)/missions/MissionsListClient.list-row.test.tsx`.

## 구현

- `periodChip`이 `tab === 'ended'`이고 `m.done`이면 `null`을 돌려준다. 종료 탭의 «종료»·«참가종료» 상태는 기존 규칙(별도 칩)이 그대로다. 다른 탭(진행 중·참가 중)의 완료 건에는 완료일 칩이 계속 나온다.

## 완료 기록

- 시험: 종료 탭 완료 미션이 «완료» 칩만 그리고 날짜 문자열이 없다는 단언을 더했다. 미션 관련 14개 파일 193건 통과, eslint 오류 0(기존 경고 1건은 이 변경과 무관).
- 경미 수정 경로로 직접 처리했다. 확인하지 못한 항목: 실제 화면(모양은 칩 하나가 빠지는 것뿐이다). 캔버스 미션 보드는 바꾸지 않았다.
