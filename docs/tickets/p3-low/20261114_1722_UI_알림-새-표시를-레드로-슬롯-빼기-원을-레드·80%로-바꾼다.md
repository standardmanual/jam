# [UI] 알림 새 표시를 레드로, 슬롯 «−» 원을 레드·80% 크기로 바꾼다

## 핵심 요약

- 요구사항(사용자, 2026-11-14): ① 상단 알림 버튼(종)의 새 알림 표시를 레드로 바꾼다. ② 모든 배지 슬롯의 배지 빼기 «−» 원을 레드로 바꾸고 크기를 80%로 줄인다.
- 관련 파일(경로 기준 `jam-web/`): ① `src/components/ui/NotificationBell.tsx`(점 `background`). ② `src/components/ui/SlotCircleButton.tsx`(컬렉션 칸·레시피 칸), `design-system/components/patterns/MixerSlot.jsx`(`ActionCircle`, 믹스·등급 올리기 슬롯), 시험 `collections/[id]/__tests__/SlotGrid.test.tsx`·`combine/RecipeSlotCard.test.tsx`, 스토리 `MixerSlot.stories.tsx`.

## 구현

- ① 점 색을 `var(--danger)`(검정 계열)에서 `var(--jam-red)`로 바꿨다. 크기·팝인 모션은 그대로다.
- ② «−» 원을 `--jam-red` 면 + `--snow` 아이콘으로, 24px → 19.2px(아이콘 14px → 11.2px)로 줄였다. «+» 원(검정, 24px)은 그대로다.
  - 눌림 영역은 44px 그대로다: `SlotCircleButton`은 `before:-inset-[12.4px]`, `MixerSlot`의 제거 버튼은 44px 박스 안 가운데에 놓인다.
  - 원의 중심이 변하지 않도록 `SlotCircleButton`의 «−» 위치를 6px → 8.4px 안쪽으로 옮겼다.

## 완료 기록

- 시험: 컬렉션·믹스·`src/components/ui` 관련 45개 파일 954건 통과, `ds:check` 오류 0. 시험 2건의 기대값(레드 면, 19.2px, 8.4px 안쪽)과 `MixerSlot` 스토리의 단언을 새 값으로 고쳤다. 경미 수정 경로로 직접 처리했다.
- 실렌더(메인 트리 `next dev`, 393×852): 컬렉션 상세의 «−» 원이 레드로 작게 나온 것을 확인했다.
- 확인하지 못한 항목: 알림 새 표시(시험 계정에 읽지 않은 알림이 없어 점이 보이지 않았다. 색은 코드로만 확인), 믹스·등급 올리기 슬롯의 «−» 실화면.
