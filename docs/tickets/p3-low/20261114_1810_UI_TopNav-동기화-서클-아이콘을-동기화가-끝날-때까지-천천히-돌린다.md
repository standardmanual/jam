# [UI] TopNav 동기화 서클 아이콘을 동기화가 끝날 때까지 천천히 돌린다

## 핵심 요약

- 요구사항(사용자, 2026-11-14): TopNav 동기화 서클을 누르면 동기화가 완료될 때까지 아이콘을 천천히 회전시킨다.
- 관련 파일(경로 기준 `jam-web/`): `src/components/ui/SyncIconButton.tsx`(회전 클래스·종료 처리), `src/components/SyncButton.tsx`(아이콘 변형에 넘기는 `loading`), 시험 `src/components/ui/__tests__/SyncIconButton.test.tsx`.

## 구현

- 한 바퀴 시간을 1초(`animate-spin`)에서 2.4초(`animate-[spin_2.4s_linear_infinite]`)로 늘렸다. 모션 줄이기에서는 종전대로 회전 대신 서클을 흐리게 한다.
- 누르는 즉시 돌기 시작한다. 아이콘 변형은 지연 처리된 `showLoading` 대신 `loading`을 받는다. 이전에는 짧은 동기화에서 회전이 아예 보이지 않을 수 있었다.
- 동기화가 끝나면 돌던 한 바퀴를 마저 돌고(`onAnimationIteration`) 멈춘다. 중간 각도에서 0도로 튀지 않는다.
- 글자 알약 변형(`Button`)은 그대로 `showLoading`을 쓴다.

## 완료 기록

- 시험: `src/components/ui`·`src/components/__tests__` 31개 파일 587건 통과, eslint 통과. 시험 기대값을 2.4초 회전 클래스로 고쳤다. 경미 수정 경로로 직접 처리했다.
- 확인하지 못한 항목: 실화면 회전 속도와 종료 시점의 부드러움(코드와 정적 렌더 시험으로만 확인).
