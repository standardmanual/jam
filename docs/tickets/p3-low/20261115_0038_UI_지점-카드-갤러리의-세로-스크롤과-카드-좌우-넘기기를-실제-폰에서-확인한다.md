# [UI] 지점 카드 갤러리의 세로 스크롤과 카드 좌우 넘기기를 실제 폰에서 확인한다

## 핵심 요약

- 요구사항: 체크인 지점 카드의 3열 갤러리(티켓 20261114_2352)는 묶음이 7개 이상이면 갤러리 영역 안에서 세로로 스크롤된다.
  같은 카드는 좌우로 넘기는 캐러셀이기도 하다. 두 손동작이 실제 폰에서 서로 걸리지 않는지 확인하고, 걸리면 고친다.
- 구현 계획: staging 배포 뒤 실제 폰(iOS Safari, Android Chrome)에서 확인한다. 문제가 있으면 갤러리 영역의 `touch-action`을 조정한다.
- 관련 파일: `jam-web/src/components/PoiCarouselModal.tsx`의 `PoiBadgeGallery`(갤러리 영역, `overflow-y-auto overscroll-contain`),
  `jam-web/design-system/components/navigation/Carousel.jsx`(가로 스와이프)

## 배경 / 문제 정의

티켓 20261114_2352 게이트 리뷰(민지)의 범위 밖 발견물이다. 아현은 갤러리에 `touch-action`을 따로 제한하지 않았다.
`pan-y`를 주면 칸 위에서 캐러셀의 가로 스와이프가 막히기 때문에, 브라우저가 손동작의 방향으로 가르도록 두었다.
이 판단은 코드와 데스크톱 렌더로만 확인했고 실제 터치 기기에서는 확인하지 못했다.

## 상세 요구사항

### UI/UX 관점

- 묶음이 7개 이상인 지점 카드에서 갤러리 위에 손가락을 대고 위아래로 밀면 갤러리만 스크롤된다(카드가 옆으로 넘어가지 않는다)
- 같은 자리에서 좌우로 밀면 카드가 옆으로 넘어간다(갤러리가 가로 스와이프를 삼키지 않는다)
- 갤러리 스크롤이 끝에 닿아도 뒤의 지도 화면이 따라 움직이지 않는다

## 구현 계획

확인이 먼저다. 문제가 없으면 코드 변경 없이 닫는다.

- 걸림이 있었다면 고친 뒤 같은 기기에서 다시 확인했다
