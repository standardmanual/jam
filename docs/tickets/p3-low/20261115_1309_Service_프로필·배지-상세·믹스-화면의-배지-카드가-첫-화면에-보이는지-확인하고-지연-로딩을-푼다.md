# [Service] 프로필·배지 상세·믹스 화면의 배지 카드가 첫 화면에 보이는지 확인하고 지연 로딩을 푼다

## 핵심 요약

- 요구사항: 티켓 20261115_1237이 그리드의 앞 12칸을 지연 로딩에서 뺐지만, 세 화면은 첫 화면에 보이는지 확인하지 못해 그대로 두었다.
- 구현 계획: 세 화면을 폭 390 기준으로 열어 첫 화면에 보이는 카드에만 `eager`를 준다.
- 관련 파일: `jam-web/src/app/(main)/profile/ProfileClient.tsx` 418행, `jam-web/src/app/(main)/badges/[id]/page.tsx` 579행,
  `jam-web/src/app/(main)/combine/`의 `PendingResultsSheet.tsx` 56행·`BagItemCell.tsx` 45행·`RecipeSlotCard.tsx` 51행

## 배경 / 문제 정의

티켓 20261115_1237 게이트 리뷰(민지)의 범위 밖 발견물이다. 첫 화면 분량의 기준은 `jam-web/src/lib/imageSrc.ts`의
`FIRST_SCREEN_GRID_COUNT`와 `docs/service/prd/asset-generator/PRD.md` §9.1에 있다.

## 완료 조건

- 세 화면에서 첫 화면에 보이는 배지 카드의 `<img>`가 `loading="lazy"`가 아니다
- 첫 화면 밖의 카드는 지연 로딩을 유지한다
