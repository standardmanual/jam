# [UI] 공유 시트 버튼을 서클 안 아이콘과 아래 이름표로 바꾼다

## 핵심 요약

- 요구사항(사용자, 2026-11-15): 배지 공유하기 바텀시트의 복사하기·저장하기·더보기를 알약 버튼 대신 «서클 안에 아이콘, 이름표는 서클 아래»로 표시한다.
- 관련 파일(경로 기준 `jam-web/`): `src/app/(main)/badges/[id]/ShareActionButtons.tsx`(버튼 줄 전체), 시험 `src/app/(main)/badges/[id]/__tests__/BadgeShareButton.test.tsx`(버튼 줄 시험 블록).
- 이전 티켓: `20261115_1249`(알약 버튼 세로 배치, 이번에 대체).

## 구현

- 칸마다 `<button>` 하나가 56px 서클(`h-14 w-14 rounded-full`)과 아래 이름표(`text-sm`)를 함께 감싼다. 터치 영역은 칸 전체다.
- 복사하기만 검은 서클(`bg-background-inverse text-snow`), 저장하기·더보기는 회색 서클(`bg-border text-foreground`)이다. 기존 «가장 흔한 행동 하나만 강조» 규칙을 그대로 지켰다.
- 서클은 `aria-hidden`이라 이름표가 접근 가능한 이름이다. 복사 중에는 복사하기 칸에 `aria-busy`가 붙는다. `canShare`가 거짓이면 더보기를 그리지 않는 동작도 그대로다.
- 눌림 반응은 서클 앱의 다른 아이콘 버튼과 같은 `active:scale-95`이다. `Button` 컴포넌트와 인라인 스타일 덮어쓰기(`!` 클래스)는 걷었다.
- 새 색·그림자·테두리·토큰은 없다.

## 완료 기록

- 시험: `src/app/(main)/badges/[id]` 12개 파일 71건 통과, eslint 통과. 버튼 줄 시험을 정적 렌더 마크업 기준으로 다시 썼다. 경미 수정 경로로 직접 처리했다.
- 실렌더(메인 트리 `next dev`, 375×812, 시험 계정 232): 서클 안 아이콘과 아래 이름표가 확인됐다. 복사하기는 검은 서클, 저장하기는 회색 서클이다.
- 확인하지 못한 항목: «더보기»(데스크톱 브라우저는 `canShare`가 거짓이라 그려지지 않는다), 좁은 폭(320px) 실화면.
