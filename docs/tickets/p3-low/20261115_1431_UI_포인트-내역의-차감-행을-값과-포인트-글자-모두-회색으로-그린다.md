# [UI] 포인트 내역의 차감(−) 행을 값과 «포인트» 글자 모두 회색으로 그린다

## 핵심 요약

- 요구사항(사용자, 2026-11-15): 포인트 페이지에서 마이너스(−) 포인트는 포인트 값과 «포인트» 글자를 그레이로 표현한다.
- 관련 파일(경로 기준 `jam-web/`): `design-system/components/patterns/PointText.jsx`(`tone` 속성), `PointText.d.ts`, `PointText.stories.tsx`, `PointText.prompt.md`, `src/components/points/PointHistoryList.tsx`(내역 행 호출부), 시험 `src/app/(main)/points/page.test.tsx`, 문서 `docs/service/writing/UX_WRITING_GUIDELINE.md` §1.3 «포인트» 행.
- 이전 규칙: 값과 «포인트»는 항상 오렌지(티켓 20261104_2319), 차감도 같은 색(티켓 20261112_1628). 이번에 차감만 예외로 바꾼다.

## 구현

- `PointText`에 `tone`(`point` 기본 | `muted`)을 더했다. `muted`는 값과 단위에 `--muted`(회색 글자 토큰, 실측 `rgb(102,102,102)`)와 `text-muted` 클래스를 쓴다. 색은 여전히 이 컴포넌트 한 곳에서 정하고 호출부가 임의 색을 줄 수는 없다.
- `PointHistoryList`는 `amount < 0`이면 `tone="muted"`를 넘긴다. 포인트 화면과 프로필 `#points`가 이 목록을 함께 쓰므로 두 곳이 같이 바뀐다. 적립은 그대로 오렌지다.
- 잔액 숫자·보상 칸·문장 속 «n 포인트»는 건드리지 않았다(차감 내역 행에만 해당).
- 스토리 `StackedMuted`, 타입 선언, 프롬프트 문서, UX Writing 가이드 문구를 함께 고쳤다.
