# [API] 어드민 그림 업로드의 예열이 배지가 아닌 그림에는 맞는 폭을 쓰게 한다

## 핵심 요약

- 요구사항: `/api/admin/upload-image`는 홈 피드 카드 표지나 미션 그림도 올리는 공용 경로인데, 예열은 배지 폭 네 개로만 한다. 그 그림들이 실제로 쓰는 폭은 다를 수 있다.
- 구현 계획: 업로드 요청이 그림의 용도를 알려 주게 하거나, 용도별 폭을 조사해 예열 폭을 나눈다.
- 관련 파일: `jam-web/src/app/api/admin/upload-image/route.ts` 68행 부근, `jam-web/src/lib/images/warmImageVariants.ts`

## 배경 / 문제 정의

티켓 20261115_1620 게이트 리뷰(민지)의 범위 밖 발견물이다. 지금은 쓰이지 않는 변환본이 만들어질 수 있고, 표지 그림의 첫 요청은 예열되지 않는다. 비용은 그림 한 장에 변환 네 번이다.

## 완료 조건

- 배지가 아닌 그림의 예열 폭이 그 그림을 그리는 화면이 요청하는 폭과 같다
