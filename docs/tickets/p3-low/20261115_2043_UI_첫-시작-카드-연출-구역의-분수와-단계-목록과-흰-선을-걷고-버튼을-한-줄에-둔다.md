# [UI] «JAM! 시작하기» 카드 연출 구역의 분수·단계 목록·흰 선을 걷고 두 버튼을 한 줄에 둔다

## 핵심 요약

- 요구사항(사용자, 2026-11-15, 화면 캡처 첨부): ① «미리 해보기 n/7» 제거. ② «다음 단계» 버튼을 «건너뛰기» 버튼과 같은 크기로 줄이고, 건너뛰기와 같은 행의 카드 왼쪽 끝에 둔다. ③ «Strava 동기화»·«잠긴 아이템 배지 열기» 같은 단계 표시 제거. ④ 흰 선(구분선) 제거.
- 관련 파일(경로 기준 `jam-web/`): `src/app/(main)/OnboardingQuestCard.tsx`(`Header`·`DemoCta`·`DemoCard`·`Divider`), 시험 `src/app/(main)/OnboardingQuestCard.test.tsx`, 문서 `docs/service/prd/home-feed/PRD.md`(연출 중 줄).
- 직전 작업: 티켓 `20261115_1932`(카드 면 퍼플·흰 알약 CTA).

## 구현

- 연출 중 카드에서만 바꿨다. 분수 라벨은 걷고 칩만 남긴다. 진행 정도는 `sr-only` 문장(«미리 해보기 7단계 중 n단계»)과 진행 막대가 알린다.
- «다음 단계»(동기화 차례의 «동기화» 포함)를 `size="xs"`로 줄여 «건너뛰기»와 같은 크기로 맞추고, `flex items-center justify-between` 한 줄에 왼쪽(다음 단계)·오른쪽(건너뛰기)으로 놓았다. 펄스 링과 흰 알약 칠은 그대로다. 화살표 아이콘은 16px에서 14px로 줄였다.
- 연출 중 카드의 구분선(`<hr>`)과 «내 활동으로 2단계» 체크 목록을 그리지 않는다. 쓰지 않게 된 `Divider`는 지웠다. `state.real` 값은 연출 구역에서 더 이상 읽지 않는다.
- 연출이 끝났거나 건너뛴 뒤의 «내 활동으로 n/2» 카드(실제 구역)는 그대로 둔다. 분수·진행 막대 트랙의 흰색도 그대로다.
