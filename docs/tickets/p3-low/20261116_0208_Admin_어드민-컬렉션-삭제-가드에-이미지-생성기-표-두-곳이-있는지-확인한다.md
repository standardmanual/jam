# [Admin] 어드민 컬렉션 삭제 가드에 이미지 생성기 표 두 곳이 있는지 확인한다

## 핵심 요약
- 요구사항: 컬렉션 되돌림의 참조 확인 목록(`ITEM_BOOK_UNDO_REFERENCE_TABLES`)에는 마이그레이션 337의 두 표(`badge_image_generations`, `badge_image_item_prompts`)가 빠져 있다가 티켓 20261115_0030에서 채워졌다. 어드민의 컬렉션 삭제 가드(`ITEM_BOOK_REFERENCE_SOURCES`)에도 같은 누락이 있는지 확인하고, 있으면 의도에 맞게 정한다.
- 구현 계획: 삭제 가드가 어떤 표를 확인하는지 읽고, 두 표가 없으면 «삭제를 막을지, 함께 지워지게 둘지»를 사용자에게 묻는다.
- 관련 파일: `jam-web/src/lib/admin/reference-guards.ts`(`ITEM_BOOK_REFERENCE_SOURCES`), `jam-web/src/lib/admin/registerChecks/references.ts`(133~152줄, 두 목록의 차이를 적은 주석과 되돌림 목록), `jam-web/supabase/migrations/337_*.sql`

## 배경 / 문제 정의
두 표는 `item_books`를 `ON DELETE CASCADE`로 참조한다. 컬렉션을 지우면 그 컬렉션의 배지 이미지 생성 기록이 확인 없이 함께 사라진다. 되돌림 쪽은 «하나라도 있으면 지우지 않는다»는 원칙(티켓 20261004_2039 가정 7)에 따라 이제 막힌다. 삭제 가드는 질의 방식이 달라 되돌림 목록과 합쳐져 있지 않으므로 따로 확인해야 한다.

## 완료 조건
- 삭제 가드가 두 표를 확인하는지 여부가 이 티켓에 기록돼 있다.
- 확인하지 않는다면 사용자의 결정(막기 또는 그대로 두기)이 기록돼 있고, 막기로 정했으면 가드와 시험에 반영돼 있다.
