# [Admin] 지운 옛 액티비티 배지 생성기를 가리키는 주석과 DB 칸 설명을 고친다

## 핵심 요약
- 요구사항: 옛 액티비티 배지 이미지 생성기를 지운 뒤(티켓 20261116_0809)에도 그 생성기를 가리키는 글이 두 곳에 남아 있다. 코드 주석 한 곳과 DB 칸 설명 한 곳을 지금 상태에 맞게 고친다.
- 구현 계획: 주석은 홈피드 문서 요구를 만족시키는 다른 변경과 함께 고치거나 훅의 요구 범위를 확인한 뒤 고친다. DB 칸 설명은 `COMMENT ON COLUMN` 한 줄짜리 마이그레이션으로 고친다.
- 관련 파일: `jam-web/src/lib/today/events.ts`(38행 주석. `admin/activity-badge-image/generate/route.ts`를 관례의 예로 든다), `jam-web/supabase/migrations/126_badges_image_gen_params.sql`(38행의 COMMENT가 원래 글. 이 파일은 고치지 않고 새 마이그레이션을 만든다), `.githooks/pre-commit`(`events.ts`를 커밋에 넣으면 홈피드 문서를 요구하는 규칙)

## 배경 / 문제 정의
- `events.ts` 38행은 «어드민 전용 라우트들과 동일한 관례»의 예로 지워진 파일을 든다. 동작에는 영향이 없다. 이 파일을 커밋에 넣으면 pre-commit이 홈피드 문서 변경을 함께 요구해서, 주석 한 줄만 고치는 커밋이 막힌다(티켓 20261116_0809에서 아현이 확인. 우회는 하지 않았다).
- `badges.image_gen_params`의 칸 설명은 옛 생성기의 저작값을 담는다고 적혀 있다. 지금은 템플릿 제작 화면의 조정값(`kind: 'activity-template'`)도 여기에 저장된다. 설명을 고치려면 프로덕션 공용 DB에 마이그레이션이 필요하다.

## 완료 조건
- `events.ts`의 주석이 남아 있는 어드민 라우트를 예로 들거나 예를 빼고 있다.
- `badges.image_gen_params`의 칸 설명이 옛 생성기와 템플릿 제작 화면의 조정값을 모두 설명한다. 마이그레이션 파일과 되돌림 SQL이 있다.
