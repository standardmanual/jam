# [UI] 지도의 지점 서클 안 보물 상자 아이콘을 키운다

## 핵심 요약

- 요구사항(사용자, 2026-11-16): 체크인 화면 지도에 표시되는 지점(드랍·픽업) 서클 안의 아이콘이 너무 작으니 더 키운다.
- 관련 파일(경로 기준 `jam-web/`): `src/components/map/MapView.tsx`(`dropMarkerIconHtml`, 아이콘 크기 `size * 0.6`), 시험 `src/components/map/dropMarkerGlyph.test.tsx`.

## 구현

- 아이콘 크기를 서클 지름의 0.6배에서 0.8배로 키웠다. 상수 `DROP_MARKER_GLYPH_RATIO`로 빼서 한 곳에서 정한다. 24px 서클이면 14.4px에서 19.2px가 된다.
- 서클은 2px 테두리가 안쪽을 줄여(24px 서클의 안쪽 20px) 0.8배면 테두리에 닿지 않고 서클을 채운다. 선택된 큰 서클도 같은 비율로 커진다.
- 서클 크기·색·테두리·배치는 그대로다. 픽업 가능(초록 면, 채움 아이콘)과 없음(회색 면, 선 아이콘) 두 상태가 같은 비율을 쓴다.

## 완료 기록

- 시험: `src/components/map` 4건 통과(아이콘이 19.2px인지 확인하는 시험 1건 추가), eslint 통과. 경미 수정 경로로 직접 처리했다.
- 실렌더: 위치 권한이 없는 로컬 환경이라 지도 자체는 열리지 않아, 마커 HTML을 따로 구워 0.6배와 0.8배를 나란히 비교했다. 0.8배는 서클을 채우되 테두리에 닿지 않는다.
- 확인하지 못한 항목: 실제 지도 위의 마커(네이버 지도 SDK), 줌 단계별 크기.
