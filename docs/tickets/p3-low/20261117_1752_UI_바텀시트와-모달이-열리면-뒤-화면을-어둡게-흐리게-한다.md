# [UI] 바텀시트와 모달이 열리면 뒤 화면을 어둡게 흐리게 한다

## 핵심 요약

- 요구사항(사용자, 2026-11-17): 바텀시트와 모달이 열리면 뒤 화면이 어둡게 깔리는 데 더해 흐리게도 보이게 한다.
- 구현 계획: 스크림 흐림 토큰 `--scrim-blur`(8px)를 `design-system/tokens/materials.css`에 만들고, 시트·모달 스크림 아홉 곳에 `backdrop-filter`로 적용한다. 투명도 줄이기 설정에서는 흐림이 0이 된다.
- 관련 파일(경로 기준 `jam-web/`): `design-system/tokens/materials.css`(토큰), `src/components/transitions.css`(`.t-panel-backdrop` 약 440줄·`.t-modal-backdrop` 약 717줄, 흐림 없음을 적은 주석 약 452줄), `design-system/components/navigation/BottomSheet.jsx`(스크림 약 72줄), `design-system/components/feedback/ModalToast.jsx`(약 70줄), `design-system/components/patterns/BadgeRevealCarousel.jsx`(약 432줄), `src/components/BadgeRevealOverlay.tsx`(약 186·209줄과 본 화면), `src/components/strava/PendingItemsPickOverlay.tsx`(약 403·425줄), 시험 `src/components/ui/__tests__/ConfirmModal.test.tsx`·`bottomSheetFaces.test.tsx`.

## 배경 / 문제 정의

- 티켓 20261015_2131(상위 결정 6)에서 JAM 2.0 라이트 전환 때 모달·시트 스크림의 흐림(8px)을 없앴다. 지금은 검정 50%만 깔린다.
- 흐림이 보이는 곳은 토스트가 떠 있는 동안의 막(검정 16%·4px, 티켓 20261112_2338)과 탭 바뿐이다. 사용자가 시트·모달에도 흐림을 되살리라고 정했으므로, 20261015_2131의 «blur 0» 결정은 스크림에 한해 이 티켓이 대체한다.

## 상세 요구사항

### UI/UX 관점
- 어둡기는 지금과 같다(`--backdrop`, 검정 50%). 흐림만 더한다. 흐림 정도는 이전 값인 8px로 둔다(사용자가 다른 값을 정하면 토큰 한 줄만 바꾼다).
- 적용 대상: 서비스 `BottomSheet`·`PoiCarouselModal`(`.t-panel-backdrop`), `ConfirmModal`(`.t-modal-backdrop`), `BadgeRevealOverlay`, `PendingItemsPickOverlay`, MODULAR `BottomSheet`·`ModalToast`·`BadgeRevealCarousel`.
- 토스트 막(`--toast-scrim-blur` 4px)은 그대로 둔다. 시트 위에 토스트가 뜨면 두 겹이 겹친다.
- 투명도 줄이기 설정에서는 흐림 없이 지금처럼 불투명 반전 면이 된다.

## 구현 계획

1. `materials.css`에 `--scrim-blur: 8px`를 더하고 `prefers-reduced-transparency: reduce`에서 0으로 둔다.
2. `transitions.css`의 두 스크림 클래스에 `backdrop-filter: blur(var(--scrim-blur))`를 더한다. 흐림 없음 주석을 새 결정에 맞게 고친다.
3. 인라인 스크림 7곳(BadgeRevealOverlay 2, PendingItemsPickOverlay 2, MODULAR 3)에 같은 속성을 더한다.
4. 디자인 시스템 매니페스트(`ds-manifest-sync.mjs`)를 맞추고, 흐림을 확인하는 시험을 더한다.

## 완료 조건

- 시트·모달 스크림 아홉 곳(CSS 클래스 두 개, 인라인 일곱 곳)이 `var(--scrim-blur)`를 쓴다.
- 투명도 줄이기에서 흐림이 없다는 것을 시험이 확인한다.
- lint·관련 vitest·`ds:check`가 통과한다.

## 완료 기록

- 구현: 토큰 `--scrim-blur: 8px`(투명도 줄이기에서 0px)를 `materials.css`에 만들고, `.t-panel-backdrop`·`.t-modal-backdrop`과 인라인 스크림 7곳에 적용했다. 모달 스크림은 투명도 줄이기에서 필터를 명시적으로 끈다. 디자인 시스템 매니페스트에 토큰을 기록했다(`npm run ds:manifest -- --write`).
- 문서: 기획 문서 `docs/plan/jam2/11 JAM 2.0 디자인 시스템.md`의 «blur 남길지» 미결 두 곳에 결정을 적었다. 20261015_2131 본문은 이력이라 고치지 않았다.
- 시험: `scrimBlur.test.ts` 신규(토큰·클래스·인라인 스크림 7곳), `src/components/ui/__tests__` 24개 파일 489건 통과, eslint 통과. `src/components`·`design-system` 전체에서 실패 28개 파일은 모두 어드민(`components/admin/**`) 시험으로, 이 변경과 무관한 기존 실패다.
- 확인하지 못한 항목: 실제 화면(iOS Safari 포함)에서 시트가 열릴 때의 흐림 모습과 열림·닫힘 페이드 중 끊김. 백드롭은 투명도로 페이드하므로 흐림 값은 보간되지 않고 필터 결과가 같이 옅어진다. 흐림이 너무 강하거나 약하면 토큰 한 줄(`--scrim-blur`)만 바꾸면 된다.
- 경미 수정 경로로 직접 처리했다.
