# [UI] 체크인 지점 배지 칸에 등급 칩이 없으면 칸이 칩 줄만큼 늘어나지 않게 한다

## 핵심 요약

- 요구사항(사용자, 2026-11-17): 체크인 지점의 배지 목록에서 등급 칩이 없는 칸은 회색 면이 칩 자리만큼 늘어날 필요가 없다. 컬렉션 상세 등에서 쓰는 BadgeGridCard 공통 규칙과 같게 한다.
- 원인: 지점 갤러리용 `compact` 변형만 칩 줄(높이 24)을 칩이 없어도 항상 확보했고(티켓 20261114_2352), 칸 높이도 `grid-auto-rows`로 고정했다. 기본 변형은 칩이 없으면 줄 자체를 그리지 않는다.
- 관련 파일(경로 기준 `jam-web/`): `src/components/ui/BadgeGridCard.tsx`(compact 분기의 칩 줄, `hasChip`), `src/components/PoiCarouselModal.tsx`(`PoiBadgeGallery`의 `gridAutoRows`, 높이 상수 주석), 시험 `src/components/ui/__tests__/BadgeGridCard.compact.test.tsx`·`src/components/PoiCarouselModal.test.tsx`.

## 구현

- `compact`의 칩 줄(h-6)을 칩이 실제로 그려질 때만 둔다. 칩이 그려지는 조건은 Lv 칩이 있거나, 등급이 있고 Common이 아니거나(`showCommonChip`이면 Common도)다. 칩이 없으면 이름 아래에서 칸이 끝난다.
- 갤러리의 `grid-auto-rows` 고정을 풀어 행 높이가 내용을 따르게 했다. 같은 행 안의 칸은 그리드 정렬(stretch)로 가장 큰 칸 높이에 맞춘다. 칩이 있는 칸의 높이는 이전 고정값과 같다(칸 폭 + 66).
- 본문 슬롯 높이(`GALLERY_H`)는 그대로 둔다. 시트 전체 크기는 바뀌지 않고, 칩이 없는 행이 낮아지면 갤러리 아래쪽이 비는 것으로 나타난다(티켓 20261114_2352 «카드 크기 고정» 결정 유지).

## 완료 조건

- compact 카드는 Common·등급 없음이면 칩 줄이 없고, 등급 칩·Lv 칩·`showCommonChip`일 때만 있다.
- 갤러리에 고정 행 높이가 없다.

## 완료 기록

- 시험: `BadgeGridCard.compact.test.tsx`·`PoiCarouselModal.test.tsx`의 칩 줄 단정을 새 규칙으로 고치고 무한레벨형·Lv·Common 켬 경우를 더했다. `src/components/ui/__tests__`·`PoiCarouselModal.test.tsx` 505건 통과, eslint 통과. 경미 수정 경로로 직접 처리했다.
- 확인하지 못한 항목: 실제 화면의 칸 높이 실측(위치 권한이 없는 로컬 환경이라 지점 시트를 열지 못했다). 칩이 있는 칸과 없는 칸이 같은 행에 섞일 때의 모습도 직접 보지 못했다.
