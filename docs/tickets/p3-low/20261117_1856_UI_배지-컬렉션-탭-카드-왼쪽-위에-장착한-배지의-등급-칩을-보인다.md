# [UI] 배지 컬렉션 탭 카드 왼쪽 위에 장착한 배지의 등급 칩을 보인다

## 핵심 요약

- 요구사항(사용자, 2026-11-17): 배지 화면 컬렉션 탭 목록의 카드 왼쪽 위에 컬렉션에 들어 있는 배지의 등급 칩을 보인다. Common 칩은 보이지 않는다.
- 사용자 결정(2026-11-17): «들어 있는 배지»는 **내가 슬롯에 장착한 배지**다. 낮은 등급부터 나열하고 Common은 그리지 않는다. 장착한 배지가 없거나 Common뿐이면 칩이 없다.
- 원인: 카드는 이미 왼쪽 위 칩 자리가 있었지만, 컬렉션 하나가 등급 하나라는 옛 전제로 «컬렉션의 첫 아이템 배지의 등급» 하나만 그렸다. 지금 컬렉션은 전부 4등급(Common·Rare·Epic·Mystic 각 9개)이라 첫 배지가 Common이면 칩이 한 번도 나오지 않았다.
- 관련 파일(경로 기준 `jam-web/`): `src/app/(main)/badges/page.tsx`(`rarityByBook` 자리, `itemBookProgress` 산출), `src/app/(main)/badges/BadgesClient.tsx`(`ItemBookProgress`, 컬렉션 탭 카드 호출), `src/components/ui/CollectionGridCard.tsx`, `design-system/components/patterns/CollectionGridCard.{jsx,d.ts,stories.tsx}`, 시험 `CollectionGridCard.tagOrder.test.tsx`·`badges/__tests__/page.test.tsx`.

## 구현

- `CollectionGridCard`(서비스·MODULAR)에 `rarities?: BadgeRarity[]` 속성을 더했다. 넘기면 낮은 등급부터 칩을 나열하고(Common 제외) `rarity`는 무시한다. `rarities`가 없으면 기존 `rarity` 하나로 같은 규칙을 쓴다(운영툴 미리보기·컬렉션 상세 호출은 그대로). 칩이 하나도 없으면 칩 행 자체를 그리지 않는다.
- 배지 화면 `page.tsx`가 이미 읽던 슬롯(`user_item_book_slots`)과 컬렉션 소속 배지의 등급을 맞춰 컬렉션별 장착 등급 집합을 만들고, `ItemBookProgress.rarity`를 `rarities`로 바꿨다. 새 조회는 없다.
- Storybook에 «장착한 등급 칩 여러 개» 이야기를 더했다.

## 완료 조건

- 장착한 배지가 Rare·Mystic이면 카드 왼쪽 위에 Rare, Mystic 칩이 이 순서로 보인다. Common은 보이지 않는다. 장착한 배지가 없거나 Common뿐이면 칩이 없다.

## 완료 기록

- 시험: 카드 시험(서비스·MODULAR 둘 다) 2건과 배지 페이지 등급 산출 시험 1건을 더하고 기존 단정을 `rarities`로 고쳤다. `src/app/(main)/badges`·`src/components/ui/__tests__` 584건 통과, eslint 오류 없음(MODULAR 카드의 `<img>` 경고는 기존), `tsc --noEmit` 오류 없음. 경미 수정 경로로 직접 처리했다.
- 확인하지 못한 항목: 실제 화면에서 칩이 여러 개일 때(좁은 2열 폭, 줄바꿈) 썸네일 위 모습. 칩 세 개는 한 줄에 들어가지만 폭이 좁은 기기에서는 두 줄이 될 수 있다.
