# [Admin] «운동 수치» 템플릿을 새 그림으로 바꾼다

## 핵심 요약

- 요구사항(사용자, 2026-11-17): 사용자가 준 `Group 20.svg`로 «운동 수치» 분류의 템플릿을 바꾼다.
- 바뀐 점: 이전 그림은 922×922 햇살 모양 원이었고 이름·값이 둘 다 원호였다. 새 그림은 764×764 원이다. 위쪽 반원(주황)에 이름이 원호로, 아래쪽 반원(초록 그라데이션)에 값이 가로 직선으로, 그 아래에 노란 Jam 로고가 놓인다.
- 관련 파일(경로 기준 `jam-web/`): `src/lib/admin/activityBadgeTemplate/templates/metricSvg.ts`(원본 SVG, 사용자의 파일 그대로), `templates/metric.ts`(정의), `__tests__/templateDefs.test.ts`. 문서 `docs/service/prd/asset-generator/PRD.md` 17.3.

## 구현

- `metricSvg.ts`를 새 파일(sha256 앞 12자리 0e39f098a9b5)로 통째로 바꿨다. 이름은 모양(`<path id="name">`), 값은 글자(`<text id="value">`)로 이미 레이어 이름이 붙어 있어 id를 바꾸는 별도 처리가 필요 없다.
- 이름 자리(원호): 샘플 글자 «동해물과 백두산이 마르고 닳»에 Noto Sans KR 900을 겹쳐 맞춘 값이다(헤드리스 크롬, 겹침 비율 0.88). 중심 (382, 382), 기준선 반지름 267.93, 가운데 0.09°, 글자 윗부분이 바깥, 글자 크기 71.34, 자간 −0.0669em, 샘플이 차지한 각도 166.95°, 색 #000000.
- 값 자리(직선): 원본 `<text>`의 속성 그대로다. 왼쪽 위 기준 x 98.4085, 기준선 y 535.408, 글자 크기 108.333, 굵기 900, 자간 −0.08em, 색 #000000. 샘플 «1829283km»의 폭이 약 568이라 가운데가 그림 가운데(382)에 놓인다. 긴 값은 폭 620까지만 쓰고 넘으면 글자 크기를 줄인다(`maxWidth`, 아래 반원 안에 머물게 하는 값이며 카리나가 정했다).
- 글꼴은 이전 사용자 답(이름·값 모두 Noto Sans KR Black)을 그대로 썼다. 이번 파일의 `<text>`도 Noto Sans KR 900이다.
- 시험(`templateDefs.test.ts`)의 metric 구역을 새 수치와 구조(원본에 name·value 레이어가 하나씩, 걷어 내도 반원·로고가 남음, 색 세 가지, 값 직선 배치, 이름 원호 각도)로 고쳤다. PRD 17.3의 정의된 분류 설명을 고쳤다.

## 완료 조건

- `getBadgeTemplateDef('metric')`이 위 수치를 돌려주고 이름은 원호 자리, 값은 직선 자리다.
- 영역 시험이 통과한다: `cd jam-web && npx vitest run src/lib/admin/activityBadgeTemplate src/app/admin/activity-badge-template`.

## 완료 기록

- 시험: 영역 13개 파일 172건 통과, eslint 통과. 경미 수정 경로로 직접 처리했다(파이프라인은 쓰지 않았다).
- 시험 그림: 실제 배지 이름·값(«건조기 도는 동안 걸은 날» 1시간, «트럭 꽁무니를 따라 뛴 저녁» 21.1km, «오르막 끝에서 만난 능선» 1,947m, «제일 빨리 달린 날» 6분 15초)을 같은 계산식으로 놓은 그림을 사용자에게 보냈다.
- 확인하지 못한 항목: ① 로컬 어드민에서 실제 미리보기·등록 흐름 확인(이번에는 계산식을 직접 돌린 그림만 확인했다). ② 템플릿 색 조정 중 아래 반원의 그라데이션(원본은 `foreignObject`의 원뿔 그라데이션)이 색 칸으로 읽히지 않아 색 계열·HUE 조정에서 아래 반원 색이 안 바뀔 수 있다(위 반원 주황과 로고 노랑은 읽힌다). ③ 이름 겹침 비율 0.88은 이전 템플릿(0.92)보다 낮다. 남은 차이의 원인은 확인하지 못했다.
- 실제 배지 이미지 등록은 하지 않았다(프로덕션 배지 이미지를 바꾸는 일이라 사용자가 말할 때 한다).
