# [Admin] 액티비티 배지 화면에서 미리보기를 검색 결과 왼쪽으로 옮기고 결과 목록을 끝까지 보이게 한다

## 핵심 요약

- 요구사항(사용자, 2026-11-17): 어드민 «액티비티 배지» 화면의 미리보기 영역을 검색 결과 왼쪽으로 옮긴다. 검색 결과 영역을 더 길게 해서 목록이 다 보이게 한다.
- 관련 파일(경로 기준 `jam-web/src/app/admin/activity-badge-template/`): `BadgeStudio.tsx`(미리보기를 `BadgePicker`의 `preview`로 넘김), `BadgePicker.tsx`(결과 영역을 미리보기와 나란한 격자로 감쌈, 결과 표의 높이 제한 `max-h-96` 제거), `BadgePreview.tsx`(좁은 칸에서 안쪽을 한 열로).

## 구현

- 위에서 아래로 «검색 조건 카드 → 미리보기 카드 → 검색 결과 카드» 순이던 것을, 검색 조건 카드 아래에 «미리보기(왼쪽) | 검색 결과(오른쪽)»를 둔다. 폭 1280px 이상(`xl`)에서 나란히 놓이고, 그보다 좁으면 이전처럼 위아래로 쌓인다(미리보기가 먼저).
- 미리보기 칸은 폭 460px로 고정이고, 안쪽의 그림과 조정 패널은 한 열로 쌓인다(그보다 좁은 화면에서는 이전처럼 두 열). 결과 목록을 아래로 내려도 미리보기가 화면 위에 붙어 따라오고, 미리보기가 화면보다 길면 칸 안에서만 스크롤한다.
- 검색 결과 표의 높이 제한(384px, 안쪽 스크롤)을 없앴다. 한 쪽 50건이 모두 펼쳐지고 화면 전체가 스크롤된다.

## 완료 조건

- 폭 1280px 이상에서 미리보기가 검색 결과 왼쪽에 놓이고, 결과 표에 안쪽 스크롤이 없다.

## 완료 기록

- 실렌더(로컬 어드민, 폭 1600): 검색하면 왼쪽에 미리보기, 오른쪽에 «검색 결과 320건»이 놓이고 표 컨테이너 높이가 4098px로 50행이 모두 펼쳐진다. 첫 배지를 고르고 아래로 내려도 미리보기가 왼쪽에 붙어 따라온다. `activity-badge-template` 시험 27건과 eslint 통과. 경미 수정 경로로 직접 처리했다.
- 확인하지 못한 항목: 폭 1280~1400처럼 결과 칸이 좁은 화면에서 표 글자의 줄바꿈 모습, 폭 1280 미만에서 쌓인 모습.
