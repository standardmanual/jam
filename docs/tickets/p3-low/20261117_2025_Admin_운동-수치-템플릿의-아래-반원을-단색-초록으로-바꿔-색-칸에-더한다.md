# [Admin] 운동 수치 템플릿의 아래 반원을 단색 초록으로 바꿔 색 칸에 더한다

## 핵심 요약

- 요구사항(사용자, 2026-11-17): 방금 바꾼 운동 수치 템플릿에서 그라데이션이 있는 아래 반원은 그린 컬러로 적용하고 색 칸에 추가한다.
- 원인: 원본의 아래 반원은 원뿔 그라데이션을 `foreignObject`의 CSS로 그린 묶음이라 색 추출(`extractSvgColors`)이 읽지 못했고, 색 계열·HUE 조정이 이 반원에 먹지 않았다.
- 관련 파일(경로 기준 `jam-web/src/lib/admin/activityBadgeTemplate/`): `templates/metric.ts`(`flattenLowerHalf`, `METRIC_LOWER_HALF_GREEN`), `__tests__/templateDefs.test.ts`. 원본 `templates/metricSvg.ts`는 고치지 않았다.

## 구현

- `flattenLowerHalf`가 원본의 `<g id="Subtract_2">`(그라데이션 묶음)를 같은 모양의 단색 `<path id="Subtract_2" fill="#0A8B5E">`로 바꾼 사본을 돌려주고, `METRIC_TEMPLATE.svg`가 이 사본을 쓴다. 해당 묶음이 없으면 원본을 그대로 돌려준다.
- 초록 `#0A8B5E`는 원본 그라데이션 두 끝색(`#005B3B`, `#14BA80`)의 가운데 색이다. 사용자가 구체적인 초록 값을 말하지 않아 카리나가 원본 그림의 분위기를 지키려고 정했다. 바꾸고 싶으면 `METRIC_LOWER_HALF_GREEN` 한 줄이다. 어드민에서는 색 칸으로 바로 조정한다.
- 색 칸은 이제 글자 #000000, 위 반원 #FF5900, 아래 반원 #0A8B5E, 로고 #FBFF00 네 가지다.

## 완료 조건

- 운동 수치 템플릿의 색 칸에 아래 반원 초록이 있고, 색 조정이 그 반원에도 먹는다. 그라데이션 마크업(`foreignObject`)이 정의의 SVG에 남아 있지 않다.

## 완료 기록

- 시험: `templateDefs.test.ts`에 단색 확인, 원본과 다른 곳이 그 묶음 하나뿐인지 확인, 색 조정 적용 확인, 묶음이 없을 때 원본 그대로를 더했다. 영역 13개 파일 175건 통과, eslint 통과. 경미 수정 경로로 직접 처리했다.
- 실렌더: 같은 계산식으로 실제 배지 이름·값을 놓은 시험 그림에서 아래 반원이 단색 초록으로 그려지는 것을 확인했다. 로컬 어드민 색 칸 화면은 열어 보지 않았다.
- 확인하지 못한 항목: 그라데이션이 사라져 원본 시안보다 아래 반원이 단조로워진 점(사용자의 지시에 따른 결과다).
