# [UI] 캡슐 게이지 트랙 위의 회색 점을 없앤다

## 핵심 요약

- 요구사항(사용자, 2026-11-19): 캡슐 게이지의 중간중간 찍혀 있는 회색 가운데 점을 제거한다.
- 관련 파일(경로 기준 `jam-web/`): `src/components/capsule/CapsuleGauge.tsx`(`DOT_POSITIONS`·`DOT_SIZE_PX`와 트랙 안쪽의 점 4개를 그리는 부분), 시험 `src/components/capsule/CapsuleGauge.test.tsx`, 문서 `docs/service/prd/home-feed/PRD.md` 캡슐 게이지 절.

## 구현

- 트랙 위 20·40·60·80% 자리의 점 4개(3px, 밝은 색 22%)를 그리지 않는다. 점 상수 두 개도 지웠다. 트랙·채움·테두리·숫자·이름표와 모션은 그대로다.
- 홈 게이지(`CapsuleGauge`)만 점이 있었다. 컬렉션 카드·진행도 줄이 쓰는 `ProgressBar` 캡슐 모양은 원래 점이 없다(그 컴포넌트의 주석에 남아 있던 «점은 게이지 전용» 서술만 고쳤다).
- 시험은 «점 4개가 있다»를 «점을 그리지 않는다»로 뒤집었다. PRD 캡슐 게이지 절의 «점 4개» 서술을 고쳤다.

## 완료 조건

- 캡슐 게이지(값 0·중간·가득)에 `left:20%` 등 점 자리가 없다. 관련 시험이 통과한다: `cd jam-web && npx vitest run src/components/capsule`.

## 완료 기록

- 시험: `src/components/capsule`·`ProgressBar.markup` 6개 파일 160건 통과, eslint 통과. 경미 수정 경로로 직접 처리했다.
