# [UI] 글로우 안쪽 빛을 시안의 밝은 부분 모양으로 키운다

## 핵심 요약
- 요구사항(사용자, 2026-11-20): 안쪽 glow가 너무 약하다. 첨부한 시안(핑크 그라데이션 카드)의 밝은 부분 모양대로 안쪽 glow를 구현한다.
- 시안에서 밝은 부분은 카드 윤곽을 따라 감싼다. 모서리와 좌우 가장자리가 가장 밝고 안쪽으로 갈수록 진한 색에 녹아들며, 위쪽 띠는 옆면보다 얇고 아래는 흰색으로 이어진다.
- 변경 파일은 `jam-web/src/lib/badgeAura.ts`의 `auraGlowInsetShadow` 하나다(약 10줄). 상세 히어로와 목록 카드가 함께 쓰므로 둘 다 바뀐다.

## 완료 기록
### 처리 내용
- 옛 안쪽 빛(`inset 0 0 192 30 @0.65` + `inset 0 0 72 0 @0.8`)은 블러가 너무 넓고 알파가 낮아 가장자리에서 거의 보이지 않았다. 두 겹 구조는 그대로 두고 값만 바꿨다.
  1. 넓은 띠: `inset 0 -10 76 14`(360px 기준), 알파 0.9. 가장자리에서 거의 불투명하게 시작해 옆면은 폭의 약 14%까지 번진다. y 오프셋을 위로 밀어 위쪽 띠를 옆면보다 얇게 했다.
  2. 좁은 테두리 빛: `inset 0 0 28 0`, 알파 0.85. 윤곽 바로 안쪽에 밝은 림을 만든다.
- 색은 중간 색 대신 밝은 색 자리(팔레트 첫째)를 흰색 쪽으로 섞은 값을 쓴다(띠 35%, 테두리 70%). 미획득은 무채색이다.
- 길이는 모두 `auraGlowMetrics().len`을 거치므로 면 크기(px·cqw)에 비례해 줄어든다. 음수 오프셋도 같다.
