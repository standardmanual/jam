# [UI] 배지 그리드 카드의 글로우 썸네일을 카드 가장자리까지 채운다

## 핵심 요약
- 요구사항(사용자, 2026-11-20): 배지 이미지는 그리드 목록에서 카드 안 패딩 없이 보여야 한다. 텍스트와 칩은 그대로 둔다.
- 대상은 서비스 `BadgeGridCard`(일반, compact 아님)에서 글로우(`bgColors`)가 깔리는 썸네일이다. 글로우 면이 카드 위·좌·우 가장자리까지 꽉 찬다.
- 코드: `jam-web/src/components/ui/BadgeGridCard.tsx`(약 20줄), 시험 `BadgeGridCard.aura.test.tsx`.

## 완료 기록
### 처리 내용
- 썸네일 래퍼를 `w-[calc(100%+1.5rem)] -mt-3`로 카드 여백(p-3)만큼 키운다. 카드(`rounded-2xl overflow-hidden`)가 위 모서리를 자르고, 아래는 글로우가 순백으로 끝나 카드 면(`--card-bg` 흰색)과 이어지므로 썸네일 면은 둥글리지 않는다.
- 글로우는 `glowSize="container"`로 바꿨다. 면 폭이 칸마다 달라 compact와 같이 면이 컨테이너(`container-type: inline-size`)가 되고 블러·여유·안쪽 빛이 폭에 비례(cqw)한다. 이미지는 면이 커진 만큼 128px로 요청한다(2배 변환본은 기존과 같은 256).
- 그림이 면에서 차지하는 비율(약 91%)과 점선 윤곽(`SlotOutline` inset 4/90)이 그대로 맞도록 면 안쪽 여백을 `p-1` 대신 `p-[4.4%]`로 준다.
- ×N 필은 가장자리에서 잘리지 않게 `bottom-2 right-2`로 안쪽에 둔다.
- 이름·칩 줄(`pt-2`, 칩, 방문 횟수 칩)과 카드 여백은 그대로다.
- **글로우가 없는 카드**(`bgColors` 없음), **locked**, **undiscovered**, **compact**는 바꾸지 않았다.

### 열린 항목 / 핵심 메모
- 같은 그리드에 글로우 카드와 locked·undiscovered·색 없는 카드가 섞이면 앞쪽만 가장자리까지 차고 나머지는 90px 안쪽 면이라 크기가 어긋난다. 어떻게 맞출지는 사용자 결정이 필요하다.
- 디자인 시스템 `BadgeGridCard`(`thumbBackground` 슬롯)는 아직 안쪽 면 기준이다. 가장자리 채움을 DS에도 옮길지는 위 결정과 함께 정한다.
- 카리나 직접 처리(경미 수정, 파일 1개와 시험 1개).
