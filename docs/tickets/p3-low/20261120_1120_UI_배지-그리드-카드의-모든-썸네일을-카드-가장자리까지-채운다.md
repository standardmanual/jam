# [UI] 배지 그리드 카드의 모든 썸네일을 카드 가장자리까지 채운다

## 핵심 요약
- 요구사항(사용자, 2026-11-20): 직전 티켓(20261120_1113)은 글로우가 있는 카드만 가장자리까지 채웠다. 글로우 없는 카드·잠김·미발견 칸도 같이 채운다.
- 이유: 한 그리드에 섞이면 글로우 카드만 커서 크기가 어긋난다.
- 코드: `jam-web/src/components/ui/BadgeGridCard.tsx`(일반 분기). compact는 별도 고정 규격이라 바꾸지 않았다.

## 완료 기록
### 처리 내용
- 썸네일 래퍼를 모든 일반 카드에서 `w-[calc(100%+1.5rem)] -mt-3`로 카드 여백(p-3)만큼 키운다. `max-w-[90px]`는 없앴다.
- 글로우 없는 카드: 면이 없어 그림이 카드 폭을 채운다(면 안쪽 여백 `p-[4.4%]`는 같다). 이미지는 128px로 요청한다.
- 잠김 칸: `LockedTile`을 `size 128`, 폭 100%, 모서리 0으로 그린다. 면이 카드 면과 같은 흰색이라 자물쇠만 보이고 크기는 다른 카드와 같다.
- 미발견·넣을 수 있는 칸: `SlotOutline`을 `size 128`·`inset 6`·`maxWidth: none`으로 그린다. inset 6은 그림 여백(4.4%)과 점선 윤곽이 겹치도록 맞춘 값이다.
- 대체 아이콘(`MedalIcon`)은 면이 커진 만큼 `w-14 h-14`로 키웠다.
