# [UI] 배지 그리드 카드 썸네일을 카드 여백과 같은 두께의 안쪽 면으로 되돌린다

## 핵심 요약
- 요구사항(사용자, 2026-11-20): 첨부한 시안처럼 카드 안 패딩 두께만큼 썸네일 둘레에 여백을 다시 두고, 배지별 대표색 글로우를 실제 서비스 배지 30개 샘플 그리드로 보여 준다.
- 직전 두 티켓(20261120_1113·1120)의 «카드 가장자리까지 채움»을 되돌린다. 단, 예전의 `max-w-[90px]` 상한은 없앤다. 폭은 칸 폭에서 좌우 여백(p-3)을 뺀 값이라 위·좌·우 여백이 같다(예전에는 좌우가 더 넓었다).
- 코드: `jam-web/src/components/ui/BadgeGridCard.tsx`(일반 분기), 시험 3개.

## 완료 기록
### 처리 내용
- 썸네일 래퍼 `relative w-full`, 면 `rounded-2xl`로 되돌렸다. ×N 필은 면 모서리 바깥쪽(`-bottom-1 -right-1`), 대체 아이콘은 `w-12 h-12`다.
- 글로우 없는 카드·잠김·미발견·넣을 수 있는 칸이 모두 같은 크기를 쓴다(이미지 요청 128px, `LockedTile` 128·폭 100%, `SlotOutline` 128·inset 6). 그림 안쪽 여백은 면 폭의 4.4%다.
- 실측(390px 폭, 3열): 카드 109px 폭, 썸네일 면 85px 정사각형, 카드 가장자리에서 위·좌 12px로 같다.

### 샘플 그리드
- 임시 화면 `/spike/grid-bleed`에 DB `badges`에서 무작위로 뽑은 실제 서비스 배지 30개(액티비티 8, 아이템·진영 20, 지하철 2)와 배지별 `bg_colors`를 넣었다. 일부는 ×3·미획득으로 표시했다. 화면 확인 후 지운다.
- 관찰: 진영(factions) 배지 PNG 상당수가 불투명한 검은 정사각 바탕이라 글로우가 그림에 가려진다. 이 배지들은 글로우 효과를 보려면 투명 배경 이미지가 필요하다.
- 관찰: 글로우가 시안보다 옅다. 색 보정(명도 0.8~0.94, 채도 상한 0.76)과 안쪽 흰 빛이 색을 많이 덮는다.
