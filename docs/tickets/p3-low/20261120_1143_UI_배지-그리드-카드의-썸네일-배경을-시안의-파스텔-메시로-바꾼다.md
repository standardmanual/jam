# [UI] 배지 그리드 카드의 썸네일 배경을 시안의 파스텔 메시로 바꾼다

## 핵심 요약
- 요구사항(사용자, 2026-11-20): 이전에 만든 글로우 그라데이션이 아니라, 첨부한 시안(카드 속 정사각 썸네일)과 같은 배경 느낌을 원한다. 배지 이미지에서 고른 대표색으로, 배지마다 다르게(랜덤) 적용한다.
- 시안의 배경은 크림색 바탕에 같은 계열 색 덩어리가 모서리에서 번지는 파스텔 메시다. 글로우와 달리 아래 흰 띠·안쪽 빛 테두리·블러 면이 없다.
- 코드: `jam-web/src/lib/badgeAura.ts`(`auraMeshLayers`·`auraMeshBase`·`auraMeshSeed`), `BadgeAuraBackground.tsx`(`variant="mesh"`), `ui/BadgeGridCard.tsx`(일반 카드가 mesh 사용).

## 완료 기록
### 처리 내용
- 색 덩어리는 진한 색·중간 색 두 가지만 쓴다(사용자의 이전 지시 «지정된 것 중 2개»). 모두 gradient 한 장의 `background`로 그려 블러·안쪽 그림자가 없다.
- **얼룩덜룩 보정(사용자 지시, 같은 날)**: 처음 버전은 덩어리 셋이 모서리마다 따로 떠 있어 얼룩져 보였다. 덩어리를 둘로 줄이고 면보다 크게(반경 100% 이상) 서로 겹치게 했으며, 맨 아래에 중간 색→진한 색 대각선 선형 바탕을 깔아 사이에 빈 곳이 없게 했다. 가운데 흰 하이라이트는 알파 0.35로 넓게 낮췄다.
- 덩어리 배치(진한 색 모서리·중간 색 반대 모서리·대각선 방향)는 4가지 프리셋 중 하나를 시드(배지 이름, 없으면 색 목록)의 FNV-1a 해시로 고른다. 배지마다 다르되 렌더마다 같아 서버·클라이언트가 어긋나지 않는다(`Math.random` 미사용).
- **채도 낮춤(사용자 지시, 같은 날)**: 메시는 글로우와 별도의 색 보정표(`AURA_MESH_TUNING`)를 쓴다. 채도 배율 0.8→0.5, 하한 0.4→0.25, 상한 0.76→0.5. 명도(0.94·0.88·0.8)와 자리별 채도 비율은 같다. 글로우(상세 히어로·compact)의 보정표는 그대로다.
- **채도를 한 번 더 낮춤(사용자 지시, 같은 날)**: `AURA_MESH_TUNING`의 채도 배율 0.5→0.34, 하한 0.25→0.16, 상한 0.5→0.34.
- **얼룩덜룩 보정 2차(사용자 지시, 같은 날)**: 가운데 흰 하이라이트를 없앴다(가운데만 밝은 점이 얼룩처럼 보였다). 두 덩어리의 색상이 멀면 경계가 얼룩이 되므로 중간 색 덩어리를 진한 색 쪽으로 40% 당겼다(`MESH_MID_PULL`). 덩어리 알파는 진한 색 0.5, 중간 색 0.4다.
- **썸네일 여백 실측·보정(사용자 지시, 같은 날)**: 시안(카드 314px 폭)은 썸네일 둘레 여백이 16px로 카드 폭의 약 5.1%다. 우리 카드는 12px(10.5~12.1%)로 두 배 넓었다. 썸네일 래퍼를 \`w-[calc(100%+0.75rem)] -mt-1.5\`로 키워 위·좌·우 6px(5.3~6.1%, 360·390·430px 폭에서 실측)로 맞췄다. 이름·칩 줄의 여백(12)은 그대로다. 시안의 썸네일은 정사각이 아니라 가로가 약 8% 더 긴 비율(280×258)인데, 정사각을 유지했다.
- **상세 히어로 반영(사용자 지시, 같은 날)**: `BadgeHeroSection`의 배경도 메시(`variant="mesh"`, 시드는 배지 이름)로 바꿨다. 그리드 카드와 같은 시드라 같은 배지는 목록과 상세에서 모양이 같다. 카드 바탕색(`#ffffff`)·어두운 글자 고정(`strongText`)·미획득 그레이는 그대로다. 임시 화면 `/spike/hero-mesh`에서 4개(획득 3·미획득 1)를 390px 폭으로 확인했다. 시험은 `BadgeHeroSectionAura.test.tsx` 2건을 메시 기준으로 고쳤다.
- 미획득(`gray`)은 바탕·덩어리 모두 무채색이다.
- `BadgeAuraBackground`에 `variant`(`glow` 기본, `mesh`)와 `seed`를 더했다. **compact 카드는 그대로 글로우**다(상세 히어로는 아래 «상세 히어로 반영»에서 메시로 바꿨다).
- 이미지 요청 폭은 90으로 되돌렸다(직전 128 변경이 `BadgeImageWarmup`·`dropMapWarmup`이 미리 받는 변환 주소(96·256)와 어긋나게 만들었다). 면이 85px라 2배(256)로 충분하다.

### 열린 항목
- compact 카드도 메시로 통일할지는 사용자 결정이 필요하다.
- 진영(factions) 배지 PNG 상당수는 불투명한 검은 정사각 바탕이라 배경이 가려진다. 투명 배경 이미지가 필요하다.
- 어드민 시험 약 400건의 `useState` null 실패는 이전부터 있던 것으로 이번 변경과 무관하다.
