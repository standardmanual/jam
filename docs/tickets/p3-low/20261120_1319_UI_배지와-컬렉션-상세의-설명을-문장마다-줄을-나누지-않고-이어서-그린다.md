# [UI] 배지와 컬렉션 상세의 설명을 문장마다 줄을 나누지 않고 이어서 그린다

## 핵심 요약

- 요구사항(사용자, 2026-11-20): 배지 상세의 설명 글이 좌우 여백이 남는데도 너무 일찍 줄이 바뀐다. 이렇게 되지 않게 한다.
- 원인: 설명을 마침표 기준으로 나눠 문장마다 `<p>` 하나씩 그렸다(티켓 20260917_1211). 그래서 «우리의 하루는 남들보다 길어. / 놀러와. / @hzbz. / runclub»처럼 짧은 문장도 따로 줄을 차지했다.
- 관련 파일(경로 기준 `jam-web/`): `design-system/components/cards/BadgeHeroSection.jsx`(`descriptionLines` 렌더), `src/app/(main)/collections/[id]/ItemBookHeroSection.tsx`(설명 렌더), `src/lib/splitDescriptionSentences.ts`(주석), 시험 `src/components/ui/__tests__/BadgeHeroSection.test.tsx`·`src/app/(main)/badges/[id]/__tests__/heroLayout.test.tsx`·`heroTextColor.test.tsx`·`src/app/(main)/collections/[id]/__tests__/heroTextColor.test.tsx`.

## 구현

- 나눈 문장을 한 문단(`<p>`) 안에 공백으로 이어 붙인다. 문장마다 `inline-block` 조각이라 줄이 바뀔 때 문장 한가운데서 끊기지 않고, 한 줄보다 긴 문장만 그 안에서 줄이 바뀐다.
- 배지 상세(DS `BadgeHeroSection`)와 컬렉션 상세(`ItemBookHeroSection`)에 같은 규칙을 적용했다. 문장 나누기 함수는 그대로다.
- 바꾸지 않은 곳: 티어 업 공개 오버레이(`TierUpRevealOverlay`)는 문장이 차례로 나타나는 연출이 문장 단위라서 그대로 둔다.

## 완료 조건

- 짧은 문장 여러 개가 한 줄에 이어서 나오고, 긴 문장은 문장 안에서만 줄이 바뀐다. 관련 시험이 통과한다.

## 완료 기록

- 시험: `src/components/ui/__tests__`·`src/app/(main)`·`TierUp` 98개 파일 1650건 통과, eslint 통과, `ds:manifest --check` 최신. 마크업을 직접 단언하던 시험 4곳은 새 구조(`<p>` 하나와 문장 조각)에 맞게 고쳤다.
- 확인하지 못한 항목: 실제 화면에서 줄이 나뉘는 모양. 가로 폭이 좁은 기기에서 문장 단위로 줄이 바뀌는지는 직접 보는 확인이 필요하다.
- 경미 수정 경로로 직접 처리했다.
