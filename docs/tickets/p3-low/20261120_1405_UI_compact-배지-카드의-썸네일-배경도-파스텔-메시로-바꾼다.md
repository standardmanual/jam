# [UI] compact 배지 카드의 썸네일 배경도 파스텔 메시로 바꾼다

## 핵심 요약
- 요구사항(사용자, 2026-11-20): compact 카드도 일반 카드와 같은 메시 배경으로 바꾼다.
- 변경 파일은 `jam-web/src/components/ui/BadgeGridCard.tsx`의 compact 분기 한 곳이다. `BadgeAuraBackground`를 `variant="mesh"`·`seed={name}`으로 부르고, 글로우가 폭 비례 블러(cqw)를 쓰려고 걸었던 `containerType: 'inline-size'`를 걷었다.

## 완료 기록
### 처리 내용
- compact 면(모서리 12, 여백 4)은 규격 그대로 두고 배경만 일반 카드와 같은 메시(두 색 대각선 번짐, 가운데 하이라이트, 입자)로 바꿨다. 시드가 배지 이름이라 같은 배지는 일반 카드와 같은 방향이다.
- 미획득(`earned=false`)은 무채색 메시이고, 잠김·미발견 칸은 지금처럼 배경을 그리지 않는다.
- 이 변경으로 서비스 화면에서 `glow` 변형을 쓰는 곳이 없어졌다. 컴포넌트의 `glow` 변형 코드는 지우지 않았다(별도 정리 대상).

### 테스트 결과
- [x] `BadgeGridCard.aura.test.tsx`의 compact 시험을 메시 기준(블러·cqw·안쪽 빛·컨테이너 타입 없음, 입자 한 겹, 일반 카드와 같은 방향)으로 바꿔 통과. `src/components/ui/__tests__`·`BadgeAuraBackground.test.tsx` 27개 파일 541건 통과
- [x] 변경 파일 `eslint` 오류 0, `tsc`는 삭제한 임시 화면을 가리키는 `.next` 캐시 오류만 남음(소스 오류 없음)
- [ ] compact 카드의 실화면(작은 면에서 입자·번짐 모습)과 아이폰 사파리는 확인하지 않았다

### 주요 의사결정 / 핵심 메모
- 카리나 직접 처리(경미 수정, 파일 1개). DS `BadgeGridCard`의 `thumbBackground` 슬롯은 배경을 호출부가 넘기는 방식이라 바꿀 것이 없다.
