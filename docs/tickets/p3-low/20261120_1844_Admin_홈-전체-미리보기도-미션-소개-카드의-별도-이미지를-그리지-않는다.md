# [Admin] 어드민 홈 전체 미리보기도 미션 소개 카드의 별도 이미지를 그리지 않는다

## 핵심 요약

- 요구사항: 티켓 20261120_1825가 미션 소개 카드(`mission_spotlight`)는 별도 카드 이미지를 만들지 않기로 했다. 그런데 어드민 홈 전체 미리보기 패널(`jam-web/src/components/admin/ops/preview/HomePreviewPanel.tsx` 86줄 근처)은 `usesMissionImage`(`lib/admin/opsInbox/imageSpec.ts`)를 확인하지 않아, 옛 정의로 `image_spec`이 들어온 미션 소개 카드에 임시 그림을 그릴 수 있다.
- 구현 계획: 그 패널의 draft 이미지 그리기 조건에 `usesMissionImage` 제외를 더하고 시험한다.
- 발견 경위: 20261120_1825 게이트 리뷰(민지) 범위 밖 발견물, 확신도 보통. 옛 정의로 만든 묶음(2026-11-24 주간 실행 전 도착분)에서만 나타난다.

## 완료 조건

- 위 구현 계획대로 고치고 시험으로 확인한다. `scripts/verify.sh`와 CI가 통과한다.
