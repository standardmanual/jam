# [Admin] 어드민 홈 전체 미리보기가 미션 소개 카드에 연결 미션의 이미지를 커버로 그린다

## 핵심 요약

- 요구사항: 티켓 20261120_1825에서 기획 상세 미리보기는 `itemToPreviewCard`에 `linkedMission`을 넘겨 연결 미션의 이미지를 커버로 보인다. 어드민 홈 전체 미리보기의 `jam-web/src/lib/admin/homePreview/load.ts` 208줄 근처는 `linkedMission`을 넘기지 않아, 같은 카드가 홈 전체 미리보기에서는 이미지 없이 보인다.
- 구현 계획: 홈 전체 미리보기가 불러오는 같은 묶음 항목 가운데 카드와 `links`로 이어진 미션 항목을 `linkedMissionOf`(`lib/admin/opsInbox/cardPreview.ts`)로 찾아 넘기고 시험한다.
- 발견 경위: 20261120_1825 게이트 리뷰(민지) 범위 밖 발견물, 확신도 보통.

## 완료 조건

- 위 구현 계획대로 고치고 시험으로 확인한다. `scripts/verify.sh`와 CI가 통과한다.
