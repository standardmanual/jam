# [UI] 회차형 미션 상세에서 끝낸 회차는 숫자 대신 체크로 표시한다

## 핵심 요약

- 요구사항(사용자, 2026-11-21): 회차형 미션 상세에서 회차를 수행하면 서클의 숫자를 없애고 체크로 표시한다(첨부 이미지: 원 안의 흰 체크).
- 관련 파일(경로 기준 `jam-web/`): `src/app/(main)/missions/[id]/MissionDetailClient.tsx`(`CountCircles`, 서클 숫자를 그리는 부분), 시험 `src/app/(main)/missions/[id]/MissionDetailClient.test.tsx`(연속 일수·활동 횟수 서클 절).

## 구현

- `CountCircles`에서 끝낸 칸(`isDone`)은 숫자 대신 `CheckBoldIcon`(16px, 글자색 `--snow`)을 그린다. 남은 칸은 지금처럼 숫자를 보인다.
- 서클 면색은 바꾸지 않았다. 끝낸 칸은 `--jam-red`, 남은 칸은 `--btn-secondary`다. 첨부 이미지의 원은 주황(#E79523)인데, 이 색으로 바꿀지는 사용자 결정으로 남겨 두었다.
- 연속 일수와 활동 횟수가 같은 컴포넌트를 쓰므로 둘 다 적용된다. 달성 완료(`completed`)면 모든 칸이 체크다. 스크린리더 문구(`aria-label`)는 그대로다.

## 완료 조건

- 끝낸 서클에는 숫자가 없고 체크 아이콘이 있다. 남은 서클만 숫자를 보인다. 관련 시험이 통과한다.

## 완료 기록

- 시험: `src/app/(main)/missions`·`src/components/ui` 45개 파일 799건 통과, eslint 통과. 기존 시험 두 건(숫자 1~7 전부 존재 단언)은 새 동작에 맞게 고치고, 체크 표시 시험을 새로 더했다.
- 확인하지 못한 항목: 실제 화면에서 체크 아이콘의 크기·굵기. 첨부 이미지와 색이 다르다(레드 유지).
- 경미 수정 경로로 직접 처리했다.
