# [UI] 지도 체크인 배지 마커의 이름표 배경이 긴 이름 뒤를 끝까지 채우게 한다

## 핵심 요약

- 요구사항(사용자, 2026-11-22): 지도의 체크인 배지 이름 뒤 배경이 다 안 채워진다(«흐지부지 러닝 클럽»의 뒤 글자가 어두운 상자 밖으로 나옴).
- 원인: 이름표 상자에 `max-width:100%`가 걸려 있고 마커 콘텐츠 폭이 72px(`BADGE_MARKER_CONTENT_WIDTH`)이라, 이름이 길면 `white-space:nowrap` 글자만 상자 밖으로 삐져나왔다.
- 관련 파일(경로 기준 `jam-web/`): `src/components/map/MapView.tsx`(`badgeMarkerIconHtml`의 `label` div, 약 263줄).

## 구현

- 이름표 상자를 `width:max-content;max-width:none;flex-shrink:0`으로 바꿔 글자 길이만큼 넓어지게 했다. 콘텐츠 열이 flex 가운데 정렬이라 상자가 72px보다 넓어져도 양쪽으로 똑같이 늘어나므로 서클 중심 좌표(anchor.x)와 라벨 높이(24px)는 그대로다. 말줄임 없이 전체 이름을 보인다는 기존 결정도 유지했다.

## 완료 조건

- 72px보다 긴 이름에서도 어두운 배경이 글자 전체 뒤를 채우고, 상자가 서클 중심에 가운데 정렬된다.

## 완료 기록

- 실측: headless Chrome에서 «흐지부지 러닝 클럽» 이름표를 기존 스타일과 새 스타일로 나란히 그려 비교했다. 기존은 상자 폭 72px로 글자가 밖으로 나왔고, 새 방식은 131px로 글자를 모두 덮으며 중심이 서클 중심과 1px 이내로 맞는다. `src/components/map` 시험 4건과 eslint 통과.
- 확인하지 못한 항목: 네이버 지도 위의 실제 마커 화면. 이름이 아주 길면(약 20자 이상) 상자가 옆 마커와 겹칠 수 있다.
- 경미 수정 경로로 직접 처리했다.
