# [UI] 완성한 컬렉션 카드 위 RARE 등급 칩이 새 초록 면에 묻힌다

## 핵심 요약

- 요구사항: 통합 팔레트 1번(티켓 20261122_2223)에서 `--jam-green`이 #34ef5a에서 #59C02B로 바뀌면서, 완성한 컬렉션 카드(면이 `--jam-green`) 왼쪽 위의 RARE 칩(`--rarity-rare` #00CC7A)과 카드 면의 밝기가 거의 같아졌다. 칩 글자는 검정이라 읽히지만 흑백으로 보면 칩 테두리가 카드 면에 묻힌다. 구분할 방법을 정한다.
- 구현 계획: 방향을 먼저 사용자에게 묻는다. 후보는 (가) 완성 카드 위 등급 칩에만 얇은 외곽선(`--foreground` 또는 흰색)을 두르기, (나) 완성 카드 위 칩만 검정 바탕·등급색 글자로 뒤집기, (다) 그대로 두기(색상 차이로 구분되고 글자는 읽힘)다.
- 관련 파일: `jam-web/src/components/ui/CollectionGridCard.tsx`(`FACE_COMPLETED` 41줄, 등급 칩 `RarityBadge` 78~81줄), `jam-web/design-system/components/cards/RarityBadge.jsx`(25줄 등급별 색), `jam-web/design-system/tokens/colors.css`(`--rarity-*` 117~120줄).

## 배경 / 문제 정의

- 발견: 2026-11-23 1번 티켓 머지 전 로컬 실렌더 비교(232 테스트 계정 컬렉션 탭 «골목길 필름 스냅» 완성 카드).
- 대비 계산값(칩 바탕과 카드 면): RARE 1.1:1(이전 1.38:1), EPIC #f5a300 1.12:1(이전 1.35:1), MYSTIC #ff2d87 1.51:1(이전 2.28:1). EPIC·MYSTIC은 색상이 초록과 달라 눈으로 구분되지만, RARE는 밝기와 색상이 모두 가까워 가장 약하다.
- 이전 값도 낮았다. 이번 색 변경으로 새로 생긴 문제가 아니라 조금 더 나빠진 것이다.

## 완료 조건

- 사용자가 고른 방향대로 완성 카드 위 등급 칩이 카드 면과 구분된다(흑백 변환 캡처로 확인).
- 완성하지 않은 카드(흰 면)의 등급 칩 모양은 바뀌지 않는다.
