# [Admin] 컬렉션 표지 생성기 화면의 작은 어긋남 두 가지를 다듬는다

## 핵심 요약

- 요구사항: (1) 영문 이름을 비운 동안 배경색 칸이 실제 상태와 다르게 «배경색(자동) #ffffff»로 보인다. 이름을 다시 넣으면 원래 설정이 돌아오므로 표시만 어긋난다. 비운 동안에도 지금 설정(직접 지정한 색 등)을 그대로 보이게 한다. (2) 대표 배지 썸네일이 조회 순서대로 섞여 보인다. 기본 배지를 고르는 정렬(sort_order → 이름 → id)과 같은 순서로 보인다.
- 구현 계획: 생성기 컴포넌트에서 배경색·글자색 칸 값을 그리기 결과가 아니라 상태에서 읽고(결과가 없을 때), 썸네일 목록을 `pickDefaultBadge`와 같은 비교 함수로 정렬한다.
- 관련 파일: `jam-web/src/components/admin/itembooks/CollectionCoverGenerator.tsx`(배경색·글자색 칸 표시, 썸네일 목록), `jam-web/src/components/admin/itembooks/collectionCoverState.ts`(`pickDefaultBadge` 정렬), `jam-web/src/app/admin/itembooks/[id]/page.tsx` 28줄(badges 조회)

## 배경 / 문제 정의

3회차(티켓 20261124_1744) 머지 뒤 카리나의 로컬 실렌더(2026-11-24)에서 발견했다. 기능은 맞게 돌아가고 표시만 어긋난다.

## 완료 조건

- 영문 이름을 비운 동안 배경색·글자색 칸이 직전 설정 그대로 보인다.
- 썸네일 순서가 기본 배지 정렬과 같다.
- 로컬 `ADMIN_EMAILS` 실렌더로 확인한다(카리나, 머지 뒤).
