# [UI] 홈피드 분류 스티커의 조약돌 모양을 둥근 불규칙 원으로 바꾼다

## 핵심 요약

- 요구사항(사용자, 2026-11-24): 홈피드 카드의 액티비티 배지(분류 스티커)가 옆으로 뭉툭한 타원이라 원에 가까운 불규칙한 호의 원으로 바꾸고 싶다. 시안 3종(A 둥근 조약돌 · B 호마다 곡률이 다른 원 · C 울퉁불퉁한 돌멩이 원)을 보고 사용자가 **안 A**를 골랐다.
- 구현 계획: `pebbleShape`를 초타원 기반 116×84에서 거의 정원(96×92)의 둥근 불규칙 원으로 바꾼다. 크기 상수는 `PEBBLE_SIZE` 한 곳이라 칩 배치 계산(`stickerSizeOf`)이 새 크기를 그대로 따른다. 물결(`wave`)은 건드리지 않는다.
- 관련 파일(경로 기준 `jam-web/`): `design-system/components/cards/CategorySticker.jsx`(`PEBBLE_SIZE`·`PEBBLE_RING_INSET`·`PEBBLE_GLYPH_HEIGHT`, `pebbleShape`, `finishShape`의 `ringStep`), `CategorySticker.prompt.md`·`.d.ts`·`.stories.tsx`(크기 문구), 시험 `src/components/CategorySticker.test.tsx`·`src/lib/today/__tests__/feedChipGeometry.test.ts`·`feedChipPlan.test.ts`(2단계 띠 높이 70→78)·`feedChipDropPickupEdge.test.ts`(text_box 시드 4의 기준 서명), 문서 `docs/service/prd/home-feed/PRD.md`(분류 스티커 부품·칩 층 두 단락).

## 구현

- 크기 96×92, 가장자리 지수 2.1~2.5(1에 가깝지 않은 거의 원), 굴곡 2·3차 진폭 각 0.025~0.05, 기울임 ±3°, 점 120개. 글자 선은 법선 안쪽 이동이 굴곡 안쪽에서 겹치므로 중심 기준 축소 + 반지름 이동평균(앞뒤 9점)으로 만들고 가장자리에서 15px 안쪽, 글자 높이 28.
- `finishShape`에 `ringStep`을 더해 조약돌만 4점마다 글자 선 표본을 뽑는다(물결은 기존 5점 그대로라 윤곽이 바뀌지 않는다).

## 완료 조건

- 조약돌이 96×92 상자 안에 있고 윤곽·글자 선이 자기 교차하지 않으며, 같은 시드는 같은 윤곽이다(시험).
- 일곱 분류 문구가 최소 두 번 되풀이되고 글자 하한(7px) 이상이다(시험).
- 칩 배치 시험이 새 크기에서 통과한다.

## 완료 기록

- 실측: 실제 `CategorySticker` 컴포넌트를 headless Chrome으로 12개(시드·문구·색 짝 다름) 그려 윤곽이 둥글고 둘레 글자와 가운데 글자가 겹치지 않는 것을 눈으로 확인했다. `src/lib/today`·`src/components`·`src/app` 시험 8352건, eslint, `ds:manifest --check` 통과.
- 기준값 조정 2건: `feedChipPlan` «2단계» 시험은 스티커가 커져(높이 84→92) 같은 띠 높이에서 3단계로 밀려 띠를 70→78로 올렸다(74~86에서 모두 2단계가 나오는 것을 확인했다). `feedChipDropPickupEdge`의 text_box 시드 4 서명은 새 크기로 다시 뽑았다(다른 유형·시드는 그대로).
- 확인하지 못한 항목: 실제 홈피드 카드 위의 배치(카드마다 칩이 놓이는 자리와 겹침). 폭이 116→96으로 줄어 옆 여백은 넉넉해졌고 높이는 84→92로 커졌으므로 위쪽 빈 높이가 좁은 히어로 카드는 staging에서 봐야 한다.
