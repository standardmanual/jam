# [UI] 그림이 있는 홈피드 카드에서 그림과 글자 사이가 벌어지지 않게 한다

## 핵심 요약

- 요구사항(사용자, 2026-11-24): 이미지가 있는 홈피드 카드(스크린샷은 배지 소개 «낯선 골목에서 시작하는 하루»)의 그림 아래 간격이 너무 넓다. 카드가 1:1 비율일 필요는 없으니 이 간격을 조정한다.
- 원인: 카드 최소 높이(2026-11-20 확정 샘플 치수)가 «그림 영역 + 제목 한 줄 + 설명 두 줄» 내용 높이보다 30~40px 크고, 카드가 `justify-between`이라 남는 높이를 그림과 글자 사이에 몰아 넣었다(배지 소개: 최소 384, 내용 약 352 → 그림 아래 간격 약 52px).
- 구현 계획: 최소 높이를 내용 높이에 맞춰 낮춘다. 카드 구조(`justify-between gap-4`)는 그대로라 글자가 길면 늘어나는 동작도 같다.
- 관련 파일(경로 기준 `jam-web/`): `src/lib/today/feedConstants.ts`(`FEED_CARD_MIN_HEIGHT`, 약 236줄), 카드 주석 `FeedHeroBoxCard.tsx`·`FeedBadgeIntroCard.tsx`·`FeedBadgeOnlyCard.tsx`·`FeedCollectionCard.tsx`, 시험 `src/components/today/__tests__/{FeedCard,FeedCollectionCard,FeedDropPickupCard}.test.tsx`·`src/lib/today/__tests__/{dropPickupFrames,feedChipGeometry,feedChipPlan,feedChipChain}.test.ts`, 문서 `docs/service/prd/home-feed/PRD.md`(드랍·픽업 행·배지 영역 줄).

## 구현

- 최소 높이(px, 폭 358 기준): 히어로 360→316, 배지 소개 384→348, 배지만 332→300, 컬렉션 소개 416→372, 드랍·픽업 400→380. 값은 안쪽 여백 16×2 + 그림 영역 + 간격 16 + 글자 묶음 84(제목 한 줄 36 + 간격 8 + 설명 두 줄 40)이다. 목록형(260)·텍스트형(정사각)·전체 이미지(정사각)는 건드리지 않았다.
- 칩 배치 계산(`cardHeightOf`)이 같은 상수를 읽으므로 칩 위치 계산도 새 높이를 따른다.

## 완료 조건

- 제목 한 줄·설명 두 줄 카드에서 그림과 제목 사이 간격이 영역 안 여백(4px) + 간격 16px 안팎이다(최소 높이가 내용 높이를 넘지 않는다).
- 칩 배치·연쇄 시험이 새 높이에서 통과한다.

## 완료 기록

- 시험 수정: 높이를 고정값으로 쓰던 시험 값을 새 상수로 맞췄다(히어로 높이 360→316을 쓰던 `feedChipPlan` 띠·오프셋 시험 포함). `feedChipChain` 120장 표본의 110번째 카드(드랍·픽업)는 최소 높이가 20px 줄어 스티커가 들어갈 자리가 없어져 알약으로 바뀌었고(3단계), 이 경우를 «후보로 풀 수 없는 위반»에 더했다(알약만 남아 알약이 이어져도 깰 수 없다는 5단계와 같은 이유).
- 검사: `src/lib/today`·`src/components/today` 시험 1450건과 eslint 통과.
- 확인하지 못한 항목: 실제 홈피드 화면. 화면 스크린샷의 제목·설명 높이로 어림하면 내용이 약 352px라 배지 소개 카드는 최소 높이(348)보다 커져 간격이 약 20px(그림 영역 안 여백 4 + 간격 16)가 될 것으로 보인다. 드랍·픽업은 스티커가 들어갈 자리가 20px 줄어 알약으로 바뀌는 카드가 늘 수 있다.
