# [UI] 컬렉션 목록 카드와 상세 완성 알림의 칩·색을 바꾼다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-25, 세 번에 나눠 받음):
  1. 배지 > 컬렉션 탭 목록 카드에서 이미지 위의 등급 칩을 없앤다. 진행 바 채움색을 홈 캡슐 게이지와 같은 `--capsule-fill`로 바꾼다.
  2. 완성한 컬렉션 카드는 «완성» 칩을 없애고 맨 아래 행에 등급 칩(Common 포함, 낮은 등급부터)을 놓는다. 카드 면은 그린에서 검정(`--accent`)으로 바꾼다.
  3. 컬렉션 상세의 완성 알림 카드는 면을 검정으로 바꾸고 «완성» 칩을 없앤다. 컬렉션 이름 위의 등급 칩은 Common도 그린다.
- 구현 계획: 서비스 `CollectionGridCard`와 MODULAR 사본에서 이미지 위 칩 행을 걷고, 완성 행을 `rarities` 칩으로 바꾼다. 상세 `page.tsx`의 완성 알림과 등급 칩(`showCommon`)을 고친다.
- 관련 파일: `jam-web/src/components/ui/CollectionGridCard.tsx`, `jam-web/design-system/components/patterns/CollectionGridCard.{jsx,d.ts,prompt.md,stories.tsx}`, `jam-web/src/app/(main)/collections/[id]/page.tsx`(완성 알림 약 290~310줄), 시험 `CollectionGridCard.tagOrder.test.tsx`·`cardFacePairs.test.tsx`·`collections/[id]/__tests__/page.test.tsx`, 문서 `docs/service/prd/badge-detail/PRD.md` 85~89줄.

## 배경 / 문제 정의

목록 카드의 이미지 위 등급 칩이 표지 그림을 가리고, 완성 카드의 «완성» 칩과 그린 면은 상세 화면의 티켓 디자인과 어울리지 않았다. 진행 바 색은 홈 캡슐 게이지와 같게 맞춘다.

## 상세 요구사항

### UI/UX 관점
- 목록 카드: 이미지 위 칩 없음. 미완성 카드의 진행 바 채움은 `--capsule-fill`(트랙은 기존 `--capsule-track`).
- 완성 카드: 면 `--accent`, 글자 `--accent-foreground`, 맨 아래 행은 등급 칩(`RarityBadge md`, `showCommon`)이고 넘치면 줄을 바꾼다. 등급이 없으면 행이 비어 있다(높이는 20px 유지).
- 상세: 완성 알림은 검정 면에 제목·본문만 둔다. 이름 위 등급 칩은 Common도 그린다.
- 컬렉션 상세·인벤토리의 진행 바(그린 채움)는 이번 범위가 아니다.

## 완료 조건

- 목록 카드 서버 렌더에 썸네일 위 칩이 없고, 진행 바 채움이 `var(--capsule-fill)`이다.
- 완성 카드는 `bg-accent` 면이고 «완성» 글자가 없으며, `rarities`에 든 등급 칩(Common 포함)이 낮은 등급 순서로 나온다. MODULAR 사본도 같다.
- 상세 완성 알림에 `bg-accent` 면이 쓰이고 «완성» 칩이 없다. Common을 장착하면 이름 위에 Common 칩이 나온다.
- 관련 시험·`ds:check`·`ds:manifest --check`·typecheck·lint가 통과한다.
