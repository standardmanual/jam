# [UI] 컬렉션 완성 카드와 상세 이름 위의 Common 칩을 없애고, 상세 진행 바를 캡슐색으로 바꾼다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-25, 티켓 20261125_1113 배포 직후):
  1. 컬렉션 목록의 완성 카드에서 Common 칩을 없앤다.
  2. 컬렉션 상세의 컬렉션 이름 위 Common 칩을 없앤다.
  3. 컬렉션 상세의 진행 바 채움색을 캡슐 진행 바 색(`--capsule-fill`)으로 바꾼다.
- 구현 계획: 서비스·MODULAR `CollectionGridCard`와 상세 `page.tsx`에서 `RarityBadge`의 `showCommon`을 걷는다(Common은 기본 규약대로 칩이 없다). `ProgressCountBar`에 선택 옵션 `color`(기본 `--jam-green`)를 더하고 상세만 `--capsule-fill`을 넘긴다. 인벤토리의 칸 사용량 바는 같은 컴포넌트라서 기본값으로 그린을 유지한다.
- 관련 파일: `jam-web/src/components/ui/CollectionGridCard.tsx`(완성 행), `jam-web/design-system/components/patterns/CollectionGridCard.{jsx,d.ts,prompt.md,stories.tsx}`, `jam-web/src/app/(main)/collections/[id]/page.tsx`(이름 위 칩 약 288줄, 진행 바 약 311줄), `jam-web/src/components/ui/ProgressCountBar.tsx`, `jam-web/design-system/components/feedback/ProgressBar.prompt.md`, 시험 `CollectionGridCard.tagOrder.test.tsx`·`collections/[id]/__tests__/page.test.tsx`·`ProgressCountBar.color.test.tsx`, 문서 `docs/service/prd/badge-detail/PRD.md` 88~89줄.

## 배경 / 문제 정의

20261125_1113에서 Common 칩도 그리기로 했으나, 화면을 확인한 사용자가 Common 칩은 필요 없다고 판단했다. 상세의 진행 바는 목록 카드의 바(`--capsule-fill`)와 색이 달라 맞춘다.

## 상세 요구사항

### UI/UX 관점
- 완성 카드의 맨 아래 행은 Rare 이상의 등급 칩만 그린다. Common만 있으면 행이 비고 높이(20px)만 유지한다.
- 상세 이름 위 칩은 Rare 이상일 때만 나온다. Common을 장착했으면 칩이 없다.
- 상세 진행 바 채움은 `--capsule-fill`이고 트랙은 기존 `--capsule-track`이다. 인벤토리 바는 그대로 그린이다.

## 완료 조건

- 완성 카드(서비스·MODULAR)에 `Common` 글자가 나오지 않고 Rare 이상 칩은 낮은 등급 순서로 나온다.
- 상세에서 Common 장착 시 이름 위 칩이 비어 있다.
- 상세 진행 바 색이 `var(--capsule-fill)`이고, `ProgressCountBar`를 색 없이 쓰면 `var(--jam-green)`이다.
- 관련 시험·`ds:check`·`ds:manifest --check`·typecheck·lint가 통과한다.
