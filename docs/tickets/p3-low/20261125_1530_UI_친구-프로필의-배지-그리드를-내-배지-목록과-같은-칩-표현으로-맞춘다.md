# [UI] 친구 프로필의 배지 그리드를 내 배지 목록과 같은 칩 표현으로 맞춘다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-25): 내 배지 > 체크인 탭과 친구 프로필의 배지 목록이 칩을 다르게 그린다. 내 배지 메뉴를 기준으로 맞추고, 체크인 밖에서도 내 배지 메뉴와 다르게 그리는 곳이 있으면 함께 고친다.
- 차이(코드 대조): 내 배지 체크인 탭은 «×방문 횟수» 칩을 이름 아래에 그리고(`visitCount`), 친구 프로필은 같은 횟수를 썸네일 모서리 필(`count`)로 그렸다. 내 배지 활동 탭은 Common도 등급 칩으로 알리고 반복 획득 횟수는 그리지 않지만, 친구 프로필은 Common 칩이 없고 횟수 필을 그렸다. 배지 상세의 선행 배지 목록도 Common 칩이 없었다.
- 구현 계획: 프로필 그리드에서 체크인 배지는 `visitCount`, 활동 배지는 `showCommonChip`으로 넘기고 `count`는 넘기지 않는다. 체크인 판정은 `FeedSection`의 `checkinInfo`를 `isCheckinEarn`으로 내보내 쓴다. 선행 배지 그리드에 `showCommonChip`을 더한다.
- 관련 파일: `jam-web/src/app/(main)/profile/ProfileClient.tsx`(`badgeItems` 약 185줄, `renderBadgeGrid` 약 420줄), `jam-web/src/app/(main)/FeedSection.tsx`(`isCheckinEarn`), `jam-web/src/app/(main)/badges/[id]/page.tsx`(선행 배지 그리드 약 519줄), 시험 `profile/ProfileClient.badgeGrid.test.tsx`, 문서 `docs/service/prd/01_PRD.md` 프로필 줄.

## 배경 / 문제 정의

친구 프로필 그리드는 티켓 20260905_0038 B에서 모서리 필로 횟수를 보였고, 내 배지 체크인 탭은 2026-11-09 지시로 이름 아래 칩을 쓴다. 두 화면이 같은 배지를 서로 다른 모양으로 보여 준다.

## 상세 요구사항

### UI/UX 관점
- 체크인 배지: 이름 아래에 «×N»(2회 이상) 칩. 모서리 필과 Common 칩은 없다.
- 활동 배지: Common을 포함한 등급 칩, 레벨형은 Lv.N 칩. 반복 획득 «×N»은 그리지 않는다.
- 선행 배지 목록도 활동 배지처럼 Common 칩을 그린다.

## 완료 조건

- 친구 프로필의 체크인 배지가 이름 아래 칩으로 횟수를 보이고 모서리 필이 없다.
- 활동 Common 배지에 칩이 나오고 `earn_count`가 있어도 ×N이 없다.
- 관련 시험·typecheck·eslint가 통과한다.

### 구현 내용 요약
위 계획대로 고쳤다. 활동 배지의 반복 획득 횟수(×N)는 이제 친구 프로필에서 보이지 않는다. 내 배지 목록에 없는 표현이라 기준에 맞췄고, 다시 보이게 하려면 활동 배지에 `count`만 넘기면 된다.
