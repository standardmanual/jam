# [UI] 배지 카드에 대표색을 넘기던 호출부와 DS 사본을 정리한다

## 핵심 요약
- 요구사항: 티켓 20261125_1649에서 `BadgeGridCard`가 대표색(`bgColors`)을 더 이상 쓰지 않게 됐다. 남은 `bgColors` prop과 호출부의 전달, 그 값을 얻으려고 더한 조회 칼럼·API 응답 필드·피드 메타 칼럼을 걷어 내고, DS 사본 `design-system/components/patterns/BadgeGridCard.jsx`의 썸네일 배경 슬롯 설명과 면 색을 서비스와 맞춘다.
- 구현 계획: 선행 티켓 머지 뒤 `grep -rn "bgColors\|badge_bg_colors\|badgeBgColors" jam-web/src`로 호출부를 전수 확인하고 묶음으로 나눠 지운다. DB 칼럼 `badges.bg_colors`와 어드민 추출 경로는 남긴다(피드 이미지 색 등 다른 쓰임 확인 후 판단).
- 관련 파일: `components/ui/BadgeGridCard.tsx`(prop), `app/(main)/badges/BadgesClient.tsx`, `badges/[id]/page.tsx`, `profile/ProfileClient.tsx`, `collections/[id]/SlotGrid.tsx`, `combine/BagItemCell.tsx`·`RecipeSlotCard.tsx`·`PendingResultsSheet.tsx`·`CombineClient.tsx`·`TierUpPanel.tsx`, `components/inventory/InventoryGrid.tsx`·`ItemCandidateRow.tsx`·`ItemCandidateSheet.tsx`, `components/PoiCarouselModal.tsx`, `app/(main)/inventory/page.tsx`, `app/api/inventory/items/route.ts`, `app/api/drops/[dropId]/route.ts`, `lib/activity-feed/hydrate.ts`(`badge_bg_colors`), `lib/combine/pending.ts`, `lib/itembook/tier-badge-slots.ts`, `design-system/components/patterns/BadgeGridCard.jsx`·`.prompt.md`.

## 배경 / 문제 정의
선행 티켓 20261125_1649는 화면 변경과 Aura 코드 삭제에 집중하려고 `bgColors` prop을 남겨 두었다(쓰이지 않음, `@deprecated`). 호출부 10여 곳이 아직 대표색을 조회해 넘기고 있어 조회 비용과 코드 잡음이 남는다. DS 사본은 «서비스는 `bgColors`로 글로우 배경을 깐다»고 설명하고 있어 사실과 어긋난다.

## 상세 요구사항

### 서비스/코드베이스 관점
- `BadgeGridCard`의 `bgColors` prop과 모든 호출부의 전달을 지운다.
- 대표색을 넘기려고만 존재하는 조회 칼럼(`bg_colors`)·API 응답 필드·정규화 타입 필드(`badgeBgColors` 등)를 지운다. 다른 기능이 같은 값을 읽으면 남긴다(확인 결과를 완료 기록에 적는다).
- 피드 메타의 `badge_bg_colors`(hydrate·레거시 재구성)는 다른 소비처가 없을 때만 지운다.
- 선행 티켓에서 `jam-web/src/lib/badgeAura.ts`에 그레인 상수 3개(`AURA_GRAIN_SIZE_PX`·`AURA_GRAIN_OPACITY`·`AURA_GRAIN_URL`)만 남았다. Aura가 없어졌으므로 파일과 상수 이름을 그레인에 맞게 바꾸고(예: `lib/badgeGrain.ts`, `GRAIN_*`) `BadgeTicket.tsx`·`badgeTicket.test.tsx`의 import를 맞춘다(민지 게이트 [참고], 2026-11-25).
