# [UI] 회색 카드 면 위 미장착 칸 이름 흐림의 대비를 검토한다

## 핵심 요약
- 요구사항: 티켓 20261125_1649로 `BadgeGridCard` 카드 면이 흰색에서 `--background-secondary`(#e5e5e5)로 바뀌면서, 컬렉션 상세의 미장착 칸 이름 흐림(`nameMuted`: `text-muted` + `opacity-60`)의 대비가 2.52:1에서 2.26:1로 낮아졌다. 비활성 칸이라 일부러 흐리게 둔 표현이지만, 회색 면 위에서도 «흐리지만 읽히는» 정도인지 실렌더로 보고 값을 정한다.
- 구현 계획: 컬렉션 상세(`/collections/[id]`)에서 장착·미장착 칸을 함께 렌더해 사용자에게 보여 주고, 유지하거나 불투명도를 조정한다(예: 0.6 → 0.7이면 약 2.8:1).
- 관련 파일: `jam-web/src/components/ui/BadgeGridCard.tsx`(`nameMuted` 분기, 이름 `<p>` 두 곳), `jam-web/src/app/(main)/collections/[id]/SlotGrid.tsx`(호출부).

## 배경 / 문제 정의
민지 게이트 리뷰의 범위 밖 발견물([주의] nameMuted 대비, 티켓 20261125_1649). 카리나 계산(WCAG 상대 휘도): 이전 흰 면 위 #a3a3a3 상당 2.52:1, 지금 회색 면 위 #999999 상당 2.26:1. 같은 변경에서 큰 배지 카드 설명 글자(`text-muted` #666, #e5e5e5 면)는 4.56:1로 AA를 통과한다.

## 상세 요구사항

### UI/UX 관점
- 장착한 칸(검정 이름)과 미장착 칸(흐린 이름)이 한눈에 구분되면서, 미장착 칸 이름도 읽을 수 있어야 한다.

## 구현 계획
- 사용자에게 실렌더 비교(현행 0.6 / 0.7)를 보여 주고 고른 값으로 바꾼다. 바꾸지 않기로 하면 근거를 적고 닫는다.

## 완료 조건
- 사용자가 고른 불투명도가 반영되어 있거나, 유지 결정과 근거가 완료 기록에 있다.
