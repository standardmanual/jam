# [UI] 토스트가 화면 아래에 붙도록 위치를 DS 토큰으로 옮긴다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-25): 아이폰 사파리에서 토스트가 브라우저 아래에 붙지 않고 위로 떠 있다. DS 원본 소스를 고쳐 근본적으로 바로잡는다.
- 원인(코드 대조): 토스트 컨테이너의 `bottom`이 `Toast.tsx`의 상수 88px(`DEFAULT_BOTTOM_PX`)였다. 이 값은 탭바를 높이 64px, 하단 간격 16px로 보던 시절에 «탭바 위 8px»로 잡은 숫자다. 탭바는 그 뒤 높이 49px, 하단 간격 `max(10px, 안전 영역 − 16px)`로 바뀌었는데(티켓 20260901_1626, 20260824_014) 토스트 숫자는 그대로여서, 토스트 아랫면이 탭바 윗면보다 약 29px 높이 떴다.
- 구현: 탭바 하단 간격 식이 `TabBar.tsx`, DS `TabBar.jsx`, `MapView.tsx` 세 곳에 복사돼 있었다. 이 식을 DS 토큰 `--tabbar-bottom`으로 모으고, 토스트는 `--toast-bottom`(= 탭바 윗면 + 8px)을 읽게 했다. 토스트 가로폭도 탭바와 같게(좌우 21px, 최대 388px) 맞췄다.
- 관련 파일: `jam-web/design-system/tokens/spacing.css`(토큰 정의), `jam-web/src/components/ui/Toast.tsx`(`toastBottom`), `jam-web/src/components/ui/TabBar.tsx`, `jam-web/design-system/components/navigation/TabBar.jsx`, `jam-web/src/components/map/MapView.tsx`(`LOCATE_BUTTON_BOTTOM`), `jam-web/design-system/components/feedback/Toast.jsx`·`Toast.prompt.md`, 시험 `jam-web/src/components/ui/Toast.position.test.ts`.

## 배경 / 문제 정의

사용자가 캡처로 보여 준 화면에서 토스트 아랫면이 뷰포트 아래에서 88px 위에 있고, 탭바는 10px 위에 있다. 토스트가 탭바와 따로 떠 보이며 브라우저 아래에 붙은 느낌이 없다.

## 상세 요구사항

### UI/UX 관점
- 토스트는 탭바 바로 위(윗면에서 8px)에, 탭바와 같은 가로폭으로 뜬다. 처음에는 탭바 자리에 겹쳐 내렸으나 사용자가 «탭바 위로»를 선택해 바꿨다.
- 위치 숫자는 서비스 코드에 직접 적지 않고 DS 토큰만 읽는다.
- 바텀시트처럼 하단을 점유하는 UI가 열려 있으면 종전처럼 그 위로 올려 띄운다.

## 완료 조건

- 토스트 컨테이너의 하단 위치가 `var(--toast-bottom)`이고, 값이 탭바와 같게 풀린다.
- 탭바(서비스·DS)와 지도 화면 버튼이 같은 토큰 `--tabbar-bottom`을 읽는다.
- 관련 시험·typecheck·eslint가 통과한다.

### 주요 의사결정 / 핵심 메모
- 위치는 «탭바 자리»와 «탭바 위 8px» 중에서 사용자가 후자를 골랐다. 값은 `--toast-bottom` 한 줄이라 다시 바꾸기 쉽다.
- DS `Toast.jsx`는 계속 한 줄의 겉모양만 그린다(티켓 20260826_005 결정). DS는 위치 토큰과 사용 규칙(`Toast.prompt.md`)을 맡고, 컨테이너와 겹침 방어는 서비스 `ToastProvider`가 맡는다.
- `ds-sync-check` 결과는 오류 0건이다. Toast 쌍의 «한쪽에만 있는 값» 경고는 컨테이너가 서비스에만 있는 구조에서 오는 기존 경고다.
