# [UI] 서비스가 쓰지 않는 아이콘 3개를 정리한다

## 핵심 요약

- 발견: 6-3b회차(20261126_1156) 범위 밖 발견물(아현 [참고], 민지 [참고]).
- `jam-web/src/components/ui/icons.tsx`의 아이콘 42종 중 서비스 코드가 쓰지 않는 것이 3개다: `FlaskIcon`, `PodiumIcon`, `SparkleCircleIcon`(이름 기준 `git grep`으로 센 값).
- 아이콘 시험(`icons.test.tsx`·`coinIconPair.test.tsx`)이 사양 `docs/assets/prototypes/icon-set-v2/spec.json`과 대조하므로, 지우려면 사양과 시험도 함께 맞춰야 한다.
- 정본 컴포넌트 변경이라 상위 티켓 20261125_1923의 승인 범위(미사용 제거) 안에서 하되, 지울지 아이콘 세트에 남길지(앞으로 쓸 예정인지)는 사용자에게 먼저 묻는다.

## 구현 계획

- 세 아이콘의 사용처를 `git grep -n "FlaskIcon\|PodiumIcon\|SparkleCircleIcon" -- jam-web`으로 다시 확인한다(어드민 포함).
- 사용자 확인 뒤: `icons.tsx`의 세 정의, `spec.json`의 해당 항목, 시험의 기대 목록, `icons.stories.tsx` 목록에서 함께 지운다. `node scripts/gen-component-list.mjs`로 목록 문서를 다시 만든다.

## 완료 조건

- 세 아이콘의 처리(삭제 또는 유지 사유)가 기록되고, 삭제했다면 아이콘 시험과 `gen-component-list --check`가 통과한다.
