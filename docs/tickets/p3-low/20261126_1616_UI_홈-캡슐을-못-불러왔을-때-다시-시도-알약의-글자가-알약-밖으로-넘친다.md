# [UI] 홈 캡슐을 못 불러왔을 때 «다시 시도» 알약의 글자가 알약 밖으로 넘친다

## 핵심 요약

- 발견: 7-3회차(티켓 20261126_1408) 화면 비교 중, 범위 밖 발견물. 7회차 변경 **전부터** 있던 문제다(전후 캡처가 같은 모양으로 넘친다).
- 현상: `jam-web/src/components/capsule/CapsuleWidget.tsx` 101행 부근 «다시 시도» 알약(지금은 정본 `Button secondary fullWidth`)은 높이가 `CAPSULE_GAUGE_HEIGHT_PX`(36px)로 고정인데,
  안에 두 줄(«캡슐을 불러오지 못했어요» 14px + «다시 시도» 12px)을 넣어 글자가 알약 위아래 밖으로 넘친다. 폭 390에서도 넘친다.
- 할 일(제안): 오류 상태에서는 높이를 내용에 맞추거나(최소 36px) 한 줄 문구로 줄인다. 어느 쪽이 맞는지는 디자이너(사용자) 결정이다.
- 관련 파일: `jam-web/src/components/capsule/CapsuleWidget.tsx`(오류 분기), `jam-web/src/components/capsule/CapsuleGauge.tsx` 51행 `CAPSULE_GAUGE_HEIGHT_PX`
