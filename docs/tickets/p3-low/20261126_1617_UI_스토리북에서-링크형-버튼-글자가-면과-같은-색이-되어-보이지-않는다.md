# [UI] 스토리북에서 링크형 버튼 글자가 면과 같은 색이 되어 보이지 않는다

## 핵심 요약

- 발견: 7-2회차(티켓 20261126_1407) 스토리 비교 중, 범위 밖 발견물. 7회차 변경 전부터 있던 문제다.
- 현상: `UI/Buttons/Button` «primary external link» 스토리와 기사 화면(`ArticleView`) 스토리의 CTA 알약에서 글자가 보이지 않는다. 계산값이 글자색·면색 모두 `rgb(23, 23, 23)`이다.
- 원인: 스토리북만 불러오는 `jam-web/design-system/styles.css` 26~27행의 `a { color: var(--link); }`·`a:hover`가 레이어 없이 선언돼, Tailwind 유틸리티(`text-snow`)보다 우선한다.
  서비스는 `src/app/globals.css`만 불러오고 이 규칙이 없으므로 서비스 화면 문제는 아닌 것으로 보인다(테스트 계정 화면에 해당 버튼이 없어 실화면 확인은 못 함).
- 할 일(제안): 그 규칙을 `@layer base` 안으로 옮기거나 지워서 스토리북이 서비스와 같게 그려지게 한다. 6회차 «스토리북을 서비스 기준으로»의 남은 차이다.
- 관련 파일: `jam-web/design-system/styles.css` 26~27행, `jam-web/.storybook/preview.tsx` 5행
