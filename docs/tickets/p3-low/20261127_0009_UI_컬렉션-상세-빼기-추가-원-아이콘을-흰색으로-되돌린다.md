# [UI] 컬렉션 상세의 «빼기»·«추가» 원 아이콘을 흰색으로 되돌린다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-27, 캡처 첨부): 컬렉션 상세 페이지에서 배지를 추가하는 «+» 서클의 «+»와 배지를 빼는 «−» 서클의 «−»를 흰색으로 바꾼다.
- 원인(코드 대조): 원 버튼 정본 `SlotCircleButton`은 이미 아이콘 색을 `text-snow`(흰색)로 정해 두었다. 그런데 컬렉션 상세의 칸 격자는 `TicketTone tone="face" keepCards` 안에 있고, 이 구간의 `BadgeTicket.module.css` 규칙 `.faceKeepCards button:not(.bg-accent)`가 모든 버튼의 글자색을 잉크색(#171717)으로 덮는다. 이 규칙이 클래스 하나짜리 `text-snow`보다 우선해, 검정 원 위의 «+»가 같은 색이 되어 보이지 않고 레드 원 위의 «−»는 어두운 색으로 나왔다.
- 구현: `SlotCircleButton`의 버튼에 표식 `data-slot-circle`을 붙이고, `.faceKeepCards`의 버튼 규칙이 이 표식이 있는 버튼을 건너뛰게 했다. 아이콘 색 자체는 바꾸지 않았다(원래 의도인 `--snow` 그대로다).
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/BadgeTicket.module.css`(`.faceKeepCards` 버튼 규칙), `jam-web/src/components/ui/SlotCircleButton.tsx`(`data-slot-circle`), 시험 `jam-web/src/app/(main)/badges/[id]/__tests__/slotCircleOnTicket.test.tsx`.

## 배경 / 문제 정의

컬렉션 상세를 티켓 디자인으로 바꾸면서(티켓 20261124_2252 계열) 칸 격자에 «버튼은 잉크색 글자» 규칙이 적용됐다. 이 규칙은 연한 회색 면 버튼(«한번에 빼기»)을 읽히게 하려는 것인데, 어두운 면 위에 얹힌 원 버튼의 아이콘까지 같이 덮었다.

## 상세 요구사항

### UI/UX 관점
- 검정 원 안의 «+», 레드 원 안의 «−» 모두 흰색(`--snow`)이다.
- 원 버튼이 쓰이는 조합 레시피 칸(티켓 밖 화면)은 종전과 같다.
- «한번에 빼기» 같은 연한 회색 면 버튼은 계속 잉크색 글자다.

## 완료 조건

- 티켓 위 칸 격자 안에서도 원 버튼의 글자색이 `--snow`로 풀린다.
- 관련 시험과 eslint가 통과한다.

### 주요 의사결정 / 핵심 메모
- 색을 `SlotCircleButton`에 `!important`나 인라인 스타일로 더 세게 박지 않고, 덮어쓰는 쪽 규칙에서 원 버튼을 빼는 쪽으로 풀었다. 아이콘 색의 단일 원천이 계속 `text-snow` 한 곳이다.
- 컬렉션 상세 외에 이 원 버튼이 `.faceKeepCards` 안에 놓이는 곳은 없다(조합 레시피 칸은 티켓 밖).
