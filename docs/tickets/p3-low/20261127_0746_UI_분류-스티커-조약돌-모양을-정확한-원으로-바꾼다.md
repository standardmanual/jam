# [UI] 분류 스티커 조약돌 모양을 정확한 원으로 바꾼다

## 핵심 요약

- 사용자 승인: 2026-11-27 — 사용자가 채팅에서 «배지를 정확한 원 형태로 변경해»라고 직접 지시했다(정본 `CategorySticker`의 조약돌 모양 변경, 화면 변화는 윤곽이 정원이 되는 것).
- 요구사항(사용자 지시 2026-11-27, 캡처 첨부): 홈피드 카드 모서리에 붙는 «ACTIVITY» 분류 스티커(둘레 글자 + 가운데 로고 «a»)의 바탕을 정확한 원 모양으로 바꾼다.
- 원인(코드 대조): 정본 `CategorySticker`의 `pebble`(조약돌) 모양이 시드마다 굴곡·기울임·네모 정도가 다른 «둥근 불규칙 원»이었다(티켓 20261124_2214 «안 A»).
- 구현: `pebbleShape`를 시드와 무관한 정원(92×92, 지름 90 + 테두리 2)으로 다시 썼다. 윤곽과 둘레 글자 선은 곡선 근사가 아니라 SVG 호(arc)이고, 글자 선은 같은 중심에서 15px 안쪽 원이다. 물결 덩어리(`wave`)는 그대로 둔다.
- 관련 파일: `jam-web/src/components/ui/CategorySticker.tsx`(`pebbleShape`·`PEBBLE_SIZE`), 시험 `jam-web/src/components/CategorySticker.test.tsx`·`jam-web/src/lib/today/__tests__/feedChipGeometry.test.ts`, Story `CategorySticker.stories.tsx`(설명 문구), 문서 `docs/service/prd/home-feed/PRD.md`(분류 스티커 부품 문단).

## 배경 / 문제 정의

캡처의 스티커는 윤곽이 한쪽으로 쏠린 울퉁불퉁한 원이라 «배지»다운 정원으로 보이지 않는다.

## 상세 요구사항

### UI/UX 관점
- 조약돌 스티커 바탕이 어떤 시드·배율에서도 완전한 원이다.
- 둘레 글자(ACTIVITY·ITEM·MISSION·CHECK IN·COLLECTION·DROP·PICKUP)는 원을 따라 배치되고, 가운데 로고는 중앙에 놓인다.
- 폭이 96에서 92로 4px 줄어 칩 배치 계산(`stickerSizeOf`)이 이 값을 따른다. 높이 92는 그대로다.

## 완료 조건

- `pebbleShape`의 모든 윤곽점이 중심에서 같은 거리에 있고 시드가 달라도 같은 모양이다.
- 관련 시험·typecheck·eslint가 통과한다.

### 주요 의사결정 / 핵심 메모
- 정원은 가로 폭이 높이와 같아야 해 상자를 96×92에서 92×92로 바꿨다. 높이를 기준으로 삼아 세로 배치는 그대로다.
- 이제 조약돌은 시드마다 달라지지 않는다. 같은 카드 안의 스티커가 모두 같은 원이라 «울퉁불퉁한 변주»는 없어진다.
- `wave`(물결 덩어리)는 손대지 않았다. 이것도 원으로 바꾸길 원하면 별도로 말해 주면 된다.
