# [UI] 분류 스티커의 물결 덩어리 모양을 소스에서 제거한다

## 핵심 요약

- 사용자 승인: 2026-11-27 — 사용자가 채팅에서 «물결은 소스코드에서 제거해»라고 직접 지시했다(정본 `CategorySticker`의 물결 덩어리 모양 삭제, 화면 변화는 물결 모양이던 스티커가 정원이 되는 것).
- 요구사항(사용자 지시 2026-11-27): 홈피드 분류 스티커의 «물결 덩어리»(가장자리에 혹 7~9개가 튀어나온 구름형, 112×92) 모양을 소스에서 없앤다. 앞서 조약돌은 정원으로 바꿨으므로(티켓 20261127_0746) 스티커는 정원 하나만 남는다.
- 범위 구분: 박스 모양의 «물결»(`box_shape: 'wave'`, `FeedBox`, 텍스트 박스·이미지 마스크)은 다른 부품이라 그대로 둔다. 이 티켓은 분류 스티커만 다룬다.
- 구현:
  - `CategorySticker.tsx`: `waveShape`·`stickerShape`·물결 상수(`WAVE_*`)와 물결만 쓰던 보조 함수(시드 난수, 곡선·점열 도우미, 자기 교차 검사)를 지웠다. 모양을 고르는 `shape`와 윤곽을 정하던 `seed` prop, `StickerShape`의 `shape`·`humps` 필드도 없앴다. `pebbleShape()`는 인자 없이 정원을 돌려준다.
  - 칩 계획: 스티커 인자에서 `shape`·`seed`를 뺐다. `stickerSizeOf`는 배율만 받는다(`StickerShapeName` 타입 삭제). 서명의 모양 표기는 `sp` 하나다. 칩 연쇄의 모양 비교는 알약 대 스티커로 남는다.
  - 난수: 스티커 모양을 뽑던 자리의 난수 한 개는 값을 버리는 것으로 남겼다. 지우면 뒤의 값(짝·글자·자리·기울기)이 모든 카드에서 밀려 배치가 통째로 바뀐다. 이 때문에 물결이던 스티커만 정원으로 바뀌고 나머지 카드의 자리·기울기·색은 그대로다.
- 관련 파일: `jam-web/src/components/ui/CategorySticker.tsx`, `jam-web/src/lib/today/feedChipPlan.ts`·`feedChipChain.ts`·`feedChipGeometry.ts`, `jam-web/src/components/today/feed/FeedCardParts.tsx`(`PlannedChipView`), 스토리 `CategorySticker.stories.tsx`, 시험 `CategorySticker.test.tsx`·`feedChipPlan.test.ts`·`feedChipGeometry.test.ts`·`feedChipDropPickupEdge.test.ts`·`FeedChipPlanLayer.test.tsx`, 문서 `docs/service/prd/home-feed/PRD.md`.

## 배경 / 문제 정의

스티커의 두 모양 중 조약돌을 정원으로 바꾼 뒤, 사용자가 물결 덩어리는 소스에서 걷기로 했다. 물결 코드가 남으면 쓰이지 않는 분기와 시험을 계속 끌고 가게 된다.

## 상세 요구사항

### UI/UX 관점
- 홈피드 카드의 분류 스티커는 모두 정원이다. 문구·색 짝·로고 글자 규칙은 그대로다.
- 카드마다 스티커의 자리·기울기·색 짝은 이전과 같다(모양 난수 한 개를 버려 순서를 지켰다).

## 완료 조건

- 소스에 스티커 물결 모양 코드(`waveShape`, `WAVE_*`, `shape="wave"`)가 남지 않는다. 박스 물결은 남는다.
- 관련 시험·tsc·eslint가 통과한다.

### 주요 의사결정 / 핵심 메모
- 모양 난수를 지우지 않고 버리는 것으로 남겼다. 지우면 스티커가 아닌 부분까지 카드 배치가 전부 바뀐다.
- 칩 연쇄의 `shape` 비교 키는 남겼다(알약 또는 스티커). 같은 꼴 3연속 금지 규칙(`form`)과 겹치는 면이 있으나 이번 범위가 아니라 손대지 않았다.
- 박스 모양 «물결»은 별개 부품이라 남겼다. 이 모양도 걷으려면 DB 칸(`box_shape`) 값 정리가 따라와 별도 결정이 필요하다.
