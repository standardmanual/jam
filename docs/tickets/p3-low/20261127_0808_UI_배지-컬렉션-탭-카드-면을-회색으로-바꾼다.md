# [UI] 배지 > 컬렉션 탭의 카드 면을 회색으로 바꾼다

## 핵심 요약

- 요구사항: 배지 목록 컬렉션 탭의 컬렉션 카드 면을 다른 탭의 배지 카드와 같은 회색으로 맞춘다.
- 구현 계획: `CollectionGridCard`의 미완성 카드 면을 `bg-card-bg`(흰색)에서 `bg-background-secondary`(회색 #e5e5e5)로 바꾼다. 완성 카드의 검정 면은 그대로 둔다.
- 관련 파일: `jam-web/src/components/ui/CollectionGridCard.tsx`(`FACE_DEFAULT`), `jam-web/src/components/ui/__tests__/cardFacePairs.test.tsx`(CollectionGridCard 쌍 단언)

## 배경 / 문제 정의

배지 목록의 액티비티·체크인 탭은 회색 카드(`--background-secondary`)인데 컬렉션 탭만 흰 카드라 탭마다 면이 달랐다.

## 상세 요구사항

### UI/UX 관점
- 미완성 카드 면: 흰색 → 회색(`--background-secondary`). 진행 바·글자색·반경·여백은 그대로다.
- 완성 카드: 검정 면(`--accent`) 그대로다.
- 사용 위치는 배지 목록 컬렉션 탭과 어드민 운영 미리보기(`OpsKindPreview`) 두 곳이다.

## 구현 계획

면 클래스 한 줄 교체와 단언 테스트 갱신. 구현 전에 실제 화면에 CSS만 임시로 덮어 만든 시안(현재/제안 비교 이미지)으로 사용자 승인을 받았다.

## 완료 조건

- 배지 > 컬렉션 탭에서 미완성 카드의 배경이 `rgb(229, 229, 229)`이고 완성 카드는 `rgb(23, 23, 23)`이다. 확인: 로컬 실행 화면에서 계산된 배경색 측정.
- `src/components/ui` 테스트 462건과 타입체크가 통과한다.

- 사용자 승인: 2026-11-27 — 컬렉션 카드 면을 흰색에서 회색(`--background-secondary`)으로 변경(화면 변화). 시안 이미지를 보고 «개발 진행»으로 승인.
