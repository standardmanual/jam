# [UI] 배지 상세 «아직 획득하지 못한 배지예요» 카드를 컬렉션 «완성» 카드 자리와 검정 면으로 옮긴다

## 핵심 요약

- 요구사항: 배지 상세의 미획득 안내 카드를 컬렉션 상세의 «컬렉션 완성!» 알림 카드와 같은 자리(글자 상자 바로 아래, 절취선 위)로 옮기고 카드 색도 같은 검정으로 맞춘다.
- 구현 계획: 세 갈래(활동·체크인·아이템)의 `body`(절취선 아래)에 있던 흰 `Card`를 걷고, 같은 모양의 `NotEarnedNotice`(`bg-accent` + `--accent-foreground` 글자)를 `afterPhoto`의 글자 상자 아래에 그린다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/page.tsx`(`NotEarnedNotice`, 세 `afterPhoto`), `jam-web/src/app/(main)/badges/[id]/__tests__/notEarnedCard.test.ts`, 참고 `collections/[id]/page.tsx`(완성 카드)

## 배경 / 문제 정의

미획득 안내가 절취선 아래 흰 카드라 컬렉션 완성 카드와 위치·색이 달랐다. 사용자 지시로 같은 자리·같은 색으로 맞춘다.

## 상세 요구사항

### UI/UX 관점
- 자리: 글자 상자(`TicketTitleBoxes`) 바로 아래, `px-4 pb-6` 구간. 아이템 배지는 일련번호 줄보다 위다.
- 면: `bg-accent`(검정), `rounded-2xl p-5 text-center`. 글자는 `--accent-foreground`이고 어떤 티켓색에서도 같다. 문구는 그대로다.
- 보조 문구는 없다(2026-11-09 결정 유지).
- 아이템 배지의 정보 구간(보유 개체 목록)은 본인 뷰에서 개체가 있을 때만 그린다. 미획득 안내가 빠져 빈 구간이 남지 않게 한 조건이다.

## 구현 계획

위 `핵심 요약`과 같다. 새 토큰·새 컴포넌트는 없다(`NotEarnedNotice`는 이 페이지 안의 화면 조각이다).

## 완료 조건

- 미획득 배지 상세 세 갈래에서 안내 카드가 글자 상자 아래, 절취선 위에 있고 배경이 `rgb(23, 23, 23)`, 글자가 `--accent-foreground`다. 절취선 아래 흰 카드는 없다. 확인: `notEarnedCard.test.ts`와 로컬 화면(아이템 배지 실측).
- 배지 테스트와 타입체크가 통과한다.
