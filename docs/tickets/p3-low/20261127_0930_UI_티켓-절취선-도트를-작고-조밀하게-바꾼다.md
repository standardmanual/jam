# [UI] 배지·컬렉션 상세 티켓의 절취선 도트를 작고 조밀하게 바꾼다

## 핵심 요약

- 요구사항: 배지 상세와 컬렉션 상세 티켓의 절취선 도트를 작고 조밀하게 바꾼다.
- 구현 계획: `BadgeTicket.module.css`의 `.dots`를 지름 4px·주기 14px(간격 10px)에서 지름 3px·주기 8px(간격 5px)로 바꾼다. 개발 전에 현재·A안·B안 비교 이미지를 보이고 사용자가 A안을 골랐다.
- 관련 파일: `jam-web/src/app/(main)/badges/[id]/BadgeTicket.module.css`(`.dots`). 컬렉션 상세도 같은 틀(`BadgeTicket`)을 쓴다.

## 배경 / 문제 정의

절취선 도트가 크고 성겨 티켓 모양이 투박해 보였다.

## 상세 요구사항

### UI/UX 관점
- 도트 지름 3px, 간격 5px(주기 8px). 점선 줄의 높이는 3px이고 절취선 가운데에 놓는다(`top: -1.5px`). 좌우 26px 안쪽, 색(`--background`), 삼각 홈은 그대로다.
- 비교한 안: A안(3px·간격 5px, 채택), B안(2px·간격 4px).

## 구현 계획

CSS 값 한 곳 교체. 새 토큰·새 컴포넌트는 없다.

## 완료 조건

- 배지 상세·컬렉션 상세의 절취선 두 줄 모두 `.dots`의 높이가 3px이고 배경 크기가 `8px 3px`이다. 확인: 로컬 화면에서 계산된 스타일 측정과 화면 확인(배지 상세·컬렉션 상세).
