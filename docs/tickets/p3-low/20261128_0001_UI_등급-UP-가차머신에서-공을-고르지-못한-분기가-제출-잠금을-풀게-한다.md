# [UI] 등급 UP 가차머신에서 공을 고르지 못한 분기가 제출 잠금을 풀게 한다

## 핵심 요약

- 요구사항: `TierUpGachaStage`가 섞기를 끝내고 중앙으로 보낼 공을 고르지 못하면(`pickWinner`가 -1) 그대로 `return`해, 결과가 화면에 반영되지 않고 `CombineClient`의 제출 잠금(`tierUpBusy`)도 풀리지 않는다. 이 분기에서도 머신을 처음 상태로 되돌리고 `abort`와 같은 정리를 거쳐 잠금을 푼다.
- 구현 계획: 405행 `if (wi < 0) return`을 «중단» 처리 경로로 바꾸고 시험을 더한다.
- 관련 파일: `jam-web/src/app/(main)/combine/TierUpGachaStage.tsx`(400~410행 승자 공 고르기), `jam-web/src/app/(main)/combine/CombineClient.tsx`(`tierUpBusy` ref 해제 경로), `jam-web/src/app/(main)/combine/gachaPhysics.ts`(`pickWinner`)

## 배경 / 문제 정의
범위 밖 발견물(민지, 티켓 20261127_2225 게이트, 참고/낮음): 공은 항상 6개라 실제로 도달하기 어렵지만, 도달하면 화면이 연출 중 상태로 멈추고 다시 제출할 수 없다.

## 완료 조건
- `pickWinner`가 -1을 돌려주는 상황에서도 머신이 처음 상태로 돌아오고 «배지 넣기»를 다시 누를 수 있다(시험).
- `scripts/verify.sh`가 통과한다.
