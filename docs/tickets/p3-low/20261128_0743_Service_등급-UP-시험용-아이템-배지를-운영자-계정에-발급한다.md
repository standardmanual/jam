# [Service] 등급 UP 시험용 아이템 배지를 운영자 계정에 발급한다

## 핵심 요약

- 요구사항: staging에 배포한 등급 UP 가차머신(티켓 20261127_2225)을 시험할 수 있도록, 운영자 계정(인벤토리 `51a0680e-cd8f-45d7-a8ed-8c0329370389`)에 같은 등급 아이템 배지를 등급 UP 재료 개수(6개)에 맞춰 임의로 발급한다(사용자 요청, 2026-11-28).
- 구현 계획: Common·Rare·Epic·Mystic을 등급마다 서로 다른 배지 6개씩, 모두 24개 발급한다. 후보는 등급 UP 후보 판정과 같은 조건(`listServiceIssueCandidates`)이고, 발급은 `grant_inventory_item`으로 한다. 되돌림을 위해 `obtained_by`를 `qa_tier_up_20261128`로 표시한다.
- 관련 파일: `jam-web/supabase/migrations/seed_qa_tier_up_materials_20261128.sql`, `seed_qa_tier_up_materials_20261128_down.sql`

## 배경 / 문제 정의
발급 전 이 계정에는 인벤토리에 남은 아이템 배지가 Common·Rare·Epic 1개씩뿐이라 등급 UP(같은 등급 6개)을 시험할 수 없었다. 인벤토리는 30칸 중 3칸을 쓰고 있었다.

## 완료 조건
- 등급마다 6개 이상이 인벤토리에 있고, 칸 수(`used_slots`)가 개체 수와 맞는다.

### 주요 의사결정 / 핵심 메모
- 남은 칸이 27칸이라 4등급 × 6개(24개)로 정했다. 등급 UP은 6개를 소각하고 1개를 주므로, 남은 3칸으로도 시험이 막히지 않는다.
- 되돌림 SQL은 아직 인벤토리에 남은 시험 개체만 지운다. 등급 UP으로 이미 소각된 재료와 그 결과로 받은 배지는 건드리지 않는다.

### 잔여 이슈
- 시험이 끝나면 남은 시험 개체를 되돌림 SQL로 지울지 정한다.
