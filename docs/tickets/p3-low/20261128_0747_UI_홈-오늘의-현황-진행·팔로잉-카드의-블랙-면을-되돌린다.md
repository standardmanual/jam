# [UI] 홈 «오늘의 현황» 진행·팔로잉 카드의 블랙 면을 되돌린다

## 핵심 요약

- 요구사항: 홈 «진행»·«팔로잉» 2칸 카드를 티켓 20261127_0829 이전의 흰 면(기본 톤 `Card` + `ProgressBar`)으로 되돌린다. 사용자는 이 카드를 블랙으로 바꾸길 원하지 않았다(2026-11-28 대화). 블랙 면 변경은 챕터 게이지 카드 전환(상위 20261127_1720)의 의도와 달리 적용된 것이다.
- 구현 계획: 커밋 `f7d8c070f`에서 스트립 관련 변경만 되돌린다. `TodayStatusStrip.tsx`·`TodayStatusStrip.test.tsx`·`ProgressCountBar.tsx`는 그 커밋 직전 상태로 복원하고, 홈피드 PRD와 `primitive.css` 주석의 스트립 서술을 걷는다. 같은 커밋의 인벤토리 변경(상단 바 `--capsule-fill`, 빈 슬롯 화면 높이)은 유지한다.
- 관련 파일: `jam-web/src/app/(main)/TodayStatusStrip.tsx`, `TodayStatusStrip.test.tsx`, `jam-web/src/components/ui/ProgressCountBar.tsx`(`onInverse`·`format` 옵션 제거), `jam-web/design-system/tokens/primitive.css`(`--jam-green` 지정 사용처 주석), `docs/service/prd/home-feed/PRD.md`(6번 영역·스트립 서술), `docs/service/prd/ui-components/tokens.md`(생성기)

## 배경 / 문제 정의

사용자가 홈 화면 확인 중 «진행»·«팔로잉» 카드가 블랙으로 바뀐 것을 발견했다. 이 카드를 바꾸려던 것이 아니고, 캡슐 게이지를 없애고 챕터 게이지 카드(프로토타입)로 바꾸는 것이 목적이었다. 티켓 20261127_0829의 블랙 면 변경(사용자 승인 줄 포함)이 의도와 어긋났으므로 되돌린다.

## 상세 요구사항

### UI/UX 관점
- «진행»·«팔로잉» 두 칸은 `Card` 기본 톤(흰 면 + 1px 테두리)으로 돌아간다. 라벨 칩은 `LabelChip` 기본 색조이고, 진행 바는 `ProgressBar`와 «n/n» 수치를 한 줄에 둔다(티켓 20261109_1429 형태).
- 인벤토리의 상단 바 색(`--capsule-fill`)과 빈 슬롯 규칙은 바꾸지 않는다.
- 캡슐 게이지는 이 티켓에서 건드리지 않는다(홈 카드 교체는 C5b).

## 구현 계획

`git checkout f7d8c070f^ -- <코드 세 파일>`로 복원하고, PRD·토큰 주석의 서술을 걷은 뒤 생성기를 다시 돌린다.

## 완료 조건

- 스트립 두 칸의 배경이 `--card-bg`(기본 톤)이고 `--background-inverse`·`LABEL_ON_INVERSE_STYLE`이 없다. `ProgressCountBar`에 `onInverse`·`format`이 없다. 확인: `TodayStatusStrip.test.tsx` 단언.
- 인벤토리 변경(`inventory/page.tsx`의 `color` 전달, `InventoryGrid`의 `fillScreen`)은 그대로다.
- 타입체크·린트·`scripts/verify.sh`가 통과한다.
