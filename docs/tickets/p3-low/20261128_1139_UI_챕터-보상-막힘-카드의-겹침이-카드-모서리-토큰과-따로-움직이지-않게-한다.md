# [UI] 챕터 보상 막힘 카드의 겹침이 카드 모서리 토큰과 따로 움직이지 않게 한다

## 핵심 요약

- 요구사항: `ChapterRewardBlockedCard`가 위 카드와 이어 붙으려고 `-mt-4`(16px)로 겹치는데, 이 값은 챕터 게이지 카드의 모서리 반경(`--radius-2xl`)과 맞물려 있다. 토큰 값이 바뀌어도 이음새가 어긋나지 않게 겹침 길이를 반경에서 파생한다.
- 구현 계획: 겹침을 하드코딩 대신 반경 토큰에서 계산하거나, 이음새를 한 컴포넌트가 책임지게 묶는다. 방식은 채원 판정이 정한다.
- 관련 파일: `jam-web/src/components/chapter/ChapterRewardBlockedCard.tsx`(겹침 클래스), `jam-web/src/components/ui/ChapterGaugeCard.tsx`(모서리 반경)

## 배경 / 문제 정의

티켓 20261127_1735 민지 게이트의 범위 밖 발견물이다(참고). 지금은 반경과 겹침이 같은 16px이라 틈이 없지만, 어느 한쪽만 바뀌면 이음새에 틈이나 움푹한 면이 생긴다.

## 완료 조건

- 모서리 반경 토큰을 바꿔도 막힘 카드와 게이지 카드 사이에 틈이 생기지 않는다. 확인: 시험 단언 또는 스토리 실렌더.
