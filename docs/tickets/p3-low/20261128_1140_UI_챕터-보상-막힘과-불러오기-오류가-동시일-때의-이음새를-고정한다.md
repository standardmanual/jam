# [UI] 챕터 보상 막힘과 불러오기 오류가 동시일 때의 이음새를 고정한다

## 핵심 요약

- 요구사항: 챕터 조회가 실패해 «다시 시도» 블록이 나오는 상태에서 막힘 안내 카드도 함께 나올 때의 이음새(겹침, 윗 여백, 모서리)를 정하고 시험으로 고정한다.
- 구현 계획: 홈의 두 컴포넌트 조합 상태 표(정상·오류·막힘·오류+막힘)를 만들고 각 상태의 이음새를 시험 또는 스토리로 남긴다.
- 관련 파일: `jam-web/src/components/chapter/ChapterGaugeSection.tsx`, `ChapterRewardBlockedCard.tsx`, `jam-web/src/app/(main)/page.tsx`

## 배경 / 문제 정의

티켓 20261127_1735 민지 게이트의 범위 밖 발견물이다(참고). 정상+막힘 조합은 시험으로 고정됐지만, 오류 블록 아래에 막힘 카드가 붙는 조합은 이음새가 정해져 있지 않다.

## 완료 조건

- 오류+막힘 조합에서 두 블록 사이에 틈이나 어긋난 모서리가 없다. 확인: 시험 단언과 360px·390px 실렌더.
