# [UI] 등급 UP 결과 글자 묶음의 배지 아래 거리를 한 곳에서 정한다

## 핵심 요약

- 요구사항: 결과 글자 묶음이 배지 중심 아래로 떨어지는 거리 112px이 `TierUpGachaStage.tsx`의 `META_OFFSET`과 `TierUpGachaStage.module.css`의 `.meta` `top: calc(var(--cy) + 112px)` 두 곳에 따로 적혀 있다. 한쪽만 바꾸면 `cy` 실측 계산과 실제 배치가 어긋나 «한 번 더»가 다시 탭바와 겹칠 수 있다. 값을 한 곳에서 정한다.
- 구현 계획: `.meta`의 top을 CSS 변수(예: `--meta-offset`)로 받게 하고 `reveal` 요소의 인라인 스타일에 `META_OFFSET`을 넣는다. 또는 CSS에서 읽어 오는 쪽으로 통일한다.
- 관련 파일: `jam-web/src/app/(main)/combine/TierUpGachaStage.tsx`(`META_OFFSET` 상수, 결과 `reveal` 요소의 `--cy` 인라인 스타일), `TierUpGachaStage.module.css`(`.meta`)

## 배경 / 문제 정의
범위 밖 발견물(민지, 티켓 20261128_1203 게이트, 참고/높음).

- `scripts/verify.sh`가 통과한다.
