# [UI] 등급 UP 막힘 안내를 유리구 위에 글자로만 보인다

## 핵심 요약

- 요구사항(사용자 지시 2026-11-28, staging 화면): 가차머신 아래의 막힘 안내 카드(«같은 등급 아이템 배지가 6개 모여야…»)를 유리구 위에 카드 배경 없이 글자로만, 가운데 정렬로 보인다.
- 구현 계획: `TierUpGachaStage.tsx`에서 `{idle && notice}`를 머신 아래에서 머신 위로 옮긴다. `TierUpPanel.tsx`의 안내를 `InlineNotice` 카드에서 흰 글자 `<p>`(가운데 정렬)로 바꾸고, `role="status"`는 안내 묶음에 남긴다.
- 관련 파일: `jam-web/src/app/(main)/combine/TierUpGachaStage.tsx`(무대 렌더 첫머리), `jam-web/src/app/(main)/combine/TierUpPanel.tsx`(`notices`)

## 완료 조건
- 막힘 안내 두 종류(받지 않은 결과, 6개 이상 등급 없음)가 유리구 위에 배경 없는 가운데 정렬 흰 글자로 보인다.
- «배지 넣기»의 `aria-describedby`와 `role="status"` 알림은 그대로다.
- 변경 파일 eslint·UI 규칙·combine 시험이 통과한다.
