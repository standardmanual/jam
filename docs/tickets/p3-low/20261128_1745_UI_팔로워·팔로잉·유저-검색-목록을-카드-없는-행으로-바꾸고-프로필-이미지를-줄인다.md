# [UI] 팔로워·팔로잉·유저 검색 목록을 카드 없는 행으로 바꾸고 프로필 이미지를 줄인다

## 핵심 요약

- 요구사항: 팔로워·팔로잉 목록과 유저 검색 결과 목록에서 유저마다 흰 카드를 두지 않고 평평한 목록으로 보이게 하고, 프로필 이미지를 지금보다 작게 한다.
- 구현 계획: 세 목록의 `ListRow`에 이미 있는 `tone="flat"`(투명 면, 가로 여백 0, 모서리 0)을 쓰고, 프로필 이미지는 48px에서 36px로 줄인다. 행 앞 칸 크기는 컴포넌트 토큰 `--list-row-lead-size`가 정하므로 목록을 감싸는 곳에서 36px로 덮어쓴다(공용 값은 `userListRow.ts`).
- 관련 파일: `jam-web/src/app/(main)/userListRow.ts`(새 파일, 공용 크기·스타일), `jam-web/src/app/(main)/profile/ProfileClient.tsx`(`renderTabContent`의 목록), `jam-web/src/app/(main)/[username]/FollowUserList.tsx`(팔로워·팔로잉 페이지 목록), `jam-web/src/app/(main)/search/page.tsx`(검색 결과), `jam-web/src/app/(main)/userListRow.test.ts`(새 테스트), `jam-web/src/app/(main)/[username]/__tests__/FollowUserList.test.tsx`, `jam-web/src/app/(main)/homeGreeting.test.ts`

## 배경 / 문제 정의

세 목록이 유저마다 흰 카드(`tone="default"`) 행이고 프로필 이미지가 48px라, 사용자가 카드를 쓰지 않는 목록과 더 작은 이미지를 원했다.

## 상세 요구사항

### UI/UX 관점
- 행 면: 카드(흰 면, 큰 모서리)를 없앤다. 행은 페이지 바탕 위에 투명하게 놓이고 행 사이 구분선은 두지 않는다. 행 높이는 위아래 12px 여백이 그대로다.
- 프로필 이미지: 48px → 36px(앞 칸 36px). 이미지가 없을 때의 사람 아이콘은 20px → 16px로 함께 줄인다.
- 적용 위치: 내 프로필·타인 프로필의 팔로워·팔로잉 탭 목록, `/[username]/followers`·`/[username]/following` 페이지 목록, `/search` 검색 결과 목록.
- 검색 결과의 «N명의 유저» 안내 줄은 행이 가장자리에 붙으므로 좌우 여백(`px-1`)을 없애 정렬을 맞춘다.
- 새 컴포넌트·변형·토큰은 만들지 않았다. 앞 칸 크기는 기존 토큰을 목록 범위에서만 덮어썼다.

## 구현 계획

공용 값 파일 추가, 세 목록에 `tone="flat"`·36px 적용, 단언 테스트 갱신, 새 테스트 추가.

## 완료 조건

- 세 목록의 행 배경이 투명(`rgba(0, 0, 0, 0)`)이고 모서리 반경이 0이며 앞 칸(`.ds-list-row-lead`) 너비가 36px이다. 확인: 로컬 화면의 계산된 스타일(팔로잉 탭·`/3332/followers`·`/search?q=jiwon`).
- 타입체크와 `src/app/(main)`·`src/components/ui` 테스트가 통과한다.

- 사용자 승인: 2026-11-28 — 팔로워·팔로잉·유저 검색 목록에서 유저별 카드를 쓰지 않고 목록으로 표시, 프로필 이미지를 작게(화면 변화). 사용자가 대화에서 직접 지시했다. 36px 크기와 구분선을 두지 않는 선택, 앞 칸 토큰을 목록 범위에서 덮어쓴 방식은 카리나의 판단이며 결과 보고에서 알린다.
