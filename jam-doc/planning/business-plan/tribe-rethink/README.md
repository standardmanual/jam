# 트라이브 재구상

> **구상 단계 폴더다.** 사용자가 완성을 선언하기 전까지 코드·DB·티켓·다른 서비스 문서에 반영하지 않는다.
> 에이전트는 이 폴더를 현재 서비스 사실의 근거로 쓰지 않는다. 지금 서비스의 트라이브 기준은
> [TRIBES.md](../../content/TRIBES.md)다. 이 재구상의 출발점은
> [액티비티 배지 재구상 노트](<../08 JAM! 액티비티 배지 재구상 노트.md>) 8절의 트라이브 재검토 브리프다.

## 1. 정한 것

| 결정 | 메모 |
|---|---|
| 트라이브를 다섯 개로 줄이고, 기능보다 서사를 먼저 정한다 | 기능은 서사가 정해진 뒤 맞춘다 |
| 트라이브는 좋아하는 것, 추구하는 것, 성향 중 무엇으로 묶여도 된다 | 모든 트라이브의 축이 같을 필요는 없다 |
| 순위는 미션이 맡고, 트라이브는 명예를 맡는다 | 명예는 누구보다 높다는 비교가 아니라, 어떤 활동으로 그 명예를 얻었는지 읽히는 기록이다 |
| 트라이브 멤버는 그냥 서비스 유저다 | 멤버를 부르는 특별한 용어를 만들지 않는다 |
| 트라이브마다 분위기를 다르게 둔다 | 미식은 통통 튀는 느낌, 사진은 지금 그대로, 음악은 인디씬의 무드, 물건 덕후는 오타쿠 무드, 혼자들은 이성적이고 무뚝뚝하지만 정이 많은 사람들 |
| 트라이브 사이에 상황 설정이 겹치지 않게 한다 | 장치(쪽지, 물건을 두는 선반, 말을 돌리는 사람 등)는 한 트라이브만 갖는다. 관련 영화·애니·소설의 설정을 참고해 트라이브에 맞게 고른다 |
| 미개봉 아이템은 트라이브 설정에 넣지 않는다 | 열어 봐야 내용을 아는 아이템은 기능 설계에서 따로 다룬다 |

## 4. 작성 규칙

1. 걷기 같은 활동을 큰 컨텐츠로 드러내지 않는다. 인물이 주제를 즐기는 과정에서 움직임이 은연중에 묻어나게 한다.
2. 컨텐츠 용어는 영어로 짓되 한글로 적는다(예: 라스트오더). '파', '원조', '내력' 같은 말은 쓰지 않는다.
   아이덴티티가 강한 고유어는 유지한다(예: 노포, 신상).
3. 시놉시스에 다른 트라이브로 이어지는 아주 작은 단서를 은연중에 넣는다.
4. 캐릭터는 직업명이 아니라 실제 인물로 쓰고 한국 이름을 붙인다. 이름은 두 단어 이하다.
5. 장소는 보통 명사가 아니라 영화·소설·애니메이션에 나올 법한 고유한 이름을 쓴다.
6. 참고작의 설정이 티 나게 드러나지 않게 한다.
7. 시놉시스와 인물·장소·아이템이 한 세계로 어우러져야 한다. 주제 몰입, 감정이입, 세계관 몰입을 기준으로 다듬는다.
8. 판타지로 흐르지 않는다. 신비는 초자연 현상이 아니라 소문이 맡는다.
9. 만 14세 이상 미성년자도 쓰는 서비스다. 음주 권유, 섭취량·효능 문장, 다이어트 이야기, 실존 상표와 실존 인물
   이름은 쓰지 않는다. 컨텐츠 원칙의 원본은 [TRIBES.md](../../content/TRIBES.md)의 「어떤 트라이브에도 붙이지 않는 소재」다.
10. 이름은 쉽고 간단하게 짓는다. 어려운 외래어(예: 분더카머)는 피하고, 소문의 이름은 무명·피아노·벽장처럼
    한 낱말로 짓는다. 트라이브 이름은 참고작 속 고유명사를 짓는 방식(예: 딸기 프로덕션, 나미야 잡화점)을 참고할 수 있다.

## 5. 문서 형식

트라이브 문서는 아래 절을 같은 순서로 갖는다. 작성 전인 문서도 같은 절을 둔다.

1. 한눈에 보기
2. 시놉시스
3. 다른 트라이브로 이어지는 단서 (나가는 단서와 들어오는 단서)
4. 주요 캐릭터
5. 주요 장소
6. 주요 사물과 아이템
7. 기존 컬렉션에서 이어받는 것
8. 참고작
9. 아직 정하지 않은 것

frontmatter는 `type: catalog`, `source_of_truth: doc`, `tags: [트라이브, 컬렉션]`이고, `basis`는 이 문서다.
`status`는 작성 전이면 `stub`, 초안이면 `draft`다.
