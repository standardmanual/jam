# 한입만 연구회 컨텐츠 원고

> **JAM 2.0 기획 문서다.** 순서 4(컬렉션의 자리, 이름, 한 줄 서사)를 사용자가 확인했다(2026-10-08). 서비스, DB, 티켓에 반영하지 않았다.
> 만드는 방법과 순서는 [트라이브 컨텐츠 제작](<../../service-redesign/15 트라이브 컨텐츠 제작.md>) 정책 5절과 6절, 문장 규칙은
> [트라이브 보이스](<../../service-redesign/트라이브 보이스.md>) 5.1절(한 문장 30자, 쉼표 두 번까지), 서사의 원본은 [한입만 연구회 초안](<../01 미식.md>)이다.
> 아래 절 번호가 붙은 '초안'은 이 트라이브 초안의 절이다.

## 2. 이름 결정 (2026-10-08 사용자 선택)

| 옛 이름 | 정한 이름 | 결정 |
|---|---|---|
| 무명(無名)을 쫓는 야식가들 | 무명을 쫓는 야식가들 | 한자 표기만 뺐다. 윈터는 '야식'이 밤 외출을 떠올리게 한다며(금지 소재 3번) 「무명을 쫓는 손님들」을 추천했지만, 사용자가 옛 이름을 살렸다. 서사에는 밤 외출을 권하는 문장이 없다 |
| 환상의 꼬치구이 트럭 | 무명의 은박지 꼬치 | 윈터 추천. '환상의'는 판타지이고 옛 설정의 쌍둥이 트럭은 초안에 없다 |
| 편의점 심야 만찬 | 그대로 | 윈터는 「창가 자리의 조합 연구소」를 추천했지만 사용자가 옛 이름을 살렸다. 서사는 럭키마트 창가의 조합 연구소로 쓴다 |
| 새벽 라이딩 끝의 국밥 | 새벽 무렵의 국밥 | 사용자가 직접 지었다. 운동 종목(라이딩)을 빼고, 첫차가 지날 무렵이라는 이혜원의 일과와 맞춘다 |
| 겨울밤의 소박한 온기 | 2번 출구의 붕어빵 | 윈터 추천. 초안 7절의 연결인 2번 출구를 이름에 둔다 |
| 봉인된 연금술 배합 | 순자 할매의 매실청 | 윈터 추천. 봉인과 연금술은 판타지이고, 초안 6절의 사물 이름 그대로다 |
| 위로의 탄수화물 | 외근 끝의 한 접시 | 윈터 추천. '위로', '탄수화물', 옛 설명의 "땀 흘린 뒤"를 뺐다. '곱빼기'는 이름만 보면 양으로 읽혀 넣지 않았다 |

## 3. 자리 미정 6개의 판단

| 옛 이름 | 판단 | 이유 |
|---|---|---|
| 위로의 탄수화물 | 고름(10번, 사용자 선택) | 자리 확정 9개에 없던 오재훈(곱빼기)을 채우고 옛 아이템 8종을 살린다. 초안에 없는 가게(분식집, 배달)는 쓰지 않고 '가게'로만 쓴다 |
| 업힐 끝의 단맛 | 고르지 않음 | 윈터는 얼리버드와 신상 헌터를 채우는 쪽으로 추천했지만 사용자가 곱빼기 쪽을 골랐다. 이름도 운동 성과다. 얼리버드 쪽 사물은 5절대로 3번에 담는다 |
| 열대야의 극야 갈증 | 고르지 않음 | 오아시스(9번)와 음료 소재가 겹치고, '극야'가 밤을 부른다 |
| 극한의 갈증 | 고르지 않음 | 탈수 직전이라는 위험 상황이고 운동 서사다 |
| 녹초와 포션 | 고르지 않음 | 포션(판타지), 회복과 후회(쓰지 않는 말)가 이름과 아이템 전반에 있다 |
| 공원 벤치의 포식자 | 고르지 않음 | 공원과 새는 초안에 없는 설정이다 |

- 그대로는 쓰지 않는 8개는 초안 7절에 적힌 대로다. 쓰지 않는 컬렉션은 지우지 않고 어드민에서 비활성화한다(정책 6절).
- 대결 무대 사물(제비뽑기 통, 번호 명찰, 심사위원의 숟가락)은 4번 서사에 얹었다.

## 4. 검수

- 금지 소재 6가지, 보이스 카드 5.1절의 쓰지 않는 말, 작성 규칙 11가지에 걸리는 것이 없다(윈터 검수).
- 경계선이던 두 곳은 사용자 결정으로 다시 썼다. 8번은 신상 헌터를 놀리는 장면을 빼고 국자와 매실청으로 쓴다. 9번은 "넣으면 나온다"는 뽑기 구도를 빼고,
  자판기가 옛날 백 원을 받는 것과 버튼 줄의 처음 보는 음료를 따로 쓴다(초안 5절도 함께 고쳤다).
- 10번의 '곱빼기'는 "곱빼기의 머릿속"으로 사람 호칭임이 드러나게 썼다. 양, 몇 그릇, 이름의 유래를 쓰지 않았다.

## 5. 순서 5로 넘기는 것

- 옛 아이템 배지 가운데 바꿀 것: 3번의 구겨진 캔맥주와 2+1 행사 바코드, 5번의 쌀 음료 두 개(술로 읽힘), 4번의 찌그러진 양은 잔, 8번과 9번의 판타지 항목,
  6번의 돼지국밥 영수증(초안은 사골 국밥), 10번의 구겨진 배달 영수증(배달은 초안에 없다).
- 10번의 군만두 간장 팩은 가게 안에서 먹는 장면에 맞게 다듬을지 정한다. 라면 면발 설명에 "남은 면"이나 "전부"를 쓰지 않는다(곱빼기 이름의 유래와 닿는다).
- 엔드롤 안쪽 사물(오더북, 젓가락 포장지 별, 라디오, 재료 상자)은 5번의 아이템 배지로 담는 안이 가장 가깝다.
- 얼리버드와 신상 헌터 쪽 사물(웨이팅 번호표, 진동벨, 반숙의 리뷰 노트)은 3번의 아이템 배지로 담는 안을 먼저 본다. 초안 6절도 얼리버드와 럭키마트를 한 칸에 묶었다.
- 7번의 붕어빵 봉투는 소나무 잡화점 「행운의 잡동사니」의 남하준 사물(붕어빵 봉투)과 겹치지 않게 팥과 슈크림 쪽으로 쓴다.
- 냄새가 1번, 2번, 5번, 10번 서사에 모두 나온다. 아이템 배지 설명을 쓸 때 냄새가 몰리지 않게 본다.
- 한 줄 서사 20문장 가운데 13문장이 쉼표 하나로 반씩 나뉜 "A, B." 모양이다(쉼표 6개를 빼기 전에는 19문장). 확정한 서사는 고치지 않고, 아이템 배지 설명에서 이 모양이 세 번 넘게 이어지지 않게 한다([트라이브 보이스](<../../service-redesign/트라이브 보이스.md>) 2절 9번). 2026-10-08 AI 티 검토에서 찾았다(사용자 결정).
- 초안 보강이 필요할 수 있는 곳: 2번 출구에 붕어빵 말고 다른 노점이 있는지(있으면 옛 아이템 5종을 살리고, 없으면 1종), 순자 할매 매실청의 담근 해와 쓰이는 자리.
