# 혼자들 컨텐츠 원고

> **JAM 2.0 기획 문서다.** 순서 4(컬렉션의 자리, 이름, 한 줄 서사)를 사용자가 확인했다(2026-10-08). 서비스, DB, 티켓에 반영하지 않았다.
> 만드는 방법과 순서는 [트라이브 컨텐츠 제작](<../../service-redesign/15 트라이브 컨텐츠 제작.md>) 정책 5절과 6절, 문장 규칙은
> [트라이브 보이스](<../../service-redesign/트라이브 보이스.md>) 5.5절(한 문장 45자, 쉼표 없이, 한 문장에 사실 하나), 서사의 원본은 [혼자들 초안](<../05 내향인.md>)이다.
> 아래 절 번호가 붙은 '초안'은 이 트라이브 초안의 절이다.

## 2. 이름 결정 (2026-10-08 사용자 선택)

| 옛 이름 | 정한 이름 | 결정 |
|---|---|---|
| 결계 '섬데이' 돌파 | 고친 기계 번호 | 윈터 추천. 결계는 판타지이고 돌파는 성과 서사다. 보이스 카드 5.5절이 류시온은 고친 기계 번호와 손글씨 자석만 쓴다고 정해서, 연결을 "처음 다시 나온 새벽"에서 "고친 흔적"으로 옮겼다 |
| 내일의 러너 | 짝 잃은 양말 | 윈터의 다른 후보를 사용자가 골랐다. '러너'는 달리기 서술이고, "내일은 낮에 나가 보자"는 다짐은 보이스 카드가 쓰지 않기로 한 줄기라서 류시온의 컬렉션을 하나로 줄이고 이 자리를 보름 정리의 짝 잃은 양말로 옮겼다 |
| 헌책방의 냄새 | 밑줄이 그어진 문장들 | 윈터 추천. 헌책방은 초안에 없는 장소라서 빼고 초안 6절의 낱말을 그대로 썼다 |
| 노이즈 캔슬링 세상 | 그대로 | 비사이드 레코즈 쪽이 「아무것도 안 트는 방」으로 바뀌어 낱말 겹침이 사라졌고, 초안 4절도 "노이즈 캔슬링 헤드폰"이라고 적었다(카리나 추천, 사용자 확인) |
| 잃어버린 시간 | 그대로 | 초안 7절의 연결(건조기 사십 분)에 맞고 혼자들 카드의 쓰지 않는 말에 걸리지 않는다. 찰칵단 카드가 막은 '잃어버린'은 서사에 쓰지 않았다 |
| 길거리 우체통의 편지 | 그대로 | 이름 없이 오가는 글이라는 뜻이 노트와 겹친다. 우체통은 서사에 쓰지 않아 새 장소가 생기지 않는다 |
| 겨울잠의 안식처 | 그대로 | 보이스 카드 5.5절의 좋은 예로 확인받은 이름과 서사다 |
| 침묵의 메아리 | 그대로 | 이름 자체는 초자연을 말하지 않는다. 옛 설명(기이한 진공)과 옛 아이템은 가져오지 않는다 |

## 3. 자리 미정 5개와 새로 만든 두 자리

| 옛 이름 | 판단 | 이유 |
|---|---|---|
| 헌책방의 냄새 | 고름(8번, 사용자 확인) | 초안 6절의 "밑줄이 그어진 문장들"은 자리 확정 7개가 닿지 않은 사물이고, 옛 아이템 4종을 살린다 |
| 종이 지도의 낭만 | 고르지 않음(다른 후보) | "골목 한 바퀴"(초안 2절, 반딧불 골목)로 풀면 밖에서 움직이는 장면이 적다는 약점(컨텐츠 분석 노트 5절)을 메우지만, 초안에 지도와 길 찾기가 없어 살릴 아이템이 없다 |
| 날씨 탓 전문가 | 고르지 않음 | '날씨 탓'이 보이스 카드 5.5절의 쓰지 않는 말(자조)이고, 폭염 주의보와 태풍 소재는 기상특보 날의 외출 권유에 가깝다 |
| 스마트폰의 노예 | 고르지 않음 | '노예'와 '자괴감'이 자조에 걸리고, 배달 앱 쿠폰은 금지 소재 5번이다 |
| 3일 차의 위기 | 고르지 않음 | "3일 차"가 창문의 사흘, 나흘째와 겹쳐 읽혀 창문을 위기나 안부 확인처럼 보이게 한다(금지 소재 2번). 다이어트 포기 선언문과 피자 영수증은 금지 소재 6번에 걸린다 |
| (새로) 등대지기의 손전등 | 9번(사용자 확인) | 중심 인물 진봉수에게 컬렉션이 없다. 다른 후보 「밤새 불을 켜 둘 것」(가게 규칙)은 창문의 불과 겹쳐 읽힐 수 있어 뒤로 두었다 |
| (새로) 이자는 없음 | 10번(사용자 확인) | 변지원에게 컬렉션이 없다. 다른 후보 「비상 동전 통」은 한입만 연구회 「오아시스 자판기의 동전」과 낱말이 겹친다 |

- 소문 「창문」의 컬렉션은 두지 않았다. 금지 소재 2번(고립과 안부)에 가장 가까워서, 창문은 아이템 배지의 Mystic 설명에서 사실로만 쓴다.
- 실내 운동 소재 2개(먼지 쌓인 홈트 기구, 헬스장 기부 천사)는 쓰지 않는다(진행 노트 4.2절).

## 4. 검수

- 금지 소재 6가지, 보이스 카드 5.5절의 쓰지 않는 말, 작성 규칙 11가지에 걸리는 것이 없다(윈터 검수).
  - 원소이가 나오는 5번과 8번은 저녁 아홉 시 이전이고, 밑줄을 긋는 사람은 "소이 또래"로만 쓴다(금지 소재 1번).
  - 류시온이 방 밖에 나오지 않은 기간, 학업을 그만둔 일, 낮의 다짐을 쓰지 않았고, 7번 서사에는 사람이 나오지 않는다(금지 소재 2번).
  - 새벽 세 시, 보름 밤, 저녁 아홉 시는 모두 사실 서술이고 권유가 없다(금지 소재 3번).
- 다른 트라이브와 소재가 닿는 곳: 5번과 7번은 비사이드 레코즈의 정적, 2번은 소나무 잡화점의 입양 칸(분실물, 단추를 쓰지 않음), 1번은 소나무 잡화점 「공구통의 비밀」(공구, 부품을 쓰지 않음)과 닿는다. 인화 봉투는 찰칵단의 장치라 컬렉션 소재에서 뺐다.

## 5. 순서 5로 넘기는 것

- 옛 아이템 배지 가운데 버릴 것: 작심 4일차의 기적(창문 나흘째와 겹침), 말라버린 비명소리와 침묵을 깨는 단 하나의 심장소리(금지 소재 2번), 사랑 고백이 적힌 종이 조각, 읽지 않은 마음, 보내지 못한 엽서(마음의 이름).
- 2번 짝 잃은 양말의 설명에는 원소이를 넣지 않는다. 옛 아이템 「한 짝만 남은 수면양말」이 바로 이어진다.
- 초안 보강이 필요한 곳(9종을 채우려면):
  - 9번 등대지기의 손전등: 진봉수의 사물이 손전등과 노트 열두 권 둘뿐이고, 노트 열두 권은 소나무 잡화점으로 가는 단서라 쓸 수 없다. 초안 6절에 등대 시절 사물을 더해야 한다.
  - 10번 이자는 없음: 동전 통, 장부, 전자계산기 셋뿐이다.
  - 1번 고친 기계 번호: 자석과 기계 번호뿐이라 얇다.
- 초안 7절 표(류시온 두 행, 자리 미정 다섯 행)를 이 배치에 맞춰 고쳤다. 초안 2절과 4절의 류시온 서술은 그대로 두고, 컬렉션과 배지 문구에서만 쓰지 않는다.
- 한 줄 서사에 '적혀 있습니다'가 세 번(4번, 8번, 10번) 나오고, 3번의 "각자의 몫입니다"는 교훈조로 맺는 문장처럼 읽힌다(확신 보통). 확정한 서사는 고치지 않고, 아이템 배지 설명에서 이 모양이 세 번 넘게 이어지지 않게 한다([트라이브 보이스](<../../service-redesign/트라이브 보이스.md>) 2절 9번). 2026-10-08 AI 티 검토에서 찾았다(사용자 결정).
