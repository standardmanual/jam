# 액티비티 배지 컨텐츠 원고

> **JAM 2.0 기획 문서다.** 순서 6(액티비티 배지 계열과 운동 속성 구간 이름)의 공통 원고다. 지금은 계열 목록 초안이고, 사용자 의견(2026-10-09)을 반영한 두 번째 판이다. 사용자 확인 전이다.
> 서비스, DB, 티켓에 반영하지 않았다. 만드는 방법은 [트라이브 컨텐츠 제작](<../../service-redesign/15 트라이브 컨텐츠 제작.md>) 2절, 5절, 7절, 8절,
> 쓰는 규칙은 [트라이브 보이스](<../../service-redesign/트라이브 보이스.md>) 2절과 4절, 갈래와 조건은 [액티비티 배지와 체크인 배지](<../../service-redesign/09 액티비티 배지와 체크인 배지.md>) 2절과
> [배지 획득 조건](<../../service-redesign/03 배지 획득 조건.md>) 2절, 3절, 수량과 기준값은 [게이미피케이션 밸런스](<../../service-redesign/19 게이미피케이션 밸런스.md>) 6절이다.

## 1. 이 원고의 약속 (사용자 결정, 2026-10-09)

- **이름과 등급:** 계열마다 이름은 하나이고, 단계는 등급(레벨형은 Lv.N)으로 표시한다. 운동 속성의 구간 계열(12개)만 구간마다 이름을 둔다([트라이브 컨텐츠 제작](<../../service-redesign/15 트라이브 컨텐츠 제작.md>) 2절).
- **설명:** 길이는 아이템 배지와 같게 1~2문장이다. 단계마다 따로 쓰고, 레벨형도 레벨마다 따로 쓴다.
- **값은 종목마다 다르다:** 걷기, 러닝, 트레일러닝, 자전거, 등산의 밸런스에 맞춰 횟수 사다리와 구간 경계값을 다르게 한다. 지금 서비스의 값을 참고하고, 값은 임시로 쓴 뒤 나중에 밸런싱한다.
  사용자가 쓴 '하이킹'은 문서의 '등산'과 같은 종목으로 읽었다(지금 서비스의 종목 키는 hiking이다).
- **운동 속성은 종목마다 계열과 이름을 따로 둔다.** 종목마다 쓰지 않는 속성은 골라서 뺀다(2.10절 선별표). 다른 갈래의 '종목별' 계열은 계열 하나에 이름 하나를 두고 종목마다 값만 다르게 한다.
- **날씨:** 폭염은 30도 이상, 한파는 영하 5도 이하다. 정책 문서([배지 획득 조건](<../../service-redesign/03 배지 획득 조건.md>) 2절, 7절)를 고쳤다. "비 오는 날 3번 움직였어요"는 이름이 아니라 조건 문구다.
  날씨 갈래는 시간 조건과 섞는다. 밤과는 섞지 않는다([액티비티 배지와 체크인 배지](<../../service-redesign/09 액티비티 배지와 체크인 배지.md>) 5절).
- **밤과 날씨 배지는 이름과 설명에 트라이브를 담지 않는다.** 해당하는 계열은 9개(3-8, 4-1~4-8)다. 트라이브 서사 없이 조건에 맞게 쓰고, 금지 소재와 보호 장치는 그대로 지킨다.
- **추가 후보는 사용자 의견대로 넣었다**(3절). 사용자가 직접 더한 첫 팔로워, 첫 팔로잉, 누적 팔로잉도 8-19와 8-20에 합쳐 넣었다.
- **아직 이름이 없는 말:** 챕터 이름과 에너지 이름은 임시 이름으로 쓰고 정한 뒤에 바꾼다. 캡슐, 믹스, 드랍, 픽업 같은 기능 이름은 JAM 활동 갈래에서 쓴다.
- **사용자가 알아서 판단하라고 한 것(카리나 판단):**
  - "같은 문장 모양이 세 번 넘게 이어지지 않게" 규칙은 한 갈래 안과 한 트라이브 안, 두 곳에서 센다.
  - 회복 갈래의 공백 일수와 한 주에 모은 에너지의 기준값은 임시로 정했다.
  - 등급은 Common, Rare, Epic, Mystic 네 개뿐이라서 사용자가 5단으로 적은 사다리(3-7, 8-4~8-7)는 레벨형(Lv.1~5)으로 두었다. 레벨형은 등급이 없다(확인할 것 2번).
  - 트라이브가 없는 배지의 문장은 한 문장 45자, 쉼표 한 번까지로 임시로 두었다.

## 2. 계열 목록 초안

> 문서가 정한 갈래와 조건 종류에서 골랐다. 지금 서비스의 배지 이름과 계열 구성은 따르지 않았고(백지에서 설계, [액티비티 배지와 체크인 배지](<../../service-redesign/09 액티비티 배지와 체크인 배지.md>) 1절),
> 값(횟수 사다리, 경계값)만 지금 서비스에서 참고했다. 종목 칸의 '합산'은 종목과 상관없이 모든 활동을 세는 것이고, '종목별'은 다섯 종목마다 따로 세고 값이 다른 것이고,
> 종목 이름이 적힌 칸은 그 종목만 쓰는 것이다.
> 상태 칸의 '승인'은 사용자가 승인한 그대로, '변경'은 사용자가 단계 값을 바꿔 반영한 것, '새로'는 사용자가 승인한 추가 후보를 넣은 것(단계 값은 카리나가 임시로 채움),
> '다시 확인'은 구조를 바꿔 다시 봐야 하는 곳, '확인 전'은 의견 칸이 없던 표다. 의견 칸은 다음 확인용으로 비워 두었다.

- 상태는 승인 27, 변경 12, 새로 29, 다시 확인 20, 확인 전 7개다.
- 트라이브를 쓰는 계열은 86개, 트라이브가 없는 계열은 9개다. 95개의 30%는 28.5개라서 한 트라이브는 28개까지다.

### 2.10 운동 속성의 종목별 선별표

사용자 결정(2026-10-09)으로 운동 속성은 종목마다 계열과 이름을 따로 두므로, 종목마다 쓸 속성을 골랐다. 고른 기준은 세 가지다.
그 종목을 대표하는 값인가, 오래 움직이거나 빨리 가라고 무리하게 권하지 않는가, 같은 종목의 다른 속성과 겹치지 않는가.

| 종목 | 한 번의 거리 | 한 번의 시간 | 속도·페이스 | 한 번의 오른 높이 | 한 번의 해발 높이 | 쌓아 온 거리 | 쌓아 온 오른 높이 |
|---|---|---|---|---|---|---|---|
| 걷기 | ○ 6-1 |  |  |  |  | ○ 6-2 |  |
| 러닝 | ○ 6-3 |  | ○ 6-4 |  |  | ○ 6-5 |  |
| 트레일러닝 | ○ 6-6 |  |  | ○ 6-7 | ○ 6-8 | ○ 6-9 | ○ 6-10 |
| 자전거 | ○ 6-11 |  | ○ 6-12 | ○ 6-13 |  | ○ 6-14 | ○ 6-15 |
| 등산 |  | ○ 6-16 |  | ○ 6-17 | ○ 6-18 |  | ○ 6-19 |

종목에 걸치는 계열은 6-20(내 가장 긴 기록: 걷기, 러닝, 트레일러닝, 자전거의 거리), 6-21(쌓아 온 움직인 시간: 합산), 6-22(내 가장 빠른 기록: 러닝, 자전거)다. 6-21과 6-22는 사용자가 승인한 추가 후보다.

뺀 것과 이유는 다음과 같다.

- **속도·페이스:** 걷기, 트레일러닝, 등산은 뺐다. 걷기와 등산은 빨리 가라고 권하게 되고, 트레일러닝은 지형에 따라 속도가 달라 값이 의미가 없다. 자전거는 평균 속도만 쓴다.
  최고 속도는 정책에 없는 조건이다([액티비티 배지와 체크인 배지](<../../service-redesign/09 액티비티 배지와 체크인 배지.md>) 12절).
- **한 번의 시간:** 등산만 쓴다. 등산은 거리보다 걸린 시간이 대표 값이다. 나머지 종목은 거리와 겹치고 오래 움직이라고 권하게 된다.
- **오른 높이와 해발 높이:** 평지가 중심인 걷기와 러닝은 뺐다. 자전거는 해발 높이를 뺐다. 오른 높이로 충분하다.
- **쌓아 온 거리:** 등산은 뺐다. 오른 높이가 대표 값이다. **쌓아 온 오른 높이:** 걷기와 러닝은 뺐다.
- 지금 서비스에는 있지만 뺀 것은 등산의 한 번 거리, 트레일러닝의 한 번 시간이다. 다시 넣고 싶으면 말해 달라.

구간 이름은 구간 계열 12개마다 4개씩 모두 48개이고, 종목마다 따로 짓는다. 종목의 움직임이 들어갈 수 있다(예: 걷기는 '걸은 날').
값은 [게이미피케이션 밸런스](<../../service-redesign/19 게이미피케이션 밸런스.md>) 6절의 규칙으로 정한다. Common은 그 종목 보통 퍼소나의 한 번 활동, Rare는 그 1.5배, Epic은 열심 기준선의 한 번 활동, Mystic은 그 위의 의미 있는 숫자다.
걷기와 등산에는 열심 퍼소나가 없어 Epic을 규칙으로 만들 수 없으므로 지금 서비스의 값을 참고해 임시로 채운다(견본 단계에서 표로 보여 준다).

## 6. 확인할 것

1. **범위가 정책을 넘었다.** 계열이 95개이고 운동 속성만 22개다. 19-E4는 갈래마다 5~8개, 모두 50~60개이고, 이유는 모든 배지에 트라이브 서사의 이름과 설명을 붙이는 양이 많아서다.
   (가) 정책을 이 범위로 고치고 갈래마다 끝낼 때마다 확인받으며 쓴다. (나) 이 중 50~60개를 1차로 골라 쓰고 나머지는 추가분으로 둔다. 추천은 (가)다. 이미 항목마다 승인하셨고, 갈래마다 확인받으면 중간에 멈출 수 있다.
2. **5단 사다리는 레벨형으로 두었다.** 등급은 네 개뿐이라 1·3·6·9·12회(3-7)와 1·5·30·50·100회(8-4~8-7)는 레벨형(Lv.1~5)이다. 레벨형은 등급이 없고 포인트가 레벨마다 10이다. 4단으로 줄여 등급형으로 두는 쪽도 가능하다.
3. **연속 계열의 1단계.** 1-2, 1-5, 1-6의 1단계(1주)는 이어진 것이 아니라 한 주이고, 1-6의 1단계는 1-1의 1단계와 같은 조건이라 두 배지를 함께 받는다. 그대로 둘지 알려 달라.
4. **운동 속성의 종목별 선별표**(2.10절)가 맞는지 확인해 달라. 이 표는 이전에 임시 승인하신 구조를 바꾼 것이라 다시 확인이 필요하다.
5. **새로 넣은 계열의 단계 값**은 카리나가 임시로 채웠다(3-9~3-11, 4-7, 4-8, 5-8~5-17, 6-21, 6-22, 8-9~8-20).
6. **팔로워 계열을 합친 방식**(8-19, 8-20)이 맞는지 확인해 달라.
7. 탐험의 기존 7개(5-1~5-7)에는 의견 칸이 없어 '확인 전'으로 두었다.
8. 정책 문서에 옮길 것은 목록을 확정한 뒤 한 번에 한다. 정책에 없는 집계는 5-4(서로 다른 지점의 수)와 5-17(동네별 활동 일수) 둘이다.
