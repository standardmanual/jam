# JAM 2.0 기획 (jam2-redesign)

> **JAM 2.0 기획 문서다.** 서비스, DB, 티켓에 반영하지 않았다. 에이전트는 이 폴더의 문서를 현재 서비스 사실의 근거로 쓰지 않는다.

3단계(현재 서비스와 비교)를 마친 뒤 JAM 2.0 기획 문서를 이 폴더로 모았다(2026-10-10 사용자 결정, 「버전명-기획내용」).
JAM 2.0의 상위 기획 문서인 [라이브 운영 블루프린트](<../business-plan/07 JAM! 라이브 운영 블루프린트.md>)는 티켓과 운영툴 PRD가 많이 가리켜서 `business-plan` 폴더에 그대로 둔다.
