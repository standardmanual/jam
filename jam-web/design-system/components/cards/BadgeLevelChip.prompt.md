# BadgeLevelChip

레벨형 배지의 `Lv.N` 칩. 티켓 20260905_0036 신규.

## 왜 `RarityBadge`의 분기가 아닌가

**v5 레벨형은 `rarity`가 NULL이다.** `RarityBadge`는 «등급»을 그리는 컴포넌트이고
서비스 9곳이 쓴다. 거기에 「레벨이면 다르게 그린다」 분기를 넣으면 두 개념이 한 컴포넌트에
섞여, 등급 로직을 고칠 때 레벨 표시가 함께 흔들린다. 그래서 별도로 뺐다.

## 규칙

- `--color-secondary` 채움 + 흰 텍스트. 카드 `#1a1a1a` 위에서 **5.86:1**(AA 통과).
- **폭 52px 고정.** 계열 카드 1행 그리드가 `[52px 칩][1fr 이름][auto 카운터]`라,
  칩 폭이 고정이어야 **이름 시작 x가 모든 계열에서 같아진다**.
- 레벨 수가 늘어도 칩 크기는 바뀌지 않는다.
