# BadgeStampRow

반복형 배지 한 계열. 티켓 20260905_0036 신규.

## 핵심 규칙 — 누적은 `×N` 칩 하나로만

**점 그리드를 쓰지 않는다.** 이유는 둘이다.

1. 47회를 점 47개로 그리면 **100회를 넘는 순간 의미를 잃는다.** v5 반복형 사다리는
   Mystic이 100~300회다.
2. 축약하면(예: 10개마다 1점) **임의 기준이 화면에 드러난다.** 유저는 「왜 10개인가」를
   묻게 되고, 답이 없다.

`×47` 칩 하나가 정확하고, 자리도 고정이다.

## 칩 칸은 «칩이 있을 때만» 잡는다 (20260906_1323 §2)

1행 그리드는 `[52px 칩][1fr 이름][auto 카운터]`지만, 칩을 그리지 않는 행
(미획득 · `rarity == null`)은 **칩 칸 자체를 만들지 않고** `[1fr 이름][auto 카운터]`가 된다.
빈 `<span>`을 남긴 채 칸만 `auto`로 바꾸면 `columnGap` 8px이 그대로 남아 여백이 절반만
없어진다. 이름은 말줄임하지 않고 줄바꿈한다(§5).

## v5 반복형이란

`rarity` **있음** + `condition_json.repeat_count`. 「같은 조건을 몇 번 달성했는가」를 센다.
v5에 139종 42계열이 있다.

티켓 20260906_0110에서 다룬다 — 컴포넌트 문제가 아니다.
