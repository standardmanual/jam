# BadgeStatusSection

배지 목록의 상태 섹션. 티켓 20260905_0036 신규.

## 섹션은 둘뿐이다

「다음 목표」와 「받은 배지」. **설계 분류(누적·주기·시간대…)를 노출하지 않는다** —
그건 카탈로그를 만든 사람의 언어이지 유저의 언어가 아니다.

## 왜 `Accordion`을 쓰지 않았나

DS의 `Accordion`은 **「한 번에 하나만 열림」**이다(`Accordion.d.ts`). 여기서는 두 섹션이
각각 독립으로 접혀야 하고, 「미도입 8종」이라 서비스에 대응 개념도 없다(티켓 20260820_010).

## 접힘 규칙

- **접힘 상태에서도 개수를 노출한다** — 숨은 콘텐츠가 있다는 힌트가 없으면 안 펼친다.
- **펼쳤을 때만 `children`을 렌더한다.** `display: none`이 아니라 **미렌더**다 —
  그래야 진행 계산 요청이 실제로 멈춘다. 630종이라 서버 계산량이 문제가 된다.

⚠️ `children ?? emptyText`이므로 **빈 배열(`[]`)을 넘기면 emptyText가 안 나온다.**
없을 때는 `null`을 넘겨라.
