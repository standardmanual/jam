배지 트리(/badges/tree) 상단의 진행 요약 카드. 획득/전체 히어로 숫자 + 등급별 분포 막대를
**2행 3열**로 보여준다(20260903_2329, 배치는 20260906_1323).

| 1행 | 전체 `14/64` | Mystic | Epic |
| 2행 | 레벨 | Rare | Common |

```jsx
<BadgeTreeSummaryHeader
  earnedCount={14}
  totalCount={64}
  byRarity={{
    common: { earned: 8, total: 19 },
    rare: { earned: 4, total: 16 },
    epic: { earned: 2, total: 17 },
    mystic: { earned: 0, total: 12 },
  }}
/>
```

- `totalCount`는 현재 탭(종목)의 전체 배지 수 — 계열 레일 안 배지 + 독립(트로피) 배지를
  합친 값이다. 호출부(현재 활성 탭 데이터)가 계산해서 넘긴다.
- 분포 막대는 등급색(`--color-rarity-*`)이 아니라 상태 채널(`--status-done-solid`, 다
  채운 것)로 채운다. 등급은 등급칩 안에서만 색을 쓰고, 이 막대는 "그 등급 중 몇 개를
  채웠나"를 말하지 등급 자체를 말하지 않는다.
- 진행 수치(%, 잔여값 등)는 표시하지 않는다 — 등급별 분모 자체가 이미 등급 체계를
  드러내는 정보라 그것으로 충분하다.
- **열 수는 3열 고정이다**(20260906_1323). 칸 수에 따라 열 수를 바꾸지 않는다 — 그러면
  칸이 하나 줄 때마다 Rare·Common의 위치가 통째로 움직인다. 큰 숫자는 첫 칸 안에 들어가고,
  그 칸에도 다른 칸과 같은 6px 막대(전체 진행률)를 둬 세 칸의 막대·라벨 위치가 맞는다.

## v5 추가 — 등급 없는 배지 (티켓 20260905_0036)

- `noRarity` — 등급이 없는 배지(레벨형) 수. **넘기지 않으면 2행 첫 자리를 빈 칸으로 둔다**
  (20260906_1323 — 열 수는 그대로 3열이다).
- 그리드에서 `repeat(4, 1fr)` 하드코딩을 걷어냈다. 요약이 「등급 4칸」 그 자체였는데,
  v5는 193종이 `rarity` NULL(레벨형)이라 4칸으로는 셀 수 없다.
