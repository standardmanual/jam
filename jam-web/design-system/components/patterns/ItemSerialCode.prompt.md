아이템 배지 일련번호를 "각인된 태그" 카드 묶음으로 보여주는 패턴. 앞 4자(알파벳 prefix)는
카드 1장씩, 나머지 숫자는 하나의 넓은 박스로 렌더링한다. 서비스 어디에 배치되든 이 컴포넌트
덩어리 그대로 쓴다 — 낱장으로 분리해 재조합하지 않는다.

```jsx
<ItemSerialCode code="ABCD000042" height={160} />
```

- `code`는 파싱하지 않고 그대로 앞 4자/나머지로 자른다 — 호출부가 `${serial_prefix}${String(serial_number).padStart(6, '0')}` 형태로 이미 조합해 넘긴다.
- 숫자 박스는 자리 수만큼 너비가 늘어난다(고정폭 아님) — 5자리든 6자리든 그대로 대응.
- `height` 하나로 전체가 비례 스케일된다. Figma 원본 실측은 height 400(카드 280×400) —
  실사용 맥락(리스트 한 줄 vs 상세 히어로)에 맞는 값을 호출부에서 정한다.
