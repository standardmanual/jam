포인트 «값 + 단위»를 그리는 표시 전용 패턴. 값과 «포인트» 글자 모두 `--point-text`(오렌지) 한 색이다.
색은 이 컴포넌트가 정하므로 호출부에서 포인트 글자에 색 클래스를 따로 적지 않는다.

```jsx
// 우측 보상 칸 — 굵은 숫자 위, 작은 «포인트» 아래, 가운데 정렬
<PointText value={1200} layout="stacked" />

// 문장 속 — «1,200 포인트» 한 덩어리만 칠하고 조사는 밖에 둔다
<p>보상으로 <PointText value={1200} />를 받았어요.</p>
```

- `value`가 `null`/`undefined`면 아무것도 그리지 않는다. `0`은 그린다 — 0일 때 숨길지는 호출부가 정한다.
- 숫자는 `toLocaleString('ko-KR')`(쉼표)로 포맷한다. 부호가 필요하면(`-30`) 포맷된 문자열을 넘기고, 부호도 같은 덩어리에서 칠한다.
- 포인트 내역 행(`ListRow` 레시피, `ListRow.prompt.md`)은 `layout="stacked"`에 `+` 없는 숫자(`120`)를 넘기고, 차감만 `−50`처럼 `−`(U+2212)를 붙인다.
- `unit=""`(빈 문자열)이면 값만 그린다. 라벨이 «포인트»를 이미 말하는 행이나 단위를 따로 두는 큰 잔액에 쓴다. 값 뒤 공백도 붙지 않는다.
- `inline`은 값과 «포인트»가 줄 끝에서 갈라지지 않게 `nowrap`이다.
- 버튼 안 포인트는 이 컴포넌트를 쓰지 않는다 — 버튼 글자색을 따른다. 숫자 없는 일반 명사 «포인트»도 칠하지 않는다.
- 크기·굵기로 강조를 더하지 않는다. 그라디언트·글로우·그림자 금지. 코인 아이콘 색은 건드리지 않는다.
- 알려진 한계: 흰·크림 면 위 12~16px 글자는 대비 4.5:1에 못 미친다(3:1은 넘는다). 어두운 면 위는 약 4.98:1이라 같은 토큰을 쓴다.
