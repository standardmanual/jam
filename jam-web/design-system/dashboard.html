모듈러 MODULAR

Palette

블랙 캔버스, 화이트 텍스트, 그레이 카드 표면(#1a1a1a), 레드-오렌지 액센트(#e8461f), 브라운 보조(#8a5a2e). 다크 전용 시스템.

Typography

Noto Sans KR. 헤딩 라이트 웨이트(300–400), 히어로 대형 디스플레이 크기, H1/H2 좁은 음수 자간.

Radius Rules

버튼·태그 = 완전 필(9999px) 전용. 카드·인풋 = 8–12px 중간 단계. 필 반경을 카드에 섞지 않는다.

Spacing

4px 기본 단위 배수: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px

Elevation

박스 섀도 없음. 블랙 배경에서 깊이감은 테두리와 회색 카드 표면으로만 표현.

Fixed Terms

획득(earn) · 드랍(drop) · 픽업(pickup) · 방문(visit) · 포인트 · 인벤토리 · 아이템북

Badge Frames

7 clip shapes for badge image containers (BadgeFrame component)

BadgeFrame
shape: circle · ticket-v · ticket-h · scallop · corner-cut · tab-notch · dumbbell. 배지 이미지/아이콘을 children으로 전달.
<BadgeFrame shape="scallop" width={200} height={200} color="var(--color-primary)"> <img src="/badge.png" /> </BadgeFrame>

ShapeTag & RarityBadge

Category tag chips and badge rarity labels

ShapeTag
7가지 쉐이프 × 8색 태그 팔레트, colorIndex로 순환. 텍스트 레이블 칩 또는 배지 썸네일 박스 두 용도로 사용.
<ShapeTag shape="hex" colorIndex={3}>SPA AT HOME</ShapeTag> <ShapeTag shape="triangle" colorIndex={1} style={{ width: 64, height: 64 }}> <img src="/medal.svg" /> </ShapeTag>

쉐이프: rect · pill · circle · dome · triangle · flag · hex

RarityBadge
배지 희귀도 필 레이블. 4색 매핑 고정 — 사용자가 학습한 색상 언어이므로 재매핑 금지.
<RarityBadge rarity="legend" />

rarity: common · rare · legend · mythic

Buttons

Borderless pill-shaped buttons — no borders on any button

Button
3가지 variant(primary filled · secondary soft-fill · ghost text-only) × 2가지 surface(light · dark). 최소 터치 타겟 44px.
<Button variant="primary">드랍하러 가기</Button> <Button variant="secondary">취소</Button> <Button variant="ghost">더보기 →</Button> <Button variant="primary" surface="dark">화이트 버튼</Button> <Button variant="primary" fullWidth>전체 너비</Button> <Button variant="primary" disabled>비활성</Button>
IconButton
44×44 원형 아이콘 전용 버튼. icon은 Lucide 아이콘 이름(CDN 로드).
<IconButton icon="chevron-left" label="뒤로" onClick={goBack} />

Cards

3 structural patterns — color not prescribed, applies any token

Pattern A — Photo Tile
이미지 그리드 셀. 오버레이 태그 포함. 컬러는 상위 컨텍스트가 지정한다.
/* 구조 토큰 */ --radius-card /* 외부 컨테이너 */ --spacing-8 /* 태그 오프셋 */ ShapeTag pill /* 오버레이 레이블 */
Pattern B — Content Card
헤더 이미지 영역 + 썸네일 그리드 + 액션 태그. Card(tone=white) 기반.
/* 구조 토큰 */ Card tone="white" /* 기본 서피스 */ --radius-card /* 외부 */ --radius-xs /* 썸네일 */ --spacing-8 /* 내부 패딩 */ ShapeTag pill /* 액션 레이블 */
Pattern C — Category Card
크기는 절대값 없이 비율만 정의. 외부 카드 1:1 정사각형. 텍스트 상단(flex:2) + 내부 카드 하단(flex:1) → 전체 높이 = 내부 카드 영역 × 3. 내부 카드 1:1 정사각형, 왼쪽 정렬. 유형: C-1(1개) · C-2(2개) · C-3(3개).
/* 외부 카드: 크기는 컨텍스트가 결정 */ aspect-ratio: 1 /* 외부 카드 1:1 정사각형 */ /* 내부 영역 구조 비율 */ flex: 2 /* 텍스트 영역 — 전체의 2/3 */ flex: 1 /* 내부 카드 영역 — 전체의 1/3 */ justify-content: flex-start /* 내부 카드 왼쪽 정렬 */ /* 내부 카드: 크기는 aspect-ratio로 자동 계산 */ aspect-ratio: 1 /* 내부 카드 1:1 정사각형 */ /* height = 내부 영역 높이(stretch), width = height → 한 변 ≈ 외부 카드 너비의 1/3 */ /* 구조 토큰 */ --radius-card --radius-xs --spacing-12 --spacing-4

Forms

Text fields — search and username input

Input
단일 라인 텍스트 필드. 미묘한 회색 테두리, --radius-md(12px). 최소 높이 44px.
<Input placeholder="유저 검색" value={q} onChange={(e) => setQ(e.target.value)} />
Textarea
멀티라인 텍스트 입력. Input과 동일한 스타일 체계. rows prop으로 초기 높이 조정, resize-y 허용.
<Textarea placeholder="리뷰를 남겨주세요" rows={4} value={text} onChange={(e) => setText(e.target.value)} />
Select
네이티브 select 래퍼. 커스텀 드롭다운 화살표, Input과 동일 스타일. options 배열 또는 children으로 전달.
<Select value={sort} onChange={(e) => setSort(e.target.value)} options={[ { value: 'recent', label: '최신순' }, { value: 'name', label: '이름순' }, ]} />
Checkbox
커스텀 체크박스. checked/onChange 제어형. 레이블은 children으로 전달. 포커스·액티브 상태 내장.
<Checkbox checked={agreed} onChange={(e) => setAgreed(e.target.checked)} > 이용약관에 동의합니다 </Checkbox>

Navigation

TabBar and TopNav — 1:1 from the service codebase

TabBar
플로팅 필 하단 내비게이션. 아이콘 전용, 선택 시 채운 아이콘 + 작은 점 표시기. 6개 탭: 투데이·배지·드랍·미션·인벤토리·프로필.
<TabBar active="today" onChange={setTab} /> <!-- active: today | badges | drops | missions | inventory | profile -->
TopNav
서브 페이지(배지 상세, 드랍, 인벤토리 아이템) 전용 스티키 탑바. 루트 화면(Today)에는 사용 안 함.
<TopNav title="배지" onBack={() => router.back()} /> <TopNav title="설정" showBack={false} rightSlot={<IconButton icon="x" />} />
SlidingTabs
슬라이딩 언더라인 탭. 카테고리·필터 전환용. 항목이 넘치면 가로 스크롤. activeIndex로 제어.
<SlidingTabs tabs={['전체', '달리기', '등산', '자전거']} activeIndex={tab} onChange={setTab} />
Accordion
단일 열림(single-open) 아코디언. WAI-ARIA 패턴(aria-expanded, aria-controls, role="region") 준수. grid-template-rows 애니메이션으로 레이아웃 쓰래싱 없음.
<Accordion items={[ { title: '획득 조건', content: '10km 달리기 완료 시 자동 획득됩니다.' }, { title: '희귀도', content: 'Rare — 전체 유저의 12%가 보유.' }, { title: '관련 배지', content: '마라톤 마스터, 새벽 러너' }, ]} />

Overlay

Modal and bottom sheet — focus-trapped dialogs with WAI-ARIA

ModalToast
중앙 정렬 강조 모달. 배지 획득·미션 완료 등 임팩트 순간에 사용. role="dialog" aria-modal. iconSlot prop으로 BadgeFrame 삽입 가능. 오버레이 배경: var(--color-overlay).
<ModalToast message="배지를 획득했어요" type="success" open={show} onDismiss={() => setShow(false)} /> <!-- iconSlot으로 커스텀 아이콘 삽입 --> <ModalToast message="드랍 성공" open={show} onDismiss={() => setShow(false)} iconSlot={<BadgeFrame shape="circle" width={80} height={80}><img src="/badge.png" /></BadgeFrame>} />
BottomSheet
슬라이드업 오버레이 패널. 컨텍스트 옵션·필터·추가 정보 표시용. Escape 해제, 포커스 트랩, 스와이프 투 디스미스는 향후 추가 예정. 오버레이 배경: var(--color-overlay).
<BottomSheet open={open} onDismiss={() => setOpen(false)} title="필터" > <FilterOptions /> </BottomSheet>

Feedback & Loader

Toast, modal toast, and WanderingEyes loader

Loader Timing Policy

Toast
하단 고정 일시적 메시지. 다크 필 쉐이프. type: success · error · info. 자동 해제는 호출부에서 처리.
<Toast message="배지를 받았어요" type="success" open={show} onDismiss={() => setShow(false)} />
Skeleton
콘텐츠 로딩 대기 플레이스홀더. ds-shimmer 애니메이션으로 shimmer 효과. width·height·borderRadius로 형태 조정. prefers-reduced-motion 전역 규칙으로 자동 비활성화.
<Skeleton width="100%" height={20} borderRadius={4} style={{ marginBottom: 8 }} /> <Skeleton width="60%" height={20} borderRadius={4} />
EmptyState
빈 상태 표시 컴포넌트. icon(선택), title, description, action 슬롯. 검색 결과 없음·첫 방문·에러 등 다양한 empty 상태에 사용.
<EmptyState icon="map-pin" title="아직 방문한 장소가 없어요" description="첫 장소를 방문하고 배지를 획득해보세요" action={<Button variant="primary">지도 열기</Button>} />
WanderingEyesLoader
눈동자가 돌아다니다가 주기적으로 깜빡이는 로더. 서비스 코드베이스 NavigationLoader와 함께 사용. eyeColor · pupilColor · duration 커스터마이즈 가능.
<WanderingEyesLoader eyeColor="var(--color-primary)" pupilColor="#ffffff" duration="2s" />
