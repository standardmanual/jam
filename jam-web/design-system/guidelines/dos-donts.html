해야 할 것

  • 크림 바탕(--background)을 유지할 것 — 카드는 흰 면(--surface)과 1px 테두리(--border)로 구분하고 섀도를 쓰지 않는다.
  • 초록 Accent(--accent)는 버튼 같은 면 채우기에만 쓰고, 강조 글자·아이콘·선은 --link를 쓸 것.
  • 완전 필(pill) 반경은 버튼과 태그에 사용하고 카드는 16px(rounded-2xl)을 유지할 것. 입력창은 캡슐(--field-radius)이다.
  • 자간은 쓰지 않고(모두 0) 웨이트는 400·500·600·700 중에서 고를 것 — 본문은 웨이트 400이다.
  • 간격은 4px 기본 배수 스케일(4/8/12/16/24/32/48/64)로 구성할 것.

하지 말아야 할 것

  • tokens/colors.css 팔레트 외부의 색상을 이유 문서화 없이 추가하지 말 것 (amber/mystic-pink 도입 선례는 readme.md 참고).
  • 다크 바탕이나 다크 테마를 만들지 말 것 — 이 시스템은 라이트 전용이다.
  • accent 면 위에 흰 글자를 쓰지 말 것 — --accent-foreground를 쓴다(흰 글자는 2.7:1).
  • 카드에 필(pill) 반경을 섞지 말 것 — 버튼으로 읽혀 버튼의 시각적 시그니처를 훼손한다.
  • 박스 섀도를 추가하지 말 것 — 엘리베이션은 테두리와 면 색으로만 표현한다.
